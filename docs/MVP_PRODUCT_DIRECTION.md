# Story MVP 产品方向

## 一句话产品目标

Story MVP 当前首先解决的不是“生成任意类型小说”，而是快速生成并持续写作一部具有成熟男频商业网文结构的 100 章成长爽文。

当前主要生成目标是：**中文男频成长爽文 / 长篇连载爽文**。

它可以采用玄幻、仙侠、高武、都市异能、末世、求生、游戏、科幻、历史、职业成长、商业、建设、资源经营、诸天或神秘学等外壳。共同点不是题材皮肤，而是主角拥有能够持续利用和放大的非对称优势，通过主动行动获得资源、能力、知识、身份、关系或行动空间，并形成逐级扩大的读者满足。

## 默认读者体验

- 主角主动发现、判断、利用、选择、布局并扩大优势，而不是长期被动受难。
- 核心优势不能轻易复制，能够重复利用并产生复利。
- 早期尽快出现可见收益；收益继续打开新的行动空间。
- 主角的社会位置、资源能力和影响范围持续扩大。
- 冲突随着成长改变形态，不只是数值变大。
- 每隔一段时间有明确兑现；兑现之后产生新的可能性和更大压力。
- 读者能清楚感觉到主角已经和以前不一样了。

## 累积成长与可组合成长

当前 MVP 优先生成主角成长型虚构世界男频长篇。主角必须持续扩大自己能够理解、影响、控制、进入或创造的范围；具体成长可以是力量，也可以是知识、职业、规则、身份、造物、组织、关系网络、世界通行能力或它们的组合。

保留主角主动性、非对称位置、优势可发展、可见阶段兑现、行动空间扩大和长篇阶段换挡，但不规定所有题材都要战斗、突破、资源转修为、固定 payoff 顺序、身份/势力/地图顺序或伦理矛盾。

既有 payoff channel 词可以作为研究观察词，但不是运行时必填项或默认组合。每本书应由自己的成长基因图决定主要兑现方式。

### 经典成长模式是一等公民

可组合不等于主动回避经典结构。资源 → 成长 → 战斗 → 身份 → 更大资源/世界可以是成熟而有效的主干；创新可以来自新的金手指、世界规则、战斗机制、关系反馈、转换方式或阶段变异。使用成熟结构不是失败，没有产生新的因果关系才是平庸。

## 一级成长收益与二级成长收益

产品需要把“主角本人越来越能做什么”和“世界因此结算了什么”分开记录。

一级成长收益是长篇主线持续兑现的个人核心能力，例如力量、战斗能力、核心技能、知识运用、造物、操控、组合或创造能力。它通常保持一条稳定主轴；阶段变异必须改变主角的行动语法，不能只增加数值、范围、职位、信用或权限。

二级成长收益是一级能力运行后的外部结算，例如财富、资源、装备、身份、声望、信用、权限、关系、追随者、队伍、组织、领地、地图和世界入口。除非作者明确选择经营、领主、战争或组织建设题材，职位、行政权限、社会信用、组织规模和公共责任默认属于二级收益。

反哺关系应当保持为：

`一级能力 → 二级收益 → 新资源 / 场景 / 敌人 / 问题 / 入口 → 下一轮一级能力成长`

二级收益可以阶段性成为剧情焦点，但不能长期取代一级能力，变成唯一主线结算。产品不为一级/二级比例设置评分、阈值或 Hard Gate；它只是创作模型和复盘语言。

## 核心爽感来源

根据题材选择，不要求每本书全部具备：信息差、认知差、资源差、效率差、成长速度差、生产能力、规则理解、身份跃迁、财富增长、势力增长、专业能力、隐藏实力、公开证明、他人反应、低成本获得高价值成果，以及把一次优势转成长期渠道或新的世界通行能力。资源经营只是可组合的发动机之一，不能替代本书真正的成长对象。

## 对创新的默认理解

创新优先是“熟悉的爽感底层机制 + 有辨识度的新玩法”，而不是默认更痛苦、更黑暗、更反套路、更高概念或更强伦理困境。失忆、寿命、感情、身份消解和悲剧型代价可以由作者主动选择，但不能仅因为它们特别，就默认比可复利的资源、渠道、生产或权力玩法更适合本 MVP。

## 金手指与主角优势

默认优先设计能改变玩法的优势，而不是单纯增加数值。每个优势应尽量回答：主角能做什么别人做不到？为什么不能轻易复制？第一次如何获利？第二次如何做得更大？如何形成资源、知识、身份或关系复利？如何打开新的故事空间？

例如某本修仙书可以把被判废的丹药转成修炼机会；另一本文明探索小说也可以把残缺知识转成职业条件、世界入口或组织权威。具体转换由本书成长基因图决定，经营渠道只是可组合的一个循环，不能预先规定所有书的成长终点。

## 代价与开局偏置

默认更偏好“代价制造策略”，例如稀缺材料、隐藏要求、冷却时间、处理上限、暴露痕迹、多目标选择或引来更高层竞争者。代价应迫使主角更聪明地使用优势，而不是每次收益后立刻用等价悲剧抵消爽感。

这只是创作偏置，不是 Hard Gate：通常 1—3 章让读者看到处境、核心问题、异常/能力和第一次主动行动；前 10 章完成“发现优势 → 尝试利用 → 遇到问题 → 调整办法 → 第一次真实收益 → 更大机会或敌人”的小闭环；10—30 章逐渐形成稳定循环、资源渠道、能力证明或身份变化。具体章数由故事决定。

## 100 章扩张

100 章不应只是同一循环重复十次，也不应套用固定的“发展—争霸”顺序。默认期待成长网络发生多次组合换挡：主角改变能做、理解、影响、控制、进入或创造的范围；具体换挡可以来自成长对象、行动方式、冲突、验证场景、关系、时间尺度或世界认识的变化。具体结构随题材变化，不套固定阶段。

所有规划先写具体发生什么，再写叙事功能。事件链应先交代触发、行动、反应、转折、高潮、结果和新问题，再说明它如何完成公开证明、身份变化、资源升级或新的压力。

## GBrain 与 Prompt 默认方向

idea、outline、review 的默认 GBrain 查询优先寻找 Reader Promise、Character Desire & Agency、Advantage / Special Capability、Repeatable Reader Loop、Core Progression Grammar、Action-Space Expansion、World Expansion Grammar、Social / Relationship Dynamics、Resource / Economy、Narrative Drive、Phase Transition、Failure / Fatigue Risks、Book DNA、Mechanism、Contrast 和 Reference Program。

除非作者方向明确需要，不把 tragic cost、哲学冲突、道德困境、反套路或身份损失作为默认检索中心。作者可以手动修改创作方向、查询、结果和 Prompt；本产品方向不是题材白名单、评分器、拒绝机制或新的治理流程。

## Experiment Boundary

真实小说实验用于发现系统能力问题，但单本小说的具体创作修正不会自动升级为产品默认。只有跨小说仍然成立的问题，才进入通用 Prompt 或代码；单本小说的世界、角色、能力历史、开篇选择和成长体系只保留在该书的 BOOK.md、章节或 Proposal 中。

## 故事规划与正文实现

故事规划决定发生什么，prose realization 决定如何把已决定的事件写成正文。BOOK §7—§10 构成当前书的 prose profile；详细设计见 `docs/NOVEL_PROSE_REALIZATION.md`。三书蒸馏只是研究证据，不是默认作者模仿。
