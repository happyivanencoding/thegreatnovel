# Composable Growth Genome

## 研究范围

Story MVP 当前研究的是主角成长型的虚构世界男频长篇，优先覆盖仙侠、玄幻、奇幻、高武架空、科幻成长、游戏异界、诸天、多世界、规则怪谈、神秘学、职业与超凡体系、生存、探索、制造、召唤、御兽、机械、路径和序列等方向。

内部笔记与 Reference Corpus 已涉及或包含：诡秘之主、苟在妖武乱世修仙、星空职业者、道诡异仙、万古神帝、百炼成仙、仙逆、武炼巅峰、踏星、飞升之后、琥珀之剑、修真聊天群、超神机械师、全球高武、我在精神病院学斩神。

外部头部样本可包括：仙工开物、遮天、神秘复苏、完美世界、斗破苍穹、诡秘之主、凡人修仙传、神墓、道诡异仙、吞噬星空、轮回乐园、圣墟、全职法师、夜无疆、仙逆、超神机械师、惊悚乐园。

这些是研究样本，不是内置 archetype，也不是固定模板；本轮不为单本作品建立专属运行结构。

## 研究结论

这些作品的共同点不是固定的“资源 → 修为 → 战斗 → 身份 → 新地图”，也不是“生存 → 发展 → 争霸”。更稳定的共同点是：主角拥有或逐渐形成某种非对称位置，主动利用它改变自己能做什么，并不断接触以前无权、无力或无法理解的问题。

成长对象可以是身体/境界、技法/职业、装备/造物、知识/真相、规则理解、生存控制、身份/组织位置、伙伴/召唤体系、领地/势力、世界穿梭、权柄、认知层级、对世界真实性的理解，或由具体小说生成的新变量。它们可以排列组合，不能被固定词表限制。

## Classic Patterns Are First-Class Citizens

Composable 的含义是：小说可以自由采用、修改、分叉、融合任何成熟成长模式，而不是要求每本书都反套路。

以下经典主干完全合法，也可能正是某本书最好的主干：

```text
资源 → 修炼/能力提升 → 战斗验证 → 公开证明 → 身份提升 → 更高级资源 → 更大地图
打怪 → 获得资源 → 升级 → 挑战更强敌人
职业 → 技能 → 任务 → 身份
探索 → 机缘 → 成长 → 新区域
副本 → 战斗 → 战利品 → 构筑 → 更高副本
```

系统不得因为这些模式常见，就默认它们低级、不创新、应当回避或必须打破。创新可以来自元素内容、元素的新连接、核心优势、世界规则、转换方式、循环变异、类型换挡、关系反馈或经典机制的重新组合。

“不要预设所有小说都采用某条经典成长链”只表示不要强迫所有作品相同。如果作者输入、GBrain 证据或当前创意表明某条成熟链最适合本书，应当放心采用，不得仅为了显得创新而回避。

## 主干链与支线网络

成长基因图可以非常简单：一个强主循环加一两个辅助循环就足够。主干可以是资源 → 修炼 → 战斗 → 身份 → 更高级资源，支线再接师徒传承、法宝制造、知识谜团或关系反馈。只要主循环每次运行时风险、能力、对手、payoff 或行动空间发生变化，它就可以长期成立；不要求网络复杂，也不要求每个阶段使用不同标签。

## 成长基因的表达

每本书的 `## 0. 本书成长基因图` 是普通 Markdown，不是 JSON、YAML、Schema 或隐藏运行时配置。它可以用以下开放形式描述：

- 核心组合：本书把哪些原本可能分离的机制组合在一起，例如特殊职业 × 身份伪装 × 神秘知识 × 组织经营 × 世界层级探索。
- 关键变量：只列本书实际需要的变量，变量名称由本书决定。
- 转换网络：允许一对多、多对一、双向反馈、条件转换、延迟兑现、负反馈和中期失效；例如探索 → 知识 → 职业条件，组织身份 → 资源/情报 ↔ 事件完成后的组织地位。
- 循环族：由本书生成真正不同的成长、探索、谜团、制造、组织、关系、生存或世界穿梭循环，并说明各自满足什么读者期待、适合哪个阶段、如何互相供能、何时退居次要。
- 阶段变异：说明 100 章内成长对象、行动方式、冲突类型、验证场景、关系、时间尺度、世界认识或读者好奇心如何换挡；不等于单纯增加敌人强度。
- 核心不变量：即使循环和阶段改变，本书仍要持续给读者的 1—3 种体验。
- 退化风险：只写本书最可能出现的 1—3 种退化，例如谜团只增加不兑现、每个副本都变成拿装备、组织吞掉个人探索或新世界只是旧循环换皮。

任何成长元素都可以重新组合：知识可以解锁职业、提供战斗预判、建立组织权威或发现世界是假的；装备可以是战斗奖励、身份媒介、世界入口、封印物、职业条件或可成长造物；关系可以改变选择、提供世界入口、成为能力组成部分、产生阵营身份，或反过来限制主角。

## 产品边界

产品默认只负责启动“主角成长型虚构世界男频长篇”。作者选定具体创意后，本书成长基因图优先于产品默认方向；它只进入页面可见的 BOOK、GBrain Results、Reference Programs 和完整 Prompt。系统不评分、不检查完整性、不自动选择组合，也不把任何示例转换网络变成所有书的固定配方。
