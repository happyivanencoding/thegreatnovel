# Composable Growth Genome

## 定位

Growth Genome 是已批准创意的整理语言，不是创造世界的第一语言。它位于 Fantasy Seed、World Vision 和 Story Program 之后，位于 Outline 与长期剧情整理之中。

## Classic Patterns Are First-Class Citizens

可组合不等于主动回避经典成长结构。资源 → 成长 → 战斗 → 身份 → 更大资源/世界、打怪 → 资源 → 升级 → 更强敌人、探索 → 机缘 → 成长 → 新区域等成熟主干都可以被作者选择；创新放在本书自己的幻想、能力、世界规则、关系反馈或阶段换挡中。

## 它负责什么

- 忠实压缩已批准幻想不变量与主角欲望；
- 组织一级成长：主角本人越来越能做什么；
- 组织二级收益：财富、资源、装备、身份、关系、势力、领地和世界入口如何服务一级成长；
- 设计至少三次真正改变玩法、力量层级、行动方式、战斗方式或世界关系的阶段升格；
- 组织一个强主循环，确有必要时再补辅助循环；
- 帮助长期故事防止重复，并将主角送入更大的敌人、地图、秘密和世界入口。

## 它不负责什么

- 选择核心幻想；
- 决定主角最强欲望；
- 决定力量是否令人向往；
- 决定世界最震撼的奇观；
- 决定所有对手必须合理；
- 决定每次收益必须有成本；
- 决定故事必须使用职业、行政、审计、合同或制度逻辑；
- 生成 Growth Genome 之前的 Fantasy Seed、World Vision 或 Story Program；
- 自动生成 100 章、十章或正文。

## 一级与二级成长

一级成长是主角个人的力量、战斗、神通、技艺、生命层次、规则掌控、造物或其它核心能力。它必须是读者长期追逐的主轴。

二级收益是一级能力运行后的外部结算。常用反哺关系是：

`一级能力 → 二级收益 → 新资源 / 场景 / 敌人 / 问题 / 世界入口 → 下一轮一级成长`

除非作者明确选择经营、领主、战争或组织建设题材，职位、权限、组织规模和公共责任不能替代主角个人成长。

## 开放表达

每本书的 `## 0. 本书成长基因图` 只需写：已批准幻想不变量、主角核心欲望与超越、一级成长主轴、核心优势阶段升格、二级收益与反哺、主循环、成本节奏、核心不变量和退化风险。

关键变量、一对多转换、多对一转换、条件转换、延迟兑现、负反馈、循环族、旧变量失效和新变量进入，只有本书真实需要时才自然补充，不能默认生成。

同一强主循环可以反复运行，只要能力、敌人、结果、情绪或世界尺度发生真实变化。不要为了显得成熟让每块剧情都强制失去等量收益，也不要让组织治理吞掉个人成长。

## 内部真实

内部因果可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先从力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道和超凡规则产生因果。作者明确选择现实职业或制度题材时，现代程序才成为主要发动机。
