# 三部经典中文长篇网文的 Prose Distillation

## 0. 文档定位

本文只蒸馏《第一序列》《将夜》《诡秘之主》的**书写方式**：场景如何落地、信息如何进入、句段如何随压力变化、对话如何推动行动、动作如何保持清晰、回报如何完成、情绪如何延后释放、章节如何收束。

本文不蒸馏故事设定，不复制原文，不建立作者模仿模板，也不把任何一本书的个人风格升级成所有小说的默认写法。

所有单书观察均为 `REFERENCE_ONLY`。真正执行时，优先服从当前书的 BOOK、作者明确意图、当前场景和已发生事实。

# 2. 《第一序列》：实用主义视角驱动的快速场景

## 2.1 一句话 Prose DNA

以贴近主角的实用主义视角，把废土压力、资源计算、人物关系和黑色幽默压进连续行动；场景通常先解决眼前问题，再用一个反转、回报或笑点改变状态。

## 2.2 十五项观察

### 1. 开篇方式

开篇快速给出身体状态、人物关系和立即任务。世界不是先被讲解，而是通过守夜、打猎、酸雨、食物和壁垒资格等现实约束被看见。

### 2. 叙述距离

主要贴近主角。环境和制度常被主角换算成“能不能活、值多少钱、会不会吃亏、谁值得相信”。这使设定天然带有角色偏见，不像百科。

### 3. 场景推进

行动链条通常很直：

`发现问题 → 立即判断 → 采取办法 → 现场反应 → 得到结果 → 新麻烦或笑点`

读者很少需要等待很久才知道人物在做什么。

### 4. 段落节奏

段落整体偏中短，但并非全是碎段。解释性信息常与对话、动作交替，避免连续长篇说明。高压处会明显缩短，日常交易和关系场景可以稍长。

### 5. 句子节奏

因果连接显性，常用“这时、忽然、不过、然后、因为、所以”等推动阅读。优点是快速清晰；风险是生成模型照抄后变成流水线连接。

### 6. 对话

对话直接、口语化，常形成：

`提问 → 实用回答 → 误解或抬杠 → 反转`

人物经常通过讨价还价、互损、避重就轻显示关系，不需要旁白再解释他们亲近或戒备。

### 7. 幽默

幽默来自残酷环境与人物实际反应之间的落差：别人谈宏大问题，主角先算食物、衣服、学费或风险；人物刚建立体面，下一句又被现实拆掉。

### 8. 动作

动作空间清楚，主角意图、对手反应和环境变化按顺序出现。战斗经常强调速度、力量和结果，外部人物的惊讶承担公开证明。

### 9. 说明

说明最有效时绑定现实用途：军队人数用于逃生判断，药价用于生活压力，制度用于身份门槛。较弱时会在后期变成较长的立场陈述或主题宣言。

### 10. 内心

主角内心活动偏直接，常是快速计算、风险判断和吐槽。它不是纯情绪倾诉，而是下一步行动的准备。

### 11. 细节

细节优先选择有用途的东西：锅、面包、棉袄、药、学费、枪、车辆、通行资格。物件同时承担世界观、资源压力和人物关系。

### 12. Payoff

Payoff 通常立即可见：

- 能力真的解决问题；
- 资源真的到手；
- 身份真的改变；
- 他人真的重新评价；
- 新行动空间真的打开。

之后常接一句轻松反转，降低自我陶醉感。

### 13. 情绪

前中期情绪更多通过照顾、花钱、保护、回头和嘴硬表达。后期主题性情绪更显性，容易进入直接总结。

### 14. 章节结尾

常见结尾是：

- 新任务；
- 一次反转；
- 一句笑点；
- 一个明确资格；
- 敌人或组织注意到主角。

结尾通常很短，直接改变下一章的行动条件。

### 15. 退化风险

最常见的退化是：

- 所有人都拥有相似的吐槽节奏；
- 每次高光都靠围观者连续震惊；
- “不是X，而是Y”反复成为固定句式；
- 转场只靠“这时/忽然/下一刻”；
- 主题由场景自然显现后，又被旁白完整复述。

## 2.3 可迁移控制

- 让世界信息先经过角色的现实需求。
- 让日常资源承担人物关系，而不是另写抒情段。
- 冲突后尽快给出可见状态变化。
- 幽默用于人物防御和关系，而不是每段强行加梗。
- 强动作场景保持意图、反应、空间、结果四步清楚。

# 3. 《将夜》：弹性叙述距离与意象—动作共振

## 3.1 一句话 Prose DNA

在宏观景象、人物近景、日常物件和哲学意味之间弹性移动；用空间、意象、沉默和节奏蓄势，再把关键决定压缩成清楚、甚至朴素的一击或一句话。

## 3.2 十五项观察

### 1. 开篇方式

开篇可以先建立时代、边地、天气和社会秩序，再收束到具体人物。宏观不是百科，而是通过雨、土墙、军营、脚印、茶水和家务进入。

### 2. 叙述距离

叙述距离变化大。它可以俯瞰帝国和历史，也可以靠近一碗面、一只煎蛋、一段沉默。变化通常由场景重心驱动，而不是随机切换。

### 3. 场景推进

场景并不总追求最快。它允许先观察、对话、停顿、回忆，再在压力到位后进入决定。慢不是停滞，而是在积累意义、位置和关系。

### 4. 段落节奏

普通场景中段落较完整；强动作和关键领悟处会突然切成大量短段，甚至让一句话单独成段。短段用于蓄势和定格，不是全书默认格式。

### 5. 句子节奏

常使用较长、平衡、层层递进的句子，也会在关键处用极短陈述完成落点。现代口语、古典语感和作者旁白并存，但要由当前书的声音统一。

### 6. 对话

对话常有身份、立场和未说完的部分。人物会沉默、反问、答非所问，读者从停顿和措辞判断关系。解释性对话之所以成立，是因为提问者真的需要信息，并会把信息用于未来行动。

### 7. 幽默

幽默多为干燥的反差：宏大命题被吃饭、银子、家务或身体需求打断；强者的庄严被人物的实际判断轻轻拆掉。

### 8. 动作

战斗重视空间几何、力量形状、距离、方向和物件。一个决定常被多层观察蓄势，真正命中时反而写得简洁。

### 9. 说明

允许直接讲体系、历史或思想，但通常有三层支撑：

- 人物提问；
- 关系互动；
- 未来用途。

说明不是因为作者想展示设定，而是当前人物需要理解世界。

### 10. 内心

内心不像《诡秘之主》那样持续列出推理分支，更多由叙述者整理成一句判断、一个沉默或一个动作。读者仍能感到人物复杂，但不总听见完整自我分析。

### 11. 细节

善于用少数强物件建立长期意义：雨、城、剑、伞、面、煎蛋、旧衣、书。物件会在后续场景中回响，成为关系和主题的载体。

### 12. Payoff

Payoff 常采用：

`意象或规则蓄势 → 空间关系变化 → 一次清晰动作 → 短句落地 → 余波解释其真正意义`

解释通常放在动作之后，而且不是简单重复结果，而是重新理解结果。

### 13. 情绪

情绪常由食物、照顾、站位、回望、沉默和景象承载。真正强烈的情绪可以最后才被命名，甚至不命名。

### 14. 章节结尾

可以是悬念，也可以是余韵、意象、关系确认或观念变化。不是每一章都强行留下危险，但结尾通常使前文获得新的理解。

### 15. 退化风险

最常见的退化是：

- 每个场景都追求诗意；
- 每个动作都配比喻；
- 作者声音压过角色声音；
- 短句排比成为仪式化模板；
- 发生一件事后连续解释象征、哲理和主题；
- 慢场景没有实际关系或状态变化，只剩气氛。

## 3.3 可迁移控制

- 允许叙述距离随场景改变，但每次变化必须有目的。
- 用少数重复物件形成情绪和关系，不堆感官清单。
- 战斗先建立空间与距离，再写能力名称。
- 重大落点可以比蓄势更简洁。
- 余波应重新解释事件，而不是复述胜负。

# 4. 《诡秘之主》：精确观察、推理链与受控未知

## 4.1 一句话 Prose DNA

以贴近人物的分析意识组织场景：身体感觉、物件位置、规则线索、风险假设和行动验证相互连接；精确不是为了把一切讲透，而是为了让未知更可信。

## 4.2 十五项观察

### 1. 开篇方式

从身体异常进入，再经过自我判断、物件清单、环境异常和记忆碎片逐步扩大问题。每获得一点信息，就产生更具体的新疑问。

### 2. 叙述距离

主要是非常贴近人物的第三人称。外部景物常以人物正在检查的顺序出现，读者看到什么、何时看到，受 POV 严格控制。

### 3. 场景推进

典型链条是：

`观察 → 假设 → 排除或保留 → 小规模测试 → 结果 → 修正判断 → 行动`

这使大量规则说明仍然具有剧情感。

### 4. 段落节奏

短段落和对话段落很多。思考、动作、观察和一句对话经常分开，形成稳定的读取单位。风险是生成模型把所有推理都拆成同样长度。

### 5. 句子节奏

句子本身不一定极短，但经常包含自我修正、备选解释和括号式补充。省略号用于思维停顿、角色克制和信息未完成，而不是单纯制造“人味”。

### 6. 对话

对话通常短、准确，受身份和人设约束。人物说完以后，POV 角色会判断对方为什么这样说、还隐藏了什么、自己应该如何回应。

### 7. 幽默

幽默主要来自内部吐槽、现代认知与异世界身份的错位，以及角色为了维持人设不得不采取的荒谬行动。它不需要所有角色一起讲段子。

### 8. 动作

战斗写清微观动作、位置、能力触发、预判和反制。能力不是单独报名称，而是与先前准备、限制和环境发生关系。

### 9. 说明

说明可以非常系统，甚至以笔记、会议、档案、仪式或推理清单出现。它成立的条件是：

- 当前人物有明确问题；
- 信息会改变决策；
- 结论保留不确定性；
- 说明后有验证或行动。

### 10. 内心

内心活动频繁，但大多承担推理、风险管理、自我纠错和身份控制。情绪往往先被压在程序化行动下面，直到安全或 payoff 后才泄露。

### 11. 细节

物件、价格、衣着、房间、仪式步骤和封印条件都很具体。细节的价值在于建立可验证世界，而不是单纯视觉丰富。

### 12. Payoff

常见结构是：

`前置准备 → 限制显现 → 战术执行 → 结果确认 → 情绪裂口或身份意义 → 状态更新`

强回报往往同时完成能力验证和人物情绪，不需要再写一段“他终于成长了”。

### 13. 情绪

强情绪经常延迟到角色已经完成任务后才出现。面具、姿势、仪式、称呼或日常物件与真实情绪形成反差。

### 14. 章节结尾

章末高度偏向短段落和对话，可以留下规则线索、一个新问题、安静威胁、身份反转，或“日常看似正常但底层异常”的收束。

### 15. 退化风险

最常见的退化是：

- 每个细节都被分析；
- 每段都有多个问号和备选假设；
- 角色全部像同一个理性分析器；
- 说明变成会议纪要；
- 规则精确但场景没有身体感和关系；
- 内心吐槽在高压情绪中破坏重量；
- 每次未知都用同一种“先列三种可能”格式。

## 4.3 可迁移控制

- 精确观察必须服务于当前问题。
- 推理链每推进几步就需要动作、验证或外部反馈。
- 允许结论暂时不完整。
- 人设不仅决定说什么，也决定哪些话不能说。
- 情绪可以延迟，但不能永远被分析取代。

# 5. 三书共同证明的十二条 Soft Controls

## 1. 先确定场景正在发生什么

读者应尽快知道：谁在什么地方，眼前要解决什么，下一步为何必须发生。

## 2. 说明必须绑定当前需要

世界观、规则、历史和能力说明只有在会改变判断、关系、风险或行动时才展开。

## 3. 具体动作先于抽象解释

优先写动作、物件、距离、反应和结果。抽象结论可以出现，但不自动跟在每个动作后。

## 4. 叙述距离可以变化，不能漂移

远景用于空间、时代和群体；近景用于感觉、偏见、误读和选择。切换应由场景功能触发。

## 5. 句段节奏服从压力

短句、长句、短段、完整段都不是好坏指标。问题是全章是否只有一种呼吸。

## 6. 对话必须改变现场

一句对话至少改变信息、关系、选择、风险、行动或情绪之一。否则应压缩。

## 7. 内心必须产生下一步

内心可以吐槽、犹豫、推理或回忆，但应改变注意力、判断或行动，不只是同义解释。

## 8. 动作必须形成因果链

写清“看见什么—做什么—对方如何反应—空间怎样变化—新机会或限制是什么”。

## 9. Payoff 只完整说明一次

不要“提前宣布—现场展示—旁白再总结”。回报后可以写余波，但余波应增加新意义。

## 10. 情绪允许延迟和不完整

人物可以先做事，后感受；可以沉默，可以嘴硬，可以把情绪放进物件和照顾行为中。

## 11. 章节结尾承担状态

结尾可以是悬念、笑点、余韵、关系确认或规则线索，但必须让下一章的世界与本章开头不同。

## 12. Humanizer 审查结构，不审查词表

不全局禁用：

- 省略号；
- 叹号；
- 问号；
- 短句；
- 排比；
- 作者旁白；
- 直接说明；
- “但是、不过、然而”。

只检查它们是否机械重复、失去场景功能或覆盖当前书的声音。

# 6. 场景功能矩阵

| 场景功能 | 必须完成 | 优先手段 | 常见失败 |
|---|---|---|---|
| Opening | 建立身体/空间/问题/期待 | 异常、任务、关系或有压力的日常 | 先讲世界百科；只有氛围没有行动 |
| Ordinary | 显示关系、资源和生活规则 | 食物、工作、家务、交易、小选择 | 日常不改变任何状态；纯填充 |
| Dialogue | 交换信息并改变关系或行动 | 避答、反问、停顿、利益、身份差 | 轮流背设定；所有人同一种机智 |
| Action | 保持空间、意图和反应清楚 | 动作链、位置、能力限制、环境 | 技能名列表；只写强弱不写过程 |
| Exposition | 让信息服务当前决策 | 提问、笔记、教学、调查、现场验证 | 无动机讲解；说明后没有行动 |
| Payoff | 让回报在现场兑现 | 能力结果、资源到手、他人反应、状态更新 | 三次解释同一回报；为了克制削弱爽点 |
| Aftermath | 处理真实后果并打开下一步 | 伤势、物件、关系、责任、安静反应 | 复述战斗；立刻升华主题 |
| Emotion | 让感受改变选择或关系 | 动作、照顾、沉默、距离、注意力 | 动作+内心+旁白+总结四次重复 |
| Ending | 留下新状态或新理解 | 短对话、物件、信息缺口、决定、余韵 | 无因果 cliffhanger；泛化金句 |

# 7. 三种可组合的抽象 Prose Profile

这些不是三本书的替代名，也不是模仿指令。它们是从样本中抽出的表达控制，可以按当前 BOOK 和场景组合。

## 7.1 Practical-Comic Profile

适用：

- 生存；
- 资源；
- 市场；
- 身份门槛；
- 队伍磨合；
- 快速冒险。

控制：

- 优先现实需求；
- 对话直接；
- 行动结果尽快可见；
- 幽默来自人物判断与环境落差；
- 章节结尾可用反转或明确资格。

限制：

- 不让所有角色都讲同一种笑话；
- 不用连续围观震惊代替真正 payoff；
- 不把每个主题都写成口号。

## 7.2 Lyrical-Subtext Profile

适用：

- 世界开阔；
- 关系余波；
- 师徒、家人、长期承诺；
- 大型战斗的蓄势与收束；
- 历史感场景。

控制：

- 选择一到两个意象锚点；
- 允许叙述距离拉远；
- 对话保留沉默和未说完；
- 关键动作落点要简洁；
- aftermath 增加新意义。

限制：

- 不让每段都诗化；
- 不让比喻遮住空间和动作；
- 不用哲理重复解释结果。

## 7.3 Analytic-Mystery Profile

适用：

- 调查；
- 规则；
- 仪式；
- 专业现场；
- 战术；
- 悬疑与知识成长。

控制：

- 观察顺序受 POV 控制；
- 保留备选假设；
- 推理后必须测试或行动；
- 细节可被后续验证；
- 情绪可以延后释放。

限制：

- 不分析所有细节；
- 不让所有角色共享同一推理声音；
- 不把场景写成报告；
- 不用无限问题替代行动。

# 8. 对 Humanizer-zh 的直接修订结论

## 应保留

- 删除无功能填充；
- 删除同义复述；
- 避免机械三段式和均匀节奏；
- 用具体动作和物件替换泛化判断；
- 让角色声音与关系距离不同；
- 信任读者能从现场理解部分含义；
- 保留合理的不规则、沉默和未完成信息。

## 必须删除或改成条件规则

- 全局禁用某些标点；
- 全局禁用某些连接词；
- 全局追求短句或口语；
- 把直接说明一律判坏；
- 把作者旁白一律判坏；
- 把重复句式一次出现就判为 AI；
- 用 AI 分数决定是否通过；
- 为“人味”故意加错字、俚语或逻辑破口；
- 把 show-don’t-tell 变成绝对规则。

## 新的核心判断

Humanizer 不问：

> 这句话像不像 AI？

而问：

> 这段表达是否完成了当前场景的功能？它是否因为重复、均匀、解释过度或声音漂移，削弱了已经决定的故事？

# 9. 映射到 Story MVP

当前 MVP 不需要新建 `prose-dna/` 数据库或风格状态系统。

当前书的 prose authority 直接来自 BOOK：

- `## 7. 叙事结构`
- `## 8. 文风与可操作参数`
- `## 9. 对话特点`
- `## 10. 节奏结构`

建议 Writer 分工：

- Writer A：把小纲写成真实场景；
- Writer B：修连续性、桥接、物件来源和 scene realization；
- Writer C：执行 Prose Realization 与 bounded humanization。

完整蒸馏文档不应每章注入。章节 Prompt 只注入：

1. 当前书 §7—§10；
2. 当前场景相关的简短 Prose Contract；
3. 作者明确的本章表达意图（如果存在）；
4. 当前故事事实与小纲。

GBrain Story Reference Programs 继续负责故事结构，不自动承担来源文风。

# 10. Source-Style Leakage Boundary

运行时不得要求：

- “模仿会说话的肘子”；
- “写成猫腻风格”；
- “用爱潜水的乌贼句法”；
- 复制来源原句、长句、口癖、专名或签名意象；
- 选择一本来源书作为唯一 exemplar。

正确做法是选择抽象控制，例如：

- “本章以现实资源判断驱动对话”；
- “关键动作前允许景象蓄势，命中时简洁落地”；
- “规则信息通过观察—假设—测试进入”。

这些控制必须再由当前 BOOK、角色和场景重新实现。
