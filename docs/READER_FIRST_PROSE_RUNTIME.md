# Reader-First Prose Runtime v1

## 目标

内部叙事模型可以精确描述机制、条件、位置、因果、状态、资源和规则边界；正式正文则优先让读者看见对象、动作、身体变化、环境反应和直接结果。BOOK、Plan、Canon 或 Audit 中出现的策划术语不会自动进入正文。

## 合同位置

`READER_FIRST_PROSE_CONTRACT` 是短的表达层合同，只注入 Primary Writer、Integrator 和已运行的 Specialist，各节点最多一份。Curator 不接收合同，而是输出本章自己的 `Reader-Facing Language` 投影。

合同强调：动作先于术语；常见题材词与本书新造词分开；普通方向、接触和结果词优先；已经通过动作成立的边界不重复解释；自然段随真实节拍变化；重大兑现先落地再写必要限制；主角判断保留个人经历和声音。

这不是术语禁用表、否定词计数器、句长评分器、段落门禁或自动重写循环。

## 上下文投影

- Director 只接收当前大型剧情块、当前章计划条目、压缩成长基因、Canon Index、最近摘要、章末衔接和作者意图。
- Curator 只输出本章相关的 BOOK Contract、Canon、计划、Prose Profile、灵感和四个 Reader-First 区块。
- Primary Writer 接收上一章全文、上上章必要章末、八字段合同、压缩 Canon、成长短投影和 Curated Context。
- Opening 取正文前部，Dialogue 取对白段及邻接段，Action 在被选中时取完整正文，Emotion 取尾部与余波片段。
- Integrator 只接收 Primary Draft、有效 Patch、八字段合同、压缩 Canon、最小权威规则和 Reader-First 短投影。

裁剪只使用确定性的字符和自然段操作，不使用 embedding、语义检索或通用 RAG。
