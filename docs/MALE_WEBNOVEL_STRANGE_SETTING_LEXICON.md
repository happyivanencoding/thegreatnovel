## 使用建议

- World Vision：一次只抽少量、跨类组合，例如“民俗 + 时间 + 梦境”或“机关 + 人格 + 星象”，不要整类搬入。
- Power Seed：优先从“能力机制 / 身体 / 记忆 / 名字 / 时间 / 影子”中取一个异常，再让能力有长期玩法。
- Story Program：词汇只负责打开想象，不自动成为主线；真正是否进入故事由人物欲望与当前 Collision 决定。
- 避免同一本书同时出现太多“权限、资格、维护、分配、治理、流程、运营”类解释；这些不是本词库的目标。
- 如果一个词只是换皮后仍然导向“资源 → 资格 → 入口 → 管理”，应视为没有真正去同质化。
