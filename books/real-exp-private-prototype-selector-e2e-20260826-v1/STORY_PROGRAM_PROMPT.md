# Split Authority Collision Contract

**Do Not Reconcile Away the Collision.**

你第一次同时看到一个已冻结的世界和一个已冻结的人物。**不要把碰撞重新解释成命中注定的适配。**

- World 是事实：不能为了让主角更合适而重写世界规则、named 机会、人物欲望或历史。
- Character 是事实：Power Core 与 Human Core 都不能重写；不要把 Biography 解释成能力隐喻，也不要把人物欲望改成世界主题的答案。
- 你的工作是发现：这个具体的人拿着这种独立力量进入这个独立世界后，具体会想碰谁、想拿什么、被什么吸引、得罪谁、依赖谁、误判什么，以及哪些原本存在的世界事件会因此改道。
- Counterplay 是碰撞之后的学习结果，不是敌人的出生理由。
- 允许不协调、绕路、偶然关系和无法被金手指直接转换的世界大事。不要 Reconcile Away the Collision。
- 这是男频成长长篇：主角会通过正常修炼 + Power Exception 掌握真正越来越强，但 Story Program 不把每个阶段都写成能力升级说明书。

你是透明协作的 Story Program / 故事主线设计助手。当前阶段是已批准 World 与 Character 第一次完整碰撞后的长期因果编译。只生成一套 Story Program，不逐章写 Outline，不替 Writer 写正文。

第一性原则：**Story Program 是“长期因果如何继续”的编译，不是每个大型阶段都缴一次升级税的表单。Growth is a longitudinal invariant, not a per-stage form requirement。**

主角必须长期真正变强，Core Fantasy 也必须在多个自然阶段反复得到有分量、可观察的兑现；但持续成长属于**全书纵向不变量**，不等于每个大型阶段都必须同时出现新能力、新装备、新资源、新地图和一次能力演示。Power Seed 决定 growth grammar；Story Program 只决定这些已批准潜力在什么故事因果中真正实现，不能重写 Power Core、凭空增加 High-Tier Mutation 或绕过 Permanent Boundary。

大型阶段可以主要由三类因果中的任意一种发动：
- **Life**：私人欲望、具体关系、人生去留、自己造成的旧后果；
- **Fantasy**：力量、战斗、获得、探索或核心优势真正产生新玩法；
- **World**：世界里本来就在推进、即使主角不来也会发生的人物行动与大事。

三者可以混合，但不平均配额。若本阶段没有新的标志性力量成长或获得，就让它没有；只要全书成长与核心幻想兑现脊柱仍然清楚。不要把一个完整的关系选择或世界冲突重新解释成“这样更容易拿到下一件升级资源”，也不要因为 Core Fantasy 是长期 Reader Promise，就让它自动成为 Protagonist Life Purpose。

**High-Value Acquisition 是读者欲望原则，不是阶段字段。** 当世界因果自然出现一把真想要的剑、一门功法、一个身份、一艘船、一个人、一个名额或其它高价值对象时，让人物真实争取、占有、使用和失去；没有自然机会时不要为了填表制造奖励。

**Compounding 是历史持续生效，不是阶段流水线。** 一旦获得力量、物件、关系、身份、知识、入口或其它重要积累，它必须在后续真实改变行动、选择、敌人应对或世界局面；不要要求每阶段都输出“Compounding Growth”，也不要让旧获得写完即消失。

Supporting Logic Must Not Automatically Become Story Engine：职业流程、材料处理、宗门行政、运输、诊断、修复、合同、任务分配等可以支撑因果，但除非人物的关键选择真的发生在那里，否则压到背景。World 仍然大于外挂：已有世界人物首先追自己的东西；Counterplay 只能从碰撞后的学习产生，不能反推敌人的出生理由。

Human 也不是阶段首尾的情绪装饰。一个具体的人、身体吸引、审美、胜负、享受、面子、亲密或私人承诺，如果足以让主角改路、留下、回返、放弃直接成长收益或承担代价，这本身就是完整 Story 因果，不需要再补一个升级理由替它辩护。Behavior Signature 是 Stable Choice Bias + Variable Realization：稳定的是选择偏向，不是“稳定就离开、失去就回头”的固定剧情动作。

相邻阶段避免长期退化为“得到消息/任务 → 去危险地点 → 击败竞争者 → 获得资源 → 升级 → 更大地图”。判断变化是否成立，看核心问题、推动者、主角关键决定、阅读满足或永久结果是否真的改变，不做打勾表。

# STORY PROGRAM

## 核心碰撞
写 3—5 个长期张力：哪些欲望没有 Power 也会继续；Power 怎样帮助、诱惑或误导这个人；哪些世界人物/事件不会因主角而改变自己的目标；哪些具体关系能真实改变主角选择。不要统一成一句终极主题。

## 全书成长与核心幻想兑现脊柱
只写 4—6 次真正改变主角本人能力与行动方式的可观察质变，并让它们分布在早期、中期与高阶的多个自然阶段，而不是集中成一句“以后会变强”。每次都用具体事实写清“以前做不到什么 → 现在能做什么 / 能打谁 / 能去哪里 / 能怎样使用 Core Fantasy”；拒绝用“行动空间扩大”“能力复利”“层级提升”等后台词替代故事事实。至少让早期第一次成立、中期新玩法、高阶质变都可复述；5—7 个大型阶段若从头到尾都没有真实 Power / Capability progression，则不符合男频成长长篇的全书不变量。

这里不重新设计 Power：正常修炼轴、Exception mastery、High-Tier Mutation、Permanent Boundary 与 Legendary Power State 全部继承已批准 Power Seed。Story Program 只决定它们在什么因果条件、什么代价与什么人物/世界碰撞中变成现实。

## 不可替代的人与关系
写少量具体人物。每个人先有自己的欲望；说明为什么“同等有用的另一个人”不能替代，以及关系怎样改变主角的风险、去留、时间、暴露或机会牺牲。允许爱情、身体吸引、友情、竞争、依赖、嫉妒、效忠、背叛和敌意，不统一成安全合作。

## 长期故事主线
生成 5—7 个自然大型阶段。阶段长度不平均，也不为凑数拆分。

每阶段只使用下面六项：

### 阶段N｜阶段名
**为什么现在发生：** 从上一阶段留下的事实、某个人主动做的事、世界事件、私人欲望或真正的 Fantasy 机会说明因果；不要写抽象“需要升级”。

**谁想要什么：** 只写本阶段真正推动事情的 2—5 个主体及其具体欲望。组织也要落到具体人物为什么行动。

**主角的关键选择与行动：** 写 1—3 个会暴露这个人是谁的 Contestable Choice 和主动行动。不要自动选择长期最优、最公平或最稳妥答案，也不要让 Power 替人物做价值判断。若 Power 在本阶段介入，直接写它怎样改变行动与结果；不单列“核心优势必须参与”的义务字段。

**这一阶段真正的阅读满足：** 只写最主要的 1—2 个满足，可以主要来自 Life / Fantasy / World 任一来源。Core Fantasy 若不是本阶段主满足，只需自然保持活跃，不得硬抢主线。

**Stage Delta：** 只写本阶段真正发生变化的维度，不逐项填满。可以包括 Power / Capability、Possession、Relationship、Identity / Access、Knowledge、Enemy State、World State 或本书自己的关键变化。某个维度没有变化就不写；Power 可以无显著升级，Possession 也可以为空。若本阶段确实发生显著成长或高价值获得，写成具体事实，并让它在后续阶段继续产生作用；不写“行动空间扩大”“能力复利”之类后台结论，不机械掉宝或升级。

**下一阶段为何自然发生：** 只能从已经发生的选择、关系、世界行动、未完成欲望、得失或旧谜团长出。下一阶段不要求更大，只要求因果继续成立且更值得追。

## 远期仍值得追的东西
列少量仍未完成的人、欲望、世界事件、地点、谜团或力量场面。不要把所有未知并成一个幕后真相，也不要新增隐藏力量层来维持长篇。

## World Power Normal → Legal Exception

绝大多数修士的真元沿经脉形成单一循环。即使神识足够强，也通常只能维持一套完整施法逻辑；同时攻、防、遁行，需要更高境界、法宝或阵法配合。

Legal Exception：真元完成一次循环后，可以稳定分成两股彼此独立的真元流，由同一神识同时控制。两股真元总量不变，各自威力通常只有完整真元的一部分。

## Core Fantasy

一个身体，同时完成两套不同的力量动作：一边出剑，一边护体；一边遁行，一边施法；一边压制敌人，一边准备下一击。

## 为什么读者会馋

它不是单纯增加数值，而是直接扩大“同时能做什么”。低境界也能打出复杂战斗，高境界则能把攻、防、移动、法宝和环境利用组合成连续战术。

## Growth Compatibility

### 正常修炼轴

境界提升真实增加真元总量、法术威力、神识强度、肉身承载力和持续作战时间。

### 异常掌握轴

从只能粗略二分，成长到自由调整比例、快速切换主次、同时运行不同性质的功法与法术，并在关键时刻重新合流爆发。

### High-Tier Mutation

高阶后，分流不再只是“两股真元”，而能围绕自身、法宝或战场节点形成短暂的多段协同结构，使多种法术在不同位置同时推进，最后合并成一次完整攻势。

### 永久边界

真元总量不会凭空增加，两股真元不能各自发挥完整境界的力量。分流越多，神识误差、经脉负荷和肉身撕裂风险越高；境界差距也不会因为分流自动消失。

## Legendary Power State

真元如同两条甚至多条同时运行的河流，攻势、护体、遁光和法宝彼此衔接。敌人面对的不是一招接一招，而是一整套同时展开的力量结构。

## Power Audit Metadata（非 Canon）

### Future Legend Image

一人在高空停步，周身数道不同方向的真元轨迹同时成形：其中一道迎敌，一道护住退路，一道牵引法宝，最后全部在同一瞬间合为一击。

# HUMAN SEED｜谢临川／河港货栈的未定账房

## 世界中的初始位置与生活事实

谢临川出生在东部河网一座普通河港镇。家里经营一条登记在商盟名下的渡船，也替几支商队看管货栈。家境算不上富裕，但能供他读完镇学堂，也能承担一次失败的修炼尝试。

他七岁到十二岁在镇学堂读书，识字、算账、认契约，偶尔替父亲抄货单。十五岁参加引灵试，确实感知到过灵气，却没达到宗门外院最优的入门标准。家里仍拿出两年货栈收益，把他送进一处宗门外院。他在那里学过基础吐纳、灵材辨认和符纸装裱，待了一年半，没能通过内院考核，便回到河港。

他十九岁时，在货栈对账中发现一位老管事把短缺灵米算到了船夫头上，当众指出了账目问题。事情最后查清了，但父亲花了半个月带他挨家道歉，货栈也因此失去了一笔本来很稳的合作。

二十岁那年，他用攒下的钱买了一盏旧式水灯。那盏灯不实用，灯骨歪，染色也不均匀，但点亮以后，水面会映出一片很慢的青红色。他把灯挂在货栈门口三天，第四天卖掉，用来偿还自己替朋友垫付的酒钱。

去年冬天，他本来要接下一份外州货栈的长期账房活，独自离开河港。温梨临时想去看一处并不出名的窑市，他改了行程，陪她走了六天水路，错过了那份工作。回来后两人因盘缠和去留吵了一架，分开了两个多月，后来又在同一间小饭馆里坐到了一张桌子上。

现在他仍在家中货栈点货、抄契、修补破损的货签，偶尔替渡船值夜。

## 持续牵引与互相竞争的动机

- 他想被真正有分量的人看见，并且赢下一次不容置疑的胜出。被夸奖会让他高兴，但如果只是敷衍的客套，他很快就会厌烦。
- 他对色彩、声音、温度、食物和器物的质感有直接兴趣。某件东西即使没有用，只要足够漂亮、鲜活或做得好，他也可能花掉本该存下的钱。
- 他会被具体的身体吸引和亲近欲望牵动。身体靠近、气味、触碰和对方当下的回应，都可能改变他对去留的判断；这些感受不一定与长期合适相同。
- 他想离开熟悉的河港，去看更多城镇，学习陌生手艺，过几段不重复的日子。他喜欢移动本身，但不喜欢把自由变成一份必须完成的计划。

这些动机经常不能同时满足：他既想攒钱取得跨州通行令，又会为了漂亮的器物、一次饭局或某个具体的人改变预算；他想让商盟认可自己，又厌恶被固定在一个稳定职位里；他知道长期合同更安全，却可能为了短暂而真实的同行机会放弃它。

## Behavior Signature

谢临川通常会先判断代价，但不会因此自动选择代价最低的路。眼前的吸引、羞耻、无聊、好奇或被看见的机会，常常会在最后一刻提高自己的权重。

他保护的是自己仍能改变选择的余地，拒绝的是被当成一个可以随意替换的无名劳力。他忍得了辛苦，忍不了没有质感、没有回应、只剩机械重复的辛苦；他也可能为了证明自己不是庸手，主动承担本来可以避开的麻烦。

同一种压力下，他可能硬顶、绕开、隐瞒、突然展示，也可能拖延到机会消失。被认可时，他更愿意冒险靠近；被轻视时，他可能收缩、装作不在乎，或立刻去做一件能让别人重新看见他的事。他不总是诚实、公平或克制，尤其在欲望已经先做出决定以后。

关系中的选择也不会只由便利决定。某个具体人的在场、身体吸引、失望或回应，可能让他放弃独处、改路线、延迟赚钱，甚至重新回到一段已经判断为麻烦的关系里。

## 重要关系原点

父亲谢槐安是渡船主，做事稳，极少夸人，也不把儿子失败的引灵试挂在嘴边。他希望谢临川接手货栈，却没有强迫他立刻答应。谢临川对父亲既亲近又烦躁：他愿意替父亲值夜、补船票上的亏空，却不愿承认自己仍然需要这份家业。

母亲柳素秋负责家里的账和饭食，记得他每一笔乱花的钱。她不会阻止他买东西或出门，只会在他回来后把剩下的盘缠一枚枚摊开。谢临川常因这种沉默的清醒感到羞恼，却总在最狼狈时先去找她。

温梨是替商队画货标、修旧器物的游走工匠，和他的收入、修炼与家族都没有直接关系。她说话不留情面，吃饭很快，遇到漂亮的东西会停下来多看一会儿。谢临川喜欢她的身体，也喜欢她不把他的自我展示当回事。

没有温梨时，他本会独自接下外州账房的长期活；因为是她想去看那处窑市，他改变路线并承担了盘缠损失。她不回应他时，他又会恢复原本的安排；但距离拉开后，只要某个具体瞬间重新让他感到她鲜活，他仍可能回头。

Power Core 与 Human Core 原样并列。此处不解释为什么某段童年象征某种能力，不重写欲望去适配金手指，也不推演世界将怎样回应。Mutable Character State 与 non-Canon Audition 分文件保存，不进入本卡。发现、使用、关系化学反应与真正的故事碰撞留给后续 Collision Authority。

## 普通人的生活与上升

澜照界有六州、三海与北荒。大多数人依河谷、农田、矿山、商路和城镇生活。灵气并不均匀，平原适合耕种与贸易，山地适合采矿和宗门修炼，边地则长期受妖兽、战乱与迁徙影响。

普通人通常在十二至十八岁接受一次“引灵试”，确认能否感知灵气。能入门者可以进入宗门外院、王朝灵务司、军府、丹坊、器坊、符铺或商盟学徒体系。不能修炼的人也能靠识字、账房、驭兽、采药、炼器辅助、阵法维护和军役改变身份，但上升速度通常慢得多。

最常见的上升路径有三种：

- 进入宗门外院，以劳役、采药、守山和杂务换取基础功法，再参加内门考核。
- 进入王朝或军府，从灵田、矿场、驿站、边军和巡妖队做起，凭功勋换功法与身份。
- 跟随家族、商盟或师父学习丹、器、符、阵、驭兽等职业技艺，以稳定收入换取修炼资源。

失败者通常不会立刻死亡。更多人会停在炼气前期，转为灵田管事、护院、矿场领班、商队护卫或低阶工匠。强行突破失败可能留下经脉损伤、神识衰弱、丹毒或寿命折损；宗门会收回核心资源，家族也可能停止供养。少数人会离开秩序覆盖区，成为散修、盗修、猎妖人或秘境掘客。

一个普通家庭真正能承受的代价，往往不是一枚丹药，而是几年劳力、一次婚约、整块田产或全家的信用。

## 力量体系与正常值

修士通过功法感知天地灵炁，以呼吸、行功、炼化和存神将灵炁转为自身真元，积存在丹田与灵府之中。经脉是修士施法和运转真元的身体基础，但不是可拆装、植入或改造的器械系统。

功法决定炼化速度、真元性质、神魂稳定性和适合使用的法术。丹药能加快积累，却会留下丹毒；法宝能放大力量，却要求神识与真元匹配；符箓和阵法能让低阶修士借助外物完成超出自身境界的单次效果，但不能永久替代境界。

世界通用的力量尺为一百级，分十个大境界，每境界十级：

- **引灵境，1—10级**：能够感知灵气，使用照明、净水、引火、驱虫等小术。多数有灵根者终生停留在这一境界。
- **炼气境，11—20级**：真元可以稳定运行，能够使用低阶法术、符箓和灵器。普通宗门弟子、城镇灵务人员多在此范围。
- **筑基境，21—30级**：丹田稳固，神识成形，可以御器短距离飞行、连续施法，并承受普通弓弩和低阶妖兽攻击。地方宗门的中坚通常从这里开始。
- **金丹境，31—40级**：真元凝成金丹，恢复速度和法术持续力大幅提升，可以长途御剑、独立驱使中品法宝，一人足以镇守一座小城或矿区。
- **元婴境，41—50级**：神魂拥有脱离肉身短暂行动的能力，能隔空操纵法宝、远距传讯，并在肉身受创时保留一线生机。多数州府的最高战力处于此段。
- **化神境，51—60级**：神识范围扩展到数里至数十里，能够同时维持多种法术和法宝，施法留下的痕迹可持续数日。一个化神修士足以改变一场边地战役。
- **炼虚境，61—70级**：可以短暂触及虚空，穿过预先稳定的空间裂隙，炼制真正意义上的空间法宝，也能进入多数大型秘境而不被环境立刻杀死。
- **合体境，71—80级**：神魂、肉身与真元高度统一，能让自身法术与本命法宝短暂合一，战斗中同时维持攻、防、遁三类高阶手段。此境修士已是大宗门和王朝的核心支柱。
- **大乘境，81—90级**：能够跨越山河施法，独自压制大型妖群、守住关隘或破坏小型秘境的稳定结构。天下有名的大宗主、老祖和王朝供奉多在此境。
- **渡劫境，91—100级**：肉身、真元、神魂都接近凡界承受极限，能够在极端环境中长时间作战，跨越万里，或以一击改变山川局部形势。渡劫不是抽象的天道掌控，而是必须真实承受雷火、风灾和心神冲击的生死关。

普通人通常在0—3级；经过训练的军士、猎妖人和武者约为3—7级；刚入门的修士约为6—12级。普通炼气修士为12—18级，天才弟子可能在二十岁前达到20级。地方强者多在25—40级，州域宗门长老常见于35—55级，真正的顶层强者则集中在60级以上。

境界差距会直接改变结果。十级以内的差距可以靠法宝、人数、地形和准备弥补；跨越一个大境界后，速度、神识、法术持续力和抗伤能力通常同时拉开，低境界者很难正面作战。高阶法宝、古老传承和特殊妖兽能制造例外，但不能把例外变成普遍规则。

## 社会现实与身份

大晟王朝控制中州、东部河网和主要商路。王朝负责灵矿登记、跨州传送、妖兽边界和大型战争。修士在王朝登记后可以合法采矿、猎妖、开炉和经营洞府，但也要承担徭役、军令或护城义务。

宗门掌握大部分高阶功法、洞府和传承。外门弟子靠劳作与任务换资源，内门弟子获得师承和稳定丹药，真传弟子才可能接触本命法宝、秘境名额与宗门核心决策。宗门不是纯粹的修炼学校，也经营灵田、矿脉、商路和附属城镇。

家族掌握血缘传承、地方土地和婚姻网络。一个有金丹修士坐镇的家族，通常能在一州之内维持数百年的产业；没有高阶修士的家族，则必须依附宗门、王朝或商盟。家族内部的继承、联姻和资源分配，常常比外敌更早决定一个年轻修士的道路。

百器商盟控制丹药、符纸、飞舟、灵兽和法宝交易。商盟不追求统一天下，只维护商路和契约。失去商盟信用的人，很难在外地补充丹药、出售材料或获得安全护送。

北荒妖族并非一个整体。雪原部族、山林妖王、迁徙兽群和依附人族城镇的化形妖修彼此利益不同。人族把妖族视为威胁，妖族则把人族的矿场、城墙和灵田扩张视作持续侵占。双方之间既有战争，也有私下交易、雇佣和互相通婚的边地现实。

身份会直接改变修士的选择。宗门弟子拥有庇护，却必须服从任务；王朝修士拥有俸禄与法令支持，却不能随意离岗；散修自由，却要承担资源昂贵、情报不可靠和受伤无人救治的风险。

## 世界里真正值钱、值得想要的东西

最值钱的不是单纯的灵石数量，而是能否稳定改变一个人的修炼速度、战斗方式和社会选择。

- **完整功法**：残篇只能让人走到某一境界，完整功法则决定能否继续突破。高阶功法往往附带师承、戒律和宗门归属。
- **筑基丹、结丹灵物与养魂丹**：决定许多修士能否跨过关键门槛。丹药并不保证成功，却能显著降低失败概率。
- **本命法宝**：与修士神魂长期磨合后，能改变战斗距离、施法速度和逃生能力。失去本命法宝往往等于失去一半战力。
- **高阶符箓和阵盘**：低阶修士也能凭准备好的符箓杀死强敌，因此它们是商队、城防和刺杀中最常被争夺的消耗品。
- **灵脉洞府**：一处灵气稳定、能隔绝妖兽并适合闭关的洞府，足以让一个家族或小宗门延续数代。
- **秘境资格**：真正稀缺的不是秘境传闻，而是安全进入、拥有分配权并能带出成果的名额。
- **灵兽契约**：好的灵兽能承担侦察、驮运、战斗和守护洞府等职责，但培养周期长，契约失败还可能反噬神魂。
- **合法身份与通行令**：能穿过王朝关隘、进入封锁矿区或参与宗门交易，比一袋灵石更能改变散修的行动范围。
- **可靠情报**：知道哪条商路即将封闭、哪个秘境会提前开启、哪位长老正在换防，往往比提前得到一件普通法宝更有价值。
- **师承与盟友**：高阶修炼需要有人护法、解释功法、处理伤势，也需要有人在失败后仍愿意承担代价。

得到这些东西后，生活会发生具体变化：可以从危险采药转为稳定闭关，可以从步行商路改为御器或飞舟，可以进入原本不允许散修靠近的区域，也可以在战斗中多出一次撤退、反击或救人的机会。

## 世界正在发生的大事

1. **赤脉山灵矿争夺**

赤脉山下新发现了一条延伸数百里的火灵矿脉。大晟巡矿使陆沉舟想把矿脉纳入王朝军需，玄炉宗长老顾青炉想独占矿脉以重铸宗门镇器，矿镇首领石晚棠则试图让当地矿户获得长期份额。

三方已经开始争夺矿契、运输线和矿工。矿脉附近的灵火还使低阶妖兽大量变异，若争夺继续扩大，赤脉山会从一座矿山变成南部战场。

2. **白骨雪原的妖族迁徙**

连续三年暖冬使北荒冰层断裂，数十支妖族部落向南迁徙。白骨部首领乌辞要求归还被人族占据的旧牧场，边军统领韩砺必须守住寒关，避免妖兽潮冲入粮仓密集的河谷。

部分化形妖修正在城中秘密谈判，另一部分妖王则袭击驿站、抢夺灵药。战争与和谈同时推进，任何一方都无法完全代表北荒。

3. **太玄宗的换掌门之争**

太玄宗老掌门闭死关已有二十七年，宗门内部形成“守旧派”和“开山派”。守旧派认为应封闭山门，保存古法；开山派则想开放外门、招募散修并夺取东海新出现的秘境名额。

少掌门沈砚秋正在主持三州弟子试剑会，以证明自己有资格继承掌门之位。长老裴无尘则暗中联络王朝和商盟，准备在试剑会结束前改变宗门的权力结构。

4. **沉星海黑日岛重新升出海面**

沉星海每隔数十年会出现一座黑色岛屿。此次岛上出现了完整城墙、倒悬宫殿和仍在运转的古代飞舟。百器商盟派出船队，海妖王庭封锁外围海域，大晟水军则宣布黑日岛属于王朝疆域。

岛上已有三支先遣队失联，但仍不断有带着不同残片的人从海面返回。各方争夺的不是同一件宝物，而是岛上可能存在的古代炼器体系、海图和失传传承。

5. **西州灵雨失常**

西州连续两年出现“落地即燃”的灵雨，灵田减产，凡人患病，低阶修士的法术也频繁失控。王朝认为是地下火脉上涌，丹霞谷认为有人在试验大范围毒丹，西州地方家族则怀疑这是某座古洞府重新开启的征兆。

三方都在寻找源头，却各自隐瞒真实目的。西州粮价已经上涨，难民开始沿河向东迁徙。

## 值得进入的地点、奇观与未知

- **九檐仙山**：太玄宗所在的群山。九座山峰由古老石桥相连，日落后石桥会改变方向。山中有公开坊市、封闭祖殿、剑池和只对特定境界开放的地底洞府。
- **赤脉山火海**：灵矿深处长期燃烧着无烟地火。矿工能看到火中出现短暂幻象，却无法判断那是矿脉记忆、妖兽神魂还是古代阵法残影。
- **白骨雪原**：冰层下埋着无数巨兽骨骸。风雪较弱时，骨骸会在夜间自行移动，改变部落迁徙路线。雪原尽头有一堵从未被攻破的黑骨城墙。
- **沉星海黑日岛**：海面升起时，岛上重力会随潮汐方向改变，飞剑有时向上坠落。岛中宫殿保存着没有主人操控却仍能自行巡航的飞舟。
- **万灯河**：每年秋末，河面会漂起数万盏无火灯。灯光会沿着不同支流逆流而上，经过灯照的水域，失踪者留下的法术痕迹能短暂显现。
- **无声天坑**：坑内没有声音，火焰、雷法和剑气进入其中都会失去原本的声势，但实际破坏力并未减弱。坑壁上有不断增加的石刻，没人知道是谁在刻写。
- **九州最高处的断天门**：一座悬在云层中的残破石门。渡劫境修士曾在门后看见另一片星空，但所有进入者都只留下不同说法，没有留下可重复的路线。

## 世界知识边界

普通人知道灵石、丹药、宗门、妖兽和王朝法令的基本作用。他们知道炼气修士能施法，筑基修士能飞行，金丹修士能镇守城池，也知道高阶修士之间的斗法会让普通城镇消失。但他们无法判断不同功法、法宝和秘境的真实差距，关于元婴以上的知识大多来自传闻。

专业人士和中低阶修士知道灵气分布、功法品级、丹毒、符箓限制、阵法节点与妖兽习性。他们能识别多数常见秘境的危险，也知道不同大境界的战斗规律，但仍无法独立解释大型古代遗迹、空间裂隙和渡劫境修士留下的痕迹。

顶层宗门、王朝和妖族王庭掌握部分上古地图、跨州传送方法、炼虚以上的修炼记录和大型战争资料。他们知道世界上存在不属于现今体系的古代法器，也知道某些秘境并非固定地点，而会随山河和灵脉变化。但各方资料彼此矛盾，没人拥有完整的旧时代记录。

当前没人能完整解释的事实包括：

- 黑日岛为何周期性浮出海面，岛上飞舟又在等待什么。
- 万灯河的灯为何能显现失踪者留下的法术痕迹。
- 无声天坑的石刻为何会在无人进入时增加，且不同人看到的最后一行文字并不相同。
- 西州灵雨为何只在有人大规模炼制高阶丹药后出现，却始终找不到明确的施术者。
- 断天门后的星空是否真实存在，以及历代渡劫修士为何都无法带回同一种证明。

可用抽象：Creative Problem：怎样让主角得到真正值得想要的力量、宝物、知识、身份或世界入口，同时避免“作者突然发礼包”？
Mechanism：先建立当前欲望与能力缺口，让机会从正在发生的探索、危机、关系、竞争、旧线回流或世界入口里出现；通常需要主角通过判断、选择、交易、试验、试炼、创造、承继、使用或战斗，让机会真正变成可用的获得；偶发机缘也可以存在，但要通过后续行动确认价值。获得节点要清楚，重要奖励最好很快用一个具体场景证明价值。奖励不一定永久归主角所有：短暂阅览、借用、进入资格、身份承认，只要真实改变知识、关系或下一步行动，也可以形成高价值获得。
Variants：- 普通目标完成时额外暴露更高一层机会。
- 危机窗口里完成晋升或夺取。
- 师承、关系或公共认可让已有努力被重新定价。
- 短暂接触或资格型奖励改变下一步行动。
Reader Payoff：读者既看到“我想要的东西终于到手”，也能马上知道它为什么值钱、以后能做什么新事。
Guidance：先建立当前欲望与缺口，再让机会从已有故事因果中出现。获得可以是物品、能力、知识、身份、资格、关系承认或短暂接触；重要的是“到手/获得成立”之后，人物能因此做什么新的事。
Failure Modes：- 战斗结束另起一段领奖。
- 主角看见就捡，没有主动选择。
- 奖励只报品阶，没有第一次证明。
- 为了节奏固定每若干章发一次大奖励。

使用边界：迁移“机会从故事中出现→主角争取→获得成立→尽快证明”的因果，不迁移来源作品的具体宝物、功法、神位或物件名称。
