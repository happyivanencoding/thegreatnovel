Persistent Reader Ruler（长期读者坐标软原则，不新增字段、战力数据库或 Hard Gate）：世界前台的力量、战绩、价值、天赋/适配、技法熟练度、装备品阶、排名、身份与世界层级，都是读者判断优越感、风险和欲望距离的 ruler；当前事件碰到哪把尺，就优先校准哪把，不要求力量尺独占，也不合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、新强敌、越级胜负、高价值获得或世界换挡时，通过当前事件自然刷新：主角现在大致在哪一档 / 对象值在哪一档、正常同档能做到或值到什么程度、这次哪里超标、下一档还有什么可见距离。**Ruler = Compression, not Exposition**：当动作与结果已经让一个事实成立时，优先用一次最相关的、已由 World / approved Story 提供的 benchmark 或懂行者比较替代多轮验证，然后立即推进到新的选择、机会、敌意、获得、关系或行动。Benchmark authority 在上游：Outline / Director 只选择和投影已有基准，Writer 不临时发明互相冲突的公斤、米数、价格或新等级。不要每章报表；目标是让读者在关键换挡后持续知道“现在在哪档、哪里不讲理、眼前东西到底有多值”。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生，再用现场已有的懂行者/对手/同伴的短反应完成“这不该是同层能做到的”比较，让惊讶本身成为爽点；不凭空加围观者，也不做群体吹捧。只有重新估价会改变后续行动（如招揽、畏惧、敌意、竞争、信任或关系位置）时才让态度转变进入剧情，否则惊讶/确认后即可停止。已公开优势的普通重复使用不反复演震惊。

Named Opportunity Value Orientation（Story Program → Outline → Director 编译保真软原则，不新增字段或 Reader Release 类型）：当 Story Program / Approved World 已经**具名**一个试场、选拔、招募、拍卖、传承机会、契约或其它具体机会，并明确它的公开目的、通常回报或成功后可打开的身份/资源/行动入口，只要某章的训练、准备、取舍或行动**因这个机会而发生**，Outline 就必须从第一次因果使用开始保留它的具体名字与已批准价值。**不能把上游的“某商盟公开试场 / 某宗门招募 / 某份契约”降成“公开机会 / 一个资格 / 更大的机会”，再等真正获得时才解释它为什么值。**

第一次成为主角当章欲望、取舍或行动理由时，用一句普通话说清“为什么值得争、成功参与通常能打开什么”。这不是提前宣布主角会赢，也不是 Future Result 预支；只是在诱惑真正进入选择前建立它的已批准价值。通用的“以后会有更大机会 / 可以去宗门军府”不能代替眼前这个具名机会的具体价值。如果上游没有批准其回报，不准临时编造；继续保持未知。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。




# Director Context

## 当前大型剧情块（压缩摘要）

规划范围：预计第1—10章。

窗口终点：矿路实测契在倒悬峡中从一笔路线交易变成真实的救援、古器争夺与部族水路冲突。第10章完成顾停舟取得回潮楔、进入成炉并第一次形成“借身＋回潮楔”的复合，同时失去原本预期的实测尾款。下一段故事因此自然进入回潮楔修复、开炉试与阮青蜃公开追索的阶段。

## 第1—3章：潮路断在账外

具体发生：顾停舟能否在一场被商号提前掩盖的潮路事故中，同时保住人和自己应得的货物份额。

- 商队在低潮期急行，顾停舟从载重、偏移的石桩和潮兽足迹看出旧路线已经失效；护队成炉者为了赶时间，坚持按原计划出发。
- 地潮冲断潮路、潮兽从深潮矿脉方向逃离。顾停舟先要求把救货份额写清，不再接受“出了事再按商号规矩算”的含糊承诺。
- 顾停舟在现实危险中分出第二个真实身体。本体带脚夫退向高地，分身只携带“定住”，钉住即将翻落的矿车。
- 他救下具体的人，也保住自己有明确份额的那辆车；另一批无主杂货被潮水卷走，损失没有被抹平。
- 事故后，懂行的成炉护卫用一次比较确认：普通入潮者连一辆车都守不稳，顾停舟却在救人时守住了另一处。

主要阅读兑现：第一次看见顾停舟同时占据两个真实危险位置，并在章末前拿到可见的保货分成和第一笔个人钱。

Block Delta：

- Power / Capability：顾停舟在真实潮压中完成稳定入潮；借身首次让分身携带“定住”持续执行目标。
- Possession：第一笔完全记在他自己名下的钱，以及没有被商号改写的原始路线记录。
- Relationship：少东家第一次把他视为现场判断者，也第一次面对他要求独立结算。
- Knowledge：潮兽正在从深潮矿脉方向逃离，事故不只是普通潮灾。

代价或余波：无主杂货确实损失，顾停舟没有能力或立场保住所有东西。

推向下一块：原始路线记录既能证明急单损失不是简单天灾，也会暴露深潮矿样和侧路价值，校路官与阮青蜃都将来要这份记录。

## 第4—7章：一张真账，三种价钱

具体发生：顾停舟能否把真实记录换成自己的身份与资本，同时拒绝让任何一方把他重新写回可替换的账房。

- 校路官核查伤亡、兽迹和石桩偏移；少东家要求把超载和隐瞒改成“无主损耗”，否则商号会失去下一批矿运。
- 顾停舟公开交出原始损失记录，却保留侧路坐标，不把自己刚救下的判断无偿交给任何一方。
- 阮青蜃提出买断路线与矿样。顾停舟拒绝单纯卖掉未来，而是以自己为承揽人签下“矿路实测契”，接受预付款、兼容潮髓与独立完成实测的条件。
- 在公开资格与私人高价之间，他选择两边都要：既把事实交给校路台，也要把路线变成自己的资本和议价权。
- 阮青蜃派人夺原件时，顾停舟让一具身体带着可被抢走的抄本离开，另一具身体把原件送进校路台。原件进入官方记录，抄本成为追索目标。
- 正式行潮籍、预付款和兼容潮髓到账。母亲只收下家中真正需要的部分，把余款继续记在顾停舟个人账下；少东家无法再以雇主身份收回路线。

主要阅读兑现：一个只能替商号补账的人，把所有势力都想要的真实记录换成正式身份、个人资本和修炼资源。

Block Delta：

- Possession：足以改变生活的首笔资本、矿路实测预付款和兼容潮髓。

院子里静了一瞬。

试炉里的暗火轻轻跳了一下。

顾停舟看着唐绾。

她没提代管，没提借用，也没说修好了得先交给百炉会验器。她要的是记录，不是楔子。

可三十潮铢不是小钱。

他现在手里有自己的钱，正因为是自己的，才更知道每一枚花出去都得算清。

顾停舟从怀里摸出钱袋，放到铁台上。袋口一松，里面的潮铢撞出清脆的声响。

唐绾看着他。

“我修完，你把它交回我手里。什么时候用，用来做什么，我自己定。”

“可以。”唐绾道。

顾停舟又按住反潮记录。

“你拿记录做作品，不能拿回潮楔当你的东西说。”

唐绾眉梢动了动，像是觉得这句话多余，却还是点头。

“我铸的是我做出来的器，不是你的战利品。”

顾停舟松开手。

唐绾把反潮记录收进自己袖中，又数了数钱袋里的潮铢，推到一旁。

“站远些。”

顾停舟没有退到门边，只退到铁台外两步。

唐绾没赶他。

她提起回潮楔，放进试炉中央的凹槽。炉里的暗火立刻贴上去，像一层红得发黑的水，顺着楔身缓缓爬行。

回潮楔先是发冷，接着微微震起来。

那道细裂亮了。

顾停舟下意识往前半步。

唐绾抬手拦住他：“别碰。里面还有残压，它现在最怕外力。”

他想要它。

唐绾低喝一声。
