# WORLD CHARACTER CONTEXT｜Facts Only

## 普通人的生活与上升
大多数人出生在河谷、山城、海港、盐场、矿镇或宗族村落。

普通人的生活围绕土地、水源、牲畜、商路、兵役、婚姻和税契展开。灵气并没有让所有人都衣食无忧：一块能稳定种出灵谷的田，往往比一间普通铺面贵；能避开妖兽迁徙的村子，比靠近遗迹的村子更适合养家。

没有修行天赋的人，也可以通过很多方式改变身份：

- 学一门能靠灵材吃饭的手艺，例如炼药、制符、驯兽、铸兵、辨矿、修船。
- 进入军府或城防营，靠战功获得田地、户籍和商路保护。
- 投靠宗门、商会、世家，成为账房、管事、护卫、外门弟子或附属家族。
- 和修士、贵族、商人联姻，改变家族的资源位置。
- 把握归潮、矿脉、遗迹开放等机会，用一辈子积蓄换一次翻身。

修士并不自动脱离日常生活。低阶修士仍要吃饭、治伤、交税、还债，也需要有人替他们种田、运货、照顾家人。一个会使三种常用符箓的匠人，未必打得过一名军府校尉，但他的收入和社会地位可能更高。

在许多地方，“有本事”比“能打”更重要。

## 力量体系与正常值
澜生界的修行，本质上是让身体、神识、术式和外物之间形成稳定配合。

施展力量不能凭空发生。修士通常需要经过长期锻炼的身体、可重复的术式，以及灵材、兵器、地势或天气中的至少一种支撑。越强的力量，越依赖具体条件；脱离熟悉环境后，很多修士会明显变弱。

世界中大致存在这样的正常层次：

- **普通人**：能辨认低等灵材，使用简单护身符，偶尔感知到妖兽或灵气变化。
- **纳息者**：可以吸收少量灵气，体力、视力、伤口恢复速度超过常人，能使用短暂的火、风、驱尘、止血等小术。
- **通脉修士**：地方武馆、军府精锐、宗门外门中的常见水平。能连续使用数种术式，独自对付数十名普通人，或猎杀低阶妖兽。
- **立相修士**：一城一镇中的真正高手。能够让兵器、身体或术法形成稳定特征，短距离御空，正面击溃一支普通军队的小队。
- **照域修士**：极其罕见，通常是大宗门长老、强国供奉、边关统帅或大商会的镇场人物。他们能影响一片街区、山谷或河段的战斗环境。
- **更高层次**：存在于传说、古籍和少数仍活着的人身上。其力量足以左右城池、山脉或一场国家战争，但没人能证明所谓“真正无上”是否存在。

世界中本来就常见的能力包括：

- 强化身体、夜视、闭气、抗寒、抗毒。
- 以符箓、阵盘、兵器放大有限力量。
- 驯养灵兽、辨识灵植、改变水火风势。
- 短距离腾挪、御剑或借器飞行。
- 用药物和灵气治疗伤势，但不能随意起死回生。

少数人能够做到：

- 在复杂地形中同时操纵多种术式。
- 让一件兵器随自身修为成长。
- 以声音、香气、梦境或血液影响他人的感知。
- 在归潮期间借助天象施展远超平日的法术。
- 与高阶妖兽建立长期而平等的联系。

这个世界不存在被普遍证实的逆转时间、真正复活、凭空创造生命、永久读心和绝对不死。古代传说里有类似记载，但所有现存证据都不足以证明它们曾经真实发生。

## 社会现实与身份
澜生界有王朝、城邦、宗门、世家、商盟、军府、海国和流动部族。它们彼此重叠，却没有一个机构能统治整个世界。

一个人的身份通常由几件事共同决定：

- 出身家族是否拥有田地、矿山、血缘传承或修士保护。
- 是否有正式师承，能否使用某个宗门的术式和资源。
- 是否拥有城籍、军籍、商籍或宗门凭证。
- 是否欠下债务、血仇或誓约。
- 是否在战场、商路、遗迹或地方灾难中证明过自己。

宗门既是修行场所，也是家族、学校、兵营、医院和产业主。不同宗门差异很大：有的培养剑修，有的经营药山，有的替城池镇压妖患，有的靠海上贸易维持山门，还有的专门替贵族处理不能见光的事情。

修士寿命越长，越容易和普通亲族产生隔阂。一个三十岁才纳息成功的人，可能要面对父母老去、兄弟分家、婚约失效；一个修行有成的人，也可能因为不愿加入宗门而被地方势力排斥。

法律无法覆盖所有力量。

城中严禁大范围术法，但贵族和宗门往往拥有豁免；平民杀死妖兽会得到赏金，杀死修士却可能被当成叛乱；同一件法器，在商会账本里是货物，在宗门眼里是传承，在军府眼里则可能是战略武器。

很多冲突不是善恶之争，而是不同身份的人对同一块土地、同一件遗物、同一段婚约拥有不同的合法解释。

## 世界里真正值钱、值得想要的东西
最值钱的东西不只有修为。

- 能连续三代产出灵谷的土地。
- 一条不会被妖兽和军队截断的商路。
- 记载真实地形、暗河和遗迹入口的旧地图。
- 能让伤势不恶化的高阶药材。
- 一件真正适合自己的兵器，而不是名声响亮的废物。
- 一个愿意在关键时候出面的人。
- 大宗门的正式身份，或某座强城的永久居留权。
- 一支训练有素、不会在归潮期间失控的灵兽队伍。
- 没有被任何势力登记过的矿脉。
- 一份能证明血缘、继承权、土地归属或旧日罪责的原始文书。
- 可以让普通人活得更久、让修士少走弯路的医术和传承。
- 一件能够打开旧时代建筑、但尚未被任何宗门完全破解的器物。

许多人愿意用修为、寿命、婚姻、家产和性命去换这些东西，因为它们不仅改变一个人的力量，也会改变他以后能住在哪里、能带谁同行、谁愿意与他交易，以及哪些敌人会开始认真看待他。

## 世界正在发生的大事
1. **盐商宋照雪正在买空西岸的青灯盐。**  
   青灯盐能延缓灵药腐坏，归潮将至，药材商和军府都在囤货。宋照雪想借垄断盐场成为西岸最大的商主，却被几家老盐户和海盗联手抵抗。她真正担心的不是竞争者，而是自己的三个儿子会在她死后立刻分裂商路。

2. **退隐的剑修魏停山准备向旧宗门讨回一把断剑。**  
   那把剑属于他的师父，三十年前被宗门判定为遗失。魏停山知道剑还在，只是不愿承认它已经被铸成了新任宗主的佩剑。他想要的未必是兵器，也可能只是证明当年的判决是错的。

3. **矿镇少女石晚舟欠下了三家铸器铺的钱。**  
   她继承了一座濒临塌陷的黑火井，打算在归潮前修好一艘古代渡云舟，将矿镇的人和货物一起运出山脉。当地铸师认为她疯了，债主却不肯让她死在矿里，因为那艘船可能真的值一座城。

4. **边关校尉赫连渡想结束一场持续了二十年的小规模战争。**  
   他计划把女儿嫁给敌国守将的长子，以婚约换回一批被扣押的军户。自己的上级认为这是软弱，手下军士则认为敌国根本不会守约。赫连渡没有拯救两国的理想，他只是不想再看见第三代孩子出生在军营里。

5. **驯兽师乌芙正在寻找一头被列为凶兽的白角夔。**  
   她认为那头夔兽不是野兽，而是某种已经失去族群的灵兽。附近的牧场主只想杀掉它，宗门则想活捉繁育。乌芙本人要的是证明自己的判断，并拿回师父死前留下的驯兽名册。

6. **大河下游的三座城正在争夺一条新出现的水道。**  
   地震改变河床后，旧运河干涸，新河却穿过了一个古代墓群。上游城想把河水引走，下游城准备雇佣修士封锁河口，墓群所属的旧王朝后裔则突然拿出文书，要求收回整片河谷。

7. **海国遗民在筹钱买回一座被陆上商盟占据的岛。**  
   他们没有复国计划，只想让三千名流亡者重新拥有祖坟、渔场和一座能供孩子读书的旧城。商盟愿意出售岛屿，却要求遗民承认自己永远放弃海上航权。

8. **归潮前夕，一座沉入地下的古代书库重新露出地面。**  
   书库里可能有失传医术、军阵、炼器图和王朝档案，没人知道哪一类最有价值。几家宗门、王朝密使、盗墓团伙、学者和附近村民都在进入其中，他们彼此的目的并不相同，也未必会因为书库关闭而停止冲突。

## 值得进入的地点、奇观与未知
- **悬瓮城**：整座城市建在一只倒扣的巨型岩瓮内部。上层住着宗门和富商，下层是集市、黑市、矿工和无籍者。城底有一条永远向上流的地下河。
- **沉铃泽**：水面平静如镜，水下却悬着数千口古钟。每逢月蚀，钟声会改变鱼群和妖兽的方向。
- **归潮原**：归潮落地之处，草木一夜之间长成树林，旧兵器、破庙和埋葬多年的灵兽会被重新唤醒。
- **黑火井**：地底火脉贯穿数百里，矿工、铸师、罪修和商人共同生活。井下有从未被任何人走完的旧矿道。
- **白鹭天桥**：一座横跨两国山脉的古桥，桥身没有桥墩，只有每隔百年才会出现的白色灵鸟能找到完整入口。
- **无岸雾海**：地图上写满了危险，却没有人知道海的尽头。海上有漂浮岛、会发光的尸骸、失踪后又归来的船，以及使用陌生文字的贸易者。
- **万兽迁岭**：妖兽每隔数十年沿着固定山脉迁徙。迁徙路线上的村镇必须选择搬走、守住，或花钱向大宗门租借护路修士。
- **古代王朝的地下驿网**：许多驿站仍在运行，却只接待持有早已灭亡的王朝印记之人。

## 世界知识边界
普通人知道：

- 王朝、宗门、商盟和妖兽都真实存在。
- 归潮会带来财富，也会带来灾难。
- 低阶修士可以通过学习和药物产生，但高阶修士需要天赋、师承、资源和运气。
- 许多古代遗迹危险，却不一定藏着宝物。
- 海外和天外都存在未知，但没人能可靠地讲清楚那里是什么。

专业人士知道：

- 不同地区的灵气性质并不相同，某些术法离开原产地后会失效。
- 妖兽迁徙、灵植开花和归潮落点存在规律，但规律并不完整。
- 古代器物通常需要特定材料、血脉、地势或文字才能启动。
- 很多宗门保存的祖师传说经过改写，不能直接当作历史。
- 高阶修士失踪的原因各不相同，不能简单归结为飞升。

顶层势力知道：

- 已知大陆只是澜生界的一部分。
- 古代王朝曾经拥有远超今日的跨域交通和炼器技术。
- 某些力量并非失传，而是被故意拆散、封存或改写。
- 归潮不是自然界唯一的大周期。
- 过去数千年里，至少有三次大范围文明断裂，但断裂之间是否存在联系，没有完整证据。

当前没人能完整解释的事实：

1. 归潮究竟从哪里来，为什么总会避开某些山脉和城池。
2. 沉铃泽的古钟是谁铸造的，钟声为何会影响活物。
3. 为什么有些古代建筑会主动识别已经灭亡的王朝身份。
4. 无岸雾海中的失踪者为何有人能够多年后返回，却失去部分记忆。
5. 传说中的“长生者”究竟是真正活着的人，还是被法器、尸骨和后人误认出来的遗迹。
