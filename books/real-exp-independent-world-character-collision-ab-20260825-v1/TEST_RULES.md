# Test Rules

- Shared protagonist-blind World Vision for A/B.
- World: GPT-5.6 Luna high, GBrain World ON.
- A Character: GPT-5.6 Luna high in a fresh ACP session, sees FULL World Vision + shared Character GBrain.
- B Character: GPT-5.6 Luna high in a separate fresh ACP session, sees only deterministic WORLD_CHARACTER_CONTEXT + the SAME Character GBrain; explicit preserve-mismatch contract.
- A/B each produce 3 Character/Fantasy candidates; candidate 1 is frozen before Story Program, no cherry-picking.
- A/B Story Program: GPT-5.6 Sol high, same Collision prompt, same full World, same Story GBrain; only selected Character differs.
- Stop at Story Program. No Outline / chapters / LLM judge.
