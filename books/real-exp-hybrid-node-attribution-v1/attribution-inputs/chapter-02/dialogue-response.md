# Specialist Audit

1. 旧坡道推车前从“还要走？”到“所以得快”的对白只报出赶路压力，没有让沈砚故意把车推到断灵点的策略、以及唐鹭对车上矿奴的实际顾虑形成潜台词；这一处的重要选择主要靠叙述补完，沈砚的声音也因此趋于通用化。
2. 章末“进哪儿？”与“那条不该有灵气的巷子”主要是在复述地点信息，唐鹭从共同脱险者转为主动协作者的选择没有在对白中落地；她的立场和两人的协作边界可以用更短的现场对话显出来。

# Proposed Patches

## Patch 1
目标锚点：从 `“你知道这车哪里坏？”唐鹭问。` 至 `“所以得快。”`
操作：replace
建议文本：
“你知道这车哪里坏？”唐鹭问。

沈砚摸过车底裂口：“承重骨裂了，前轮会在断轨上卡死。”

“那还推？”

“推到它卡。”

唐鹭盯着他：“你故意的？”

“等阵盘断灵。”

“车里的人呢？”

沈砚抬眼看向车斗：“我先接住车。”
理由：把沈砚主动等待断灵、以矿车作为试点的风险选择交给对白，同时保留唐鹭对车上人的直接关切；两人的短句分别体现器物判断和人员退路，不改变后续卡车、断灵与两次修补的事件顺序。

## Patch 2
目标锚点：从 `“下一班，”他说，“跟我进去。”` 至 `“那条不该有灵气的巷子。”`
操作：replace
建议文本：
“下一班，”他说，“跟我进去。”

唐鹭皱眉：“你听见什么了？”

“下面有人在喘。”

“矿奴？”

“成片的，气都在往下沉。”

唐鹭看向霍沉刚下令的中央矿脉：“他把人往那边赶，你还要进那条不该有灵气的巷子？”

“正要趁没人进去。”

她抹掉掌根的血：“我跟你去。你要是再拿一车人试路，先告诉我。”
理由：先用可听见的呼吸和下沉动作承接破阵片的异常，再让唐鹭明确选择跟随并给沈砚设下协作边界；保留进入支巷、调查吞息脉动和下一章推动，不新增决定或资源变化。
