# Proposed Persistent Canon
- 谢临川仍是照骨城岁库的记名杂役，炼气三层，先天命火微弱，没有宗门身份、血脉资源或可继承的强大传承；他的长期身份与基础能力未改变。
- 他已证明能够从符契、登记牌和岁河痕迹中分辨已经发生、正在发生与尚未来到的变化，并由失效引水符契听见三个月后的黑色天河、看见毁城未来及与北城旧引水渠相连的青灰道果。
- 这项能力不是全知预言：未来只以声音、痕迹和片段显形，谢临川不能因此穿过未来、把道果带回今世，或凭空获得道果、剑意、火种、法宝和灵药等实体成果。
- 已确认黑色天河会在三个月后毁掉照骨城；一枚尚未属于谢临川的青灰道果将在毁城未来与北城旧引水渠发生联系。甲三七原已失效，却被把成熟日期推迟到三个月后的记录重新接回了将来的水里。
- 记录和岁册可能成为未来力量进入今世的通道：甲三七的水痕、待销毁遗言中的隐藏记录，以及定岁宫岁册上不属于今世的日期和三处标记，构成了可持续追查的线索链。
- 本章没有新增或改变任何关系阶段；没有形成长期伤势。改动日期者或相关未知力量的身份、目的与敌对程度仍未确认，谢临川也尚未获得可直接使用的持久实体资源。

# Proposed Chapter Summary
谢临川在岁库清理失效的引水符契甲三七时，听见三个月后的黑色天河并看见毁城后的自己与一枚连接北城旧引水渠的青灰道果。他核对出有人把甲三七的成熟日期改到三个月后，将编号和线索藏进待销毁遗言并把符契单独封存。夜里遗言封条自行渗水，定岁宫岁册浮出不属于今世的日期，并依次点亮照骨城、北城旧引水渠和甲三七的追索标记。

# Proposed Open Promises
- 未来成果仍须以剑意、火种、法宝、灵药、破绽和法则的实体形式落入谢临川手中，而不是退化为全知预言。
- 被截断金丹道路的追杀者将改走新的危险道路；其回归会具体证明未来缺口能够生出不同于原命运的威胁。
- 救命道果不会被简单独吞；照骨城的多人见证与裴照尘的自主选择仍将逐步形成未来道基、锚城和本命法宝。
- 未开遗迹将把取得一件成果推进为保留一座成果生产处；黑色天河源头的昼律将把城市生路推进为区域法则。
- 昼律之后，时间遗弃的古代、尚未诞生的未来仙域和归墟终局会重叠，谢临川必须在果实与可持续生长的道路之间择流。
- 无终猎庭会把未经许可的未来偏移视为缺口，最终以多个终局和单一必胜未来逼迫谢临川回答：拥有选择未来的力量，是否也会把自己变成新的唯一命册。
- 长期终点仍是让九垣界重新拥有选择明日的资格；谢临川留下的不是无限未来宝库，而是能让共同选择的道路稳定降临的规则、承载者和见证网络。
- 查明黑色天河真正来自哪条未来、为何提前在照骨城形成，以及第二次落势能否被延缓而不造成更大的缺口。
- 确定救命道果应保留多少、由裴照尘承受多少，以及城市如何共同见证。
- 查明定岁宫为何无法完整记录谢临川的空白命灯，以及命灯是天生缺失、被谁留下还是来自未来的空位。
- 查明追杀者改走的危险道路如何把失去的金丹真火重新造回来。
- 确定归墟遗民索要的故乡是否真的值得被带回今世。
- 确定未开遗迹中的未来宗门会成为照骨城的盟友、竞争者还是新的战争机器。
- 查明是谁把甲三七的成熟日期推到三个月后，以及该改动与黑线、水痕和黑色天河的关系。
- 查明三个月倒计时究竟从哪一笔改动开始，北城旧引水渠尽头的青灰道果如何成熟、等待何人取走，以及取走它是否要求一座城付出代价。
- 查明不属于今世的日期为何在定岁宫岁册中显现，以及照骨城、北城旧引水渠和甲三七之间的追索路径为何被写入记录。
