# Proposed Active Scene State
当前地点：照骨城北墙中段内侧、第三闸对应的墙根与墙内折角处。北墙符钉已经裂开，裂缝仍在扩张；黑水沿废弃旧引水渠和地底排水孔进入低洼街。低洼街已暂时清空，人员被引向高坡、南坡和旧仓台，照骨城尚未整体迁出。
在场人物：谢临川；裴照尘在他身侧两步处，未离开北墙；北墙和高处仍有守城修士、撤离中的城中人。定岁宫外勤修士不在现场；来护送裴照尘的宗门仍未现身。
即时伤势：无明确外伤，掌心未被割破；黑水冷意曾使手腕血流迟缓，指骨中的剑鸣加重，但尚未确认形成持续伤势。
手中关键物品：来源册；夹有待复核清单。未来废墟飘来的冷灰与其中未熄冷光已落在裂缝旁干燥砖沿，谢临川没有收入袖中；甲三七仍不在他手中，仍与第三闸和改动日期构成线索。
当前敌人或追兵：北墙裂缝和持续涌出的黑水是当前直接威胁；未来拔剑留下的冷白剑痕仍未成形。定岁宫明日辰时将再取岁库经手记录，日期改动者及其背后力量、来护送裴照尘的宗门身份与意图仍未知。
当前倒计时：黑色天河原定三个月后的城毁结果已经以第一道黑水落势提前投到今夜，三个月不再是稳定不动的直线；下一次水声是进入未来坐标的触发条件，但具体时刻不明。明日辰时为定岁宫再次取证的近期限。
下一步直接目标：在下一次水声响起时，从第三闸对应墙内折角进入尚未成为门的裂缝和三个月后的废墟分支，确认并尝试截取尚未成形的剑光；在此之前继续保留灰烬在墙沿，不把它当作已经属于自己的剑或力量，并尊重裴照尘的停手边界。

# Proposed Persistent Canon
- 谢临川仍是照骨城岁库的记名杂役，炼气三层，先天命火微弱，无宗门身份、血脉资源或可继承的强大传承；本章没有改变他的长期身份、基础能力或长期伤势。
- 谢临川已证明能够沿同一岁痕听见并看见尚未发生的实体结果，也能追踪未来结果提前投影到现实的坐标；这不是全知预言。黑水、水声、剑痕和灰烬可以从未来抵达今夜，但未来残剑与真正剑光尚未成形，谢临川尚未获得剑意、残剑或其他未来实体力量。
- 甲三七表面已失效，但旧成熟日期与被挪到三个月后的新成熟日期可同时存在；其来源确认为北城旧引水渠第三闸。日期改动、北墙裂口和三个月后的拔剑结果由三道岁痕交汇到同一处未来废墟坐标，但黑色天河的完整来源与因果链仍未确定。
- 三个月后的废墟中由未来拔剑动作留下的冷灰及未熄冷光已沿不稳定岁痕实体抵达今夜；谢临川将其留在北墙裂缝旁，没有据为己有，因此目前没有新增的持久实体资源。
- 定岁宫命册能够记录谢临川的姓名、记名杂役身份和炼气三层境界，却无法在命灯一栏留下落点；这不是被擦除或遮蔽，而是原本没有可供落笔的位置，原因仍未知。照骨城在命册中也无法保持完整登记。
- 黑色天河威胁已从三个月后的未来结果提前投下第一道现实落势，黑水进入照骨城北墙和低洼街；迁城、守城及是否交出裴照尘的分歧因此成为当下真实冲突，但城市尚未完成迁移。
- 谢临川与裴照尘已首次直接接触。裴照尘明确拒绝被当作救命道果或未来容器，要求保留自主选择，并要求谢临川在他说停时停止；谢临川承诺若查明两者有关会先告知，再询问裴照尘是否允许继续。两人目前是带有明确边界的共同查路关系，尚非已确定的盟友或道基承载关系。

# Proposed Chapter Summary
谢临川抵达北城北墙后，第二次未来水声使本应三个月后裂开的符钉在今夜崩裂，黑水沿北城旧引水渠和地底排水孔进入低洼街，守城修士完成暂时撤离。他通过来源册、被改动的日期、剑鸣和墙上提前出现的剑痕，确认三个月后的自己拔剑留下的结果已投影到北墙，并找到第三闸对应的墙内折角这一未来废墟坐标。谢临川首次与裴照尘正面交谈，接受其自主选择和停手边界；裂缝中随后掉出带有未熄冷光的未来灰烬，他没有将其据为己有，并决定在下一次水声响起时进入尚未成为门的未来废墟分支。
