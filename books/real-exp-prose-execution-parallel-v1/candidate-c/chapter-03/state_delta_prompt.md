冷风贴着沈砚的指节滑过去时，身后的石室里传来一声沉闷的撞击。

石柱根部的回声先一步告诉了他哪里会塌。他没有回头，肩膀抵住左侧岩壁，把药篓横在胸前，沿着那道带风的斜缝侧身挪动。缝隙比刚才更窄，石面上的湿气蹭过他的袖口，胸口的刺痛却比石头更先提醒他山正在下沉。

第二声撞击从背后追来。

裂脊妖兽的爪子撞上塌壁，碎岩从缝口滚落，擦着沈砚的后颈飞过去。他的脚刚要落下，胸腔里的残灯便暗了一瞬。那一点沉重的回声沿着心口往左偏，告诉他前方的石脊下面已经空了。

沈砚收脚，手掌按住右侧岩面，等头顶的石粉落完，才把脚尖探到另一块凸起的石头上。

石头没有动。

他把身体的重量一点点移过去。肩膀上的擦伤被岩壁重新磨开，血顺着衣料往下渗，胸口那片干裂的土地却只传来一阵短促的颤动。石室里的妖兽还在喘，山外的轰鸣隔着岩层滚下来，两个声音在他身后叠成一片。

再往前，缝隙里出现了灰白的光。

沈砚低下头，把药篓先推过去，随后收住腹部，硬从石壁之间挤了出去。湿土在他背后塌了一块，带着碎石堵住刚刚露出的缝口。他撑着地面爬起来时，冷风已经扑到了脸上。

这是山外的风。

他从一面被树根顶裂的旧石壁后面钻了出来。天还没有亮，赤垂山上空却被震起的尘雾染成了死白。旧采石坑就在脚下，坑壁一侧已经沉进土里，几根废弃的木梁斜插在碎石中，像被山吞到一半的骨头。

沈砚站直身，胸口忽然重重一跳。

老井里的水声先传了过来。

不是水流，而是水面撞在井壁上的空响，一下，停一下，像有人在黑暗里用力拍门。紧接着是村路下方的石块摩擦声，细碎的震动顺着地脉往旧坑汇聚。再远一些，几间屋舍的地基同时发出低哑的裂声，木梁被拉扯，瓦片一片片滑落。

沈砚的脸色沉了下去。

村庄的声音正在相继断开。

他抓紧药篓背带，沿着旧运石道往下跑。这里的路被落石掩了大半，他没有走正中的坡面，而是踩着山壁边缘一块块尚未松动的石头下行。胸口的残灯跟着脚步微微明灭，每一次震动都把更远处的回声递到他耳边。

走到村后坡时，他看见了许砺。

原本沿北侧背坡往高处移动的人群已经被逼了回来。第二道裂缝从东坡下方斜斜切过，越过一片灌木，直追到撤离队伍身后。几个年轻人扶着老人退到一块倾斜的门板旁，孩子被抱在怀里，水桶倒了两个，桶里的水混着黑泥淌进裂口。

许砺站在队伍最后，木棍横在手中，正要把一个差点踩空的年轻人拽回来。

“沈砚！”

他看见人，声音里没有松气，只有更快的判断：“地底有路？”

“有。”沈砚跑到他面前，胸口还在起伏，“但不是东坡。”

许砺回头看了一眼那道已经逼到脚边的裂缝：“东坡还能不能绕？”

“不能走了。”沈砚抬手指向东侧，“山根已经断。再往那边挪，整条坡会一起下去。”

许砺没有犹豫。他把木棍往地上一顿，转身朝人群喊：“都听着！东坡不走，往旧坑撤！”

队伍里立刻起了骚动。

“旧坑不是塌了吗？”

“那里连水都没有，去那儿等死？”

“孩子还在屋里，粮种也没拿出来！”

许砺一把抓住最先往东边看的年轻人：“东坡现在就是死路。想活的跟我走，想回屋的自己看地面。”

那年轻人低头看见鞋边的土正在向裂缝里滑，脸色变了，转身去扶身后的老人。

沈砚喘匀一口气，压住胸口传来的沉重回响：“把水桶、种子和屋里最要紧的东西都带到旧坑边。别搬柜子，别搬石磨，能抬的先抬水和种子。”

许砺盯着他：“你要在旧坑接人？”

“只能先试一小批。”

“试错呢？”

沈砚看向自己胸口。衣料下，那片干裂的土地正随着村里的裂声一点点发紧，残灯的火苗压得很低。

“人和地都可能没。”他说，“但只收人，里面的土会死。水和土地必须一起。”

许砺的目光在他脸上停了一息，立即转向村民：“听见没有？水先，种子第二。井绳、火石、锄头，屋里能救命的东西带上。其余的放下！”

他的声音短而硬，像一块钉进松土里的石头。几个人分头冲回村中，另一些人抬起门板，把伤脚的老人和两个孩子送向旧坑。没有人再问沈砚胸口里藏着什么，山体给出的时间已经不允许他们把疑问问完。

沈砚跟着许砺折回老井。

井口的半边石沿已经塌下去，黑水在碎石下面时隐时现。两个年轻人用木柄撬开一块大石，石头刚离地，井壁上方便又落下一片砂砾，险些把其中一人的手砸在下面。

“停。”沈砚伸手拦住他们。

他蹲下来，把受伤的掌心按在剩下的井沿上。

冰冷的石头贴住伤口，血立刻被粗糙的纹理吸走一线。胸腔里的残灯没有亮，只在极深处轻轻颤了一下。那条细弱的脉像一根藏在干土下的线，顺着他的手臂向下探去，穿过井壁，碰到了被碎石压住的水。

沈砚听见了水。

老井下方的水脉没有断，只是被一截塌下的石梁压住。石梁右边的井壁已经空了，继续从那里撬，整口井会往下翻。

“左边。”他说，“先清左边三块，别动那根黑石。”

年轻人将信将疑地照做。第一块石头移开，井壁没有动；第二块石头被拖出来时，黑水从缝里涌了一下。第三块刚松开，右侧那根黑石便往下沉，带着一大片碎石砸进井底。

两个人都白了脸。

许砺抬头看沈砚。

沈砚没有解释。他把呼吸压得更慢，让胸口那点回声沿着井水继续往外走。暗红的波纹在他意识里铺开，碰到村路下方的旧沟，又顺着沟渠的方向折回。老井、村路，还有旧采石坑北侧埋在石屑里的硬岩，三处回声短暂地连到了一起。

他收回手，掌心重新裂开。

“水先别往外挑。”沈砚说，“把井绳和桶送到旧坑，能存多少存多少。井底的水还会回，但不能让人挤在井口。”

许砺点头，转身就安排人手。

沈砚沿着那条旧沟走向村里。裂缝已经越过路面中间，村路像一条被掰开的木板，两侧还勉强搭在地基上。他跨过第一道断口，手掌按住一块埋在路边的青黑色铺石。

回声再次落下。

这一次，他清楚地感到界舟在回应。不是把石头拔走，也不是把裂缝补上，而是在村路下方留下了一点不会立刻散开的牵引。牵引很弱，刚接住路下的土，胸口便传来一阵压迫，仿佛干裂土地上又压进了一块湿重的石头。

沈砚没有继续加力。

他记住这处位置，沿着路边走到几间靠近旧坑的屋舍。屋檐上的灰尘被震得往下落，门槛和地基之间已经张开了细缝。他没有进屋，只在每一座屋舍的地脚各按一下，让那点回声贴着地基沉下去。

第一座屋舍的地基还能撑。

第二座屋舍下面有空洞，回声刚落进去，屋内便传来一声木柜倾倒的闷响。沈砚立即收手，转到旁边一座用旧石垒成的矮屋。那里埋着一截与村路相连的石脉，回声落下后，胸口的刺痛反而缓了一下。

他抬头看向旧采石坑。

三条细弱的牵引在那里汇拢，坑北侧那片被废弃多年的石台下，传来一声比村路更沉的回响。那不是稳定的声音，只是地脉在最后的重量里勉强保住了一点完整。

可眼下，那里是村里仅剩的、能把人聚在一起的地方。

沈砚返回旧坑时，许砺已经带着第一批人到了。

旧坑边铺着一层碎石和薄土。几个水桶靠在一起，桶底沾着井泥；两只麻布种袋被人抱在怀里，旁边放着火石、井绳、锄头和一口缺了耳的铁锅。一个老妇人死死攥着一只褪色的布包，不肯把它放下，直到许砺告诉她里面的种子也要带进去，她才把布包交给身边的人。

更多村民从屋舍间赶来，脸上都是尘土。

有人问：“进去以后，还能看见自己的屋吗？”

没人回答。

沈砚走到坑北石台中央，蹲下来，把双手按进薄土。石屑刺进掌心，胸腔中的残灯与三处回声同时震动了一下。旧坑底部的土面先是轻轻下陷，随后又向外撑开，像有一张看不见的手掌在地底缓慢张开。

一圈不大的土地被牵了出来。

那圈土只比一间屋子的地面大不了多少，边缘还连着几缕枯草和碎石。它没有变成空中的影子，也没有被压缩成一片平面，而是沿着界舟回声的方向，带着根下的湿气和土里的细根，一寸寸脱离旧坑。

沈砚胸口的残灯亮了一下。

许砺看见了那圈土，立即把人往后拦：“先别挤。沈砚说一批，就一批。”

“谁进去？”一个男人问。

“离得近的先来。”许砺看向几个受伤的人和抱孩子的妇人，“伤的、孩子，先站到土圈里。其他人把东西放边上，别压住地。”

那妇人抱着孩子没有动。她看着沈砚苍白的脸，又看了看脚下不断扩大的裂口。

沈砚说：“我只能试。进去不是躲在一个袋子里，里面有地，但现在很小，也不稳。要是灯灭了，谁都出不来。”

这句话让人群更乱了些。

“那还进去？”

“留在这里就能出去吗？”许砺喝道，“东坡已经断了！”

远处传来一声巨响。村路尽头的土面猛地向下塌了一截，几间屋舍的墙脚同时歪斜。灰尘涌过来，所有人的声音都被压低。

抱孩子的妇人咬了咬牙，先迈进土圈。

她的鞋底踩过薄土时，圈内的枯草向两侧伏倒。孩子在她怀里哭了一声，哭声没有散在风里，而是贴着沈砚的胸骨传了进去。暗红的光从妇人脚边升起，沿着她和孩子的衣角向上裹住，既没有撕扯，也没有把他们抹去。

沈砚感觉到一阵新的重量落在胸腔深处。

那不是石头的重量。

是一个人的呼吸、孩子贴在母亲肩头的心跳，还有他们脚下那一小块带着根须的土。干裂土地上裂纹张开，承接住这点重量，残灯的火苗却立刻矮了一截。

妇人的身影在旧坑边淡下去。

下一瞬，沈砚听见胸腔里传来一声落地。

孩子的哭声在那里回荡了一下，随后被一片干土吸住。那块刚刚接入的土地落在原有裂土旁，边缘与旧土没有完全接上，中间隔着一指宽的黑缝。妇人抱着孩子蹲在地上，水桶翻倒，水只在她脚边湿了一小片。

沈砚心口一紧。

还有四个人站在土圈里。他强行把回声往前送了一寸，残灯又暗下去，干土深处传来沉闷的挤压声，像一条细脉被过重的脚步踩住。

他立即截断了牵引。

土圈边缘的暗红光骤然收回，剩下的人踉跄着退了出来。一个孩子的手还伸在半空，被身后的老人一把拉住。

“停。”沈砚扶着膝盖，额角渗出冷汗，“先到这里。”

“才一个？”有人失声道。

“不是一个。”沈砚抬眼看向他们，“里面还有一小块地。再接人，灯会继续暗。”

他把胸口的回声放开一线，让众人听见那片干土里传来的细碎动静。妇人的哭声、孩子压低的抽噎、倒下的水桶撞在地面的声音，全都从他心口深处传出来，模糊，却真实。

人群一下安静了。

有人后退，把怀里的种袋抱得更紧；也有人抬脚想往土圈里冲，被许砺横臂拦住。

“听不见吗？还没轮到你。”

“那里面真有地？”

“有。”沈砚说，“所以不能只把人塞进去。”

许砺看着他：“水呢？”

“还在外面。”

“种子？”

“也在外面。”

“那你先护住里面的人。”许砺转身对村民喊，“水桶和种袋全放到坑北，别让人踩。进不去的先把东西守住，别把活路自己撞断。”

这句话把人群重新拉回了地面。两个年轻人抬着装满井水的木桶过来，桶沿在震动里不断撞响；另一个人抱着种袋，脚下裂开的土几次逼到鞋边，仍咬牙把东西送到石台旁。

沈砚没有再尝试接人。

他把手掌按在那块刚刚形成的锚点边缘，胸腔里的残灯仍然昏暗。里面的妇人和孩子没有消失，气息却很轻，脚下那片新土的湿意正向裂缝里缓慢渗去。它们需要水，也需要更完整的土地，可这些东西现在都还在外面。

井口方向忽然传来一阵石头滚落声。

许砺抬头：“井又堵了。”

沈砚转身就走。

他沿着刚才留下的回声跑回老井。井壁上方的一块大石滑落，正好压在取水的位置，两个年轻人被迫退到一旁。沈砚没有去搬那块石头，而是把手贴在井沿，听见石梁下面的水正在往左侧退。

“把绳子绕到后面的树根。”他说，“别从正面拉。石梁会翻。”

许砺赶来，立即照办。三个人把井绳绕过一截露出土面的老根，另一端套住石梁。绳子绷紧时，山体又震了一下，井口周围的裂缝向外爬，像一圈黑色的手指。

“拉！”

石梁先没有动，随后从底部传来一声闷裂。年轻人被反弹的绳子带得摔倒，石梁却只向左移开半尺。黑水从它下面猛地涌出，冲散了井底的泥。

几只水桶同时放下去。

沈砚听见水落入桶底的声音，也听见村路下方的回声正在变得越来越薄。他回头看向旧坑，坑北的锚点已经被人群和物件围住，许砺带回来的村民越来越多。有人抱着被褥，有人扛着拆下来的门板，有人只拿了一把锄头和一小袋粮种。没有人再搬沉重的家什。

旧坑附近的土地却在裂。

一条细缝从他放下回声的矮屋地基下钻出来，穿过村路，直指石台边缘。沈砚沿着缝看去，胸腔里那条细弱的脉也跟着抽动。它像在告诉他，临时锚点并没有真正接住村子，只是把断开的几处地脉暂时拴在了一起。

拴绳正在一根根崩断。

“沈砚！”许砺在旧坑边喊，“人都到了，最后一队也从西屋出来了！”

沈砚抬头。

许砺站在石台上，身后挤满了村民。水桶、种袋和能带走的东西堆在脚边，老人和孩子被护在中间。仍有人不信那道进入胸腔的生路，但他们已经没有别的路可站。

“还能不能再接？”许砺问。

沈砚看了一眼胸口。

残灯仍在暗处摇晃。那一小片接入的土地像一块被硬塞进裂缝的泥，虽然没有死，却让舟内的细脉发出持续的低鸣。他若现在再接人，灯火未必能撑住；可若不接，外面的地脉会先把所有人连同屋舍一起撕开。

他刚要开口，赤垂山深处忽然传来一声断裂。

那声音比此前所有震动都更慢，也更深。

老井里的水一下失去了回声。村路下方的石脉同时沉默，几座屋舍的地基在同一刻发出脆响。旧坑北侧的石台向下坠了半寸，堆在旁边的水桶翻倒，水沿着薄土迅速流进裂缝。

许砺伸手抓住一个差点跌倒的孩子，抬头望向东坡。

山壁在那里动了。

不是滚下一块石头，也不是裂出一道缝。东坡上方整片被震松的岩层缓慢抬起，灰白的断面从尘雾里显出来，像一堵失去根基的墙。它遮住了天光，也遮住了村口，正朝旧坑和坑边聚拢的人群倾斜下来。

有人发出一声短促的惊叫。

许砺没有让队伍散开。他把孩子塞进身后人的怀里，抄起木棍，朝所有人吼：“别跑！都到石台里来！水和种子放中间，老人孩子靠里！”

村民在他的声音里挤向锚点。有人脚下打滑，旁边的人伸手把他拉住；一个抱着种袋的年轻人摔倒，袋口裂开，种子撒在土上，他没有去捡散开的每一粒，只把剩下的种子抱到石台边。

沈砚听见所有脚步同时落地。

胸口里的残灯也在同一刻狠狠一沉。

他站到石台中央，掌心贴着已经裂开的薄土。老井的回声从左侧传来，村路和屋舍的回声从右侧传来，刚刚接入的那一小块土地则在胸腔深处微弱地回应。三处声音隔着正在断裂的山体相互寻找，像一群快被冲散的人在黑暗里伸手。

东坡山壁压过了村口。

尘土像潮水一样扑来，碎石砸在水桶和屋檐上。许砺把最后一个孩子按到人群中间，回身看向沈砚。

“现在？”

沈砚没有回答。

他知道这一次不能再只接一个人，也不能把人从土地里剥出来。井水、村路、屋舍的地基，还有脚下这片被所有人踩住的土，必须在同一个回声里找到位置。

他把另一只手也按进石台。

胸腔里的残灯在黑暗中抬了一下，微弱的火光照出那片干裂土地上新添的黑缝。缝隙深处，细弱的地脉被过重的回响压得弯曲，却没有断。

沈砚咬住渗血的嘴角，将呼吸一点点压向地底。

旧采石坑下方，三条回声终于在山壁落下之前，响成了同一个声音。
