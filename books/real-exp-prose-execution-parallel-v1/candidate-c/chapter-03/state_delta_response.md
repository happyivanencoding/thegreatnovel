# State Delta Audit

- 旧 ACTIVE SCENE STATE 中“沈砚仍在赤垂山山腹封死石室、沿向上斜缝撤离、下一步确认出口”的状态已被正式正文推进并替换：沈砚已脱出山腹，抵达旧采石坑并往返落石村；本章末尾他位于旧坑北侧石台中央。
- 旧 ACTIVE SCENE STATE 中“裂脊妖兽在塌壁后持续喘息并可能撞开缺口”没有在本次正式正文后续得到确认；正文未确定它是否存活、是否追出，不将其保留为已确认的当前追兵。
- 正式正文确认一名妇人与孩子连同一小块带根土地已进入沈砚胸腔，但新土与原土之间仍有黑缝，妇人与孩子的后续稳定状态、补水和土地能否接合尚未确定。
- 正式正文无法确定旧坑临时锚点能否承受东坡整片岩层的压下，也无法确定其余村民能否安全转移、落石村土地能否保全。
- 掌心割伤重新裂开，肩部擦伤被磨开，嘴角渗血，胸口持续受压并刺痛；正文没有证明这些伤势已成为长期伤势。

# Proposed Active Scene State

- 当前地点：落石村后方的旧采石坑坑北石台，作为临时锚点；沈砚双手按在已裂开的薄土上。东坡整片被震松的岩层已显出灰白断面，正向旧坑和石台倾斜。
- 在场人物：沈砚；许砺；聚在石台周围的落石村村民，包括老人、孩子、伤者及其余撤到旧坑的人。沈砚胸腔内新接入的一小块土地上有一名妇人与孩子。
- 即时伤势：掌心割伤在按井沿、岩面和石台时重新裂开；肩部擦伤被岩壁磨开并渗血；胸口有持续压迫和刺痛，刚以统一回声承受更重负荷；嘴角有渗血。正文未显示骨骼重伤。
- 手中关键物品：药篓仍在沈砚身上，内有灵草和剩余草药；残灯、原有干裂土地、细弱地脉及新接入的带根土地不属于手持物，均在胸腔内。旧坑石台旁另有井水、种袋、井绳、火石、锄头和缺耳铁锅等村民带来的物资。
- 当前敌人或追兵：无已确认的有意识敌人或追兵；东坡失去根基、正向旧坑倾斜的整片岩层，以及持续断裂的村庄地脉，是当前直接威胁。裂脊妖兽的去向和状态未确认。
- 当前倒计时：东坡岩层即将压向旧坑；老井回声已经失去，村路和屋舍地基正在沉默、脆裂，旧坑临时锚点下的三处牵引正在承受断裂压力。残灯已经昏暗，新接入土地与原土未完全接合，细弱地脉被重压弯曲，再增加负荷可能使灯火继续变暗或熄灭、细脉断裂并拖累沈砚。
- 下一步直接目标：在东坡岩层落下前，维持三条回声合一的临时锚点，让石台上的村民、井水、种子和脚下土地找到可承受的位置；优先保住已接入的妇人与孩子及新土，并在不使残灯进一步失稳、细脉断裂的前提下决定能否接纳其余村民。

# Proposed Persistent Canon

- 长期身份：沈砚仍是落石村的采石兼采药少年；没有已证明的血脉、师门、正式修为或身份跃迁。
- 已证明能力：沈砚能结合山风、水声、碎土落向、回声和石脉经验判断地层压力、空隙与较安全的路线；借助残舟结构和胸腔内回声，他还能在触碰前感知岩石、石柱、舟身及地基将要断裂的位置，探出被压住的水脉，并向断开的村路、屋舍地基和地脉放下微弱牵引。
- 新增已证明能力：沈砚能把一小圈带着湿气和细根的土地从外界牵入胸腔，并让一名妇人与孩子连同这块土地进入其中。
- 能力限制：他只能作判断、绕行或承受极小冲击，不能阻止山崩；可接入的土地和承载规模很小，不能只把人塞入而不带土地、水和运行条件。新土尚未与原土完全接合，额外重量会使残灯变暗、细弱地脉受压甚至断裂，并可能反过来拖累沈砚。
- 持久资源与承载：残破界舟、残灯、原有干裂土地和细弱地脉仍在沈砚胸腔内；一小块新接入的带根土地及其中的妇人与孩子也已进入，但状态不稳定、需要水并仍未完全接合。药篓、灵草和剩余草药仍在沈砚身上。
- 关系阶段：沈砚与许砺保持危机中的相互信任与分工；许砺组织村民、优先保存水和种子并配合沈砚的临时锚点。
- 确认知识：老井下方水脉尚未断，只被石梁压住；村路、老井和旧坑北侧石台的回声可以被暂时牵引到一起，但这种牵引并未真正保全村庄。残舟更深处仍有一个更厚重的搏动源，沈砚只收到过模糊方向回应，性质和再次回应的条件未确认。
- 长期伤势：尚未确认长期伤势；掌心割伤、肩部擦伤、嘴角出血和胸口压迫刺痛是当前已确认的伤情。
- 重要敌我状态：尚无已确立的长期敌对势力或追兵；裂脊妖兽在沈砚脱离石室后的存活、位置和行动未确认。落石村及村民的最终状态仍未结算。

# Proposed Chapter Summary

沈砚从山腹斜缝脱出后赶回落石村，与许砺将村民、水桶、种袋等聚到旧采石坑；他以残灯和胸腔地脉回声探明老井水脉，在村路和屋舍地基留下临时牵引，并从坑北石台牵出一圈带根土地。首名妇人与孩子连同这块土地进入胸腔，但残灯变暗、土地未完全接合、细脉受压，沈砚停止继续接人；当许砺聚拢其余村民时，老井和村路回声沉默，东坡整片岩层朝旧坑倾斜，沈砚在石台按住双手，使井水、村路、屋舍和锚点的三条回声在岩层落下前响成同一声音。
