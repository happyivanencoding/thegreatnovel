# Cross-Candidate Review：Candidate A / Candidate C

## 评审边界与判定口径

本评审只读取了以下允许范围内的文件：

- Candidate A：reviews/reader-review.md、reviews/world-engine-review.md、reviews/execution-fidelity.md，以及 chapter-01/formal_prose.md、chapter-02/formal_prose.md、chapter-03/formal_prose.md。
- Candidate C：同名三份 reviews 文件，以及 chapter-01/formal_prose.md、chapter-02/formal_prose.md、chapter-03/formal_prose.md。

正文实际位于 candidate-a/chapter-0X/ 与 candidate-c/chapter-0X/，而不是 reviews/chapter-0X/。没有读取 Candidate B、B 路径、实验外历史实验、生产代码、Prompt、State、Canon 或外部服务。

以下横向比较的是两本在 execution 层的共性与差异，不选择哪一本更好。引用格式为“候选者 / 文件:行号”。

## 总结结论

两本不是同一组失败的复制品。

- 共同的 execution 纹理是：主角先诊断、核对或测量，再施用能力；Writer 都有规律化、否定式、把正确解释及时交给读者的 AI 文风倾向；NPC 在部分场景中承担了较明确的流程或主题功能。
- A 的问题更集中在“解释机制先于兑现、主角仍可被普通理性调查型人物替代、早期资产没有现在归属、正文局部泄漏后台模型语言”。
- C 已经让资产进入主角身体并以疼痛、容量和承载后果约束行动；它的问题是拥有规模和治理尚未形成，群体村民仍容易被写成撤离与物流单位。
- 两份 execution-fidelity 评审都明确判定 Prep 没有形成语义过载；两份也都判定 Director 主要是高保真展开器，但没有把“只是展开器”本身判成质量回归。
- State/Canon 是否造成 recap 无法在本次边界内确认。可以确认正文有重复解释或机制回收，不能把它归因给未读取的 State/Canon。

## 逐项回答

### 1. 两本是否都解释过量？

结论：不是同等强度的共同问题。A 明确存在解释过量；C 有局部解释密集和重复校正，但现有证据不足以把 C 判为整体解释过量。

**共同问题**

两本都反复采用“先否定一个直观解释，再给出正确机制”的句法，并在动作后再把因果关系整理成可复述的链条。A 的评审把这种现象归为“过于整齐的解释和对话结构”，C 的评审也指出“震动—回声—裂缝—暗红—承重”与否定句式的连续重复。[A / reviews/reader-review.md:101-109；C / reviews/reader-review.md:71-79]

因此存在共同的局部解释回收倾向，但不能据此说两本都已经达到同一程度的过量。

**仅 A**

A 的机制解释已被明确判为时间机制解释负担：Chapter 3 在黑水、裂墙和剑痕已经发生后，又用“先有日期被挪动—水声沿日期回来—剑痕落到今夜的墙上”重新整理因果链。[A / reviews/reader-review.md:71-75；A / chapter-03/formal_prose.md:425-429]

随后正文又把日期、水声、墙和未来拔剑结果再收束为“新的通道”和“同一个入口”。[A / chapter-03/formal_prose.md:559-603] 这已经不只是让读者理解规则，而是在具体资产尚未兑现时持续替读者完成机制归纳。

**仅 C**

C 的 Chapter 2 有一段连续规则说明：灯、土地和细脉进入胸腔后，容量很小，再多会让灯暗、脉断并拖住主角。[C / chapter-02/formal_prose.md:271-291] C 的盲读评审承认这段规则说明连续，但同时判断本章状态确实改变，只把“后续若仍只靠规则解释”列为风险，而非本章已经成立的失败。[C / reviews/reader-review.md:21-31]

**未发现/未知**

不能把 C 的局部规则说明直接等同于 A 的整体时间机制解释过量。C 的执行评审明确判定 PREP_OVERLOAD 为 NO，并认为承载上限主要通过重量、根须、灯火和动作后果呈现。[C / reviews/execution-fidelity.md:25-37；C / reviews/execution-fidelity.md:98-107] 这里也不能把正文解释过量与 Prep 过载混为一项。

### 2. 是否都先分析再行动？

结论：是，两本都具有“先分析再行动”的主角行为模式；但它在 A 中更明显地延迟魔法兑现，在 C 中更多是嵌入动作的现场判断。

**共同问题**

A 的谢临川先核对编号、日期、来源和记录位置，再决定藏线、追查或接近裂缝；C 的沈砚先听结构、看碎土方向、敲岩壁、判断承重，再选择路线、诱导妖兽或牵引地脉。[A / reviews/reader-review.md:33-41；C / reviews/reader-review.md:47-55]

两本都不是“能力一出现就直接施放”的写法，而是先为行动建立解释上的充分条件。这是共同的行为指纹；只有当它不断替代风险、欲望和即时选择时，才成为共同的节奏问题。

**仅 A**

A 的分析常常直接变成不行动：他不抓未来剑光、不抽取冷光、不收取灰烬，把“先确认”置于取得资产之前。[A / reviews/reader-review.md:77-83；A / chapter-03/formal_prose.md:225-231、445-485、605-631] 这也是 A 评审标出的 ANALYSIS_BEFORE_MAGIC。

**仅 C**

C 的分析多数立即转成可验证的现场动作：沈砚先判断不能动黑石，再让村民清理左边三块；先听见屋舍下有空洞，便马上收手；先判断妖兽应撞哪面墙，再抽掉薄石。[C / chapter-02/formal_prose.md:107-139；C / chapter-03/formal_prose.md:87-123] 因而 C 没有足够证据被判为“分析拖住行动”，它的风险更接近判断过于稳定、几乎总能正确。

**未发现/未知**

未发现 C 与 A 一样把“先分析”推进到资产长期不兑现。C 在 Chapter 2 已完成残灯、土地和细脉的内化，Chapter 3 又把能力用于井、道路和有限接人。[C / reviews/reader-review.md:25-31、57-61]

### 3. 主角人格是否都被外挂压住？

结论：不是。A 的主角个性确实被未来机制和最优理性选择压平；C 没有被判为可替代，但个人欲望与关系史仍偏薄。

**共同问题**

两本的前三章都大量依赖主角的专业判断和能力规则来组织行动，个人欲望不是每场戏的首要发动机。这个相似点可以作为风险观察，但不能把 C 直接归入“人格被外挂压住”。

**仅 A**

A 明确标出 PROTAGONIST_TOO_REPLACEABLE：如果换成普通理性调查型主角，发现异常、留证、撤人、拒绝未来力量等事件序列基本不变；谢临川几乎总能做出安全且道德上正确的选择，没有个人欲望、恐惧或偏见留下难看的后果。[A / reviews/reader-review.md:35-45、101-109]

未来回声还直接规定了他的注意力：他不断辨认“已发生、正在发生、尚未来到”，即使剑痕和灰烬已经到场，仍把它们放回未来边界。[A / chapter-03/formal_prose.md:189-231、567-617] 这里的外挂不是简单的力量数值，而是已经占据了主角的判断框架。

**仅 C**

C 的评审明确不标 PROTAGONIST_TOO_REPLACEABLE。沈砚的路线依赖采石经验、旧运石道、药草气味、岩壁承重和村庄地形知识，普通理性不能直接替换这些因果来源。[C / reviews/reader-review.md:47-55；C / reviews/world-engine-review.md:86-104]

但 C 仍有较窄的风险：评审指出他的个人欲望和关系史不如技术判断鲜明，几乎每次判断都正确，代价多为疼痛、出血和容量下降。[C / reviews/reader-review.md:53-55、71-79] 这是“技术判断压过人格”的风险，不是已经成立的“外挂压住人格”。

**未发现/未知**

三章不足以判定两位主角的长期人格弧线。A 后续是否会出现真正的失误和私欲、C 后续是否会展开关系史，都不能由当前正文外推。

### 4. 资产是否都有拥有感？

结论：没有共同的“都没有拥有感”。A 的早期资产拥有感弱；C 已经有实际拥有感，但规模和治理感不足。

**共同问题**

两本都把早期资产置于明确边界内，尚未给出稳定、扩张或长期经营结果。A 的果实、残剑和灰烬仍属于未来；C 的内在土地、残灯和细脉会变暗、断裂并拒绝过量。[A / chapter-03/formal_prose.md:577-617；C / chapter-02/formal_prose.md:271-291] 这是未完全结算的共同阶段特征，不是共同的拥有失败。

**仅 A**

A 的前三章没有真正成立的“现在属于我”：未来果实只是预览，残剑未拔，灰烬落入掌心后被放回，甲三七是暂存的调查物而不是力量。[A / reviews/reader-review.md:47-53、85-89]

正文最后仍明确写着“掌心没有剑”，灰烬与冷光被留在砖沿，主角得到的是入口方向和坐标，而非现在可调用的资产。[A / chapter-03/formal_prose.md:605-641] 因而 A 的问题是 OWNERSHIP_PAYOFF_WEAK 与 ASSET_FEELS_ABSTRACT。

**仅 C**

C 的残灯、干土和细脉确实进入沈砚胸腔，成为会随心跳变化、承受外界重量并反过来传递结构信息的内在资产；Chapter 3 又验证了它能接入一位妇人与孩子。[C / reviews/reader-review.md:57-61；C / chapter-02/formal_prose.md:269-305；C / chapter-03/formal_prose.md:141-181]

C 的问题不是“没有拥有”，而是 OWNERSHIP_SCALE_NOT_FELT：土圈只比一间屋子的地面大一点，接入一对母子后灯就变暗，水和种子仍在外面，主角不能决定空间内部的长期规则。[C / reviews/reader-review.md:57-61、89-91]

**未发现/未知**

未知 C 的内在资产能否稳定、恢复和形成资源循环，也未知 A 未来是否会取得真正的第一件资产。[C / reviews/world-engine-review.md:106-117；A / reviews/world-engine-review.md:68-75]

### 5. 世界是否都只围绕主角转？

结论：两本都不是。两本的世界引擎都已显示出主角不在场时仍继续运转。

**共同问题**

未发现“世界只对主角有价值”或“所有事件都等主角触碰后才发生”的共同问题。A 的世界引擎评审明确写出外勤追查、城内迁守交人争论、符钉裂开和黑水上涨在主角没有取用未来资源时继续推进。[A / reviews/world-engine-review.md:17-27、49-56]

C 也明确写出沈砚尚未回到村口时，老井已翻水、动物已逃离、许砺已组织撤离；他进入地下后，村路、屋舍、村民和妖兽继续变化。[C / reviews/world-engine-review.md:68-84；C / chapter-01/formal_prose.md:17-25、41-65]

**仅 A**

没有仅 A 的“主角中心世界”问题。相反，A 的城中人、守城修士、外勤修士和裴照尘都有自己的即时目标；Chapter 3 的撤离和迁守争论并不等谢临川批准。[A / chapter-02/formal_prose.md:205-231、373-419；A / chapter-03/formal_prose.md:101-127、503-525]

**仅 C**

没有仅 C 的“主角中心世界”问题。许砺在沈砚不在场时独立带队、改变路线和分配物资，村民也在沈砚往返老井与旧坑时自行取水、取种和搬运。[C / reviews/world-engine-review.md:50-66、70-84；C / chapter-03/formal_prose.md:35-79、231-279]

**未发现/未知**

这里只能判断前三章。A 的最初水痕是否由主角接触甲三七触发，评审明确保留未知；C 的长期政治、派系和灾后秩序也未出现。[A / reviews/world-engine-review.md:54-56、68-75；C / reviews/world-engine-review.md:106-117]

### 6. NPC 是否普遍功能化？

结论：两本都有“角色或群体承担场景功能”的共同倾向，但都不能概括为所有 NPC 都是空壳；A 更像主题/机制代理，C 更像人口与物流单位。

**共同问题**

两本的 NPC 经常被分配单一的现场任务：追查、调度、阻拦、搬运、撤离或替主角说出规则。A 的评审指出外勤修士、守修士和裴照尘的功能分工很清楚；C 的评审指出村民整体常以队伍、批次、老人孩子、水桶和种袋携带者出现。[A / reviews/reader-review.md:101-110；C / reviews/reader-review.md:71-79、93-97]

共同问题是“功能承担超过了个体欲望的展开”，不是“所有 NPC 都没有动作”。

**仅 A**

A 的特有表现是主题代理化。裴照尘与谢临川轮流说出“救城和拿走我的明天不是一件事”等完整立场句，外勤修士则像制度记录的平声部。[A / reviews/reader-review.md:103-109；A / chapter-03/formal_prose.md:371-405]

这仍有局部反例：裴照尘挡住视线、拒绝被当作容器并拦住冲回低街的少年，确实改变了现场行动。[A / reviews/execution-fidelity.md:48-55；A / chapter-03/formal_prose.md:311-325、541-553] 因而只能标为对话和角色功能化倾向，不能说他普遍没有主体性。

**仅 C**

C 的特有表现是群体人口化。许砺相对具体，但普通村民更多按“第一批”“最后一队”“老人孩子”“水桶和种袋”出现，缺少姓名、独立目标和对空间分配的持久立场。[C / reviews/reader-review.md:93-97]

正文确实给了老妇人攥种子布包、年轻人搬水和孩子等动作，也给了村民对屋舍、粮种和进入顺序的短暂分歧。[C / chapter-03/formal_prose.md:131-139、149-217、243-279] 所以 C 是中等程度的人口单位化，不是彻底功能化。

**未发现/未知**

“普遍”需要更多章节才能确认。当前 A 有具体的裴照尘，C 有具体的许砺及若干有动作的村民；不能把局部功能化扩展成全体 NPC 的结论。

### 7. Director 是否都过度机械？

结论：两本的 Director 都主要是 Outline 的高保真展开器，但没有足够证据把“展开器”本身判成过度机械或质量问题。

**共同问题**

共同的结构特征是 Director 没有增加 Outline 之外的主要因果决策：A 的执行评审判定三章 DIRECTOR_AS_EXPANDER_ONLY=YES，并说明第 2、3 章的现场顺序和阻力仍服务于原事件链；C 的评审也判定三章逐项重述当前章条目，没有增加新的因果决策或关系转折。[A / reviews/execution-fidelity.md:9-21、57-63；C / reviews/execution-fidelity.md:3-23]

这是共同的流水线形态，不自动等于过度机械。

**仅 A**

未发现 A 独有的 Director 质量损失。A 的评审明确说高保真展开本身没有造成文本质量损失，问题出在 Chapter 3 Writer 正文的设计语言，而不是 Director。[A / reviews/execution-fidelity.md:59-63、71-81]

**仅 C**

未发现 C 独有的 Director 质量损失。C 的评审将其称为“能力冗余而非质量损失”，并指出 Outline 已经足够细，因此 Director 不重新设计不构成回归。[C / reviews/execution-fidelity.md:15-23]

**未发现/未知**

本次没有读取 Director 实际文件，只读取了两份允许范围内的 execution-fidelity 评审；因此可以确认评审结论“主要是展开器”，不能进一步审定 Director 的逐句机械程度。现有材料不足以把它升级为问题标签。

### 8. Prep 是否都过载？

结论：不是。两份执行评审都明确判定 PREP_OVERLOAD=NO。存在上下文体量或字段冗余观察项，但没有证据证明语义输出过载并导致正文回退。

**共同问题**

未发现共同的语义 Prep 过载。A 的第 3 章 Prep 虽然密集，但评审认为每次重申都绑定触发、行动边界、结果或结尾推动；C 的 C2/C3 输入上下文虽重，输出仍保留当前危机、局部承载、人物行动和下一步推动。[A / reviews/execution-fidelity.md:65-69；C / reviews/execution-fidelity.md:25-37]

**仅 A**

没有仅 A 的 PREP_OVERLOAD。A 的评审只记录第 3 章合同内容密集，且时间逻辑绑定摸墙、比对日期、判断裂口和决定不伸手等现场动作。[A / reviews/execution-fidelity.md:65-69]

**仅 C**

C 有一个 A 评审中没有同样量化呈现的结构性观察：C2 输入为 632 行、C3 输入为 1011 行，重复携带未来资源、人口和空间规划资料。[C / reviews/execution-fidelity.md:29-37] 但该评审明确说这些内容没有进入 Prep 八字段输出，也没有造成正文失焦，因此这是上下文冗余，不是已成立的过载。

**未发现/未知**

未发现任一候选的语义过载证据。State、Canon 和实际 Prompt 不在本次允许读取范围内，不能从输入体量直接推断下游一定发生了 recap 或质量损失。

### 9. Writer 是否有相同 AI 文风问题？

结论：有相同“家族”的 AI 文风问题，但不是同一个具体故障。A 还出现后台设计语言泄漏；C 的设计语言评审为 NO，主要问题是物理模拟器式规律、连续否定和钩子节拍重复。

**共同问题**

两本都表现出：

1. 物理或超自然变化一出现，就迅速告诉读者“它不是什么、它究竟是什么”；
2. 主角几乎总能做出正确判断，错误和误会很少；
3. 章节末尾把复杂现场整齐收束成一个下一章钩子；
4. NPC 对话容易承担规则说明或价值立场。

A 的评审列出整齐解释、主题代理对话和系统最优选择；C 的评审列出同一套物理词汇接管不同场景、否定式解释、判断过准、功能化对话和重复钩子。[A / reviews/reader-review.md:101-109；C / reviews/reader-review.md:71-79]

**仅 A**

A 独有的是设计模型词汇直接进入正式正文：第三章写出“坐标已经出现了”“入口的方向”“新的通道”“同一个入口”“废墟分支”。[A / reviews/execution-fidelity.md:71-81；A / chapter-03/formal_prose.md:463-471、559-603、625-647]

因此 A 被明确标为 DESIGN_LANGUAGE_LEAK=YES，最近失败层是 Chapter 3 Writer；这不是事件或 Canon 边界错误，而是后台结构被说成了小说叙述。[A / reviews/execution-fidelity.md:9-21、95-116]

**仅 C**

C 独有的是“物理模拟器换素材”的质感：第一章山崩、第二章舟室与妖兽、第三章村路与屋舍都由震动、回声、裂缝和承重的同一套句法回路处理。[C / reviews/reader-review.md:71-79]

例如 C2 把灯、土地和细脉的内化解释成一套完整边界，C3 又把牵引、承载和停手按相同的正确判断回路推进。[C / chapter-02/formal_prose.md:271-291；C / chapter-03/formal_prose.md:111-123、185-207]

但 C 的 execution-fidelity 评审明确判定 DESIGN_LANGUAGE_LEAK=NO：地脉、界舟、接入、承载和锚点都通过触觉、重量与现场后果呈现，没有出现后台生产术语。[C / reviews/execution-fidelity.md:98-107]

**未发现/未知**

不能把 C 的规律化 AI 文风直接升级为 A 的设计语言泄漏；也不能因为 A 有设计词汇，就说两本 Writer 出现同一种具体故障。两本共享的是节奏和解释方式，不是同一组词。

### 10. State/Canon 是否导致 recap？

结论：观察到两本正文都有机制回收或重复说明，但 State/Canon 是否是原因未知，不能归因。

**共同问题**

表层上，两本都有 recap 式回收：A 反复把“日期—水声—墙—剑痕”整理成同一条传递链；C 反复把“震动—回声—裂缝—承重—容量”整理成同一套正确规则。[A / reviews/reader-review.md:71-75、103-108；C / reviews/reader-review.md:71-79]

这能确认“正文存在重述”，不能确认重述来自 State/Canon。它也可能是 Writer 的表达选择或当前章合同的连续性复述。

**仅 A**

A 的 recap 更显式、更接近因果图解：Chapter 3 在事件已发生后再写“先有日期被挪动”“水声沿着日期回来”“剑痕落到今夜的墙上”，并继续把四处线索收束到一个入口。[A / chapter-03/formal_prose.md:425-429、559-603]

因此 A 有较强的表层 recap 问题，但仍不能因此断定是 State/Canon 造成。

**仅 C**

C 的 recap 更像稳定的操作规则和章末钩子：灯暗、脉断、承载过量、停止接人等限制被多次以正确解释重新确认，结尾又把三条回声合成一个声音。[C / chapter-02/formal_prose.md:271-291；C / chapter-03/formal_prose.md:185-207、281-303]

这属于 C 的 Writer 纹理问题，与 A 的后台模型词汇不是同一故障。

**未发现/未知**

本次没有读取 State 或 Canon 文件，故不存在把 recap 归因于 State/Canon 的直接证据。C 的 execution-fidelity 评审虽然记录 C2/C3 上下文重复携带未来资源、人口和空间数据，但同时明确这些数据没有进入 Prep 八字段输出；A 的评审也把第 3 章上下文体量与语义过载区分开。[C / reviews/execution-fidelity.md:29-37；A / reviews/execution-fidelity.md:65-69]

所以本项只能判为“正文有 recap，成因未知”，不能判为“State/Canon 导致 recap”。

## 最终归类

### 跨类型共同问题

1. 主角都遵循先诊断、再施用能力的行为节奏。A 因此延迟了魔法和资产兑现；C 目前更多是把诊断嵌入生存动作，但若长期只保留正确判断，也会压薄欲望与失误。
2. Writer 都有规律化的 AI 文风：否定一个解释后立即给出正确解释、因果链过度整齐、正确判断过密、NPC 对话承担功能、章末钩子节拍相似。
3. NPC 在局部场景中都容易成为流程或主题载体。A 偏制度/主题代理，C 偏群体物流与人口单位；不能把两本都概括成所有 NPC 扁平。
4. 两本表层都出现机制 recap，但没有足够证据把它归因于 State/Canon。

### 只适用于 A 的问题

1. 时间机制解释负担已明确成立，具体资产未落地时因果图解继续占据篇幅。
2. 谢临川的选择大多是安全、道德且可替代的最优解，主角人格尚未从外挂和职业理性中凸显出来。
3. 早期资产基本停留在未来投影、灰烬、冷光和坐标，前三章没有真正的现在拥有。
4. Chapter 3 Writer 出现坐标、入口、通道、分支等后台设计模型语言泄漏。
5. 裴照尘等角色的部分对话以完整主题立场互递，较像主题代理，而不是充分受情境扰动的人。

### 只适用于 C 的问题

1. 资产已经进入主角身体并有承载后果，但拥有规模、稳定边界和内部治理尚未形成，属于 OWNERSHIP_SCALE_NOT_FELT 而不是 OWNERSHIP_PAYOFF_WEAK。
2. 普通村民整体仍容易被压缩成人口、批次和物资携带者；许砺和少数村民的具体动作不足以消除群体层面的 PEOPLE_AS_POPULATION_UNITS。
3. C 的 AI 文风主要表现为“同一台物理模拟器换素材”、正确判断回路和重复章末回声，而不是 A 式后台设计词汇泄漏。
4. C2/C3 有较重的输入上下文和字段冗余观察项，但现有评审没有证明它已转化为 Prep 语义过载。

### 没有足够证据的判断

1. State/Canon 是否造成任一候选的 recap：未读取相应文件，不能归因。
2. C 是否与 A 达到同等程度的整体解释过量：C 只有局部规则密集和重复校正的证据，且执行评审判定输出未过载。
3. 任一候选的 Director 是否“过度机械”：现有材料只支持“主要是高保真展开器”，不支持把它判为质量缺陷。

5. 两本的长期世界自治、资产稳定性、治理结构和主角人格弧线：当前只有三章，不能外推。
