# Specialist Audit

发现三处需要局部修补的动作与空间连续性问题：

1. 唐鹭将短灯插入砂层撑住第三根铁肋后，正文没有写取回，后文却直接把短灯放回矿车侧梁。
2. 检修缝后先写有铁栅且检修槽“被封住”，后文却直接按可供沈砚一人挤出的出口使用，缺少打开和通过的动作。
3. 该出口明确“只能吐出一个人，吐完便会闭合”，结尾却直接写“他们必须先出去”并计划带唐鹭回来，未交代先后顺序、唐鹭如何脱困以及回程通道如何保留。

# Proposed Patches

## Patch 1
目标锚点：
“第三根铁肋停止下沉。”

操作：insert_after

建议文本：
等车轮压过第三根铁肋，唐鹭把短灯从砂层里抽回；她留下的铁片仍卡在缝中，暗红的薄圈没有散，铁肋暂时没有回沉。

理由：
补出短灯从支撑点回到唐鹭手中的动作，同时说明抽走灯柄后卡点为何仍能维持，后文短灯再次出现便有明确位置和承接。

## Patch 2
目标锚点：
“灯光照到一面铁栅。铁栅后面不是外面的矿道，而是一段被封住的检修槽。”

操作：replace

建议文本：
灯光照到一面铁栅。栅门下端有一根断掉的横档，沈砚用车辐撬开矿垢，铁栅向外松出一道只容一人侧身的口子；栅后是向上接回收线的检修槽，槽底仍被斜石卡住，冷风和上方的灯光正从那道缝里透进来。

理由：
当前“被封住的检修槽”没有可通行动作，却马上被当作一人出口使用。补出车辐撬开横档、斜石卡住槽底和冷风灯光的实际连通，既保留单人出口限制，也闭合位置关系。

## Patch 3
目标锚点：
“他们必须先出去，把一条真的路写成死路。”至“再带着唐鹭回来，把那副废车拆开，把阀门里的火取出来。”

操作：replace

建议文本：
沈砚必须先独自挤出去，把这条真的路写成死路，引霍沉去另一条巷道；再从检修槽外侧撬开卡住的斜石，把唐鹭接出来，带她回来拆车取火。

理由：
当前出口被写成只能容一人且通过后会闭合，结尾却默认两人已经共同出去并能返程。明确沈砚先出、外侧开石接出唐鹭的顺序后，伪造记录、引开霍沉和带唐鹭回来拆车取火的既定结尾推动不变。
