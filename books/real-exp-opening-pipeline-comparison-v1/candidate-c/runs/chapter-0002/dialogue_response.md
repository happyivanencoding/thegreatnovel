# Specialist Audit

1. 唐鹭说“你走”之后，沈砚只回“闭嘴”，关键的“留下来让车上的矿奴先脱险”主要依赖叙述说明，沈砚的个人立场没有落到这句对白里；这是一个可替换的泛化拒绝。
2. 在“阵盘灭了”与“车却换了轨”之后，霍沉的对白只是复述现场结果，随后把沈砚留下观察的处置主要由叙述承接，未充分体现他把维修现场继续当作盘问和试验。
3. 结尾“里面在做什么了”偏抽象，也不像唐鹭在矿道现场会先问的口语，削弱了她对具体声息或活物的关注。

# Proposed Patches

## Patch 1
目标锚点：唐鹭说“你走”之后的沈砚回应“闭嘴”。
操作：replace
建议文本：
“我走了，车里的人怎么办？”
理由：保留沈砚短促、直接的说话节拍，让他拒绝私自脱身的关键取舍通过自己的话落地；不改变随后先救车上矿奴的行动。

## Patch 2
目标锚点：霍沉说“阵盘灭了”、又说“车却换了轨”并由叙述接出“沈砚没有解释”的位置。
操作：replace
建议文本：
“阵盘灭了。”霍沉说。

他盯着车轮留下的痕：“阵盘灭了，它怎么还会换轨？”

沈砚抬眼：“你要的是车动。”
理由：让霍沉的异常确认直接成为逼问，让沈砚用结果回避来源，体现两人的盘问关系和各自声音；后续留下矿车、封存阵盘、把沈砚调入废器堆的处置均不变。

## Patch 3
目标锚点：结尾唐鹭的“你听见里面在做什么了？”及沈砚的“还没有”。
操作：replace
建议文本：
“里面有动静？”唐鹭问。

他把薄片收入掌心，护腕牵着他的手臂朝巷口偏去。

“还没听清。”
理由：把抽象的“在做什么”换成矿道现场的普通问法，保留沈砚尚未确认具体内容的悬念，也让下一句“先看它在吞什么”自然承接调查行动，不提前揭示支巷里的事实。
