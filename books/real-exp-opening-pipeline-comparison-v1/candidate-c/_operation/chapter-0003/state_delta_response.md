# Proposed Persistent Canon
- 已证明能力：沈砚可通过接触辨认矿车、铁肋、阵壁和回收路中的震动与方向；在有外部散灵、地火及可接触的铁铜材料时，护腕能沿已有路径导能，形成临时铜黑咬合并修复或支撑滑轮、支脚、门栓和承重结构；他还能辨认矿脉灵气、炉印热量与地底旧器脉动的汇流关系。
- 能力限制：护腕不产生新的力量，必须依靠可牵引的外部热量、散灵和材料路径；铜黑咬合是临时、粗糙的结构加固，会在持续下沉或受力时崩裂。护腕会收紧发热，直接接触阵壁、炉印回路或地火会造成灼伤并把他向回路牵引；当前余灵不足以切断主回路。
- 关系阶段：沈砚与唐鹭的临时协作已发展为带有共同秘密和相互支援的有限信任；唐鹭参与危险加固、接受伪造记录和返回取火的方案，并记住阵壁旁的路径，但双方尚未成为稳定同盟。
- 持久资源：无法取下的铜制护腕与黑色破阵盘回收片继续相互指引；损坏的旧矿车仍留下侧梁、滑轮架和部分铁铜构件，可作为支撑阀门、阵壁及改导地火的材料，但尚未完成改造。
- 长期身份：沈砚仍是受左腕炉印约束的烬脉矿场矿奴，也是能辨认、修复部分废器并被指定处理异常废器的劳力。
- 确认知识：西侧废弃支巷的黑色阵壁把矿脉灵气、矿奴炉印中的热量和一件埋在地底、仍持续脉动的旧器汇入向下管道，管道尽头接着阀门下的地火；地火正在替更深处的未知对象烧人，下一次蓄能可能把矿奴一同拖下去。旧器、深处对象和整套回路的原始目的仍未知。
- 长期伤势：正文未确认沈砚或唐鹭新的长期伤病；沈砚左腕护腕的贴附、收紧和发热仍是确定的身体负担，当前割伤、灼伤和肩背伤仅作为即时状态保留。
- 重要敌我状态：霍沉已知西侧支巷需按炉料清册清空，并下令中央矿脉提前蓄能、献炉提前及三日内封死矿道；他仍掌握矿场监督和封路权。唐鹭是当前有限协作者；阵壁后的矿奴是被回路牵引的受害者，不是已确认的敌人；正文未确认其他敌对势力。

# Proposed Chapter Summary
沈砚与唐鹭进入西侧废弃支巷，在同步呼吸的牵引下找到一辆被拖入并压住石门的旧矿车。沈砚借护腕和外部散灵、地火及旧铁铜材料修复滑轮、支脚和门栓，两人共同把矿车推过持续下沉的铁肋和三处卡点，车体最终只剩侧梁、滑轮架和一只勉强能转的轮子。他们抵达黑色阵壁和岩台，发现向上接回收线的检修槽及半埋阀门；沈砚确认矿脉灵气、矿奴炉印热量和地底脉动旧器被汇入阀门下方地火的向下管道，下一次蓄能可能把矿奴连同热量一并拖下去，但他未能切断主回路。霍沉传令中央矿脉提前蓄能、献炉提前，三日内封死旧坡道、主巷及废弃矿道并按炉料清册清空西侧支巷；本章末沈砚与唐鹭决定先后撤出、伪造死路记录并返回改造阀门，方案尚未执行。
