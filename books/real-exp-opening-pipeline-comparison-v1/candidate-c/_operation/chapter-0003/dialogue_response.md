# Specialist Audit

发现一处需要修改：唐鹭在听见门后同步呼吸后，现有对白只确认“里面的人能听见我们”，没有把她“先带少数人出去”的立场说出来；沈砚随后直接转入借火和修门，也没有用对白明确回应这项取舍。这样两人的协作动作成立，但共同秘密升级为“救谁、先怎么救”的关系压力主要由叙述承担，唐鹭的退路意识与沈砚不肯只修个人出口的执拗还不够可听见。其余对白均有明确的行动功能，沈砚的短直和唐鹭的现场反问也能区分，未发现其他需要修改的事项。

# Proposed Patches

## Patch 1
目标锚点：`唐鹭的手按住短灯，声音更低：“里面的人能听见我们。”` 之后、`沈砚把左腕贴到轴销上。` 之前。
操作：insert_before
建议文本：
唐鹭盯着门缝：“先把门弄开，带两个出来。”

沈砚：“现在出去，门口会塌。”

“那就先带一个。”

“带一个，剩下的还在里面。”

她看了他一眼：“你要进去？”

“先把路撑住。”
理由：让唐鹭把“先救少数人”的判断落在具体动作上，而不是停留在抽象的“让人出去”；沈砚不直接说教，用门口承重的现实风险回应，并以“先把路撑住”表明继续深入是为了改变出口。该段只补足已发生的立场冲突，不改变两人进入支道、修复卡点和本章直接结果。
