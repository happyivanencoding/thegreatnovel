# Specialist Audit
发现三处需要局部补足的动作链：

前文明确车上锁链只够矿奴站稳，且霍沉后来没有再让人割链；后文却直接写四人下车，缺少解除锁链的动作。

右轨先被写明底下空了一截，随后又被落石顶偏；当前第二次修补主要呈现左轨接通，没有交代右轮如何获得承托，矿车沿弯轨通过的空间链条不完整。

第二次修补中，护腕的震动和轨道受力已经出现，但散灵从砂层直接落到薄铜与轨道，没有明确再次回收到手臂，因而“第二次可验证回收与供能”的动作路径略断。

# Proposed Patches
## Patch 1
目标锚点：`他们经过霍沉身边时，唐鹭朝外伸手，把最前面的矿奴先拖下车。`
操作：insert_before
建议文本：矿车在回收灯下停住。沈砚抬起短锤，逐个敲开车厢横杆上的锁扣；铁链落到底板，四个人这才有了离车的空隙。
理由：前文已建立矿奴被锁在车上、不能离开车身，且霍沉没有安排割链。补出释放动作后，后续拖人下车、把人推到灯下才与既有物理限制一致。

## Patch 2
目标锚点：`旧坡道的左轨断在一块塌下的石梁前，右轨虽然还在，方向却被主巷落下来的岩块顶偏了。`
操作：insert_after
建议文本：他先用一枚铁楔塞住右轨下方空着的那一截，再把被岩块顶偏的轨头撬回车轮能压到的位置。右轮有了落脚处，车身才不会只压在刚接好的左轨上。
理由：当前场景同时保留了右轨的空基和偏转状态；补出已有铁楔的物理承托，才能让接通左轨后的整辆矿车沿两道轨道通过，不增加新的法诀或改变结果。

## Patch 3
目标锚点：从`左腕的护腕随之震了一下，刚刚走完的热流又从承重骨里折回来，沿车底朝前延伸。`至`散在砂层里的微光被拽成一束，先落在那片薄铜上，再分成两股钻进轨道。`
操作：replace
建议文本：薄铜贴上断口时，左腕的护腕再次收紧，把散在砂层里的微光先牵回手臂；热意沿破阵盘残线走完一圈，再从他的掌下分成两股，钻进两截轨道。
理由：把第二次回收明确落到护腕和手臂，再落到薄铜与两截轨道，能补齐“再次回收—供能—接轨”的可见动作链，同时保留连续两次修补的先后和直接结果。
