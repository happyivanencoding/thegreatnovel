# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”；其纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定力量来源。
- 沈燧能在特定接触中感知物件尚未完成的具体动作，并将残留动作导入器物。断镐主体已碎；在侧炉余火、粗铁和黑铁锋片的残留锋意作用下形成的裂路器，已证明能切开旧通风门和倒悬废炉闸。
- 裂路器不是完整法器，不能抵挡真正的高温火流。连续使用后粗铁背部红透、包布烧损过半、黑锋出现受热发白，沈燧右掌和右臂的伤痛显著加重；其下一次能否继续驱动并有效开路尚未确认。
- 焦黑火鳞已经耗尽并碎成黑灰；沈燧从炉膛圆槽取出一枚尚未合拢的火鳞胚。火鳞胚能在右掌边形成短暂、薄弱且不稳定的高温护持，并指向更深处尚未传完火的烧毁火脉和一座未接火的空炉；它尚未完成传火。
- 沈燧与阮青禾对矿工和伤者的现场指挥已形成信任；五名获救炉工熟悉旧炉道和风向，已主动选择暂时跟随这条路线。该合作仍是现场协作，尚非长期盟约。
- 裴照川已将沈燧记为“失控器修”；玄烬仙宗仍把沈燧、异常器物及相关炉息纳入异常回收与封锁范围。
- 废弃炼器窟深处已确认存在未传完的烧毁火脉和未接火空炉；半张残图所示持续工作的炉心及可能熔断封炉印的熔断槽仍未确认实际效果与安全性。
- 沈燧的右掌、右臂黑色裂痕和掌骨痛仍在且已加重，右臂出现持续发抖；左肩擦伤仍在。
