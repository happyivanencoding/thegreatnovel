# Specialist Audit

发现两处需要修改的动作与空间衔接问题：

- 沈燧此前一直用右手握着焦黑火鳞，到了“伸出右手”“指尖碰到它”又直接用同一只手接触并取出火鳞胚，中间没有交代如何腾手；随后“炉壁上的焦黑火鳞”又把已经在他手中的旧火鳞写回了炉壁，物件位置发生跳变。
- 沈燧取出火鳞胚前，五名炉工和同行矿工已经在弯月刻内沿左壁排开；结尾再写“依次进入弯月刻”会造成队伍空间位置倒退或重复。

# Proposed Patches

## Patch 1
目标锚点：从“沈燧伸出右手。”至“它替那座空炉挡住了最后一次火。”
操作：replace
建议文本：
沈燧把焦黑火鳞抵在圆槽外沿，鳞面仍朝着闸口，确认它没有从火潮前退开，才松开右手，伸出两指碰向那枚尚未合拢的鳞片。

指尖碰到它时，掌心的黑铁锋片先热了一下，接着，圆槽底部传来一声极轻的回响。不是撞击，也不是炉火炸裂，而是一股向前递送的力。细火从鳞片的缝里探出去，越过炉膛，穿进地下更深的一道焦黑纹路。

那道纹路尽头还有火。

火没有传过去。

沈燧的手指收紧，把那枚鳞片从圆槽里取了出来。

鳞片离开炉底的一刻，抵在圆槽外沿的焦黑火鳞猛地向外张开。最后一股火潮撞上去，被压成低低的一圈红光；随后，焦黑的鳞面从边缘碎裂，落成几片没有温度的黑灰。

它替那座空炉挡住了最后一次火。
理由：明确旧火鳞在取胚前的承放位置和右手腾挪，避免同一只手同时持有旧鳞并取出胚；同时保持旧火鳞朝向闸口并在取胚后完成最后一次挡火，修复物件位置与动作顺序而不改变直接结果。

## Patch 2
目标锚点：“阮青禾紧跟上去，五名炉工和矿工拖着伤者依次进入弯月刻。”
操作：replace
建议文本：
阮青禾紧跟上去，五名炉工和矿工拖着伤者贴着左壁，依次向弯月刻更深处挪去。
理由：承接队伍已经在弯月刻内排开的现场位置，明确这一步是沿既有通道向深处推进，不把队伍重新写回一个已经进入过的空间。
