# Specialist Audit

当前三名核心人物的基本声音区分成立：沈燧用短句做判断和承担，阮青禾围绕路线、落点和后果说话，裴照川则用回收秩序和封锁命令组织现场。需要局部修正的有两处：

1. 沈燧在“铸个能用的”“所以才要快”等关键节点的对白偏功能化。让矿工进入侧炉的护短动机主要由旁白补足，声音层还没有明确落到“不能让他们再次被封回去”这一当下立场。
2. 结尾阮青禾仍停留在当前侧道的导航，废窟残图和发热炉心尚未通过人物对白落地，因而从“裂路器不能挡倒灌炉火”转向“带人进入高温区”的下一步理由主要依赖叙事说明，缺少她的路线判断和沈燧的行动回应。

# Proposed Patches

## Patch 1
目标锚点：阮青禾问“你要在这里铸东西？”之后，沈燧回答“铸个能用的。”
操作：replace
建议文本：
“先铸个能把人送出去的。”
理由：保留沈燧的短促和实用口吻，同时把粗糙铸造直接系在他要护住同行者的当前选择上，不改变铸造动作或后续结果。

## Patch 2
目标锚点：矿工说“后面有人——”之后，沈燧回答“所以才要快。”
操作：replace
建议文本：
“所以不能让他们再把人封回去。”
理由：把裴照川刚说过的封路威胁转成沈燧自己的拒绝和偏执，避免这句只承担催促功能；不新增决定，只明确他已经在执行的护人动机。

## Patch 3
目标锚点：结尾阮青禾说“左边的墙记号还在，沿着弯月刻走，别碰右边的炉缝。”之后。
操作：insert_after
建议文本：
阮青禾的手在左墙上停住，指腹擦出一层密密的旧线，线尾落在一枚暗红的小点上。

“这是通往废窟的残图。里面还有炉心，没熄。”

沈燧看了一眼身后的红光，又看向那枚小点。

“带他们进去。别让它先灭。”
理由：让阮青禾继续以现场辨图推进信息，让沈燧用一句克制的回应把队伍从当前侧道导向发热炉心；只显出新目标和行动压力，不提前断言炉心的能力或结算后续结果。
