- 旧 Active Scene State 中前方封锁尚未确定。正文已确认玄烬仙宗封钉封死灰门及前后通路，并将侧道列为异常回收区；裴照川已亲眼见证裂路器连续开路并将沈燧记为“失控器修”。

# Proposed Persistent Canon

- 沈燧是黑炉镇矿工和苦力，被称为“漏炉废人”；其纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定力量来源。
- 沈燧能在特定接触中感知物件尚未完成的具体动作，并将残留动作导入器物。断镐主体已碎，原断镐不能直接再次驱动；在侧炉余火、粗铁和铸锤条件下，黑铁锋片承接残留锋意锻成了粗糙的裂路器。
- 裂路器已证明可以劈开石壁、切断铁链和薄封钉，连续形成短时裂隙；它不是完整法器，不能挡住真正的高温火流，持续使用会加重沈燧右掌和右臂的伤痛，并使器物迅速过热。
- 黑铁锋片目前与粗铁楔口连成裂路器，器物已有受热变白和焦损迹象；其在更高温度下能否继续使用尚未确认。
- 矿工和伤者因沈燧与阮青禾的实际指挥开始按路线协作并有限跟随，形成现场信任；阮青禾与沈燧已形成基于炉墙记号的路线协作，但尚非长期盟约。
- 裴照川已将沈燧记为“失控器修”。玄烬仙宗已把沈燧、异常器物及相关炉息纳入异常回收与封锁范围。
- 废弃炼器窟深处仍有持续工作的炉心；残图显示炉心附近存在可能熔断封炉印的熔断槽，但残图不完整，熔断槽的实际效果和安全性尚未确认。
- 沈燧的右掌、右臂黑色裂痕和掌骨痛仍在，左肩擦伤仍在；恢复程度未确定。

# Proposed Chapter Summary

沈燧在阮青禾辨认旧炉墙记号的协助下，借侧炉余火、粗铁和黑铁锋片的残留锋意锻成裂路器；玄烬仙宗封死灰门后，他两次使用裂路器开出短时裂隙，带着矿工和伤者进入废弃炼器窟的侧道。裴照川亲眼确认裂路器连续开路，将沈燧记为“失控器修”并封死废窟前后出口。队伍在侧道夹层发现半张炼器窟残图，确认深处仍在工作的炉心及可能熔断封炉印的熔断槽，随后继续走向逐渐升温的高温区。
