我会把三张卡都当作严格的非 Canon 候选：先把 World、T0 Origin、各自尺度和 Power 闭合，再让第一副本与前五章承诺从这些字段推出；不自动替作者选方向，也不把后续副本答案提前写死。# SINGLE-PASS PREMISE CANDIDATES

## S1｜死者最后一步

### 一句话货架简介

主角是一具从尸体最后动作里孵出的行动残骸，能偷走死者最后一个动作，让自己完成普通活人绝不可能完成的逃生、杀人和夺宝。

### World-only Direction

所有副本都是独立、完整、会自行运转的封闭世界；进入者只能通过入口进入，并在满足主任务与返程边界后带走有限奖励。

跨副本主尺为「余动阶」：

- R0：只能完成自身自然动作。
- R1：能强制完成一次身体级动作。
- R2：能影响手持物或小型生物。
- R3：能影响房间范围。
- R4：能影响街区范围。
- R5：能影响城市局部。
- R6：能影响世界级事件。

第一副本为「白潮城」：一座建在潮间泥滩上的城，每日会经历三次涨潮。退潮时只露出一条会不断变窄的硬泥脊，涨潮后街道、船屋和墓地都会被水流重新切断。

本地力量尺为「潮相」：

- C0：无法承受潮水冲击。
- C1：能在浅水中站立。
- C2：能沿硬泥脊移动。
- C3：能在一次涨潮中存活。
- C4：能改变一条潮沟。
- C5：能改变城内局部潮汐。

主任务：带出一枚「潮肺」。

返程边界：第三次涨潮封死入口后，副本关闭。

可选目标：替退役摆渡人卢婆找回一只铁盒。

### World Interface-only Direction

任何生物或物体死亡、停止运转后，都会在原地留下三十息的「最后动作重影」。附近的人能够观看、记录和传播这段重影。

重影只能显示动作，不能再次产生力量；记录可以作为证词、交易凭据或罪责依据，但不能改写已经发生的结果。

### Protagonist Ontology-only Direction

主角是「行动残骸」：

- 没有完整器官，身体由灰白色肌肉、断裂骨节和不断重复的微小动作组成。
- 可以被实体攻击，也能抓握、奔跑和攀爬。
- 没有稳定的脸，面部会短暂呈现最近接触过的死者最后表情。
- 不属于活人，也不属于普通尸体。
- 身体不会自然成长，只能通过 Power 改变行动能力。

### Initial Origin-only Direction

T0 时，主角诞生于白潮城外的潮泥尸坑。

三具溺亡者的最后动作同时重叠：一人抓住木桩，一人试图爬起，一人伸手求救。重叠后的动作凝成一具半人高的灰白残骸。

出生时没有记忆、名字、装备或同伴，只能缓慢爬行。

### Initial Scale Position-only Direction

- 跨副本主尺「余动阶」：R1。初始仅具备一次身体级强制动作的潜能。
- 白潮城本地尺「潮相」：C0。T0 尚未接触潮水，身体也不具备承受潮冲的本地适应性。
- 副本内登记身份尺：不适用。白潮城的身份登记只适用于具有本地户籍和生理生命迹象的居民，行动残骸不满足条件。

### Power-only Direction

Power 名称：「偷终动作」。

触发条件：

- 主角必须直接触碰一个刚死亡的生物，或一个刚停止运转的物体。
- 目标必须仍保留三十息内的最后动作重影。
- 只能选择目标最后一次主动完成或试图完成的动作。

目标类别：

- 死亡生物。
- 停止运转的机械、门锁、船、陷阱等物体。

可执行动作：

- 偷走该动作，储存在自身。
- 让自己或一个接触中的目标完整执行一次该动作。
- 动作的方向、力度和范围不能超过原动作。

永久边界：

- 同时只能储存一个动作。
- 使用后动作消失。
- 不能复活死者，不能获得死者记忆，不能制造目标没有做过的动作。
- 若自身结构无法完成该动作，只能完成可承受部分。
- 不能使用超过三十息的死亡重影。
- T0 例外：诞生时自动储存三具尸体重叠后的一个动作，仅此一次，之后仍必须按正常触发条件使用。

### Story Interface / Opening Promise

副本界面只显示四项：

- 主任务：带出潮肺。
- 可选目标：找回铁盒。
- 失败边界：第三潮封门。
- 可携带奖励：潮肺、铁盒及被明确允许带出的物品。

潮肺能让持有者在一次完整涨潮中保持呼吸，离开副本后仍能改变后续副本的潜水、窒息和水下移动选择。

#### 1—10章 Outline

1. 主角从尸坑诞生，偷走守尸人的最后抓握动作，第一次逃生。
2. 遇见卢婆，得知铁盒与潮肺都在城内，接受互相利用的交易。
3. 硬泥脊断裂，主角利用死船夫的抛绳动作渡过潮沟。
4. 夺得潮肺，死去城主的最后动作重影却显示它并非城主所有。
5. 卢婆从同伴变成竞争者，承认铁盒里有她儿子死前留下的记录。
6. 收尸 guild 依据重影追捕主角。
7. 主角发现潮肺会主动吸取附近死者的最后一口气。
8. 卢婆为夺铁盒出卖主角，却在关键处剪断追捕者的退路。
9. 第三次涨潮提前到来，潮肺、铁盒和出口只能保全两项。
10. 主角带着一项主奖励和一项私人承诺离开，白潮城留下未解释完的死者记录。

#### 本次前五章实现界面

前五章必须完成：

- 出生规则被兑现。
- Power 首次显露并改变生存判断。
- 第一件高价值物被获得。
- 卢婆从向导变成利益相关者。
- 主任务与可选目标发生冲突。

### Authority-Compilation Trace

1. **尸坑残骸爬出** → `Initial Origin-only Direction` → T0 诞生已成立 → 尸坑与残骸身体 → 合法，因为身体由三具尸体最后动作重叠形成。
2. **主角抓住守尸人的铁钩并逃出** → `Power-only Direction` + 守尸人死亡重影 → 触发已满足 → 守尸人遗留的抓握动作 → 合法，因为目标刚死亡且动作在三十息内。
3. **沿硬泥脊渡潮沟** → `World-only Direction` 的白潮城地形 + `偷终动作` → 触发已满足 → 死船夫的抛绳动作 → 合法，因为主角只复现一个已有动作。
4. **夺取潮肺** → `World-only Direction` 的副本目标 + 城主遗体重影 → Power 触发已满足 → 潮肺与城主最后的藏匿动作 → 合法，因为动作只能帮助打开或移动已有目标，不能凭空生成潮肺。
5. **旁观者传播城主最后动作** → `World Interface-only Direction` → 观看与记录规则已满足 → 重影和记录 → 合法，因为界面只传播证据，不改变潮肺归属。
6. **潮肺带出后继续生效** → `Story Interface / Opening Promise` 的可携带奖励规则 → 返程条件满足后生效 → 潮肺 → 合法，因为奖励是实体物件，不是临时结算 Buff。

### 第一章标志性画面

涨潮前的尸坑里，三具尸体同时重复最后一个动作：抓、爬、求救。灰白色残骸从三道动作中站起来，第一件事不是呼吸，而是伸手抓住一只正在收紧的铁钩。

### 主角反复会做的新动作

- 从尸体身上偷走最后一次挥刀、攀爬、开锁或投掷。
- 让死去的船、门锁和机关替自己完成最后一次动作。
- 把不同死者的动作接成一条新的逃生路径。
- 在公开重影中判断谁在撒谎。
- 为了保留一个动作，故意不立即使用另一个动作。

### 第一次不公平兑现

主角被十几名活人堵在断桥边，正常人只能跳进涨潮水里。他触碰刚刚溺死的船夫，偷走对方最后一次「把绳索抛上桩顶」的动作，身体瞬间完成一次不可能的精准投掷，直接把自己拉到对岸。

### 20章玩法扩张

- 从单纯偷动作，发展为利用死亡现场重组完整行动链。
- 活人会故意制造“最后动作”，诱导主角获得错误能力。
- 公开重影成为证据、勒索和舆论武器。
- 带出的潮肺改变跨副本生存路线，但不会取代 Power。
- 副本可以围绕战争遗址、失控机械、尸体密集区和即将毁灭的城市展开。

### 100章以上仍能长出的不同故事

可以写成战争世界、灾难世界、刑案世界、古墓世界、机械文明和死后社会。

长期核心不是“不断升级法术”，而是：

- 谁控制死者最后的叙述。
- 主角是否有资格使用死者留下的动作。
- 活人会不会为了制造强力遗产而主动设计自己的死亡。
- 一个没有正常生命史的主角，如何建立属于自己的动作与名字。

### 最小可信桥梁

只需固定三件事：

1. 副本是独立封闭世界。
2. 死亡会留下最后动作重影。
3. 主角能偷走并复现其中一个动作。

不需要预设后续世界、中央控制者或无限复制机制。

### 不可磨平的三点

- 主角不是“会用尸术的人”，而是由动作残骸组成的非人生命。
- 能力的资源是死者最后一刻，而不是灵力、装备或等级经验。
- 每次获得力量，都同时接触一个死者未完成的欲望。

## S2｜看见我，给我一条路

### 一句话货架简介

主角是一道只有被人看见才能落地的影子，任何活人看清他一瞬间，他就能从对方的视野里跳到另一个位置。

### World-only Direction

所有副本都是独立世界，进入者通过副本入口抵达本地，系统只提供主任务、可选目标、返程边界和可携带奖励。

跨副本主尺为「显身阶」：

- S0：完全依赖直接注视。
- S1：脱离注视一拍仍能保持形体。
- S2：脱离注视三息仍能保持形体。
- S3：脱离注视一分钟。
- S4：脱离注视十分钟。
- S5：脱离注视一小时。
- S6：完全独立存在。

第一副本为「盲灯城」：一座建在地下的城市。城中唯一安全的光来自蓝色灯火，黑色灯光会吸引无脸生物；居民长期蒙眼或佩戴遮光面罩生活。

本地力量尺为「灯阶」：

- L0：无法点燃或维持灯火。
- L1：维持手灯。
- L2：照亮房间。
- L3：照亮街道。
- L4：控制城区光源。
- L5：重燃整座城市的主灯。

主任务：带出塔顶的第一枚蓝灯芯。

返程边界：黑日经过城市时，所有副本出口关闭。

可选目标：帮助盲信使芽娘救出被困在灯井里的弟弟。

### World Interface-only Direction

任何事件只要被两名以上独立的活人同时看见，就会在附近反光表面留下一个小时的「公共回像」。

公共回像只能重复展示原事件，不能触碰物体、推动人物或替任何人行动。它可以被观看、复制和传播，并会影响当地的审判、声誉、交易和追捕。

### Protagonist Ontology-only Direction

主角是「视影体」：

- 没有固定肉身，初始形态是一道黑色人形影子。
- 被一名活人直视时，可以暂时获得实体轮廓。
- 没有独立体温、心跳和正常重量。
- 可以说话，但声音只能从被看见的实体部位传出。
- 不依赖镜子、摄像机或死者的观看。

### Initial Origin-only Direction

T0 时，主角诞生于盲灯城废弃审判厅的一面碎裂镜子中。

镜面里原本只有一盏熄灭的灯和一道没有主人的影子。影子在镜面破裂后保持人形，拥有声音与连续意识，但没有任何记忆、名字或外部实体。

### Initial Scale Position-only Direction

- 跨副本主尺「显身阶」：S0。离开活人直接注视后，形体立即失去稳定。
- 盲灯城本地尺「灯阶」：L0。主角没有灯火器官，也没有控制本地灯源的能力。
- 盲灯城居民身份尺：不适用。该尺只适用于能够被城市登记为居民的实体生命，视影体不具备本地生理身份。

### Power-only Direction

Power 名称：「视线借路」。

触发条件：

- 至少一名活着且有意识的生物，直接看清主角完整形体。
- 连续注视必须达到一拍。
- 摄像机、画像、镜中倒影和公共回像都不算直接观看。

目标类别：

- 正在直接观看主角的活人。

可执行动作：

- 主角可以瞬间移动到该观察者当前视野内的任意空置位置。
- 移动后主角完整落地，不需要中间路径。
- 可以带走贴身小物，但不能携带其他生物。
- 同一个观察者十息内只能被借路一次。

永久边界：

- 目标必须仍在直接观看范围内。
- 不能进入被其他物体占据的位置。
- 不能通过记录、镜面或死人视线触发。
- 若没有任何活人注视，主角不会死亡，但会退回最近一次被直接看见的位置。
- Power 不增加显身阶；长期脱离注视仍然受 S0 限制。

### Story Interface / Opening Promise

副本界面只显示：

- 主任务：带出第一枚蓝灯芯。
- 可选目标：救出芽娘的弟弟。
- 失败边界：黑日经过时出口关闭。
- 可携带奖励：蓝灯芯、当地物件和被明确承认的契约。

第一枚蓝灯芯离开盲灯城后仍能让主角在短时间内保持可见实体，改变他今后在无人观看环境中的行动选择。

#### 1—10章 Outline

1. 主角从碎镜中成形，被守卫看见后第一次借路逃出审判厅。
2. 芽娘通过脚步和声音找到他，提出救弟弟的交易。
3. 主角借多个路人的视线进入灯塔，夺得第一枚蓝灯芯。
4. 两名守卫同时看见全过程，公共回像开始在全城反复播放。
5. 芽娘承认弟弟并不是被困，而是被灯井选择为下一任主灯人。
6. 灯猎队利用公共回像锁定主角的移动模式。
7. 主角在无人街区短暂失去形体，只能依靠蓝灯芯撑住轮廓。
8. 芽娘将主角卖给灯猎队，换取弟弟的生存资格。
9. 黑日提前经过，城市所有注视关系被打乱。
10. 主角必须在救弟弟、带走灯芯和保住自己的实体之间选择两项。

#### 本次前五章实现界面

前五章必须完成：

- 影子存在形态被直接展示。
- 视线借路至少成功两次。
- 蓝灯芯被获得。
- 公共回像让全城重新定价主角。
- 芽娘的真实利益改变双方关系。

### Authority-Compilation Trace

1. **影子从碎镜中成形** → `Initial Origin-only Direction` → T0 形体已成立 → 碎镜内的无主影子 → 合法，因为起点只规定出生位置与零点状态。
2. **主角被守卫看见后跳到门后** → `Power-only Direction` → 一名活人连续看清完整形体，触发已满足 → 守卫当前视野内的空位 → 合法，因为目标是直接观看者。
3. **借路进入灯塔** → `Power-only Direction` → 多个观看者分别满足触发 → 视野内不同空位 → 合法，因为每次移动都依赖当前直接视线。
4. **全城播放主角夺灯芯的过程** → `World Interface-only Direction` → 两名活人同时见证，触发已满足 → 公共回像 → 合法，因为回像只记录与传播，不帮助主角移动。
5. **主角在黑暗中失去实体** → `Protagonist Ontology-only Direction` + `Initial Scale Position-only Direction` → S0 边界始终有效 → 无直接观察环境 → 合法，因为 Power 不提高显身阶。
6. **蓝灯芯离开副本后仍能维持短暂实体** → `Story Interface / Opening Promise` → 可携带奖励规则已满足 → 蓝灯芯 → 合法，因为这是实体奖励，不是未声明的新 Power。

### 第一章标志性画面

碎裂审判镜里，一道没有主人的黑影睁开眼。守卫低头看见它的一瞬间，影子从镜面里消失，下一刻已经站在守卫身后的灯火里。

### 主角反复会做的新动作

- 借不同人的视线连续跳跃。
- 把敌人的注视变成自己的移动路线。
- 故意制造公开场面，以获得更多“落点”。
- 在盲区里变成无法触碰的影子。
- 让两个敌人互相争夺“谁在看他”。

### 第一次不公平兑现

主角被封在没有门的黑屋里。守卫从观察孔看进来，主角等对方完整看清自己，瞬间跳到守卫背后的空位，夺走钥匙后再次借另一名守卫的视线离开整条走廊。

### 20章玩法扩张

- 副本中的观看关系成为潜入、追逐和战斗地形。
- 主角需要判断什么时候制造观众，什么时候消灭所有视线。
- 公共回像制造声誉、悬赏、崇拜和伪证。
- 蓝灯芯让他短时间摆脱 S0，但无法取代借路。
- 不同副本可以拥有不同的观看习俗、隐私制度和公开审判传统。

### 100章以上仍能长出的不同故事

可以写成竞技场、宫廷、宗教城、隐秘战争、城市监控、公众审判和反观看社会。

长期冲突来自：

- 被看见究竟是力量还是暴露。
- 主角是否需要公众才能成为“真实的人”。
- 失去注视时，他是否仍拥有连续的自我。
- 一个能把观众变成道路的人，最终会如何面对没有观众的世界。

### 最小可信桥梁

只需固定三件事：

1. 视影体依赖直接观看。
2. 直接观看可以成为移动入口。
3. 两人以上的见证会生成不可干涉的公共记录。

### 不可磨平的三点

- 主角的移动依赖人类目光，而不是地图、法阵或传送术。
- 公开观看既是战斗资源，也是社会枷锁。
- 他的最大弱点不是力量不足，而是无人看见。

## S3｜一张会走路的嘴

### 一句话货架简介

主角是一张没有身体的活嘴，能把墙、门、牢笼和任何真实边界吞掉，在两侧之间咬出一条路。

### World-only Direction

所有副本都是具有真实历史、人物关系和本地秩序的封闭世界。每个副本至少存在一种可被感知的物理边界：墙、门、壳、牢笼、城界或空间隔层。

跨副本主尺为「破界阶」：

- B0：不能破坏边界。
- B1：可打开指宽缝隙。
- B2：可打开手掌宽度。
- B3：可打开一人通过的缺口。
- B4：可打开车辆通过的缺口。
- B5：可打开房屋级缺口。
- B6：可打开街区级缺口。

第一副本为「封顶矿城」：一座建在地下矿脉中的城市，上方覆盖着一层厚重透明穹顶。穹顶每天向下压缩，逼迫居民不断迁往更深处。

本地力量尺为「开界阶」：

- M0：只能使用现成门缝。
- M1：可打开手指宽的石缝。
- M2：可打开人头宽的缝隙。
- M3：可打开单人通道。
- M4：可打开房间级通道。
- M5：可打开城市壳层。

主任务：带出封顶矿城中央的「定缝钉」。

返程边界：穹顶压到第三层矿道后，入口永久闭合。

可选目标：帮助锁匠罗婶救出被封在旧矿区的女儿。

### World Interface-only Direction

任何人或物穿越、破坏、封闭真实边界时，边界表面都会留下六十息的红色「界痕」。

界痕可以被观看、记录和传播，能够作为通行证、犯罪证据、领地争议和追踪依据，但界痕本身不能扩大缺口、改变边界或替任何人穿越。

### Protagonist Ontology-only Direction

主角是一张会移动的黑色活嘴：

- 没有头、躯干、四肢和固定位置。
- 可以说话、听见声音、感知边界两侧的压力。
- 嘴唇能贴附在墙、门、笼、地面裂缝等物理边界上。
- 不能抓握普通物品，也不能直接承受没有边界交叉的攻击。
- 只有在边界处，主角才拥有稳定存在。

### Initial Origin-only Direction

T0 时，主角诞生于封顶矿城最底层的一只封闭救生棺内部。

棺盖和棺身之间原本只有一条头发丝宽的缝。缝隙中长出一张拇指宽的黑嘴，拥有一把成年人的声音，但没有记忆、姓名、身体或移动能力。

### Initial Scale Position-only Direction

- 跨副本主尺「破界阶」：B1。最大稳定缺口为指宽。
- 封顶矿城本地尺「开界阶」：M1。T0 只能处理手指宽的石缝。
- 穹顶「壳压阶」：不适用。该尺只衡量矿城结构承受的下压强度，适用于建筑边界，不适用于主角这一非结构实体。

### Power-only Direction

Power 名称：「吞界」。

触发条件：

- 嘴唇必须直接贴住一条真实、物理存在的边界。
- 边界必须分隔两个不同空间、容器或封闭区域。
- 目标边界必须能被主角感知到两侧压力。

目标类别：

- 门、墙、牢笼、铠甲、箱体、城墙、矿道隔层等实体边界。
- 不包括人体皮肤、抽象规则、社会身份、记忆和纯能量屏障。

可执行动作：

- 吞掉一段边界，在两侧制造一个临时连通口。
- 主角可以自己通过，也可以让一名生物或一件物品通过。
- 缺口持续六十息，随后自动闭合。
- 每成功带一名活着的生物完整通过一次，稳定缺口提升一阶，最高 B6。

永久边界：

- 不能凭空制造第二侧空间。
- 不能吞掉抽象概念或人的身体边界。
- 同一条边界在同一副本内只能吞一次。
- 缺口闭合后，已经通过的东西不会被拉回。
- 主角不能在没有边界的开放空间中自由移动。
- T0 例外：出生时可吞掉救生棺盖与棺身之间的原始缝隙一次，此后必须重新触碰边界。

### Story Interface / Opening Promise

副本界面只显示：

- 主任务：带出定缝钉。
- 可选目标：救出罗婶的女儿。
- 失败边界：穹顶压到第三层矿道。
- 可携带奖励：定缝钉及被明确带出的物件。

定缝钉能让一次吞界缺口保持稳定更久，离开副本后仍能改变主角的跨墙、救援和临时据点玩法，但不能取消 Power 的目标限制。

#### 1—10章 Outline

1. 黑嘴在救生棺缝中诞生，吞掉一指宽边界，第一次离开棺材。
2. 遇见锁匠罗婶，得知穹顶正在下压，接受寻找定缝钉的交易。
3. 吞掉矿门与铁笼，进入旧矿区并第一次带出一名活人。
4. 罗婶为救女儿把主角封进一段死矿道，双方关系反转。
5. 主角在压缩前吞开一面禁墙，发现旧矿区里仍有一个被城市遗忘的生活区。
6. 定缝钉被矿主和救援队同时争夺。
7. 主角必须选择扩大通道救人，还是保留缺口尺寸通过定缝钉。
8. 穹顶下压导致整座矿城的边界重新排列。
9. 罗婶女儿拒绝离开旧矿区，要求主角带出一批无法搬走的居民。
10. 主角带出定缝钉，并决定是否让封顶矿城保留一条永远打开的裂口。

#### 本次前五章实现界面

前五章必须完成：

- 非人形态和移动限制被直接展示。
- 吞界能力连续改变地形。
- 第一名被救出的活人带来 Power 成长。
- 罗婶从委托人变成控制主角行动的人。
- 禁墙后的新事实重新定义“救人”和“带出奖励”。

### Authority-Compilation Trace

1. **黑嘴从救生棺缝中诞生** → `Initial Origin-only Direction` → T0 已成立 → 救生棺内的头发丝缝隙 → 合法，因为出生位置与形态已明确。
2. **吞掉棺盖边界** → `Power-only Direction` → 嘴唇接触实体边界，触发已满足 → 棺盖与棺身之间的缝 → 合法，因为目标分隔两个真实空间。
3. **打开矿门进入旧矿区** → `Power-only Direction` + `World-only Direction` → 目标是实体门，触发已满足 → 矿城两个封闭区域 → 合法，因为 Power 只移除边界，不制造新空间。
4. **救出第一名活人并提升破界阶** → `Power-only Direction` → 生物完整通过，成长条件已满足 → 一名活人 → 合法，因为成长规则已写入 Power。
5. **界痕被矿主用于追踪** → `World Interface-only Direction` → 边界被穿越，触发已满足 → 红色界痕 → 合法，因为界痕只记录和传播，不替任何人打开道路。
6. **定缝钉延长缺口时间** → `Story Interface / Opening Promise` → 可携带奖励已获得 → 定缝钉 → 合法，因为延长效果来自明确写出的物件，不是临时增加 Power。
7. **主角不能在露天矿场奔跑** → `Protagonist Ontology-only Direction` + `Initial Scale Position-only Direction` → 无真实边界，触发不满足 → 开放空间 → 合法，因为行动限制始终有效。

### 第一章标志性画面

地下救生棺里没有人，只有一张黑嘴贴着棺盖缝隙说：“外面有人吗？”

下一秒，嘴把缝隙咬宽，整口棺材像被撕开的门一样向两侧张开。

### 主角反复会做的新动作

- 咬开墙、门、箱和牢笼，改变战场结构。
- 把敌人的防具变成自己的入口。
- 在即将坍塌的建筑中连续制造临时通道。
- 带着一个人穿过原本不可能通过的边界。
- 选择保留哪一条界线，迫使本地人物重新争夺空间。

### 第一次不公平兑现

矿主把主角锁在三层铁笼和石墙之后，十几名守卫堵住唯一出口。主角没有攻击任何人，只咬住铁笼的一条边，把矿主的私人金库、囚室和外部矿道连成一条短暂通路，直接从所有防守中穿出。

### 20章玩法扩张

- Power 从逃生工具变成攻城、救援、截货和临时基地能力。
- 敌人会开始设计没有接缝、没有内外的封闭结构。
- 界痕成为追踪、领地争夺和身份审判依据。
- 定缝钉让主角获得更长的临时据点窗口。
- 副本可以围绕城墙、监狱、巨兽体内、封闭船舱和战争堡垒展开。

### 100章以上仍能长出的不同故事

可以写成监狱世界、城邦世界、战争世界、地下文明、巨型生物体内、封闭宫殿和空间灾难。

长期核心是：

- 边界究竟是在保护谁，还是在囚禁谁。
- 主角每次开路，是否也在摧毁一个本地世界赖以维持的秩序。
- 一个只能在“内外之间”存在的生命，能否拥有真正属于自己的家。
- 当主角足以打开城市级缺口时，打开道路是否等于发动战争。

### 最小可信桥梁

只需固定三件事：

1. 副本世界由真实边界组成。
2. 界痕负责记录边界变化。
3. 主角能吞掉实体边界并短暂连通两侧。

### 不可磨平的三点

- 主角不是会开门的人，而是门本身的捕食者。
- Power 改变的是空间关系和救援可能，不是攻击数值。
- 每一次开路都会同时改变本地人的逃生、财产和领地关系。
