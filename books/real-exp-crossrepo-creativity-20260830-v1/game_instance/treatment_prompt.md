# PRE-AUTHORITY CREATIVE APERTURE｜非 Canon

这里不是 production Fantasy Seed，也不生成新的世界/人物/力量权威。它只在任何 Authority 冻结前扩大作者可选择的搜索空间。

大胆设定不是术语更多、机制更复杂，而是尽早押注一个会改变读者想象与主角动作的高风险事实：主角以什么存在形态开始、世界眼前有什么不可忽略的异常、主角拥有哪种直接且不公平的特权、行动怎样被别人看见并产生社会后果。好设定至少让主角反复做出普通“人类修士升级”不会自然拥有的新动作，并能在第一章形成一幅具体画面。

共同边界：
- 先寻找让人想点开第一章的画面、身体状态、危险、欲望、反客为主或尺度冲击，再补最少可信桥梁；不要先把五百章合理性解释完。
- Category Collision 必须改变因果和玩法，不是把两个类型词并排写在简介里。
- 允许非人、非标准身体、异常生命阶段、公开观看/记录、跨层叙事或其它强界面；也允许普通人形，只要起点关系本身足够特殊。
- 不能只给普通修士换职业、换能源名、换宗门名、换一套考试/资格/资源分配流程。
- 直接特权优先改变战斗、身体、移动、生存、探索、占有、召唤、学习、变形、支配或其它可感知动作；不默认落成分析、维护、审核、路线优化或工作效率。
- 每个候选只保留少量熟悉锚点，让读者能一句话听懂；大胆不等于难懂。
- 不复制任何来源作品的角色、专名、事件组合或具体能力，只迁移“高风险押注、强画面、玩法碰撞、立即兑现”的创作方法。

你是 Single-Agent Premise Forge。你一次同时设计世界异常、主角存在形态、直接特权与叙事界面，用来测试单代理在明确要求“大胆”时是否仍会过早自洽。

生成 3 个完整候选：S1 追求最强商业吸引力而非最安全；S2 主动再大胆一档；S3 可以极端，但必须一句话可懂。不要自动选择。三者不能只是同一个人类修士、同一种升级循环换世界名。

字段边界必须真实可拆：`World Interface-only Direction` 只写即使换掉主角也成立的观看／记录／传播规则，不提主角、Power 或开篇事件；`Initial Origin-only Direction` 只写第一场事件发生前已经成立的 T0 出生位置、诞生方式与零点经历，不补未来剧情；`Initial Scale Position-only Direction` 必须逐条写主角 T0 在 World 已定义每一条适用主尺／副尺上的精确位置，不适用也必须明确写 `不适用` 及原因，不能让 Human / Power 临时发明 `0级`、`尺外` 或默认一阶；`Power-only Direction` 必须把触发、目标类别、能做的动作与永久边界写清，不能靠 Story 再补。作者选择后，这些字段会被代码作为各 lane 的硬约束分别投影，所以不能把关键事实只藏在第一章画面、Compilation Trace 或最小桥梁里。

大胆不等于先写一个震撼镜头，再让下游临时发明机制把它圆上。每个候选必须 **Authority-compilable**：
- 第一章每个超常结果都要能从已经写明的 World / Interface / Ontology / T0 Origin / Power 直接推出；触发尚未满足时不得提前使用该能力，除非 `Power-only Direction` 明确写出一次性的 T0 例外及其边界。
- Interface 默认只能观看、记录、传播或改变社会后果，不能偷偷复制、放大或改写 Power 的因果覆盖；若它本身会路由因果，必须作为对所有相关行动者都成立的 protagonist-blind World 规则写清。
- 主角 T0 若落在公开力量尺之外，World-only 必须先定义一个不依赖主角的通用位置或类别；不能等 Human / Story 把 `0级`、`尺外` 或 `未登记` 临时解释出来。
- 20章与百章图景只能复合已经存在的规则，不得假设未写明的全城共同载体、无限复制、中央控制或新能力。
- `Authority-Compilation Trace` 不是自夸总结。逐项写出“具体动作／结果 → 精确来源字段 → 触发是否已满足 → 目标／载体 → 为什么合法”；发现无法闭合就修改候选本身，而不是写“后续解释”。

# 作者方向与硬约束

成熟中文男频高强度游戏副本 / 无限流成长爽文。长期形式是：一个稳定、极易理解的跨副本 Meta Grammar + 一个个真正独立、生活自洽的 Local Instance World。系统、任务、结算只是把主角送进故事并把获得带出去的骨架，不是故事本身；每个副本都必须像真的世界，有本地人物自己的欲望与关系、公开力量尺度、真正值得争夺的东西、危险与历史，不能写成换皮关卡、密室题库或 NPC 工具箱。

第一轮只设计第一个副本与跨副本最小公共规则，禁止提前设计第二副本的具体社会、力量、宝物、敌人或专门针对主角 Build 的答案。第一个副本作为当前 World Horizon，大约 8—12 章完成最自然；本次只实际生成前 5 章，因此前五章必须形成持续上升的完整前半段，但不要为了交付五章强行打完 Boss 或提前结算整个副本。

“游戏感”要清楚但低认知成本：进入条件、主任务/可选目标、失败或退出边界、可携带奖励、跨副本成长坐标应尽早让读者明白；面板只显示少数真正改变选择的信息，不堆几十项属性、职业树、材料表或规则说明。跨副本主力量必须有一把简单精确的长期 Reader Ruler；独立副本如果有自己的本地力量体系，也要有可读的精确本地尺，但本地尺不改写全局主尺。规则可以被利用，但不要让“找文字漏洞”成为唯一爽点。

第一副本开局要有强烈的“我想进去看看 / 我必须知道接下来会发生什么”：进入后尽快建立一个具体高价值欲望对象、一个立刻能伤人的威胁、至少一个有自己利益的本地人物或同行者，以及一个不是完成主任务就自动得到的额外诱惑。副本表层任务与世界真实矛盾可以不同，但 Mystery 不要一出现就解释完；让未知通过新事实改变选择，而不是连续假反转。

节奏偏快、剧情跌宕。前五章内至少发生数次真正改变当前故事的 State Change：例如初始生存判断被推翻、第一次高价值获得、同行/本地人物关系换位、主角 Power Asymmetry 首次显露、任务目标被更大的欲望或危险重新定价。每次推进后直接进入 consequence，不用复测、登记、报告、清点、路线规划、流程验证填充篇幅。战斗、追逐、潜入、交易、关系选择、发现、抢夺等可以交替，不要 Boss 逐级排队。

Power Asymmetry 宁强勿弱，应该让读者很快觉得“这个能力我也想要”，并能在不同副本持续复利；不要只给副本内临时数值 Buff。新优势显露时若有真实观众，允许 Collective Shock、懂行者 Ruler Calibration、关键人物 Behavioral Repricing 同时吃满。获得必须有 afterlife：带出副本后能继续改变后续力量、身份、关系、选择或下一副本玩法，而不是结算界面里一闪而过。

Human 必须像具体的人，不是最优通关算法。钱、胜负、虚荣、审美、身体吸引、享受、好奇、自利、报复、偏心、野心和舍不得都合法；至少一个具体人物关系要能真正改变他的选择。同行者不能都围着主角当辅助，副本中的本地人物更不能因为“是 NPC”就失去人格。

世界与力量要具体、好懂、可视觉化；Small Grammar, Large Variation。禁止用抽象哲学、治理、资源分配、维护、项目管理、测试验证或工程实施制造复杂感。前 1—2 章要让读者知道：这是怎样的副本、当前最直接的危险、什么东西最值钱、主角与常人的力量差距、回去需要什么；同时保留至少一个真正值得跨章追的未知。

Story Program 只具体规划当前第一个副本 Horizon，并为副本结束后的 World Horizon Handoff 留出自然出口；Handoff 只说明何时该扩、carry-forward 与 orchestration，不预写下一副本答案。Outline 规划第 1—10 章。本次实际只生成第 1—5 章。


# NON-CANON CREATIVE QUARRY｜Optional Stimulus

下方材料来自一个独立、可丢弃的 Creative Quarry。它们不是 Authority，也不是必须使用的 checklist。你的任务仍是执行上面的 production Premise Forge 合同。

使用纪律：
- 每个 S 候选最多借 1 条 Concrete Substrate，再最多借 1 条 Living Actor Engine 或 Recurring Carrier；也可以全部不用。
- 必须把素材重新发明成新因果，不得照抄 Quarry 的人物、物件组合或措辞。
- Appetite Pressure 只能帮助你感觉“什么会让人想抢/怕/嫉妒/舍不得”，不得预写未来 Human Seed 或主角人格。
- Quarry 绝不能替 Power-only Direction 发明能力，也不能替 World-only Direction 写完整规则。
- 一个候选仍然只有一个 dominant premise bet；如果素材只会增加名词、说明、机制层或认知负担，就丢弃它。
- 优先保留能增加 Changed Verbs、第一章标志画面、Living Actor friction、20/100章不同故事姿态的素材。
- 不提 Creative Quarry、来源项目或“借鉴”。最终只输出 production 要求的三张 S 卡。

我先做一次轻量上下文核对：只查已有 TGN 记忆中的“创意采石场 / Premise 边界 / non-Canon”约束，避免把后续架构或既有正史误带进素材；若查到相关记录，我只会据此收紧输出边界，不改任何文件。上下文核对完成：相关约束只确认了两点——本轮素材必须保持候选、不可自动晋升为 Canon；World / Power / Human / Story 需要隔离，不能替后续架构提前做决定。下面直接按你给定的五段格式产出，不再读取项目文件，也不把记忆中的既有创作线当作输入。`rg` 在当前 PowerShell 环境不可用；这只影响记忆索引定位，不影响本轮创作。我不会扩大检查范围，改用有行号的定向文本检索，随后直接交付素材。# CREATIVE QUARRY

## A. Concrete Substrates｜4条

1. 潮间带退潮后会露出短暂的硬泥脊，涨潮时原路会被水、漂木和浮屋切断；天然允许抢渡、救人、追逐、藏货，以及用脚下软硬判断下一步能不能走。

2. 厚玻璃受热不均时，外表完整，内部却可能藏着延迟发生的裂纹；天然允许徒手搬运危险物、用温差逼裂、隔着玻璃观察，也允许一次看似成功的动作在几步后突然崩坏。

3. 白蚁丘和蜂巢会靠细小通道、温度差与气流维持内部秩序；天然允许用烟、热气、食物或声音改变通道走向，让追踪、潜入和驱赶变成即时动作。

4. 在口头命令容易失真的地方，人们会把取货、停工、欠债或放行写进绳结、刻痕和颜色；天然允许剪断、重绑、偷换、误读，并让同一条绳子在不同人手里变成命令、凭证或威胁。

## B. Appetite / Emotion Pressures｜4条

1. 一个刚输掉比赛的年轻人极想让旁观者承认他仍然厉害；他会主动重做刚才最危险的动作，还故意把失败痕迹藏起来。

2. 一个照料濒死动物的人害怕失去它最后的温度和气味；他会拒绝高价交换，把动物裹进自己的衣服，甚至追着拿走它的人闯进禁区。

3. 一个被同伴抢走功劳的手艺人嫉妒得无法忍受对方受人欢呼；他会在公开展示前偷偷换掉一个细小零件，却把修复工具留在现场等人发现。

4. 一个欠债店主想让曾经羞辱过自己的人低头求他；他会扣住最后一份干粮和遮雨处，明知对方可能因此受伤也不肯松手。

## C. Living Actor Engines｜4条

1. 一个退役摆渡人想在下一次涨潮前捞回一只铁盒；她会先剪断警示绳、独自下水，若没有主角介入，原本唯一安全的水路会变成谁都敢闯的诱饵。

2. 一群洞燕只认最暖的气流筑巢；它们下一步会集体迁入一条狭窄通道，鸣叫、粪羽和扑翼会暴露经过者，若无人干预，整条通道都会被迫改变用途。

3. 三人打捞队只想私吞一只未开封的箱子；他们会先交换货签、拆散队伍，再把其中一人留在错误地点顶罪，若没有主角介入，守门人和队员之间会先爆发争夺。

4. 一支送葬小队只想赶在暴雨前把棺木送到钟楼；他们会拆掉一段私人院墙的木桥强行通过，若没有主角介入，原本互不相干的几户人家会因此封路、追赶并争夺棺木。

## D. Recurring Carriers｜4条

1. 门框上三道旧白色水痕：第一次只是测水位，后来被拿来判断谁说了假话，最后新痕盖住旧痕时，又变成逼人开门的现场证据。

2. 一条打着三个结的蓝绳：第一次用来捆货，第二次系在人的手腕上，第三次被剪下一截后，既可以当邀请，也可以当公开指控。

3. 一个缺口搪瓷盆：第一次接雨水，后来用来承接碎玻璃，再后来敲击盆沿成为远处信号；它每次出现，都能显示持有者此刻是在求生、交易还是挑衅。

4. 指甲缝里反复出现的黑色粉末：第一次像普通污渍，后来成了证明某人碰过某件东西的痕迹，最后有人急着把它洗掉，洗手动作本身反而改变了旁人的判断。

## E. Collision Invitations｜4条

1. A1 潮间带硬泥脊 × C1 退役摆渡人：一次捞取行动可能变成抢夺安全时间的竞赛；救人和夺货会在同一条即将消失的路上冲突。

2. A2 延迟裂纹玻璃 × B1 炫耀压力：公开证明勇气的动作可能直到观众欢呼后才崩裂，让“赢得注目”和“及时逃命”变成相反选择。

3. A3 巢穴气流 × B2 依恋压力：为了保住一只濒死生物而改变温度，可能同时改变群体生物的迁徙方向，把保护动作变成暴露位置的信号。

4. A4 绳结命令 × C3 打捞队：一次换签或剪绳可能同时改变货物归属和行动许可，让本来要完成交易的人突然必须证明自己没有背叛。
