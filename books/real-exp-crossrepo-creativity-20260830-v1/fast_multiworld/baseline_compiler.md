我会按“可编译性而非创意优劣”逐项核对三案：只追问字段是否足以推出具体动作、触发与载体是否闭合，以及尺度与长线承诺是否越界。为遵守 TGN 现有权威边界，我先读取系统审计规范和相关记忆索引；不会改写候选。我采用 `tgn-system-steward` 的只读审计方式：它要求 Compiler 只判触发、目标／载体、尺度和远期复合冲突，不能拿“保守”替代可编译性。接下来只读取当前工作树中与 Premise Compiler 直接相关的约束，确认没有把旧分支规则误套进来。# PREMISE AUTHORITY COMPILER

- Opening legality: `借终式`本身可由正在黄昏回式的驮兽、主角咬合与同类蹄击推出。冲突在骨镜：其明文只自动记录“一次完整回式”，未覆盖主角随后踢开收尸人；三百步内的实际见证者也未写明。因此“骨镜记录尸车内怪物行动→城内悬赏”不能由现有 Interface 精确推出。

## S3

- Verdict: CONDITIONAL PASS
- Opening legality: 死囚三息直视、死囚脚下影子与百人直接见证均有明文，换影与定影可成立。但能力规定主角必须出现于“该目标脚下的影子”；首章目标是死囚，标志性画面却让主角出现在刽子手身后，二者未被写成同一位置或连续表面。
- Scale legality: PASS。`墙影`与`无见`均为 World 已定义的公开尺位；T0 未新增尺外位置。
- Long-form legality: 首章百人定影已明文令`影体尺`提升一段，故主角应从`墙影`升至`地影`。第 13—16 章又写“三次公开换位成功，墙影提升至地影”，与已发生的首次提升及“一次定影升一段”冲突。三次定影后的“任意无人影子”解锁与逐次升阶也须按同一状态账本复合。跨世界抵达与携带既有定影的机制未定义。
- Exact hidden bridges: 死囚脚下影子与“刽子手身后”的位置同一性；首次定影后的影体尺状态；后三次定影的升阶账本；跨世界出口。
- Boldness preserved: 保留。被看见三息后换影、公众把既成结果钉死、无肉身主角在刑场翻位，以及公开证据反噬匿名，均不是冲突来源。
