# CHARACTER LIFE CONTEXT｜Upbringing Authority

## 普通人的生活与上升

断路界的人一生大多围绕一座稳定的门生活。白天，村民可以沿熟悉的路去田地、矿场、集市和邻近聚落；入夜后，道路可能折回原地、把人带进荒地，或让人彻底失去方向，因此大多数人会在日落前回到门内。

稳定的远行依靠门。两扇门必须拥有配对的门骨，才能建立可重复使用的门路；门路的宽度由较窄的一侧限制。普通人出远门通常跟随商队、猎队、军队或有经验的引路人，独行者只有在熟悉的白昼路段才相对安全。

年轻人常见的上升入口有四种：进入火院修炼身火，加入门卫与军府，成为商队护卫或猎队成员，或者拜入门匠作坊。修炼失败的人通常回到农务、矿务、车队、门粮采集或低阶守夜岗位；身火受损严重者不能再修炼，却仍可能凭经验成为引路人、门录抄员或门内工头。

普通人的生活并不贫困到无法维持，但门路、粮食、药材、门骨和夜间安全都受稳定门数量限制。一个聚落有没有三幅以上的门，往往直接决定它能不能拥有固定市集、医者和长期商队。

## 社会现实与身份

聚落首先围绕稳定门建立，其次才是城墙、街市和官署。门卫掌握出入秩序，门匠掌握修补与扩幅，商盟掌握门路货运，军府掌握五幅以上门的调度。一个人的出生地、门籍和能否获得门路通行资格，常常比短期财富更决定他能去哪里。

火院与家族通常保有不同的身火技法。军府偏好能在门外作战、护送粮道的修士；商盟偏好能活着穿过折路和保护货物的人；门匠作坊则看重身体耐热、手艺和长期服从，不会单纯按身火阶录用。

当前较重要的公开势力包括：

- 断北军府：军府，负责北部边境与大型门路的军事调度。
- 白石行盟：商盟，经营粮食、药材、门骨和远程门路。
- 鸦脊部：荒原部族，长期在无稳定门的区域迁徙与放牧。
- 鹿回门院：地方门匠与门养师组成的工坊组织，普通人可通过学徒制进入。
- 临河王朝：王朝，依靠门籍、粮道和军府控制主要城镇。

门录也会改变身份。公开战斗被门记录后，胜负、伤亡和出手方式可能成为招募、审判、婚姻、交易和军职晋升的依据；但门录不能证明伏击者的动机，也不能证明门内发生了什么。

## 世界里真正值钱、值得想要的东西

- 身火技法：同一阶位下，能否更快聚火、让火力更稳定、减少身体损耗，决定修士是否值得招揽。
- 火食与药材：能提升身体承载力，但昂贵且有失败风险；普通家庭通常只能供一个孩子长期修炼。
- 导火兵器：能把身火传得更远、更集中，使中阶修士在狭窄门口拥有明显优势。
- 门骨：用于配对和修补门路，产地稀少，掌握它就等于掌握远程交通资格。
- 稳定门的使用权：一幅门关系到个人和小队，三幅门关系到商队，五幅以上门则关系到军队、粮食和城市生死。
- 路图与引路经验：地图只能记录白天的道路，真正有价值的是哪些路段会在什么季节、什么天气提前折断。
- 门匠作品：一座稳定、可扩幅、能承受军队通过的门，比许多身火修士更能改变一地命运。
- 门录信誉：一段公开影像能让一个无名护卫获得军府、商盟或火院的资格，也能让某个家族永远背上败战名声。
- 可靠的伙伴与队伍：断路环境下，能在夜前判断撤退、在门外救伤员的人，比单独的高阶力量更能决定普通远行是否成功。

## 世界知识边界

普通人知道身火大致分九阶，知道身火修士能强化身体、使火离体，也知道夜间道路会折断。大多数人知道一幅、三幅、五幅、七幅、九幅门分别能通过什么规模的队伍，知道出远门要依靠商队、猎队、军队或门路。三人以上在稳定城门附近看见高阶力量时，大家都知道门可能留下十二息门录，但也知道门录不能看见门内。

专业人士与修士知道身火如何承载、哪些火食会烧伤身体，知道不同兵器和技法的适配差异，也知道门幅并不等于门属生物的战斗力。门匠知道门根、门膜、门腹和配对门骨的维护方式，能判断一座门是否正在失去世界承认。军府与商盟还掌握大量门路时刻、粮道风险和门录调阅权。

顶层势力知道九幅门的分布、主要门路的军粮容量、哪些旧门能够扩幅，以及某些门属生物会主动拒绝军队或难民。他们能用门路调动战争、贸易和人口，却无法凭命令让一座门稳定，也无法保证所有道路在夜间保持连续。

当前无人能完整解释的事实包括：

- 道路为什么主要在夜间折断，以及为什么有些夜晚会提前发生。
- 世界究竟依据什么承认一座门；聚落、门根、门骨和人的长期生活之间的关系仍无定论。
- 门属生物最初从何而来，为什么会接受某些人通过、拒绝另一些人。
- 为什么门录只保留十二息，为什么它没有声音，也无法记录门内。
- 霜井门连接的未知地点是否真实存在，还是门腹自身制造出的错误出口。
- 某些荒废聚落的门会在多年后重新稳定，门内却出现从未在当地生活过的植物、兽骨与道路痕迹。

# FROZEN PRECISE POWER RULER GRAMMAR｜只用于人物 T0 精确位置

### 精确力量主尺｜Frozen Grammar

主尺类型：连续数字

主尺名称：身火阶

精确位置格式：身火{N}阶

数字精度规则：1—9，每1阶都是可记录的精确位置，不使用半阶或模糊小阶

当前可见范围：身火1阶—身火9阶

当前大档位：初火（1—2阶）、成火（3—4阶）、守门级（5—6阶）、镇域级（7—8阶）、九阶

- 无身火的普通人只能依靠工具、队伍和门路生活。
- 身火1—2阶可以显著增强耐寒、体力和恢复力，是普通护院、矿工头目与短途护卫的常见水平。
- 身火3—4阶能够让火力短暂离体，强化兵器，独自应对常见路兽，是乡镇猎队和正式门卫的骨干。
- 身火5—6阶能够连续释放火力、压制一群普通人，并在小型道路折断时保护一支队伍，是城镇门卫、军府百夫长和大型商队护首的正常上限。
- 身火7—8阶可以在一定范围内改变战场节奏，短时固定危险路段，破坏普通门楼外壳，或逼退低幅门属生物，是一城一地真正稀少的强者。
- 身火9阶极少见，能够把火力铺成覆盖一段边界的战场手段，决定五幅门附近的局部战争，但仍不能单凭阶位推定能摧毁九幅门。

门属生物的公共门幅分类为：

- 一幅：容一人通过；
- 三幅：容车马与小队；
- 五幅：容整支军队；
- 七幅：容街巷与大型器械；
- 九幅：能把一段城墙或战场边界纳入自身门腹。

身火阶长期用于比较个人，门幅长期用于比较交通、战争和聚落命运。两者不能互相替代。

断路界还存在一条可选的副道路：门匠与门养师。它们不另造一套力量，而是学习如何喂养门属生物、修补门膜、配对门骨、调整门路和扩大门幅。普通门匠只能维护一幅或三幅门；真正的高阶门匠能让一座旧三幅门稳定扩展到五幅，或在战争中暂时让门腹承受更大的边界。九幅门匠极为稀少，他们的作品足以改变王朝边境和军队行进路线。

任何三人以上同时看见的高阶力量，都会被最近的稳定城门记录成一段十二息的无声影像，保留一天。影像只记录门外被看见的力量，不显示力量来源，不复制物体或能力，不改变原事件；门内发生的事不会被记录。没有稳定城门的地方，也不会产生门录。

可用抽象：Creative Problem：人物变强、变富、获得身份或进入世界级冲突之后，怎样避免他自动变成只剩任务、职责、胜负、资源和长期 KPI 的执行器？
真正的问题不是“给角色加一个爱好”，而是：
> 当直接升级收益被拿掉时，什么具体东西仍然值得这个人物去吃、做、看、练、保护、赠予、回返、追逐或享受？成长以后，这种私人价值如何继续影响真实选择？
Mechanism：当人物已经建立过具体私人欲望时，成长后的新阶段可以让其中少量欲望以新的方式重新进入行动：
`早期私人价值 → 力量/身份/财富扩大 → 欲望优先级与实现方式变化 → 在新处境中通过具体选择再次出现 → 证明人物没有被自动职业化`
关键不是维持原样，而是允许 **desire reordering**：
- 频率可以降低；
- 实现方式可以改变；
- 旧欲望可以与新欲望竞争；
- 某些欲望可以真正消失，但需要由经历、选择或关系造成，而不是“升级后自动成熟”。
私人价值必须落在行为里，而不是作者声明里。可见形式包括但不限于：回家、吃一顿曾经吃不起的东西、继续一个无人奖励的练习、为具体的人改变风险选择、想看远方、追逐强敌、赠予、享受身体与生活、拒绝一个会吞掉行动空间的机会。

使用边界：只迁移当前卡片的抽象机制，不迁移来源人物、事件、专名、世界设定或句式。
