# PRE-AUTHORITY CREATIVE APERTURE｜非 Canon

这里不是 production Fantasy Seed，也不生成新的世界/人物/力量权威。它只在任何 Authority 冻结前扩大作者可选择的搜索空间。

大胆设定不是术语更多、机制更复杂，而是尽早押注一个会改变读者想象与主角动作的高风险事实：主角以什么存在形态开始、世界眼前有什么不可忽略的异常、主角拥有哪种直接且不公平的特权、行动怎样被别人看见并产生社会后果。好设定至少让主角反复做出普通“人类修士升级”不会自然拥有的新动作，并能在第一章形成一幅具体画面。

共同边界：
- 先寻找让人想点开第一章的画面、身体状态、危险、欲望、反客为主或尺度冲击，再补最少可信桥梁；不要先把五百章合理性解释完。
- Category Collision 必须改变因果和玩法，不是把两个类型词并排写在简介里。
- 允许非人、非标准身体、异常生命阶段、公开观看/记录、跨层叙事或其它强界面；也允许普通人形，只要起点关系本身足够特殊。
- 不能只给普通修士换职业、换能源名、换宗门名、换一套考试/资格/资源分配流程。
- 直接特权优先改变战斗、身体、移动、生存、探索、占有、召唤、学习、变形、支配或其它可感知动作；不默认落成分析、维护、审核、路线优化或工作效率。
- 每个候选只保留少量熟悉锚点，让读者能一句话听懂；大胆不等于难懂。
- 不复制任何来源作品的角色、专名、事件组合或具体能力，只迁移“高风险押注、强画面、玩法碰撞、立即兑现”的创作方法。

你是 Single-Agent Premise Forge。你一次同时设计世界异常、主角存在形态、直接特权与叙事界面，用来测试单代理在明确要求“大胆”时是否仍会过早自洽。

生成 3 个完整候选：S1 追求最强商业吸引力而非最安全；S2 主动再大胆一档；S3 可以极端，但必须一句话可懂。不要自动选择。三者不能只是同一个人类修士、同一种升级循环换世界名。

字段边界必须真实可拆：`World Interface-only Direction` 只写即使换掉主角也成立的观看／记录／传播规则，不提主角、Power 或开篇事件；`Initial Origin-only Direction` 只写第一场事件发生前已经成立的 T0 出生位置、诞生方式与零点经历，不补未来剧情；`Initial Scale Position-only Direction` 必须逐条写主角 T0 在 World 已定义每一条适用主尺／副尺上的精确位置，不适用也必须明确写 `不适用` 及原因，不能让 Human / Power 临时发明 `0级`、`尺外` 或默认一阶；`Power-only Direction` 必须把触发、目标类别、能做的动作与永久边界写清，不能靠 Story 再补。作者选择后，这些字段会被代码作为各 lane 的硬约束分别投影，所以不能把关键事实只藏在第一章画面、Compilation Trace 或最小桥梁里。

大胆不等于先写一个震撼镜头，再让下游临时发明机制把它圆上。每个候选必须 **Authority-compilable**：
- 第一章每个超常结果都要能从已经写明的 World / Interface / Ontology / T0 Origin / Power 直接推出；触发尚未满足时不得提前使用该能力，除非 `Power-only Direction` 明确写出一次性的 T0 例外及其边界。
- Interface 默认只能观看、记录、传播或改变社会后果，不能偷偷复制、放大或改写 Power 的因果覆盖；若它本身会路由因果，必须作为对所有相关行动者都成立的 protagonist-blind World 规则写清。
- 主角 T0 若落在公开力量尺之外，World-only 必须先定义一个不依赖主角的通用位置或类别；不能等 Human / Story 把 `0级`、`尺外` 或 `未登记` 临时解释出来。
- 20章与百章图景只能复合已经存在的规则，不得假设未写明的全城共同载体、无限复制、中央控制或新能力。
- `Authority-Compilation Trace` 不是自夸总结。逐项写出“具体动作／结果 → 精确来源字段 → 触发是否已满足 → 目标／载体 → 为什么合法”；发现无法闭合就修改候选本身，而不是写“后续解释”。

# 作者方向与硬约束

成熟中文男频玄幻成长长篇。请创造完全新的世界，不复用近期实验的猎阶/异兽心核、景息/天景、衡阶/重力、潮炁/潮印、兵器回响等指纹。核心阅读欲望优先是个人变强、战斗、奇遇、稀有功法/兵器/身体变化、怪物/异族、秘境、强者竞争、公开比较和真正让人眼馋的获得；治理、维护、运输、工程、资源分配只能做背景。世界规则要一句话能理解，专有名词少而清楚；力量有长期可复用的公开主尺和高价值对象。World 阶段完全不知道未来主角和金手指。


# NON-CANON CREATIVE QUARRY｜Optional Stimulus

下方材料来自一个独立、可丢弃的 Creative Quarry。它们不是 Authority，也不是必须使用的 checklist。你的任务仍是执行上面的 production Premise Forge 合同。

使用纪律：
- 每个 S 候选最多借 1 条 Concrete Substrate，再最多借 1 条 Living Actor Engine 或 Recurring Carrier；也可以全部不用。
- 必须把素材重新发明成新因果，不得照抄 Quarry 的人物、物件组合或措辞。
- Appetite Pressure 只能帮助你感觉“什么会让人想抢/怕/嫉妒/舍不得”，不得预写未来 Human Seed 或主角人格。
- Quarry 绝不能替 Power-only Direction 发明能力，也不能替 World-only Direction 写完整规则。
- 一个候选仍然只有一个 dominant premise bet；如果素材只会增加名词、说明、机制层或认知负担，就丢弃它。
- 优先保留能增加 Changed Verbs、第一章标志画面、Living Actor friction、20/100章不同故事姿态的素材。
- 不提 Creative Quarry、来源项目或“借鉴”。最终只输出 production 要求的三张 S 卡。

我会按“非 Canon、可丢弃原材料”的边界输出，重点避开近期实验指纹；先快速核对已有项目记忆中的禁用方向，再直接给四类素材与碰撞邀请。# CREATIVE QUARRY

## A. Concrete Substrates｜4条

1. 有些巨兽蜕下的皮膜半透明，干后会卷曲成硬片，里面粘着它经过的泥、花粉和碎石；人可以把新鲜皮膜蒙在身上挡箭，或趁它未干时追踪、偷运、伪装。

2. 一种矮草的种荚遇到连续声音就会闭合，安静后才慢慢张开；脚步、兵刃碰撞和喊声会让一片草地接连“合嘴”，适合制造误判、困住猎物或逼人用无声动作穿行。

3. 雷击过的黑色岩脉会沿着裂缝结出薄如刀片的亮片，稍微受热便自行碎裂；有人拿它磨兵器，有人把亮片嵌进护具，争抢时必须在随时崩裂的岩壁上动手。

4. 某种穴居蜂会用不同颜色的泥封住巢门，搬巢前会整夜重排封泥；拆下来的泥片可以临时遮门、做标记，也能让后来者误读一处巢穴是否安全。

## B. Appetite / Emotion Pressures｜4条

1. 一个被同伴救过命的采猎者，想证明自己不是累赘；他会故意接最危险的路线、拒绝包扎，并在众人面前把伤口重新撕开来继续战斗。

2. 一名年轻铸兵师嫉妒师兄拿到唯一的稀有材料；他不急着偷走材料，而是当众提出比试，逼师兄先把成品打出来，好让所有人看见谁更配拥有它。

3. 一个失去家传姓氏的人，想重新得到旧家族的承认；他会收集带有旧印记的废物，逐件修好后挂在身上，遇到曾经的族人便主动展示。

4. 一头繁殖期的独居猛兽害怕自己的巢被发现；它会反复搬动幼崽、故意留下错误气味，并在夜里袭击所有靠近假巢的人。

## C. Living Actor Engines｜4条

1. 受伤的岩背兽想夺回被人捡走的幼崽；它下一步会沿着商队气味追击，撞翻路障，若没有主角介入，沿线商队会被迫改道，几个采猎队也会互相争夺幼崽。

2. 一个被逐出兵坊的试刀人想找回断刃上的一小截刀尖；他会逐场挑战持有相似兵器的人，输了就留下赌注，继续把消息扩散到更大的比武场。

3. 三名洞窟拾荒者想抢在别人前面打开一处刚露出的窄缝；他们会互相隐瞒发现、轮流放风，并在争执中敲掉支撑岩块，导致洞内路线不断变化。

4. 一位年老的祭歌手想找回一段失传的高音；他会偷偷混入各地仪式，故意唱错最后一句，引得年轻歌手纠正他，也让不同地方的人开始争夺那段唱法。

## D. Recurring Carriers｜4条

1. 一根打满结的旧绳：第一次用来量深度，后来变成分配战利品的依据，再后来某个结被割断，所有人对“谁先到达”产生不同说法。

2. 一只缺口朝外的青瓷碗：起初是路边乞者的饭碗，后来被用来盛药、接血，最后在公开比试中成为判断谁受伤更重的显眼证物。

3. 一道总被重新刷白的门槛：第一次只是店铺入口，后来白灰被踩出不同脚印，再后来有人把兵器、尸体和战利品依次拖过它，使这道门槛每次出现都代表不同的“进入资格”。

4. 手腕上洗不掉的银灰色斑痕：最初只是接触某种矿粉后的身体痕迹，后来被人当作危险经历的证明，再后来同样的斑痕出现在不该接触矿粉的人身上。

## E. Collision Invitations｜4条

1. A1 的巨兽蜕膜 + B1 的“证明自己不是累赘”：一个人抢着披上尚未干透的皮膜挡下第一轮攻击，却因皮膜卷缩被迫改变战法。

2. A2 的闭合种荚 + C1 的受伤岩背兽：猛兽的奔跑让草地一片片合拢，追兵和救援者都必须根据声音停顿重新判断位置。

3. B2 的嫉妒 + D1 的打结旧绳：两名兵师用同一根绳子标记试炼距离，比赛结束后双方都坚持自己的结法才是真正的记录。

4. C3 的洞窟拾荒者 + A3 的雷击亮片：拾荒者把亮片当作照路工具，岩壁受热接连碎裂，原本争夺入口的人反而被迫在坍塌中争抢同一件东西。
