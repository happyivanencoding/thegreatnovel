# PREMISE AUTHORITY COMPILER

## S1

- Verdict: CONDITIONAL PASS
- Opening legality: 不成立于当前明文。巨兽“刚死亡”不等于存在一层可进入的、已脱离主人的外皮；Power 只允许进入“脱离主人不超过三十息”的外皮，或三日内自然蜕层。`Authority-Compilation Trace` 直接把“刚死”推成“外皮已脱离”，没有 World / Origin / Power 依据。且第二副巨兽蜕层被 Trace 称为“整品”，候选正文未在触发前给出其蜕品与实际存在状态。
- Scale legality: PASS。无脉类与薄品均在 World 已公开的主尺／副尺内，未新增主角专属等级。
- Long-form legality: 换身、以体型和移动方式改变战斗、争夺稀有蜕层、公开影像带来追猎与战利品后果，均可由既有 World + Power 复合推出。不得把“固定杀招”理解为跨外皮永久保留某一残留动作；当前 Power 只授予当前目标外皮的一种残留本能动作。
- Exact hidden bridges:
  - 第一章反杀所进入的巨兽载体，缺少“已脱离主人且仍在三十息内”或“黑月后三日内自然蜕层”的事实。
  - 该载体缺少已在触发前明定的蜕品；不能由 Trace 追加“整品”。
- Boldness preserved: 保留。主动弃身换体、尸堆复起巨兽、以战利品身体反杀猎队、身体即战术与身份风险，均未被要求降级。

## S2

- Verdict: FAIL
- Opening legality: 不成立。主角位于矿石细裂；猎人砍伤异兽后，异兽血流入岩缝，并不能推出主角已“接触目标的新鲜开放伤口”或“接触与该伤口相连的伤界边缘”。World 没有定义血液流入另一道岩缝会把两处伤界连通。随后从异兽腹侧“旧伤”出现，也缺少该旧伤在当时仍开放、且与前肢新伤同属可通行伤界的明文事实。
- Scale legality: PASS。未入尺类与细痕均使用已有公开尺，没有临时零级或主角专属肉身尺。
- Long-form legality: 不成立。Power 仅允许从同一目标的另一道开放伤口、或与其相连的伤界出现；没有定义主角如何把不同个体、战场、巢穴或跨城伤界编成可穿行的伏击网或战争通道。Ontology 说明他只能沿裂缝／伤口存在，不等于获得任意伤界之间的移动与路由能力。
- Exact hidden bridges:
  - “血流入岩缝”不是对目标伤口或其相连伤界边缘的接触。
  - 腹侧旧伤的开放状态、与前肢新伤的连通状态均未在动作发生前给出。
  - 主角本体被定义为两片肉膜；“抬手／挥击”及其如何成为异兽前爪可重复的动作，没有 Ontology 或 Power 定义。
  - 多伤口伏击网、跨城伤界通道超出“同一目标”的 Power 覆盖。
- Boldness preserved: 保留。伤口即入口、敌方攻击反成反杀条件、借强者肢体完成一息攻击，这些激进动作本身不是冲突；冲突只在其所需连接、出口与动作载体未被定义。

## S3

- Verdict: CONDITIONAL PASS
- Opening legality: 影子剥离与一具外身从入口走出，可由“闯入、十息内血触地、单一影子”的触发链推出。外身使用“同样的刀”反杀，则未被当前 Power 完整推出：Power 只给随身兵器的“基本形状”，未给出原兵器的实体、材料、锋利度、灵性效果或可战斗性。
- Scale legality: PASS。一界与一门均是 World 已公开的领域主尺／入口副尺；主角作为稳定微型秘境可被该尺容纳。
- Long-form legality: 部分成立。以界钥扩大边界、增加入口、改变内部地形，有 World 明文覆盖；外身却始终不能离任一入口三十步，且目标离开或死亡即崩解。因此“不同身体对应不同外界战斗任务”不能自动延展为远距离外勤；“移动的战争据点”也没有 World / Power 给出秘境移动机制。
- Exact hidden bridges:
  - “兵器基本形状”不足以推出外身持有并用该兵器完成击杀。
  - 外身的外界任务若超出入口三十步，缺少可用操作。
  - 秘境扩张不等于秘境可移动；百章“移动战争据点”缺少机制。
- Boldness preserved: 保留。主角即秘境、闯入者流血后其影子成为临时外身、强者肉身反向成为守门战力、入口和边界同时构成弱点与收益，均仍是候选的核心货架画面与 Changed Verbs。
