## S1｜《借死成王》

### 一句话货架简介

别人杀妖夺宝，他没有自己的身体——谁的尸体落到他手里，谁的肉身就会成为他的下一件兵器。

### World-only Direction

- 天空存在一口永久不闭合的“黑井”，每四十九日会坠下一具天外巨兽尸体。
- 每具黑井尸体内部必定嵌有一件不可复制的高价值遗物，统称“天遗器”；尸体落地后的七日内，胸腔、头骨和腹腔会逐渐变成危险遗境。
- 公开力量主尺为“九门战位”，只测量拥有稳定生命脉动的活体：一门至九门。
- 世界承认一类通用类别“无门类”，用于没有稳定生命脉动、无法占据九门战位的实体；它不是零门，也不是低阶。
- 公开副尺为“形体尺”：微、指、臂、身、屋、山、天，按实体最大稳定外形计量。
- 黑井尸体、天遗器和高门战斗，是各城争夺与强者比较的长期来源。

### World Interface-only Direction

- 各城的“观战碑”会自动记录三十丈内涉及天遗器，或至少有一名六门战位参与的战斗。
- 记录从战斗发生前三十息持续到战斗结束后三十息，并向所在城池公开播放。
- 观战碑只能观看、保存和传播，不能改变攻击结果、放大力量、制造实体或替任何一方触发能力。
- 公开记录会带来悬赏、追杀、名声、宗门争夺与身份误判，但这些都是社会后果。

### Protagonist Ontology-only Direction

- 主角属于“寄壳死生体”，是一种极罕见但世界已知的生命类别。
- 其真正身体不是人形，而是一团有自我意识的黑色骨髓结，内部没有完整器官、骨骼或固定四肢。
- 它可以作为独立实体存在，也可以把尸体当作外部身体。
- 尸体不是主角本身；主角离开后，尸体仍只是普通死物。
- 它没有继承尸体记忆、功法、身份或装备的天然机制。

### Initial Origin-only Direction

- T0 时，主角刚在一具刚从黑井坠落的天外巨兽口腔深处成形。
- 真体是一枚直径约十二厘米的黑色骨髓结，位于巨兽舌根后的裂腔中。
- 它尚未占据任何尸体，尚未见过活人，也没有移动过外部尸壳。
- 巨兽尸体、主角真体和一件嵌入巨兽右胸骨后的天遗器，在第一场事件发生前已经同时存在。

### Initial Scale Position-only Direction

- 九门战位：不适用。原因：主角真体没有稳定生命脉动，世界将其归入通用“无门类”，不是零门。
- 无门类位置：无门类·未着壳。
- 形体尺：指级，真体最大稳定直径约十二厘米。
- 天遗器价值列：不适用。原因：主角不是遗物，也未占有或融合天遗器。

### Power-only Direction

- 触发：主角必须直接接触一具死亡不超过一百息的尸体。
- 目标类别：人、兽、异族及拥有实体结构的活物尸体；不能占据仍活着的目标，也不能占据纯能量、声音或抽象规则。
- 能做的动作：
  - 将真体移入尸体内部。
  - 暂时控制尸体行动，使其像活体一样站立、奔跑、攻击和使用原有身体结构。
  - 在尸体被再次摧毁前主动脱离。
- 永久边界：
  - 不能获得尸体记忆、功法、境界、血脉身份或原有装备的使用知识。
  - 尸体越接近死亡，能维持的时间越短；超过尸体死亡后的自然腐败阶段，控制立即结束。
  - 同一时间只能控制一具尸体。
  - 真体必须位于尸体内部才能施加控制；离开尸体后极其脆弱。
  - 没有一次性 T0 例外；第一章能力能否使用，只取决于新鲜尸体接触是否成立。

### Story Interface / Opening Promise

第一章，黑井尸体刚落地，寻宝队割开巨兽下颚，发现里面只有一团黑髓。有人伸手触碰，黑髓钻入巨兽尸体，整座尸山突然站了起来。

观战碑同步记录这场战斗。城里的人看到的不是一个少年，而是一具天外巨兽尸体正在用陌生意志行走。

开篇承诺：主角每一次死亡都可能意味着获得一具更强的身体，但每一具身体也会暴露一种新的身份和弱点。

### Authority-Compilation Trace

1. 巨兽尸体从黑井坠落  
   → `World-only Direction：黑井每四十九日坠落天外巨兽尸体`  
   → 触发已满足  
   → 目标：天外巨兽尸体  
   → 这是世界异常的直接结果，不依赖主角。

2. 黑髓接触尸体后进入巨兽体内  
   → `Initial Origin-only Direction：主角真体位于巨兽舌根裂腔` + `Power-only Direction：直接接触新鲜尸体后移入`  
   → 触发已满足  
   → 载体：刚死亡不超过一百息的巨兽尸体  
   → 主角没有占据活体，也没有使用未满足的能力。

3. 巨兽尸体站起并攻击寻宝队  
   → `Power-only Direction：控制尸体行动` + `Protagonist Ontology-only Direction：尸体是可被寄居的外部身体`  
   → 触发已满足  
   → 目标：已被占据的巨兽尸体  
   → 只是控制既有肉身结构，没有复制功法或制造力量。

4. 巨兽胸骨中出现天遗器  
   → `World-only Direction：每具黑井尸体内部必定嵌有天遗器`  
   → 触发已满足  
   → 载体：巨兽右胸骨  
   → 遗物是世界异常自带的对象，不是主角临时获得的新设定。

5. 战斗被全城观战碑记录  
   → `World Interface-only Direction：涉及天遗器的战斗自动记录与传播`  
   → 触发已满足  
   → 载体：观战碑的影像记录  
   → 只改变观看范围与社会后果，不改变战斗因果。

### 第一章标志性画面

一具刚坠落的天外巨兽尸体撑破荒城外墙，寻宝者从它嘴里拖出一团黑色骨髓。黑髓钻入尸体，巨兽低头，用已经死去的眼眶重新“看”向所有人。

### 主角反复会做的新动作

- 以不同尸体改变战斗方式。
- 用巨兽尸体撞城门，用异族尸体潜入宗门，用强者尸体反杀原本的胜者。
- 主动寻找刚死不久的敌人，抢夺尸壳而不是战利品。
- 让敌人不敢轻易杀人，因为每一具新鲜尸体都可能变成主角的下一副身体。

### 第一次不公平兑现

寻宝队长以为自己杀死黑髓，主角却借巨兽尸体站起，一掌拍碎队长的护甲。队长最强的攻击，反而替主角取得了第一具真正强大的战斗身体。

### 20章玩法扩张

- 主角连续使用不同种族、不同体型的尸壳。
- 观战记录让“行走巨尸”成为悬赏榜上的公开目标。
- 敌人开始焚尸、封尸、抢夺尸体，尸体本身成为战场资源。
- 主角必须在强大尸壳、隐蔽身份和尸体剩余时间之间取舍。
- 天遗器争夺迫使他与真正的九门强者正面竞争。

### 100章以上仍能长出的不同故事

- 各大势力建立“无尸战场”，试图让战死者无法被利用。
- 主角可能占据旧王、异族皇者或古代巨兽的尸体，却始终无法继承其身份，只能面对身份与自我之间的冲突。
- 某些强者开始故意准备自己的尸体，试图把死亡变成最后一次布局。
- 主角真正的成长不是获得更多功法，而是学会选择什么身体值得成为自己。

### 最小可信桥梁

- 黑井尸体天然保存时间较长，因此第一章能提供一具新鲜且庞大的尸壳。
- 寻宝队知道天遗器存在，却不知道黑髓属于寄壳死生体。
- 观战碑只记录战斗，不替主角解释身份；误判和追杀由人自行产生。

### 不可磨平的三点

- 主角永远没有一具真正属于自己的肉身。
- “被杀”不是失败，而是获得新身体的入口。
- 读者每次看到主角，都会先问：这具身体原来是谁的？

## S2｜《杀我者为形》

### 一句话货架简介

他出生就是一颗不会说话的异卵；谁亲手杀死他，他就会孵化成谁的种族，并用那副身体反杀回去。

### World-only Direction

- 世界上空悬着一轮永不落下的白月。
- 白月照射尸体时，尸体会留下坚硬外壳，称为“王蜕”；王蜕是各宗门争抢的高价值对象，能够作为稀有功法和变异材料的载体。
- 公开力量主尺为“七冠阶”，适用于已经破壳并能独立行动的生命体，一冠至七冠。
- 世界另有通用“胚卵列”：封壳、裂壳、半孵、初行，用于尚未成为完整生命体的蛋、蛹、胎囊等；它不等于零冠。
- 公开副尺为“形量尺”：卵、猫、人、屋、山、天。
- 不同种族的冠阶可以比较，但冠阶不代表功法、武器或社会身份完全相同。

### World Interface-only Direction

- 各城“照生台”会自动记录城内所有涉及四冠及以上生命体的战斗。
- 记录包含攻击者、受击者、死亡时刻和可见身体变化，并向城中公开播放。
- 照生台不复制能力、不制造分身、不放大攻击，也不决定谁能复活或变形。
- 公开记录会造成名声、恐慌、悬赏、宗门争抢和对种族身份的误判。

### Protagonist Ontology-only Direction

- 主角属于一种未被正式命名的“逆孵体”。
- T0 形态是一个完整外壳包裹的卵状生命，内部只有一枚意识核心和未分化的身体组织。
- 它没有固定种族、面孔、四肢、鳞片或毛发。
- 它不是王蜕，也不是普通妖兽卵；王蜕是死后形成的外壳，逆孵体是活着的胚体。
- 它保留连续意识，但身体形态必须在破壳后才确定。

### Initial Origin-only Direction

- T0 时，主角是一颗长约六十厘米的黑色卵，形成于一头四冠荒兽的胸腔内。
- 荒兽已经死亡三日，白月照过尸体，胸腔外侧已经长出王蜕硬壳。
- 主角尚未破壳，没有见过任何活物，也没有被任何生命体攻击过。
- 卵壳、荒兽尸体和一枚贴在尸体肋骨上的王蜕碎片，在第一场事件发生前已经存在。

### Initial Scale Position-only Direction

- 七冠阶：不适用。原因：主角尚未破壳，属于世界已定义的“胚卵列”，不是零冠。
- 胚卵列位置：封壳。
- 形量尺：卵级，长度约六十厘米。
- 王蜕价值列：不适用。原因：主角不是死亡后形成的王蜕，只是与王蜕碎片共处同一尸体。

### Power-only Direction

- 触发：主角当前身体必须被一个有明确意识、明确身体的活体直接造成致命破坏。
- 目标类别：主动完成致死攻击的活体；不包括环境坍塌、疾病、饥饿、误伤或无意识碰撞。
- 能做的动作：
  - 在死亡瞬间破壳。
  - 以致死者的种族和基本身体结构重组成新的完整身体。
  - 从致死者身上继承一项可见的身体特征，例如鳞甲、复眼、骨翼、毒腺或特殊关节。
- 永久边界：
  - 不能复制致死者的功法、境界、记忆、武器、盔甲、血统身份或语言能力。
  - 只能继承一项身体特征，不能同时继承整套能力。
  - 只能模仿真正造成致命伤害的活体，不能选择旁观者或远程操纵者。
  - 每次重组后，必须再次被符合条件的活体杀死，才能获得下一次新形态。
  - 同一种族的身体可以重复出现，但不能因为同一次死亡获得两个形态。

### Story Interface / Opening Promise

猎人把主角误认为稀有王蜕卵，用长枪刺穿黑卵。卵壳碎裂，里面没有幼兽，只有一个与猎人一模一样的少年身体。

照生台记录下这一幕，全城看到“被杀死的卵”变成了杀卵者的种族。

开篇承诺：每个敌人都可能成为主角下一副身体，但强者越不敢杀他，他越必须想办法逼对方亲手完成致死一击。

### Authority-Compilation Trace

1. 黑卵被猎人的长枪贯穿  
   → `Initial Origin-only Direction：主角处于封壳状态` + `Power-only Direction：活体直接造成致命破坏`  
   → 触发已满足  
   → 目标：持枪并主动完成攻击的猎人  
   → 没有把误伤、环境或故事需要当作触发条件。

2. 黑卵破壳  
   → `Power-only Direction：死亡瞬间破壳重组`  
   → 触发已满足  
   → 载体：原本的黑卵  
   → 这是能力明文动作，不需要 Story 临时增加复活机制。

3. 主角重组成猎人所属种族的身体  
   → `Power-only Direction：以致死者的种族和身体结构重组`  
   → 触发已满足  
   → 载体：新生身体  
   → 只复制种族与身体结构，不复制猎人功法、武器或记忆。

4. 主角获得猎人种族的骨甲  
   → `Power-only Direction：继承一项可见身体特征`  
   → 触发已满足  
   → 目标：致死者的身体特征  
   → 这是身体变化，不是力量等级跳升。

5. 战斗影像向全城传播  
   → `World Interface-only Direction：四冠及以上生命体战斗由照生台记录`  
   → 触发已满足  
   → 载体：照生台记录  
   → 只扩大观看和社会后果，不制造重组结果。

### 第一章标志性画面

长枪刺穿黑卵，蛋液顺着枪杆流下。下一刻，碎壳里伸出一只带着猎人面孔的手，抓住枪杆，把枪尖重新送回猎人胸口。

### 主角反复会做的新动作

- 诱导不同种族的强者亲手杀死自己。
- 用刚获得的身体特征适应下一场战斗。
- 以敌人的种族外形潜入、挑衅或参加公开比斗。
- 故意让旁观者误以为自己已经彻底死亡。
- 在“我要变成谁”和“我不能变成谁”之间做出战术选择。

### 第一次不公平兑现

猎人以为自己完成了击杀，主角却在三息内拥有了猎人的种族、骨甲和更适合近战的身体结构，反过来利用猎人的出枪习惯杀死他。

### 20章玩法扩张

- 主角获得飞行、潜行、攀爬、毒腺、甲壳等不同身体特征。
- 公开记录让各方知道“杀他会替他换形”，强者开始避免亲手完成最后一击。
- 主角必须设计让特定种族成为自己的致死者。
- 宗门会争夺他“最后被谁杀死”的资格。
- 他逐渐把公开比斗变成一场关于身体选择权的心理战。

### 100章以上仍能长出的不同故事

- 强者宁愿把主角封印，也不愿杀死他；主角必须突破封锁，寻找真正能击杀自己的对手。
- 某些种族会把“被主角变成自己的样子”视为亵渎，形成跨地域追杀。
- 主角可能获得古老异族的身体，却永远无法继承其完整文明与记忆。
- 最危险的敌人不是最强者，而是能精准控制自己攻击力度、让主角无法触发能力的人。

### 最小可信桥梁

- 猎人误把黑卵当作白月尸体中形成的王蜕。
- 黑卵所在尸体已经被照生台认定为四冠战斗区域。
- 猎人的攻击确实是主动、直接且致命的；第一章不需要预先满足任何额外条件。

### 不可磨平的三点

- 主角的成长钥匙是死亡，但死亡必须由合格的敌人亲手完成。
- 他每变强一次，外形就更像某个敌人，而不是更像自己。
- 公开记录会让所有人知道：杀死他，等于替他选择下一副身体。

## S3｜《我是一口活着的深渊》

### 一句话货架简介

别人进入秘境寻找宝物，他出生就是秘境里的一张嘴——吞掉兵器、怪物和秘境材料，就把它们长成自己的身体。

### World-only Direction

- 天空中的月轮每年会剥落一批“月片”，月片落地后会长成独立秘境。
- 每座秘境都有一个外部入口和一个内部核心，秘境核心中会自然形成高价值对象“月髓”。
- 公开力量主尺为“九铸阶”，同时适用于生命体、兵器、建筑和秘境材料，由一铸至九铸。
- 九铸阶不是修炼进度，而是实体承受、破坏和锻造强度的公开尺度。
- 公开副尺为“体量尺”：尘、掌、犬、人、屋、楼、山、域。
- 秘境、月髓、古代兵器和异种生物，是各方强者长期争夺的对象。

### World Interface-only Direction

- 各城的“天幕铸录”会自动记录六铸及以上物体被破坏、锻成或带出秘境的过程。
- 记录会投影到附近城池，用于公开比较、悬赏和秘境排名。
- 天幕铸录只能记录、保存和传播，不会把材料复制出来，不会增强物体，也不会替任何目标完成吞噬。
- 记录只带来社会后果：争夺、封锁、悬赏、仿制和名声。

### Protagonist Ontology-only Direction

- 主角属于“吞界幼兽”，是一种以进食建立身体结构的空间生命。
- T0 形态没有头、四肢或固定骨骼，只有一张环形口器、一个消化囊和一层柔软外皮。
- 它的内部空间是真实但极小的生理结构，不是完整秘境，也不能容纳无限物体。
- 它可以通过身体收缩移动，但没有天然远程攻击、飞行或瞬移结构。
- 它是生命体，不是秘境核心，也不是月髓。

### Initial Origin-only Direction

- T0 时，主角刚在一块新坠落的月片内部成形。
- 它的环形口器外径约九十厘米，身体蜷缩在一间不足两丈的天然石腔里。
- 石腔内只有月片原有碎石，没有吞入任何生命、兵器或月髓。
- 月片入口已经在外部形成，但主角尚未离开石腔，也尚未吞食任何东西。

### Initial Scale Position-only Direction

- 九铸阶：一铸。原因：外皮和口器只能承受一铸级冲击。
- 体量尺：犬级，外径约九十厘米。
- 秘境级：不适用。原因：主角是生活在秘境中的吞界幼兽，不是拥有独立入口和核心的完整秘境。
- 月髓价值列：不适用。原因：主角尚未吞入或持有月髓。

### Power-only Direction

- 触发：主角必须用口器直接咬住并完整吞下实体目标。
- 目标类别：有形的生命组织、矿物、兵器、建筑材料和秘境结构。
- 不能作为目标的类别：声音、光线、纯意识、抽象规则、未接触的能量和远距离攻击。
- 能做的动作：
  - 吞下不超过自身口器容积的实体。
  - 消化目标后，永久把目标的一项可见物理性质或身体结构长入自己，例如硬度、弹性、耐热、鳞片、骨刃、攀附肢。
  - 现有身体最多同时保留三项外来性质或结构。
- 永久边界：
  - 目标铸阶最多高于自身一铸；超出范围时无法咬穿或消化。
  - 不能获得目标的意识、记忆、功法、境界、使用经验或抽象能力。
  - 吞下的完整物体会被消耗，不能同时保留为可取出的原物。
  - 新性质会替换一个旧性质；替换掉的性质永久消失。
  - 体量不会因为吞下一件小物自动暴涨，只有吞入足够多的实体结构后，身体才会按生理成长。

### Story Interface / Opening Promise

一队秘境猎人发现月片入口，用一柄一铸铁枪撬门。门后突然滚出一张巨大的嘴，咬断铁枪，吞下枪尖，身体表面立刻长出一圈黑铁牙。

开篇承诺：别人从秘境里带走宝物，主角会把宝物变成自己的牙、骨、甲和腿；每一次获得都改变战斗方式与外形。

### Authority-Compilation Trace

1. 月片落地并形成秘境入口  
   → `World-only Direction：月轮剥落月片，月片落地后形成秘境`  
   → 触发已满足  
   → 载体：月片与天然石腔  
   → 这是世界异常，不由主角创造秘境。

2. 主角咬断一铸铁枪  
   → `Initial Scale Position-only Direction：主角为一铸` + `Power-only Direction：可吞食不高于自身一铸的实体`  
   → 触发已满足  
   → 目标：一铸铁枪  
   → 目标体积小于口器容积，能力边界完整成立。

3. 铁枪硬度长入主角身体  
   → `Power-only Direction：消化后永久获得一项可见物理性质`  
   → 触发已满足  
   → 载体：主角口器与外皮  
   → 没有复制兵器招式，只获得可见的材料硬度。

4. 主角用铁牙咬碎入口石壁  
   → `Power-only Direction：新获得的硬度` + `World-only Direction：月片石壁属于实体秘境结构`  
   → 触发已满足  
   → 目标：不高于当前边界的石质结构  
   → 这是身体性质改变后的近距离动作，不是新增远程能力。

5. 天幕铸录公开记录铁枪被吞食  
   → `World Interface-only Direction：六铸以上物体才自动记录`  
   → 触发未满足。  
   → 因此第一章可以不自动直播这一幕；若后续吞食六铸对象，才会合法触发记录。  
   → 这保留了接口边界，没有为了制造开场传播而擅自降低阈值。

### 第一章标志性画面

秘境入口像一扇裂开的石门。一队猎人刚把铁枪伸进去，门后便张开一张没有眼睛的巨口，咬断枪杆，黑色铁牙从嘴边一节节长出来。

### 主角反复会做的新动作

- 吞下不同材料，把硬度、耐热、弹性或锋利结构长进身体。
- 咬穿秘境墙壁，从别人认为封死的路径中爬出。
- 牺牲旧性质，换取适合当前敌人的新身体结构。
- 把怪物的鳞片、骨刃、毒腺等变成身体部件。
- 进入更高铸阶秘境前，先寻找能让自己升阶的低级实体材料。

### 第一次不公平兑现

猎人的铁枪本来是破门工具，却被主角一口吞掉。下一息，猎人用刀劈来，刀刃撞上刚长出的黑铁牙，反而崩断。

### 20章玩法扩张

- 主角形成三种可切换的身体性质组合。
- 同一件宝物既可以保留为战利品，也可以吞掉成为身体，形成明确取舍。
- 他从秘境墙体、怪物肢体和废弃兵器中逐步长出攀附肢、骨刃和耐热外皮。
- 猎人开始把低铸阶材料布置成陷阱，逼他吞下不想要的性质。
- 主角从“会吃东西”变成能主动设计战斗地形的活体兵器。

### 100章以上仍能长出的不同故事

- 主角进入更高铸阶秘境，必须在吞掉月髓、吞掉秘境墙体和保留稀有兵器之间选择。
- 各方势力会争夺他的身体，因为他的外形本身就是稀有材料组合。
- 他可能吞掉某座秘境的一部分，导致自己的身体逐渐拥有“入口、内腔和核心”般的结构，但不能凭空成为完整秘境。
- 最终冲突可以围绕一个问题展开：究竟是把世界上所有珍贵东西吃进身体，还是保留它们，让别人也有资格获得力量。

### 最小可信桥梁

- 猎人误以为月片入口内只有低级石材，因此使用一铸铁枪探路。
- 铁枪体积小于主角口器容积，且铸阶没有超过主角一铸。
- 第一章不强行触发天幕铸录；公开传播从后续真正涉及六铸对象的战斗开始。

### 不可磨平的三点

- 主角的战利品不会躺在储物袋里，而会改变他的身体。
- 变强必然意味着吞掉某件原本珍贵的东西。
- 主角不是进入秘境的冒险者，他本身就是秘境里最想活着出去的怪物。
