## S1｜《披身者》

### 一句话货架简介

他没有自己的身体，只能穿上刚刚失去主人的兽蜕活下去；第一天，他披着半干巨蜕从尸堆里站起，反杀了杀死他“原身”的猎队。

### World-only Direction

世界每逢四十九日出现一次“黑月”，所有有脊生物都会脱下一层外皮。蜕层在三日内仍保留原主最后一个生存动作，越强的生物留下的蜕层越完整，王级蜕层甚至能挡住同阶兵刃。

常规力量以公开的“九脉尺”衡量：

- 无脉类：没有可测脉路，不等同于一阶。
- 一脉至九脉：修士、异族与大多数大型生物的公开力量等级。

蜕层另有“蜕品副尺”：

- 空品：只剩材料价值。
- 薄品：能遮护身体，残留动作微弱。
- 整品：保留完整外形与一种本能动作。
- 王品：能承受高阶力量冲击，属于极稀有战利品。

蜕层可以被采集、交易、争夺和穿戴；它不是力量本身，却决定了许多战斗者能否活过下一场战斗。

### World Interface-only Direction

城镇与关隘的石墙会自动留下境内公开冲突的无声连续影像。日出后，影像会在城门、集市和兵坊外同步显现，也可由抄录者复制传播。

影像只观看、记录和传播，不改变任何人的身体、力量、位置或行动结果。它会产生公开的胜负、通缉、战利品归属和名声后果。

### Protagonist Ontology-only Direction

主角是“无原身生命”：意识可以独立思考，却没有固定的人类身体，必须依附某一层生物外皮才能行动。

他不是人类、亡魂或普通灵体；他的真实存在位于当前外皮之内，外皮破碎后，他会暴露为极弱的无形幼体。

### Initial Origin-only Direction

T0 时，主角在边城旧猎场的尸坑底部诞生。

他的意识从一层尚未冷却的黑鳞蜕层内侧凝成，蜕层属于一头已经死亡的巨兽，当前评级为薄品。他拥有一次呼吸、一次睁眼和短暂的方向感，但没有姓名、记忆、武技或人类身体。

### Initial Scale Position-only Direction

- 九脉主尺：无脉类。原因：主角没有脉路与固定肉身，世界已有“无脉类”公开类别，不能按一阶处理。
- 蜕品副尺：薄品。原因：T0 依附的黑鳞蜕层未完整干燥，只有遮护功能，不能按整品处理。
- 其他尺度：不适用。世界没有为无原身生命另设临时等级。

### Power-only Direction

**触发：**主角的意识必须接触一层刚刚失去主人的生物外皮。目标必须属于有血肉、有外皮的动物、人类或异族；外皮脱离主人不超过三十息，或本来就是三日内的自然蜕层。

**动作：**

- 脱下当前外皮。
- 进入目标外皮并使其恢复可行动状态。
- 获得目标外皮的形态、基础力量、移动方式和一个残留本能动作。
- 在外皮破损前，以该外皮作为自己的身体行动。

**永久边界：**

- 同时只能穿戴一层外皮。
- 不能获得目标的记忆、功法、修为、语言或战斗经验。
- 不能穿戴植物、矿物、器物、无外皮生命或仍有主人意识的身体。
- 外皮的品质决定身体上限，主角自身不能把薄品强行提升为王品。
- 外皮完全破碎后，主角会重新暴露为无脉幼体。
- 不能凭空制造外皮。

### Story Interface / Opening Promise

读者从第一场战斗就能看见：主角被长矛刺穿后，不是倒下，而是从破裂的黑鳞里钻出，扑进刚死去的巨兽蜕层，下一息变成一头与猎队完全不同的怪物。

故事承诺是：主角每赢下一场战斗，就可能换掉自己的身体；但每一副强大身体都带着原主的危险本能、稀缺价值与公开争夺。

### Authority-Compilation Trace

1. 黑月后的黑鳞蜕层存在  
   → `World-only Direction` 的黑月蜕皮规则 + `Initial Origin-only Direction`  
   → 不涉及 Power 触发  
   → 载体是巨兽自然蜕层  
   → 主角从蜕层内侧诞生，合法。

2. 主角能睁眼、呼吸、观察  
   → `Protagonist Ontology-only Direction` + `Initial Origin-only Direction`  
   → 不涉及 Power 触发  
   → 载体是当前薄品蜕层  
   → 无原身生命依附外皮行动，合法。

3. 长矛刺穿黑鳞  
   → 当前蜕层是物理外皮，来源于 `Initial Origin-only Direction`  
   → 不涉及超常触发  
   → 目标是主角当前外皮  
   → 外皮会被普通武器损坏，合法。

4. 主角脱离黑鳞  
   → `Power-only Direction` 的“脱下当前外皮”  
   → 当前外皮已破损，但不要求目标死亡；触发已满足  
   → 载体是主角自己的薄品蜕层  
   → 只能暴露幼体，合法。

5. 主角进入刚死亡巨兽的蜕层  
   → `Power-only Direction`  
   → 巨兽刚失去生命，外皮脱离主人不超过三十息，触发满足  
   → 目标类别为有血肉、有外皮的动物  
   → 获得外形与基础身体动作，不获得记忆和功法，合法。

6. 主角以巨兽形态扑杀猎人  
   → `Power-only Direction` 的基础力量与残留本能动作  
   → 触发已满足  
   → 载体是巨兽整品蜕层  
   → 结果只来自身体形态、力量和一个本能动作，没有临时增加功法，合法。

7. 城墙留下并传播这场战斗  
   → `World Interface-only Direction`  
   → 不触发 Power  
   → 载体是城内公开冲突影像  
   → 只产生观看、记录与社会后果，合法。

### 第一章标志性画面

黑鳞巨蜕被长矛钉在尸堆上，里面却传出一声人的喘息。猎人以为蜕层还活着，刚要补刀，黑鳞从中间裂开，一个没有血肉的人形幼体扑入旁边的巨兽蜕皮。

下一刻，尸堆里站起一头巨兽。

### 主角反复会做的新动作

- 在战斗中主动弃身换体。
- 用小型身体潜入，再换成重型身体突袭。
- 穿上猎物的外皮混入其族群。
- 故意保留某种怪物的本能动作，作为自己的固定杀招。
- 让敌人判断错“眼前的身体是不是主角”。
- 为了抢一层稀有蜕层，反过来围猎比自己强得多的生物。

### 第一次不公平兑现

敌人刚杀死巨兽，以为战利品已经到手；主角却利用三十息窗口穿上巨兽蜕层，直接获得远超自己无脉幼体的力量和跳跃能力。

### 20章玩法扩张

主角开始争夺不同用途的蜕层：

- 轻型蜕层用于潜入和逃生。
- 重型蜕层用于正面战斗。
- 飞行类蜕层用于跨越险地。
- 带毒或带甲蜕层用于克制特定敌人。
- 人类与异族势力开始通过公开影像追查“换身怪物”。

战斗不再只是提升境界，而是判断下一副身体值得不值得冒险抢。

### 100章以上仍能长出的不同故事

长线可以发展为蜕层市场、异族禁忌、王品蜕层战争和“原身是否存在”的身份冲突。主角可以在不同种族之间切换，却始终面对同一个根本问题：身体越强，越容易被看成某个被他夺走的存在。

### 最小可信桥梁

世界本来就存在会保留生物动作的自然蜕层；主角只是一个天然依附外皮的生命。无需额外发明灵魂夺舍、功法复制或隐藏等级。

### 不可磨平的三点

1. 主角没有固定身体，身体更换必须成为战斗本身。
2. 公开影像会让每次换身都产生身份与战利品后果。
3. 强大外皮永远是可争夺、可损坏、不可随意制造的稀缺对象。

## S2｜《伤口里的刺客》

### 一句话货架简介

他住在伤口里，能从敌人刚裂开的伤口钻进钻出；别人越想靠重伤解决他，越是在给他铺下一条反杀的路。

### World-only Direction

世界上的任何强烈破坏都会留下“伤界”：岩石会出现红色裂缝，血肉会出现无法立刻闭合的伤口。伤界内部不是普通空间，而是一段贴着现实存在的狭窄暗层，里面会滋生以伤口和血液为食的异兽。

伤界会在伤口完全愈合、岩缝被重新合拢或边缘被特殊材料钉死后消失。伤界可以被探索、封锁和争夺。

常规战力以“八门尺”衡量：

- 未入尺类：没有稳定的身门。
- 一门至八门：公开力量等级。

伤界另有“裂深副尺”：

- 细痕。
- 窄裂。
- 深缝。
- 天口。

高价值对象是“封痕钉”：可以稳定封住一道伤界，也可以把伤界固定为长期秘境，因此被宗门、军队和探险者争抢。

### World Interface-only Direction

所有伤界边缘都会投射出内部行动的模糊影像。外界可以看见谁进入、谁受伤、谁夺得物品，却看不清内部的完整细节。

影像会自动留下出现时间和进入顺序，并在附近城镇的“伤榜”上公开。它只负责观看、记录、传播和形成探索权、战果、悬赏与名声，不改变伤界的空间、战斗结果或任何人的能力。

### Protagonist Ontology-only Direction

主角是一种“缝生生命”：身体由两片彼此错开的肉膜组成，中间没有完整内脏，只能沿伤口、裂缝和伤界边缘存在。

他没有稳定的人形，也不能在完整的皮肤、石面或金属表面上正常行动。

### Initial Origin-only Direction

T0 时，主角在一座废弃石矿的细裂中诞生。

矿工的铁锤曾经劈开岩层，裂缝内部形成一条尚未闭合的伤界。主角的两片肉膜分别贴在裂缝两侧，身体横跨三寸距离。零点时，他只有对震动的感知，没有语言、记忆或外部移动能力。

### Initial Scale Position-only Direction

- 八门主尺：未入尺类。原因：主角没有可开启的身门，不能按一门处理。
- 裂深副尺：细痕。原因：T0 诞生地是最浅的岩层裂缝，只能容纳一条手指宽的伤界。
- 肉身尺度：不适用。原因：主角没有连续的人形肉身，世界已有缝生生命类别，不临时创造“零级身体”。

### Power-only Direction

**触发：**主角必须接触目标身上的新鲜开放伤口，或接触与该伤口相连的伤界边缘。目标必须是有血液循环的活体，包括人类、兽类和有血异族；植物、矿物、器物、亡体不适用。

**动作：**

- 从目标的一道伤口进入。
- 沿同一目标身上的另一道伤口或相连伤界出现。
- 让目标靠近伤口的一条肢体，在一息内重复主角做出的一个动作。
- 以伤口内部作为短暂藏身处。

**永久边界：**

- 主角不能制造伤口，也不能把完整身体直接切开成入口。
- 目标必须已经受伤，且伤口仍然开放。
- 每次只能锁定一个目标。
- 不能读取目标记忆、夺取修为或长期控制身体。
- 伤口闭合后，主角会被挤出伤界。
- 他不能离开伤口、裂缝或伤界独立行动。

### Story Interface / Opening Promise

第一章就让读者看到：猎人刺伤一头异兽，血沿岩缝流下；岩缝里那个没有完整身体的东西顺着血钻进异兽伤口，从异兽自己的腹侧裂口钻出，借它的前爪完成一次不可能的反击。

故事承诺是：战场上的每一道伤口，都可能变成主角的入口、伏击点和逃生路。

### Authority-Compilation Trace

1. 主角在石矿细裂中诞生  
   → `Initial Origin-only Direction` + `Protagonist Ontology-only Direction`  
   → 不涉及 Power 触发  
   → 载体是已有的岩层伤界  
   → 缝生生命只能沿裂缝存在，合法。

2. 猎人的刀划开异兽前肢  
   → `World-only Direction` 的伤界规则  
   → Power 尚未由主角使用  
   → 目标是有血液循环的活体  
   → 新鲜开放伤口产生，合法。

3. 异兽的血流入主角所在岩缝  
   → `World-only Direction` 的伤界与伤口相连规则  
   → Power 触发条件满足  
   → 载体是异兽伤口与岩缝边缘  
   → 主角能够接触目标伤口，合法。

4. 主角从异兽伤口进入  
   → `Power-only Direction`  
   → 新鲜开放伤口已存在，触发满足  
   → 目标是有血肉的活体异兽  
   → 进入伤口内部，合法。

5. 主角从异兽腹侧旧伤出现  
   → `Power-only Direction`  
   → 同一目标存在第二道开放伤口，触发满足  
   → 载体仍是同一头异兽  
   → 只发生位置转移，没有增加力量，合法。

6. 异兽前爪被迫重复主角的挥击  
   → `Power-only Direction` 的一息肢体复动作  
   → 触发满足  
   → 目标仍是受伤异兽  
   → 结果只持续一息，不等同长期控制，合法。

7. 旁观者从伤界边缘看到模糊影像  
   → `World Interface-only Direction`  
   → 不触发 Power  
   → 载体是伤界投影  
   → 只产生记录与社会后果，合法。

### 第一章标志性画面

血从异兽腿上的刀口滴进岩缝，岩缝里忽然长出一只没有手指的手。猎人回头时，异兽腹部的旧伤裂开，一个半透明的缝生物从里面钻出，抬手，异兽自己的前爪同时砸下。

### 主角反复会做的新动作

- 故意诱导敌人互相制造伤口。
- 把战场伤口当作门、路、陷阱和藏身处。
- 从敌人背后的旧伤钻出。
- 借强者的身体完成一次超出自身力量的攻击。
- 让敌人不敢轻易追杀受伤同伴。
- 在伤界秘境中把多个伤口连成临时伏击网。

### 第一次不公平兑现

一名八门以下的猎人刺伤异兽后，主角立即利用那道伤口跨越距离，并借异兽的前肢打出远超自己身体承受范围的一击。

### 20章玩法扩张

主角会进入更复杂的伤界：

- 战场留下的巨大伤口。
- 被异兽反复撕开的巢穴。
- 宗门封印失败后的裂缝。
- 由封痕钉固定的长期秘境。
- 专门利用伤口布阵的猎杀队。

敌人会改变战术：有人不再攻击主角的同伴，有人用假伤口诱导他进入，有人抢夺封痕钉封死他的退路。

### 100章以上仍能长出的不同故事

伤界可以形成横跨城池的战争通道、异族领地和长期秘境。主角既可能成为最强刺客，也可能被迫守护某道伤界里的族群。世界对他的根本敌意始终成立：治愈者想让世界无伤，强者却不断制造伤口，而主角只能寄生在裂开的现实中成长。

### 最小可信桥梁

伤口与伤界本来就是同一类世界现象的不同规模；主角只是在这种连接上天然生存，并没有额外发明跨空间法术。

### 不可磨平的三点

1. 主角必须住在伤口里，不能获得稳定人形。
2. 敌人的攻击既是危险，也是他的移动与反击条件。
3. 伤口会被治愈、封死，主角永远没有绝对安全的藏身处。

## S3｜《活秘境》

### 一句话货架简介

别人进入秘境寻宝，他本身就是一座会长大的秘境；只要闯入者在里面流血，他就能把对方的影子铸成自己的战斗身体。

### World-only Direction

世界上偶尔会有古老遗迹“孵化”为独立秘境。秘境拥有边界、入口、内部空间、怪物和宝物，但通常没有人格，只按照自身规则运行。

秘境可以通过夺取另一座秘境的“界钥”扩大边界、增加入口或改变内部地形。界钥是唯一能够长期占有秘境的高价值对象，因此会引发宗门、王朝和异族争夺。

所有具备独立领域的存在，都以“界围尺”衡量：

- 无界类：没有稳定领域。
- 一界至九界：稳定领域从小到大的公开主尺。

秘境另有“门数副尺”：

- 一门至九门：稳定入口数量。
- 入口越多，越容易被探索，也越难守住。

### World Interface-only Direction

秘境外壁会在有人进入后变得半透明，外界可以看见内部的大致轮廓、战斗闪影和宝物位置。

秘境会自动记录进入顺序、伤亡结果和界钥归属，并在附近的“秘境榜”上公开。记录只负责观看、传播、排名与争夺权，不会复制内部能力、改变空间或替任何一方战斗。

### Protagonist Ontology-only Direction

主角不是人，而是一座刚刚诞生的微型秘境。

他的意识分布在墙壁、地面和内部空气中；入口相当于他的嘴，边界相当于他的皮肤，内部空间相当于他的身体。他没有独立的人类肉身。

### Initial Origin-only Direction

T0 时，主角在一座塌毁神庙下诞生。

他拥有三丈半径的圆形内部空间、一道狭窄入口、一面盐白色石墙和一条正在沉睡的盲眼蜥蜴。零点时，空间刚刚封闭，主角第一次感到“里面”和“外面”的区别，但尚未接触任何人。

### Initial Scale Position-only Direction

- 界围主尺：一界。原因：稳定边界半径为三丈，属于最小独立秘境，不是无界类。
- 门数副尺：一门。原因：T0 只有神庙下方唯一入口。
- 人体八门尺：不适用。原因：主角不是人类或人形生命，世界对秘境已有界围类别。
- 普通武者肉身等级：不适用。原因：主角没有可测肉身，不能临时按一阶或零级处理。

### Power-only Direction

**触发：**活体闯入者进入主角内部，并在十息内让自己的血液接触秘境地面。目标必须是有血肉的活体；植物、矿物、器物、亡体不适用。

**动作：**

- 把该闯入者的影子从地面剥离。
- 将影子铸成一具临时外身，从入口走出。
- 外身拥有目标当前肉身的力量、速度、外形和一件随身兵器的基本形状。
- 主角可以用外身行动一百息。

**永久边界：**

- 同时只能铸造一具外身。
- 外身不继承目标的记忆、功法、经验、语言或神通。
- 外身不能离入口三十步以上。
- 目标离开秘境或死亡时，外身立即崩解。
- 外身受到的严重损伤会反馈到主角边界。
- 主角不能凭空复制影子，也不能把同一目标重复铸成多具外身。

### Story Interface / Opening Promise

第一批寻宝者进入一座看似只有一间石室的小秘境。领头人割破手掌，在墙上留下记号，地面的影子却被墙壁一寸寸剥下。

下一刻，入口外出现了一个与领头人一模一样、却只听从秘境意识的战斗身体。

故事承诺是：每个闯入者都可能成为秘境主角的一件临时兵器，而每一场入侵都会让这座秘境获得新的生存方式。

### Authority-Compilation Trace

1. 盐白石室、一道入口和盲眼蜥蜴存在  
   → `Initial Origin-only Direction`  
   → 不涉及 Power 触发  
   → 载体是 T0 秘境内部  
   → 主角作为微型秘境诞生，合法。

2. 主角能感知边界、地面和入口  
   → `Protagonist Ontology-only Direction`  
   → 不涉及 Power 触发  
   → 载体是自身空间结构  
   → 秘境意识分布在内部，合法。

3. 活人进入秘境  
   → `World-only Direction` 的秘境入口规则 + `Power-only Direction`  
   → 尚未触发，必须继续满足流血条件  
   → 目标是活体闯入者  
   → 进入本身合法，但不能提前铸造外身。

4. 闯入者割破手掌，血液接触地面  
   → `Power-only Direction`  
   → 十息内流血触地，触发满足  
   → 目标是有血肉的活体  
   → 满足完整触发条件，合法。

5. 目标影子被剥离  
   → `Power-only Direction`  
   → 触发已满足  
   → 载体是目标影子与秘境地面  
   → 只能剥离该目标的一道影子，合法。

6. 入口外出现目标形态的战斗外身  
   → `Power-only Direction`  
   → 触发已满足  
   → 载体是单一影子外身  
   → 获得身体力量、速度和兵器基本形状，不获得功法与记忆，合法。

7. 外身离入口超过三十步后崩解  
   → `Power-only Direction` 的永久边界  
   → 不需要新触发  
   → 载体仍是单一外身  
   → 远程复制与无限分身被排除，合法。

8. 外界看见秘境内部战斗并记录  
   → `World Interface-only Direction`  
   → 不触发 Power  
   → 载体是秘境外壁的投影  
   → 只产生观看、排名和争夺权，合法。

### 第一章标志性画面

寻宝者的血滴在石室中央，整个秘境忽然安静下来。地上的影子像一张被剥下的兽皮，沿着墙根爬向入口；入口外，另一个“人”握着同样的刀走出来。

### 主角反复会做的新动作

- 诱导强者进入秘境，再把强者的影子铸成外身。
- 用不同闯入者的身体应对不同战斗。
- 让敌人亲眼看见自己的同伴变成敌方战力。
- 把秘境内部设计成迫使敌人流血的战场。
- 通过争夺界钥扩张边界和入口。
- 同时经营“寻宝秘境”和“吞人秘境”两种公开名声。

### 第一次不公平兑现

一个远强于主角当前一界边界的寻宝者进入石室并流血，主角立即借用他的身体力量，在入口外用他的兵器反杀同伴。

### 20章玩法扩张

主角从一间石室开始经营自己的生存空间：

- 设置能逼迫闯入者受伤的地形。
- 争夺其他小秘境的界钥。
- 增加入口，但也暴露更多弱点。
- 通过秘境榜吸引强者主动进入。
- 让不同身体对应不同外界战斗任务。

读者看到的成长不是“主角换境界”，而是一座活着的秘境逐步拥有更大边界、更复杂地形和更危险的入口。

### 100章以上仍能长出的不同故事

主角可以卷入秘境占有战争、宗门寻宝体系、异族领地争夺和“秘境是否算生灵”的伦理冲突。

他最终可能成为移动的战争据点、强者争夺的战略资源，或故意伪装成普通秘境等待最强敌人进入。无论规模如何扩大，他都必须面对固定弱点：入口、边界、界钥与闯入者的血。

### 最小可信桥梁

世界本来就存在会孵化、扩张和被争夺的秘境；主角只是第一座拥有完整人格的秘境。影子铸身是其内部空间对闯入者的单一反应，不需要额外添加无限复制或中央控制。

### 不可磨平的三点

1. 主角没有人类身体，本身就是地图、牢笼和战场。
2. 强者进入秘境后，反而可能成为主角的临时身体。
3. 秘境的力量永远受入口、边界、界钥和闯入者血液限制。

## S1｜《借死成王》

### 一句话货架简介

别人杀妖夺宝，他没有自己的身体——谁的尸体落到他手里，谁的肉身就会成为他的下一件兵器。

### World-only Direction

- 天空存在一口永久不闭合的“黑井”，每四十九日会坠下一具天外巨兽尸体。
- 每具黑井尸体内部必定嵌有一件不可复制的高价值遗物，统称“天遗器”；尸体落地后的七日内，胸腔、头骨和腹腔会逐渐变成危险遗境。
- 公开力量主尺为“九门战位”，只测量拥有稳定生命脉动的活体：一门至九门。
- 世界承认一类通用类别“无门类”，用于没有稳定生命脉动、无法占据九门战位的实体；它不是零门，也不是低阶。
- 公开副尺为“形体尺”：微、指、臂、身、屋、山、天，按实体最大稳定外形计量。
- 黑井尸体、天遗器和高门战斗，是各城争夺与强者比较的长期来源。

### World Interface-only Direction

- 各城的“观战碑”会自动记录三十丈内涉及天遗器，或至少有一名六门战位参与的战斗。
- 记录从战斗发生前三十息持续到战斗结束后三十息，并向所在城池公开播放。
- 观战碑只能观看、保存和传播，不能改变攻击结果、放大力量、制造实体或替任何一方触发能力。
- 公开记录会带来悬赏、追杀、名声、宗门争夺与身份误判，但这些都是社会后果。

### Protagonist Ontology-only Direction

- 主角属于“寄壳死生体”，是一种极罕见但世界已知的生命类别。
- 其真正身体不是人形，而是一团有自我意识的黑色骨髓结，内部没有完整器官、骨骼或固定四肢。
- 它可以作为独立实体存在，也可以把尸体当作外部身体。
- 尸体不是主角本身；主角离开后，尸体仍只是普通死物。
- 它没有继承尸体记忆、功法、身份或装备的天然机制。

### Initial Origin-only Direction

- T0 时，主角刚在一具刚从黑井坠落的天外巨兽口腔深处成形。
- 真体是一枚直径约十二厘米的黑色骨髓结，位于巨兽舌根后的裂腔中。
- 它尚未占据任何尸体，尚未见过活人，也没有移动过外部尸壳。
- 巨兽尸体、主角真体和一件嵌入巨兽右胸骨后的天遗器，在第一场事件发生前已经同时存在。

### Initial Scale Position-only Direction

- 九门战位：不适用。原因：主角真体没有稳定生命脉动，世界将其归入通用“无门类”，不是零门。
- 无门类位置：无门类·未着壳。
- 形体尺：指级，真体最大稳定直径约十二厘米。
- 天遗器价值列：不适用。原因：主角不是遗物，也未占有或融合天遗器。

### Power-only Direction

- 触发：主角必须直接接触一具死亡不超过一百息的尸体。
- 目标类别：人、兽、异族及拥有实体结构的活物尸体；不能占据仍活着的目标，也不能占据纯能量、声音或抽象规则。
- 能做的动作：
  - 将真体移入尸体内部。
  - 暂时控制尸体行动，使其像活体一样站立、奔跑、攻击和使用原有身体结构。
  - 在尸体被再次摧毁前主动脱离。
- 永久边界：
  - 不能获得尸体记忆、功法、境界、血脉身份或原有装备的使用知识。
  - 尸体越接近死亡，能维持的时间越短；超过尸体死亡后的自然腐败阶段，控制立即结束。
  - 同一时间只能控制一具尸体。
  - 真体必须位于尸体内部才能施加控制；离开尸体后极其脆弱。
  - 没有一次性 T0 例外；第一章能力能否使用，只取决于新鲜尸体接触是否成立。

### Story Interface / Opening Promise

第一章，黑井尸体刚落地，寻宝队割开巨兽下颚，发现里面只有一团黑髓。有人伸手触碰，黑髓钻入巨兽尸体，整座尸山突然站了起来。

观战碑同步记录这场战斗。城里的人看到的不是一个少年，而是一具天外巨兽尸体正在用陌生意志行走。

开篇承诺：主角每一次死亡都可能意味着获得一具更强的身体，但每一具身体也会暴露一种新的身份和弱点。

### Authority-Compilation Trace

1. 巨兽尸体从黑井坠落  
   → `World-only Direction：黑井每四十九日坠落天外巨兽尸体`  
   → 触发已满足  
   → 目标：天外巨兽尸体  
   → 这是世界异常的直接结果，不依赖主角。

2. 黑髓接触尸体后进入巨兽体内  
   → `Initial Origin-only Direction：主角真体位于巨兽舌根裂腔` + `Power-only Direction：直接接触新鲜尸体后移入`  
   → 触发已满足  
   → 载体：刚死亡不超过一百息的巨兽尸体  
   → 主角没有占据活体，也没有使用未满足的能力。

3. 巨兽尸体站起并攻击寻宝队  
   → `Power-only Direction：控制尸体行动` + `Protagonist Ontology-only Direction：尸体是可被寄居的外部身体`  
   → 触发已满足  
   → 目标：已被占据的巨兽尸体  
   → 只是控制既有肉身结构，没有复制功法或制造力量。

4. 巨兽胸骨中出现天遗器  
   → `World-only Direction：每具黑井尸体内部必定嵌有天遗器`  
   → 触发已满足  
   → 载体：巨兽右胸骨  
   → 遗物是世界异常自带的对象，不是主角临时获得的新设定。

5. 战斗被全城观战碑记录  
   → `World Interface-only Direction：涉及天遗器的战斗自动记录与传播`  
   → 触发已满足  
   → 载体：观战碑的影像记录  
   → 只改变观看范围与社会后果，不改变战斗因果。

### 第一章标志性画面

一具刚坠落的天外巨兽尸体撑破荒城外墙，寻宝者从它嘴里拖出一团黑色骨髓。黑髓钻入尸体，巨兽低头，用已经死去的眼眶重新“看”向所有人。

### 主角反复会做的新动作

- 以不同尸体改变战斗方式。
- 用巨兽尸体撞城门，用异族尸体潜入宗门，用强者尸体反杀原本的胜者。
- 主动寻找刚死不久的敌人，抢夺尸壳而不是战利品。
- 让敌人不敢轻易杀人，因为每一具新鲜尸体都可能变成主角的下一副身体。

### 第一次不公平兑现

寻宝队长以为自己杀死黑髓，主角却借巨兽尸体站起，一掌拍碎队长的护甲。队长最强的攻击，反而替主角取得了第一具真正强大的战斗身体。

### 20章玩法扩张

- 主角连续使用不同种族、不同体型的尸壳。
- 观战记录让“行走巨尸”成为悬赏榜上的公开目标。
- 敌人开始焚尸、封尸、抢夺尸体，尸体本身成为战场资源。
- 主角必须在强大尸壳、隐蔽身份和尸体剩余时间之间取舍。
- 天遗器争夺迫使他与真正的九门强者正面竞争。

### 100章以上仍能长出的不同故事

- 各大势力建立“无尸战场”，试图让战死者无法被利用。
- 主角可能占据旧王、异族皇者或古代巨兽的尸体，却始终无法继承其身份，只能面对身份与自我之间的冲突。
- 某些强者开始故意准备自己的尸体，试图把死亡变成最后一次布局。
- 主角真正的成长不是获得更多功法，而是学会选择什么身体值得成为自己。

### 最小可信桥梁

- 黑井尸体天然保存时间较长，因此第一章能提供一具新鲜且庞大的尸壳。
- 寻宝队知道天遗器存在，却不知道黑髓属于寄壳死生体。
- 观战碑只记录战斗，不替主角解释身份；误判和追杀由人自行产生。

### 不可磨平的三点

- 主角永远没有一具真正属于自己的肉身。
- “被杀”不是失败，而是获得新身体的入口。
- 读者每次看到主角，都会先问：这具身体原来是谁的？

## S2｜《杀我者为形》

### 一句话货架简介

他出生就是一颗不会说话的异卵；谁亲手杀死他，他就会孵化成谁的种族，并用那副身体反杀回去。

### World-only Direction

- 世界上空悬着一轮永不落下的白月。
- 白月照射尸体时，尸体会留下坚硬外壳，称为“王蜕”；王蜕是各宗门争抢的高价值对象，能够作为稀有功法和变异材料的载体。
- 公开力量主尺为“七冠阶”，适用于已经破壳并能独立行动的生命体，一冠至七冠。
- 世界另有通用“胚卵列”：封壳、裂壳、半孵、初行，用于尚未成为完整生命体的蛋、蛹、胎囊等；它不等于零冠。
- 公开副尺为“形量尺”：卵、猫、人、屋、山、天。
- 不同种族的冠阶可以比较，但冠阶不代表功法、武器或社会身份完全相同。

### World Interface-only Direction

- 各城“照生台”会自动记录城内所有涉及四冠及以上生命体的战斗。
- 记录包含攻击者、受击者、死亡时刻和可见身体变化，并向城中公开播放。
- 照生台不复制能力、不制造分身、不放大攻击，也不决定谁能复活或变形。
- 公开记录会造成名声、恐慌、悬赏、宗门争抢和对种族身份的误判。

### Protagonist Ontology-only Direction

- 主角属于一种未被正式命名的“逆孵体”。
- T0 形态是一个完整外壳包裹的卵状生命，内部只有一枚意识核心和未分化的身体组织。
- 它没有固定种族、面孔、四肢、鳞片或毛发。
- 它不是王蜕，也不是普通妖兽卵；王蜕是死后形成的外壳，逆孵体是活着的胚体。
- 它保留连续意识，但身体形态必须在破壳后才确定。

### Initial Origin-only Direction

- T0 时，主角是一颗长约六十厘米的黑色卵，形成于一头四冠荒兽的胸腔内。
- 荒兽已经死亡三日，白月照过尸体，胸腔外侧已经长出王蜕硬壳。
- 主角尚未破壳，没有见过任何活物，也没有被任何生命体攻击过。
- 卵壳、荒兽尸体和一枚贴在尸体肋骨上的王蜕碎片，在第一场事件发生前已经存在。

### Initial Scale Position-only Direction

- 七冠阶：不适用。原因：主角尚未破壳，属于世界已定义的“胚卵列”，不是零冠。
- 胚卵列位置：封壳。
- 形量尺：卵级，长度约六十厘米。
- 王蜕价值列：不适用。原因：主角不是死亡后形成的王蜕，只是与王蜕碎片共处同一尸体。

### Power-only Direction

- 触发：主角当前身体必须被一个有明确意识、明确身体的活体直接造成致命破坏。
- 目标类别：主动完成致死攻击的活体；不包括环境坍塌、疾病、饥饿、误伤或无意识碰撞。
- 能做的动作：
  - 在死亡瞬间破壳。
  - 以致死者的种族和基本身体结构重组成新的完整身体。
  - 从致死者身上继承一项可见的身体特征，例如鳞甲、复眼、骨翼、毒腺或特殊关节。
- 永久边界：
  - 不能复制致死者的功法、境界、记忆、武器、盔甲、血统身份或语言能力。
  - 只能继承一项身体特征，不能同时继承整套能力。
  - 只能模仿真正造成致命伤害的活体，不能选择旁观者或远程操纵者。
  - 每次重组后，必须再次被符合条件的活体杀死，才能获得下一次新形态。
  - 同一种族的身体可以重复出现，但不能因为同一次死亡获得两个形态。

### Story Interface / Opening Promise

猎人把主角误认为稀有王蜕卵，用长枪刺穿黑卵。卵壳碎裂，里面没有幼兽，只有一个与猎人一模一样的少年身体。

照生台记录下这一幕，全城看到“被杀死的卵”变成了杀卵者的种族。

开篇承诺：每个敌人都可能成为主角下一副身体，但强者越不敢杀他，他越必须想办法逼对方亲手完成致死一击。

### Authority-Compilation Trace

1. 黑卵被猎人的长枪贯穿  
   → `Initial Origin-only Direction：主角处于封壳状态` + `Power-only Direction：活体直接造成致命破坏`  
   → 触发已满足  
   → 目标：持枪并主动完成攻击的猎人  
   → 没有把误伤、环境或故事需要当作触发条件。

2. 黑卵破壳  
   → `Power-only Direction：死亡瞬间破壳重组`  
   → 触发已满足  
   → 载体：原本的黑卵  
   → 这是能力明文动作，不需要 Story 临时增加复活机制。

3. 主角重组成猎人所属种族的身体  
   → `Power-only Direction：以致死者的种族和身体结构重组`  
   → 触发已满足  
   → 载体：新生身体  
   → 只复制种族与身体结构，不复制猎人功法、武器或记忆。

4. 主角获得猎人种族的骨甲  
   → `Power-only Direction：继承一项可见身体特征`  
   → 触发已满足  
   → 目标：致死者的身体特征  
   → 这是身体变化，不是力量等级跳升。

5. 战斗影像向全城传播  
   → `World Interface-only Direction：四冠及以上生命体战斗由照生台记录`  
   → 触发已满足  
   → 载体：照生台记录  
   → 只扩大观看和社会后果，不制造重组结果。

### 第一章标志性画面

长枪刺穿黑卵，蛋液顺着枪杆流下。下一刻，碎壳里伸出一只带着猎人面孔的手，抓住枪杆，把枪尖重新送回猎人胸口。

### 主角反复会做的新动作

- 诱导不同种族的强者亲手杀死自己。
- 用刚获得的身体特征适应下一场战斗。
- 以敌人的种族外形潜入、挑衅或参加公开比斗。
- 故意让旁观者误以为自己已经彻底死亡。
- 在“我要变成谁”和“我不能变成谁”之间做出战术选择。

### 第一次不公平兑现

猎人以为自己完成了击杀，主角却在三息内拥有了猎人的种族、骨甲和更适合近战的身体结构，反过来利用猎人的出枪习惯杀死他。

### 20章玩法扩张

- 主角获得飞行、潜行、攀爬、毒腺、甲壳等不同身体特征。
- 公开记录让各方知道“杀他会替他换形”，强者开始避免亲手完成最后一击。
- 主角必须设计让特定种族成为自己的致死者。
- 宗门会争夺他“最后被谁杀死”的资格。
- 他逐渐把公开比斗变成一场关于身体选择权的心理战。

### 100章以上仍能长出的不同故事

- 强者宁愿把主角封印，也不愿杀死他；主角必须突破封锁，寻找真正能击杀自己的对手。
- 某些种族会把“被主角变成自己的样子”视为亵渎，形成跨地域追杀。
- 主角可能获得古老异族的身体，却永远无法继承其完整文明与记忆。
- 最危险的敌人不是最强者，而是能精准控制自己攻击力度、让主角无法触发能力的人。

### 最小可信桥梁

- 猎人误把黑卵当作白月尸体中形成的王蜕。
- 黑卵所在尸体已经被照生台认定为四冠战斗区域。
- 猎人的攻击确实是主动、直接且致命的；第一章不需要预先满足任何额外条件。

### 不可磨平的三点

- 主角的成长钥匙是死亡，但死亡必须由合格的敌人亲手完成。
- 他每变强一次，外形就更像某个敌人，而不是更像自己。
- 公开记录会让所有人知道：杀死他，等于替他选择下一副身体。

## S3｜《我是一口活着的深渊》

### 一句话货架简介

别人进入秘境寻找宝物，他出生就是秘境里的一张嘴——吞掉兵器、怪物和秘境材料，就把它们长成自己的身体。

### World-only Direction

- 天空中的月轮每年会剥落一批“月片”，月片落地后会长成独立秘境。
- 每座秘境都有一个外部入口和一个内部核心，秘境核心中会自然形成高价值对象“月髓”。
- 公开力量主尺为“九铸阶”，同时适用于生命体、兵器、建筑和秘境材料，由一铸至九铸。
- 九铸阶不是修炼进度，而是实体承受、破坏和锻造强度的公开尺度。
- 公开副尺为“体量尺”：尘、掌、犬、人、屋、楼、山、域。
- 秘境、月髓、古代兵器和异种生物，是各方强者长期争夺的对象。

### World Interface-only Direction

- 各城的“天幕铸录”会自动记录六铸及以上物体被破坏、锻成或带出秘境的过程。
- 记录会投影到附近城池，用于公开比较、悬赏和秘境排名。
- 天幕铸录只能记录、保存和传播，不会把材料复制出来，不会增强物体，也不会替任何目标完成吞噬。
- 记录只带来社会后果：争夺、封锁、悬赏、仿制和名声。

### Protagonist Ontology-only Direction

- 主角属于“吞界幼兽”，是一种以进食建立身体结构的空间生命。
- T0 形态没有头、四肢或固定骨骼，只有一张环形口器、一个消化囊和一层柔软外皮。
- 它的内部空间是真实但极小的生理结构，不是完整秘境，也不能容纳无限物体。
- 它可以通过身体收缩移动，但没有天然远程攻击、飞行或瞬移结构。
- 它是生命体，不是秘境核心，也不是月髓。

### Initial Origin-only Direction

- T0 时，主角刚在一块新坠落的月片内部成形。
- 它的环形口器外径约九十厘米，身体蜷缩在一间不足两丈的天然石腔里。
- 石腔内只有月片原有碎石，没有吞入任何生命、兵器或月髓。
- 月片入口已经在外部形成，但主角尚未离开石腔，也尚未吞食任何东西。

### Initial Scale Position-only Direction

- 九铸阶：一铸。原因：外皮和口器只能承受一铸级冲击。
- 体量尺：犬级，外径约九十厘米。
- 秘境级：不适用。原因：主角是生活在秘境中的吞界幼兽，不是拥有独立入口和核心的完整秘境。
- 月髓价值列：不适用。原因：主角尚未吞入或持有月髓。

### Power-only Direction

- 触发：主角必须用口器直接咬住并完整吞下实体目标。
- 目标类别：有形的生命组织、矿物、兵器、建筑材料和秘境结构。
- 不能作为目标的类别：声音、光线、纯意识、抽象规则、未接触的能量和远距离攻击。
- 能做的动作：
  - 吞下不超过自身口器容积的实体。
  - 消化目标后，永久把目标的一项可见物理性质或身体结构长入自己，例如硬度、弹性、耐热、鳞片、骨刃、攀附肢。
  - 现有身体最多同时保留三项外来性质或结构。
- 永久边界：
  - 目标铸阶最多高于自身一铸；超出范围时无法咬穿或消化。
  - 不能获得目标的意识、记忆、功法、境界、使用经验或抽象能力。
  - 吞下的完整物体会被消耗，不能同时保留为可取出的原物。
  - 新性质会替换一个旧性质；替换掉的性质永久消失。
  - 体量不会因为吞下一件小物自动暴涨，只有吞入足够多的实体结构后，身体才会按生理成长。

### Story Interface / Opening Promise

一队秘境猎人发现月片入口，用一柄一铸铁枪撬门。门后突然滚出一张巨大的嘴，咬断铁枪，吞下枪尖，身体表面立刻长出一圈黑铁牙。

开篇承诺：别人从秘境里带走宝物，主角会把宝物变成自己的牙、骨、甲和腿；每一次获得都改变战斗方式与外形。

### Authority-Compilation Trace

1. 月片落地并形成秘境入口  
   → `World-only Direction：月轮剥落月片，月片落地后形成秘境`  
   → 触发已满足  
   → 载体：月片与天然石腔  
   → 这是世界异常，不由主角创造秘境。

2. 主角咬断一铸铁枪  
   → `Initial Scale Position-only Direction：主角为一铸` + `Power-only Direction：可吞食不高于自身一铸的实体`  
   → 触发已满足  
   → 目标：一铸铁枪  
   → 目标体积小于口器容积，能力边界完整成立。

3. 铁枪硬度长入主角身体  
   → `Power-only Direction：消化后永久获得一项可见物理性质`  
   → 触发已满足  
   → 载体：主角口器与外皮  
   → 没有复制兵器招式，只获得可见的材料硬度。

4. 主角用铁牙咬碎入口石壁  
   → `Power-only Direction：新获得的硬度` + `World-only Direction：月片石壁属于实体秘境结构`  
   → 触发已满足  
   → 目标：不高于当前边界的石质结构  
   → 这是身体性质改变后的近距离动作，不是新增远程能力。

5. 天幕铸录公开记录铁枪被吞食  
   → `World Interface-only Direction：六铸以上物体才自动记录`  
   → 触发未满足。  
   → 因此第一章可以不自动直播这一幕；若后续吞食六铸对象，才会合法触发记录。  
   → 这保留了接口边界，没有为了制造开场传播而擅自降低阈值。

### 第一章标志性画面

秘境入口像一扇裂开的石门。一队猎人刚把铁枪伸进去，门后便张开一张没有眼睛的巨口，咬断枪杆，黑色铁牙从嘴边一节节长出来。

### 主角反复会做的新动作

- 吞下不同材料，把硬度、耐热、弹性或锋利结构长进身体。
- 咬穿秘境墙壁，从别人认为封死的路径中爬出。
- 牺牲旧性质，换取适合当前敌人的新身体结构。
- 把怪物的鳞片、骨刃、毒腺等变成身体部件。
- 进入更高铸阶秘境前，先寻找能让自己升阶的低级实体材料。

### 第一次不公平兑现

猎人的铁枪本来是破门工具，却被主角一口吞掉。下一息，猎人用刀劈来，刀刃撞上刚长出的黑铁牙，反而崩断。

### 20章玩法扩张

- 主角形成三种可切换的身体性质组合。
- 同一件宝物既可以保留为战利品，也可以吞掉成为身体，形成明确取舍。
- 他从秘境墙体、怪物肢体和废弃兵器中逐步长出攀附肢、骨刃和耐热外皮。
- 猎人开始把低铸阶材料布置成陷阱，逼他吞下不想要的性质。
- 主角从“会吃东西”变成能主动设计战斗地形的活体兵器。

### 100章以上仍能长出的不同故事

- 主角进入更高铸阶秘境，必须在吞掉月髓、吞掉秘境墙体和保留稀有兵器之间选择。
- 各方势力会争夺他的身体，因为他的外形本身就是稀有材料组合。
- 他可能吞掉某座秘境的一部分，导致自己的身体逐渐拥有“入口、内腔和核心”般的结构，但不能凭空成为完整秘境。
- 最终冲突可以围绕一个问题展开：究竟是把世界上所有珍贵东西吃进身体，还是保留它们，让别人也有资格获得力量。

### 最小可信桥梁

- 猎人误以为月片入口内只有低级石材，因此使用一铸铁枪探路。
- 铁枪体积小于主角口器容积，且铸阶没有超过主角一铸。
- 第一章不强行触发天幕铸录；公开传播从后续真正涉及六铸对象的战斗开始。

### 不可磨平的三点

- 主角的战利品不会躺在储物袋里，而会改变他的身体。
- 变强必然意味着吞掉某件原本珍贵的东西。
- 主角不是进入秘境的冒险者，他本身就是秘境里最想活着出去的怪物。
