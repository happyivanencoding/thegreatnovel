## 候选1： 《战利品构筑师》

一句话创意：被猎团栽赃、即将卖进死猎场的低阶猎手，能把自己亲手完成的破局凝成可重复装配的“胜因模块”，必须在百日内打出足以夺回父亲猎场的战绩。

最直接的读者满足：用破烂武器拆穿强者的招牌构筑，把敌人的必杀方式变成自己的新底牌，战斗结束就能看到具体成长。

主角核心优势：他能从亲自击败的敌人、怪物和遗物中提取“胜因”，例如反冲、借势、诱导、蓄爆，再将不同胜因组合成新的战技构筑。

为什么这是优势：别人只能获得固定装备或学习完整技能，他能提炼“为什么这一招有效”，并把低阶模块组合成高阶效果；模块必须源于他亲自完成的破局，无法靠旁观、购买或简单抢夺复制。

第一次收益：前三章，他用一件断弩和地形反杀石甲兽，提取“反震”模块，立刻获得第一笔赏金，并发现自己可以把战斗结果转化为长期资产。

核心爽点循环：接下危险猎单 → 用弱装备设计破局 → 击败目标并提取胜因 → 组合出新构筑 → 获得更高赏金、战利品和挑战资格 → 对抗更复杂的强敌。

开局1—3章：宏观揭示裂界时代的力量由“可验证的胜因构筑”决定，猎团垄断高阶构筑；镜头落到被栽赃的主角身上，他被当作诱饵送入废弃猎场，首次完成破局并获得能力。

第一次收益：获得“反震”模块和一笔足以延缓死猎场处置的赏金。

前五章闭环：完成一次低阶悬赏，提取两个模块，组合成反击构筑，击败追杀他的原猎团成员，拿到能继续参赛的身份凭证。

前10章：第一个完整小闭环是“击败目标—提取胜因—组合构筑—完成更高难度猎单—获得新模块和资源”。

第一个公开证明：约在第十五至二十章，他用三件低阶模块击破成名猎手的“无伤构筑”，让观众第一次确认他不是偶然捡到能力，而是在创造新的战斗流派。

100章扩张方向：从个人构筑扩大到自建猎队、培养兼容模块的战斗体系，再进入能够改变区域技能规则的古代猎场；主角最终争夺的不是单件神装，而是“谁有资格定义下一代战斗构筑”。

关键关系：曾经栽赃他的前队长，最初把他当成可回收的战利品来源；随着主角不断拆解自己的招牌能力，两人从追捕与反杀变成互相研究构筑的宿敌，最终可能成为必须共同面对旧猎团的竞争合作者。

最大的重复风险：每场战斗都变成“打怪、掉模块、换构筑”，导致敌人只是新词缀的展示架。

与其它候选的真正差异：本候选的成长对象是“胜因和战斗构筑”，资源来自主角亲自完成的战斗破局，验证方式是实战反杀；候选2成长的是空间路线，候选3成长的是活体生态，三者的资源生成与能力复利机制不同。

与《城市断点/断点值守》的本质区别：核心发动机是个人猎杀、战斗构筑和战利品复利，不依赖市政设施、调度流程、审批权限或跨部门协作。

## 候选2： 《我把两个世界缝在一起》

一句话创意：在界门公会垄断通行权的时代，一个寻找失踪妹妹的低阶门徒，能够把亲自走过的两个入口缝成不受公会控制的私门。

最直接的读者满足：别人花钱、交命、求公会才能进入的世界，主角可以独自打开；每发现一条新路线，就等于获得新的资源、财富和行动自由。

主角核心优势：他能将两个亲自穿越过的门槛缝合成稳定通路，并保存每条路线独有的环境条件，例如重力、温度、时间流速和资源分布。

为什么这是优势：普通探险者只能绘制地图或使用公会固定门，主角的身体因一次门崩成为“未归属坐标”，能够绑定尚未被任何势力登记的入口，并重新组合路线。

第一次收益：前三章，他从一扇即将关闭的无主界门带回能治疗母亲的昼火果，同时留下第一枚私人路线锚点。

核心爽点循环：发现无主界门 → 独自闯过并绑定路线 → 带回稀有资源或救出关键人物 → 将新门缝到安全地点 → 获得财富与装备 → 进入更危险、更高价值的世界。

开局1—3章：宏观揭示“门潮”正在让旧世界与陌生疆域重新接壤，固定界门公会因此垄断财富与身份；主角只是负责背尸的门徒，却被迫进入一扇无人记录的门，门崩之后获得缝界能力。

第一次收益：带回救命药材，并拥有一条任何公会都不知道的私门。

前五章闭环：主角借私门进入禁区取药，再从另一端绕过公会封锁回到原地，救下母亲，同时用剩余药材偿还一部分债务，确认路线可以重复利用。

前10章：第一个完整小闭环是“发现无主门—绑定路线—取得资源—缝回安全区—出售或使用资源—用收益寻找下一扇门”。

第一个公开证明：约在第十八至二十五章，一支公会探险队被困在崩塌界域，主角当众缝出一条不存在于任何地图上的逃生路线，第一次让所有势力意识到他掌握的是新的通行权。

100章扩张方向：从一条私门发展为多界路线链，再发展为移动探险队、跨界商路和独立前线据点；后期路线本身会发生迁徙和变异，主角必须探索没有固定入口的“无门世界”。

关键关系：界门公会的继承人最初负责夺取他的路线锚点，把他视为必须控制的危险资源；随着主角开辟的世界越来越多，两人从捕猎者与逃亡者变成路线理念相反的竞争者，最终共同面对公会试图封死所有新世界的行动。

最大的重复风险：每次冒险都变成“开门、取宝、回城”，世界差异沦为地图皮肤。

与其它候选的真正差异：本候选的基本资源是“访问权和空间连接”，成长依赖路线组合、世界探索与通行垄断；候选1靠战斗胜因复利，候选3靠生物进化复利，本候选不要求主角把敌人能力拆成模块，也不依赖养成固定伙伴。

与《城市断点/断点值守》的本质区别：核心是个人探索、私有世界入口和跨界冒险，不是公共系统的故障发现、调度、审批、维护或权限晋升。

## 候选3： 《我给怪物装上第二条进化路》

一句话创意：被兽潮商会夺走牧场、弟弟又被卖作活饵的废弃育兽师，能够看见怪物未完成的进化分支，把不同生物的生态特征 graft 成全新的战斗生命。

最直接的读者满足：被判定为废物的怪兽突然完成不可预测的进化，靠独一无二的生态组合击败血统优越者，主角还能直接借用伙伴的战斗本能参战。

主角核心优势：他能识别生物隐藏的进化分叉，把被击败异兽的生态特征移植给活体伙伴，并让不同特征形成条件进化；完成进化后，他可以短暂接入伙伴的战斗感官和动作本能。

为什么这是优势：普通驯兽师只能喂养、强化或契约单一血统，错误移植会让异兽死亡或失控；主角能判断个体差异，保留互斥特征，并把一次战斗适应变成可继续发展的进化路线。

第一次收益：前三章，他救活一只被当作废兽处理的铁角幼兽，将岩蛛的贴壁能力与其冲撞能力组合，使它反杀收购商的猎犬，得到第一笔赎弟弟的赏金。

核心爽点循环：进入荒野猎取异兽 → 提取生态特征 → 为伙伴设计进化分支 → 伙伴完成变异并赢得战斗 → 获得新特征、稀有兽卵或领地 → 组成更复杂的生态战队。

开局1—3章：宏观揭示兽潮时代的力量来自占据生态位，强大血统垄断了进化路径；镜头落到被商会除名的主角身上，他用一只濒死废兽完成第一次条件进化。

第一次收益：废兽赢得战斗，主角获得赏金、异兽核心和继续追查弟弟下落的资格。

前五章闭环：主角猎取第二种异兽，给铁角兽补上远程能力，完成一次双兽协同狩猎，得到足够支付赎金的第一笔资源，并发现弟弟被送往更深的兽潮禁区。

前10章：第一个完整小闭环是“猎取特征—设计进化—完成狩猎—获得新特征—形成两只异兽的协同生态”。

第一个公开证明：约在第十五章的血统兽斗场上，他让被判废的铁角兽击败商会的纯血战兽；观众第一次看见，所谓低等血统也能拥有全新的进化方向。

100章扩张方向：从改造一只废兽，扩大到培养互补兽群、进入古代生态区、建立移动兽域，最终能够设计新的生态位，让消失的远古物种重新出现；主角自身也从借用单一兽能，发展到短暂承载多条生态链。

关键关系：兽潮商会的首席育兽师最初认为主角只是破坏血统秩序的异端，并负责追捕他的异兽；随着主角不断创造新物种，两人从师徒式的技术争执变成进化理念上的宿敌，后来必须共同面对失控的远古兽潮。

最大的重复风险：每个篇章都变成“寻找新特征、移植、进化、打败更强异兽”，伙伴容易被写成可以替换的技能槽。

与其它候选的真正差异：本候选的成长对象是活体伙伴及其生态链，优势来自个体差异、变异组合和长期协同；候选1把战斗逻辑拆成主角自己的模块，候选2把入口和路线变成主角的行动网络，本候选则让成长同时改变伙伴、战斗方式和世界生态。

与《城市断点/断点值守》的本质区别：核心发动机是荒野狩猎、异兽进化、伙伴关系和生态扩张，不依赖公共安全工程、设施运维、调度平台、审批合同或制度流程。
