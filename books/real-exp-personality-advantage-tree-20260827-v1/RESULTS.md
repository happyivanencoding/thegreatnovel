# RESULTS｜Personality → Advantage Tree

Date: 2026-08-27

## Protocol

- One fresh protagonist-blind World.
- One shared blind-selected Core Power Asymmetry: `穿隙`.
- Human Seed generated 4 candidates in one production Luna-high call; all four kept, no cherry-pick.
- Same Human GBrain bundle for all candidates.
- Same Story GBrain bundle for all four Story Programs; retrieval was frozen before Human entered Story Program.
- Four fresh GPT-5.6 Sol high Story Programs. Only Human/Character authority differs.
- No Outline or chapter generation.
- `~100 / ~200` are read-only longitudinal projections over natural Story Program stages, not exact Canon chapter numbers.

## Shared World / Core

World: 刻修以亲自接触并承受过的“真质”形成刻纹；公开主尺为引纹 / 定纹 / 展纹 / 镇纹 / 改质。高价值对象包括母碑、三叠刻器、剥纹术、错质身、百炉会、倒悬矿塔、无字墓原、换壳场等。

Shared Core Power `穿隙`：真正理解一个障碍如何承受力量后，持有者可以沿可行结构让自己的身体穿过去；这是低阶提前获得的“到达权”，不等于正面战力。

## Four Humans

1. 贺沉舟：钱 / 远行 / 被当成不可替换的人 / 家庭牵引。
2. 魏行简：身体与生活欲望 / 公开被看见 / 具体弱者与家庭 / 强者空间。
3. 林照野：审美与稀有物欲 / 专业承认 / 独立于家族信用 / 不愿把人当耗材。
4. 谢闻川：求知与求证 / 教会别人获得选择 / 自由时间 / 不愿被组织长期占用。

## What clearly passed

### Personality → Choice: PASS

四个人在首次获得异常到达权后，对“退出 / 获利 / 证明自己 / 救人 / 查清 / 追稀有物”的排序明显不同。

### Choice → Route → Opportunity: PASS

- 贺沉舟：个人潜入 → 谈价 → 商路/入口占有。
- 魏行简：公开证明 → 救援 → 内部开路 → 长期盟约。
- 林照野：材料/器物 → 性质转移 → 审美占有。
- 谢闻川：求证 → 协作制作 → 现场控场。

### Growth Floor: PASS

四线都持续升级、持续拿高价值物、至少获得一个后续新 Asymmetry，并与开局 `穿隙` 发生真实复合；没有任何一线因为人格偏离最优升级路线就失去男频成长。

## What only partially passed

### Opportunity → Different Advantage Tree: PARTIAL

最大问题：**四个人全部获得了某种 `剥纹`。**

共同骨架过强：

`静态穿越 → 携带兵器 → 剥纹 → 三叠器物 → 动态封锁反制 → 高阶动态穿越`

因此最终不是四棵独立优势树，而更像：

- 贺沉舟 / 魏行简：`Core + 剥纹 + 三叠短刀`，用途一个偏个人潜入/谈价，一个偏救援/团队开路；
- 林照野 / 谢闻川：`Core + 剥纹 + 性质暂存/返附载体`，一个偏个人器物与性质转移，一个偏协作控场。

即：**两种机械分支 × 四种人格化使用方式**，还不是四种稳定不同的长期 Asymmetry Tree。

## Root cause hypothesis

不是 Human 没有影响 Story Program；Human 已经明显改变选择和路线。

更早的收敛点在 Story Program 的长期成长决策：同一个 World 中，`剥纹` 是与 `穿隙` 最显眼、最容易形成复合的高价值机制，因此 Sol 即使面对不同 Human，也反复选择它作为第一项新 Asymmetry。

如果下一轮要改，应该验证：

> **新 Asymmetry 必须先从当前 Human 实际选择后进入的 route-specific opportunity 中产生，而不是 Story Program 先从整个 World 里挑一项最适合 Core Power 复合的全局最佳答案。**

这不是要求“不同性格必须发不同外挂”，也不是加人格→能力映射表；而是要求 `Choice → Route` 先真实限制后续可获得机会，再由机会产生新 Asymmetry。

## Verdict

- Personality → Choice: **PASS**
- Choice → Route → Opportunity: **PASS**
- Opportunity → Different Advantage Tree: **PARTIAL**
- Growth Floor across personalities: **PASS**

Overall: **PARTIAL**.

当前 production 已经做到“人格改变为什么去、跟谁走、错过什么、把能力用给谁”；尚未证明人格能够稳定地产生真正不同的第二/第三非对称优势树。
