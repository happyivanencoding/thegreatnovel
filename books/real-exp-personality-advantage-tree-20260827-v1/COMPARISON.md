## 一、最早在哪里真正分叉

真正的分叉不是“第一次穿墙”，因为四人都必须兑现共享 Core；而是第一次异常成功后，面对“现在可以退出、获利、交差”时怎样处理这份到达权：

- 贺沉舟把它换成证据、谈价资格和远行车位，而且会为了证明自己不可替换而追加风险。
- 魏行简先把它用于救具体弱者，同时坚持报酬和独立身份，不接受“救人就该无偿牺牲”。
- 林照野把它用于追实物、货物归属和专业事实，还会为审美价值承担不经济的代价。
- 谢闻川把它用于保留证据、查明机制和拒绝组织买断，并开始承担“查清之后”的关系后果。

但这不是完全纯净的同场景A/B：四人的开局事故也由 Sol 分别生成。因此能确认的是“选择符合各自 Human”，不能确认“若四人面对完全相同的封仓事件，仍会如此分叉”。

## 二、Human 支持的选择链

### 贺沉舟

- 计算损失、在意体面与有用性  
  → 二次入仓取货单  
  → 获得白曜车位、进入百炉和矿塔  
  → 得到剥纹，却暴露能力出口。

- 钱能打动他，但具体恩情和人命会改写交易边界  
  → 接受萧伏墓原高价合同，又救姚章、保留样本  
  → 失去白曜渠道  
  → 因掌握样本和封门能力进入东井争夺，换得商路和三叠刀。

- 重关系债胜过最高报价  
  → 七城放弃全取军功、矿塔拒绝萧伏天价  
  → 错过军府核心身份与巨额现金  
  → 得到沈洗砚合作、矿塔入口和高纯质片。

这是“个人潜入—谈价—入口占有”的路线。

### 魏行简

- 抗拒长兄和军籍替自己定义价值  
  → 拒绝军厨、拒绝商盟独占、参加公开斗战  
  → 成为“穿炉者”  
  → 进入墓原并主动用到达权交换剥纹。

- 优先保护眼前弱者  
  → 水井先救母亲、妹妹和砾民孩子，而非追主谋  
  → 错失完整阴谋证据、与兄长决裂  
  → 获得阿洛迦客印，进入矿塔与换壳场路线。

- 不做无偿英雄，又需要能共同生活的现实利益  
  → 换壳场先谈三年份额再参战  
  → 放弃一次性抢样本  
  → 获得正式客商身份、长期材料权和与孟小满共同经营的基础。

这是“救援—内部开路—长期盟约”的路线。

### 林照野

- 审美欲、实物判断和专业承认  
  → 押货去百炉、追查调货、买下漂亮但普通的旧刀  
  → 进入矿塔鉴货与旧壳争夺  
  → 得到剥纹，并因拒绝取出承重母碑而失去先手。

- 不愿把具体人当耗材，又拒绝用秘密换最快利益  
  → 不拿矿塔拓图换家族信用、先救队员  
  → 林家信用继续被冻结  
  → 进入旧驿、墓原取证路线，得到留质片。

- 真心想占有稀有器物，但仍受关系改变  
  → 换壳场放弃记录核心首占、回头救阿洛迦  
  → 失去直接占有权  
  → 通过公开战绩和契约得到“白罅”。

这是“材料鉴别—性质转移—审美占有”的路线。

### 谢闻川

- 求证欲与对组织占用的抗拒  
  → 留下水样、不接受封口、离开河谷验质  
  → 进入百炉、矿塔、墓原的调查链  
  → 获得剥纹，却持续失去稳定组织庇护。

- 重视教会别人选择与署名权  
  → 为许小满作品正名，放弃补赛；拒绝替她安排去留  
  → 获得三叠胚器和持续合作  
  → 许小满、砾民材料与剥纹残质共同形成返纹尺。

- 不愿用最短暴力方案解决事实问题  
  → 拒绝刺杀城主、毁掉母碑继承证据封水  
  → 失去军功与沈洗砚最干净的继承胜局  
  → 得到公开撤离路线、石脊证据和最终客席身份。

这是“求证—协作制作—现场控场”的路线。

## 三、优势树到底分没分

结论是：**用途明显分叉，能力结构只分成两簇，没有形成四棵树。**

共同骨架极强：

> 静态穿越 → 携带兵器 → 出口即战 → 全员获得剥纹 → 三叠器物 → 动态/活体反制 → 连续变化中的高阶穿越

具体来看：

- 贺沉舟与魏行简属于第一簇：都是`Core＋剥纹＋三叠短刀`。  
  差异在用途：贺沉舟偏个人潜入、取证、谈价和高价值入口；魏行简偏拆内部节点、救援和为队伍开通道。战术身份不同，但能力节点基本相同。

- 林照野与谢闻川属于第二簇：都增加了“把剥下的性质暂存并重新附着”。  
  林照野用无铭留质片进行个人性质转移；谢闻川用返纹尺为同伴、盾牌、门和撤离桥返纹。协作方式不同，但底层仍是同族机制。

所以它不是单纯给同一把刀换四个名字；路线和战术用途确实不同。但若严格要求 `Different Advantage Tree`，目前更像：

> 两个机械分支 × 四种人物化使用方式

而不是四条由人格自然生长出的独立能力树。

## 四、哪些只能算 Sol 创意

可以归因给 Human 的，只能是有完整链条的：

> 性格/生活牵引 → 具体选择 → 进入或放弃某条路线 → 获得/错失机会 → 改变优势的用途

不能归因给 Human 的包括：

- 百炉会、矿塔、墓原、东井、七城、换壳季本身；它们来自 Shared World。
- 沈洗砚、萧伏、阿洛迦、顾临川原本的目标；它们也早于主角存在。
- 四人都获得剥纹、都走三叠器物、都面对动态刻纹反制的共模结构。
- 剥纹出现在哪一处遗迹、留质片与返纹尺的具体参数、器物名称、线级NPC与古代结构重释。
- 林照野得到留质片、谢闻川得到返纹尺，最多只能说与其路线和关系适配；当前没有证据证明这些能力是由 Human 必然生成的。

只有一轮样本、没有同一 Human 的重复生成，因此任何“林照野人格必然产生留质能力”之类的结论都超过了证据。

## 五、Growth Floor

四条线都通过：

- 贺沉舟：引纹→定纹→展纹→镇纹；剥纹、三叠刀、商路、高纯质片、矿塔入口持续兑现。
- 魏行简：引纹→定纹→展纹→镇纹；剥纹、“折隙”、母碑抄录、七城议价权、三年份额持续兑现。
- 林照野：引纹→定纹→展纹；剥纹、留质片、独立通行权、“白罅”持续兑现，并明确形成复合。正式镇纹标签未明确，但不影响本轮 Growth Floor 通过。
- 谢闻川：引纹→定纹→展纹→镇纹；剥纹、返纹尺、公开路线和跨势力身份持续兑现。

四人都满足“持续变强、持续高价值获得、至少一个新 Asymmetry 与旧 Core 复合”。没有任何一条停留在“只会更方便地穿墙”。

## 六、Verdict

**PARTIAL**

分项判断：

- `Personality → Choice`：**PASS**
- `Choice → Route → Opportunity`：**PASS**
- `Opportunity → Different Advantage Tree`：**PARTIAL**
- 四线 Growth Floor：**PASS**

残余风险：

1. 开局事故和事件排序也由 Sol 同时生成，最早分叉仍混有采样创意，不能视作纯净同场景因果实验。
2. 四线都会拒绝最高价/最快军功/组织控制，最终都成为跨势力独立议价者，存在“反控制、救具体人、第三方案”的共同道德最优先验。
3. 全员剥纹、全员三叠器、全员动态封锁升级，会让正文压缩后退化成同一套“穿入—剥性质—出刀—升阶”。
4. 林照野与谢闻川的第二能力在功能上高度近亲，仍可能被读者视为留质载体换皮。
5. 林照野只有六阶段，约200章后的基础境界和新能力继续增长均未明确。

因此，current production 已经证明了人物能改变“为什么去、与谁争、放弃什么、把能力用于谁”；尚未证明人物能稳定生成真正不同的长期优势树。
