# POWER SEED

## 一句话大白话

别人只能绕过墙、门和封锁，你只要真正看懂障碍怎么承受力量，就能带着自己的身体穿过它。

## World Power Normal → Power Asymmetry

绝大多数刻修只能把真质附着在身体、兵器或墙面上，用锋利、坚硬、灼热等性质破坏障碍。引纹阶最多劈开铁锁，定纹阶可以摧毁普通门墙，展纹阶则能靠铺开真质强行突破一段街道或院落。

这个能力的超标之处不在于破坏力，而在于它绕过了“必须摧毁障碍”这一正常规则。

持有者只要理解障碍的结构、受力方式和内部空隙，就能让身体沿着那条可通行的路径穿过去。坚硬的墙、封闭的牢门、坍塌的石层、复杂的防御刻纹，都可能被直接穿过。别人需要展纹阶甚至镇纹阶才能突破的位置，他在低阶时就能抵达。

最容易被看懂的 World ruler 是“到达权限”：同层普通人只能从障碍外部接近目标，而他能直接进入正常境界不允许进入的位置。

## Core Fantasy

封锁、牢笼、悬崖、厚墙和敌方防线，都不再天然意味着“到不了”。

## 为什么读者会馋

如果明天醒来得到它，最想立刻做的事不是研究理论，而是：

- 穿进别人打不开的宝库；
- 从必死的牢房里直接走出去；
- 越过城墙或战阵，出现在敌人最意想不到的位置；
- 在矿洞、遗迹或地下城里抵达别人只能远望的地方；
- 被强者追杀时，钻进任何对方无法及时追入的障碍。

它带来的不是“移动更方便”，而是直接拥有了别人没有的到达权。很多资源、秘密和安全位置，会因为这项能力变成持有者可以先拿、先看、先占据的东西。

## Growth Compatibility

### 正常修炼轴

正常修炼仍然增强身体承载真质的能力、刻纹强度、战斗耐久和复合性质。纹阶越高，穿过障碍时能携带的兵器、护甲和资源越多，也越能在穿越后立刻战斗。

### 异常掌握轴

异常掌握从“看懂一面墙的空隙”逐渐发展到理解多层障碍、动态结构和互相叠加的刻纹。掌握越深，越能判断哪些障碍可以穿过、哪些位置会在穿越时崩塌，也越能把穿越动作和出刀、落纹、躲避结合起来。

### High-Tier Mutation

高阶后，能力的质变不是单纯穿得更厚，而是能在连续变化的复杂障碍中保持一条短暂可行的路径：穿过层层防御、正在崩塌的战场或多重性质交叠的区域，并在抵达的一刻保留完整战斗状态。

### 永久边界

无法理解的障碍不能穿过。障碍若持续变化、内部结构被真质扰乱，或者由活体与主动变化的刻纹组成，理解就可能失效。

能力不能替代正常战斗力：穿进敌人身边，不代表能打赢敌人；穿过障碍时也不能把不了解的东西当作安全通道。

## Legendary Power State

厚重城墙、封闭遗迹和镇纹阶布下的战场封锁，在他眼中都只是需要读懂的路径。别人用数日攻打的防线，他可以从最不可能的位置穿入；别人只能远望的禁地，他能够带着兵器和战斗状态直接抵达。

## Power Audit Metadata（非 Canon）

### Future Legend Image

一个人从被认为绝不可能突破的封锁内部走出，身后墙体、阵地与层层防御仍然完整，旁观者直到他出手前都不知道他已经抵达。

# HUMAN SEED｜魏行简／军户次子

## 世界中的初始位置与生活事实

魏行简出生在赤砥王朝北部一座边城，父亲是守城军户，母亲经营军属之间的小型食摊。他是家中次子，长兄早早进入军府，家里一直默认他将来负责照料母亲和两个年幼的妹妹。

他从小在城墙、军械库和军属居住区之间长大，见过受伤的守军、送不回来的尸体，也见过军籍带来的住房和配给。十五岁时参加试刻，承受性质的时间不长，留下几个月的失眠，此后被家里劝回，不再继续尝试。

他曾在冬天替母亲守食摊，因为不肯给一名军官赊账，摊位被砸坏，后来那名军官又因战事调离，事情没有得到正式处理。

长兄一次巡城时受伤，回家休养半年。兄弟两人第一次共同经营食摊，也第一次发现彼此对“应该怎样活”有完全不同的看法。

他曾偷偷拿自己的积蓄请一名退伍老兵吃了一顿热饭。事情被母亲发现后，母亲没有责骂他，只是把下个月的买盐钱提前扣掉。

他在城内一场公开比武中输给了一个比自己年轻的军府子弟，输得并不难看，却被旁观者记住了他的身份而不是他的表现。

## 持续牵引与互相竞争的动机

- 想被看作一个有能力、有吸引力的人，而不只是某个军户家庭的“次子”。
- 对身体、食物、睡眠和男女之间的亲近有直接而强烈的欲望，不愿把人生过成单纯的牺牲。
- 希望母亲和妹妹过得安稳，不必依附长兄或某个军府官员。
- 对真正的强者和危险保持好奇，既羡慕他们拥有的行动空间，又害怕自己永远只能在城内旁观。

他不能同时追求安稳家庭生活与无拘无束的冒险。要获得被人看见的资格，往往必须把自己置于危险或竞争中；但每一次受伤、欠债或惹事，都会直接压缩家里的生活余地。

## Behavior Signature

他会优先保护现场最具体、最脆弱的人，但不会因此自动尊敬掌握秩序的人。面对不公平，他可能当场顶回去，也可能先记住对方的名字和弱点，等到更合适的时候处理。

他不喜欢别人替他定义“应该成熟一点”，尤其反感把欲望说成羞耻。他愿意为喜欢的人花钱、冒险或丢脸，却不愿为了抽象的名声牺牲自己的身体和时间。

他在公开场合容易被挑衅，私下却很能忍受重复劳动。真正让他改变选择的，通常不是大道理，而是一个具体的人是否会因此受伤、离开或看不起他。

## 重要关系原点

- 母亲：她把摊位和家里每个人的吃饭问题看得比荣誉重要。行简从她那里学会了生活的重量，也因此不愿让她把自己的一生只换成“孩子们过得不错”。
- 长兄魏行烈：行简既依赖又嫉妒。长兄拥有军籍、制服和外部认可，却常常把家庭责任说成理所当然。
- 旧友孟小满：军属区一起长大的女孩，如今在城中替人缝补军服。她知道行简什么时候是在逞强，行简则不愿让她永远只看到自己的狼狈。

## Composition Boundary
Power Core 与 Human Core 原样并列。此处不解释为什么某段童年象征某种能力，不重写欲望去适配金手指，也不推演世界将怎样回应。Mutable Character State 与 non-Canon Audition 分文件保存，不进入本卡。发现、使用、关系化学反应与真正的故事碰撞留给后续 Collision Authority。
