# Book Engine Mutation / Decision Vector — Evaluation

## Verdict

**SELECTIVE DIRECTIONAL PASS**

本实验验证的问题不是“怎样再增强一个新世界”，而是：在不新增 Agent / Gate / Thread DB / Relationship Portfolio / Scorer 的前提下，能否让 Story Program / Story Refresh 更稳定地产生同一本长篇的不可逆历史。

最终不采用完整 Treatment Bundle。稳定 promotion 仅包括：

- `Behavior Signature = Decision Vector`，且 `Signature ≠ Tension`；
- `Local Closure + Book State Mutation` 双结算；
- `Carry → Recontextualize → Combine → Consequence / Reprice` 的 Historical Recontextualization；
- Character / Relationship Afterlife 可以通过遗产、缺口、关系换位、可靠消息或敌人新策略继续生效，不要求人物肉身回归；
- 删除“每个 Horizon 必须推进 1—3 条旧线”的隐性回访税；
- 保留并保护更强的多世界 `Main-World Return Consequence`。

## Frozen Experiment Design

新蒸馏来源：`gbrain-longform-spine-tension-v1-20260901` 六书 source-first synthesis。Treatment 只增加 source-blind long-form craft，不改变 Frozen World / Human / Power / Canon、模型 `gpt-5.6-sol high` 或 production Story Program / Story Refresh 合同。

跨 Human 选择两个本质不同样本：

1. 《我身藏诸界》宁烬 21—30：多世界 Story Refresh，当前 production 已经具备强 Advantage Stack 与主世界 Rival / 社会重新估价；
2. 闻野舟：普通单世界玄幻 Story Program，Human 的核心牵引是被真正重要的人看见、感官兴趣、移动/变化与具体关系，不是宁烬的“都想拿 / 不让别人定价”。

A = current production；B = current production + source-blind Treatment Bundle。匿名 Luna-high Judge 不知道实验条件。

## Promotion Decision

跨 Human 结果不支持 wholesale bundle，却支持三项窄升级：

1. **Decision Vector**：人物张力来自两个都真有价值但不能同时完整取得的东西；第三解不能无损全拿；不同 Horizon 换冲突形态，不重复同一道题。
2. **Book State Mutation**：自然 Horizon 结束时，Local Story 真正结账，同时至少一个以后仍相关主体不能再按旧身份、关系、价格、策略、知识位置或选择空间行动；该 Mutation 复用现有 Stage Delta，不新增字段。
3. **Historical Recontextualization**：旧 Power / Asset / Relationship / Identity / Knowledge 进入新环境后改变用途、风险或价格；不是换地图后原样再用。

明确不采用：

- 每 Horizon 强制 1—3 条旧线推进；
- 每卷旧人召回；
- Relationship Portfolio / Thread DB；
- 固定 Payoff Pressure 模板或 Scorer；
- 所有高潮强制多线合流 / Public Proof；
- 新 Agent / Reviewer / Gate。

## Post-change Production Validation

`run_postchange.py` 使用修改后的正式 Prompt、**不附加 Treatment Bundle**，对宁烬 21—30 与闻野舟再次进行 Sol-high production-shaped 复验。两案均通过直接读，判 **PASS**。

### Ning 21—30 POST_CHANGE

- Decision Vector 不再只是“贪 / 不让别人定价”的标签，而是具体变成“折粮刀所有权 vs 亲眼追到不存在的北门 / 赢下结果”的不能全拿；第三条路仍保留河湾损失、骨口再裂与最终折粮刀留给岑非灯。
- Local Closure 清楚：最后一车粮穿过门形、折粮刀停止追粮、九百坟线不再继续逼河；北门历史、岑父清白与旧军责任继续未知。
- Book State Mutation 清楚：乔小满以后不能继续只安排别人搬走，因为自己的河湾已经失去；陆停山失去旧残盾追索路线；宁烬取得会限制路线/退出自由的兵印；回玄曜后天外商会从“拦路抢静态遗物”改成收兵器、停舟、邀请宁烬本人并上报真实往返现象。
- 更重要的是**没有为了长篇感把裴照临机械召回**：其线本轮明确休眠，但 Main-World Return Consequence 仍由天外商会真实承担。因此“取消旧线配额”没有退化成“确认能力→下一门”。

### Wen POST_CHANGE

- Character-specific choice 保持明显：他会为百猎榜留下而不追顾晚禾；又会为顾晚禾/幼兽错过桑照训练窗口；后来争王种心核时反过来选择不追顾晚禾。稳定的是“偏向仍有鲜活回应的一边”，不是重复一组选择题。
- 未选路线真实继续：桑照、阮砺、乌妲、梁烬、顾晚禾都有自己的行动，主角错过的机会不会等他以后补游。
- Historical Recontextualization 成立：无声台失败变成后续对阮砺旧战术的真实学习；桑照旧兵器把闻野舟带入梁烬锻刀与活兽材；走劲甲再与剥取兽性、脱身兽性复合，而不是新装备库存加一。
- 蜕壳城阶段产生 `Local Closure + Book State Mutation`，但 `World Horizon Handoff = NOT YET`：当前世界仍有反生林、空腔原、王种墓场等不同 Story Engine 的纵深，所以不会把“一个大阶段讲完”误判成“必须换世界”。

两案都没有新增固定旧线回访、Thread DB、Relationship Portfolio、未来世界预写或新的章节 Agent。Batch Writer / Sol-high Authority Delta 未改。

## What This Did Not Solve

- 尚未证明 100/200/300 章正文级长期稳定性；
- 尚未证明 planning 增益在所有题材都无损传到最终 prose，因此 Batch Writer / Authority Delta 链保持不动；
- 没有为关系、Payoff、线程增加新的计分器或数据库；这是有意保留的边界，而不是遗漏。
