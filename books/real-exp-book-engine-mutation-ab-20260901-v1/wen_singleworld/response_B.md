# STORY PROGRAM

## 核心碰撞

- 闻野舟想被真正有分量的人看见，也真会享受公开场合里所有目光压过来的瞬间；顾晚禾却总把下一段路放在眼前。两种欲望都不依赖特殊力量，也不可能永远同时满足：他跟她走，就会错过正在形成的名声和位置；他留下登台，她不会替他停下。

- 剥走强敌一招中最关键的一部分，会不断诱惑闻野舟寻找更强、更漂亮、更不讲理的招式。他容易把“我能从这一击里拿到什么”误当成“我能承担整场战斗”，因此会主动靠近本不属于当前猎阶的交锋。力量给他越级窗口，不替他补足身体、经验、连续攻防和第二次失误。

- 闻野舟对合手兵器、异兽纹理、颜色与身体力量有真实占有欲。这使他面对顾晚禾、乌妲和一件已经到手边的古兵时，可能选择兵器而不是关系；该选择不是能力升级的必经步骤，也不会被解释成他“终于懂得真正的自己”。

- 阮砺要找仍在跳动的王种心核，桑照要夺回家传兵器，梁烬要让沉铁门凭那柄长刀重新立名，乌妲要把幼年王种带回族人身边。他们的目标不会为了帮助或反制闻野舟而改变；闻野舟只能在真实碰撞后让其中某些路线改道，不能把他们收编成自己的成长环节。

- 白角部不以炼入兽性作为唯一强者道路，顾晚禾也不崇拜猎阶。闻野舟最值得炫耀的东西，在她们面前并不自动兑换成亲近、服从或正确判断；反过来，她们对异兽和移动生活的选择，也不会因为他的力量方便就天然与他一致。

## 不可降格的 Reader-Facing Story Events

### RSE-01
事件原子：猎市上一头异兽冲破控制，一名一阶猎手发动短距爆发追截 → 尚无猎阶的闻野舟第一次从那次爆发中剥走正在起效的一段，使猎手当场失步 → 他把借来的冲力接进自己的反撞，当众完成原本只有正式猎手才能完成的制杀。
状态残留：闻野舟的异常第一次被外界真实看见，他获得第一枚低阶心核和被正式估价的机会；该状态不能替代上述“强者发动—当场缺力—力量反过来完成制杀”的现场事件。
排程边界：阶段1内由 Outline 排章。
读者证明锚点：猎市；闻野舟；一阶；心核

### RSE-02
事件原子：桑照因猎市表现邀请闻野舟随自己前往百猎榜换榜场，顾晚禾同日在南行商队旁等他最后一次答复 → 闻野舟明知前者更可能带来名声、钱与高阶圈层，仍跟顾晚禾离镇 → 百猎榜挑战没有等他，桑照败北，家传兵器继续留在寒岫宗一方。
状态残留：闻野舟第一次为顾晚禾真实放弃一条已经打开的上升路线，桑照的失败也成为他无法追回的世界事实；该结果不能替代站在两条路之间并亲自走向顾晚禾的事件。
排程边界：阶段1末至阶段2开端，由 Outline 连续排章。
读者证明锚点：桑照；顾晚禾；百猎榜；寒岫宗

### RSE-03
事件原子：闻野舟把自己从蜕壳城夺得的黑背古刀交进沉铁门炉中，换取新刀完成后归自己所有 → 铸材所属的八阶异兽在刀未出炉时苏醒，梁烬和军府强者的正面压制同时承受扑杀 → 闻野舟剥掉支撑落地的那段力量，使扑杀偏离，梁烬趁这一瞬完成最后锻打 → 新长刀落入闻野舟手中，并在第一次挥出时真正切断一段正在运行的兽性。
状态残留：黑背古刀没有消失成无意义耗材，而是成为沉铁门长刀的一部分；长刀归闻野舟所有，能切断正在运行的兽性。该持有状态不能替代献刀、醒兽、偏移扑杀与新刀首次见效的完整事件。
排程边界：阶段4内由 Outline 排章。
读者证明锚点：沉铁门；梁烬；黑背古刀；八阶；长刀

### RSE-04
事件原子：王种墓场中，那头逃走的八阶异兽从陷阱后正面扑向六阶闻野舟 → 闻野舟只剥走它支撑落地的那一段，使整次扑杀偏开半尺 → 他把借来的冲势接入沉铁门长刀，从暴露出的喉下送入刀锋，亲手结束这头八阶异兽。
状态残留：闻野舟以六阶位置完成一次明确的六阶对八阶猎杀，取得完整心核与关键遗材，核心力量的高阶传奇姿态首次成立；战绩与获得不能替代读者亲眼看到“王种最强扑杀反而把刀递给他”的事件。
排程边界：阶段6高潮，由 Outline 排章。
读者证明锚点：王种墓场；六阶；八阶；沉铁门长刀；喉下

## 全书成长与核心幻想兑现脊柱

- 早期，闻野舟从“只能凭身体和小聪明赢镇内比试”变成真正的一阶猎手。他吸收猎市所得低阶心核，获得稳定热感知；异常力量则从偶然抓住明显爆发，进步到能分辨扑杀、硬化和转向中究竟哪一段正在决定结果。别人仍可凭连续招式压住他，他也仍只能保留一段借来的效果。

- 到二阶时，他不靠连续升阶制造进度，而是在南行追猎、白角部碰撞和蜕壳城争夺中反复使用同一位置：热感知负责找到活物与伏击，异常力量负责从高阶动作中撕开一次窗口。蜕壳城内，他以二阶位置打穿一名四阶竞争者的一次硬化，夺得黑背古刀；刀能承接远高于普通低阶兵器的冲势，使他第一次能把借来的高阶力量真正送进目标，而不是身体先承受不住。

- 中期，闻野舟经过足够的正式狩猎与武技磨合进入三阶至五阶。黑背古刀被他主动投入沉铁门新刀的锻造，不是被没收或换成资格；完成后的长刀成为新的非对称优势：以前他剥掉一段兽性后，对手下一招仍能重新发动；现在他先让关键一段缺失，再用长刀切进尚在运行的其余部分，可以把一次短暂破绽扩成足以完成连杀或脱身的断档。

- 这一复合不改变开局 Power Core：闻野舟仍不能夺取尚未发动的兽性，仍只能保留一段借来的效果，借力仍在完成一次动作后消散。长刀是他真实拥有的独立兵器，不是剥取能力的新模式；刀离手时，他仍只能依靠原本边界作战。

- 百猎榜公开场合，闻野舟以五阶位置击败一名六阶猎手。对方依据阮砺从蜕壳城得到的可靠见闻，故意用不带兽性的身体动作夹杂延迟发动，第一次让闻野舟剥错节点并遭受重击。闻野舟被迫公开长刀的切断效果才扳回胜负；五阶、六阶与越一阶结果必须由现场懂行者一次说清，随后让猎庭记录、招揽价格和阮砺的战术真正改变。

- 高阶阶段，闻野舟进入六阶后才正面卷入八阶异兽之战。他不夺走全部扑杀，只抽掉落地支撑，再借冲势把长刀送进喉下。取得完整心核后，他通过正常融合进入七阶，并获得该王种原有的单次空中改向本能：以前他只能夺走对手的转向，自己仍受落点限制；现在他能让对方在空中失去一次修正，同时用自己的改向携带借来的爆发绕到另一侧。两项能力组合后才形成“对方按旧落点扑空，自己带着对方的力量从新角度完成一击”的新战斗姿态。

Book-Level Longitudinal Spine：

- 顾晚禾线：闻野舟想要的是她本人，还是她带来的鲜活生活 → 下一次可见变化应是他先为她放弃百猎榜，后来又在她明确启程时选择留在榜场，两次选择方向相反但都真实付出机会成本 → 两人最终能否接受彼此不同的停留节奏，保持未知。

- 阮砺／桑照线：家传兵器与百猎榜第一会落到谁手里，阮砺会怎样处理闻野舟的异常 → 下一次可见变化是桑照在闻野舟缺席时败一次、之后凭自己的路线夺回兵器，而阮砺从亲眼见证发展出一次真正有效的错节点反制 → 阮砺在蜕壳城所得王种心核最终会把他带到什么位置，保持未知。

- 异常力量线：闻野舟为什么能剥走正在运行的兽性 → 下一次可见变化只能是它在普通猎手、部族异兽、古兵与王种身上表现出相同永久边界，证明这不是某一功法的普通变种 → 能力来源、是否与远古巨兽有关，当前仍必须保持未知。

- 社会位置线：一个无猎阶的皮料零工能否成为真正有分量的人 → 下一次可见变化是猎市偶然惊艳、二阶越四阶、五阶胜六阶、六阶杀八阶依次推翻旧报价，使猎庭、军府、宗门和旧识必须按明确猎阶与战绩重新对待他 → 七阶之后他愿意接受什么身份、拒绝什么身份，保持未知。

## 不可替代的人与关系

- 顾晚禾先想走自己的路，也愿意为受伤驮兽和幼年王种停留一段，但不会为闻野舟永久改变路线。她不能被另一个“同样支持主角的女伴”替代，因为真正改变闻野舟选择的是她不崇拜猎阶、不承诺等他，以及两人已经共同支付过一次实际失业与远行成本。她会让他放弃名声，也会因他选择兵器或榜场而独自离开。

- 白角部首领乌妲首先要找回被人类猎队掳走的幼年王种，保住族人与异兽共同狩猎的生活。她不能被普通荒原盟友替代：闻野舟第一次接触她时，会因剥走部族异兽正在使用的感知而直接得罪她；只有幼王、白角部对炼入兽性的不同态度和顾晚禾治疗异兽的行动，才能让这段敌意转成有限信任。

- 连续多年位列百猎榜第三的桑照首先要夺回被寒岫宗扣下的家传兵器，而不是培养闻野舟。他不能被普通赏识者替代，因为他给出的正是闻野舟最想要的“有分量的人看见”，闻野舟却会为了顾晚禾拒绝第一次同行。桑照第一次败北发生在闻野舟缺席时，之后夺回兵器也必须依靠自己的成长，而不是等主角替他赢。

- 寒岫宗弟子阮砺首先要取得蜕壳城内仍在跳动的王种心核，并维持百猎榜第一与宗门利益。他不能被普通强敌替代，因为他亲眼见过闻野舟从正在发生的高阶动作中拿走一段，随后确实研究出“先用无兽性的身体动作骗取判断，再延迟发动真正兽性”的反制。这个反制会让闻野舟受创、错失先手并被迫公开长刀，而不是供主角再次展示原解法。

- 沉铁门门主梁烬首先要让宗门凭一柄真正能切断兽性运行的长刀翻身。闻野舟不是他的天命持有者；梁烬愿意把刀交给他，是因为闻野舟交出已归自己所有的黑背古刀、在醒兽时创造了完成最后锻打的瞬间，并愿意让这柄刀在百猎榜和王种之战中公开留下沉铁门之名。若没有这次具体交换，梁烬不会因主角特殊就白送宗门重器。

## 长期故事主线

### 阶段1｜猎市见光
**为什么现在发生：** 下一次猎市正是闻野舟出售皮具、攒离镇私钱的最近机会；桑照也在为即将到来的百猎榜挑战准备兵器配件。顾晚禾已经确定随商队南行，不会等猎市之后再替闻野舟重新安排日期。

**谁想要什么：** 闻野舟想把一件皮具卖出真正懂行的价格，也想在重要人物面前留下名字；顾晚禾想按原计划南行；桑照想为夺回家传兵器补齐临战所需，并寻找任何可能改变挑战结果的人与物。

**主角的关键选择与行动：** 闻野舟拒绝为了讨好买家改掉自己喜欢的颜色和纹理；异兽失控后，他没有退到安全处，而是在一阶猎手发动爆发时第一次剥走其中一段并完成反撞。事后他坚持取得属于制杀者的低阶心核与皮具全款，不把公开胜利换成一句夸奖。

**这一阶段真正的阅读满足：** 一个没有猎阶、长期站在猎队边缘的人，当众把正式猎手正在使用的力量拿来完成制杀；桑照第一次真正停下来承认他有东西，猎市作品、钱和低阶心核都实际到手。

**Stage Delta：**
Power：闻野舟成功融合低阶心核，获得稳定热感知，精确位置由无猎阶进入一阶。
Possession：猎市皮具售出所得、剩余异兽材料与正式武器购置余钱归他本人。
Relationship：桑照给出随行百猎榜换榜场的明确邀请；顾晚禾不改变南行日期。
Identity：镇内众人第一次把他当成可能进入正式猎队的人，而不是识货的皮料零工。

**下一阶段为何自然发生：** 桑照与顾晚禾在同一时间朝不同方向离开。闻野舟必须在已经打开的高阶圈层与顾晚禾本人之间作出不可同时完成的选择。

### 阶段2｜南行追幼王
**为什么现在发生：** 闻野舟选择跟顾晚禾南行，因此错过桑照的百猎榜挑战；商队南下时恰逢白角部迁徙与边军封堵，顾晚禾因驮兽伤势停留，闻野舟也无法把迁徙当成远处消息绕过去。

**谁想要什么：** 闻野舟想跟顾晚禾继续走，也想亲眼看看白角部的异兽；顾晚禾想处理沿途驮兽伤口，不愿被闻野舟替她决定何时离开；乌妲要找到被掳走的幼年王种；边军只想在部族进入城镇腹地前逼其退回荒原。

**主角的关键选择与行动：** 闻野舟第一次交手时误把白角部异兽的协同追踪当成围杀，剥走其正在使用的感知，直接得罪乌妲；发现真正的掳兽猎队后，他不替边军与部族谈判，只决定自己追上猎队、夺回他们携带的实物线索并让顾晚禾通过封锁。即使得知桑照败北，他也不折返补救。

**这一阶段真正的阅读满足：** 核心力量第一次离开擂台式正面对攻，用来夺走异兽正在锁定目标的感知、抢回追猎主动；同时读者看到闻野舟真的为一个具体女人错过已经打开的名声路线，而世界没有等他。

**Stage Delta：**
Power：闻野舟把热感知融入野外追猎，并在多次真实狩猎后进入二阶；异常掌握从抓取明显爆发进步到能辨认感知锁定发生的瞬间。
Relationship：乌妲从直接敌视转为允许他参与追猎，但不信任他对兽性的态度；顾晚禾确认他确实为自己付出了百猎榜机会，却没有因此承诺长期留下。
Knowledge：众人取得幼年王种将被送往蜕壳城开启期交易的实物线索。
World State：桑照第一次挑战阮砺失败，家传兵器继续留在寒岫宗一方。

**下一阶段为何自然发生：** 幼年王种的去向把乌妲与顾晚禾拉向蜕壳城；闻野舟既想继续跟顾晚禾，也被正在裂开的巨兽外壳、古代兵器和高阶强者同时吸引。

### 阶段3｜裂壳夺刀
**为什么现在发生：** 蜕壳城按原周期裂开，霍归川封锁外围，阮砺进入壳内寻找仍在跳动的王种心核；掳兽猎队试图借开启期的人流出售幼年王种，使原本独立的部族追猎与遗迹争夺在同一地点碰撞。

**谁想要什么：** 乌妲只要幼年王种活着回到族人身边；顾晚禾想先处理幼王伤势，再决定自己的下一条路；阮砺要抢到仍在跳动的王种心核；霍归川要压住壳内活物可能造成的失控；闻野舟最初为幼王进入，见到黑色内壁旧战场中的黑背古刀后，又真心想把刀拿走。

**主角的关键选择与行动：** 当幼王踪迹与黑背古刀在裂壳深处朝两个方向分开时，闻野舟没有选择最正确或最安全的答案，而是追向古刀，把营救交给仍在行动的顾晚禾和乌妲；他以二阶位置迎战一名四阶竞争者，剥掉对方局部硬化最吃力的一瞬，用借来的爆发把黑背古刀送入防御缺口，随后带刀离开。

**这一阶段真正的阅读满足：** 二阶对四阶的第一次明确越级胜负，以及一件已经被写得值得眼馋的古兵真正到手、立刻承接高阶冲势并完成破甲；与此同时，顾晚禾和乌妲没有因主角改路就停下，她们依靠自己的行动救回幼王。

**Stage Delta：**
Possession：黑背古刀归闻野舟所有；它经历壳内旧战场冲击仍不卷刃，能够承接明显高于普通二阶兵器的爆发。
Relationship：顾晚禾无法接受闻野舟在最紧迫处追刀，关系从“他跟着她走”变成双方都知道他可能被另一件具体欲望带走；乌妲虽取回幼王，却不再把闻野舟视为可靠同行者。
Enemy State：阮砺亲眼看到闻野舟使一段正在发动的硬化失效，开始依据可观察事实调查他的出手时机，但不知道隐藏机制。
World State：乌妲取回幼年王种；阮砺取得仍在跳动的王种心核；霍归川未能控制全部壳内所得。
Knowledge：众人确认壳内深处确有仍在活动的生命迹象，但不回答远古巨兽是否活着。

**下一阶段为何自然发生：** 黑背古刀已经能承受借来的高阶力量，却不能延长闻野舟制造的短暂破绽；沉铁门正在铸造的长刀恰好是他会真正想占有的东西。与此同时，铸材所属的八阶异兽仍未确认死亡，这场锻造无论他是否前往都会继续。

### 阶段4｜沉铁醒兽
**为什么现在发生：** 闻野舟主动带黑背古刀前往沉铁门，不是因为世界给他发了升级任务，而是他听说那里正在造一柄能切断兽性运行的长刀；梁烬需要让锻造成功，军府则坚持先确认八阶异兽死亡，两方冲突已经逼近失控。

**谁想要什么：** 闻野舟想让那柄长刀真正归自己；梁烬想凭成刀让沉铁门重新进入高阶宗门视野；军府强者想先杀死八阶异兽，避免锻造现场成为灾难；尚未死透的八阶异兽要挣脱分割与围杀。

**主角的关键选择与行动：** 闻野舟不要求保留黑背古刀原样，而是把已经属于自己的古刀投入炉中，换取新刀完成后的完整所有权；八阶异兽苏醒时，他只决定守住炉前这一处，不接管撤离或围杀安排。他从扑杀中剥走落地支撑，使梁烬获得最后一次锻打机会；新刀出炉后，他拒绝交给军府保管，亲自持刀追出。

**这一阶段真正的阅读满足：** 已得古兵不是被剧情淘汰，而是作为闻野舟自己的筹码铸进更强长刀；主奖品真正归他，且第一次挥刀便把“短暂缺一块”变成“其余兽性也被刀锋切断”的复合高光。

**Stage Delta：**
Power：闻野舟进入三阶，能更稳定地判断一招真正的发力节点，但仍只能保留一段借来效果。
Possession：黑背古刀成为沉铁门长刀的一部分；成刀归闻野舟本人，不是借用、保管或未来资格。
Capability：剥取与长刀首次形成复合——先使关键片段缺失，再切断尚在运行的兽性，使高阶对手无法立即用下一段兽性补回破绽。
Relationship：梁烬因成刀与闻野舟形成互相需要但并不从属的关系；闻野舟负责让刀留下战绩，梁烬保留铸刀者的名声。
World State：八阶异兽负伤逃离沉铁门，其踪迹转向王种墓场；军府从“先处理材料归属”转为必须追杀活兽。

**下一阶段为何自然发生：** 新刀、蜕壳城越级战绩和醒兽现场见证共同把闻野舟推回公开视野；百猎榜再次成为桑照、阮砺和闻野舟无法绕开的同一场碰撞，而顾晚禾也将在换榜前离开这片区域。

### 阶段5｜榜上换价
**为什么现在发生：** 桑照在第一次败北后重新发起挑战，阮砺带着蜕壳城所得王种心核回到榜场；闻野舟已经通过一段充分的正式狩猎期进入五阶，新刀战绩使猎庭无法继续按无背景猎手估价他。顾晚禾则明确告知自己会在换榜结束前启程，不再接受一次含糊的“等我”。

**谁想要什么：** 桑照要当众击败阮砺、取回家传兵器；阮砺要保住榜首和兵器，并逼闻野舟暴露更多边界；闻野舟想在真正有分量的场子里打出自己的名字，也想知道顾晚禾这次是否仍值得他离场；顾晚禾只要一个明确选择，不要被当成比赛之后仍会停在原地的人。

**主角的关键选择与行动：** 闻野舟选择留在榜场，不再重复第一次跟随顾晚禾的答案；面对一名受阮砺指点的六阶对手，他第一次被无兽性的身体动作骗错节点并遭受重击。为了赢下已经无法隐藏的公开战，他主动让沉铁门长刀完全显效，以五阶位置切断六阶兽性并完成反胜。

**这一阶段真正的阅读满足：** 五阶胜六阶的公开大场面同时兑现全场震动、精确猎阶校准和现实重新定价；闻野舟终于得到自己一直想要的重量级注视、奖金、招揽与榜上战绩。另一边，桑照依靠自己的路线击败阮砺，家传兵器真正回到手中。

**Stage Delta：**
Power：闻野舟的精确位置为五阶；越一阶胜负不自动把他改写成六阶。
Identity：猎庭正式记录五阶胜六阶战绩，宗门、军府和大家族的招揽价格同时提高；沉铁门也因长刀公开见效重新获得高阶订单与挑战。
Possession：榜场奖金与战绩奖励实际到账，闻野舟第一次拥有足以让家里不再经不起一次伤亡、同时仍可自行远行的私钱。
Relationship：顾晚禾按自己的日期离开；闻野舟没有追赶，也没有把这次分开解释成关系终结。桑照归还第一次错失的认可，却不因胜利成为闻野舟的上级。
Enemy State：阮砺失去榜首与家传兵器，但有效反制已经迫使闻野舟受创、暴露长刀并改变作战顺序；他不再重复争榜，而把目标转向逃往王种墓场的八阶异兽。

**下一阶段为何自然发生：** 八阶异兽仍活着，阮砺需要它的完整心核重建公开分量，军府必须结束醒兽后果，闻野舟则第一次拥有足以进入这场争夺的猎阶、兵器和私人欲望。

### 阶段6｜墓场借王一击
**为什么现在发生：** 逃走的八阶异兽进入王种墓场，附近异兽开始利用陷阱袭击追兵；阮砺、霍归川和闻野舟分别因王种心核、军府战果与个人猎杀欲望进入墓场，没有任何一方能把事情降成普通围猎。

**谁想要什么：** 闻野舟要亲手杀死八阶异兽并拿走完整心核；阮砺要用这枚心核弥补失去榜首与家传兵器后的力量差；霍归川要在异兽再次改变城防边界前杀死它；墓场异兽要利用受伤王种与人类追兵互相消耗。

**主角的关键选择与行动：** 闻野舟只作一个高分量方向选择：他要王种心核，军府如何封锁和清理不由他安排。阮砺利用已经验证过的延迟发动和纯身体假动作，让闻野舟第一次剥错目标、失去先截王种的路线并被逼入墓场深处；闻野舟随后不再等待熟悉的正面招式，而是在八阶异兽真正扑下时只夺走落地支撑，把借来的冲势接进长刀，完成喉下击杀。

**这一阶段真正的阅读满足：** 六阶正面杀八阶，核心幻想的传奇画面完整落地；胜利之后不是立即追责或收税，而是王种心核、关键甲片、军府赏金与世界级重新估价连续兑现。闻野舟第一次站进七阶能够改变城防结果的圈层。

**Stage Delta：**
Power：闻野舟以六阶位置完成六阶对八阶猎杀；成功融合所得王种心核后进入七阶，并获得稳定的单次空中改向兽性。
Capability：他能剥走对手正在使用的转向或落地支撑，同时用自己的空中改向携带借来的冲势，从旧落点之外完成攻击；仍不能储存第二段借力，也不能夺取未发动兽性。
Possession：完整王种心核被他亲手取得并完成融合；关键甲片、军府赏金和沉铁门长刀继续归他，不以资格或代管结算。
Identity：霍归川及在场强者以六阶杀八阶、战后进入七阶为依据重新估价；闻野舟成为能直接影响一城安全边界的公开强者。
Enemy State：阮砺的反制真正让闻野舟失去先手并改走墓场深路，但阮砺没能取得最终心核；他仍保有蜕壳城所得王种心核与自己的成长路线，不被降成静态败将。
World State：沉铁门醒兽事件完成结账；白角幼王已经回归族人，百猎榜与家传兵器争夺已经改写，当前区域最具牵引力的几件大事不再停在原状态。

**下一阶段为何自然发生：** 闻野舟已从无猎阶进入七阶，当前区域的幼王、蜕壳城开启、沉铁门醒兽、百猎榜换位与王种追杀均已被真实改变。继续留在原层只会重复招揽、争榜和同类猎杀；下一步需要新的独立人物欲望、世界尺度与可进入的更高竞争圈层，而不是再把旧事件放大一遍。

## World Horizon Handoff

- **触发条件：** 阶段6全部结果落地：闻野舟以六阶杀死八阶异兽、完成王种心核融合并进入七阶；沉铁门长刀、猎庭战绩、顾晚禾离开、桑照取回家传兵器、阮砺失去榜首但保留独立追逐路线均成为已发生事实。当前区域不能再仅凭上述旧对象生成一种全新的主要欲望时，停止继续消费本 Horizon。

- **Expansion Scope：** `macro`

- **为什么此时必须扩：** 当前 Horizon 的主要高价值对象与公开竞争已经完成一次不可逆改写；闻野舟也已从被排除在高阶战斗圈外的人，进入能改变城防结果的七阶圈层。下一阶段需要新的独立生活方式、强者关系、世界入口和不同于“争榜／猎王／夺现有心核”的故事发动机，而不只是给同一批对手提高猎阶。

- **Carry Forward：**
  - 闻野舟当前精确位置为七阶；稳定兽性包括热感知与王种的单次空中改向。
  - 剥取能力的全部永久边界继续有效：只能取正在使用且经过当前交锋的部分；同一时刻只能保留一段；一次动作后消散；不能夺取未发动能力。
  - 沉铁门长刀归闻野舟所有，能切断正在运行的兽性；它与剥取能力已经形成公开可见的复合战法。
  - 六阶杀八阶、战后进入七阶是公共战绩；外界只知道现场结果与长刀效果，不知道剥取能力的隐藏因果。
  - 顾晚禾已经独自离开，两人关系未终结也未承诺重聚。
  - 阮砺失去榜首与桑照家传兵器，仍持有蜕壳城所得王种心核，并已经证明自己能够从可靠观察中形成有效反制。
  - 桑照已经凭自己的路线夺回家传兵器；乌妲已经带幼年王种回到白角部；梁烬与闻野舟因长刀声名保持互利而非从属关系。
  - 蜕壳城深处仍有活物、远古巨兽为何未彻底腐烂、王种墓场为何影响附近异兽等问题继续保持未知，不因当前胜负自动合并或解答。

- **Reader-Facing Edge：** 当前 Authority 没有批准具体外来人物、外部地点或下一世界器物，不得硬造。Handoff 前只让闻野舟在现有顶层战绩记录或高阶强者的明确判断中亲眼确认：猎阶九不是力量尽头，部分九阶战绩已经无法用当前可靠记录解释；不说明九阶之后是什么，也不把任何答案提前写成针对他的入口。

- **World Expansion Task：** 在触发条件成立后，运行 protagonist-blind World Expansion；World Agent 不读取 Current Character / Power Stack / Human / Future Story。扩展批准后再编译 Current Character，并运行 Story Refresh。

## 远期仍值得追的东西

- 顾晚禾｜她离开后会选择怎样的生活，闻野舟下一次见到她时，七阶身份究竟会拉近还是拉远两人的关系。
- 阮砺｜他已经学会一次有效反制，又持有蜕壳城王种心核；他可以继续变强并改变策略，但不自动获得与主角同级的递归 Advantage Stack。
- 乌妲与幼年王种｜幼王回归不是部族线终结；边军仍把南迁视为入侵，白角部也不会因为闻野舟帮过一次就接受炼入兽性的道路。
- 蜕壳城深处的活物｜只保留已经看到的生命迹象，不提前决定远古巨兽是否仍活着。
- 闻野舟的剥取能力来源｜继续保持未知；未来只能由新证据逐层推进，不能由相似古兵、王种心核或高手猜测直接宣布答案。
- 猎阶九之外｜作为已批准的世界边界继续存在，但不得在下一次 protagonist-blind World Expansion 前预写具体力量、势力、人物或为闻野舟量身准备的成长对象。
