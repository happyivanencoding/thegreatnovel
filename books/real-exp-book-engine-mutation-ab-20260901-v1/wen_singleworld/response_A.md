# STORY PROGRAM

## 核心碰撞

- 闻野舟即使没有那项异常力量，也会追逐被真正强者看见的时刻、合手而漂亮的器物、鲜活的生活和顾晚禾本人。稳定收入、宗门位置与安全路线能吸引他，却不能自动压过一次公开证明、一个具体的人或一件他真想拿到手的东西。
- 他的力量诱惑他等待强敌把最得意的一招完整用出来。对付不了解他的敌人，这会制造极不公平的越级窗口；被阮砺实际见证并研究后，这种习惯会被假动作、多点攻击和不经过正面交锋的手段利用，迫使他改变打法。
- 顾晚禾不会因他变强、出名或得到名器而停止移动。她能让他放弃已经到手的稳定位置，也能在他终于享受万众瞩目时独自离开；她不是奖励，也不负责把他变成更成熟的人。
- 阮砺寻找仍在跳动的王种心核，桑照要夺回家传兵器，乌妲要找回幼年王种，梁烬要让沉铁门凭那柄截断兽性运行的长刀翻身。这些欲望在闻野舟出现前已经存在；他能夺取其中的机会、改变胜负，却不能把所有人收束成围绕自己运转的队伍。
- 闻野舟对颜色、纹理、身体、热食和器物手感的偏爱，会把他带向并非修炼效率最高的路线。《并血篇》、截性长刀和王种心核之所以进入他的人生，必须先经过他已经选择的人、战斗与地点，而不是世界替他的核心力量搜索最佳配件。

## 不可降格的 Reader-Facing Story Events

### RSE-01

事件原子：猎市兽笼崩裂，成年青斑豹扑向顾晚禾 → 尚无猎阶的闻野舟在它折身落地时剥走那一段转向与落势 → 青斑豹扑偏，他借来的落势只够完成一次动作，恰好把猎叉送进它张开的口中。

状态残留：闻野舟第一次确认自己能拿走正在发生的兽性片段，猎市也留下“无阶者杀死成年异兽”的公开传闻；该结果不能替代上述失控、剥取、扑偏与反杀的现场事件。

排程边界：阶段1前段由 Outline 排章。

读者证明锚点：猎市；青斑豹；顾晚禾；无猎阶；猎叉

### RSE-02

事件原子：猎庭公开定阶中，一阶闻野舟面对二阶猎手的三次折身扑杀 → 前两次只闪避，让对手确信他抓不住节奏 → 第三次剥走对方真正用来变向的那一瞬，借同一段转身力量从对方背后完成反击。

状态残留：猎庭仍把闻野舟定为一阶，但公开记录他击败二阶对手；青背猎刀与奖金当场归他。战绩、定阶与持有物不能替代这场完整反杀。

排程边界：阶段2内由 Outline 排章。

读者证明锚点：猎庭；一阶；二阶；青背猎刀

### RSE-03

事件原子：沉铁门地底的八阶异兽苏醒，七阶霍归川正面挡住扑杀 → 五阶闻野舟从它落地前腿中剥走支撑冲势的一段硬化，把借来的冲力送进截性长刀 → 刀口令那条前腿连续三息无法重新发动兽性，霍归川因此斩断它的颈骨。

状态残留：截性长刀正式归闻野舟所有；五阶介入八阶战斗的公开事实使军府、宗门和猎庭重新估价他。刀的归属与战绩不能替代“五阶对八阶、剥走支撑、三息失效、七阶完成斩杀”的现场。

排程边界：阶段6后段由 Outline 排章。

读者证明锚点：五阶；八阶；截性长刀；霍归川；三息

### RSE-04

事件原子：王种墓场内，七阶闻野舟独自迎着八阶王种的正面扑杀不退 → 王种落爪前忽然失去支撑身体的半尺落点 → 闻野舟把剥来的冲势与自身两种兽性同时接入截性长刀，将刀送进它暴露的喉下，并亲手取出仍在跳动的王种心核。

状态残留：闻野舟以七阶独杀八阶王种，完整王种心核归他所有，核心幻想的高阶形态首次完整成立；猎榜记录、心核持有与“越阶成功”不能替代这次正面迎击和反杀。

排程边界：阶段7终局由 Outline 排章。

读者证明锚点：王种墓场；七阶；八阶王种；半尺；王种心核

## 全书成长与核心幻想兑现脊柱

- 开局时，闻野舟没有猎阶，只能偶然抓住敌人最明显的一段力量，借来的效果完成一次动作便消失。炼入山猫心核、达到一阶后，他仍不能保存任何东西，但能用自己的空中折身承接剥来的转向或冲势，不再每次都被借来的力量拖倒。
- 在蜕壳城真正拿到《并血篇》和第二枚提供局部骨膜硬化的心核后，他经过长期融合，让两种原本会互相排斥的兽性同时留在身体里。以前他剥走高阶冲击后只能赌身体不被撕裂；现在可以先用骨膜硬化承受，再以山猫折身改变力量方向，把一次偶然反击变成可接入连招的越级窗口。这是故事中获得的新非对称优势，不改变“只能保留一段、只用一次”的永久边界。
- 截性长刀进入他的手中后，新的优势不是让他多存一段力量，而是让被刀真正伤到的身体部位在数息内无法重新调用兽性。核心能力单独使用只能制造一刹那缺口，长刀单独使用又很难准确砍中兽性运行的节点；两者结合后，他能先剥出缺口，再沿缺口下刀，把一刹那延长成足以改变高阶战局的三息。
- 王种心核不另开一套力量体系，而是把他已有的局部骨膜硬化提升为可沿骨骼与兵器连续传递的王种级身体本能。以前他面对八阶扑杀只能借一次、打一刀；完成融合并进入八阶后，他能让自身骨骼承受借来的高阶冲势，再经截性长刀改写落点，形成“敌人的最强冲击越大，他送回去的那一刀越重”的稳定高阶战姿。
- 猎阶始终是唯一公开主尺：无阶发现能力 → 一阶公开击败二阶 → 二至三阶在蜕壳城争得《并血篇》 → 三阶公开战胜四阶 → 五阶介入八阶战斗但不能单独杀敌 → 七阶独杀八阶王种 → 融合王种心核后成为八阶。胜负不反推猎阶，跨阶战绩与正常修炼分别写清。

Book-Level Longitudinal Spine：

- 顾晚禾究竟是他想共同生活的人，还是他用来追逐鲜活感的入口 → 下一次变化必须由两人中至少一人主动选择同行、分路或回返，并真实损失另一条机会 → 两人是否适合长期停在同一种生活里仍保持未知。
- 一个无阶皮料杂工被高层世界看见后，会不会终于满足 → 下一次变化应让旧猎市、父母、曾拒绝他的富户或猎庭因公开战绩具体改价、求取或改口 → 被所有人看见之后，他还会想让谁承认自己，保持未知。
- 阮砺在蜕壳城看见闻野舟的异常后，会把他当成可夺取的工具、必须除去的麻烦，还是同层对手 → 下一次变化必须是阮砺根据可靠观察设计出真正奏效的打法，并由此拿到一项现实收益 → 阮砺取得那枚跳动王种心核后会变成什么，前期不提前解释。
- 闻野舟为何能剥走正在发生的兽性片段 → 下一次变化只允许顶层强者确认“这不是已知兽性，也不会永久夺取能力”，或由后续复用暴露更精确边界 → 能力来源、为何属于他以及是否与远古巨兽有关，当前全部保持未知。

## 不可替代的人与关系

- **顾晚禾：** 她想沿不同城镇和部族继续移动，靠处理驮兽与异兽伤口挣钱，也想接触自己没见过的活体王种。其他同行者可以提供路线、情报或身体吸引，却不能替代她已经实际改变过闻野舟人生选择的历史。她的去留会使他放弃职位、错过期限，也会在他选择名器与公开声望时先行离开。
- **阮砺：** 他要拿到蜕壳城中仍在跳动的王种心核，并维持寒岫宗对猎榜与遗迹的控制。普通强敌可以比闻野舟更强，却不能替代这个最早在高阶现场看见其能力、随后用真实调查完成有效反制的人。两人的关系从悬殊估价转为猎取、竞争，最终才成为同阶胜负。
- **桑照：** 她只想以公开胜负夺回被寒岫宗扣下的家传兵器，不负责扶持闻野舟。她能独立击败阮砺、拿回自己的东西，因此不可替代地证明世界大事并不等待主角解决。她对闻野舟的认可有分量，却不会因认可而把自己的猎榜位置让给他。
- **乌妲：** 她要找回幼年王种并带白角部脱离围杀。别的部族首领可以提供荒原入口，却不能替代闻野舟亲手割开兽笼、把幼兽交还给她造成的私人债与戒心。她能带他接近王种墓场，也能在他觊觎王种心核时首先怀疑他。
- **梁烬：** 他要让沉铁门凭截性长刀重新进入顶层宗门视野。普通器师能替闻野舟打造好刀，却不能替代这柄在闻野舟出现前已经开铸、又恰好能与其能力形成复合的具体长刀及其铸造者。梁烬会欣赏他，也会为了宗门名声把他推到八阶异兽面前。

## 长期故事主线

### 阶段1｜猎市见光

**为什么现在发生：** 闻野舟终于做出一件准备带去猎市的贴腕皮具，想卖出钱并被懂行者看见；顾晚禾同时得到随商队前往蜕壳城的机会。猎市为招揽猎手展出活体异兽，成年青斑豹因伤势与拥挤撞破兽笼。

**谁想要什么：** 闻野舟想卖出皮具、攒离镇私钱，也想让顾晚禾看见自己并非只能做杂工；顾晚禾想拿到商队位置，不愿为他的临时兴奋错过启程；兽商想保住货物和声誉；本地猎手想在众人面前迅速制服青斑豹。

**主角的关键选择与行动：** 他没有逃出猎市，而是冲向顾晚禾所在的位置，在青斑豹真正扑下时第一次剥走兽性片段并完成反杀。事后，他拒绝富户趁热给出的长期皮料职位，把所得奖金用于接受正式融合，炼入一枚低阶山猫心核。

**这一阶段真正的阅读满足：** 普通杂工在众目睽睽下第一次让强兽自己的扑杀变成反杀工具；猎市的食物、皮料、兽笼与力量阶层第一次成为可触摸的生活。

**Stage Delta：**
- Power：闻野舟发现核心能力；炼入山猫心核后成为一阶，获得一次空中折身的稳定兽性。
- Possession：获得第一笔真正属于自己的猎杀奖金，但大部分被他主动花在心核、合口热食和出行装备上。
- Relationship：顾晚禾第一次亲眼看见他为靠近自己承担致命风险，却没有因此答应长期留下。
- Identity：从皮料杂工变成猎市传闻中的“无阶杀兽者”，尚未获得猎庭正式战绩。

**下一阶段为何自然发生：** 猎庭必须确认他的猎阶和能力是否属于已知兽性；他也需要一场可重复、可比较的公开战斗，才能把偶然传闻变成真正被看见的资格。

### 阶段2｜一阶借走二阶的转身

**为什么现在发生：** 猎庭公开定阶恰逢百猎榜换榜年的地方选拔，沉铁门拿出青背猎刀作为优秀新人的实物奖励。闻野舟若不能在商队启程前完成定阶，就只能继续以杂工身份同行。

**谁想要什么：** 闻野舟想拿到正式猎阶、青背猎刀和真正懂战斗者的承认；二阶猎手关越想守住地方选拔位置并拿走猎刀；猎庭考官想判断闻野舟的战绩是否只是意外；顾晚禾只愿等到约定时间，不替他延期。

**主角的关键选择与行动：** 他明知第一场公开使用会暴露能力，仍主动挑战二阶关越。前两次折身扑杀中他忍住不抢错误片段，第三次才剥走真正的变向节点，用对方的成名动作从背后击倒对方。胜后，他没有接受本地猎队的稳定位置，而是带刀赶上顾晚禾的商队。

**这一阶段真正的阅读满足：** 核心幻想第一次完整公开兑现：一阶者把二阶强者最熟练的一招当场拆走并反用；青背猎刀、奖金、酒肉和招揽同时真实到账。

**Stage Delta：**
- Capability：闻野舟仍是一阶，但已能判断连续动作中哪一次才是真正发力。
- Possession：青背猎刀正式归他，能承受三阶以下的短时冲击；奖金让他拥有第一笔离镇私钱。
- Identity：猎庭记录“一阶胜二阶”，多个猎队主动加价招揽。
- Knowledge：他确认剥错片段同样会占用唯一保留位置，不能在一招中反复试错。

**下一阶段为何自然发生：** 他选择随顾晚禾离镇，商队携带的一只密封兽笼却正是白角部南迁、边军封锁与幼年王种失踪三条世界线的共同铰链。

### 阶段3｜兽笼里的王种幼体

**为什么现在发生：** 商队进入边军与白角部相互试探的区域。顾晚禾处理驮兽伤口时发现密封车厢中还有一头被药物压制的幼兽；乌妲追来的正是它，商队主事却准备把它送往蜕壳城高价出售。

**谁想要什么：** 顾晚禾要让幼兽活下来，却不愿替任何阵营效忠；乌妲要夺回幼年王种；边军校尉要把幼兽扣作白角部入侵的证据和未来战兽；商队主事要完成交易；闻野舟既想保住通行凭证和私钱，也不愿被当作一个可以替换的押货杂工。

**主角的关键选择与行动：** 他拒绝替商队看守兽笼，在两方交锋时直接割开锁带，把幼兽推向乌妲，而不是主持停战或解释归属。四阶押兽人用硬化肩背撞来时，他剥走承受刀锋的局部硬化，以青背猎刀第一次伤到高出自己两阶的人。随后他选择跟着顾晚禾和白角部撤离，放弃商队的蜕壳城正规通行凭证。

**这一阶段真正的阅读满足：** 一个价值足以引发战争的活体王种真正出现在眼前；闻野舟以低阶力量介入高阶冲突，并为一个具体的人和一头具体幼兽改掉原定路线。

**Stage Delta：**
- Power：经过沿途狩猎与实战，闻野舟稳定进入二阶；核心能力仍只能承载一段、完成一次动作。
- Relationship：顾晚禾确认他会为鲜活的人与事毁掉稳妥安排，但也看出他享受被自己看见；两人的吸引加深，信任没有同步增长。
- Relationship：乌妲欠下救回幼兽的人情，却开始警惕闻野舟对高价值心核的明显兴趣。
- Enemy State：商队主事和边军校尉把他列为劫夺王种的共犯。
- Identity / Access：失去正规入城凭证，获得与白角部同行的短暂位置。

**下一阶段为何自然发生：** 蜕壳城按周期开启时出现一条未受封锁的侧裂，追兵、白角部和外层商队同时被迫改变路线；闻野舟不是拿到替代凭证，而是在世界事件失控后从无人控制的裂口进入。

### 阶段4｜壳里仍在呼吸

**为什么现在发生：** 蜕壳城开启的结构与旧地图不符，黑色内壁像肌肉一样缓慢收缩。阮砺深入寻找仍在跳动的王种心核，霍归川封锁返回路线；闻野舟、顾晚禾与乌妲被侧裂带入旧战场。

**谁想要什么：** 闻野舟想得到一部明确记载两种排斥兽性如何共存的古谱；顾晚禾要把受伤幼兽带出去；乌妲要保住幼兽与族人；阮砺只要跳动王种心核，愿意让其他入口全部塌死；霍归川要阻止壳内活物进入城面。

**主角的关键选择与行动：** 他在古尸身上看见两种完全不同的兽性痕迹，追入一间仍被黑壁挤压的兵室，亲手夺得《并血篇》和一枚保存完好的骨膜硬化心核。顾晚禾选择先带幼兽撤离，他没有立刻跟随，而是继续争夺古谱；两人因此分开，而不是由她在原地等待。阮砺第一次正面看见闻野舟剥走高阶兽性，却只确认可观察结果，不知道其私有边界。

**这一阶段真正的阅读满足：** 活着般收缩的巨兽外壳、旧战场和高价值古谱共同兑现探索幻想；闻野舟真正把能改变同层战斗方式的功法与心核带出城，而非只取得阅览资格。

**Stage Delta：**
- Possession：完整《并血篇》与骨膜硬化心核归闻野舟所有；另得到少量可出售的古代甲片。
- Knowledge：他知道两种排斥兽性可以共存，但融合失败会让两种身体本能同时撕裂宿主。
- Relationship：顾晚禾独自带幼兽脱险，对闻野舟选择宝物而非跟随自己既恼怒又理解；两人不再默认同行。
- Enemy State：阮砺确认闻野舟持有古谱，并开始调查其能力的触发方式。
- World State：至少一批亲历者看见黑色内壁主动收缩，“蜕壳城并非完全死物”成为无法压回传闻的公开问题。

**下一阶段为何自然发生：** 阮砺不能在霍归川眼前公开夺取古谱，便把压力带到百猎榜换榜场；闻野舟也不愿秘密交出已经拿到手的东西，选择在最亮的公开场合把自己的价格抬高。

### 阶段5｜榜上有名

**为什么现在发生：** 百猎榜换榜与桑照挑战阮砺同时举行。寒岫宗提出以真传位置换取《并血篇》，随后安排实际见过闻野舟战斗记录的四阶弟子莫岱在挑战场上逼他交物。

**谁想要什么：** 闻野舟要保住古谱、进入百猎榜并选走一件能承受高阶借力的好兵器；莫岱要夺回古谱、凭胜利进入寒岫宗内层；阮砺要维持宗门与榜首威望；桑照要当众击败阮砺并夺回家传兵器；顾晚禾准备随白角部继续北行，不愿围着他的成名时刻停留。

**主角的关键选择与行动：** 闻野舟拒绝以古谱换真传，在比赛前完成第二心核融合，以三阶身份登台。莫岱用连续假硬化诱他先抓错误片段，再从远处发动真正杀招，使他第一次因对手学习而失去原有路线；他被迫公开暴露山猫折身与骨膜硬化同时存在，才以三阶击败四阶。胜后他当场从猎榜奖励中选走沉铁门黑脊刀，而不是把奖励留成日后领取的名额。与此同时，桑照靠自己的胜负击败阮砺，取回家传兵器。

**这一阶段真正的阅读满足：** 三阶对四阶的精确越级、两种排斥兽性公开共存、群体震动、懂行者校准和各方加价同时落地；另一条顶层复仇线也由桑照本人完成。

**Stage Delta：**
- Power：闻野舟成为三阶；山猫折身与骨膜硬化稳定共存。
- Possession：黑脊刀、换榜奖金和猎榜前百的实际分红到手；旧青背猎刀被他留给父亲防身，不作折价替换。
- Identity：百猎榜新列第八十九；寒岫宗从招揽改为公开敌视，沉铁门开始关注他。
- Relationship：顾晚禾在庆功前离开；闻野舟这一次选择留下享受名声，没有再次追上去。
- Enemy State：阮砺的第一次针对奏效，迫使闻野舟暴露第二兽性；阮砺也因败给桑照失去榜首，转而加速夺取蜕壳城王种心核。

**下一阶段为何自然发生：** 梁烬从公开战斗中看见一种能让截性长刀真正命中兽性节点的使用者；阮砺则已经知道如何绕开闻野舟的正面剥取，两人的行动同时汇向那头尚未确认死亡的八阶异兽。

### 阶段6｜刀要在活物身上开锋

**为什么现在发生：** 沉铁门完成截性长刀的主体铸造，作为材料来源的八阶异兽却在地底恢复心跳。梁烬需要一次真实高阶战证明宗门翻身，霍归川要在异兽彻底苏醒前杀死它，阮砺要夺走活性材料以稳定蜕壳城心核。

**谁想要什么：** 闻野舟想要截性长刀本身，而不是试刀资格；梁烬要让自己的刀在七、八阶战斗中留下无法否认的结果；霍归川要杀兽；阮砺要取走活血囊；桑照想阻止寒岫宗再凭一件王种遗物压住猎榜。

**主角的关键选择与行动：** 梁烬把已经铸成的刀交到闻野舟手里，明确表示只要他敢带刀入场并让刀活着回来，刀便归他。阮砺的人用毒雾、远射和多点假发动避开正面交锋，迫使闻野舟放弃截住阮砺的最短路线；阮砺因此真实夺走一部分活血囊。闻野舟经过此前持续狩猎进入五阶，在八阶异兽扑杀时剥走前腿支撑，将借来的冲势送进长刀，制造三息失效，帮助霍归川完成斩杀。

**这一阶段真正的阅读满足：** 已经铺垫的截性长刀完整到手并立刻证明价值；五阶者在七阶、八阶战场上留下不可替代的一刀，获得远超普通小胜的社会重估。

**Stage Delta：**
- Power：闻野舟经过数轮真实狩猎与正常融合进入五阶，不因介入八阶战斗自动升阶。
- Possession：截性长刀正式归他；另得到斩杀赏金、一块八阶甲皮和可供长期修炼的高阶药材。
- Capability：剥走兽性节点后以长刀命中，可令同一部位连续三息无法重新发动兽性。
- Identity：霍归川按五阶记录他，却公开承认这一刀改变了八阶战局；军府、宗门和大家族开始以六阶核心人才的规格接触他。
- Enemy State：阮砺的反制改变了路线并让他夺得活血囊，没有被闻野舟用原解法抹平。
- Relationship：梁烬把宗门翻身的名声押在闻野舟持刀后的战绩上，两人形成互相利用、也互相珍惜作品的关系。

**下一阶段为何自然发生：** 死去的八阶异兽体内存在长期啃食王种残骸的痕迹；同时，白角部传来消息，幼年王种正被某种无法抗拒的身体本能引向王种墓场。闻野舟既想见顾晚禾，也第一次明确想亲手拿到完整王种心核。

### 阶段7｜王种把最强一扑递给他

**为什么现在发生：** 白角部幼兽持续向王种墓场移动，附近异兽开始使用陷阱驱赶人类。阮砺凭活血囊稳定了蜕壳城心核，也赶往墓场寻找能让自己彻底进入高阶的王种遗骸。闻野舟放弃军府当下给出的固定位置，循顾晚禾与乌妲的路线进入荒原。

**谁想要什么：** 闻野舟想要一枚完整王种心核，也想确认自己和顾晚禾是否还能主动选择同一段路；顾晚禾要保住幼兽，却不肯成为闻野舟的随行医者；乌妲要让幼兽摆脱墓场召唤；阮砺要取得墓场深处的古代遗物与王种残核；一头八阶王种要吞食幼兽，夺回其正在成熟的血脉。

**主角的关键选择与行动：** 他没有要求白角部替自己围猎，而是独自追杀那头八阶王种，以此换取乌妲带幼兽撤离的时间。阮砺趁机进入另一片古墓区，拿走闻野舟同样知道很值钱、却没有选择追逐的古代记录；这条机会真正落到阮砺手中。闻野舟在长期荒原狩猎中先正常进入七阶，最终正面剥走王种扑杀的半尺落点，以截性长刀独杀八阶王种，取出完整心核。

**这一阶段真正的阅读满足：** 核心幻想达到王种尺度：敌人越强、最有把握的一扑越重，递到闻野舟手里的反杀力量便越大；王种心核、尸体材料与七阶传奇战绩形成复合结算。

**Stage Delta：**
- Power：闻野舟在跨季狩猎、五至七阶多轮实战和正常修炼后进入七阶，以条件明确的越级窗口独杀八阶王种。
- Possession：完整王种心核、王种喉甲、獠牙与可出售尸材归他；白角部不要求他交出敌对王种遗骸。
- Relationship：他为顾晚禾选择这条路线，却同样承认自己想要王种心核；顾晚禾接受与他同行一个冬季，不承诺永久停留。
- Enemy State：阮砺得到另一片墓区的古代记录，没有自动获得闻野舟同级的复合能力；其原有蜕壳城心核路线继续成熟。
- Identity：闻野舟成为足以改变一座城安全边界的七阶猎手，早年熟人不能再把他当作幸运杂工。
- World State：墓场中的部分空壳会诱导活兽重复某种狩猎动作，但其原因仍未被解释。

**下一阶段为何自然发生：** 王种心核已经到手，需要在旧世界的公开主尺上真正改变闻野舟的身体与待遇；阮砺也凭自己从蜕壳城开始的路线进入八阶，主动选择无声台完成两人之间的公开结算。

### 阶段8｜八阶之后，旧尺仍在延伸

**为什么现在发生：** 闻野舟以《并血篇》长期消化王种心核，使原有骨膜硬化获得王种级质变；猎庭必须重新定阶。阮砺则以蜕壳城心核进入八阶，选择各宗门共同认可的无声台挑战闻野舟，夺回自己失去的最高估价。

**谁想要什么：** 闻野舟要让王种心核真正变成身体里的力量，并在旧圈层面前证明自己已经不是被高阶者临时利用的一刀；阮砺要用不依赖正面成名招的打法杀死他；桑照要看清新的榜首尺度，却不会自动替任何人站队；猎庭要重定两名八阶者的公开位置；顾晚禾要闻野舟亲口决定下一段路，而不是等名声替他选择。

**主角的关键选择与行动：** 他把王种心核用于强化已有骨膜硬化，没有另起第三套兽性；进入八阶后先回到旧猎市，让当年提供稳定管事职位的富户亲自按八阶猎手的价格求见，他收下该得的家人保障，却拒绝把人生重新锁回镇中。无声台上，阮砺使用远程器物、假发动与延迟爆发，逼他不能依赖一次抢取解决全部战斗；闻野舟以山猫折身改变身体位置、王种骨膜承受高阶冲击，再剥走阮砺真正发动的一段力量并沿截性长刀送回，赢下同为八阶的决定性胜负。

**这一阶段真正的阅读满足：** 王种心核先在旧社会坐标上兑现生活特权，再在同阶顶级对决中证明复合优势；无阶杂工终于让曾经高不可及的八阶强者必须围绕他的节奏作战。

**Stage Delta：**
- Power：闻野舟成为八阶；王种骨膜可沿骨骼与兵器承受、传递高阶冲势，但仍不能保存第二段借力。
- Capability：山猫折身、王种骨膜、剥取片段与截性长刀形成完整复合战姿，任一单项都无法完成同样的承受、改向与持续破坏。
- Identity：进入当前公开力量最高可见圈层；猎庭按八阶记录，宗门、军府和大家族不再以弟子或客卿规格对待他。
- Relationship：顾晚禾拒绝成为其固定府邸中的附属者；两人约定共同走完下一段外行程，之后是否继续仍由届时的欲望决定。
- Enemy State：阮砺在自身原有路线成熟后仍败于闻野舟的复合优势；他可以存活并继续成为危险人物，但不再拥有追赶主角每项新增优势的默认待遇。
- World State：闻野舟在无声台留下八阶刀痕后，一道多年无人触碰仍会自行延长的旧划痕当众转向，越过台沿继续伸展，证明所谓“无人见证的九阶旧战”并未随着交战者消失而真正停止。

**下一阶段为何自然发生：** 初始城镇、猎榜、蜕壳城、截性长刀、白角部与王种心核已经先后改变闻野舟的力量、关系和社会位置；无声台旧痕则把“九阶并非尽头”从顶层档案变成所有人亲眼可见的事实，当前世界层第一次具备停止继续消费旧竞争圈的条件。

## World Horizon Handoff

- **触发条件：** 闻野舟完成王种心核融合、以八阶身份在无声台击败同阶阮砺，旧城、猎庭、军府和宗门均已按最高可见圈层重新估价他；无声台旧划痕当众越出台沿后，停止继续用新的地方猎场或榜位重复证明其八阶分量。
- **Expansion Scope：** `macro`
- **为什么此时必须扩：** 当前层最强的个人欲望与世界机会已经让他从无阶杂工升入八阶圈层，旧猎榜、地方宗门和单一遗迹继续加码只会重复“更高阶猎物与更贵心核”。下一轮需要独立生成能让更广阔力量圈、不同生活方式和“九阶之后究竟是什么”真正进入人物选择的世界尺度，而不只是再放入一个更强敌人。
- **Carry Forward：** 猎阶仍是公开主尺，扩展只能延长范围、不能重造语法；闻野舟只能剥走正在使用且经过当前交锋的一段兽性，单次动作后消散；山猫折身、王种骨膜、《并血篇》与截性长刀继续有效；他是公开八阶并有七阶独杀八阶王种的战绩；顾晚禾、乌妲与幼年王种、桑照及其家传兵器、梁烬与沉铁门、存活的阮砺继续拥有自己的欲望；蜕壳城仍可能存活、王种墓场空壳仍在影响活兽、反生林异兽群仍未停止扩散；闻野舟父母与旧城已因其八阶身份获得新的社会位置。
- **Reader-Facing Edge：** 在当前 Horizon 最后两章，让无声台那道本会自行延长的旧划痕在闻野舟八阶胜负结束后继续越出台沿。人物只能确认它不属于刚结束的战斗，也超过现存九阶记录能够解释的范围；不得提前说明它通向哪里、由谁留下或代表哪种新力量。
- **World Expansion Task：** 在触发条件成立后，运行 protagonist-blind World Expansion；World Agent 不读取 Current Character / Power Stack / Human / Future Story。扩展批准后再编译 Current Character，并运行 Story Refresh。

## 远期仍值得追的东西

- 顾晚禾与闻野舟能否在移动、停留、身体吸引和各自机会之间形成不依附于名声的长期关系。
- 阮砺败后会如何处理蜕壳城心核、失去榜首与同阶败绩；他知道的古代记录仍不等于谜团答案。
- 桑照夺回家传兵器后真正想挑战的下一场胜负，以及她与闻野舟尚未结算的猎榜位置。
- 白角部幼年王种成熟后会选择部族、荒原还是王种墓场的召唤。
- 蜕壳城黑色内壁为何收缩，壳内是否仍有远古巨兽存活。
- 反生林被斩断的肢体为何能够继续生长，以及韩青禾的调查会带来什么新事实。
- 王种墓场的空壳为何能让活兽重复陌生的狩猎动作。
- 无声台持续延长的旧划痕究竟记录着一次尚未结束的战斗，还是另一种当前世界无法解释的事实。
- 闻野舟的剥取能力来源、为何不属于已知兽性，以及它在九阶之后仍必须服从的永久边界。
