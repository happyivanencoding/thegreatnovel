# 第1章 Single / Hybrid 对照

## 对照输入

- 两组使用同一份第1章 Director 事件合同。
- 两组使用第1章运行前的同一 BOOK/CANON 快照（`f05f1bb^`），`previous_chapter_text` 为空；该快照没有泄漏第5章状态。
- Single 只调用一次 Writer；Hybrid 采用已保存的 Curator → Primary → 四专项 → Integrator 链路。两组都没有把对照稿写入 Canon。

## 可观察差异

- 开篇：两者都保留 world_to_character，从血统评级/生态位规则收束到白砾收购场、砾角和沈砚的选择。Single 更快压缩到签字与逃离；Hybrid 在同一事件合同内增加了更密的感官、动作和现场反应颗粒度。
- 对话：Single 的霍燧与沈砚对话直接完成“欠款—临时领养—签字”的交易推进；Hybrid 在相同决定上保留更多回收权、异常个体和互不信任的潜台词，专项 Dialogue Patch 只做局部立场修正。
- 动作：两者都没有提前使用砂豆或借感。Hybrid 将砾角的侧向受力、开门、矮墙逃离和猎犬追出拆成连续动作，Action Specialist 只检查空间和因果，不重规划。
- 情绪与关系：Single 通过三天口粮、弟弟活饵和“路在这里”完成主角压力；Hybrid 进一步把砾角保持距离、沈砚让出出口等关系余波落到动作上。Emotion Specialist 的修改仍未把砾角写成驯服状态。
- 拼装：Hybrid final 相比 Primary Draft 段落数略降、字符数略增，来自去重、口径统一、铁链状态修正和先后借感澄清；没有新增剧情块，也没有覆盖 Primary 的主要事件。

## 运行边界

Single control 仅作实验对照，不更新 BOOK、Canon、未来十章计划或章节目录中的正史正文。
