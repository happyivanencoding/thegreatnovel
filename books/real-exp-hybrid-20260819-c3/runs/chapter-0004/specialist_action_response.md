# Specialist Audit

- 干粮交换段把沈砚写成仍保留几块食物，与事件合同要求拿出“最后一块干粮”不一致。
- 前文章末已明确贴壁膜干裂、碎裂；本章又写成腰侧仍夹着完整的“那片”贴壁膜，物品连续性不清。
- 前文已有两只猎犬，本章前段多用单数“猎犬”，结尾却突然使用“它们”，未交代两只猎犬是否都在水槽上方追击。

# Proposed Patches

## Patch 1

目标锚点：  
“几块粗饼还贴在里面……这是他此刻愿意拿出来交换一条未知道路的最后一块。”

操作：replace

建议文本：  
“沈砚摸进衣襟。里面只剩最后一块边缘完整的干粮。他把它抽出来——这是他愿意拿来交换一条未知道路的最后一点食物。”

理由：统一干粮的资源状态，准确兑现“最后一块干粮”的交换动作。

## Patch 2

目标锚点：  
“他腰侧还夹着那片从岩蛛腹侧取下的贴壁膜。膜边已经干硬，表面却在潮气里微微回软。”

操作：replace

建议文本：  
“他腰侧还夹着从那片贴壁膜上撕下的一块残片。残片边缘已经干硬，沾到潮气后，表面只微微回软。”

理由：承接前章贴壁膜已经碎裂的状态，同时保留本章短暂再次试用的动作。

## Patch 3

目标锚点：  
“身后的塌口传来一声沉重的撞击。猎犬撞在了水槽上方的盐壳上。”

操作：replace

建议文本：  
“身后的塌口传来两声沉重的撞击。两只猎犬都在水槽上方的盐壳外，撞击与铁链拖动声一前一后逼近。”

理由：明确两只猎犬的追击位置，消除前文单数与结尾“它们”之间的空间指代断裂。
