# 《借我一招》Opening Three Chapter Reader-First 可读性验证

实验标识：`real-exp-opening-reader-first-fresh-v1`

日期：2026-08-22

分支：`principal_dev_new_sys`

## 本轮问题

本轮不再使用《炉藏万象》，用完全不同的经典玄幻 / 宗门成长 / 武学战斗样本，验证当前前三章执行链能否同时做到：

- 第一章信息负担低，读者先看见顾长川、他的淘汰风险和眼前机会；
- 核心能力第一次使用用普通话讲清楚：看见别人完整使出一招，自己可以完整借用一次；
- 第一章保留真实翻盘，第二章把偶然优势变成主动目标，第三章进入公开竞争；
- 每章有新的阶段状态、关系 / 资源 / 身份变化和必要的社会反馈；
- 不把后三章写成“危险 → 判断 → 借招 → 解决”的同一场戏。

本轮追加的正文最高优先级是“立即理解”：事实先于比喻，因果显式，主语和对象少省略，能力先给大白话模型，战斗先写局势变化。完整临时规则保存在 `READER_IMMEDIATE_UNDERSTANDING.md`。

## 为什么不使用序章

本实验先采用无序章分支。设定只要求读者理解“顾长川想变强、升院考核将至、他能借一次别人真正打出的招”，不需要先建立复杂世界模型。第一章直接从人物危机和武力差距进入，更能检验是否真的需要额外宏观开场。

如果正文证明无序章仍无法建立最低世界认知，这一轮只记录问题，不在本轮追加序章或重跑。

## 冻结范围

- 使用 `FIXED_CORE.md` 中用户明确给出的新小说设定；它是本实验的创作输入，不是生产规则。
- `BOOK.md` 只承载本次实验所需的总体设计和初始状态；不生成完整长篇 Future 10，不自由改写整本书。
- `CHAPTER_PLANS.md` 只冻结前三章的结构目标：第一章发现与第一次逆转，第二章主动谋划与关系 / 资源博弈，第三章公开竞争与社会身份变化。
- 只生成 Chapter 1—3；不生成 Chapter 4，不生成额外候选，不启用 Specialists、Integrator、Reviewer、评分器或自动改写循环。
- 不调用 GBrain，不使用《炉藏万象》、其它实验小说或来源文本作为正文参考。
- 不把顾长川、借招、青崖宗、升院考核等专属内容写入生产 Prompt。

## 执行链与调用边界

每章严格使用当前真实默认核心节点：

`Director → Curator → Primary Writer → State Delta`

三章共 12 次真实内容调用。为避免增加 Chapter Prep call，本实验把已经冻结的 Director 八字段 response 作为 Curator / Primary 的当前章执行合同输入；这是实验编排，不修改生产 runtime。每个节点一次调用，失败或内容不满意都保留 raw response，不重跑。

每次调用都保存完整 prompt 和 raw response。Primary response 只把 `# 正式正文` 派生到 `chapters/chapter-000N.md`；State Delta 只更新本实验副本的 `BOOK.md`。

## 只做必要审计

最终报告只核对事实和结构：三章是否完成、每章调用节点、能力兑现、主动目标变化、状态 / 关系 / 资源变化、重复故事结构、术语数量、工程式动作展开、社会反馈和连续性问题。不给正文数字评分，不自动重写。
