# 《借我一招》Opening Three Chapter 可读性验证报告

## 1. 实验对象与序章决定

实验对象是全新小说《借我一招》，不是《炉藏万象》的换皮：经典玄幻 / 宗门成长 / 武学战斗；主角顾长川，十七岁，青崖宗外门弟子，想留下宗门并变强；核心能力是近距离看见别人完整打出一招后，自己可以完整借用一次。

本轮没有使用序章。原因是本书当前需要的世界认知很少：读者只需知道强者存在、顾长川想变强、明日有升院考核，以及“看完整一招，自己能完整打一次”。第一章直接从考核前的具体门槛进入，更适合验证无序章是否已经足够清楚；本轮不为验证序章而机械添加。

## 2. 三章实际发生的事情

### Chapter 1：发现与第一次逆转

顾长川在升院考核前接受最后一轮补试，必须把三百斤试石推出白线，否则明天不能上台并会被分流。周既明完整打出回澜掌，试石越线但因铁架松动滚向宁秋禾封存的考核名册。顾长川没有第二次观看机会，却直接明白自己可以把刚才完整看见的一招完整打出一次；他复现回澜掌，把滚石推出白线，保住名册和自己的明日候考资格。

实际状态变化：顾长川仍没有永久武技，回澜掌用过即消失，右肩、胸口和手臂受伤；宁秋禾把他从待分流栏改入候考栏；周既明从轻视变为防备；顾长川形成主动目标：明日考核前主动寻找值得借的招、合适的出招对象和交换观察机会。

### Chapter 2：主动选招与关系 / 资源博弈

顾长川没有再等别人出招，而是根据伤势选择主要靠腿腰换位的招式。他向宁秋禾询问机会，宁秋禾拒绝临时私斗、免费观招和泄露底牌，只同意见证一次自愿、完整、受控的示范。周既明拒绝完整重打并用假动作试探。顾长川选择候考弟子许照，用自己看懂的回澜掌力路换取许照一次完整的回身卸力步示范；顾长川只观察，本章不使用。

实际状态变化：顾长川获得明日可完整调用一次的临时回身卸力步；许照获得应对周既明的具体信息，两人形成有条件交易而非同伴；周既明开始重新安排公开考核的出招时机；名册和升院结果尚未改变。

### Chapter 3：公开竞争与身份变化

升院考核公开开始，规则是取台心合格牌并带回自己的白线，不要求击倒对手。周既明主动点名顾长川，利用力量、经验、位置和伤势占优，并用假动作封锁观察。顾长川没有提前消耗唯一借招；周既明为守住合格牌而真实正面进攻时，顾长川才使用一次回身卸力步，把来力带到侧后方，取牌并用普通步法回到自己的白线。

实际状态变化：裁判宣布顾长川本轮公开升院考核合格，宁秋禾把他的名字登记进公开升院合格名单；他取得内门报到和后续资源竞争的行动空间，但尚未正式入内门、尚未完成报到、尚未分配资源。回身卸力步用后消失，伤势仍在；周既明成为公开竞争者；许照确认顾长川守约但两人仍不是同伴；旁观者不再默认顾长川必然淘汰。

## 3. 结构核对

- 主动目标变化：留下宗门并变强 → 明日考核前找合适招 / 对象 → 用信息交换获得一次合适借招 → 在公开规则下把唯一借招转成升院合格资格。
- 核心能力第一次出现：用普通话清楚成立。Chapter 1 直接写明“看完别人完整打一招，自己的身体可以照着完整打出一次”，同时明确用完消失、身体承受伤势；来源和远期原理保持未知。
- 重复故事结构：未发现三章重复为“危险 → 判断 → 借招 → 打赢”。三章分别是补试救场、关系交换 / 受控观察、公开取牌竞争。
- 新造术语：没有大量新增机制术语。主要专属招式名只有“回澜掌”“回身卸力步”；二者都先通过动作和结果成立，再使用名称。
- 工程式动作展开：未发现明确的工程说明式展开。战斗和示范写了决定结果的脚步、转胯、带力、越线、取牌、回线，普通路程与重复动作被压缩。
- 社会反馈：三章均有结果后的反馈。宁秋禾改候考资格，周既明改变态度；许照确认交易边界，周既明调整策略；第三章由裁判、宁秋禾、许照、周既明和旁观者共同确认公开身份变化。
- 连续性：未发现明确连续性错误。伤势、借招消耗、许照守约条件、周既明防备、候考到公开合格的阶段变化均能从前章 State Delta 承接。
