# 正式正文

白塔第七层的门缝里透出一线白光。

光不亮，却把塔前的石阶照得像落了一层霜。门里先传来三下敲击。

笃。

笃笃。

二、一、三。

江临的手指立刻收紧。

宁青梧站在石阶下，右手垂在身侧。那根红绳从她掌心垂下来，少了一个结，绳尾被风吹得轻轻碰在她腕骨上。

她没有看门，只看着江临。

顾槐生从城墙方向快步走来，甲胄上带着灰，肩后还有未散的烟气。他先看了一眼门缝，脸色沉下去，随即挡在江临侧前方。

“不能进。”他说，“城东的人还没撤完。你留下。”

江临抬眼：“你让我留下守城？”

“现在不是计较这个的时候。”

“那是什么时候？”

顾槐生的嘴唇绷得很紧。他没有回答，只转头望向远处城门。那里火光摇晃，人影不断往内城跑，喊声隔着半座城传来，听不清具体内容，却能听出乱。

白塔里的敲击又响了一次。

笃。

笃笃。

江临盯着那道门缝，声音很平：“第七层重开，你带人撤离，我进塔。”

顾槐生回过头，目光落在他脸上。

“那是以前的约定。”

“以前的约定不是约定？”

“江临，外面比塔里更需要你。”

“所以你就替我改？”

顾槐生的眼神一沉：“我是在让你活着。”

江临笑了一下，笑意很淡。

“我进不进去，什么时候轮到你替我决定了？”

石阶旁的火盆忽然爆开一串火星。宁青梧抬手挡了一下，红绳从她指间滑过去，缺口正对着白塔的门。

江临看见了，目光停了一瞬。

宁青梧终于开口：“里面的声音，你听出来了。”

“听出来了。”

“你觉得是他？”

“我只知道，这个顺序只有他用过。”

宁青梧没有点头，也没有否认。她把红绳攥回掌心，问得很轻：“那你还要进？”

江临看着她：“你回来，是为了让我别进？”

“不是。”

“那是为了什么？”

宁青梧沉默片刻。

“我不知道你进去以后会看见什么。”她说，“我也不知道这根绳子为什么会在这时候有反应。”

她说得很直接，没有替自己找更完整的答案。江临望着她手里的红绳，心里那点逼问的念头反而压了下去。

不知道就是不知道。

至少她没有用一个编好的理由，把他推去该去的地方，或者拦在不该停的地方。

塔门里的白光忽然往外一涨。

门缝比刚才宽了一点，露出里面半截黑石台阶。台阶上没有人，只有更深处传来的回声。

笃。

笃笃。

这一次，敲击声很轻，像敲在一面旧镜的背后。

顾槐生伸手按住江临肩膀。

力道很重。

“留下。”他说，“我不能让你进。”

江临低头看了一眼那只手。

顾槐生没有松开。

城外忽然传来一声闷响，像有什么东西撞上了城墙。塔前的石面震了一下，远处有人大喊：“北墙破了！”

顾槐生肩背一僵，手却按得更紧。

江临抬手，握住他的手腕，慢慢把那只手从自己肩上拿开。

“北墙破了，你该去那里。”

“你——”

“你答应过，带他们撤。”

顾槐生盯着他，眼里的怒意几乎压不住：“你拿一句旧话逼我？”

江临松开手。

“不是我逼你。”他说，“是你先把那句话扔了。”

顾槐生的脸色变了。

这一刻，塔外的喧闹、远处的火光、白塔里断续的敲击，全都像隔了一层。他们之间只剩下那句曾经说出口的话。

顾槐生可以继续拦他。

江临也可以强行越过去。

可顾槐生没有再动。

他站在原地，拳头一点点攥紧，甲片碰出低沉的响声。

“你进去，”他说，“外面的人怎么办？”

江临看向城中奔逃的人群，又看向门内黑石台阶。

“你在。”

顾槐生呼吸一滞。

江临没有再解释。他转向宁青梧。

宁青梧的眼眶有些红，却没拦他。她只是把那根缺一结的红绳抬起来，递到他面前。

江临没有接。

红绳还在她手里，绳尾被门里的白光照得发亮。

“它该在谁手里，你自己决定。”江临说。

宁青梧的手停在半空，随后慢慢收回去。

她看着他，忽然问：“如果里面不是他呢？”

江临踏上第一阶石阶。

“那我进去看看，是谁在学他敲门。”

白塔的门开始收拢。

顾槐生猛地上前半步，像要抓住他。江临已经跨过门槛，反手按在内侧石壁上，转身看向塔外。

宁青梧站在石阶下，红绳缠在手腕上。

顾槐生站在更远一点的地方，身后是冒着烟的城墙，脸上的灰被白光照得格外清楚。

“顾槐生。”江临说。

顾槐生抬头。

“城别丢了。”

门缝只剩一人宽。

顾槐生没有回答。他咬着牙，转身朝北墙奔去。

宁青梧没有跟上江临。她站在原地，直到门缝缩成一线，才抬起手，用红绳的缺口对着那道即将合拢的光。

塔门彻底关闭。

外面的声音一下断了。

江临站在第七层的黑石台阶上，四周只剩白光和潮湿的冷气。

前方深处，又传来三下敲击。

笃。

笃笃。
