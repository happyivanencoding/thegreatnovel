# HUMAN SEED CANDIDATE 1｜季衡／把名字钉在纸上

## 世界中的初始位置与成长环境

季衡出生在河谷小城的契书户。父亲替乡绅、商户和军府小吏抄写税契、地契与借据，母亲经营一间卖纸墨和晒药的小铺。家里不贫寒，却始终没有真正属于自己的田，也没有能让人高看一眼的身份。

他识字早，熟悉印章、见证、地界和账目，却没有正式师承。家里人希望他继承父亲的手艺，安稳地替别人把话写成凭据。

## Formative Facts → Adaptation → Observable Behavior

- 父亲年轻时替一户农人抄过土地转让契，因为原始契书遗失，最后被双方同时指认为骗子 → 季衡误以为口头承诺和多年情分都不可靠，只有能被追溯的凭据才算数 → 他替人办事时总要留下副本、见证和时间顺序，哪怕因此得罪急着成交的客户。

- 母亲曾收下一批来路不明的药材，病人出事后，供货商凭一枚伪印逃脱责任 → 他学会先追查东西从哪里来，再判断它值不值得用 → 他买旧货、接手遗物或替人鉴定时，会先找原始记录，宁愿错过便宜货，也不愿接受“大家都这么说”。

- 他曾花掉家中半个月的进项，替一个已经死去的佃户追回一份被水泡烂的旧契 → 他发现自己无法容忍一段真实经历被一笔勾销 → 对于无人争夺的旧账、旧地界和被改写的家谱，他会持续追查，直到确认自己手里有足够证据。

## 当前私人欲望

“我不想一辈子替别人写他们的田、他们的债、他们的身份。我想有一块地，契书上写的是我的名字，谁来查都抹不掉。”

## Core Obsession

他想把一切容易被人改口、抢走、否认的东西，变成自己能够掌握的确证。

最初是土地和家产，后来会扩大到商路、血缘、旧案、继承权、地图和人与人之间的承诺。东西越大，他越想知道它真正属于谁、谁有资格证明、谁在故意留下空白。

## Excess｜哪里过量

他已经有足够的钱买一间小铺，却把积蓄全部拿去收购一批被虫蛀的旧账册，只因为其中几页可能证明一座荒废渡口的归属。

普通人会认为那些账册不值得冒险，他却愿意因此推迟婚事、得罪客户，甚至亲自去找已经搬走几十年的见证人。

## Behavior Signature

面对高价值机会，他先问“东西真正属于谁”，而不是先问能赚多少。

受到羞辱时，他很少当场争辩；他会记下对方说过的话，寻找能让对方无法抵赖的证据。

面对恐惧，他会把风险拆成凭据、见证、退路和损失上限；关系逼迫他表态时，他不会轻易说“我相信你”，而会要求对方留下某种可以承担后果的承诺。

重大损失发生后，他不会立刻报复，而会先查清楚自己究竟在哪一个环节失去了证明权。

## 重要关系原点

- 父亲季文安：只想守住这门不显赫但能养家的手艺，不愿儿子去碰地方势力的旧账。季衡想证明父亲一生替别人保存凭据，却从未保存住自己的位置。两人都认为对方正在把家拖进危险里。

- 妹妹季兰：想嫁进城里，获得一份不用看账房脸色的生活。她认为哥哥把什么都变成证据，连亲情也变得难以相处。她可能需要季衡帮她查清一桩婚约，却不愿接受他因此掌握自己的秘密。

- 盐商沈百川：想通过季衡找回几份旧契，稳住一条盐运支线。沈百川愿意给他身份和钱，却要求他替自己把某些事实写得“更方便解释”。两人都需要对方，却无法接受对方对事实的处理方式。

## 人物钩子

别人争一块地时，他不急着站队，先冒雨跳进河里捞出一卷烂掉一半的原契；捞出来后，他发现契书对自己也不利，却仍然当众照实念完。

读者会记住：这个人不是靠嗓门和拳头证明自己，而是会为了“不让真实被抹掉”，把本来能安稳过完的日子主动变复杂。

# HUMAN SEED CANDIDATE 2｜冯渡／先拥有一条船

## 世界中的初始位置与成长环境

冯渡出生在海港外的船户区。父亲是替商会修船的木匠，母亲替水手缝补帆布，家中没有城籍，只能依附不同商队接活。冯渡从小在船坞、潮沟和货栈之间长大，认识木料、绳结、潮汐、船工和码头规矩，却没有接受完整的文字教育。

他见过太多人把性命交给一条船，却连那条船的半成所有权都没有。

## Formative Facts → Adaptation → Observable Behavior

- 父亲修好一艘商船后，商会以“途中损坏”为由扣掉大半工钱 → 冯渡学会手艺只有在货物、船契和分成中留下位置才算真正属于自己 → 他接活时总要争取材料采购权、维修记录或货运份额，不愿只拿一次性的工钱。

- 他少年时跟船出海，船队遇上妖兽迁徙，船主先保自己的货，把几名临时水手留在后船 → 他误以为被雇佣的人永远是最先被舍弃的那批 → 他后来会优先修船、买备用绳索和掌握退路，却不愿把生死交给一个只会说“照规矩办”的船主。

- 他曾用母亲准备给自己成婚的积蓄，买下一艘被判定无法远航的旧船 → 他第一次拥有了可以自行决定去哪里的东西，也第一次承担了不能转嫁给别人的亏损 → 从那以后，他会把挣来的钱优先换成船具、货舱、航图和码头份额，而不是改善眼前生活。

## 当前私人欲望

“我不想再替别人把货送到岸上。我想有一条自己的船，船往哪里走、装谁的货、挣来的钱进谁的口袋，都由我来定。”

## Core Obsession

他追逐的不是单纯的远方，而是让每一次移动都变成自己的资产和筹码。

一条船之后是第二条船、稳定的泊位、属于自己的货源、不会轻易断掉的航线，以及一支愿意跟他出海的人。只要他还在替别人承担风险，他就会觉得自己没有真正走远。

## Excess｜哪里过量

旧船已经能维持近岸运输，收入足够让他在城里买屋成家，他却把所有积蓄投入一条更破的远洋船，只因为那条船曾经走过一条如今无人愿意承担风险的航线。

他可以连续数月睡在船坞，宁愿让母亲继续住漏雨的旧屋，也要先买下一个能让船队在风季停靠的废弃泊位。

## Behavior Signature

面对高价值机会，他先计算自己能留下什么：船份、货份、航权、港口关系，或者一个以后无法绕开他的节点。

受到羞辱时，他不会急着证明自己有本事，而会把对方拒绝给他的条件，变成下一次谈判中对方必须付出的价格。

面对恐惧，他会保护能让自己继续移动的东西；面对关系压力，他不承诺“我一定带你走”，只会问对方愿意拿什么赌在这条船上。

重大损失发生后，他不会停船休整太久，而会立刻寻找下一件仍能归自己所有的东西，仿佛只要手里还有一部分航行权，就还没有真正输掉。

## 重要关系原点

- 母亲冯柳：想让儿子拥有一间靠岸的铺子，结束船户随时被赶走的生活。她愿意卖掉自己的船工工具帮他一次，却无法接受儿子把整个人生继续押在海上。

- 老船长段七：想保住自己在港口的名声和一条稳定的商队路线。段七看中冯渡的修船本事，却要求他永远做最可靠的副手。冯渡需要段七教他真正的航路，却迟早会把段七视为自己必须超过的人。

- 货栈女掌柜韩青禾：想扩大自己的药材货源，不愿把生意绑在任何船主身上。她和冯渡彼此提供稀缺资源，也彼此防着对方把临时合作变成长期占有。

## 人物钩子

港口所有人都把一艘搁浅旧船当废木头，冯渡却先去找它的船契；确认船契无人继承后，他用三个月替债主跑最差的货，换来船身一半的所有权。

读者会记住：他不是想“闯荡天下”，他想让每一段冒险最终在账面上、船身上和自己的生活里留下无法被别人拿走的部分。

# HUMAN SEED CANDIDATE 3｜魏执／我要让别人按我的判断活下来

## 世界中的初始位置与成长环境

魏执出生在一户普通军户家庭。父亲曾在城防营负责粮秣和伤员转运，母亲经营军营外的小食摊。家里有军籍，却没有修士背景，也没有足够的战功换来真正稳固的田地。

魏执识字不多，却熟悉队列、粮道、伤亡登记和军府里如何把责任推给一个最没有靠山的人。他不崇拜英雄，只相信一件事：在真正出事的时候，谁有资格下令，谁就决定谁承担代价。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾因上级改动粮车数量而被罚，明知不是他的错也无法申辩 → 魏执学会了“没有决断权的人只能替别人承担结果” → 他在任何集体行动中都会主动确认谁下令、谁承担、谁能改变计划。

- 他第一次带一小队人押送伤员时，按照老兵经验绕开危险路，却在半途遇到更大的妖兽迁徙，最后只能丢下部分物资 → 他误学会不能把命交给“大家都这么做”，必须自己判断最坏结果 → 他后来宁愿被骂擅作主张，也要在行动前重新查看地形、粮水和撤退方向。

- 他曾因抢先承担一次错误决策，被长官当众称为“自作聪明的军户子” → 他发现承认责任并不会自动换来尊重，只有让结果逼别人承认自己 → 他开始主动争取那些成败清楚、旁观者足够多的差事。

## 当前私人欲望

“我要有一次，所有人都知道该不该走、该不该守，最后只能听我的。事情办成以后，他们不能说是上头安排的；事情办砸了，也不能把我推出来顶罪。”

## Core Obsession

他想不断扩大自己能够作出关键判断、并让别人愿意把性命交给这个判断的范围。

他追逐的不是官位本身，而是从一队人、一座营寨、一段粮道，逐渐进入更大局面中的决定位置。地位越高，能被他改变的结果越多，他就越难接受只做一个执行命令的人。

## Excess｜哪里过量

他已经获得一个安全的文书职位，只要熬几年就能换到稳定俸禄和一块军田，却主动申请去接手一支装备最差、每逢归潮都缺人的巡逻队。

不是因为他想救谁，而是因为那里的结果足够清楚：只要他判断错一次，所有人都会知道错在什么地方。

## Behavior Signature

面对高价值机会，他会选择能让自己真正承担结果的位置，而不是看起来最体面的升迁。

受到羞辱时，他不会立刻动手，而会把对方逼到必须接受自己判断的局面里。

面对恐惧，他先确认能牺牲什么、必须保住什么；面对关系压力，他不会许诺“你不会死”，只会给对方一个明确的位置和撤退条件。

重大损失发生后，他会反复重建当时的决策顺序，既不轻易自责，也不允许别人用一句“运气不好”结束讨论。

## 重要关系原点

- 父亲魏川：只想攒够军田和退籍的功劳，让儿子离开军府。魏执认为父亲一生都在替别人承担后果，却从未争取过真正的决定权。父亲则认为儿子把“能下令”误当成了活着的资格。

- 老兵周魁：想用多年经验换一个不再上前线的位置。他愿意教魏执如何让疲惫的人继续听令，却不愿接受一个年轻军户取代自己成为队伍真正的依靠。

- 军府文吏许闻达：想把魏执培养成一把敢担责、好控制的刀。魏执需要许闻达提供调令和记录上的支持，却清楚对方真正想要的是一个替自己背锅的人。

## 人物钩子

一次押运中，上级给出模糊命令，所有人都等着别人先动。魏执当众撕掉原本的路线图，指着三条路说明哪一条会丢货、哪一条会死人，然后要求所有人先听完他的判断，再决定是否跟他走。

读者会记住：他最危险的地方不是敢拼，而是他真的想让别人把命交给他的判断，并且愿意为这种资格承担别人不愿承担的后果。

# HUMAN SEED CANDIDATE 4｜林问川／不接受“大概”

## 世界中的初始位置与成长环境

林问川出生在山城的一间民间伤药铺。父亲会辨药、接骨和处理妖兽伤，母亲负责收账和照顾病人。家境比普通农户好，却没有正式医籍，也没有宗门师承，只能靠口碑与药材商维持生意。

他从小见过很多人因为买不起高阶药材、找不到真正懂病的人，最后只能接受“命不好”“伤太重”“再熬几天”这种解释。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾按祖传经验救治一名商队护卫，病人短暂好转后突然恶化，最后没人说得清究竟是哪一步出了问题 → 林问川学会了“有效一次不等于知道为什么有效” → 他会记录药量、时间、饮食和症状变化，不愿把成功归功于祖传，也不愿把失败归咎于命数。

- 一位富商为家人买走铺中最好的药材，普通病人只能使用便宜替代品 → 他看见药材、身份与判断权如何互相影响 → 他后来会把稀缺药材留给最需要的人，但收费时极其强硬，认为穷人可以欠账，却不能让掌握资源的人白拿他的判断。

- 他曾为一个并不亲近的病人追查旧病历，耽误了自己参加城中医馆考核的机会 → 他逐渐把“弄清一个人究竟怎么坏掉的”视为比眼前机会更重要的事 → 任何未解释的症状都会在他心里留下未完成的账。

## 当前私人欲望

“我想知道一个人到底为什么会坏掉，然后让真正有钱、有身份的人也得来问我，而不是随便找个名医开张贵药就算了。”

## Core Obsession

他追逐的是对身体和病因越来越细的判断权，并希望把这种判断变成别人无法绕开的价值。

他不会满足于治好一批病人。治病越多，他越想建立自己的记录、方法、病例和声誉；见过的病越复杂，他越无法容忍任何人用一句“差不多”替代真正的答案。

## Excess｜哪里过量

他已经能靠处理常见伤病稳定挣钱，却会花掉一整月收入，去购买一名陌生死者留下的病历和药方，只因为那人的症状与自己曾经误判的一例相似。

遇到没有报酬的疑难病，他会连续数夜守在病床旁，甚至错过最赚钱的出诊，只为了确认病情究竟在哪个环节改变。

## Behavior Signature

面对高价值机会，他先看能否接触完整过程和真实记录，而不是只看报酬与名声。

受到羞辱时，他不会急着证明自己医术高明，而会追问对方是否愿意让自己的判断接受复盘。

面对恐惧，他会把恐惧转成观察、记录和试验；关系逼迫他直接给出保证时，他往往会让人不舒服地听见风险，而不是说一句让人安心的假话。

重大损失发生后，他不会把失败包装成无可避免，而会追查每一个被忽略的细节，即使最后证明自己确实无能为力。

## 重要关系原点

- 父亲林守拙：想守住祖传药铺，不愿儿子把普通伤药铺变成承担巨大风险的疑难医馆。林问川认为父亲靠经验活了一辈子，却留下了太多无法解释的病案；父亲则担心儿子会为了答案耗尽自己。

- 药材商女儿许青禾：想接管家中药材渠道，证明自己不只是替父亲跑账的女儿。她能给林问川稀缺药材，却要求他把病例和配方变成可交易的东西。两人彼此需要，也都担心对方把知识变成控制自己的筹码。

- 年轻学徒赵平：想学一门能快速赚钱的手艺，将来开自己的铺子。他崇拜林问川追根究底的本事，却无法接受师父为了一个答案放弃眼前收益；赵平迟早会面对“先救人还是先弄清楚”的选择。

## 人物钩子

前三章里，他治好一个伤势不重的富家子弟，却拒绝收下对方送来的名贵药材，转身去买一个普通脚夫失败的旧药方。

理由很简单：富家子的伤为什么会好，他已经知道；脚夫为什么会死，他还不知道。
