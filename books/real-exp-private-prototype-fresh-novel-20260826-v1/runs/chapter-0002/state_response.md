# Proposed Active Scene State

当前地点：霜泽边缘、向石槽倾倒的空心冰柱南侧裂冰面
在场人物：裴听岚、岑照、雪角羊群、桑令仪及两名景猎团成员、低阶霜兽、被困石槽下方的人
即时伤势：裴听岚右手脱下手套，掌心被寒气刺至发麻；无人明确重伤
手中关键物品：裴听岚左手手套与旧斗篷；岑照的赶羊长杆；景猎团成员的发光短刃
当前敌人或追兵：低阶霜兽守在破裂冰柱旁，持续逼退景猎团
当前倒计时：空心冰柱正在向石槽倾倒，最后窄路持续收窄
下一步直接目标：在冰柱压垮石槽前救出下方被困者，并设法脱离
当前主动目标：救出石槽下方的人

# Proposed Persistent Canon

- 裴听岚仍无正式修炼能力，但能感知冰层内部风压与空腔。
- 裴听岚首次将风压凝成巴掌大的白色落点，并在离手后持续留存、推动冰层。
- 该落点目前力量微弱，只能缓慢松动、推开堵塞物，尚未证明具备战斗能力。
- 空心冰柱已破裂，低阶霜兽从中出现并与景猎团交战。
- 石槽下方确认有人被困，冰柱正向石槽倾倒。
- 岑照仍在控制失控羊群，裴听岚与她共同面对冰柱坍塌危机。

### Active Relationships

岑照｜护送羊群并撤离｜与主角关系亲近、共同承担危险｜持续呼喊裴听岚撤退｜共同脱离冰柱区
桑令仪｜击退霜兽并寻找未知物品｜与主角尚无明确关系｜注意到裴听岚留下风之落点｜未决是否介入救援

# Proposed Chapter Summary

冰柱破裂后，一头低阶霜兽冲出并逼退景猎团，失控羊群堵住退路。裴听岚听见石槽下方有人求救，借掌心感知冰中风压，首次将风留在冰面形成持续转动的白色落点，松动了石槽上方的冰层。但空心冰柱随即向石槽倾倒，他必须在撤离与救人之间作出选择。

- 温泉旧池黑石的后续去向。
