# 主观审计｜real-exp-private-prototype-fresh-novel-20260826-v1

> 审计方式：`tgn-system-steward v0.1.3` 方法 + 当前 ChatGPT 独立复核。本文只记录本书暴露的质量问题，不自动升级为 production 规范。

## 总结

**人物与场景比上一版更鲜活，但设定创新被写成了术语创新与机制复杂化。** 读者需要先学习一整套“景”词汇，才能理解本来很简单的力量与地点；Core Fantasy 有潜力，但早期兑现太克制，长期仍主要是同一能力扩数量和距离。与顶级男频相比，最大差距是：**先要求读者理解世界，才允许读者爽；而顶级男频通常先让读者懂、馋、震惊，再逐步接受世界。**

## 主要问题

1. **World 术语过载。** `景息 / 天景 / 景相 / 成景 / 镇景 / 死景 / 景谱 / 景器 / 景地 / 景猎团 / 落景` 同时出现。多数概念可以直接用灵气、风雷霜火、功法、兵器、遗迹等既有认知表达。创新应优先放在规则和故事，不放在重新命名普通概念。

2. **Reader Onboarding 失败。** “下次进泽”本身不是错，但正文没有先让读者牢固知道“霜钟泽就是镇外那片巨大冻湖/冰泽”。人物已经像本地人一样说话，读者却还没有成为本地人。原则应是：**先给大白话可用含义，再允许专名缩写。**

3. **机制解释过度。** “冰层开裂—空心冰柱—水下死景—南移—热水脉—羊道”把一个简单危机包装得过于复杂。前期只需让读者清楚：**冰湖出事，巨大冰柱压向镇子，水源被堵，羊群被困。** 原因和深层机制可以以后再揭。

4. **金手指有潜力，但不够直接、不够震惊。** 去掉术语后，能力其实很好懂：**别人离开后力量会散；主角可以把力量留在碰过的东西上，自己走远后仍继续发动。** 但前几章只兑现成“一小股风慢慢推冰/石头”，缺少强者尺度反馈和“正常高阶修士也做不到”的震惊感。

5. **复合成长仍未真正成立。** Story Program 仍主要是 `1个落点 → 3个 → 7个 → 数十个 → 数里`。功法、兵器和环境主要只是落景载体，还没有形成“核心异常 + 新功法 + 新能力 + 兵器/传承”互相复合、最终支持稳定越级的独有战斗体系。

6. **Supporting Logic 再次抢戏。** 第4章重新出现引水管、转轮、铜管、铁箍、螺栓、钳子和“你会修，所以就该你修”的设备维修剧情。这与本书作者方向明确要求“不回到工程 ontology”冲突。最早问题已在 Outline / Director 出现，Writer 只是展开执行。

7. **长期 shock 有进步，但仍偏世界秘密。** 折月峡“以为是古代残影，后来发现是尚未发生的雁脊关现实”属于有效 delayed recontextualization，值得保留；但仍缺少足够强的“为什么裴听岚偏偏能这样”的主角级长期秘密。

## 最早根因

优先级：**World Vision → Power → Story Program → Outline / Director → Writer**。

- World 最早创造了高认知成本的自造词族。
- Power 继承该词族，并把可直接理解的能力重新包装成抽象术语。
- Story Program 没有真正把核心异常扩展成复合能力栈。
- Outline / Director 再次让维修等 supporting logic 成为一整章的主要内容。
- Writer 有表达层责任，但不是系统根因。

## 应保护的部分

- **Human / Character 继续有效。** 裴听岚、岑照、桑令仪的私人欲望和关系牵引明显比传统功能型人物鲜活。
- 前三章的冰湖、冰柱、羊群、霜兽和救人，比上一版更像真正的男频冒险场景。
- “力量留在本人离开的地方继续发动”这个核心机制值得保留，只需大白话化并增强早期 shock。
- 折月峡未来残影的长期重释方向正确。

## 建议的深层原则

**新颖优先发生在规则、组合、冲突和后果；普通概念优先使用读者已有词汇。只有当新名词承载了现有词无法准确表达、且值得长期记忆的新概念时才命名。第一次出现时：先懂，再命名。**

例如不要先写“景息凝成景相后可以落景”，而应先让读者知道：

> 修士能驾驭风雷霜火，但人一走，力量通常就会散。裴听岚却发现，自己可以把力量留在碰过的东西上。

之后如果世界里确实需要，再告诉读者这种异常后来被称为“落景”。
