# STORY PROGRAM

## 核心碰撞

- 裴听岚即使始终没有落景，也会想离开温泉镇，去听陌生声音、进入陌生空间，让真正有分量的人记住自己。他对新鲜、注目与身体吸引的追逐不会自动变成修炼使命，也会让他错过稳妥位置、低估长期代价。

- 落景让他能够把力量留在自己已经离开的地方，这极其适合展示、冒险与临场改动，也会诱使他把战场铺得过大。落点越多，本体越弱；他最享受众人发现“那里也是他的力量”时，恰恰也是最容易被人突破本体的时候。

- 岑照要保住自己养出来的羊群，并决定自己什么时候离开。姜鹤野要救妹妹，沈长汀要保住裂霜宗，谢停云要在王命之外迁走雁脊关百姓，桑令仪要亲自飞进天幕裂口。他们不会因为裴听岚拥有落景就改换人生目标。

- 岑照能让他放弃已经到手的远行机会；桑令仪会让他为了一个更危险、更漂亮的去处继续向前。前者不是故乡的象征，后者也不是自由的化身。她们具体的身体、脾气、选择与是否在场，会分别改变他的去留。

- 他渴望被看见，却未必喜欢被定义。公开展示落景会带来景谱、兵器、挑战与名声，也会招来宗门收编、军府征用和针对介质的反制。他会主动争取目光，随后又因别人试图决定他该怎样使用力量而翻脸。

## 全书成长与核心幻想兑现脊柱

1. 霜钟泽的风穿过空心冰柱时，裴听岚第一次凝成“鸣风景”。声音经验只帮助他辨认风压变化，不是力量来源。他起初无法像普通修士那样把景相稳定维持在身周，只能在手掌接触的冰面上留下一个持续数息的风压点。以前他只能听见石门后有人呼救；此后他能先把风落在门轴上，自己绕去另一侧，再让门轴从无人处猛然转动。

2. 得到基础景谱并完成正常引息修炼后，他能在身周十余丈成景，同时维持三处落景。落点可以留在刀、石阶或兽角上，以碰撞、绳断或他主动收紧景息触发。以前他必须站在敌人面前出手；此后他能把敌人逼过一块石阶，自己正面退开，再由背后的石阶把人掀回刀前，足以独斗数名引息武者或一头低阶荒兽。

3. 在折月峡的月白石环境中，他学会收回尚未耗尽的落景，并把它从相接的旧介质转入新介质。他能让鸣风从插入崖壁的短刃转入刚刚撞上的飞钩，再沿连续接触的岩面改变方向。以前他无法追上会踏空换位的宗门天才；此后他能让七处落点接续发力，在自己尚未抵达时封住对方落脚处，也能进入没有完整道路的峡壁深处。

4. 经历两年角兽迁徙与荒野战斗后，他晋入开域，能把数十处落景维持在一座关城的墙面、兵器、车轮与地面上。只要介质真实相接，鸣风便能形成一段延迟推进的连续过程。以前他最多改变一场小队战斗；此后他能让已经无人守卫的城门自行闭合，让一列翻倒的车轮依次滚开，为数千人争出撤离时间，并能拖住镇景强者而不是被其一击压垮。

5. 进入天幕裂口后，他达到镇景层次，能把鸣风沿数里内的浮石、断墙、飞舟、锁链与冰层展开。以前裂口中一次断层便会切断他的力量；此后他能先把景相送过一连串漂移实体，令远处建筑先行转向、兵器先行出鞘、碎冰先行合拢，身体最后才沿已经形成的风路抵达。空无介质之处依旧无法落景；敌人一旦击碎关键接触面，整段风路便会断开，而大规模布景仍会使他的本体明显衰弱。

## 不可替代的人与关系

- **岑照**想保住自己养成的羊群，也想有一天离开温泉镇，但她不要裴听岚替她决定何时走、去哪里。换一个同样熟悉雪地和羊群的人，裴听岚不会为其失去内城学徒位置，也不会在已经取得折月峡深入资格后折返。她的沉默、冻红的手、咬开绳结的动作和不肯给承诺的方式，会让他留下，也会让他因得不到回答而故意走得更远。

- **桑令仪**是独立景猎团的滑翼手，想拥有一艘真正属于自己的天景航具，并亲自穿过天幕裂口最低处。她欣赏裴听岚敢在现场改动计划，却不会替他的任性收尾。另一个同样优秀的飞行者可以运送他，却不能替代她带来的身体吸引、竞争欲，以及两个人都想第一个看见陌生空间的私密默契。她会使他延长冒险、暴露落景，甚至放弃已经可以带回去证明自己的战果。

- **姜鹤野**只想让妹妹活下来。他愿意教裴听岚基础修炼，也愿意欺骗、利用甚至把追兵引向温泉镇。换一个老师可以教同样的景谱，却不能替代这笔带着人命、欺瞒和共同逃亡的旧账。裴听岚既欠他第一次真正修炼的办法，也不会原谅他曾把岑照的羊场当成脱身路线。

- **沈长汀**要追回双景谱，避免裂霜宗因争夺继承权而分裂。他是第一个在实战中看懂落景弱点的人，会主动击碎地面、弃用金属兵器、把战斗推向无处着力的开阔空域。他与裴听岚的敌意不是天生克制，而是数次交手后学出来的；两人也会因为姜鹤野妹妹的生死短暂站在同一边。

- **谢停云**早在认识裴听岚之前就决定违令迁民。他需要的不是一个听命的年轻修士，而是有人在守军撤走后仍敢承担第三座烽台。裴听岚一直想被有分量的人记住；谢停云给予他的第一次公开承认，却会同时把“弃关同谋”的罪名压到他身上。

## 长期故事主线

### 阶段1｜霜钟初落

**为什么现在发生：** 霜钟泽南部的冰层提前开裂，一组原本固定在湖中的空心冰柱随水下死景缓慢南移，堵住温泉镇的热水脉，也压坏雪角羊场唯一的冬季通路。桑令仪所在的景猎团赶来抢在冰柱崩毁前取走其中的风浸石。裴听岚既需要工钱，也不愿错过这群真正去过远方的人。

**谁想要什么：** 裴听岚想挣到离镇的钱，并让景猎团中真正懂天景的人听见自己；岑照想在道路彻底封死前把羊群转到高坡；桑令仪想取走风浸石，修好自己的滑翼；镇上管事只想保住公共浴屋的热水脉，不在乎羊场是否被截断。

**主角的关键选择与行动：** 裴听岚放弃替浴屋守设备的稳妥工钱，跟着岑照进入冰柱区。冰柱倒塌时，桑令仪只能正面挡住冲出的低阶霜兽，他却在接触冰面的瞬间凝出鸣风景，并把第一处落景留在倾斜石槽上；他本人去拉被困的人，风压随后从无人处推开堵门巨石。他没有把唯一机会用来追赶正在撤走的景猎团，而是先替岑照打开羊道。

**这一阶段真正的阅读满足：** 一个被判定没有修炼资格的人，第一次让自己的力量在本人离开后继续发力；霜钟泽、成景修士、低阶荒兽和天景航具同时把小镇之外的力量尺度摆到他眼前。

**Stage Delta：** Power / Capability：裴听岚凝成鸣风主景相，只能留下一个持续数息的接触式落点。Relationship：桑令仪记住了他，却认为他不懂珍惜机会；岑照看到他真有离开的可能，反而开始避开关于将来的谈话。Identity / Access：景猎团允许他在下一次进泽时同行。World State：冰柱崩塌露出一条被封多年的地下旧道。

**下一阶段为何自然发生：** 姜鹤野正借霜泽掩盖行踪，地下旧道让他直接出现在温泉镇附近；追来的沈长汀不可能绕开刚刚显露异常的裴听岚。

### 阶段2｜被追杀者的路

**为什么现在发生：** 姜鹤野需要穿过霜泽前往两日岭，采到能暂时稳定妹妹景相的双照花。沈长汀沿他留下的霜景追到温泉镇。姜鹤野闯过羊场时引来追兵，岑照的冬棚被双方交手毁掉一半。

**谁想要什么：** 姜鹤野要带双景谱抵达妹妹身边；沈长汀要在宗门其他人赶来前追回景谱；裴听岚想得到一套真正能让自己继续修炼的基础景谱，也想借这条路离开小镇；岑照要把两名修士和他们的恩怨赶出羊场。

**主角的关键选择与行动：** 裴听岚没有接受沈长汀以钱换线索的提议，而是要求姜鹤野用基础风景谱支付带路费用。他利用三处落在石阶、木橇和断刀上的鸣风制造假路线，却在发现姜鹤野准备把追兵引向羊群后强行改道，宁可暴露自己也不让岑照替他们承受后果。面对追上的沈长汀，他不替姜鹤野证明正确，只承认自己已经收了报酬并决定把人送到两日岭。

**这一阶段真正的阅读满足：** 裴听岚第一次把落景用于完整战斗，让追兵同时遭到来自身后石阶、侧面断刀与正面本体的攻击；他也真正拿到基础景谱，从一次偶发现象走上可持续修炼之路。

**Stage Delta：** Power / Capability：他稳定进入引息后段，能同时维持三处落景，并以碰撞或断绳触发。Possession：取得一套裂霜宗外传的基础风景谱，内容只够修炼鸣风景，不包括双景谱。Relationship：他与姜鹤野形成带着欺瞒的债务关系；沈长汀不再把他视作无关路人，并在第二次交手中学会优先破坏落景介质；岑照没有挽留，只告诉他羊场不会永远等他回来。Identity / Access：桑令仪因旧道一战邀请他加入景猎团的散修队，参加秋季百景争鸣。

**下一阶段为何自然发生：** 裴听岚终于得到离开温泉镇、进入折月峡并被各宗门看见的机会；姜鹤野和沈长汀也都必须去那里寻找失传雷霜叠景留下的完整记载。

### 阶段3｜折月照见他人之战

**为什么现在发生：** 百景争鸣如期举行，各宗门争夺折月峡深处的进入资格。姜鹤野需要峡中遗刻确认双景谱能否救妹妹，沈长汀则要证明被带走的谱本并不完整。桑令仪想取得一块足够打造景刃的月白石，并试飞峡谷上方多年无人穿过的夜空带。

**谁想要什么：** 裴听岚要在众人面前赢一次，并亲眼看看正午仍有夜空的峡谷；桑令仪要月白石和一条能让她扬名的飞行路线；姜鹤野要妹妹活下来；沈长汀要带回完整真相，避免宗门为了残谱继续内斗；几家宗门想独占失传的雷霜叠景。

**主角的关键选择与行动：** 有宗门愿意保送裴听岚进入下一轮，条件是他把落景说成一件一次性景器的效果；他拒绝隐藏，当众用七处落点击败正面力量高于自己的弟子。进入折月峡后，他没有沿最安全路线追逐名次，而是与桑令仪攀入会显现陌生战斗的月白石区。姜鹤野与沈长汀争夺遗刻时，他既不替任何一方抢谱，也不准他们以桑令仪的滑翼作为逃走工具。

**这一阶段真正的阅读满足：** 落景第一次成为公开、鲜明、可被强者记住的战斗方式；折月峡的另一片夜空、月白石幻见和悬崖追逐兑现了真正值得进入的玄幻地点。

**Stage Delta：** Power / Capability：裴听岚能维持七处落景，并将尚未耗尽的鸣风从相接旧介质转入新介质；他能沿短刃、飞钩和崖壁连续换向。Possession：他从月白石区夺得一柄尚未淬成的月白短刃，并立即用它承载鸣风、穿过断崖。Identity / Access：多个宗门确认落景属于他本人，他得到深入折月峡一次的资格，也同时进入军府和宗门的招揽名单。Knowledge：峡中遗刻显示，所谓双景谱原本由两名修士交替承受反噬，并非让一人安全占有两景；姜鹤野与沈长汀必须合作才有机会救人。裴听岚还在月白石中看见一名陌生将军站在青雷下，说出“第三座烽台已经空了”，所有人都把它当成古代残影。Relationship：桑令仪亲眼看见他为了一场陌生景象放弃更高名次，对他的兴趣从招募变成了竞争与身体吸引。

**下一阶段为何自然发生：** 裴听岚刚取得继续深入折月峡的资格，来自荒原的商队却带来消息：岑照没有撤回温泉镇，而是带着羊群加入阿卢的角兽迁徙队伍，正被王朝军队当作牧族同谋围堵。

### 阶段4｜羊群不回故乡

**为什么现在发生：** 草场干涸迫使阿卢驱赶沉睡角兽穿过王朝耕地。岑照发现温泉镇附近已无法长期养活羊群，主动以熟悉热泉和寒地草料为条件加入迁徙队伍。王朝军队准备烧掉迁徙路线前方的草场，逼角兽群转向牧族营地，却会同时烧死岑照的羊群和沿途村民的冬粮。

**谁想要什么：** 岑照要让自己养出的羊活着抵达新草场，不肯被裴听岚带回已经养不起它们的温泉镇；阿卢要让角兽群穿过王朝边境；当地军将要以最小兵力挡住兽群，保住自己的城；裴听岚要找到岑照，也想证明自己这次回来不是为了替她做决定。

**主角的关键选择与行动：** 裴听岚放弃尚未使用的折月峡深入机会，赶上迁徙队伍。他没有要求岑照离开，而是公开站到她选定的路线一边，因此失去一家宗门已经递来的入门位置。他把落景留在领头角兽的旧角、峡谷石面和羊群木铃上，引导受惊兽群转入更险的黑土沟；这条路救下两座村落，却仍使大片军粮田被毁，也让不少牧族牲畜死在沟中。

**这一阶段真正的阅读满足：** 数万角兽在起伏草原上改道的世界奇观；裴听岚已经赢得向上机会，却会为了一个具体的人承担并不带来升级的损失。

**Stage Delta：** Relationship：岑照接受他同行和靠近，两人在迁徙前夜有了第一次真正的身体亲密，却没有因此约定共同生活；第二天岑照仍选择跟着羊群走，裴听岚也没有放弃自己的远方。Identity / Access：王朝把他列为协助牧族毁田的嫌犯，宗门撤回入门邀请；牧族与沿线平民则开始传唱他从无人处转动木铃、带走角兽群的战斗。World State：角兽群避开两座城，却撞断了通往雁脊关的一条军粮道，朝廷只能从东境守军中抽人补缺。

**下一阶段为何自然发生：** 雁脊关兵力被抽走时，九夜青雷继续向关城扩张；谢停云决定提前撤民，朝廷则派督军逼他守城。桑令仪的景猎团受雇运送百姓，裴听岚沿迁徙线抵达关外，再次遇见她。

### 阶段5｜九夜弃关

**为什么现在发生：** 两年的迁徙、护路与荒野战斗后，裴听岚已经完成开域前的正常修炼。九夜青雷抵达雁脊关外，停留在地面的雷柱每天向城墙逼近。谢停云私撤守军、疏散百姓，朝廷督军却封闭城门，准备以城中人口证明关城仍可死守。

**谁想要什么：** 谢停云要在雷原吞没关城前迁走最后一批百姓；朝廷督军要保住“雁脊关未失”的事实，哪怕必须留下百姓；桑令仪要用修好的滑翼舟穿过雷柱上方，把被困者带出城；裴听岚要让迁徙路上认识的人活着离开，也想亲自踏入九夜青雷看看鸣风景能承受怎样的真实天象。

**主角的关键选择与行动：** 裴听岚公开承认自己帮助谢停云撤城，主动把军府追兵引到第三座烽台。他认出折月峡月白石中见过的城墙、伤痕和那句话，知道自己站进了那场“古代残影”，却没有照着残影等待结局，而是提前把落景铺进城门轴、废弃兵器、车轮和烽台石缝。镇景督军击穿他的正面风域时，他让数十处鸣风依次发动，空城的墙面、刀枪和车辆同时转动，为百姓打开最后一条撤离线。

**这一阶段真正的阅读满足：** 落景从小范围奇招成长为一座关城里同时存在的战场力量；折月峡的旧异象突然与眼前现实严丝合缝，原本被当作古代残影的战斗变成尚未发生的真实一夜。

**Stage Delta：** Power / Capability：裴听岚正式开域，能让数十处落景沿连续介质形成延迟风路，足以拖住镇景强者并改变关城攻防，但无法正面击败对方。Possession：月白短刃在承载整座城门的鸣风后碎裂，他保留三块仍能放大景相的刃片。Identity：谢停云当众承认他守住了撤离线；朝廷同时将他定为弃关同谋。Knowledge：月白石显现的并非单纯古战，而可能是天幕错位后泄露出的其他地点、其他时刻。Enemy State：军府与宗门开始针对落景拆毁地面、弃用连续甲阵，并选择无物可落的开阔空域作战。World State：雁脊关被青雷吞没，数万百姓存活，王朝再也无法完全隐瞒东境失控。

**下一阶段为何自然发生：** 祁无咎确认裴听岚见过尚未发生的战斗，停止销毁最后几卷相关天幕图并派人找他；同一时期，天幕裂口下降到可由天景航具抵达的高度，桑令仪先一步驾舟进入后失去音讯。

### 阶段6｜身体最后抵达

**为什么现在发生：** 雁脊关失守使星位偏移不再能被观天院压下。天幕裂口下缘出现大量漂移的宫墙、冰层和碎裂山体，各国、宗门与景猎团同时准备进入。祁无咎要在战争爆发前确认裂口究竟连着什么；桑令仪为了成为第一个穿过下缘的人，未等各方封锁便独自起航。

**谁想要什么：** 祁无咎要带回足以判断世界变化、却不会立刻引发各国争抢的证据；桑令仪要越过此前所有飞舟止步的位置，并决定自己的航路；王朝与几家宗门要夺得裂口内第一座稳定落脚地；裴听岚要找到桑令仪，也要亲眼确认自己在折月峡看到的那些战斗究竟在哪里发生。

**主角的关键选择与行动：** 王朝愿意撤销弃关罪名，条件是他交出月白刃片并替军府先行布景；他拒绝，和祁无咎的队伍进入裂口。找到桑令仪后，他本可带着完整星图返回、得到全天下都无法忽视的名声，却因桑令仪发现一座正在漂离的真实古城而继续深入。他把鸣风落在浮石、断墙、飞舟锁链、碎冰和敌人的景器上，让力量沿这些不断碰撞的实体先行跨越裂口；当争夺者以为他仍在远处时，刀、墙、舟和冰层已经同时成为他的出力点，他的身体最后才踏入完成的风景。

**这一阶段真正的阅读满足：** 传奇状态的落景第一次完整兑现——看不见裴听岚，整片实体战场却已经属于他的鸣风；折月峡的异战、古代天幕图与雁脊关未来残影获得震撼但可回看的统一解释，而世界其他未知仍然没有被一并解释掉。

**Stage Delta：** Power / Capability：裴听岚进入镇景，能沿数里内真实相接或持续碰撞的介质展开鸣风景；他仍不能把力量悬停在裂口虚空中，关键介质被毁后整段风路会断，本体也会因大规模落景而显著衰弱。Relationship：他与桑令仪确认彼此不是临时同伴，却都拒绝为关系放弃自己的去处；她会在他想带人返回时继续向前，他也会在她只顾飞行时强行改变航线。Knowledge：折月峡月白石会接到天幕裂口中不同地点、不同时间的真实光景，“不属于自己的战斗”并非幻觉；这解释了部分星位错乱，却不能解释死景迁移、无源天灾和相隔万里的同夜雷声。Identity / Access：裴听岚成为第一个从裂口深处活着返回、又能再次沿旧落景进入的人，各方不再只想招揽他，而开始争夺、监视或切断他接触的介质。World State：天幕裂口由遥远禁地变成各方可以真实进入的新天地，第一轮探索已经改变宗门、军府和景猎团的力量判断。

**下一阶段为何自然发生：** 漂移古城仍在向裂口更深处移动，桑令仪留下了继续追逐它的航迹；岑照和阿卢的迁徙队伍正在寻找不受星位偏移影响的新草场；沈长汀带来的消息则表明，姜鹤野妹妹虽然活了下来，双景反噬却开始以过去从未记录的方式转移。裴听岚已经被天下听见，但他仍要决定下一次把力量先送到哪里，身体又愿意为谁随后抵达。

## 远期仍值得追的东西

- 岑照能否找到真正属于自己的草场，她与裴听岚之间没有被一次亲密或一次分别定型的关系，以及她是否会在他不回来时建立完全不同的生活。

- 桑令仪想得到并驾驭一艘能长期穿行天幕裂口的航具；她可能与裴听岚同行，也可能因争夺第一次抵达某地而成为最了解他弱点的竞争者。

- 姜鹤野妹妹活下来后的自主欲望、沈长汀是否仍愿承担另一半双景反噬，以及裂霜宗会如何对待一套必须由两个人互相信任才能成立的景谱。

- 温泉旧池中那块被管事拿走的黑石去了哪里。它可以只是一件被低价卖掉的值钱奇物、一笔迟来的旧账或通向某个买家的线索，不必成为裴听岚力量来源和世界终极秘密。

- 死景为何会在主人死后迁移，相隔万里的景地为何出现同夜雷声，以及少数无源天灾究竟模仿了什么；这些问题不必与天幕裂口共享同一个答案。

- 裴听岚以镇景之力面对真正天灾强者的场面：敌人主动摧毁桥梁、兵器和地面，把战场打成无物可落的空域；他必须在本体最弱时亲自夺回一块能让整片景相重新接续的真实介质。

- 他已经获得最初渴望的注目，却仍未拥有一种不会迅速变成重复生活的活法。名声、爱情、修炼、远行与回返会继续彼此争夺他的时间，不由核心力量替他作答。
