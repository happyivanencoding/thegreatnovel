# Protocol

- Fresh world: no reuse of prior private-prototype novel world/power/character.
- World is protagonist-blind.
- Power and Human are generated independently after World approval.
- Human uses explicit anonymous prototype selector `prism-wanderer-alpha`; no private source text.
- Power selector sees only World Power Baseline + three anonymous Power candidates.
- Character is deterministic Power/Human composition; no Character Composer.
- Story Program is first full Collision (Sol high).
- Outline/chapters use current production prompts and model routing.
