# Atomic Chapter Obligations｜Boundary Specification v0.3

> Status: Experimental. This specification defines what the compiler may prove; it does not authorize production adoption.

## 1. Purpose

Atomic Chapter Obligations are deterministic, typed obligations compiled from Frozen Chapter Mission, Reader Release, Canon, Power, Human, Curator and Primary evidence. They validate a locally edited final draft. They are not prose instructions, chapter quotas, a second creative plan, or an LLM classifier.

```text
Frozen Authority
    ↓ deterministic compile
Atomic Obligation Pack
    ↓
Primary Draft → Luna-high Paragraph Delta → local patch apply
    ↓
Deterministic Gate
    ├─ all hard/triggered obligations close → candidate may be considered
    └─ any fail / unsupported / source conflict → Full Luna-high Reviser
                                                    ↓ gate again
                                                residual failure may still stop
```

## 2. Authority and identity precedence

For the current protagonist identity:

```text
Current Frozen Mission explicit actor
> explicit current Primary fallback when Mission is generic
> remote Human / Book fallback
```

A stale Human Seed or previous prototype name may not override the actor explicitly named in the current Mission. Primary fallback is allowed only when the Mission is generic and the name is explicit; behavior style is never enough to guess identity. Nearby pronouns cannot repair an explicit conflicting name.

For facts:

```text
Occurred Canon
> Frozen current Mission / Reader Release / Power / Human authority
> Curator attention projection
> Primary realization
> optional inspiration
```

A true source conflict fails closed; the compiler must not choose the “most reasonable” version.

## 3. Obligation modes

| Mode | Meaning | Absence in final text |
|---|---|---|
| `terminal` | Must be true by chapter end | hard failure |
| `pending` | Must remain future/open/deadlined | premature completion may fail; repeated wording is not required |
| `conditional` | Required only when the named trigger is proven | no trigger → not applicable |
| `must_remain_unknown` | The answer may not be revealed | no repeated “unknown” wording required |
| `preserve_if_present` | Valuable Primary material may not be erased when its paragraph/category is touched | no requirement to add new value |
| `diagnostic` | Source inconsistency, missing context or unsupported clause | true conflict fails closed; benign diagnostic does not |

## 4. Core boundary families

### 4.1 Actor → Action → Object

The actor, action and object must bind in one bounded action domain. A protagonist body cannot replace a clone; one named ally cannot perform another ally’s action. A nearby pronoun cannot cancel an explicit wrong actor. Long-distance keyword co-occurrence is not closure.

### 4.2 Result / State / Ending

`can`, `may`, `prepares`, `qualifies`, `creates a basis`, `is about to` and `must do before a deadline` are not terminal completion. Direct Result, State Change and Ending are separate obligations even when they share nouns.

### 4.3 Negation and intention

Negated or planned action does not count:

- `没有交出原册` is not transfer;
- `还没有上车` is not departure;
- `准备付款` is not payment;
- `正要突破` is not breakthrough.

Positive terms must be outside a bounded negation/intention prefix.

### 4.4 Ownership / possession / copy

Ownership title, physical possession, usage right, custody and copy transfer are distinct. `原件` and `副本` may not collapse. Transfer binds at sentence/action level so adjacent paragraphs cannot falsely merge `主角收好原件` with `官员带走副本`.

### 4.5 Resource and money lattice

At minimum:

```text
received ≠ entitlement ≠ pending ≠ lost ≠ disputed
```

A quotation, contract, voucher or settlement basis cannot be upgraded to received property.

Additional boundaries:

- `首笔 / 第一笔 / 一部分 / 折付 / 暂付` cannot satisfy a full terminal settlement;
- partial receipt closes only when Frozen Authority explicitly authorizes partial fulfillment;
- when Authority gives no amount, a newly invented amount fails;
- when Authority gives an amount, the same amount and unit must be preserved;
- entitlement or份额 cannot be rewritten as cash in hand.

### 4.6 Time

A deadline is a boundary, not an event. `下一次低潮前出发` remains pending unless the current Mission explicitly requires departure now. Relative time must bind to the current source, not generic `第一次 / 下一次` words.

### 4.7 Power

Separate:

- stable power position;
- battle-scale output or pressure resisted;
- temporary composite effect;
- usage condition / cooldown;
- public ruler / knowledgeable calibration.

Defeating or resisting a higher scale does not automatically change stable rank. `再次使用前必须散尽残压` is a cooldown; it does not mean residual pressure must already be zero at chapter end unless explicitly required.

### 4.8 Public Proof

A hard Public Proof requires all three:

1. visible performance by the bound protagonist on the bound power / object / result;
2. a qualified ruler or knowledgeable calibrator;
3. behavioral repricing: quote, admission, recruitment, hostility, registration, pursuit or changed treatment.

The triad must describe the **same performance and topic**, in a bounded performance → ruler → consequence sequence. Three unrelated paragraphs cannot be assembled into proof. Repricing an unrelated horse or commodity does not prove the protagonist’s power.

Public Proof never authorizes an unapproved stable tier.

### 4.9 Reader Release

Only explicitly scheduled facts are hard first-release obligations. Require one clear realization; do not require repeated explanation or unscheduled encyclopedia material.

### 4.10 Relationship state

Only the explicit state transition is required, such as:

- master/subordinate → equal paid cooperation;
- cooperation → public break;
- a named debt or trust state established.

The transition must bind to the same named counterpart. Cooperation with a road inspector cannot satisfy a Mission transition involving the young master. Same-scene `你 / 我` may bind; cross-scene pronoun stitching may not.

### 4.11 Unresolved fact versus source conflict

`must_remain_unknown` blocks unauthorized answers, old history, culprit identity or mechanism certainty. It does not require restating that the fact is unknown.

These are normally unresolved boundaries, not conflicts:

- `不得补写 / 不应据此推断 / 保持未知`;
- missing detail that the chapter is explicitly forbidden to invent;
- missing recent summaries used only for repetition diagnostics.

A source conflict requires two Authority statements about the same time, holder, actor, result, presence or terminal status that cannot both be true. `无明确权威冲突，但某人是否到场未知；不得补写` must not fail preflight as a conflict.

### 4.12 Human cue

A cue is conditional on:

1. the named person/relationship;
2. the specific contact, treatment or private trigger;
3. approved Human authority.

Generic “make characters human” is not atomic. Untriggered attraction, scent, body contact or intimacy may not be inserted.

### 4.13 Protected commercial value

Use `preserve_if_present` for:

- protagonist desire and possession;
- relationship tension;
- reward / ownership;
- Public Proof and social repricing;
- surprise / discovery turn.

These are not per-chapter quotas. They protect Primary material only when Delta touches the relevant paragraph/category. Surprise cannot be replaced by ordinary “he checked the object”; the reversal or unexpected discovery itself must remain.

## 5. Locality and global closure

A local patch may be adopted only when:

- all hard and triggered obligations pass;
- no true source conflict or unsupported clause exists;
- ownership/resource/power/time state is globally consistent after the patch;
- nonadjacent dependent paragraphs are updated together;
- deletion does not erase protected commercial value;
- the patch parser applies exactly to the intended paragraph range.

Local correctness is not enough when a later paragraph still asserts the opposite state.

## 6. Fail-closed cases

Use Full Reviser when any of the following occurs:

- unknown actor identity or explicit actor conflict;
- unsupported world-specific mechanism;
- true source conflict;
- ambiguous original/copy or resource status;
- power transition cannot be distinguished from battle scale;
- current Ending is pending but source timing is unclear;
- patch modifies too wide a span or leaves a dependent later state unresolved;
- the compiler cannot map natural language to a typed validator.

Coverage is not a goal if it requires guessing.

## 7. Full fallback is not automatically safe

Historical Full Reviser output is shadow control, not a safe gold label. After fallback, the full draft must pass the same Atomic Gate. If it still fails, the route is `FULL_REVISER_RESIDUAL_FAILURE`; it must not silently save merely because the expensive model ran.

## 8. Calibration policy

- Hand-constructed boundary unit tests measure safe/unsafe semantics.
- Historical mutations measure known-bad recall, not precision.
- Historical Full Reviser output is shadow control, not gold.
- Real routes require final Reader and Authority blind.
- Sparse stochastic routes require independent repeat and cross-book evidence.
- Fallback-adjusted wall includes Delta, discarded output, Full fallback and residual repair.

## 9. Domain coverage boundary

v0.3 still uses a bounded Chinese male-fiction vocabulary and typed grammar. It must preflight fail closed when:

- new-book names, powers or objects are outside the compiler’s supported grammar;
- Mission actions require long-range semantic inference rather than explicit actor-action-object;
- multi-actor, multi-stage or cross-scene handoff cannot be deterministically split;
- Authority itself conflicts or a required current fact is missing.

Cross-book fail-closed is safer than false adoption, but it also means the current compiler is not production-general.

## 10. Current non-goals

v0.3 is not authorized to:

- replace Director / Curator / Full Reviser;
- infer arbitrary new worlds from synonyms;
- decide prose quality from obligation closure alone;
- use an LLM classifier as the adoption gate;
- productionize from one world or four selected chapters.
