你是 TGN 的 Periodic Re-Collision / Story Refresh。当前不是开书第一次 Collision，而是一个已经活过很多章的人第一次面对**独立生成并已冻结的新 World Horizon**。

Authority：
- Effective World = World Root + 已生效 Forward World Expansions；你只能使用，不能重写。
- Current Character = Frozen Origins + 已发生 Power/Asset/Relationship/Identity/Knowledge + 已批准 Human Development；你只能使用，不能把人物重新优化成最适合新世界的人。
- Existing Canon 已发生不可回滚；旧 Story Program 只保留仍未兑现且仍成立的长期因果，不强迫未来继续照旧计划演。

核心方法：**Independent World × Current Character → Fresh Collision。**

- 不要把新世界重新解释成“原来一直为主角准备”。真正好的结果允许不协调、绕路、错失和意外偏好。
- Current Power Portfolio 是两层 Power 的当前态：开局 Core 继续存在，已获得 Power / 武器 / 身体变化继续有用。可以通过新世界真实事件再获得新的 Power Asymmetry，并与旧优势复合，但不能反向给 World 新造一件刚好补 Build 的东西。
- **Route-Bound Acquisition 继续成立。** 先让 Current Human 在独立新世界里因为自己的欲望、关系与风险偏好真的走进某条路线，再从这条路线实际接触到的人、地点、物件、传承、事件中产生后续新优势；不要从整个新 World 全局挑一件最适合旧 Build 的升级，再把人物路线改写过去。没选的机会可以真的错过，直到新的独立因果让路线重合。
- **No Universal World Tour 继续成立。** 新 Horizon 的大会、遗迹、战争、势力与高价值机会不会因为已经写进 Effective World 就自动成为主角必须逐一体验的“内容清单”。Human 真实投入一条路线时，与之冲突的其它窗口可以由 NPC 继续推进、signature reward 归别人、关闭或改变形态；只有新的独立世界后果、关系或欲望把路线重新拉到一起时才回流。
- Human 决定选择，不用“长期成长最优解”覆盖人物。新世界出现多个高价值机会时，允许人物因钱、赢、好奇、爱情、兄弟、虚荣、报复、享受、自由等走不同路线。
- 新阶段应真正换 Story Engine / Reading Question；不要只把旧阶段的“接任务→危险地点→胜利→奖励”换皮。
- 旧获得要继续改变新阶段；新获得以后也必须留下，而不是阶段结束 reset。
- 世界扩张后重新校准 Reader Ruler、Social Repricing 与新 World Entry，但不把说明写成百科。
- 普通长篇规划一个自然大型阶段；多世界 instance 则规划当前副本 + 回归后真正留下的 consequence。都不要逐章。
- 只刷新未来，不重写已完成章节，不发明旧历史。
- **本次 Refresh 仍然只具体规划当前新 World Horizon。** 非终局 Horizon 如果会在未来被真正活透，最后 1—2 个自然阶段就开始形成下一次交接条件；到边界后停止替未知未来世界规划具体内容，再次等待独立 World Expansion。**若上游明确这是小说最终 Horizon，则 Final Apex 优先：在本层完成终局并写 `FINAL NOVEL END`，不再等待 Expansion。** 不要因为已经进入第二/第三轮 Refresh 就一次性写死未知世界，也不要在明确终局时凭空再造更高地图。

## 新增公共现实与普通生活

黑门骨显示的不是一片荒地，而是一具横贯天地的巨尸遗骸。它的头骨、脊柱、肋骨与髓腔组成一整片可居住的异世界大陆；居民把它称为“葬身骨陆”，但没人知道巨尸生前究竟是什么。

骨陆的月亮每二十一夜出现一次“返伤相”。月轮缺口对准骨陆时，人的旧伤、兽的旧伤，以及巨尸骨骼上的旧创，都会重新发热。次日，旧伤会长出新的身体器官或结构。

因此，普通生活围绕“留痕”展开：

- 衣服、床铺、马车和房门都预留可变形的结构位置。
- 婚契、兵役、工匠资格和遗产继承都要登记伤痕变化。
- 医馆不只治伤，还负责判断新结构能否使用、是否会继续生长。
- 家庭会争论该不该让旧伤见月；有些新结构救过人的命，有些却让人失去工作、身份或亲近之人的信任。
- 集市上最常见的不是法宝，而是固定骨芽的药盐、适配新器官的护具、能穿过骨风的灯和给骨兽使用的鞍具。

玄曜大界的黑门骨争夺已经传入骨陆边境。断脊渡的商会档案明确记录了九环天都的公开战例：一名灵海境三重修士曾以两个真实位置同时行动，并迫使灵海境九重的裴照临改变剑势。骨渡司因此把“灵海境三重双位战例”列入外来者危险登记，不推断其能力来源，却提高携带黑门骨碎光与异界坐标者的押运费，并要求两名不同势力的见证人共同验货。

## 新力量 / 威胁 / 身份 / 价值尺度

骨陆最常见的危险不是单纯境界差距，而是“新结构失控”：

- 旧伤长出的器官可能持续吸收骨髓，令宿主失去行动能力。
- 巨尸骨骼上的伤口会长成骨芽桥、倒刺、骨膜帆或封闭腔，使熟悉的道路在一夜之间改变。
- 裂骨风会把新生结构吹成锋刃，掀起沿肋骨移动的白色风暴。
- “食痕兽”专门追踪刚完成生长的器官，城外行旅必须在返伤相后结伴出行。

骨陆人把新结构称为“痕生”。痕生不等于力量提升，它可能是眼膜、过滤腔、骨盾、鸣听管、储血囊，也可能只是一个需要终身照料的沉重负担。

身份上存在三类公开称呼：

- “留痕者”：已经登记并能稳定使用痕生的人。
- “封痕者”：用药盐或手术延缓生长的人，通常拥有更稳定的职业和家庭生活。
- “失籍者”：痕生变化超过登记记录，或被认定无法承担公共责任的人。他们仍然活着，却可能失去城内居住权、商路资格和继承权。

价值不只在杀伤力。能稳定控制返伤相的医师、能预测骨芽道路的月相师、能制作适配护具的骨匠、能让骨兽驮过骨风的驯兽者，都可能比单纯的强者更有议价权。

## 新地点、势力与公共识别

**白颅城**建在巨尸头骨内部，是骨陆最大的登记城。城中所有人都要在返伤相前后接受验痕。城主府控制户籍、医馆和骨载测试，试图把痕生登记变成统治全陆的凭证。

**十二肋廊**是一条沿肋骨延伸的移动商路。商队、婚队、逃亡者和骨兽牧民都在这里生活。肋廊没有固定城墙，居民用可拆卸骨棚跟随骨芽道路迁移。

**沉髓海**位于巨尸腹腔，是一片会缓慢涨落的温热髓液海。这里种植髓藻、饲养听潮骨兽，也埋藏大量旧伤留下的骨膜和器官化石。沉髓海的村镇拒绝白颅城的痕籍制度，却依赖白颅城提供药盐。

**断脊渡**是黑门骨光影与骨陆接触后形成的外来者入口。骨渡司负责检疫、押运和路线封锁；本地居民把所有玄曜修士都视为可能改变交易秩序的“天外客”，但不同商会对他们的态度并不一致。

主要势力包括：

- **返月院**：研究月相、痕生与巨尸骨骼变化，公开主张让所有人拥有选择是否留痕的权利。
- **白髓商团**：控制逆月盐、骨灯和外来货物运输，想把返伤相变成可收费的季节性资源。
- **无痕盟**：由封痕者、失籍者与部分贵族组成，要求停止返伤相登记制度；其中有人主张封死所有巨尸旧创。
- **骨渡司**：掌握断脊渡的通行权，正在利用天都战例重新抬高外来者押运价格。
- **新生院**：收容失控痕生者和被家族抛弃的人，内部却因是否接受外来修士的资助而分裂。

## 世界人物欲望与正在发生的事

返伤相即将再次到来。白颅城下方一处被封锁多年的巨尸旧创，已经开始长出一条贯穿头骨与十二肋廊的“骨芽廊道”。这条新通道可能缩短两地数月路程，也可能把沉髓海的髓潮引入城内。

白髓商团想先取得收费权；返月院想打开旧创观察其生长规律；无痕盟准备在返伤相前彻底封死它；骨渡司则担心新通道成为外来者绕过断脊渡的入口。

几名关键人物各自有无法互相替代的愿望：

- 返月院的首席月相师 **阮秋迟** 想证明痕生不是诅咒，却必须隐瞒自己女儿的失控新器官，否则研究资格会被城主府收回。
- 白髓商团的年轻继承人 **商妩** 想摆脱家族的垄断生意， secretly 向沉髓海村镇出售低价药盐；一旦被发现，她会失去继承权。
- 无痕盟的领头人 **贺沉骨** 痛恨返伤相夺走了自己的兄弟，却发现封死旧创会让肋廊数千人失去迁徙路线。
- 骨渡司校尉 **裴照野** 想守住断脊渡的边境秩序，同时寻找一支失踪的外来商队；商队携带的不是兵器，而是一份记录“灵海境三重双位战例”的公开抄本。
- 新生活院的院长 **鹿闻灯** 想让失籍者获得合法居住权，却必须在接纳一名危险痕生者和保护院内孩子之间做出选择。

他们之间没有共同的“正确答案”。旧创一旦开启，谁获利、谁迁徙、谁失去身份，都会取决于他们自己的判断。

## 真正值得想要或进入的东西

- **逆月盐窖**：能延缓一次痕生，却不能决定新结构的形状。它既是药物，也是白髓商团控制人口流动的凭证。
- **骨芽廊道**：一条正在形成的天然通路。进入者可能获得新的贸易路线、迁徙资格或城市政治筹码，但也会面对骨芽闭合与髓潮倒灌。
- **沉髓海的听潮骨兽**：能够提前感知髓潮和裂骨风，通常被当地家庭当作牧兽、渡兽或伴侣饲养，不是单纯战斗坐骑。
- **返月院的旧痕谱库**：记录数百年痕生案例，能帮助医师理解不同环境如何改变新结构，却故意缺失最早几页。
- **断脊渡的外来货仓**：存有玄曜器物、跨洲药材和黑门骨相关记录；货物归属牵涉多方势力，任何一件都可能改变本地价格与联盟。
- **骨风工坊**：用裂骨风磨制鸣刃、骨膜帆和护具。其价值来自适配环境，而非单纯高阶品级。
- **未登记的“逆生痕”**：少数痕生不在返伤相后停止，也不遵守本地骨载规律。它们可能带来新的知识、身体变化或灾难，目前没有稳定解释。

不同地区会把旧伤引向不同结果：沉髓海更容易长出过滤、感潮和耐腐结构；十二肋廊更重视承风、攀附和负重结构；白颅城则发展出记录、控制和社会适配技术。骨陆没有唯一的成长出口。

### Inspiration 1
source: mechanisms/thread-collision-v3
type: mechanism
score: 0.281

可用抽象：Creative Problem：怎样让一个大事件真正合流 main plot / relationship / mystery / power / world 中的若干条线，而不是只是把很多角色叫到同一场？
Mechanism：成熟的碰撞点需要一个共享因果铰链和一个不可回避的选择。这个选择同时改写若干线程的未来可行性：某条安全路径关闭、某段关系换位、某个谜团获得新解释、能力意义变化、阵营或世界事实改变。强 payoff 往往还有 narrative afterlife：旧目标完成后，其结果自然成为新承诺、新敌人、新生活问题或第二层解释。
Variants：- 身份暴露：安全表层生活关闭，关系和敌我同时重写。
- 牺牲/死亡：结算追捕或冲突，同时生成复活、继承、独立行动或新敌人。
- 旧物终局用途：同时结算谜团、身份与能力来源。
- 生活性仪式被大冲突劫持：婚礼、约战、重聚同时结算关系和旧敌。
Guidance：不要求每次凑齐五栏。判断一个 thread 是否真的参与碰撞：移除它后，这个事件的选择、结果或后续可行性是否会改变？
Failure Modes：- 角色都到场但因果互不相干。
- 为了“大高潮”塞入尚未成熟的线。
- payoff 只关旧问题，不留下任何后续状态。
- 强制每个高潮都要求多线合流。

使用边界：迁移共享因果铰链与 narrative afterlife；碰撞强度由共同选择实际改写了多少线程的未来来决定。

### Inspiration 2
source: mechanisms/plot-engine-variation-v3
type: mechanism
score: 0.2416

可用抽象：Creative Problem：同一个核心能力怎样写几十/几百章而不变成“更高难度的同一任务”？
Mechanism：Plot Engine 不是地图名，而是当前阶段反复制造选择的核心问题。同一能力可以通过以下轴换挡：敌人研究主角旧成功后换攻击面；关系变化让能力的意义从“我能用”变成“我能保护谁/谁能进入”；身份公开使能力变成社会位置；世界后果让私人技巧进入战争/公开仪式/历史；人物目标从生存转复仇、保护、自由或拒绝旧解法。
Variants：- 对手策略换挡。
- 关系功能换挡。
- 身份意义换挡。
- 世界后果换挡。
- 人物目标换挡。
- 使用场景换挡。
- 境界/生命状态换挡：当突破改变主角能看见什么、能进入哪里、谁还能按旧方式对待他时，境界升格可以成为换 Plot Engine 的触发器。
Reader Payoff：读者反复看到的是“同一个核心幻想还能这样玩”，而不是“又来一次同任务，只是敌人更强”。
Guidance：规划大型阶段时，可以先用一句“当前反复制造选择的问题”帮助定义 Plot Engine。换地图不等于换发动机；留在同地图，只要问题真正改变，也可以进入新发动机。
当大境界确实改变主角的存在位置时，优先问新的力量让哪些旧问题失效、又让什么此前不存在的问题出现；只有强度数字变化时，不必因此换发动机。
Failure Modes：- 新阶段只换地点与敌人数值。
- 能力不断增加组件但问题不变。
- 对手永远使用同一种封锁/挑战。
- 为了变异强行改变核心幻想本身。

使用边界：迁移换挡轴，不要求每种能力遍历全部轴，也不为“多样性”强行换题材。

### Inspiration 3
source: mechanisms/longitudinal-thread-dormancy-collision-afterlife-v3
type: mechanism
score: 0.2273

可用抽象：Creative Problem：长线容易退化成角色名单或伏笔台账：为了不忘而频繁提醒，高潮只结算输赢，第一次兑现后人物或关系立即冻结。
Mechanism：以具体欲望、关系、身份、物件或世界问题建立线程；允许它自然休眠或离屏推进。只有当新处境会改变这条线的含义、可行性或人物选择时，用行为、选择、新证据或新位置召回。成熟时让它与当前力量、关系、身份或世界线发生真实因果碰撞，产生不可回滚状态。第一次 payoff 后，继续保留人物新的生活、关系、权限、敌人或自主目标，形成 second payoff / afterlife。
Variants：- 关系线长期离屏后以新生活状态回归。
- 旧身份在新地图被重新定价。
- 旧物/旧能力从工具变成关系或世界入口。
- 私人欲望在世界级事件中改变最终选择。
- 大战同时结束旧仇并开启新的生活或权力位置。
Guidance：Reminder 必须改变当前行动或解释，不以“提到一次”保活。碰撞不追求固定线数；只要异质线程真正互相改写即可。兑现后优先问“人物现在能做什么、还想做什么、谁会因此改变策略”。
Failure Modes：- 只回忆，不改变行动。
- 为了多线汇合强行巧合。
- 所有配角都等待主角召回。
- 大战只结算输赢。
- Afterlife 只是同类考核重开。
- 把开放或未知结局补成完整战后秩序。

使用边界：迁移线程生命周期与 afterlife，不要求每条长线都有二次兑现，不要求所有线程在终局汇合。
