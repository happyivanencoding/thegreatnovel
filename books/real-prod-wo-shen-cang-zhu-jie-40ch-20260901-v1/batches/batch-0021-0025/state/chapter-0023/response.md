当前敌人或追兵：折粮刀持续反抗；暂未见新的追兵  
当前倒计时：归锋夜还剩两夜  
下一步直接目标：将折粮刀带回黑砧城，开启分事炉

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 风髓双口可借荒风协同压制折粮刀，不能直接改变其旧事牵引。
- 双真共享元力、同步受伤；同时牵制折粮刀会显著加重骨口负担。
- 宁烬已接受黑砧城分事炉交易，准备从拆出的名兵中先选一柄。

### Active Relationships

岑非灯｜护住最后一袋旧粮并证明亡父不是逃兵｜与主角关系恶化但仍有共同事件牵连｜宁烬带走折粮刀并留下粮袋｜可能继续追索折粮刀与亡父证明。  
贺乌衣｜带折粮刀回黑砧城、赎回妹妹并保住炉火｜与主角暂时合作、互相利用｜共同夺刀成功并转向黑砧城｜需兑现开启分事炉及让宁烬先选名兵的承诺。

### Identity / Access

- 宁烬已取得进入黑砧城分事炉交易的实际资格，但尚未进入黑砧城。

### Knowledge / Enemy State

- 折粮刀已离开最后一袋旧粮，北向牵引暂时中断。
- 折粮刀仍会主动反抗被带往黑砧城。

### World State

- 折粮刀被宁烬与贺乌衣带往黑砧城，关外争夺的中心暂时转移。
- 归锋夜逼近两夜，黑砧城炉火与分事炉进入最后期限。

### Tracked Assets

折粮刀｜宁烬与贺乌衣｜前往黑砧城途中｜被锁链控制但持续反抗｜从岑非灯处明确带走。  
最后一袋旧粮｜岑非灯｜无主关外粮车残架旁｜袋口破损、黄米停止向北滚动｜折粮刀离开后仍由岑非灯持有。  
沾血旧木牌｜岑非灯｜最后一袋旧粮处｜仍未转移｜继续作为亡父身份证明。  
分事炉｜黑砧城｜黑砧城内｜尚未开启｜待宁烬与贺乌衣携刀返回。

# Proposed Chapter Summary

折粮刀挣脱粮车并继续北拖，宁烬与贺乌衣联手将其压入地面、锁住刀柄，最终带往黑砧城。岑非灯抱住最后一袋旧粮，却被留在原地；折粮刀离开后，粮袋停止向北滚动。归锋夜只剩两夜。

- 分事炉能否拆出折粮刀承载的三柄名兵，旧事将如何延续。
- 宁烬从拆出的名兵中先选择哪一柄，以及贺乌衣是否兑现承诺。
- 岑非灯能否凭最后一袋旧粮与旧木牌证明亡父不是逃兵。
- 折粮刀被带入黑砧城后是否会继续反抗或改变旧事牵引。
- 贺乌衣能否借折粮刀赎回妹妹并保住铸场炉火。
- 九百坟线是否会因折粮刀异动重新启动。
- 归锋夜剩余两夜内无主关将发生什么。
- 无主兵荒原的荒原兵序与续事阶究竟如何运作。
- 无墙宫殿及其连续门扉遵循什么规则。
- 宁烬下一次开启黑门骨会进入或带回什么。

- 宁烬三成盐路利润何时兑现。
