地点：无主关外黄沙土路  
在场人物：宁烬双真、岑非灯、贺乌衣及三名黑砧城成员

当前敌人或追兵：贺乌衣率黑砧城成员抢夺折粮刀  
当前倒计时：归锋夜还剩三夜  
下一步直接目标：判断是否介入折粮刀与最后一袋粮的争夺  
当前主动目标：查明无主兵荒原的力量规则与可利用之处

# Proposed Persistent Canon

### Power / Capability
Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 风髓双口仍可随身保留并在玄曜近距离导引风流，不能传送人或物。
- 双真共享元力、同步受伤，双端死亡风险仍在。
- 无主兵荒原公开力量尺为荒原兵序；续事阶代表未竟之事产生可复验进展，不能与玄曜九境九重直接换算。

### Active Relationships
岑非灯｜护送亡父留下的最后一袋粮前往不存在的北门｜与主角尚未建立关系｜当众拒绝贺乌衣让步｜是否继续护粮未决。  
贺乌衣｜将折粮刀带回黑砧城｜与主角立场未明但已构成现场争夺者｜率三名黑砧城成员现身抢刀｜是否强行夺刀未决。

### Identity / Access
- 宁烬作为外来者进入无主关，尚无当地身份或准入。

### Knowledge / Enemy State
- 折粮刀承载“送粮至北门”的未竟之事，会自行拖拽粮车向北。
- 北门已消失数十年；折粮刀继续北拖，可能牵动九百坟线。
- 黑砧城试图控制折粮刀。

### World State
- 无主关外存在承载未竟之事、会自行行动的兵器；其行动可能重新改变河流、村庄与坟地的旧战场格局。
- 归锋夜还剩三夜。

### Tracked Assets
折粮刀｜岑非灯暂持/被其拖拽｜无主关外粮车旁｜拖着半截铁链向不存在的北门前进｜贺乌衣准备夺取。  
最后一袋粮｜岑非灯｜粮车车板中央｜袋口磨破、黄米持续漏出｜随折粮刀向北拖行。

# Proposed Chapter Summary

宁烬开启黑门骨进入无主兵荒原，确认这里以荒原兵序衡量力量，续事阶取决于未竟之事的复验进展。无主关外，岑非灯护着亡父留下的最后一袋粮，折粮刀却拖车前往已消失数十年的北门。黑砧城的贺乌衣率人赶来夺刀，并警告九百坟线将被牵动。

# Proposed Open Promises

- 两处骨唇活口在玄曜大界能否稳定恢复并长期使用。
- 两处真身共享活口与同步受伤的长期代价。
- 折粮刀能否将最后一袋粮送到不存在的北门。
- 九百坟线是否会因折粮刀继续北拖而重新启动。
- 黑砧城为何必须夺取折粮刀。
- 归锋夜剩余三夜内无主关将发生什么。
- 无主兵荒原的荒原兵序与续事阶究竟如何运作。
- 黑门骨映出的无墙宫殿及其连续门扉遵循什么规则。
- 宁烬下一次开启黑门骨会进入或带回什么。
- 新通道与热髓泄口将如何继续改变骨陆运输格局。
- 商妩右肩骨甲与返伤相伤势能否恢复。
- 宁烬三成盐路利润何时兑现。
