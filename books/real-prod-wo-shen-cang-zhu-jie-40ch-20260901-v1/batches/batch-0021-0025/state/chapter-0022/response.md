# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重  
- 风髓双口可在两处真身之间导引荒风，能短暂偏转粮车方向，不能直接吹走粮车或传送人、物。  
- 双真共享元力、同步受伤，双端死亡风险仍在。  
- 荒原兵序中，续事阶可推动未竟之事产生可复验进展；与玄曜境界不可换算。  
- 黑砧城分事炉可暂时拆分兵器形状与其承载旧事；折粮刀可能被拆成三柄名兵，但旧事不会消失。

### Active Relationships

岑非灯｜护送亡父留下的最后一袋粮并证明亡父不是逃兵｜与主角仍未建立关系｜以沾血旧木牌触发折粮刀加速｜阻止任何人触碰折粮刀。  
贺乌衣｜夺取折粮刀带回黑砧城分事炉｜与主角暂时合作但互不信任｜提出宁烬先挑一柄拆出的名兵，并以砸毁铸炉作保证｜试图继续夺刀。  
贺乌衣的妹妹｜婚书被黑砧盟扣押｜与主角无直接关系｜贺乌衣明确以夺刀赎人｜去向仍在黑砧城。

### Identity / Access

- 宁烬作为外来者进入无主关，尚无当地身份或准入。

### Knowledge / Enemy State

- 折粮刀认岑非灯的血与其亡父留下的粮，继续拖车指向已消失的北门。  
- 折粮刀牵动的不只是道路，而是可能逼现实恢复已消失的旧地点。  
- 黑砧城需要折粮刀，原因包括赎回贺乌衣妹妹、解除铸场受制并赶在归锋夜前保住炉火。  
- 坟线守户、渡口与残盾队伍已因荒原各处旧事异动而行动。

### World State

- 折粮刀继续北拖已造成关外道路争夺与人员撤离，九百坟线及相关旧战场格局面临进一步牵动。  
- 归锋夜剩余三夜，黑砧城炉火与无主关秩序进入紧迫状态。

### Tracked Assets

折粮刀｜岑非灯暂持/被其拖拽｜粮车旁土路｜拖着最后一袋粮向北，已被横风偏转并遭铁钩短暂勾住｜贺乌衣仍在争夺。  
最后一袋粮｜岑非灯｜粮车车板中央｜袋口磨破、黄米持续漏出｜仍被折粮刀拖向北门旧址。  
沾血旧木牌｜岑非灯｜粮袋上｜触发折粮刀明显加速｜尚未转移。  
分事炉｜黑砧城｜黑砧城内｜可暂时拆分兵器形状与旧事｜尚未开启。

# Proposed Chapter Summary

贺乌衣提出用黑砧城分事炉拆出折粮刀承载的旧事，并承诺让宁烬先挑一柄名兵。岑非灯以旧木牌证明亡父不是逃兵，折粮刀骤然加速。宁烬双真借风髓双口偏转粮车，贺乌衣趁机夺刀失败，关外多方因旧事异动开始撤离或争夺。
