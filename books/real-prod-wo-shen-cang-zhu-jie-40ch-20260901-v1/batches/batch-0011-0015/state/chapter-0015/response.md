地点：巨尸旧创外侧骨地，北肋岔已闭合。  
在场人物：宁烬（双真）、商妩、车夫与三辆逆月盐车。  
即时伤势：宁烬元力近乎耗尽；商妩右肩旧伤彻底裂开，薄骨甲持续外撑。  
手中关键物品：黑门骨、海眼碎片、赤曜灯芯、储物戒。  
当前敌人或追兵：贺沉骨已夺走四辆盐车并封死北肋岔；白髓商团暂未追击。  
当前倒计时：返伤相只剩两夜；原北肋岔路线已失效。  
下一步直接目标：护送剩余三辆盐车穿过巨尸旧创，寻找通往新生院的路与商妩的生路。  
当前主动目标：护住商妩与剩余三辆盐车，抵达新生院。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 宁烬已证明可用白昼火快速烧断局部骨芽。
- 双真共享同一元力池；本章两具真身同时拉扯后元力近乎耗尽，短期内难以连续作战。

### Active Relationships

商妩（白髓商团验货人）｜带剩余三车盐继续求生并保住继承可能｜与宁烬为相互承担风险的雇佣合作关系｜宁烬放弃四车盐救出她，商妩因此失去商团支持｜需共同穿过巨尸旧创并处理返伤相。

### Identity / Access

- 宁烬仍是商妩雇佣的护运者。
- 商妩已被白髓商团收回继承资格、盐窖调度权与白颅城商籍担保。
- 商妩返伤相后将无法获得白颅城医馆与盐窖支持。

### Knowledge / Enemy State

- 贺沉骨已明确会封闭北肋岔，但不会封锁通往新生院的旧创道路。
- 白髓商团已公开认定商妩私售低价逆月盐、擅开未登记路线并造成货物损失。
- 商妩右肩薄骨甲正在继续外撑，返伤相可能使伤势进一步变化。

### World State

- 贺沉骨封死北肋岔并扣留四辆逆月盐车，北肋岔原路线彻底中断。
- 白髓商团撤销商妩的继承资格、盐窖调度权与白颅城商籍担保，商妩失去公开商业与医疗入口。
- 原七车押运队变为仅剩三车，改向巨尸旧创深处的新生院。

### Tracked Assets

四辆逆月盐车｜贺沉骨｜北肋岔外侧｜被骨芽扣留，逆月盐部分散落但未被宁烬带走｜本章明确转移。  
剩余三辆逆月盐车｜商妩及车夫｜巨尸旧创外侧骨地｜车队尚存，等待继续前进｜本章从旧创出口脱困后保留。

# Proposed Chapter Summary

宁烬在出口处同时拉住商妩与四辆盐车，最终放弃盐车，以双真和白昼火救出商妩。贺沉骨封死北肋岔并夺走四车，白髓商团随即撤销商妩的继承资格、盐窖调度权与白颅城商籍担保。宁烬带着商妩和剩余三车改向新生院，返伤相只剩两夜。
