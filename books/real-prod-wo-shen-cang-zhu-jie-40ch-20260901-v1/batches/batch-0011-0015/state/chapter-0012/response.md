# Proposed Active Scene State

地点：北肋岔前的避风凹陷。  
在场人物：宁烬（双真）、商妩、车队人员、七辆逆月盐车。  
即时伤势：宁烬肩部被裂骨风骨刃割伤，已由商妩用盐布处理；双真共同消耗后灵海元力不足三成，正在恢复。  
手中关键物品：黑门骨、海眼碎片、赤曜灯芯、灵玉。  
当前敌人或追兵：贺沉骨（府阶五段，本地骨载修士）已封闭北肋岔；白髓商团仍可能在后续阻挠。  
当前倒计时：返伤相约两夜半后降临。  
下一步直接目标：处理北肋岔闭合问题，确保车队继续前往十二肋廊。  
当前主动目标：以三成首批货利润完成押运，同时保留黑门骨自主权。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海3重

- 双真可同时作为两个真实位置行动，共享同一片灵海；持续作战会同步消耗元力，也会共同承受伤势与疲劳。
- 白昼火可烧开裂骨风中的局部风眼，但火焰过强会炸碎骨芽，制造更多骨屑。
- 玄曜掌可震断车队附近新生骨芽。
- 黑门骨可与巨尸骨陆裂口相连，机制仍未明。

### Active Relationships

商妩（白髓商团验货人）｜护送盐车、争取盐窖继承权｜与主角为雇佣合作关系｜在裂骨风中协助处理宁烬伤势并共同应对路线风险｜需决定如何通过被贺沉骨封闭的北肋岔。  
贺沉骨（本地骨载修士，府阶五段）｜按自身判断处理北肋岔｜与主角尚未建立关系｜已提前封闭北肋岔｜是否放行或与车队冲突未决。

### Identity / Access

- 宁烬仍以商妩雇佣的护运者身份押运逆月盐车。
- 北肋岔原本是绕开白髓商团大路的路线，但当前入口已被贺沉骨控制。

### Knowledge / Enemy State

- 裂骨风会被新生骨芽放大，强行以大范围火力抵挡会增加骨屑危害。
- 贺沉骨能让巨尸旧创暂时闭合，已证明可以直接封闭北肋岔。
- 贺沉骨同时接受白髓商团与无痕盟等势力委托，但主要按自身判断行事。

### World State

- 北肋岔这一条可绕开白髓商团常走大路的盐运通道，已被贺沉骨暂时封闭。

### Tracked Assets

逆月盐七车｜商妩及车队｜北肋岔前避风凹陷｜车队完整，已通过裂骨风｜最近无明确转移。

# Proposed Chapter Summary

宁烬随商妩押运七辆逆月盐车进入十二肋廊，遭遇返伤相前的裂骨风。他以双真分守车队，却因持续消耗元力和肩部受伤认识到双真并非两条命。车队夜宿北肋岔前，贺沉骨提前闭合骨缝，截断了他们绕开白髓商团大路的路线。

# Proposed Open Promises

- 返伤相将在约两夜半后降临，宁烬与商妩的旧伤可能发生变化。
- 北肋岔已被贺沉骨封闭，车队能否通过或改道尚未解决。
- 贺沉骨与宁烬、商妩的首次交涉或冲突尚未发生。
- 宁烬需以受伤且元力不足三成的状态继续完成七车押运。
- 商妩拒绝白髓商团既定价格与路线，盐窖继承权与商团阻挠尚未解决。
- 黑门骨与巨尸骨陆的连接已被确认，但来源、诸界数量与更深机制仍未知。
- 双真能否与下一条世界可能性形成真正复合，尚未兑现。
