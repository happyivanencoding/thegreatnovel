# Proposed Active Scene State

地点：巨尸骨陆通往十二肋廊的骨脊路上。  
在场人物：宁烬（双真）、商妩、七辆逆月盐骨车及车队人员。  
即时伤势：宁烬镜海界重伤仍在恢复；商妩左肩有旧伤。  
手中关键物品：黑门骨、海眼碎片、赤曜灯芯、三十万灵玉。  
当前敌人或追兵：返月相将至；裂骨风、骨芽闭合等骨陆路况未知；白髓商团可能阻挠商妩。  
当前倒计时：三夜后返伤相降临。  
下一步直接目标：护送七辆逆月盐车抵达十二肋廊，并由宁烬参与路线判断。  
当前主动目标：以三成首批货利润完成押运，同时保留黑门骨自主权。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海3重  
- 双真可同时作为两个真实位置行动，伤势与力量仍由同一片灵海承担；本章再次公开验证。
- 黑门骨可与巨尸骨陆裂口相连，并被两名不同势力见证人确认；未获得更多机制解释。

### Active Relationships

商妩（白髓商团验货人）｜低价运送逆月盐、争取盐窖继承权｜与主角形成雇佣合作关系｜以三成首批货利润雇宁烬押运七车盐｜共同决定路线，商妩仍可能面对商团阻挠。  
季槐（返月院成员）｜完成黑门骨验看｜与主角为临时见证关系｜确认黑门骨与断脊渡裂口相连｜返月院与旧痕谱库仍是可接触的本地资源。  
骨渡司｜按三倍价格押运高风险外来者｜与主角存在利益冲突｜宁烬拒绝押运并自行随商妩出渡｜后续可能因盐路与定价产生阻碍。

### Identity / Access

- 宁烬已登记为玄曜外来修士、灵海境三重、高风险外来者。
- 以商妩雇佣的护运者身份进入通往十二肋廊的盐运路线。

### Knowledge / Enemy State

- 巨尸骨陆每二十一夜发生一次返伤相；三夜后月轮缺口将对准此地。
- 返伤相会使旧伤重新发热、生长，可能产生骨盾、听管、过滤腔等变化，也可能造成长期异变。
- 逆月盐只能延缓一次痕生，不能消除伤势或决定最终变化。
- 骨陆道路存在裂骨风、骨芽闭合等危险；车辆与护具必须保留可活动空隙。

### World State

- 断脊渡已将宁烬登记为高风险外来修士，并因九环天都战例提高押运定价。
- 逆月盐首批低价货正由商妩绕开白髓商团既定价格与路线，前往十二肋廊。

### Tracked Assets

逆月盐七车｜商妩及车队｜巨尸骨陆骨脊路上｜首批待运货物｜商妩雇佣宁烬后由渡口出发。

# Proposed Chapter Summary

宁烬独自通过黑门骨进入巨尸骨陆，在断脊渡登记并以三倍押运价被评为高风险外来者。两名见证人确认黑门骨与裂口相连后，商妩雇他护送七辆逆月盐车前往十二肋廊。宁烬接受三成首批货利润，双真随车队出渡；三夜后返伤相将至。

# Proposed Open Promises

- 三夜后返伤相降临，旧伤与骨陆环境将发生变化。
- 宁烬护送七辆逆月盐车前往十二肋廊，获得三成首批货利润。
- 商妩拒绝白髓商团既定价格与路线，盐窖继承权与商团阻挠尚未解决。
- 裂骨风、骨芽闭合等骨陆路况将在押运途中影响路线与行动。
- 返月院旧痕谱库与外来货仓仍是断脊渡可利用的本地资源。
- 黑门骨与巨尸骨陆的连接已被确认，但黑门骨来源、诸界数量与更深机制仍未知。
- 双真能否与下一条世界可能性形成真正复合，尚未兑现。
