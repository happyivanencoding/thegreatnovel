# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海3重
- 双真共享元力与伤势；本章再次证明持续双线作战会快速降低元力，且两处身体均可受伤。
- 白昼火可精准烧断骨刺、局部烧开风眼，但不足以阻止大范围骨裂风或骨缝收缩。
- 宁烬可凭双真协同推动盐车穿过狭窄危险路线。

### Active Relationships

商妩（白髓商团验货人）｜坚持自行押运并争取盐窖继承权｜与主角为雇佣合作关系｜当众割断商团标绳，带车队改走废缝｜继续共同穿越废缝。
贺沉骨（本地骨载修士，府阶五段）｜只按自身判断封闭北肋岔｜与主角保持对立但未直接交战｜承认废缝也是路，未阻拦车队改道｜后续是否追赶或再次拦截未决。
白髓商团追收人员｜收回盐车并迫使商妩接受商团附约｜与主角及商妩对立｜以旧附约主张商妩违约并被迫留在北肋岔后方｜是否追入废缝未决。

### Identity / Access

- 宁烬仍是商妩雇佣的护运者。
- 商妩已公开脱离商团标绳约束，带七车逆月盐走未核准废缝。

### Knowledge / Enemy State

- 白髓商团持有一份声称由商妩母亲代按的附约，主张商妩不得低于商团定价售盐。
- 贺沉骨封闭北肋岔，但承认废弃骨缝仍属于可通行路线。
- 废缝中的裂骨风会被骨芽放大，前方骨裂正在持续收缩。

### World State

- 白髓商团对商妩及七车逆月盐的追收已公开化。
- 北肋岔被贺沉骨封闭后，商妩带车队转入废弃侧缝，白髓商团的常规追击路线被截断。

### Tracked Assets

逆月盐七车｜商妩及车队｜北肋岔侧方废弃骨缝｜车队完整但正在遭受裂骨风与收缩骨裂威胁｜本章无明确转移。

# Proposed Chapter Summary

贺沉骨以府阶五段力量封死北肋岔，白髓商团又持旧附约追讨商妩和七车逆月盐。商妩当众割断商团标绳，决定改走废弃侧缝。宁烬以双真和白昼火护送车队穿行，却在裂骨风中两处受伤、元力继续下降。车队虽甩开后方追兵，前方骨裂却开始收缩。
