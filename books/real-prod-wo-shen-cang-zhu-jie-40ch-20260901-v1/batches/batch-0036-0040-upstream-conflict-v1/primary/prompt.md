## 本轮正文表达实验：朴素、直接、先让读者看懂

本轮实验的表达优先级是：清楚 > 顺畅 > 有画面 > 文学感。目标读者是普通中文男频网文读者；正文要让读者按正常速度读到一句时，基本立刻知道发生了什么。两种表达都准确时，选择普通、直接、一次读懂的说法，不为了“高级感”增加猜测成本。除下方“漂亮二段论”这一条窄硬禁令外，这些仍是 Primary Writer 的软写作方向，不是评分器、禁词表或新的 prose mode，不要求自评或自动重写。

## 绝对禁令｜“漂亮二段论”不得重复成章法

**禁止把已经展示清楚的事实、动作或结果，再另起一个漂亮短句做裁断、对照、否定翻转或意义升华，并在同一章反复复现成稳定节拍。** 典型同构包括：`他不怕 A。他怕的是 B。`、`他只会 A。可这一件事，已经够了。`、`一个 X 做 A。另一个 X 做 B。`、连续 `不是 A，不是 B，而是 C`，以及任何“事实已经成立 → 短句总结 → 再解释这意味着什么”的变体。判断看语义结构，不看具体词；不要把“怕的是”换成“真正要紧的是”之类同义词继续制造同一章法。

禁的是**重复成章法**，不是一切短句、对照或金句。某个真正关键位置自然出现一次可以保留；**一章一旦已经自然出现一处明显的这种收束，后文绝对不要再主动制造第二处同构收束。** 优先让动作、人物反应、直接后果、对白后的沉默或下一个事件自己完成意义；已经 show 出来的东西，不再为了“漂亮”补一个 tell 的尾巴。

## Trait Saturation｜性格成立后不要继续刷同一口癖
稳定人格是**选择偏向**，不是每章重复同一种证明。某个“爱钱 / 好胜 / 嘴硬 / 谨慎 / 好奇”等牵引已经通过一两次有记忆点的选择和台词清楚成立后，后续只有它真的改变新选择时才再次前景化；不要继续靠同义的“值多少钱 / 这才叫买卖 / 我不喜欢亏”或其它固定口癖反复提醒读者。让 Frozen Human 中其它真实牵引、具体关系、面子、冲动、审美、身体反应或不够理性的偏爱自然轮流进入现场；不是为了多样性硬轮班，而是避免把一个活人压成单一标签播放器。

- 能直接说清楚就直接说：明确写人物、对象、动作、原因和结果。少用需要读者自行补全的代词、空泛指代、隐喻和省略；当前指代不绝对清楚时，重复名词也可以。
- 重要能力、物品和规则第一次出现时，先用普通话让读者知道“它是什么、跟主角有什么关系、现在为什么重要”，再使用世界内部术语。不要先连续写几句意象，让读者自己猜机制。
- 具体动作优先写具体动作和结果。开门、逃跑、战斗、操作和判断危险时，少用多层抽象比喻解释同一件事；一个准确的比喻就够了。普通走位、搬运、受力和已经理解过的能力执行步骤可以压缩。
- 直接说出答案，少连续使用“不是……”“没有……”“只是……”“并非……而是……”来排除错误解释。只有转折本身重要时才保留排除；已经通过动作和结果说清的内容，不要换一种说法反复确认。
- 对话像人在现场传递信息：紧急时优先说清位置、危险、选择和结果。保留人物态度和性格，但不要让角色持续说谜语、机锋、隐喻或半句话。
- 世界观和空间信息只解释当前故事与开篇定向需要的最小部分，但**公共常识要直接讲清**：主流力量、粗略强弱尺、当前/下一档含义、会改变日常生活的危险规则、常见上升入口或价值物，如果 Curated Context 已明确投影，就用普通陈述句告诉读者；不要只摆出火盆、服装、站位、专名或异常现象让读者自己推。**本章若真实跨过前文已说明的公开力量/身份档位，结果处直接命名新档位一次；只写本地术语或现象、让读者自己换算到“一阶/正式护卫/某身份”等，不算完全完成状态校准。** 暂时不重要的历史、制度、隐藏原因和完整空间结构后放。
- 简单不等于空泛。仍然写具体动作、人物反应、冲突、态度、必要的环境感觉和结果，不要用“他很生气”“情况很危险”替代事件。先让读者理解，再保留少量有味道的描写。

## Story-bearing Texture：丰富不是修饰堆积

正文的丰富感优先来自承载故事的具体细节，而不是增加形容词、副词、泛化比喻或同义情绪解释。每个主要 beat 只选择少量真正改变读者画面的细节：具体动作、有功能的物件与空间位置、身体反馈、力量造成的可见后果、以及不同人物各自不同的反应。一个场景通常只需要最有辨识度的少量感官锚点，不机械覆盖视觉、听觉、嗅觉、触觉；力量感优先让别人、环境或可选行动发生变化，而不是只写“强大、恐怖、骇人”。修饰词和比喻只有在改变 POV 判断、人物关系或现场画面时才值得保留。不要为了“写得丰富”延长章节；没有承载人物、冲突、因果或幻想体验的细节应继续压缩。

朴素、直接不等于情绪中性。人物不是状态更新器：事件真实碰到人物的欲望、自尊、利益、恐惧、关系或期待时，允许自然出现高兴、害怕、恼火、不服、得意、尴尬、委屈、心虚、期待、失望、冲动或嘴硬等反应；不按清单覆盖，不机械增加情绪词，也不要为了避免情绪词改写成晦涩隐喻。情绪优先通过可见行为泄露：语气、说不说、动作快慢、视线、笑或忍笑、手的反应、嘴硬、装作不在乎，或一个本来不会做的短期选择。人物可以克制，但克制应表现为有反应后选择压住；不要默认人人立即看懂、接受和做最优决定，也不要为制造人味强行让人物犯蠢。

重大胜利、失败、羞辱、翻盘、资格、机会、关系突破、背叛、认可或资源到账等结果，不要只更新身份、关系或 Canon；当事件价值确实需要时，给最相关的一两个角色一个很短的反应窗口，再进入实际收益与下一步。同一结果不必让所有人有同一种反应，反应要来自各自当前在意的事。对话仍需服务信息、关系、选择或行动，但不必每句高效；嘲讽、抱怨、试探、嘴硬、笑，或一句只暴露态度的话，只要让人物更具体就有用。

当重大结果直接撞到角色的核心欲望、自尊、恐惧或期待时，默认允许出现一个可辨认的情绪倾向，不要只用疼痛、战术判断、看一眼或状态确认代替它。它可以很克制，仍通过动作、语气、注意力或选择表现；不要求每个角色、每章都有，也不要直接用强情绪标签。人物总体克制不等于无情绪：重大欲望兑现后，除非已有明确理由压住，至少让读者感到他确实在乎。**已批准的私人欲望也不要被正文自动净化。** 如果 Curated Context 明确带入身体吸引、审美、虚荣、钱、享受、偏心、嫉妒、好奇或其它私人牵引，而且当前场景自然触发它，就让 POV 至少通过一次注意力、身体反应、靠近/回避、想要或短期选择露出来；不要把这种牵引统一翻译成尊重边界、职责协作、成熟沟通或“正确但克制”的决定。没有自然触发时不硬塞，也不把情欲写成每次见面的固定标签。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

写完关键动作或转折时，优先自问：第一次接触这个世界的普通读者快速读过，能不能立刻知道人物做了什么、为什么做、做成以后发生了什么？如果不能，先改清楚，再考虑增加文学性。

## 选择性因果与章节承接

只展开会改变人物选择、风险、能力差异或结果的关键因果节点。重点写为什么普通方法不行、主角发现了什么差异、他做了哪个决定、决定为什么有风险、结果具体改变了什么；重复搬运、普通走位、左右微调、完整受力过程、每一步碎石或火流变化、已经理解过的同一种能力执行步骤默认压缩。**决定已经做完后的普通实施默认一句或一个短段概括**；只有实施中重新出现新的选择、冲突、不确定性、失败风险或人物关系变化，才值得恢复成完整场景。若所谓“决定性动作”本身只是 Supporting Skill（修具、排车、绑缚、诊断、制作、计算等）为真正的人物/世界冲突服务，而该技能并非本书当前核心幻想，就写到“做了什么 → 为什么有效 → 结果怎样”即停，不把它再展开成一个需要逐步解决的小任务。因果清晰不等于完整模拟物理过程。

当 Curated Context 按当前 Plan 携带了已批准 World fact 时，用 1—3 个短的直接旁白段把读者此刻需要的世界模型补齐。普通 World Entry 通常遵循 **Action creates the question → Exposition answers just enough → Action continues**；但**开篇 Public Common Knowledge 不必先等动作提问**，可以在当前场景自然停顿处直接交代一组已经排程的公共常识。**已明确排程的 Reader Release 是本章需要落实的 timing decision，不是可有可无的装饰。** Writer 不负责从完整世界中选择还该介绍什么，只落实 Curator 已投影的事实；不得越过未知边界，也不得借世界说明重新打开已经成立的旧事实。对 `公共常识` Release，只有普通读者快速读过后能直接说出规则，才算兑现；仅靠环境细节、人物动作、专名、暗示或“看起来很特别”让读者自行归纳，不算已经说明。若 Reader Release 明确给出 named 势力 / 地点 / 身份的安全公开类别，正文第一次需要读者识别它时直接用普通话说清一次类别，不用外观、行为或上下文暗示代替这个基础答案；若同一 Release 还包含这个地点/势力/传承/价值物为什么值得强者争、为什么对当前主角位置有分量，也保留一个最短的**欲望/价值锚点**，不要只留下名称和危险。只有正文同一位置已经自然、明确传达了同一事实时才不重复说明。

“第一息 / 第二息 / 第三息”之类的微观计时，只在时间顺序本身影响成败时使用；普通动作不要为了显得精确而逐息书写。新章不要原样或近似复述上一章最后一句或最后一个动作来证明连续性；上一章已经建立的状态默认继续成立，新章从这个状态造成的下一个有意义变化进入。

1. 动作先于术语：第一次出现本书独有概念时，先让读者看见对象、动作和结果，再由人物用普通话形成理解；只有反复使用确实能减少解释时才固定命名。
2. 常见题材词可以自然使用；本书新造的机制、部件、阵法和抽象关系必须先通过场景成立，不要为了显得原创而给普通动作换名字。
3. 普通语言优先：能用“借力、卡住、撞开、绕过去、压下来、黏住、看见、躲开、把力量送过去”说清楚时，不默认升级成工程或审计术语。
4. 已经通过动作成立的边界只在发生新变化时更新，不连续用“不是、没有、尚未、并不、不代表、还不能算”重复证明旧边界。
5. 段落要有真实节拍变化；连续动作、观察或判断保持自然段，单句段留给冲击、决定、翻转、停顿、强烈反应和章末钩子。
6. 重大首次兑现先写结果、外界反应、主角实际收益和行动空间，再写必要的限制或代价；不要用三种同义表述同时削弱兑现。
7. 主角的判断要带着自己的经历、习惯、偏见、欲望、幽默或刻薄，不把人物写成通用的冷静正确男主。
8. 每个场景优先服务一个当前读者主问题。世界规则、空间信息、能力信息和人物背景只在帮助读者理解当前行动时展开，不要在同一小段里要求读者同时新建多个完整模型。
9. 本章内具名的重要物品一旦明确换了持有人或位置，后文必须服从新的状态；只有正文再次写出转移动作时才能改变，不能无说明地回到旧状态。

准确机制仍须保留，但优先通过可见动作、直接结果、人物理解和后续选择让读者理解。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。


## Batch Continuity
- 你自己刚写完的第N章正文就是第N+1章的直接前文；即时追杀、攻击、谈判、坠落、门正在关闭等不得在章缝里消失。
- 物品、钱、伤势、位置、关系和公开力量位置一旦改变，后章服从新状态。
- 不提前实现后章计划；但可以让上一章 Ending Handoff 的压力真实出现。
- 不为桥接新造禁杀规则、备用传送、强敌心软、免费救援或其它方便机制。

- 世界独有规则不仅服务解题：若 Batch Plan 已给具体人物命运/关系后果，让它通过人物选择真正进入故事。

# FROZEN HUMAN CORE
宁烬，十七岁。稳定牵引是钱、赢、面子、稀奇罕见之物、危险又漂亮的人或东西，以及“既然有机会碰到，为什么只拿一半”的贪心。他敢押、反应快、讨厌被别人替自己决定价值，也不喜欢明明能争却先替自己找退路。

# SHARED BOOK CONTRACT
## 0. 本书成长基因图

### 已批准幻想不变量

宁烬亲自进入独立真实世界、卷入真实冲突并承担后果，才能永久带回该世界原本允许、而玄曜大界不允许的核心现实可能性。当前新可能性为“双影为邻”，不是普通功法、宝物或免费境界提升。

### 已批准长期成长兑现

- 双真：同一个宁烬同时处于两个同等真实的位置。
- 风髓双口：在双真同时存在且两端未堵死时，导引风、热、液压等流动力量。
- 未尽续行：宁烬真正开始的具体动作，在原载体被打断后由另一真身或已有结构接续。
- 双影为邻：两具真身各自投下真实影子时，使两道属于宁烬的影子连续接上；对宁烬亲手开始的动作及其直接驱动物体，两处影边视作相邻下一寸。

### 已批准长期后果

四层优势形成 Advantage Stack，但不提升玄曜主境界，不增加元力，不传送人或固体，不产生第三端点，也不保证动作自动成功。

### 核心不变量

- 每个独立世界都有自己的活人、欲望、冲突与不可替代结果。

## 新增公共现实与普通生活

这座无墙宫殿被当地人称为“万门宫”。

它没有外墙，也没有真正的天穹。无数门框悬在长廊、台阶、桥面和空旷庭院之间；每一扇门后，都挂着一轮不同的太阳。

这里最普通、也最重要的因果只有两句：

**门不是通往房间的洞，而是一轮太阳划给自己的边界。谁的影子落在门内，谁的身体就会逐渐被那轮太阳认领。**

**两扇门是否相近，不看地面相隔多远，只看它们的影子能不能连续接上；影子接得上，天涯也是近邻，影子接不上，门框相对也仍是远方。**

因此，“内外”不是墙里墙外，而是有没有太阳承认你。有人站在门廊上，身体一半属于赤昼太阳，一半仍属于出生时的冷白太阳，这种人被称为“夹昼者”。

普通人的生活完全建立在太阳归属上：

- 房屋不是固定在地面，而是固定在某段稳定的影子里。搬家时，居民要先搬走床、灶和祖先骨灰，再搬动连接房屋的遮影架。
- 婴儿出生在哪轮太阳的影子下，往往决定他一生的体温、睡眠、视力、骨骼密度和对食物的需求。接生婆必须判断孩子是否同时被两轮太阳认领。
- 婚姻不是两个人住在一起，而是两个人能否让影子长期相接。不同太阳下的恋人会搭建“共影棚”，每天只在两轮太阳交界的短暂时刻见面。
- 夫妻分开时，必须把共同影子拆开。拆影失败的人会失去一部分方向感，走到任何门前都无法判断自己究竟属于哪里。
- 农田按照太阳划分。长昼太阳适合谷物，蓝黑太阳适合菌田，赤潮太阳能让果实快速成熟，却会使未经适应的人皮肤灼裂。
- 逃亡者不能只躲进另一扇门。若新太阳没有接纳他的影子，他会在穿越过程中逐渐失去原本的体温、语言或记忆顺序。
- 战争也不以攻城为核心。军队真正争夺的是一扇门的影子链、一个能让太阳改换归属的人，或一段可以让整座街区迁入另一轮太阳的连续阴影。

- **交影人**：能够让两个人、两件物或两扇门的影子短暂相接。
- **换日者**：能主动改变自身或他人太阳归属，但每次换日都会留下身体代价。
- **无昼民**：不被任何太阳认领，能进入多数断昼区域，却无法正常繁衍后代。
- **夹昼者**：同时承受两轮太阳改造的人。他们可能获得独特适应，也可能在成年前身体分裂。

## 新地点、势力与公共识别

**长昼前庭**是万门宫最繁华的公共区域。长昼太阳始终悬在门后，农田、集市和大型工坊都依靠它运转。这里的人普遍寿命较短，却拥有极强的昼间工作能力。承昼王庭的宫殿也在此处，但王庭真正控制的是长昼太阳最稳定的影子链，而非某座建筑。

**七影廊**连接七轮太阳，是万门宫目前最长、最稳定的连续影路。七影廊上住着商人、逃亡者、婚队和迁徙工匠。它每隔数年就会改变一处接点，导致原本近在咫尺的两座城忽然远隔数十年路程。

**无昼井**是一片没有门、没有太阳、也没有稳定影子的下陷宫区。无昼民在此种植黑根、饲养盲耳兽，并保存不属于任何太阳的旧物。任何太阳的军队进入这里，都会在数日内失去方向和归属。

**祖门台**是一扇悬在高空的古门。它后面的太阳已经沉寂多年，却仍会在继承者靠近时重新照出影子。谁能被它照出完整影子，谁就可能继承一整片旧领地，以及那轮太阳留下的身体适应。

- **无昼众**：由无昼民、被太阳放逐者和部分夹昼者组成。他们想彻底取消太阳对身体的认领，但若计划成功，许多依靠太阳生存的普通人也会失去生命条件。

万门宫人通过影子的颜色、边缘数量和移动方向识别公开身份。隐藏能力仍然可能存在，但一个人的太阳归属、是否夹昼、是否无昼，通常会在日常生活中直接显露。

## 真正值得想要或进入的东西

- **祖门台的无主太阳**：它可能重新选择一名继承者，也可能拒绝所有旧血统。被它完整照出的活人，可以让一扇古门改变所属，但代价是身体必须放弃原本太阳留下的一部分适应。

- **长昼前庭的永昼果园**：果树不受普通季节影响，果实能暂时改变人的睡眠和体温。果园本身是环境特权，不会让所有进入者获得相同结果。
- **夹昼者的身体谱**：记录不同太阳共同认领后产生的身体变化。它可能帮助医师救人，也可能证明万门宫正在诞生一种旧制度无法容纳的新生命。

## 新增公共现实与普通生活

这座无墙宫殿被当地人称为“万门宫”。

它没有外墙，也没有真正的天穹。无数门框悬在长廊、台阶、桥面和空旷庭院之间；每一扇门后，都挂着一轮不同的太阳。

这里最普通、也最重要的因果只有两句：

**门不是通往房间的洞，而是一轮太阳划给自己的边界。谁的影子落在门内，谁的身体就会逐渐被那轮太阳认领。**

**两扇门是否相近，不看地面相隔多远，只看它们的影子能不能连续接上；影子接得上，天涯也是近邻，影子接不上，门框相对也仍是远方。**

因此，“内外”不是墙里墙外，而是有没有太阳承认你。有人站在门廊上，身体一半属于赤昼太阳，一半仍属于出生时的冷白太阳，这种人被称为“夹昼者”。

- **无昼境**：在没有太阳认领的区域行动，并切断既有归属。

影籍越高，不代表正面战斗必胜。有人只能保护一间产房，有人能迁移一座村庄，有人擅长切断敌军的太阳补给，却无法杀死一个普通人。

## 新地点、势力与公共识别

**长昼前庭**是万门宫最繁华的公共区域。长昼太阳始终悬在门后，农田、集市和大型工坊都依靠它运转。这里的人普遍寿命较短，却拥有极强的昼间工作能力。承昼王庭的宫殿也在此处，但王庭真正控制的是长昼太阳最稳定的影子链，而非某座建筑。

**七影廊**连接七轮太阳，是万门宫目前最长、最稳定的连续影路。七影廊上住着商人、逃亡者、婚队和迁徙工匠。它每隔数年就会改变一处接点，导致原本近在咫尺的两座城忽然远隔数十年路程。

**悬胎院**建在三轮太阳交界处。这里专门收留夹昼儿童、双太阳孕妇和无法适应新归属的人。院内的医师认为夹昼者可能是新的物种起点，承昼王庭则认为他们会破坏太阳继承秩序。

**无昼井**是一片没有门、没有太阳、也没有稳定影子的下陷宫区。无昼民在此种植黑根、饲养盲耳兽，并保存不属于任何太阳的旧物。任何太阳的军队进入这里，都会在数日内失去方向和归属。

**祖门台**是一扇悬在高空的古门。它后面的太阳已经沉寂多年，却仍会在继承者靠近时重新照出影子。谁能被它照出完整影子，谁就可能继承一整片旧领地，以及那轮太阳留下的身体适应。

主要势力包括：

- **承昼王庭**：想让长昼太阳的影子连接所有主要门区，以统一贸易、婚姻与军队。王庭相信只有一轮主太阳才能结束不断发生的边界战争。
- **七影民盟**：由七影廊的居民组成，反对任何单一太阳吞并其它区域。他们保护影路，却也偷偷改变接点，让某些城镇永远无法被王庭找到。
- **移门匠会**：掌握移动门框、重接影链和修复断昼区域的技术。内部有人想让所有人自由选择太阳，也有人靠贩卖迁徙机会控制数十座村镇。
- **无昼众**：由无昼民、被太阳放逐者和部分夹昼者组成。他们想彻底取消太阳对身体的认领，但若计划成功，许多依靠太阳生存的普通人也会失去生命条件。
- **归日军**：承昼王庭训练的边军，真正的军旗不是颜色，而是士兵脚下统一的影子方向。敌军一旦被迫踏入同一影向，便会失去队形和退路。

万门宫人通过影子的颜色、边缘数量和移动方向识别公开身份。隐藏能力仍然可能存在，但一个人的太阳归属、是否夹昼、是否无昼，通常会在日常生活中直接显露。

## 新增公共现实与普通生活

这座无墙宫殿被当地人称为“万门宫”。

它没有外墙，也没有真正的天穹。无数门框悬在长廊、台阶、桥面和空旷庭院之间；每一扇门后，都挂着一轮不同的太阳。

这里最普通、也最重要的因果只有两句：

**门不是通往房间的洞，而是一轮太阳划给自己的边界。谁的影子落在门内，谁的身体就会逐渐被那轮太阳认领。**

**两扇门是否相近，不看地面相隔多远，只看它们的影子能不能连续接上；影子接得上，天涯也是近邻，影子接不上，门框相对也仍是远方。**

因此，“内外”不是墙里墙外，而是有没有太阳承认你。有人站在门廊上，身体一半属于赤昼太阳，一半仍属于出生时的冷白太阳，这种人被称为“夹昼者”。

普通人的生活完全建立在太阳归属上：

- 房屋不是固定在地面，而是固定在某段稳定的影子里。搬家时，居民要先搬走床、灶和祖先骨灰，再搬动连接房屋的遮影架。
- 婴儿出生在哪轮太阳的影子下，往往决定他一生的体温、睡眠、视力、骨骼密度和对食物的需求。接生婆必须判断孩子是否同时被两轮太阳认领。
- 婚姻不是两个人住在一起，而是两个人能否让影子长期相接。不同太阳下的恋人会搭建“共影棚”，每天只在两轮太阳交界的短暂时刻见面。
- 夫妻分开时，必须把共同影子拆开。拆影失败的人会失去一部分方向感，走到任何门前都无法判断自己究竟属于哪里。
- 农田按照太阳划分。长昼太阳适合谷物，蓝黑太阳适合菌田，赤潮太阳能让果实快速成熟，却会使未经适应的人皮肤灼裂。
- 逃亡者不能只躲进另一扇门。若新太阳没有接纳他的影子，他会在穿越过程中逐渐失去原本的体温、语言或记忆顺序。
- 战争也不以攻城为核心。军队真正争夺的是一扇门的影子链、一个能让太阳改换归属的人，或一段可以让整座街区迁入另一轮太阳的连续阴影。

万门宫的居民不会把门当成机关。他们把门当成土地、血统、婚姻、身体和国家的共同根基。

## 新力量 / 威胁 / 身份 / 价值尺度

太阳认领并不等于单纯变强。

被某轮太阳长期认领后，人的身体会出现不可逆的适应：

- 长昼太阳会让骨骼变轻、睡眠缩短，但也会使人逐渐失去在黑暗中辨认亲人的能力。
- 冷白太阳会令血液凝滞、寿命延长，却让身体难以承受突然升高的温度。
- 赤潮太阳能强化肌肉和生殖能力，但情绪会随太阳高度剧烈波动。
- 蓝黑太阳会让人听见影子移动的声音，却会削弱对真实颜色的判断。
- 无昼区域不会改造身体，却会让长期居住者逐渐失去被任何太阳认领的资格。

主要危险包括：

- **争影**：两轮太阳同时认领同一人或同一件物品，身体会出现双重体温、错位骨骼或两个互相矛盾的影子。
- **断昼**：影子链突然断裂，整座街区会在一夜之间变成“外部”，居民的身体开始拒绝原本的食物、空气和睡眠方式。
- **倒日**：某轮太阳改变门内轨迹，使原本稳定的房屋、道路和祖坟全部偏离归属。
- **太阳饥荒**：一轮太阳衰弱后，仍被它认领的人会不断吸收周围热量，导致牲畜死亡、农田结冰，甚至令婴儿无法发育。
- **门后迁徙**：太阳并不移动，但它的影子开始向另一扇门延伸。只要影子完全接上，两片居民区就会突然成为近邻，旧有战争与婚姻边界随之失效。

当地常见身份包括：

- **一昼民**：身体稳定属于一轮太阳的人。
- **交影人**：能够让两个人、两件物或两扇门的影子短暂相接。
- **换日者**：能主动改变自身或他人太阳归属，但每次换日都会留下身体代价。
- **无昼民**：不被任何太阳认领，能进入多数断昼区域，却无法正常繁衍后代。
- **夹昼者**：同时承受两轮太阳改造的人。他们可能获得独特适应，也可能在成年前身体分裂。

万门宫真正值钱的不是最高杀伤，而是谁能带着多少人、多少牲畜和多少土地安全跨过太阳边界。

## 新地点、势力与公共识别

**长昼前庭**是万门宫最繁华的公共区域。长昼太阳始终悬在门后，农田、集市和大型工坊都依靠它运转。这里的人普遍寿命较短，却拥有极强的昼间工作能力。承昼王庭的宫殿也在此处，但王庭真正控制的是长昼太阳最稳定的影子链，而非某座建筑。

## 新增公共现实与普通生活

这座无墙宫殿被当地人称为“万门宫”。

它没有外墙，也没有真正的天穹。无数门框悬在长廊、台阶、桥面和空旷庭院之间；每一扇门后，都挂着一轮不同的太阳。

这里最普通、也最重要的因果只有两句：

**门不是通往房间的洞，而是一轮太阳划给自己的边界。谁的影子落在门内，谁的身体就会逐渐被那轮太阳认领。**

**两扇门是否相近，不看地面相隔多远，只看它们的影子能不能连续接上；影子接得上，天涯也是近邻，影子接不上，门框相对也仍是远方。**

因此，“内外”不是墙里墙外，而是有没有太阳承认你。有人站在门廊上，身体一半属于赤昼太阳，一半仍属于出生时的冷白太阳，这种人被称为“夹昼者”。

普通人的生活完全建立在太阳归属上：

- 房屋不是固定在地面，而是固定在某段稳定的影子里。搬家时，居民要先搬走床、灶和祖先骨灰，再搬动连接房屋的遮影架。
- 婴儿出生在哪轮太阳的影子下，往往决定他一生的体温、睡眠、视力、骨骼密度和对食物的需求。接生婆必须判断孩子是否同时被两轮太阳认领。
- 婚姻不是两个人住在一起，而是两个人能否让影子长期相接。不同太阳下的恋人会搭建“共影棚”，每天只在两轮太阳交界的短暂时刻见面。
- 夫妻分开时，必须把共同影子拆开。拆影失败的人会失去一部分方向感，走到任何门前都无法判断自己究竟属于哪里。
- 农田按照太阳划分。长昼太阳适合谷物，蓝黑太阳适合菌田，赤潮太阳能让果实快速成熟，却会使未经适应的人皮肤灼裂。
- 逃亡者不能只躲进另一扇门。若新太阳没有接纳他的影子，他会在穿越过程中逐渐失去原本的体温、语言或记忆顺序。
- 战争也不以攻城为核心。军队真正争夺的是一扇门的影子链、一个能让太阳改换归属的人，或一段可以让整座街区迁入另一轮太阳的连续阴影。

万门宫的居民不会把门当成机关。他们把门当成土地、血统、婚姻、身体和国家的共同根基。

## 新力量 / 威胁 / 身份 / 价值尺度

太阳认领并不等于单纯变强。

被某轮太阳长期认领后，人的身体会出现不可逆的适应：

- 长昼太阳会让骨骼变轻、睡眠缩短，但也会使人逐渐失去在黑暗中辨认亲人的能力。
- 冷白太阳会令血液凝滞、寿命延长，却让身体难以承受突然升高的温度。
- 赤潮太阳能强化肌肉和生殖能力，但情绪会随太阳高度剧烈波动。
- 蓝黑太阳会让人听见影子移动的声音，却会削弱对真实颜色的判断。
- 无昼区域不会改造身体，却会让长期居住者逐渐失去被任何太阳认领的资格。

主要危险包括：

- **争影**：两轮太阳同时认领同一人或同一件物品，身体会出现双重体温、错位骨骼或两个互相矛盾的影子。
- **断昼**：影子链突然断裂，整座街区会在一夜之间变成“外部”，居民的身体开始拒绝原本的食物、空气和睡眠方式。
- **倒日**：某轮太阳改变门内轨迹，使原本稳定的房屋、道路和祖坟全部偏离归属。
- **太阳饥荒**：一轮太阳衰弱后，仍被它认领的人会不断吸收周围热量，导致牲畜死亡、农田结冰，甚至令婴儿无法发育。
- **门后迁徙**：太阳并不移动，但它的影子开始向另一扇门延伸。只要影子完全接上，两片居民区就会突然成为近邻，旧有战争与婚姻边界随之失效。

当地常见身份包括：

- **一昼民**：身体稳定属于一轮太阳的人。
- **交影人**：能够让两个人、两件物或两扇门的影子短暂相接。
- **换日者**：能主动改变自身或他人太阳归属，但每次换日都会留下身体代价。
- **无昼民**：不被任何太阳认领，能进入多数断昼区域，却无法正常繁衍后代。
- **夹昼者**：同时承受两轮太阳改造的人。他们可能获得独特适应，也可能在成年前身体分裂。

万门宫真正值钱的不是最高杀伤，而是谁能带着多少人、多少牲畜和多少土地安全跨过太阳边界。

### 本地精确力量主尺｜Instance Grammar

主尺类型：大境界+数字子级  
主尺名称：影籍五境七级  
精确位置格式：{影境}{N}级  
数字精度规则：每境记录1—7级；只承认可由三名不同太阳下的见证者复验的整数级，不使用半级、隐藏小数或模糊称号  
当前可见范围：留影境1—7级；接影境1—7级；换日境1—7级；分庭境1—5级；无昼境1—2级

五境含义如下：

- **留影境**：稳定维持自身在一轮太阳下的身体归属。

- **换日境**：改变一个生命或物品的太阳归属。
- **分庭境**：同时维持多个太阳边界，使不同区域暂时共存。
- **无昼境**：在没有太阳认领的区域行动，并切断既有归属。

影籍越高，不代表正面战斗必胜。有人只能保护一间产房，有人能迁移一座村庄，有人擅长切断敌军的太阳补给，却无法杀死一个普通人。

## 新增公共现实与普通生活

这座无墙宫殿被当地人称为“万门宫”。

它没有外墙，也没有真正的天穹。无数门框悬在长廊、台阶、桥面和空旷庭院之间；每一扇门后，都挂着一轮不同的太阳。

这里最普通、也最重要的因果只有两句：

**门不是通往房间的洞，而是一轮太阳划给自己的边界。谁的影子落在门内，谁的身体就会逐渐被那轮太阳认领。**

**两扇门是否相近，不看地面相隔多远，只看它们的影子能不能连续接上；影子接得上，天涯也是近邻，影子接不上，门框相对也仍是远方。**

因此，“内外”不是墙里墙外，而是有没有太阳承认你。有人站在门廊上，身体一半属于赤昼太阳，一半仍属于出生时的冷白太阳，这种人被称为“夹昼者”。

普通人的生活完全建立在太阳归属上：

- 房屋不是固定在地面，而是固定在某段稳定的影子里。搬家时，居民要先搬走床、灶和祖先骨灰，再搬动连接房屋的遮影架。
- 婴儿出生在哪轮太阳的影子下，往往决定他一生的体温、睡眠、视力、骨骼密度和对食物的需求。接生婆必须判断孩子是否同时被两轮太阳认领。
- 婚姻不是两个人住在一起，而是两个人能否让影子长期相接。不同太阳下的恋人会搭建“共影棚”，每天只在两轮太阳交界的短暂时刻见面。
- 夫妻分开时，必须把共同影子拆开。拆影失败的人会失去一部分方向感，走到任何门前都无法判断自己究竟属于哪里。
- 农田按照太阳划分。长昼太阳适合谷物，蓝黑太阳适合菌田，赤潮太阳能让果实快速成熟，却会使未经适应的人皮肤灼裂。
- 逃亡者不能只躲进另一扇门。若新太阳没有接纳他的影子，他会在穿越过程中逐渐失去原本的体温、语言或记忆顺序。
- 战争也不以攻城为核心。军队真正争夺的是一扇门的影子链、一个能让太阳改换归属的人，或一段可以让整座街区迁入另一轮太阳的连续阴影。

万门宫的居民不会把门当成机关。他们把门当成土地、血统、婚姻、身体和国家的共同根基。

## 新力量 / 威胁 / 身份 / 价值尺度

太阳认领并不等于单纯变强。

被某轮太阳长期认领后，人的身体会出现不可逆的适应：

- 长昼太阳会让骨骼变轻、睡眠缩短，但也会使人逐渐失去在黑暗中辨认亲人的能力。
- 冷白太阳会令血液凝滞、寿命延长，却让身体难以承受突然升高的温度。
- 赤潮太阳能强化肌肉和生殖能力，但情绪会随太阳高度剧烈波动。
- 蓝黑太阳会让人听见影子移动的声音，却会削弱对真实颜色的判断。
- 无昼区域不会改造身体，却会让长期居住者逐渐失去被任何太阳认领的资格。

主要危险包括：

- **争影**：两轮太阳同时认领同一人或同一件物品，身体会出现双重体温、错位骨骼或两个互相矛盾的影子。
- **断昼**：影子链突然断裂，整座街区会在一夜之间变成“外部”，居民的身体开始拒绝原本的食物、空气和睡眠方式。
- **倒日**：某轮太阳改变门内轨迹，使原本稳定的房屋、道路和祖坟全部偏离归属。
- **太阳饥荒**：一轮太阳衰弱后，仍被它认领的人会不断吸收周围热量，导致牲畜死亡、农田结冰，甚至令婴儿无法发育。
- **门后迁徙**：太阳并不移动，但它的影子开始向另一扇门延伸。只要影子完全接上，两片居民区就会突然成为近邻，旧有战争与婚姻边界随之失效。

当地常见身份包括：

- **一昼民**：身体稳定属于一轮太阳的人。
- **交影人**：能够让两个人、两件物或两扇门的影子短暂相接。
- **换日者**：能主动改变自身或他人太阳归属，但每次换日都会留下身体代价。
- **无昼民**：不被任何太阳认领，能进入多数断昼区域，却无法正常繁衍后代。
- **夹昼者**：同时承受两轮太阳改造的人。他们可能获得独特适应，也可能在成年前身体分裂。

万门宫真正值钱的不是最高杀伤，而是谁能带着多少人、多少牲畜和多少土地安全跨过太阳边界。

## 新地点、势力与公共识别

**长昼前庭**是万门宫最繁华的公共区域。长昼太阳始终悬在门后，农田、集市和大型工坊都依靠它运转。这里的人普遍寿命较短，却拥有极强的昼间工作能力。承昼王庭的宫殿也在此处，但王庭真正控制的是长昼太阳最稳定的影子链，而非某座建筑。

**七影廊**连接七轮太阳，是万门宫目前最长、最稳定的连续影路。七影廊上住着商人、逃亡者、婚队和迁徙工匠。它每隔数年就会改变一处接点，导致原本近在咫尺的两座城忽然远隔数十年路程。

**悬胎院**建在三轮太阳交界处。这里专门收留夹昼儿童、双太阳孕妇和无法适应新归属的人。院内的医师认为夹昼者可能是新的物种起点，承昼王庭则认为他们会破坏太阳继承秩序。

**无昼井**是一片没有门、没有太阳、也没有稳定影子的下陷宫区。无昼民在此种植黑根、饲养盲耳兽，并保存不属于任何太阳的旧物。任何太阳的军队进入这里，都会在数日内失去方向和归属。

**祖门台**是一扇悬在高空的古门。它后面的太阳已经沉寂多年，却仍会在继承者靠近时重新照出影子。谁能被它照出完整影子，谁就可能继承一整片旧领地，以及那轮太阳留下的身体适应。

主要势力包括：

- **承昼王庭**：想让长昼太阳的影子连接所有主要门区，以统一贸易、婚姻与军队。王庭相信只有一轮主太阳才能结束不断发生的边界战争。
- **七影民盟**：由七影廊的居民组成，反对任何单一太阳吞并其它区域。他们保护影路，却也偷偷改变接点，让某些城镇永远无法被王庭找到。

- **无昼众**：由无昼民、被太阳放逐者和部分夹昼者组成。他们想彻底取消太阳对身体的认领，但若计划成功，许多依靠太阳生存的普通人也会失去生命条件。
- **归日军**：承昼王庭训练的边军，真正的军旗不是颜色，而是士兵脚下统一的影子方向。敌军一旦被迫踏入同一影向，便会失去队形和退路。

万门宫人通过影子的颜色、边缘数量和移动方向识别公开身份。隐藏能力仍然可能存在，但一个人的太阳归属、是否夹昼、是否无昼，通常会在日常生活中直接显露。

# PREVIOUS FINAL PROSE
第三十五章 共影棚押上爱情

归日军占住了第八接点外的长昼影路。

贺燃灯没有立刻动手。

他让士兵把七根影旗插进门框周围，旗杆落下时，地上的金色影子彼此相连，像一条平直的路，把共影棚和第八接点隔在两边。

宁烬左边那具真身站在棚口，右边那具还留在赤潮桥上。

两边都看得见归日军的阵形。

也都看得见那扇空门后，七道颜色不同的影子正在缓缓靠拢。

阮七娘进了棚子。

她没有去看贺燃灯，而是把木案上的东西一件件放到宁烬面前。

接影术谱。

一袋私蓄金银。

三枚永昼果。

最后，她从脖子上摘下一把小铜钥匙，放在黑壳灯旁边。

“共影棚的钥匙。”阮七娘说，“棚里所有遮影架、旧线、备用灯油，都归这把钥匙管。”

宁烬看着她。

“你全押？”

“我说过的。”

阮七娘抬头，隔着棚口望向远处。

赤潮码头不在眼前。按照地面距离，那里要走很久，得跨过不知道多少扇门、多少段断影。可第八接点若成，赤潮码头和这座棚子会被接到一起。

她想要的不是一张能多卖钱的影路图。

是每天能把人带到眼前的路。

“他叫许渡。”阮七娘忽然说，“在赤潮码头摆船。十七天前，他送我回来时，赤潮太阳提前偏了，我们两个站在同一座棚子里，影子却没接上。”

她用手指按住木案上的影线。

“他站在这里，我站在这里。说话都听得见，手却伸不过去。”

宁烬没接话。

阮七娘深吸了一口气，把情绪压下去，指向贺燃灯的影旗。

“他要把第八接点拧向长昼前庭。贺燃灯说这条路能救人，对他也值命。可他拿走以后，共影棚和赤潮码头又得等下一次换席，也许又得从头等完十七天。”

“你要我怎么做？”宁烬问。

阮七娘拿起接影术谱，翻到中间一页。

纸上画着一座棚子，两道影子从棚底延伸出去，一道去往长昼，一道去往赤潮。旁边写着密密麻麻的旧注。

“第八接点出现前，得先把一头影子守在共影棚，一头送到空门边。接影术能把两道影子短时连住，但必须有人顶着太阳认领。”

她看向宁烬两具真身。

“你现在正好被长昼和赤潮各认了一半。你能同时守两端。”

宁烬低头看向自己脚下。

左边那具真身的影子已经泛着淡金色，右边那具真身的影子则更红。两边的身体温度不同，伤口也在不同的痛法里发作，但同一个人确实站在两轮太阳下。

阮七娘没有把这当成奇迹。

她只看见了一个能用上的缺口。

这点让宁烬很舒服。

“报酬我收。”他说。

阮七娘眼睫一动。

“接点还没到手。”

“你拿出来的这些，是请我出手的钱。接点要是拿到，再算后面的价。”

阮七娘盯了他一会儿，忽然笑出声。

“行。你这张脸看着年纪不大，算盘倒很响。”

她把一枚永昼果递给左边那具宁烬。

宁烬咬下一口。

果肉入口温热，像一团柔和的火顺着喉咙落下。左边那具真身被长昼照得发冷的骨头慢慢回了些温度，右边那具真身掌心的灼痛也压下去一点。

两具身体同时缓过一口气。

宁烬把余下的果肉吞下，把那把小铜钥匙推回阮七娘手边。

“从哪边出去？”

阮七娘走到棚后，掀开一层黑布。

后面不是墙，是一条窄窄的影缝。影缝贴着共影棚底下的旧线往外延伸，绕开归日军插下的长昼影旗，直通第八接点侧面。

“这条线以前只够我和许渡见面。”阮七娘说，“一个人走还行，两个人会把影压散。”

宁烬看了眼自己的两具真身。

“那就一边一个。”

“你们两个都走进去，影会被拉断。”

“谁说我要一起走？”

阮七娘一怔。

宁烬已经转身。

左边那具真身留在共影棚内，抬手把黑壳灯提起来。右边那具真身从赤潮桥边退进一扇矮门后，沿着赤潮影线往第八接点外侧绕去。

阮七娘立刻明白他的意思。

一具真身守棚，一具真身去抢外侧影位。

“你左边那具伤更重。”她说。

“右边这具也没好到哪去。”

宁烬把黑壳灯挂到棚梁上。

灯火压住了棚底两道影子的边缘。

“别让它灭。”

阮七娘握紧铜钥匙。

“我守着。”

棚外，贺燃灯抬起手。

归日军的七面影旗同时向前倾斜。

金色影路往空门中央压去。

右边那具宁烬已经绕到一段废桥下方。赤潮太阳的热从门框后直直落下，石桥烫得像铁板。他压低身体，左肋的伤口在衣服里重新裂开，血很快被热气烘得发黏。

前面有两名归日军士兵守着。

两人脚下影子同向，长矛横在桥缝前。

“外来人，退回去。”其中一人喝道。

宁烬没有停。

他右手按住石桥边缘，借着赤潮热浪扑来的瞬间，整个人往下滑进桥缝。

长矛刺空。

士兵俯身去看，桥缝里却只有一道被热浪拉长的红影。

下一刻，宁烬从废桥另一头翻上来，手掌撑地，疼得脸色发白。

他没有和两人缠。

第八接点快要露出来了。

空门前，七道影子已经汇成一团杂乱的暗色。归日军的长昼影旗压住了其中一角，贺燃灯骑在影兽上，赤金灯悬在肩后。

右边那具宁烬刚踏入空门边缘，贺燃灯便转过头。

“你真要跟我抢？”

“你要救的人是命，许渡就不是？”

贺燃灯的脸绷得很紧。

“我没说他不是。”

“那你拿人家的路干什么？”

贺燃灯握住缰绳。

“因为我没有第二条。”

宁烬看了眼他身后的长昼影路。

“巧了，我也没有。”

贺燃灯抬手。

一面影旗倒下，金色影子像一堵墙，朝宁烬压来。

与此同时，共影棚里的黑壳灯猛地晃了一下。

阮七娘按住灯座，棚顶旧线发出细响。她脚下那道冷白影子被长昼影路挤得越来越细，另一端却仍死死朝赤潮方向伸着。

“宁烬！”她喊了一声。

右边那具宁烬抬头。

七道太阳影子终于碰到了空门中央。

第八接点露出了一寸。
