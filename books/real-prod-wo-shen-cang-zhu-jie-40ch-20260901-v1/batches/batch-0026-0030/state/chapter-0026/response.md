# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 风髓双口协同拖拽旧事会牵扯左肋伤势。
- 宁烬可通过两具真身接续同一记拖拽；前一具真身造成的拖拽力不会因断刃或身体分离而归零。
- 三柄名兵已重新合成一柄裂开的折粮刀，刀背缺损、刀身留有两道裂纹。
- 分事炉已无法再次将折粮刀拆成三柄成品。

### Active Relationships

岑非灯｜要保住父亲送来的粮与折粮刀旧事｜与主角暂时同行｜宁烬救下他并带走折粮刀后，岑非灯未再争抢｜需决定是否继续同行。  
贺乌衣｜想取得名兵并守住炉火｜与主角公开敌对｜炉锤被折粮刀拖裂，分事炉火路塌毁｜要求归锋夜前不要再让他看见折粮刀。

### Knowledge / Enemy State

- 折粮刀仍指向城外北方，送粮旧事尚未结束。
- 九百坟线中与旧粮道相牵的兵器已开始朝寂军河上游移动。

### World State

- 宁烬将未完成的“送粮”旧事从分事炉中拖出，三柄名兵重新合成裂开的折粮刀。
- 黑砧城分事炉失去再次拆刀成品的机会。
- 九百坟线与旧粮道相牵的兵器开始向寂军河上游移动。

### Tracked Assets

折粮刀｜宁烬｜黑砧城分事炉外侧/城内铸场｜三柄名兵重新合成，刀身有裂纹、刀背缺损，仍被送粮旧事牵引向北｜本章由三柄名兵重新合成。  
最后一袋旧粮｜岑非灯｜黑砧城分事炉内｜仍由岑非灯抱持｜未转移。  
分事炉与裂炉锤｜贺乌衣｜黑砧城分事炉内｜炉火路塌毁，炉锤裂成两瓣｜本章被折粮刀拖拽损毁。

# Proposed Chapter Summary

宁烬在炉锤落下时接续拖拽折粮刀旧事，使两具真身之间的拖拽力不归零，三柄名兵因此重新合成裂开的折粮刀。岑非灯被救下，分事炉与炉锤损毁；随后九百坟线兵器齐鸣，朝寂军河上游移动。
