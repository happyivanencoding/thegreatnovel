# Proposed Active Scene State

地点：新生院骨坡与骨棚外，骨芽廊道入口。  
在场人物：宁烬（双真）、商妩、鹿闻灯及新生院人员、车夫老阮、三辆逆月盐车。  
即时伤势：宁烬元力近乎耗尽，镜海界旧伤开始发热；商妩右肩返伤相持续外撑。  
手中关键物品：骨灯、黑门骨、海眼碎片、赤曜灯芯、储物戒。  
当前敌人或追兵：暂无追兵进入旧创；白颅城、白髓商团、贺沉骨、无痕盟均可能争夺或封闭骨芽廊道。  
当前倒计时：月亮再落一寸，约一夜后，骨芽廊道将开始改路。  
下一步直接目标：查明骨芽廊道能否通行，并争取为三辆盐车与商妩找到新的生路。  
当前主动目标：与商妩进入骨芽廊道，确认并争取这条新盐路。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 双真共享同一元力池；宁烬当前元力近乎耗尽，短期难以连续作战。
- 镜海界旧伤会在元力运转或返伤相影响下发热，具体后果未明。

### Active Relationships

商妩（白髓商团验货人）｜争取新盐路并保住生路｜与宁烬为相互承担风险的雇佣合作关系｜主动要求同行进入骨芽廊道｜共同查明并争取新通道。  
鹿闻灯（新生院院长）｜让院民有盐、有路并存活｜与宁烬、商妩暂为有限接触与交换关系｜确认商妩返伤相并提出留院｜是否提供路线协助未决。

### Identity / Access

- 商妩仍为失籍者，失去白颅城医馆、盐窖与商籍担保。
- 新生院可暂时收留并提供压制返伤相的盐，但尚未形成长期承诺。

### Knowledge / Enemy State

- 骨芽廊道封闭多年，可能重新连接白颅城外骨地与十二肋廊。
- 廊道开启可能带来通行机会，也可能使沉髓海热髓冲向城下。
- 白颅城、白髓商团、贺沉骨、无痕盟对廊道分别存在控制、收费、封锁或彻底封闭意图。

### World State

- 巨尸旧创内的骨芽廊道正在自行生长，预计一夜后开始改路。
- 白颅城与十二肋廊之间可能重新出现连接，相关势力将围绕廊道通行权与安全风险行动。

### Tracked Assets

剩余三辆逆月盐车｜商妩及车夫｜新生院骨棚外｜车队尚存，作为交换盐与谋求新路的关键资源｜抵达新生院后保留。

# Proposed Chapter Summary

宁烬护送商妩与三辆盐车抵达新生院，得知商妩的返伤相已无法获得白颅城救治。旧创中的骨芽廊道正在重新生长，一夜后将开始改路，可能连接白颅城与十二肋廊，也可能引发热髓冲城。宁烬决定与商妩进入廊道探路。
