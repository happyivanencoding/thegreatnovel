# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 两处骨唇活口已随宁烬返回玄曜大界，未被天地环境抹除。
- 活口可在玄曜近距离导引风流；仍不能传送人或物。
- 双真共享元力、同步受伤，双端死亡风险仍在。
- 骨质伤口与风髓双口结构需缓慢恢复，不能用元力强催。

### Active Relationships

商妩（白髓商团验货人）｜独立经营新盐路并履行三成利润约定｜与宁烬为共同经营、共同承担风险的合伙关系｜宁烬离开，商妩确认将自行继续经营｜三成利润待兑现。  
鹿闻灯｜继续经营新生院并维护新通道｜与宁烬保持信任合作｜确认新通道即使宁烬离开也会继续运转｜后续处理新生院与通道事务。  
贺沉骨｜封闭危险支路、保持主廊开放｜与宁烬保持有限合作｜继续拥有封路权｜后续维持通道安全。

### Identity / Access

- 宁烬作为新通道实际开路者的公开影响仍留在骨陆，但本人已返回玄曜大界。

### Knowledge / Enemy State

- 黑门骨映出两座未知世界：无主兵荒原、无墙宫殿。
- 两座世界的人员、规则、入口与出口均未知。
- 骨陆新盐路已在宁烬离开后继续运行，白髓商团暂未收回控制权。

### World State

- 新通道已脱离宁烬现场介入，仍由商妩、新生院与贺沉骨等人继续运营。
- 骨陆运输路线缩短，髓藻与逆月盐交易价格开始重新调整，失籍者流动入口持续改变。

### Tracked Assets

黑门骨｜宁烬｜玄曜大界赤褐色山地，已收回储物戒｜可开启跨世界门影，曾映出两座未知世界｜本章由骨陆带回玄曜并显示新影像。  
骨纸盐路约定｜商妩｜商妩身上｜记录宁烬三成盐路利润｜本章继续有效，利润未兑现。  
风髓双口｜宁烬双真｜两处真身左肋｜结构随身保留，仍在恢复｜本章确认已跨世界带回玄曜。

# Proposed Chapter Summary

宁烬离开骨陆，商妩决定独立经营新盐路，鹿闻灯确认新通道会继续运转，宁烬三成利润仍被记录。宁烬带着两处风髓骨口和黑门骨返回玄曜大界，确认骨口未被天地抹除且境界仍为灵海四重。黑门骨显出无主兵荒原与无墙宫殿两座未知世界，宁烬收起黑门骨，带着双真向荒地前进。
