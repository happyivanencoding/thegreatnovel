# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 双真可同时前往两个方向并独立行动，但共享同一元力池。
- 返伤相已使两处旧伤同步裂开，伤势会同时牵动两具真身与灵海。
- 宁烬拒绝用逆月盐延缓本轮痕生，选择主动进入骨芽廊道探路。

### Active Relationships

商妩（白髓商团验货人）｜带三辆盐车撤往高坡并等待宁烬开路｜与宁烬为相互承担风险的雇佣合作关系｜明确表达担忧并继续配合撤离｜三成利润尚未结算。  
鹿闻灯（新生院院长）｜疏散院民与盐车、避免堵在主廊｜与宁烬、商妩为有限互助关系｜下令将盐车撤向高坡并提供逆月盐｜新生院能否持续庇护仍未定。  
贺沉骨｜封锁危险支路并等待髓潮方向｜与宁烬、商妩处于通道争夺关系｜公开承认主廊尚未决定归属｜将如何处置宁烬双真与两条通路未决。

### Knowledge / Enemy State

- 返伤相已经到达，裂骨风与热髓潮同时逼近骨芽廊道。
- 十二肋廊方向的裂骨风会削利骨芽，沉髓海方向已开始渗出温热髓液。
- 骨陆各方已亲眼确认宁烬能够让两个真实位置同时行动，相关传闻获得公开证实。
- 贺沉骨、无痕盟与白颅城护卫尚未取得廊道控制权。

### World State

- 骨芽廊道争夺从预备封锁进入裂骨风与热髓潮同时逼近的公开危机。
- 新生院开始将人员与盐车撤向高坡，主廊附近的通行与避险秩序已经改变。

### Tracked Assets

逆月盐十二包｜商妩持有一包，其余由鹿闻灯暂存｜商妩腰间／新生院｜一包被保留给新生院，其余未转移｜商妩明确放弃立即使用。  
剩余三辆逆月盐车｜商妩及车夫｜由骨棚外撤向新生院外高坡｜车队尚存，正在撤离｜鹿闻灯已下令疏散。

# Proposed Chapter Summary

返伤相在月轮升至最高处时到来，宁烬两处真身的旧伤同时裂开。面对裂骨风与热髓潮同时逼近，宁烬拒绝用逆月盐封住旧伤，让商妩带三辆盐车撤向高坡，自己分赴十二肋廊与沉髓海出口探路开路。骨陆各方也亲眼确认了双真的真实存在。
