# Proposed Active Scene State

地点：骨芽主廊新开的狭长通道与白颅城外侧荒骨地之间。  
在场人物：宁烬双真、商妩、鹿闻灯、新生院人员、牧民、车夫、贺沉骨及各方护卫。  
即时伤势：宁烬两处旧伤裂开，形成骨唇状活口；元力几乎耗尽，受巨骨重压并持续流血。商妩右肩骨甲碎裂，伤口出血，行动受限。  
手中关键物品：骨灯、黑门骨、海眼碎片、赤曜灯芯、储物戒。  
当前敌人或追兵：裂骨风与热髓潮余势；廊道仍可能继续闭合，各方势力仍在场。  
当前倒计时：最凶险的一波已过去，通道与泄口仍未完全稳定。  
下一步直接目标：护送商妩、三辆盐车及撤离人员抵达安全高坡，确认新通道不会再次封死。  
当前主动目标：保住两处活口与新通道，让车队和人员安全通过。

# Proposed Persistent Canon

### Power / Capability
Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 返伤相使两处旧伤形成对应的骨唇状“活口”。
- 两个活口可导入并转移风、热髓、液压与热流，形成跨两处真身的通道。
- 两处真身必须同时存活，且两个活口都不能被堵死；该结构不是额外经脉或额外元力。
- 白昼火可灼定活口边缘、硬化骨芽并短时维持通道。

### Active Relationships
商妩（白髓商团验货人）｜继续协助宁烬与车队撤离｜与宁烬形成共同承担生死风险的合作关系｜主动返回救出受压的宁烬并承受右肩伤势｜三成利润尚未结算。

### Knowledge / Enemy State
- 新通道已将热髓导向白颅城外侧荒骨地，避免其倒灌城下旧创。
- 十二肋廊与白颅城外侧之间已形成一条暂时可通车的泄压通路。
- 各方已亲眼见证宁烬以两处活口导引风髓，并确认其结构存在明确的同时存活与不堵塞限制。

### World State
- 骨芽廊道危机暂时解除，三辆盐车、牧民与新生院人员已通过新通道。
- 白颅城外侧新增热髓泄口，十二肋廊与白颅城之间的通行和势力争夺格局已改变。

### Tracked Assets
逆月盐十二包｜商妩持有一包，其余由鹿闻灯暂存｜车队与新生院撤离路线上｜一包已交给鹿闻灯，其余未转移｜商妩未使用。
剩余三辆逆月盐车｜商妩、车夫及撤离队伍｜已通过骨芽主廊新通道｜车队完整但受高温冲击｜本章未发生新的转移。

# Proposed Chapter Summary

返伤相令骨芽主廊闭合、热髓逼近白颅城。宁烬双真以裂开的旧伤形成两个骨唇活口，借白昼火导引裂骨风与热髓，撑开主廊并将热髓泄向城外荒骨地。商妩冒险协助宁烬脱离巨骨，三辆盐车与撤离人员最终安全通过。

# Proposed Open Promises

- 两处骨唇活口能否在后续稳定存在，以及会继续长成什么结构。
- 两处真身共享活口、同步受伤的长期代价。
- 新开的热髓泄口与骨芽通道是否会改变白颅城及十二肋廊的势力争夺。
- 贺沉骨、无痕盟与白颅城势力将如何处置宁烬与这条新通路。
- 商妩右肩骨甲与返伤相伤势是否会继续恶化。
- 新生院是否继续为商妩、车队与宁烬提供盐和庇护。
- 黑门骨与巨尸骨陆的连接及更深机制仍未知。
- 双真能否与骨芽廊道形成真正复合。
