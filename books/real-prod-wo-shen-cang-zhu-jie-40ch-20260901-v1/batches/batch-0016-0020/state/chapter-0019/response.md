# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 两处骨唇活口只能引导风、热、液压等流动力量，不能传送人或物。
- 两处真身必须同时存活，且两端不能被彻底堵死；骨质伤口仍需恢复。

### Active Relationships

商妩（白髓商团验货人）｜自行经营新生院至十二肋廊盐路｜与宁烬为共同经营、共同承担风险的合伙关系｜正式确认宁烬享有盐路利润三成｜利润尚未兑现。  
贺沉骨｜封闭危险侧缝、维持主廊通行｜与宁烬保持有限合作｜明确表示主廊不封｜后续将继续处理热髓侧缝。

### Identity / Access

- 商妩脱离白髓商团担保，暂以自身车队和新通道经营盐路。
- 宁烬作为新通道的实际开路者，已获得各方公开重视与议价影响力。

### Knowledge / Enemy State

- 新通道已可供盐车通行，首辆空车已驶向十二肋廊。
- 白颅城与白髓商团暂未能封锁通道；新生院、十二肋廊牧民和贺沉骨共同阻止封路。
- 黑门骨在储物戒中出现轻微震动，原因未知。

### World State

- 骨芽廊道新通道正式投入通行，白颅城、新生院与十二肋廊之间的运输和失籍者流动入口已经改变。
- 商妩拒绝白髓商团与城主府接管，盐路暂由新生院与商妩一方实际运营。
- 贺沉骨封闭危险侧缝，但主廊保持开放。

### Tracked Assets

逆月盐｜已由商妩一方卖给新生院｜新生院药棚及盐囊堆放处｜部分已用于救治，剩余作为盐路货物｜本章完成交易。  
剩余三辆逆月盐车｜商妩及车队｜新生院外与新通道沿线｜盐货已售，首辆转为空车并驶向十二肋廊｜本章发生用途变化。  
骨纸盐路约定｜商妩持有｜商妩身上｜记载新生院盐价、主廊通行日与宁烬三成利润｜本章新立。

# Proposed Chapter Summary

天亮后，新通道仍可通车，新生院以低价接收盐并救治伤者。商妩拒绝白髓商团和城主府接管，决定自行经营盐路，并正式确认宁烬享有三成利润。贺沉骨封闭危险侧缝但不封主廊，各方暂时承认通道开放。首辆空车驶向十二肋廊，黑门骨在储物戒中突然震动。
