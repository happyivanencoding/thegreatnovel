# Proposed Active Scene State

地点：万门宫七影廊，宁烬两具真身分别位于长昼太阳长廊与赤潮太阳石桥，各自门影内  
在场人物：宁烬两具真身；陆移烛；宿无眼；阮七娘  
即时伤势：两具真身左肋伤口持续渗血；掌心灼伤在赤潮太阳下加剧；元力几乎耗尽  
手中关键物品：黑门骨  
当前敌人或追兵：无明确敌人或追兵；两轮太阳正在分别侵染两具真身  
当前倒计时：十三天后无影换席，第八接点翻出  
下一步直接目标：在两具真身被不同太阳进一步认领前，选择可立即行动的交易或入口  
当前主动目标：保住两具真身的行动能力并寻找脱离争影状态的办法

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境九重｜精确位置：灵海4重
- 双真进入万门宫后仍共享元力与伤势，但已分别受到长昼太阳与赤潮太阳的影界侵染。
- 万门宫中，影子所属的太阳决定身体被哪一侧逐渐认领；不同太阳的交界会对双真造成持续身体压力。
- 双真之间即使相隔不到十步，只要影子不相接，也无法直接接触或传递力量。

### Active Relationships

- 陆移烛（悬胎院医师）｜请求宁烬将腹部隆起、受两轮太阳争认的孕妇送往蓝黑影路｜暂为求助关系｜已提出交易请求｜等待宁烬决定是否帮忙。
- 宿无眼｜希望宁烬进入无昼井深处切断长昼根影｜暂为招募关系｜承诺开放黑根田与背日兽的路｜等待宁烬回应。
- 阮七娘（共影棚主人）｜准备向宁烬出售第八接点相关价码｜暂为交易关系｜确认宁烬是双真且掌握其争影困境｜等待宁烬听价。

### Identity / Access

- 宁烬作为外来双真进入万门宫，已被陆移烛、宿无眼、阮七娘识别。
- 阮七娘掌握共影棚及七影廊深处的接点信息。

### Knowledge / Enemy State

- 万门宫的门不是普通通道，而是太阳划出的影界边界；影子接上即可跨越远距，影子断开则近在眼前也难以抵达。
- 第八接点将在十三天后无影换席时翻出，可将原本相隔极远的两片区域接成近邻。
- 万门宫居民的居所、婚姻与行动都受太阳和影子接合状态约束。

### World State

- 万门宫存在多轮太阳划定的稳定影域；居民依靠影子边界搬迁、生活和维持关系。
- 不同太阳下的居民只能在交界或共影棚中短暂接合影子；太阳偏移会立即中断接合。

### Tracked Assets

- 黑门骨｜宁烬｜身上｜开启万门宫入口，仍可映出无墙宫殿与门影｜持有者未变
- 续事阶1位薄铁牌｜宁烬｜身上｜有效｜持有者未变

# Proposed Chapter Summary

宁烬通过黑门骨进入万门宫，发现两具真身虽相隔十步，却因影子断开无法接触，并分别受到长昼与赤潮太阳侵染。陆移烛、宿无眼和共影棚主人阮七娘先后提出救人、入井和第八接点交易，宁烬决定先听阮七娘的价钱。
