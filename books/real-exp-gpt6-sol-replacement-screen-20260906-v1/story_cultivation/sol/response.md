# STORY PROGRAM

## 核心碰撞

- 祁烈即使没有特殊力量，也会追逐有观众的胜负、能立刻花掉的钱、速度与失重。他想让父亲看见自己赢，却不肯用服从军府安排来换那声认可。每次公开胜利都可能同时带来他渴望的重新估价，以及他厌烦的招揽、管束和归属要求。
- “一次失败永久留下正确动作”会诱使祁烈主动去碰危险。他容易把“同一种失败不会再奏效”误判成“危险已经被自己吃透”；陌生攻击、改变结构的第二招、境界造成的基础差距和来不及承受的第一次重创，仍然可以让他付出真实代价。
- 闻青禾追父亲的灯号，顾砺川要偿还旧债，迟雁秋要封住她认为不该再开的深处，折翎要夺回幼鸟，傅寒钟与乔素问要为两种铸兵道路争胜。这些目标都先于祁烈存在；他只能选择撞进哪一条路线，不能把众人的冲突整理成共同任务。
- 闻青禾的冒险欲、折翎带来的速度、乔素问能做出而祁烈真想拥有的兵器，都会改变他的路线。尤其闻青禾不是需要他保护的委托人：她会先出发、会抛下他继续追信号，也会在关键处反过来救他，因此祁烈为她放弃某件东西时，那是关系已经改变选择，不是责任感自动接管人物。
- 军府街生活只让祁烈认得白山纹、驮兽和几套残缺枪架。精确、守路、损失归因等职业残留只在少数现场帮助他看见局部细节，不成为跨阶段解题语法。

## 不可降格的 Reader-Facing Story Events

### RSE-01
事件原子：祁烈把一次普通的军府脚夫选拔拱成两轮公开赌赛 → 第一轮在所有人面前被邵峥撞出木桩道 → 第二轮再次遇到同一失衡时，身体自行完成他从未练成的落脚与回身 → 仍是启源0层的他当场赢下十二枚银币，立刻买走那双惦记已久的轻靴。

状态残留：祁烈拥有鹿筋轻靴和剩余奖钱，第一次知道自己亲身吃过的败法会留下修正；军府街开始记住他的名字。该状态不能替代两轮赌赛中“先败一次、再让同一败法失效”的现场。

排程边界：阶段1内由 Outline 排章。

读者证明锚点：军府街；启源0层；十二枚银币；鹿筋轻靴

### RSE-02
事件原子：灰昼中折翎撞入拍卖院救幼鸟 → 第一次俯冲把刚到启源1层的祁烈掀落屋脊 → 折翎沿同一风线第二次压来时，他的身体自动换脚、贴翼避开骨锋，并用刚能驱动的元息切开幼鸟锁笼 → 他放弃猎杀折翎能换来的赏钱，被折翎带着越过城墙，第一次从空中看见落月原。

状态残留：幼鸟回到雁群，折翎不再把祁烈视作普通捕猎者；城中只知道启源1层的祁烈第二次避开了不可能避开的俯冲，不知道修正会永久留下。该结果不能替代第一次坠落、第二次修正、放弃赏钱与越墙飞出的完整事件。

排程边界：阶段2内由 Outline 排章，必须发生在第一次灰昼大碰撞现场。

读者证明锚点：灰昼；折翎；拍卖院；启源1层；落月原

### RSE-03
事件原子：回光裂谷深处再次亮起三短一长 → 祁烈与闻青禾同时看见嵌在黑壁中的完整古枪“沉星枪” → 封口异象压落时，闻青禾把父亲的破损方向盘抛给祁烈，自己被断桥隔住 → 祁烈放开已经握住的沉星枪，沿第一次坠桥留下的修正路线回身救她 → 顾砺川以贯脊2层异象撑开一线，两人从迟雁秋贯脊4层正在闭合的封口中逃出，而沉星枪永久坠入封层。

状态残留：闻青禾与祁烈共同带出方向盘和仍带余温的灯灰；沉星枪明确失去，不能在没有新因果时重新到账；顾砺川与迟雁秋的旧分歧公开破裂。该状态不能替代“古枪已经到手边、祁烈主动放开、再回身救人”的选择现场。

排程边界：阶段4内由 Outline 排章。

读者证明锚点：回光裂谷；三短一长；沉星枪；贯脊2层；贯脊4层；破损方向盘

## 全书成长与核心幻想兑现脊柱

- 开书时祁烈是`启源0层`。军府街赌赛只证明最简单的身体修正已经成立：第一次摔出桩道，第二次身体直接完成正确落脚。它不提供元息，不把胜负反推成境界提升。
- 祁烈用奖钱购买正规启源课程、食物和恢复时间。第一次自然训练窗口必须直接说清：普通人发现元息泄漏后，还要用同一负荷反复受伤、恢复，才能把正确循环固化；祁烈第一次真实失败后就不再重复漏在同一处，因此少掉的是重复试错与伤停，吸收上限、食物、睡眠和身体结构仍一个不少。经过足够负荷与恢复后，他抵达`启源1层`，第一次能主动让元息循环、护住伤口并送入兵器。
- 灰昼、雁背和裂谷把单个修正扩成连续动作：落脚、贴翼、回枪、失衡复位可以在多重压力下接成一条路线。但阶段3至阶段4期间他仍保持`启源1层`；裂谷伤势与缺少恢复条件使精确位置没有上涨，读者能明确知道“动作更稳了，身体总量没有凭空变强”。
- 阶段5经过数月恢复、进食和正常负荷，祁烈抵达`启源2层`。乔素问把自己早已完成的换衡枪结构，与折翎在幼鸟归群后主动留下的一根断裂长羽结合，铸成归祁烈所有的“折风枪”。普通长枪在灰昼横风和雁背转向中只会拖拽持枪者；折风枪能把横风变化传到掌心，并在元息灌入时改变枪身配重。它是由乔素问、折翎与祁烈已经走过的路线共同产生的新外部非对称优势，不改写 Power Core。
- 折风枪与修正反射第一次复合时，祁烈能够把一次已经失败过的空中换位直接接成持枪反击：枪给出当前风向，身体调用上次留下的正确动作，二者合在一起才让一个不能飞的启源修士在异兽急转中保持攻击。后续再次乘上折翎时，他自然复用旧修正，让读者亲眼确认永久性；折翎仍有自己的选择，不因此变成坐骑财产。
- 傅寒钟`通肢6层`与乔素问`通肢3层`会提前让祁烈亲眼看见稳定飞行；顾砺川`贯脊2层`与迟雁秋`贯脊4层`会让他看见覆盖战场的异象。通肢1层与贯脊1层因此先成为他真正馋过、怕过的公共新动词。将来抵达时，正常里程碑仍分别是飞行与展开异象；祁烈的版本才会在飞行失衡和整套功法换轨中调用旧修正，不能反过来改写公共规则。
- 当前 Horizon 只批准折风枪这一项新非对称资产。更远阶段仍必须让新的高价值非对称优势从祁烈实际选择的人、地点、争夺或物件中加入，并与修正反射产生任一单项做不到的新结果；不得在 World Expansion 之前替未知世界预选最适配升级。

Book-Level Longitudinal Spine：

- 父亲能否承认祁烈，而不把承认附加成“进入军府、按旧兵规生活” → 下一次父亲主动支持或拒绝祁烈的一项具体去留，会改变这条关系 → 两人能否在不互相驯服的情况下真正站到同一边，仍保持未知。
- 三短一长究竟来自闻照野、遗留装置还是另一个掌握信号的人 → 新的实物、信号位置变化或可靠目击会改变追索方向 → 闻照野是否活着、回光黑壁展示什么，仍保持未知。
- 祁烈公开表现超过`启源2层`的常规估值后，会被军府、宗门和商盟怎样重新定价 → 下一次真实招揽、针对或拒绝准入将改变他可选择的身份路线 → 他最终愿意把名字系在哪一方，仍保持未知。
- 折翎为何愿意再次靠近人城，以及祁烈与它的关系能走到哪里 → 幼鸟、猎队或灰昼路线出现新的现实变化时，双方必须重新选择距离 → 折翎会成为长期同行者、偶尔相助的异兽还是再次与人敌对，仍保持未知。

### Reader-Facing Actor Ruler Anchors

- ACTOR-RULER-01｜人物：傅寒钟｜精确位置：通肢6层｜展示：离地稳住月铁与古兵熔接位置，在灰昼横风中继续掌炉｜时机/地点：阶段2／百炉会公开试锋场｜现场意义：祁烈第一次看见通肢修士能把天空当作正常立足处，也明白傅寒钟有能力追击折翎却选择守住最后一炉
- ACTOR-RULER-02｜人物：乔素问｜精确位置：通肢3层｜展示：飞越燃烧屋脊切断坠落棚架，随即返回试锋台让自己的护卫枪阵继续受检｜时机/地点：阶段2／拍卖院与百炉会相邻街区｜现场意义：她能救下眼前人，却不会替军府追雁；她真正要赢的是作品比较与订单
- ACTOR-RULER-03｜人物：顾砺川｜精确位置：贯脊2层｜展示：展开白山般的战场异象，撑住裂谷侧道与持续石雨｜时机/地点：阶段4／回光裂谷封口｜现场意义：祁烈第一次知道一个人为何能成为一城支柱，也看见顾砺川仍无法正面压过迟雁秋
- ACTOR-RULER-04｜人物：迟雁秋｜精确位置：贯脊4层｜展示：让覆盖裂谷口的封山异象持续闭合，并压碎低阶兵器无法承受的石桥｜时机/地点：阶段4／回光裂谷封口｜现场意义：她无需击中祁烈就能夺走整条退路；祁烈逃出只算局部脱身，不等于击败或绕空四层差距

## 不可替代的人与关系

- **父亲**最想阻止祁烈把一次幸运当成可以无限下注的本钱，却又希望儿子真能走到自己当年没有资格进入的位置。如果祁烈消失，他仍会守着汤摊、在旧军府熟人面前追问裂谷封口，并拒绝替任何一方劝儿子归队。新增共享历史是：十六年前他正值北门，亲手放顾砺川与迟雁秋的负伤回撤队入城；他听见顾砺川当时要求回头找闻照野，也看见第二天顾最终签下“普通塌方”。他不知道裂谷真相，这段过去只使他今天不肯相信顾的保证，也让顾无法把他当普通军属敷衍。该历史不解释祁烈整个人，也不成为父亲膝伤或家庭生活的总根因。父亲不可替代，因为祁烈想要的不是长辈泛泛认可，而是这个从不夸他、又确实看得懂他站姿的人亲眼看见胜负。
- **闻青禾**最想找到父亲或得到足以停止自我欺骗的证据；她自己的未完之事是追完三短一长，而不是陪祁烈成长。如果祁烈消失，她仍会买通旧矿工、走废弃排水道，并把顾砺川的旧报告逼到无法继续沉默。她与祁烈互相吸引的不是安全感：她敢先走，他敢把她没说出口的路线变成赌局；两人都会嫌对方抢在自己前面。她不可替代，因为只有她同时握有破损方向盘、闻照野的私人记忆与主动下裂谷的决心；换一个同样勇敢的探险者，祁烈不会为其放开已经握住的沉星枪。
- **折翎**最想让两只幼鸟脱离人类买卖，并重新获得一条不经过城墙灯塔的灰昼迁徙线。如果祁烈消失，它仍会袭击拍卖院、带幼鸟离城并记住伤害过雁群的人。它不会因为被救就接受驯服；允许祁烈靠近、留下断羽或再次载他，都是每次重新作出的选择。折翎不可替代，因为速度、失重、非人的判断和雁群亲缘共同构成祁烈在人类组织里得不到的生活特权。
- **乔素问**最想让可修、可量产的护卫兵器在真实使用中胜过一件昂贵孤品。她尚未完成的是证明自己的道路能长期救人，而不是只赢一次试锋。如果祁烈消失，她仍会完成军府首批订单、记录实际断损，并继续与傅寒钟争夺百炉会下一代的话语权。她不可替代，因为折风枪来自她十二年商队维修积累和对傅寒钟技艺的反向继承；另一个器师可以做出好枪，却不能做出同一件带着这段师徒争执的作品。
- **顾砺川与迟雁秋**共享闻照野留下的旧结，却要相反的结果。顾砺川要让自己十六年前的签字不再决定今天，迟雁秋要阻止一次私人追索把更大势力引向裂谷。如果祁烈消失，顾仍会接管入口并补写报告，迟仍会完成封口。顾不能替代迟的判断，迟也不能替代顾的亏欠；两人的力量、旧友关系和不同选择共同决定祁烈与闻青禾面对的是一条正在闭合的路，而不是等待主角领取的遗迹任务。

## 长期故事主线

### 阶段1｜军府街十二枚银币

**为什么现在发生：** 灰昼将至，军府要在封路前补选一批驮兽脚夫。原本只是按时完成木桩道的普通选拔，祁烈为了观众、奖钱和轻靴，主动追加自己的赌金，把它拱成与军府后备邵峥的两轮公开竞速。

**谁想要什么：** 祁烈要整条军府街看见自己赢，并拿到能随手花的钱；`启源2层`的邵峥要用一次干净胜利锁定军府后备位置；父亲希望祁烈及时停手，至少别再让家里替他填赌债；军府领队只想选出能在灰昼前可靠赶路的人。

**主角的关键选择与行动：** 祁烈第一轮被撞出木桩道后，没有用“对方是修士”替自己收场，而是把剩下的钱也压进第二轮。身体在同一失衡出现时自行换脚回身，他利用的是路线与动作，不与邵峥硬拼力量。赢下十二枚银币后，他当着父亲的面先买鹿筋轻靴，而不是把全部钱交回家。

**这一阶段真正的阅读满足：** 启源0层少年第一次让同一种败法当众失效；明确的钱与轻靴立刻到手，父亲也确实亲眼看见，只是没有因此变得温顺。

**Stage Delta：** 祁烈确认最简单的修正反射真实存在，但仍是`启源0层`；他获得十二枚银币并买下鹿筋轻靴；邵峥从“无须记住的普通少年”改为愿意研究其步法的本地对手；父亲第一次无法再用“你连门都没进去”结束争执。

**下一阶段为何自然发生：** 祁烈用剩余奖钱购买正规启源课程、食物和恢复条件；灰昼当天，他要穿新靴去看傅寒钟与乔素问的公开试锋。与此同时，折翎已经开始下一次入城，闻青禾也在等同一个灰昼打开排水侧道。

### 阶段2｜灰昼撞城

**为什么现在发生：** 祁烈经过足够训练和恢复，刚完成启源检测；傅寒钟必须在手部震颤恶化前熔接月铁，乔素问的军府订单试锋也不能再延。灰昼让百炉会、拍卖院、雁群和闻青禾的侧道计划在同一片北城同时启动。

**谁想要什么：** 祁烈要让人看见自己已是正式修炼者，也想近距离感受通肢修士与名兵的分量；折翎只要夺回两只幼鸟；闻青禾要借混乱从排水道出城；傅寒钟要完成最后一件证明古兵值得修的作品；乔素问要让自己的护卫枪在真实混乱中仍能救人并赢下订单。

**主角的关键选择与行动：** 祁烈先扑向折翎，想把第一次正式出手变成全街高光，因此吃下第一次屋脊坠落。第二次俯冲时修正反射接管落脚，他没有追求杀雁赏金，而是切开幼鸟锁笼、抓住折翎带出的速度窗口。现场的撤人、封街和追击分别由军府、商盟与宗门处理，他只决定自己放什么、抓住什么。

**这一阶段真正的阅读满足：** `启源1层`的公共新动词与修正反射第一次在同一场公开危机中兑现；祁烈放弃一笔现成赏钱，换来无人能买到的雁背越墙与第一次俯瞰落月原。

**Stage Delta：** 祁烈抵达`启源1层`，能主动循环元息、护住伤处并驱动兵器；老师已用白话说明他的优势减少重复试错与伤停，却不增加吸收上限。折翎带回幼鸟，对祁烈形成有限识别而非驯服。乔素问的护卫枪阵在混乱中继续工作，赢得军府批量订单；傅寒钟完成月铁熔接，使军府古兵重新可用，但他的作品仍无法量产。两条铸兵道路都取得真实结果，双方再也不能把对方简单称为失败者。闻青禾从侧道出城，祁烈被折翎带到她前方的落月原。

**下一阶段为何自然发生：** 祁烈落地后看见闻青禾携破损方向盘钻入旧排水口，也亲耳听见裂谷方向的三短一长。他已经得到想看的落月原，却发现真正让人想追的东西正在地下移动。

### 阶段3｜侧道里的活灯

**为什么现在发生：** 闻青禾不会等军府与宗门争完入口权；灰昼正是旧排水道唯一不被完整监视的窗口。祁烈不是受邀队员，他因为已经看见她的路线、听见灯号，又不肯让这场故事在自己落地后继续远去，主动跟进侧道。

**谁想要什么：** 闻青禾要先于顾砺川和迟雁秋碰到信号源；祁烈要看见发灯的人、证明自己不是只会赢街赛，也想抢到一件真正值钱的裂谷发现；顾砺川要从主入口接回闻青禾并重新面对旧事；迟雁秋要在侧道完全打开前封死裂谷。

**主角的关键选择与行动：** 祁烈把同行变成“谁先摸到发灯处”的单方面赌局，闻青禾不接受赌注，却也不为他放慢。第一次黑壁投影后的落石使他找到一条修正路线；下一段相似画面却对应不同方向的崩裂，他误以为自己已经吃透规律，被新结构真正击伤。此后他停止把能力当答案，只在同一失败确实重现时调用修正。两人抵达仍有余温的灯灰，并在更深裂隙看见沉星枪。

**这一阶段真正的阅读满足：** 回光裂谷的未知保持在故事前景：黑壁画面、三短一长、余温灯灰与沉星枪同时出现，却没有任何一项被“遗迹归属”提前结算。祁烈与闻青禾形成能互相抢先、也必须互相补缺的危险关系。

**Stage Delta：** 祁烈仍是`启源1层`，伤势使当前发挥暂时下降；他明确知道修正只覆盖真正相同的失败模式。闻青禾不再把他当误入者，却不会把方向盘或决定权交给他。两人确认灯号近期曾被实际点亮，但发信者、回光画面的性质与闻照野生死仍未知。沉星枪成为明确的高价值欲望：它能在贯脊压力残留中保持完整，既可能值巨款，也可能让低阶持有者拥有远超普通兵器的承受上限。

**下一阶段为何自然发生：** 顾砺川和迟雁秋已经分别抵达主入口；他们的贯脊异象开始改变整条裂谷。继续追灯、取沉星枪和及时离开不再能同时完成，祁烈与闻青禾必须在封口真正落下前作出选择。

### 阶段4｜沉星枪落下去

**为什么现在发生：** 迟雁秋确认侧道已被重新打通，立即开始整体封口；顾砺川兑现“重新开门”的行动，以较弱的贯脊2层异象强撑退路。闻青禾仍追向灯号，祁烈已经握到沉星枪，没有任何人愿意等待另两方谈妥。

**谁想要什么：** 祁烈要把沉星枪带走，也要与闻青禾一起活着出去；闻青禾要保住方向盘并确认灯号没有终止；顾砺川要救出两人、带回能推翻旧报告的新证据；迟雁秋宁可失去古枪和侧道，也要让深处停止向外开放。

**主角的关键选择与行动：** 祁烈先抓住沉星枪，真实感受到它值得多少钱、能承受怎样的力量。封口压断石桥后，闻青禾把方向盘抛给他，让他至少带证据走；他没有替众人判断裂谷该开还是该封，只选择放开枪、返回断桥救她。顾砺川承担正面异象压力，祁烈则用自己已经失败过的坠桥路线完成回身；迟雁秋不断改变封口方向，使他无法靠一个局部克制穿空境界差距。

**这一阶段真正的阅读满足：** 贯脊强者的公共分量第一次完整落地，启源1层的祁烈只能在两名高阶者碰撞形成的一线窗口中夺回一个人；沉星枪已经到手又被主动放弃，使闻青禾与祁烈的关系获得不可替代的实际重量。

**Stage Delta：** 沉星枪坠入封层并明确失去，当前结算不发放同分量替代古兵。祁烈与闻青禾共同逃出，关系从临时同行变成彼此都曾放弃更直接收益的共犯。顾砺川公开站到重开旧案的一边；迟雁秋完成大部分封口，却没能消灭方向盘、灯灰和两名目击者。祁烈仍是`启源1层`，重伤需要正常恢复；他没有因逃出贯脊异象自动升级。

**下一阶段为何自然发生：** 裂谷行动结束后，旧报告、百炉会试锋、幼鸟归还和祁烈的公开表现都必须在石灯城产生现实后果。祁烈还没有拿到古枪，却已经让乔素问、折翎、军府与归岫宗分别改变了对他的下一步行动。

### 阶段5｜折风枪与第二次飞行

**为什么现在发生：** 数月恢复与训练后，祁烈的循环、持续输出和次日恢复终于稳定到`启源2层`。乔素问要为首批军府护卫枪完成公开交付试锋；折翎在两只幼鸟安全归群后再次来到城外，留下灰昼中折断的一根长羽。乔素问已经拥有枪的结构，祁烈也拥有材料与真实雁背经验，折风枪因此从既有关系中成立。

**谁想要什么：** 祁烈要一杆真正属于自己的枪、试锋奖金和全街第二次改价，也要父亲这次站在看得见的位置；乔素问要让首批作品在最苛刻的实战动作中获胜；邵峥已经观察过祁烈的公开表现，要证明只要每一招都不重复，修正反射便没有轻易取胜的机会；父亲要确认儿子的胜利究竟来自可持续成长还是继续拿命下注；折翎只决定祁烈是否配得上第二次靠近雁背。

**主角的关键选择与行动：** 邵峥以`启源3层`的更大基础盘持续更换攻击，不给祁烈复用单一解法，迫使他放弃一击翻盘的漂亮打法。祁烈依靠正常训练撑过不同压力，再用折风枪提供的横风与配重变化，把多个已经分别失败过的动作接成一次新组合；他以`启源2层`完成小幅越级胜利，但精确位置不因此变化。随后折翎允许他再次上背，旧有空中修正与折风枪第一次共同工作。

**这一阶段真正的阅读满足：** 祁烈获得折风枪的完整所有权、百炉会试锋奖金和公开胜利；旧对手的有效针对真实迫使他换打法，胜利来自正常力量、永久修正、具体兵器与现场横风的复合。父亲亲眼看见，并第一次承认这不是同一场侥幸。

**Stage Delta：** 祁烈抵达`启源2层`并拥有折风枪；他能在折翎急转中凭枪感知横风，再调用旧修正完成持枪换位，这是此前身体反射或兵器任一方都做不到的动作。百炉会把枪与奖金当场交给他，不降成借用或试用资格。军府与归岫宗分别提出正式入口，祁烈接受已经赢得的钱与作品，拒绝立即把去留交给任何一方。父亲承认他的胜负，却仍反对他继续追裂谷信号，两人从“是否看见”转成“看见之后是否仍允许彼此选择”。

顾砺川补交真实报告后，不能再以旧日沉默者身份维持现状；迟雁秋也不能再把闻青禾当作只持有传闻的失踪者家属。闻青禾拥有可检验的灯灰、方向盘变化和共同目击者，下一次追索有了新的实物条件。石灯城各方从此不能再把祁烈按“启源失败少年”报价，邵峥及其他真正看过他的人也会避免重复使用已经暴露的败法。这些共同构成当前 Horizon 的 Book State Mutation。

**下一阶段为何自然发生：** 石灯城能争的入口、能查的旧报告和能问的当事人已经用尽，三短一长却没有因侧道封闭而停止。祁烈想追的不再是下一场街赛，闻青禾也无法只靠本地旧矿工继续找父亲；更远行动必须等待一次独立的苍衡古星范围 World Expansion，而不是在本 Story Program 中预写目的地。

## World Horizon Handoff

- **触发条件：** 回光裂谷侧道封闭；顾砺川补交旧案报告；闻青禾带出灯灰与方向盘的新变化；祁烈在百炉会试锋后稳定于`启源2层`、获得折风枪，并主动决定追出石灯城现有知识范围。上述事实全部发生后，石灯城—落月原 Horizon 结束。
- **Expansion Scope：** `macro`
- **为什么此时必须扩：** 石灯城已经能够提供的公开胜负、修炼入口、裂谷当事人和地方记录不足以继续改变三短一长的答案；祁烈与闻青禾的下一步欲望都需要新的社会范围、资料来源与行动尺度。继续留在本地只会重复封口争执和低阶公开试锋。
- **Carry Forward：** 祁烈的`启源2层`精确位置、永久修正反射及其已公开但未被外人看穿的表现；折风枪、鹿筋轻靴和试锋奖金；折翎及两只幼鸟的自主关系；闻青禾、破损方向盘、余温灯灰与仍未知来源的三短一长；父亲与顾砺川、迟雁秋之间十六年前的北门见闻；顾砺川补交报告后的公开立场与迟雁秋已经完成的封口；傅寒钟修复成功的军府古兵、乔素问获得的批量订单；灰昼、残月环、既有精确力量主尺和全部公共里程碑。
- **Reader-Facing Edge：** Handoff 前最后1—2章，封闭后的回光黑壁仍短暂投出陌生星空，三短一长在画面中再次亮起；它只证明本地封口没有结束这个问题，不说明画面年代、地点、发信者或下一世界答案。
- **World Expansion Task：** 在触发条件成立后，运行 protagonist-blind World Expansion；World Agent 不读取 Current Character / Power Stack / Human / Future Story。扩展批准后再编译 Current Character，并运行 Story Refresh。

## 远期仍值得追的东西

- 闻照野是否活着、三短一长由谁发出，以及回光黑壁究竟展示过去、远方还是另一种现象。
- 祁烈能否持续获得新的路线型非对称优势，并让折风枪、修正反射及以后真实赢得的优势形成更深复合。
- 祁烈与父亲能否在不以服从交换认可的前提下改变关系；父亲掌握的北门见闻何时会迫使顾砺川或迟雁秋作出新选择。
- 折翎、两只幼鸟与人类城路的关系会怎样变化；它与祁烈的靠近是否能承受下一次真实利益冲突。
- 傅寒钟修复的孤品古兵与乔素问的批量护卫枪会分别改变谁的力量、价格与选择，两条铸兵道路是否还会再次正面碰撞。
- 残月为何破碎、古兵为何会在漫长沉寂后苏醒、断裂古路与无昼星墟分别隐藏什么；这些未知保持彼此独立，不预设为同一个幕后答案。
