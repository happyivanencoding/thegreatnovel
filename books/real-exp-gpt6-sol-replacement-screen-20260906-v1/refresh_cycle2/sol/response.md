# STORY PROGRAM

## 当前 Re-Collision

第3章的有效事实是：两枚同号钥牌共同开启了回影井石道；陆昭没有进入并返回；黑柄短刀受到牵引，刀面水痕与伤口血线出现逆向聚集。旧 Story Program 中建立在“第3章已经完成一次进入”的后续因果全部失效。

异常长雨、旧井坍塌、旧朝兵器出土、三大兵坊争货与城主府封井仍独立发生。它们不会因为陆昭只有纹阶4而降低危险，也不会主动提供适合钉影的兵器。

陆昭原本只想把钥牌验证出高价，同时不失去所有权。第4章的新证据却会使他的核心判断第一次失效：东西拿在自己手里，不再等于自己能够独占它的命运。

这使新碰撞不再只是“穷小子拿到宝物后如何保住”，而是：

**一个把占有看得极重的人，遇上一件即使握在手中也无法按普通方式确认归属的值钱东西。**

陆昭不会因此转职为回影井研究者。他首先想到的仍是加价、保密、排除竞争者和让别人为接触证据付钱；直到哥哥的实物出现，他才第一次为了某件不能按价出售的东西改变路线。

## 当前 Power / Human / World 的长期张力

陆昭仍是纹阶4。护街与雨猎骨干通常在纹阶7—10，能决定封井、兵器归属和公开处置的人远强于他。钥牌、短刀与现场经历的社会价格已经超过他的正面保护能力。

钉影每日最多三次，面对明显高阶目标只能争取极短时间。它能改变一次夺物、兵器落点或逃生结果，不能让陆昭击败纹阶跨度明显的对手。兵坊见过一次以后，也会开始用多人夹取、远距离逼迫和消耗次数进行针对，不会反复用同一种抢法送给他赢。

黑柄短刀当前首先是证据、昂贵资产与暴露源，不直接增加纹阶或锋利度。伤口与刀面异象会迫使陆昭处理身体风险，却不提供异常修炼速度。

陆昭真正不能同时取得的东西逐渐变为：

- 安全卖出钥牌，与继续保有最稀有之物；
- 兑现与柳棠的交易，与夺回陆峥的明确实物；
- 追随斗笠人越过现有世界边界，与救下已经被自己拖入代价的柳棠；
- 把一切都换算成价格，与承认某些人和物已经进入他的私人偏心。

柳棠、斗笠人、兵坊与城主府各有自己的利益。陆昭暂时消失，柳棠仍要保护棠记声誉，兵坊仍会争夺旧朝兵器，城主府仍会封井，斗笠人仍会尝试使用第一枚钥牌。

## 本阶段核心情节发动机与变化后的主要 Reading Question

本阶段发动机是：

**无法稳定独占的异物，引发交易、夺取、公开定价和私人底线的连续改写。**

故事不会循环为“受雇探井—带货出来—领取奖励”。每次关键行动必须改变至少一项现实条件：谁仍愿意出价、谁开始直接控制持有人、什么东西不能再卖、谁学会针对钉影、哪段关系承担了真实损失。

当前 Reading Question 是：

**纹阶4的陆昭能否把已经被强者盯上的钥牌与短刀真正留在自己手里，并让别人为他的所有权付钱？**

第4章后变化为：

**当普通的保管、藏匿和买断都不足以解决新证据时，谁能决定钥牌、短刀以及持有人怎样被使用？**

陆峥实物出现后再次变化为：

**当最高价与哥哥留下的确定痕迹不能同时保住，陆昭会舍掉什么；被他牺牲利益的人还愿不愿意继续站在他身边？**

每次 Mystery Reveal 只回答足以改变行动的一层。答案必须立刻造成加价、封锁、夺物方式变化、关系损失或路线改变。

## 全书成长与核心幻想兑现脊柱（只写从当前点向前仍成立的部分）

- 纹阶是持续有效的精确主尺。本轮陆昭从纹阶4起步，靠已经赚到的钱购买纹师教习，并通过雨兽狩猎、伤势恢复和真实冲突逐步达到纹阶7。回影井异象不加快正常修炼。
- 纹阶7只使他进入护街、雨猎骨干的正常起点。面对纹阶10左右的熟练者，他仍不能稳定正面取胜；面对纹阶21以上强者只能抢一个局部结果；接近纹阶30的听雨城顶层仍能压倒性处置现场。
- 钉影始终保持每日三次、强者迅速挣脱的边界。敌人会学习它的限制，迫使陆昭把次数留给真正改变归属或生死的一瞬。
- 黑柄短刀继续归陆昭使用。它留下的异常与损伤持续存在，使它越来越值钱，也越来越难被当成普通兵器藏起来。
- 陆昭会从长雨冲出的旧朝兵器争夺中取得一柄能够承载多重纹路的锁镰。他选择它是因为它最贵，并非因为它适合自己；笨重、难练和与短刀习惯冲突都必须真实存在。
- 陆昭后来发现，可以钉住自己掷出锁镰的影子，使锁镰在半途短暂停顿，改变一次回收或转向。该用法共享每日三次额度，不提高纹阶，也不能稳定越过明显等级差。
- 钱、钥牌、短刀损伤、锁镰、陆峥实物、公开战绩、敌人的针对方式、柳棠承受的损失和斗笠人的去向都必须继续留下，不因离开当前阶段而重置。
- 当前 Horizon 只确认第4章允许公开的一层现象。石道来源、完整规律、影响范围、持续时间、可逆性、钥牌真正用途与陆峥去向继续保持未知。

## 不可替代的人与关系

**陆峥**

陆峥仍是唯一能够突然提高陆昭风险阈值的人。

本轮保留旧 Program 尚未兑现的承诺：一件能够由现场有效证据确认属于陆峥的实物，会从当前旧井与旧物交易链中出现。它只证明陆峥的东西进入过这条异常链，不证明陆峥活着、死去、亲自进入过石道或知道回影井的来源。

若没有这件东西，陆昭会接受足够高的整体买断；它出现后，他会毁掉一笔已经谈妥的交易。

**柳棠**

柳棠想借这批异常旧物建立自己的鉴定声誉与独立生意。她需要可复核的事实、能够履行的交易和别人愿意继续相信的棠记招牌，不会无条件陪陆昭冒险。

第4章后，她既是不可替代的共同见证者，也是最容易被各方施压的人。陆昭利用她的招牌抬价，可以让她获得过去接触不到的钱；陆昭为陆峥实物毁约，也会让她承担赔款、失信和客源流失。

她不会因为后来被救便抹去损失。两人的关系最终保留账、怒气、欲望与偏心，而不是结算成无条件信任。

**斗笠人**

斗笠人掌握第一枚同号钥牌，是唯一能够与陆昭再次开启石道的人。他的身份、钥牌来源和最终目的继续保持未知。

他需要在城主府彻底封井前完成一次行动，因此会与陆昭短暂合作；但他不接受陆昭对钥牌、证据或进入顺序的单方面控制。双方既互相需要，也都希望在最后一次开启时抢先越过对方。

**兵坊中年人**

兵坊中年人已经目睹钥牌与短刀异象。他下一步必须带回能够兑现的结果，才能证明自己没有错过一件足以改变兵坊竞争的位置。

他会先带价，再带强者，最后改变夺取方法。他并非只负责给陆昭送敌人或报价；若陆昭拒绝，他会把旧朝兵器、第一枚钥牌持有人与城主府封井期限重新组合，争取让陆昭失去单独开价的资格。

## 未来大型阶段

### 第一阶段：明日棠记，价钱第一次失效

**具体世界问题：**兵坊需要在更多人介入前完成买断，斗笠人需要两枚钥牌再次共同开启石道，柳棠需要证明昨日见证不是一场无法重复的骗局。陆昭的伤口与短刀异象仍在持续。

**主要推动者：**带着正式报价回来的兵坊中年人、按约到达棠记的斗笠人、押上招牌的柳棠，以及想把验证资格卖出高价却不交所有权的陆昭。

**主角关键选择：**兵坊愿意连钥牌、短刀、治疗和保密承诺一起买断。陆昭拒绝，只同意在柳棠见证下进行一次受控开启，并要求任何后续交易都只购买使用机会。第4章的短促争夺随之发生。

**最主要阅读满足：**所有人原本都在给钥牌和短刀开价，一个无法被旧交易规则容纳的现场事实出现后，报价者当场停手、改口并重新安排人手；纹阶4的陆昭第一次发现，自己握住的东西比买家原先理解的更危险，也更贵。

**真实 Delta：**

- Knowledge：`M-WELL-01` Reveal Contract 允许的两条 State Residue 成为公开现场事实，更深原因仍未知。
- Asset：黑柄短刀继续归陆昭，但留下本次争夺造成的明确缺口。
- Identity：陆昭从异常钥牌持有人变成不可替代的现场证据持有人。
- Relationship：柳棠成为共同见证者，获得议价资格，也被卷入兵坊与城主府的压力。
- World：城主府把回影井从普通塌井提升为必须在期限内控制的异常入口；三大兵坊开始争夺开启顺序与证据解释权。
- Power：陆昭仍为纹阶4，钉影没有升级。

**旧积累怎样继续生效：**两枚钥牌仍缺一不可；黑柄短刀因第3章牵引而成为事件载体；陆昭的占有欲使他拒绝一次足以安全退出的高价。

**下一阶段为何自然发生：**第4章事实已经被多方目睹，任何一家都无法再靠低价私下买断。三大兵坊对地下冲出的一批旧朝兵器同时加速出手，陆昭必须把证据价值换成真正拿得到的资产。

### 第二阶段：最贵的兵器偏偏不好用

**具体世界问题：**长雨再次冲垮一片旧井石层，一批旧朝兵器进入旧物市。三大兵坊都想在城主府封井前吞下其中能够承载多重纹路的兵器，旧井居民和旧物贩子则急着在封锁前换钱离场。

**主要推动者：**想抢到整批兵器的兵坊中年人、主持公开分货的柳棠、仍控制第一枚钥牌的斗笠人、靠塌井旧物活命的居民，以及想把第一次订金变成真正重资产的陆昭。

**主角关键选择：**陆昭可以收下确定现金，用于疗伤、教习和离开争夺；也可以把大部分现金与一次开启收益押进兵器分配，争一柄价值最高却与短刀习惯严重冲突的旧朝锁镰。他因为价格、独占欲和不愿被兵坊认定只能拿小钱，选择锁镰。

**最主要阅读满足：**陆昭不是被赐予合适兵器，而是凭钥牌、见证和一次决定性的钉影，从比自己强的人手中把真正昂贵的旧朝兵器变成自己的东西；随后立刻面对“拿到了，但根本不好用”的真实落差。

**真实 Delta：**

- Asset：陆昭正式取得可承载多重纹路的旧朝锁镰；它归他所有并能投入使用，但当前笨重、难控。
- Money：第一阶段取得的多数收益被用于锁镰、疗伤和正规纹师教习，不再保有安全退出所需的现银。
- Public Proof：一名纹阶8护卫试图强行截走锁镰。纹阶4的陆昭不能击败对方，只以钉影争到一个瞬间，完成锁镰归属的公开交割。
- Enemy Strategy：兵坊确认钉影的时间短、次数有限，开始采用多人逼迫与连续消耗，不再让一名强者单独伸手。
- Relationship：柳棠从这次分配中获得收入与声誉，同时明确要求陆昭不得再绕过她改变已经公开担保的结果。
- Power Growth：陆昭开始正规修炼与雨兽实战，仍未因取得锁镰立刻跨阶。

**旧积累怎样继续生效：**钥牌与第4章证据提供进入高价交易的资格；黑柄短刀仍是最熟悉的近身武器；钉影只负责把一次合法归属真正落到手中。

**下一阶段为何自然发生：**陆昭公开拒绝现金、拿走锁镰后，各方确认他不会轻易退出。下一批塌井旧物中出现陆峥实物时，兵坊已经知道可以利用交易、柳棠的担保和陆昭的资金缺口迫使他作出选择。

### 第三阶段：哥哥留下的东西不在价单里

**具体世界问题：**城主府提前封锁旧物外运，一家兵坊趁机提出整体结算：替陆昭承担锁镰费用和后续保护，换取钥牌、短刀与退出承诺。柳棠已经以棠记名义担保这笔交易。就在交割前，一件能够确认属于陆峥的实物出现在待交兵坊的塌井旧物中。

**主要推动者：**急于完成整体买断的兵坊中年人、必须维护棠记信用的柳棠、想利用最后期限换取合作的斗笠人，以及第一次遇到不能按最高价处理之物的陆昭。

**主角关键选择：**陆昭可以完成交易，取得足以改变生活的现金，并通过柳棠继续追查陆峥实物；也可以当场毁约，亲手夺下实物，同时失去买断款、让柳棠承担赔偿与失信。他选择后者。

**最主要阅读满足：**陆昭先抓住自己最眼馋的昂贵锁镰，又第一次用它抢回一件无法出售的东西。他的贪、好胜与对哥哥的偏心没有被解释成正确成长，而是在同一场冲突中彼此撕开。

**真实 Delta：**

- Asset：陆昭保有锁镰、第二枚钥牌、黑柄短刀与陆峥实物。
- Knowledge：只能确认陆峥实物进入了当前异常旧物链；陆峥是否活着、是否到过井下仍未知。
- Power：陆昭经过前期教习与雨兽实战达到纹阶6；他第一次钉住自己掷出锁镰的影子，使其半途短暂停顿并改变回收方向。该动作共享每日三次额度。
- Public Proof：这次复合只让他从纹阶10追夺者手中抢到物品并逃开，没有形成完整越级击败。
- Relationship：柳棠承担真实赔款与招牌损失，停止替陆昭赊账、担保或接受口头补偿。
- Identity：兵坊确认陆昭存在高于金钱的明确底线；陆峥相关物成为可以对他设局的弱点。
- Enemy：失去整体买断的一家兵坊转为公开夺取，其他两家也开始以柳棠和陆峥实物逼他表态。

**旧积累怎样继续生效：**陆昭因第一阶段拒绝买断而仍持有钥牌；第二阶段取得的锁镰成为夺回实物的手段；柳棠过去替他建立的公开信用，使这次毁约无法被一句道歉消除。

**下一阶段为何自然发生：**陆昭既失去安全退出，也失去柳棠的公开担保。城主府的最终封井期限到来，斗笠人只愿再合作开启一次；兵坊、城主府、柳棠与两名钥牌持有人只能在井口完成最后结算。

### 第四阶段：封井前错过的那一步

**具体世界问题：**异常长雨引发最后一次大规模坍塌。城主府必须封死最危险的井道，三大兵坊则想在封井前夺走钥牌、锁镰和剩余旧朝兵器。接近纹阶30的城级名手到场后，任何人都无法再把冲突伪装成普通旧物交易。

**主要推动者：**执行封井的城主府强者、要挽回损失的兵坊中年人、准备完成最后一次开启的斗笠人、为棠记证据与赔款而来的柳棠，以及追着陆峥实物线索不肯退出的陆昭。

**主角关键选择：**石道即将被封时，斗笠人带着第一枚钥牌越过封井石面。陆昭可以跟上，保住追查陆峥和第一枚钥牌的最近机会；也可以留下，用当日最后一次钉影与锁镰把被坍塌和兵坊夹住的柳棠拖出井口。陆昭选择柳棠，因此亲眼失去追上斗笠人的机会。

**最主要阅读满足：**陆昭没有变成无私英雄。他仍保住自己的钥牌、短刀、锁镰和哥哥实物，却为一个已经被他害过的人舍掉无法估价的先手机会。纹阶7的他只赢下自己能改变的一瞬，听雨城顶层仍以压倒性力量完成封井。

**真实 Delta：**

- Power：陆昭通过本阶段持续的正常修炼与实战达到纹阶7，进入护街、雨猎骨干的最低正常位置。
- Capability：钉影与锁镰的半途停顿成为可重复但受三次额度限制的个人用法；兵坊已经见过，后续会针对。
- Asset：第二枚钥牌、黑柄短刀、旧朝锁镰和陆峥实物继续由陆昭持有；第一枚钥牌随斗笠人越过当前可知边界。
- Relationship：柳棠没有原谅此前损失，但确认陆昭会为她失去真正昂贵的机会。两人的关系变为债务、怒气、合作能力与私人偏心同时存在。
- Identity：陆昭成为听雨城公开掌握异常钥物、兵器与现场经历的人，城主府和三大兵坊都不能再把他当作普通旧物贩子。
- World：最危险的回影井入口被封，旧朝兵器争夺完成当前结算；两枚钥牌分处边界两端，使任何一方都无法宣称已经完整控制异常。
- Book State Mutation：听雨城已经知道封井不能抹去钥牌、短刀、失踪持有人与公开见证造成的后果。陆昭也从“等待别人给价的人”变成会让各方围绕其私人底线重新布置行动的人。
- Knowledge：只确认斗笠人与第一枚钥牌越过了现有可知范围，不确认其去向、环境、遭遇或石道尽头。

**旧积累怎样继续生效：**陆峥实物使陆昭走到井口；锁镰与钉影让他能在明显等级差下改变一次结果；柳棠此前承担的损失使最终选择具有真实关系重量；黑柄短刀继续保留第3、4章形成的异常与损伤。

**下一阶段为何自然发生：**听雨城关于长雨、塌井、兵器分配和表层封井的冲突已经完成局部结算，但斗笠人、第一枚钥牌与石道延伸处已经越过当前 Effective World 能够具体定义的范围。继续规划其环境、势力、资源或力量规则将越过 Authority。

## World Horizon Handoff

**触发条件：**

- 第4章已经通过现场事件完成 `M-WELL-01` 当前允许的一层 Reveal；
- 三大兵坊对异常钥物与地下兵器完成当前一轮争夺；
- 城主府执行表层封井，听雨城内部的长雨危机形成局部结算；
- 陆昭取得并实际使用旧朝锁镰，正常成长至纹阶7；
- 陆峥实物已经改变陆昭路线，但没有回答陆峥去向；
- 柳棠已经经历共同获利、真实违约与一次不可用金钱抵消的救援；
- 斗笠人与第一枚钥牌越过当前可知边界；
- 封井完成后，黑柄短刀仍朝封闭石面的方向出现一次第3章已经建立过的牵引反应，只证明当前层之外仍有后果，不展示任何新世界内容。

**Scope：**`macro`

**为什么当前层已需要扩：**

当前 Effective World 足以定义听雨城、旧井区、兵坊争货、城主府封井、纹阶主尺与当前异常入口，却没有批准石道边界之外的环境、居民、势力、资源、力量正常值或历史。

Handoff 不是因为陆昭已经征服听雨城。他仍只有纹阶7，纹阶21—28的城级名手与纹阶29—36的顶层仍构成真实上限。需要扩张的原因是当前因果已经把第一枚钥牌和一个行动者送出已批准范围；若继续具体描述，只能凭空替未知世界造答案。

**必须 carry forward 的已发生事实：**

- 陆昭精确位置为纹阶7，正常修炼速度未被回影井改变；
- 钉影每日最多三次，明显高阶目标仍会快速挣脱；
- 钉影可与旧朝锁镰形成一次半途停顿或转向，共享原有次数；
- 黑柄短刀继续保留逆向水痕、牵引与争夺损伤，原因及可逆性未知；
- 第二枚黑铁兵库钥牌、旧朝锁镰、陆峥实物归陆昭；
- 第一枚钥牌随斗笠人越过当前可知边界；
- 第4章 Reveal Contract 的两条 State Residue；
- 柳棠与陆昭之间已经发生的共同获利、毁约损失、拒绝担保与救援；
- 兵坊已经掌握钉影的短时边界及陆峥实物对陆昭的特殊价值；
- 城主府与三大兵坊对陆昭形成的公开估值、敌意、限制与争取；
- 回影井来源、完整规律、石道边界、异常影响范围、两枚钥牌关系、斗笠人身份、陆峥去向仍全部开放。

**固定 orchestration：**

`protagonist-blind World Expansion → deterministic Current Character → Story Refresh`
