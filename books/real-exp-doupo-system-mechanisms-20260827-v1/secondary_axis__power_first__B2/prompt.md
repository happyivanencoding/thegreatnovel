你是 TGN Story Program 的受控机制实验执行者。只根据 FROZEN WORLD / POWER / HUMAN 与本实验条件，设计接下来约40—80章的3个连续大型阶段。严格保持 Human authority：结构机制只能提供机会和信息，不能替人物决定效用函数。不要写正文，不要新增人格背景，不要把主角统一成理性成长最优代理人。
每个阶段只输出：阶段名｜主要诱惑/压力｜主角关键选择｜主要结果｜为什么下一阶段发生。
最后输出 `Human Signature Check`：指出这个 Human 在什么节点做了只有他较可能做的选择。保持简洁。

# FROZEN WORLD
玄陆以九境为公开主尺：一境入门，三境能独行危险地带，五境是一城强者，七境进入大宗门/王朝核心，九境是当世顶层。世界还长期使用武技品阶、兵器品阶、炼药师品级、公开榜单与战绩作为校准尺。高价值物包括完整高阶功法、改变修炼瓶颈的丹药、顶级兵器、秘境名额和极稀有灵火。它们不是为主角准备的，整个世界都会争。
主角刚在边州公开以三境击败普通四境，真实实力已达到三境顶尖、在特定条件下能越一境。现在将进入中央大城“天衡城”：那里同代天才密集，五境强者常见，真正的大宗门在此招人。

# FROZEN POWER
开局 Power Asymmetry：主角能在交锋中暂时截取对手正在发动的一项关键效果，并立刻接入自己的下一次动作；不能拿走未发动的能力、不能永久复制、一次只保留一个效果。越强的对手如果依赖一项明确强招，越可能给主角制造越级窗口。正常修炼仍真实提高主角本身境界、身体、武技和承载能力。

# FROZEN HUMAN｜力量第一
顾凌最强的私人欲望就是成为同代最强并进入真正顶层。他极度享受硬实力带来的自由、胜负和强者认可。具体关系对他重要，但除非涉及对方生死或不可逆背叛，他不会为了陪伴、暧昧或短期关系机会放弃稀有而确定的力量跃迁。面对‘一次稀有修炼机会 vs 喜欢的人明天离开’，他通常选择力量机会，并相信以后会追上去。

# FROZEN MIDPOINT
主角已是三境顶尖，正在天衡城寻找下一阶段路径。世界里有炼药；它可能成为真正的第二强者轴，但主角此前只会最基础药材处理，没有隐藏炼药天赋。

# CONDITION B2｜Secondary Fantasy Axis, not Career Workflow
炼药只有在它本身能成为“我也想把它练到顶”的强者幻想时才进入长期主线：它可以有世界公认的强弱尺度、顶尖人物、公开对决/作品比较、极稀有成果和强社会价格，但不要把成长写成学徒→考试→升品→再考试的职业流水线。普通练习、配方步骤、重复考核默认压缩；重点放在真正改变分量的作品、胜负、稀有创造、强者认可与不可替代的机会。副轴可以长期停在同一品级而发生不同故事，也可以被主角暂时放下。它是否值得投入、投入到什么程度，必须由 FROZEN HUMAN 决定；不要为了证明“第二轴成立”让所有主角都追它。
