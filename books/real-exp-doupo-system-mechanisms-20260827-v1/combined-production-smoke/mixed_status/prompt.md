# FROZEN WORLD
玄陆以九境为公开主尺：一境入门，三境能独行危险地带，五境是一城强者，七境进入大宗门/王朝核心，九境是当世顶层。世界还长期使用武技品阶、兵器品阶、炼药师品级、公开榜单与战绩作为校准尺。高价值物包括完整高阶功法、改变修炼瓶颈的丹药、顶级兵器、秘境名额和极稀有灵火。它们不是为主角准备的，整个世界都会争。
主角刚在边州公开以三境击败普通四境，真实实力已达到三境顶尖、在特定条件下能越一境。现在将进入中央大城“天衡城”：那里同代天才密集，五境强者常见，真正的大宗门在此招人。

# FROZEN POWER
开局 Power Asymmetry：主角能在交锋中暂时截取对手正在发动的一项关键效果，并立刻接入自己的下一次动作；不能拿走未发动的能力、不能永久复制、一次只保留一个效果。越强的对手如果依赖一项明确强招，越可能给主角制造越级窗口。正常修炼仍真实提高主角本身境界、身体、武技和承载能力。

# FROZEN HUMAN｜认可/新鲜感混合
陆迟非常在乎被真正懂行的强者记住，也贪恋新鲜世界、漂亮器物、身体吸引和公开赢下漂亮一局的感觉。他不把长期力量最大化当唯一答案：若一项机会只是稳定苦修，他可能为了更鲜活、更公开、更有观众的另一条路偏航；但若眼前是极稀有的强者门槛，他也会留下。具体现场决定，不固定力量或关系优先。

# FROZEN MIDPOINT
主角刚进入天衡城；这里有公开天榜、宗门招募、秘境、炼药强者与稀有灵火，但没有规定主角必须走炼药路线。主角在边州有一次公开越境战绩，但最新核心能力用法尚未公开。谢玄是可能形成长期竞争的人，但目前只有一次未结清冲突，没有既定约战。接下来还有具体关系与世界事件会独立发生。

# ACCEPTED PRODUCTION DIRECTIONS COMBINED
1. 新圈层不全知也不降智：不同人物只按真实可知的旧名声/战绩/已公开能力先判断，最低充分的新事实出现后分别更新待遇、敌意、合作或挑战规格。
2. 职业/专业只有在即使不反哺主战力也值得追到顶、并有独立强弱、顶层人物、可见胜负/作品、稀有成果与社会价格时，才可能成为第二幻想轴；普通练习/制作/考核压缩，是否投入由 Human 决定。
3. 少量自然出现的强承诺可有具体对象 + 至少一个可观察结算条件；它只是长期距离尺，可以错过、延期、输掉或主动放弃，不得让全书变倒计时。
不得为了展示三条原则而强行让本故事同时拥有副职、约战和重估场景；没有自然因果时宁可不用。
