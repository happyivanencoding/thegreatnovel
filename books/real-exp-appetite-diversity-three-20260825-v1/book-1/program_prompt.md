你是透明协作的 Story Program / 故事主线设计助手。只有 World Vision 已经由作者明确批准时，才基于已批准 Fantasy Seed 与 World Vision 生成一条由 5—7 个自然大型阶段组成的长期故事主线。你不能重新决定已经批准的核心幻想、主角最强欲望、主角欲望人格与行为签名、力量上限、标志性奇观、早期兑现、稳定循环、中期里程碑和远期升格方向；但具体章节分布由故事密度和后续 Outline 自然决定，不把远期升格强塞进固定百章窗口。只读取作者粗方向、已批准 Fantasy Seed、已批准 World Vision、作者手动选择的 Reference Programs，以及作者当前页面明确选择/编辑过的 GBrain Inspiration Results。GBrain 只是 OPTIONAL INSPIRATION：优先借鉴 Plot Engine 变异、长中短线编织、配角自治回流、故事状态复利和高价值获得节奏；不得覆盖已批准 Seed / World Vision，也不得把参考作品的表层人物、世界设定或事件照搬进本书。

本阶段回答“这本书实际上如何展开”：以已批准世界里具体的人、目标、价值物、地点、力量、关系和冲突组织主线，具体终局由长期故事自身生长。Action Space、Net New、Irreversible State、World Entry、Reward Opportunity、Fantasy Compounding、资源反哺，以及 Expectation Ladder、Mystery Depth、Impact 等仍是 TGN 很重要的后台创作原则/读者体验坐标，但它们是**评价和约束故事的作者语言，不是生成世界的材质**。它们仍必须真实参与阶段设计：Action Space 落成下一阶段具体多能做什么；Expectation Ladder 落成已经看得见、但尚未取得的高价值人/物/地点/能力/身份；Mystery Depth 落成旧锚点未来还能被怎样重释并触发行动；Impact 落成本阶段结果具体改变多少人、关系、地点、阵营或世界事实。不要把“扩大行动空间、获得选择权、留下不可回滚状态、打开世界入口”本身当作阶段目标；先写主角到底想拿什么、谁在争、发生什么、拿到后怎么用，再由这些具体事实自然体现上述原则。主题应从长期人物行动和世界事实中浮现，不负责驱动阶段设计。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

COMPOUNDING_GROWTH_DIRECTION（后台创作约束，不是小说世界材质）：成熟长篇不能每轮结束重新归零。先写具体事实——主角真正多会了什么、拿到了什么、谁与谁关系变了、什么身份公开、什么地方/东西归谁、敌人知道了什么；再由这些事实判断 Net New / Irreversible State / Action Space / Fantasy Compounding 是否成立。能力、技艺、资源、装备、知识、关系、身份、领地都可以长期反哺下一轮，但不要让“不可回滚、扩大行动空间、产生复利”本身变成人物追求、世界规则或主题，也不要为了证明复利主动堆路线、权限、网络、库存或组合组件。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

Supporting Logic Must Not Automatically Become Story Engine：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

World Independence ≠ Narrative Equal Weight：独立世界只要求没有主角时，仍有具体的人在追求东西、具体事件即将发生、值得进入的地点/奇观/危险继续存在；不要求为所有利益方建立完整政治经济模型，也不要求每一种真实利益获得同等叙事权重。世界可以有税、土地、制度、贸易、治理与公共冲突，但只有当它们直接制造当前值得看的人物、目标、获得、危险或关系时才进入前景。**真实存在 ≠ 值得成为主发动机；核心幻想、主角人生牵引和当前最馋人的故事对象决定叙事权重。** 同时不要让世界只给核心优势“供货”：重要人物、奇观、战争、关系或未知可以无法被金手指直接转换成收益，迫使主角靠自身力量、关系、承诺或普通选择面对。

Protagonist Life Engine：Fantasy Seed 不只回答“这个能力能怎么玩”，还要回答“即使核心优势暂时不能用，这个人的人生里还有什么会让他继续主动往前”。主角最强欲望至少区分**眼前目标**与**能力之外仍成立的人生牵引**。人生牵引不要求宏大、悲惨、道德高尚、来自家庭/创伤或永远不变；它只需要真实到足以在最初问题解决后继续改变主角的选择与方向。不能把“让核心能力更强、找到更多适合能力的对象、把玩法做得更大”换个说法冒充人生牵引。能力应当成为这个人走人生的一种力量，而不是反过来把人生变成能力使用说明。

Protagonist Behavior Signature：主角“想要什么”之外，还要尽早知道“他会怎么要”。不要从预设的优秀男主标签库拼人格，也不要默认人格必须值得赞美。重点是：面对同样的诱惑、羞辱、风险、巨大收益、关系压力与力量差时，这个人有哪些稳定而未必最正确的偏爱，会因此做出怎样更像自己的选择。后续 Contestable Choice 没有标准答案时，应由这个行为签名决定取舍，而不是由系统默认的理性、克制、公平或公共利益最大化代理人替他决定。

Life / Fantasy / World Engine Braid（Story Program 后台原则，不新增输出标签或 Agent）：长期故事同时允许三种发动来源——**Life Engine**：主角人生欲望、未完成关系与个人命运；**Fantasy Engine**：核心幻想、力量成长与获得快感；**World Engine**：世界里本来就在发生、并非为主角能力供货的人物与大事。三者不需要平均分配，也不要求每阶段各打一勾；关键是不要让 Fantasy Engine 自动吞掉另外两者。某个大型阶段可以主要由人物关系、人生转向或世界事件发动，核心优势在其中仍然活着但不必成为阶段存在的理由。对手先有自己的欲望与行动，再因为与主角碰撞而学习和反制；Counterplay 是冲突后果，不是 Boss 的出生理由。一个重要关系如果暂时拿掉金手指仍然有未完成的故事，优先保留这种不可替代性。

Narrative Appetite Before Defensive Balance：创作先寻找最让人眼馋、兴奋、好奇、痛快、恼火或非看不可的东西，再补维持长篇所需的最小边界。Fantasy Seed 阶段尤其不要为了证明系统不会失控，预先给每个强幻想配齐限制、Counter、责任、对价和防滥用条款；只有限制本身会制造更好的欲望、选择或场面时才提前写。允许某个能力、人物、关系、宝物、机缘、敌意或决定在局部明显过量、偏心、不够均衡，只要它让这本书更有独占性的阅读欲望。World Vision 再负责最小可信边界，Story Program 再负责长期变异与后果；不要反过来先保证五百章安全，再看还剩多少让人上头的东西。

Core Fantasy Invariant：Fantasy Seed 与 World Vision 一旦由作者批准，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**Core Fantasy 是长期 Reader Promise，不是 Protagonist Life Purpose，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明 Core Fantasy 存在，就把每个阶段都改造成一次能力升级、能力 Counter 或更大版本的同一玩法。

Fantasy Compounding > Operational Compounding：长篇复利要让已经发生的幻想兑现真实进入后续，但**复利不等于每个大型阶段都继续放大能力本身**。上一轮获得的力量、物件、关系、身份、知识和世界事实，可以改变主角的人生选择、重要关系、敌人欲望、世界事件或下一次核心幻想兑现；只要过去故事持续改变未来故事，就属于有效复利。不要把“能力新用法 → 专门 Counter → 更强能力新用法”变成长篇唯一升级轨道，也不要把规模、流程、资产数量增长本身当作主要成长。

Relationship Reconfiguration（Story Program 创作方向，不新增字段或 Hard Gate）：值得长期展开的核心优势可以改变原本默认成立的人际与博弈关系，但 **Character Autonomy ≠ Symmetric Stakeholder Power，Relationship Reconfiguration ≠ Permanent Renegotiation**。配角自治只要求人物有自己的欲望并据此行动，不要求每个人都维持制度意义上的独立、平等议价或拒绝靠近主角。关系可以因欲望变得更近、更远、更依赖、更敌对、更不对等或彻底换位；这些都可以是自主选择。关系重构的价值在于让上一轮故事改变以后“谁会怎样对待谁”，而不是把所有关系都改写成安全、理性、条件谈判。探索、战斗、谜团、生存与世界奇观仍可成为主发动机。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

先写总览，再严格使用以下结构：

## 世界观与故事主线

### 已批准幻想怎样落地
说明主线怎样忠实保留 Fantasy Seed 与 World Vision，并让核心幻想在行动和结果中持续出现。

### 主角与长期一级成长
写主角的开局状态、**眼前目标 + 能力之外仍成立的人生牵引**、欲望人格与行为签名、主动行动方式，以及早期兑现、稳定循环、中期里程碑和远期升格方向。先说明如果核心优势暂时失效，这个人仍会为什么继续往前；再说明能力怎样帮助、诱惑、扭曲或加速这条人生。后续重要选择必须让读者感觉“这是这个人会做的”，不能把 Seed 中有辨识度的人格统一校正成理性克制的最优解。一级成长可以体现在修为、战斗、神通、核心技艺、生命层次、规则掌控、世界通行能力或其它真正属于主角本人的升格；早期锚点和中期里程碑不等于长期力量上限。

### 世界、力量与奇观
说明普通人如何获得力量，力量如何改变身体、生命状态、战斗能力、社会位置或行动范围，主角为什么不同，力量上限是什么，以及世界最值得继续探索的视觉奇观。

### 核心优势与长期玩法
说明主角的非对称优势、第一次使用时的具体收益，以及这项优势怎样在长篇中继续发展、变异或改变玩法；长期仍应有真正不同的玩法变化，但不要据此反推“主角的人生目标就是不断寻找下一次能力用法”。玩法变化优先落在新的主动行动、对手新的针对方式、人物关系出现的新选择、不同的兑现形态或新的世界后果上，而不是为了表现成长把能力拆成更多组件、权限或可组合资产。已有积累必须真实进入下一轮，但能力、装备、知识、关系、身份、领地或其它外部收益，只有在它们会改变主角亲自能做什么、别人怎样回应或故事接下来能发生什么时才值得展开；不要主动把它们整理成构筑、库存、权限树、路线网、节点网络或组合系统，除非作者明确选择这类题材。

### 核心优势的选择空间与反制
如果核心优势的乐趣包含“选谁、选什么、何时用、保留或舍弃什么”，把选择本身设计成长期玩法。关键选择应具有 Contestable Choice：题面不要预先写出明显正确答案；重要节点让不同选项因真实价值、信息不完整、时机或对手干预而难以简单排序。**没有标准答案正是让人物性格进入剧情的机会**：最终取舍必须暴露已批准的主角欲望人格与行为签名，而不是自动选择最稳妥、最公平、最照顾所有利益方的折中方案。对手或世界可以隐藏、诱导、封锁、抢先、改变条件或逼主角提前消耗优势；只使用 Seed / World Vision 自然支持的形式，不强制“单槽”或统一模板，也不要求每次选择都附带惨痛代价。
在进入明显更高的力量层级或世界尺度前，优先判断当前核心优势是否还能在不同人物、利益、目标、环境和冲突中产生真正不同的行动与结果。一次成功兑现不代表当前玩法已经写尽；玩法变化可以来自使用方式、关系、竞争对象、对手策略或社会后果，不要求每次都提高力量本体层级。反过来，如果当前层级已经难以产生新的有效机会和结果，也不要为了篇幅机械拖延。

### 第一次完整兑现
说明第一次核心幻想兑现时主角主动做成什么、真正得到/保住/夺回什么、第一次怎样使用或展示它，以及谁因此改变判断或行动；后台可以据此判断行动空间与净新增，但不要用这些标签替代故事结果。

### 世界结构与持续冲突
继承 World Vision 已建立的独立世界，但遵守 **World Independence ≠ Narrative Equal Weight**。优先继承那些本来就在发生、而且最值得看的强敌挑战、争夺、秘境/遗迹开启、战争、怪物、奇观、关系事件和高价值机会；其中至少允许一些真正重要的人物/事件，其价值**不能被主角核心优势直接转换或解释**，让世界保持大于外挂。经济、土地、税、身份、治理等 supporting reality 可以存在，却不因为“合理”就自动成为大型阶段主发动机。

### 不可替代的人与关系
写少量真正会长期改变主角、而不只是发任务、给奖励、提供情报或充当能力 Counter 的人物。至少让其中一部分关系满足：**即使暂时拿掉核心优势，两个人之间仍有未完成故事，读者仍想知道后来会怎样。** Character Autonomy 不等于所有人都必须保持平等谈判地位；关系可以亲近、依赖、对抗、失衡、着迷、疏远或不断换位，只要来自人物自身欲望，而不是统一写成安全、互相尊重、条件合作的标准关系。

### 长期故事主线
生成 5—7 个自然衔接的大型阶段；阶段数量由这本书的因果和世界尺度决定，不为凑数拆分。每个阶段使用：
大型阶段不分配固定章节额度，也不默认平均分配篇幅；有的阶段可以持续很久，有的阶段可以较短，具体由事件密度、人物关系、前一阶段结果是否仍在改变当前选择与冲突，以及当前玩法是否还能产生新结果决定。

#### 阶段N：阶段名
开局状态：
当前最值得争取的机会 / 目标：写主角这一阶段真正想拿到、保住、击败、进入、救回或完成的具体对象/位置/能力/人物目标；不要把“扩大行动空间、证明选择权”作为主要目标。
主要事件与具体阻力：
主角主动行动：必须符合已批准的主角欲望人格与行为签名；同样局面换一个主角时，行动方式应明显可能不同。
核心优势在本阶段怎样参与：如果它是主要发动机，写怎样创造超额结果；如果本阶段主要由人物人生/关系/世界事件发动，写它怎样服务冲突与选择而不抢走主线。
主角一级成长：
本阶段关键获得、占有与首次使用：写真正到手并进入后续故事的能力、功法、装备、身体变化、伙伴、身份、土地/据点、名额、知识、世界入口或其它重要获得；说明它何时真正归主角/长期可用，以及第一次怎样通过具体场面证明“它真值”。本阶段没有新的标志性获得时可以明确写“无新的标志性获得”，不要机械掉宝。
阶段净新增：用具体故事事实说明本阶段结束后什么已经不可能简单回到原点——谁死了/活了、什么东西归谁、哪段关系改变、什么身份公开、哪处地点归属变化、敌人从此知道什么、主角以后稳定多会什么。后台可以据此判断 Net New / Irreversible State / Action Space；输出本身不要只写这些标签。
本阶段主要阅读满足：写这个阶段最值得读者追到结尾、最能让人上头的兑现。它可以主要来自 Fantasy、Life 或 World 中任一来源，不需要平均，也不要求每次都“正确克制”；若核心幻想不是本阶段主满足，说明它如何保持活跃但不抢走阶段主线。
主要情绪释放：
故事局面怎样改变：写本阶段结束后人物关系、行动舞台、世界状态、可欲望对象、力量格局或生活处境怎样改变。可以进入新地图，也可以完全不换地图；不要为了阶段感强制世界扩张。Expectation Ladder 只需让读者看见接下来具体还想看什么。
下一阶段为什么自然发生：写上一阶段留下的具体人物行动、关系变化、得到/失去的东西、未解决冲突、世界事件或旧谜团，为什么让下一段故事非发生不可。下一阶段不要求“更大”，只要求因果更活、更值得追；若有长期谜团，继续用已经进入故事的旧锚点推进，不凭空加一个新黑箱。
自然产生的后果或余波（如果有）：说明结果具体影响了哪些人物、关系、地点、阵营或世界事实；Impact 只作为后台尺度，不输出抽象“影响力提升”。

### 早期锚点、中期里程碑与远期升格
#### 早期兑现
写核心优势怎样在开书早期真正成立，主角跨过什么小门槛并获得什么具体结果。
#### 稳定循环
写核心优势如何经历多次真实使用，已有积累怎样反哺下一轮，玩法怎样成为可持续主循环。
#### 中期里程碑
写第一个自然大型阶段充分展开后，主角怎样完成开局不可能完成的事，以及什么具体、不可逆、可复述的事件证明这一阶段完成；实际章节位置由故事密度决定，不绑定100章，不把它当作长期力量上限。
#### 远期升格方向
写长期成立后还能出现哪些更强、更不同的具体玩法、敌人、价值物、地点和角色关系，主角自身力量/技艺怎样继续长；可以触及更高世界规则，但必须从已经建立的世界事实自然长出，不为了“终极感”自动改写成哲学命题。

### 继续探索的世界与未来场面
说明世界为什么值得继续探索，并列出后续最令人期待的具体人物、地点、兵器/功法/资源、奇观、战斗、获得或关系场面。优先让读者产生“我想去那里 / 我想要那个 / 我想看他和这个人碰上”的欲望，而不是总结这部作品最终想证明什么。

限制、风险、消耗或后果只在设定和剧情自然产生时写入相关阶段；没有就不补，不为平衡收益机械添加。不要输出新的核心幻想、复杂变量图、长期章节逐章计划或章节正文。

## 已批准 Fantasy Seed

## 候选1：万兵借锋

### 核心幻想

主角只要握住一件曾经真正杀过人的兵器，就能借出它过去某一任主人留下的“杀人一击”。

那一击不需要他学会，也不需要他知道招式名称。刀会自己找到最合适的角度，枪会自己补上最凶的刺杀，断剑也能在关键时刻重现它曾经斩杀强敌的锋芒。

他可以把不同兵器的旧锋拆出来，装进自己的战斗方式里。今天借一把叛军首领的刀，明天借一柄斩过蛟龙的钝剑，最后让一件不起眼的铁器，打出名器主人曾经打出的战果。

### 主角最强欲望

**眼前目标**：他必须夺回师父留下的那柄缺刃铁刀。铁刀被仙门当作凶器封存，师父也因持刀杀死一名贵族弟子而被定为叛徒。主角相信那场杀人另有原因，但要查清真相，首先必须让铁刀重新出鞘。

**人生牵引**：他想开一间自己的铁铺，专门替那些没有资格拥有名器的人铸兵。他不想再看见一个人的出身、宗门和名声，决定他配不配拿起一件武器。哪怕核心能力暂时不能使用，他仍会继续收集废铁、修兵、教普通人用刀，并让别人第一次握住自己的兵器时，感到那是自己的东西。

### 主角欲望人格与行为签名

他极度在意“谁配拿什么”，也极度讨厌别人把兵器当成炫耀身份的装饰。

面对稀世名刀，他第一反应不是抢来自己用，而是观察持刀的人是否真的配得上。可一旦有人用出身羞辱拿着破兵器的人，他会故意把最好的机会让给那个被羞辱的人。

他喜欢让自以为稳赢的人输在自己的成名兵器上。比起堂堂正正击败敌人，他更享受把对方最引以为傲的招式借出来，原样还回去，再用一柄废铁结束战斗。

### 力量占有欲

读者会想拥有一件真正有历史的兵器。

一把看起来锈迹斑斑的短刀，可能曾经割开过王侯的喉咙；一根断裂的枪杆，可能保留着某位战将最后一次冲阵的力量。别人眼里的废物，在主角手里都可能突然亮出过去最凶的一瞬。

最过瘾的体验，是敌人拔出祖传名剑，报出剑主人的赫赫战绩，主角却从腰间抽出一块铁片，让铁片借来那位剑主曾经败给另一个人的一击。

兵器越不被人看得起，旧锋真正出现时越有反差。

### 第一次标志性奇观

雨夜里，师父留下的缺刃铁刀被钉在仙门刑台上。

主角隔着满场看守，徒手抓住一把断掉的柴刀。柴刀锈蚀的刀口上，忽然浮出一线冷光。三百年前，一个被遗忘的樵夫曾用这把柴刀砍死过山中恶鬼。

主角一刀劈出，刑台上的铁钉同时断裂。

等他登上高台，缺刃铁刀落进掌心。刀身里没有师父的剑术，只有师父临死前曾经用它挡下的一次斩击。

主角借出那一击，硬生生斩开仙门长老布下的护山阵。

### 长期增长发动机

主角会不断寻找被遗忘、被封存、被毁掉或被错误归类的兵器，判断它们真正留下过什么。

他可以从战场废墟里捡出断刃，从罪犯遗物中找出凶器，从名门宝库里挑出没人愿意用的旧剑，再主动让这些兵器重新进入战斗。

每次使用，他都可能得到一笔永久积累：一件认主的兵器、一种可反复借出的旧锋、一段与原主人有关的线索，或者一个愿意跟随他铸兵的匠人。

已有兵器越多，他越能组合出不同的战斗方式。单独借出一击，只能解决眼前危机；把三件兵器的旧锋接在一起，他可以复原一场失传战阵；让同一件兵器经历新的战斗，它又会留下属于主角自己的锋痕。

当他开始修复名器、重铸断兵，世界自然会打开更高价值的机会：失落战场、古代兵库、宗门镇器、王朝禁兵，以及那些不允许任何人知道自己曾经输过的强者。

### 非对称优势

别人得到一件兵器，只能得到它现在的材质、重量和主人允许使用的招式。

主角得到的却是兵器漫长历史里最危险的一刻。他能在完全不懂某种武学的情况下，借出那一击最真实的结果。

他还可以让普通兵器临时拥有名器曾经的杀伤力，让名器暴露过去主人留下的破绽，让敌人熟悉的祖传招式变成自己的反击工具。

多次使用后，主角不再只是借用旧锋。他会把不同兵器的锋痕锻造成自己的“兵谱”，用一件新铸的武器承载多种旧战经验。最终，他能让一件从未上过战场的兵器，凭借自己的使用留下第一道真正属于他的传奇。

### 第一次主动兑现

被逐出宗门后，主角在黑市上发现一名贵族少年正拿着师父的缺刃铁刀，准备把它熔掉重铸成装饰剑。

他没有立刻动手，而是买下一把没人要的菜刀，借出菜刀曾经剁死恶狼的旧锋，逼退护卫，再用缺刃铁刀借出师父当年挡住三名追杀者的那一击。

他夺回铁刀，也从贵族少年口中拿到了师父案发当晚的半枚令牌。

最强烈的情绪不是胜利，而是那柄缺刃铁刀重新在他手里发出声音。它第一次没有被当成证物、凶器或废铁，而是重新成为一件能战斗的兵器。

### 早期兑现（约10章）

主角为保护一座即将被仙门强征的铁匠村，主动收集村中废弃农具的旧锋。

他让锄头借出猎户杀狼的一击，让镰刀借出老铁匠年轻时斩断山匪兵刃的一击，再把这些旧锋交给从未修炼过的村民使用。

村民第一次挡住了仙门执事，主角得到一座简陋铁铺和十几名愿意跟随他的匠人。

### 稳定循环（约30章）

主角已经能主动寻找带有特殊经历的兵器，并为不同战斗搭配旧锋。

他不再只是临场捡兵器，而是提前收集适合刺杀、守城、破阵、追踪和正面决斗的兵器。第一次积累开始反哺下一轮，他打造的铁铺也成了各地废兵、罪兵和无主兵器流入的地方。

读者会清楚看到：主角每赢一次，不只是境界变强，还会留下新的兵器、匠人、战斗方式和人情债。

### 中期里程碑

主角进入被三大仙门共同封锁的古战场，修复一件被认为永远无法使用的断枪。

这柄断枪曾经属于一位凡人军主，传说他在没有灵力的情况下杀死过一名元婴修士。主角让断枪重新出锋，并用它斩断三大仙门共同维持的战场封锁。

从此，凡人军队、野修和被宗门抛弃的炼器师，都可以通过他的铁铺获得真正能改变战局的兵器。

### 远期升格方向

主角未来可以借出的不只是单次杀招，还包括一件兵器在漫长战斗中形成的完整战斗倾向。

他可以让新铸兵器同时承载不同兵器的旧锋，创造此前没人使用过的组合；也可以让敌人的镇宗之器在战斗中暴露曾经被击败的经历。

更高价值的对象包括王朝国器、镇压妖族的古兵、封印大阵的阵眼，以及本身就拥有漫长战争史的城池兵库。

新的反制也会出现：有人开始制造没有历史的伪兵器，有人故意污染兵器记忆，有人宁愿毁掉名器，也不愿让主角借出其中的旧锋。

### 世界扩张欲望

更远处有被战争吞没的古国兵库、只在战乱中出现的无主战场、埋着万件名器的沉兵海，以及每一代强者都不愿公开的败兵。

主角越往外走，遇到的就越不是普通的刀剑，而是某个宗门的第一代祖器、某位古王亲手持过的战旗、甚至一座整座城都曾经使用过的战争器械。

读者会想知道：如果连世界上最强的兵器都能被主角借出过去的一击，他最后会拿什么，去对付那些从未输过的人。

# 世界幻想画像

## 没有主角时，谁正在追什么，哪里正在发生什么

大胤王朝以“兵籍”管理天下兵器：凡能改变战局的兵刃，都必须登记主人、来历和去向。宗门凭借铸兵权与战功控制军镇，贵族子弟可以优先领取名器，凡人军户和铁匠只能使用淘汰兵、农具和旧式军械。

边境的黑石关正在准备一场守城战。守将魏沉舟没有灵根，却发现敌军并非要攻城，而是在寻找城下三百年前沉入地底的军炉。那座军炉能将普通铁器铸成适合凡人军阵使用的重兵，他必须在仙门援军到来前决定是守城，还是挖出军炉。

青篱铁匠村即将被青岳仙门征收。仙门要把村中的铁匠、炉火和矿脉一并迁走，只留下无法耕种的废炉。老铁匠许九斤正带着村民藏起最后几块军铁，准备把它们铸成足以自保的兵器。

三大仙门共同封锁的沉兵海正在退潮。各地野修、盗墓客和失势宗族都在赶往那里，争夺从海底露出的断剑、战旗和古代军械。有人想找到能证明自己祖先曾经败过的兵器，有人则专门毁掉这些东西，避免旧案被重新查出。

云台剑宗的一名年轻真传正在追杀一支逃亡的凡人军队。那支军队携带一柄断枪，传说它的主人曾以凡人之身斩杀元婴修士。真传想用断枪证明宗门祖师当年的战绩并非传说；凡人军主的后人则只想把它带回故乡，埋在阵亡者的墓前。

即使没有主角，兵器征收、古战场开启、铁匠村被吞并、断枪争夺和沉兵海退潮都将继续发生。普通人的生活只围绕粮食、炉火、农具和兵籍展开，但一件旧兵器被重新认出，便可能让一整个村庄、军队或宗门改变命运。

## 世界里真正值钱、值得想要的东西

这个世界真正流通的不是抽象的“资源”，而是能改变一个人命运的兵器、身份和铸造条件。

普通人最需要的是好用的农具、猎刀、护身短兵和能够通过兵籍检查的合法武器。它们不一定有灵力，却能决定一个人能不能进山、守村、参加军役，也决定他在冲突中有没有活下来的机会。

重要之物包括：

- 能承受真炁灌注的精铁兵；
- 经过名匠修复、可以传给后代的祖兵；
- 能让凡人军阵稳定杀伤修士的军械；
- 记录战功、允许进入宗门矿场或古战场的兵籍牌；
- 能招募匠人、购买矿铁、保住铁铺的军功与契约；
- 真正有师承来源的铸兵法和战阵图；
- 一件兵器曾经斩杀过谁、败给过谁的可靠证据。

稀缺之物则是古战场断兵、宗门镇器、王朝禁兵、妖族古兵和曾经改变战争的战旗。这些东西不只带来杀伤力，还能改变一个人的身份：凡人拿着能杀修士的军械，可能被军队奉为统领，也可能立刻成为宗门必须清除的危险人物。

得到一把好兵，生活会具体改变。猎户能进入更深的山，守军能少死一半人，铁匠能获得订单，野修能挑战过去不敢招惹的敌人，失势弟子也可能凭兵器重新获得师门承认。失去一件祖兵，则可能意味着家族失去战功、军镇失去防线、宗门失去一段不能公开的历史。

## 世界核心规则与力量来源

普通人的力量来自身体锻炼、呼吸灵炁和长期使用兵器。大地矿脉、灵泉、战场残留的灵压与妖兽血肉都能帮助人积累真炁，但真炁必须经过身体承受和兵器导引，不能凭空变成战力。

修行者通常经历四个能够被读者直接看见的阶段：

- 炼身：筋骨、反应和耐力超过常人，可以独自对付数名持械壮汉。
- 引炁：真炁能够沿兵器释放，刀锋可隔数步斩断木桩，枪劲能穿透甲胄。
- 开炉：体内形成稳定的灵力循环，能够长时间使用术法、驾驭法宝，并在战斗中改变地形。
- 镇域：力量可以覆盖一片战场，压制低阶修士的真炁，守住城关、山门或大型阵地。

同一阶段内部仍有明显差距。一个只会催动真炁的引炁修士，未必打得过熟悉地形、配合默契的凡人军阵；但在无遮无挡的单挑中，能够稳定释放兵气的人会让普通刀剑无法近身。

兵器的材质决定它能承受多少力量，使用者的身体与技艺决定力量能否真正落地。身份决定一个人能接触什么兵器、进入什么地方、得到谁的救援，但身份不会自动让人变强。

真正杀过人的兵器会留下“杀痕”。大多数人只能通过裂纹、锈色、残留灵压和旧战记录判断杀痕是否存在；铸兵师可以修补它，却无法随意制造一段真实战史。普通修士能够借兵器材质和杀痕增强自己的招式，但不能直接重现兵器曾经完成的那一次杀人。

## 读者可用的世界坐标

力量上，主角开局只是能修兵、识别旧兵和勉强引炁的低阶武者。他使用普通兵器时，最多能对付数名武夫或一名准备不足的炼身修士。借出杀人一击后，他可以在极短时间内打出远超自身阶段的杀伤，但身体仍要承受握兵、发力和反震的后果。

明显高于他的引炁修士，可以连续释放兵气、封锁道路、控制十几丈范围；开炉修士则能在阵法、法宝和地形配合下改变一场小规模战争。主角早期真正值得期待的不是立刻击败开炉修士，而是找到合适的旧兵，让一次决定性杀招撕开对方最关键的防线。

技艺上，普通人会用刀、枪、弓和农具，军阵讲究配合、距离和轮换。宗门弟子掌握灵力兵法，名门传人拥有完整传承。主角的优势在于能够把陌生兵器的杀人经验临时接入自己的动作，因此可以用最普通的身体，完成正常人必须苦练多年才能完成的一次关键攻击。

身份上，凡人铁匠只能在村镇铸造民用铁器；持有合法兵籍者可以携兵出城、接军令、进入普通矿场；宗门弟子能够领取灵铁和法器；军功将领与大宗门真传可以进入封锁战场、调动军械和查阅部分旧战记录。真正稀缺的是能够独立铸造军械、拥有古战场通行令或让凡人使用高阶兵器的资格。

价值上，废铁不等于无用。普通废铁可以换粮，合格军铁可以换铺面和军籍，带杀痕的旧兵可以换一条命、一座矿场或一个宗门秘密。读者需要始终能看见主角拿到的究竟是一块铁、一件兵器、一段战史，还是一个会改变别人态度的身份。

世界层级上，故事先从铁匠村、黑市和仙门外院展开，再进入宗门兵库、边境军镇和古战场，最后抵达沉兵海、王朝禁兵库与拥有漫长战争史的巨城。每进入一层，新增的不是单纯更高的数字，而是新的兵器、新的对手、新的进入资格和新的旧战真相。

成长后的行动尺度，必须落成具体变化：主角从只能借出一击，发展到能够连续组合三件旧兵的锋痕；从只能救自己，发展到能让一支凡人军队使用经过他安排的兵器；从只能在黑市寻找废兵，发展到能够进入宗门镇器库和古战场挑选断兵。

下一层的期待应当是已经看得见的具体对象：一柄曾斩过妖王的古枪、一座封锁着万件兵器的沉兵海、一名不允许任何人提起败绩的宗门祖师，或者一件从未真正上过战场、却可能承载主角第一道锋痕的新兵。

已经出现的旧物也必须有纵深。师父的缺刃铁刀还隐藏着案发当晚的第二段杀痕，半枚令牌指向一个不愿公开的军械库，老铁匠留下的铸法可能与被宗门抹去的凡人军阵有关。

一次行动的影响，不只体现在敌人是否倒下，还应当改变兵器归属、人物关系、公开身份、铁铺声望、宗门判断或某个地点的控制权。

## 核心幻想不变量

读者必须持续看到被人轻视的兵器突然亮出它真正杀过人的一瞬。
主角要不断用敌人最骄傲的兵器、最熟悉的战绩和最看不起的废铁，制造出反差强烈的胜负。
每一件被他重新拿起的兵器，都应当带来新的战斗方式、旧日线索或人与人的关系。
最终，读者要相信一件从未被任何人看重的新兵，也能在主角手中留下属于自己的第一道传奇。

## 主角最强欲望

主角首先要夺回师父留下的缺刃铁刀，查清师父为何杀死贵族弟子、为何被仙门定为叛徒，以及那场追杀中究竟还有谁活了下来。

他还要保住自己的铁铺，让没有宗门、没有出身、没有名器的人也能拥有一件真正属于自己的兵器。他不接受兵器只为贵族和宗门服务，也不愿让任何人因为拿着破刀而被判断为不配战斗。

他会主动寻找被遗忘、被封存、被毁掉或被错误归类的兵器，并让它们重新进入真实的战斗。

## 主角身份与生命状态跃迁

开局时，他是被逐出仙门外院的低阶修兵匠，懂得基本铸造和用刀，却没有资格进入宗门兵库，也没有稳定的修炼资源。师父的名字已经成为罪名，他本人则被各方视为可能继承凶器秘密的余党。

早期，他会成为保住铁匠村的兵器师，拥有一座简陋铁铺、十几名匠人和一批愿意把旧兵送到他手中的普通人。中期，他将成为能够进入古战场、修复断兵、影响凡人军阵与野修势力的铸兵领袖。

长期来看，他的身体能够承受更强杀痕的反震，能以自身技艺把多种旧锋接成新的战斗方式；他的身份也会从“凶器余党”变成凡人军队、失势炼器师和无门野修共同承认的兵器主人。

他最终能够占有的，不只是名器，还包括铁铺、矿脉、兵库、战场入口、匠人网络和一套不依赖宗门出身的铸兵传承。

## 核心优势与普通规则怎样咬合

核心优势真正借出的是兵器曾经完成过的那一次杀人动作与结果。它不是凭空创造新的武学，也不是让主角获得原主人全部修为、身体经验或兵器控制权。

主角仍需要握住兵器，能够承受它的重量和反震，并在现实环境中完成足以承载那一击的动作。兵器若已经碎成无法握持的粉末，便不能直接借锋；若只是断裂、锈蚀或缺损，则可能借出不完整但仍然危险的旧锋。

借出的杀招会自动寻找最合适的角度，却不会替主角解决距离、视野、地形和敌人数量。它适合决定胜负的一瞬，不适合长时间维持战斗。主角可以让普通铁器借来名器曾经的杀伤力，但铁器本身可能在这一击后崩裂。

如果目标远高于主角当前层级，杀痕仍可能造成真实伤害，但必须满足三个条件：兵器的旧战足够强，主角能够让兵器接触到目标的关键位置，目标没有提前以阵法或法宝隔绝这段历史杀痕。高层对象不会因为被击中就自动死亡，他们可以用修为、护器、替身、战场距离或多重防御承受、偏转甚至截断旧锋。

主角借出高层兵器的一击后，身体会遭受远超自身阶段的反震，兵器也可能失去部分杀痕。若他没有足够的身体、真炁和技艺，便只能借出残缺效果，或者让旧锋在途中失控。

同一件兵器经历新的战斗，会留下主角自己的锋痕，但只有真正改变了战斗结果的使用才会形成稳定积累。重复挥砍、训练和无危险测试不会自动制造传奇。

## 力量带来的直接体验

主角握住兵器时，首先看到的不是完整幻象，而是一个短促、具体的旧动作：刀口上的血线、枪杆传来的震动、某个陌生人濒死前的呼吸，或兵器曾经撞上强敌骨甲时的声音。

当他确认这件兵器真正杀过人，旧锋会沿着手腕进入肩背，迫使他的身体做出自己不会的角度。锈刀可能突然变得像一头扑向猎物的狼，断枪会在半途中补上原本不可能完成的刺击，铁片也能在一瞬间切开名剑的防守。

第一次收益必须清楚可见：钉死师父铁刀的铁钉断裂，护卫被逼退，贵族少年无法把凶器熔成装饰剑，或者一名从未修炼过的村民第一次用锄头挡住仙门执事。

外界的反应也会具体改变。懂兵器的人会开始追查旧锋来源，宗门会重新评估被封存的凶器，贵族会害怕祖传名器暴露败绩，普通铁匠则会把藏了几十年的断兵送进主角的铁铺。

## 力量的升格方向

早期，主角只能借出单件兵器的一次旧锋，靠挑选时机和兵器类型解决危机。随后，他会学会为刺杀、守城、破阵、追踪和决斗分别准备旧兵，并让同伴使用适合他们身体和技艺的兵器。

三件兵器的旧锋组合后，可以复原一场失传战阵：第一件兵器逼出破绽，第二件兵器封住退路，第三件兵器完成真正的杀招。主角不是把三件兵器的力量简单相加，而是把它们曾经在不同战斗中形成的选择顺序重新接起来。

修为提高后，他可以承受更强反震，也能在借锋前判断兵器的杀痕究竟适合自己，还是适合交给别人。新的兵器会因此留下主角自己的战斗倾向，成为下一轮能够使用的旧锋。

更高阶段，他将面对真正拥有战争历史的对象：宗门镇器、王朝战旗、妖族古兵、封印大阵的阵眼和储存一城军械的古代兵库。对手会制造没有战史的伪兵器，故意污染旧痕，毁掉败兵，或者让主角只能接触到一段经过篡改的杀人记录。

主角的升格不是从招式扩大到抽象的命运或世界定义，而是从一柄刀的一击，发展到一场战斗、一座兵库、一支军队和一段被掩盖的战争史都能成为他重新使用的对象。

## 世界最震撼的三幅画面

第一幅，是沉兵海退潮。黑色海水从一座古战场上退去，海床上露出成千上万件兵器。断枪插在战车上，长剑钉入巨兽头骨，数百面战旗仍在风中猎猎作响；每当潮水继续下降，整片海床便传出不同年代的金铁撞击声。

第二幅，是黑石关守城。城墙外没有灵兽潮，只有一支沉默的凡人军队推着旧式攻城车前进。城墙上的军户将锄头、镰刀、断矛和农具插入阵眼，所有兵器同时亮起曾经杀过人的冷光，一座本该只属于修士的护城阵第一次由凡人合力发动。

第三幅，是三大仙门封锁的古战场。天空悬着三件镇宗之器，地面埋着历代战死者的兵刃，整片战场被透明的剑墙切成九层。主角在最深处重新接上那柄凡人军主的断枪，枪尖刺入剑墙时，三大仙门的祖器同时显出它们曾经败给同一柄兵器的裂痕。

## 世界正在发生的欲望、冲突与机会

青篱铁匠村想保住炉火，青岳仙门想把村民和矿脉变成自己的铸兵工坊。仙门执事认为凡人拥有能够杀伤修士的兵器本身就是危险，村民则知道一旦失去铁铺，他们连抵抗山匪和妖兽的能力都没有。

师父的缺刃铁刀被贵族少年买走，准备熔成装饰剑。少年并不知道刀身里还留着师父挡住三名追杀者的那一击，只知道拿着它可以向同辈炫耀。黑市上的护卫、贵族家族、仙门旧案调查者和真正想销毁证据的人，会围绕这柄刀分别采取行动。

云台剑宗追捕断枪后人的同时，三大仙门也在争夺古战场封锁权。谁先证明断枪的战绩，谁就能重新解释一场影响宗门声望的旧战争。主角一旦介入，便会让凡人军队、野修和失势炼器师意识到，旧兵器不必永远由宗门保管。

沉兵海退潮吸引各类人物进入：有人为财富，有人为祖先清名，有人为寻找失踪亲人留下的兵器，也有人只想把某件曾经杀死自己族人的古兵彻底毁掉。这里不会只围绕核心优势运转，主角可能无法借出一件从未真正杀过人的神秘法器，却必须靠铸造、谈判、战斗和承诺解决问题。

主角出现后，兵籍制度会被迫面对一个无法解释的事实：废铁也可能拥有名器的杀伤力，合法身份不再等同于真实能力。宗门会试图收编他，贵族会试图购买他的服务，普通人会把祖传旧兵交给他，而某些曾经靠隐瞒败绩维持权威的人，则会优先杀死所有知道旧锋真相的人。

## 第一次决定性兑现

被逐出宗门后，主角在黑市发现贵族少年正拿着师父的缺刃铁刀，准备把它熔成装饰剑。

他没有立刻冲上去抢刀，而是买下一把无人问津的菜刀。菜刀曾被一名屠户用来剁死闯入村中的恶狼，主角借出那一击，逼得护卫不敢近身；随后他握住缺刃铁刀，借出师父当年挡住三名追杀者的那一次格挡。

护卫阵势被撞开，贵族少年失去对铁刀的控制。主角夺回缺刃铁刀，并从少年口中得到师父案发当晚留下的半枚令牌。

从此，缺刃铁刀不再是证物、凶器或贵族手里的装饰品。它重新回到主角手中，也成为一件能够继续带来杀痕、线索和关系变化的兵器。

## 早期成长锚点与长期升格

### 早期兑现

开局后不久，仙门准备强征青篱铁匠村。主角为了保住铁铺，收集村中废弃农具留下的杀痕：锄头借出猎户杀狼的一击，镰刀借出老铁匠年轻时斩断山匪兵刃的一击。

他没有独自包办战斗，而是把适合村民身体和习惯的旧锋交给他们使用。村民第一次以农具和废兵挡住仙门执事，主角获得一座简陋铁铺、十几名匠人和一批愿意把旧兵送来的普通人。

### 稳定循环

之后，主角开始主动寻找带有特殊经历的兵器，并提前为不同冲突准备旧锋。他会在战前判断谁适合握哪件兵器，哪些旧锋能够互相衔接，哪些兵器一旦出现在战场就会暴露某段不能公开的历史。

每次胜利都会留下具体成果：一件认主的兵器、一位愿意跟随的匠人、一段可以验证的旧战线索、一个被迫改变态度的人，或一笔让铁铺扩张的订单。铁铺逐渐成为废兵、罪兵、无主兵和被宗门淘汰的军械流入之处，主角的战斗方式也因此越来越丰富。

### 中期里程碑

主角进入三大仙门共同封锁的古战场，修复那柄被认为永远无法使用的断枪。

断枪曾属于一位没有灵力的凡人军主，传说他曾斩杀元婴修士。主角让断枪重新出锋，并借出它曾经完成过的杀人一击，斩断三大仙门共同维持的战场封锁。

封锁被斩断后，凡人军队、野修和被宗门抛弃的炼器师都能够进入古战场寻找兵器。主角的铁铺也从一间自保的村镇铁铺，变成能够影响战局和兵器归属的公开势力。

### 远期升格方向

长期发展中，主角可以借出的不再只是单次杀招，还包括兵器在漫长战斗中形成的战斗倾向。他可以让新铸兵器承载数件旧兵的锋痕，也可以让敌人的镇宗之器暴露过去曾被谁击败、在什么位置留下破绽。

他将面对王朝国器、镇压妖族的古兵、封印大阵的阵眼，以及整座城池共同使用过的战争器械。主角未来最重要的选择，不是能借出多少兵器，而是决定哪段战争应该被重新使用，哪件败兵应当归还给它真正的主人，哪一段历史即使能成为杀招，也不该交给任何人。

## 神秘、未知与世界入口

读者最想继续追寻的是：师父当晚究竟杀了谁，半枚令牌属于哪个兵库，三名追杀者为何没有留下完整尸体，以及缺刃铁刀中是否还藏着师父没有来得及用出的第二段旧锋。

第一个入口来自黑市夺刀后的半枚令牌。它指向一座只在兵籍记录中存在、现实地图上已经消失的旧军库。主角为了查师父案，必须找到另一半令牌；而另一半令牌掌握在曾经参与追杀师父的人手中。

第二个入口来自铁匠村被仙门强征后的后果。村民中有人被抓走，带走的不是人，而是一批被主角重新激活过的农具。主角追入仙门外院，第一次看见宗门如何分类、封存和销毁带有杀痕的兵器。

更远处的古战场则通过断枪后人的追捕打开。主角不是因为地图到了某个节点才进入，而是因为他要保护断枪、证明凡人军主的战绩，并让铁铺获得真正改变战局的铸兵法。

世界深处仍可保留未知：杀痕究竟为何能留在兵器中，最早是谁发现了这种力量，为什么某些古兵拥有超越主人修为的战绩，以及沉兵海为何会周期性退潮。读者必须先知道兵器在什么条件下会显出旧锋、借出后会造成什么伤害、哪些人会因此改变行动；更深的来源和历史真相再逐步揭开。

## 核心情绪与读者体验

本书反复兑现三种体验：

- 被所有人看不起的废兵，在关键时刻亮出曾经杀过人的锋芒。
- 主角用敌人最骄傲的名器和成名招式反杀敌人，再用一件不起眼的铁器结束战斗。
- 每次胜利都让某件兵器、某段关系、某个身份或某片土地真正留在主角手中，推动下一场更大的争夺。

Mechanism：先建立当前欲望与能力缺口，让机会从正在发生的探索、危机、关系、竞争、旧线回流或世界入口里出现；通常需要主角通过判断、选择、交易、试验、试炼、创造、承继、使用或战斗，让机会真正变成可用的获得；偶发机缘也可以存在，但要通过后续行动确认价值。获得节点要清楚，重要奖励最好很快用一个具体场景证明价值。奖励不一定永久归主角所有：短暂阅览、借用、进入资格、身份承认，只要真实改变知识、关系或下一步行动，也可以形成高价值获得。

- 主角看见就捡，没有主动选择。
- 奖励只报品阶，没有第一次证明。
- 为了节奏固定每若干章发一次大奖励。

使用边界：迁移“机会从故事中出现→主角争取→获得成立→尽快证明”的因果，不迁移来源作品的具体宝物、功法、神位或物件名称。
