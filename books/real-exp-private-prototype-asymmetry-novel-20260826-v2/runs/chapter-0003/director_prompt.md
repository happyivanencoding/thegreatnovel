# Opening Three Chapter Contract

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的规则 → 主角立即行动。前三章应在相关冲突或爽点真正需要之前，让读者自然获得足够的世界坐标与度量尺（如主角/对手强弱、身份层级、关键价值尺度），但只释放理解当前故事所需的信息。核心优势第一次形成结果时，尽量让读者同步得到一个世界内比较：同层普通人/天才或已出现的更高层人物通常能做到什么，这次结果为什么超标；可以来自境界、测试值、战绩或懂行者反应，不必讲设定表。新造世界概念第一次影响人物选择时，先让读者知道它具体让谁或什么发生怎样的变化、人物因此能或不能做什么；名字和深层原因可以随后出现。不要先把世界模型讲完，再把主角放进来，也不要写成设定集。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

## 前文章末必要衔接

“你能不能再做一次？”

“不知道。”

林猎手立刻冷笑：“说得倒干净。”

闻野舟转头看他，眼神冷下来。

“你想让我再做一次？”他问，“可以。你再朝顾晚禾的摊子砍一斧？”

林猎手的脸一下涨红。

“你找死！”

他下意识去摸腰间，摸了个空，才想起猎斧还插在泥地里。

闻野舟没再说话。

他不怕林猎手发火。

他怕的是自己真被逼到墙角，才发现刚才那一下再也抓不住。

桑照抬起眼，林猎手的动作便停住了。

“这里不是你们斗气的地方。”桑照说，“林猎手，你的斧劲失常，是事实。闻野舟撞断木栏，也是事实。至于中间到底发生了什么，现在没人能说准。”

林猎手不服：“那就这么算了？”

“谁说算了。”

桑照从腰间取出一册薄本，翻到空白页，用炭笔写了几行。纸页摩擦的声音很轻，四周却没人再插嘴。

写完，他抬头问闻野舟：“名字。”

“闻野舟。”

“无猎阶？”

“没有猎阶。”

桑照写下去，又问：“三日后，猎庭复测，你来不来？”

闻野舟看着他。

“三日后？”

“到猎庭，照今天的异常走一遍核验。”桑照合上薄本，“不会直接给你猎阶。能不能过，也不是我现在说了算。但你今天的事，猎庭会留记录。”

“要是不来呢？”林猎手抢着问，语气发冷。

桑照看了他一眼：“那就是他自己的事。”

林猎手还想说什么，桑照已经把薄本收回腰间。

“今天这场冲突，先记在案。”他说，“林猎手，黑鬃獾是从你负责的验货圈脱出来的，先把异兽找回来，把损坏的栏和笼门处理掉。闻野舟，没有猎庭再问，你不能拿今天这事到处招摇，也别把不明白的东西当本事乱用。”

闻野舟听得出这不是警告他滚。

这是把他留在了事里。

桑照说完，转身就走。

走出两步，他又停了一下，回头看闻野舟。

那目光停得不长。

“别迟到。”

闻野舟点头：“知道了。”

桑照这才离开。

人群没有立刻散。

那些看着闻野舟的目光还是复杂，有人怀疑，有人好奇，也有人把他从头到脚重新看了一遍。可至少没有人再把他当成一个闯进验货圈、只会碍事的无阶小子。

林猎手站在断栏旁，脸色阴沉。

他盯着闻野舟许久，最终一把拔起地上的猎斧。斧刃沾着泥，他攥得指节发白，却没有再动手。

“复测那天，”他冷冷道，“我也会在。”

闻野舟抹掉嘴角干掉的血迹。

“那你看着。”

林猎手的眼神像刀子一样刮过来，转身推开人群，朝空笼窄道的方向走去。

他一走，围着的人也慢慢散开。

顾晚禾蹲下去，把散在地上的兽皮一张张捡起来。闻野舟想帮忙，肩膀刚抬起来，麻疼就顺着锁骨窜到胸口。

顾晚禾看见了。

“别动。”她说。

闻野舟停了停：“我没事。”

“你嘴边还有血。”

“擦过了。”

顾晚禾没跟他争。她把最后一张兽皮卷好，压到摊位角落，又把彩纹护臂放进包袱最里面。

闻野舟看着那只护臂：“没坏吧？”

“没坏。”顾晚禾把包袱系紧，“扣带也没断。”

她说完，抬头看他。

刚才面对林猎手时，她一直很安静。现在人散了，她眼里的那点发白已经退下去，只剩下很实在的审视。

“你刚才说，你不知道那股劲是什么。”

“嗯。”

“真的不知道？”

闻野舟看着她，没有躲。

“真的。”

顾晚禾沉默了一会儿。

闻野舟以为她还会问下去。

可她只是把包袱背到肩上，伸手扶正被撞歪的摊板。

“那就别在这里试。”她说，“猎市的人多，林猎手也不会就这么算了。”

闻野舟胸口那股发闷的气，忽然散了些。

“你不问我是不是使诈？”

顾晚禾看了他一眼。

“我看见的是你挡在前面。”她说，“别的，等你自己弄明白再说。”

闻野舟没接话。

他低头把两根还能用的木栏扶到一边，手碰到断口时，掌心被木刺扎了一下。他拔出刺，随手甩掉血珠。

顾晚禾收好摊子，站在他身后等了一会儿。

“闻野舟。”

“嗯？”

“商队明早离镇。”

闻野舟动作停住。

顾晚禾的声音很平，没有逼他，也没有替他拿主意。

“他们不会为了猎庭三日后的复测改路。天亮前要出镇，错过了，就不会等你。”

猎市里有人开始重新钉木栏，远处空笼窄道传来猎手呼喝和异兽撞笼的闷响。

闻野舟抬头，看见镇门方向的天色已经往暗处沉。

三日后的猎庭。

清晨离镇的商队。

一个是刚刚落到他手里的机会，一个是眼前不能等的人和路。

顾晚禾没有催。

她只是背着包袱站在摊位边，等他开口。
