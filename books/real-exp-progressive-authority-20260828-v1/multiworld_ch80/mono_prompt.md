# META WORLD ROOT
灾变后，幸存者会被“界门庭”周期性送入彼此独立的异世界。跨世界稳定规则只有几条：进入前会给一个最低限度的任务与返回条件；死亡通常真实；完成后可以带回被界门承认的少量物品、身体变化与能力；返回庭区后有短暂结算与交换窗口。不同异世界可以拥有完全不同的社会、力量、历史与公共常识，界门庭不会提前把整个世界说明白。
界门庭本身存在更高阶参与者与未知来源，但前80章只确认不同批次、危险差与可携带收益，没有揭晓终极真相。


# FROZEN HUMAN CORE
周彻极强的好奇心常常压过保守收益，他喜欢赢，也喜欢那种只有自己真正看懂局势的满足感。他很在意自由，不喜欢被队伍规定必须怎样做；但对长期同行的闻葵已经形成明显偏心，涉及她的生死时会接受原本不想承担的风险。对陌生人，他不会自动承担救援责任。


# CURRENT CANON @ CH80
周彻已经完成三个世界：废城夜兽、海上漂城、镜像矿国。三个世界的主要阅读发动机分别是生存、阵营竞争、身份/真假判断，玩法没有完全重复。

闻葵在第三世界为了保住另一名队员放弃了一件稀有带回物；周彻没有得到等价补偿。两人关系更近，但没有表白。
庭区里有人开始高价收购“能影响进入身份”的信息；一支高阶小队第一次注意到周彻，但尚未与他正式接触。
下一次应该进入一个真正独立的新世界；不能只是把前三个世界的生存、阵营、真假身份换皮再来一遍。
