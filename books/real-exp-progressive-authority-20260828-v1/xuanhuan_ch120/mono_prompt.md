# WORLD ROOT
玄河大陆的主流力量是真气淬体与武技。地方武者通常经历开脉、凝罡、化域三个公开大档，青州最强者也只偶尔触及化域。青州之外确定存在更大的中域，但开书阶段只知道那里有跨州商路、真正的大宗门与更高层武者，具体社会与力量生态没有预先写死。
普通人的生活依附城镇、商路与宗门外围；兵器、武技、灵药、异兽材料和安全的跨州入口都是具体值钱的东西。世界里还有大量没有围绕主角存在的遗迹、商队、宗门竞争、异兽迁徙与地方战争。


# FROZEN HUMAN CORE
顾野好胜，喜欢钱、漂亮兵器和被真正懂行的人看见；他厌恶长期被组织控制。面对巨大收益时敢冒险，但不是无条件赌命。沈照是一个具体例外：若她真的会因此失去某件不可替代的东西，他会改变原本更有利于自己的路线。顾野不喜欢把自己包装成道德榜样。


# CURRENT CANON @ CH120
顾野已经从青州边城进入州府，公开身份是年轻武者中的第一梯队；他仍是凝罡高段，没有进入化域。
开局核心异常：完整看过别人一式后，可以在自己的身体条件允许范围内无损复现一次；经过长期掌握，现在能储存三式，但每式使用后仍会消失。
后续获得：一柄能临时改变重量的黑曜长刀；一次异兽骨髓淬体让他的爆发承载明显高于同层；他与这两项优势已经形成“重刀突然轻化换位—复现对手招式反打”的复合战法。
顾野在州府大比夺魁后拒绝了军府长期编制，只接受一次跨州护送。沈照因自己的家族旧事决定去中域追查一名失踪长辈，顾野没有替她做决定，但已经答应若路线一致就同行。
青州当前主要旧敌已经失去继续压住他的能力；读者已经多次看到青州层级的宗门考核、州府比赛、遗迹争夺，继续原地加码会重复。
