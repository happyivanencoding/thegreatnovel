# Cross-Window Findings

1. 共同日常要先落为可重复的物、动作或空间；vacancy 随后通过“第一件不能照旧完成的事”出现，而非靠抽象悲伤。
   Evidence：DJ-01、DJ-02、DJ-03、DJ-04、DJ-07、DJ-11、DJ-13、DJ-15。

2. 等待不是默认静止。它需要硬约束、可见占位，以及等到什么或替谁争取时间；缺一项就容易沦为情绪停滞。
   Evidence：DJ-03、DJ-06、DJ-08、DJ-11、DJ-14；反边界：DJ-15。

3. 替代不等于找一个新角色复制离开者。它可以是局部授权、物理接口、责任交接、新路线、保护命令或重学旧动作。
   Evidence：DJ-02、DJ-03、DJ-05、DJ-07、DJ-09、DJ-10、DJ-12、DJ-15。

4. 离开场景应停在不可逆动作或第一项新秩序成立处；后续 vacancy、寻人、承接或重逢应另开场景。
   Evidence：DJ-01、DJ-05、DJ-06、DJ-09、DJ-12、DJ-15。

# Counterexamples & Boundaries

- 约定性、可预期的告别不必硬加空屋与重建：莫山山告别窗口 61847–61856 缺少日常替代链。
- 共同离开没有留下者，就不适用 vacancy：大师兄与余帘远行窗口 85775–85824。
- 只有“不想让他们走”的一句愿望，不能升级成完整分离场景：72298–72301。
- 不知情或不依赖离开者的人可以照常生活；离开不应自动让全世界暂停：49488–49490。
- 重逢者若已改变身份、能力或行动位置，应转 `reunion_reentry`，不能用 departure_vacancy 把关系自动复原。
- 等待也可能增加危险、而非通向重逢：酒娘等待酒徒的窗口 84143–84172 是明确反例。

# What Existing Skill Misses

对照当前 `scenes/departure_vacancy.md`，真正需要新增的判断能力是：

1. “共同日常基线 → 首次失灵”的检测。现有 Skill 要求缺席带来变化，但未要求找出第一项具体失效的旧动作，容易写成概念性告别。

2. 对“等待是否为行动”的判定。应能识别等待的约束、占位、成本、期限与用途；否则转普通 aftermath 或 travel transition。

3. vacancy 的分布式后果。缺席不只改变留下者情绪，也会重排店铺准入、公共责任、战术、路线与第三人对空间的解释。

4. 把场景拆为四种不同职责：离开临界动作、首次 vacancy、带线索的改线、重逢后的重新入场。现有文本只给出单一离开场景的总原则。

5. 对替代的边界判断。代理人、血缘关系、制度接班人、旧动作都只能承接局部功能；不能默认抹平失去。

6. 可发现性问题：`departure_vacancy.md` 已存在，但主 Skill 的 Primary Skills 枚举未列出它，选择器层面可能无法稳定选到该场景能力。

# Candidate Transfer Rules

1. **旧动作失灵规则**

   - applicability：离开前双方确有稳定、可重复的共同生活接口。
   - rule：先写一个旧动作或物件失效，再写角色的首次替代、拒绝或改线。
   - stop rule：第一次不可逆移动、失败或新分工已成立即止。
   - failure pattern：反复说空荡、想念、舍不得，却没有具体动作变化。

2. **有条件等待规则**

   - applicability：角色不能立即追赶、召回或离开。
   - rule：同时给出约束、占位动作、等待对象或期限。
   - stop rule：约束解除、成本耗尽，或角色明确改线后结束。
   - failure pattern：角色只是望远、回忆、流泪，没有可改变的下一步。

3. **局部替代规则**

   - applicability：有代理人、继承人或新关系试图进入缺席者留下的位置。
   - rule：明确其授权来源、允许进入的范围，以及仍不可替代的旧功能。
   - stop rule：第一次接受、拒绝或设限后结束。
   - failure pattern：新人立即完整复制旧关系，使失去无成本。

4. **离开与余波分场规则**

   - applicability：离开本身已包含争执、交接或物理越界，后续仍有空位后果。
   - rule：离开场只完成决定与不可逆动作；下一场再写首次失灵、责任承接或寻人。
   - stop rule：越界、托管或路线确定即切场。
   - failure pattern：一场内同时完成告别、悲伤、重建、寻人和治愈。

5. **改线寻人规则**

   - applicability：缺席者仍可能被找到，且出现可行动的线索。
   - rule：线索必须改变地点、同行者、资源或风险安排。
   - stop rule：角色已选择一条可验证的新路线。
   - failure pattern：笼统“找遍天下”，没有路线、线索或代价。

6. **失去后的承接规则**

   - applicability：离开者原本承担可指认的责任、能力或位置。
   - rule：让承接者修复第一份被打断的工作物，或接下第一项明确任务。
   - stop rule：第一轮承接落地后，不立即宣称一切恢复正常。
   - failure pattern：只写“他接过了责任”，没有对象、任务与实际动作。
