# Cross-Window Findings

1. **只展开“状态跨门”的工序，而不是完整流程。**
   值得展开的是：单材能否提纯、多材能否兼容、雏形能否稳定、异常输入能否被处理、成品能否被保全；稳定守火和重复批次可压缩。证据：DPC-01、02、06、07、10、12；反证边界：DPC-09。

2. **失败要改变下一步的可选项，而非充当固定戏剧税。**
   失败可消耗备份、暴露“配方正确但输入不适配”、迫使止损，或把目标改成保全中间态。证据：DPC-03、04、05、07、10；反证边界：DPC-08 的协作过程没有靠失败制造张力。

3. **中间产物应有明确的“质量传递”。**
   上一阶段不是背景：提纯物决定能否融合，雏形决定是否能救场，完成的药液决定能否进入修复，有限备份决定下一步能否继续。证据：DPC-01、02、03、07、10。

4. **制作完成与价值成立通常是两步。**
   价值可由市场估值、裁决比较、受用者反应、组织行动空间或稳定收容证明；应依当前冲突选择一种，而非统一增加围观者。证据：DPC-04、05、06、11、12；反证边界：DPC-02 的重点是行动前置条件，不必等市场或公众评价。

5. **公开压力只在它能改写制作选择时才进入镜头。**
   比赛规则、倒计时、围观和对手会影响保全、风险承担或裁决；纯私密学习、修复和闭关不需要硬塞观众。证据：DPC-03、05、10、11、12；反证边界：DPC-01、06、09。

# Counterexamples & Boundaries

- **不必公开证明。** DPC-01、02、06 的核心价值来自家庭危机、后续身体风险或修复对象，不来自舞台喝彩。
- **不必每次失败。** DPC-08 的张力来自职责切分与总融合，不需要“炸一次炉”。
- **不必展开长时工作。** DPC-09 把数十日训练压缩为投入、失败痕迹与能力变化；DPC-06 只在耐性本身接近极限、且疗效尚未发生时才把长期守火拉近。
- **不可随意救场。** DPC-03、07 的救场都有已成立的中间状态或特异相克条件；没有这些已建立条件时，应报废、延期或改路线。
- **成品不必都走售价。** DPC-04 适合鉴价，DPC-11 适合受用者反应，DPC-12 适合收容；错误做法是把三种证明全部堆进同一场。

# What Existing Skill Misses

当前 [crafting_creation.md](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/crafting_creation.md:5) 已覆盖“材料反馈→调整”，第 7 行已要求压缩重复工序，第 9–11 行也已覆盖检查、使用与转交 `showcase_evaluation` / `resource_economy`。因此，“不要教程化”“成品可见”“有评价”“有首次使用”不是新增贡献。

真正可新增的判断能力只有三项：

1. **阶段门，而不是泛反馈。**
   现有文本没有要求 Writer 判断“哪个中间态一旦成立，就把风险传递给下一阶段”。DPC-01、02、07、10 反复显示：提纯物、融合物、雏形、有限备份都不是装饰性进度条。

2. **不可逆窗口中的三选一：继续、保全、报废。**
   现有规则允许返工，却未要求在材料已投入、容器将毁、时间将尽时明确选择。DPC-03、04、05、07、10 支持该判断；它不能退化为固定的“主角总能救回”。

3. **制作场受到外部压力时，应先保护哪个已成立状态。**
   现有库允许不同场景切换，但没有制作侧的切换规则。DPC-03、07、10、12 表明：外部压力到来后，读者关心的常常已不是下一道工序，而是中间态、成品或归属能否被锁住。

“消耗品要用实际效果证明价值”不列为新增：现有 `crafting_creation` 与相邻 Skill 已能覆盖，避免近义重复。

# Candidate Transfer Rules

1. **阶段门展开规则**
   - **applicability**：当前制作至少存在一个会决定后续能否融合、成形、使用或保全的中间状态。
   - **rule**：只展开该状态的形成、它返回的可观察信号，以及由信号强制产生的下一步；其余连续加工压缩。
   - **stop rule**：中间状态稳定并把问题移交给下一阶段时停。
   - **failure pattern**：把每种材料、每次火候都写一遍，读者却不知道哪一步改变了成败。

2. **不可逆窗口决策规则**
   - **applicability**：存在有限材料、倒计时、容器损坏、体力枯竭或无法重做的输入。
   - **rule**：故障出现后，先让人物判断：继续完成、保住已成形部分，还是立刻报废止损；选择必须改变后续资源或胜负条件。
   - **stop rule**：救回、止损或报废已经成为不可逆事实时停。
   - **failure pattern**：每次故障都靠临时加码成功，导致风险失去可信度。

3. **压力下的成果保全规则**
   - **applicability**：外部竞争、干扰、雷劫、抢夺或场地崩坏，能威胁到已存在的中间产物或成品。
   - **rule**：将主问题切换为“该保护什么、放弃什么、用何种既有条件保护”；不要继续播报配方。
   - **stop rule**：成果已安全交付、收容、失去或被正式裁决时停。
   - **failure pattern**：把制作与比赛/战斗割裂，危机发生后人物仍机械完成原流程。

4. **消耗品价值证明路由规则**
   - **applicability**：成品外观不足以说明价值，且当前冲突属于市场、竞争、关系义务或身体风险之一。
   - **rule**：只选一种对应证明：市场用独立估值/交易，竞争用可比裁决，关系义务用受用者变化，危险物用稳定收容。
   - **stop rule**：所选证明已改变人物可获得的资源、关系、资格或行动空间时停。
   - **failure pattern**：成品一出现就堆叠价格、掌声、疗效、排名和传说，反而稀释当前戏的主问题。
