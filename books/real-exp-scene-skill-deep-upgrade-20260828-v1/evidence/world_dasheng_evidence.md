# Research Question

乡野、城市、组织与修行圈首次真正改变人物行动时，原文如何用少量物件、职业、仪态、价格/待遇、身体与空间细节，建立有生活感的层级入口，而不抢走当前动作。

# Cross-Window Findings

1. 首次跨层时，世界信息应落在“会改变行动的通行装置”上：船与分流、登记桌、令牌、阵法、席位、地方接待，而非独立设定说明。读者一旦知道谁能进、凭什么进、进后承担什么，就已能预测下一拍。`DSE-03/04/07/08/10/12/15`

2. 生活感来自一个可感知细节与一个社会机制的咬合：牛与饭对应劳力支配，银子对应村权，骑具对应资源阶层，饭菜对应治理结果，乞丐与鹿对应城市偏好。单有气味、建筑或服饰不是生活世界。`DSE-01/02/05/07/13/14`

3. 价格、待遇和职位应写成“重新分配行动权”，而非数字或名头展示：分银改变村人立场，县令可调药材且负招生义务，上卿意味着阵营绑定，白狼统领在异地却未必有实际权威。`DSE-02/06/11/12`

4. 层级最好经由第三方的即时反应完成验证：沉默、改口、排斥、让位、行礼、求饶、害怕被波及。这样读者看到的是系统对人的作用，而不是旁白替系统宣布强弱。`DSE-02/04/09/11/12/15`

5. 头衔不是可携带的绝对实力尺子；地域、关系网和机构衰败会重估它。新区域的制服穿法、服务质量、谁敢顶撞，足以替代一段地方势力图。`DSE-03/07/10/11`

# Counterexamples & Boundaries

- 不在急动作里补全世界：`DSE-04` 的准入冲突只保留楼、令牌与处置；`DSE-11` 的地方风物在冲突启动后立即让位给人际试探。
- 不把“有生活感”理解成温暖或繁荣：`DSE-14` 的臭味、窝棚、鹿与乞丐共同服务于制度矛盾；`DSE-15` 的宴席服务于恐惧。
- 不因政策、职业或组织出现就写宏观介绍：`DSE-13` 的水利、种子、税赋之所以成立，是它们立刻解释了孩子体格、饭桌和观察者判断。
- 不把原文中的地方规则提升为全书普遍规律：如南海郡的地方化组织失灵只见于 `DSE-11`；县令的资源能力也仅由 `DSE-06` 支持。

# What Existing Skill Misses

现有 Scene Skill 已要求场景入口自然、资源戏有取舍、展示戏有现实后果；但缺少三项独立判断能力：

1. “入口锚点”选择：`scene_entry` 还是 Utility，未规定新世界应优先选择能改变通行权的物件/手续/位置，而非泛泛环境描写。
2. “生活细节—制度因果”绑定：`resource_economy` 处理资源配置，但没有覆盖非资源戏中，用饭菜、服饰、侍者、住房和价格作为层级证据的能力。
3. “名位的本地有效性”判别：`showcase_evaluation` 有比较基准，却未要求在异地先验证职位是否被承认、由谁承认、承认失败后人物会失去什么行动权。

# Candidate Transfer Rules

1. **层级入口锚点**
   - Applicability：人物第一次进入新村镇、城市、组织或修行圈，且当场有明确目的。
   - Rule：选一项空间/物件、一项在场者习惯、一道实际筛选；三者必须共同改变人物下一步。
   - Stop rule：读者已能判断“谁能进、凭什么进、进后风险为何”即停。
   - Failure pattern：导游式建筑清单，删掉后人物行动毫无变化。

2. **待遇必须转换为行动权**
   - Applicability：职位、赏赐、价格、食宿、配给、招揽或晋升出现时。
   - Rule：只给一个正常门槛或日常代价，再显示待遇让谁可调用资源、免除义务或被迫站队。
   - Stop rule：待遇已使下一步选择改变。
   - Failure pattern：连续报数、报品阶、报头衔，却没有人因此改口、让步或改变路线。

3. **异地头衔先做本地验证**
   - Applicability：人物带着旧身份进入陌生地域或衰败机构。
   - Rule：用制服穿法、接待规格、第一句称呼或下属的越界，测试该头衔是否在当地兑现。
   - Stop rule：权威已被确认、拒绝或重新议价。
   - Failure pattern：把跨地域名位当万能通行证，地方人物只作背景板。

4. **宏观世界压进一户人家或一项日常**
   - Applicability：需要让读者理解组织/政策已经改变普通生活。
   - Rule：选饭桌、劳作、孩子游戏、住房、就医或商品价格中的一个，并给出可见因果。
   - Stop rule：该日常已迫使观察者修正判断，或改变人物的即时决定。
   - Failure pattern：用一段总评代替人的身体、饭菜、工作与关系。

5. **高层空间用礼仪而非说明书分级**
   - Applicability：宴席、会面、招揽、考核、总部等高压社交场。
   - Rule：让座位、退场权、记录权、谁先说话或谁承担风险，承担层级信息。
   - Stop rule：人物已知自己的谈判位置与越界后果。
   - Failure pattern：反复解释组织架构，现场却没有任何人因身份不同而得到不同对待。
