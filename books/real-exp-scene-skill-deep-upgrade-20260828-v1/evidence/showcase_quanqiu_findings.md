# Cross-Window Findings

1. **最低充分结果不是固定“打一招”，而是让拥有分配权的人无法继续按旧价行动。**
   榜单让同辈追赶、外来者索名、校方按高规格处理（`GQG-SHOW-01`）；战场斩杀令敌城撤逃（`GQG-SHOW-04`）；公开承诺令初武唤醒战力（`GQG-SHOW-12`）。

2. **惊讶应按观察者的利害关系分层，而不是多人换词夸强。**
   懂行者识别能力并判断上限（`GQG-SHOW-02`）；同级敌人先感到死亡威胁、后改变逃战策略（`GQG-SHOW-04`、`GQG-SHOW-10`）；普通人把保护者的可见力量转为行动与信心（`GQG-SHOW-08`）；高层以请求、观望或威慑回应（`GQG-SHOW-11`）。

3. **先给旧尺，后给不可逆结果，最后只兑现一个现实变化，读者就已能完成重估。**
   “五品第一”把旧战绩压成共同尺（`GQG-SHOW-01`）；“不够资格”的敌方判断被跨阶斩杀翻转（`GQG-SHOW-09`）；“已废”的误判被一次反击翻转（`GQG-SHOW-10`）。

4. **当能力的真正价值是外溢收益，身体或关系中的第一例比参数更有效。**
   残肢重生与老人重新爆发使抽象资源具备可见价值（`GQG-SHOW-02`）；阳城居民同时看见九品被压制与阵法机会（`GQG-SHOW-08`）。这两窗均表明：实际可用性比追加数值更能完成社会定价。

5. **确认后通常应立刻进入新局面；仅当“确认”本身仍缺执行主体或条件时，才继续。**
   归来、榜单与学校声望成立后即转场（`GQG-SHOW-05`）；群妖退离即切断接触（`GQG-SHOW-06`）；但第1206章的承诺还需获得可执行的条件确认和动员，故不能在惊讶处停（`GQG-SHOW-12`）。

# Counterexamples & Boundaries

- **仅有好看战斗，不自动构成 Showcase。** 第165–166章《决赛》《交流赛结束》（25341–25724）有比赛结果，但本窗口未展示足够明确的新资源、身份或敌策变化，排除。
- **只有排名而缺现实后果时，公开评价的价值有限。** 第277章《三品第一》（45645–45807）证明了排名和外界知晓，但窗口内未出现新的资源分配或行动改变，排除为主证据。
- **喜剧性围观不等于重新估价。** 第461章《友谊第一，比赛第二》（80437–80665）中的反应主要服务于竞赛喜剧，未稳定改变待遇或策略，排除。
- **“战斗能否过关”优先属于 combat / trial。** 第617章前段是战斗；只有斩杀外溢为敌城撤逃后，才进入 `showcase_evaluation` 可借用的 Public Proof 区间。
- **强者的单句评价不等于合作。** `GQG-SHOW-11` 中“希望”只证明重新估价与试探请求，不能推为正式联盟。
- **宣言只有驱动可观察行动才是 Public Proof。** `GQG-SHOW-12` 的有效性来自质询、唤醒、备战和敌方不敢当笑话；没有这些后果的豪言应在确认后收束。

# What Existing Skill Misses

现有 `showcase_evaluation` 已正确覆盖：比较基准、实际结果、按立场反应、现实后果，以及“不要重复同一层级测试”。本次证据支持的新增判断能力不是重复这些原则，而是：

1. **识别“谁有重新报价权”**：反应角色不只按立场区分，还要看其是否能改变排名、资源、部署、城市秩序、谈判或战场策略。`GQG-SHOW-01/04/08/12`。
2. **把惊讶分成信息链而非情绪数量**：识别者校准异常、受害者改策略、分配者改待遇、群体据此行动；同层重复惊叹应删。`GQG-SHOW-02/04/10`。
3. **区分“结果已成立”与“结果仍缺执行承诺”**：前者应停，后者必须补最短的条件确认或资源调动。`GQG-SHOW-05/06` 对照 `GQG-SHOW-12`。
4. **把大规模展示压缩为一个身体/空间结果加一个制度后果**：断肢再生→学校可用战力，轻踩九品→地方职责与机会规则，斩八品→敌城撤逃。`GQG-SHOW-02/04/08`。
5. **要求反转先有可行动的误判**：敌人必须已经据旧估值采取控制、轻视或靠近策略，隐藏结果才会真正改写局面。`GQG-SHOW-10`。

# Candidate Transfer Rules

1. **规则：先选“报价者”，再写展示。**
   - Applicability：场景中有能改资源、资格、合作、敌策或部署的人。
   - Rule：展示前明确其旧报价；展示后只写其改变的一项现实动作。
   - Stop rule：该动作已落地，就转入它制造的新问题。
   - Failure pattern：让无行动权的围观者轮流夸强，或让所有角色做同一种震惊。

2. **规则：能力展示优先落到第一项不可逆实用结果。**
   - Applicability：新能力的价值不止伤害，还能恢复、保护、供给、赋权或重写边界。
   - Rule：挑一具身体、一个空间规则或一项可获得机会作为效果载体；后续同类结果压缩。
   - Stop rule：读者已能回答“它现在能替谁解决什么旧成本”。
   - Failure pattern：用连续参数、连续受试者或解释性旁白替代效用。

3. **规则：反转展示必须先让误判进入策略。**
   - Applicability：主角被低估、伪装、受伤或有未公开的复合优势。
   - Rule：先让对方基于旧判断做一个可失效的选择，再用一次结果使其改逃、改防、改谈或改价。
   - Stop rule：旧策略被废、下一策略已出现。
   - Failure pattern：敌人从未真正按旧判断行动，爆发就只是突兀加数值。

4. **规则：公共战果用“短宣告 + 可执行后果”两段式。**
   - Applicability：战果发生在远处，需要回流到组织、城市或更大共同体。
   - Rule：短宣告只给核心事实；第二段只保留排名、资源、动员、撤逃或身份变化中的一项主后果。
   - Stop rule：公共信息已被可信 ruler 固化。
   - Failure pattern：回放战斗、逐个采访、把结算拆成多章重复确认。

5. **规则：公开承诺不以欢呼验真，以他方承担成本验真。**
   - Applicability：展示对象是阵营选择、合作提议、身份宣告或政治承诺。
   - Rule：让有执行权的一方提出条件，并以调兵、让渡、备战、邀请或停止某行动回应。
   - Stop rule：承诺已获得最短执行闭环。
   - Failure pattern：只有高声宣言和情绪，没有任何人因此改变资源配置。
