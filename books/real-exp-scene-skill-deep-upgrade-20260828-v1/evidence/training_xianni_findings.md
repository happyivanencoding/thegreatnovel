# Cross-Window Findings

1. **无新信息的重复可压缩；改变方法、风险阈值或可执行能力的节点必须展开。**
   支持：`E01, E02, E04, M726, L1736, L2054`

2. **时间跳跃要留下至少两类可回看的标尺：阶段/计数、身体或空间状态、外部见证、下一行动。只报年份不够。**
   支持：`E03, E04, E05, M726, L1894, L2054`

3. **失败值得展开的条件不是“痛”，而是它迫使角色更换变量、确认上限、止损，或改变继续条件。**
   支持：`E01, E02, M713, M960, L1736, L1918`

4. **领悟成立的最低证明是：旧解释被排除或修正，随后出现新的可执行动作、预测或选择；完整实战验证可后置，但不得消失。**
   支持：`E06, M960, L1403, L1736, L1918`

5. **身体细节只有充当“承载阈值、累积代价或能力结构变化”时才承担成长叙事功能。**
   支持：`E04, M713, M1157, L1894, L2054`

# Counterexamples & Boundaries

- 时间不自动换来境界：`E03` 的长期闭关仍卡在原层级。
- 突破不自动换来全套成熟能力：`E02` 中多个法术仍失败或不稳。
- 内景领悟不自动成为稳定技能：`M723` 只有一次残留现实效果。
- 被动等待不是训练：只有同时存在对手试探、不可逆代价和明确结果条件时，`L1894` 才成立。
- 身体受损也不是固定必需税：`L1403` 的微型机制领悟主要靠观察与可执行模型。
- 角色的解释不等于确定世界设定：本报告未采用含有大段未证实历史推断的候选作为核心证据。

# What Existing Skill Misses

当前 `training_learning`、`comprehension_insight`、`breakthrough_advancement` 已明确“无新反馈则压缩”“理解须落到行动”“突破须有身体或世界反馈”。新增的不是同义重述，而是五个判断能力：

1. **长期段落的承重物选择**：现有 Skill 未明确要求在时间压缩后保留“阶段标尺 + 状态变化 + 下一步行动”这一最小组合。
2. **失败是否值得占场**：现有 Skill 说要有反馈，但未区分“普通再失败”与“改变变量、承载阈值、退出条件或身份连续性”的高价值失败。
3. **身体细节的功能判断**：现有 Skill 列举身体跟不上，却未要求身体描写必须承担阈值、代价、重构或行动限制中的至少一项。
4. **延后兑现的领悟**：现有 `comprehension_insight` 偏向当前场景得到现实反馈；原著显示可先完成可执行模型，再在后续场景兑现，但该未来兑现必须可追踪。
5. **时间跳跃后的外部校准**：现有 Skill 没有要求把长修炼后的状态交给环境、同辈、强者或社会位置作一次可比较验证。

# Candidate Transfer Rules

1. **长期训练压缩规则**

   - Applicability：日常重复不再改变方法、关系或风险。
   - Rule：压缩日常；保留至少一个阶段标尺、一个身体/环境/关系变化，以及一个由新状态触发的行动。
   - Stop rule：新状态已被行动或外部反应确认。
   - Failure pattern：只写“数年后变强”，没有可见差异或行动后果。

2. **失败展开筛选规则**

   - Applicability：训练、领悟、恢复、渡劫或试验首次受阻。
   - Rule：仅展开会改变假设、练法、承载阈值、退出条件或下一次目标的失败；其余同构失败压缩为结果。
   - Stop rule：角色已更换具体变量、确认路径无效，或明确止损。
   - Failure pattern：反复做同一动作，只换“更痛、更累”的描述。

3. **领悟兑现规则**

   - Applicability：角色从现象、前辈演示、旧知识冲突或失败中建立新模型。
   - Rule：写出被排除的旧解释、可执行的新因果，以及新模型允许角色对什么对象做什么；若本场不验证，必须进入可追踪的后续应用。
   - Stop rule：新模型已改变一次判断、试验、选择或行动。
   - Failure pattern：只写“若有所悟”，没有对象、动作、预测或后续兑现。

4. **身体细节准入规则**

   - Applicability：修炼、领悟或突破涉及身体变化。
   - Rule：只保留能标记承载上限、不可逆代价、结构重构或行动限制的身体细节。
   - Stop rule：身体状态已改变角色能否继续、怎样继续或完成后能做什么。
   - Failure pattern：疼痛、流汗、吐血仅用于装饰强度，删掉后剧情判断毫无变化。

5. **长跳跃外部校准规则**

   - Applicability：跳过数月以上训练、闭关、等待或重复吸收。
   - Rule：跳跃后安排一次环境、同辈、对手、资源关系或旧障碍的比较，使读者看见“过去做不到/现在能做到”。
   - Stop rule：比较已给出当前能力边界与下一问题。
   - Failure pattern：跳跃后立即报新等级，读者无法判断其实际行动空间。
