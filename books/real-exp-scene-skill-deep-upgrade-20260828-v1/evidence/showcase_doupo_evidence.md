- **标尺 / 读者模型**：不是“火焰多就赢”，而是双方在同一控火命题下能调动的有效力量。
- **停点**：叶家承诺回报、曹单离开。
- **Interpretation / transfer observation**：数量可作为视觉证据，但必须绑定场内同一任务，不能孤立报数。
- **anti-inference**：不能推成“火焰越多必然越强”，也不能把暂时退让写成和解。

### DP-13｜五大家族魂值考核

- **定位**：第1143章；**57298–57342**；anchor：`魂值1395`
- **场景姿态 / 目标**：公开数值考核；挽回叶家的五大家族资格。
- **Evidence**：叶家若不能进入前三将被剔除；旧门槛是白鹰的 785，曹单认为萧炎无法超过。石碑读数达到 1395，突破旧记录；主持者宣布第一。
- **展开 / 压缩**：展开已有门槛、读数前静默、官方宣布；压缩其他人的完整测量。
- **状态改变的交换**：叶家从濒临出局转为拥有继续通过后续考核的现实机会。
- **反应**：曹颖从旁观转正视；曹单转嫉恨；叶家松弛；主持者转热切。
- **身体 / 空间细节**：大殿、石碑、镜盘、数字、静默。
- **标尺 / 读者模型**：先让读者记住第三名数字，再给远超数字的单一结果。
- **停点**：第一名与记录成立，进入下一项目。
- **Interpretation / transfer observation**：纯数值场景也可有冲击，前提是数字先承载真实淘汰后果。
- **anti-inference**：该数值不是人物全部实力，也不等于已赢得整场考核。

### DP-14｜古族成人仪式挑战

- **定位**：第1327、1329—1334章；**67875–68270**；anchor：`我输了`
- **场景姿态 / 目标**：外族人面对上位家族同辈的公开约战；取得被正视的资格。
- **Evidence**：前置门槛是需在古妖手中坚持百回合，才足以堵住反对者；古妖以血脉、境界和古族尚武秩序压迫，拒战会被视为可笑。萧炎前段受伤，后以隐藏火莲逆转，古妖公开认输。
- **展开 / 压缩**：展开低位标签、天阶压制、观众误判、火莲翻转、认输；压缩完整招式链。
- **状态改变的交换**：正式判定败者后，原先幸灾乐祸者不再敢轻易挑衅。
- **反应**：同辈由嘲弄转为避让；长辈以明确话语约束继续挑衅。
- **身体 / 空间细节**：仪式广场、血脉测试、地面崩裂、异火显现。
- **标尺 / 读者模型**：先让权威提出“不败百回合”的低标，再让实际结果越过它。
- **停点**：认输及旁观者退让。
- **Interpretation / transfer observation**：低预期门槛可先让读者理解“被尊重的最低条件”，反转后无需再加一轮证明。
- **anti-inference**：胜利有隐藏手段、战术与强者制止因素，不代表稳定碾压对手。

### DP-15｜陨落山巅三局两胜

- **定位**：第1527—1538章；**78851–79430**；anchor：`一决生死`
- **场景姿态 / 目标**：势力间公开赛制；重估联盟与旧霸主的相对位置。
- **Evidence**：双方无法承受全面战争，因此用三局两胜战帖结算；前两局平局，最终由萧炎对敌方首领。最终击败后，围观势力开始判断霸主位置可能变化。
- **展开 / 压缩**：展开战帖、赛制、前两局未定、最后胜负及战后流向；压缩三场全部招式。
- **状态改变的交换**：敌方撤退；联盟成员获得新声望，外部仇敌与强者开始加入联盟。
- **反应**：内部由紧张转狂欢，外部由观望转站队，敌方则沉默撤离。
- **身体 / 空间细节**：约定山巅、两方阵营、赛制等待、最终重伤与撤退。
- **标尺 / 读者模型**：赛制先限定“什么算赢”，避免单场高光无法改写势力叙事。
- **停点**：声望、新成员流入、撤退三项现实后果显现。
- **Interpretation / transfer observation**：势力级 Repricing 要把个人胜负接到可见的阵营流动。
- **anti-inference**：即时“霸主易位”仍是社会判断，不等于政治秩序已完全稳定。

### DP-16｜药典九品玄丹

- **定位**：第1564—1570章；**80741–81018**；anchor：`丹雨降`
- **场景姿态 / 目标**：行业最高层公开炼丹较量；重定第一炼药师身份并换取家族性资源。
- **Evidence**：旧判断是近百年无人炼成九品玄丹，连主持者也预期四人因能量不足失败；四鼎公开启动后确实陷入失败预期。关键资源转移发生后，萧炎成丹并出现外部异象。
- **展开 / 压缩**：展开历史不可能、能量不足、资源转移、异象、确认与授予；压缩数日炼制过程。
- **状态改变的交换**：同行承认其行业首位；药族允许药老在宗族碑完成原本无法取得的记录。
- **反应**：不服者被结果压住；主持者从复杂审视转为兑现请求。
- **身体 / 空间细节**：四鼎、能量被争夺、丹雨异象、在场者共同确认。
- **标尺 / 读者模型**：先建立历史失败率，再让“失败中的资源重组”成为真正转折，而非把异象误当成功。
- **停点**：名衔和宗族碑资源落实。
- **Interpretation / transfer observation**：最高级证明可把技术成果兑换为关系与制度权限，但要写清中间的资源条件。
- **anti-inference**：不能写成独立、稳定、无辅助地胜过所有同行；成功含资源汇合与偶然因素。

# Cross-Window Findings

1. **Public Proof 先要有“会造成损失的旧价”，再给可翻案的标准。**
   旧价不是泛泛轻视，而是“不给资格、封锁市场、要求退出、拒绝保护、准备剔除”。标准则要能被现场复核：石碑数值、统一药方、时间上限、回合契约、赛制。
   支持：DP-01、02、05、06、09、11、13、15。

2. **证明完成的标志不是惊叹，而是有人被迫改变下一步行动。**
   高价值反应是发徽章、交交易点、撤威压、退出冲突、改为保护、承认城市控制、允许宗族碑、加入联盟；纯“众人震惊”不能单独结算。
   支持：DP-02、06、08、10、11、12、15、16。

3. **过程只展开会改变判定的那个“证明铰链”。**
   可保留首次失败、关键环境限制、一次可见反制、官方验定；无新差异的炼制、攻防、旁观者换词应压缩。
   支持：DP-01、05、06、07、09、11、16。

4. **强结果常会把关系改成更清晰的敌意，而不是和解。**
   公开败北可撤掉轻视，却可能带来报复、羞耻、吞并计划转移或更高层介入。
   支持：DP-03、04、05、10、12、14。

5. **社会价格若依赖两个权源，证明也必须分两段。**
   战力可证明“不可轻犯”，信物、职业认证、正式授予才证明“应被谁保护、可进入何种制度”。
   支持：DP-02、10、16。

# Counterexamples & Boundaries

- **已有声望已足够时，不必重演证明。** 第563章附近，强榜第二出场后对手直接认输（**28661–28665**）。排名已是有效社会价格，再加展示只会重复。
- **客观通过但没有外部改价，不属于 Public Proof/Repricing。** 第1156章的幻境通关（**58035–58068**）证明个人能力，但缺少公开排名、授予或关系变化。
- **失败不自动产出 Repricing。** 九龙雷罡火测试里多数候选失败后只被筛掉；没有新的身份、资源、敌意变化，就无需逐个保留。
- **华丽异象不能替代结果。** 药典中一度四人都被判断会失败；真正结算来自后续资源转移、成丹确认与制度兑现，而非异象本身。
- **同一见证者、同一连续考核不要重复计数。** 五大家族第二项灵魂操控（**57349–57395**）可以继续抬高评价，但与 DP-13 属同一批人、同一考核链，不宜当作独立跨窗口规则证据。

# What Existing Skill Misses

现有 `showcase_evaluation` 已包含比较基准、可见效果、立场化评价、压缩重复反应和实际后果；这些不应重复造一个近义 Skill。

真正新增的判断能力应是：

1. **Repricing eligibility gate**：判断这是不是“公开证明”，而不只是公开发生。必须已有一个持有人明确、会影响行动的旧价；否则应留在 `trial_challenge`、`crafting_creation` 或普通 aftermath。
2. **可证伪标准绑定**：基准必须提前决定失败会意味着什么；不能先让结果发生，再让旁白临时宣布它很强。
3. **Ruler 与 spectator 分层**：观众的惊讶可服务体验，但只把裁判、机构、敌手、资源持有人作出的行动改动计为 Repricing 完成。
4. **双权源证明识别**：当战力、身份、关系凭据分别决定不同资源时，不能用一次胜利代替全部社会认证。
5. **反应预算的硬判断**：每个保留反应都要回答“它改变了谁的下一步？”答不出时，删掉“震惊、议论、赞叹”。

# Candidate Transfer Rules

1. **先挂出可损失的旧价。**
   - Applicability：有人正因低估而拒绝资格、压价、封锁、羞辱、逼退或不提供保护。
   - Stop rule：旧价、持有人、损失已经清楚后，立即进入标准。
   - Failure pattern：只有“大家看不起他”的抽象旁白，读者不知道证明会改变什么。

2. **标准先于结果，而且应能当场验定。**
   - Applicability：考核、约战、比试、公开试用、竞标、资格审查。
   - Stop rule：规则足以让读者预判“失败 / 成功各会怎样”即停止解释。
   - Failure pattern：结果出来后才补规则，或用旁白强行把普通表现称为压倒性。

3. **只展开证明铰链，压缩熟练重复。**
   - Applicability：结果由一个关键选择、反制、验定、资源投入或身体对照决定。
   - Stop rule：该铰链已让旧解释失效，就不要再堆同层级招式或工序。
   - Failure pattern：为显得厉害而逐招复盘，真正的胜负标尺反而被淹没。

4. **反应只保留能改写下一步的人。**
   - Applicability：结果会影响身份、资源、敌意、合作、资格或关系。
   - Stop rule：已有一个代表性人物执行改价，如授予、认输、撤回、保护、交付、离场。
   - Failure pattern：多人轮流用不同措辞惊叹，但没人付出成本或改变决定。

5. **分开证明“能做到”与“有资格获得”。**
   - Applicability：资源还依赖身份、关系、合法性、归属或机构授权。
   - Stop rule：第二个权源也已被可核验证据触发。
   - Failure pattern：人物战胜对手后，作者直接跳到获得高层保护、职位或准入资格。

6. **不为证明而证明。**
   - Applicability：已有公认声望、证明不改变资源，或场景核心仍是过关本身。
   - Stop rule：直接使用既有社会价格，或切换到 `trial_challenge` / aftermath。
   - Failure pattern：每次登场都安排围观者重估，造成重复高光和通胀。

# Source Fidelity Audit

- 所有纳入窗口均有章节与本地 source line locator；未使用网络、模型记忆补剧情或外部资料。
- 未纳入“只有私下能力通过、没有公开重定价”的第1156章幻境通关（**58035–58068**）。
- 未把强榜既有声望导致的直接认输（**28661–28665**）伪装成新的证明场景。
- 未把 DP-13 后紧邻的灵魂操控继续测试单独算作跨窗口证据，避免同一场考核重复计数。
- DP-08 的结论限定为“势力后盾获证明”；未夸大为主角单独击败全部挑战者。
- DP-11 限定为控火资格；DP-13 限定为魂值；DP-16 明确包含资源汇合和偶然条件。无强证据时均未外推为稳定、全维度实力结论。
