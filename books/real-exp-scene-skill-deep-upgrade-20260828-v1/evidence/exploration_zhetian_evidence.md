# Research Question

奇观、遗迹与未知空间中，人物如何以“移动—发现—判断—新边界”组织阅读；何时放慢发现，何时压缩路线；怎样以可感尺度、危险与价值，让地点成为值得进入、却未必可以进入的对象。

**Evidence**

**Interpretation**

- 状态交换：向导建议改为升空远观，队员仍想挖石；黑风使“再走一点”从意见分歧变为立刻致死。
- 他者反应：向导拒绝再走；轻视边界者最先死亡，幸存者被迫各自保命。

- 反例：当地点主要承担生存惩罚时，不应继续用奇观导览拖慢；应交给生存、撤离或战斗。

**Evidence**

- 前态：众人已认定禁区不可涉足，持令者声称不得不入。
- 展开 beats：同伴反复劝止 → 核验古令 → 到边缘即停 → 镜面远观两人进入 → 禁区异动 → 古令被收 → 人物当场被打碎。
- 压缩：禁区内部路线完全不展开，因为观察者不掌握其位置与行动；只保留边缘、雾气、声音和结果。
- 状态交换：古令原被视为进入凭证，结果只换来接触资格，不能换取安全。
- 他者反应：所有旁观者从质疑、紧张到认为其死亡，构成地点的社会性危险标尺。
- 身体/空间/细节：边缘不可跨、远距镜池、仙雾与隔空声音；“每一步可能有杀机”以进入者结局兑现。
- reader ruler：此处的空间尺度是“谁能看、谁能入、谁仍不能理解内部”，不是地理尺寸。
- 停点：进入者毁灭，场景立即转为同伴反应与禁区存在的后续交涉。

**Interpretation**

- 反例：未知空间不一定需要内部导览；若 POV 只能旁观，压缩路线、把门槛和后果写实反而更清楚。
- 不可据此推广为“禁区只需秒杀”；此窗的效果依赖此前已建立的古令期待。

## E12｜第1339章《地府》｜L123757–123831｜锚点：“守护此城”

**Evidence**

- 场景姿态/目标：在异星小型冥土中，从远观巡逻者到主动潜入城关。
- 前态：人物初见阴兵，不确定地点性质；同行孩童从恐惧逐步转为兴奋。
- 展开 beats：看见阴兵 → 对跨多地同名传说做推断 → 发现骨上王城 → 绕行全星 → 俘虏阴兵取记忆 → 得到“守城”残念与人偶 → 判断城外无收获 → 潜入 → 生命体触发整城阵纹。
- 压缩：绕遍陨星只留“阴雾、骸骨、阴兵集中于城”的结论；重复俘虏动作只保留共同结果与一个例外。
- 状态交换：阴兵从“鬼怪印象”变为可跨星域调兵的组织痕迹；城外探索结束，入城改变风险级别。
- 他者反应：孩童的恐惧—适应—兴奋呈现非战力者的读者坐标；阴兵由巡逻转为合围。
- 身体/空间/细节：小陨星、白骨王城、黑雾、甲胄年代、生命体被阵纹感应。
- reader ruler：外部可绕行、城内有阵纹、守卫只保留单一命令，三层信息足够建立行动图。
- 停点：红毛身影出现，探索已转为遭遇战与谜团对抗。

**Interpretation**

- “先以低成本对象取样，确认外层不再产出，再进核心”能让主动深入成为判断后的选择，而非作者推人入门。
- 不可将所有重复试探保留；本窗恰因十余次结果相同而压缩，只展开变成墨玉人偶的例外。

# Cross-Window Findings

1. 探索应在“行动地图被改写”的节点放慢，而非在每次移动时放慢：入口失效、路线分层、价值第一次可见、风险规则被实证、进入权被否定，都会产生选择；同功能移动可直接跨越。见 E02、E03、E04、E06、E08、E12；旁观禁区时内部路线完全压缩的边界见 E11。

2. 尺度必须是可行动的 ruler，而不是形容词。可用深度/距离、可见范围、身体承受、地标相对关系、前人死亡位置、谁能站在哪一层来标定；其作用是决定能否靠近、是否绕开、是否再验一次。见 E01、E02、E05、E06、E07、E10。

3. 地点会成为“想进入的对象”，不是因为被命名为秘境，而是价值被具体化，同时进入权被一项可见代价抵住：神药近在眼前却受古棺杀机阻隔、石刻能推进修行却有凶禽领地、帝墓显现却被强者和禁制占据。见 E01、E07、E08；“真名/盛景不足以证明价值或真伪”的反证见 E09。

4. 路线压缩的正确单位不是时间，而是“没有新的风险模型、价值模型或选择”。一个月漂流、数百里接近、数千米下潜、反复击杀低阶威胁都可压缩；但每次重新推演、接近核心、发现例外、身体出现新代价时必须展开。见 E02、E05、E06、E10、E12。

5. 未知空间的停止点应是下一主问题获得清晰归属：被吸入后转生存，确认敌人后转战斗，证据足够后转调查，进入权不足则转撤离或等待窗口。见 E02、E04、E09、E11、E12。

# Counterexamples & Boundaries

- 第224章中，古矿边缘主要成为生存阈值，黑风出现后不再适合继续强调古迹壮观；应交接给撤离/生存，而非延长探索（E05）。
- 第620章中，化仙池的发现很快被“异常渡劫者是谁”取代；若继续写湖面、古木和传说，会遮蔽真正的对手识别（E09）。
- 第951—952章中，前人死于剑意不等于主角也必须逐寸试探。主角能稳定处理的蝙蝠与常规阻碍被压缩，说明节拍须随能力差调整（E10）。
- 第1183章中，观察者无内部 POV、也没有行动权时，内部路线不应伪装成可知地图；门槛、远观和结果已经足够（E11）。
- 第054章前半的干尸与黑雾首先是规则失效，不宜误归为纯探索；它在人物被迫追人、空间开始可读后才转为奇观/遗迹探索（E01）。

# What Existing Skill Misses

当前 [`exploration.md`](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\exploration.md) 已明确覆盖“环境改变行动地图”“发现落到靠近/绕开/标记/撤退”“转入其他主问题即停止”。因此，移动—发现—判断—新边界本身不是缺口。

真正新增的判断能力是：

1. **空间尺度 ruler**：现有 Skill 要求读者知道人物在哪里，却没有要求用距离、视野、行进时间、地标关系、身体承受或前人位置，把“宏大/深邃”转成可复核的行动尺度。

2. **探索专属的慢/快切换**：全局规则已说“有状态变化就展开”，但 exploration 未指出首次奇观、尺度重校准、入口阈值、价值与风险同时改变时应放慢；也未指出连续移动应如何切成若干信息节点后压缩。

3. **地点吸引力的运行时绑定**：现有文本知道“高价值地点未必有进入权”，但 exploration 单独运行时缺少一条明确链路：`具体用途/机会窗口 → 风险阈值改变 → 进入、等待或保留撤离权`。现有欲望参考材料并不自动进入 Primary Router。

相邻的 `horror_anomaly`、`survival_endurance`、`investigation` 分别覆盖规则失效、生存余量和证据收缩；它们不能代替上述三项探索特有判断。

# Candidate Transfer Rules

1. **尺度落地规则**

   - Applicability：人物首次看见会影响进入或选路的未知空间。
   - Rule：只选一个主尺度 ruler（距离/深度/视野/时间/地标比例/身体承受）和一个近景细节；随后必须让它改变“能否再近、从哪走、谁能走”。
   - Stop rule：ruler 已支持一次明确选择后，停止继续堆叠尺寸。
   - Failure pattern：反复写“无边、巨大、深不可测”，读者却不知道人物与目标相隔什么、为何不能接近。

2. **发现节点减速规则**

   - Applicability：首次奇观、入口阈值、规则违例，或价值与风险同时变得具体时。
   - Rule：放慢为“看见 → 用身体/工具/他者反应校验 → 做出靠近、绕开、标记、等待或撤退决定”。
   - Stop rule：决定已经改变路线、权限或风险模型，即压缩后续同质移动。
   - Failure pattern：要么把每一步都写成导览，要么一眼看尽全貌而没有判断过程。

3. **价值—进入权绑定规则**

   - Applicability：地点被设为潜在资源、线索、传承、救援目标或可改变人生的机会。
   - Rule：给出一个具体用途或窗口，同时给出一项看得见的进入成本；用人物或旁人的反应表明该成本如何改变风险阈值与退出权。
   - Stop rule：读者已清楚“为何想要、为何现在不能直接拿、下一步可做什么”。
   - Failure pattern：地点只有“有宝”的宣告；或危险只剩“很可怕”，两者都不改变人物选择。

4. **分区试探规则**

   - Applicability：空间可区分为外层/核心、可测/不可测、可撤/不可撤的区域。
   - Rule：先以可撤回动作验证一层；保留一次真实撤离手段；只有结果支持时再进入下一层。
   - Stop rule：发现核心已超出当前能力、信息或撤离权时，停止推进并交接给准备、潜入、生存或撤离。
   - Failure pattern：角色靠一句“谨慎”继续深入；或每层都重复同一种试探、没有新的边界。
