# Cross-Window Findings

1. 压力下先处理的不是“沟通质量”，而是各自最不能丢失的东西：宁缺优先保密、保命或保留行动空间（JY-D02、JY-L03、JY-L04）；莫山山优先拒绝价值污名（JY-D04、JY-D05）；师兄弟则分别保人、保规则、保风险、保服从位置（JY-D07）。

2. 同一人物的直说、沉默、玩笑必须服从“核心目标是否受阻”：外围冒犯可延后处理，救治路径被规则堵死时才升级（JY-D02、JY-D05、JY-L04）；玩笑紧接他人痛苦则失效，应转为事实说明（JY-C01、JY-D04、JY-L08）。

3. 私人关系与身份差可以同时成立，但要让它们在不同层面结算：公开场合的礼数、程序、军权仍有效；私下的称呼、命令、沉默或行动只改变具体人际边界（JY-D05、JY-D06、JY-L03、JY-L07）。

4. 对白的状态变化需要落在可观察反应上：离席、收刀、收行囊、停止杀意、继续处刑、饮尽酒、仍然离开（JY-C01、JY-D05、JY-D06、JY-L02、JY-L03、JY-L08）。没有此类动作时，漂亮话不应被判定为关系转折。

5. “聪明人”不可共用一套成熟谈判腔：有人以规则回应，有人用礼数安抚，有人用自承缺陷，有人用事实冷讽，有人只以行动答复（JY-D07、JY-D08、JY-L06、JY-D06）。

# Counterexamples & Boundaries

- 玩笑不天然降温：在关系伤口刚被揭开或对方正在交出痛苦时，玩笑会错位，只能转为说清现实目标（JY-D04；反例候选：第三卷第六十章《涧畔句句错，不想错过》39245–39269）。
- 直说不天然获得结果：莫山山重开裁决但未消除身份压力；集体求情也未撤销处罚（JY-D05、JY-D07）。
- 礼数不等于道德让步：长拜仍可伴随处刑，正式程序仍可维护暴力（JY-L07）。
- 沉默不天然等于同意：桑桑以沉默、行囊与行礼完成选择（JY-D06）；宁缺的沉默则在知识试探中暴露风险（JY-D08）。
- 私人称呼不天然跨越制度或神性鸿沟：亲密关系可获得“被理解”，却仍不能改变退出路线（JY-L08；反例候选：第五卷第六十五章《问天（下）》66442–66487）。
- 讽刺需有可支撑的现场权力：面对旧创伤施害者时，冷事实能反转控制，但依赖制度与力量结构已改变（反例候选：第六卷第四十章《熊孩子，光明者，普通人（上）》76700–76755）。

# What Existing Skill Misses

当前 `relationship`、`social_bargain_decision`、`comedy_banter` 已经要求人物有真实反应、对白改变关系或条件，也明确玩笑不能覆盖风险。新增的不是同义提醒，而是以下判断能力：

1. **压力优先级判定**：先识别每人此刻首保的是秘密、行动空间、尊严、制度位置、关系债务还是“我不愿成为什么人”；再决定他会直说、绕答、礼貌、讽刺还是退出。现有 Skill 只要求“按性格反应”，未给出这种可执行的分化轴。

2. **双层话语协议**：同一场景同时标记“公共身份协议”和“私人关系协议”。前者决定谁能命令、谁须行礼、哪些条件可公开说；后者决定谁的短句、沉默或动作真正能令对方改变。避免把亲密写成对权力结构的自动豁免。

3. **玩笑的功能诊断**：区分玩笑是在保密、试探、降格身份、拖延决定，还是在对方刚交出伤痛时构成错位；后一种必须停止玩笑并转入事实或行动目标。

4. **结果层级拆分**：将“被理解”“态度软化”“暂时停手”“路线改变”视为不同结果。关系戏允许只做到前两层，不能因为有情感确认就伪造合作、和解或留下。

# Candidate Transfer Rules

1. **先定首保对象，再定说话法**
   - Applicability：多人受同一压力，且角色地位、关系、风险不同。
   - Rule：为每个核心角色写出一个首保对象；首轮对白只服务该对象。
   - Stop rule：首保对象已被对方承认、拒绝或转化为动作后，进入下一行动。
   - Failure pattern：所有聪明角色都先报筹码、讲道理、谈双赢。

2. **公共协议与私人协议并写**
   - Applicability：亲密关系置于宗门、家族、军政、师徒或制度场。
   - Rule：每句关键对白标记它改变的是公开位置，还是私人边界；两者不可混写。
   - Stop rule：双方已明确谁仍受程序约束、谁能触发私人行动时停止解释。
   - Failure pattern：一句亲昵称呼就让权威规则、旁观者与利益关系全部失效。

3. **玩笑必须有功能与落点**
   - Applicability：人物以玩笑、脏话、挖苦处理高压。
   - Rule：明确它是在保密、试探、降格、拖延，还是缓冲；下一拍必须出现对方的误解、反击、接梗或行动变化。
   - Stop rule：玩笑已完成一次关系温度或权力位置变化，即回到主冲突。
   - Failure pattern：角色持续抖机灵，危险、悲伤或核心问题被消音。

4. **把沉默写成可读选择**
   - Applicability：角色面对秘密、身份压迫、无法接受的条件，或不愿公开情绪。
   - Rule：沉默前给出可回答的问题；沉默后让其通过离席、收物、行礼、看向对象或改变路线结算。
   - Stop rule：行动已明确沉默的含义时停止旁白代译。
   - Failure pattern：沉默只是一串“没有说话”，读者无法判断其是同意、恐惧、压抑还是拒绝。

5. **允许理解而不允许伪造结果**
   - Applicability：双方关系真实，但一方握有不可逆身份、路线或职责。
   - Rule：可让对方承认感情、治疗伤害、停顿或留下一句承诺；除非事实条件已变，不让其自动改道。
   - Stop rule：态度已变化、路线仍明确时结束场景。
   - Failure pattern：一场告白立刻消除制度冲突、战争目标或身份鸿沟。
