# Research Question

刺杀、伏击、暗处交锋与多方混战中，有限视野怎样驱动因果；风险怎样由动作成立；何种接触点应展开；误判后怎样重估；何时应停止场景。

# Evidence Windows

## SE-01｜第0046章《我的》｜3370–3419

- 姿态/目标：熟人伪装成玩闹伏击，实际目标是杀死顾慎为。
- 前态：他察觉左右有人，却把异常归因为同伴玩笑。
- 证据：展开“呼吸不如守卫稳”这一异常、首次偷袭、背伤、悬崖铁链、贴身夺刀与第二次反扑；压缩常规招式。状态交换是他由容让转为以伤换近身、取得制伏，继而因解释与站位错误再失足坠崖。对手先因被扼喉恐惧，后伪装力竭再次出脚。身体/空间只取肩伤、铁链、崖缘。
- 停点：坠落已把当前杀局转成求生，不留在原地继续解释。
- 解读：读者不必先知动机；只要看见“判断错了什么—身体付了什么价—空间如何封死”即可跟住因果。可迁移为：真相揭开后，优先改写人物的行动许可，不先补解释。
- 反推限制：不能据此推出“停下来讲话必败”；本例的失败来自崖缘、对手仍有行动力和错误判断叠加。

## SE-02｜第0097章《巷战》至第0098章《俘虏》｜7080–7155

- 姿态/目标：护送疑似证人，故意留漏洞诱捕灭口者。
- 前态：少年队已布伏，却把目标理解为“来杀证人的少数刺客”。
- 证据：展开醉汉探路、楼上箭雨、守卫追杀离开马车、街巷新骑队逼近、车顶近战；压缩普通交战。状态交换是外围队形因追杀瓦解，马车从诱饵变成孤点；顾慎为随后发现敌方真正要杀的是自己。对手通过假围观、同时开窗、分层追骑改变局面。空间只取车厢、屋顶、直巷转入巷道。
- 停点：援手回到留人巷、俘虏到手；下一问题转为“谁改写了目标”。
- 解读：多点攻击不必逐人写；应展开第一次让保护结构失效的接触点。
- 反推限制：不是所有队形分散都构成失误；这里因为核心目标仍留在空位，才成为致命状态变化。

## SE-03｜第0282章《伏击》｜19426–19446

- 姿态/目标：暗中监视两名线索人物，跟踪灭口刺客以找幕后者。
- 前态：顾慎为守了两夜，以为自己是观察者。
- 证据：展开黑血旗诱走全城、刺客入巷、落地即前后四刀、屋顶回撤、女弓手齐射；压缩两夜守候及其余追兵。状态交换是跟踪者在落地瞬间变为被围者，随后第三方清场又使他失去活口。蒙面人全程无喊叫，女弓手只给“跟我走”的新选择。空间是小巷、院墙、屋顶。
- 停点：伏击者死尽，核心问题转为女弓手的身份与意图。
- 解读：有限视野的有效写法不是反复强调黑暗，而是让“已确认的线索”被敌人用作反向定位。
- 反推限制：不能把所有突援写成救援；此处援手同时剥夺审问机会，仍制造新的信息债。

## SE-04｜第0314章《突袭》｜21778–21796

- 姿态/目标：孟氏连续三拨夜袭龙王府。
- 前态：对方以报复为目标，却高估金钱、人数和训练标签的可替代性。
- 证据：第一拨因已付钱而意志松散，被压缩为结果；第二拨的“诱敌—侧后偷袭”与守方同构战术被展开；第三拨女杀手因尸体、血与真实杀场失序而迅速崩解。状态交换是袭方从主动报复变为三次消耗，并把城内观感交给守方。
- 停点：天亮后公众形成力量判断，场景转为政治后果。
- 解读：当多轮动作服务同一结论时，保留“每轮失败的不同机制”，而非平均展开三场战斗。
- 反推限制：这不是“实战一定胜训练”的一般结论；文本明确针对保密训练、缺乏真实行动经验且被现场尸体打乱的该批人。

## SE-05｜第0331章《挑战》｜22979–23052

- 姿态/目标：帐内守护无法还手的同伴，帐外是人数与手段未知的强盗。
- 前态：顾慎为以近距离生命感知覆盖帐篷周边，但不知道敌人从何种介质接近。
- 证据：展开地下三股生命感应、三剑命中、帐篷被暗器拆塌、枪杆被反借力、远程暗器迫使其不能闪避；压缩敌方名号和围观反应。状态交换是“守住帐内”因帐篷坍塌变成露天受压，对手的远距打法迫使他改变位置。
- 停点：荷女恢复最基本交流能力，守护目标不再完全静止；下一阶段变成两人如何面对余下敌群。
- 解读：低信息动作可用一个可复核的感官规则承载，不必把黑暗神秘化；规则一旦失效，立即改写战术。
- 反推限制：不能泛化为超常感知万能；文本明确给出持续高速运转不可久持的代价。

## SE-06｜第0529章《夜袭》｜36702–36734

- 姿态/目标：夜间营地骤遇不明大军，先完成己方可作战编组。
- 前态：酒宴刚散，只有哨报“敌人来袭”“至少三千”。
- 证据：展开各群体反应差异、龙方五十人与女射手的站位、北庭人找马与失序、火把显出敌军、对方从正面停住而两翼扩散。压缩大量个人起身、穿甲与呼喊。
- 状态交换：不明袭击被确认为同族骑军的包围，冲突从“迎敌”转成“谁有权向客人索人”。
- 停点：敌方身份、包围形态与索求已明确，夜战问题转为谈判/单挑安排。
- 解读：大规模低视野场景先给读者一个能改变决定的轮廓：火点、翼侧、人数级差、己方可用阵列。
- 反推限制：不要求所有夜袭都先谈判；这里因为王旗、来者身份和目标可被语言暂时约束，才允许降速。

## SE-07｜第0622章《混战》｜43211–43260

- 姿态/目标：公开比武失控为二十余人的混战；顾慎为需要在内息反噬前改变局部胜负。
- 前态：敌我分组尚清楚，但强敌牵制、保护对象与旁观大军同时存在。
- 证据：展开“进攻”命令如何令卫兵由守转攻、最薄弱目标被先后取走、三名卫兵死亡、顾慎为在混乱中只选最强气息连出三剑。压缩其余人逐招往返。反应不是集体震惊，而是银雕亮令旗、骑兵转向保护。
- 状态交换：局部胜负被确认，但龙王的身体代价与骑兵指挥权成为更高优先级。
- 停点：令旗改写全场命令归属，战斗问题结束。
- 解读：多方混战可用“一条命令—一个薄弱点—一项新控制权”串起；读者无需知道每个人正在对谁出招。
- 反推限制：这不支持任意让主角“感知最强者”；文本此前建立了功法状态且同时保留误伤友军的代价。

## SE-08｜第0629章《刺杀》｜43681–43731

- 姿态/目标：帐内宴饮突变为七人刺杀，守方需先让老汗王脱离匕首半径。
- 前态：银雕站在烛光与阴影交界监视，但注意力一度偏向龙王。
- 证据：展开喊声触发、七人排练式扑击、掀翻酒案挡住四人、银雕抱人后退、狭窄帐篷限制持刀卫士横斩、龙王以拳抢先。压缩其余宾客的具体动作，只保留他们在“表忠/自保/装死”之间的瞬间选择。
- 状态交换：刺客被制住后，最危险者暂时变成仍持刀且被怀疑的龙王；老汗王一句“住手”重置全场目标。
- 停点：老汗王定性、清场、离帐；不继续追加尸体处理。
- 解读：杀意由“谁先占据可杀距离、谁被器物挡住、谁的武器因空间失效”成立，不靠抽象的危险词。
- 反推限制：桌案不是通用掩体；它在此只因冲击路线、帐篷宽度与目标位置而有效。

## SE-09｜第0784章《绞杀》｜55293–55359

- 姿态/目标：多方围住两名互为死敌的核心高手，外层人物试图借他们互杀获利。
- 前态：核心二人短暂同向攻击，外围仍各怀目标。
- 证据：展开最强对手先被共同压力逼退、外围九人形成第三层、木老头把外围逼向核心、骆启白反向把所有人赶入死亡中心；压缩多数单次刀剑交换。反应通过“各自为战还是并肩”的临时结盟出现。
- 状态交换：战斗由松散围攻变成无法抽身的旋涡；外围人的每次介入都会被核心刀剑杀伤。
- 停点：最后外围强者倒下、核心二人首次拉开；新的伏击者立即接管场景。
- 解读：多方混战应持续维护“核心危险源—外围推力—唯一退出口”，而非轮流报每组战况。
- 反推限制：不能照搬“所有人被卷入核心”；本例由两名核心人物不能停手、外层相互利用共同造成。

## SE-10｜第0838章《混战》｜59293–59307

- 姿态/目标：风沙中误入敌后，试图以斜线冲击避开敌群。
- 前态：主将不知道中军位置、剩余兵力和自己是否偏航，只能凭太阳、山势与厮杀声判断。
- 证据：展开对“斜线进攻”的目标说明、风势减弱后的地形确认、听见厮杀即吹两声号令冲锋、撞见提前突围的中原军。压缩大军具体行进。
- 状态交换：寻找敌军的行动被迫改成与另一支溃退军相撞的局部战场。
- 停点：相遇发生，导航问题结束，进入新的接敌问题。
- 解读：有限视野不是取消因果；应让读者知道人物依据什么不完整线索下注，以及新视觉/声音一出现会废弃哪份旧计划。
- 反推限制：这里不证明“莽撞突进有效”；文本明确指出该打法在专业将领看来不应采用。

## SE-11｜第1078章《独逃》｜75466–75535

- 姿态/目标：夜营中黑衣人先毒后杀，再以“救人”身份接近被锁在一起的两人。
- 前态：陈锦克把外部危险理解为可凭武力击退的袭击，并误信暗中友方。
- 证据：展开统一肩窝刺法、三人保持五六步间距、表面试探、锁链带来的侧翼协作、骆少雄突入、林小山拉链破坏追击、毒发、第二层包围。压缩镖师大面积死亡。
- 状态交换：陈锦克从判断同伴拖累，改判其救了自己；又从“强援到场”改判强援中毒独逃，二人变为待俘目标。
- 停点：第三拨无色毒剂令两人失力，黑衣人确认无威胁后逼近。
- 解读：误判应由人物刚看见的动作推翻，而非作者宣布“他想错了”；每次重估都要改变信任、目标或可用动作。
- 反推限制：不等于每个伏击必须三层递进；多层在此服务于“表面营救本身也是筛选/控制”的特定结构。

## SE-12｜第1115章《夜袭》至第1116章《牙印》｜77842–77945

- 姿态/目标：五人潜入夜袭，守方反伏击并寻找背后操盘者。
- 前态：潜入者确认房中无人后发暗器，认为自己仍掌握节奏。
- 证据：展开房外听声、暗器试探、上官如的三招闪避、潜入者等屋顶同伙却无人回应、迷药反制；其后四名同伙被未知第三者杀死，迫使守方重估。压缩馆内其他人醒来后的反应。
- 状态交换：潜入者从猎人变为俘虏；守方从“抓住夜袭者”变为“夜袭者也被人利用，第二刺客仍在场”。
- 停点：尸体伤口与逃走者证明新刺客存在，转入追查，而不继续审讯原俘。
- 解读：成功的反伏击不能只给守方爽感；保留一个由新尸体、伤口或缺席者带来的未解风险，才有后续因果。
- 反推限制：不必强行加第三方；仅当场内残留事实无法由已知双方解释时，才应转入调查。

# Cross-Window Findings

1. 有限视野应被写成“可用证据的缺口”，而非氛围。先给人物一个可靠但不完整的判断依据，再用新动作推翻它。见 SE-01、SE-03、SE-10、SE-11。

2. 致命风险最有效的载体是可改变行动的物件与距离：崖边铁链、车厢、屋顶、帐案、狭窄帐篷、锁链、无色毒剂。抽象“杀意”只在这些动作后才有解释力。见 SE-01、SE-02、SE-08、SE-11。

3. 应展开的是首次接触或局面改写点，不是招式总量：落地遭前后夹刺、保护圈被追杀抽空、酒案改变冲击线、外围被挤入刀剑核心。无新状态的来回交换应压缩。见 SE-02、SE-03、SE-08、SE-09。

4. 误判后的重估至少要落到一项变化：换目标、换信任、换站位、换战术或停止追击。若人物认知更新却不改变下一拍，误判只是装饰。见 SE-01、SE-03、SE-10、SE-11、SE-12。

5. 多方混战适合用局部结构承载：一个核心危险源、一股外围推力、一个决定撤退/归属的门槛或命令。见 SE-07、SE-08、SE-09；SE-06 说明大军夜袭只需先交代可行动的轮廓，不必逐兵逐卒。

6. 刺杀场景应在当前物理问题被解决、且下一主问题已明确时停止：坠崖转求生、伏击转辨认援手、令旗改写指挥权、尸体转出第三刺客。见 SE-01、SE-03、SE-07、SE-12。

# Counterexamples & Boundaries

- 第0045章《暗杀》3302–3334 是少年游戏，虽有跟踪、巷口与撤离，但对象不会真正反杀；它可作为“技巧演练不等于杀局”的反例，不纳入主证据。
- SE-04 表明同一夜三拨袭击不该平均展开：第一拨与第三拨被压缩，只有战术同构和经验崩盘保留。
- SE-06 表明大规模夜袭不必立刻进入近身动作；敌方身份、包围形态、己方可用编组尚未成立前，局部布置比刀法更重要。
- SE-12 表明“第三方再刺”只在尸体、伤口或时序不能被既知双方解释时成立；不能为了续场硬塞新敌。

# What Existing Skill Misses

现有 `combat` 能要求优势变化、对手真实回应与适时退出；`stealth_infiltration` 能处理暴露风险。但它们尚缺三项本证据包支持的判断能力：

1. 信息账本：区分人物已见、合理推测、误读与读者暂不知；并要求新动作明确废弃哪条旧判断。
2. 接触点预算：把“首次触及身体/目标/逃路”“保护结构第一次断裂”“第三方留下无法解释的事实”识别为必须展开点，其余交手可压缩。
3. 多方战的局部骨架：明确核心危险源、外围推力与退出门槛，避免只用“多人混战、场面混乱”替代因果。

# Candidate Transfer Rules

1. **不完整视野规则**
   - 适用：夜间、遮挡、伪装、多人混杂、角色只能获得局部情报。
   - 写法：先给一条可行动证据与一条未覆盖的空白；新动作必须改变目标、站位或信任。
   - 停止：新证据已将当前问题改为追逃、战斗、审讯或调查。
   - 失败模式：只写“看不清/很危险”，却没有人物据此作出的错误选择。

2. **接触点展开规则**
   - 适用：刺杀、伏击、突袭的第一次有效接触。
   - 写法：展开一处身体、一个障碍物或一段距离怎样改写行动；常规换招压缩。
   - 停止：该接触的后果已在位置、伤势、目标控制或撤路上落地。
   - 失败模式：把每一招等权描写，真正改变局面的那一下反而不突出。

3. **误判重估规则**
   - 适用：人物原先的敌我、目标、援手或战术模型被现场事实推翻。
   - 写法：明确旧判断、可见矛盾、即时新选择。
   - 停止：新选择已经进入执行，不用追加长段心理复盘。
   - 失败模式：角色全知不犯错，或犯错后行动完全不变。

4. **多方混战骨架规则**
   - 适用：三方以上、局部视角无法覆盖全场。
   - 写法：每段只维护核心冲突、外围压力和一条出入/指挥边界；其他组别仅在改变这三项时出现。
   - 停止：控制权、撤离权或核心目标已易手。
   - 失败模式：逐组轮播战况，读者知道很多动作却不知道谁的选择改变了局势。

5. **刺杀收束规则**
   - 适用：刺客被制、目标脱险、逃路断绝或新证据显现后。
   - 写法：让结果先落到身体、位置、俘虏、尸体或指挥权，再切入后果场景。
   - 停止：继续动作不再改变当前致命问题。
   - 失败模式：敌人已失去杀伤条件仍追加回合，或未留下可处理后果便突然换场。
