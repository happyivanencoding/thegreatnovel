# Cross-Window Findings

1. 大战背景只在它压迫局部决策时进入镜头：车队路线、城墙火力、一个指挥节点、可撤车辆，而非平铺整片战场。支持：`YY-E02`、`YY-M01`、`YY-M03`、`YY-L03`、`YY-L05`。

2. 枪械的叙事单位不是“开一枪”，而是“有效距离／暴露代价／下一步换位”。极限距离导致单发撤离；蛛丝、雾气、死角和近距手枪改变是否能开火。支持：`YY-E04`、`YY-E05`、`YY-M02`、`YY-L02`、`YY-L03`。

3. 多人交火应以可见的局部职能推进：谁压制、谁补位、谁拖伤员、谁供弹、谁断后；其中一项失效，下一拍才发生。支持：`YY-E03`、`YY-M01`、`YY-M03`、`YY-L05`。

4. 伤势必须进入战术账本：它改变站立、瞄准、装填、移动、恢复、护送或撤离；单写疼痛不构成战斗后果。支持：`YY-E03`、`YY-M03`、`YY-M04`、`YY-M05`、`YY-L05`。

5. 战斗的退出不是“胜负宣布”，而是行动空间被重新结算：弹药耗尽、武器过热、目标进死角、援舰到达、车辆只剩两辆、资源已被搜走。支持：`YY-E04`、`YY-E05`、`YY-M03`、`YY-M05`、`YY-L05`。

# Counterexamples & Boundaries

- `YY-E02` 的初始攻城（约 1645–1660）快速概述，因为局部火力优势已清楚，逐人交换不会产生新选择。
- `YY-E05` 中重创目标后不补枪：目标已进死角，单发成本又高；“有枪就连续补杀”不是默认策略。
- `YY-M02` 后续段落 36254–36259 中，即使有五百米可击杀目标，角色仍等待更高价值的伏击目标；可射击不等于应立即射击。
- 第八卷第二百一十九章《狭路相逢》（60981–61029）中，第三方强敌与枪炮声风险迫使敌对者共同隐藏；但 `YY-L02` 仍发生多点交火。因此“环境危险时停火”只在第三方威胁压过当前收益时成立。
- 第十卷第一百四十章《模拟战争》（80116–80154）为颜料弹演习，可用比例和队形压缩伤势链；不能拿来作为实战重伤处理证据。

# What Existing Skill Misses

当前 `combat` 已明确覆盖局部 POV、距离/位置、资源、团队分工、对手适应与战后余波；这些不是本次新增。

真正可新增的是三个更细的判断：

1. **枪械必须留下“可追踪的后果”。** 现有 Skill 要求交代距离与手段，但未明确要求：每次重要开枪至少令射手暴露、目标进死角、弹道被反推、武器进入冷却／过热，或迫使换位。证据：`YY-E04`、`YY-E05`、`YY-M02`、`YY-L03`。

2. **战争局部 POV 需要“远景压力→局部节点→撤出账本”的闭环。** 现有 Skill 已说用局部 POV 承载战争，但未要求远景只能在改变局部任务时出现，且局部结果必须落到人员、载具、弹药或阵地去留。证据：`YY-M01`、`YY-M03`、`YY-L03`、`YY-L05`。

3. **伤势应给出行动能力的具体变化。** 现有 Skill 已要求结果落到身体，但未明确要求把伤势翻译成“不能站、不能装填、针刺不入、需被拖拽、需就地处理、只能撤离”等下一拍约束。证据：`YY-E03`、`YY-M01`、`YY-M03`、`YY-M04`。

# Candidate Transfer Rules

1. **射击后的暴露结算**

   - applicability：远程枪击、反狙击、火炮拦截，且射击会产生弹道、声响、热量、冷却或位置暴露。
   - rule：关键一枪后，立即写清它改变了谁的视线、位置、武器状态或撤离判断。
   - stop rule：命中／失手已迫使一方换位、收枪、转近战或脱离时停止该段射击交换。
   - failure pattern：枪械只作声效；连续开火却无人根据弹道、死角、过热或位置作出反应。

2. **宏观战场只服务一个局部任务**

   - applicability：军团、舰队、兽潮、攻城、炮击等规模远超单人视野的场景。
   - rule：先确定一个局部可操作目标，例如一段城墙、一辆车队、一个火力点、一个撤离口或一个指挥节点；宏观信息只保留会改写该目标的部分。
   - stop rule：该节点突破、失守、完成撤离或被替换为新目标。
   - failure pattern：只报军力、伤亡与火光，没有任何局部对象因之改变选择。

3. **远近混合以“有效区间”换招**

   - applicability：同场存在狙击、步枪、手雷、短枪、近战或高空火力。
   - rule：至少交代一个有效距离／死角／掩体条件，并在敌我跨越该阈值时切换武器或动作。
   - stop rule：新距离关系已经稳定，主问题转入撤离、近战、隐蔽或谈判。
   - failure pattern：角色持枪近身仍按远距打法，或进入死角后仍无代价持续命中。

4. **伤势转译为能力限制**

   - applicability：伤势、失血、震荡、装备损坏或疲劳会影响后续行动。
   - rule：只保留会改变行动的身体细节：能否站、看、握、装填、跑、被拖拽、处理伤口或维持意识。
   - stop rule：伤势已被处理并明确形成新的行动能力，或已强制进入撤离／恢复场景。
   - failure pattern：角色反复“吐血受伤”却继续执行同等强度动作，且无资源与时间代价。

5. **战后先结算可行动资产**

   - applicability：阶段胜利、敌退、短暂脱离或战线稳住之后。
   - rule：优先结算仍能行动的人、剩余弹药／装备、可用交通、可守空间与下一处风险。
   - stop rule：新行动目标已经成立。
   - failure pattern：刚结束激战就长篇感慨，未交代为什么还能追、为何必须撤、靠什么继续。
