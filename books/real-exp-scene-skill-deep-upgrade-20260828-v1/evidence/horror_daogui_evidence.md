- **他人反应**：无可用人类见证，限制本身承担读者定位功能。
- **身体 / 空间 / 细节选择**：镜面、眼睛、近远距离、残余感官。
- **标尺 / 读者模型**：视觉越全面，认知越可靠。
- **停止点**：有限感知已令目标可行动时停。
- **Evidence**：感知削减带来可操作性恢复。
- **Interpretation**：有限感知不是单纯遮蔽，而是恐怖场景的控制阀。
- **可迁移观察**：大尺度异常中先决定“人物还能用哪一种感官”，并让失去其他感官改变策略。
- **反推禁止**：不能用含混代替空间逻辑；读者仍应知道人物在哪、正避开什么。

## E11｜反例：规则稳定后，恐怖应让位给后果

- **章节 / 行号**：第八百一十七章《死亡》；46808–46857。
- **锚点**：`死亡没了`
- **场景姿态 / 目标**：规则灾难的社会后果；不是悬疑式异常场景。
- **前态**：战场已有明确的新规则：人难以死亡，伤害与疲劳持续积累。
- **展开的 beats**：不死者与伤残者持续作战；一名老人无法结束痛苦；“可死亡”的能力出现后，群体情绪与战场士气立刻翻转。
- **压缩 / 省略**：不重新展示“死亡为何消失”的神秘感。
- **改变状态的交换**：新能力改变群体行动、道德压力与战争资源。
- **他人反应**：围观者立刻把能力当作解脱与可用秩序。
- **身体 / 空间 / 细节选择**：疲惫、残缺、苍蝇、无法停止的痛苦；重点是持续后果。
- **标尺 / 读者模型**：死亡是伤害的最终边界。
- **停止点**：规则一旦稳定且被社会利用，场景转向战争、伦理与资源。
- **Evidence**：异常已被共享、理解并纳入集体决策。
- **Interpretation**：不是所有诡异规则都应持续按 horror 写；稳定规则的代价可以成为另一主场景。
- **可迁移观察**：当人物已能预测异常并围绕它分工，应切换 `survival_endurance`、`combat` 或 `aftermath`。
- **反推禁止**：不表示异常失去力量，只表示主阅读问题已变。

## E12｜先拆掉假鬼，再让物件真正越界

- **章节 / 行号**：第八百七十九章《夜》；50373–50401。
- **锚点**：`麻袋跳来`
- **场景姿态 / 目标**：二段式夜间异常；区别“像鬼的摆设”与“因果不该成立的物件”。
- **前态**：角色夜归、尿急、灯笼照柴房，读者预期传统鬼怪。
- **展开的 beats**：寿衣在暗处看似悬浮；同伴立即给出日常解释并拆掉假象；随后血湿麻袋在无人搬运的情况下向人靠近。
- **压缩 / 省略**：截至麻袋的运动与内容暗示，不揭示里面物体如何行动。
- **改变状态的交换**：角色从误惊变为真正失去行动余裕。
- **他人反应**：一个人先被吓、同伴先嘲笑并解释；第二次两人共同失去镇定。
- **身体 / 空间 / 细节选择**：灯笼光、寿衣、湿痕、重量感、跳动频率。
- **标尺 / 读者模型**：悬浮人形看似异常；但固定寿衣可被解释，装尸块的麻袋不应自行接近。
- **停止点**：麻袋显出异常运动即停。
- **Evidence**：文本明确把第一层恐怖意象降格，再以物理因果违例建立第二层。
- **Interpretation**：怪异不靠“更吓人的名词”，而靠读者已修正判断后再次被更小、更硬的事实推翻。
- **可迁移观察**：可先给一个可解释的假警报，再让真正异常只违背一条清晰物理规则。
- **反推禁止**：不要把每个道具都先故弄玄虚；两段必须分别改变人物判断。

# Cross-Window Findings

1. **先建立“本应如何运作”的具体标尺，再只打断一条规则。** 病房应无洞窟残留、食物应带来满足、醒来应结束梦、物件应不能自行接近；异常因此可见，而不必依赖“阴森”“不可名状”。【E01、E02、E09、E12】

2. **不安应进入人物的行动链，而非停在叙述含混。** 主角会隐瞒、求证、设诱饵、追踪、改为取证或缩小感知范围；每次异常都改变下一步，而非只增加气氛。【E01、E04、E05、E07、E10】

3. **身体反馈可作为异常的最小硬证据。** 疼痛、伤口、呕吐物、窒息、感知过载，都让“我是不是看错了”不能只停在心理层面。【E01、E02、E03、E09】

4. **解释只需停在可行动的操作规则。** 读者可知道“声音不可靠”“旧证据可被重释”“看得太远会失控”，但不必立刻知道世界本体、敌方全貌或时间结构。【E04、E05、E07、E10】

5. **有限感知必须有功能，而不是单纯遮掩。** 某一感官不可靠或信息过量，会逼迫人物改变验证方式、行动距离或信任对象。【E03、E04、E07、E10】

6. **异常一旦稳定、共享并可预测，就不再以 horror 为主。** 此时读者的主要问题变成生存、组织、战争或代价；继续堆诡异只会稀释后果。【E06、E11，加反证边界 E08】

# Counterexamples & Boundaries

- **普通解释已覆盖关键因果时，必须收束。** 食物里的针有监控与具体责任人，继续暗示超常阴谋会损伤证据纪律。【E06】
- **传统恐怖布景不是异常本身。** 手电鬼脸与悬挂寿衣都可由现场操作解释；只有后来发生的、无法由已有操作解释的物件运动才重新建立恐怖。【E08、E12】
- **“世界规则很怪”不等于每场都写 horror。** 死亡消失后，人物和群体都已理解并利用规则，核心是苦难、战争与选择。【E11】
- **高强度怪异不应靠无限增量。** 白玉京段落把“知道更多”写成失控，再以感知缩减恢复行动；它的边界是可操作性，不是词汇密度。【E03、E10】

# What Existing Skill Misses

当前 [`horror_anomaly.md`](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\horror_anomaly.md) 已明确“正常模型失效”“异常回应行动”“不靠形容词堆砌”。本轮真正新增的判断能力是：

1. **证据层级分流**：区分主观异感、身体残留、他人见证、制度记录；并判断哪一层被推翻后仍足以改变行动。【E02、E04、E06】
2. **身体作为验证接口**：不只要求“有身体反应”，而要判断身体后果是否与另一层场景中的动作构成可复核映射。【E01、E02】
3. **感知预算**：决定人物该失去、保留或依赖哪一种感官；“信息更多”可以是危险，缩小感知范围可以是解法。【E03、E10】
4. **假警报的用途与终止条件**：普通解释或人为惊吓应迅速结算；只有后续出现新的因果违例，才能重启恐怖。【E06、E08、E12】
5. **从 Horror 切换的可判定条件**：当规则已共享、可预测、可组织利用时，主问题应离开异常恐怖。【E11】

# Candidate Transfer Rules

1. **单一常识违例**
   - applicability：人物刚进入新空间、熟人关系或日常程序仍可被读者理解时。
   - rule：先给出一个可预测的日常结果，再让一个具体物件、身体反馈或空间连接违背它。
   - stop rule：读者已能说清“哪条规则坏了”后，立即让人物行动。
   - failure pattern：连续增加黑影、怪声、器官、专名，却没有新的规则变化。

2. **感知证据分层**
   - applicability：人物的精神状态、身份或信息来源本就不可靠时。
   - rule：把“主观感到”“身体残留”“他人反应”分开安排；至少让一层推动行动。
   - stop rule：已有足够证据决定下一步防范时，不等绝对真相。
   - failure pattern：所有证据都只靠主角自述，或每个外部见证都无理由背叛。

3. **身体映射只保留一到两组**
   - applicability：需要表现两种感知层、梦境层或异常媒介互相渗透时。
   - rule：让一处身体疼痛、伤口或异物，对应另一层的可定位动作。
   - stop rule：对应关系一旦成立，转入救治、反击或取证。
   - failure pattern：把每个动作都逐项翻译，导致异常变成解码游戏。

4. **先结算假警报，再给硬违例**
   - applicability：夜路、旧屋、废墟等天然携带恐怖预期的场景。
   - rule：允许一个“看起来像鬼”的对象被普通原因拆解；随后用更小但不可解释的因果变化重新起压。
   - stop rule：真正违例被确认时收在人物的即时反应上。
   - failure pattern：把假警报拖成谜团，或把每个道具都安排成会动的怪物。

5. **感知预算**
   - applicability：异常尺度超过人物理解能力，或信息本身造成风险时。
   - rule：明确保留一个可用感知通道，并让其他通道的扩大带来代价。
   - stop rule：限制感知已让人物能完成一个明确动作时停止解释。
   - failure pattern：作者用全知说明填满未知，或用纯模糊让空间与危险失去方向。

6. **规则稳定即切场**
   - applicability：异常已经被多人确认，并能预测其代价与利用方式时。
   - rule：将主阅读问题改为生存、战斗、关系、资源或伦理。
   - stop rule：不再用新增怪象维持同一段张力。
   - failure pattern：世界已适应规则，文本却仍反复要求读者“觉得诡异”。
