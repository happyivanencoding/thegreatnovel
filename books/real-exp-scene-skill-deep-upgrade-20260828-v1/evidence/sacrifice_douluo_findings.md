# Cross-Window Findings

1. **对象价值要先落为“选择空间被改变”，再落情感。**
   高信号窗口都先给出不能两全的压力：敌我差、逃亡路径、考核终点、身体承受或制度使命；感情决定谁承担，而不是替代机制说明。
   支持：SE-DL-01、02、03、10、12、13。

2. **牺牲发生时，最稳的因果链是“不可回收动作 → 受益者立刻获得生机／通路 → 旁观者改变判断”。**
   只写牺牲者的意志不足；必须让物、身体、资格或时间实际移交，并由受益者与见证者各自回应。
   支持：SE-DL-03、04、10、12、13。

3. **“局部恢复”与“主体回归”必须拆开处理。**
   小舞的肉体恢复并不等于灵魂、意识和关系恢复；其魂环也可变强，但仍是缺席的可见痕迹。
   支持：SE-DL-04、05、06、07、08。

4. **遗留能力不应被写成纯奖励；它需要保留来源痕迹、操作限制或未完成关系。**
   魂环与魂骨既提高唐三能力，也触发悲伤、受灵魂恢复限制，并解决旧有战法缺陷而非万能开挂。
   支持：SE-DL-07、08、09。

5. **同构危机的第二次出现，是检验牺牲是否真正改变人物关系的高价值机会。**
   第578章中，小舞再度试图独自承担，唐三以不同代价拒绝复刻第一次结局；读者的判断尺已由第一次献祭预先建立。
   支持：SE-DL-03、04、10。

6. **“不立刻等价补偿”不是“永不修正代价”。**
   可修正，但只能由新增知识、身体边界、授权资源或更高规则明确导出；修正后仍应留下新任务、风险或关系后果。
   支持：SE-DL-06、11、14；反证边界：SE-DL-05、14。

# Counterexamples & Boundaries

- **身体即时恢复并不必然削弱牺牲。** 第578章中唐三伤势获得考核奖励修复，但这一幕的主要变化是双方拒绝重演第一次献祭；适用前提是恢复来自已建立的考核规则，而非作者无来源发糖。SE-DL-10。
- **可回补的代价需要“新信息＋新负担”。** 第605章并未维持“必须交出全部魂环”的初始估算；它用身体承载逻辑重新限定返还范围，并增加补环、补骨和双武魂完成要求。SE-DL-11。
- **复活可成立，但不能跳过死亡造成的秩序变化。** 终局复活前，个人关系、军队意志、敌方判断和战局都已移动；复活本身也有技能条件、未知成功率和多方资源补足。SE-DL-14。
- **不要把普通救援误认作牺牲。** 常规挡击、团队增援、战术掩护若未造成可验证的永久损失、主体缺口或长期责任，不应强套 `sacrifice_convergence`。
- **不要把“死亡即解脱”泛化。** 波赛西场景成立依赖其百年职责、传承规则、唐晨已死和她明确表达的个人状态；不适用于任何年长角色。SE-DL-13。

# What Existing Skill Misses

现有 `sacrifice_convergence` 已经覆盖：先建立无法两全、牺牲动作必须被他人利用／回应、之后留下缺口与承诺、避免立刻抹平损失。这些判断是正确的。

真正新增、且不与既有文本近义重复的能力有：

1. **恢复层级判别。**
   能区分“肉体／局势恢复”与“主体性、可互动关系、独立行动能力恢复”；因此不会因人物醒来、伤口愈合或队伍获胜而误判牺牲已被消解。证据：SE-DL-04–08。

2. **遗物不是奖励的运行判断。**
   识别“牺牲遗留能力”何时仍应携带来源痕迹、使用边界、社会场景中的反向情绪或旧机制缺口，而不是只给主角新增强度。证据：SE-DL-07–09。

3. **镜像危机的反牺牲判断。**
   当旧牺牲已成为关系创伤时，能判断新危机是否应让幸存者阻止重复，而非再复制一次相同牺牲。证据：SE-DL-03、04、10。

4. **代价修正的合法性判断。**
   能区分“新世界信息使原方案过度／有害”与“作者用补偿撤销后果”；前者可修正但要留下新条件，后者会削弱场景。证据：SE-DL-06、11、14。

5. **第三方牺牲的授权链。**
   能检查牺牲者是否拥有独立目标、是否真的授权幸存者承担后果、旁观者是否完成对幸存者的信任重估，避免把濒死配角工具化。证据：SE-DL-12、13。

# Candidate Transfer Rules

1. **先建“唯一出口”，再允许极端付出。**
   - applicability：本章已授权生死／重大失去，且现场存在明确的不可兼得条件。
   - rule：用敌我差、时间、空间、资源或身体承受中的至少一个具体约束，说明常规方案为何失败。
   - stop rule：读者已能复述“保谁、失谁、为什么不能两全”就停止加压。
   - failure pattern：只让角色喊“我必须救他”，却没有可检验的失败条件。

2. **把牺牲写成可追踪的交接，而非情绪峰值。**
   - applicability：牺牲会改变谁能活、谁能逃、谁能使用资源或谁承担后果。
   - rule：明确牺牲者交出了什么，受益者立即获得什么，旁观者据此如何改判关系。
   - stop rule：交接结果和至少一个真实反应已落地，即进入余波。
   - failure pattern：牺牲者独白很长，但没有可见受益、受益者也无需行动。

3. **局部救回时，保留一个不能被该救援解决的主体缺口。**
   - applicability：故事需要牺牲后形成长期目标，但世界允许治疗、复苏或撤离。
   - rule：明确恢复的是身体、位置、资格或短期生机中的哪一层；把未恢复的意识、信任、同行资格、旧能力或关系放进后续行动。
   - stop rule：读者能区分“救回了什么／还没回来什么”。
   - failure pattern：治疗效果一出现，就默认关系与代价全部归零。

4. **遗留物须同时提供效用与缺席证据。**
   - applicability：牺牲者确实留下能力、物件、权限或技能。
   - rule：让遗物解决一个已有的具体问题，同时保留来源、使用限制、情感触发或无法替代原主体的边界。
   - stop rule：遗物第一次改变行动空间后，不重复解释来源。
   - failure pattern：把遗物直接写成纯升级奖励，牺牲者从故事中被抹去。

5. **旧牺牲可在同构危机中转化为新的关系证明。**
   - applicability：当前危机的选择结构确实逼近旧创伤，而不是只有表面相似。
   - rule：让读者先识别“又要谁留下”，再让幸存者以不同真实代价阻断重复。
   - stop rule：共同存活或关系立场的变化已被一个动作确认。
   - failure pattern：仅重复旧牺牲，人物既没有新选择，也没有新代价。

6. **允许代价校准，但不得无因免账。**
   - applicability：新信息真的改变了原先对机制、承载或资源的理解。
   - rule：同时说明旧方案为何错误／过度、新方案为何可行、仍要支付什么新的代价。
   - stop rule：成本账本从模糊承诺变为后续可执行任务。
   - failure pattern：新角色突然宣布“其实不用付代价”，且没有前提、限制和后续负担。

7. **第三方牺牲必须保留其自己的最后意志。**
   - applicability：牺牲者不是主角，且死亡或离场已不可避免。
   - rule：至少给出其独立愿望、对受托者的验证、交托内容，以及幸存者以后必须回应的责任。
   - stop rule：受托关系成立，牺牲者的最后选择已改变幸存者下一步。
   - failure pattern：配角只在主角升级前出现并消失，没有其自身欲望或后续影响。
