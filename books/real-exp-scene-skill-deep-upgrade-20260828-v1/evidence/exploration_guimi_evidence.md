   - pre-state：当地人已数千年看守、仪式无数次，偶有声音却无法解读；主角拥有部分高阶能力但无开门把握。
   - expanded beats：先明确旧方法的长期失败；以正确仪式和分散观察点进行一次可辨识测试；初次无异常不硬判失败；声音出现后才放慢，连接到尊名与时间线；即使出现波动，仍无法打开边界，结论收束为“时间未到”。
   - compressed/omitted beats：数千年重复仪式和反复诵念不逐次展示。
   - state-changing exchange：当地人的等待经验与主角的试验相互校正；环境只给部分回应，不提供通行许可。
   - opponent/other-character reaction：迷雾以无反应、模糊声音、涟漪等不同强度反馈；居民的希望也被限制在可验证范围内。
   - body/space/detail selection：马灯、凝固雾气、祭坛符号、分散的观察点；避免以泛泛“宏大”代替实验边界。
   - ruler/reader model：真正值得放慢的不是第一次看到雾，而是旧方法、当前试验和新回应首次形成可比较结构时。
   - stop point：得出当前无法打开的结论后停止强攻。
   - Evidence：文本先给长期失败史，再给一次受控尝试与有限异常，最后明确未突破。
   - Interpretation：环境的反应等级可以推进场景，但反应不足以授权胜利。
   - anti-inference：不能将“等时机”作为拖延借口；本窗有明确试验、反应和暂时结论。

11. **E11**

   - chapter：第六部·第六十八章《线索》；lines 102588–102661。
   - scene posture/type：旧异常被新时间锚点重释。
   - scene goal：判断月城附近深坑、魔狼出现和仓促离开是否有可追查关联。
   - pre-state：当地仅知道深坑、无爆炸痕迹、调查队遇见魔狼而未受袭；这些都曾是无法解释的旧事。
   - expanded beats：先逐项询问异常形态、调查结果、魔狼行为和是否留痕；获得精确日期后，主角将其与自身进入灰雾的时间连接；旧事故从地方怪谈变成可能与自身行为相关的证据，但仍只作假设。
   - compressed/omitted beats：无关的月城历史和无结果调查不展开。
   - state-changing exchange：当地大祭司提供事实，主角不立即宣告真相，而是止于新增关联。
   - opponent/other-character reaction：魔狼“匆忙离开”是过去留下的异常反应；没有被伪造成直接证词。
   - body/space/detail selection：山丘变深坑、没有土石飞散、无痕离开的魔狼；“缺失”本身成为选择性证据。
   - ruler/reader model：重释成立的最低条件是新发现提供可核对的共同锚点，而不是作者突然宣布伏笔。
   - stop point：形成高价值假设后停止追问，不把关联写成证实。
   - Evidence：日期连接出现后，人物只作“是否与我有关”的判断，并未当作定论。
   - Interpretation：旧证据的价值可因新时间连接跃升，但知识状态必须同步保守。
   - anti-inference：不能由时间相近直接推出因果；本窗保留了其他解释。

12. **E12**

   - chapter：第六部·第七十二至七十三章《探索》《门后》；lines 112820–112994。
   - scene posture/type：废墟调查转恐怖/撤离，后由更高能力者做条件复验。
   - scene goal：在班西废墟搜集可研究材料，并判断多个异常点能否安全触碰。
   - pre-state：探索者持有海盗传闻与地图，但不知电报局、祭坛废墟、木门之间的真实规则。
   - expanded beats：不明液体出现后先短暂观察；确认血痕与壁画值得研究，却不直接取样，改用占星；水晶球爆裂使“可研究”改写为“必须撤离”；第二地点用风吹碎石代替徒手清理，血色渗出后覆盖撤退；木门先按已知安全动作试探，再改变把手操作，才触发街景；恐惧兑现后转为逃离。随后，另一人复刻操作、测试离开原址后的失效条件。
   - compressed/omitted beats：废墟间普通移动和无反应试探没有拉长；重复动作只在触发规则变化时保留。
   - state-changing exchange：隐藏女郎因占星爆炸暴露；木门的回应改变了探索者的心理与路线；后续复验者确认“门离开班西即失效”。
   - opponent/other-character reaction：监视者被诈语引出；门后声音、异象和恐惧构成空间主动回应。
   - body/space/detail selection：水晶球碎片、断肋、风暴、被遮盖的血色、普通木门、灰白雾街；每项都对应一次“碰不碰、怎么碰、还走不走”的选择。
   - ruler/reader model：发现应放慢到足以区分“表面物”“触发动作”“地域条件”和“即时代价”，而非只展示怪异图景。
   - stop point：第一人跨入恐怖/逃离问题后退出探索；第二人确认条件规则后也不强开门内世界。
   - Evidence：文本连续呈现观察、低成本探测、受伤撤退、条件复验四个不同层级。
   - Interpretation：风险递进最清晰的单位，是每一步让可用策略减少或代价上升。
   - anti-inference：不能把所有异常都安排多轮测试；这里复验由更高能力者承担，且只验证最关键的地点条件。

# Cross-Window Findings

1. **发现应当放慢的阈值，是行动模型被改写，而非“出现新奇物”。**
   当发现同时改变路径、风险、目标或解释模型时，文本会补足“观察差异 → 暂定判断 → 环境/他人回应 → 新选择”的局部链条；只增加地点信息则压缩。见 E01、E02、E06、E12。

2. **风险递进以策略空间收缩表现，而不是重复渲染危险。**
   风险可从可观察、可低成本试探，推进到需要撤离、只能由更高层处理、或会把群体卷入不可逆后果。见 E01、E06、E09、E10、E12。

3. **调查必须持续标示知识权限：亲历事实、暂定判断与未知原因不能混写。**
   受限证人的信息范围、人物能力阈值、以及尚未证实的历史关联，都会决定下一步只能做什么。见 E05、E07、E08、E09、E11。

4. **旧证据被重释，必须获得新的约束连接，并立刻改变后续调查对象。**
   壁画与旧神像、长期雾气与当前仪式、深坑与明确日期，均不是“伏笔回收”式宣布，而是以新连接改变问题结构。见 E04、E10、E11。

5. **环境应压缩在没有新选择产生的移动段，而不是因场景危险就一律慢写。**
   普通行进、重复仪式、无辨识力的材料与搜查结果均被压缩；只有规则、风险或路线首次改变时才展开。见 E01、E06、E08、E10、E12。

# Counterexamples & Boundaries

- E01 中三起未找到源头的普通闹鬼事件被快速带过：有氛围、无新判断的重复处理不应占据探索篇幅。
- E03 中梦境足够诡异，但没有必要性、入口控制或可承受失败代价时，正确动作是退出，不是强行揭底。
- E05 中地点价值极高，却因能力与知识不够而延后：不能把“高价值发现”误写成“现在就该进入”。
- E10 中迷雾已经数千年无解；一次有控制的试验仍不足以开门，不能把轻微反馈夸大成突破。
- E11 的日期连接只支持高价值假设，不能直接升级为因果真相。

# What Existing Skill Misses

当前 [`exploration.md`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/exploration.md:3) 已覆盖行动地图、环境细节取舍与探索停止点；[`investigation.md`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/investigation.md:3) 已覆盖线索筛选和假设收缩；[`deduction_reveal.md`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/deduction_reveal.md:3) 已覆盖旧证据重组。因此“环境何时压缩”与“旧证据如何重释”不应重复造新能力。

真正新增的判断能力是：

1. **发现放慢阈值**：现有规则说“改变行动地图的发现应展开”，但未规定何时必须完成局部证据链。新增应是：只有发现重写当前路线、风险、目标或解释模型时，展开“差异—暂断—回应—选择”；否则压缩。

2. **探索/调查的风险状态迁移**：现有 Skill 能写危险，但未要求区分“未知、被怀疑、经试探验证、正在兑现、已规避”。这会导致重复写“很危险”而没有策略变化。E01、E06、E12 展示了应以策略空间收缩来推进。

3. **逐拍知识边界**：`deduction_reveal` 已要求知识边界，但探索与调查尚未要求每个发现区分“直接观察”“当前可支持推断”“仍未知原因”。E08、E11 表明，这会直接决定人物有没有资格据此行动。

4. **场景级交接**：库允许同章切换 Skill，但当前运行时仍以整章一个 Primary、最多一个 Secondary 注入。探索一旦转为生存、恐怖、调查或推理，需要交接行动地图、已知线索与风险状态；并列两个 Skill 不等于真正完成交接。相关约束见 [`SKILL.md`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/SKILL.md:17) 与 [`scene_skills.py`](C:/dev/tgn-story-mvp/src/story_mvp/scene_skills.py:99)。

# Candidate Transfer Rules

1. **转折发现的最小展开**

   - applicability：新发现同时改变路线、风险、目标或解释模型。
   - rule：写清“看到的差异 → 角色的暂定判断 → 现场/他人可观察回应 → 因此作出的下一选择”。
   - stop rule：新选择已明确，且继续描写不再改变风险或行动地图时停止。
   - failure pattern：把每件奇物、景观或传闻都放慢，导致探索变成导览。

2. **风险按策略状态推进**

   - applicability：人物在未知空间、异常现场或受限调查中移动。
   - rule：每次重要观察只在风险从“未知/怀疑/验证/兑现/规避”之一转到另一状态时展开，并明确可用策略发生什么变化。
   - stop rule：风险状态不变、行动方式也不变时压缩；核心问题已变成逃生、潜入或战斗时切换 Skill。
   - failure pattern：连续添加阴森细节，却不让人物的路线、装备、撤离权或选择改变。

3. **证据权限先于结论**

   - applicability：证人、遗物、环境痕迹或历史资料提供信息。
   - rule：逐项标示它是亲历事实、当事人猜测，还是人物仍无法知道的部分；下一步只能使用前两者支持的最小结论。
   - stop rule：已获得足以支持下一次直接行动的事实时停止追问；不要为完整解释滥取证。
   - failure pattern：把受限执行者当作全知解说器，或把时间接近直接写成因果证实。

4. **旧证据的再激活**

   - applicability：当前矛盾出现，且已有旧物、旧名词、旧场景与之存在可检验连接。
   - rule：只召回少量相关旧证据，指出新增连接，再让新解释改变调查对象、警戒对象或验证动作。
   - stop rule：新解释已带来行动后果后停止复述旧线索。
   - failure pattern：为了“伏笔回收”而宣布旧细节重要，却没有新连接或行动后果。

5. **探索到其他 Scene Skill 的交接**

   - applicability：探索已把未知空间转成具体威胁、调查对象或结构性矛盾。
   - rule：交接时保留三项状态：当前行动地图、已知线索及其可信度、风险处于何阶段；后续 Skill 只消费这三项，不重新导览。
   - stop rule：新主问题稳定后，前一 Skill 退出。
   - failure pattern：仍用探索语气反复描述环境，掩盖场景已经转为生存、调查或推理的事实。
