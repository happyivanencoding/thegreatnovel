# What Existing Skill Misses

对照当前 `relationship.md`、`departure_vacancy.md`、`reunion_reentry.md`、`sacrifice_convergence.md`，真正新增的判断能力是：

1. 关系动作的成本分级：区分日常照料、私下暴露、公开对抗、不可逆牺牲；不可无依赖链直接跳至最高代价。
2. 沉默的反事实判定：只有“说出会改变外部结果”的沉默，才是关系 payoff，不把所有停顿都算作深情。
3. 非对称关系状态：单向照料、未回应、旧依恋和第三方责任必须保留，不将一次拥抱或救援升级为对等确认。
4. 竞争义务排序：关系可暂时胜过规则，却必须在师门、群体、生存等现实义务进入时重新做一次可见选择。
5. 牺牲后的关系裁决：当人物为保护一段关系而伤害另一段关系，必须由被牺牲者的最后动作、称呼或托付重写责任，而非由旁白免责。
6. 物件/空间作为关系证据：衣角、伞、座位、遗骸处置、空台并非装饰；只有它们改变占位、风险或下一行动时，才应保留。

# Candidate Transfer Rules

## R1：关系触发的路线反转

- applicability：已有明确安全出口、撤离路线或防守点；另一关系对象位于未知危险。
- rule：先让读者看见可选的安全路径，再用可信但未完全确认的关系线索迫使人物反向进入危险；必须写出空间阻力、身体损耗或社会代价。
- stop rule：人物抵达目标空间，或发现足以改写目标定义的缺席证据。
- failure pattern：只写“因为在乎所以冲过去”，却没有放弃的路线、障碍和代价。

## R2：公开压力下的沉默保护

- applicability：托付物、秘密或关系对象正在被直接追问；人物仍受组织、阵营或身份约束。
- rule：让人物在可举报、可交出、可解释的节点选择否认、改述或不发声，并让该选择保留资源或改变风险。
- stop rule：询问者接受错误解释，或沉默已经令下一行动空间发生变化。
- failure pattern：秘密根本没有受威胁，或隐瞒不承担任何信任、声誉、资源或路线后果。

## R3：微小照料作为关系兑现

- applicability：受伤、寒冷、饥饿、等待、封闭空间等情况下，告白不足以改变实际位置。
- rule：选择一项有限资源或具体身体动作，如伞、食物、座位、衣物、药物；让对方接受、拒绝或反向照料。
- stop rule：资源归属和人物位置已经改变。
- failure pattern：堆叠“担心、心疼、温柔”，却没有资源分配、空间移动或实际回应。

## R4：竞争义务的可见排序

- applicability：恋人、亲人、师门、组织责任至少两条同时真实存在，且两条路线都可执行。
- rule：先允许关系获得一次优先级；危机规模变化后，用求援、伤亡、责任交接等具体讯号迫使人物重新选择。
- stop rule：一条路线被不可逆行动选中，并留下现场缺口。
- failure pattern：人物永远口头两难却不行动；或把爱情写成不受规模和后果影响的万能优先级。

## R5：牺牲后的责任落点

- applicability：人物为保护某段关系，必须伤害、放弃或失去另一段重要关系。
- rule：幸存者应先承受指责、阻隔或身份代价；由牺牲者的最后称呼、动作、遗愿或处置权留下关系裁决和可执行任务。
- stop rule：责任已重新命名，且幸存者明确接住至少一个缺口。
- failure pattern：只有漂亮死亡和哭泣，没有关系裁决、行动任务或可持续后果。

## R6：幻境中的真实关系锚点

- applicability：幻境、心魔、假重逢或诱导回头的场景。
- rule：只调用此前真实发生过的照料、触碰、共同承担或物件行为，使人物的身体方向改变；不得只重复名字。
- stop rule：人物转身、前进或拒绝虚假对象，且诱惑因此失效。
- failure pattern：幻象自行消失；或一次记忆被错误提升为恋爱排序与自动治愈。
