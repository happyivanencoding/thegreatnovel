- Anti-inference：此窗的感知规则属于迷雾森林，不能外推为所有林地均偏向嗅觉追踪。

### YY-L-01｜第四卷第一百八十七章《永夜排名》｜L39382–39402

- Anchor：`又到了撤退的时候`；Posture/type：要塞崩解→空中吊索撤离→掩护射击；Goal：幸存者与受伤指挥者登舰离场。
- Pre-state：要塞已破，地面仍有漏网高阶敌人；指挥者负伤、攀索困难。
- Expanded beats：战舰火力压制地面；幸存者沿吊索攀升；舱门火力优先压倒舰炮漏掉的高阶敌人；受伤指挥者在攀爬中成为远距狙杀目标；同伴以身体承弹并抓住吊索，将其带入舱内，战舰立刻关闭舱门撤离。
- Compressed/omitted：要塞战斗经过压缩为废墟与伤亡状态。
- State-changing exchange / reaction：吊索让撤离边界清晰；掩护火力与同伴承伤决定谁能跨过边界；敌方关键一枪失败后失去后续追击资源。
- Body/space/detail：废墟、吊索、舱门、舰炮、高阶漏网敌、攀爬伤势、远距狙击。
- Ruler：战场撤离的“距离”应由撤离边界、保护对象和持续火线定义，而非全员一起奔跑。
- Stop point：舱门关闭、战舰离场；随即转伤势余波。
- Transfer：先明确谁必须越过何种边界，再让掩护、伤员、后卫与敌方攻击目标围绕该边界变化。
- Anti-inference：本场成功依赖战舰、吊索和同伴能力，不能把身体承弹作为普遍撤离解。

### YY-L-02｜第七卷第二百四十二章《再次脱身》｜L62316–62373

- Anchor：`谁说我要逃了`；Posture/type：强者包围→威慑重排追击者→短促脱离；Goal：先送同伴离场，再从多名强者包围中脱身。
- Pre-state：敌方以领域封锁空间，通常移动能力不足以一次脱出；主角也因高消耗威胁而难以直接开战。
- Expanded beats：主角用可能致命的一枪逼主敌让路；同伴分批撤走；其宣称剩余强力射击，迫使包围者互相估算谁承担代价；一击实际击杀外围较弱者，制造阵线松动后穿越并离开。
- Compressed/omitted：后续分路追踪与二次交战不在本窗。
- State-changing exchange / reaction：武器余量即使未实际使用，也改变对手靠近、分担和封锁的意愿；包围从稳定封闭变成互相避责的空隙。
- Body/space/detail：领域边界、十米风烟、光翼、单次高消耗武器、外围与核心敌人。
- Ruler：弹药/大招在追逃中不是库存数字；其可信的使用可能性会改变对方的路线和接触意愿。
- Stop point：穿过外围、启动位移后脱离视野。
- Transfer：有限强力资源应在使用、蓄势或被对手相信可使用时，明确改变火线和包围结构。
- Anti-inference：这里依赖既有战绩和敌方内部不信任，不能把虚张声势视为普遍可用。

### YY-L-03｜第九卷第二百四十七章《未知装置》｜L88289–88315

- Anchor：`始终保持在十分钟左右`；Posture/type：痕迹追踪→识破假线→远距尾随；Goal：追踪撤退敌人并判断其真实汇合方向。
- Pre-state：两名敌人分别撤离；一方明显留痕，另一方留下蛛丝等细痕。
- Expanded beats：追踪者先从方向和撤离动机判断哪条线更有价值；发现蛛丝痕过于“照顾追踪者”，转而用真实残留能量追踪；敌人绕圈和变向，追踪者依据残留衰减保持约十分钟距离；其后识别到旧信号痕迹，确定敌方已有集合方向。
- Compressed/omitted：后续接近据点与战斗未计入本窗。
- State-changing exchange / reaction：可见痕迹并未提高真实追踪置信度，反而降低；远距尾随避免把自己暴露成可反制目标。
- Body/space/detail：蛛丝碎片、树叶拉曳、绕圈、原力残留、十分钟、信号弹余痕。
- Ruler：应分开“直接看到目标”“最后已知位置”“可疑痕迹”“经验证的真实线索”；它们带来的搜索范围和风险不同。
- Stop point：得到明确汇合方向，转潜入观察。
- Transfer：反追踪后，追击者应更新置信度、延迟与搜索方向，而不是看到痕迹就自动追上。
- Anti-inference：依赖特殊感知能力；普通追踪者不能无代价越过假痕。

# Cross-Window Findings

1. 功能距离，而非“更近/更远”，决定追逃姿态：射程差能把追击变为被压制搜索，沟壑或屋顶会重置可用火线，包围则减少可选出口。支持：YY-EM-05、YY-M-01、YY-M-02、YY-M-03、YY-L-01。

2. 直视接触、最后位置、真实痕迹与假痕必须分开写；脱离视野不是自动脱逃，发现痕迹也不是自动追上。支持：YY-EM-03、YY-EM-04、YY-M-03、YY-L-03。

3. 开火/弹药只有改变下一拍的接近、观察、掩护或撤离时才是有效证据。支持：YY-EM-02、YY-EM-05、YY-M-02、YY-M-04、YY-L-02。

4. 伤势必须映射为具体行动能力或可被读取的痕迹：追踪者被拖慢、逃者无法继续猎杀、攀索者成为保护对象，都会改变队形和路线。支持：YY-EM-03、YY-EM-04、YY-M-04、YY-L-01。

5. 战场撤离是“把人/物越过边界”的资源分配，不是路线日志。支持：YY-EM-06、YY-EM-07、YY-L-01。

6. 逃脱不一定是主角技术胜利；绝对力量差下，真正条件可能是对手迟疑、第三方威胁或敌方内部互不信任。支持：YY-EM-08、YY-L-02；反证边界：YY-EM-03、YY-L-03 中脱离来自可解释的体能/信号判断，而非偶发救援。

# Counterexamples & Boundaries

- 高阶追者对低阶逃者的放弃，可能来自第三方威胁，不应归因于“地形够复杂”。YY-EM-08。
- 断后与不等掉队者是具体约束下的代价选择，不是通用撤离模板。YY-EM-06、YY-EM-07。
- 强力远射在无法改变对方路线、掩体、节奏或资源判断时，只是战斗动作，不自动构成追逃 beat。对照 YY-EM-05、YY-M-02。
- 假痕不等于万能反追踪；它需要足以诱导对方的可见性，且追踪者未掌握更可靠信号。YY-L-03。
- 已排除第一卷第十五章《第一次》L953–1007：主要是短距战斗与背叛，不足以支撑路线级追逃。
- 已排除第二卷第五十一至五十四章 L5277–5304、L5378–5437：单向狙击后撤离，缺少完整追兵相位。
- 已排除仅凭标题推断的第四卷第三十五至三十九章：未把“逃亡”等标题当作证据。

# What Existing Skill Misses

现有 `chase_escape` 已覆盖相对距离、路线、视野、速度、体力、载具、地形、对手适应与退出条件；`combat / stealth_infiltration / survival_endurance` 也已分别覆盖通用资源、伤势、痕迹和生存压力。以下才是新增判断能力，不是近义重复：

1. 功能距离状态：近距、可攻击距、可观察距、失联但可追踪距分别允许什么行动。支持：YY-EM-05、YY-M-01、YY-M-02、YY-M-03。

2. 直视与推断追踪分离：每次失去目标、取得痕迹或识破假痕，都要更新最后位置、延迟、搜索范围与置信度。支持：YY-EM-03、YY-EM-04、YY-L-03。

3. 弹药作为追逃姿态：开火、蓄势、换弹或停火必须改变火线、暴露、掩体、接近成本或撤离意愿。支持：YY-EM-02、YY-M-02、YY-M-04、YY-L-02。

4. 伤势到能力的映射：伤势要具体改变加速、攀越、瞄准、驾驶、携带或留下痕迹，并让对手据此调策。支持：YY-EM-03、YY-EM-04、YY-M-04、YY-L-01。

5. 载具/地形的操作约束：不是“有车/有山”，而是故障、载重、高差、通行性、遮蔽或高度层改变谁能到达、看见或开火。支持：YY-EM-02、YY-EM-05、YY-M-01、YY-EM-06。

6. 战场撤离结构：保护对象、撤离边界、接应火力、伤员、后卫与队形应构成单独目标结构。支持：YY-EM-06、YY-EM-07、YY-L-01。

7. 跨 Skill 状态携带：从追逃切到战斗、潜伏、救治时，至少保留相关的最后位置、视野/置信度、伤势、弹药、出口或保护对象。支持：YY-M-03、YY-M-04、YY-L-01、YY-L-03。

实现层观察：`travel_transition` 与 `aftermath` 当前仅在总览中列为 Utility，运行时没有可加载的对应短 Skill；这不是原著规律，但会使追逃后“带着何种伤势、弹药、追踪状态转场”的表达缺少注入位置。

# Candidate Transfer Rules

### CTR-1：功能距离规则

- Applicability：远近反复切换，且距离会改变攻击、观察、拦截或躲藏能力。
- Transfer rule：先写清当前距离允许谁做什么；距离变化后，至少一项可行动作必须失效或新成立。
- Stop rule：距离稳定到新主问题成立，转战斗、潜伏或撤离。
- Failure pattern：只写“更近了/更远了”，双方可用动作完全不变。

### CTR-2：追踪置信度规则

- Applicability：失去直视后仍依赖痕迹、感知、目击、信号或假线索。
- Transfer rule：每次跟踪/反跟踪更新最后位置、时间延迟、搜索范围或置信度中的至少一项。
- Stop rule：重新取得足够确定的位置、形成拦截，或线索失效而转场。
- Failure pattern：断视野即脱逃；发现痕迹即瞬间追上。

### CTR-3：弹药姿态规则

- Applicability：有限弹药、蓄势、换弹或射击噪声会改变接触代价。
- Transfer rule：开火、失手、换弹或停火必须改变火力窗口、路线、掩体、暴露或继续接触意愿。
- Stop rule：弹药不再改变下一拍，或已转近战/潜伏。
- Failure pattern：枪声只是装饰，资源永不影响选择。

### CTR-4：伤势能力规则

- Applicability：伤势可影响追、逃、攀爬、驾驶、瞄准、携带或隐迹。
- Transfer rule：把伤势落成一个具体能力损失或可被读取的痕迹，并让他人据此调整。
- Stop rule：能力限制稳定，或救治/撤离成为主问题。
- Failure pattern：反复喊疼，人物行动与对手判断均不变。

### CTR-5：载具与地形约束规则

- Applicability：载具、载重或地形实际改变路线、视野、火线、速度或拦截。
- Transfer rule：每段只选一个可操作约束，并让它改变可达性或双方关系。
- Stop rule：下车、损毁、越过地形边界，或该约束不再区分选项。
- Failure pattern：载具只是速度倍率，地形只是景物说明。

### CTR-6：战场撤离规则

- Applicability：目标是把指定人物或物资送过边界，且敌方接触仍可能持续。
- Transfer rule：明确保护对象与撤离条件；每步改变掩护、队形、伤员、后卫、路线或敌方攻击目标。
- Stop rule：对象越界、丢失、被夺，或主问题转为战斗、救援或追逃。
- Failure pattern：撤离写成无目标的跑步，接应与保护对象消失。

### CTR-7：跨 Skill 状态携带规则

- Applicability：追逃、战斗、潜伏、生存或余波之间切换。
- Transfer rule：转场时显式保留相关的最后位置、距离/视野、资源/伤势、出口/保护对象。
- Stop rule：新 Skill 的主要阅读问题稳定成立。
- Failure pattern：一切换场景，位置、弹药、伤势与追踪状态被重置。
