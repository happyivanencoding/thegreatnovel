# Cross-Window Findings

1. 强弱 ruler 必须先于高潮落地，而且最好是对手无法用嘴否认的身体、空间或行动权变化：铠甲裂口、资源耗尽、真身锁定、共享力量断供、撤退被封。
   证据：CD-01、CD-02、CD-04、CD-08、CD-09、CD-11、CD-12。

2. 详细写的不是“交换数量”，而是每次改变读者胜负模型的交换；相同机制的持续对轰应压成环境后果、影子、声响或一段概述。
   证据：CD-02、CD-03、CD-04、CD-06、CD-09、CD-10。

3. 强敌的反应应经历“保留旧解释→投入反制→承认原模型失效”，而非只负责震惊。
   证据：CD-01、CD-02、CD-08、CD-09、CD-10。

4. 底牌递进的触发点是旧方案无法解决当前胜负机制：穿不透铠甲、打不到共享资源的空档、钟裂后仍未锁定真身、终局对撞后敌仍能逃。
   证据：CD-02、CD-08、CD-09、CD-10、CD-12。

5. 公开证明需要转化为待遇、资格、秩序或行动空间；只写旁观者惊叹不足以完成证明。
   证据：CD-01（无人再挑战与处罚）、CD-03（宗门与外部势力重估）、CD-05（学院认可）、CD-06（排名和资格）、CD-10（古族公开认输）。

6. 阶段碾压只能在敌方核心机制已经失效后出现，并应保留边界：CD-11 明言再多一名敌人会重新进入缠斗；CD-02、CD-07、CD-10 都保留主角伤势与资源代价。
   证据：CD-02、CD-07、CD-08、CD-10、CD-11。

# Counterexamples & Boundaries

- 不必每战递进到底牌。CD-04 的短战只用“守住消耗—抓住收力”即可结束；增加终极技反而破坏比赛的功能。
- 不能把命中当胜利。CD-07、CD-09、CD-12 都要求额外确认：敌人是否还能行动、真身是否锁定、是否仍可逃离。
- 阶段碾压不能抹除上限。CD-11 的压制后明确主角消耗巨大；这正是“碾压”成立而不失真的边界。
- 公开展示不必总由观众完整看懂。CD-03 允许观众先看到实力证据、对手后在临界点识别全部身份信息。
- 对手的失误必须可追溯。CD-02 的轻敌、CD-08 的共享力量误配、CD-10 的过早结论，都由先前已建立的机制导致，而非作者强塞失误。

# What Existing Skill Misses

现有 `combat` 已要求状态变化、敌人真实回应、压缩重复交换；`showcase_evaluation` 已要求比较基准和社会后果。新增的判断能力不应是近义复述，而应是：

1. **“证明”与“实力”分层**：数值、观感、实战、社会承认是四个不同状态；应明确本场要消灭的是哪一种怀疑。CD-01、CD-03、CD-05。

2. **胜利机制锁定**：每个阶段先命名对手真正的胜利条件，再判断某一击是否真的废除了它。例如“铠甲还在”“共享力量还能转移”“真身尚未确认”“敌人仍可逃”。CD-02、CD-08、CD-09、CD-12。

3. **反解释链**：对手不只是“震惊”，而是先尝试把异常解释为偶然，再改变战术或投入资源；直到其旧解释无法维持。CD-01、CD-02、CD-08、CD-10。

4. **底牌的功能去重**：同一底牌可以升级规模，但只有当它解决了一个前一层不能解决的新问题才可保留；否则应压缩。CD-03、CD-09、CD-10。

5. **碾压的合法起点**：必须先展示对手的核心反制被拆，才进入短促的一边倒；碾压后立刻切换到俘虏、裁决、余波或新目标。CD-06、CD-08、CD-11。

# Candidate Transfer Rules

1. **规则：先决定本场要证明什么。**
   applicability：公开挑战、排名赛、初次亮相、被质疑的能力展示。
   rule：把“数值成立”“实战成立”“社会承认”拆开；至少用一段可见交换让怀疑者失去原解释。
   stop rule：怀疑已被行动结果和一个现实后果同时消除即停。
   failure pattern：只报等级或只让群众惊叹，随后人物待遇和选择完全不变。

2. **规则：每个战斗阶段只围绕一个胜利机制。**
   applicability：越阶、敌人有护甲/阵法/共享资源/替身/逃逸能力的战斗。
   rule：先让读者看到机制，再让主角的动作改变机制的可用性。
   stop rule：旧机制被废除后，立刻切换到新的胜负问题。
   failure pattern：大招命中即宣布胜利，实际防御、真身、撤离或资源条件仍然存在。

3. **规则：把普通来回压缩，把“读法变化”展开。**
   applicability：同一攻防结构重复三次以上的战斗。
   rule：重复来回可压成环境、伤势或消耗；只有首次识别、首次失效、首次反制和最终验证展开。
   stop rule：继续写不会改变位置、资源、信息、伤势或行动权时退出战斗段。
   failure pattern：每一招都写，读者却无法说出胜负条件发生过何种变化。

4. **规则：底牌必须改变对手的决策，而非只提高音量。**
   applicability：主角有多张技能、法器、形态或资源牌。
   rule：底牌出现后，对手应被迫重估、换目标、改防御或失去原策略。
   stop rule：同一底牌的效果已被完整证明后，后续只保留必要的新用途。
   failure pattern：连续更大招式只造成更大爆炸，没有新的限制、窗口或后果。

5. **规则：阶段碾压用三种不同信号成立。**
   applicability：破阵、强弱层级突变、敌方核心人物失能后的收束。
   rule：至少同时给出身体/资源、空间/位置、行动权三类信号中的两类。
   stop rule：敌方失去反击或撤退资格后，立即转入处置、救援、资格或下一威胁。
   failure pattern：胜者反复击倒已无行动能力的敌人，场景不产生新的状态变化。
