# Cross-Window Findings

1. **世界入口优先回答当前人物能不能继续生活或行动，而非优先解释世界史。**
   W01、W04、W08、W11、W14、W16 都先解决照明、住房、船舱、联络、语言、住宿等问题；世界背景只保留到足以改变该问题的程度。

2. **价格不是装饰，而是把身份、阶层与选择权转成读者可比较尺度。**
   W04、W05、W07、W08、W09、W13、W16 都让租金、会费、餐食、服务费、年薪或住宿费改变人物能选什么、别人如何接待。

3. **第一次进入封闭圈层时，入口程序比组织历史更重要。**
   W02、W03、W06、W12、W15 共同使用合同、徽章、告解、敲门、服饰、交易媒介、座位或承诺完成准入；组织本体和上层机制留在门后。

4. **神秘边界应保留“原因未知”，但不能同时隐藏当前操作后果。**
   W01、W03、W10、W15、W16、W17 均清楚给出人物现在能否点灯、进门、留宿、接受职位、执行禁忌或继续祈祷；红月、追踪者、港口缺失、城市本体、钟声动机则被延后。

5. **衣着、身体与空间会先于解释完成社会定位；他人的误读本身就是入口压力。**
   W05、W06、W12、W13、W14、W15 显示：旧衣、面纱、油彩、手杖、异常身高、座位距离、关窗与武器摆放，能直接改变谁愿意接待、谁会警戒、谁把来者误判为何种人。

# Counterexamples & Boundaries

- 极端跨阈值并不适合硬塞物价或职业细节。第七卷第一章《欢迎》106745–106804 的重点是隔绝群体穿出神弃之地，只以照明、植物、船和欢迎完成转变；它不是普通城市入口模板。
- 紧急危机不应暂停处理来补生活设定。第三部第六十章《戒严的拜亚姆》48012–48066 的街垒、飞空艇和尸体服务于危机处置，不承担“初入城市”任务。
- 角色已进入一个机构后，重复仪式不能冒充第一次进入。第四部第二十四章《大弥撒》65605–65689 是宗教生活深化，不是入口证据。
- 当前选择若依赖机制，就应解释最低必要规则。W02 的合同、W08 的海上武器规则、W17 的祈祷结果都没有故作玄虚；可藏的是来源和本体，不可藏的是人物眼下怎么做。
- `乌托邦港` 与后续列车—旅馆链属于同一异常入口。后续窗口 112042–112239 虽高信号，但为避免连续章节凑数，未纳入主证据集。

# What Existing Skill Misses

当前 Scene Skill 已有 `exploration`、`horror_anomaly`、`resource_economy`、`social_bargain_decision` 等能力，也将 `scene_entry`列为 Utility；但它们尚未明确以下判断：

1. **入口细节的功能性选材。**
   现有规则要求细节服务行动，却未要求 Writer 在“价格 / 服饰 / 服务流程 / 空间设施 / 礼仪”中只选一两个最能回答当前问题的锚点。结果容易变成泛化环境描写，或把所有设定一次搬出。

2. **社会可见性与误读。**
   `stealth_infiltration`关注隐藏身份；本组证据新增的是另一种情况：人物并未潜入，但其衣着、身高、手杖、捐献或口音自动触发社会分类，迫使其处理误读。W12、W13、W14 是独立证据。

3. **公共表层—秘密通道的双层入口。**
   现有 `social_bargain_decision` 可写谈判，但未规定“公开礼仪继续正常运行，同时以一个小凭证切换到圈内程序”的入场结构。W03、W06、W15 表明，此结构可避免负责人直接讲完组织史。

4. **普通模型先成立，再用单一外部矛盾切开神秘边界。**
   `horror_anomaly`关注正常规则失效；但本组新增的是：先让港口、旅馆、交通、宗教或市场完全可操作，再用地图缺失、未解释钟声、无法归类的视觉异常改变旧信息权重。W10、W16、W17 支持。

5. **入口停点。**
   需要一个可执行的停止判断：当读者已知“这里能提供/限制什么、人物要付何代价、他人如何响应”后，立即回到主冲突；不再追加同义背景。现有 Skill 的一般 Stop Rule 未把这三项合成 World Entry 专属条件。

# Candidate Transfer Rules

1. **生活锚点规则**

   - applicability：人物首次进入陌生城市、住所、职业或公共机构，且眼下有住宿、找路、花钱、求职、联络等现实问题。
   - rule：只选一项即时资源、一项空间条件、一项社会反应；让人物因它们作决定。
   - stop rule：读者已能回答“这里怎样维持生活、人物现在怎样行动”即停。
   - failure pattern：先讲城市历史、阶层或制度，人物却尚未用过一件东西、付过一笔钱或被任何人对待。

2. **可见身份—误读规则**

   - applicability：外来者的衣着、身体、工具、口音或礼仪会被当地人立即看见。
   - rule：先写他人作出的具体误判，再让主角选择纠正、利用、承受或改装。
   - stop rule：误读已改变接待、风险、路线或服务方式即停。
   - failure pattern：作者只宣告“很显眼 / 很高贵 / 很可疑”，没有任何角色因此改变行为。

3. **双层制度入口规则**

   - applicability：宗教、协会、市场、组织既有公共表层，也有少数人可使用的内部程序。
   - rule：先让人物遵守公共礼仪；再以一个小凭证、固定动作或简短口令切入内部。
   - stop rule：内部接应已接手当前问题，不解释组织全史。
   - failure pattern：负责人一见面就完整讲解等级、起源、权限和全部秘密。

4. **民俗的操作边界规则**

   - applicability：地方有危险民俗、宗教禁忌或无法立刻验证的异常。
   - rule：先给普通人能执行的动作，例如关门、避时、避地、保留某物；再只展示一次与之冲突的异常。
   - stop rule：人物已知今晚该怎么做，但仍不知“为什么”时停。
   - failure pattern：禁忌只被当背景名词，或作者立即公布怪物与机制。

5. **成本塑形规则**

   - applicability：场景要建立阶层、职业可信度或资源边界。
   - rule：只给会改变选择的一笔价格或持续成本，并让其影响服务等级、住处、客户、待遇或风险承担。
   - stop rule：读者已能比较“此人拿得起什么、舍弃什么”。
   - failure pattern：连续报物价而没有购买、拒绝、接待变化或机会成本。

6. **城市四问规则**

   - applicability：第一次抵达将持续影响后续行动的城市。
   - rule：按当前剧情只回答其中必要项：靠什么活、怎样找人、谁能公开出现、出了事依赖哪条非正式路径。
   - stop rule：这四问中足以决定主角下一步的部分已经清楚。
   - failure pattern：行政区划和历史很多，但读者不知道主角今晚去哪、能联系谁、应避开谁。

7. **异常后置规则**

   - applicability：地点或机构真实本体需要保留为后续谜题。
   - rule：先让交通、住宿、工作、仪式或交易在局部可验证；再以一个外部矛盾重新标记异常。
   - stop rule：矛盾已迫使读者重估此前普通信息，不揭示原因。
   - failure pattern：一开始就声明“这里不对劲”，却没有任何正常模型可被推翻。
