- 展开节拍：逃方在被发现时以一次伤害换取追方短暂停顿；判断追方会被身后强者牵制，获得短暂恢复窗；随后沿途补充力量，并主动选择有古神气息、能治疗自身伤势的月族区域；追方摆脱三人后追入；逃方到达资源地即转身迎战。
- 被压缩部分：多次跨星移动、沿途穿越与补充力量的普通路程。
- 状态交换：追方的外部压力给逃方创造安全窗；终点由“远离追兵”变为“能改变战力差的战场”。
- 追兵反应：先被第三方围杀拖住，后以高代价击散围杀者，继续追入。
- 身体/空间细节：星空裂缝、远距移动、伤口、古神雕像与古神气息。
- 读者标尺：追方是否仍被三名强者牵制、伤势是否恢复、资源地是否抵达。
- 停点：逃方明确“不再逃”，combat 接管。

**Interpretation**

- 安全窗可由追兵的外部任务或敌对关系产生；它必须改变下一步可做之事，而非只提供喘息描写。
- 反推限制：不能把所有第三方都视作掩护；此处逃方确认了其牵制能力，并选择了能反转自身伤势的地点。

## XIANNI-CHASE-12

**Evidence**

- 章节/定位：第一千三百二十六章《追杀》—第一千三百二十七章《骗局……》；行 `81081–81151`
- 锚点：`还有两次`
- 姿态/类型：重伤者逃亡 → 有限次数安全窗 → 追方封路与最终截获。
- 场景目标：逃方完成剩余数次挪移抵达安全处；追方阻断其融入天地的路线并捕获。
- 进入状态：双方先前角色已翻转；逃方重伤，以“再有三次”“还有两次”“最后一次”计算安全。
- 展开节拍：追方沿逃方留下的波纹追踪并以雷霆打断挪移；逃方以香火与鲜血冲击脱身，坠向星球并呼唤数千修士阻拦；追方无视阻拦、以裂缝逼出隐遁；逃方再次以传承力量进入近乎透明状态；追方在最后一步用定身打断其脱离，并立即处理其自毁反应。
- 被压缩部分：不足半柱香内的多次交错，不按每次移动重复叙写。
- 状态交换：剩余挪移次数是可读的安全窗；地方势力只能延缓，不能天然隔断追踪；透明化提供一次误判窗口，但被定身直接改写。
- 追兵反应：从追踪波纹，到封锁挪移，再到无视地方阻拦、针对最后逃法布置克制。
- 身体/空间细节：波纹、雷霆漩涡、伤臂、血液冲击、星球援军、裂缝、透明化。
- 读者标尺：剩余挪移次数、双方交错间隔缩短、援军数量但无法阻拦、逃法是否被打断。
- 停点：目标被实体化抓出，追逃结束，转入处置结果。

**Interpretation**

- “还有几步到安全”应当同时给出追方能否封路的手段；否则倒计时只是口头保证。
- 反推限制：地方援军在此只是延迟层；若追方能直接绕过或穿透，不应把“进入己方区域”写成绝对脱险。

# Cross-Window Findings

1. 追逃的最小可读单位不是“又跑了一段”，而是一次相对态势变更：距离、感知、载体、出口、资源或目标价值中至少一项发生变化。无变化的长途移动应压缩。
   证据：`01`、`04`、`07`、`08`、`09`、`12`。

2. 有效安全窗必须同时写明来源与失效方式：遮蔽耐受、入口时限、神识可用范围、追方被牵制、剩余挪移次数均可成立；单纯“暂时安全”不足以承压。
   证据：`02`、`04`、`07`、`09`、`11`、`12`。

3. 追兵信息不是静态全知。信号可能被迷雾压缩、被遮蔽、被切断、被残余波纹维持，也可能被目标物的识别误导。
   证据：`01`、`02`、`08`、`09`、`12`。

4. 路线选择只有改变“可达性”才值得展开：进入危险森林、选择有队伍的方向、抢占空间门槛、进入可恢复或可反击的资源地，都会把路线转成行动选择。
   证据：`01`、`03`、`04`、`11`。

5. 追逃应在核心问题稳定改变时交接：追方已被困、速度差不可逆、入口完成隔绝、双方已进入可正面处理的距离，才转向 `combat`、`stealth_infiltration` 或 `survival_endurance`。
   证据：`01`、`03`、`06`、`09`、`10`、`11`。

# Counterexamples & Boundaries

- 遮蔽不等于脱险：雕像有半时辰承受上限，且激活本身会暴露位置。`XIANNI-CHASE-02`
- 第三方队伍不等于安全区：它只把个人追逃转为群体战斗，逃方仍被审查并需保留撤离预案。`XIANNI-CHASE-03`
- 追兵故意控速不是常态：其前提是目标物可毁且价值高。`XIANNI-CHASE-05`
- 追方短暂停止也不等于结束：若仍有资源优势、出口可控或能重新定位，追逃可反转。`XIANNI-CHASE-07`
- 一次性爆发速度不能解决持续加速的追兵；短爆发若不改变路线或终局速度，只会提前耗尽资源。`XIANNI-CHASE-09`
- “进入己方区域”只能提供阻隔层；追方能绕过阻隔时，仍必须展示真正的封路或截获手段。`XIANNI-CHASE-12`

# What Existing Skill Misses

当前 `chase_escape` 已明确“距离、路线、优势变化”和无效移动压缩；新增的不是同义重复，而是以下判断能力：

1. **把安全窗建模为可失效的合同。**
   现有 Skill 说“短暂藏身”；原著证据显示还需明确安全窗来自何处、可持续多久、由什么触发崩溃。`02`、`04`、`09`、`12`

2. **把追踪视为可操作的信息链。**
   应区分：直接视野、残余波纹、神识扫描、可切断信号、局部感知壳。追方与逃方对这条链的操作，能直接决定下一拍。`01`、`08`、`09`、`12`

3. **区分“伤害追兵”与“改变追兵路线/动作”。**
   只有令其停顿、误认目标、改走入口、转向第三方或受外部敌人牵制的动作，才是追逃中的有效状态交换。`04`、`08`、`11`

4. **增加“安全目的地是否真的可承接追逃”的判断。**
   队伍、势力范围、入口、资源地都不是标签；需验证它们能否改变追兵的可达性、速度或目标优先级。`03`、`04`、`11`、`12`

5. **把 Skill 交接写成判定，不只是建议。**
   当相对态势不再能由移动改变，应立刻转场；不是继续制造“更近了”的叙述。`06`、`09`、`10`、`11`

# Candidate Transfer Rules

1. **安全窗规则**

   - Applicability：角色暂时脱离视线、进入掩体、获得第三方牵制或抵达入口前。
   - Rule：用“来源 + 标尺 + 失效机制”建立安全窗；例如承受时长、可用次数、追踪信号剩余量或门槛关闭条件。
   - Stop rule：安全窗一旦被用来完成一个明确动作，立刻切到该动作的主场景。
   - Failure pattern：只说“暂时安全”，却不给追兵如何重新追上的路径。

2. **信息链规则**

   - Applicability：追兵依赖感知、痕迹、通讯、法术波纹或目击追踪。
   - Rule：每次关键移动后说明信息链是变强、变弱、被误导、被切断还是被重新接上。
   - Stop rule：若信息链已经稳定断绝且追兵无新追法，结束追逃。
   - Failure pattern：追兵无代价永久锁定，或逃方无动作突然消失。

3. **路线价值规则**

   - Applicability：人物需要改向森林、城市、队伍、门槛、险地或资源点。
   - Rule：只展开会改变可达性、感知、速度差、追兵目标或后续战场优势的路线选择。
   - Stop rule：路段不再改变上述任一项时，用一句时间/位移压缩。
   - Failure pattern：把每道障碍都写成逐次跨越，却不改变相对态势。

4. **阻碍规则**

   - Applicability：逃方准备用资源、诱饵、法术或第三方争取时间。
   - Rule：阻碍必须迫使追兵出现可观察反应：停顿、绕路、换目标、被入口筛掉、被外部敌人牵制。
   - Stop rule：阻碍只造成伤害、但不改变追击行为时，不继续把它当追逃节拍。
   - Failure pattern：连续丢技能，追兵速度和路线完全不变。

5. **交接规则**

   - Applicability：封路完成、双方贴近、追方失去路径、逃方到达可反击资源地，或速度差已不可逆。
   - Rule：明确写出“移动已不能解决什么”，然后切至 `combat`、`stealth_infiltration`、`survival_endurance` 或其他主场景。
   - Stop rule：新场景已有独立阅读问题后，不回头补写跑动。
   - Failure pattern：战斗已经开始却仍用追逐语言维持假紧张，或真正脱离后仍反复回望追兵。
