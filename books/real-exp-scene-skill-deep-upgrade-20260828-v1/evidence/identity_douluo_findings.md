# Cross-Window Findings

1. **揭露必须迫使至少一方失去旧行动资格。**
   泰坦不能再按赌约收编唐三（E03）；萨拉斯不能立即强审（E04）；比比东将抓捕对象扩展为保护者的敌对阵线（E05）；雪清河失去“太子谈判”的中间位置（E09）；海神岛权威失去受礼资格（E10）。
   **判断**：Secret 的戏剧重量来自行动空间被改写，而非信息稀有。

2. **知识分层应先于统一反应：先知、识破者、刚得知者和仍误判者不能写成同一种震惊。**
   唐昊已知血缘含义、唐三未知（E01）；大师是推断者、唐三是被识破者（E02）；泰坦识别旧主从、宁风致做政治重估、学员只看见反转（E03）；唐三早知而七怪刚知（E05）；海马斗罗不知、波赛西才可确认（E10）。
   **判断**：Reveal 前应明确知识席位，否则群像反应会坍成“全场震惊”。

3. **最有效的证明物不是说明书，而是迫使识别者改动作的可见证据。**
   锤使泰坦下跪（E03）；令牌使萨拉斯让步（E04）；花坠落引爆抓捕（E05）；红色魂环改变招募估值（E08）；三叉戟烙印改写海神岛礼法（E10）。
   **判断**：优先选择能被关键人即时辨认、且会改变其利益或程序的物、身体痕迹、权限凭证。

4. **关系兑现与任务转向可以同场发生，但任务必须从新关系里长出来。**
   大师识破后成为师父（E02）；唐昊确认儿子后给出保护方向（E01）；唐三护住小舞后进入逃亡（E05）；阿银真相让父子共同启动恢复与复兴（E12）；唐晨认亲后交付有限权限（E11）。
   **判断**：先让关系边界落地，再从它导出行动；不要用外部新危机抢走刚完成的关系选择。

5. **“认可”不等于“问题已解”。**
   昊天宗同辈的亲近不代表长老团认可（E07）；唐晨认可唐三却不能同行（E11）；教皇令只能延后审问，不能消除敌意（E04）。
   **判断**：Reveal 的停点宜落在新权利/新边界成立处，同时保留一个现实限制进入下一场。

# Counterexamples & Boundaries

- **延迟揭露有时是正确选择。**
  小舞在星斗大森林归队后以受袭与自获魂环解释自身异常（约第112章《人面魔蛛》，5166–5178）。本窗不能据此将其身份视作对同伴已公开；当泄露会先引来猎杀、而保护方尚无承受能力时，保留表层解释可维持当下队伍行动。

- **单纯补全旧事，不自动构成 Identity Reveal。**
  雪清河讲述唐昊退隐背景（第320—322章，13307–13419）主要让唐三重组父辈事件；本窗没有由该信息直接发生的关系重站队。应优先归为 `deduction_reveal`，除非后续场景把该新解释转为具体保护、交易或敌对选择。

- **强度展示不等于秘密揭露。**
  唐三一挑三后与四元素学院谈判（第532—533章，25844–26069）确实重置了对方的谈判估价，但文本核心是实力展示与场地合作争议，不是隐藏身份被拆穿。适合 `showcase_evaluation + social_bargain_decision`，不应硬套 `identity_reveal`。

- **公开规模须匹配风险。**
  E01、E02 只允许一个可信亲属或导师进入秘密；E05、E10 则在无法退场的公共仪式中公开。不要为了热闹把本应私密、尚无防护能力的秘密提前摊给全场。

# What Existing Skill Misses

现有 `identity_reveal.md` 已明确“不同知识层级”“揭露后要有实际选择”“旁人反应不能整齐划一”，这些原则在本组原著证据中得到支持。真正可新增的判断能力是：

1. **知识席位图，而不只是“有人早知、有人刚知”。**
   应在场景前标出：谁持有秘密、谁有物证识别权、谁只是受影响者、谁仍会按旧身份行动。E03、E05、E10表明，这决定了反应顺序与戏的结构。

2. **识别证据必须改变对方的权限或成本。**
   “至少一人做过去不会做的选择”仍偏宽。E03、E04、E08、E10显示，更精确的问题是：揭露后，谁失去原先可做的事，谁被迫承担新义务，谁获得可立即调用的权限。

3. **区分“身份获准进入”与“关系真正被接纳”。**
   E07证明同一身份可先通过门槛、后在共同风险中重建同辈关系；不应把血缘、组织资格或称谓自动等同为信任。

4. **区分公开的目的：求保护、招募、锁定敌我、还是交接责任。**
   E04是保护窗口，E08是招募估值，E09是锁死立场，E12是责任交接。它们不能只靠同一套“揭露—震惊—表态”节拍实现。

5. **以“有限兑现”结尾。**
   E04、E11显示，身份揭露后给出部分保护或权限，同时保留未解决限制，能防止 Reveal 变成万能通行证。

# Candidate Transfer Rules

1. **规则：先画知识席位，再写揭露。**
   - Applicability：同场有三名以上利益相关者，或秘密会改变阵营/程序。
   - Stop rule：关键角色的旧判断已被一项可见证据推翻，并出现不同方向的实际反应。
   - Failure pattern：所有人同一时间、同一种惊讶；作者只能靠解释台词区分立场。

2. **规则：让关键识别者先改动作，再命名真相。**
   - Applicability：身份、权限、血统、能力可被专业者或旧关系者识别。
   - Stop rule：其动作已改变主角的安全、归属、交易或敌我状态。
   - Failure pattern：角色先长篇自报身份，听众在结尾才补一个“原来如此”。

3. **规则：秘密揭露必须落到一个被撤销或被迫承担的行动权。**
   - Applicability：秘密会影响组织、制度、追捕、招揽、家族或上下级关系。
   - Stop rule：明确“谁现在不能再做什么”或“谁现在必须做什么”。
   - Failure pattern：真相公布后，人物关系、站位、计划全都照旧，只增加设定知识。

4. **规则：将公开范围匹配保护能力。**
   - Applicability：秘密一旦扩散会引来猎杀、清算或高成本利用。
   - Stop rule：若保护方尚不能承担后果，秘密只交给能够改变当下生存条件的最少角色。
   - Failure pattern：为制造高潮让主角在无防护场合主动公开，之后只能靠偶然救场。

5. **规则：把“承认”与“彻底解决”拆开。**
   - Applicability：家族归属、旧主从、师徒、组织继承、长期敌对等大关系。
   - Stop rule：新称谓、权限或共同任务已成立，但仍保留一个真实限制进入下一场。
   - Failure pattern：身份一说开，旧怨、组织阻力、资源缺口同时消失。
