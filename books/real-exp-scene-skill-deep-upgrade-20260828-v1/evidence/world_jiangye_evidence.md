## E01｜长安城门：城市先以管制和夜生活落地

- **章节 / 定位：** 第一卷第二十七章《我与长安相见欢》；源文件 1316–1363；anchor：`无处不热闹`。
- **scene posture/type：** 外来者首次入城。
- **scene goal / pre-state：** 主仆要入城投宿、准备求学；此前习惯边城夜晚的寂静与匮乏。
- **Evidence：** 展开的是排队、军士翻检包裹、刀弓管制、居民抱怨但守法、夜市灯火、衣着、杂耍、异国客人与摊贩化妆品。城市尺度不是报人口，而是十八个城洞仍堵塞、城墙遮天、夜间持续拥挤。决斗制度通过围观者自动噤声与割袖规则被说明。
- **expanded beats：** 过关检查；物件是否合法；夜街的身体、衣物、消费品；围观决斗的规则。
- **compressed/omitted beats：** 不展开城池沿革、行政层级或街区总览。
- **state-changing exchange：** 军士放行；主角向侍女解释武器与决斗的边界，随即决定不围观、先找客栈。
- **opponent/other reaction：** 军士由审查转为调侃；本地人把制度当日常；围观者共同维护决斗秩序。
- **body/space/detail selection：** 肩上包裹、下弦弓、紧袖衣、裸臂、灯火、拥堵城洞；细节都与携带、行动或消费相关。
- **ruler/reader model：** “大城”=资源和权势集中，但可由城门、兵器规则、夜间活动与民众举止被操作性地理解。
- **stop point：** 主角拒绝看热闹，转为投宿，停止继续游览。
- **Interpretation / transfer observation：** 城市入口可先给一条可执行边界，再用夜生活展示它不是纯军事设施。
- **anti-inference：** 不能据此推出“城市入场必写夜市或决斗”；本窗的高密度来自主角的边塞参照与携械处境。

## E02｜书院前院：朴素表层与异常反应并置

- **章节 / 定位：** 第一卷第七十九章《第一堂课》；3543–3577；anchor：`世上本无特殊`。
- **scene posture/type：** 首次作为学生进入书院。
- **scene goal / pre-state：** 上课、确认今后生活位置；主角已知书院名望，却只看见普通校门与书屋。
- **Evidence：** 展开校服、合乘马车、晨钟、住校选择、同学互报家门、石门与书舍；在“看似寻常”的疑问后，场景立刻切入安静巷道中的陌生书生、书卷、木瓢与不合常理的信任压迫。
- **expanded beats：** 日常入学仪式；院门的朴素；主角的怀疑；异常人物提出交换。
- **compressed/omitted beats：** 书院历史只以主角已知名望带过，没有长篇院史。
- **state-changing exchange：** 对方试图以木瓢换黑伞，主角拒绝；牛车离去，主角改向书舍。
- **opponent/other reaction：** 同学热情接纳；陌生书生不施压争夺，只以离去留下不安。
- **body/space/detail selection：** 黑罗头巾、青色学服、三根石柱般的门、未被晨光照到的巷道、满灰却“干净”的棉袍草鞋。
- **ruler/reader model：** 书院的重要性不靠金碧辉煌，而靠“普通表面无法解释的安全感、人物分量和规则豁免”。
- **stop point：** 牛车离开后即切回学生生活，不继续解释书生身份。
- **Interpretation / transfer observation：** 高层机构入口可以先允许读者看见其日常运转，再让一个低物质、强反常的细节打破表层理解。
- **anti-inference：** 不可抽象成“每个学院都要有神秘导师”；此窗的反常来自既有角色与物件的相遇。

## E03｜书院二层楼：上层圈层以仪态与资格差建立

- **章节 / 定位：** 第二卷第一百五十六至一百五十七章《山顶的青树，压烂的糕点，一切都是幻觉……》《绝顶风光》；8291–8402；anchor：`一块糕点`。
- **scene posture/type：** 候选者抵达隐秘上层的门槛。
- **scene goal / pre-state：** 通过山道试炼、取得二层楼资格；主角狼狈、耗尽体力，竞争者从容等待。
- **Evidence：** 山顶先以云雾、树、岩石和高冠者确认空间高度；继而用竹片退出机制、十余步石阶的不可逆伤害提示制度边界。上层成员不是逐一介绍背景，而以琴、棋、箫、绣框、铁锤和对“帽子”的玩笑显露日常姿态。
- **expanded beats：** 两位考生的体面差异；资格条件；二层楼成员的职业性物件与互相调侃。
- **compressed/omitted beats：** 不系统讲解成员履历、武学谱系。
- **state-changing exchange：** 二师兄给出等待或先行的选择；竞争者等待；主角抵达后，两人获得并肩竞争的位置。
- **opponent/other reaction：** 竞争者从轻视转为承认并肩资格；山顶成员由旁观转为认真讨论主角能到此的原因。
- **body/space/detail selection：** 破衣、糕点、青竹片、石阶、古冠、工作工具；“谁能携带什么”成为阶层的可见尺度。
- **ruler/reader model：** 上层圈层重要，不是因为被称赞，而是普通人的终点在此才成为“入门”；其中人的玩笑也有能力与秩序托底。
- **stop point：** 最后一关变成明确选择题后，空间导览停止，转入试炼。
- **Interpretation / transfer observation：** 展示上层时，可让主角的生活物件与上层人的日常工具同框，先让读者感觉资格差，再解释规则。
- **anti-inference：** 此处的戏核仍是试炼竞争，不可把所有“高层场景”改成群像亮相。

## E04｜荒原粮队：风景只保留会改变行军的部分

- **章节 / 定位：** 第二卷第十章《山后，栅栏后》；13335–13350；anchor：`走进寒冷荒原`。
- **scene posture/type：** 队伍首次越过边塞，进入高风险荒原。
- **scene goal / pre-state：** 护送粮草到王庭；南方修行者和民夫对荒原陌生，主角熟悉边塞生存。
- **Evidence：** 先给队伍构成、粮车与最高指挥权，再给路线、木柴、水源、起营时间、宿营时间；草、雪、鹰鸣和寒气只在主角依据它们判断行军时被展开。
- **expanded beats：** 后勤领取；队伍比例；向导被替换；路线与扎营决策；对速度的争议。
- **compressed/omitted beats：** 数日无事的行程直接压缩，不以连续地貌充填篇幅。
- **state-changing exchange：** 主角接管路线和宿营安排；燕骑首领质疑，但队伍执行其方案。
- **opponent/other reaction：** 南方少女视之为新鲜旅行；燕骑担忧时限；主角将其当熟练劳动。
- **body/space/detail selection：** 粮车、马匹啃草、兽粪、木柴、黄羊、肺中冷痛。
- **ruler/reader model：** 荒原不等于“荒凉背景”；可行动地图由水、柴、时辰、粮草与谁有指挥权组成。
- **stop point：** 当主角发现烟尘、令营地安静，场景转入具体危险。
- **Interpretation / transfer observation：** 进入野外空间时，优先展开“为什么今天走这条路、为何此刻停下”，其余移动压缩。
- **anti-inference：** 不能推成所有荒野必须写求生技术；本窗的技术密度由护粮任务决定。

## E05｜桃山幽阁：上层制度通过“不相称的门”落地

- **章节 / 定位：** 第二卷第十章《山后，栅栏后》；13363–13379；anchor：`木栅栏`。
- **scene posture/type：** 执事进入神殿的隐秘惩戒层。
- **scene goal / pre-state：** 传达与确认被囚大神官状态；读者已知神殿庄严，却未知其内部的关押结构。
- **Evidence：** 桃山正面先以桃花与道殿显示权威，后侧随即转为绝壁、雾、血腥通道与符文铁墙；最后用“看似可随意穿过”的木栅栏，反衬其十四年不可逃的真实约束。
- **expanded beats：** 地形转换；到达者身体被压低；通道感官；栅栏与跪拜。
- **compressed/omitted beats：** 不完整讲述监狱制度与历史案件。
- **state-changing exchange：** 执事向栏后人跪拜，提出裁决者的问询；囚徒转身回应。
- **opponent/other reaction：** 身居要职的进入者仍以额触地；被囚者的平静反而抬高其分量。
- **body/space/detail selection：** 弯腰、湿雾、血腥、豆灯、铁墙、宽木条。
- **ruler/reader model：** 制度威力可由“实体极弱、社会与修为边界极强”的反差建立。
- **stop point：** 栅栏后的身份与气质已成立，即转入对话和事件信息。
- **Interpretation / transfer observation：** 上层机构的恐怖感不必靠加码华丽建筑；一个与后果不相称的普通物件，若有可验证后果，更有效。
- **anti-inference：** 不应泛化为“牢狱要写残酷感官”；此处感官服务于神殿正反两面的制度反差。

## E06｜强者入长安：同一城市换观察者就换尺度

- **章节 / 定位：** 第二卷第十二章《长安乱》；13541–13566；anchor：`好大一座阵`。
- **scene posture/type：** 顶级外来者进入熟悉城市。
- **scene goal / pre-state：** 潜入长安、寻找目标；来者必须隐藏真实身份。
- **Evidence：** 他先在朱雀大道前停步，感知城市防御后绕路；随后住普通客栈、逛坊市、吃面片汤、买棉袄，再因一碗汤与小侍女相遇，顺势追踪到目标铺面。
- **expanded beats：** 进入时的禁区感知；伪装后的普通消费；小善意触发追踪。
- **compressed/omitted beats：** 不重述长安街景，默认读者已经见过。
- **state-changing exchange：** 小侍女替他擦污渍、重买食物；他把自己的食物转给乞者，继而跟随她。
- **opponent/other reaction：** 市民完全把他当普通老人；城市防御以无声反应拒绝强者正面进入。
- **body/space/detail selection：** 佝偻、棉袄、面汤污渍、石板路、朱雀图像、巷中店铺。
- **ruler/reader model：** 同一城市可用不同角色的“可进入 / 不可进入”重新定价；强者看到的是阵与遮蔽，普通人看到的是吃穿与行路。
- **stop point：** 跟到目标铺面、确认观察对象后结束漫游。
- **Interpretation / transfer observation：** 重返已建立空间时，不重做导览；换一个有不同权限与风险的人，让旧细节承担新含义。
- **anti-inference：** 不是每次重返都要换 POV；只有权限差真的改变读者理解时才值得这样做。

## E07｜瓦山小镇：宗教重地先作为可花两文钱的节日生活出现

- **章节 / 定位：** 第四卷第五十四章《瓦山小镇》；38878–38914；anchor：`瓦山到了`。
- **scene posture/type：** 病中来客抵达宗教胜地外围。
- **scene goal / pre-state：** 为同伴求医，主角戒备且需要找到高阶僧人。
- **Evidence：** 先用瓦形山峰提示地标，再短交代寺院的宗教位置；真正展开的是节日前的旗幡、老屋、游客、孩子追人、两枚铜板、捞鱼网和兄妹的即时快乐。主角停在镇外，不打断其日常。
- **expanded beats：** 节日物件；儿童消费与游戏；镇与后山的声场反差。
- **compressed/omitted beats：** 佛宗历史只保留能解释“为什么这座寺值得来”的最小量。
- **state-changing exchange：** 哥哥给妹妹铜板，游戏重启；主角决定不进镇，改上后山找人。
- **opponent/other reaction：** 居民只把宗教盛会当生活节日；主角由观察转向行动。
- **body/space/detail selection：** 黑白旗幡、石池、网兜、铜板、水花、黑马车停在镇外。
- **ruler/reader model：** “圣地重要”先让普通人照常花钱、游玩、带孩子，才不会变成空洞的历史名词。
- **stop point：** 马车转上“无法抵达正殿”的山道，目标从逛镇转为求见。
- **Interpretation / transfer observation：** 宗教、皇都或名胜的入口，可用低金额、低地位、可立即完成的生活行为验证它已被居民真实占用。
- **anti-inference：** 不可由此推出重大地点都应先写儿童；本窗的儿童行为服务于病中主角对“寻常生活”的短暂停留。

## E08｜烂柯寺前殿：景观一旦完成情绪工作，立刻引出圈层摩擦

- **章节 / 定位：** 第四卷第五十七至五十八章《不识真佛在眼前》《殿前私语》；39071–39119；anchor：`佛国变回人间`。
- **scene posture/type：** 进入高规格宗教场所与来宾圈层。
- **scene goal / pre-state：** 主角陪病者游寺，同时等待治疗机会；他并不想卷入礼仪冲突。
- **Evidence：** 雨雾散开、巨佛显露、正殿出现人车声；巨像提供信仰尺度，来客马车和口气则立刻把空间改为“各国使团与修行者会相遇”的社交场。
- **expanded beats：** 巨佛材质、距离与仰视感；病者的手冷；华贵马车、随从、说话姿态。
- **compressed/omitted beats：** 不继续导览佛殿，不罗列来宾身份。
- **state-changing exchange：** 南晋来客训诫主角不敬佛；主角回击，车中强者出面道歉，双方暂时收手。
- **opponent/other reaction：** 年轻贵族恼怒；更高阶剑修先判断局面、降低冲突。
- **body/space/detail selection：** 雨、伞、巨佛面上的水痕、华车窗帘、握剑的手茧。
- **ruler/reader model：** 上层圈层的规则不是“人人尊贵”，而是不同身份的人对失礼的承受度和止损方式不同。
- **stop point：** 双方分离；主角的注意力回到病者与求医。
- **Interpretation / transfer observation：** 新场所的庄严感完成后，应让它立即压到人物目标上——例如引来礼法摩擦、检查或资格判断。
- **anti-inference：** 不能把“上层反应”写成统一傲慢；本窗中真正有效的是强者的克制与下位者的冒进并存。

## E09｜白塔寺湖心岛：地形介绍必须同时成为逃亡路线

- **章节 / 定位：** 第四卷第十二章《闯庵》；44851–44870；anchor：`湖中有小岛`。
- **scene posture/type：** 受追捕者闯入佛国核心寺院。
- **scene goal / pre-state：** 带着同伴逃避满城追捕，急需休息与临时据点。
- **Evidence：** 白塔寺的宗教地位、白塔来源、湖、窄桥、残荷、庵堂一次性交代，但每项都立刻服务于“选哪条路、哪里可藏、守卫会从哪里出现”。进入庵堂后立即遭伏击。
- **expanded beats：** 地形连接关系；追兵的来源；桥上跑动；伏击点。
- **compressed/omitted beats：** 寺史仅保留足以解释白塔和地位的部分。
- **state-changing exchange：** 主角穿桥、先手击倒伏击者，成功进入庵堂，却暴露行踪。
- **opponent/other reaction：** 僧侣由看乌鸦转为报警追赶；苦修僧利用桥头位置伏击。
- **body/space/detail selection：** 背人、窄桥、断荷、古钟、铁杖、昏暗纱窗。
- **ruler/reader model：** 空间说明要让读者能预判下一次追堵，而不是只知道“这里很美”。
- **stop point：** 进入庵堂、攻击发起后，入口说明彻底停止。
- **Interpretation / transfer observation：** 在逃亡、潜入、追捕中，地形信息的单位应是“可利用或可被利用的一步”。
- **anti-inference：** 不适用于纯休憩、关系或庆典场景；那里不必把每个景物都变成战术节点。

## E10｜桃山绝壁：顶层空间的边界以失败一次才可信

- **章节 / 定位：** 第五卷第二十三至二十四章《花前月下（下）》《去念》；63603–63658；anchor：`他现在就是普通人`。
- **scene posture/type：** 潜入神国核心的高风险进入。
- **scene goal / pre-state：** 潜入桃山、接近被囚同伴；主角有高阶能力，并误判准备充分。
- **Evidence：** 桃花不是纯景观，而是无需守卫的阵；绝壁、触目阵、云雾和崖坪构成多层边界。主角压制自身力量仍触发规则，坠落后才从旧经验找出新动作，抵达最低崖坪后立即潜入马厩等待。
- **expanded beats：** 入侵路径；规则触发；身体失控；以既有经验解决；到达后的隐蔽行动。
- **compressed/omitted beats：** 不展开桃山全图或神殿建筑清单。
- **state-changing exchange：** 无人对话；环境规则与主角身体构成实际交换：越想看、越受攻击；放弃常规控制才得以攀行。
- **opponent/other reaction：** 阵法与战马分别给出非语言反应；战马因血腥气息保持安静。
- **body/space/detail selection：** 跳崖、手指、剧痛、冷汗、云雾、马厩、稻草。
- **ruler/reader model：** 顶级禁地的分量由“已有能力仍不足以直接进入”建立；通过不是权限展示，而是付出即时身体代价。
- **stop point：** 到达崖坪、获得可执行的新任务“等人”，即不再重复绝壁险峻。
- **Interpretation / transfer observation：** 若要让制度/阵法边界可信，至少让人物原有的有效手段明确失败一次，并让突破方式留下新的限制或代价。
- **anti-inference：** 不应机械要求每个新地点都先失败；此窗的失败是为了校准顶层防线，而非拖延进度。

## E11｜战时长安：城市状态变化先通过生活系统改写

- **章节 / 定位：** 第四卷第一百零六章《大驾，光临》；51906–51919；anchor：`变成一座孤城`。
- **scene posture/type：** 已建立城市进入战争状态。
- **scene goal / pre-state：** 长安从混乱中暂时稳定，但外部战争升级；读者已熟悉它作为开放都会的常态。
- **Evidence：** 羽林军盯街、衙役奔走、帮派搜巷、城门落锁、粮车例外通行，几笔就把此前开放城市改成孤城；随后残破巨辇出现。
- **expanded beats：** 维持秩序的不同机构；进出城规则；损坏的礼仪载具。
- **compressed/omitted beats：** 不回顾整场战争，也不逐条说明戒严法律。
- **state-changing exchange：** 皇命落城门；粮队成为唯一例外；外来掌教到场。
- **opponent/other reaction：** 官军、衙役、帮派各自执行职责；巨辇残破而仍保持仪式性。
- **body/space/detail selection：** 马蹄、窄巷、落城门、血迹、残幔、断臂。
- **ruler/reader model：** 城市“为什么重要”在危机时可由物流、出入权和维护秩序的人被谁调动来回答。
- **stop point：** 敌方最高人物出现，城市状态说明让位给其入侵动作。
- **Interpretation / transfer observation：** 旧空间升级时，优先改写它的日常系统，而非再次提高景观描写音量。
- **anti-inference：** 不代表战时城市必须写帮派；关键是选择读者此前认识、现在确实发生变化的公共系统。

## E12｜掌教入后山：进入敌方核心后，空间立刻改变战术问题

- **章节 / 定位：** 第四卷第一百零六章《大驾，光临》；51922–51961；anchor：`终于来到后山`。
- **scene posture/type：** 敌对顶级人物强行进入书院核心。
- **scene goal / pre-state：** 掌教要夺取阵眼；书院前院空虚，后山仍是未知核心。
- **Evidence：** 巨辇碾碎石坊、通过窄巷湿地旧书楼、强破云阵；穿雾后才给崖坪与温暖山风。景观不被单独欣赏，立刻变成“这里是否真空、谁能拦、阵眼在哪里”的战术判断。
- **expanded beats：** 破界动作；前院教习反应；云阵被突破；后山首批守者现身。
- **compressed/omitted beats：** 不全面介绍后山成员和地理。
- **state-changing exchange：** 掌教连续点名、无人应答，遂判断书院空虚并继续深入。
- **opponent/other reaction：** 前院教习惊恐；后山成员不以迎宾礼应对，而以棋局、动物与环境共同反制。
- **body/space/detail selection：** 吃力抬辇的残余神卫、碎石坊、湿地鱼群、云雾、棋子、松与水车。
- **ruler/reader model：** 敌人视角进入核心空间时，读者通过其错误或不完整判断，感到空间仍有未揭露的防御能力。
- **stop point：** 后山已被转换为可对抗的棋局，转入战斗。
- **Interpretation / transfer observation：** 新空间的“重要性”可由侵入者愿意付出什么来取得，而不是由旁白宣称；一旦核心行动问题形成，即停止介绍。
- **anti-inference：** 不能把任何风景都拟成战场；此处环境战术化来自真实的攻防场景。

# Cross-Window Findings

1. 新空间先给“人物能否进入、如何进入、带什么进入”的边界，再给审美与历史。城门检查、荒原粮队路线、白塔寺窄桥、桃山触目阵都先决定行动空间，景物随之有意义。`[E01, E04, E09, E10]`

2. 生活质感不是背景填料，而是机构权力的日常出口：武器规定、学服与课程、两枚铜板、客栈与面汤、粮草与城门例外，都让宏大空间可被角色实际使用或受限。`[E01, E02, E06, E07, E11]`

3. 尺度锚点多采用“旧经验失效”而非纯数字：边城人见长安、普通学生见二层楼、强者遇长安阵、潜入者遇桃山阵，读者随人物已有尺度被重估。`[E01, E03, E06, E10]`

4. 介绍一旦回答了“这里是什么、我现在为何在乎”，文本立即把镜头交给一个动作：投宿、上课、选择试炼、扎营、上山求医、脱身、潜伏或开战。`[E01, E02, E04, E07, E09, E12]`

5. 上层圈层不以统一的傲慢表征。真正有分量的人可能克制、平静、先止损；高位机构的压迫也可通过普通门、普通食物、普通衣物的反差显现。`[E05, E06, E08]`

# Counterexamples & Boundaries

- **不是所有进入都展开生活纹理。** 桃山绝壁与白塔寺逃亡把生活面压到最低，因为当前读者问题是“能否活着越过边界”。`[E09, E10]`
- **不是所有空间都要由制度讲解。** 二层楼和书院前院先让人物服饰、器物、姿态与异常互动产生判断，再按需要给出规则。`[E02, E03]`
- **不是所有宏大地点都应立刻转冲突。** 瓦山小镇允许兄妹捞鱼停留，因为它同时反衬求医者的紧迫和后山的安静；但到达上山路径即停止。`[E07]`
- **不是所有重返都要重新导览。** 强者进入长安时，文本复用面汤、客栈、巷道等旧日常，只改变其可见的防线与追踪价值。`[E06]`
- **同章相邻的 E11 / E12 仅作边界反例保留。** 前者是城市系统转态，后者是敌方进入学院核心；若二者没有不同的读者问题，应合并而非拆成两张卡。

# What Existing Skill Misses

当前 `novel-scene-skills` 的 `scene_entry` 仅规定“自然带入人物、地点、强者或新空间”；`exploration` 已覆盖未知区域到行动地图的转化，但缺少以下独立判断：

1. 区分“空间导览”与“世界已被人过日子”的证据：该选何种消费、衣物、劳动、物流或身体负担，才能证明空间真实运转。
2. 为城市、学院、宗教地与上层圈层建立“入口边界优先”的选择：先写检查、资格、路线、可见禁区，还是先写人情与消费，取决于人物此刻的进入成本。
3. 重返同一地点时，根据观察者权限替换尺度锚点，而非重复旧景物。
4. 用一个不相称的小物件建立大制度：宽木栅栏、两枚铜板、下弦弓、破糕点、面汤，而非只靠“庄严/强大”的形容。
5. 对“回答为什么重要后立刻回动作”的停笔判断更具体：空间已改变人物可做之事、谁能拦他、或谁会重新估值他，即该切换主场景。

# Candidate Transfer Rules

1. **入口先给一条可执行边界。**
   - Applicability：人物第一次进入城市、学院、营地、宗教地、上层居所，且进入方式会影响后续选择。
   - Rule：先给一个会影响携带、路线、资格、时限或可见范围的边界，再选 2–4 个与该边界有关的生活细节。
   - Stop rule：人物已经通过、被拒、改道或明确下一步目的后，停止导览。
   - Failure pattern：先连写地名、建筑史和风景，人物却还没有能做什么。

2. **生活物必须承担“使用、价格或负担”之一。**
   - Applicability：需要让宏大世界显得可居住。
   - Rule：优先选择人物要携带、购买、维护、穿戴、排队取得或受规则限制的物件。
   - Stop rule：物件已改变人物行动、关系或对空间的判断，就不继续列同类物品。
   - Failure pattern：把摊位、服饰、食物堆成旅游画册，删掉后剧情与理解毫无变化。

3. **用观察者权限决定尺度，而非重复设定。**
   - Applicability：重返已建立城市、机构或战场。
   - Rule：换到权限、目标或风险不同的人物，只重写其能看见的新边界。
   - Stop rule：旧空间被重新估值，且人物据此行动后停止。
   - Failure pattern：每次回城都重写街景，或强行切 POV 却不改变读者能知道什么。

4. **上层圈层以仪态和小物件显露，不先报名册。**
   - Applicability：首次接触高手、隐秘组织、贵族或学院核心。
   - Rule：选择一项劳动工具、身体姿态、礼节或对风险的反应；让其与主角的困境并置。
   - Stop rule：读者已能判断谁有资格、谁在伪装、谁真正掌握局面时，转入试炼、谈判或冲突。
   - Failure pattern：角色轮流自我介绍、互相夸境界，空间仍没有任何实际限制。

5. **空间说明必须产出下一步动作。**
   - Applicability：所有 World Entry。
   - Rule：每段空间信息最后落到靠近、绕开、扎营、投宿、求见、潜入、交易、撤退或开战中的一项。
   - Stop rule：下一动作的对象、方向与风险已经明确。
   - Failure pattern：场景停在“真壮观/真神秘/真繁华”的总结，下一段重新起步。
