- 迁移观察：突破可由情绪松动触发，但必须落在一个外显动作结果上。

# Cross-Window Findings

- 长期练习的最小可读单位不是“练了很久”，而是“固定尺子下，一个差异被看见”。尺子可以是树痕、连续风刃、固定赛制、符纹层数、速度基线或介质失效；没有同一前后条件，时间压缩会退化为报年月。`CY-TR-04/06/08/14/15/18`

- ruler 必须改变人物下一步，而不只是赞美或排名：家族提高陪练密度，导师给出期限或转向，竞争规则公开兑现差距，测试物否定或确认路线。`CY-TR-03/05/08/09/15/18`

- 避免教程化的稳定手法，是只展开“新反馈—新选择—一处可见结果”，把无新信息的重复压成时长、次数与一项代表性痕迹。`CY-TR-02/04/06/07/10/17`

- 训练线应允许局部成功、主线失败：强招若损害该路线的核心指标，可保留战斗价值、停止作为根本；未完成者也可凭可见中间积累继续投入。`CY-TR-11/14/16/19`

- 导师不需要持续讲授。最有效的导师场景是设定合适的门槛、期限、资源边界或观察位置，然后把解法留给人物身体化完成。`CY-TR-05/09/18`

# Counterexamples & Boundaries

- 不要把“练得久”写成必然突破：三年未完成仍可能是合理进度；十年也可能只换来三次心灵提升。`CY-TR-11/16`
- 不要只因威力更大就判定新路正确：若它牺牲角色路线的核心承诺，必须出现同口径的负向比较。`CY-TR-14`
- 不要把导师、家族或遗迹当万能外挂：它们在有效窗口中都提供了具体条件、门槛或反馈，而非直接授予成果。`CY-TR-03/05/18/19`
- 不要把跨媒介实践普适化：画作在此能反哺技艺，是因为人物已有相关积累、观察对象与个人方法。`CY-TR-10/17`
- 不要把“换环境”当逃避：只有原方法已连续不给新反馈时，行走与观察才成为有根据的改法。`CY-TR-19`

# What Existing Skill Misses

现有 `training_learning` 已覆盖：可观察目标、具体偏差、反馈后调整、压缩无信息重复、导师说明绑定问题，以及训练完成/暴露瓶颈时停场。

真正新增的判断能力是：

- “可观察”还不够：应要求一个可复用的外部 ruler，并说明它为什么能裁决路线，例如同一装置、同一对手条件、年龄/期限、固定测试物或核心性能基线。
- 长期时间压缩不只报“若干年后”：至少保留一项中间产物或一次相同条件下的复验，让读者能看见积累改变了什么。
- 当新成果更强却偏离主路线时，应区分“可作为局部战术保留”与“不可继续作为根本投入”；现有 Skill 的“新瓶颈”尚未提供此类路线裁决。
- 家族、导师、竞争者不只是反应来源：他们分别可提供反馈密度、时间边界与公开对照；只有它们改变了人物的下一次选择，才值得占用场景篇幅。
- 对“尚未完成”的训练，应检查是否已有另一条可比的中间证据，避免把过程压扁成成功/失败二元。

# Candidate Transfer Rules

1. **固定尺子，才压缩时间**

   - Applicability：人物持续练同一核心动作，且可安排稳定条件。
   - Rule：先立一个能重复的外部尺子；跨时段仅保留“起点—一次代表性变化—当前结果”。
   - Stop rule：尺子已不能显示差异，或不再服务当前剧情目标时停止训练镜头。
   - Failure pattern：只写“苦练数月、实力大进”，读者无法判断积累为何可信。

2. **让 ruler 改变投入，而非只给评语**

   - Applicability：导师、家族、对手、考官在场。
   - Rule：ruler 必须给出期限、资源、门槛、旧战绩或淘汰条件中的至少一项，并迫使人物改变下一步。
   - Stop rule：裁决已落地为行动后，不继续复述其权威。
   - Failure pattern：强者长篇解释、旁人齐声惊叹，但人物练法和选择没有变化。

3. **用一处性能差异兑现长期练习**

   - Applicability：需要表达技艺从熟练到可靠、从强到更适配。
   - Rule：只选一个最贴近路线目标的差异：更连续、更准、更快、更能承压，或同等条件下消耗更低。
   - Stop rule：性能差异已被动作或测试明确表达，即转场。
   - Failure pattern：同时堆境界、招式、体质、旁人评价，反而没有一项可比较结果。

4. **先保留错误路线的局部价值，再决定是否止损**

   - Applicability：人物的新成果很强，却与核心目标冲突。
   - Rule：在相同核心尺子下复验；若负差异成立，可把成果限定为临时战术，不再投入根本修行。
   - Stop rule：路线判断完成后，不再反复自责或重复测试。
   - Failure pattern：见到威力就全面升级，或一次不顺就把既有成果完全作废。

5. **瓶颈后的换法，要有已耗尽的证据**

   - Applicability：长期重复已无法产生新反馈。
   - Rule：先交代旧方法的稳定停滞，再改为更适配的环境、媒介或对手；新方法必须尽快给出一个不同类型的反馈。
   - Stop rule：新反馈已经改变训练方向时，不把探索展开成完整教学。
   - Failure pattern：角色无理由换场、换老师、换功法，把新鲜感伪装成成长。
