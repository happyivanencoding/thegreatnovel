# Research Question

研究长期关系如何通过日常动作、依赖、争执、离开与回归成为人物路线变量；何时应直说，何时不应以微反应替代；关系确认后如何允许场景停留。以下是有限窗口证据，不将单一场景推广为全书规律。

## E01｜共同离开先被写成共同生活的迁移

- 章节：第一卷第五章《睹无月思怀》
- 行号：288–334
- Anchor：`晚上把行李收拾一下`
- Scene posture/type：居所迁移前的日常决策。
- Scene goal：让两人离开渭城的选择先落到“共同收拾、共同离开”的生活单位。
- Pre-state：二人长期共同生活于破屋，宁缺决定赴长安。
- Evidence：
  - 宁缺不是单独宣布前程，而是让桑桑收拾行李；桑桑对门响、油料等生活问题的回应仍在进行。
  - 临走前，空间、柜子、被褥与不舍被同时纳入视野。
- Expanded beats：门与油灯的琐碎问题 → 离开决定 → 行李动作 → 对旧屋和共同生活痕迹的停留。
- Compressed/omitted beats：没有逐项交代谁收了什么，也没有长谈“我们关系是什么”。
- State-changing exchange：命令式但已默认共同执行的“收拾行李”，把目的地从宁缺个人愿望变为两人的路线。
- Opponent/other-character reaction：无第三者；关系本身是场内压力。
- Body/space/detail selection：门、柜子、被褥、逼仄位置，而非抽象“相依为命”。
- Ruler/reader model：读者应能看出“离开”会同时搬走两人的生活系统。
- Stop point：留在收拾与睡前的旧屋情绪，不提前写成长安后的新生活。
- Interpretation：日常物件在迁徙场里可承担“关系已是共同单位”的证明。
- Anti-inference：不能据此推出所有共同出发都应靠家务细节证明；这里只有长期共居已被文本建立。

## E02｜危险离开时，用一碗未吃完的面建立回归约束

- 章节：第一卷第五十二章《春风亭，老朝小树》
- 行号：2293–2312
- Anchor：`回来继续吃`
- Scene posture/type：行动出发前的轻度争执与告别。
- Scene goal：让宁缺去赴险，不把桑桑的担忧写成抽象哭诉。
- Pre-state：宁缺接下高风险杀人交易；桑桑在后院做家务。
- Evidence：
  - 桑桑用更重的洗涮动作表达不满；宁缺先解释报酬与人情，又补出替故人还账的个人理由。
  - 她没有转为长篇阻拦，而是看着剩面，要求他记得回来；宁缺把承诺落回“再煮一锅”。
- Expanded beats：装备与伪装 → 厨房的反常用力 → 解释 → 门槛、风雨、剩面 → 出发。
- Compressed/omitted beats：没有解释“她为什么爱他”，也没有把危险任务的战斗内容提前塞进此场。
- State-changing exchange：从“不理会他的解释”变为以晚饭规定回归；离开被绑定为必须返回的路线。
- Opponent/other-character reaction：朝小树在场，但不介入这段交换；他的存在反衬两人的内部规则。
- Body/space/detail selection：铁锅、抹布、未吃完的面、湿门槛、雨巷。
- Ruler/reader model：担忧必须有一个可执行、可复核的归来接口；这里是“吃面”。
- Stop point：宁缺转入雨巷，桑桑的句子已完成承诺压力。
- Interpretation：当人物马上要进入高风险行动，短促的生活约定比再加一层微表情更能使关系改变行动的意义。
- Anti-inference：不是说“饭”天然等于亲密；它在此有效，因先有共同做饭与共同居住的连续前史。

## E03｜兑现后允许停在“热面”和外人的看见上

- 章节：第一卷第六十三章《一世人，两碗煎蛋面》
- 行号：2738–2791
- Anchor：`一世人，两碗煎蛋面`
- Scene posture/type：危险行动后的回家停留。
- Scene goal：不急着把春风亭事件升级，而是兑现 E02 留下的回归承诺。
- Pre-state：宁缺刚从高风险夜战归来，朝小树随其回到老笔斋。
- Evidence：
  - 朝小树从两碗热面、桑桑的在场和两人自然排他的相处里，理解宁缺所说“生活”的重量。
  - 关系没有被人物自我定义，而由局外人读出其日常秩序。
- Expanded beats：战后疲惫 → 回铺子 → 煎蛋面 → 外人观察到两人间不可插入的默契 → 朝小树离开。
- Compressed/omitted beats：不复盘战斗，不给桑桑和宁缺追加一段“生死后告白”。
- State-changing exchange：没有新的伴侣承诺；状态变化是行动归来被生活重新接住。
- Opponent/other-character reaction：朝小树从调侃和不解转为理解，承担读者校准。
- Body/space/detail selection：面碗、围裙、铺门、小桌，而非战后伤势的铺陈。
- Ruler/reader model：若前场已经设下“回来吃”，回归场可用同一生活动作兑现，并允许停在兑现本身。
- Stop point：朝小树离开、外部新任务出现前。
- Interpretation：关系兑现后停留在既有日常动作上，可以让大战的后果被读者感到，而不必马上新开危机。
- Anti-inference：该做法依赖前场明确设下的面食约束；无前置承诺时，突然的“做饭收尾”可能只是装饰。

## E04｜争执在日常时间成本被具体化后，直说比忍耐更自然

- 章节：第一卷第一百八十四章《放着我来》
- 行号：11467–11481
- Anchor：`耽搁别人的时间`
- Scene posture/type：共同生活中的效率争执。
- Scene goal：把宁缺试符的兴奋，转成对桑桑实际时间与休息权的侵犯。
- Pre-state：宁缺反复以“我来”干预浇花、烧火、擦席，实际都比正常家务慢。
- Evidence：
  - 文本先连续展示三次失败或迟缓，才让桑桑爆发。
  - 她的长句不是泛泛责怪，而是列出“等符生效”本可完成的具体劳动，并反用宁缺旧日原则。
- Expanded beats：三次“帮忙” → 每次等待 → 她停止忍耐 → 明说时间成本 → 宁缺承认自己只是兴奋。
- Compressed/omitted beats：不写冷战、不再添加第三次道歉，也不把矛盾升级成关系破裂。
- State-changing exchange：她取得明确的拒绝权；宁缺的练习不再能随意占用她的劳动节奏。
- Opponent/other-character reaction：宁缺从兴奋变为讪讪；后山其他人也受同一问题影响，证明不是无端挑刺。
- Body/space/detail selection：水桶、灶洞、湿毛巾、水盆、竹席。
- Ruler/reader model：当一方的行为反复占用另一方可量化的时间、劳动或休息时，直说应由累计事实触发，而非用一次蹙眉代替。
- Stop point：宁缺承认动机后即可；不要继续讲授“尊重劳动”的道理。
- Interpretation：直说的自然阈值不是情绪强度，而是双方已必须重分配现实负担。
- Anti-inference：如果没有重复成本和可执行冲突，直接抛出长篇控诉会显得突然。

## E05｜第一次长期分离，先保持日常不变，再让缺席显影

- 章节：第一卷第一百九十四章《晨光》
- 行号：12445–12513
- Anchor：`也没有什么区别`
- Scene posture/type：长期离别前夜与启程。
- Scene goal：让分离不靠煽情告别，而靠“照旧”的动作显出其反常重量。
- Pre-state：宁缺将第一次长时间离开桑桑，赴荒原实修。
- Evidence：
  - 晚饭、洗脚、睡觉、晨起、牙具、毛巾和衣着照料都维持旧顺序。
  - 临行时两人没有新增誓言；离开后，桑桑想的是少杀一只鸡会不会让他路上饿。
- Expanded beats：回家报到 → 普通晚饭 → 夜里靠近 → 早晨被照料 → 行李已备妥 → 启程后各自想念。
- Compressed/omitted beats：没有重复解释“这会是第一次分开”，也没有让两人郑重道别数轮。
- State-changing exchange：无新对白；状态变化由照料程序第一次被迫中断。
- Opponent/other-character reaction：陈皮皮被宁缺托付“家里有个小侍女”，侧面说明她已进入其行动安排。
- Body/space/detail selection：被褥压痕、牙具、毛巾、秋服、行李、鸡。
- Ruler/reader model：长期关系的离开可先展示旧程序完整运行，再在启程后的一个具体照料念头处切断。
- Stop point：两人各自离开画面，想念已成立，不追写远程抒情。
- Interpretation：重复日常不必每次升级关系；在缺席前完整呈现一次，即可成为之后的负荷基线。
- Anti-inference：这不适用于原本就松散、没有共同生活程序的关系。

## E06｜缺席让生活空间和行动学习发生替代

- 章节：第二卷第九十二章《世间哪里有闲人》
- 行号：19474–19603
- Anchor：`怎样也习惯不了`
- Scene posture/type：分离期间的独处与能力转向。
- Scene goal：把宁缺缺席从“想念”落实为桑桑重新使用屋子、保暖和力量的方式改变。
- Pre-state：宁缺在荒原，桑桑留守老笔斋，并开始跟随老人学习神术。
- Evidence：
  - 她只烧半张炕，取宁缺留下的符贴身保暖，又把他的被褥盖给老人。
  - 她学习神术的明确动机不是泛泛成长，而是未来能替宁缺打架、杀人。
- Expanded beats：留守的屋内取暖 → 遗留物被重新使用 → 照顾旁人 → 学习能力的目的被重新定义。
- Compressed/omitted beats：没有用回忆插叙重讲两人的全部过去。
- State-changing exchange：无直接对话；缺席改变她的能源分配、照料对象与成长路线。
- Opponent/other-character reaction：老人逐步接受家务秩序，并理解桑桑练习的目标。
- Body/space/detail selection：半暖的炕、银炭、贴身的符、被褥、食盒。
- Ruler/reader model：离开要在留下者遇到的第一批实际问题中显示：旧协作不在，谁接手、谁被替代、能力为何被迫转向。
- Stop point：桑桑的行动动机已清楚后，切出该屋内状态。
- Interpretation：关系成为路线变量，不止是“我想他”，而是缺席改变资源使用、风险准备与能力投资。
- Anti-inference：不能把所有技能学习都归因于关系；这里的因果由桑桑的明确动机支持。

## E07｜外部身份诱惑来临时，直说共同生活条件

- 章节：第二卷第一百四十四章《没有你，我困不着觉》
- 行号：22960–23005
- Anchor：`如果分开都会睡不好`
- Scene posture/type：身份归属冲突。
- Scene goal：让“认回父母、进入高门”成为对既有生活路线的真实替代方案。
- Pre-state：桑桑得知可能是大学士之女，养父母要带她离开老笔斋。
- Evidence：
  - 桑桑承认对方会对她好，却拒绝当场离开；她要求等宁缺回来共同决定。
  - 面对长辈，她直接列出不可替代的工作和睡眠依赖；宁缺在归途中也承认自己离开老笔斋便无法安睡。
- Expanded beats：认亲陈述 → “然后呢”追问 → 对方安排新生活 → 桑桑拒绝 → 直说共同居住与睡眠条件 → 宁缺返城的内在理由。
- Compressed/omitted beats：不把桑桑写成宣言式反抗者，也不立刻安排双方正式定义关系。
- State-changing exchange：外部家庭路线被拒绝；“是否离开”重新交还给两人的共同生活安排。
- Opponent/other-character reaction：大学士夫妇震惊，无法理解她为何不以身份跃迁替换旧关系。
- Body/space/detail selection：手里的抹布、鞋尖、铺子、洗脚水、面和牙具。
- Ruler/reader model：当外部选项会改写居所、照料、睡眠、身份和日后决定权时，明确说出依赖条件比含蓄反应更自然。
- Stop point：到宁缺意识到自己“不能没有桑桑”为止；重逢另作场景。
- Interpretation：直说在此不是告白，而是为共同路线提供不可替代的事实依据。
- Anti-inference：不可把未成年时期的身体依赖抽象化、浪漫化为普遍亲密模板；本窗口只证明其在该人物关系中的叙事功能。

## E08｜同一空间隔着帘子时，不直说也能构成高压关系场

- 章节：第五卷第二十一章《相看两厌（上）》、第二十二章《相看两厌（中）》
- 行号：63428–63532
- Anchor：`中间就隔着一道薄薄的布帘`
- Scene posture/type：身份变化后的近距离错位相见。
- Scene goal：表现两人仍受共同生活记忆牵引，但当前并不具备可共同确认的关系条件。
- Pre-state：桑桑身份与位置已发生剧烈变化；宁缺在桃山，二人近在咫尺。
- Evidence：
  - 宁缺下意识想买三份食物，随后才改为两份。
  - 桑桑隔帘看见他，手中食物被捏坏；二人各自吃同类食物，空间只隔一层帘子。
- Expanded beats：宁缺的无意识惯性 → 纠正数量 → 隔帘对视但不相认 → 同步动作。
- Compressed/omitted beats：没有强行让他们立即对话、解释身份或互诉感情。
- State-changing exchange：无语言交换；变化是共同生活的自动反应仍存在，但不能再自动恢复关系。
- Opponent/other-character reaction：侍从只负责等待，不承担情绪解释。
- Body/space/detail selection：烤红薯、手部挤压、门槛、车厢、薄帘。
- Ruler/reader model：若双方尚未拥有共同决定权，微动作和空间阻隔可比直说更准确；它们应指向一个明确未解决的行动条件。
- Stop point：停在同食与帘隔，不立刻揭开冲突。
- Interpretation：这是 E04、E07 的边界：成熟关系并不自动要求直说；能否共同执行说出的结论才是关键。
- Anti-inference：不要把“隔帘同食”当作通用浪漫符号；它依赖前文已建立的食物与共居记忆。

## E09｜真正不可逆的离开，用直说和行动升级，而非继续猜测

- 章节：第五卷第一百六十三章《我不想你走》
- 行号：74239–74297
- Anchor：`你就别想走`
- Scene posture/type：关系与世界路线同时断裂的离别场。
- Scene goal：让桑桑离开不只是恋人分别，而是宁缺必须决定是否与整个人间的力量对抗。
- Pre-state：桑桑已登上由信仰驱动的大船，向彼岸离去。
- Evidence：
  - 宁缺先以共同经历与生活账本要求她回应，桑桑沉默。
  - 在沉默不能再改变她路线后，他明确说不允许离开，并立即用人字符攻击拖船的关键连接。
- Expanded beats：起飞 → 抱腿失败 → 追问共同历史 → 无回应 → 明确拒绝离开 → 攻击具体机制。
- Compressed/omitted beats：不把多年的感情史逐段复述；不在大战前插入安慰性和解。
- State-changing exchange：从挽留失败转为对彼此路线的正面冲突。
- Opponent/other-character reaction：桑桑以一指破招，并明确重逢条件转为生死相见。
- Body/space/detail selection：鞋、腿、船首、刀、城墙、天际的绳索关系。
- Ruler/reader model：当离开已即时、不可逆，且双方下一步必须依据立场行动时，直说必须短、明确，并立刻兑现为选择。
- Stop point：桑桑破招后，旧挽留已不成立；转入新的对抗阶段。
- Interpretation：直说不是用来“表达浓度”，而是给行动选择定边界。
- Anti-inference：不可用这种强制性行动替代普通离别沟通；这里的世界级风险与人物能力是必要条件。

## E10｜回归先要求一个可执行目的，再允许恐惧改变目的地

- 章节：第六卷第一百零四章《一心安处》
- 行号：83027–83122
- Anchor：`跟我回家`
- Scene posture/type：失而复得后的路线协商。
- Scene goal：重逢不自动等于复原；“回家”必须经由双方对生存风险的重新定义。
- Pre-state：宁缺找到被屏障隔开的桑桑，二人经历长久分离。
- Evidence：
  - 宁缺先讲述追寻与旧事，再用普通语气要求她出来；拥抱后连续提出回家。
  - 桑桑不接受抽象归属，反问“哪个家”，再直接说明自己怕死；宁缺因此从回原世界改为回长安老笔斋。
- Expanded beats：寻找痕迹 → 平静要求现身 → 见面拥抱 → “回家”被追问 → 恐惧公开 → 目的地重定。
- Compressed/omitted beats：不把重逢立刻写成性格恢复或世界问题解决。
- State-changing exchange：双方从“找回彼此”进入“共同选择可活下去的家”。
- Opponent/other-character reaction：动物先作警惕，后收敛，给身体接近提供轻微外部反馈。
- Body/space/detail selection：鸡骨头、油灯、石像、手、肩、风雪、炕。
- Ruler/reader model：回归场应让旧动作完成辨认，但必须用一个新的可执行选择证明关系位置已不同。
- Stop point：定下“长安老笔斋”这一可行动目的地后。
- Interpretation：关系确认后的停留可以长，但每段停留都应推动“下一处在哪、承担什么风险”的共同选择。
- Anti-inference：不能把任何“回家”都写成终局和解；此处仍保留世界存亡风险。

## E11｜亲密后的真恐惧应被听见，再转为同向行动

- 章节：第六卷第一百零五章《一夜，有话》
- 行号：83125–83202
- Anchor：`我真的很怕死`
- Scene posture/type：重逢后夜谈与重新同行。
- Scene goal：避免 E10 的“回家”成为单方命令；让桑桑的生存恐惧改变两人的行动基准。
- Pre-state：二人已重逢，但桑桑仍担心人间会杀死她。
- Evidence：
  - 亲密动作引出她主动转谈威胁；宁缺起初仍按自己的方案说回长安。
  - 她直接承认恐惧、落泪；宁缺转为“若怕就不做了”，并把目的地降至可存活的老笔斋。
  - 随后两人同骑离开，关系由语言落实为共同路线。
- Expanded beats：亲密中的不适 → 威胁信息 → 未来与孩子的琐谈 → 恐惧直说 → 方案改写 → 上马同行。
- Compressed/omitted beats：没有对恐惧做心理学解释，也没有让宁缺重复保证数次。
- State-changing exchange：桑桑从沉默承受转为明确提出生存边界；宁缺从单向目标转为接受边界。
- Opponent/other-character reaction：大黑马、青狮以回避和顺从调节场内气氛，不夺走主体决定。
- Body/space/detail selection：灯火、怀抱、眼泪、隆起的腹部、马背、风雪。
- Ruler/reader model：当一方的隐藏事实会推翻已提出的共同方案，应该直说；另一方必须以路线、风险或承担方式回应，而不是只给安慰。
- Stop point：二人上马离开，方案已有实体化动作。
- Interpretation：关系内的“直说”完成后，最短的验证是共同改变下一步。
- Anti-inference：不能因有亲密接触就默认对方已同意行动；本窗口正显示同意必须经过恐惧与目的地的重新确认。

## E12｜旧日常可在关系变形后作为有限回声，而非自动复原

- 章节：第六卷第一百一十六章《一碗面》
- 行号：84106–84164
- Anchor：`而且今天我放了葱`
- Scene posture/type：关系历史的回声式兑现。
- Scene goal：让桑桑在身份、能力和处境均已变形后，仍以一碗面回应共同记忆与旧债。
- Pre-state：桑桑独自带着孩子逃亡，来到与宁缺旧交有关的小镇。
- Evidence：
  - 她做清汤面，旧人以当年雨夜没有吃到的面相问。
  - 她补上葱和煎蛋；对方接受这碗面，知道这仍包含“把命交给对方”的旧关系含义。
- Expanded beats：照料孩子的笨拙 → 旧地见人 → 做面 → 旧账被一句话唤起 → 具体补足 → 吃面。
- Compressed/omitted beats：不让桑桑长篇回忆宁缺，也不把一碗面直接写成所有冲突都已解决。
- State-changing exchange：桑桑以可辨认的旧生活动作承认历史联系；旧人接受并重启互信。
- Opponent/other-character reaction：朝小树理解并吃面；旁人只感到敬畏，不能真正替代其共同记忆。
- Body/space/detail selection：襁褓、面碗、葱、煎蛋、筷子。
- Ruler/reader model：长期关系的日常符号可跨大事件回归，但必须带着新处境中的具体差异，而不是复制旧场。
- Stop point：旧人吃面后；外部危机仍在，不把温情当作收束。
- Interpretation：关系兑现后的停留可以是“回声”，前提是旧动作在新身份、新负担下被重新完成。
- Anti-inference：不能把食物符号机械复用；若没有共同前史与新的具体变化，读者只会看到重复。

# Cross-Window Findings

1. 日常动作先是“共同生活的账本”，只有在缺席、替换、争执或迁移时才应集中兑现为路线变量。
   E01 的搬迁、E02–E03 的面与回归、E04 的时间成本、E05–E06 的离开后重分工、E07 的住处选择、E12 的回声，均不是单靠“我很在乎你”，而是让居所、食物、保暖、劳动、睡眠或能力投资发生变化。
   支持：E01、E02、E04、E05、E06、E07、E12。

2. 直说适用于“现在必须共同决定下一步”的时刻；说完应立刻有可观察的选择变化。
   E04 的劳动时间冲突、E07 的是否离开老笔斋、E09 的即时离别、E10 的回家定义、E11 的生存边界，均由明确语言把关系事实转换为下一步路线。
   支持：E04、E07、E09、E10、E11。

3. 微反应不是较高级的亲密写法；当说出的结论尚不能共同执行时，它反而更准确。
   E08 中两人隔帘同食、动作失控，却没有安全的共同选择可落地，因此不直说；E10 中第一次“回家”也被追问后才进入可执行协商。
   支持：E08、E10，反证边界：E04、E07、E11。

4. 关系兑现后可以停留，但停留必须兑现前置物或重新确认新的共同位置，不能把停留写成空白抒情。
   E03 回收 E02 的“回来吃面”；E10–E11 让重逢分别落到“家在哪里”与“怎么同行”；E12 让旧面条在新身份下重新有意义。
   支持：E02、E03、E10、E11、E12。

# Counterexamples & Boundaries

- 不要因为关系深就强迫直说。E08 的关键恰在“他们仍有共同记忆，但还没有可共同承担的决定”；此时直说会错误消除错位。
- 不要把争执写成泛情绪。E04 先连续给出等待、家务和休息损失，才允许桑桑长句反驳；没有累计成本，就没有这句直说的支点。
- 不要把回归写成自动复原。E10 的拥抱后仍要解决“哪个家”与“会不会死”；E11 的共同上马才是重逢被验证的动作。
- 不要把日常符号当万能和解。E12 的面只重启旧交，不消除追杀与外部危险。
- 不要把单方挽留误判为共同决定。E09 中宁缺的直说立即成为对抗；它有效地改变场景状态，但并未获得桑桑同意。

# What Existing Skill Misses

当前 `relationship` 已要求关系改变距离、边界、信任、选择或共同计划，并允许沉默、玩笑、直说、回避、触碰与争执；`departure_vacancy`、`reunion_reentry` 也已覆盖缺席与重逢后的非自动复原。因此以下才是可考虑进入 Scene Skill v2 的新增判断，而非近义重述：

1. 日常依赖的“累计—变体—路线”判断。
   现有关系 Skill 更擅长处理已经触发的关系场；缺少的是：重复照料、等候、分工和收尾不必逐场升级，何时应压缩为既成生活秩序，何时应由缺席、拒绝、替换、越界或主动承担，将它们兑现成路线变量。
   证据：E02、E04、E05、E06、E07、E12。

2. 直说与微反应的选择阈值。
   当前 Skill 允许两者，但未充分规定选择条件。新增判断应是：若下一步的去留、照料、责任或风险必须依赖共同确认，且有足够私密性与现实压力，使用一句明确直说；说完立即由选择落地。若没有共同执行条件，则保留动作、空间或沉默。
   证据：E04、E07、E08、E09、E10、E11。

3. 日常负担争执的 Primary 路由。
   若争执的核心是“谁承担时间、劳动、风险，谁有资格替对方决定去留”，应以 `relationship` 为 Primary，谈判仅为 Secondary；若核心仍是条件、筹码或交易，则继续用现有 `social_bargain_decision`。
   证据：E04、E07、E10、E11。

不应算作新增贡献的部分：关系兑现后允许停留、离开带来缺席、回归不是自动复原，现有 Skill 已覆盖。

另有一处真实但非本次 v2 规则本体的问题：Scene Skill 总览的 Primary Skills 列表未完整列出 runtime 已注册的 `departure_vacancy` 与 `reunion_reentry` 等技能，可能误导人工选择；运行时注册本身不受影响。

# Candidate Transfer Rules

1. **日常负荷只在被改写时展开。**
   - Applicability：已有连续共同生活事实；本场发生缺席、替代、拒绝、效率冲突、迁移或新责任。
   - Rule：选 1–3 个已经存在的生活动作，显示谁的时间、资源、身体或路线被改写；不要重讲全部相处史。
   - Stop rule：读者已能回答“原先谁承担、现在为何不能照旧、下一步由谁承担”即停。
   - Failure pattern：逐件罗列家务，或每个日常动作都硬升格为关系告白。

2. **直说只服务于共同的可执行决定。**
   - Applicability：双方必须据此决定去留、风险、照料、责任或边界；场内已有足够信任与压力。
   - Rule：一句具体事实或诉求即可；下一拍必须用接受、拒绝、改线或行动验证。
   - Stop rule：决定已被行动接住后，不追加同义解释、泪点或誓言。
   - Failure pattern：把微反应拖到人物无法行动，或在信息尚不允许共同确认时强行告白。

3. **日常争执先判定争的是什么。**
   - Applicability：表面是家务、效率、照料或安排，深层实际影响一方的时间、尊严、风险或去留权。
   - Rule：先给出可见累计成本，再让人物指出具体越界；结果必须改变分工、行动权限或路线。
   - Stop rule：越界被承认且新分配可见后停止。
   - Failure pattern：把关系争执写成抽象训话；或明明是交易条件，却错误套入亲密冲突。
