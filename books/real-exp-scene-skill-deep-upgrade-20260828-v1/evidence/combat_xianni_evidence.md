- `anchor`：`最致命的关键`
- **Evidence**
  - 场景姿态/目标：高阶联手重创敌手后的资源抢收与突发压制。
  - 前置状态：胜利来自偷袭、协力、对手信息过期；主角和盟友都已受伤。
  - 展开 beats：用最短篇幅回收前战成立条件、控制对手与盟友互斗以换抢收时间、裂缝收缩、巨手突袭、保命手段不可用、变大身体抢到裂缝边缘。
  - 压缩 beats：已经发生的厮杀不重复。
  - 改变状态的交换：战斗胜利不等于获得资源；资源裂缝从可取变为即将消失。
  - 他人反应：盟友转为潜在竞争者；强敌的残余生机被主动保留以拖住竞争者。
  - 身体/空间细节：元神刺痛、吐血、百丈距离、收缩裂缝、巨手五指。
  - ruler / reader model：读者以“裂缝还剩多少、保命手段是否可用、谁被谁拖住”判断压力。
  - stop point：目标转为从巨手下存活/取走资源；原对战已完成。
- **Interpretation**
  - transfer observation：决定性一击后可立刻切到“战果能否兑现”；不要用战后总结替代新的时间压力。
  - anti-inference：不能把任何盟友都写成背刺者；本场不信任有既有利益冲突和行为依据。

### XI-CX-13｜绝对强弱差，一击后应直接落到结果

- `chapter`：第一千六百五十章《斩三步！》；`100733–100757`
- `anchor`：`狠狠的一握`
- **Evidence**
  - 场景姿态/目标：救人并处决施害者。
  - 前置状态：敌手正以大规模术法抽取数百人的生机，自认占据完整控制。
  - 展开 beats：敌手施术、未知强者一声冷哼震碎其双臂、敌手先认出身份后立刻下令族人逃、虚掌一抓一握、敌手肉身崩溃，后续雷霆封杀逃者。
  - 压缩 beats：没有给敌手补设一轮“挣扎”。
  - 改变状态的交换：敌手从施术者直接转为被收取的头颅。
  - 对手反应：惊恐、后退、组织族人逃亡；反应本身替代无效反击。
  - 身体/空间细节：断臂、退后、数百元神回体、漆黑星球与雷霆。
  - ruler / reader model：一声冷哼已标定层级，后续一抓的功能是兑现，不是制造悬念。
  - stop point：主目标死亡；逃者处理为后续余波。
- **Interpretation**
  - transfer observation：若强弱差已由可见结果完全建立，杀招之后应直接写死亡/逃亡/后果，不虚构势均力敌回合。
  - anti-inference：不能用身份标签代替结果；本场先给出断臂和术法崩溃，才允许一握收束。

### XI-CX-14｜战前能准备，战中就不假装即时成阵

- `chapter`：第一千七百六十一章《七伏杀》；`107324–107367`
- `anchor`：`七伏环绕`
- **Evidence**
  - 场景姿态/目标：伏杀前的资源与身体成本布置。
  - 前置状态：主角有独处准备时间，目标不是击杀，而是重伤两名远强于己的敌手并让其互相失衡。
  - 展开 beats：数个伏笔逐一落地；每项有明确功能与代价，包括失血、元神精气、疲惫、诱饵和空间遮蔽。
  - 压缩 beats：不把布置写成即时交战，也不让每伏变成独立小战。
  - 改变状态的交换：主角以血与疲劳换取可被触发的地形、遮蔽和诱导。
  - 对手反应：本窗口尚未入场；反应被有意留到诱饵生效后。
  - 身体/空间细节：失血、结痂、急促呼吸、黄沙、雾化遮蔽。
  - ruler / reader model：读者能逐项知道“这份成本以后会压向谁”，但不被迫预知战果。
  - stop point：诱饵发出，等待猎物进入；此处必须转入下一场景。
- **Interpretation**
  - transfer observation：若战前确有时间，准备应以“功能＋成本＋触发条件”呈现；战中不应凭空补出同量布置。
  - anti-inference：不能把所有战斗都预埋七层机关；此法严格依赖可用准备期。

### XI-CX-15｜临时增幅的正确收束：在窗口关闭前处决

- `chapter`：第一千八百七十五章《杀吕文冉！》；`114005–114058`
- `anchor`：`不送`
- **Evidence**
  - 场景姿态/目标：临时能力暴涨后的致命单挑。
  - 前置状态：增幅有时限；目标此前已试图击杀主角，且一旦时限过去便会反杀。
  - 展开 beats：气息攀升、对手恐惧并停止轰击、挥击击退、一步临身、踹碎肉身、追上元神、连续削弱、最终一掌拍灭。
  - 压缩 beats：不展开多轮神通互换。
  - 改变状态的交换：对手从攻击者到残缺元神，再到形神俱灭。
  - 对手反应：嫉妒转恐惧，背景威胁转求饶。
  - 身体/空间细节：汗水、颤抖、血雾、瞬身距离、临时魂铠。
  - ruler / reader model：读者知道杀人不是展示残酷，而是时限内唯一能消除反杀风险的选择。
  - stop point：死亡确认；立刻说明时限逻辑，不再追加招式。
- **Interpretation**
  - transfer observation：临时压制成立时，若敌手未来风险真实存在，应把行动写成迅速完成处决，而不是保留无意义回合。
  - anti-inference：不能把“背景威胁”自动当处决理由；这里有明确先手杀机与时限反转。

### XI-CX-16｜群体伏杀中，先用受伤读出封印机制

- `chapter`：第一千九百七十七章《风雪隐中杀！》至第一千九百七十九章《血战！》；`120245–120340`
- `anchor`：`一切都是电光火石间`
- **Evidence**
  - 场景姿态/目标：封锁街区内遭多方向围杀，目标从突围转为识别封印、清除第一波并寻找真正杀招。
  - 前置状态：环境安静异常；双方先感到封印波动，却不知道完整布局。
  - 展开 beats：雪阵双向封路、分工迎敌、第一拳击碎阵图却被封印入体、十五人多面合击、主角以身体承接并反冲、天牛形态清场、吸收元神后判断敌人的临时增幅和幕后限制。
  - 压缩 beats：阵法外观和每个敌人的独立招式不展开。
  - 改变状态的交换：一拳虽破阵却令自身被禁锢；以受伤换出敌人力量性质与布局深度。
  - 对手反应：第一波不停顿地加压；清场后其余围困者退逃。
  - 身体/空间细节：血流入眼、天灵刺入、封印入体、风雪、街道前后左右上五向。
  - ruler / reader model：读者先由受伤和外泄效果知道“拳未解决问题”，再从敌人行动看懂这是分层杀局。
  - stop point：首轮伏杀清除、真实限制条件被识别；新强敌出现时另开阶段。
- **Interpretation**
  - transfer observation：多敌战可用一次带伤的成功动作揭示更深机制；不要在开场一次性讲清全部阵法。
  - anti-inference：不能把“先受伤后解释”机械化；只有伤势确实改变下一步策略时才成立。

# Cross-Window Findings

1. **危险感先由可见阈值成立，而非先报全套机制。** 一眼审视、一次防御失效、身体剧痛、空间异常或敌人停手，已足够让读者重估强弱；机制可在行动造成后果后补足。`XI-CX-02 / 05 / 07 / 16`

2. **普通交换应只保留“改变选择”的那一拍。** 多日追逐、重复飞遁、无新增信息的攻防可压缩；需要展开的是触发动作、资源临界、首次失效和最终命中。`XI-CX-01 / 03 / 08 / 10`

3. **强者的真实反应是改策略，不是持续震惊。** 其可转为封出口、绕过召唤物直接抓操作者、优先处理自身外部围杀，或直接命令部属撤离。`XI-CX-07 / 08 / 11 / 13`

4. **“一击结束”只在胜负层级已被结果验证时成立。** 先给出足以证明层级差的断臂、招式崩溃、无法防御或时限条件；之后死亡/逃亡/后果可直接落地。`XI-CX-10 / 13 / 15`

5. **追逃的压力不是“跑得多累”，而是可花费的生存机会。** 资源、伤势、地形、第三者与追手自身负担必须至少改变距离、路线、注意力或恢复窗口之一。`XI-CX-01 / 09 / 11`

6. **临时能力与战果都需有关闭条件。** 临时铠甲会结束、裂缝会收缩、对手可能有一次性逃生物；这些条件决定是果断收束、抢收战果还是留下未决伤害。`XI-CX-06 / 12 / 15`

# Counterexamples & Boundaries

- `XI-CX-06`：目标已伤、空间也压缩，但仍不该一击结束；其一次性法器和境界代价构成真实逃离路径。不能因“杀意很强”跳过对方尚存资源。
- `XI-CX-08`：决定性杀招未带来胜利，但足以改写身份关系；此时正确 stop 是认输与未来约战，不是强行逆转。
- `XI-CX-14`：复杂伏杀只能在确有独处准备期时成立。战斗进行中再补同等规模的预设，会破坏已建立的时间压力。
- `XI-CX-12`：战斗赢了不等于场景结束；若战果有明确消失倒计时，战后立刻转入资源/生存目标是合理的。
- `XI-CX-03`：资源交付后的瞬杀依赖明确利益冲突；不能把所有谈判或投降都写成欺骗。

# What Existing Skill Misses

现有 `combat.md` 已要求“每次行动改变优势分配”、压缩无效交换，并要求强敌试探/适应；`chase_escape.md` 已覆盖距离、路线和资源取舍。真正新增的判断能力是：

1. **先建立可读的能力阈值，再解释机制。** 现有卡强调“为什么防守失效”，但没有把“身体/空间异常或一次失败测试足以先立危险尺”作为显式决策。

2. **区分“该打赢”与“该证明”。** 现有卡以胜负为主问题；`XI-CX-08` 显示决定性一击也可只完成资格证明，随后立即认输收束。

3. **把未支付的逃生资源纳入 stop 判断。** 现有卡的 stop 条件覆盖撤退/胜负，但未明确要求：若目标仍有可执行的最后资源，不能因为其已受伤就伪造一击终局。

4. **追逃中追手也应有独立负担。** 现有 chase 卡主要追踪双方位置和逃者选择；`XI-CX-11` 证明追手的伤势、外敌和目标优先级也能构成可利用的行动窗。

5. **战后战果作为新的倒计时对象。** 现有 combat 卡提及短余波，但未区分“余波”与 `XI-CX-12` 这种会立即吞没胜利果实的资源压力。

# Candidate Transfer Rules

1. **阈值先行规则**
   - applicability：信息不足、实力差可能很大、角色尚未能完整解释机制。
   - rule：先写一个可见阈值：一次工具失效、一次身体异常、一次空间反应或一次敌手策略变化；解释只补足该阈值影响的下一步。
   - stop rule：若读者已能判断下一步选择，不再追加说明书式机制。
   - failure pattern：先报能力全表，导致第一次受击没有未知危险。
   - evidence：`XI-CX-02 / 05 / 07 / 16`

2. **杀窗压缩规则**
   - applicability：一方资源、防御、触发动作或逃路进入不可逆临界。
   - rule：压缩已被理解的普通交换，只展开“临界为何成立—谁先行动—命中后的状态变化”。
   - stop rule：死亡、逃离、捕获，或场景已转为灾变/资源兑现时立即换场。
   - failure pattern：杀窗出现后仍补三四轮同义攻防。
   - evidence：`XI-CX-01 / 03 / 10 / 15`

3. **强弱差收束规则**
   - applicability：强弱差已经由可见结果证实，且弱方没有未展示的真实脱身资源。
   - rule：用一次结果和对手的策略性反应确认层级，然后直接落到死亡、逃亡或控制权变化。
   - stop rule：不可再把弱方写成无代价对攻。
   - failure pattern：只写“震惊”不写策略变化，或为延长戏份强造均势。
   - evidence：`XI-CX-10 / 13 / 15`

4. **追逃机会账户规则**
   - applicability：追手明显更强，逃者不能靠纯速度解决。
   - rule：每次付出的资源、伤势或环境操作，必须至少换取距离、路线、注意力、追手停顿或恢复窗口之一。
   - stop rule：距离关系稳定，或问题已转成战斗/潜伏/资源行动时结束追逃。
   - failure pattern：连续“加速—更近—再加速”，但没有可核验的态势变化。
   - evidence：`XI-CX-01 / 09 / 11`

5. **未支付逃生资源规则**
   - applicability：目标重伤、受困或被压制，但仍可能握有一次性法器、援手、代价转移或空间出口。
   - rule：杀招可造成永久损失，但应允许该资源实际改变结局，并留下相称代价。
   - stop rule：逃生资源已消耗并确实失效后，才可写彻底收束。
   - failure pattern：用“他已受伤”替代对其剩余手段的判断。
   - evidence：`XI-CX-06 / 12 / 16`

6. **准备期与交战期分层规则**
   - applicability：角色在敌人未入场前，确有时间布置伏杀。
   - rule：每项准备只交代功能、成本和触发条件；诱饵发出后立即切入实际交战。
   - stop rule：布置完成或敌人入场即停止新增准备。
   - failure pattern：战斗中临时补出大量未付成本的机关。
   - evidence：`XI-CX-14 / 01 / 12`
