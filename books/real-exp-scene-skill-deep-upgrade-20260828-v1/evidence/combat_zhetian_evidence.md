# Research Question

公开大战、同阶/越级单挑、多人混战和星域级战斗，如何仍让读者持续看得懂“谁占优、为什么、下一步会改写什么”？重点核对：

- 战斗尺度扩大后，局部目标、位置、通路与保护范围如何承担因果；
- 强弱如何用可观察的 ruler 呈现；
- 旁观反应如何承担信息更新，而不是重复吹捧；
- 力量升级后，敌方如何转换为围杀、借兵、换战场或改写胜负条件。

# Evidence Windows

## E01｜同阶对决先立 ruler，再让招式改变 ruler

**Evidence**

- chapter / locator：第258章《大战天鹏》，L21965–L22154。
- scene posture/type：公开同阶单挑；旁观者可近距离退避、评估。
- scene goal：两名同阶顶尖体魄争夺“谁能压住谁”，而非立即结算生死。
- pre-state：对手主动压低修为至同阶；其速度与肉身被公认为可与主角对应。
- expanded beats：首次硬碰硬先毁场；主角连续以山岳型重压试出对手能撕开正面压制；对手改用速度连击，逼主角暴露对应的移动手段；主角再以近身位置夺回主动。
- compressed/omitted beats：普通拳脚互换不逐招计算；只保留改变“肉身、速度、近身权”三个 ruler 的动作。
- state-changing exchange：对手以极速形成持续压制，主角找到同步速度并抢到背后近身位，优势由对手转回主角。
- opponent / other-character reaction：旁观者不是泛泛惊叹，而是先判断对手体魄可抗、后判断主角能追上极速，连续更新双方 ruler。
- body / space / detail selection：山顶、瀑布、山体崩裂只用于量出冲击；真正细写的是距离、速度、背后位置与肉身承受。
- ruler / reader model：读者问的不是“谁招式更炫”，而是“主角能否同时解决对手的肉身与速度两项优势”。
- stop point：主角重新拿到近身权、对手被压至被动时，本窗口停；不把后续胜负拖入同一证据。
- anchor：`天鹏极速`

**Interpretation**

同阶大战可将“强弱”拆成少数可见维度。每次换招必须改变其中至少一项，否则应压缩。

**Transfer observation**

先给敌手一个真实、可验证的优势；主角不能只报更大威力，必须通过位置或动作权把该优势逐步取消。

**Anti-inference**

本窗口不证明所有单挑都应“先均势后反压”；它依赖双方本来就有可比较的体魄与速度 ruler。

## E02｜公开围战用“谁敢上、谁在试探”替代名单堆叠

**Evidence**

- chapter / locator：第415章《圣体四极大战》至第417章《不灭金身》，L38800–L39164。
- scene posture/type：突破后公开受挑战；多人围观、多人试探，但核心持续收束为一对一。
- scene goal：让新境界的实际压制力被公开确认，同时保留更高等级对手的悬念。
- pre-state：主角刚突破，群敌认为这是其根基未稳、最适合截杀的窗口。
- expanded beats：先一击杀死携禁器的试探者；再写装备与境界均更高的正式挑战者；最后写真正能把主角隔在空间外、以大道远攻的敌手。
- compressed/omitted beats：没有逐个处理所有上前者；多数人只以“沉默、止步、被迫观战”呈现。
- state-changing exchange：敌方先以禁器和远程空间优势阻止近身；主角破开隔绝空间，迫使对方从“控距”转为直接承受近身风险。
- opponent / other-character reaction：老辈插手解除兵器受困、护道人在禁术反噬时喊停，说明旁观者的反应会改变可用手段，而非只是喝彩。
- body / space / detail selection：空间隔绝、兵器压制、近身距离被持续保留；夜景和大场面仅作可见压力。
- ruler / reader model：主角是否能跨过“装备等级、境界差、空间隔离”三道防线。
- stop point：对手因超出自身承受范围的禁术反噬而失去行动权，公开强弱结算完成。
- anchor：`一击毙命`

**Interpretation**

公开大战中的旁观者应有分层功能：试探者揭示 ruler，护持者改变边界，真正对手把 ruler 抬高；不必让所有人轮流赞叹。

**Transfer observation**

多人到场时，优先写“谁愿意把什么代价押上去”。未行动者可用沉默、退避或限制同伴承担群体反应。

**Anti-inference**

不应把每次公开战都写成连续挑战擂台；本窗口的群体结构来自“新强者刚突破、各方抢先试探”的特殊局面。

## E03｜被围杀时，空间封锁本身就是胜负条件

**Evidence**

- chapter / locator：第597章《霸气》至第599章《古帝王腾》开头，L57980–L58237。
- scene posture/type：逃亡中的局部围杀，年轻强者与高阶追兵共同压缩行动空间。
- scene goal：从追杀态中夺回局部行动权，并让围杀方意识到人数不等于有效控制。
- pre-state：主角已被多次追捕并受伤；年轻强者成群逼近，外围另有高阶力量与大范围阵势。
- expanded beats：先迅速击溃领头者；再对付其余人的远程兵器；高阶敌人介入后，战场从“单点交手”转换为“数百里封锁”；主角判断阵纹覆盖与可用退路。
- compressed/omitted beats：十八人的逐人攻防没有平均分配；只展开能改变封锁、俘虏、撤离条件的节点。
- state-changing exchange：主角当众杀死俘虏，围杀方从以人压人改为用阵势封路；胜负问题由“谁能杀谁”改为“谁还能离开封锁区”。
- opponent / other-character reaction：年轻围攻者先退避高阶余波；宗门人物的愤怒来自公开羞辱与控制失效，不是单纯赞叹战力。
- body / space / detail selection：山峰、数百里阵势、搜索半径、封锁雾气都直接服务撤离 ruler。
- ruler / reader model：主角是否还能保持“选战场、选目标、选退路”的主动权。
- stop point：封锁完全成形、下一阶段转入新的敌手与局面时停止。
- anchor：`方圆千里`

**Interpretation**

多人战的“人数优势”只有在能封住路线、视野或救援时才构成实质压力。否则人数只是名单。

**Transfer observation**

当敌方兵力多于主角时，先明确其控制方式：包围、通路、阵势、救援或目标人质；主角的每次反击应削弱其中一项。

**Anti-inference**

本窗口不支持“大战必写大阵”；阵势在这里被写，是因为它实质改变了撤离权。

## E04｜强敌会把“赢了”转为“你已失去回路”

**Evidence**

- chapter / locator：第677章《战王腾》至第679章《斩我明道诀》，L65754–L66064。
- scene posture/type：公开宿敌战，围观群体会即时重估胜负。
- scene goal：证明“阶段优势”不等于胜局，并以敌方的策略转换制造第二个胜负问题。
- pre-state：双方均有高阶秘术与外物；观者把敌方视为该阶段的标杆。
- expanded beats：敌方以空间放逐制造“主角已无法返回”的公开判定；群体随即把它当作胜负结论；主角靠自身路径返回，并把敌方庆贺时聚集的站位转成反击窗口。
- compressed/omitted beats：不重复解释同类秘术；重点保留“放逐—确认死亡—返回—群体聚集受损”的因果链。
- state-changing exchange：主角被放逐后，敌方从单挑转为庆贺与靠近；主角返回，战场由单人困局转为敌方核心群体暴露。
- opponent / other-character reaction：先是亲友绝望、敌方认定胜利，后是群体被反击打断；反应承担“现有 ruler 已失效”的信息。
- body / space / detail selection：无垠虚空不是装饰，而是让“回不来”成为完整、可感的失败条件。
- ruler / reader model：能否从敌方定义的战场规则中返回；敌方的胜法是否真能封死下一步。
- stop point：敌方用自损式重构摆脱必杀，双方重新回到可战状态。
- anchor：`永恒的放逐`

**Interpretation**

强敌的有效应对，不是下一招更亮，而是将主角刚暴露的依赖转化为新战场规则。

**Transfer observation**

当一方看似获胜时，应问：其余角色会据此改变什么位置、资源配置或警戒状态？只要这些变化会反过来暴露新窗口，第二阶段就有因果。

**Anti-inference**

不能机械加入“假败反杀”。这里只有敌方确已用空间规则夺走回路，返回才具备反转价值。

## E05｜巨大尺度先移出承受区，再用观看通路保留局部因果

**Evidence**

- chapter / locator：第703章《毙大圣》至第704章《大战诸王》，L68246–L68422。
- scene posture/type：高阶多人混战，主战者、外部观者、潜伏袭击者和后续援军同时存在。
- scene goal：在高等级毁灭力下，持续看清谁被围、谁在争取时间、谁能改变人数差。
- pre-state：一名主战者对抗多名高阶敌手；场外人物无法直接参战，但拥有一次可送入战场的外物。
- expanded beats：主战者以伤换伤击杀一人；两名强敌改用兵器与协作压制；更多敌手出现，胜负从单挑转为“能否在数量继续增长前破局”；最后敌方提出离开生命区域，转入域外战场。
- compressed/omitted beats：不逐一写所有围攻者的招式；新敌人只有在改变人数、武器等级或目标时进入镜头。
- state-changing exchange：主战者抢到外物，敌方由硬杀改为把战斗带去域外，以避免/突破既有保护限制并扩大消耗条件。
- opponent / other-character reaction：场外人先绝望、再尝试送入关键资源；反应直接影响主战者是否获得新的工具。
- body / space / detail selection：古阵裂缝、战船、域外转移是战术限制；“可毁大域”的说明只用于解释为什么必须换场。
- ruler / reader model：主战者能否在人数和兵器双重劣势下，维持可交换的生存窗口。
- stop point：对手把战场迁出本地、战争问题升级为域外决战时停止。
- anchor：`去域外战斗`

**Interpretation**

宏大战斗不是扩大破坏描述，而是改变“谁可以进入、谁无法承受、什么资源能够送达”的场地规则。

**Transfer observation**

尺度超过现场承受能力时，必须明确一项实际后果：移战场、阵法隔离、远程观察、无法援助或保护对象。没有后果的尺度描写应删减。

**Anti-inference**

不要求所有大战都转场；若局部地点仍是争夺物或地形优势来源，留在原地反而更有因果。

## E06｜禁术的 ruler 要写成“代价是否已触底”

**Evidence**

- chapter / locator：第860章《血战元古》至第862章《成仙路上的法》，L82483–L82761。
- scene posture/type：公开同阶生死战；双方有复生、化道、领域等多重能力。
- scene goal：让读者追问“主角能否破解必杀规则，而非能否再打出更大威力”。
- pre-state：敌手以可消耗本源的重生术维持战线，并拥有能使对手化道的禁术。
- expanded beats：双方领域互撞后转入长回合追击；敌手禁术将主角多次切开；主角观察禁术轨迹，以受伤换取可用规律，再将其反制为自身攻击路径。
- compressed/omitted beats：长时间交锋只保留禁术命中、代价显现、规律被看见、反制成立四类节点。
- state-changing exchange：敌手的“必杀”先迫使主角失去身体完整性；主角以观察与承受取得控制部分规律，禁术从敌方绝对优势变为敌方本源消耗。
- opponent / other-character reaction：旁观者先把禁术视为无解，后因其被拆解而重新评估；敌方阵营则从自信转为担忧复生代价。
- body / space / detail selection：断体、手部化道、荒脉被毁都只用于量出“继续承受是否还可能”。
- ruler / reader model：敌手还能复生几次；主角是否已找到对方机制的可操作边界。
- stop point：敌方禁术被连续破坏、其本源代价明示后停止。
- anchor：`元皇道剑`

**Interpretation**

真正有效的越级/禁术战，不是把主角写成无伤硬扛，而是让“能承受几次、每次换到什么信息”成为明确 ruler。

**Transfer observation**

有绝对感能力时，至少落一项可见边界：次数、距离、蓄力、使用者本源、可观察轨迹或保护对象。

**Anti-inference**

不能把任何受伤都当作“学习成本”；只有伤势确实换来新行动可能时才展开。

## E07｜多线混战只保留会改写主线的支线

**Evidence**

- chapter / locator：第915章《对决华云飞与李小曼》至第916章《狠人一脉》，L86886–L87038。
- scene posture/type：遗迹内多方混战；主战、护卫战、半圣对峙、极道兵器威胁并行。
- scene goal：主角在限制场地中击败宿敌，同时不让同伴与离场目标失控。
- pre-state：主角面对两名宿敌，同伴对另一人；遗迹存在龙气、阵纹与会毁灭全场的极道兵器风险。
- expanded beats：主角先用范围动作把两敌同时纳入；同伴接走一条支线；宿敌封住场地龙气，取消主角已有地利；极道兵器威胁迫使各方暂时停止升级；主战继续转入殿宇追击。
- compressed/omitted beats：其他古庙内的战斗只作为“全场压力”；不另开完整回合。
- state-changing exchange：敌方封住地脉，使主角失去环境优势；主角转为主动近战，并把“抢先找到离场信息”列为时间目标。
- opponent / other-character reaction：同伴不是重复担忧，而是实际接走敌手；各方对极道兵器的忌惮直接收束战场尺度。
- body / space / detail selection：殿宇、屋脊、古庙阵纹、龙气与藏经目标持续出现，因为它们限定可移动区域与时间预算。
- ruler / reader model：谁掌握地利；主角能否在主战未结束前保住同伴并抢到下一步行动权。
- stop point：主战双方进入新的封闭对决，其他支线均已压缩成背景压力。
- anchor：`封龙图`

**Interpretation**

大型混战可只让一条支线在某一拍入镜：它必须改变主战的时间、地利、保护对象或下一步选择。

**Transfer observation**

多线场景中，给每条支线一个唯一作用；不能改变主线问题的支线只保留一笔状态更新。

**Anti-inference**

这不意味着所有支线都应工具化。关系戏若本身是本章主要阅读问题，可以成为主线。

## E08｜尺度极大时，以“为什么去了这里”代替纯破坏升级

**Evidence**

- chapter / locator：第999章《对决古之大帝！》至第1000章《无敌的年轻大帝》，L93932–L94113。
- scene posture/type：域外渡劫式单人大战；对手连续增量升级。
- scene goal：主角要逆过既有大道，而不是仅活过雷劫。
- pre-state：主角主动离开生命区域，避免战斗余波毁掉大陆；此前已拒绝外部助力。
- expanded beats：先处理陨星与器物型天罚；再发现敌人是同境界历史强者的道痕；对手由一人增至多人，主角用临时分身改变人数比，但仍无法结算。
- compressed/omitted beats：雷击本身不逐道描写；每次升级只保留新对手类型和它改变的胜负条件。
- state-changing exchange：主角从“承受天劫”转为“必须击败同境界道痕”；对手数量增加后，原本的单人策略失效。
- opponent / other-character reaction：没有现场观众；群体感知仅用于说明该力量已超常识，避免硬塞观战席。
- body / space / detail selection：域外、陨星、星体级雷击都服务“为何不能在地面打”与“为何无人能救”。
- ruler / reader model：主角能否在同阶条件下应对不断增加的历史标杆；每增加一名敌手，原策略是否还能用。
- stop point：对手增至九名、单人方案明确失效，窗口结束。
- anchor：`对决古之大帝`

**Interpretation**

大尺度并不等于多写星空。尺度首先应解释：为何必须移场、谁无法介入、原胜法为何被数量或规则推翻。

**Transfer observation**

若战斗离开常规场景，第一段就交代迁移理由；后续只保留会改写行动空间的星体/地形细节。

**Anti-inference**

并非每次升级都要上升到宇宙尺度；没有环境后果时，硬扩尺度只会稀释局部因果。

## E09｜公开混战的旁观反应要容纳分歧，而非统一站队

**Evidence**

- chapter / locator：第1057章《大战古皇子》至第1058章《不屈》，L99091–L99277。
- scene posture/type：公开阵营战；两场主战、外围拦截战、阵法阻援同时发生。
- scene goal：一方阻止屠城者继续推进，并为盟友创造单挑窗口。
- pre-state：敌方拥有多名顶级同辈、八部兵力和高阶援手；主角方需保护被毁城池之外的行动空间。
- expanded beats：主角以真身与道身分担三名顶级敌手；盟友主战单挑核心敌人；外围阵法截住增援；围观人群由惊异、争论到因战场推进而重新判断。
- compressed/omitted beats：八部人马不逐一列名；以“能否支援核心战场”作为外围战唯一计算。
- state-changing exchange：主角并非试图立即击败三人，而是用双身拖住他们；这让盟友得到独立结算核心仇敌的时间。
- opponent / other-character reaction：古族惊异其一敌三；人族旁观者对是否应反抗发生分歧；这些反应呈现社会代价与叙事争议，而非单调膜拜。
- body / space / detail selection：废城、荒野推进、阵法前线、敌援路径都与“谁能支援谁”直接相连。
- ruler / reader model：主角能拖住多久；主战者能否在援军到达前完成单挑。
- stop point：双方进入更高烈度持续交锋、原先的拖延结构仍成立时停止。
- anchor：`一挡三`

**Interpretation**

多人混战中，主角的局部胜利可以是“拖住”，只要读者清楚这段时间将被谁兑换成什么结果。

**Transfer observation**

把并行战线写成时间交易：A 线每多撑一拍，B 线得到何种明确机会；否则不要切镜头。

**Anti-inference**

本窗口的社会争议来自真实伤亡与长期族群冲突，不能把无关群众的误解当作廉价反转装置。

## E10｜极大尺度的战斗，用远程观看保留“谁先改策略”

**Evidence**

- chapter / locator：第1071章《大圣战》至第1072章《皇道争雄》，L100322–L100508。
- scene posture/type：域外高阶战；地面角色只能借阵台观看。
- scene goal：主战者在第二名同阶敌人抵达前先解决第一名敌人。
- pre-state：敌方以“切磋”名义约战，实际准备两名同阶强者与高阶兵器夹击。
- expanded beats：战前先说明普通角色无法接近；以阵台显示域外战局；主战者开场猛攻、不让敌手喘息；敌方第二人介入，主战者的快速结算方案失败。
- compressed/omitted beats：域外残骸和兵器异象只作为力量等级与旧战场背景；不逐颗星体描写。
- state-changing exchange：主战者的先手压制迫使敌手依赖兵器与援军；第二强者出现后，战斗从可速决单挑转为消耗型二对一。
- opponent / other-character reaction：地面角色无法冲入，只能通过阵台、阻拦同伴和判断兵器归属参与；反应改变的是后续地面阵营行动。
- body / space / detail selection：域外战场、阵台、无法接近、星体被毁，构成明确的观看与援助边界。
- ruler / reader model：第一敌人能否被迅速结算；第二敌人何时抵达；兵器是否把数量差放大到不可逆。
- stop point：二对一正式成立，原先“先杀一人”的方案失效。
- anchor：`大圣战`

**Interpretation**

宏大战的现场角色不必都在战场里。远程观看能保留群体压力，但必须让观众的情绪、判断或地面部署有后续作用。

**Transfer observation**

当战斗高到配角无法参战时，给他们一个有限通路：观看、封锁、送资源、撤离或保护；没有通路就不要频繁切回他们。

**Anti-inference**

远程观战不是通用升级器。若地面角色没有新的选择，只应短暂交代，不应反复插播。

## E11｜公开胜负可用“对手被迫改规则”完成二次定级

**Evidence**

- chapter / locator：第1352章《惨烈》，L124878–L124967。
- scene posture/type：星空公开宿敌战；旁观者众多，双方都在争夺同阶第一的社会判定。
- scene goal：确认同阶是否分胜负，并暴露一方一旦无法取胜时会否解除限制。
- pre-state：双方同阶血战，敌方仍维持境界约束；观者将其视为同辈巅峰 ruler。
- expanded beats：互换严重伤势；双方以拳法与血脉意志读到对手的底牌；敌方久攻不下后准备解除封印；随即发现此前一直战斗的并非主角真身。
- compressed/omitted beats：伤势不逐处累计；只保留能证明“同阶仍未压倒”与“敌方准备换规则”的伤。
- state-changing exchange：敌方要解除境界限制时，原本的同阶胜负已被承认；主角真身现身，直接把敌方的公开声势转为心理与地位劣势。
- opponent / other-character reaction：旁观者从恐惧双方体魄，转为震惊主角仍未真身出战；反应改变敌方的道心压力。
- body / space / detail selection：断骨、心口受创、星空碰撞都在量出同阶无法轻易结算；真身与道身的空间区隔是最终状态变化。
- ruler / reader model：敌方是否必须解除限制；主角是否已被逼到真身应战。
- stop point：真身公开、原先同阶局的社会解释被改写时停止。
- anchor：`星空下第一`

**Interpretation**

公开战的“赢”可以先由敌方行为承认：当对手不得不换境界、借外力或改目标，读者已获得阶段性 ruler 结论。

**Transfer observation**

阶段胜负成立后，优先落在对手策略或公共地位变化上，再决定是否继续写肉身伤势。

**Anti-inference**

不能把隐藏真身、替身当作常规羞辱手段；它只在“敌方必须靠改规则取胜”已被充分建立时有效。

## E12｜灭世尺度应压缩统计，展开抵抗节点与策略边界

**Evidence**

- chapter / locator：第1586章《黑暗动乱》至第1589章《太阳圣皇》，L144529–L144834。
- scene posture/type：宇宙级灾变；多数地点采用压缩叙述，少数抵抗节点展开。
- scene goal：让读者感到整体无解，同时仍能理解哪些地方为何能短暂抵抗、敌方为何绕开或转移。
- pre-state：多名至尊离开原地，各自以生命吞噬延缓衰老；没有同级统治者可全局阻止。
- expanded beats：大量星域伤亡以压缩结果交代；遇到帝阵、特殊防线或强者时，展开其能否阻拦、敌手是否值得硬攻；个别遗留力量把敌手引至域外，避免本地继续承受。
- compressed/omitted beats：绝大部分普通死亡不拆成战斗回合；不把每一颗星球都写成同构屠杀。
- state-changing exchange：守势能阻止强攻，却不能阻止敌手改道；局部胜利不是扭转灾变，而是改变某一片生命区域的即时命运。
- opponent / other-character reaction：群众祈祷、强者权衡、敌手算成本，分别承担情感、战略与尺度信息。
- body / space / detail selection：星辰毁灭、帝阵、关隘、域外转移只在解释“为何能守/为何不能追”时展开。
- ruler / reader model：一处防线能撑住多久；敌手为突破要付出什么；局部抵抗是否只能换来撤离或延迟。
- stop point：保护节点把敌手移出承受区、但整体灾变仍持续时停止。
- anchor：`黑暗动乱`

**Interpretation**

灭世场景需要承认局部行动的边界：一个角色不能解决全局时，其行动仍可明确改变一座城、一条通路或一批生命的状态。

**Transfer observation**

宏观灾难使用“压缩面 + 展开点”：压缩不可逐一承受的总体损失；只展开能改变路线、代价、保护范围或希望结构的抵抗节点。

**Anti-inference**

不可把宏观死亡数字当作自动的情感重量。没有具体保护关系、抵抗选择或后续代价时，数字会迅速麻木。

# Cross-Window Findings

1. 战斗尺度必须落实为行动空间的变化，而不是破坏物的增大：封锁退路、移出承受区、建立远程观看、决定谁能支援，都会改变下一拍。
   支持：E03、E05、E07、E08、E10、E12。

2. 强弱 ruler 最稳定的写法，是让敌方策略发生被迫转换：从同阶硬碰转为封路、借兵、围攻、解除限制或换战场。
   支持：E03、E04、E09、E10、E11。

3. 多人混战不按人数平均分镜，而按“这条支线是否改变主战的时间、地利、援军或保护对象”决定篇幅。
   支持：E05、E07、E09、E10。

4. 旁观反应的有效作用是更新读者模型：指出新 ruler、承认旧 ruler 失效、暴露社会代价，或触发实际介入；同义吹捧应删除。
   支持：E01、E02、E04、E06、E09、E11。

5. 高阶能力必须带可观察边界；伤势、次数、本源、兵器、距离或环境承受力至少有一项会决定下一步。
   支持：E04、E06、E08、E10。

# Counterexamples & Boundaries

- E01 中场地被打坏，但战斗没有转场：因为山顶仍足够承载双方的同阶 ruler。不是出现大破坏就必须换场。
- E02 的观众并非一直发言；大量人以沉默、退避、护持动作处理。群体反应应稀缺且信息增量明确。
- E08 没有安排现场观战席：该场域外战的孤立性本身就是压力。无实际作用的旁观切换会削弱孤绝感。
- E10 远程观看有效，是因地面人物能据此判断兵器、阻拦冲动介入并调整阵营行动；只有“看见”而没有选择时，不应反复切回。
- E12 明确显示局部抵抗不等于逆转全局。宏大战不能靠一场局部胜利伪装为总危机已解决。

# What Existing Skill Misses

当前 `combat.md` 已经正确覆盖：局部目标、位置/距离、对手真实回应、团队战分工，以及“大型战争用局部 POV 承载整体态势”。

真正新增的判断能力是：

- 缺少“尺度迁移阈值”：何时必须把战斗移出承受区、建立阵法/远程观察，且这些动作如何改变援助与退路。E05、E08、E10、E12。
- 缺少“ruler → 敌方策略转换”的明确写法：不只写敌人会适应，而要写其从何种胜法被逼到何种新胜法。E03、E04、E09、E11。
- 缺少多线战的“时间交易”规则：支线应明确兑换主线的时间、地利或保护结果。E07、E09、E10。
- 缺少旁观反应的功能分配：反应何时用于测量、社会定价、实际干预，何时应彻底省略。E01、E02、E06、E11。
- 缺少高阶能力的“场景内可见边界”要求：能力再大，也要让次数、代价、场地或对手处理方式改写下一拍。E04、E06、E08。

# Candidate Transfer Rules

1. **规则：先写尺度后果，再写尺度景观。**
   - applicability：攻击已可能伤及无关区域、配角无法靠近，或战斗需要移入新场域。
   - rule：先交代谁不能留、谁不能援、什么会被毁、为何必须转场；随后只保留改变这些条件的空间细节。
   - stop rule：迁移/隔离已改变行动权后，停止重复报破坏范围。
   - failure pattern：只不断升级“山崩星裂”，但人物仍在原地照常互换招式。

2. **规则：多人战每条支线必须兑换主线资源。**
   - applicability：同一章出现两条以上战线。
   - rule：每条支线进入正文前，确定它改变的是时间、援军、地利、视野、保护对象或撤离条件中的哪一项。
   - stop rule：支线完成一次状态更新后，若不能继续改写主线，压缩为一句。
   - failure pattern：反复切换多个“都在激战”的镜头，却没有人因此获得或失去行动机会。

3. **规则：用被迫改策略作为阶段强弱 ruler。**
   - applicability：公开单挑、越级战、宿敌战或需要社会定价的战斗。
   - rule：先让敌方当前胜法成立；当其被迫改为围攻、封路、借外物、换场、解除限制或换目标时，明确这代表旧 ruler 已失效。
   - stop rule：策略转换已被动作证明后，不再追加数段同义旁观吹捧。
   - failure pattern：主角一直占优，但敌手仍以完全相同的方式进攻，场景没有新问题。

4. **规则：高阶能力至少暴露一个可操作边界。**
   - applicability：复生、放逐、领域、禁术、帝兵、巨大范围能力。
   - rule：给出次数、本源、蓄力、距离、轨迹、环境承受或保护优先级之一，并让它影响下一拍。
   - stop rule：边界已被验证后，不再额外制造同类限制。
   - failure pattern：能力一会儿绝对无解、一会儿突然失效，读者无法推理应对。

5. **规则：旁观反应只在读者模型更新时出现。**
   - applicability：公开战、多人围观、阵营冲突。
   - rule：反应只能承担 ruler 更新、社会代价、实际介入、或阵营分歧之一；同类反应轮换视角。
   - stop rule：某项信息已被读者理解后，后续改用动作、沉默或退避。
   - failure pattern：每次出招都有“众人震惊”，但没有新判断、新选择或新代价。
