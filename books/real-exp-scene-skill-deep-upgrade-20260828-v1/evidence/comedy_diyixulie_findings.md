# Cross-Window Findings

1. 笑点的最稳固来源不是语言花活，而是人物把同一硬变量处理成不同东西：庆缜把羞辱当行动信号，任小粟把打劫当情报采集，许瞒把威胁说成常识，营长把死亡焦虑改写成队伍士气。人物声音由其“优先保护什么”产生。证据：DYS-C03、C06、C09、C12、C14。

2. 严肃剧情不靠“笑完再提醒危险”回压，而是靠一个不可忽略的物理或程序性动作：枪击、包围、枪口、手铐、敌袭、冲锋。它把对话状态变成新的行动状态。证据：DYS-C03、C09、C10、C12、C14、C15。

3. 连续抖包袱只有在每一回合都改变群体的任务承诺、关系位置或风险判断时才成立；一旦只剩同义重复，原文会用离场、警报、上铐、冲锋切断。证据：DYS-C02、C08、C12、C14、C15；反证边界：DYS-C14 的连续互怼仍在逐步处理恐惧、胜负观与守阵任务。

4. 知识不对称能产生喜剧，但其真正价值是迫使角色作出错误或延迟的选择，而不是让读者单纯优越。读者比看守、商人、反派或被误导部下多知道一层时，后续必须让该误判产生拘束、撤离、侦察或策略后果。证据：DYS-C03、C09、C12、C13。

5. 严肃自白后的玩笑只能碰边界，不能吞掉余波。DYS-C10 用枪口结束试探后才回到孤独；DYS-C15 在死亡机制说明后才允许互怼。证据：DYS-C10、C14、C15。

# Counterexamples & Boundaries

- 第306章《庆氏易主》有临死前回忆童年趣事，但缺少对手接梗和可辨的笑点状态变化；它更像人物姿态，不纳入 comedy/banter 主证据。
- 第551章《老师与学生》主要是“怀疑被好意推翻”的认知反转；没有足够的互动性笑点与回压链，排除。
- 第1012章《心疼杨小槿》可持续较长的邻里误会，是因为场景目标本来就是日常身份反讽；它不能证明高压场景也可无限续梗。
- 第1031章《庆慎与庆缜》的同句反弹有效表现关系，但窗口内没有足够严肃压力回归，不能单独支撑“严肃剧情共存”规则。
- 第1205章《大兴西北》有资源分配中的轻松反应，但主场景的证据重心是权力移交，不足以单列为 banter 窗口。
- 第1229章《大梦谁先觉》是哲学与牺牲对话；虽有尖锐口语，却不是以喜剧机制组织，排除。
- 反例边界：DYS-C14、C15 表明“危急时不可连续互动”不是绝对规则；只要每一轮都把恐惧转成共同任务，互动可延长，但敌情/冲锋一到必须停止。

# What Existing Skill Misses

当前 [`comedy_banter`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/comedy_banter.md) 已经覆盖：人物错位、对方按性格回应、避免共享网络机灵、第三次无新变化即压缩，以及主场景回归时退出。以下才是本批证据的新增判断，不重复这些已有条目：

1. “错位”需要标出被改写的硬变量：地位、风险、资源、时间或行动授权。若一句话没有使其中至少一项发生可见偏移，它只是俏皮话，不应展开。DYS-C03、C06、C08、C09、C12。

2. 高压 banter 必须预置“回压载体”：在最后一句前，Writer 应已知道会由谁的何种动作把场景切回现实，例如下令、上铐、举枪、警报、敌军抵达。现有 Skill 要求退出，但未要求把退出动作作为包袱结构的一部分。DYS-C03、C09、C10、C12、C14、C15。

3. 人物声线可用“目标函数”区分，而非靠称呼或口癖：有人把危险折算为收益，有人把责任折算为仪式，有人把权力折算为秩序，有人把死亡折算为队伍能否继续。这样即使移除原著专名，角色对白仍不可互换。DYS-C03、C06、C09、C11、C14。

4. 知识差型笑点需要规定“误判成本”：对方的误解至少应造成让步、暴露、错误部署或延迟反应；否则读者信息优势会变成空转。DYS-C03、C09、C12、C13。

# Candidate Transfer Rules

1. **硬变量错位规则**
   - applicability：双方对地位、风险、资源、时间或授权的理解不一致，且 scene 有明确任务。
   - rule：只展开能改写一个硬变量的笑点；把“谁把什么当成什么”写清。
   - stop rule：对手已经让步、暴露真实判断或采取强制动作时，立即转行动。
   - failure pattern：人物只是换词嘲讽，地位、选择和信息都没变。

2. **回压载体规则**
   - applicability：危险、谈判、身份试探、临战或牺牲场景。
   - rule：在写第一句 banter 前，先确定其后的实体回压：命令、武器、身体动作、警报、程序性后果。
   - stop rule：回压载体出现后，不再补“为什么好笑”的旁白或第二轮解释。
   - failure pattern：危险被角色连续无视，读者开始不信现场代价。

3. **目标函数声线规则**
   - applicability：至少两名角色在同一压力下有不同利益、职责或知识。
   - rule：让每人按其稳定优先级回答，而不是按固定口头禅回答；可问“他会把当前问题折算成什么？”
   - stop rule：两轮后若对白互换姓名仍成立，停止加梗，改用行动。
   - failure pattern：所有角色都像同一个聪明作者在抢一句更机灵的话。

4. **误判必须付费规则**
   - applicability：读者或一方角色掌握另一方不知道的信息。
   - rule：误判后的反应必须留下成本或推进：暴露策略、错误放松、接受交易、改变路线、启动调查。
   - stop rule：误判已被纠正或代价已触发，即退出反讽。
   - failure pattern：角色持续犯同一错误，只为让主角显得更聪明。

5. **临战互怼规则**
   - applicability：人物已经明确知道代价，并在等待不可避免的行动。
   - rule：每一回合只能完成一项任务：承认恐惧、确认共同信念、重定义可承受损失或确认行动。
   - stop rule：敌情、命令、冲锋或真实伤亡出现时，立即停止。
   - failure pattern：进入实战后仍维持轻松聊天，使牺牲变成无重量背景。
