# Cross-Window Findings

1. **辨认、接纳、重新取得行动位置是三次不同的状态变化。**
   名字、旧物或私密记忆只能解决“是不是他”；当事人是否愿意重新靠近是下一层；家族、团队、机构是否让其以新身份行动又是第三层。支持：RE-DL-01、03、07、08、09。

2. **外貌或身份变化越大，确认越应由不同证明力的线索递进，而不是用一句自报姓名。**
   旧称呼可制造亲近感，旧物可能反而引发警戒，独有能力或不可伪造的共同经历才可完成确认。支持：RE-DL-01、03、07；反证边界：RE-DL-08 中恋人重逢已不需要再做能力验真。

3. **重逢不能自动抹平缺席者造成的当前缺口。**
   奥斯卡缺席改变群体重聚的气氛；小舞的短暂显形和阶段恢复也不等于完整归来。支持：RE-DL-02、10、11、12。

4. **旧关系的连续性应由当下动作证明，而不是靠怀旧旁白。**
   五怪以新能力重建协同，唐三和小舞在新环境中恢复组合，奥斯卡以自己的选择重新进入宁荣荣与伙伴的共同未来。支持：RE-DL-04、06、09、12。

5. **成功重逢可以以再次分流收束。**
   关系是否真实连续，不看人物是否从此不再分开，而看他们能否明确当前优先级、相互承认外部责任，并建立下一次可执行的会合条件。支持：RE-DL-05、06、09。

6. **“回来”必须按恢复层级写清楚。**
   可感知存在、短暂显形、拥有身体、拥有完整意识、能独立行动、能重新进入社会关系，并不是同一状态。支持：RE-DL-06、10、11、12。

# Counterexamples & Boundaries

- 旧名并非万能通行证。学院守门人不认戴沐白、朱竹清并不是关系失真，而是公共秩序和私人记忆的知识不对称。RE-DL-01。
- 不要把所有群像重逢都写成热闹团圆。奥斯卡的缺席使宁荣荣的情绪成为此场的真实结果。RE-DL-02。
- 不要每次都安排战斗验明身份。唐三、奥斯卡之间需要能力与秘密，是因为双方确有伪装、敌意与误认风险；宁荣荣见到奥斯卡时，重点已是情感回应。RE-DL-03、07、08。
- 身体回归不等于生活回归。小舞阶段性出现和“复活四分之一”都能制造 payoff，但必须保留独立行动与稳定存在的限制。RE-DL-10、11。
- 完整复活也不应立即抹平代价。唐三仍有重伤与魂环缺口，小舞仍有逝者损失，二人需要把关系放入下一段责任。RE-DL-12。

# What Existing Skill Misses

当前 `reunion_reentry` 已正确覆盖：旧关系仍在但人已改变、辨认不应只靠报姓名、确认后仍需以新共同动作或边界收束。

真正新增的判断能力是：

1. **三层状态判别：认出 ≠ 接纳 ≠ 获得行动资格。**
   现有 skill 将它们压在“辨认、信任与行动位置”中；本研究显示三层可分别由熟人、亲密对象、机构／家族／团队完成。RE-DL-01、03、07、08、09。

2. **门槛归属判断。**
   Writer 需判断当前场景真正由谁掌握“回归是否生效”的权限：守门者掌握公共进入，恋人掌握情感进入，父亲掌握家庭与社会认可，团队掌握协作位置。不是所有旁观者都该同时相信。

3. **不完整重逢的缺口管理。**
   现有 skill 提到“有人没有回来”，但没有要求把缺席转成当下场景的结构力量，或区分暂时显形、身体恢复、独立行动等恢复层级。RE-DL-02、10、11、12。

4. **重逢后的分流合法性。**
   现有 skill强调共同动作，新增判断是：共同动作成立后仍可立刻分流；只要人物明确各自新的责任、保留可执行联结条件，关系并未退回原样。RE-DL-04、05、06。

5. **关系恢复后的现实资格题。**
   恋人互认之后，不应自动把身份差、保护能力、阵营归属一并消除。若这些条件本来真实存在，归来者必须以自己的选择取得新位置。RE-DL-08、09。

# Candidate Transfer Rules

1. **分开写“认出、接纳、入位”。**

   - applicability：离开显著改变外形、身份、能力、立场或公共名声。
   - rule：先确定每一层由谁确认；每层只给该人物有资格判断的证据。
   - stop rule：当前场景只要完成其主层级，就转入下一层或下一场。
   - failure pattern：一声“我是我”之后，恋人、团队、机构和敌人全部无条件恢复旧态。

2. **让旧名撞上一个现实门槛。**

   - applicability：归来者进入已重组的组织、家庭、团队或领地。
   - rule：用程序、职责、利益、现有分工或知识差制造一个具体阻力。
   - stop rule：门槛已被合适证据或新协议解决，不反复羞辱归来者。
   - failure pattern：场景只写旁人惊叹变化，旧身份从未影响任何现实选择。

3. **确认链按风险配置，不机械叠加。**

   - applicability：现场存在伪装、冒名、敌意或变化大到可信度不足。
   - rule：从低证明力的称呼、习惯、旧物，推进到私密共同经历或不可轻易伪造的行动能力。
   - stop rule：关键怀疑者已有足以改变行为的证据。
   - failure pattern：无风险的温情场也强行打斗验身；或高风险场只用口头自称解决。

4. **让不在场的人继续占据场景。**

   - applicability：重聚本应完整但有关键成员失联、死亡、失能或不能公开现身。
   - rule：使缺席改变谈话、站位、庆祝方式或下一步目标。
   - stop rule：读者已明白“谁没回来，以及这使谁现在不能像从前那样行动”。
   - failure pattern：群像一拥抱就当全员圆满，缺席者只作为一句背景交代。

5. **恢复分层，逐层给权。**

   - applicability：人物经历死亡、失忆、重伤、附体、异化、长期失踪或身份剥夺。
   - rule：分别写存在确认、意识回应、身体稳定、独立选择、重新获得社会／团队职能。
   - stop rule：本窗只兑现授权范围内的一层，不替后续层级提前结账。
   - failure pattern：人物睁眼或显形后，就自动恢复全部关系、能力和行动权限。

6. **重逢后以新共同动作或新分流收束。**

   - applicability：旧关系已确认，人物需要进入下一段剧情。
   - rule：要么让双方在新条件下完成一次协同；要么明确各自当前责任、保留下一次联结的可执行条件。
   - stop rule：共同能力或新的分流协议已通过行动／选择成立。
   - failure pattern：用旁白总结“他们回到了从前”，却未显示他们现在能一起做什么，或为何暂时不能同行。
