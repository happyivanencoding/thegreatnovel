# Cross-Window Findings

1. 技术细节应只标出“下一拍为什么被迫改变”的节点：接触借力、呼吸耗尽、蓄势声响、伤处受限、飞行续航都可作为节点；无新选择的招式串应压缩。`CWM-02, CWM-04, CWM-09, CWM-11, CWM-15`

2. 势均力敌的可读性来自持续保留反制权，而非机械轮流占优：一方取得优势后，另一方仍能以位置、恢复、节奏或信息反制；胜负应在这些回应逐渐失效后才落定。`CWM-01, CWM-08, CWM-09, CWM-14`

3. 对手适应必须改变后续打法：对手看过旧战、识破征兆、锁定伤处或更新模型后，主角若要反转，须拿出新的成本、条件或第二层判断。`CWM-03, CWM-05, CWM-12, CWM-13, CWM-16`

4. 时间只在改变选择时才需要可见化：换气、憋气、麻痹累积、连续爆发、飞行续航可以成为读者的时间尺；没有这样的阈值，不必添加虚假的倒计时。`CWM-04, CWM-08, CWM-09, CWM-15`

5. 公开竞技的 ruler 最小化：用一次赛前基准、一次关键误读或解说校正、一次裁判终局，足以建立强弱；不应每轮都让观众复述“好强”。`CWM-02, CWM-05, CWM-12, CWM-14`

6. 裁判最适合承担规则和伤害边界，而非解释器：其介入应对应失控、要害、无法反制的攻击或正式判定。`CWM-08, CWM-10, CWM-13, CWM-16`

# Counterexamples & Boundaries

- 长时攻防不一定要全程高信息密度。耐力战可压缩，只保留消耗如何转成重心或呼吸问题。`CWM-03`
- 不要因为是比赛就强加对话或心理旁白；语言不通时，气势试探、身体动作和空间选择足够承载判断。`CWM-07, CWM-13`
- 不要把“展示对手全部能力”误当最优战术。角色若故意体验技术，属于其目标偏移的反例，不应写成标准取胜法。文本第3段，第060–061章，43904–44010。
- 裁判舞弊、特异的遗忘/读心能力、明显高阶精神压制，都不能直接生成正常公开单挑规则。文本第3段，第073–074章，45117–45376；文本第4段，第052–054章，58324–58588；文本第4段，第087–088章，61185–61327。
- 不均势战可提供“如何针对短板”的证据，但不能被拿来证明同层单挑规律。`CWM-11, CWM-12, CWM-15`

# What Existing Skill Misses

现有 `combat` 已明确“动作—真实回应—状态改变”、压缩重复交换、强敌会适应，并非本包新增贡献；见 [`combat.md`](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\combat.md:5)。

真正新增的判断能力有三项：

1. 势均力敌单挑的持续反制约束：当前 Skill 覆盖战斗、团队战和战争，但未要求在“同层单挑”中持续保留双方反制窗口、禁止用单次展示跳过中段。`CWM-01, CWM-08, CWM-09, CWM-14`

2. 时间作为可见状态而非泛称节奏：当前 Skill 提到节奏变化，但未要求仅在换气、读秒、恢复、连续爆发或空间续航会改变下一选择时，把时间显式化。`CWM-04, CWM-08, CWM-15`

3. 公开竞技如何回灌每次交换：当前库把 `competition/public_proof/ranking` 列为 Modifier，并给出“大赛”组合，但没有规定赛前基准、一次误读/校正、裁判终局怎样与攻防状态连接。`CWM-02, CWM-05, CWM-12, CWM-14`

不算缺失：技术细节避免程序化、对手适应、旁观者结果落点、裁判作为外部判定，现有 `combat` / `trial_challenge` / `showcase_evaluation` 已有通用覆盖。

# Candidate Transfer Rules

1. **交换只写选择变化。**
   Applicability：同层或近同层、读者需要跟住技术攻防的单挑。
   Rule：每个展开交换必须改变至少一项：距离/架势、可用反制、准备时间、身体损耗、信息模型或场地控制。
   Stop rule：连续两次交换只重复同一优势时，压缩到状态结果。
   Failure pattern：把每招写成名字、动作、音效，读者仍不知道下一招为何必然不同。

2. **均势保留反制权，直到反制资源耗尽。**
   Applicability：结果尚未批准为碾压、双方都具备已建立的应对能力。
   Rule：领先方的压制必须暴露代价；落后方的反制必须有来源与成本，直到一方的呼吸、伤势、空间、准备或判断真正断裂。
   Stop rule：一方已无可见且可信的反制资源时，立即落定。
   Failure pattern：用突然更强的招式跳过已建立的相持结构。

3. **仅把会改决策的时间写进场。**
   Applicability：换气、读秒、招式准备、连续爆发、恢复或空间续航存在确定阈值。
   Rule：让时间通过“还能撑几轮/此刻不能恢复/必须在换气前进入某距离”改变选择。
   Stop rule：时间不改变下一拍，就不报秒、不造倒计时。
   Failure pattern：在无真实期限的场景反复写电子钟或数字，制造伪紧张。

4. **预判必须有可追溯信号，也必须能被适应。**
   Applicability：角色要提前识别对方招式、破绽或杀招。
   Rule：先建立可感知信号或既有资料，再写预判；对手发现后应改变征兆、距离或使用时机。
   Stop rule：没有文本内可见信号时，改写为风险判断而非准确预知。
   Failure pattern：角色每次都“恰好知道”，对手却永不更新。

5. **公开竞技只给一个读者 ruler。**
   Applicability：需要让非专业读者知道此次交换的强弱意义。
   Rule：每个阶段最多选一个最有立场的载体：赛前标准、一次观众误读、一次专业校正、一次裁判终局或一次赛后复盘。
   Stop rule：尺度和后果已经清楚后，移除重复惊叹。
   Failure pattern：观众、解说、队友轮流同义夸强，反而打断攻防。
