# Cross-Window Findings

- **角色声音应按注意对象和接话任务设计。**同一消息下，有人找对手、有人找风险、有人管秩序、有人要证据、有人只在结论时开口；这些选择比口癖稳定。〔E-01、E-04、M-05、M-06、L-03〕

- **群聊里的解释要有可见载体。**截图、日期、文件、照片、自动键盘、账号记录或公告，把“有人说了什么”变成可被误读、转发、验证或追责的对象。〔E-02、E-05、M-01、M-04、L-04〕

- **压缩拍只适合共享前提已成立之后。**`+1`、表情、短回声和刷屏能快速显出共识；新风险、陌生角色或关键技术边界仍须有人说完整。〔E-02、E-04、M-01、M-05、L-03〕

- **误解应改变下一步，不只是提供一句笑话。**有效误解会改变路线、诊断、集体日程、处罚对象、身份归因或人物位置。〔E-06、M-01、M-03、L-04〕

- **笑点停止于阅读问题改写之时。**不可逆处罚、行动方案兑现、生命风险、责任暴露、权限改变出现后，应转入后果或新问题；继续加同类反应会遮蔽状态变化。〔E-02、E-05、M-03、M-04、M-06、L-05〕

- **群聊的“信息传递”包含可见性和责任链。**公开群适合动员、共识和施压；私聊可保护来源；转述、账号、禁言与撤回决定谁被相信、谁可发言、谁承担后果。〔E-06、M-05、L-04〕

# Counterexamples & Boundaries

- 诊断、永久风险和生死确认不能被群体玩笑吞没：E-04 明确保留不可强拆的风险，M-03 必须落到可验证操作，M-04 在现场证据出现后立即转救援，L-03 在伤口出现后禁掉越界调侃。

- “高流量忽略”只适用于低优先级、可补发的信息：M-05 的二维码请求被吞没，但该窗口本身不能支持忽略紧急求助。

- 禁言不是通用喜剧终止器：E-02、L-03、L-05 都有既存群主权限、明确越界或重复条件；没有这些条件时，应以行动结果、危险确认或换题停止。

- 多层误读不能替代必要澄清：M-02 的模糊化依赖读者已知禁忌和后续处罚；若读者必须据此采取行动，应直接提供可执行事实。

# What Existing Skill Misses

现有 `comedy_banter` 已有“错位—角色反应—不重复包袱—风险不可失真”的基本控制。新增的、非近义重复判断能力是：

- **信息可见性链：**谁看见原消息、谁只看到裁剪版本、谁被私聊保护、谁能追溯账号；用它判断误解是否可成立。〔M-01、E-06、L-04〕
- **媒介即行动：**截图、文件、照片、语音、自动回复、账号标识不是装饰，而是能改变归因、权限、行动路线的场景道具。〔E-05、M-04、L-04〕
- **角色声音的任务分工：**把角色写成“整理者、挑衅者、风险确认者、低可见性提问者、权限执行者”，而不是给每人分配口癖。〔E-01、M-05、M-06、L-03〕
- **紧急度切换：**同一聊天机制可从喜剧翻为调查或救援；切换依据是现场交叉证据与读者问题变化，不是作者宣布“严肃起来”。〔M-04、L-03〕
- **权限与路由的节奏作用：**禁言、撤回、私聊转述、群体迁移可直接改变发言资格和责任归属。〔E-02、L-04、L-05〕

# Candidate Transfer Rules

- **完整锚点后再做群体短回声**
  - Applicability：多人需对同一计划、邀请或异常作出反应。
  - Stop rule：完整目标、限制、下一步已由一人说清，且群体反应已落实为日程、选择或共识。
  - Failure pattern：所有人都抖机灵，读者却不知道他们究竟同意了什么。〔M-01、E-04〕

- **按注意对象分配接话，而非分配口癖**
  - Applicability：三人以上围绕同一消息交谈。
  - Stop rule：每人已通过一次选择、误判或行动暴露当前关注点。
  - Failure pattern：任意交换台词人物仍成立，群像失去可辨认性。〔E-01、M-06、L-03〕

- **让解释通过可见道具承担后果**
  - Applicability：信息可由截图、日志、图片、日期、账号、文件或界面传递。
  - Stop rule：道具已触发误读纠正、责任确认、权限变化或行动。
  - Failure pattern：道具只是视觉装饰，删掉也不改变任何人判断。〔E-05、M-01、L-04〕

- **允许低优先级信息被噪声吞没，但为硬信息改路由**
  - Applicability：群体正在集体兴奋、测试或跑题。
  - Stop rule：低优先级请求已成为后续小钩子；高优先级信息则改用 @、私聊、语音或明确的整理者。
  - Failure pattern：把紧急求助也写成“没人回”，制造无意义的角色失智。〔M-05、M-06〕

- **误解必须兑现为状态变化**
  - Applicability：读者与角色之间存在身份、来源、意图或风险的信息差。
  - Stop rule：误解已经改变路线、行动、关系、处罚或身体状态。
  - Failure pattern：反复误会后仍回到原状，只剩无后果的闹剧。〔E-06、M-03、L-04〕

- **用“不可逆结果”而不是句数终止笑点**
  - Applicability：调侃开始触及处罚、责任、生命风险、实际方案或公共身份。
  - Stop rule：第一个不可逆结果已由身体、空间或界面确认，立刻转后果或新问题。
  - Failure pattern：状态已变化仍追加第三、第四个同类包袱，读者不再知道当前主问题。〔E-02、M-04、L-05〕
