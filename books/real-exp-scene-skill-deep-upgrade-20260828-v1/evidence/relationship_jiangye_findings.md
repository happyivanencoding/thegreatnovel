# Cross-Window Findings

1. 日常动作先是“共同生活的账本”，只有在缺席、替换、争执或迁移时才应集中兑现为路线变量。
   E01 的搬迁、E02–E03 的面与回归、E04 的时间成本、E05–E06 的离开后重分工、E07 的住处选择、E12 的回声，均不是单靠“我很在乎你”，而是让居所、食物、保暖、劳动、睡眠或能力投资发生变化。
   支持：E01、E02、E04、E05、E06、E07、E12。

2. 直说适用于“现在必须共同决定下一步”的时刻；说完应立刻有可观察的选择变化。
   E04 的劳动时间冲突、E07 的是否离开老笔斋、E09 的即时离别、E10 的回家定义、E11 的生存边界，均由明确语言把关系事实转换为下一步路线。
   支持：E04、E07、E09、E10、E11。

3. 微反应不是较高级的亲密写法；当说出的结论尚不能共同执行时，它反而更准确。
   E08 中两人隔帘同食、动作失控，却没有安全的共同选择可落地，因此不直说；E10 中第一次“回家”也被追问后才进入可执行协商。
   支持：E08、E10，反证边界：E04、E07、E11。

4. 关系兑现后可以停留，但停留必须兑现前置物或重新确认新的共同位置，不能把停留写成空白抒情。
   E03 回收 E02 的“回来吃面”；E10–E11 让重逢分别落到“家在哪里”与“怎么同行”；E12 让旧面条在新身份下重新有意义。
   支持：E02、E03、E10、E11、E12。

# Counterexamples & Boundaries

- 不要因为关系深就强迫直说。E08 的关键恰在“他们仍有共同记忆，但还没有可共同承担的决定”；此时直说会错误消除错位。
- 不要把争执写成泛情绪。E04 先连续给出等待、家务和休息损失，才允许桑桑长句反驳；没有累计成本，就没有这句直说的支点。
- 不要把回归写成自动复原。E10 的拥抱后仍要解决“哪个家”与“会不会死”；E11 的共同上马才是重逢被验证的动作。
- 不要把日常符号当万能和解。E12 的面只重启旧交，不消除追杀与外部危险。
- 不要把单方挽留误判为共同决定。E09 中宁缺的直说立即成为对抗；它有效地改变场景状态，但并未获得桑桑同意。

# What Existing Skill Misses

当前 `relationship` 已要求关系改变距离、边界、信任、选择或共同计划，并允许沉默、玩笑、直说、回避、触碰与争执；`departure_vacancy`、`reunion_reentry` 也已覆盖缺席与重逢后的非自动复原。因此以下才是可考虑进入 Scene Skill v2 的新增判断，而非近义重述：

1. 日常依赖的“累计—变体—路线”判断。
   现有关系 Skill 更擅长处理已经触发的关系场；缺少的是：重复照料、等候、分工和收尾不必逐场升级，何时应压缩为既成生活秩序，何时应由缺席、拒绝、替换、越界或主动承担，将它们兑现成路线变量。
   证据：E02、E04、E05、E06、E07、E12。

2. 直说与微反应的选择阈值。
   当前 Skill 允许两者，但未充分规定选择条件。新增判断应是：若下一步的去留、照料、责任或风险必须依赖共同确认，且有足够私密性与现实压力，使用一句明确直说；说完立即由选择落地。若没有共同执行条件，则保留动作、空间或沉默。
   证据：E04、E07、E08、E09、E10、E11。

3. 日常负担争执的 Primary 路由。
   若争执的核心是“谁承担时间、劳动、风险，谁有资格替对方决定去留”，应以 `relationship` 为 Primary，谈判仅为 Secondary；若核心仍是条件、筹码或交易，则继续用现有 `social_bargain_decision`。
   证据：E04、E07、E10、E11。

不应算作新增贡献的部分：关系兑现后允许停留、离开带来缺席、回归不是自动复原，现有 Skill 已覆盖。

另有一处真实但非本次 v2 规则本体的问题：Scene Skill 总览的 Primary Skills 列表未完整列出 runtime 已注册的 `departure_vacancy` 与 `reunion_reentry` 等技能，可能误导人工选择；运行时注册本身不受影响。

# Candidate Transfer Rules

1. **日常负荷只在被改写时展开。**
   - Applicability：已有连续共同生活事实；本场发生缺席、替代、拒绝、效率冲突、迁移或新责任。
   - Rule：选 1–3 个已经存在的生活动作，显示谁的时间、资源、身体或路线被改写；不要重讲全部相处史。
   - Stop rule：读者已能回答“原先谁承担、现在为何不能照旧、下一步由谁承担”即停。
   - Failure pattern：逐件罗列家务，或每个日常动作都硬升格为关系告白。

2. **直说只服务于共同的可执行决定。**
   - Applicability：双方必须据此决定去留、风险、照料、责任或边界；场内已有足够信任与压力。
   - Rule：一句具体事实或诉求即可；下一拍必须用接受、拒绝、改线或行动验证。
   - Stop rule：决定已被行动接住后，不追加同义解释、泪点或誓言。
   - Failure pattern：把微反应拖到人物无法行动，或在信息尚不允许共同确认时强行告白。

3. **日常争执先判定争的是什么。**
   - Applicability：表面是家务、效率、照料或安排，深层实际影响一方的时间、尊严、风险或去留权。
   - Rule：先给出可见累计成本，再让人物指出具体越界；结果必须改变分工、行动权限或路线。
   - Stop rule：越界被承认且新分配可见后停止。
   - Failure pattern：把关系争执写成抽象训话；或明明是交易条件，却错误套入亲密冲突。
