# Cross-Window Findings

1. **战斗 posture 决定注意力单位，而非“战斗强度”本身。**
   多层伏击追踪“真实目标、掩体、敌层和预置空间”（E01、M01、M07）；有限资源战追踪“每次投入迫出的防御层”（E02、M02、L04、L05）；定点暗杀则只需追踪门、声音和可数攻防（E03）。
   Evidence：E01、E02、E03、M01、M02、M07、L04、L05。

2. **资源序列应写成重新定价的因果，不是装备清单。**
   箭、刀、念珠、血液、阵地、援军和防御层，只有在其消耗改变对手下一步时才被放大；无变化的轨迹与伤亡均被压缩。
   Evidence：E02、E04、M02、M04、L04、L05。

3. **强弱差的读者尺必须具体到“仍可改变什么”。**
   有时是距离与本命物（E04、M06），有时是人数、遮蔽与投射顺序（M04），有时是敌人被迫更换的防御层和位置（L01、L05）。单纯境界说明不能替代战斗进展。
   Evidence：E04、M04、M06、L01、L05。

4. **复杂动作只在因果分叉点展开。**
   五片剑的多向注意力、符法链条、团队红线网络、清潭中的锁定与换伤，都只细写那些使下一拍成为必要结果的动作。
   Evidence：E02、M03、M05、M06。

5. **终局反转可以改写胜负解释权，而不只改写存活者。**
   成京城把“唐军伏杀”翻成“唐军中伏”；临康城把“是否杀死横木”翻成“横木是否永远无法确认最后一剑”；一对三突围则把“击败全部敌人”收束为“逼关键敌人烧掉底牌”。
   Evidence：M07、L03、L04。

# Counterexamples & Boundaries

- E03 是明确反例：目标已死亡、暴露风险已解决时，应立刻停止，不能为“层层反转”追加敌人。
- E04 说明“第一次取得控制后让敌方复战”只适用于人物有明确验证目标；普通救援不适用。
- M04 不能被误用为“群体天然压制高阶者”；原文是开阔地、孤立修行者、精锐骑兵和投射序列共同造成的结果。
- L03 的终局反转是行动次序与认知控制，不是弱者突然获得更高战力。
- E01、M01、M07 都有前置空间、信息或阵地条件；无前置的突发埋伏不能直接照搬其多层结构。

# What Existing Skill Misses

当前 [`combat.md`](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\combat.md) 已有“目标、距离、手段、优势变化、真实回应、压缩无效交换”的基础。真正缺少的新增判断是：

1. **Posture-specific reader ruler**：当前技能要求读者理解优势，但没有要求先选择本场读者应追踪的单位：伏击的敌层/边界、弹药战的防御层、群战的角色网络、终局的行动顺序与解释权。

2. **Ambush opening 的知识分层**：当前没有明确区分“角色已知、读者已知、故意暂不解释但必须马上以物理结果兑现”的信息层。E01、M01、M07 显示，伏击首轮不能一开始讲完机制，也不能只给神秘感。

3. **有限资源的连续重定价**：当前提到资源会改变优势，但没有要求每次资源投入显式改变对手的防守层、位置、行动权限或撤退成本。M02、L04、L05 说明这比“消耗了多少”更可写、也更可判定。

4. **终局不等于击杀或撤退**：当前 stop rule 已覆盖胜负与目标得失，却没有处理“角色夺回目标选择权”或“制造不可消除的认知缺口”已构成终局的情形。L03、M07、L04 是补充证据。

5. **复杂动作的因果链预算**：当前说只展开优势变化，但未指定多段动作必须满足“前一动作改变后一动作适用条件”。M06 是最清楚的反例边界：没有这种链条的复杂招式应压缩。

# Candidate Transfer Rules

1. **伏击首轮：先给可计算危险，再揭示隐藏层。**
   - Applicability：角色进入存在掩体、路线、伏兵或预设空间的突发冲突。
   - Rule：首轮只建立方向、掩体、压制方式与一个可见后果；隐藏层仅在其改变真实目标、撤离边界或资源选择时揭示。
   - Stop rule：真实威胁与第一轮状态改变均已成立，即切入应对或反伏击。
   - Failure pattern：开场一次性讲完设伏机制，或只写神秘攻击却不给读者可追踪的危险。

2. **有限资源：每次投入必须迫使对手重定价。**
   - Applicability：箭矢、法器、体力、阵地、援军、时间窗等存在明显上限。
   - Rule：每次使用后，至少改变一项：防御层、距离、姿态、位置、撤退成本或下次资源选择。
   - Stop rule：资源已证明无法继续改写当前问题，或关键资源已换得明确窗口。
   - Failure pattern：连续报“又用一次”“再挡一次”，但敌我选择空间没有变化。

3. **强弱差：先指定读者能看到的胜负尺。**
   - Applicability：一方明显强于另一方，且结果不能由简单伤害数字说明。
   - Rule：开战前或首轮内确定一个具体尺：近身距离、阵地边界、防御层、目标优先级、队形或保护对象；后续动作围绕该尺改变。
   - Stop rule：该尺被彻底锁死、反转，或主问题已切换。
   - Failure pattern：反复说明“对方很强”，但读者看不出弱者到底还能争什么。

4. **复杂动作：只保留可见的因果接力。**
   - Applicability：连招、符法链、多人协作、阵法或高速多目标交锋。
   - Rule：每一步必须使下一步获得新的适用条件；中间没有改变资源、空间、知识或目标控制权的动作压缩为结果。
   - Stop rule：最后一击只要兑现此前建立的条件，即停止解释其余常规动作。
   - Failure pattern：招式很多、画面很满，但删掉任一步后胜负完全不变。

5. **终局反转：检查谁取得目标与解释权。**
   - Applicability：弱者无法正面击杀强者，或胜败已不再只是生死。
   - Rule：让行动改变“谁决定目标、顺序、代价或后续解释”；这一变化必须留下不可逆的身体、位置、资源或认知后果。
   - Stop rule：该不可逆后果已被对手和读者确认，不再额外补一轮假高潮。
   - Failure pattern：把反转写成突然出现的更强援军，或把未杀死对手误称为胜利。
