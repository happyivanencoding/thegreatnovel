# Cross-Window Findings

- **ruler 必须是可改变选择的判据，而非等级名称。** 吸收效率决定暂停还是硬撑；招式协调决定是否继续打磨；核心稳定决定能否跨境；侵蚀差异决定是否换结构。`[B-CY-02, B-CY-03, B-CY-04, B-CY-06, B-CY-10, B-CY-11]`
- **长期积累应作为当前临界动作的可验证前提回收。** 经络适应、半年纠偏、三年筛选、十七年沉淀、千年瓶颈、百年实验都被压缩；正文展开的是它们终于影响当下结果的那一拍。`[B-CY-01, B-CY-03, B-CY-06, B-CY-07, B-CY-10, B-CY-11, B-CY-14]`
- **瞬时跨越需要一个结构性变化，而不是“力量暴涨”说明。** 原著反复把变化放到丹田核心、刀势协调、元神离体、分身、内外双层结构、真实混洞或心灵存在上。`[B-CY-03, B-CY-04, B-CY-05, B-CY-06, B-CY-07, B-CY-10, B-CY-11, B-CY-13]`
- **突破后的行动空间应尽快落到旧问题的新增解法。** 追击与保护关系改变、出窍获得新感知、组织开放资源、分身并行、旧伤可被处理、终局目标终于可见，均比数值更能完成兑现。`[B-CY-04, B-CY-05, B-CY-06, B-CY-07, B-CY-13, B-CY-14]`
- **高阶成功通常只跨过当前门槛，并显露下一道更具体的责任或风险。** 封王接入战争计划；规则突破后紧接天劫；八劫生命仍要渡劫；终局成功仍要求实际执行终局行动。`[B-CY-06, B-CY-10, B-CY-11, B-CY-13, B-CY-14]`

# Counterexamples & Boundaries

- 不是所有“效率提升”都应写成突破。B-CY-02 中临时强化有效，却因消耗与伤害边界不可持续，正确结果是换目标、停止硬撑。
- 不是所有情感峰值都自动构成突破。B-CY-05 已说明此前多次同类绘画只有轻微变化；B-CY-08 的跨越还依赖长期技艺瓶颈与关键一刀。
- 不是所有新结构第一次尝试就成功。B-CY-10 中先剥离外层仍无效，之后才通过持续比较侵蚀差异改进；B-CY-12 的第一套自创法门可用，仍不等于最终契合。
- 不必强制把每次突破立即转成展示戏。B-CY-09 保持在画卷与心境主场景中，暂缓外部兑现；适用前提是该主场景本身仍有未完成的核心问题。
- 不能用突破抹除后果。B-CY-07 的分身受本尊与世界限制；B-CY-13 已跨生命层级，仍有天劫与消耗边界。

# What Existing Skill Misses

现有 `breakthrough_advancement` 已覆盖具体瓶颈、前置条件、阶段反馈、首次体验及行动范围变化；`comprehension_insight`、`training_learning`、`showcase_evaluation` 也已有相邻能力。新增贡献不应重复这些内容。

真正缺少的是跨场景判断：

- **积累因果追踪**：判断分散在非连续场景中的训练、理解、身体适应、资源或关系准备，分别满足了同一个突破 ruler 的哪一项；删去任一项是否会使本次跨越失效、延迟或改路。现有 Skill 未提供这条跨场景追踪协议。
- **同一读者尺子的跨阶段保持**：让同一可观察限制贯穿“积累前—临界点—突破后—下一次使用”，避免每场换一套测试，读者只得到抽象的“更强”。
- **突破后效的跨场景传播**：现有总库把 payoff/aftermath 仅列为 Utility 声明，且没有独立落地文件。需要判断新状态是否在下一场不同类型行动中改变目标、路线、关系、资源或风险，而非只完成一次展示。

这三项更适合作为跨场景 Utility/Curator 判断，不宜另起一个同义的“突破 Primary Skill”。

# Candidate Transfer Rules

- **规则：先建立可决策的突破 ruler。**
  - Applicability：当前突破依赖多项条件，且“继续练”未必正确。
  - Rule：在临界前让读者知道一个能决定继续、暂停或换法的具体判据；最终动作必须改变该判据。
  - Stop rule：判据已从“不可达/不稳定”变为“可达/稳定”，并完成一次现实验证即停。
  - Failure pattern：只报层级、年限或能量，不说明为什么人物现在应换法或敢跨。

- **规则：回收最少但必要的旧积累。**
  - Applicability：突破由跨场景积累支撑，而非单次偶然。
  - Rule：只回收直接改变本次成败的两三项旧条件；让它们在当前动作中承担不同功能，如承载、理解、控制或代价。
  - Stop rule：读者已能把旧积累和当前跨越连成因果链，不回放完整训练史。
  - Failure pattern：以“多年苦修”代替因果，或为补设定把突破场写成履历复盘。

- **规则：用同一尺子展示行动空间扩张。**
  - Applicability：数值无法自然呈现成长，且前后可比较的动作、感知、承载或控制限制存在。
  - Rule：突破前先让一个具体限制成立；突破后用同一限制的一次新解法，改变实际选择或他人判断。
  - Stop rule：一次可比较行动已经改变下一步，不再追加同强度展示。
  - Failure pattern：每场换新测试；读者知道人物更强，却不知道旧限制究竟被怎样解除。

- **规则：高阶跨越先比较旧结构，再允许重构。**
  - Applicability：旧方法无法解决持续压力，且人物拥有两个以上可比较的理解或资源。
  - Rule：先让旧结构在同一压力下暴露具体失效形态；重构只保留能解释该差异的部分，并保留可损失外层或新代价。
  - Stop rule：新结构已把当前威胁从不可处理降为可处理；未解决的更高问题转入下一场。
  - Failure pattern：危机中凭空得到完整答案，或把第一次可用方案写成永久终解。

- **规则：突破兑现必须进入后续问题。**
  - Applicability：突破预期会改变长期路线，而非只服务一次胜负。
  - Rule：在下一场不同类型事件中，至少让一个目标、资源、关系、权限或风险因新状态而改变，同时保留一个新门槛。
  - Stop rule：新状态已改变一次实际选择，不连续安排重复展示。
  - Failure pattern：突破停在体感或旁观惊叹；下一场人物仍按旧能力与旧路线行动。
