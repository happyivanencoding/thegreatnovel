# Cross-Window Findings

1. **笑点先要有可识别的欲望账本。** 吃夜宵、番茄鸡蛋、请客、收费、装备与“加钱”都不是随机贪嘴或嘴贫，而是角色想获得、赔付或守住的具体利益。没有账本，笑点会变成可替换台词。
   Evidence：DW-C02、DW-C03、DW-C06、DW-C07、DW-C11。

2. **有效 callback 不是重复句子，而是旧模式在新权力关系中被重新定价。** “你变了”索取照料，“手表”变为团体识别码，“计划没成过”刺破战时自夸，剑灵旧账解除师徒防御。
   Evidence：DW-C01、DW-C05、DW-C12、DW-C15。

3. **社会反馈必须改变现实行动空间，才值得展开。** 旁观者的惊愕、恐惧或站队，分别改变了买卖、结交、执法和声望价格；只是“大家都笑了”不构成足够反馈。
   Evidence：DW-C05、DW-C06、DW-C08、DW-C13。

4. **喜剧可攻击面子，不能撤销已成立的真正成果。** 黑猪仍被毁、魂魄仍有用；武卫军的情报优势仍成立；战力、交易和情感真相都先落地，笑点才可出现。
   Evidence：DW-C02、DW-C11、DW-C12、DW-C14。

5. **重大 payoff 后，喜剧最好落回已建立的生活关系，而非解释或讽刺 payoff 本身。** 夜宵、火锅、做饭把能力、身份和生死压力重新接回人物怎样共同生活。
   Evidence：DW-C03、DW-C08、DW-C14；反证边界：DW-C16。

6. **紧张场景可以有一拍喜剧，但笑后必须由行动或新信息重新锁住威胁。**
   Evidence：DW-C10、DW-C11、DW-C16。

# Counterexamples & Boundaries

- **不是每个强反差都应展开。** DW-C16 的战争只允许杀敌间隙的一句玩笑；若继续追梗，会吞掉疲劳、伤亡和守城的真实 payoff。
- **不是每个关系玩笑都可由任何人说。** DW-C12、DW-C13 显示，吕小鱼和核心同伴有拆吕树台的关系权利；外人起哄则会触发保护与反击。
- **不是每个“贪财”表达都可连续复用。** DW-C11 的“加钱”有效，是因其后接真实高风险承诺与同袍装备目标；脱离代价只会把人物压扁成口癖。
- **不是先抛梗再补风险。** DW-C10 先给危险前态，笑点后立即识别敌人并撤离；如果威胁尚未建立，读者只会读成轻浮。
- **不是所有情感重场都需要笑。** DW-C14 先完成身份焦虑与承诺；DW-C16 则几乎不提供情绪性缓冲，因为即时战况不允许。

# What Existing Skill Misses

当前 `comedy_banter` 已正确要求“笑点来自人物”“同梗第三次无新变化就压缩”“重大风险不能失去后果”。本组证据新增的不是同义重述，而是以下可判断能力：

1. **欲望结算识别**：判断一句话是不是绑定了可兑现的资源、赔偿、照料、身份或行动机会；否则不应被当作 Scene Engine。
2. **callback 升级判定**：不只问“关系有无变化”，还问旧模式是否被新权力、内幕、社会价格或责任反转。
3. **三层反馈建模**：区分发起者、被戏弄者、旁观群体；旁观反馈必须改变交易、信誉、执法或下一步选择。
4. **payoff 保护顺序**：先确认结果已经由动作/证据成立，再允许笑点结算；不允许喜剧提前撤销危险、牺牲或信息。
5. **关系权限判断**：谁能拆台、谁只能被拒绝，不取决于台词锋利度，而取决于既有共同生活、责任和互保。
6. **严肃场景的换气阈值**：当损耗仍在增长时，只给一拍笑点与一个反应，随后必须返回任务动作。

# Candidate Transfer Rules

1. **欲望落地规则**
   - Applicability：角色的戏谑涉及吃、钱、资源、赔偿、身份、照料或行动机会。
   - Rule：先写清角色要什么、为此付什么，再让话语把该交易扭转或结算。
   - Stop rule：利益/承诺完成一次可见交换后停止，不再追加第二层解释。
   - Failure pattern：只留下“他很爱钱/她很会抬杠”的标签，场景没有任何状态变化。

2. **callback 升级规则**
   - Applicability：已有可识别的旧习惯、称谓、承诺或失败记录。
   - Rule：仅在新窗口增加了权力差、信息差、社会定价或关系责任时回收。
   - Stop rule：新价格被一个具体反应证明后退出。
   - Failure pattern：重复同一句、重复同一反应、重复同一输赢，形成口癖。

3. **社会反馈转化规则**
   - Applicability：场内存在会影响角色名望、交易、规则执行或行动空间的第三方。
   - Rule：让第三方的误读/震动/站队改变一项现实后果，而不只提供笑声。
   - Stop rule：价格、权限或下一步路线已经改变后停止群像反应。
   - Failure pattern：围观者集体“震惊”，但下一章一切照旧。

4. **payoff 优先规则**
   - Applicability：能力突破、谈判成交、身份揭示、救援、重大关系确认之后。
   - Rule：先完成结果、证据或代价，再用一拍生活化/关系化笑点让人物消化它。
   - Stop rule：笑点完成换气后，立刻回到新状态的实际用途。
   - Failure pattern：笑话把损失变假、把承诺变轻、把读者刚获得的信息悬空。

5. **关系权限规则**
   - Applicability：一人要拆另一人的台、占便宜或改写其自我叙述。
   - Rule：只有已有共同承担、照料、互保或长期旧账的角色，才能进行高强度拆台；外人只能停在试探、交易或礼貌边界。
   - Stop rule：被拆者的面子或关系位置完成一次变化即停。
   - Failure pattern：所有配角都拥有同样的网络机灵，人物关系失去层次。

6. **危机换气规则**
