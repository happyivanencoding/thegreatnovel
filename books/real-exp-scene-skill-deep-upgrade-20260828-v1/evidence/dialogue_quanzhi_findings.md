# Cross-Window Findings

1. 专业角色声音主要由“他把什么当作判断对象”构成，而不是话多或话少。喻文州看时间线与可利用信息，黄少天看操作与可乘之机，张新杰看职责和风险，叶修看对方是否交出关键变量。`E-early-03`、`E-mid-05`、`E-late-03`、`E-late-06`

2. 专业信息进入对白时，最有效的载体不是解释，而是一个未决问题：配置能否执行、概率是否可承受、对手到底知道什么、下一位该谁上。答案必须改变配置、搜索、命令、选人或信息边界。`E-early-02`、`E-mid-02`、`E-mid-04`、`E-mid-06`、`E-late-06`

3. 熟人互损只有在它指定了靶子、迫使选择或产生即时后果时才保留；否则文本会压缩或不用。`E-early-05`、`E-early-06`、`E-late-01`、`E-late-02`、`E-late-04`

4. 群体场景不靠全员轮流发言。稳定结构是：提出者／质疑者／执行者／裁决者，加上少数能把现场温度翻译给读者的反应者。`E-early-03`、`E-mid-03`、`E-late-03`

5. 极短命令只能建立在共享上下文已经存在时；它的含义应由执行、结果和对手反应完成，而非追加解释。`E-early-02`、`E-mid-06`、`E-late-06`

# Counterexamples & Boundaries

- 第一千六百三十六章《复盘》100203–100223：正式复盘的目标是共享已知比赛资料，原文将大量讨论概述处理，而不强行逐轮戏剧化；此时应压缩会议，不套“每人一句个性化反应”。
- 第一千二百六十章《强制平局》73674–73718：竞争张力主要由重复操作、规则和裁判中止产生，几乎不需人物对白；竞争场景不必强加调侃。
- 第六百五十一章《轮回的配合》39227–39245：有辨识度的垃圾话，但真正改变战局的是无声配合；对白若未改写选择、关系或战局，应降为背景。
- 第二十五章 1136–1167：生活化互损鲜明，却缺乏群体竞争状态变化，排除。
- 第四百一十至四百一十一章 24284–24397：主要是单人展示与观看，不足以支撑“群体专业对白”结论，排除。

# What Existing Skill Misses

当前 `comedy_banter` 已要求笑点来自关系错位，`social_bargain_decision` 已要求对白改变条件，`trial_challenge` 与 `showcase_evaluation` 已强调真实反馈。新增的、非近义重复的判断能力是：

- 区分“角色的判断对象”：同一句专业信息，谁看风险、谁看职责、谁看可利用性，决定其声音，而不是为每人分配不同口癖。
- 区分三种拒答：保密防守、拒绝媒体预设、把问题转交给真正责任人；它们会分别改变信息边界、采访路径与群体关系。
- 把专业信息限定为“可执行的不确定性”：概率、时间、站位、资源、已知／未知技能，必须在同一场景里引起命令、选人、路线或赌约变化。
- 为多人对白加入“反应拓扑”：不是人人解释，而是由提案、审查、执行、裁决、旁观这几种位置组成。
- 把赛后专业性理解为“失败后优先处理什么”，而不是统一要求安慰或统一要求冷酷。

# Candidate Transfer Rules

1. **竞争评估对白**
   - Applicability：角色需要判断陌生对手、配置、技术或情报价值。
   - Rule：让不同角色各自处理同一证据的一部分；至少保留一项反驳、概率边界或未知项。
   - Stop rule：判断已导致配置、观察任务、交易条件或下一动作变化。
   - Failure pattern：所有人依次补充正确知识，变成会议纪要。

2. **带代价的拒答**
   - Applicability：公开采访、赛前试探、招募审查、对手索取敏感信息。
   - Rule：拒绝必须指向一个明确变量，并让提问者改问法、改策略或带着不确定性行动。
   - Stop rule：信息边界已清楚，场景转入行动。
   - Failure pattern：角色只卖关子，问题和风险均未改变。

3. **靶向互损**
   - Applicability：熟人、宿敌或已有共同经历的竞争关系。
   - Rule：调侃必须选定具体靶子：面子、责任、旧错、站位或当前选择。
   - Stop rule：靶子已作出反应、让步、反击或被迫行动。
   - Failure pattern：所有角色使用同一种机灵话，笑点不改变场面。

4. **共享术语的短命令**
   - Applicability：队伍已建立共同训练、默契或明确任务语境。
   - Rule：命令保持最短；把完整含义留给队员执行与结果补足。
   - Stop rule：命令的真实用途已通过结果或对手反应被读者看见。
   - Failure pattern：未建立上下文就使用黑话，让读者只能等旁白翻译。

5. **败局后的可执行信息**
   - Applicability：高压竞争中出现失败、受伤、资源损失或临场意外。
   - Rule：先抛出一项能改变下一步的数据，再落到选人、路线、资源或风险控制。
   - Stop rule：下一动作已确定。
   - Failure pattern：用空泛鼓励覆盖失败，或反过来把人物写成无情报、无情绪的机器。

6. **群体决策的最小反应拓扑**
   - Applicability：三人以上围绕同一竞争决定互动。
   - Rule：只保留会改变尺度的人：提案者、判断者、执行者、裁决者；旁观者只在其反应改变现场温度时出现。
   - Stop rule：权力归属与可执行决定明确。
   - Failure pattern：轮流报观点，没人真正承担决定。
