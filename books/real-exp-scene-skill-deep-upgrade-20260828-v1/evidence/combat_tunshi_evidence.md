# Research Question

大尺度力量差、怪兽/多人战、突破后的 dominance 与公开强弱证明，如何：

- 用可感知的 ruler 压缩尺度；
- 让多招式、多装备服从战斗因果而非目录化；
- 在突破后迅速、可信地完成新层级证明。

# Evidence Windows

- **CT-01**
  - **章节 / 行号：**第四篇《生命涅槃》十六章《炸！炸！炸！》—十七章《天崩地裂》，20843–21143。
  - **场景姿态 / 目标：**全球灾变下的远程试探；用人类最高常规军事资源确认怪兽是否仍可被杀。
  - **前态：**吞噬兽已毁战争基地；小当量攻击无效，人类只能把一枚大当量武器混入十九架战机。
  - **展开拍点：**先用“黑夜小太阳”与怪兽毫发无伤建立第一 ruler；连续爆炸压缩为重复试探；最后才落到全世界盯住同一架战机、倒计时、白屏与蘑菇云。
  - **压缩 / 省略：**不逐架写十九次攻击，而以“第几架”“同类爆炸”“观测者压力”推进。
  - **状态改变交换：**普通核爆从威胁降为怪兽的轻微刺激；终极武器把“必败”改成“尚可能杀死”的悬置。
  - **敌方 / 他人反应：**怪兽把前几次爆炸当刺激；各国高层、武者、平民分别通过卫星、手表、夜空承受同一结果。
  - **身体 / 空间 / 细节选择：**怪兽腹部与战机的贴近碰撞；远方夜空的“太阳”；通信大面积中断。
  - **ruler / 读者模型：**不是报当量，而是“炸毁城市的东西只像一阵风”→“远方国家也看见太阳”。
  - **停点：**白屏后等待结果，不在爆炸当下解释全部后果。
  - **Evidence：**大尺度靠“既有极限失效”先立尺，再用一处全民可见的现象收束。
  - **Interpretation：**适用于先要证明敌我不在同一尺度、结果仍未揭晓的灾变战。
  - **反推限制：**不能据此推出每场大招都需要全球观众；这里的全球观看来自灭绝级公共风险。

- **CT-02**
  - **章节 / 行号：**第四篇《生命涅槃》二十六章《“B6级”镭射炮》，21886–21984。
  - **场景姿态 / 目标：**公开评估戏；把一件新武器从“主角声称有办法”变成可共同理解的希望。
  - **前态：**洪、雷神已准备拼死；最高层对罗峰的把握既急切又怀疑。
  - **展开拍点：**罗峰公开承诺；专家要求说明武器；专家用既有 A/B 分级及“可杀何级生命”翻译其意义；随即补上一击机会的限制。
  - **压缩 / 省略：**不演示武器装配过程，不罗列技术参数。
  - **状态改变交换：**会议从“准备牺牲”变成“部署唯一窗口”。
  - **敌方 / 他人反应：**旁观者先失语、追问，理解 ruler 后失态欢呼；洪马上把情绪拉回一次性失败风险。
  - **身体 / 空间 / 细节选择：**封闭会议室、集体注视、老人哭笑；没有直接切回怪兽。
  - **ruler / 读者模型：**旧地球镭射炮→宇宙 A/B 级→目标怪兽所处层级。
  - **停点：**“只有一次机会”成立即停，转入执行。
  - **Evidence：**公开证明可由立场不同的解释者完成，关键是解释改变在场人的下一步。
  - **Interpretation：**适用于新成果尚未实战、但必须立刻改变团队决策的场景。
  - **反推限制：**这不是实力实证；文本明确保留“一炮未必成功”的失败条件。

- **CT-03**
  - **章节 / 行号：**第五篇《宇宙冒险者》五十三章《大海喋血》—五十五章《金角巨兽的最强绝招》，28530–28869。
  - **场景姿态 / 目标：**怪兽对多人围捕的 dominance 证明。
  - **前态：**对方先以人数、等级、编队和活捉目标判断胜券在握；金角巨兽已清掉低阶队员，但十五名高阶者仍在围攻。
  - **展开拍点：**先让多人合击确实伤到怪兽，防止假压制；怪兽进入强化后仍不急于报招；一件残片作为唯一关键杀手段切掉三名队长；其余十二人刚转身便被连续穿杀。
  - **压缩 / 省略：**爪、翼、尾的前段屠杀以功能组压缩；终局不逐个写十二人死亡。
  - **状态改变交换：**“可被围住、可活捉”变成“指挥中枢瞬断，逃跑也不成立”。
  - **敌方 / 他人反应：**现场由兴奋转为逃亡；远端家族先等捷报，后以所有人拒绝回应确认全灭。
  - **身体 / 空间 / 细节选择：**海底、山脉般躯体、蹄爪伤口；只保留一次真正决定胜负的小型兵器。
  - **ruler / 读者模型：**先承认十五人合击能伤它，再用“三名队长同拍死亡、十二人逃不掉”完成等级反转。
  - **停点：**全灭与远端失联成立后停止，不继续清点尸体。
  - **Evidence：**多人战的力量差不能只靠“怪兽很大”；要先给强者团队一次有效动作，再夺走其队形、指挥和逃路。
  - **Interpretation：**适用于一方需要被写成压倒性捕食者的场景。
  - **反推限制：**该场的公开反馈是敌方远端推断，不是现场社会评价；不能把它当作公开身份扬名模板。

- **CT-04**
  - **章节 / 行号：**第八篇《雨相山》二十六章《罗峰的刀》，43000–43102。
  - **场景姿态 / 目标：**小尺度 showcase；证明长期修炼已跨过同侪标准。
  - **前态：**罗峰十年未闯桥，外界只知道他没有公开成绩。
  - **展开拍点：**选择非惯用的近战对手；第一刀就使对手下跪后退；中段多式刀法作为持续压制；最后用一招贴身终结；强者据“非主修路径也过关”重估他。
  - **压缩 / 省略：**多种刀式不逐一讲原理，只保留它们让对手无法恢复主动权的事实。
  - **状态改变交换：**从“掌控者的未知近战能力”变为“近战也达到同届强者线”。
  - **敌方 / 他人反应：**对手从硬接到谨慎；观察者改变对其职业边界的判断。
  - **身体 / 空间 / 细节选择：**狭窄桥面、单膝、滑退、两米内的终结距离。
  - **ruler / 读者模型：**不用大数字，用“本不该擅长的路径也过第二层”。
  - **停点：**过关和评估者反应成立后，立即转向下一层。
  - **Evidence：**力量证明可以用“违背既有分类预期”作 ruler。
  - **Interpretation：**适用于读者已知人物标签、此次证明正好打破该标签时。
  - **反推限制：**这里不需要大空间或群众反应；场景目标是评估，不是灾难展示。

- **CT-05**
  - **章节 / 行号：**第八篇《雨相山》二十七章《边打边学》—二十八章《大巧不工》，43103–43289。
  - **场景姿态 / 目标：**以战斗作学习场；展示“看懂对方优势”而非机械加招。
  - **前态：**双方都能组成同阶攻击，但对手的结构更紧、更有变化，罗峰正面攻击落下风。
  - **展开拍点：**罗峰先用身法保住存活与观察窗口；对手逼他停止躲避；强者旁观者直接说出身法为何有效；罗峰从对方的组合方式抽出差异，再把躲避转为终结。
  - **压缩 / 省略：**连续闪避不逐拍展开，只保留“躲得开”与“从中读出什么”的两个转折。
  - **状态改变交换：**劣势不是被强行反转，而是被转换为可读的样本。
  - **敌方 / 他人反应：**对手因打不中而急躁；旁观者能辨认真正进步并提供读者校尺。
  - **身体 / 空间 / 细节选择：**千米桥域、百道幻身、两股剑域的结构差。
  - **ruler / 读者模型：**读者只需记住“攻击输、移动赢、看懂后才收招”。
  - **停点：**学习成果已转为胜负改变时停；不把后续每次练习再演一遍。
  - **Evidence：**招式数量可存在，但每一组只承担一个差异：压制、闪避、识别、兑现。
  - **Interpretation：**适用于战斗的主要阅读问题是“他能否读懂并跨过机制差”。
  - **反推限制：**不能把所有受压都写成学习；若人物拿不到观察窗口，持续挨打不会自然产生领悟。

- **CT-06**
  - **章节 / 行号：**第九篇《宇宙秘境》六十章《罗峰战界主》—六十一章《去死吧！》，49792–49969。
  - **场景姿态 / 目标：**越大阶挑战；证明新层级的真实胜率。
  - **前态：**域主九阶挑战界主四、五阶，纯力量相差数十倍，对方还能展开一方世界。
  - **展开拍点：**敌方先以山崩石流展示纯力差；罗峰用“石头飞得慢”把比较缩到速度；敌方缩小攻击范围以提升效率；罗峰承伤后用身体形态变化越过盾牌与常识，击破命核。
  - **压缩 / 省略：**两条能量龙的往复追击只保留“广域无效→缩圈有效→近身反被利用”。
  - **状态改变交换：**对手从世界压制、逼其受伤，转为无法理解最后一击如何发生。
  - **敌方 / 他人反应：**先震惊其速度和幻身，再把策略改为缩圈；死亡前仍困于旧身体规则。
  - **身体 / 空间 / 细节选择：**山峰被碎石夷平、数千里世界投影、断臂延伸的近身刀。
  - **ruler / 读者模型：**“数十倍力量差”只出现一次，随后用敌方改变策略、世界崩散来证明它被跨越。
  - **停点：**命核破碎、世界消失即止。
  - **Evidence：**大力量差的可感知 ruler 可以是“敌人优势已被充分使用却仍无法把胜势转成击杀”。
  - **Interpretation：**适用于主角拥有已建立的非常规身体/机制，能具体绕过敌方默认防御模型。
  - **反推限制：**不能把它泛化为“突破后必能越级”；本场胜因包含先前建立的特殊生命形态。

- **CT-07**
  - **章节 / 行号：**第十五篇《刀河王》六十四章《激战》—六十八章《刀光成河》，79137–79592。
  - **场景姿态 / 目标：**多人围杀反转为公开立威。
  - **前态：**敌方以三名强者为核心，认为罗峰只靠外物；后续又有两百余名封王聚集。
  - **展开拍点：**近两百万虫族先作为一次“打草惊蛇”的威胁；敌方因此叫来更强援军；罗峰以空间封锁取消撤退选项；两枚高代价爆发物迫使三人同时崩盘；追杀一名残损强者；再用少数实际击杀让十八人队伍溃逃，最后以剩余威慑离场。
  - **压缩 / 省略：**虫群、兵器、毒液都不独立介绍；只在其改变“探测—锁人—破甲—封逃—震慑”的功能时出现。
  - **状态改变交换：**敌方“围住一名人类”变为“无人敢阻止其离场”。
  - **敌方 / 他人反应：**三名核心敌人先贪婪后恐惧；新到者因没看见前因而误判，再被单次真实死亡纠正。
  - **身体 / 空间 / 细节选择：**千万公里虚无区、受损神体、羽翼速度、一个被追上的目标。
  - **ruler / 读者模型：**规模只用三层：两百万合击是威胁、三名核心是局部赌局、两百旁观者的行为改变是公开定价。
  - **停点：**“震慑已足够、继续会引来更高层风险”后撤离。
  - **Evidence：**装备多时，读者应记住的是因果链，不是名称清单。
  - **Interpretation：**适用于角色需要用有限底牌把围杀转成名望/威慑，但不能长期无代价清场。
  - **反推限制：**文本明确底牌有限且会招来更强敌；不能把“全杀”当作此类场景的默认兑现。

- **CT-08**
  - **章节 / 行号：**第二十一篇《宇宙尊者》二十五章《战宇宙之主》—二十八章《你是宇宙之主》，101687–102019。
  - **场景姿态 / 目标：**成名之战；将个人突破转换成敌对阵营不可回避的公开事实。
  - **前态：**敌方先以幻术、灵魂攻击、领域压制和宇宙之主正面战占优；大量尊者进入围困区。
  - **展开拍点：**罗峰先承受压制，保留真正大招；微型宇宙展开后，叙述从近身战切到天空、范围内人群、外部宇宙之主的误判；六千余尊者被一次碾压；同一力量再把原先压制他的主敌打退。
  - **压缩 / 省略：**正面多轮碰撞被压缩，重点留给“为何等待”“谁已进入范围”“九秒时限”。
  - **状态改变交换：**从被围剿对象变成能让三大联盟付出无法忽略代价的存在。
  - **敌方 / 他人反应：**外部强者先误认大招来源，内部主敌由威胁转为急于谈判、阻止屠杀。
  - **身体 / 空间 / 细节选择：**天地变黑、混沌气流、百亿公里微型宇宙、少量领袖的即时判断。
  - **ruler / 读者模型：**“六千余人”不是背景数字，而是“围困者数量→一次压平→复活代价”的连续社会后果。
  - **停点：**九秒结束、主敌无法留人，主角撤出。
  - **Evidence：**大规模 dominance 需要把“范围、时限、谁在范围内、结果改变什么”锁在同一条链里。
  - **Interpretation：**适用于主角的目标本身就是公开改写敌对阵营对其风险定价。
  - **反推限制：**不适用于普通清怪；这里的群体进入范围、敌对积累和政治后果都被长期铺垫。

- **CT-09**
  - **章节 / 行号：**第二十三篇《初入宇宙海》十二章《围殴！》，106315–106409。
  - **场景姿态 / 目标：**二打一的局部压制；展示多层手段如何不目录化。
  - **前态：**敌人原本在领域内占优，罗峰另有未暴露的分身与环境控制。
  - **展开拍点：**隐藏战力先刺掉对方一半神体；罗峰把环境控制、微型宇宙、两路攻击叠成同一压制结构；敌人只能挡住其中一路；九秒时限结束后敌人逃离。
  - **压缩 / 省略：**不分别讲每个至宝的完整说明，只写其让谁变慢、谁能靠近、谁必须防守。
  - **状态改变交换：**敌人由主动追杀者变为被两路攻击逼退的对象。
  - **敌方 / 他人反应：**敌人承认一对一已难占优，事后转为散播消息、制造长期报复。
  - **身体 / 空间 / 细节选择：**水域、两道龙卷加持两把武器、九秒后压力消散。
  - **ruler / 读者模型：**不是“有三层宝物”，而是“他只能挡 A，于是必吃 B”。
  - **停点：**敌人成功逃走即停，保留后续仇怨。
  - **Evidence：**多人/多装备战的最小单位是“一个对手选择被另一动作惩罚”。
  - **Interpretation：**适用于需要展示组合优势、但不应让胜利显得没有反抗的场景。
  - **反推限制：**不能把所有手段都叠成必杀；本窗口刻意保留敌人逃离，且其后果仍在增长。

- **CT-10**
  - **章节 / 行号：**第二十三篇《初入宇宙海》十三章《玩具》—十四章《滚开》，106410–106608。
  - **场景姿态 / 目标：**反例：极大力量尺度的 awe / exploration，不是 dominance。
  - **前态：**罗峰带着已极强的塔形至宝进入未知风暴区，目标是接近光翼。
  - **展开拍点：**先让至强至宝被风暴当作“玩具”抛飞；用单道冲击与既有最强者攻击的差距立尺；主角靠缩小体积减少受击频率，才取得有限移动权。
  - **压缩 / 省略：**不逐道描写风暴；只重复“失控”“缩小后能前进”这两个状态。
  - **状态改变交换：**不是从弱变强，而是从无控制变为勉强可接近目标。
  - **敌方 / 他人反应：**没有人格敌手和社会评价，主要是主角对环境的震撼。
  - **身体 / 空间 / 细节选择：**数光年空间、微尘般的塔、巨型刀刃风暴。
  - **ruler / 读者模型：**“原本最强的防护被踢成球”比继续报攻击倍数更直接。
  - **停点：**能稳定接近光翼后停，转入新的未知。
  - **Evidence：**同样是大尺度，若人物没有控制权，尺应服务于 awe 与生存，不应伪装成爽点证明。
  - **Interpretation：**适用于遗迹、天灾、禁地等“角色很强但仍不够”的场景。
  - **反推限制：**不能借此宣称主角已压过环境；文本明确他只是靠缩小规避部分碰撞。

- **CT-11**
  - **章节 / 行号：**第二十八篇《宇宙最强者》十六章《战》—十七章《围攻界兽》，128539–128694。
  - **场景姿态 / 目标：**反例：多人对怪兽并不自动形成群体 dominance。
  - **前态：**八名真神先观望；火虫真主被迫当先锋，初步交手后众人误判界兽只略强。
  - **展开拍点：**先锋先试出“交手可减缓吞噬”；其余人按远攻、束缚、近战、灵魂攻击投入；界兽受伤后暴露更强灵魂冲击，并把攻击焦点转向最脆弱、最有动机的先锋。
  - **压缩 / 省略：**八人具体兵器不逐件展开，只保留每类动作与其造成的敌方反应。
  - **状态改变交换：**“八人合围似乎占优”变为“敌人尚有未揭示的反制层”。
  - **敌方 / 他人反应：**众人由谨慎转为松气；界兽从受压转为选择性打断队伍。
  - **身体 / 空间 / 细节选择：**封锁虚空、先手先锋、八人环绕、一名强者留在外围观察。
  - **ruler / 读者模型：**人数只说明战术分工，真正 ruler 是“能否迫使敌人停止吞噬、能否承受其反制”。
  - **停点：**章节在界兽锁定先锋处切断，不伪造后续胜负。
  - **Evidence：**多人战需要保留敌方的应对权；合围不是结论。
  - **Interpretation：**适用于首轮试探或强敌能力尚未完全揭示的团战。
  - **反推限制：**本窗口不能支持“八人已经赢了”；原文在反制启动处截断。

- **CT-12**
  - **章节 / 行号：**第二十八篇《宇宙最强者》三十八章《突破，连锁反应，传说》—三十九章《真神》，130419–130586。
  - **场景姿态 / 目标：**突破后的宇宙级公开证明。
  - **前态：**罗峰已接近极限，私下比对两类生命结构，尚未完成新层级。
  - **展开拍点：**先从手掌的一处结构改变开始；局部变化触发全身连锁；金光越过物质、时间和空间；不同阶层、不同阵营从普通人到真神都只能以跪伏回应；之后才确认“十万倍”这一结果。
  - **压缩 / 省略：**内部结构推演被压缩为“发现共通点—一点脱离—连锁”；不展开十万单位的变化细节。
  - **状态改变交换：**私人悟解变成整个原始宇宙都无法忽略的生命层级事件。
  - **敌方 / 他人反应：**不是换词惊叹，而是共同、非自愿的生命本能反应；随后各族把它重估为对界兽浩劫的希望。
  - **身体 / 空间 / 细节选择：**手掌第一点金光、全身蜕变、无数地点的同一反应。
  - **ruler / 读者模型：**局部可见变化→跨宇宙不可阻挡的外溢→最高位真神也受影响。
  - **停点：**突破事实、最高比较基准和社会含义都成立后转入后果。
  - **Evidence：**突破证明可先给最小身体锚点，再给一个不可被更高层忽略的外部后果。
  - **Interpretation：**适用于世界规则允许“突破天然外显”的高潮。
  - **反推限制：**不能照搬“全世界跪伏”；该效果依赖本书已建立的至高规则与生命路线。

- **CT-13**
  - **章节 / 行号：**第二十八篇《宇宙最强者》四十五章《摩罗撒最后的癫狂》—四十七章《镇压》，131061–131348。
  - **场景姿态 / 目标：**突破后的即时 dominance；以同一难题的旧失败作尺。
  - **前态：**界兽反复逃逸，多名真神只能驱赶，无法真正困住；它还在吞噬关键本源。
  - **展开拍点：**罗峰赶到后不再铺开战斗；直接放出塔形至宝；界兽尝试血光挣脱仍被吸入；旁观者以“此前困不住、现在随手镇压”完成比较；塔内再以三重压制剥夺界兽自爆资格。
  - **压缩 / 省略：**赶路、旧战场追逐、围观者移动都被压缩，焦点只有“逃不掉”。
  - **状态改变交换：**界兽从能令全体真神疲于驱赶，变为不能逃、不能自爆、只能被审问。
  - **敌方 / 他人反应：**界兽不信自身会被一件塔单独吸走；真神们先被镇住，后用既往失败反衬新层级。
  - **身体 / 空间 / 细节选择：**数光年黑暗漩涡、塔底、三重压制、敌方欲自爆而不可得。
  - **ruler / 读者模型：**不另造新数值，直接复用同一头怪兽此前让多名强者无解这一事实。
  - **停点：**“逃、自爆、行动”三项自由都被剥夺后，dominance 已完成；后续审讯另起场。
  - **Evidence：**突破后最快的强度证明，是让读者已知的旧难题失去原有解法。
  - **Interpretation：**适用于已有共同基准、突破后需要立即兑现而非重开测试的场景。
  - **反推限制：**文本明确这依赖星辰塔和小型宇宙本源；不能抽象为角色在任意地点都能阻止同级敌人自爆。

# Cross-Window Findings

1. **大尺度先给“旧极限失效”，再给一条可感知后果链。**
   先让核爆、至强至宝、多人合击或既有高阶强者失效，再落到夜空、身体受控、队形断裂、公开策略转向。数字只在建立比较时出现一次。
   证据：CT-01、CT-03、CT-10、CT-13。

2. **装备与招式不该按“拥有物”排列，而应按“敌方选择被怎样封死”排列。**
   一个手段若没有改变探测、封逃、破防、逼挡、限制自爆或撤离，就应压缩；多个手段只有形成连续因果时才值得展开。
   证据：CT-03、CT-07、CT-09、CT-13。

3. **dominance 的可信证明不是连续秒杀，而是逐层剥夺对方的可行选项。**
   先让对方能伤、能挡、能逃或能依赖规则；再明确这些选项分别何时失效。
   证据：CT-03、CT-06、CT-07、CT-13。

4. **公开强弱证明要落到他人的决策或行动空间，而非重复感叹。**
   会议从赴死转为部署、围杀者转为停手、三大联盟从追杀转为计算代价、各族从不明转为调整预期，才算公开定价完成。
   证据：CT-02、CT-07、CT-08、CT-12。

5. **团战的人数只能是压力，不是胜负。**
   人多时应至少区分先锋、控制、远攻、观察或逃生职责；强敌仍须有可验证的反制层。
   证据：CT-03、CT-09、CT-11；反证边界：CT-10。

# Counterexamples & Boundaries

- **不是所有大场面都该写成 dominance。**CT-10 的核心是“至强者仍被环境摆布”，应服务于 awe、探索和生存；若强行加入旁观者服从或社会定价，会误写场景问题。
- **不是所有公开解释都等于实证。**CT-02 只证明武器的理论可行性，文本保留一击失败风险；真正兑现必须另有实战。
- **不是所有团战都能直接收束。**CT-11 中八人暂时形成压制，但怪兽立即展示更高反制，章节切断前不能宣称胜负。
- **不是所有突破都需全域异象。**CT-12 的外显来自本书宇宙规则；一般作品可用一项已知限制被越过、一个权威对象改变判断来替代。
- **资源型碾压必须有边界。**CT-07 明示高代价底牌有限，且继续屠杀会引来更高层反噬；“杀光所有人”不是可迁移的默认终点。

# What Existing Skill Misses

当前 `combat` 已要求动作改变优势、团队战体现分工；`showcase_evaluation` 已要求比较基准和现实后果；`breakthrough_advancement` 已要求突破后的首次真实体验。真正新增、且不与现有表述近义重复的判断能力是：

1. **ruler 链选择：**当尺度过大时，优先选“旧极限失效 → 一处具身/空间后果 → 行动后果”，而不是继续叠数字。现有技能要求“有比较”，但未给出何时用失败基准、何时用旁观行为、何时用环境可见后果的排序判断。

2. **能力束的因果折叠：**多装备/多招式出现的合法单位不是“一项能力”，而是“迫使敌方放弃一个选项的链”。这能直接识别目录化：删去某手段后，若敌方可做选择不变，就应压缩。

3. **dominance 的三次验证：**强度兑现至少应选取敌方一个已展示的有效选项，再使其失效；若还要公开证明，则补一位能依据旧标准行动的观察者。它比“敌人震惊”更可检验。

4. **突破外显与突破实证的区分：**世界异象、身体蜕变、社会重估是三种不同层面的证据，不能互相代替。异象只在作品规则已授权时可当实证；否则仍需新状态首次改变一个具体难题。

5. **团战的反证明检查：**人数增多后，先问“每个组是否改变同一个强敌的不同选择”；若否，群体只是背景。CT-11 说明不能因人数多就提前写胜负。

# Candidate Transfer Rules

1. **失效 ruler 链**
   - **Applicability：**敌我差距大到常规数值无法让读者感受，且世界已有一个公认强度基准。
   - **Rule：**先让该基准失败，再选一个身体、空间或公共观察后果承接，不追加第三套同义数字。
   - **Stop rule：**读者已能回答“旧极限为什么不够、失败改变了谁的选择”即停。
   - **Failure pattern：**连续报半径、倍数、当量，读者知道很大却不知道人物为什么绝望或改策。

2. **因果型能力束**
   - **Applicability：**角色同时使用三项以上招式、装备、队友能力或环境权限。
   - **Rule：**每项只以其造成的选择变化出现：发现、封路、破防、逼挡、限制、收束；同功能的第二项压缩。
   - **Stop rule：**敌方最后一个可行回应已被写清，或战斗转为新问题。
   - **Failure pattern：**按获得顺序报技能、按名称逐个发招，删掉一半也不影响胜负。

3. **已展示选项失效**
   - **Applicability：**需要迅速证明突破后 dominance，且对手/环境已在当前或前文展示过有效规则。
   - **Rule：**先让旧规则再运行一次，再用新状态使它失败；优先剥夺逃、挡、反击、复原中的一项。
   - **Stop rule：**一个旧难题已在新状态下无效，并产生可见后果，即转出。
   - **Failure pattern：**突破后只报新数值，敌人从第一拍就不反应，读者无法知道新层级具体越过了什么。

4. **公开证明的行为落点**
   - **Applicability：**场景目标包含地位变化、威慑、资格、战争决策或群体态度重估。
   - **Rule：**选一名有明确立场的观察者，让其以撤退、下令、改价、求援、停止攻击或改目标完成判断。
   - **Stop rule：**一项现实关系/行动空间已改变；不再追加同义赞叹。
   - **Failure pattern：**多人依次说“很强”，但没有人做任何不同的事。

5. **团战分工与反制保留**
   - **Applicability：**怪兽战、围杀、战争局部 POV。
   - **Rule：**只保留能改变敌方不同选择的角色组；至少让强敌给出一次可验证反制，再决定是否形成压制。
   - **Stop rule：**分工已导致目标、撤路或队形发生不可逆变化。
   - **Failure pattern：**把群体写成背景音；或一上来让敌人吃满所有攻击，团战没有策略与风险。
