# Research Question

资源价值体系如何服务场景：

钱、学分、丹药、能量与战利品，只有在改变“此人现在能练什么、敢冒什么风险、被谁当作什么身份、还能选哪条路”时才展开。价格应成为行动尺子与机会成本，而不是库存展示；资源管理完成状态转换后，必须退出主戏。

# Evidence Windows

## RQ-01｜报名费把“想变强”变成迫近的现实选择

- 章节 / 定位：第3章《穷文富武》；204–321。
- Evidence：方平得知武科报名费、后续训练与突破均需大量资金；普通家庭若无法进入武大资源体系，几乎没有稳定成为武者的路径。
- 场景姿态 / 目标：认知型决策场；目标不是介绍物价，而是确认“是否必须考武科”。
- 前状态：他有重生后的创业设想，却没有武力、资本或武道资格。
- 展开 / 压缩：展开报名时间、家庭余额、培养成本与学校供给；压缩泛泛的武道知识和职业说明。
- 状态改变的交换：一万元不是单纯价格，而是短期限内决定能否进入上升通道的门槛；“考武科”从兴趣变成必须完成的行动。
- 他人反应 / 细节：同学只能谈“试一次”或放弃；人物口袋里仅余零钱，形成身体携带的贫困感。
- ruler / reader model：读者不需记住总成本，只需知道“拿不出报名费＝连失败资格都没有”。
- 停点：确认必须筹钱、必须报考后即停，后续转入实际筹资与备考。
- Interpretation：资源在开局可作为目标合法化器，而非升级奖励。
- anti-inference：这不是“所有开篇都应先报穷”；这里只因报名存在明确截止期且直接封闭身份路径。

## RQ-02｜丹药价格同时标出突破风险与阶层差

- 章节 / 定位：第29章《武者真有钱！》；3399–3469。
- Evidence：被缴获的丹药被逐项说明其训练、续战、突破和护内腑用途；社会武者与武大学生因渠道不同，突破同一境界的成本不同。
- 场景姿态 / 目标：审问中的资源辨识场；目标是判断手中物是否足以改变自己的武道路。
- 前状态：方平只把药瓶视为高价战利品，不理解其适用层级。
- 展开 / 压缩：展开“没有护腑资源便可能在突破中受伤”“同阶不同渠道成本不同”；压缩完整药物目录。
- 状态改变的交换：一颗药的价格被转译为安全余量、突破次数和能否承受失败；贫困武大学生会被第二次突破费用卡死。
- 他人反应 / 细节：被审者因自身为突破筹资失败而转向抢劫；药瓶被握紧，身体反应承接数字冲击。
- ruler / reader model：价格的尺子不是“贵”，而是“少一项保护资源，是否还敢冲境界”。
- 停点：方平理解资源差会造成强弱循环后停止估价，返回自身行动。
- Interpretation：药物信息只有在绑定“训练—损伤—突破—失败后果”时才值得展开。
- anti-inference：不能据此把每种丹药都写成风险说明书；只有当前决策涉及该药时才展开用途。

## RQ-03｜学校选择由资源、任务密度与死亡风险共同定价

- 章节 / 定位：第78章《学校之间的差距》；10427–10537。
- Evidence：两类学校的免费/半价突破资源、导师层级与任务供给不同；高资源学校也意味着更多高危任务。
- 场景姿态 / 目标：选择前咨询；目标是把“名校更好”具体化为可比较的未来。
- 前状态：方平在本地优待与顶级学校之间犹豫。
- 展开 / 压缩：展开一品突破的资源差、后续任务机会和三品前免费供给；压缩学校的泛历史与完整师资名册。
- 状态改变的交换：放弃本地的免费资源，换取更高训练上限和任务机会；同时接受更高死亡概率。
- 他人反应 / 细节：王金洋不替他决定，只给出条件；方平听到需放弃的资源后出现明显迟疑。
- ruler / reader model：资源不是单独的“福利”，而是与风险、成长天花板捆绑的报价。
- 停点：报价已让人物真正为难即可停，最终学校选择留给后续行动。
- Interpretation：大额资源最有效的呈现方式之一，是让它改写路线选择，而非立即到账。
- anti-inference：普通水平者未必从顶级资源中获益更多；原文明确限定了能力门槛。

## RQ-04｜学分的非对称兑换，把权限写成真实成本

- 章节 / 定位：第103章《二道贩子的梦想！》；14303–14428。
- Evidence：学分可换训练、住宿、场地与丹药；现金换学分的比率明显更差，学校用制度阻断低价倒卖。
- 场景姿态 / 目标：新身份进入制度后的规则发现。
- 前状态：新生只知道自己获得了学分，不知道其可用范围与损失边界。
- 展开 / 压缩：展开基础学分恰好覆盖一次安全突破、武器会挤占训练资源、现金与学分双向兑换差；压缩完整兑换目录。
- 状态改变的交换：获得学分不等于获得可随意消费的现金；人物必须在训练、安全、武器与短期变现中选。
- 他人反应 / 细节：窗口人员与导师不断劝新生优先保留训练资源；排队大厅和兑换窗口让“权限货币”有空间落点。
- ruler / reader model：一分学分的价值由“能否换到校内稀缺训练权限”决定，不由现金面值决定。
- 停点：方平意识到暂不倒卖、优先保留未来选项时停。
- Interpretation：同一资源的双重定价，能自然呈现制度控制与身份差异。
- anti-inference：不可机械复制不对称汇率；它需要真实机构有意限制资源外流的动机。

## RQ-05｜把学分卖成现金，是一次被明确标价的自损选择

- 章节 / 定位：第119章《卖丹药》；17080–17231。
- Evidence：方平将大量学分换成丹药再出售；兑换处人员明确提醒新生学分难挣、现金买不到部分资源，且私售有风险。
- 场景姿态 / 目标：高风险变现场。
- 前状态：方平拥有有限学分与特殊的财富转换收益，但缺现金。
- 展开 / 压缩：展开“卖掉后还剩多少学分”“私售折价与被盯上的风险”“为何普通学生不该这样做”；压缩具体买家的长篇议价。
- 状态改变的交换：他用未来训练选择权换取现金与当前财富值；随后确认循环买卖不能持续获利。
- 他人反应 / 细节：老师先劝阻后放行；买方担心货量与自身实力不足，资源暴露立刻变成安全压力。
- ruler / reader model：读者看到的不是套利技巧，而是“新生把日后修炼的底牌变现了”。
- 停点：现金到账、套利闭环被证实不可重复后停止，转入下一项行动。
- Interpretation：资源戏可写人物的特殊能力，但必须同时让制度、风险与不可复制性出场。
- anti-inference：方平的额外收益依赖其个人机制，不能推广为一般角色的合理商业路径。

## RQ-06｜任务奖励必须迅速落到“买什么、缺什么、能不能活”

- 章节 / 定位：第140章《回校，收获》至第141章《大客户方平》；20752–21027。
- Evidence：任务学分按贡献与死亡后果分配；方平拿到资源后没有停在数字上，而是立刻面对适合自己的武器与学分/现金支付方式。
- 场景姿态 / 目标：任务余波中的配置决策。
- 前状态：多支小队完成度不同，存在伤亡、奖励差和装备缺口。
- 展开 / 压缩：展开贡献与奖励差、伤者买药困难、合适武器的价格与替代方案；压缩其余队员战利品细目。
- 状态改变的交换：任务成绩转成可支配学分；方平为适配下一阶段战斗，接受用现金和旧装备补差，而不是保留全部学分。
- 他人反应 / 细节：导师按死亡与冒进扣减收益；其他队伍因收益过低而情绪低沉，资源直接显形为风险后果。
- ruler / reader model：武器价格的尺子是“能否在下一场战斗里不被旧装备拖死”，不是其稀有名头。
- 停点：支付方式确定、武器配置完成后退出资源场，后续应转战斗或训练。
- Interpretation：任务奖励的最好兑现不是报收获，而是让它解决刚被任务暴露的缺口。
- anti-inference：不应让每次任务都紧接购物；只有前一场确实暴露装备/恢复/权限缺口时才成立。

## RQ-07｜资源经营一旦抢走训练主线，文本给出明确刹车

- 章节 / 定位：第174章《武者渠道商》；27038–27280。
- Evidence：方平设想校内资源平台，确有渠道效率与利润空间；导师认可可尝试，但明确把“修炼进度不能被耽误”设为条件。
- 场景姿态 / 目标：副线商业构想的边界协商。
- 前状态：公司扩张未产生预期价值，方平试图从武者资源渠道寻找新路径。
- 展开 / 压缩：展开平台为何能节省强者兑换时间、为何需要担保与承担责任；压缩经营流程、产品目录和日常订单。
- 状态改变的交换：商业机会换来导师担保与责任，但不能换走训练优先级。
- 他人反应 / 细节：管理者先指出垄断、护送、信用与资格障碍，再给出有限许可；阻力来自现场关系而非作者旁白。
- ruler / reader model：资源经营的尺子不是预计利润，而是是否比做任务更有效、是否会拖慢当前成长。
- 停点：获得有条件许可并确认训练优先后停，不继续铺陈创业执行。
- Interpretation：资源管理可作为一场“能否占用主线时间”的选择戏。
- anti-inference：并非所有资源副线都该被允许；若不能回流到当前主目标，应压缩或切走。

## RQ-08｜能源石在地窟中同时是货币、训练条件与城市权力

- 章节 / 定位：第368章《王城=能源矿！》；62424–62456。
- Evidence：王城市场以能量结晶交易，高质量能源石主要用于修炼；城市依赖矿脉与守护力量，普通货币与修炼资源被同一体系连接。
- 场景姿态 / 目标：敌方城市中的侦察式观察。
- 前状态：方平在陌生王城内，只把能源石当作个人可用的高价值物。
- 展开 / 压缩：展开市场交易介质、能源石的品级用途和城内外的资源差；压缩普通商品与摊贩细节。
- 状态改变的交换：没有主角直接交易，但观察到“低品质货币—高品质修炼物—王城控制”的链条，改变了他对敌方城市与矿脉价值的判断。
- 他人反应 / 细节：买卖双方不热衷出售高品质能源石；集市、城内照明与矿脉构成可见的空间证据。
- ruler / reader model：资源价值被标成“谁能修炼、谁能在城内安全生活、谁能决定兑换”。
- 停点：经济规则已能反向解释王城强弱后，回到侦察与生存主线。
- Interpretation：世界资源体系可通过一次有目标的观察场呈现，但必须服务正在进行的潜入任务。
- anti-inference：无主角选择、无后续用途的纯市场浏览，不能独立承担资源戏。

## RQ-09｜矿区的价值取决于纯度、暴露风险与可持续性

- 章节 / 定位：第371章《进入矿区》；62690–62712。
- Evidence：矿脉并非“见矿就挖”；低纯度矿被保留蕴养，高纯度能源石才值得在根须守卫与暴露风险下取走。
- 场景姿态 / 目标：高危猎取 / 取舍场。
- 前状态：方平已进入矿区，面临大量低价值矿与极高侦测风险。
- 展开 / 压缩：展开矿脉循环、低纯度矿的再蕴养、守卫根须与取走一块高纯度矿的风险；压缩重复挖掘。
- 状态改变的交换：放弃大量可见但不值得携带的低纯度资源，以更高风险换取少量可修炼资源。
- 他人反应 / 细节：地下根须像牢笼，人物在泥土上方穿行；空间限制成为价值判断的一部分。
- ruler / reader model：资源不是“数量越多越好”，而是“单位体积/风险下，能否改变当前修炼与逃生能力”。
- 停点：拿到足以证明价值的高纯度资源、风险上升后停，立即切回潜入或逃离。
- Interpretation：资源获取场可把品质、携带限制和敌方反应合并成同一压力。
- anti-inference：不能把所有采集都写成精算；只有资源质量差异会改变路线时，才需要展开。

## RQ-10｜巨额资源先变成组织身份，再变成可调用的保护

- 章节 / 定位：第445章《借你一万学分》；77391–77414。
- Evidence：方平带回大量能源石与高品战利品；他不将其直接据为现金，而与学校达成大量学分、暂不支取、战死后捐献的安排。
- 场景姿态 / 目标：归来展示后的归属谈判。
- 前状态：众人震惊于战利品规模，资源归属与处置未定。
- 展开 / 压缩：展开资源稀缺、学校收购方案、个人不急用与未来捐献承诺；压缩完整战利品清点。
- 状态改变的交换：个人战利品换成校内长期信用与可调用资源；学校也承诺其需要时不吝供给。
- 他人反应 / 细节：强者因能源石数量失语，校长的报价与导师索要神兵把“资源＝身份”外化。
- ruler / reader model：巨额资源的意义是“一个学生已能与学校谈长期互保”，不是千亿本身。
- 停点：归属、保留与未来责任都确定后停，转入后续局势。
- Interpretation：公开资源 payoff 可通过“他人重估此人可承担的责任”完成。
- anti-inference：不是所有战利品都该捐献；这里的效果依赖学校、人物与战场已有的互保关系。

## RQ-11｜战利品分配先确认信用，再允许高风险消耗

- 章节 / 定位：第490章《先分赃》；86281–86470。
- Evidence：高品能源石被拿来制造爆炸、资源按贡献分配；方平先扣除自身投入，再公开计算并强调不会为小利损害信用。
- 场景姿态 / 目标：危机撤离前的快速结算。
- 前状态：队伍重伤、仍处敌城，资源未分且即将用部分资源制造撤退窗口。
- 展开 / 压缩：展开“用什么当爆炸物”“消耗是否计入共同成本”“各人的贡献份额”；压缩城主府其他杂物。
- 状态改变的交换：资源从战利品转为撤离成本与队伍未来信用；公平分配使后续共同冒险可持续。
- 他人反应 / 细节：队友会直接追问爆炸用能源石算谁的，说明价值争议在危险中仍存在。
- ruler / reader model：一笔资源值不值，先看它能否换来撤退和团队信任，再看市价。
- 停点：份额确定、资源归属被认可即停，回到撤离风险。
- Interpretation：分赃可以是 leadership 场，不是库存场；关键是把“谁承担成本、谁获得信用”写清。
- anti-inference：没有共同危险、共同出力或后续协作时，不必专写分配谈判。

## RQ-12｜战斗中的资源投入只回答“还能不能继续打”

- 章节 / 定位：第621章《烧钱烧到疯狂》；118399–118548。
- Evidence：高阶战斗中，不灭物质与高价值资源被直接用于恢复战力；低额任务奖励与高额战斗消耗形成反差。
- 场景姿态 / 目标：大战中的战力续航场。
- 前状态：高品战斗持续，人员伤势与资源消耗都已逼近边界。
- 展开 / 压缩：展开一次恢复是否足以维持战线、投入与击杀收益是否相称；压缩资源总账与可售清单。
- 状态改变的交换：资源被消耗后，伤者/战线获得继续作战的窗口；钱的意义退到“还能撑几轮”。
- 他人反应 / 细节：人物对高价值恢复物并非纯粹欣喜，而是把其视为战场上的消耗品。
- ruler / reader model：单位价值不重要，重要的是它能否让关键战力多活一拍、多完成一个目标。
- 停点：恢复已经把问题从“会不会崩”改成“如何结束战斗”时立即转回 combat。
- Interpretation：战斗中的资源戏可以极短，只需让投入改变战斗选项。
- anti-inference：不应在战斗中展开完整财务计算；此处的数值仅用于标出战局代价的反常规模。

## RQ-13｜紧急分赃以贡献比例锁定同盟，不抢救援主戏

- 章节 / 定位：第665章《分赃》；129907–130018。
- Evidence：队伍在赶往救援途中，将资源按贡献、令牌、装备损耗与个人出力定比；分配后立刻返回更紧迫的救援。
- 场景姿态 / 目标：移动中的联盟结算。
- 前状态：刚从高危区域脱身，伙伴的师长正被追杀，资源巨大且存在个人秘密。
- 展开 / 压缩：展开估值基准、各人贡献与份额；压缩逐件搬运与全部物资形态。
- 状态改变的交换：主角多取份额但明确依据，伙伴获得可见的长期收益与不追问秘密的理由。
- 他人反应 / 细节：众人认可分配，且主动表示可不分；高速赶路与传音让场景不脱离救援压力。
- ruler / reader model：分配金额的尺子是“谁冒了什么风险、谁因此会继续跟随”，而非绝对财富。
- 停点：比例确定即止，下一拍立刻回到救援与战场。
- Interpretation：高压下可保留极短的资源分配，只要它解决下一场协作的信用问题。
- anti-inference：一般紧急场景不应插入账本；本例有既成队伍、巨额共同战利品与持续协作需求。

## RQ-14｜资源公开展示的目标，是改变救援与组织决策

- 章节 / 定位：第761章《收获》；154368–154654。
- Evidence：方平展示资源并非庆功，而是证明魔武值得被救、强者能被修复、战力可被重新配置；随后资源按恢复、神兵、晋级与防守需要分配。
- 场景姿态 / 目标：组织危机后的说服与重配。
- 前状态：魔武受损，外部强者对投入与救援价值存在判断冲突。
- 展开 / 压缩：展开能修复谁、给谁神兵、谁因资源可晋级、谁将承担下一次反攻；压缩大部分宝物名称和收藏价值。
- 状态改变的交换：私人收获转成救援资源、战力承诺与组织债；接受资源的人获得行动责任。
- 他人反应 / 细节：大厅堆放的资源形成视觉冲击，但真正的转折来自强者改变态度并接受配置。
- ruler / reader model：资源价值以“能否保住一个人、补回一条战线、让谁进入下一层”衡量。
- 停点：关键资源已绑定到具体人和下一战职责后停止。
- Interpretation：大额资源展示应服务争取支持或重组力量，不能独立充当高潮。
- anti-inference：资源再多也不自动解决价值冲突；原文中仍需人物先证明组织值得投入。

## RQ-15｜后期清点先定战略去向，才允许报规模

- 章节 / 定位：第987章《清点收获》；214285–214405。
- Evidence：面对巨额收获，方平首先确认需向多个盟友与区域分配，只保留急需部分；之后才按恢复、修炼与空间器具用途估值。
- 场景姿态 / 目标：大战后的战略储备场。
- 前状态：外部势力动荡，己方既有恢复需求，也有结盟与防守压力。
- 展开 / 压缩：展开哪些资源能恢复本源、哪些只能用于一般修炼、哪些需优先外送；压缩低阶杂物。
- 状态改变的交换：战利品不再是个人升级池，而是外交、恢复与战略储备的有限预算。
- 他人反应 / 细节：人物在修炼室内清点，空间容量本身成为资源价值的一部分。
- ruler / reader model：再大的资源量也必须回答“先救谁、给谁、留下什么应急”，否则只是空数字。
- 停点：战略去向与关键用途确立后停，后续应切换外交、恢复或战争推进。
- Interpretation：后期资源戏可扩大尺度，但仍需用明确去向替代完整库存。
- anti-inference：这不支持每次大战后长篇清点；其成立条件是资源将立即影响多方关系与战争选择。

# Cross-Window Findings

1. 资源必须被翻译成“当前可行动性”，而非名义拥有量：能否报名、突破、买到适配武器、维持战斗、进入机构或选择学校，才是读者可感的价值尺子。
   支持：RQ-01、RQ-02、RQ-03、RQ-04、RQ-06、RQ-12。

2. 最有效的价格信息不是单个数字，而是至少一个可比较的反事实：现金与学分的权限差、低品与高纯度矿的风险差、免费供给与高危任务的路线差。
   支持：RQ-03、RQ-04、RQ-05、RQ-08、RQ-09。

3. 战利品分配在有共同风险与持续协作时，本质上是信用和领导权的场景：贡献依据公开，资源才会变成下一次出力、保密或互保的理由。
   支持：RQ-10、RQ-11、RQ-13、RQ-14。

4. 资源戏的节奏应是“缺口出现 → 重新估值 → 一个可见交换/配置 → 下一行动”，而不是“获得 → 清单 → 再清单”。
   支持：RQ-05、RQ-06、RQ-09、RQ-12、RQ-13；反证边界：RQ-07。

5. 大资源只有在改变组织级风险、身份或战略时才能扩容；否则应维持个人层面的即时用途。
   支持：RQ-10、RQ-14、RQ-15；反证边界：RQ-07、RQ-12。

# Counterexamples & Boundaries

- RQ-03：资源更丰富不自动适合所有人。原文明确区分普通学生与有能力吃下任务机会的人；没有能力前，资源差不必成为主戏。
- RQ-05：主角的变现行为建立在其个人财富转换机制上；不能把“卖训练资源”泛化为合理的常规策略。
- RQ-07：资源经营有真实机会也必须让位于当前成长主线。若经营不能立刻改善训练、任务或身份，应在获得许可/做出取舍后压缩。
- RQ-12：战斗中资源只服务续航与关键决策；不能将激战暂停为完整账本。
- RQ-13：危机中仍可分配资源，是因为它同时解决团队信用和隐藏信息问题；普通赶路或救援场景不应硬插分赃。
- RQ-08：世界经济观察只有在改变潜入者的判断、路线或目标时才值得保留；纯陈列不构成资源场景。

# Candidate Transfer Rules

1. **权限折算 ruler**

   - applicability：同一资源可用现金、积分、配额、资格或人情兑换，且至少两种方式的可得性不同。
   - rule：只展示足以迫使选择的两档价格，并立刻说明便宜渠道能换到什么、昂贵渠道失去什么。
   - stop rule：人物确定保留、兑换或放弃其中一种权限后停止。
   - failure pattern：只报“很贵/很便宜”，却没有任何可行动差异。

2. **缺口优先的资源兑现**

   - applicability：刚完成任务、战斗、试炼或训练，且现场已经暴露装备、恢复、资格或时间缺口。
   - rule：资源到账后优先让它解决刚刚暴露的一个缺口；其他物资以一句结果压缩。
   - stop rule：新装备、药物、权限或路线已让下一行动可执行。
   - failure pattern：奖励被完整列出，却不影响下一场行动。

3. **贡献可见的战利品分配**

   - applicability：两人以上共同冒险，且之后仍要互信、协作或承担共同风险。
   - rule：只列与份额有关的贡献、损耗和共同成本；让接受者以行动、态度或下一次承诺回应。
   - stop rule：份额与归属被认可，下一拍切回目标、撤离或战斗。
   - failure pattern：主角任意多拿、其他人无反应，或分配变成冗长库存表。

4. **资源投入必须换来风险窗口**

   - applicability：丹药、能量、装备或资金在当前场面中可改变受伤、突破、逃离或维持战力的概率。
   - rule：先给出若不投入会失去什么，再让投入直接打开一拍可见行动。
   - stop rule：资源已换成存活、突破尝试、撤离口或战斗持续能力。
   - failure pattern：为显示豪阔而消耗资源，却不改变人物能做什么。

5. **资源副线的主线让位规则**

   - applicability：人物开始经营、囤货、倒卖或建设资源渠道。
   - rule：只展开“此事是否比当前训练/任务更能解决主问题”的一次判断；若不能，压缩到许可、拒绝或转交。
   - stop rule：主线优先级被确认。
   - failure pattern：日常经营流程吞掉冒险、关系或成长场景。
