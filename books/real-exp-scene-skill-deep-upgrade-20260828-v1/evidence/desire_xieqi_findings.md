# Cross-Window Findings

1. 欲望首先改变的是 POV 的“看什么”，不必直接决定“做什么”。身体、气味、豪华空间、现金与亲近姿态会占据注意；但危险、任务、明确边界或责任可重排优先级。`E-XQ-01 / 02 / 04 / 06 / 07`

2. 关系偏心最有效的证据不是“我在乎”，而是它让人物在高风险节点改变程序：不上报、援助、承担费用、退出竞争或调整接近路线。`E-XQ-03 / 07 / 09 / 10 / 11`

3. 公开的身体/关系展示，只有在旁观者能据此重新分配资格、婚约、关注或资源时，才是场景发动机；私下亲近本身不自动具有这个作用。`E-XQ-05 / 08 / 09`

4. 金钱的场景价值不在报数，而在于它是否解除具体债务、形成可见伪装、抬高信息价格，或把对手的行为重算为损益。`E-XQ-05 / 06 / 07 / 12 / 13`

5. 欲望场景的停止点应落在一个可观察的状态改写：撤手、坐直、付钱离职、手下后撤、退出竞争、关门拨号。若继续只增加感官信息或重复暧昧，应压缩。`E-XQ-02 / 04 / 06 / 10 / 12 / 13`

# Counterexamples & Boundaries

- 第一部第二章《出来混，要讲规矩》162–205：客人“花钱图开心”并未压倒场所规则；陈阳先给替代方案，坚持边界，冲突升级后才反制。
- 第一部第四十五章《史上最尴尬的艳遇》3872–3948：面对醉酒方楠，陈阳受吸引但转为照料、喂药、买药；吸引不等于可推进。
- 第二部第六十九章《幸福生活》26363–26420：享乐场景被卫星电话与组织事务打断，说明生活享受不能自动长期占据 POV。
- 第三部第七十一至七十二章 42678–42818：爱与身体吸引仍无法越过婚姻名分和身份边界。
- 第三部第一百零九章 46289–46323：钱、女人与安全也可使人物回避权力竞争，而非追逐更大野心。

# What Existing Skill Misses

现有 `relationship` 已要求关系改变行动，`resource_economy` 已处理价格与机会成本，`social_bargain_decision` 已处理筹码与条件；它们本身是正确的。新增判断能力不应另造一个“欲望 Primary Skill”，而应补足三项跨 Skill 的输入判断：

1. 欲望对象如何改变 POV 的注意顺序：现有 Skill 未要求区分“只是描写到吸引”与“吸引使人物漏看/多看/改选某个证据或路线”。
2. 私密吸引与公开估值的分流：只有旁观者和待分配资源同时存在时，亲近、竞争、面子才可转成资格、价格或站位变化。
3. 关系偏心的限幅：旧恩、嫉妒、照料可以改写行动，但必须同时写清未被取消的风险、程序或退出边界，避免把偏心写成自动免责。

# Candidate Transfer Rules

1. **欲望必须改变下一拍。**
   - Applicability：POV 对人、钱、享乐、名分有明确即时欲望，且同场存在任务或风险。
   - Rule：只选一个感官/物质细节，让它改变注意、迟疑、靠近、回避或风险判断。
   - Stop rule：行动已经转向后停止增加同类身体或奢侈细节。
   - Failure pattern：只写“很漂亮/很贵/很想要”，但后续选择完全不变。

2. **公开关系信号必须有受众和分配后果。**
   - Applicability：现场有竞争者、旁观者，且存在职位、婚约、资格、资源或关注待分配。
   - Rule：关系展示后，至少一个第三方应改变站位、报价、招揽、敌意或合作条件。
   - Stop rule：第三方的现实判断已改变即收束。
   - Failure pattern：把私下亲近硬搬到公开场合，却没有任何人因此改变选择。

3. **偏心只能改变处理方式，不能替代证据。**
   - Applicability：亲近者卷入疑案、阵营冲突或高风险请求。
   - Rule：并置可疑事实与共同经历，让 POV 选择延后、有限援助、核验或不同行动，而非直接宣布清白。
   - Stop rule：停在程序或援助范围已经改变的动作节点。
   - Failure pattern：用“我相信她”消灭风险，或用旧恩直接恢复敌我关系。

4. **金钱要落实为“束缚—支付—新行动”。**
   - Applicability：钱是人物欲望、困境或谈判筹码。
   - Rule：写清欠什么/缺什么、支付或报价动作、支付后新获得的行动自由。
   - Stop rule：新路线、资格或选项已显现。
   - Failure pattern：连续报金额、物件或排场，却没有改变任何选择空间。

5. **享乐作为掩护，必须付出可见成本。**
   - Applicability：人物需以消费、玩乐、社交或亲近掩盖真正任务。
   - Rule：让场所或同行者看到足以相信的消费、时间、空间隔离或人际安排，再切任务。
   - Stop rule：伪装可信、人物切入真正行动后立即转场。
   - Failure pattern：人物宣称在伪装，但无人被说服，也没有付出成本。

6. **面子冲突要给出真实代价与反向约束。**
   - Applicability：人物因羞辱、公开失位或尊严受损想升级行动。
   - Rule：先让其想保住什么，再给出会损失的关系、命、资源或机会；由此决定顶住、退让或换手段。
   - Stop rule：选择及其直接代价已经发生。
   - Failure pattern：面子只被当作无成本暴怒按钮。
