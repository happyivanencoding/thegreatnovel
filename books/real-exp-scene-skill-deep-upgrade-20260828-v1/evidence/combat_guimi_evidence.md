# Evidence Windows

## CG-01

**Evidence**
- **章节 / locator**：第一部，第七十一章《滞涩现象》至第七十五章《自救》；6361–6838。锚点：“至少三个人围着它”。
- **scene posture/type**：封印物事故中的小队限制战。
- **scene goal / pre-state**：队伍需隔离危险物并救回被影响成员；敌手不是人格化对手，而是有影响人数、距离与触发条件的异常物。
- **expanded beats**：先展示影响规则，再让队伍把职责拆为看守、突入、侧警与唤醒；队列进入仓库后，成员的位置变化直接决定谁会先被牵制。
- **compressed/omitted beats**：常规移动和已理解的压制动作被略过；不补全异常物的完整来源学。
- **state-changing exchange / reaction**：成员被拖入异常行为后，其他人不能继续原计划，必须改为维持监控与救援；规则改变了目标优先级。
- **body/space/detail selection**：用围拢人数、半弧站位、仓库入口和持续动作作为规则的可见载体。
- **ruler/reader model**：读者只需知道“谁接近、谁失去行动、谁能唤醒”，便能预判队形为何不能乱。
- **stop point**：封印物重新受控、人员脱险，停止逐步监控。

**Interpretation**
- **transfer observation**：规则型敌手先给“影响条件 + 失效后果”，再给行动；队形不是装饰，而是对规则的回答。
- **anti-inference**：不能推出所有异常战都需要先完整说明数值范围；本窗口的持续监控本身就是胜负条件。

## CG-02

**Evidence**
- **章节 / locator**：第一部，第一百二十三章《超凡战》；11174–11255。锚点：“主要目的一直是阻止仪式”。
- **scene posture/type**：三名守夜人突入、敌方撤离中的仪式打断战。
- **scene goal / pre-state**：敌方已具备隐身、替身与仪式现场；小队并非必须击杀她，核心是破坏祭台。
- **expanded beats**：一人用梦境暴露隐身者，两人立即射击；敌方替身脱身后，以阴冷环境分别限制三名成员；各人按自身可见的威胁处理脚踝、窒息、施法受阻。
- **compressed/omitted beats**：未逐一解释每只幽影的背景或每发子弹机制。
- **state-changing exchange / reaction**：敌人借破坏祭台造成的混乱逃走；小队承认追击条件丢失，回收为原始任务。
- **body/space/detail selection**：窗台、草坪、破窗、一楼祭台和三条受阻路径，承担了战术信息。
- **ruler/reader model**：读者始终知道谁在控场、谁在突破、谁在被迫自救，以及“阻止仪式”比击杀更高。
- **stop point**：祭台失效且目标离场，战斗停在任务完成而非强造追杀。

**Interpretation**
- **transfer observation**：当仪式是敌方胜利条件时，队伍的“未杀死敌人”不等于场景失败。
- **anti-inference**：不是所有逃脱都应视为反转；这里逃脱成立，是因为先前已明确主目标不同。

**Evidence**

- **scene posture/type**：高威胁敌人的远距控场与围捕。
- **scene goal / pre-state**：己方知道靠近目标风险极高，只掌握可用的远距梦境、镜面与射击手段。
- **expanded beats**：三人按远距控制、镜面执行、近距支援分工；敌方以细丝、隐身、替身、黑焰逐项拆解计划，迫使控制手段重置。
- **compressed/omitted beats**：没有在开场列出敌方完整能力树；未知能力只在真正改变计划时出现。
- **state-changing exchange / reaction**：己方得到短暂固定目标窗口后才集中火力；敌方的反制令队员付出真实伤亡代价。

- **ruler/reader model**：读者知道“为什么不能靠近”“当前谁在维持窗口”，但不提前知道敌方下一张底牌。
- **stop point**：固定窗口结算并导致局势不可逆转后退出。

**Interpretation**
- **transfer observation**：复杂敌方能力可保持未知，但每次未知落地时必须立刻说明它毁掉了哪一条既有行动链。
- **anti-inference**：不能把“信息后置”误写成敌人无因果地追加能力。

**Interpretation**
- **transfer observation**：面对百科无法承受的高位规则，应先给可破坏的阶段条件，而非解释宇宙设定。
- **anti-inference**：不能因此把所有高位对手写成“打断一次即永久失效”。

- **compressed/omitted beats**：幸运机制不在开场给全；读者只从连续失败和人物判断中认识它。

## CG-10

**Evidence**
- **章节 / locator**：第四部，第三十六章《“诡法师”VS“寄生者”》；83455–83516。锚点：“根本就没有的东西”。
- **scene posture/type**：射程、信息与能力窃取互相克制的半神战。
- **scene goal / pre-state**：主角需远程控制寄生者；敌方能窃取念头、能力、位置、行动能力和双方距离。
- **expanded beats**：以无自我意识的秘偶承受“窃取念头”；随后才揭示秘偶可延伸控制链的距离与数量上限；敌方窃取位置和移动能力后，主角靠预置秘偶互换回收陷阱。
- **compressed/omitted beats**：其余途径背景与长期成长史未展开。
- **state-changing exchange / reaction**：每个能力都不是“命中即结束”，而是夺走某项行动许可；对方随即改变位置、射程或控制权。
- **body/space/detail selection**：庄园内外、五百米至千米的控制链、老鼠群与本体互换。
- **ruler/reader model**：读者知道当前这次能力能偷什么、会令哪条行动线断裂，并知道本次反制依赖预置位置。

**Interpretation**
- **transfer observation**：只有当“范围、容量、持续时间”改变当下布局时，才值得精确披露；这些参数应紧贴首次利用它的动作。
- **anti-inference**：这不是“规则越多越好”的证据；其较密集的说明服务于远程布局，脱离布局即应压缩。

## CG-11

**Evidence**
- **章节 / locator**：第五部，第八十二章《自救》；87208–87294。锚点：“真是不幸啊”。
- **scene posture/type**：敌方 POV 的倒计时自救战。
- **scene goal / pre-state**：被灵体之线控制者明确知道自己实际只剩约十秒可作有效决策。
- **expanded beats**：对手依次放大副作用、制造混乱、拉开距离、建立空中阻断；随机封印物、替身免疫、预埋寄生子弹分别令预案失效或延迟。
- **compressed/omitted beats**：不先交代主角所有子弹和全部底牌，只在其成为唯一可行解时揭示。
- **state-changing exchange / reaction**：敌方每次自救都以“可行动秒数”衡量；最后丢弃随机性资源虽恢复可控，却恰好满足主角的埋伏条件。

- **stop point**：寄生成功、敌人失去自主身体控制。

**Interpretation**
- **transfer observation**：复杂战中可把读者标尺降为一个即时倒计时；不必先解释所有能力，只要每次选择都改变剩余窗口。
- **anti-inference**：倒计时必须来自已展示的控制进程，不可由旁白随意宣布。

## CG-12

**Evidence**
- **章节 / locator**：第五部，第一百零六章《三打一》；89093–89173。锚点：“只用三秒”。
- **scene posture/type**：三个秘偶分工完成单一控制链的团队战。

- **state-changing exchange / reaction**：控制链成功后，敌方用早已埋下的精神污染反向攻击操控者；己方再用扭曲减轻病势，争取继续压制。
- **body/space/detail selection**：屋顶、花园角落、巨龙下落、三秒与一秒的不同窗口。
- **ruler/reader model**：读者可清楚追踪“减速为何不够、子弹为何必须插入、放大为何换目标”。
- **stop point**：初控完成且新威胁转为精神污染时，原控制链不再重复说明。

**Interpretation**
- **transfer observation**：团队战应写成“前一人的限制，给后一人的发动条件”，而不是三人轮流出招。
- **anti-inference**：队伍协同不能免除反制；敌方应能利用先前接触、位置或资源留下的入口。

## CG-13

**Evidence**
- **章节 / locator**：第六部，第八十五章《最佳辅助》至第八十六章《联动》；104103–104260。锚点：“最佳辅助”。
- **scene posture/type**：双战场、召唤媒介与封印物克制的联动战。
- **scene goal / pre-state**：一侧要牵制高位敌手，另一侧需在敌方天使降临前击杀巫王；双方都不能无限维持资源。
- **expanded beats**：先以随机转移切断敌方支援；队友用积攒诅咒换取脱身窗口；另一战场先摧毁召唤之门，再以月亮领域封掉闪现与化身，再让诅咒、雷击和终结攻击按序结算。
- **compressed/omitted beats**：没有独立展开所有天使能力的全谱。
- **state-changing exchange / reaction**：敌方以伤害转嫁逼迫诅咒者中止；己方先用领域限制其逃生方式，才让后续伤害成为致命伤害。
- **body/space/detail selection**：召唤之门、沙漠与原战场、被锁定的额部媒介、受伤回流的身体。
- **ruler/reader model**：读者知道当前最重要的不是伤害量，而是谁能开门、闪现、维持联系或离开场地。
- **stop point**：召唤媒介断裂、巫王被终结，双战场联动完成。

**Interpretation**
- **transfer observation**：双战场只需持续交代彼此的交换条件：一边拖住多久，另一边才能完成哪项不可逆动作。
- **anti-inference**：不应把跨场支援写成免费援军；每次调度须展示牺牲的维持、位置或防护。

## CG-14

**Evidence**
- **章节 / locator**：第六部，第九十三章《忙而不乱》；104814–104874。锚点：“一两秒的时间”。
- **scene posture/type**：天使级追击中的并行威胁处理。
- **scene goal / pre-state**：主角需在目标切断联系前定位并降临，同时阻止另一强敌借漏洞侵入关键空间。
- **expanded beats**：提前设置祈祷共振以省去进入步骤；分出部分力量击退入侵者；本体再以已学习的时间能力定住目标；最后投放事前运入的外援附身。
- **compressed/omitted beats**：不在当下追述所有前期交涉，只在其兑现为“一秒省下的时间”时说明。
- **state-changing exchange / reaction**：目标本能撤离，入侵者趁主角调度分心入场；每个分身动作都消耗同一时间窗口。

## CG-15

**Evidence**
- **章节 / locator**：第八部（源文在第七部总结末说明部名），第二十六章《联手》至第二十七章《一个奇迹》；116325–116518。锚点：“不允许偷盗”。
- **scene posture/type**：多方神灵围绕规则许可、身份归属与晋升条件的终局规则战。
- **scene goal / pre-state**：一方需阻止高位意志复苏并完成晋升；多方分别争夺规则书、封印、身份与极短暂的行动窗口。
- **expanded beats**：规则书先限制复活，再被更高位规则抵消；敌方为对抗更大威胁而削弱封印，反而让“禁止偷盗”反噬自身；身份与命运归属决定某次预言是否能生效；主动死亡改变了晋升支柱。
- **compressed/omitted beats**：不复述世界历史，只解释当前规则改变了哪一个动作是否允许。
- **state-changing exchange / reaction**：每条规则先改变行动许可，另一方再以更高位或不同归属反制；多方协作只维持到制造短暂隐秘窗口。
- **body/space/detail selection**：规则书、古老宫殿、封印强弱、被抹去的场域、死亡与回归。
- **ruler/reader model**：读者每次只需回答“现在能不能偷、能不能复活、这个身份是否仍属主角”，不必提前掌握全部权柄体系。
- **stop point**：晋升完成、原规则冲突被新状态覆盖。

**Interpretation**
- **transfer observation**：高阶规则战仍必须把规则改写为当前动词的许可或禁止，否则读者无法判断交换。
- **anti-inference**：不能迁移其神格规模、身份设定或世界观专名；可迁移的仅是“规则 → 行动许可 → 反制条件”的呈现次序。

# Cross-Window Findings

1. **规则披露应以“本拍可判断性”为单位，而非以能力全表为单位。**
   先给触发条件、作用对象或即时限制，令读者能判断选择；其余机制留到真正改变选择时再出现。支持：CG-03、CG-04、CG-05、CG-07、CG-09、CG-11、CG-15。
   CG-10 是边界：当距离、容量和控制链本身就是布局，参数需要相对完整披露。

2. **规则战的主问题会从“击伤对方”转换成“改写条件、媒介或行动许可”。**
   攻击被消解、召唤门仍开、降临尚未完成、逃生能力未封时，伤害不构成阶段胜利。支持：CG-02、CG-04、CG-07、CG-13、CG-15。

3. **团队站位的可读性来自职能链，而不是“大家配合”。**
   应写清 A 先限制、遮蔽或承伤，才让 B 获得发动窗口；敌方打断 A，即迫使 B 改序或换位。支持：CG-01、CG-02、CG-03、CG-12、CG-13、CG-14。

4. **能力克制是条件化交换，不是常驻属性标签。**
   某能力的优势必须落在现场条件、敌方已暴露弱点、对方可付出的反制代价上；交换之后，下一次能力选择应改变。支持：CG-06、CG-08、CG-10、CG-11、CG-13。

5. **未知机制可以保留，但未知不能吞没失败因果。**
   读者可以不知道敌方从哪里获得能力、完整上限为何；但应知道它刚刚毁掉了哪一步、令什么风险变为现实。支持：CG-03、CG-05、CG-08、CG-09、CG-12。

6. **复杂战斗的压缩单位不是“招”，而是状态变量改变。**
   仅展开会改变距离、行动许可、计时窗口、媒介完整性、控制权或撤离可能性的动作；同一优势下的重复攻击压缩。支持：CG-02、CG-06、CG-11、CG-12、CG-14。

# Counterexamples & Boundaries

- **不需要把所有仪式都写成对抗战。** 第六部第七十七章《召唤仪式》103431–103489 中，召唤、守卫、外援和晋升者各守职责，但没有敌方即时破坏。这里的价值是清楚呈现“谁能何时介入”，不是制造连续反制。
- **当规则已在场前清楚、核心问题是通过判定线时，应使用 trial，而非强行套规则战。** CG-01 的封印物监控与 CG-04 的降临打断都具对抗性；如果没有对手围绕条件反制，战斗型仪式框架会增加噪声。
- **密集参数说明只在空间布局依赖它时成立。** CG-10 需要说明控制射程、秘偶数量与链路限制；普通近战中照搬这类说明会成为百科化。
- **未知不总要立即解释。** CG-09 的幸运干扰先以连续失效呈现；但文本仍让读者看清“原方案失效、目标改为脱身”。若连这一层也不提供，就会变成任意反转。
- **高位规则战不可直接降尺度复制。** CG-15 的可迁移点是行动许可的因果表达；不应搬用神格、多重身份或“规则书”式解决方案。

# What Existing Skill Misses

现有 [combat.md](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/combat.md:3) 对“当前目标、位置、可用手段、胜负条件、真实反应、团队分工、停止点”已经是正确且充分的基础；不需要以本研究替换它。当前库还明确限定 Scene Skill 不改事件合同或 Canon，并把 ritual 作为 Utility：[SKILL.md](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/SKILL.md:17)。

真正新增的判断能力只有五项：

1. **最小可操作规则披露**：每个超凡动作生效前，判断读者是否已知道触发、对象/范围、即时后果或可利用限制中的必要部分；区分“本拍必须知道”与“原理仍可未知”。
2. **仪式执行链与打断点**：把准备、满足条件、发动、维持、完成拆成可被攻击或守护的阶段，并明确当前该打断谁、媒介是什么、失败会转移什么代价。
3. **空间职能—行动顺序—失效后果**：不止写分工，而要写谁覆盖哪条路径、谁先行动才让谁有窗口、一处失守会导致哪个计划失效。
4. **条件化能力克制**：把“克制”落为本轮为什么有效、依赖何种现场条件、敌方能用什么代价反制、这次暴露如何改写下一次选招。
5. **知识不对称下的读者模型更新**：允许角色和读者暂不知机制全貌，但未知只能遮蔽“为什么终极如此”，不能遮蔽本拍行动、失败代价与目标切换。

# Candidate Transfer Rules

1. **规则最小披露**
   - **Applicability**：超凡能力首次改变当前角色的选项、距离、伤害有效性或撤离可能时。
   - **Rule**：在效果结算前，补足读者判断本拍所需的一项限制：触发、对象、范围、时间、代价或可被打断点；其余知识保留。
   - **Stop rule**：读者已能预判下一选择的风险时停止解释。
   - **Failure pattern**：先造成结果、后给无关联设定；或在行动前一次性罗列完整能力树。

2. **条件链而非伤害链**
   - **Applicability**：仪式、召唤、封印、控制、撤离等“完成条件”比击杀更重要的战斗。
   - **Rule**：每拍明确当前条件、其媒介/持有者、可打断路径；若攻击无效，立刻把主问题改为破坏条件或保护己方条件。
   - **Stop rule**：条件被完成、被毁或不可逆地转移后，退出旧攻防问题。
   - **Failure pattern**：继续逐招输出，或把攻击无效写成纯挫败而不生成新行动。

3. **队形必须产生发动窗口**
   - **Applicability**：两人以上且位置、视线、掩护、媒介或施法时间会影响结果的场景。
   - **Rule**：每名关键成员只承担一个可见空间职能；写成“甲先限制/遮蔽/承受，因此乙能发动；敌人破甲，则乙必须换位、换序或改目标”。
   - **Stop rule**：职能链不再影响能力发动时，压缩为普通协作。
   - **Failure pattern**：轮流出招；只说“默契配合”；成员位置改变却没有计划后果。

4. **克制须以条件结算**
   - **Applicability**：双方能力看似相克，或敌方新能力迫使战法更新时。
   - **Rule**：每次克制写清“优势对什么成立、靠什么现场条件、对方如何以何代价绕开”；反制成功后，下一拍必须替换至少一个能力选择、位置或目标。
   - **Stop rule**：克制关系不再改变胜负变量时，不重复说明。
   - **Failure pattern**：把能力写成永久属性压制；对方忽然免疫却无触发条件。

5. **未知只能遮蔽机制全貌**
   - **Applicability**：敌方能力首次出现、信息受限或需要保留悬念时。
   - **Rule**：先让读者看清可观察结果与受损行动链；在角色选择新方案前，补足足以比较风险的局部规则。
   - **Stop rule**：本场胜负已不依赖该未知时，不追补百科。
   - **Failure pattern**：未知导致人物只能等待作者揭牌；或揭牌后仍无法解释先前选择为何合理。
