- body/space/detail selection：军旗、手书、传阅时颤动的手和沙盘对照，让身份信用呈现为可操作文件。
- ruler/reader model：身份的有效形式不必是“本人露脸”；关键是接收者能否验证并据此调用资源。
- stop point：援军合法性、代价和下一步行政动作已明确，转入战局后果。
- unique anchor：`许银锣的手书`

**Interpretation**

对制度角色而言，可信凭据比情绪性揭露更能扩大行动权。

**Transfer observation**

当揭露服务于跨空间协作，可让可验证载体承担身份，而把人物本人留在更高风险的行动线。

**Anti-inference**

不能把文书当万能证明；此处它同时有稀缺字迹、使者到场和另一方确认三层可达验证。

**Evidence**

- 行号：125625–125727
- scene posture/type：高位真相公开后立即改变保护与杀意。
- scene goal：把“谁是守门人”的猜测转为主角必须进入核心区域、同伴必须争取时间、敌人必须阻止的行动结构。

- state-changing exchange：一句“让他成为守门人”使敌方将主要攻击目标转向主角，同伴将撤退选项改成牺牲性阻拦。

- ruler/reader model：真相不是奖励读者，而是倒计时开关：知道的人越多，主角的行动窗口越短。
- stop point：主角进入屏障，敌方与同伴的行动转向已经完成。
- unique anchor：`成为守门人`

**Interpretation**

当真相本身会触发顶级敌意，揭露必须与保护能力、入口窗口或撤离安排同拍出现。

**Transfer observation**

高风险身份揭露应在同一场景内交代：谁因此要杀、谁能拖住、主角能否立刻把信息转为位置变化。

**Anti-inference**

不能泛化为“大身份只能在战斗中揭露”；此处敌我双方都已经围绕入口对峙，信息一旦公开必然立刻军事化。

### ID-DGF-12

**Evidence**

- 章节：第五卷·第一百二十一章《绝世武神》
- 行号：132676–132797
- scene posture/type：身份以世界级结果被多方远程确认。
- scene goal：让“武神诞生”从主角自身状态，变成敌方撤退、盟友恢复行动意志的社会事实。
- pre-state：各地盟友把主角视作最后希望但无法确认生死；敌方仍在推进。
- expanded beats：先给主角晋升完成；再切到不同地点感知异常；敌方最高战力因“武神”撤退；盟友先不敢相信，再赶赴确认。
- compressed/omitted beats：不安排主角逐一通报，也不复述完整能力参数。
- state-changing exchange：没有传统对话，身份由不可忽略的现象与敌人撤退共同完成认证。
- opponent/other-character reaction：敌方从扩张转为备战/撤退；盟友由绝望转为追随和重新部署。
- body/space/detail selection：雷霆、各地人物的同步反应、敌方回撤方向，证明“身份”已改变全局行动许可。
- ruler/reader model：读者追问“是否连最危险的对手都按此身份调整行动”；敌方撤退给出答案。
- stop point：盟友确认身份后进入下一阶段大战，不继续重复宣告。
- unique anchor：`武神`

**Interpretation**

最高等级的身份确认可以不靠自报，而靠一个所有关键方都无法忽略、并会据此改策的结果。

**Transfer observation**

若身份规格极高，优先让权力格局的可见变化完成认证；旁白命名只做必要收束。

**Anti-inference**

不能把大范围异象当作通用替代方案；只有当故事已建立多方能识别其后果时，它才不是空泛特效。

# Cross-Window Findings

1. **身份信息只有被接收者转化为行动权时，才值得占据场景核心。** 卧底任命、紧急调兵、集体防守、进入关键区域，都在真相落地后立即发生。[ID-DGF-01, ID-DGF-02, ID-DGF-05, ID-DGF-11]

2. **公开范围随“行动所需的最小知情集”变化，而不是随真相的重要性扩大。** 一对一救援可私下自曝；群体需要共同承担风险时才以信物、名望和到场完成公开；高误判风险的亲近关系则先验证不揭穿。[ID-DGF-02, ID-DGF-04, ID-DGF-05, ID-DGF-06]

3. **身份揭露后的反应应按利益与位置分叉。** 同一身份可使一部分人撤出、一部分人求名挑战、一部分人重建保护义务；“全场震惊”无法替代阵营变化。[ID-DGF-03, ID-DGF-09, ID-DGF-12]

4. **可信度应绑定可观察证据，而非靠角色相信。** 组织结构推断带来正式任命；信物和到场形成群体信任；亲笔文件与交叉确认带来行政执行；敌手撤退完成最高规格认证。[ID-DGF-01, ID-DGF-05, ID-DGF-10, ID-DGF-12]

5. **不揭露也必须改变局势。** 延迟揭穿用于避免伤害关系或避免无收益暴露；持续伪装则会让敌方形成可能危险的错误模型，不能被写成无成本保护。[ID-DGF-06, ID-DGF-07, ID-DGF-08]

# Counterexamples & Boundaries

- 标题写“身份暴露危机”的第一卷第一百七十四章，实际只有恒远因口误产生怀疑，尚未发生站队、权限或保护关系改变，不可当作完整揭露场景证据。
- 第二卷第二百一十九章说明：高概率识别不等于应立即揭穿；若对象无法立刻提供关键行动、误判会伤害关系，应保留验证空间。[ID-DGF-06]
- 第三卷第三十三章说明：伪装会驱动敌手误判和升级追查；不能把“不说真名”写成自动降低风险。[ID-DGF-08]
- 第四卷第一百二十五章《地书和守门人》有大量世界观真相，但窗口内主要是解释结构更新，缺少同场、可归因的社会行动改写；不作为正面 Scene Skill 证据。
- 第五卷第一百一十三章《监正的身份》涉及高阶身份结论，但本轮未将其纳入主证据：其直接行动链跨多个宏观战场，难以在单一 bounded window 内可靠归因。

# What Existing Skill Misses

当前 `identity_reveal` 已要求不同知识层和实际选择，基础判断是正确的。新增价值不在重复“揭露后要有反应”，而在补足以下判断能力：

1. **最小知情集判断**：先问“谁知道后能立刻做不同的事”，再决定公开给谁，而不是默认把秘密交给现场所有人。
2. **行动权账本**：明确揭露后谁获得调兵、进入、庇护、撤手、追杀或代表他人承诺的权利。
3. **揭露与保护能力联动**：高风险身份一旦触发敌意，必须同拍给出掩护、窗口、盟友站位或撤离路径。
4. **延迟揭露也要有场景结果**：验证、静默、共同遮蔽、敌手误建模都可改变状态；不能把“暂不说”写成无事发生。
5. **认证形式选择**：本人坦白、短句确认、信物、文书、能力结果分别适合不同权力关系；不应只靠口头揭晓。

# Candidate Transfer Rules

1. **规则：先选能兑现行动的人。**

   - applicability：身份信息能改变救援、授权、准入、结盟或撤离。
   - 写法：先让接收者接到可行动事实，再在必要处支付身份解释。
   - stop rule：接收者已下令、让路、撤手或承担保护义务时停止。
   - failure pattern：所有人听到身份都很震惊，但无人改变计划。

2. **规则：公开范围等于当前任务所需的最小知情集。**

   - applicability：秘密关系、匿名网络、脆弱亲属或多方利益并存。
   - 写法：区分“能知道”“必须知道”“现在知道会造成额外风险”的角色。
   - stop rule：错误行动被纠正、必要协作已启动，不追加无关观众。
   - failure pattern：为制造高潮而全场公开，反而让保护、潜伏或关系线失去理由。

3. **规则：揭露后要分叉，不要齐声。**

   - applicability：至少三名角色对身份有不同利益、旧账或权力位置。
   - 写法：给出相反方向的行为反应，例如撤离、加价、挑战、遮掩、调兵。
   - stop rule：新阵营/站位已经清楚，进入其造成的下一行动。
   - failure pattern：把所有角色写成同一种震惊，场景没有新的社会结构。

4. **规则：危险真相必须带着保护能力出现。**

   - applicability：身份一旦确认就会引来捕杀、争夺、胁迫或政治抢夺。
   - 写法：同场交代暴露触发什么、谁能挡住、主角在多长窗口内能完成何事。
   - stop rule：主角已借窗口改变位置或完成关键动作。
   - failure pattern：先宣布高危身份，敌人却无行动、盟友也没有保护安排。

5. **规则：延迟揭露不是空拍。**

   - applicability：证据不足、误判代价高，或对象暂时不能把真相转成行动。
   - 写法：让验证、暂缓、误导或共同保密明确改变后续可说/不可说的边界。
   - stop rule：角色已决定下一次验证条件或保密责任。
   - failure pattern：角色“怀疑了”后既不测试、也不调整关系或部署。
