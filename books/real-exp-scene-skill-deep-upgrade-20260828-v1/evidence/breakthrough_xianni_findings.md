# Cross-Window Findings

1. 真正的突破至少有两个不同层面的确认：内部门槛完成，加上一次新行动或外界重新定价。仅有感悟、半步、资源入体或称号都不够。`[BX-01, BX-03, BX-05, BX-08, BX-11]`

2. “资源足够”与“能突破”在原著里被反复拆开：资源解决承载、维持或燃料；理解/结构解决真正门槛。`[BX-03, BX-04, BX-09, BX-12]`

3. 高价值的失败不是跌落，而是让人物获得对旧瓶颈的更准确命名，并迫使下一步策略改变。`[BX-01, BX-02, BX-04]`

4. 突破后的第一行动优先用于改变当前困局，而非立刻报数值：破困、救人、反制、转移、开启新行动空间。`[BX-01, BX-07, BX-08, BX-10, BX-11]`

5. 社会证明可延后，且不必是庆贺：对手逃跑、强者震惊、旧规则失效、旁观者被迫重估，都可作为证明。`[BX-01, BX-03, BX-08, BX-09, BX-13]`

# Counterexamples & Boundaries

- “看见第三步”只改变方向感和心态，不改变修为，不能写成突破。`[BX-06]`
- 婴变资源大量投入、肉身改造开始，也仍可因为资源不足而主动中止。`[BX-04]`
- 青灵星悟道只到“半只脚”，必须经历后续天劫和稳定过程。`[BX-08]`
- 同境界内从中期到后期、社会称号授予、模拟世界中的战力提升，都不应伪装成跨层突破。
- 连续跃迁常依赖本书罕见组合：道果、封印、裂缝无天劫、特殊血身、传承座椅等；不可被抽成通用升级公式。`[BX-07, BX-10, BX-11]`

# What Existing Skill Misses

现有 `breakthrough_advancement` 已正确提出“旧上限—条件—门槛—首次体验”的基本骨架，但本批证据带来四项非近义新增能力：

1. “阶段判定”能力：明确区分尝试、半步、局部成功、稳定突破、社会证明，避免把感悟或资源吸收误判为成功。
2. “瓶颈归因”能力：要求写清资源解决什么、身体解决什么、理解解决什么；禁止用同一类“能量不足”覆盖全部障碍。
3. “结构性门槛”能力：高阶场景不只问能量是否够，还要问旧结构是否已被替换、重排或补齐。
4. “兑现时序”能力：突破后先让新状态解决当前局面；社会证明可放在后续公开场景，避免当场变成数值说明会。

# Candidate Transfer Rules

1. **规则：先标阶段，再写推进。**
   Applicability：读者可能把顿悟、资源吸收、半成品误读为成功的突破场。
   Stop rule：若尚无新结构/新行动，不得称“突破完成”。
   Failure pattern：把“有感觉”“已经半步”直接写成境界跨越。

2. **规则：每个条件只承担一个明确职责。**
   Applicability：突破同时存在资源、身体、理解、关系或环境压力。
   Stop rule：能用一句话说清“它解决哪一个门槛”后停止补设。
   Failure pattern：堆叠资源名词，却无法解释为何先前仍失败。

3. **规则：把失败写成诊断交换。**
   Applicability：旧方案确实被证明不可行。
   Stop rule：失败已经改变人物对瓶颈的判断、资源选择或行动目标。
   Failure pattern：重复受伤、吐血、运功，但下一步仍做同一件事。

4. **规则：成功后立刻安排一次只在新层级可完成的行动。**
   Applicability：突破对当前危机、关系或行动空间有直接影响。
   Stop rule：该行动已经证明旧门槛失效，即切出或转入下一主场景。
   Failure pattern：成功后只报境界、气息与旁白赞叹。

5. **规则：社会证明延后也成立。**
   Applicability：突破发生在私密闭关、险境或无人可见区域。
   Stop rule：后续一次真实冲突已迫使他人重新定价。
   Failure pattern：为了证明突破，硬塞围观者、庆贺和排名。

6. **规则：高阶突破要补齐“结构缺口”，不能只加量。**
   Applicability：多能力、多本源、双路线或力量互斥的升级。
   Stop rule：明确缺口被补齐，并写出一个仍存在的适应代价。
   Failure pattern：多种力量同时暴涨却不写冲突、整合或后果。
