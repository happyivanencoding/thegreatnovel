# Research Question

提取近身肉搏、身体性力量、野性压制、巨物/巨力战与 dominance payoff 的可迁移、可追溯判断：该写什么受力与落点，如何由环境和对手身体结果承载力量，何时延展，何时短收。

# Evidence Windows

### DS-E01-TIGER-GRAPPLE

- 章节：第三十章《逐虎过涧》；行 1447–1503；anchor：`双手抓住两只虎爪`
- **Evidence**：山路猛虎扑击，主角站稳抓爪、掀翻，却被虎身反弹；虎转为逃跑，追猎被压缩为一天一夜，最终扛虎回庄。对手从扑杀者变为逃跑者，县令、猎户与庄民改为敬畏。承载细节是斜坡、虎口腥风、虎尾、肩扛重量与新增伤痕。
- **Interpretation**：野性近战可保留一次“硬接未彻底解决”的身体结果，再由路线、耐力和公共目击兑现压制。不能推成近身硬接必一击制敌。

# Cross-Window Findings

1. **力量的首要标尺是抗力对象的结果，而不是招式名或等级。**岩壁、湖水、门寨、弩阵、岩浆河、巨兽口腔、山峰、敌方骨骼、群体战术变化都让读者自行估值。
   Evidence：DS-E01、DS-E03、DS-M03、DS-M04、DS-L01、DS-L02、DS-R01。

2. **身体细节只在改变下一拍时保留：受力、失稳、变形、恢复、再受力。**拳面见骨、玄甲裂、撕皮、虎骨粉碎、石躯开裂都对应新动作或胜负条件，非肌肉与伤口目录。
   Evidence：DS-E04、DS-M02、DS-M03、DS-M05、DS-L02。

3. **战斗长度应走三分支，而不是统一回合数。**互有抗力且交换持续改写身体/位置时延展；一次接触已改写关系与路线时短收；不可战时展示威胁后撤离。
   Evidence：延展 DS-M02、DS-M03、DS-L02；短收 DS-E02、DS-M01、DS-R01；撤离 DS-L03。

4. **dominance payoff 必须发生“再定价”。**对手认输、群体溃散、旁观者改态度、敌方改策略、路线或资源归属改变，才是压制结果完成。
   Evidence：DS-E01、DS-E03、DS-M01、DS-L02、DS-L04、DS-R02。

5. **野性不是吼叫或兽喻，而是让对方原有的身体策略失效，并被具体边界约束。**潜伏被三步截停、毒咬被撕皮化解、河床边界锁住角力、巨口转为通路、撤离边界否决硬战。
   Evidence：DS-M01、DS-M05、DS-L02、DS-M04、DS-L03。

# Counterexamples & Boundaries

- DS-E01：第一次掀虎并未结束战斗；需用追逐和耐力兑现。
- DS-E04、DS-M02：武器、寒潮、毒宝可以让强体真实受创，不能把受伤写成“无事发生”。
- DS-E05：巨物互殴会制造尺度，却不必决定最终胜负。
- DS-M03：巨物战初段攻击无效，后段胜利依赖敌方消耗、环境与突破，不能只写意志爆发。
- DS-L01：无对手的承压测试属于突破 payoff，不属于近身 combat。
- DS-L03：敌我差距不可战时，撤离比虚假的来回对招更有力量。
- DS-R02：重复碾压在读者已确认抵抗模式无效后必须压缩，但保留资源消耗，避免无代价感。

# What Existing Skill Misses

现有 [`combat.md`](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/combat.md:3) 已有“优势分配、真实回应、压缩重复、结果落到身体/位置/旁观者、适时停点”；总库也已要求不改 Canon、结果成立后不追加抽象总结。

真正新增的判断能力是：

1. **抗力标尺选择**：不是泛称“写环境／身体结果”，而是判断当前该由岩壁、器物、对手结构、场地边界或群体行为中的哪一两种承载力量尺度。
2. **战斗长度路由**：明确区分“对等可延展／碾压短收／绝对劣势撤离”，避免只凭胜负尚未宣布而硬续。
3. **身体变化的因果支付**：突破、变身、恢复要由先前承受的压力、损伤或失效方式支付，并在第一次改变受力传递时兑现。
4. **野性压制的边界绑定**：用河床、出口、目标、护持对象或逃逸线把野性动作变成任务压力，避免反复咆哮。
5. **dominance 的再定价要求**：身体结果后至少发生一个真实价格变化：认输、退避、改策、资源转移、身份变化或路线改变，而非集体换词惊叹。

# Candidate Transfer Rules

1. **抗力标尺规则**
   - applicability：本场核心是肉身力量、压制或力量估值。
   - rule：最多选两类抗力对象，写出位移、破坏、失稳、穿透或恢复的结果，再补一个身体或他者反馈。
   - stop rule：读者已经能比较力量级别，且结果改变下一步行动。
   - failure pattern：反复轰同一堵墙；只报“巨大、恐怖、几重境界”。

2. **三分支长度规则**
   - applicability：进入 combat 前已能判断双方抗力、当前目标与是否存在可战阈值。
   - rule：对等且每拍改变身体/位置则延展；碾压只写代表性接触与对手失去选择；绝对劣势写威胁尺度后转撤离。
   - stop rule：认输、新目标、失去行动能力或逃生路线成立时停。
   - failure pattern：所有敌人写成等长度回合；为“有戏”硬塞反转。

3. **身体支付规则**
   - applicability：变身、突破、修复或肉身强化需在场内兑现。
   - rule：先给热、裂、疲惫、失控或抗性失效；只展开到它第一次改变力量传递、落点或承伤方式。
   - stop rule：新能力已被抗力对象证明。
   - failure pattern：逐块罗列肌肉骨骼；瞬间满状态；身体变化不影响下一动作。

4. **野性边界规则**
   - applicability：需要兽性、原始冲撞、贴身压迫。
   - rule：先给一条物理或任务边界，例如不能出圈、目标不能逃、必须守住出口；每个野性动作必须推进边界状态。
   - stop rule：边界改变或目标失能。
   - failure pattern：动物比喻、怒吼和狠话很多，位置、任务与代价不变。

5. **dominance 再定价规则**
