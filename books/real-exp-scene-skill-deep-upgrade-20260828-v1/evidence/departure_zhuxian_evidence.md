  - **state-changing exchange**：张小凡从道德反驳转为不能轻率离开她；照料关系倒置。

  - **pre-state**：他离开血池是为赶回寒冰石室；认定鬼王仍在看守碧瑶。
  - **expanded beats**：鬼先生死亡留下未完遗言；鬼厉发现鬼王已离岗；逆着逃亡人潮回去；石室石台空了；他发现绿衣碎角与不应存在的脚印。
  - **compressed/omitted beats**：不立刻交代碧瑶去向；不让鬼厉当场获得全部答案。
  - **state-changing exchange**：鬼厉此前选择离开危险现场，返回后失去“继续守在她身边”的可能。
  - **other-character reaction**：逃亡者只求自保；小白后来通过碎衣角理解大致情况并救走昏厥的鬼厉。
  - **body/space/detail selection**：逆流人群、碎石、空寒冰台、绿衣角、脚印、割裂流血的手。
  - **ruler/reader model**：空缺要落到先前有明确用途的位置上；读者能一眼辨认“原来这里应有什么”。
  - **stop point**：鬼厉昏倒，小白带他离开正在坍塌的石室。
- **Interpretation**
  - 最强的失去证据不是旁白说“没有了”，而是角色抵达原本必须有人在的位置，发现其功能已被清空。
  - **transfer observation**：可先让角色为一个合理目标离开，再用返回时无法逆转的空间事实呈现代价。
  - **anti-inference**：不要把空位自动解释为死亡；本窗只证明失踪、夺取或转移，真相仍应保留。

## ZX-D12

- **章节 / locator**：卷八·第十四章《灵牌》；source lines **27378–27413**；anchor：`无字空牌`
- **Evidence**
  - **scene posture/type**：失去后由仪式与物件完成的迟到承认。
  - **scene goal**：道玄在祠堂中面对万剑一之死与旧关系。
  - **pre-state**：祠堂仍维持常规香火与牌位秩序；道玄试图以跪拜恢复秩序。
  - **expanded beats**：黑气扰动牌位；一块无字牌跌落；道玄被其触发，拾起后称“师弟”；离开后，林惊羽发现空牌已被以血写上灵位。
  - **compressed/omitted beats**：不回放二人的全部历史，不用道玄独白解释悔恨。
  - **state-changing exchange**：无人面对面交谈；道玄把未被正式承认的死者写入共同秩序。
  - **other-character reaction**：林惊羽先疑惧，后通过牌位变化发现已经发生的决定。
  - **body/space/detail selection**：香、灵位、跌落的空牌、血字、祠堂风声。
  - **ruler/reader model**：物件变化应同时改变社会/关系意义；读者不仅看到遗物，而是看到“谁被允许进入何种秩序”。
  - **stop point**：血写灵位被林惊羽看见。
- **Interpretation**
  - 物件可以承载失去，但要把它写成一次可复核的制度性或习惯性改动。
  - **transfer observation**：前后对照最好是“原本空白/未归位 → 被明确安置”，而非只给遗物特写。
  - **anti-inference**：血字不能泛化为悲伤表达；它服务于此处压抑、失控与迟到承认。

## ZX-D13

- **章节 / locator**：卷八·第十五章《召唤》；source lines **27494–27535**；anchor：`终于离去了`
- **Evidence**
  - **scene posture/type**：明知可能失去对方，仍回归责任的主动离开。
  - **scene goal**：陆雪琪在张小凡昏睡时离开草庙村，回青云应战。
  - **pre-state**：她已决定抛开约束，守在张小凡身边；张小凡刚从失去中恢复。
  - **expanded beats**：紧急信号出现；她说明青云危局、自己能留下也能回去；承认舍不得及可能无法再见；亲吻后慢慢离开且不回头；小灰留在张小凡身边观察其手指反应。
  - **compressed/omitted beats**：不让张小凡醒来批准她；不展开战争本身。
  - **state-changing exchange**：她放弃即时相守，选择回归师门；张小凡被留下，随后自行起身决定前往青云。
  - **other-character reaction**：小灰先惊讶白衣消失，再坐在张小凡胸口守着；张小凡醒后改变行动方向。
  - **body/space/detail selection**：紧急剑形信号、断壁、草地、慢行而不回头的背影、小灰的位置。
  - **ruler/reader model**：主动离开成立于“可留下”的欲望充分可见，而职责以当前不可替代的危机压过它。
  - **stop point**：她离去；随后只保留张小凡醒来并起身的最小结果。
- **Interpretation**
  - “分别是选择”不是宣称责任伟大，而是让读者看见角色主动放弃什么，并立刻看到谁被留在原地、谁接住后果。
  - **transfer observation**：责任型离开可不等对方醒来；但必须已有共同状态、明确紧急理由与留下者的可见后果。
  - **anti-inference**：若角色没有可见替代项，此类场景应写作被迫失联/撤离，不应伪装成高尚选择。

# Cross-Window Findings

- **缺席最有力的证明，是第一个被迫改写的行动，不是离别宣言。**
  大巫师离开后族长接责（ZX-D03）；鬼厉离开后空房与遗信让他人接手（ZX-D04）；张小凡返抵石室后无法继续守护碧瑶（ZX-D11）；陆雪琪离开后小灰留守、张小凡改向青云（ZX-D13）。
  这不是“多写后续”，而是用一个已被改变的行动权限证明旧状态结束。

- **“谁仍在等”必须是行动状态。**
  大黄持续守遗体、陆雪琪明确等鬼厉（ZX-D08）；鬼王进入空石室继续守候并调整策略（ZX-D10）；小灰在陆雪琪离开后留在张小凡身侧（ZX-D13）。
  等待若未改变人物的选择、风险或站位，只是情绪背景，不构成 departure evidence。

- **物件、空间、习惯只有带前后基线时才是失去证据。**
  残烛由老人独自替换（ZX-D02）；旧路已不可行、旧屋只可跪拜（ZX-D06）；空寒冰台与绿衣残角（ZX-D11）；无字牌被写成灵位（ZX-D12）。
  共通点是“原本怎样被使用”与“现在无法怎样使用”均可从窗口中复核。

- **主动分别与纯粹失去应分开选技。**
  林惊羽被放行（ZX-D02）、大巫师离乡（ZX-D03）、鬼厉拒绝同行（ZX-D05）、陆雪琪回援青云（ZX-D13）都有可见替代项及主动取舍；田不易死亡（ZX-D07）、碧瑶失踪（ZX-D11）则应首先写物理后果、未完成行动与信息缺口。
  不应把死亡、昏迷、灾难撤离自动命名为“选择”。

- **最小停点常在“空缺被读者确认”的一刻。**
  大巫师过出口（ZX-D03）、空房和遗信（ZX-D04）、第一滴泪（ZX-D05）、空石台（ZX-D11）、血写灵位（ZX-D12）。
  再追加同义哭诉通常不会增加状态。

# Counterexamples & Boundaries

- **不是所有照料都是分别。** 卷一、二滴血洞中的互相照料建立的是“有人陪伴”，尚未形成真实离开；不能把护理、病重或短暂分开直接套为 vacancy。
- **不是所有物件都是有效缺口。** 合欢铃在 ZX-D10 中只显示空间异动，不能据此断言碧瑶已醒或作出选择；无文本授权时，物件不能替人物发言。
- **死亡当刻不应强塞延迟象征。** ZX-D07 首先让遗体、最后托付和幸存者下一步成立；空房、遗物、习惯变化更适合余波窗口。
- **公共送别不可复制到私人关系。** ZX-D03 的跪送来自共同依赖与公共权威；私人离别可以像 ZX-D05、ZX-D09 一样收在未说出口、停留、转身或之后的照看。
- **“不回头”只在回头确会改变决定时有效。** ZX-D13 已充分建立陆雪琪想留的欲望与紧急责任；若角色本无犹豫，不回头只是装饰。

# What Existing Skill Misses

当前 `departure_vacancy` 已经正确覆盖：离开不是移动或伤感、留下者遇到第一个问题、旧状态结束、以及以新决定或关系变化为停点。它不缺“缺席导致必须独自行动”这一大原则。

真正新增的判断能力只有三项：

1. **持续等待的行动化状态**
   现有规则提及期限、承诺与召回器，但未明确要求判断“谁仍在等，以及等待如何改变其当下选择、风险、资源或路线”。ZX-D08、ZX-D10、ZX-D13 显示，等待者必须是行动者，而非背景中的哀伤者。

2. **物件 / 习惯 / 空间的前后基线对照**
   现有通用写作层允许使用物件与空间；新增点不是“多写遗物”，而是识别：离开前的反复使用或稳定位置，如何在离开后变为空置、替代、改用或无法完成。ZX-D02、ZX-D06、ZX-D11、ZX-D12 支持这一点。

3. **分别的能动性判别**
   现有卡允许安排、目标与拒绝，但未要求区分：角色是否看得见“留下”的替代项，并主动接受离开的即时损失；还是死亡、失联、沉眠、灾难撤离。ZX-D02、ZX-D03、ZX-D05、ZX-D13 与 ZX-D07、ZX-D11 构成边界。

不应误报为新增的能力：

- “不能再做什么、必须独自决定”已在 `departure_vacancy`。
- “用物件、空间、身体和他人反应落地”已是通用 Reader-First 要求。
- “牺牲留下缺口”已有 `sacrifice_convergence`。
- “重逢后不自动恢复原状”已有 `reunion_reentry`。

另：当前运行时已登记 `departure_vacancy` 等事件型 Skill，但 `.agents` 的 Primary 清单未列出它们；这是 catalog/documentation mismatch，不是能力不存在。Scene Skill v2 仍是研究假说，不应据此直接修改生产技能。

# Candidate Transfer Rules

1. **先找“第一件做不了的事”。**
   - **applicability**：重要人物已离开、失联、死亡或暂不可用，且场景需要证明缺席。
   - **rule**：选一项此前已有使用基线的动作、位置或责任，让留下者第一次发现它无法按旧方式完成。
   - **stop rule**：该失败、替代或改用已迫使一个新决定时停止。
   - **failure pattern**：只写空椅、遗物、落泪，却没有任何行动或关系权限改变。

2. **把等待者写成会改变路线的人。**
   - **applicability**：Canon 已明确约期、守候、照料、未归者或召回器。
   - **rule**：等待者必须至少改变一次当前行动：留下、延后、替代看守、拒绝离开、转向搜寻或承担新风险。
   - **stop rule**：等待已影响一次可见决策，不再重复倒计时。
   - **failure pattern**：把“我会等你”当情绪标签，后续行为完全不受影响。

3. **判定分别是否为选择，再决定写法。**
   - **applicability**：角色可能留下，也可能离开。
   - **rule**：先明确可留下的具体收益，再明确必须离开的当前压力；离开者以行动接受损失，而非口头宣言。
   - **stop rule**：替代项、取舍与即时后果均已可见。
   - **failure pattern**：角色只是被追赶、昏迷或死亡，却被写成主动牺牲。

4. **用“后一个空间镜头”承接离开。**
   - **applicability**：离开本身无法完整显示空缺，或离开者与留守者目标不同。
   - **rule**：切到原位置，让读者看见谁补位、谁缺位、旧物如何仍在运作或停止运作。
   - **stop rule**：空间的新使用关系已明确。
   - **failure pattern**：切镜头只重复离别情绪，未增加新的责任、风险或信息。

5. **遗留物只在改变秩序时使用。**
   - **applicability**：已有物件、地点、仪式或习惯能被角色重新使用、安置、放弃或改名。
   - **rule**：呈现“前状态 → 被谁以何种行动改变 → 新状态”，避免让物件代替人物作心理发言。
   - **stop rule**：读者已能从变化推回关系位置或可做之事。
   - **failure pattern**：连续罗列遗物，或为每件物品附加未经 Canon 支持的寓意。

# Source Fidelity Audit

- **定位可信度：高。** 上述 13 个窗口均以 GB18030 解码后的 `splitlines()` 复核，均给出卷、章、精确行号与短 anchor。
- **未纳入的候选：**
  - 卷一/二滴血洞互相照料：有陪伴与死亡恐惧，但尚无离开/失去造成的新状态，排除。
  - 卷一第四十四章《金铃》：有铃与旧人遗迹，但核心是发现法宝及其来历，不足以证明当前人物的分别机制，排除。
  - 卷四第五章《心意》：战后余波和人物移动为主，未见足够明确的离开后行动重分配，排除。
  - 卷八第十三章《依偎》：可作为 ZX-D11 后续理解，不独立纳入，避免与“空石台—绿衣角”重复取证。
- **未作推断：**
  - 不把合欢铃异动解释为碧瑶的清醒、意愿或承诺。
  - 不从任何单一窗口推出《诛仙》全书普遍的离别法则。
  - 不把角色计划、传闻或他人猜测提升为已发生事实。
