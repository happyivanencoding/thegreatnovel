# Cross-Window Findings

1. **欲望先改变“看什么”，才改变“做什么”。**人物先把人群看成肥羊、宗门看成仓库、顶层看成不能不看的未知，之后才会靠近、强征或继续上楼。用目标重分类替代“他很想要”。
   证据：LUE-D01、LUE-D05、LUE-D09、LUE-D13。

2. **诱惑最有力的场景尺子是“本可安全离开，却亲手取消退出”。**完成采集后去宝库、已得令牌后上第九层，都是先建立退出权，再由报复或未知收益夺走它。
   证据：LUE-D05、LUE-D09、LUE-D01。

3. **高价值物不必只造成抢夺；它会重排注意力任务。**候清忘记复核，修行者明知有坑仍要入门，仙帝因关键资源重新计算攻击，说明欲望的可写后果是优先级重排。
   证据：LUE-D02、LUE-D11、LUE-D14、LUE-D15。

4. **同一场景内，欲望可以竞争并轮换主导权。**方行先拒救再倾囊，随后马上重启逐利；法门诱惑压住救亲承诺；仙藏前的欲望又被救命债和资格压住。
   证据：LUE-D07、LUE-D11、LUE-D12。

5. **面子与关系欲望应落在具体权限上。**谁能上桌、谁有资格拿、谁被公开轻视，比“尊严受损”更快启动行动，也更能让旁人作出反应。
   证据：LUE-D06、LUE-D10、LUE-D12。

6. **风险阈值上调必须有现场凭据。**小塔的安全余量、可解禁制、敌手互相牵制，分别让原本不值得的动作变得可试；并且原著给出一次性消耗、意外守楼、十息倒数等边界。
   证据：LUE-D04、LUE-D08、LUE-D09、LUE-D14。

# Counterexamples & Boundaries

- **不是所有见宝者都会抢。**仙王传承前，鹿叟等人因救命债、共同经历与所有权正当性停步。LUE-D12。
- **不是所有极高价值物都能成交。**佛门僧人面对珍贵经书仍拒换，因为他真正要的是神秀而非外物；本次未列入主窗口，但定位为第847–848章，54995–55045。
- **不是所有诱惑都意味着失智。**鹿叟与敖烈在 LUE-D11 中仍能陈述理由，危险恰在他们清醒地接受未知代价。
- **不是所有关系都压过自利。**LUE-D03 中柳三的怜悯未能改变钱通的牺牲方案。
- **不是所有风险升级都可复制。**LUE-D08 的强闯以一次性小塔为前提；LUE-D14 的毁宝威胁以对象价值、火焰能力和三方牵制为前提。

# What Existing Skill Misses

现有 `resource_economy`、`hunt_acquisition`、`social_bargain_decision`、`relationship` 已能处理资源配置、取得、条件谈判与关系边界。新增的、非近义重复的判断能力是：

1. **诱惑进入场景的判定。**不是“资源出现”就转资源戏，而是判断新对象是否已使人物改看目标、缩短安全距离或放弃退出点。
2. **欲望优先级冲突的编排。**现有 Skill 会写取舍；本研究补充“自利、关系、面子、求知、报复分别在何时赢过彼此”，并要求用行为顺序而非解释证明。
3. **风险阈值的来源。**区分“有一次性安全余量所以敢试”“时间压力所以强征”“对手互相牵制所以敢抢”，避免把胆大写成无来由的性格。
4. **对象的社会化变形。**宝物可从资源转为诱饵、公开羞辱工具、谈判底牌或敌方合作的裂缝；这不是单纯估值变化。
5. **退出点作为欲望引擎。**在角色已可离开的时刻引入高一阶机会，能准确区分“自然升级”与“无端贪心”。

# Candidate Transfer Rules

1. **退出点诱惑**
   - **Applicability：**角色已完成当前目标，且有明确安全离场路径；新机会只高一阶并可见。
   - **Rule：**先确认“可以走”，再给未结面子账、未知高层或额外收益；让角色亲自取消退出。
   - **Stop rule：**新风险或新守卫一旦改变场景问题，停止继续加宝，转入逃脱、谈判或战斗。
   - **Failure pattern：**角色还没完成原目标就突然贪新物，读者会把它看成编剧拖延。

2. **诱惑导致的注意力劫持**
   - **Applicability：**交易、传承、竞拍、探宝中，人物必须在复核/撤离与抢占机会间选择。
   - **Rule：**让人物先把注意力投向“如何拿到”，从而漏掉一项本应完成的检查、边界或关系承诺。
   - **Stop rule：**漏洞已造成具体后果后，不再重复说明角色贪心。
   - **Failure pattern：**让人物无理由降智，或没有可见对象却声称“被诱惑”。

3. **关系与自利的顺序对撞**
   - **Applicability：**角色确有资源、风险顾虑和一段足以触发行动的关系。
   - **Rule：**先让其明确拒绝或计算风险，再以实际资源交付、改道或承担后果证明关系暂时胜出；随后允许资源焦虑重新接管行动。
   - **Stop rule：**资源转移与关系边界已成立后，结束救助场，转入下一资源行动。
   - **Failure pattern：**用空泛心软替代代价，或把一次善意写成稳定人格结论。

4. **公共资格触发面子行动**
   - **Applicability：**场景存在可见的座位、入场资格、称谓、分配权或公开评价。
   - **Rule：**先让对方在具体权限上排除角色/同伴，再让被排除者以能改变秩序的动作回应。
   - **Stop rule：**资格或位置已重新分配，立刻让场内人反应，不再延长骂战。
   - **Failure pattern：**只有辱骂没有资格损失，导致冲突烈度显得凭空。

5. **多方自利反制**
   - **Applicability：**至少三方围绕同一关键资源竞争，且彼此并不完全信任。
   - **Rule：**夺取或威胁毁掉一小部分关键资源，使原本联合的对手重新计算“谁先出手谁获益最少”。
   - **Stop rule：**对手的合作已转回互防，马上兑现短暂行动窗口。
   - **Failure pattern：**把该结构写成主角永久压制强敌，忽略资源、能力与时间的局部条件。
