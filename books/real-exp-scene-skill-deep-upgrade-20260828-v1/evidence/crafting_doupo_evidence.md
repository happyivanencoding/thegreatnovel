# Evidence Windows

### DPC-01

- **Evidence**：第72章《初学炼药》—第74章《不请自来》，2934–3039。
- **scene posture/type**：新手首制＋低阶商品进入家族困局。
- **scene goal / pre-state**：主角要做出疗伤药；尚不能稳定控制火温，家族正被对手的低价疗伤药压缩生意。
- **expanded beats**：药材连续烧毁→辨认“温度过高”→首次提纯；三种材料进入融合时，一处升温、一处保温的双重控制险些失手；成品药液形成。
- **compressed/omitted beats**：后续连续数日炼药被压成“库存增长”，不逐瓶复演。
- **state-changing exchange**：由“连单材也烧毁”变成“有可用疗伤药库存”；制作直接接入家族的市场对抗。
- **opponent/other-character reaction**：师父只在关键错误处短评；家族成员以竞争方产量、价格和销售损失衡量药物价值。
- **body/space/detail selection**：封闭山洞、鼎面观察口、汗与斗气耗尽；细节只服务“火候不可同时粗暴处理”。
- **ruler/reader model**：读者看的不是配方，而是“能否把失控的局部状态稳住，并让成品进入真实需求”。
- **stop point**：首次成药并显出它能改变家族供给问题时停止。
- **Interpretation / transfer observation**：新手戏可把“单材提纯成功”和“多材兼容成功”分成两个阶段门；每阶段只展示一次可诊断失败。
- **anti-inference**：不能据此推成“所有制作都要先烧掉大量材料”；本窗的试错由初学与低阶材料支撑。

- **state-changing exchange**：成品不是展示物，而是把后续行动从“会伤及经脉/心神”改为“有可承受的保护条件”。

- **Interpretation / transfer observation**：当制作是行动的必要前置，应展开“该成品对应哪种失败”，而非泛写成品光泽。
- **anti-inference**：这不是“每件成品都必须当场使用”；这里只有前置防护与后续行动紧密相连。

- **Interpretation / transfer observation**：不可逆事故到来时，制作戏可转为“保中间态”而非硬续全部程序。
- **anti-inference**：不能把“炸炉后奇迹救回”设成常规模板；该救场以已完成的中间成品和场内剩余时间为前提。

- **opponent/other-character reaction**：鉴定者通过纹路、品质、作用与底价重估制作者身份；态度随成品变化。

- **stop point**：价格已把成品转成后续行动资源，且制作者获得新身份待遇后停止。
- **Interpretation / transfer observation**：同一批制作里，先保底、后冲上限，能让风险选择具备可见经济理由。
- **anti-inference**：不表示所有制作都应引入拍卖或金币；市场评估只适用于当前冲突就是资源不足的场景。

- **anti-inference**：不是“每次公开制作都要多轮淘汰”；三份机会和失败品评分属于此场裁决结构。

### DPC-06

- **scene posture/type**：长期修复型制作。

- **compressed/omitted beats**：近一个月的常规守火、材料逐株转液被叙述压缩；只保留首个顽固材料、阶段完成、临界耗尽。
- **state-changing exchange**：药液并非成形即算成功，目标器物出现生机与声波反应才改变状态。
- **opponent/other-character reaction**：护法者从冷言旁观到准备救援；其反应标出制作者身体代价，而非替代疗效证明。
- **body/space/detail selection**：悬崖、隔绝场、发白脸色、火焰闪烁、药液缩小。
- **ruler/reader model**：长时制作的张力来自“能否撑到目标真正吸收”，不是逐日增加新药材。
- **stop point**：药力已传递、目标显出明确恢复征兆、制作者越过极限时停止。
- **Interpretation / transfer observation**：延迟生效的制作，要把“成品形成”与“作用对象发生变化”分开设为两个状态门。
- **anti-inference**：不意味着长时制作必写到力竭；这里的延长由修复目标、材料抗性与长期守火共同造成。

### DPC-07

- **Evidence**：第929章《大动静》—第932章《丹成》，45966–46127。
- **scene posture/type**：高阶定制丹药的准备、异常诊断与外援解法。
- **scene goal / pre-state**：主角先等状态恢复、备足材料，才公开开炼；高等级血液在融合阶段超出配方平衡。
- **expanded beats**：主材分别提炼；强血与药力冲突撞击药鼎；主角识别问题不在手法而在输入强度；常规调和失败后，引入具备针对性优势的外部血液，才解除压制。
- **compressed/omitted beats**：成功后的多日稳定融合被压成守火与等待，只保留此前异常已经解决的事实。
- **state-changing exchange**：从“照方仍失败”变为“材料性质改写原方案”；外援不是增加火力，而是提供能压住异常输入的特定条件。
- **opponent/other-character reaction**：围观者不能直接介入，以免破坏制作；外援主动指出普通药物无效的原因。
- **body/space/detail selection**：公开石台、震响的鼎壁、带尖刺般形态的血液、制作者视野受压。
- **ruler/reader model**：读者追问不是“再加多少材料”，而是“错误来自步骤还是输入本身，谁拥有正确的相克条件”。
- **stop point**：异常被确实解除，后续进入缓慢融合等待时停止。
- **Interpretation / transfer observation**：制作故障应先定位“工序错”还是“输入超出工序适用范围”；后者不能靠重复同一操作解决。
- **anti-inference**：不能把特殊外援写成临场万能解药；本窗外援的有效性来自其与异常源的明确关系。

### DPC-08

- **Evidence**：第1049章《火菩丹》—第1050章《融合》，52146–52243。
- **scene posture/type**：多人协作的高阶制作。
- **scene goal / pre-state**：三人共同完成七品高级丹药；发起者擅长提炼，但融合精度不足，且现场需被隔离。
- **expanded beats**：先分配职责与部分配方；提炼者分批处理，另外两人只接手净化后的药力融合；八个阶段最终收束为一次高风险总融合。
- **compressed/omitted beats**：连续多日的守火与重复批次不逐批描写，以“第几轮、体力是否支撑、外界评价变化”结算。
- **state-changing exchange**：协作成员从被质疑的年轻人，变为能提前完成关键融合、被资深同行重新定价的参与者。

- **ruler/reader model**：协作制作的读点是“谁负责哪一类不可替代失误”，而非三人同时做同一件事。
- **stop point**：八份中间产物齐备，总融合成为唯一未解问题时停止。
- **Interpretation / transfer observation**：多人制作应按失误类型分工，并把最终汇合设为新的风险门。
- **anti-inference**：不是所有高阶制作都必须协作；本窗合作源于能力结构互补，而非单纯凑人数。

### DPC-09

- **Evidence**：第1118章《苦修炼丹》—第1124章《灵魂境界》，55994–56335。
- **scene posture/type**：闭关训练的叙述压缩。
- **scene goal / pre-state**：主角为接近大会标准进行高频训练，尚不能稳定完成目标级别成品。
- **expanded beats**：正文保留的是训练代价、临门失败痕迹、出关后的控制变化，以及旁人对新状态的辨认。
- **compressed/omitted beats**：二十余日的绝大多数逐炉尝试、送药材、常规守火全部跳过。
- **state-changing exchange**：失败没有被逐次戏剧化；真正改变的是灵魂与控火更精细，之后能够承担更高门槛。

- **Interpretation / transfer observation**：熟练期制作可用“投入量＋失败残留＋出关后的新操作能力”三点压缩，不复播工序。
- **anti-inference**：不能将所有闭关一笔带过；若某次失败改变材料、关系或路线，就应独立展开。

### DPC-10

- **Evidence**：第1180章《炼丹开始》—第1181章《丹雷屡现》，59371–59459。
- **scene posture/type**：大型竞赛中的长周期高阶炼制。
- **scene goal / pre-state**：竞争者都在公开场内炼制，主角材料仅有有限备份，目标成品远超多数选手。
- **expanded beats**：先批量提炼普通材料；主材抗火、长时转化被单独展开；一次微小偏差使某材料直接放弃重提；三种关键精华进入十日融合。
- **compressed/omitted beats**：五天到十天的稳定融合、其他选手的常规进展主要以时间跳跃和场外丹雷收束。
- **state-changing exchange**：失败不是立即失败出局，而是消耗唯一备份、提高后续选择压力；中间雏形形成后，竞争焦点从“能否开始”转向“能否稳住至成丹”。
- **opponent/other-character reaction**：观众按丹雷与剩余选手判断等级；对手存在让主角的材料与时间压力具备外部尺。
- **body/space/detail selection**：大量悬浮材料、石台、长时静默、偶发炸炉声、成形前的三团精华。
- **ruler/reader model**：高阶制作的关键不是材料数量，而是“最后可替代材料何时被消耗、是否还能承担下一次偏差”。
- **stop point**：最难融合已越过，产品进入孕育期时停止。
- **Interpretation / transfer observation**：有限备份下，微小误差本身就足够产生风险，不必再附加敌袭或额外阴谋。
- **anti-inference**：不推出“高阶制作必须十日以上”；时长是此物阶、竞赛形式和材料性质共同造成的。

### DPC-11

- **Evidence**：第1385章《炼丹》—第1387章《解决》，71067–71213。
- **scene posture/type**：公开制作作为组织秩序重建的证明。
- **scene goal / pre-state**：组织内部的制作部门失序、人员倚仗身份；主角炼制高阶温和成品，服务于孩子的长期体质需求。
- **expanded beats**：数百材料与长时炼制被压缩为流畅的高阶操作；丹雷由专人承受；成品随后被实际服下并呈现温和初效。
- **compressed/omitted beats**：三日炼制过程不逐项展示，只保留围观规模、丹雷、收丹和后续用药。
- **state-changing exchange**：公开成功先建立能力权威，随后权威才能支撑对组织奖惩与资源规则的重新执行。
- **opponent/other-character reaction**：围观者欢呼、旧管理者回避；受用者的家属以谨慎提问确认成品适配性。
- **body/space/detail selection**：要塞、人群、五色丹雷、婴儿服药后的柔光。
- **ruler/reader model**：一件消耗品的价值既可由受用者证明，也可由它是否改变群体对制作者的服从关系证明。
- **stop point**：首次适配反应已出现，且公开能力已转化为下一项组织行动的正当性。
- **Interpretation / transfer observation**：当成品承担社会权威时，先完成可见证明，再进入制度处置；不要把两者并写成口头宣言。
- **anti-inference**：不意味着公开炼制天然有统治力；本窗的组织效果建立在既有责任、公开见证和实际成品上。

### DPC-12

- **Evidence**：第1568章《丹雨》—第1569章《借玉》，80912–81010。
- **scene posture/type**：极高阶制作的异常合流与最终保全。
- **scene goal / pre-state**：雏丹能量不足，且对手、他人雏丹与外部能量都已卷入；成功率本就有限。
- **expanded beats**：异火把不同来源的雏丹能量净化后再投入；异象、雷劫、成品逃逸；制作者把“炼成”之后的收服也作为完成的一部分。
- **compressed/omitted beats**：前期数日提炼、常规能量聚集不再重复；只保留异常能量并入是否改变成败。
- **state-changing exchange**：成品出现不等于结束；雷劫、逃逸与收容决定它是否真正归属制作者。
- **opponent/other-character reaction**：现场炼药者震动、部分人觊觎又被威慑；资深者因此承认其地位。
- **body/space/detail selection**：丹雨、雷云、逃离的成品、容器与封印。
- **ruler/reader model**：对具有自主性或高风险的成果，完成线是“形成—经受最后条件—被稳定占有”，不是第一眼看见。
- **stop point**：成果已收容、外部抢夺意图被压下、社会评价发生变化时停止。
- **Interpretation / transfer observation**：若成品会逃逸、失控或反噬，最终保全应是制作场的最后一拍。
- **anti-inference**：不能把所有成品人格化或附加雷劫；此窗只支持“成果形成后仍可能有必要的交付/保全门”。

# Cross-Window Findings

1. **只展开“状态跨门”的工序，而不是完整流程。**
   值得展开的是：单材能否提纯、多材能否兼容、雏形能否稳定、异常输入能否被处理、成品能否被保全；稳定守火和重复批次可压缩。证据：DPC-01、02、06、07、10、12；反证边界：DPC-09。

2. **失败要改变下一步的可选项，而非充当固定戏剧税。**
   失败可消耗备份、暴露“配方正确但输入不适配”、迫使止损，或把目标改成保全中间态。证据：DPC-03、04、05、07、10；反证边界：DPC-08 的协作过程没有靠失败制造张力。

3. **中间产物应有明确的“质量传递”。**
   上一阶段不是背景：提纯物决定能否融合，雏形决定是否能救场，完成的药液决定能否进入修复，有限备份决定下一步能否继续。证据：DPC-01、02、03、07、10。

4. **制作完成与价值成立通常是两步。**
   价值可由市场估值、裁决比较、受用者反应、组织行动空间或稳定收容证明；应依当前冲突选择一种，而非统一增加围观者。证据：DPC-04、05、06、11、12；反证边界：DPC-02 的重点是行动前置条件，不必等市场或公众评价。

5. **公开压力只在它能改写制作选择时才进入镜头。**
   比赛规则、倒计时、围观和对手会影响保全、风险承担或裁决；纯私密学习、修复和闭关不需要硬塞观众。证据：DPC-03、05、10、11、12；反证边界：DPC-01、06、09。

# Counterexamples & Boundaries

- **不必公开证明。** DPC-01、02、06 的核心价值来自家庭危机、后续身体风险或修复对象，不来自舞台喝彩。
- **不必每次失败。** DPC-08 的张力来自职责切分与总融合，不需要“炸一次炉”。
- **不必展开长时工作。** DPC-09 把数十日训练压缩为投入、失败痕迹与能力变化；DPC-06 只在耐性本身接近极限、且疗效尚未发生时才把长期守火拉近。
- **不可随意救场。** DPC-03、07 的救场都有已成立的中间状态或特异相克条件；没有这些已建立条件时，应报废、延期或改路线。
- **成品不必都走售价。** DPC-04 适合鉴价，DPC-11 适合受用者反应，DPC-12 适合收容；错误做法是把三种证明全部堆进同一场。

# What Existing Skill Misses

当前 [crafting_creation.md](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/crafting_creation.md:5) 已覆盖“材料反馈→调整”，第 7 行已要求压缩重复工序，第 9–11 行也已覆盖检查、使用与转交 `showcase_evaluation` / `resource_economy`。因此，“不要教程化”“成品可见”“有评价”“有首次使用”不是新增贡献。

真正可新增的判断能力只有三项：

1. **阶段门，而不是泛反馈。**
   现有文本没有要求 Writer 判断“哪个中间态一旦成立，就把风险传递给下一阶段”。DPC-01、02、07、10 反复显示：提纯物、融合物、雏形、有限备份都不是装饰性进度条。

2. **不可逆窗口中的三选一：继续、保全、报废。**
   现有规则允许返工，却未要求在材料已投入、容器将毁、时间将尽时明确选择。DPC-03、04、05、07、10 支持该判断；它不能退化为固定的“主角总能救回”。

3. **制作场受到外部压力时，应先保护哪个已成立状态。**
   现有库允许不同场景切换，但没有制作侧的切换规则。DPC-03、07、10、12 表明：外部压力到来后，读者关心的常常已不是下一道工序，而是中间态、成品或归属能否被锁住。

“消耗品要用实际效果证明价值”不列为新增：现有 `crafting_creation` 与相邻 Skill 已能覆盖，避免近义重复。

# Candidate Transfer Rules

1. **阶段门展开规则**
   - **applicability**：当前制作至少存在一个会决定后续能否融合、成形、使用或保全的中间状态。
   - **rule**：只展开该状态的形成、它返回的可观察信号，以及由信号强制产生的下一步；其余连续加工压缩。
   - **stop rule**：中间状态稳定并把问题移交给下一阶段时停。
   - **failure pattern**：把每种材料、每次火候都写一遍，读者却不知道哪一步改变了成败。

2. **不可逆窗口决策规则**
   - **applicability**：存在有限材料、倒计时、容器损坏、体力枯竭或无法重做的输入。
   - **rule**：故障出现后，先让人物判断：继续完成、保住已成形部分，还是立刻报废止损；选择必须改变后续资源或胜负条件。
   - **stop rule**：救回、止损或报废已经成为不可逆事实时停。
   - **failure pattern**：每次故障都靠临时加码成功，导致风险失去可信度。

3. **压力下的成果保全规则**
   - **applicability**：外部竞争、干扰、雷劫、抢夺或场地崩坏，能威胁到已存在的中间产物或成品。
   - **rule**：将主问题切换为“该保护什么、放弃什么、用何种既有条件保护”；不要继续播报配方。
   - **stop rule**：成果已安全交付、收容、失去或被正式裁决时停。
   - **failure pattern**：把制作与比赛/战斗割裂，危机发生后人物仍机械完成原流程。

4. **消耗品价值证明路由规则**
   - **applicability**：成品外观不足以说明价值，且当前冲突属于市场、竞争、关系义务或身体风险之一。
   - **rule**：只选一种对应证明：市场用独立估值/交易，竞争用可比裁决，关系义务用受用者变化，危险物用稳定收容。
   - **stop rule**：所选证明已改变人物可获得的资源、关系、资格或行动空间时停。
   - **failure pattern**：成品一出现就堆叠价格、掌声、疗效、排名和传说，反而稀释当前戏的主问题。
