# Cross-Window Findings

1. 牺牲者的意愿必须在支付前落到可拒绝的具体选择上，而不是事后由旁人代为证明。SE-02 先给三尾逃路；SE-05 碧瑶先推开张小凡；SE-06 大巫师对族长说明自己会客死；SE-13 玲珑先回应兽神的具体愿望；SE-14 水月主动挡下死亡。`[SE-02, SE-05, SE-06, SE-13, SE-14]`

2. 被救者／受托者的资格应由已见行动、可承担的未来责任或可守住的边界支撑，不能只靠“关系亲近”。张小凡因可守秘密而被托付；审问者只以亲见战斗作担保；鬼厉因具备未来应对兽妖的可能而被大巫师下注；小环先显示施术天赋与不放弃救人，才获得鬼先生传承。`[SE-01, SE-04, SE-06, SE-08, SE-11]`

3. 救援的即时结果必须改变场上力量或行动资格；悲伤可后置，结果不能模糊。普智改变两名孩子的生存路径；碧瑶把张小凡推出主剑攻击；小环救回野狗且被鬼先生救下；水月阻止陆雪琪自尽并打出脱离围杀的空隙。`[SE-01, SE-05, SE-10, SE-14]`

4. 不可逆付出不能只用“死亡”一笔带过，至少应留下身体、关系、制度或行动链中的长期缺口。二狐死亡后遗物也不能抵消失去；碧瑶残魂令所有人转为长期求救；大巫师死亡留下骨灰、失魂的幸存者与苗寨继任；水月死后文敏必须接续遗命。`[SE-03, SE-05, SE-09, SE-12, SE-14]`

5. 后续恢复若存在，必须带保留条件或永久变化；若失败，失败本身要继续驱动人物。碧瑶残魂并不等于已复原；大巫师验证可救部分后仍失败；小环的成功需要鬼先生介入并留下师徒债；玲珑的“复生”以失去不死性为条件。`[SE-05, SE-08, SE-09, SE-10, SE-11, SE-13]`

6. 反例边界：不要为制造悲壮而抹掉可行出口或强迫角色牺牲。SE-02 恰恰先让六尾要求三尾逃走，三尾才拥有可见的拒绝权；SE-10 中周一仙明确反对小环继续，证明“愿意救”不自动授权她自毁。`[SE-02, SE-10]`

7. “救人之心”不能自动洗净行动后果。普智确有救人、托付与临终代价，但其方案又导致草庙村惨案，后文以公开揭露使张小凡与林惊羽承担长期创伤。`[SE-01, SE-14]`

# Counterexamples & Boundaries

- 三尾妖狐窗口表明，牺牲不应是唯一被叙事允许的选项：六尾先提出脱身方案，三尾才拒绝。若角色没有真实退出权，所谓“自愿”缺乏证据。`[SE-02]`
- 小环窗口表明，施救者的愿望与受术资格不是一回事。她缺少关键残魂条件，且代价会损及寿命与根基；若无鬼先生介入，场景不能诚实地把它写成成功。`[SE-10]`
- 大巫师窗口表明，救援甚至可以失败；不能因牺牲者已死，就强行补一个复原结果安慰读者。`[SE-09]`
- 普智窗口是关键反证：救援、遗愿与牺牲不构成道德免罪。若方案把无知受托者放进无法承担的风险，后续必须让伤害显影。`[SE-01, SE-14]`
- 玲珑窗口只支持神话尺度的“恢复附带永久降格”，不支持把一般伤亡随意改写成可复活设定。`[SE-13]`

# What Existing Skill Misses

当前 `novel-scene-skills` 把 Sacrifice 列为 Modifier，但未给出以下新增判断能力：

1. 自主性判定：区分“有退出权后仍选择”“被局势逼死”“旁人替其决定”。现有 Skill 只有类型标签，不能判断牺牲是否真正属于角色自己。
2. 受托资格判定：要求救援对象或接班人拿出已见行动、可承受风险或明确未来责任；不能只以亲密关系代替资格。`[SE-01, SE-04, SE-06]`
3. 恢复边界判定：明确“还剩什么可救”“破什么才能救”“成功或失败后永久失去什么”。现有 recovery/restoration 没有阻止恢复把牺牲抹平。`[SE-05, SE-08, SE-09, SE-13]`
4. 余波接管判定：牺牲结束后，要求至少一个幸存者承担可执行遗命、债务、补位或新任务，而不是只安排哀悼。`[SE-11, SE-12, SE-14]`
5. 非浪漫化判定：即使动机可敬，也要保留错误方案、伦理代价、被迫取舍或失败结果，避免牺牲天然正当化。`[SE-01, SE-09, SE-10]`

# Candidate Transfer Rules

1. **先给退出权，再允许牺牲。**
   - applicability：角色有可行动的替代路线，且要写其自主留下／支付。
   - stop rule：退出路线已经被现实条件彻底堵死时，不要伪造“你可以走”的选项。
   - failure pattern：角色从未有选择，却被叙述称作“甘愿牺牲”。`[SE-02, SE-05]`

2. **先写受托资格，再交付生命、秘密或责任。**
   - applicability：牺牲会把资源、使命、罪责或长期行动权交给幸存者。
   - stop rule：若受托者没有可核验行动，只能交付有限任务，不可直接授予全盘责任。
   - failure pattern：用“他是主角／他们关系好”替代资格，导致托付像作者指定。`[SE-01, SE-04, SE-06, SE-11]`

3. **把代价拆成动作前、动作中、动作后三段。**
   - applicability：高风险救援、禁术、以命换命、长期耗损。
   - stop rule：代价已由此前正文充分建立时，不重复堆叠同一病痛描写。
   - failure pattern：只在高潮报一句“燃尽生命”，之前身体无损，之后世界无痕。`[SE-07, SE-09, SE-14]`

4. **恢复必须保留不可逆状态。**
   - applicability：救魂、续命、复原、复生、夺回失物。
   - stop rule：若故事明确要写完全康复，必须另给足以承担代价的后果，不能两边都要。
   - failure pattern：牺牲后立刻痊愈、复活或获得等价奖励，使前一场付出失去重量。`[SE-05, SE-08, SE-09, SE-13]`

5. **用幸存者的下一次行动完成牺牲的余波。**
   - applicability：牺牲者留下明确遗命、债务、线索或空缺。
   - stop rule：牺牲者没有留下可执行内容时，不强造遗言；可改写为制度缺口或关系断裂。
   - failure pattern：葬礼／哭泣结束后，幸存者行为与牺牲前完全相同。`[SE-11, SE-12, SE-14]`

6. **把失败作为结果，不把失败当成过场。**
   - applicability：高代价尝试存在真实失败概率。
   - stop rule：若结果已由上游合同固定成功，不额外制造假失败。
   - failure pattern：失败后立刻开启更强方案，牺牲者与失败成本没有留下任何行动限制。`[SE-09, SE-10]`
