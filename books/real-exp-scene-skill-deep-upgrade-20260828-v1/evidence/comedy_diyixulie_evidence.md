- compressed/omitted beats：主角的无耻自夸只用一次，不反复占据会议。
- state-changing exchange：反常答谢使全场停顿；真正的状态变化却由指挥官自首承担责任、主角击晕带走完成。
- opponent/other-character reaction：三名师长愣住；严肃人物用转话题把会场拉回正事；副官与监察兵最终协助。
- body/space/detail selection：指挥营帐、辞职信、白色监察制服、击晕与全军敬礼。
- ruler/reader model：读者先被“没按剧本来”打断，再被牺牲决定压回战争伦理。
- stop point：主角带人离开、士兵敬礼后，停止继续开玩笑。
- **Evidence**：短锚点“全体将士一起谢我”。
- **Interpretation**：严肃会议的笑点可以来自礼仪预期被打偏，但必须由更高代价的选择迅速重新定调。
- transfer observation：在组织危机中，失礼一拍只适合做节奏折点；随后必须落到责任、授权或行动。
- anti-inference：不是把军政场景写得轻浮；笑点没有否定失败后果。

### DYS-C12

- 章节 / 行：第1069章《交易》；56526–56572。
- scene posture/type：伪俘虏在生死交易中故意讨价还价。
- scene goal：拖延、取得亲随身份并进入敌方体系。
- pre-state：主角表面被法术困住；敌手以杀其主人施压。
- expanded beats：主角先演出焦急，再反问报酬；敌手把抗拒误判为忠诚与可投资性；主角提出无关紧要的变羊要求和做饭要求；敌手终于识别拖延，给其上铐。
- compressed/omitted beats：第二个荒诞要求后即被对手截断；不再连续加条件。
- state-changing exchange：绵羊人被再次变形制造笑点；敌手以“耐心有限”结束，手铐将场景从口头交易改为实际囚禁。
- opponent/other-character reaction：绵羊人无辜受害且困惑；敌手由得意转为收紧控制。
- body/space/detail selection：灰袍、地缚、发亮器物、镣铐、受害者的物种变化。
- ruler/reader model：读者可看出主角在演、反派看不出；笑来自反派把拖延当忠诚，回压来自实际束缚。
- stop point：手铐戴上、队伍出发。
- **Evidence**：短锚点“变成羊”。
- **Interpretation**：伪装型喜剧的上限由对手的容忍度决定；对手一旦升级控制，主角不能继续索要笑点。
- transfer observation：在敌我信息不对称中，荒诞要求可测试对手的误判深度；必须让对手最后做出改变约束的动作。
- anti-inference：没有主角暗中优势或合理拖延目的时，不应用无厘头条件替代谈判。

### DYS-C13

- 章节 / 行：第1185章《回马枪》；62557–62635。
- scene posture/type：旁观者把“通缉主角”误当成可利用的战略捷径。
- scene goal：建立敌方即将引入中土势力的威胁，并让主角转向调查。
- pre-state：敌方正讨论如何借他人之手对付主角；一名知情者明白其危险，家主仍自负。
- expanded beats：知情者建议把麻烦引向别家；家主把此当庆祝理由；镜头切到主角与不知情部下同行；主角否认相关事件；知情同伴憋笑；新情报出现后，主角立即决定回城侦察。
- compressed/omitted beats：对被蒙骗者的嘲弄只维持在知情者的内心与短暂反应，不公开羞辱。
- state-changing exchange：主角的否认被知情者理解为惯常糊弄；但情报一出，立刻从旅途闲谈变为夜间侦察任务。
- opponent/other-character reaction：敌方庆祝；被误导者放下警惕；知情者从憋笑转为对主角能力的警觉。
- body/space/detail selection：夜行商队、篝火、扎营、远处宴会中的寒意。
- ruler/reader model：读者拥有多方信息，笑来自两个阵营分别对同一人作出错误自信判断。
- stop point：主角进入黑夜，切回威胁行动。
- **Evidence**：短锚点“十句话里”。
- **Interpretation**：戏剧反讽能带来轻快感，但真正的功能是让读者比被蒙骗角色更早感到危险。
- transfer observation：若利用读者信息优势，结尾必须让隐藏真相影响下一项任务，而非只让读者优越。
- anti-inference：不能让所有配角都持续被骗；若错误判断没有现实代价，会损伤角色智力。

### DYS-C14

- 章节 / 行：第1257章《熔石为甲，挥焰成袍》；71379–71413。
- scene posture/type：阵地战前的临死群体互怼。
- scene goal：把伤员留下的决定转化为全队可执行的拖延意志。
- pre-state：营长负伤、已决定留下；所有人预期生还希望很低。
- expanded beats：士兵指出其违反禁烟规定；营长以“将死”反击；他把死亡焦虑缩小到牙齿能否被找回；士兵追问胜负；营长以近乎狡辩的方式重定义“不输”；敌军出现。
- compressed/omitted beats：敌袭一报，立即停止集体互怼。
- state-changing exchange：从对遗体的小担心，转到“把希望留给撤退者”的明确任务。
- opponent/other-character reaction：年轻士兵哭笑不得、再提出真正恐惧；营长用夸张回答替队伍稳住情绪。
- body/space/detail selection：战壕、烟、受伤右手、连在一起的手雷保险栓、潜望镜。
- ruler/reader model：笑没有降低死亡概率，反而让读者更清楚众人知道自己可能死。
- stop point：敌袭警报。
- **Evidence**：短锚点“大槽牙”。
- **Interpretation**：临战笑点在此是共同承认恐惧后的自我组织，不是把恐惧否认掉。
- transfer observation：群体临战 banter 只有在成员已共同接受代价、且下一拍有命令或敌情时才可持续两三回合。
- anti-inference：不能以“临死也要搞笑”为人格模板；这里每一回合都在建立士气与任务承诺。

### DYS-C15

- 章节 / 行：第1260章《终见光明（大结局下）》；71828–71920。
- scene posture/type：终局冲锋前后的英灵群体调侃。
- scene goal：确认众人明知绑定死亡风险仍选择共同进攻。
- pre-state：大军即将冲入最终战场；宿主死亡会连带英灵消散。
- expanded beats：英灵直问主角死亡后果；主角以年龄与辈分反击；群体反过来威胁战后群殴；主角确认准备；全体冲锋；战斗中仍有一两句针对战力差的短反应。
- compressed/omitted beats：死亡规则确认后，不再反复讨论“会不会死”；直接进入冲锋与真实伤亡。
- state-changing exchange：玩笑式威胁被“准备好了吗”收束为共同承诺，随后发生实战和牺牲。
- opponent/other-character reaction：英灵先质疑、后明确应答；外围部队受其感染折返加入。
- body/space/detail selection：金色洪流、敌军合围、坦克、装甲、倒下又重起的战士。
- ruler/reader model：笑点让群体像有旧账的战友，而非无人格的献祭单位；风险规则仍被明确保留。
- stop point：冲锋开始后，场景核心转为战术与死亡，不再维持闲聊。
- **Evidence**：短锚点“二十多万人打你”。
- **Interpretation**：在巨大牺牲前，玩笑可证明角色拥有选择，而非被叙事强迫慷慨赴死。
- transfer observation：终局群像的 banter 应先把代价讲清，再用短互怼把“我愿意”落到具体共同关系。
- anti-inference：不能以群像玩笑替代战术、伤亡与行动因果。

# Cross-Window Findings

1. 笑点的最稳固来源不是语言花活，而是人物把同一硬变量处理成不同东西：庆缜把羞辱当行动信号，任小粟把打劫当情报采集，许瞒把威胁说成常识，营长把死亡焦虑改写成队伍士气。人物声音由其“优先保护什么”产生。证据：DYS-C03、C06、C09、C12、C14。

2. 严肃剧情不靠“笑完再提醒危险”回压，而是靠一个不可忽略的物理或程序性动作：枪击、包围、枪口、手铐、敌袭、冲锋。它把对话状态变成新的行动状态。证据：DYS-C03、C09、C10、C12、C14、C15。

3. 连续抖包袱只有在每一回合都改变群体的任务承诺、关系位置或风险判断时才成立；一旦只剩同义重复，原文会用离场、警报、上铐、冲锋切断。证据：DYS-C02、C08、C12、C14、C15；反证边界：DYS-C14 的连续互怼仍在逐步处理恐惧、胜负观与守阵任务。

4. 知识不对称能产生喜剧，但其真正价值是迫使角色作出错误或延迟的选择，而不是让读者单纯优越。读者比看守、商人、反派或被误导部下多知道一层时，后续必须让该误判产生拘束、撤离、侦察或策略后果。证据：DYS-C03、C09、C12、C13。

5. 严肃自白后的玩笑只能碰边界，不能吞掉余波。DYS-C10 用枪口结束试探后才回到孤独；DYS-C15 在死亡机制说明后才允许互怼。证据：DYS-C10、C14、C15。

# Counterexamples & Boundaries

- 第306章《庆氏易主》有临死前回忆童年趣事，但缺少对手接梗和可辨的笑点状态变化；它更像人物姿态，不纳入 comedy/banter 主证据。
- 第551章《老师与学生》主要是“怀疑被好意推翻”的认知反转；没有足够的互动性笑点与回压链，排除。
- 第1012章《心疼杨小槿》可持续较长的邻里误会，是因为场景目标本来就是日常身份反讽；它不能证明高压场景也可无限续梗。
- 第1031章《庆慎与庆缜》的同句反弹有效表现关系，但窗口内没有足够严肃压力回归，不能单独支撑“严肃剧情共存”规则。
- 第1205章《大兴西北》有资源分配中的轻松反应，但主场景的证据重心是权力移交，不足以单列为 banter 窗口。
- 第1229章《大梦谁先觉》是哲学与牺牲对话；虽有尖锐口语，却不是以喜剧机制组织，排除。
- 反例边界：DYS-C14、C15 表明“危急时不可连续互动”不是绝对规则；只要每一轮都把恐惧转成共同任务，互动可延长，但敌情/冲锋一到必须停止。

# What Existing Skill Misses

当前 [`comedy_banter`](C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/comedy_banter.md) 已经覆盖：人物错位、对方按性格回应、避免共享网络机灵、第三次无新变化即压缩，以及主场景回归时退出。以下才是本批证据的新增判断，不重复这些已有条目：

1. “错位”需要标出被改写的硬变量：地位、风险、资源、时间或行动授权。若一句话没有使其中至少一项发生可见偏移，它只是俏皮话，不应展开。DYS-C03、C06、C08、C09、C12。

2. 高压 banter 必须预置“回压载体”：在最后一句前，Writer 应已知道会由谁的何种动作把场景切回现实，例如下令、上铐、举枪、警报、敌军抵达。现有 Skill 要求退出，但未要求把退出动作作为包袱结构的一部分。DYS-C03、C09、C10、C12、C14、C15。

3. 人物声线可用“目标函数”区分，而非靠称呼或口癖：有人把危险折算为收益，有人把责任折算为仪式，有人把权力折算为秩序，有人把死亡折算为队伍能否继续。这样即使移除原著专名，角色对白仍不可互换。DYS-C03、C06、C09、C11、C14。

4. 知识差型笑点需要规定“误判成本”：对方的误解至少应造成让步、暴露、错误部署或延迟反应；否则读者信息优势会变成空转。DYS-C03、C09、C12、C13。

# Candidate Transfer Rules

1. **硬变量错位规则**
   - applicability：双方对地位、风险、资源、时间或授权的理解不一致，且 scene 有明确任务。
   - rule：只展开能改写一个硬变量的笑点；把“谁把什么当成什么”写清。
   - stop rule：对手已经让步、暴露真实判断或采取强制动作时，立即转行动。
   - failure pattern：人物只是换词嘲讽，地位、选择和信息都没变。

2. **回压载体规则**
   - applicability：危险、谈判、身份试探、临战或牺牲场景。
   - rule：在写第一句 banter 前，先确定其后的实体回压：命令、武器、身体动作、警报、程序性后果。
   - stop rule：回压载体出现后，不再补“为什么好笑”的旁白或第二轮解释。
   - failure pattern：危险被角色连续无视，读者开始不信现场代价。

3. **目标函数声线规则**
   - applicability：至少两名角色在同一压力下有不同利益、职责或知识。
   - rule：让每人按其稳定优先级回答，而不是按固定口头禅回答；可问“他会把当前问题折算成什么？”
   - stop rule：两轮后若对白互换姓名仍成立，停止加梗，改用行动。
   - failure pattern：所有角色都像同一个聪明作者在抢一句更机灵的话。

4. **误判必须付费规则**
   - applicability：读者或一方角色掌握另一方不知道的信息。
   - rule：误判后的反应必须留下成本或推进：暴露策略、错误放松、接受交易、改变路线、启动调查。
   - stop rule：误判已被纠正或代价已触发，即退出反讽。
   - failure pattern：角色持续犯同一错误，只为让主角显得更聪明。

5. **临战互怼规则**
   - applicability：人物已经明确知道代价，并在等待不可避免的行动。
   - rule：每一回合只能完成一项任务：承认恐惧、确认共同信念、重定义可承受损失或确认行动。
   - stop rule：敌情、命令、冲锋或真实伤亡出现时，立即停止。
   - failure pattern：进入实战后仍维持轻松聊天，使牺牲变成无重量背景。

# Source Fidelity Audit

- 已核验并采用的 15 个窗口均有本地文件的精确行定位；没有使用网络资料、模型记忆补剧情或无法定位的章节概述。
- 已排除的候选：第88、306、551、1012、1031、1205、1229章。排除原因分别为：笑点过短而无完整交换、缺乏 banter 回应、主要是认知反转、以日常误会为主、缺少严肃回压、重心为资源移交、重心为哲学/牺牲对话。
