# Cross-Window Findings

- **缺席最有力的证明，是第一个被迫改写的行动，不是离别宣言。**
  大巫师离开后族长接责（ZX-D03）；鬼厉离开后空房与遗信让他人接手（ZX-D04）；张小凡返抵石室后无法继续守护碧瑶（ZX-D11）；陆雪琪离开后小灰留守、张小凡改向青云（ZX-D13）。
  这不是“多写后续”，而是用一个已被改变的行动权限证明旧状态结束。

- **“谁仍在等”必须是行动状态。**
  大黄持续守遗体、陆雪琪明确等鬼厉（ZX-D08）；鬼王进入空石室继续守候并调整策略（ZX-D10）；小灰在陆雪琪离开后留在张小凡身侧（ZX-D13）。
  等待若未改变人物的选择、风险或站位，只是情绪背景，不构成 departure evidence。

- **物件、空间、习惯只有带前后基线时才是失去证据。**
  残烛由老人独自替换（ZX-D02）；旧路已不可行、旧屋只可跪拜（ZX-D06）；空寒冰台与绿衣残角（ZX-D11）；无字牌被写成灵位（ZX-D12）。
  共通点是“原本怎样被使用”与“现在无法怎样使用”均可从窗口中复核。

- **主动分别与纯粹失去应分开选技。**
  林惊羽被放行（ZX-D02）、大巫师离乡（ZX-D03）、鬼厉拒绝同行（ZX-D05）、陆雪琪回援青云（ZX-D13）都有可见替代项及主动取舍；田不易死亡（ZX-D07）、碧瑶失踪（ZX-D11）则应首先写物理后果、未完成行动与信息缺口。
  不应把死亡、昏迷、灾难撤离自动命名为“选择”。

- **最小停点常在“空缺被读者确认”的一刻。**
  大巫师过出口（ZX-D03）、空房和遗信（ZX-D04）、第一滴泪（ZX-D05）、空石台（ZX-D11）、血写灵位（ZX-D12）。
  再追加同义哭诉通常不会增加状态。

# Counterexamples & Boundaries

- **不是所有照料都是分别。** 卷一、二滴血洞中的互相照料建立的是“有人陪伴”，尚未形成真实离开；不能把护理、病重或短暂分开直接套为 vacancy。
- **不是所有物件都是有效缺口。** 合欢铃在 ZX-D10 中只显示空间异动，不能据此断言碧瑶已醒或作出选择；无文本授权时，物件不能替人物发言。
- **死亡当刻不应强塞延迟象征。** ZX-D07 首先让遗体、最后托付和幸存者下一步成立；空房、遗物、习惯变化更适合余波窗口。
- **公共送别不可复制到私人关系。** ZX-D03 的跪送来自共同依赖与公共权威；私人离别可以像 ZX-D05、ZX-D09 一样收在未说出口、停留、转身或之后的照看。
- **“不回头”只在回头确会改变决定时有效。** ZX-D13 已充分建立陆雪琪想留的欲望与紧急责任；若角色本无犹豫，不回头只是装饰。

# What Existing Skill Misses

当前 `departure_vacancy` 已经正确覆盖：离开不是移动或伤感、留下者遇到第一个问题、旧状态结束、以及以新决定或关系变化为停点。它不缺“缺席导致必须独自行动”这一大原则。

真正新增的判断能力只有三项：

1. **持续等待的行动化状态**
   现有规则提及期限、承诺与召回器，但未明确要求判断“谁仍在等，以及等待如何改变其当下选择、风险、资源或路线”。ZX-D08、ZX-D10、ZX-D13 显示，等待者必须是行动者，而非背景中的哀伤者。

2. **物件 / 习惯 / 空间的前后基线对照**
   现有通用写作层允许使用物件与空间；新增点不是“多写遗物”，而是识别：离开前的反复使用或稳定位置，如何在离开后变为空置、替代、改用或无法完成。ZX-D02、ZX-D06、ZX-D11、ZX-D12 支持这一点。

3. **分别的能动性判别**
   现有卡允许安排、目标与拒绝，但未要求区分：角色是否看得见“留下”的替代项，并主动接受离开的即时损失；还是死亡、失联、沉眠、灾难撤离。ZX-D02、ZX-D03、ZX-D05、ZX-D13 与 ZX-D07、ZX-D11 构成边界。

不应误报为新增的能力：

- “不能再做什么、必须独自决定”已在 `departure_vacancy`。
- “用物件、空间、身体和他人反应落地”已是通用 Reader-First 要求。
- “牺牲留下缺口”已有 `sacrifice_convergence`。
- “重逢后不自动恢复原状”已有 `reunion_reentry`。

另：当前运行时已登记 `departure_vacancy` 等事件型 Skill，但 `.agents` 的 Primary 清单未列出它们；这是 catalog/documentation mismatch，不是能力不存在。Scene Skill v2 仍是研究假说，不应据此直接修改生产技能。

# Candidate Transfer Rules

1. **先找“第一件做不了的事”。**
   - **applicability**：重要人物已离开、失联、死亡或暂不可用，且场景需要证明缺席。
   - **rule**：选一项此前已有使用基线的动作、位置或责任，让留下者第一次发现它无法按旧方式完成。
   - **stop rule**：该失败、替代或改用已迫使一个新决定时停止。
   - **failure pattern**：只写空椅、遗物、落泪，却没有任何行动或关系权限改变。

2. **把等待者写成会改变路线的人。**
   - **applicability**：Canon 已明确约期、守候、照料、未归者或召回器。
   - **rule**：等待者必须至少改变一次当前行动：留下、延后、替代看守、拒绝离开、转向搜寻或承担新风险。
   - **stop rule**：等待已影响一次可见决策，不再重复倒计时。
   - **failure pattern**：把“我会等你”当情绪标签，后续行为完全不受影响。

3. **判定分别是否为选择，再决定写法。**
   - **applicability**：角色可能留下，也可能离开。
   - **rule**：先明确可留下的具体收益，再明确必须离开的当前压力；离开者以行动接受损失，而非口头宣言。
   - **stop rule**：替代项、取舍与即时后果均已可见。
   - **failure pattern**：角色只是被追赶、昏迷或死亡，却被写成主动牺牲。

4. **用“后一个空间镜头”承接离开。**
   - **applicability**：离开本身无法完整显示空缺，或离开者与留守者目标不同。
   - **rule**：切到原位置，让读者看见谁补位、谁缺位、旧物如何仍在运作或停止运作。
   - **stop rule**：空间的新使用关系已明确。
   - **failure pattern**：切镜头只重复离别情绪，未增加新的责任、风险或信息。

5. **遗留物只在改变秩序时使用。**
   - **applicability**：已有物件、地点、仪式或习惯能被角色重新使用、安置、放弃或改名。
   - **rule**：呈现“前状态 → 被谁以何种行动改变 → 新状态”，避免让物件代替人物作心理发言。
   - **stop rule**：读者已能从变化推回关系位置或可做之事。
   - **failure pattern**：连续罗列遗物，或为每件物品附加未经 Canon 支持的寓意。
