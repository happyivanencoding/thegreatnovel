# Cross-Window Findings

- 高信息对白的最小单位不是“说出一条设定”，而是“信息份额 + 对应受话者 + 该受话者的新选择”。旁人可只误读、沉默或通过反应旁观；一旦人人都能完整解释，场景会失去知识差。`DF-02、DF-03、DF-07、DF-12`

- 试探应有可损失的伪装或代价。有效试探会暴露说话者的立场、能力、欲望或信息边界；被试探者可以反制、重定义问题或仅给局部回应。`DF-02、DF-04、DF-06、DF-10`

- 身份差的作用不只是让人“客气”。它决定谁能质问、谁可沉默、谁的一个动作足以封口，以及公开位阶与私下筹码是否错位。`DF-04、DF-07、DF-09、DF-12`

- 部分披露只在保留项会改变下一轮筹码、关系安全或行动风险时成立；若保留不再影响选择，应停止拖延，转为直说或行动。`DF-03、DF-06、DF-07`；反证边界：`DF-11`

- 幽默服务压力时，笑后必须至少留下一个未被抵消的后果：伤势、面子、关系债、公开问题或下一步承诺。`DF-01、DF-08、DF-12、DF-13`

# Counterexamples & Boundaries

- 不该一律调侃：母子重逢的核心是“是否被怨恨”，文本以房间、停顿与直说承受尴尬；插科会破坏关系目标。`DF-11`

- 不该一律保留：当高位者必须让下属明白危险等级时，命令和随后的行动比继续打哑谜更有效。`DF-04`

- 不该一律让对手反问：内部权力方直接把问题改写成组织纪律，试探者只能退场；答案的缺席本身是状态变化。`DF-10`

- 不该把威胁当作长期关系筹码：对长期盟友，威胁只足以制造暂时服从，不能替代对共同风险/利益的重新估值。`DF-09`

# What Existing Skill Misses

当前 Skill 已有的部分不应重复提案：对白改变筹码、对手不是接口、幽默不能抹掉后果、关系需经反应成立、身份揭露需有差异化反应，均已有明确控制。[social_bargain_decision.md](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\social_bargain_decision.md:5)、[comedy_banter.md](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\comedy_banter.md:5)、[relationship.md](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\relationship.md:5)、[identity_reveal.md](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\identity_reveal.md:5)

真正新增、且有上述原著窗口支持的判断能力是：

- 知识—受话者路由：每轮高信息交换指定“真正听懂/只猜到/假装理解/只从反应旁观”的角色分工，避免群像轮流解释。现有身份揭露的知识层级只覆盖 reveal，未覆盖普通试探、谈判与玩笑。`DF-02、DF-03、DF-12`

- 公开位阶与私下筹码分离：不是隐藏身份揭露，而是已公开的位阶如何限制称呼、质问、打断、玩笑和让步；一句话可不揭露新事实，却重置谁有资格说话。`DF-04、DF-07、DF-09`

- 部分披露的“保留项”管理：当前技能允许隐瞒，但未要求逐轮写清本轮最小披露、仍保留的具体内容及其下一轮作用。`DF-03、DF-06、DF-07`

- 双层后果判定：关键一句对白应判断任务筹码与关系/公开面子是同向、反向，还是只改变其中一层。`DF-01、DF-06、DF-12、DF-13`

# Candidate Transfer Rules

- 规则：为每个关键交换写明“信息份额—真正受话者—旁观者的可见反应”。
  适用：三人以上、秘密/位阶/关系认知不对称的对白。
  Stop rule：真正受话者已据此改变选择或站位。
  Failure pattern：每个在场者都复述、点评或准确理解同一信息。

- 规则：把公开身份约束与私下筹码分开写；先决定角色此刻“能否直问、能否打断、能否开玩笑”，再写台词。
  适用：官场、师徒、敌我暂谈、公开婚恋/社交场。
  Stop rule：一次回应已重新划定发言资格、面子或行动权限。
  Failure pattern：只有敬称变化，没有任何实际选择、站位或行动改变。

- 规则：若选择部分披露，记录一个具体保留项，并让它在下一轮迫使对方试探、核验、让步或重新估值。
  适用：完整坦白会伤害关系、暴露行动或提前耗尽筹码时。
  Stop rule：保留项不再改变下一步选择时，改为说清或转入行动。
  Failure pattern：持续“神秘兮兮”却没有可核验风险，读者只能等待作者揭晓。

- 规则：调侃之后立刻落到一个具体后果：伤势、沉默、尴尬站位、被迫回答的问题、资源承诺或下一步行动。
  适用：熟人群像、关系缓冲、压力后的短暂换气。
  Stop rule：笑点已完成一次关系释放或面子改变。
  Failure pattern：危险刚发生就连续抖包袱，角色不受影响，后果被笑声覆盖。

- 规则：面对不能安全回答的问题，允许角色用“最小确认 + 行动”而非完整解释。
  适用：高位者、守秘者或真相尚未到揭露时机的人物。
  Stop rule：提问者已明白风险等级，并据此改道、退场或执行新命令。
  Failure pattern：只用含糊反问拖延，既不改变提问者判断，也不导向后续行动。
