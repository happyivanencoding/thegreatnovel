# Research Question

财富、宝物、面子、机会如何先改变人物的注意力、行动与风险阈值；它们又如何同自利、好奇、报复、关系和责任竞争，而非只由旁白宣布“很重要”。

# Evidence Windows

### LUE-D01｜鬼市的高价假象变成洗劫入口

- **章节 / 定位：**第12–14章《道门鬼市》→《大收获》；804–964；锚点：`一群肥羊`
- **Scene posture/type：**资源匮乏下的隐秘交易，转诱饵式掠夺。
- **Evidence：**
  - **scene goal / pre-state：**方行灵石耗尽、修行停滞；进入禁令下的鬼市求资源。
  - **expanded beats：**先让在场者围观高价“宝物”，再让贪利者凑近；迷烟放倒众人后，按先前观察到的交易物逐个收取。
  - **compressed/omitted beats：**普通交换只作为“场内物资与人心已被点燃”的背景。
  - **state-changing exchange：**高价承诺换来靠近与失去警惕，实际交换变成方行取得灵石和贮物戒。
  - **opponent reaction：**受害者醒后先核对自己所得与所失；因各自也有不能见光的物件，未形成共同追责，反而继续顺手取物。
  - **body/space/detail selection：**夜谷、蒙面、围拢的脑袋、迷烟、横倒的人群，构成“欲望使安全距离消失”的可见过程。
  - **ruler/reader model：**读者先看见“人为什么靠近”，再看见靠近的代价。
  - **stop point：**方行资源足以续接修行，离场。
- **Interpretation：**诱惑不必直接令对手变蠢；它先让对手放弃安全距离，才给行动者创造窗口。
- **transfer observation：**把珍贵物放在公共视野中，并让旁人主动靠近，比先解释陷阱更能成立风险升级。
- **anti-inference：**仅适用于资源短缺、身份可遮蔽、手段已可用的场景；不能推出“贪财者必然会被洗劫”。

### LUE-D02｜黑吃黑：稀缺丹药使复核失效

- **章节 / 定位：**第25–26章《黑吃黑》→《偷鸡不成蚀把米》；1656–1788；锚点：`偷鸡不成蚀把米`
- **Scene posture/type：**稀缺资源交易中的反欺诈。
- **Evidence：**
  - **scene goal / pre-state：**候清急需真妖灵丹，且自信方行不敢公开冲突。
  - **expanded beats：**候清将注意力放到如何以副丹骗人；方行发现异常后不立刻揭穿，改以身份线索与强法器压迫对方补出真丹。
  - **compressed/omitted beats：**丹药本身的炼制说明未展开，重点留给双方的检查与误判。
  - **state-changing exchange：**候清想以假换真，最终交出真丹而自己留下假货。
  - **opponent reaction：**候清离场后才发现受骗；此前因贪求占便宜，未完成本该进行的复核。
  - **body/space/detail selection：**拿捏、验看、迟疑和离场后的回看，代替“他太贪”的评语。
  - **ruler/reader model：**看谁因目标资源而把注意力从“物品真假”移到了“怎样赢对方”。
  - **stop point：**真丹控制权完成转移，反转揭明。
- **Interpretation：**欲望常先改变的是认知任务优先级，而非直接消灭理性。
- **transfer observation：**让人物在“复核对象”与“抢占机会”间错排优先级，能把贪念写成行动漏洞。
- **anti-inference：**反转依赖赝品可混淆、双方都忌惮曝光、主角有更强反制；不适用于透明且可第三方验真的交易。

### LUE-D03｜奖励诱饵与关系性异议

- **章节 / 定位：**第30–31章《诱饵》→《妖瘴山》；2038–2089；锚点：`富贵险中求`
- **Scene posture/type：**表演出来的逐利，与他人的自利决策竞争。
- **Evidence：**
  - **scene goal / pre-state：**方行被安排为危险诱饵；同行者以飞剑、灵石等奖励包装任务。
  - **expanded beats：**他从表面恐惧转为主动打水、喂马、请教修行，借“愿为奖励冒险”的姿态换取信息与低警惕。
  - **compressed/omitted beats：**旅途日常被压缩，只保留能改变同行人判断的服务与问话。
  - **state-changing exchange：**柳三因相处产生怜悯，想改方案；钱通仍以自身风险最小化为由坚持牺牲方行。
  - **opponent reaction：**关系性不忍存在，但未能覆盖群体的自利算计。
  - **body/space/detail selection：**赶路、喂马、打水等低位动作，令“假装愿意”落在行动而非独白。
  - **ruler/reader model：**人物是否真被利益驱动，不由表态决定，而由他借此换到了什么。
  - **stop point：**同行者的真实方案与力量关系已暴露。
- **Interpretation：**这里不是“贪心使人送死”，而是方行把贪心当作可被他人相信的面具。
- **transfer observation：**当角色需要潜入他人决策结构时，可让他顺着对方设计的奖励表现兴趣，再把利益姿态转化为情报与位置。
- **anti-inference：**不能把这种伪装当成真实风险偏好证据；柳三的关系反应也未必总能改变集体选择。

### LUE-D04｜未知宝物与可疑契约的拉扯

- **章节 / 定位：**第193章《砣碑石龟》；12791–12872；锚点：`先拿到再说`
- **Scene posture/type：**未知宝物诱发接近，但风险信息阻止盲取。
- **Evidence：**
  - **scene goal / pre-state：**方行发现无法鉴定的面具，立即改变路线靠近；随后石龟现身并提出以契约换取殿内资源。
  - **expanded beats：**未知性先触发取物冲动；石龟控制大阵后，他改为试探、套问、核验契约，再利用自身已有条件伪造可控签约。
  - **compressed/omitted beats：**殿内陈设不逐件介绍，只留面具、石龟、契约和大阵。
  - **state-changing exchange：**石龟以资源换服从；方行表面承诺，取得面具与玉册后脱身。
  - **opponent reaction：**石龟为留住唯一来客而放宽承诺，后发现控制失效才发动追杀。
  - **body/space/detail selection：**王座、面具、无法移动的石龟、被调动的死门，使风险层级持续可见。
  - **ruler/reader model：**真正的诱惑不是“东西值钱”，而是“不知道它是什么且看起来不凡”。
  - **stop point：**宝物已取得、契约的欺骗后果启动。
- **Interpretation：**强诱惑可以促成接近，但不必取消策略；它可与“被控制”的风险形成连续再估值。
- **transfer observation：**未知高价值物出现后，先写角色靠近，再以新的威胁迫使其改用试探或交换。
- **anti-inference：**不可套用成“角色总能骗过契约”；本窗依赖既有可替代气息这一具体条件。

### LUE-D05｜目标已完成，报复与宝库又抬高阈值

- **章节 / 定位：**第378章《龙珠破海禁》；24697–24750；锚点：`目的达到了`
- **Scene posture/type：**完成主任务后，报复欲与额外财富欲抢走撤离权。
- **Evidence：**
  - **scene goal / pre-state：**方行已收足所需欲火，面对“撤不撤”的节点。
  - **expanded beats：**想到被龙女戏弄后，他放弃安全离场，转找宝库；宝库位置一经确认，即冒险潜海、绕禁、试探同源珠子。
  - **compressed/omitted beats：**此前采集过程被总结，重点落在撤离选择与突破禁制。
  - **state-changing exchange：**最初只是泄愤式再行动，最终获得山宝和另一件异宝，同时触发更深处异变。
  - **opponent reaction：**本窗主要由禁制、海压与隐藏机关承担“对手反应”。
  - **body/space/detail selection：**潜水、海底走廊、逐渐加密的禁制、门缝宝光，持续抬高“再走一步”的成本。
  - **ruler/reader model：**读者先看到可安全退出，再看到角色为何亲手取消这个选项。
  - **stop point：**第二件异宝到手，隐藏空间的异常开启。
- **Interpretation：**欲望竞争的强写法，是让已完成目标与新增目标在同一节点相撞。
- **transfer observation：**在“任务已完成”的节点给出一笔未结的面子账或看得见的额外收益，可自然推动越界。
- **anti-inference：**不能把这当作永远不撤退；这里有报复、可见宝光和可利用工具三重支撑。

### LUE-D06｜席位与同伴尊严压过安全收益

- **Evidence：**
  - **scene goal / pre-state：**宴席仅余一个位置，大金乌因身份被拒绝上桌；方行本可保住社交场合的安全与体面。
  - **expanded beats：**侮辱发生后，他立即击飞金丹修士，再在满场敌意中照常入席饮酒。
  - **compressed/omitted beats：**宴席礼节与旁人闲谈被压缩。
  - **state-changing exchange：**一个座位从礼仪问题转成公开权力重排。
  - **opponent reaction：**对方先默认方行会顾忌道无方；一击后众人收声，道无方不得不调停。
  - **body/space/detail selection：**被挡在席外、空席、落座饮酒，直接呈现何为“不给同伴留位置”。

- **transfer observation：**当关系欲望触发时，用座位、门槛、称谓、是否被允许进入等实体替代情绪评语。
- **anti-inference：**这是核心同伴被公开羞辱；普通讥刺不必升级到同一烈度。

### LUE-D07｜先拒绝救人，再把钱全部交出

- **章节 / 定位：**第610章《心里不舒坦》；38975–39023；锚点：`身上的钱全送人了`
- **Scene posture/type：**关系怜悯与自利、风险、资源焦虑的连续竞争。
- **Evidence：**
  - **scene goal / pre-state：**叶孤音受债务、命灯与孩子牵制；方行先明确对方缺乏交情，且其对手有元婴靠山。
  - **expanded beats：**拒绝之后，他追上去交出全部灵精与灵药；叶孤音试图以自身偿还，他拒绝；确认自己已无钱后，立刻提出再找目标抢一笔。
  - **compressed/omitted beats：**既往关系背景仅保留到足以解释他为何改主意。
  - **state-changing exchange：**资源由方行转移给叶孤音，善意以可量化损失成立。
  - **opponent reaction：**叶孤音把援助误判为可用身体偿还；大金乌先质疑，后按“钱已耗尽”的新状态接受抢夺计划。
  - **body/space/detail selection：**追上、交物、拒绝偿还、转身找“肥羊”，形成欲望先后顺序。
  - **ruler/reader model：**读者看见善意不是免费情绪，而是打断了原有资源储备。
  - **stop point：**援助已落实，资源焦虑重新接管下一步行动。
- **Interpretation：**同一人物的欲望优先级可以在一个场景内真实换位。
- **transfer observation：**先让人物明确算过风险再做资源交付，比直接善良更能写出关系赢过自利。
- **anti-inference：**并非“见人必救”；该决定受濒死儿童、共同背景与具体困境共同限制。

### LUE-D08｜保命宝物先把“能不能”变成“想不想试”

- **章节 / 定位：**第651章《拿人头来！》；41903–41926；锚点：`心痒难捺`
- **Scene posture/type：**能力/宝物给出的安全感抬高风险阈值。
- **Evidence：**
  - **scene goal / pre-state：**方行拥有一次性保命小塔；它原本应被珍重保存。
  - **expanded beats：**得知功能后，他多次在面对强敌、抢亲、闯阵等节点想试用；本次终于驾塔硬闯大阵。
  - **compressed/omitted beats：**宝物来历仅保留至足以说明用途与次数限制。
  - **state-changing exchange：**小塔换来穿阵成功与公开胜局，但一次性符文消耗。
  - **opponent reaction：**守阵者的准备与誓言被绕过，转为愤怒、憋屈和质疑“算不算本事”。
  - **body/space/detail selection：**小塔由拇指大小变成山体，撞翻元婴，再复归不起眼的物件。
  - **ruler/reader model：**风险升级不是口头说胆大，而是角色已经拥有一种能把死局改写为可试局的工具。
  - **stop point：**闯阵结果成立，消耗也明确。
- **Interpretation：**宝物诱惑的对象可以不是占有，而是“终于可以把危险玩法兑现”。
- **transfer observation：**若要写能力提高冒险冲动，先给一次明确可用的安全余量，再写人物主动寻找测试场。
- **anti-inference：**不能把能力写成无代价底牌；本窗的一次性消耗正是阈值失控后的真实边界。

### LUE-D09｜已经拿够，仍被顶层未知物拖上楼

- **章节 / 定位：**第780章《万宝九重楼》→第781章《真仙头骨》；50595–50645；锚点：`双脚不听话`
- **Scene posture/type：**盗取行动中的“退出点失败”。
- **Evidence：**
  - **scene goal / pre-state：**方行已取得多层资源与白玉令，本可离开；高层禁制、元婴坐镇使继续上行风险陡增。
  - **expanded beats：**他跳过低价值物，先取关键令牌；看到顶层仍未探索，未知与等级差使他改道破阵上楼。
  - **compressed/omitted beats：**低阶丹药、兵器和经卷被一笔带过。
  - **state-changing exchange：**已得收益不再是终点，顶层“可能更好”的猜想换来更严禁制与意外守楼者。
  - **opponent reaction：**前层守卫因不相信有人敢当众洗劫而失守；顶层守楼者的出现立即改写危险。
  - **body/space/detail selection：**楼层递进、麻袋、白玉令、汗、向上的楼梯，持续具体化“再上一层”。
  - **ruler/reader model：**每一层都在问：现在离开，还是把已得收益押给更高未知？
  - **stop point：**第九层的守楼者出现，原盗取节奏被打断。
- **Interpretation：**机会诱惑可不是“价值更大”，而是让已完成的行动突然显得不完整。
- **transfer observation：**为贪取/探索戏设置一个本可安全离场的节点；新线索应只比已有收获高一阶，足以诱发继续而不替代主线。
- **anti-inference：**不可把所有角色都写成失去刹车；这里有层级明确、禁制可解、主角能力适配等条件。

### LUE-D10｜宝物被公开拍卖，变成现金与面子的武器

- **章节 / 定位：**第915章《拍卖青月灯》；59817–59869；锚点：`拍卖青月灯`
- **Scene posture/type：**高价值物的公开化施压。
- **Evidence：**
  - **scene goal / pre-state：**方行需要现金，也因袁家先前只给一万灵精而感到被轻视；拍卖会牵动扶摇宫报复风险。
  - **expanded beats：**掌柜先因风险拒绝；方行以分成利诱、再以强硬姿态占用场地和人脉，公开放出拍卖消息。
  - **compressed/omitted beats：**宝物属性不作长篇目录化说明。
  - **state-changing exchange：**持有物变成全城可见的挑衅；文总管以十万灵精换撤回消息，方行拒绝。
  - **opponent reaction：**掌柜从交易逻辑退到保命逻辑；帝珍轩免佣仍被卷入；袁家被迫在盟友与神子间重新计算。
  - **body/space/detail selection：**下跪的掌柜、场地、人脉、公开消息，比“此物很重要”更早显出压力。
  - **ruler/reader model：**价值通过别人宁愿不赚钱、愿意补偿、却仍怕承担后果来证明。
  - **stop point：**消息已公开，外部势力被不可逆地卷入。
- **Interpretation：**财富欲与被轻视的面子感可叠加，把本可私下处理的资源推到公共冲突。
- **transfer observation：**将稀缺物从“持有”改成“公开出售/展示”，可让价值外溢为他人的选择压力。
- **anti-inference：**本窗不能简化为纯逐利；宝物同时牵连小蛮与方行的关系目标。

### LUE-D11｜法门诱惑压住求仙与救亲承诺

- **章节 / 定位：**第1302章《痴迷于道》；84782–84815；锚点：`我也要去修行`
- **Scene posture/type：**知识/力量型诱惑的失控边缘。
- **Evidence：**
  - **scene goal / pre-state：**鹿叟与敖烈接触三篇高深经义；方行判断经文可能是陷阱。
  - **expanded beats：**鹿叟明知有风险，仍愿为求道踩入；敖烈已不由自主开始修炼，哪怕姐姐仍在敌手。
  - **compressed/omitted beats：**经义内容没有被大量复述，重点放在人物开始修炼前后的自我辩解。
  - **state-changing exchange：**法门承诺“更接近道”，换取他们对既有目标与关系责任的暂时降权。
  - **opponent reaction：**方行以求仙、救姐等既有欲望反问；两人仍以“修成也许更有帮助”自我合理化。
  - **body/space/detail selection：**焦躁、沉默、讪讪回应、已经开始运功，显示诱惑从阅读到行动的跨越。
  - **ruler/reader model：**不问“他们是否被迷惑”，而问他们明知有坑后仍愿拿什么下注。
  - **stop point：**方行意识到强阻会耗损关系，无法用命令解决。
- **Interpretation：**最强诱惑可让人物保持清醒，却主动重排价值顺序。
- **transfer observation：**写力量/知识诱惑时，让角色说出清醒理由并立刻做不可逆的第一步，比写失神更危险。
- **anti-inference：**本窗不证明法门一定有害，也不证明二人愚蠢；原文保留了其收益可能。

### LUE-D12｜仙藏在眼前，仍受救命债与资格约束

- **章节 / 定位：**第1371章《仙王传承》；89595–89622；锚点：`不好意思直接上手`
- **Scene posture/type：**强财富欲被关系债与正当性暂时压住。
- **Evidence：**
  - **scene goal / pre-state：**传承地禁制解除，众人面对完整仙藏。
  - **expanded beats：**肥猪弟子先冲入通道抢拿；鹿叟等人眼热却停住，先看方行态度。
  - **compressed/omitted beats：**仙藏品类只按经卷、丹药、珍宝等层级掠过。
  - **state-changing exchange：**方行宣示所有权；其他人因他开启传承、曾救命、共同闯关而暂不争夺。
  - **opponent reaction：**有人不满、有人嘀咕，但无人立即动手。
  - **body/space/detail selection：**通道、药香、珠光、冲进去的弟子与停步的同伴，构成两种欲望反应。
  - **ruler/reader model：**同一份财富面前，谁冲抢、谁等待，揭示的不是财富大小而是关系位置。
  - **stop point：**所有权边界已被公开确认。
- **Interpretation：**欲望的反例必须写成行动：不拿、等对方表态、接受不利分配，才算边界成立。
- **transfer observation：**让同一奖赏面对不同债务/资格的人，能避免“见宝必抢”的单调群像。
- **anti-inference：**这只是当下不争，不代表人物不觊觎，亦不代表所有权永久无争议。

### LUE-D13｜救人压力把“备货”改成公开征掠

- **章节 / 定位：**第1249章《我就是在抢》；81390–81427；锚点：`我本来就是在抢`
- **Scene posture/type：**时间压力下的资源强征。
- **Evidence：**
  - **scene goal / pre-state：**龙女被带走五日，方行急需星空物资；神主只给出部分准备。
  - **expanded beats：**他把神道院直接看作资源仓，破山、列出肉酒灵丹灵精与符器等“税额”，随后逐家搜刮。
  - **compressed/omitted beats：**物资用途不逐项解释，紧迫时间成为唯一持续尺子。
  - **state-changing exchange：**“税”这一体面标签被对方质疑后，方行直接承认是抢。
  - **opponent reaction：**修士先想抵抗，察觉实力差距后转为隐匿与事后告状。
  - **body/space/detail selection：**断山、清单、抗议与后续文书，把力量差和时间差可视化。
  - **ruler/reader model：**欲望先把“一个宗门”改看成“可补齐缺口的仓库”，行动规模随后才扩大。
  - **stop point：**资源征集模式建立，反抗转为无力的事后反应。
- **Interpretation：**这不是纯粹贪财；救人急迫与力量碾压共同压低了他的冲突门槛。
- **transfer observation：**若人物为紧急目标需要资源，先写他重新分类眼前对象，再让其改变称呼、报价与行动规模。
- **anti-inference：**缺少时间压力或压倒性力量时，不能直接复用为强征戏。

### LUE-D14｜宝树、仙园与“不能烧”的谈判

- **章节 / 定位：**第1628章《坐下来好好谈谈》→第1630章《十息》；105925–106109；锚点：`捞一票走人`
- **Scene posture/type：**多方争夺中，欲望与关系性约束竞争。
- **Evidence：**
  - **scene goal / pre-state：**方行面对天元大罗与神主，硬碰无胜算；太虚宝宝暗示可夺物逃走。
  - **expanded beats：**他先想带走太虚宝树，却因仙园草木曾主动选择自己而迟疑；随后将这种迟疑转换为公开归属主张，现身谈判并以焚毁仙园威胁。
  - **compressed/omitted beats：**仙园草木不作逐株描写，保留其“被选择”的关系意义。
  - **state-changing exchange：**双方想抢药，方行以毁宝能力迫使停手；对方再以他的性命与长生欲施压，限定十息。
  - **opponent reaction：**攻击意愿随“仙园会不会被毁”的成本重新计算；双方都暴露出对宝树高于普通仙药的欲望。
  - **body/space/detail selection：**火焰、仙园、十息倒数，把谈判的价值与时间压力外化。
  - **ruler/reader model：**资源并非单层价值：可取仙药、核心宝树、可毁底牌分别推动不同选择。
  - **stop point：**十息限制成立，场景转入即时取舍。
- **Interpretation：**让对象先成为关系上的“不能随便拿”，再成为战术上的“不能让人拿”，可避免单纯宝物争夺。
- **transfer observation：**多方争物时，给关键对象配置收益、归属、毁灭风险三层价值。
- **anti-inference：**不能断言方行一定会烧尽仙园；原文只充分证明该威胁改变了对手计算。

### LUE-D15｜抢走一片天意，借三方私心止追

- **章节 / 定位：**第1809章《惟一之路？》；117918–117965；锚点：`抢来了一片天意`
- **Scene posture/type：**多方欲望互锁中的机会抢夺。
- **Evidence：**
  - **scene goal / pre-state：**三位仙帝争夺化天所需天意，九关众人陷在灾劫中。
  - **expanded beats：**方行不先救人，而是趁三帝互防抢走一片天意；三帝立刻由彼此争夺转为共同追杀。
  - **compressed/omitted beats：**灾区全貌被压缩，保留三帝的停手与九关的短暂逃生。
  - **state-changing exchange：**方行获得小份关键资源，代价是引来仙帝追击；他指出谁若先伤自己，谁就会输给另两人。
  - **opponent reaction：**三帝由联合追杀重新变回互相提防，停止攻击并返回争夺。
  - **body/space/detail selection：**被截下的天意、追击、停在半空的三帝，呈现自利如何反过来制约报复。
  - **ruler/reader model：**不需要打赢最强者；只要改变他们最不愿失去的资源分配，就能改写其动作。
  - **stop point：**三帝撤回争夺，九关获得短暂逃生窗口。
- **Interpretation：**小规模夺取关键节点资源，能把敌人的合作重新拆回竞争。
- **transfer observation：**面对多个强敌时，优先寻找其共享目标中的可夺小部分，而非强行正面取胜。
- **anti-inference：**这只证明短暂扰乱及附带救援；不能把它写成方行主动救人或长期压制仙帝。

# Cross-Window Findings

1. **欲望先改变“看什么”，才改变“做什么”。**人物先把人群看成肥羊、宗门看成仓库、顶层看成不能不看的未知，之后才会靠近、强征或继续上楼。用目标重分类替代“他很想要”。
   证据：LUE-D01、LUE-D05、LUE-D09、LUE-D13。

2. **诱惑最有力的场景尺子是“本可安全离开，却亲手取消退出”。**完成采集后去宝库、已得令牌后上第九层，都是先建立退出权，再由报复或未知收益夺走它。
   证据：LUE-D05、LUE-D09、LUE-D01。

3. **高价值物不必只造成抢夺；它会重排注意力任务。**候清忘记复核，修行者明知有坑仍要入门，仙帝因关键资源重新计算攻击，说明欲望的可写后果是优先级重排。
   证据：LUE-D02、LUE-D11、LUE-D14、LUE-D15。

4. **同一场景内，欲望可以竞争并轮换主导权。**方行先拒救再倾囊，随后马上重启逐利；法门诱惑压住救亲承诺；仙藏前的欲望又被救命债和资格压住。
   证据：LUE-D07、LUE-D11、LUE-D12。

5. **面子与关系欲望应落在具体权限上。**谁能上桌、谁有资格拿、谁被公开轻视，比“尊严受损”更快启动行动，也更能让旁人作出反应。
   证据：LUE-D06、LUE-D10、LUE-D12。

6. **风险阈值上调必须有现场凭据。**小塔的安全余量、可解禁制、敌手互相牵制，分别让原本不值得的动作变得可试；并且原著给出一次性消耗、意外守楼、十息倒数等边界。
   证据：LUE-D04、LUE-D08、LUE-D09、LUE-D14。

# Counterexamples & Boundaries

- **不是所有见宝者都会抢。**仙王传承前，鹿叟等人因救命债、共同经历与所有权正当性停步。LUE-D12。
- **不是所有极高价值物都能成交。**佛门僧人面对珍贵经书仍拒换，因为他真正要的是神秀而非外物；本次未列入主窗口，但定位为第847–848章，54995–55045。
- **不是所有诱惑都意味着失智。**鹿叟与敖烈在 LUE-D11 中仍能陈述理由，危险恰在他们清醒地接受未知代价。
- **不是所有关系都压过自利。**LUE-D03 中柳三的怜悯未能改变钱通的牺牲方案。
- **不是所有风险升级都可复制。**LUE-D08 的强闯以一次性小塔为前提；LUE-D14 的毁宝威胁以对象价值、火焰能力和三方牵制为前提。

# What Existing Skill Misses

现有 `resource_economy`、`hunt_acquisition`、`social_bargain_decision`、`relationship` 已能处理资源配置、取得、条件谈判与关系边界。新增的、非近义重复的判断能力是：

1. **诱惑进入场景的判定。**不是“资源出现”就转资源戏，而是判断新对象是否已使人物改看目标、缩短安全距离或放弃退出点。
2. **欲望优先级冲突的编排。**现有 Skill 会写取舍；本研究补充“自利、关系、面子、求知、报复分别在何时赢过彼此”，并要求用行为顺序而非解释证明。
3. **风险阈值的来源。**区分“有一次性安全余量所以敢试”“时间压力所以强征”“对手互相牵制所以敢抢”，避免把胆大写成无来由的性格。
4. **对象的社会化变形。**宝物可从资源转为诱饵、公开羞辱工具、谈判底牌或敌方合作的裂缝；这不是单纯估值变化。
5. **退出点作为欲望引擎。**在角色已可离开的时刻引入高一阶机会，能准确区分“自然升级”与“无端贪心”。

# Candidate Transfer Rules

1. **退出点诱惑**
   - **Applicability：**角色已完成当前目标，且有明确安全离场路径；新机会只高一阶并可见。
   - **Rule：**先确认“可以走”，再给未结面子账、未知高层或额外收益；让角色亲自取消退出。
   - **Stop rule：**新风险或新守卫一旦改变场景问题，停止继续加宝，转入逃脱、谈判或战斗。
   - **Failure pattern：**角色还没完成原目标就突然贪新物，读者会把它看成编剧拖延。

2. **诱惑导致的注意力劫持**
   - **Applicability：**交易、传承、竞拍、探宝中，人物必须在复核/撤离与抢占机会间选择。
   - **Rule：**让人物先把注意力投向“如何拿到”，从而漏掉一项本应完成的检查、边界或关系承诺。
   - **Stop rule：**漏洞已造成具体后果后，不再重复说明角色贪心。
   - **Failure pattern：**让人物无理由降智，或没有可见对象却声称“被诱惑”。

3. **关系与自利的顺序对撞**
   - **Applicability：**角色确有资源、风险顾虑和一段足以触发行动的关系。
   - **Rule：**先让其明确拒绝或计算风险，再以实际资源交付、改道或承担后果证明关系暂时胜出；随后允许资源焦虑重新接管行动。
   - **Stop rule：**资源转移与关系边界已成立后，结束救助场，转入下一资源行动。
   - **Failure pattern：**用空泛心软替代代价，或把一次善意写成稳定人格结论。

4. **公共资格触发面子行动**
   - **Applicability：**场景存在可见的座位、入场资格、称谓、分配权或公开评价。
   - **Rule：**先让对方在具体权限上排除角色/同伴，再让被排除者以能改变秩序的动作回应。
   - **Stop rule：**资格或位置已重新分配，立刻让场内人反应，不再延长骂战。
   - **Failure pattern：**只有辱骂没有资格损失，导致冲突烈度显得凭空。

5. **多方自利反制**
   - **Applicability：**至少三方围绕同一关键资源竞争，且彼此并不完全信任。
   - **Rule：**夺取或威胁毁掉一小部分关键资源，使原本联合的对手重新计算“谁先出手谁获益最少”。
   - **Stop rule：**对手的合作已转回互防，马上兑现短暂行动窗口。
   - **Failure pattern：**把该结构写成主角永久压制强敌，忽略资源、能力与时间的局部条件。
