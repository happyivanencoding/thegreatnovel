# What Existing Skill Misses

现有 `social_bargain_decision` 已经正确覆盖“人物先保护什么”“拒答要留下可观察替代物”“多人对白不写成会议纪要”；`relationship` 与 `comedy_banter` 也已覆盖关系边界和高压笑点的现实回压。真正可新增的不是近义规则，而是以下判断能力：

1. **压力分配面识别**：对三人以上场景，先识别同一危险被分别理解为哪几种损失，再要求每一种损失落到不同的资源、位置、路线或责任上。现有 Skill 强调角色差异，但没有把“差异必须形成可见分配结构”作为判断点。

2. **误判—校正—重排闭环**：区分“人物只说错了”和“人物因错误理解而站错位置、交错权限、押错目标；得到新信息后立刻重排行动”。这是 DXL-01、03、06、14 的共同机制。

3. **未和解分歧的行动结算**：现有 Skill 的停止条件是下一行动成立；还需明确：当双方价值无法调和时，不要补一轮共识，要检查稀缺资源是否已经被明确分配。DXL-09–13 显示这比强行和解更可信。

4. **群像对白的空间投影**：对话结束后，应检查是否出现队列、前后位、枪械归属、伤员去向、撤离/反攻分流等空间结果。没有这个投影，多人对白很容易退化为“聪明人开会”。

# Candidate Transfer Rules

1. **同压异保规则**

   - `applicability`：3 人以上共同面对同一危险，且至少两人对损失的时间尺度不同。
   - `rule`：先让提案暴露稀缺项；每个保留的角色只用一个回应表明自己先保什么；随即把差异落到资源、位置、对象或权限。
   - `stop rule`：稀缺项已有归属，或队形/路线/执行人已变。
   - `failure pattern`：所有人都说“要小心”；每人都发表完整价值观；差异没有改变任何行动。

2. **误判后的行动校正规则**

   - `applicability`：有人对另一个人、势力或风险只有不完整信息，且该误判会改变行动。
   - `rule`：先给出一个可理解的错误解释；由信息权限更高者提供最小反证；被纠正者必须在下一拍改变站位、通路、目标或授权。
   - `stop rule`：新判断已经转成可见安排。
   - `failure pattern`：反转只为显得角色聪明；纠正后所有人继续原计划；解释量超过实际决策需要。

3. **未和解分歧结算规则**

   - `applicability`：资源不足，且两种优先级都能成立。
   - `rule`：让双方各自说出不可放弃的对象；不裁判谁“正确”；直接展示车辆、兵力、能力、伤员资格或撤离名额最终投向，并留下另一方的关系余波。
   - `stop rule`：资源已投放，继续辩论不再改变结果。
   - `failure pattern`：作者用一段演讲让所有人接受；把情感不适写成战略反证；资源已经分配仍重复同一立场。

4. **群像空间投影规则**

   - `applicability`：对白的结果应进入撤离、救援、潜入、战斗或协作。
   - `rule`：用一个最小物理结构承接对白：队列顺序、谁拿枪、谁留守、谁在前/中/后、谁随伤员走、谁承担下一命令。
   - `stop rule`：读者不看解释也能从空间关系看出谁被保护、谁承担风险、谁有执行权。
   - `failure pattern`：会议结束后人物仍原地站着；命令没有执行人；群像声音可任意互换。
