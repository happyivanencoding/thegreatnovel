# Cross-Window Findings

1. 重逢的完成条件不是“认出来”，而是旧关系与新现实能同时成立。
   E04 中书院承认桑桑仍受宁缺影响，却不把她当回旧身份；E09 要先回答“回哪个家”；E12 以共同承担危险确认站位；E14 再以生死决定权重订关系。
   支持：E04、E09、E12、E14。

2. 旧日常应只保留一笔，并立即改变当前选择、权限或协作。
   鸡汤与便笺触发桑桑的逃生计算；石像促成她破开屏障；算盘从旧日能力变为逃亡协作；煎蛋面使她重入旧关系网；针线把旧女红回声转为当前救治能力。
   支持：E08、E09、E11、E13、E14。

3. “重新一起生活”必须落到可重复的共同操作，而不是抽象和好。
   宁缺与桑桑重新选定安处、共同返程、形成“她算他行”的路线分工，并在危险中拒绝单独安全。
   支持：E09、E10、E11、E12。

4. 分离必须留下可见后果，否则重逢不会有新内容。
   桑桑独食并获得新能力；宁缺的价值排序转冷；桑桑从无所不能变为需要计算与照料身体。
   支持：E02、E07、E08、E11。

5. 不存在共同目的时，不能强造共同生活回归。
   两位老人能叙旧却仍须走向各自目标；桑桑重返旧城是在结清牵绊；她与宁缺的分离只留下未来条件，并未被假装解决。
   支持：E03、E05、E06。

# Counterexamples & Boundaries

- E01：分离前可完整展示旧日常，因为它的任务是建立未来空位；重逢后再完整复演同样日常，通常只会滞留。
- E03：多年旧友相见、吃面、回忆，并不要求产生新共同生活；根本目标相斥时，收束为告别更真实。
- E05：人物回旧城、旧店、旧人，可能是在还债或切割，不是回归。
- E06：明确“以后再见”的条件，仍是未兑现状态；不能当作当下团圆。
- E12：共同承担并非总是正确；若单独撤离确实更能保护他人或符合已成立目标，应允许关系以暂时分开收束。

# What Existing Skill Misses

对照当前 [reunion_reentry.md](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/reunion_reentry.md:3)、[relationship.md](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/relationship.md:3)、[departure_vacancy.md](/C:/dev/tgn-story-mvp/.agents/skills/novel-scene-skills/scenes/departure_vacancy.md:3)：

- 现有 Skill 已有“旧关系仍在、人已改变”“旧物可用于辨认”“以新共同动作／边界收束”的原则。因此，“旧日常回声”“重逢需要新目的”本身不是新增能力。
- 真正可补的是：辨认已经完成后，旧日常只保留能立即触发当前决定、风险判断或新分工的一笔；若删去该回声不改变当前选择，就应压缩。来源支持：E08、E11、E13、E14。
- 可补“共同生活复位”的判断：私密重逢不必依赖公开相认或第三方见证；一项可重复的分工、照料、路线决策、居所选择，也能完成关系状态改变。来源支持：E09、E10、E11、E12。
- 可补“回家对象核验”：当人物身份、世界目标或生存条件已变时，不能默认旧址就是共同归宿；必须让双方明确选定当前可共同承受的安置方式。来源支持：E05、E09、E14。
- 不应新增近义 Primary Skill；以上更适合作为 `reunion_reentry + relationship` 的窄判断补充。

# Candidate Transfer Rules

1. **有限回声规则**

   - applicability：已完成基本辨认，当前场景仍需要把分离历史接到今天的选择。
   - rule：只取一个旧物、旧动作或旧分工；它必须立刻改变当前的风险判断、请求、权限或下一步行动。
   - stop rule：该回声已经推动当前行动后，立刻回到当下冲突。
   - failure pattern：把旧日常写成连续回忆、家务蒙太奇或“我们以前多好”的说明。

2. **可执行共同生活规则**

   - applicability：主问题不是身份揭秘，也不是交易，而是“现在还能否一起过／一起做事”。
   - rule：以一项可重复的协作落地，例如谁计算谁执行、谁照料谁承担、去哪里住、怎样共同撤离。
   - stop rule：双方已通过行动接受该协作，下一场由它带来的任务开始。
   - failure pattern：只拥抱、哭诉或说“我们重新开始”，却没有任何新分工与后续行动。

3. **共同归宿重选规则**

   - applicability：人物经历长期分离、身份变化或旧目标失效，“回家”已存在多个含义。
   - rule：让双方明确当前要回的不是抽象过去，而是一个可进入、可共同承担、能容纳新风险的地点或状态。
   - stop rule：归宿被定义，随后转入抵达、撤离或防守。
   - failure pattern：一方把旧地址或旧世界当作默认答案，压过另一方当前的安全、意志或身份变化。

4. **亲密转共同任务规则**

   - applicability：重逢已完成，但外部威胁、孩子、资源、身份或目标仍未解决。
   - rule：先允许一个有限亲密落点，再让一方给出事实级风险，另一方以具体行动接住；不要把风险当设定讲解。
   - stop rule：共同目标、首个行动与基本边界均已成立。
   - failure pattern：亲密刚发生就被新危机粗暴打断，或两人只交换情绪不形成下一步。

5. **不强制复位规则**

   - applicability：双方虽有共同历史，但新目标、价值或代价无法兼容。
   - rule：允许重逢只完成确认、告别、偿还或新的有限边界。
   - stop rule：双方已清楚知道为何不能同行。
   - failure pattern：为了“圆满”让人物无代价放弃已经成立的目标与立场。
