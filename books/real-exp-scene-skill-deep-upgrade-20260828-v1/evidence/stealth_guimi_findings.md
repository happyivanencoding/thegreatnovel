# Cross-Window Findings

1. Evidence：身份是否暴露，常由“谁能按何种知识验证”决定，而不是由外貌本身决定。熟人会读整体形象（E04），秘书会读能力签名（E07），观察者会读表演痕迹（E11），调查者会读时间结构（E10）。
   Interpretation：Scene Skill 需要把观察者模型拆成：可见外形、习惯互动、能力知识、行为逻辑四类；每场只启用实际可达的一两类。`[E04, E07, E10, E11]`

2. Evidence：值得展开的伪装细节都是未来会被核验的细节：习惯/口音/关系反应（E05、E06），夜间问答与门禁暗号（E09），可被追查的票根与地域习惯（E08）。
   Interpretation：写“细节”前应先明确它将面对哪一次观察；不能承担核验的履历与化妆步骤应压缩。`[E05, E06, E08, E09]`

3. Evidence：有效身份不追求无懈可击，而是预先规定调查越深时会得到哪一层可承受结论，以及何时放弃该身份（E08）；面对认知入侵时，也可保留可承受的尾巴（E14）。
   Interpretation：暴露阈值可写为“核心目的是否仍受保护”，而非“对方是否产生任何怀疑”。`[E08, E14, E10]`

4. Evidence：潜入的退出依赖新的、可推导的时间压力：目标会发现来者未归（E01）；诱饵方案会升级追击层级（E12）；目标可重定位且第三者不明时不追（E15）。
   Interpretation：退出不应是作者喊停，而应来自下一次核验、追击升级或情报价值已变。`[E01, E12, E15]`

5. Evidence：仪式和隐身都不是自动安全；仪式可被反向读取连接（E02），高阶无形潜入必须有对应的异常识别界面（E13），观察者也可能完全看不见正确位置上的目标（E15）。
   Interpretation：涉及仪式/超常潜入时，Scene Skill 应要求写明“双方各自能看见什么、看不见什么、何时转为可见”。`[E02, E13, E15]`

# Counterexamples & Boundaries

- 第三部第三十九章《大胆假设》`46318–46320`：人物想借临终关怀深入扮演，但医院中的濒死者都有亲属或见证者；此时假扮没有伪装空间，只会造成惊吓。反例说明：目标身份若必须取代仍被亲密关系持续确认的人，不应为了展示能力硬写潜入。
- E03：身份变化能力也有自我边界；不能把“能变脸”写成可承担一切角色。
- E10：正常作息并不自动构成不在场证明；“过于恰好”的安全叙事会成为调查入口。
- E12：高风险地区中，把可识别对象当诱饵并非总是加码爽点；若会把局部风险升级为高阶围猎，应停止。
- E15：目标暴露在观察范围内也不自动触发攻击；若尚不能排除第三方陷阱，继续观察或退出是合理结果。

# What Existing Skill Misses

现有 [`stealth_infiltration.md`](C:\dev\tgn-story-mvp\.agents\skills\novel-scene-skills\scenes\stealth_infiltration.md) 已覆盖任务进度、暴露风险、环境反馈与基础退出。新增且非近义重复的判断能力是：

1. “观察者知道什么”分层：熟人、专业调查者、能力体系知情者、读心者对同一伪装的验法不同。现有技能只概括“谁可能发现”，未要求选定其识别界面。
2. 分层身份与可控退场：身份设计可允许低风险调查查到灰色故事，深查则触发可放弃身份；这不是普通“伪装身份”。
3. 能力签名暴露：行动本身会证明“你不是这个人”，因此最优动作可能是克制不用。
4. 可回应的不在场证明：替身需要覆盖可能发生的问答，不只是提供一个静态视觉假象。
5. 认知入侵下的结论控制：当无法阻止观察时，保留一个可承受的部分真相，让对手得到错误层级的结论。
6. 仪式的双向信息泄露：仪式不只是流程，也可能把目的、连接或入口暴露给对手。

# Candidate Transfer Rules

1. **身份核验界面规则**
   - applicability：当前场景存在具体观察者，且其与目标有熟识、专业调查或能力知识。
   - rule：先写观察者能验证的一项界面，再写伪装者如何应对；不要同时铺满外貌、口音、履历、能力。
   - stop rule：该界面已通过、或已产生可见怀疑后，退出伪装准备段。
   - failure pattern：只写“他伪装得很完美”，却不交代任何人凭什么会信。

2. **可核验细节筛选规则**
   - applicability：替身会面对熟人、近距离共处或制度核验。
   - rule：只展开将被再次问到、看见或期待的习惯、关系反应、身体特征、时间安排。
   - stop rule：已覆盖下一次实际接触的核验点。
   - failure pattern：把人物档案、化妆步骤和无关童年经历当作紧张感。

3. **能力签名禁用规则**
   - applicability：在场者知道被扮演者的能力、权限或行事边界。
   - rule：先明确“这个动作会暴露什么身份差异”，再决定改用何种低可见手段。
   - stop rule：当前信息已取得，或必须使用签名能力并转入暴露后的新场景。
   - failure pattern：为了展示主角能力，让冒名者当着知情人使用不属于目标的力量。

4. **分层身份退场规则**
   - applicability：身份将经受不同强度的背景调查，且人物可以承受放弃该身份。
   - rule：为常规调查准备可接受解释；为深查准备会终止身份、但能保护核心目标的退出结论。
   - stop rule：深查已触发时，不再临场补十层新谎言，转入离场。
   - failure pattern：身份一旦被怀疑就靠巧合或权力压下所有调查。

5. **双地点存在规则**
   - applicability：人物需要隐蔽离开原位置，而原位置有人可能随时发问、查看或求助。
   - rule：替身必须能覆盖实际可能发生的互动；先写会来检查的人和问题，再写替身。
   - stop rule：首个核验窗口过去，或替身无法再回应。
   - failure pattern：只放一个静态幻象/睡觉身影，却忽略敲门、问答与突发事务。

6. **观察后的撤离规则**
   - applicability：潜入目标是拿到线索，而不是当场制服对手。
   - rule：一旦获得身份、位置或关键关系，立刻写出对方下一次核验会在何时发生，并据此撤离。
   - stop rule：撤至不再受当前核验链追及的位置。
   - failure pattern：拿到线索后仍在现场绕圈，只为延长“惊险”。

7. **部分泄露控制规则**
   - applicability：已建立读心、梦境、仪式窥探等机制，且角色不能完全阻断。
   - rule：让角色保护核心目的，同时允许观察者得到一个可解释、但会导向错误优先级的余波。
   - stop rule：对手已获得可承受结论；不要继续清洗到反而显得异常。
   - failure pattern：一律全防住，或一律把全部真相交给敌人。
