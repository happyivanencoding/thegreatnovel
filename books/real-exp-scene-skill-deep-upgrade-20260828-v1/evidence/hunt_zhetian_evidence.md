- Scene posture/type：高阶神药的培育、异常识别与控制优先。
- Scene goal：让两枚神药种子在适宜环境中重生，同时确认其中是否存在不可控意志。
- Pre-state：主角有最适合培育的命泉，却无法直接控制旁边更强的杀剑；神药本身也会逃逸。
- Evidence：他先承认无法取得四剑，转而利用其外围杀气；神药种子复苏后，意外意志随生长增强，原“培育”目标立即改写为“隔绝供给、限制成长、尝试清除”。神药的生命精气与逃逸倾向同时证明价值和风险。
- Expanded beats：放弃四剑、选择种植环境、神药复苏、异常意志显现、控制措施。
- Compressed/omitted beats：神药神话背景的延展。
- State-changing exchange：资源由可培育资产变为可能反噬的容器，供给本身必须被截断。
- Opponent reaction：无主要敌手；神药意志与杀剑残余即为真实的非人反应。
- Body/space/detail selection：破裂神源、嫩芽、隔绝阵、杀气黑雾，均是“生长亦在增加威胁”的可见证据。
- Ruler/reader model：取得活资源后的第一证明，不必是立刻服用；也可以是证明它改变了可执行的培育、控制或风险处理。
- Stop point：异常已确认、控制方案启动；不虚假宣布问题解决。
- Interpretation：该场补足“到手即用途”的边界：活资源先要证明能否安全持有。
- Anti-inference：不可把神药人格化或异常化当作每次资源的固定加料。

## ZHT-H12｜第1762章《踏足仙路》｜159765–159778

- Anchor：`点收战果`
- Scene posture/type：大战后对战略资源的快速控制。
- Scene goal：在强敌死亡、局势未完全稳定时先占住其本源地与核心资源。
- Pre-state：主角刚经历重大战斗，周围仍有更大的仙路争夺与潜在抢夺者。
- Evidence：他不沉溺于战绩，而是立即进入无主之地确认神泉与悟道树；发现本源神土的特殊性后，优先整体搬离并封存，而非当场采食或逐件展示。
- Expanded beats：胜利后的资源确认、地脉价值判断、整体转移。
- Compressed/omitted beats：战斗余波与旁观者赞叹。
- State-changing exchange：战果从“击败强敌”变成“取得可持续产出环境”。
- Opponent reaction：未出现直接抢夺者，但“避免被人取走”明确构成行动时钟。
- Body/space/detail selection：神泉、悟道树、整座本源神土的重量，强调资源价值在生态与位置，不只在单件。
- Ruler/reader model：若资源依赖原生环境，最强的“取得”是控制环境，而非摘下一件样品。
- Stop point：本源地已被带离；场景转回更大的主线战局。
- Interpretation：资源猎取可用“先控产地”替代“先拿成品”。
- Anti-inference：这依赖人物已具备搬运和封存能力，不可给低阶人物无代价复制。

# Cross-Window Findings

1. 目标价值必须先落到“当前唯一瓶颈”或“可持续生产能力”，稀有度只是证明，不是起点。圣果解决体质与生存问题；《源天书》解决资源供给问题；赌石所得资源直接覆盖突破；本源神土则提供持续产出。
   Evidence：ZHT-H02、ZHT-H03、ZHT-H06、ZHT-H12。

2. 候选筛选不是展示眼光，而是让人物明确排除：信息不足、表象过强但无人敢动、代价高于当前承受、或无法安全保有的候选。
   Evidence：ZHT-H03、ZHT-H05、ZHT-H09、ZHT-H10、ZHT-H11。

3. 竞争者或权威的反应既能验证价值，也会立即改变取得方式：从私下获取改为封场、撤离、租出、换路线或先控制产地。
   Evidence：ZHT-H04、ZHT-H05、ZHT-H06、ZHT-H08、ZHT-H12。

4. “得手”必须有近场证明，但证明形式不止服用升级：可以是身体复原、突破材料到位、技能书改变可行路径、外部竞价背书、可撤离的控制权，或确认需要先隔离风险。
   Evidence：ZHT-H02、ZHT-H03、ZHT-H06、ZHT-H07、ZHT-H11。

5. 高价值资源应同时携带一个真实的持有问题：饲养成本、逃逸、环境依赖、争夺压力、未知意志或撤离条件。否则场景会退化为掉宝目录。
   Evidence：ZHT-H06、ZHT-H08、ZHT-H09、ZHT-H11、ZHT-H12。

# Counterexamples & Boundaries

- 不因“遗迹相关”便必有目标物。灵宝遗地具备历史关联、进入门槛与道痕，却未发现九秘；该次收获是排除错误地点。ZHT-H10。
- 不因“看见更大宝物”便继续深入。紫山取得关键书后放弃帝器；圣崖目标已变为可参悟的秘术后不搜刮尸体。ZHT-H03、ZHT-H07。
- 不因“资源很珍贵”便应立即用掉。神蚕和神药种子都先暴露出保有成本与异常，处置或控制优先于消费。ZHT-H06、ZHT-H11。
- 不因“强者在场”便降低风险。禁地与古棺场均由强者参与，却仍必须缩小目标和承担身体代价。ZHT-H02、ZHT-H07。
- 不把占有本身当作正向 payoff。将活人当药材的窗口说明，若资源仍有能动性，贪婪的加工方案可成为反噬机制。ZHT-H01。

# What Existing Skill Misses

当前 `hunt_acquisition` 已清楚覆盖“需求—候选—控制权—最低确认”，但本批证据能补出的新增判断能力是：

1. “验证会泄密”的双重效应：外部强者的紧张、报价或封场可证明目标不凡，却会同时消灭独占窗口；场景应立即改写为撤离、转化或抢占通道。ZHT-H04、ZHT-H05、ZHT-H08。

2. “保有形态”不是固定的取得：资源可被转换为租约、技能性资产、产地控制或隔离中的活资源；判断标准是人物是否真正增加了可行动选择，而非是否把物品揣进储物空间。ZHT-H03、ZHT-H06、ZHT-H11、ZHT-H12。

3. 明确的弃选阈值：不是泛称“风险太高”，而是指出缺哪一项——辨识、适配、封存、撤离或抗压能力。缺项成立时，放弃本身应当推进角色与读者的判断。ZHT-H03、ZHT-H05、ZHT-H09、ZHT-H10。

4. 资源 payoff 的两拍结构：第一拍立即证明“现在能做什么”；第二拍保留后续代价、培养或追索，不在同一场把完整升级与全部社会反应塞满。ZHT-H02、ZHT-H06、ZHT-H11。

# Candidate Transfer Rules

1. 规则：先写“当前缺口”，再展示候选价值。
   - Applicability：目标资源能解除当前生存、修行、权限或行动瓶颈时。
   - Stop rule：读者已能回答“拿到后本章/下一场多了什么选择”，不再追加百科估价。
   - Failure pattern：先报稀有度和传说，人物为什么非要它不可始终不清楚。

2. 规则：候选至少经过一次可失败的筛选。
   - Applicability：存在多个资源点、石料、路线、遗迹入口或交易对象时。
   - Stop rule：筛选已改变人物的投入、路线或放弃对象。
   - Failure pattern：主角一看即中；所谓眼光没有代价、替代项或误判压力。

3. 规则：价值被公开验证后，立即重算“能否守住”。
   - Applicability：竞价、封场、权威震动、敌人追踪或同伴争议出现时。
   - Stop rule：已决定保留、转换、共享、撤离或隐藏中的一种，并写明代价。
   - Failure pattern：所有人震惊后资源仍像普通物品一样安全留在主角手里。

4. 规则：活资源与环境型资源优先证明控制条件。
   - Applicability：资源会逃、会反噬、需要培育，或离开产地即失效时。
   - Stop rule：已明确谁能供养、如何封存、哪项风险尚未解决。
   - Failure pattern：把活物、神药或产地压缩成一次性数值道具。

5. 规则：让“得手”在近场落地，但把完整兑现留给下一问题。
   - Applicability：资源已实际进入人物控制。
   - Stop rule：已呈现一项身体、能力、路线、关系或资源结构的可见改变。
   - Failure pattern：只写“收入囊中”，或反过来在同一场完成升级、估价、交易、展示和下一轮目标。

6. 规则：把放弃写成信息增量，不写成空手而归。
   - Applicability：目标地点、器物或候选未能跨过辨识/控制阈值。
   - Stop rule：人物已经获得明确的排除结论或下一条可行动线索。
   - Failure pattern：用“暂时打不过”草率退场，未说明究竟缺少什么条件。
