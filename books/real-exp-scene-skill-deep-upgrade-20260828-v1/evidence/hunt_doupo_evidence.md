# Research Question

异火、药材、功法/宝物等高价值目标，如何建立欲望、给出线索、安排竞争与门槛、显出机会成本，并在取得后完成第一次有效使用；哪些寻找过程应压缩。

# Evidence Windows

### H01｜炼制先变成猎取资金

- `evidence_id`: H01；第385—387章《经济窘迫的萧炎》—《黑印拍卖场》；`20354–20439`。
- `scene posture/type`: 资源变现，为后续猎取建立预算。
- `scene goal / pre-state`: 萧炎为炼制复紫灵丹买下四副药材后近乎耗尽积蓄；若炼制失败，连后续行动资金也会断裂。
- `expanded beats`: 展开药材成本、成功率风险、丹药市价、拍卖席位如何由拍品价值决定。
- `compressed/omitted beats`: 连续炼制过程没有逐炉铺开。
- `state-changing exchange`: 三枚丹药从库存变成拍卖资格与可支配资金。
- `opponent reaction`: 鉴定师、拍卖场据丹药价值重估其身份。
- `body/space/detail selection`: 桌面药材、药鼎、玉瓶与“赤贫”状态，具体承接资金压力。
- `ruler/reader model`: 高价值猎取前，资源不是背景数字；它必须决定人物能否进入下一轮争夺。
- `stop point`: 拍卖资格成立；主问题切至拍卖与目标选择。
- **Evidence**: 药材成本、失败风险、鉴定估价与席位变化均被明确写出。
- **Interpretation**: 先让“我为什么不能乱买”成立，后面的高价目标才有真实重量。
- `anti-inference`: 不代表每次寻宝都要先写筹钱；这里只因人物的炼药能力可直接兑换行动资源。

- `compressed/omitted beats`: 无新线索的洞内移动、返程与后续炼制。

- `opponent reaction`: 药老纠偏；美杜莎从即时杀意转为有限期交易。
- `body/space/detail selection`: 黑谷、兽巢、泥沙、巨大钟乳、青石凹槽、玉勺与流动液体。
- `ruler/reader model`: 高价值资源的完成条件包括真实层级、兼容工具、残留边界与取得后关系代价。
- `stop point`: 真正液体安全收纳、保护条件成立、突破用途明确。
- **Evidence**: 章节明确区分外溢物与核心，并明确禁止取尽。
- **Interpretation**: “资源到手”不能仅以装瓶判定。
- `anti-inference`: 不代表每个资源都必须有障眼法或留根；这是天地灵物与既有关系共同造成的特例。

- **Interpretation**: 可信退出是获取动作，不是谈判空白。

### H05｜找药过程被“可验证的交换规则”替代

- `evidence_id`: H05；第821—825章《千药坊》—《得手》；`41154–41393`。
- `scene posture/type`: 稀缺药材的制度化竞争。
- `scene goal / pre-state`: 萧炎缺天魂融血丹的后三味主药；市场只能提供前五味，正常金币购买无法解决最后缺口。
- `expanded beats`: 药坊说明二层资源不能用金币买；换取条件是等价丹药；现场出现竞争者与更高阶丹药门槛；主角从遍查店铺转为争取一次明确交换。
- `compressed/omitted beats`: 街上逐店找药、低价值药材展示、前半场普通换丹。
- `state-changing exchange`: “不知何时能寻齐”转为“需要拿出可验证的五品价值并击败竞争报价”。
- `opponent reaction`: 齐山借身份压价；药坊需在价值与规则间裁决。
- `body/space/detail selection`: 两层药坊、玉盒、药鼎、纸上药单。
- `ruler/reader model`: 当目标的缺口已精确到少数材料，逐店搜寻应压缩；读者应看到的是可执行交换门槛。
- `stop point`: 高价值药材被摆上台，明确进入竞价/炼制问题。
- **Evidence**: 金币失效、丹药兑换、竞争者介入都被明示。
- **Interpretation**: 搜寻的展开价值在于改变“哪里有、用什么换、谁会抢”。
- `anti-inference`: 不代表所有药材都应市场化解决；这里的药坊本身拥有稳定的稀缺资源与规则。

- `scene posture/type`: 异火线索兑现、跨阵营竞争、强夺后撤离。
- `scene goal / pre-state`: 萧炎已把异火视为焚决成长与炼药能力的必要资源；目标位于蛇人族势力范围。
- `expanded beats`: 先确认目标与美杜莎进化关联；古河以高价值承诺交换同一目标；萧炎利用争端与混乱接近；收服后不把冲突拖成长篇展示，而转入逃亡。
- `compressed/omitted beats`: 无新信息的沙漠行进与外围对峙。
- `state-changing exchange`: 异火从遥远需求转为多方公开争夺物；取得本身立刻关闭原有和平谈判路径。
- `opponent reaction`: 古河一方以高价值交换施压；蛇人族与美杜莎的行动使主角不能停留。
- `body/space/detail selection`: 沙漠、地下火域、异火、群体包围与撤离路线。
- `ruler/reader model`: 强竞争不必只靠加价；世界已有关系与目标归属也能成为成本。
- `stop point`: 火种已脱离原位置，主问题切换为逃亡。
- **Evidence**: 章节连续呈现目标确认、竞争、收服与撤离。
- **Interpretation**: “取得”可作为更大追杀问题的起点，而非一场戏的安稳终点。
- `anti-inference`: 不能把所有异火猎取都写成群体战争；该窗口的竞争规模来自蛇人族与美杜莎的既有位置。

### H12｜取得异火后，不立刻塞满全部成长

- `evidence_id`: H12；第226—234章《异火的吞噬，启动！》—《焚决进化！》；`11488–11904`；anchor：`异火锻体`。
- `scene posture/type`: 高风险整合、功法进化与首次可感知收益。
- `scene goal / pre-state`: 萧炎已取得青莲地心火，但还未真正能控制或用于焚决。
- `expanded beats`: 先选安全地点；抽离火种、异火锻体、承受与修补、确认本源异火、再推进焚决进化。
- `compressed/omitted beats`: 重复能量运转与已明确的承受过程。
- `state-changing exchange`: “持有火种”变为“本源异火和功法实际进化”，并留下身体与控制层面的真实代价。
- `opponent reaction`: 此段外部竞争退场，身体和药老判断承担反馈。
- `body/space/detail selection`: 山洞、火焰侵体、药液、身体破损与修补。
- `ruler/reader model`: 第一次使用应证明资源为何不可替代，但不必同场把所有升级、估值、展示做完。
- `stop point`: 焚决进化成立；后续的展示、战斗应另切场景。
- **Evidence**: 连续章节将火种抽离、锻体、确认本源与功法进化分层。
- **Interpretation**: 资源首次使用最有效的顺序是“控制权成立 → 不可替代效用成立”，而非先报数值。
- `anti-inference`: 不意味着每次资源整合都必须受重伤；这是异火本身的高风险属性。

# Cross-Window Findings

1. 高价值目标必须先绑定即时缺口与明确用途，稀有度本身不够：H01、H04、H07、H09、H10、H12。

2. 当“目标在哪里、拿什么换、谁会阻拦、还差什么”已清楚时，找路、逐店询问、重复运转应压缩；篇幅应留给门槛验证和控制权变化：H02、H05、H07、H08、H09、H10。

3. 资源的所有权转换并不等于 payoff。至少要完成真实整合、首次效用或关系变化：H03、H08、H10、H12；H09 是边界反例，传承完成但首战使用未在该窗口内兑现。

4. 竞争者不只有“正面打手”一种形态：可为截取窗口的制造者、制度门槛、唯一持有者、资源自身意志或倒计时：H02、H04、H05、H08、H09、H10。

5. 高价值猎取的代价应改变下一步，而非机械附加损失：库存消耗与服务债务（H01、H04）、关系合同（H03）、暴露与撤离（H02、H11）、资格限制（H09）。

# Counterexamples & Boundaries

- 不需要每次都展开竞争者。天妖傀窗口的有效阻力是封印、材料、时间与救人需求，而非反派抢夺：H08。
- 不应把“听到异火消息”写成获得。九龙雷罡火窗口明确停在兼容性否决处：H07。
- 不应把“进入宝库/看到秘法”写成战力兑现。天妖傀尚未炼成，天火三玄变的首次实战也不在窗口内：H08、H09。
- 不应永远截胡。H02 的策略依赖可观察的交接窗口；没有低暴露机会时，等待只会失去目标。
- 不应为了环保式“留根”强行留资源。H03 的保留边界来自该灵物的生成方式与人物关系，不是通用道德动作。

# What Existing Skill Misses

现有 `hunt_acquisition` 已覆盖“需求—定位—竞争—取得”，`resource_economy` 已覆盖估值与机会成本；本轮真正新增的判断能力是：

1. 识别竞争者的获取行为何时反而产生“二手获取窗口”，而不是把竞争者只当阻碍：H02。
2. 判定资源是否存在“表层产物—真核心—兼容提取协议—残留边界”的链条；找到候选仍可能拿错或毁掉：H03。
3. 将一次性支付、未来服务、输入材料责任、保护期等分开记录；物品到手不等于交易闭合：H03、H04。
4. 将能力证明、制度资格、可否带走区分为连续门槛；“获得机会”不是“已获得功法”：H09。
5. 为宝库/异火等资源补上“第一次不可替代使用”的停点，而非在发现资源时提前宣布 payoff：H08、H10、H12。

# Candidate Transfer Rules

1. **分层资源提取**

   - Applicability：目标有副产物、伪装层、处理风险或再生边界。
   - Rule：先确认真核心、处理工具与不可逆边界，再写收纳。
   - Stop rule：真核心已安全控制，残留边界与首次用途已明确。
   - Failure pattern：把最先看到的产物当终点，或为全取而损毁资源本体。
   - Evidence：H03。

2. **二手获取窗口**

   - Applicability：竞争者正替主角定位、清场、运输或刚完成交接。
   - Rule：只展开目标位置、护卫损耗、交接确认与撤离时钟。
   - Stop rule：控制权转换，且继续搜刮会明显提高暴露风险。
   - Failure pattern：过早正面强夺；得到核心物后仍停留炫耀。
   - Evidence：H02。

3. **唯一持有者交换**

   - Applicability：目标由唯一持有者控制，人物拥有有限替代资产或可信退出路径。
   - Rule：让持有者的真实效用变化可见；明确一次性成本、未来服务、材料责任。
   - Stop rule：物品交接且新增债务边界明确。
   - Failure pattern：只写“砍价成功”，不写卖方为何让步或人物新背上的义务。
   - Evidence：H04。

4. **资格型功法/宝物**

   - Applicability：资源受宗门、机构、试炼或身份规则限制。
   - Rule：区分“被允许尝试”“通过资格”“完成交付”；拒绝后再谈必须改变交易筹码。
   - Stop rule：资格或交付已被外部规则确认；若未展示首用，则不要伪称完整 payoff。
   - Failure pattern：把服务交换直接写成白送传承。
   - Evidence：H05、H09、H10。

5. **首次使用闭环**

   - Applicability：资源已入手，但读者仍不知道它是否真的解决当前问题。
   - Rule：优先给一次具体、不可替代的身体变化、救治结果、行动权限或关系回报。
   - Stop rule：资源改变的可做之事已由行动或外部反应成立。
   - Failure pattern：只报品阶、数值或“很强”，或者同场塞进所有升级和展示。
   - Evidence：H08、H10、H12。

# Source Fidelity Audit

- 纳入的 12 个窗口均以本地 GB18030 解码后的行号定位；没有使用外部资料补充情节。
- 仅作为候选、未纳入结论的窗口：第275—278章《寻药》—《七幻青灵涎》、第586—617章陨落心炎事件、第1393—1424章残图与菩提古树、第1495—1519章净莲妖火。它们主题相关，但本轮未完成足够紧凑的逐项定位与反推校验，故不伪造其机制细节。
