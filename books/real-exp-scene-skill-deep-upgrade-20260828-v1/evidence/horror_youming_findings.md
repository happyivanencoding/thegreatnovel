# Cross-Window Findings

1. 恐惧最稳定的形态，不是“危险出现”，而是危险方或危险空间同时掌握人物所需的入口、知识、保护或生存期限。人物因此会靠近、交易、隐瞒或暂时服从，而不是只逃跑。`YM-HY-02`、`04`、`07`、`11`、`12`

2. 有限信息要保持可行动，需分开三层：已观察到的事实、当前可暂用的操作规则、仍未解释的身份／根因／意图。原著让人物先用探针、分段报价、单一路径或可感知变量行动，不急于求全解。`YM-HY-03`、`06`、`10`、`13`、`16`

3. 危险合作不是信任增加，而是“退出权更窄、共同失败后果更大、对方仍有独立目的”的临时行动窗口。合作只要能改变入口、分成、追杀压力或身体约束，就足够成立。`YM-HY-04`、`07`、`09`、`10`、`11`

4. 邪异压力靠一条被兑现的失效链成立：熟手的防御失效、身体不再服从、空间压力造成损耗、熟人不再遵从旧关系。其后必须迫使角色改策略；同类意象若不再改策略，应压缩。`YM-HY-01`、`05`、`08`、`12`、`15`

5. 未知空间与关系是互相改写的：谁拥有禁法、谁被空间识别、谁能带路或承担失控后果，直接决定谁能说了算。空间不是独立布景。`YM-HY-07`、`09`、`13`、`14`、`15`

# Counterexamples & Boundaries

- 当空间机制已被人物看穿且风险可计算时，不应继续以“未知恐怖”为主；应转入威慑、战术或撤离决策。`YM-HY-13`、`14`
- 当人物只是做低成本探查、还没有关系或生存压力纠缠时，使用 `exploration` 已足够；不要强加邪异关系戏。`YM-HY-03`
- 只写痛、冷、黑暗、变形，不足以构成压力；它们必须让人物的判断、路线、筹码或身体控制实际失效。`YM-HY-02`、`08`
- 高位人物的帮助不等于安全，也不等于背叛预告；若帮助没有改变出口、可见性、资源、身份或选择数量，不应把它包装成“危险关系”。`YM-HY-04`、`11`
- “不解释”不能成为常态。若下一步已取决于一个可干预变量，应给出该变量，而不是继续留白。`YM-HY-03`、`13`、`16`

# What Existing Skill Misses

现有 `horror_anomaly` 已覆盖“正常模型失效、人物测试、异常以结果回应、避免连续怪名词”；`exploration` 已覆盖未知空间的行动地图；`relationship` 已覆盖信任与边界变化。因此以下不是近义重复。

1. 恐惧—收益—权力耦合
   现有 Skill 没有要求判断：威胁是否也控制人物要的入口、资源、身份、知识或保护；帮助是否同时缩窄退出权、制造依赖。`YM-HY-02`、`04`、`07` 是明确证据。

2. “观察事实／操作规则／根因未知”的三层信息
   现有文本要求保留未知，却未规定哪些必须让读者和人物立即知道、哪些可暂时依赖、哪些应继续未知。`YM-HY-03`、`06`、`13`、`16` 显示三层混在一起时，场景容易变成故意含糊或过早解谜。

3. 不对称帮助的行动后果
   现有 `relationship` 能写关系变化，但缺少“强者帮忙却不等于安全”的专门判断：帮助究竟改变出口、可见性、资源、身份还是路线？`YM-HY-04`、`11`、`15`

4. 关系化空间
   现有 `exploration` 主要处理物理行动地图；缺少“谁能开门、谁被空间承认、谁能带路、谁的退出权降低”的关系—空间联动。`YM-HY-07`、`09`、`14`、`15`

5. 压力下的可靠锚点
   现有 `horror_anomaly` 要求具体后果，但未要求感知、记忆或身体控制受扰时必须保留一个外部锚点。`YM-HY-08`、`16`

6. 未解压力的交接
   场景停点已有，但缺少将“确认观察、当前操作边界、未解含义”分开移交下一场的规则。`YM-HY-06`、`11`、`15`、`16`

# Candidate Transfer Rules

## 1. 危险收益耦合

- Applicability：同一人物、力量或空间既威胁主角，又控制其明确想要的入口、资源、身份、知识或保护。
- Rule：每次接触至少改写一次“收益—依赖—风险”；只写可见帮助与可见代价，不替角色确认对方动机。
- Stop rule：人物已作出不可逆的靠近、拒绝、交换或依赖选择。
- Failure pattern：人物只因恐惧逃跑；或只因神秘靠近；帮助没有改变行动空间。

## 2. 三层未知

- Applicability：人物必须在根因、身份或意图未明时继续行动。
- Rule：每个关键异常只固定三项：已观察信号、暂可依赖的操作规则、仍未解释的含义；至少留一个局部出口、方位或安全条件。
- Stop rule：局部规则已迫使下一步具体行动。
- Failure pattern：什么都不说；规则随意变；为解释异常立刻切入调查或真相揭示。

## 3. 不对称帮助

- Applicability：对方拥有更高力量、信息或空间权限，并能帮助也能伤害主角。
- Rule：每次帮助都必须改变一个实际变量：出口、可见性、资源、身份、路线或选择数；同时留下一个未解释的保留／限制。
- Stop rule：帮助已改变依赖或行动集合；若条件成为公开筹码，转 `social_bargain_decision`。
- Failure pattern：善意自动等于可信；NPC只当谜语终端；无前置压力的突然背叛。

## 4. 关系化空间

- Applicability：入口、路径、可见性或安全性取决于身份、同行者、权限或关系位置。
- Rule：每个空间发现至少改变一个关系变量，或每个关系动作至少改变一个空间变量；优先追踪谁能进去、谁会暴露、谁能领路、谁失去退出权。
- Stop rule：空间变量已迫使关系选择，或关系变化已迫使改道、隐蔽、撤退。
- Failure pattern：空间导览与关系戏平行推进；门只是“诡异”却不影响路线。

## 5. 压力下的可靠锚点

- Applicability：邪异压力影响感知、记忆、时间感或身体控制，但人物仍需做决定。
- Rule：只选一个会使判断失效的具体失真，并配一个可复核外部锚点。
- Stop rule：失真已迫使策略改变，或锚点已确认／否定局部规则。
- Failure pattern：反复写出汗、耳鸣、发抖；不可靠视角被用来临时改写事实。

## 6. 未解残余交接

- Applicability：本场局部行动完成，但核心身份、机制、意图或空间含义仍未知。
- Rule：结尾只保留一条确认观察、一条当前操作边界、一条未解问题；下一场从该行动结果开始。
- Stop rule：三项已足以约束下一场的具体选择。
- Failure pattern：下一场重演发现；提前揭尽真相；把气氛或计划误当既成事实。
