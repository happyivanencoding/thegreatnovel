# Cross-Window Findings

1. 欲望要先以可触摸的当前对象进入场景，再以选择/反应改变路线；单靠内心宣言不够。对象可以是兵器、榜单、身体、临时安全空间或名号，但必须让它迫使人物承担风险、改口、训练、接战或重设关系边界。〔DLS-02, DLS-04, DLS-06, DLS-11, DLS-13, DLS-15〕

2. 长期目标并非天然压倒短期欲望。文本先让诱惑真实且可得，再用明确期限、实战代价、另一人的脆弱需求或自主权决定是否延后；“忍住”必须带来新的行动或新的关系状态。〔DLS-03, DLS-07, DLS-14, DLS-15, DLS-16〕

3. 江湖名望的有效写法是“公共证明后，别人马上按这个名字改行为”。它会改变接待规格、程序、同辈竞争、部属可借用的权威与私下谈判风险，不只是围观者夸强。〔DLS-01, DLS-09, DLS-12, DLS-13〕

4. 好胜不必被升华为大道理。榜上有名的虚荣、想胜过朋友、拒绝情感捷径而选择实战，都可作为人物自驱；关键是让它接到具体训练、挑战或伤势代价。〔DLS-02, DLS-09, DLS-14〕

5. 身体吸引最有力时，往往不是从外貌清单起笔，而是从危险、保护、能力差或空间匮乏中生长出来；身体细节随即改变距离、速度、判断或信任。〔DLS-05, DLS-06, DLS-10, DLS-11, DLS-15〕

# Counterexamples & Boundaries

- DLS-05 表明审美/身体吸引可以只承担瞬时注意和能力对比：若没有选择、关系边界或路线变化，不应强拔成“欲望主场景”。
- DLS-07 表明可得的双修与亲密不应因“收益高”自动兑现；雁门期限先被具体化，才有可信的延后。
- DLS-15 表明“停下”只在另一方真实处于脆弱、并以新信任回应时成立；否则会变成公式化克制。
- DLS-12 表明名望可以由部属调用，但必须确实改变对手的处置方式；单纯喊出主角名字不算社会影响。
- DLS-04 表明宝物执念需要身份贴合与后果；没有这两项时，直接“明知危险还拿”会显得角色失智。

# What Existing Skill Misses

当前 `relationship`、`resource_economy`、`showcase_evaluation`、`training_learning` 已分别覆盖关系边界、资源机会成本、外部估值与训练反馈；真正新增的判断能力是：

1. 缺少“欲望碰撞”作为可识别的场景发动机：现有 Skill 能处理关系已变化后的互动，但未判断“即时身体/宝物/名望诱惑是否正在与长期目标争夺下一拍”。〔DLS-03, DLS-07, DLS-14, DLS-15〕

2. 缺少“身体—空间—行动”判别：现有 relationship 允许触碰与情绪，却未要求身体/审美描写必须由危险、保护、能力差或隐私空间触发，并改变人物距离或行动。〔DLS-05, DLS-06, DLS-11〕

3. 缺少“名望的非奖杯化”判别：showcase_evaluation 要求外界估值落地，但未明确识别名声何时已经成为主角不在场也能改变程序、接待、威慑和联盟路线的社会变量。〔DLS-01, DLS-09, DLS-12〕

4. 缺少“身份性宝物欲望”判别：resource_economy 偏估值与机会成本，未覆盖角色会因“这东西像我”而持有麻烦物，并由此承担人际立场的情形。〔DLS-04〕

5. 缺少“延后亲密的正向 payoff”判别：当前 Skill 可以写关系边界，但没有指出在脆弱时刻，停止占有、转为提供对方真正需要的安全感，本身可完成更强的关系状态变化。〔DLS-15〕

# Candidate Transfer Rules

1. **欲望碰撞规则**
   - Applicability：当前诱惑会改变行动、风险、关系边界或时间分配。
   - Rule：先让诱惑以可见对象进入，再让人物承认其价值；随后给出它会关闭什么机会，最后让选择被另一角色或现实条件回应。
   - Stop rule：一旦人物选择了取得、拒绝或延后，且代价/回应已可见，即切到下一行动。
   - Failure pattern：只写“他忍住了”“她很诱人”，没有任何路线状态变化。

2. **身体与空间规则**
   - Applicability：共同危险、临时避难、能力差或刚脱险使人物距离被迫缩短。
   - Rule：选一个有功能的空间细节和一个身体细节；先完成保护、移动、疗伤或避险动作，再让亲密反应出现。
   - Stop rule：双方距离、信任或行动方式已经改变时停止，不继续盘点外貌。
   - Failure pattern：把人物身体当镜头陈列，删去后不影响选择与关系。

3. **名望兑现规则**
   - Applicability：主角刚获公共证明，或其名字已在陌生场域流通。
   - Rule：安排至少一位非核心人物因名号改变礼数、程序、风险估值或联盟选择；必要时让主角本人对这份名望表态。
   - Stop rule：名声已落到一个具体进入权、负担或新敌意后停止。
   - Failure pattern：多人换词夸强，却没有任何人因此换做法。

4. **身份性宝物规则**
   - Applicability：物品不仅有数值价值，还贴合角色的战斗习惯、自我想象或关系历史。
   - Rule：让角色知道它有麻烦仍不愿放手，并在紧后续兑现一项关系、暴露或路线代价。
   - Stop rule：执念已迫使角色承担一个具体后果时停止。
   - Failure pattern：只报属性，或让角色无理由牺牲大局去保物。

5. **非工具化亲密规则**
   - Applicability：亲密既可能带来修行/资源收益，也可能使一方觉得自己被利用。
   - Rule：让双方欲望和脆弱都可见；若当下真正需要的是安全感，主角的延后必须通过守护、陪伴或新的边界实际完成。
   - Stop rule：另一方以新信任、休息、承诺或行动回应后结束。
   - Failure pattern：把克制写成永远正确的说教，或抹掉主角真实欲望。

6. **好胜落地规则**
   - Applicability：人物面对可比较的同辈、榜单或旧友，且这种比较能通往下一项训练/挑战。
   - Rule：允许人物直接承认“想赢”，再让这份冲动落入一次练习、挑战或高代价替代路径。
   - Stop rule：比较目标和下一步努力已经明确。
   - Failure pattern：事后用宏大理想掩盖竞争欲，导致人物没有可感知的个人驱力。
