# Cross-Window Findings

1. 复杂团队战的主阅读单位应是可改变队伍结构的局部目标，而非全员动作清单：脱团、救援出口、治疗能否施法、高点归属、谁先倒下。局部目标一旦兑现，立即替换阅读问题。证据：`CQZ-03`、`CQZ-04`、`CQZ-05`、`CQZ-07`、`CQZ-08`。

2. 职业分工最清楚的呈现方式，是“本职动作—被该动作暴露的限制—他人的针对反应”，不是先介绍职责。证据：`CQZ-03`（治疗的全局观察）、`CQZ-05`（治疗与打断）、`CQZ-07`（阵地救援）、`CQZ-12`（集火惯性）。

3. 视野应被写成可操作的资源：盲区、遮挡、地形高度、绕后、目标丢失，而不是抽象地说“掌握视野”。证据：`CQZ-01`、`CQZ-06`、`CQZ-09`、`CQZ-10`、`CQZ-11`。

4. 专业解释的最佳位置取决于它是否改变当前选择：高速过程中先给效果与即时选择；读者已看见异常结果后，才补机制、慢放或旁观者判断。证据：`CQZ-02`、`CQZ-07`、`CQZ-10`、`CQZ-12`。

5. 一拖多成立时，胜负尺应从“击败全部敌人”降为“迫使其延迟、失位或改路”；该延迟必须在另一条战线兑现。证据：`CQZ-04`、`CQZ-09`、`CQZ-10`。

# Counterexamples & Boundaries

- 第三百九十六章《胜负手》23296–23320 的团队赛被压缩成多点切换和赛后评价，原文也承认镜头难以兼顾。它适用于展示一场比赛的总体精彩与结构性缺陷，不适合作为单场正文逐拍可读性的模板。
- `CQZ-07` 说明短指令有效，但它建立在前一章已明确“谁被围、谁可救、为何不能退”的基础上。没有这种前置，短指令会是信息缺失。
- `CQZ-10` 的技术说明被后置，是因为当下动作速度超过即时解释的承载量；若某项规则决定角色是否敢进入危险区，则不能延后到结果之后。
- `CQZ-11` 的表层救援与真实聚人目标之所以可成立，是敌方的后退、转火与站位调整都有即时因果。若对手的“上钩”没有合理动作链，隐藏意图会退化为作者强行翻牌。

# What Existing Skill Misses

当前 `combat` Skill 已正确提出“局部 POV 承载整体态势”“团队战让分工、救援、视野和局部目标互相影响”，但尚缺以下新增判断能力：

1. **局部目标的替换门槛**：何时从“牵制二人”切到“后方治疗受袭”，又何时从“治疗受袭”切到“救援出口能否打开”。现有 Skill 说要维持局部目标，未规定旧问题何时应退出。
2. **角色职责的可见语法**：应以“职责动作暴露限制，再被他人利用”呈现分工，而非仅提醒 Writer 写出分工。
3. **多线镜头预算**：不要求平均追踪每一线；可暂隐一线过程，但其结果必须以人数、资源、救援能力或路径变化回流主线。
4. **解释时机的判定**：把技术信息区分为“当前选择所必需”与“结果后用于校准理解”，避免边打边开复盘会。
5. **逆风牵制的验收尺**：一拖多不以击杀验收，而以延迟、脱离、逼迫改路或剥夺支援验收；若没有下游兑现，牵制只是拖长篇幅。

# Candidate Transfer Rules

1. **局部目标接力**
   - applicability：四人以上、同时存在至少两条接触线。
   - rule：每段只让读者追一个可验收目标，如“治疗能否完成一次施法”或“被围者能否获得出口”；状态改变后再切换下一目标。
   - stop rule：旧目标已被明确兑现、失效，或被更高优先级目标覆盖时，停止补充旧线的交换。
   - failure pattern：持续切换人物而没有状态改变，读者只能记住“很乱”。

2. **职责动作即信息**
   - applicability：职业、岗位、器械或能力分工对胜负有实质影响。
   - rule：先写角色执行本职动作，再写此动作带来的暴露、保护或限制，最后写对手如何针对。
   - stop rule：读者已能预测该角色下一次选择时，不再重复解释职责。
   - failure pattern：先集中介绍所有岗位功能，行动尚未发生就变成战术说明会。

3. **把视野写成位置后果**
   - applicability：有遮挡、高低差、绕行、背后、烟尘或注意力转移。
   - rule：每次提及视野，都绑定为“谁失去目标、谁看见路径、谁因此改变站位”。
   - stop rule：视野变化已转化为攻击、脱离、会合或误判时，结束该信息链。
   - failure pattern：只写“掌握视野”“视野受限”，却没有行动后果。

4. **高密度动作，延迟术语**
   - applicability：一个交换中技术层级高、速度快，术语解释会打断读者对结果的追问。
   - rule：当下只交代动作、即时效果和被迫反应；在结果出现后，以复盘、观察或第二次使用补最小机制。
   - stop rule：读者已能判断下一步风险时，不再增加技术背景。
   - failure pattern：每个技能都先定义、再说明相克、再行动，导致场面停摆。

5. **逆风的可兑现牵制**
   - applicability：一人或一小队不具备正面获胜条件，却需要为队友争取窗口。
   - rule：明确其牵制产物：拖慢会合、逼退火力、抽离保护者、迫使改路；后续必须让另一线实际使用该窗口。
   - stop rule：窗口已兑现，或牵制者再继续只会重复逃跑时退出。
   - failure pattern：把“撑住”写成无限闪避，其他队友没有获得任何新行动空间。
