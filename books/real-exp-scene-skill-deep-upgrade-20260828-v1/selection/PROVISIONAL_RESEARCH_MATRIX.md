# Scene Skill v2 — Provisional Research Matrix

> Status: HYPOTHESIS pending source-first evidence + cross-book synthesis. Do not use as production authority.

## Design principle

- Shared core first; split variants only when the **reader's live question / state model / beat selection / stop rule** differs materially.
- Skill count follows `reader value × frequency × failure diversity`, not taxonomy completeness.
- Full source evidence stays in research layer; runtime sees only abstract Generation Lens / Revision Lens.
- Raw GBrain never enters Primary or Authority Reviser.

## Combat: highest-resolution family

Current `combat` remains shared fallback core. Candidate variants to test:

| Candidate | Reader question | Anchor evidence candidates | Adjacent skill boundary |
|---|---|---|---|
| combat_parity_duel | 双方都能赢时，哪一次交换真正改变主动权？ | 武道宗师 / 一世之尊 / 斗破 | public proof remains showcase modifier |
| combat_underdog_upset | 弱者真正能赢的窄窗口在哪里，怎样扩大/关闭？ | 斗破 / 仙逆 / 全球高武 | not generic trial challenge |
| combat_dominance_payoff | 新强度怎样用最少交换证明“过去困难现在简单”？ | 大圣传 / 遮天 / 吞噬星空 / 斗破 | stop early; showcase may carry repricing |
| combat_adaptation_counterplay | 对手看懂主角旧打法后，双方怎样重新争夺信息和选择？ | 全球高武 / 一世之尊 / 武道宗师 | not deduction; must remain physical/action state |
| combat_protect_hold | 胜负标准不是杀敌，而是守住人/物/门/时间；敌人如何换目标？ | 全球高武 / 遮天 / 永夜君王 | survival_endurance may be secondary |
| combat_ambush_assassination | 信息不完整、接触极少时，哪一拍决定生死？ | 死人经 / 永夜君王 / 仙逆 | stealth before contact; combat after discovery |
| combat_multi_actor_melee | 多方同时行动时，怎样只跟踪会改局部目标的角色？ | 遮天 / 全球高武 / 死人经 | avoid roster bookkeeping |
| combat_large_scale_local_pov | 战争/巨大战场怎样保持一个局部目标的可追踪因果？ | 遮天 / 永夜君王 / 吞噬星空 | large scale is context, not omniscient catalog |

Likely **do not split** pursuit/mobile combat: `chase_escape + combat` already expresses this; wounded survival: `survival_endurance + combat`; public proof: `showcase_evaluation + combat`.

## Other high-leverage lanes

### Dialogue / Character Voice
Deepen `social_bargain_decision`, `relationship`, `comedy_banter`. Candidate new secondary skill only if evidence supports: `character_voice_pressure` — people become distinct by what they notice/protect/refuse/misread under pressure, not by catchphrase.

### World Entry / Lived Texture
Candidate new skill `world_entry_lived_texture`: first entry into a city/organization/class/world layer; select one or two facts that make local life, value and access visible, without encyclopedia or decorative sensory quota.

### Desire / Temptation
Candidate new skill `desire_temptation`: valuable object/person/place/status changes attention, risk threshold or route before the narrator explains importance. Must not moralize or require temptation every chapter.

### Relationship
Deepen existing `relationship`: person-specific gravity, embodied/private attention, changed choice, post-payoff adaptation. Do not split romance/friendship/family unless evidence shows different scene engines.

### Horror / Anomaly
Deepen existing `horror_anomaly`: normal-model establishment, specific rule failure, limited trustworthy information, action-forcing anomaly. Likely no split until evidence demands.

### Exploration / Discovery
Deepen `exploration` and `investigation`; keep distinction: exploration changes spatial/world model, investigation changes explanatory hypothesis/evidence state.

### Training / Comprehension
Deepen `training_learning` / `comprehension_insight`; likely keep separate. Focus on feedback selection, skipped repetitions, proof via changed capability.

### Showcase / Public Proof
Deepen `showcase_evaluation`: minimal ruler → visible result → differentiated repricing → only consequence-bearing social reaction.

### Identity / Departure / Reunion / Sacrifice
Already structurally distinctive. Upgrade evidence depth before adding variants.

## Runtime target

Each v2 Skill should eventually expose:

1. Primary Reading Question
2. Use When / Do Not Use When
3. Scene State Model
4. Generation Lens (Primary)
5. Revision Lens (Authority Reviser)
6. Failure Patterns
7. Stop Rule

Evidence source names / locators stay out of runtime-loaded text.
