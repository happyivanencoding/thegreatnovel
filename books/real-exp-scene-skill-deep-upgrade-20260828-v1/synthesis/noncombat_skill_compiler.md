# social_bargain_decision
**Primary Reading Question:** 谁想让谁改变什么，最后哪项决定、条件、权限或承诺真的变了？

## Use When

人物之间正在争取、拒绝、交换、确认或延后一个会改变后续行动的条件。

## Generation Lens

保留双方真正要保住的筹码、风险和最低接受线，让每句关键对白成为一次可追踪的行动：抬价、让步、拒绝、暴露、试探、改口或关闭选择。拒答不能只留下空白；它应留下一个边界、有限事实、替代任务、时限或再次进入的条件。多人场景只保留能改变提议、质疑、执行或裁决位置的人。公共身份、程序和私人关系可以同时存在，不让亲近自动抹掉制度条件。

暂不成交也可以结束，但双方至少应带走不同的任务、承诺、期限或风险变化。下一拍必须由对方的反应产生，而不是重复上一轮立场。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 对白没有改变状态 → 补一个已有角色能作出的回应或动作，使条件、权限、信息、路线或信任发生变化。
- 拒答只有冷漠或转身 → 补最小边界或再进入条件。
- 多人轮流重复观点 → 删除同义回合，保留真正改变决策结构的一方。
- 私人关系错误覆盖公共约束 → 恢复一个仍在生效的程序、身份或代价。

不为每场谈判补齐筹码、角色位或成交。

## Failure Patterns

- 台词漂亮，但没有人改变选择。
- 拒绝只负责拖延，没有替代物或后续入口。
- 群体对白变成全员发表意见。
- 私人亲近被误写成制度豁免。
- 专业信息只完成说明，没有改变配置、路线或责任。
- 已经没有新筹码仍继续争辩。

**Stop when:** 决定、条件、承诺、合作边界、权限或关系位置已经产生可执行变化；继续说只是在复述同一立场时停止。

# relationship
**Primary Reading Question:** 既有关系在这一刻具体改变了人物愿意承担什么、允许什么或选择哪条路？

## Use When

共同历史、亏欠、信任、保护、失望、依赖或告别正在改变人物的行为，而不只是改变情绪名称。

## Generation Lens

让关系通过选择和回应显形：一方先做出符合自身历史的动作，对方再按自己的理解回应，随后改变距离、称呼、边界、行动权、风险、路线或共同计划。若关系确实有重量，人物应在某处偏离原本可行的安全路线、底牌或承受边界；不必把这层对照说出来。

公共身份、责任和程序仍可成立；私人靠近、沉默或保护只改变具体的人际边界，不自动改写制度结果。单方照料、保护、离开或牺牲只证明一方的选择，不替对方补出同意或永久关系。关系兑现后允许停留，让新位置通过小动作、共同动作或尴尬适应被体验。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 关系只被命名，没有行为后果 → 补一个最小的边界、路线、风险或照料变化。
- 单方行动被写成双向确认 → 删除未经支持的互爱、和解或承诺结论。
- 私人关系抹掉公共责任 → 恢复仍在生效的身份、程序或第三方代价。
- 沉默被解释成深情但没有外部结果 → 若已有可接的动作，补动作；否则压缩沉默。
- 关系兑现后立即被新危机覆盖 → 保留一小段适应或余波。

告别、离开和牺牲只在正文已有充分因果时做局部检查，不设固定召回器、责任任务或双向确认要求。

## Failure Patterns

- 用“关系更深了”代替行为变化。
- 所有亲近都自动战胜责任和制度。
- 一方付出被误写成双方共识。
- 每个停顿、眼神和物件都被强行翻译。
- 关系兑现后立即总结或制造新危机。
- 为了制造误会而让人物无根据地失智。

**Stop when:** 新的关系边界已经由行为、选择或明确表达成立，并且继续互动不再增加关系信息或体验。

# comedy_banter
**Primary Reading Question:** 人物把同一个现实变量看成不同东西后，现场的面子、关系、风险或任务怎样偏移？

## Use When

当前主问题允许通过错位、拆台、误解或关系性玩笑释放压力、试探立场或改变现场温度。

## Generation Lens

先让笑点命中一个硬变量：地位、风险、资源、时间、责任或行动授权。人物的声音来自他优先保护什么、愿意支付什么，而不是口癖或统一的机灵。每个有效回合都应改变面子、任务承诺、关系位置、误判成本或风险判断；知识差必须逼出错误、让步、暴露、延迟或错误部署。

高压场景中的玩笑应带着可见的回压载体：命令、武器、警报、上铐、敌情、身体伤害或程序后果。回压出现即转入现实行动。严肃自白后的玩笑只能触碰边界，不吞掉已经成立的余波。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 笑点没有改变硬变量 → 删除；若已有可承接的反应，补最小的面子、任务或风险变化。
- 角色对白可以互换 → 改变其取舍和回应，不添加口头禅。
- 危险被玩笑抹平 → 恢复已有的物理或程序性回压。
- 误判没有成本 → 让已有误判落到路线、部署、暴露或延迟上。
- 严肃结果后仍连续抖梗 → 在第一个真实后果处停止。

不要求固定轮数，也不要求每段都有效果。

## Failure Patterns

- 只是换词嘲讽，现场状态不变。
- 所有人像同一个聪明人说话。
- 误解只让读者优越，不影响任何选择。
- 危险出现后角色仍像在安全闲聊。
- 用旁白解释为什么好笑。
- 连续包袱没有新的关系、任务或风险变化。

**Stop when:** 一个笑点已经完成关系释放、面子变化或任务偏移；出现不可逆后果或主问题改写时立即转入下一种行动。

# horror_anomaly
**Primary Reading Question:** 人物原本依赖的正常规则在哪里失效，失效后还有什么可以相信？

## Use When

人物面对无法用当前正常模型解释的异常，并且异常会改变安全判断、可信信息、路线或行动策略。

## Generation Lens

先让读者和人物共享一条具体的正常标尺，再让一个清晰的规则违例产生结果。每个异常只承担一个硬违例；人物按已有经验解释、测试或保护自己，现实随后支持、否定或加深危险。保留至少一条仍可行动的感知通道，未知原因可以保留，但发生了什么必须清楚。

身体反应只有在能对应动作、物件、空间或他人反应时才保留。风险推进应表现为策略从观察、怀疑、验证逐步收缩到规避，而不是形容词升级。异常一旦变得共享、可预测或可利用，就交给生存、调查、战斗、关系或余波场景。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- “阴森、诡异、不可名状”替代了事件 → 改成一个具体规则失效。
- 多个异常互相抢夺注意 → 保留最能改变行动的一项。
- 身体反应没有后果 → 接上已有动作、物件或风险变化。
- 过度模糊导致空间不可追踪 → 明确观察事实，保留原因未知。
- 一直说更危险但策略不变 → 补最小的路线、撤离权或判断变化。

不要求每场凑齐多种证据层，也不把未知原因强行解释完。

## Failure Patterns

- 连续堆怪现象，却没有人物判断。
- 读者不知道人物看见了什么。
- 感知越多，行动反而越无方向。
- 普通解释已经足够，却继续制造警报。
- 异常已经可预测，仍坚持使用恐怖发动机。
- 用集体尖叫替代不同人物的应对。

**Stop when:** 人物确认一条正常规则失效，并采取新的具体行动；或异常已经转成更明确的生存、调查、战斗、推理或关系问题。

# exploration
**Primary Reading Question:** 未知空间正在把人物的行动地图改写成什么？

## Use When

人物需要确认一个空间能否进入、怎样通行、哪里有价值、哪里危险或下一步应往哪里去。

## Generation Lens

让环境回应人物当前目的，而不是独立展示景色。只保留会改变路线、权限、资源、风险、目标或解释模型的边界、痕迹、居民、设施和地形。发现应自然落到靠近、绕开、标记、取样、追踪、撤退或改目标中的一个选择。

高价值地点不等于当前拥有进入权；能力、情报、身份或失败代价不足时，延迟进入本身就是行动。读者应始终知道人物在哪里、看见什么、为何在意以及下一步能做什么。切换 Skill 时交出位置、可用路线、已知规则和风险阶段，不重演已完成的导览。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 环境变成景物目录 → 删除不改变行动地图的细节。
- 人物位置或入口边界不清 → 补一条当前可操作的边界。
- 发现没有产生选择 → 补最小的靠近、绕行、标记或撤退决定。
- “很危险”没有策略含义 → 改成谁不能继续、哪里不能走或撤离权如何变化。
- 已进入调查、猎取、生存或冲突 → 删除继续探索式介绍。

不强行补完整地图、历史或城市生活。

## Failure Patterns

- 走到哪里介绍到哪里。
- 奇观增加，但路线和目标不变。
- 把能看见写成能进入。
- 为保持神秘而隐藏眼下能否行动。
- 每个地点都获得同等篇幅。
- 已经交接给新主问题，仍重复旧空间。

**Stop when:** 未知空间已经转成明确的路线、目标、权限、生存、调查或敌人问题；继续走动只增加景物时停止。

# investigation
**Primary Reading Question:** 当前未知如何被行动和证据缩小成一个更具体的问题？

## Use When

人物需要通过观察、询问、跟踪、实验、比对或设局获取外部信息，并改变对可能解释的判断。

## Generation Lens

把未知写成可检验的问题。每条有效证据都应确认、排除、暴露矛盾、提高一条线索权重，或精确化下一步目标；信息必须推动查谁、去哪、测什么、回到哪里或设置什么反应。证人和对象有自己的利益、记忆缺口和应对，不是线索终端。

区分直接观察、当前可支持的推断和仍未知的原因。错误方向可以存在，但必须来自已有证据和人物判断。证据足够支撑结构性解释时，停止继续搜集，交给 `deduction_reveal`。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 线索没有改变假设空间 → 删除；或补一个已有角色会因此采取的最小行动。
- NPC 只负责吐线索 → 保留其利益、隐瞒、误记或反制中的一个已有动机。
- 观察、推断和未知混写 → 降低结论强度，恢复事实边界。
- 重复证词和同义线索 → 合并为一个最有区分度的证据。
- 已有证据足够解释，却继续找线索 → 提前交接到推理。

不为每次调查补齐线索数量或证人类型。

## Failure Patterns

- 线索数量增加，人物判断不变。
- 证人像数据库接口。
- 错误方向只是作者拖延。
- 把猜测写成事实。
- 为了神秘保留与当前问题无关的细节。
- 调查已经完成，却继续访问更多信息源。

**Stop when:** 未知已缩小为新的具体问题，证据足以支持下一次直接行动，或已有证据应转入结构性推断。

# deduction_reveal
**Primary Reading Question:** 已知事实重新组合后，哪种解释突然能同时成立，并改变人物下一步做什么？

## Use When

关键证据已经在场，主要问题不再是寻找更多事实，而是解释它们之间的时间、位置、动机、因果、身份或规则关系。

## Generation Lens

只召回支撑当前矛盾的少数事实，让不同解释互相约束。暂定模型可以成立，也可以被已有事实迫使修正；每次修正都应减少一种解释、暴露一个前提或改变验证方式。Reveal 的价值在于人物因此改防谁、去哪、信谁、利用什么机会或放弃哪条路线，而不是让读者听完一段总结。

必要时只做最低限度的验证。只解释当前行动需要的层级，不凭揭示补造更大的世界机制。若还需要持续获取外部证据，返回 `investigation`。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 重新念线索，没有解释变化 → 删除重复事实，保留真正承重的连接。
- 结论跳跃 → 补一个原文已有的时间、位置、动机或规则约束，不新增事实。
- 揭示没有行动后果 → 接上一个已有角色能作出的判断或选择。
- 暂定推断被写成确定真相 → 恢复不确定性。
- 真相成立后继续搜集确认 → 删除多余确认，或切换到新问题。

不要求每个揭示都完整解释全部谜团。

## Failure Patterns

- 把旧线索按顺序复述。
- 用灵光一闪跳过关键连接。
- 让人物知道超出其证据边界的答案。
- Reveal 只服务读者，不改变行动。
- 多个角色轮流确认同一真相。
- 推理场景变成新的线索搜集。

**Stop when:** 一个解释已经能约束关键事实，并明确改变人物的判断或行动。

# training_learning
**Primary Reading Question:** 人物怎样从做不出、做不稳或做不到压力下调用，变成当前任务所需的可重复能力？

## Use When

人物正在改变动作质量、稳定性、消耗、时机、适用范围或压力下的可调用性。

## Generation Lens

先让训练目标可观察，再保留会改变练法的偏差。反馈可以来自身体、对手、空间、数据或结果；它必须让人物调整方法，并使下一次执行可比较。重复只有在错误、修法或读者判断仍变化时才展开，其余压缩。

导师只交付当前需要的前提、观察锚点和边界，让人物自己承担执行与判断。首次成功可以只是局部功能；稳定、压力调用和迁移按当前事件需要选择其一，不组成固定阶梯。练熟不自动等于突破，突破也不自动等于公共证明。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- “悟性不足”或“感觉不对”过于空泛 → 改成一个具体偏差。
- 连续尝试不改变错误模型 → 合并或删除。
- 一次成功被写成稳定能力 → 保留已有的限制、代价或下一验证目标。
- 导师变成教程 → 压缩到足以知道不能照抄什么、该观察什么、何时求助。
- 场景声称压力调用却没有测试 → 只有在事件已有空间时补一个最小压力条件，否则不要扩写。

不要求每场证明间隔保持、迁移给他人或完整训练链。

## Failure Patterns

- 练习次数代替反馈。
- 所有尝试都按同一正确流程推进。
- 一次偶然成功被当成能力完成。
- 导师讲完理论，人物没有执行判断。
- 训练段落偷偷完成突破或展示。
- 只写数值增长，不写实际动作差异。

**Stop when:** 当前任务所需的稳定度或可调用性已经成立，或瓶颈明确需要另一种方法、资源、理解或阶段。

# comprehension_insight
**Primary Reading Question:** 人物怎样把旧模型解释不了的现象重组为一次可用的理解？

## Use When

人物已有观察或知识，却无法预测、解释、控制或选择，核心障碍是工作模型不成立。

## Generation Lens

先让原有理解具体，再让一个反例、失败或结构差异迫使它松动。人物通过比较、拆分、模拟、回忆或最低限度试验形成暂定模型；这个模型必须改变一次预测、验证、动作或选择，并得到现实反馈。解释到当前行动需要的层级即可，不把理解扩写成完整法则。

Insight 可以直接说清，但不能替代变化过程。它解决“为什么或怎样理解”，不自动解决动作稳定、境界跨越或外部估价。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- “忽然明白”没有可见变化 → 补一个已有反例与新模型之间的具体连接。
- 新理解没有改变行动 → 接上一次最低限度的预测、试验或选择。
- 思考变成完整理论课 → 删除不影响当前决定的解释。
- 推理超出已有观察 → 降低结论，保留未知部分。
- 理解、训练和突破混在一起 → 将段落收回当前真正完成的层级。

不强制每场出现导师、试验或顿悟台词。

## Failure Patterns

- 用“灵光一闪”跳过模型变化。
- 只换一组抽象词，没有新预测。
- 解释越完整，行动越少。
- 把想明白直接写成稳定掌握。
- 把最低反馈写成宇宙真理。
- 事实和推断没有边界。

**Stop when:** 新模型已经改变一次判断、试验或行动，并获得最低限度的现实反馈。

# showcase_evaluation
**Primary Reading Question:** 谁必须按新的尺度重新估价这项能力、成果或人物，估价后现实改变了什么？

## Use When

展示结果会迫使某个拥有分配、部署、资格、谈判或策略权的人改变原有待遇或行动。

## Generation Lens

先保留旧尺或旧报价，再让成果在一个有意义的实际条件下工作。优先选择一项不可逆的身体、空间、资源、保护或机会结果，而不是连续参数。观察者按自身利害反应：识别者校准上限，受威胁者改防或改逃，分配者改价、资格或部署，普通人获得直接保护或行动信心。

只保留一个主结果和一个现实后果。公开承诺以执行者承担成本验真；若结果已经成立并改变待遇，立即转入新局面。若仍缺条件、授权或动员，只补最短的执行闭环。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 只有围观和夸赞，没有现实变化 → 接上一个已有行动权人物改变待遇、资源、策略或资格的动作。
- 只有参数，没有用途 → 把已有结果落到一个可见的身体、空间或机会成本上。
- 反转没有旧误判行动 → 若原文已有误判，补其被结果击穿；没有则不要硬造反转。
- 多个观察者重复震惊 → 合并为不同利害中的一个代表性反应。
- 已经重新估价却继续测试 → 停止追加同层级证明。

不要求每次展示都产生排名、订单或公众欢呼。

## Failure Patterns

- 好看的动作被误写成展示。
- 排名成立但无人改变行为。
- 无行动权的角色轮流宣布“很强”。
- 公开宣言没有执行成本。
- 用回放战斗代替现实定价。
- 展示完成后继续炫技。

**Stop when:** 尺度、用途和至少一项现实判断或行动后果已经清楚。

# breakthrough_advancement
**Primary Reading Question:** 旧能力、身份或生命状态跨过了哪道真实门槛，跨过后最先能做什么？

## Use When

人物不只是做得更好，而是旧上限、权限、身体结构或状态边界真正失效。

## Generation Lens

明确旧瓶颈与新状态的关键差异，让突破调用已经具备的资源、理解、身体条件、关系或机会。只展开会决定是否跨门槛的承受、控制、选择和反馈；重复运转、吸收或能量流动压缩。成功后优先给一次新状态的真实体验：过去不能感知、连续完成、承受、进入或使用的事现在首次成立。

局部效果、练熟、稳定调用和公共证明保持不同语义。限制可以留下，但不要用解释立即削弱兑现。若主要问题变成“别人如何估价”，转入 `showcase_evaluation`。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 只有数值变化，没有状态差异 → 补一个已有条件下可观察的新能力、权限、身体或行动范围。
- 局部成功被升级成完整突破 → 降回实际完成的层级，保留限制和下一验证目标。
- 突破过程重复无新判断 → 压缩运转描写，保留门槛反馈。
- 宣布突破但没有首次使用 → 补最小的真实体验。
- 无依据地追加伤害、代价或永久规则 → 删除新增推断。

不要求每次突破都受伤、不可逆或立即公开。

## Failure Patterns

- “能量暴涨”代替具体门槛。
- 练熟被写成跨级。
- 想明白被写成状态改变。
- 新状态只存在于旁白和数字中。
- 成功后连续证明同一变化。
- 为制造重量临时添加未经支持的代价。

**Stop when:** 新状态已经通过真实体验、动作、权限或世界反馈成立，且旧门槛不再是原来的门槛。

# character_voice_pressure
**Primary Reading Question:** 当前压力迫使每个人优先保护什么，又愿意为此支付什么？

## Use When

人物必须在保密、尊严、行动空间、职责、关系债务、信息责任或身体代价之间取舍。此 lens 只作跨场景参考，不作为 Primary。

## Generation Lens

先服从当前 Primary 的阅读问题，再让人物的注意对象、首保对象、支付边界和接下来要承担的任务穿过具体选择。声音从取舍、回避、抢先行动、承担风险或改变说法中出现，不从口癖中出现。公共协议与私人协议可以同时存在。多人场景保留提出、质疑、执行、裁决及少量温度反应；沉默只有在改变责任、可见性或行动时才有重量。

专业信息应落在一个未决但可执行的问题上，回答后推动命令、路线、配置、搜索或风险控制。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 角色可以互换 → 改变其已有优先级下的选择，不添加装饰口吻。
- 群体全员轮流发言 → 删除重复发言，保留真正改变功能位置的人。
- 内心标签替代声线 → 改为注意、拒绝、承担或行动差异。
- 专业信息变成讲义 → 接回已有的选择、责任或风险。
- 沉默被过度解释 → 只有存在外部结算时才保留。

不要求每个角色显式声明自己的价值排序。

## Failure Patterns

- 所有人使用同一种成熟谈判腔。
- 为展示个性强行让聪明人物失智。
- 每个角色都必须发言。
- 专业角色只讲正确知识，不承担后果。
- 把动作、物件和停顿全部翻译成潜台词。

**Stop when:** 读者能从人物的选择和代价区分其压力反应，且当前 Primary 已向下一行动推进。

# world_entry_lived_texture
**Primary Reading Question:** 这个新空间如何限制进入、承载生活，并改变别人对来者的对待？

## Use When

人物跨入新空间、机构、社区、职业秩序或生活环境，而入口边界会影响当前主问题。此 lens 只作参考，不作为 Primary。

## Generation Lens

只选择互相咬合的少量投影：一条当前可操作的准入、礼仪、支付或退出边界；一个会被使用、支付、携带、维护或承受的生活锚点；一个因此改变接待、报价、站位、警戒或路线的他人反应。用这些回答人物能否进入、怎样继续行动以及别人如何对待他。

生活纹理服务于当前 Primary，不扩写成导览、制度史或地点百科。完成投宿、求见、交易、改道、潜入、扎营或撤退等下一动作后退出；紧急场景可以压缩到最低。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 入口变成旅游导览 → 删除不影响准入、生活或待遇的景物。
- “高贵、昂贵、严格”没有行为 → 改成支付、拒绝、站位、服务或退出变化。
- 人物能看见却不知道能否进入 → 补一条当前操作边界。
- 生活细节没有被使用或承受 → 压缩。
- 入口纹理反客为主 → 删除，恢复当前 Primary。

不要求每次进入都出现价格、服饰、服务和误读。

## Failure Patterns

- 罗列建筑、历史和风俗。
- 入口礼仪只说明组织背景，不改变准入。
- 报出价格却没有购买、拒绝或机会成本。
- 宣布“显眼”“可疑”，却无人改变行为。
- 为保持神秘而隐藏眼下能否进门或留下。
- 每场机械添加生活纹理。

**Stop when:** 入口边界、生活尺度和一项现实对待已经足以推动当前下一动作。

# desire_temptation
**Primary Reading Question:** 欲望具体改变了人物看什么、漏掉什么、愿意承担什么或何时放弃退出权？

## Use When

人物的资源欲、面子、关系、金钱、身体吸引、自由或更高目标正在改变注意顺序、风险阈值或行动优先级。此 lens 只作参考，不作为 Primary。

## Generation Lens

让欲望先改变注意，再决定是否改变行动：人物多看了什么、漏检了什么、重新把目标归类成什么、是否加码、援助、撤手、改道或继续。欲望必须有现场凭据，例如时间压力、可见收益、面子损失、关系债、身体痛苦、已展示的威胁或付款后获得的出口。

人物本来可以安全离开时，只有已有收益、责任、面子账或风险变化足以取消退出权，才让其亲手留下。欲望可以被更高目标、责任、恐惧或边界压回，不自动等于占有、失控或推进。

## Revision Lens

必须 Preservation First。只修最高价值缺陷：

- 只写“贪心、心动、好胜” → 补一个已有的注意偏移或行动差异。
- 欲望没有风险凭据 → 删除心理宣言，保留可见的现场压力。
- 身体吸引被写成占有或失控 → 删除未经支持的推断，恢复人物边界。
- 面子、金钱只是标签或数字 → 改成席位、资格、支付、债务、路线或退出自由的变化。
- 人物已经能离开却被强行拖入 → 只有已有收益、责任或代价足够时才保留，否则让其离开或压缩。

不要求每场出现诱惑，也不要求欲望一定战胜责任。

## Failure Patterns

- 欲望只存在于旁白判断。
- 看见目标就自动行动。
- 吸引自动等于推进或占有。
- 金钱只用于展示财富。
- 面子成为无成本暴怒按钮。
- 没有收益或代价，却取消人物退出权。

**Stop when:** 欲望已经改变注意、选择或风险计算；若没有产生任何变化，则压缩欲望投影。
