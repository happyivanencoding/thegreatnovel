# reunion_reentry v2

## Question

一个离开很久、身份或能力已经改变的人回来后，双方如何完成认出、接纳与重新入位，而不是自动恢复原状？

## Projection Guidance

“认出”“愿意重新靠近”“允许其重新行动”是三个不同结果。当前场景只推进其中必要的一层。

旧物、旧动作、称呼或共同记忆只负责完成辨认；辨认之后必须出现：

- 一个当前仍然存在的错位；
- 一次新的共同动作、共同目的或边界选择；
- 或者明确说明为何暂时不能同行。

旧日常只保留一笔，并立即改变当前选择、风险、路线或分工。若双方目标不再兼容，重逢可以停在告别、偿还或有限承认，不强行恢复共同生活。

## Revision Watch

仅在已有局部证据支持时修：

- 已完成认出，却没有任何行动位置变化：补一个已有当前目标中的共同动作或边界。
- 旧日常连续复演、遮蔽了当前错位：压缩为一个能推动选择的回声。
- 拥抱、称呼或确认被写成关系全部恢复：保留已有的身份、责任、能力或第三方限制。
- 没有可执行共同目的：停止补写“重新开始”，改为已有事实支持的分流或有限关系。

## Use When

长期分离、误认、异化、失联、阶段性归来或旧关系重新进入公共／私人空间。

## Generation Lens

先决定当前回归者带回了什么变化：新身份、新能力、新责任、伤痕、立场或新的生活位置。

再让相认通过适合现场风险的证据完成：

- 低风险：习惯、称呼、共同记忆即可；
- 有伪装风险：递进使用旧物、私密记忆、不可轻易伪造的能力或行动；
- 公共归来：让旧身份先撞上门槛、程序、团队分工或社会评价。

认出之后，立刻回答“现在如何一起做事、一起承担，或为何不能一起走”。新的共同目的不必是战斗，也可以是返程、安置、照料、守密、分工或共同处理责任。

## Revision Lens

保留当前错位，不用怀旧抹平现实限制。

不要把单方愿意靠近改写成双方确认；不要把恋人、伙伴、师徒或旧友一律写成浪漫关系。

若回归者只是短暂显现、暂时拥有身体或短时参与行动，不得直接补成稳定生活与完整社会位置。

## Failure Patterns

- 一声自报姓名解决全部怀疑。
- 认出、接纳、社会认可被压缩成同一拍。
- 旧日常完整复演，当前变化没有作用。
- 拥抱被当作恢复原状。
- 所有重逢都强行遇袭、公开测试或再次分离。
- 没有共同目的，却硬写共同生活回归。
- 把情绪强度当作行动位置。

## Stop

双方已经通过共同动作、边界、承诺或合法分流证明：这个人重新进入了关系，但不是简单回到过去。

# identity_reveal v2

## Question

隐藏身份或真实归属揭开后，谁必须重新判断谁，谁获得或失去什么行动权，公开范围应停在哪里？

## Projection Guidance

揭露前先确定知识席位：

- 谁掌握秘密；
- 谁能验证证据；
- 谁只是受影响者；
- 谁仍会按旧身份行动；
- 谁知道后能立即改变部署、保护、站队或程序。

公开范围取当前任务所需的最小知情集，不随真相重要性自动扩大。

身份揭露必须带来行动权差分，例如：

- 获得进入、调兵、庇护或代表他人承诺的权利；
- 失去原有准入、信任或公开位置；
- 迫使敌方改攻、盟友撤手、亲属退出或组织重排；
- 让某人承担保护、保密或追责义务。

证明形式服从接收者的权力关系：本人确认、信物、文书、能力结果、现场后果都可以成立。高危身份揭露必须同时交代保护窗口、撤离路径或能承担敌意的人。

## Revision Watch

仅在已有证据与当前 Canon 允许局部修时执行：

- 揭露后无人改变行动：补一个已有角色能够执行的权限、站位、保护或敌对动作；否则将场景降为线索重解释。
- 不必要地全场公开：缩小到能实际改变行为的知情者，保留其他人的旧判断。
- 所有人统一震惊：按已有利益、知识与关系补出方向不同的反应。
- 高危身份已公开但没有保护路径：仅在正文已有援手、窗口或撤离条件时补接；没有既有条件则不得凭空制造。
- 高概率推断被写成必须揭露：保留验证、延迟或共同保密。

## Use When

身份、归属、匿名关系、真实权力位置或伪身份的揭露会改变权限、站队、敌意、保护或程序。

## Generation Lens

先问：这条真相现在要换取什么行动？

然后安排：

1. 接收者获得足以行动的事实；
2. 证明形式与其知识和权限匹配；
3. 揭露支付必要的身份成本；
4. 立即出现行动权变化；
5. 不同知识席位产生不同后果。

延迟揭露也必须产生结果：验证条件、保密责任、错误建模、部署升级或关系保护。

## Revision Lens

只修行动权链，不扩写世界观百科。

保留不同人物的知识差异，不倒灌未建立的长期历史。身份承认、获得准入、恢复信任和解决旧债必须分开。

## Failure Patterns

- 身份揭露只是给读者发答案。
- 全场知道、全场相信、全场同一反应。
- 只改变线索解释，不改变行动。
- 高危真相公开后没有敌意、保护或时间窗口。
- 用“关系亲近”代替验证与授权。
- 把不揭露写成零成本安全。
- 揭露后自动恢复全部旧身份。

## Stop

必要知情者已经据此改变权限、站位、保护、敌我判断或程序；继续解释同一身份不会增加新的行动结果。

# sacrifice_convergence v2

## Question

一个不可逆的牺牲如何同时改变眼前局势、完成真实的责任转移，并让受益者留下必须继续承担的缺口？

## Projection Guidance

仅在以下链条真实存在时使用第三方牺牲判断：

1. 牺牲者有独立意志或独立利益；
2. 若存在退出路径，退出路径真实可见；
3. 受益者或受托者有既有关系、现场行动或可核验能力，足以取得有限授权；
4. 某种生命、时间、能力、资格、责任或保护被实际转移；
5. 受益者必须通过下一次行动接住这项转移；
6. 牺牲留下不可被立即抹平的残余缺口。

牺牲者可以拒绝出口，也可以被迫失去；没有选择时，不把结果包装成“自愿牺牲”。

## Revision Watch

当前可安全局部修的范围仅限已被证据支持的链条：

- “自愿牺牲”没有真实退出权：改写为被迫失去，或保留为选择结果，不凭空增加逃生出口。
- 受托者被直接写成天然合法继承人：补已有关系或现场行动形成的有限授权；没有依据则保持未授权。
- 牺牲已发生，却没有受益者的第一步使用：仅在已有任务、遗命、资源或责任路线时补接；否则 `NONE`。
- 后续恢复抹掉已有死亡、失能、关系断裂或责任缺口：删除抹平语句，保留已成立的缺口。
- 牺牲被写成道德免罪或爱情证明：恢复已有错误方案、伦理不安、失败或第三方代价。

恢复层级、遗留能力、镜像危机和新代价校准仍 provisional，不进入本轮 Revision Watch。

## Use When

一个角色必须以不可逆付出换取救援、保护、逃生、托付、资格转移或幸存者继续行动。

## Generation Lens

先写清眼前唯一缺口：撤离时间、挡住敌人的位置、救下某人的条件或最后一条行动路线。

再让牺牲者按自己的利益作出不可撤回动作。动作必须立即改变受益者的处境，随后把转移内容落到具体对象：

- 谁获得了什么；
- 谁因此必须做什么；
- 谁失去了什么；
- 哪一项旧问题仍未解决。

牺牲不是“死亡＝奖励”。受益者的下一步必须消耗、承担或重新解释这份托付；失败也必须继续产生行动后果。

## Revision Lens

Preserve the asymmetry.

不要替牺牲者补出高尚动机，不替受益者补出同意，也不把受益者自动写成完整继承人。

不可逆结果至少保留一个身体、关系、制度或行动缺口。若救援失败，不用更强方案立即撤销失败。

## Failure Patterns

- 没有出口，却称作自愿。
- 用“他是主角”替代受托资格。
- 牺牲没有改变现场力量或行动资格。
- 遗物、能力或复活把死亡直接抵销。
- 受益者只哭泣，不接下任何行动。
- 牺牲自动证明爱情、忠诚或道德正确。
- 为制造悲壮强迫角色放弃更合理的退出路线。
- 恢复后所有人、所有能力和所有责任回到原状。

## Stop

眼前危机已因牺牲发生明确变化，转移对象已经可辨，受益者已开始接住它，并且残余缺口能够被读者复述。

# departure_vacancy v2

## Question

一个重要的人离开、失联、沉眠或被迫失去后，谁从此不能再照旧行动，谁必须承担替代、等待、改线或接回任务？

## Projection Guidance

先建立离开前的共同生活基线：

- 谁照料谁；
- 谁守哪个位置；
- 哪项工作、饭食、路线、能力或决定由谁完成；
- 哪个空间、物件或称谓证明双方仍在共同生活中。

离开后尽快呈现第一件无法照旧完成的旧动作，并让它导致新的责任、路线、风险、准入或替代关系。

严格区分：

- 主动离开：存在可留下的替代项，角色看见它并主动选择离开；
- 被迫失去：死亡、失联、灾难、沉眠或强制撤离，不伪装成主动牺牲。

等待只有在具备约束、占位动作、对象或期限时才是行动。替代只能承接局部功能，不能完整复制缺席者。

## Revision Watch

只在已有基线或已有行动条件时局部修：

- 文本已有共同生活接口，却没有展示其失灵：补一个具体旧动作的首次失败。
- 主动离开没有留下选项：改为被迫分离／失去，不新增“本可留下”的事实。
- 等待只有哭泣和回忆，但已有期限、守门、寻人或改线条件：补第一项行动；没有条件则 `NONE`。
- 替代者被写成完整复制缺席者：缩回已有授权范围，保留不可替代部分。
- 离开场同时完成告别、重建、寻人和治愈：按已有停点拆出后续 vacancy 或 aftermath。

## Use When

离开本身正在制造新空位、新路线、新责任、新限制或新的替代关系。

## Generation Lens

先写离开前仍然有效的生活接口，再让接口失效：

1. 旧空间、动作或责任被废止；
2. 留下者第一次发现不能照旧完成；
3. 出现替代、拒绝、等待、改线或接回；
4. 新秩序只推进到第一项成立处。

计划性离开可以由旧居失效、物资核算、路线确定或最后一次维护停止来封口。被迫失去则先写结果，不补造主动选择。

## Revision Lens

离开不自动等于死亡，空位不自动等于永久失去。

不要添加未经 Canon 建立的召回器、归期、遗言或未来承诺。保留被留下者获得的新自由、新责任或新风险；不要把所有 vacancy 都解释成单纯损失。

## Failure Patterns

- 只有哭泣、空屋和想念，没有旧动作失灵。
- 离开前没有共同生活基线，却强写生活空位。
- 把被迫失去包装成主动牺牲。
- 等待没有约束、对象、期限或用途。
- 新人完整复制缺席者。
- 一场内同时完成离开、重建、寻人和治愈。
- 把遗物自动变成未来回归承诺。
- 离开后全世界都暂停行动。

## Stop

离开已经通过一个不可逆动作、第一次旧功能失灵或第一项新替代／改线决定形成可见的新局面。

# Event Handoff Rules

1. `departure_vacancy → reunion_reentry`

   只交接已成立的：离开类型、共同生活基线、第一件失灵的旧动作、缺席者状态、留下者的新路线。不得交接“关系已经修复”。

2. `departure_vacancy → relationship`

   只有当空位改变了具体照料、责任、信任、边界或行动路线时交接。情绪停滞本身不能作为关系结论。

3. `reunion_reentry → relationship`

   先交接认出结果、当前错位、新共同目的或合法分流条件；不得把拥抱、称呼或认出直接交接为双向承诺。

4. `identity_reveal → reunion_reentry`

   若身份揭露的主要后果是旧人重新进入关系，交接知识席位、证明形式、公开范围和行动权变化；不得交接成所有人已经知道或接受。

5. `identity_reveal → relationship`

   只有当揭露改变了私人边界、信任、保护或共同决定权时交接。身份信息本身不是关系变化。

6. `sacrifice_convergence → aftermath`

   必须交接：牺牲者的独立意志、授权依据、不可逆转移、受益者的第一步行动和残余缺口。没有这些内容时，交接为普通死亡、失败或战斗余波。

7. `sacrifice_convergence → relationship`

   只能交接已成立的责任、债务、保护、拒绝或关系断裂；牺牲不得自动交接为爱情、原谅或永久关系。

8. `sacrifice_convergence → reunion_reentry`

   若牺牲后的恢复或归来发生，只交接实际恢复的层级与仍存在的缺口；不得提前交接完整身体、完整能力、完整社会位置。

9. 每次交接只传递“已发生状态＋未解决压力＋下一步可执行接口”，不传递作者计划、未兑现承诺或未建立的历史。

10. 一场只选择一个 Primary Event Skill。其他事件只能作为局部修饰；若主要问题从“离开”变为“归来”“身份改变”或“不可逆交接”，立即切换主 Skill。
