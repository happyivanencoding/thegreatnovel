# recovery_restoration v2

## Question

人物当前失去的是哪一层功能？什么阻断使普通恢复无效？本场只需恢复到什么行动阈值？部分恢复会怎样改变下一步？

## Projection Guidance

仅当恢复层级、阻断条件、行动阈值或残余限制不清时使用。

优先确认：

- 缺损属于身体承载、能量储备、能力调用、意识/行动权，还是社会位置。
- 是否存在已建立的封印、异力、缺失载体、永久残损或资源限制。
- 当前恢复只需达到“能活、能移动、能调用、能工作、能承担某项决定性行动”中的哪一个阈值。
- 尚未恢复的部分是否会真正约束下一步。

层级已清楚、首次再用已成立时，停止投射并写 `NONE`。

## Revision Watch

`NONE`（Direct Reviser A/B：`NONE`）

## Use When

人物的核心问题是从受损、失去或中断状态重新获得可用功能。

不因出现伤势、药物或休养自动调用。若主要问题已经变成战斗、资源争夺、模型误判、境界跨越或他人定价，应转交对应 Primary。

## Generation Lens

先把“不能做什么”写成可观察事实，再选择本场真正要恢复的一层。不要默认身体、能量、意识、能力和社会位置同步恢复。

当普通疗法无法解释进展时，先处理已经建立的核心阻断；不要用不断换药、加痛感或延长时间替代诊断。每个处理动作都应改变恢复判断：确认有效、暴露失败、解除阻断、恢复一项功能，或改变可承担的行动。

长疗程只保留诊断、关键失败、首次有效反馈和首次再用。稳定重复的服药、运功、等待与移动压缩。

部分恢复可以成立，但必须明确：

- 现在能完成什么；
- 还不能完成什么；
- 为什么当前程度已经足以启动下一项行动。

首次再用优先选择已有局势中的必要动作：复工、履约、保护、逃生、谈判或出手。恢复若带来新境界，先结算恢复，再转入 `breakthrough_advancement`。

## Revision Lens

必须 Preservation First，只修最高价值缺陷：

- “恢复了”过于抽象 → 补出一个恢复前做不到、恢复后重新做到的动作。
- 部分恢复被写成全盛 → 降回实际阈值，并保留会影响下一步的限制。
- 普通治疗反复推进 → 找出已建立的真正阻断；若没有依据，删除新增阻断。
- 时间跨度很长但状态没有节点 → 压缩过程，只保留方法、反馈、阈值或行动变化。
- 残余限制只作装饰 → 让它约束下一次选择；做不到时删除该限制。
- 身体已愈但意识或行动权未回归 → 分开处理不同恢复层。
- 恢复资源已被看见并争夺 → 停止继续写静态疗伤，转入资源或战斗场景。

## Failure Patterns

- 默认恢复如初。
- 用疼痛代替恢复判断。
- 把醒来、止血、能量回升和回到峰值写成同一状态。
- “数日后痊愈”却没有行动证明。
- 一次能动被写成稳定作战能力。
- 为制造代价临时添加永久伤残或新规则。
- 恢复后继续重复证明同一功能。
- 关系或社会位置由旁白宣布恢复，没有实际共同动作或责任变化。

## Stop

当本场目标层已经通过实际行动确认，人物知道当前能做什么、不能做什么，且残余限制已兑现或不再影响下一步时停止。

## Handoff Guidance

- `training_learning`：功能已恢复，但动作仍不稳、不可重复或无法承压。
- `comprehension_insight`：恢复受阻的核心变成解释模型错误，而不是身体处理。
- `showcase_evaluation`：恢复后的能力需要被有行动权的人重新定价。
- `resource_economy`：疗伤来源变成稀缺、可争夺、可交易或需要分配的资源。
- `combat`：恢复后的主要问题已经是双方如何交战，而不是能否恢复。

# trial_challenge v2

## Question

这道外部门槛究竟授予或剥夺什么？人物拥有哪一个可见的决策权？哪个铰链会改变判定？多阶段试炼本场只结算哪一级权利？

## Projection Guidance

仅当“资格与真实主线”、可见决策权、判定铰链或阶段权利不清时使用。

优先确认：

- 判定物、阈值、出局动作和通过后第一项实际权利。
- 试炼资格与人物真正要完成的任务是否分开。
- 人物或团队是否能在路径、顺序、资源、合作、风险或规则解释上作出可见选择。
- 哪个失败、异常、稀缺名额、队伍失配或对手动作会改变成功概率。
- 进入、资格确认、目标完成、社会承认之间哪些已经结算，哪些仍留给后续。

这些关系已清楚时，停止投射并写 `NONE`。

## Revision Watch

`NONE`（Direct Reviser A/B：`NONE`）

## Use When

人物必须在明确外部规则、判定线和失败后果下争取进入、资格、资源、位置或权限。

如果外部判定只提供合法身份，过程没有选择、代价或反馈，应压缩为结果。若主要问题是反复练习，转入 `training_learning`；若主要问题是证明能力价值，转入 `showcase_evaluation`。

## Generation Lens

先让读者知道判定物、阈值、失败后的损失和通过后的第一项行动空间。不要只说“这场考试很重要”。

把资格和真实故事分开。通过一层只授予该层已经承诺的权利，不自动完成救援、复仇、身份承认、资源占有或终局目标。

让人物拥有一个真正可见的决策权：改变顺序、押注强项、选择伙伴、分配资源、承担风险、利用规则或决定退出。若人物没有任何能改变结果的选择，试炼过程应压缩。

重点展开判定铰链，而不是完整考试流程。铰链可以是有限次数、规则异常、关键名额、队伍失配、对手干预、成品保全或结果复核。重复尝试只有在反馈、方法、代价或概率发生变化时展开。

隐藏规则必须先由现场异常或失败支付验证成本，再让人物修正理解。不得在结果揭晓时临时改写规则。

多阶段试炼每次切场都结算权利：保留什么、失去什么、下一层目标是什么、退出会付出什么。团队试炼重点写规则如何迫使队伍指挥、分工、重组或撤退，不平均展示成员。

## Revision Lens

必须 Preservation First，只修最高价值缺陷：

- 只说“很重要” → 写明通过后获得或失去的具体行动空间。
- 人物没有决策 → 从已建立的选项中补一个改变结果的选择；没有既有选项则压缩场景。
- 资格通过被写成主线目标完成 → 分开当前结算层和未结算目标。
- 隐藏规则像作者补丁 → 补现场已有的异常、失败和一次验证成本；无依据则删除。
- 多阶段只换地点不换权利 → 补每一层的资格、退出代价和下一层目标。
- 重复操作没有新反馈 → 合并同类尝试，保留真正改变判定的铰链。
- 通过后只有欢呼 → 接上有行动权者改变资格、资源、待遇或策略的动作。
- 团队成员轮流炫技 → 收回到一个改变整体结果的协作决策。

## Failure Patterns

- 把考试流程写成流水账。
- 只写“赢了一场”，没有资格、资源或位置变化。
- 主角没有选择，结果靠作者宣布。
- 末尾突然揭露此前没有迹象的真规则。
- 每过一层只换地图，不结算权利。
- 把资格通行证直接写成终极目标完成。
- 团队试炼变成成员排队展示。
- 已确认通过后继续重复证明。

## Stop

当外部判定已经确认，本场应结算的资格或权利已经落地，且下一目标、退出代价或未结算层级清楚时停止。

## Handoff Guidance

- `training_learning`：外部资格已结算，剩余问题是把能力练到稳定、可重复或可承压。
- `comprehension_insight`：试炼的核心已转为破解规则、翻译提示或重组工作模型。
- `showcase_evaluation`：试炼结果已成立，接下来是有行动权者如何重新估价。
- `resource_economy`：通过后的奖励、名额、入口或材料进入分配、争夺或交易。
- `combat`：试炼规则已退居背景，胜负主要由对手之间的战术与行动决定。

# breakthrough_advancement v2

## Question

旧能力、身份或生命结构究竟跨过了哪道门槛？当前属于尝试、局部成功、半步、稳定突破还是社会证明？每项资源解决什么，结构瓶颈是什么？跨过后最先能做什么？

## Projection Guidance

仅当阶段状态、资源与结构瓶颈、同一判尺、首次新行动或社会证明时序不清时使用。

优先确认：

- 当前是尝试、局部变化、资格/半步、稳定突破，还是延后的社会证明。
- 贯穿突破前后的同一判尺是什么，例如核心能否稳定、结构能否承载、单位动作能否完成、力量能否在压力下维持。
- 资源解决燃料、承载、维持还是机会；身体、理解或结构解决哪个真正瓶颈。
- 旧结构被替换、重排、融合或补齐了什么。
- 新状态是否有一次旧状态不可能完成的第一行动。
- 社会证明是否需要延后到下一场真实冲突。

这些关系已清楚时，停止投射并写 `NONE`。

## Revision Watch

`NONE`（Direct Reviser A/B：`NONE`）

## Use When

人物的旧上限、权限、身体结构、生命层级或能力边界真正失效，并形成新的可用状态。

不因资源增加、感悟出现、称号变化、临时强化、练熟或看见更高方向自动调用。没有结构变化或新状态成立证据时，不称为完整突破。

## Generation Lens

先标出阶段，不把尝试、半步、局部成功、稳定突破和社会证明合并成一句“突破了”。

用同一判尺比较前后状态。若突破前问的是“核心能否承载高压”，突破后仍应让读者看到核心是否稳定，而不是突然换成气势、等级或围观反应。

拆开资源瓶颈和结构瓶颈：

- 资源可以提供燃料、承载条件、维持时间或关键材料；
- 理解、身体或结构变化才可能解决真正的跨层门槛；
- 每项条件只承担一个明确职责。

失败可以成立，但必须诊断出旧路径为何不够，并改变下一步资源选择、结构方案或行动目标。资源开始消耗、局部成形、看见方向，都不等于稳定突破。

突破后的第一行动优先解决当前已存在的问题：破困、救人、转移、反制、开启新通路或承担此前无法承担的责任。没有合适现场时，不强行安排展示，可保留社会证明到后续真实冲突。

连续跨越必须分别结算每一道门槛。高阶突破若依赖多种力量，应写出它们如何稳定共存，而不是只写同时暴涨。适应期、消耗或限制只有在已有依据时保留，不把受伤设为固定成长税。

## Revision Lens

必须 Preservation First，只修最高价值缺陷：

- 只有数值和气势变化 → 用同一判尺补出具体状态差异。
- 感悟、资源吸收或半步被写成完成 → 降回实际阶段，保留未解门槛。
- 资源被当成结构解法 → 明确资源只解决承载、燃料或维持中的哪一项。
- 结构变化没有缺口 → 补出已有前置条件中真正缺失、替换或重排的部分；无依据则降低突破结论。
- 突破后没有首次新行动 → 在已有局势中补最小可行兑现；没有合适局势则保留延迟证明。
- 私密突破被硬塞围观和排名 → 把社会证明延后到有行动权者被迫重估的场景。
- 同一变化被连续测试 → 保留首次有效动作，切出到下一主场景。
- 为制造重量追加未经支持的永久代价 → 删除。

## Failure Patterns

- “能量暴涨”替代真实门槛。
- 资源数量直接等于突破完成。
- 想明白直接等于身体或结构改变。
- 把局部成功、半步和稳定状态混为一谈。
- 突破前后偷偷更换判尺。
- 新状态只存在于旁白、数字和等级名称中。
- 突破后只打木桩或重复报境界。
- 为了社会证明强行召集旁观者。
- 每次突破都受伤、不可逆或立刻获得社会地位。
- 连续跨层只报一个结果，不分别交代门槛。

## Stop

当阶段状态、同一判尺下的前后差异、资源与结构职责、首次新行动或合理的延迟证明已经清楚时停止。

若只完成理解、局部成功或资格，不继续伪装成稳定突破；转交 `comprehension_insight`、`training_learning` 或保留下一门槛。

## Handoff Guidance

- `training_learning`：结构已经成立，但控制、稳定性、重复调用或压力适应尚未证明。
- `comprehension_insight`：变化停留在新模型、新解释或方向感，尚未改变能力结构。
- `showcase_evaluation`：突破已成立，接下来由有分配、部署、资格或谈判权者重新定价。
- `resource_economy`：真正瓶颈是取得、保有或分配资源，结构尚未跨越。
- `combat`：第一新行动进入现实交锋，主要问题变成双方如何利用、限制或反制新状态。
