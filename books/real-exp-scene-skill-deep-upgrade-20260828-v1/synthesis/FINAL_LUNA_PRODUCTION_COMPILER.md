# social_bargain_decision

**Primary Reading Question:** 谁想让谁做什么；这一轮交流具体改变了谁的条件、信息边界、发言资格或下一行动？

**Projection Guidance:** 仅当诉求或本轮结算不清时，盯住条件、信息边界、发言资格与下一行动；已清楚则 NONE

**Revision Watch:** 仅修连续对白无结算或角色可互换：保留原决定与筹码，合并重复回合或恢复一个已批准的差异化反应。

## Use When

人物正在谈判、试探、招募、审问、拒答、交换条件、公开表态或争夺决定权；对话本身必须改变可行动空间，而不是只搬运信息。

## Generation Lens

先抓住各自最想保住的东西、愿付的代价和真正受话者。重要一句话必须留下可见结算：条件升降、有限信息暴露、信任改变、关系边界变化、发言资格变化、路线关闭或行动启动。

拒答不是气氛。若人物不完整回答，应留下一个可观察替代物：有限事实、新问题、担保、任务、时间点或行动。部分披露只在保留内容仍影响下一轮选择时成立。

动作、距离、旁观者和物件只有在改变谁能发言、谁必须表态、谁可旁听或谁承担风险时才进入对白结构。多人对白只保留会改变决定结构的角色。

专业信息应落在一个未决但可执行的问题上，并推动命令、配置、选人、路线或风险判断。人物声音来自压力下先保护什么、先注意什么、愿意承担什么，而不是口癖。

笑点只能短暂释放关系、面子或压力。真实责任、伤势、权限或行动一旦不可逆出现，立即回到主问题。

## Revision Lens

Preservation First。只修明确失败：

- 连续对白没有改变条件、信息、关系或行动，删并同义回合，保留第一次真正结算。
- 人物可互换，不重写整段，只在一个关键回应处恢复各自已有的首保对象、注意对象或代价边界。
- 拒答只剩冷笑、沉默或反问且没有留下东西时，仅在上下文已有授权结果的情况下恢复一个最小有限事实或行动。
- 专业信息不可执行时，压到足以改变一次选择的最低信息。
- 多人轮流发言却没有职责差异时，保留真正推动状态的少数角色。
- 笑点越过危险、责任、处罚或决定成立后的停止点时，删到现实后果第一次接管场景。
- 不新增交易条件、秘密、筹码、承诺、制度权限或人物动机。

## Failure Patterns

信息搬运；会议纪要；连续试探不付成本；保留项没有筹码价值；身份只剩敬称；所有聪明人同一种声音；笑点吞掉后果。

**Stop when:** 决定、条件、承诺、合作边界、信息边界、发言资格或下一行动已经发生可执行变化。

# relationship

**Primary Reading Question:** 既有关系在这一刻具体改变了人物愿意承担什么、允许什么或选择哪条路？

**Projection Guidance:** 仅当关系如何改写选择不清时，盯住具体欲望、对方回应与新边界或路线落点；已清楚则 NONE

**Revision Watch:** 仅修关系被命名却无行为后果，或单方付出被写成双向确认；保留既有边界与责任，做最小删补。

## Use When

共同历史、亏欠、信任、保护、失望、依赖或告别正在改变人物的行为，而不只是改变情绪名称。

## Generation Lens

让关系通过选择和回应显形：一方先做出符合自身历史的动作，对方再按自己的理解回应，随后改变距离、称呼、边界、行动权、风险、路线或共同计划。

关系对象应改变一个具体的安全路线、风险阈值、底牌、时间、劳动或身体承受。日常负荷只有在迁移、缺席、替换、争执或新责任迫使它重新分配时才展开。

公共身份、责任和程序仍可成立；私人靠近、沉默或保护只改变具体的人际边界，不自动改写制度结果。单方照料、保护、离开或牺牲只证明一方的选择，不替对方补出同意或永久关系。

若双方必须据此共同决定去留、风险、照料或边界，应使用具体直说，并由接受、拒绝、改线或共同动作承接。没有可执行共同结论时，才保留微反应或沉默；沉默必须有真实外部反事实。

区分单方选择、对方接受或拒绝、双向确认和竞争义务排序。关系兑现后允许停留，让新位置通过小动作、共同动作或尴尬适应被体验。

## Revision Lens

Preservation First。只修最高价值缺陷：

- 关系只被命名，没有行为后果时，补一个最小的边界、路线、风险或照料变化。
- 单方行动被写成双向确认时，删除未经支持的互爱、和解或承诺结论。
- 私人关系抹掉公共责任时，恢复仍在生效的身份、程序或第三方代价。
- 沉默被解释成深情但没有外部结果时，若已有可接动作则补动作，否则压缩沉默。
- 关系兑现后立即被新危机覆盖时，保留一小段适应或余波。
- 不把关系默认解释为浪漫关系，不设置情绪配额，不以关系强度覆盖师门、群体或生存义务。

## Failure Patterns

用“关系更深了”代替行为变化；亲近自动战胜责任和制度；一方付出被误写成双方共识；每个停顿和物件都被强行翻译；兑现后立即总结或制造新危机。

**Stop when:** 新的关系边界已经由行为、选择或明确表达成立，并且继续互动不再增加关系信息或体验。

# identity_reveal

**Primary Reading Question:** 隐藏身份或真实归属揭开后，谁必须重新判断谁，谁获得或失去什么行动权，公开范围应停在哪里？

**Projection Guidance:** 仅当知识席位、证明物或行动权变化不清时，盯住最小知情集与一项权限、站队或保护变化；已清楚则 NONE

**Revision Watch:** NONE

## Use When

身份、归属、匿名关系、真实权力位置或伪身份的揭露会改变权限、站队、敌意、保护、保密或程序。

## Generation Lens

揭露前先确定知识席位：谁掌握秘密、谁能验证证据、谁只是受影响者、谁仍会按旧身份行动，以及谁知道后能立即改变部署、保护、站队或程序。

公开范围取当前任务所需的最小知情集，不随秘密的重要性自动扩大。证明形式服从接收者的知识与权力关系：本人确认、信物、文书、能力结果或现场后果都可以成立。

真正的揭露必须带来行动权差分：获得进入、调度、庇护或代表他人承诺的权利；失去旧准入、信任或公开位置；迫使敌方改攻、盟友撤手、亲属退出或组织重排；或让某人承担保护、保密或追责义务。

高危身份揭露必须服从已有的保护窗口、撤离路径或能承担敌意的人。关系承认、身份获准进入、恢复信任和解决旧债分开处理。

延迟揭露也必须产生结果，例如验证条件、保密责任、错误建模、部署升级或关系保护。事实、支持性推断和未知原因不能混写。

## Revision Lens

只修行动权链，不扩写世界百科：

- 保留不同人物的知识差异，不把全场改成统一震惊。
- 揭露后无人改变行动时，仅在已有条件内补一个权限、站位、保护或敌对动作；没有依据则降为线索重解释。
- 不必要地全场公开时，缩小到能实际改变行为的知情者。
- 高危真相已公开但没有保护路径时，只有在正文已有援手、窗口或撤离条件时补接。
- 不把身份揭露倒灌成未建立的长期历史、旧关系或隐藏动机。
- 不把高概率推断直接写成必须揭露。

## Failure Patterns

身份揭露只是给读者发答案；全场知道、全场相信、全场同一反应；只改变线索解释而不改变行动；高危真相公开后没有敌意、保护或时间窗口；亲近替代验证与授权；揭露后自动恢复全部旧身份。

**Stop when:** 必要知情者已经据此改变权限、站位、保护、敌我判断或程序。

# departure_vacancy

**Primary Reading Question:** 一个重要的人离开、失联、沉眠或被迫失去后，谁从此不能再照旧行动，谁必须承担替代、等待、改线或接回任务？

**Projection Guidance:** 仅当缺席现实变化不清时，盯住离开前基线、首次失灵的旧动作与新责任或路线；已清楚则 NONE

**Revision Watch:** NONE

## Use When

离开、失联、沉眠、死亡或强制撤离正在制造新的空位、责任、路线、等待或替代关系，而不是只制造伤感。

## Generation Lens

先建立离开前的共同生活或使用基线：谁照料谁、谁守哪个位置、哪项工作、饭食、路线、能力或决定由谁完成，哪个空间或物件证明双方仍在共同生活中。

离开后尽快呈现第一件无法照旧完成的旧动作，并让它导致新的责任、路线、风险、准入或替代关系。替代只能承接有授权的局部功能，不能完整复制缺席者。

严格区分主动离开与被迫失去。主动离开必须存在可留下的替代项，角色看见它并主动选择离开；死亡、失联、灾难、沉眠或强制撤离不得伪装成主动牺牲。

等待必须行动化：留下、延后、替代看守、转向搜寻、拒绝离开或承担新风险至少发生一次。遗留物、空位、旧路或习惯只有在“原来如何使用”与“现在如何空置、替代、改用或无法使用”之间形成差异时才承担缺席证据。

## Revision Lens

Preservation First：

- 文本已有共同生活接口，却没有展示其失灵时，补一个具体旧动作的首次失败。
- 主动离开没有留下选项时，改为被迫分离或失去，不新增“本可留下”的事实。
- 等待只有哭泣和回忆，但已有期限、守门、寻人或改线条件时，补第一项行动。
- 替代者被写成完整复制缺席者时，缩回已有授权范围。
- 离开场同时完成告别、重建、寻人和治愈时，按已有停点拆出后续 vacancy 或 aftermath。
- 不把空位自动解释为死亡，不凭遗物新增召回器、归期或未来承诺。

## Failure Patterns

只有哭泣、空屋和想念，没有旧动作失灵；离开前没有共同基线；把被迫失去包装成主动牺牲；等待没有约束、对象、期限或用途；新人完整复制缺席者；一场内完成离开、重建、寻人和治愈。

**Stop when:** 离开已经通过不可逆动作、首次旧功能失灵或第一项新替代、等待或改线决定形成可见的新局面。

# sacrifice_convergence

**Primary Reading Question:** 一个不可逆的牺牲如何同时改变眼前局势、完成真实的责任转移，并让受益者留下必须继续承担的缺口？

**Projection Guidance:** 仅当牺牲的意志、授权、转移、受益者行动或残余缺口不清时，盯住最小交接链；已清楚则 NONE

**Revision Watch:** NONE

## Use When

一个角色必须以不可逆的生命、能力、时间、资格、位置或责任损失，换取救援、保护、逃生、托付或另一人继续行动。

## Generation Lens

先明确唯一缺口与不可两全条件：撤离时间、挡住敌人的位置、救下某人的条件或最后一条行动路线。

牺牲者按自己的利益作出不可撤回动作。若存在退出路径，应让退出路径真实可见；若没有选择，应写成被迫失去，不包装成自愿牺牲。

第三方牺牲必须保留独立意志、授权依据、不可逆转移和幸存者责任：

1. 牺牲者有自己的最后愿望或独立利益；
2. 受托者通过既有关系、现场行动或可核验能力取得有限授权；
3. 生命、时间、能力、资格、责任或保护被实际转移；
4. 受益者在后续行动中接住这项托付；
5. 牺牲留下不能被立即抹平的残余缺口。

牺牲不是“死亡等于奖励”。受益者的下一步必须消耗、承担或重新解释这份托付。恢复、遗留能力、镜像危机和新代价校准不自动纳入本 Skill。

## Revision Lens

Preservation First：

- “自愿牺牲”没有真实退出权时，改写为被迫失去，或保留为事实允许的选择。
- 受托者被写成天然合法继承人时，补已有关系或现场行动形成的有限授权；没有依据则保持未授权。
- 牺牲已发生却没有受益者第一步使用时，仅在已有任务、遗命、资源或责任路线时补接。
- 后续恢复抹掉已有死亡、失能、关系断裂或责任缺口时，删除抹平语句。
- 不因后续需要把牺牲者改写成纯资源，不把牺牲自动写成道德免罪、爱情证明或永久关系。

## Failure Patterns

没有出口却称作自愿；用“他是主角”替代受托资格；牺牲没有改变现场力量或行动资格；遗物、能力或复活抵销死亡；受益者只哭泣不接行动；为制造悲壮强迫角色放弃更合理的退出路线。

**Stop when:** 眼前危机已因牺牲发生明确变化，转移对象可辨，受益者已开始接住它，残余缺口能够被复述。

# reunion_reentry

**Primary Reading Question:** 一个离开很久、身份或能力已经改变的人回来后，双方如何完成认出、接纳与重新入位，而不是自动恢复原状？

**Projection Guidance:** 仅当认出、接纳、重新入位或当前错位不清时，盯住一项证据、一个限制与新的共同动作或合法分流；已清楚则 NONE

**Revision Watch:** NONE

## Use When

长期分离、误认、异化、失联、阶段性归来或旧关系重新进入公共或私人空间。

## Generation Lens

把认出、愿意重新靠近、允许其重新行动分开。旧物、旧动作、称呼或共同记忆只负责完成辨认；辨认之后必须出现一个当前仍存在的错位，以及一次新的共同动作、共同目的、边界选择，或明确说明为何暂时不能同行。

让回归者当前的新身份、新能力、新责任、伤痕、立场或生活位置有机会改写原定方案。“回家”必须落到哪个家、以什么风险回去。

低风险时可以用习惯、称呼或共同记忆；存在伪装风险时，才递进到旧物、私密记忆、难伪造的能力或行动；公共归来则让旧身份先撞上门槛、程序、团队分工或社会评价。

旧日常只保留一笔，并立即改变当前选择、风险、路线或分工。若双方目标不再兼容，重逢可以停在告别、偿还或有限承认，不强行恢复共同生活。

不完整回归要保留层级：可感知存在、意识回应、身体稳定、独立选择、重新取得团队或社会职能不是同一状态。

## Revision Lens

Preservation First：

- 认出被写成旧关系全部恢复时，保留当前身份、责任、能力或第三方限制。
- 已完成认出却没有行动位置变化时，仅从已有目标补一个最小共同动作或边界。
- 旧日常连续复演并遮蔽当前错位时，压缩为一个能推动选择的回声。
- 没有共同目的时，停止补写“重新开始”，改为已有事实支持的分流或有限关系。
- 不强行补全分离期间未被 Canon 建立的心理、历史或承诺。

## Failure Patterns

一声自报姓名解决全部怀疑；认出、接纳、社会认可和行动资格挤成一拍；旧日常完整复演；拥抱被当作恢复原状；所有重逢都强制遇袭、公开测试或再次分离；没有共同目的却硬写回到从前。

**Stop when:** 双方已经通过共同动作、边界、承诺或合法分流证明这个人重新进入关系，但不是简单回到过去。

# comedy_banter

**Primary Reading Question:** 人物把同一个现实变量看成不同东西后，现场的面子、关系、风险或任务怎样偏移？

**Projection Guidance:** 仅当笑点靶子或现实后果不清时，盯住面子、风险、任务偏移与回压停止点；已清楚则 NONE

**Revision Watch:** NONE

## Use When

当前主问题允许通过错位、拆台、误解或关系性玩笑释放压力、试探立场或改变现场温度。

## Generation Lens

先让笑点命中一个硬变量：地位、风险、资源、时间、责任或行动授权。玩笑必须服务于保密、试探、降格、拖延、缓冲或占便宜，并命中具体面子、旧账、责任、站位或当前选择。

人物声音来自他优先保护什么、愿意支付什么，而不是口癖或统一机灵。有效回合应改变面子、任务承诺、关系位置、误判成本或风险判断。

媒介如截图、照片、账号、文件、自动回复、禁言或私聊，只有在改变误解、归因、权限或责任链时才进入场景。高压场景中的玩笑应带着命令、武器、警报、拘束、敌情、身体伤害或程序后果等回压载体。

出现真实责任、身体风险、权限变化或不可逆结果时，立即转入调查、救援、执行或后果，不靠旁白宣布严肃。

## Revision Lens

Preservation First。只修最高价值缺陷：

- 笑点没有改变硬变量时删除；若已有可承接反应，补最小的面子、任务或风险变化。
- 角色对白可互换时，恢复其已有取舍和回应，不添加口头禅。
- 危险被玩笑抹平时，恢复已有的物理或程序回压。
- 误判没有成本时，让已有误判落到路线、部署、暴露或延迟上。
- 严肃结果后仍连续抖梗时，在第一个真实后果处停止。
- 不为每个角色补一条个性台词，不为群体场景强行补齐功能岗位。

## Failure Patterns

只是换词嘲讽；所有人像同一个聪明人；误解只让读者优越；危险出现后仍像安全闲聊；旁白解释笑点；连续包袱没有新的关系、任务或风险变化。

**Stop when:** 一个笑点已经完成关系释放、面子变化或任务偏移；出现不可逆后果或主问题改写时立即转入下一种行动。

# investigation

**Primary Reading Question:** 当前未知如何被行动和证据缩小成一个更具体的问题？

**Projection Guidance:** 仅当未知或证据层级不清时，盯住可检验问题、假设收缩与下一行动；证据足够即停，已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物需要通过观察、询问、跟踪、实验、比对或设局获取外部信息，并改变对可能解释的判断。

## Generation Lens

把未知写成可检验的问题。每条有效证据都应确认、排除、暴露矛盾、提高一条线索权重，或精确化下一步目标；信息必须推动查谁、去哪、测什么、回到哪里或设置什么反应。

证人和对象有自己的利益、记忆缺口和应对，不是线索终端。观察、当前可支持的推断与仍未知的原因分开。错误方向可以存在，但必须来自已有证据和人物判断。

当证据足够支撑结构性解释时，停止继续搜集，交给 `deduction_reveal`。不为每次调查补齐线索数量或证人类型。

## Revision Lens

Preservation First：

- 线索没有改变假设空间时删除，或补一个已有角色会因此采取的最小行动。
- NPC 只负责吐线索时，保留其已有利益、隐瞒、误记或反制。
- 观察、推断和未知混写时，降低结论强度，恢复事实边界。
- 重复证词和同义线索合并为一个最有区分度的证据。
- 已有证据足够解释却继续找线索时，提前交接到推理。

## Failure Patterns

线索数量增加但判断不变；证人像数据库接口；错误方向只是拖延；把猜测写成事实；为神秘保留与当前问题无关的细节；调查完成后继续访问更多信息源。

**Stop when:** 未知已缩小为新的具体问题，证据足以支持下一次直接行动，或已有证据应转入结构性推断。

# deduction_reveal

**Primary Reading Question:** 已知事实重新组合后，哪种解释突然能同时成立，并改变人物下一步做什么？

**Projection Guidance:** 仅当事实连接或行动后果不清时，盯住解释约束与一次改判或行动；结论成立即停，已清楚则 NONE

**Revision Watch:** NONE

## Use When

关键证据已经在场，主要问题不再是寻找更多事实，而是解释它们之间的时间、位置、动机、因果、身份或规则关系。

## Generation Lens

只召回支撑当前矛盾的少数事实，让不同解释互相约束。暂定模型可以成立，也可以被已有事实迫使修正；每次修正都应减少一种解释、暴露一个前提或改变验证方式。

旧证据重释必须接入新的时间、位置、对象或规则约束，并改变调查对象或验证动作。Reveal 的价值在于人物因此改防谁、去哪、信谁、利用什么机会或放弃哪条路线。

必要时只做最低限度的验证。只解释当前行动需要的层级，不凭揭示补造更大的世界机制。若还需要持续获取外部证据，返回 `investigation`。

## Revision Lens

Preservation First：

- 重新念线索却没有解释变化时，删除重复事实，保留真正承重的连接。
- 结论跳跃时，补一个已有的时间、位置、动机或规则约束，不新增事实。
- 揭示没有行动后果时，接上一个已有角色能作出的判断或选择。
- 暂定推断被写成确定真相时，恢复不确定性。
- 真相成立后继续搜集确认时，删除多余确认或切换到新问题。

## Failure Patterns

把旧线索按顺序复述；用灵光一闪跳过连接；让人物知道超出证据边界的答案；Reveal 只服务读者不改变行动；多个角色轮流确认同一真相；推理场景变成新的线索搜集。

**Stop when:** 一个解释已经能约束关键事实，并明确改变人物的判断或行动。

# horror_anomaly

**Primary Reading Question:** 人物原本依赖的正常规则在哪里失效，失效后还有什么可以相信？

**Projection Guidance:** 仅当正常标尺、单一违例或可行动后果不清时，盯住规则失效与风险迁移；转生存或调查即停，已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物面对无法用当前正常模型解释的异常，并且异常会改变安全判断、可信信息、路线或行动策略。

## Generation Lens

先让读者和人物共享一条具体的正常标尺，再让一个清晰的规则违例产生结果。每个异常只承担一个硬违例；前一违例尚未结算前，不继续堆黑影、怪声和新名词。

身体反应只有在能与动作、物件、空间或他人反应形成可复核映射时才保留。至少区分主观感到什么与身体、他人或记录层面留下什么后果，但不要求每场凑齐多种证据层。

感知越多不必越接近真相。保留一个仍可行动的感知通道，并让过量感知产生具体代价。风险应从未知、怀疑、验证逐步迁移到兑现或规避，不能只用形容词升级。

普通解释已覆盖关键因果时，警报必须结算。异常一旦被多人共享、可预测或可利用，就交给生存、战斗、调查、关系或余波。

## Revision Lens

Preservation First：

- 用“阴森、诡异、不可名状”替代具体事件时，改成一个已有事实支持的规则失效。
- 多个异常互相抢夺注意时，保留最能改变行动的一项。
- 身体反应没有后果时，接上已有动作、物件或风险变化。
- 过度模糊导致空间不可追踪时，明确观察事实，保留原因未知。
- 一直说更危险但策略不变时，补最小的路线、撤离权或判断变化。
- 不凭空增加接触物、敌人能力或本章未授权结果。

## Failure Patterns

连续堆怪现象却没有人物判断；读者不知道人物看见什么；感知越多行动越无方向；普通解释已经足够却继续制造警报；异常已可预测仍坚持恐怖发动机；集体尖叫替代不同人物的应对。

**Stop when:** 人物确认一条正常规则失效并采取新的具体行动，或异常已经转成生存、调查、战斗、推理或关系问题。

# exploration

**Primary Reading Question:** 未知空间正在把人物的行动地图改写成什么？

**Projection Guidance:** 仅当行动地图缺口出现时，盯住入口、路线、风险边界与发现后的选择；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物需要确认一个空间能否进入、怎样通行、哪里有价值、哪里危险或下一步应往哪里去。

## Generation Lens

让环境回应人物当前目的，而不是独立展示景色。只保留会改变路线、权限、资源、风险、目标或解释模型的边界、痕迹、居民、设施和地形。

有效发现遵循：

`观察差异 → 暂定判断 → 环境或他人回应 → 新选择`

仅增加奇观、地点名或背景资料而不改变路线、风险、目标、资源或解释模型时压缩。风险推进必须表现为策略变化：能否继续、是否绕行、谁承担失败、是否还能撤离。

高价值地点不等于当前拥有进入权；能力、情报和失败代价不足时，延迟进入本身就是行动。切换 Skill 时交出人物位置、可用路线、已知规则、证据可信度和风险阶段，不重演导览。

## Revision Lens

Preservation First：

- 环境变成景物目录时，删除不改变行动地图的细节。
- 人物位置或入口边界不清时，补一条当前可操作的边界。
- 发现没有产生选择时，补最小的靠近、绕行、标记或撤退决定。
- “很危险”没有策略含义时，改成谁不能继续、哪里不能走或撤离权如何变化。
- 已进入调查、猎取、生存或冲突时，删除继续探索式介绍。
- 不补完整地图、历史或地点百科。

## Failure Patterns

走到哪里介绍到哪里；奇观增加但路线和目标不变；把能看见写成能进入；为保持神秘隐藏眼下能否行动；每个地点同等展开；交接后重复旧空间。

**Stop when:** 未知空间已转成明确的路线、目标、权限、生存、调查或敌人问题；继续走动只增加景物时停止。

# survival_endurance

**Primary Reading Question:** 当原计划被环境击穿且暂时无法结束问题时，谁以什么职责维持生命与行动能力，直到窗口出现？

**Projection Guidance:** 先让一个具体前提失效，再把资源、伤势、时间或出口改写成职责与动作；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物暂时不能直接获胜、撤离、求援或结束危险，必须通过补给、休息、协作、守备、改线或等待维持行动时使用。

## Generation Lens

先写清原计划依赖什么，再让一个可观察事实击穿它。关键变量必须分给具体责任人，并带有触发阈值与下一步动作。

食物、药物、能源和战利品只有在换回体力、守位、移动、士气、撤离距离或敌方迟滞时才前景化。多人场景区分谁守、谁护、谁撤、谁运输、谁维持出口。伤势回答“此人现在还能承担什么”，时间窗由实际承担者校准。

希望必须来自已经积累的信息、资源或环境变化。生存窗口成立后，交接给撤离、反击、求援、战斗、追逃或恢复。

## Revision Lens

Preservation First：

- 环境只是景观时，恢复一个已经成立的计划失效。
- 资源只被报数时，补一项已有功能后果。
- 伤势不改变职责时，改写为守位、携带、撤离或被保护对象。
- 重复疼痛、饥饿和库存报数时压缩。
- 战斗或撤离窗口已成立时，删除继续硬撑的重复段落。
- 不新增灾难、稀缺资源或计划外敌人。

## Failure Patterns

只堆风雪、饥饿和疼痛；原计划从未真正失效；资源发下去后人人自动感恩；所有人承担同一职责；伤员一律留下或撤离；倒计时不改变排序；撤退写成无目标奔跑；窗口成立后仍反复描写痛苦。

**Stop when:** 新路线、撤离、反击、求援、恢复或稳定生存已成为明确窗口，或敌人接触后主问题转为战斗、追逃或调查。

# stealth_infiltration

**Primary Reading Question:** 当前观察者能通过什么界面验证身份、位置或目的；人物的退出权何时消失？

**Projection Guidance:** 先选一个可达的验证界面，再让观察或修补改变暴露边界；凭证只解决被核验的一层，已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物需要隐藏身份、位置、目的、关系或行动痕迹，并且现场存在真实观察者、制度核验或环境感知时使用。

## Generation Lens

先明确目标、观察者知道什么，以及什么算失败。每场只选实际可达的一两个验证界面：外形、习惯、关系、能力签名、时间、路线、声音或凭证。

每次接近同时改变任务进度与暴露边界。守卫、熟人和调查者按各自知识行动，不共享全知。一张凭证只解决它被验证的那一层，不能同时证明人数、路线、目的、时段和常识。

异常顺利本身也是信息，应改变人物对对方意图和下一步风险的判断。取得目标后立即检查退出权：谁已知情、谁能封路、谁会再次核验、哪条路线仍可用。局部怀疑不等于立即失败，但核心目的或位置失守时必须交接。

## Revision Lens

Preservation First：

- 伪装细节不能被现场观察验证时删除。
- 若伪装过于万能，补一个已有事实支持的不同验证维度。
- 被发现后仍重复潜行时，改为写知情者、出口和下一场景。
- 只写氛围时，保留一个能改变判断的声音、视线或人流变化。
- 不把怀疑直接升级为确认，不把取得目标写成风险清零。

## Failure Patterns

伪装完美却没有验证依据；一张凭证解决所有盘查；守卫静止不动；怀疑直接等于确认；取得目标后风险清零；异常顺利只当奖励；被发现后机械全员开战；静态替身被当作完整掩护。

**Stop when:** 目标已取得且验证链不再追及，或核心身份、位置、目的已失守；主问题转为追逃、战斗、谈判、讯问或调查时停止。

# chase_escape

**Primary Reading Question:** 当前功能距离、追踪置信度与出口状态，下一次怎样改变？

**Projection Guidance:** 只展开会改变可达性、可见性、追踪置信度、资源续航或出口权限的动作；已清楚则 NONE

**Revision Watch:** NONE

## Use When

双方仍在通过移动、追踪、改线、遮蔽、载具或出口争夺改变相对态势时使用。

## Generation Lens

距离必须写成功能距离：近距、攻击距、观察距、失联但可追踪距分别允许不同动作。只写更近或更远而不改变行动能力，不构成有效 Beat。

追踪是会变化的信息链。直视、最后位置、真实痕迹、假痕、残余信号和搜索置信度分开处理；每次失去或恢复信息，都要改变搜索范围、延迟或拦截可能性。

安全窗必须有来源、标尺和失效机制。遮蔽、入口、第三方牵制、剩余位移或资源地都不能自动等于安全。资源、伤势和载具只有在改变追击、改线、掩护、携带或撤离时才前景化。

终点不是跑了很久，而是移动已不能解决当前问题，转入战斗、潜入、生存或调查。

## Revision Lens

Preservation First。保留已经成立的距离、路线和资源事实。动作没有造成状态变化时压缩；资源只是报数时恢复一个已有行动后果；已转为战斗、潜入或生存时不补回重复奔跑。

## Failure Patterns

直线距离替代功能距离；失去视野就自动脱逃；发现痕迹就自动追上；安全窗无来源或失效点；弹药、伤势和载具不改变动作；第三方区域自动成为安全区；交接后状态被重置。

**Stop when:** 逃脱、截获、封路、出口隔绝、追踪链稳定断裂，或移动已不能改变结果而战斗、潜入、生存或调查接管。

# combat

**Primary Reading Question:** 当前真正决定胜负的条件是什么；双方下一次行动会怎样让它失效、转手或重新成立？

**Projection Guidance:** 仅当胜负尺、对手回应或资源后果不清时，盯住目标、位置、行动许可与停止点；已清楚则 NONE

**Revision Watch:** NONE

## Use When

双方或多方围绕可观察的目标、位置、保护对象、行动许可、资源窗口或退出条件发生即时冲突。若已经转成追逃、潜入、生存维持、规则推理或公开估价，交给对应 Skill。

## Generation Lens

先锁定一个读者可见的胜负尺。命中不一定等于胜利：若对手仍能逃、挡、复原、转移代价、召援或继续控制目标，正文要让读者知道还缺哪一层。

先让阈值或失败结果出现，再补本拍必须知道的局部规则。每个值得展开的动作只承担一个主要变化：暴露、限制、破防、牵制、终结或收束。下一拍必须吃到前一拍留下的身体、位置、资源、视野、规则或行动权限变化。

资源与伤势只有转成实际行动才值得前景化：它们应改变承伤次数、攻击窗口、移动、持武、职责、接班、撤离或目标控制。多能力、多装备和多人配合按功能链呈现，不按名称清点。

对手按自己真实知道的信息改变目标、位置、节奏或反制；没有观察、理解或执行条件时，不为了“聪明”强行适应。

按当前姿态调整注意力：

- 势均力敌：双方保留可信反制，直到准备、体力、位置、节奏或关键资源真的断一项。
- 弱打强：先让读者看见弱方还能争的窄窗口；窗口关闭时允许撤退或换目标，不把弱者硬写成五五开。
- 碾压兑现：用代表性交换逐层剥掉对手的承伤、反击、逃跑或复原选项；差距已可见就尽快结束，社会重新估价交给 `showcase_evaluation`。
- 适应反制：只有旧打法已暴露且对手具备条件时，让对手改成功条件；主角的新动作必须利用刚变化的行动空间。
- 保护或守点：把胜负尺改为对象完整度、覆盖位置、敌方可达路线与时间窗；只展开会改变保护状态、接班或撤离窗口的动作。
- 团队或大战：只跟踪会改变局部目标的职责与支援链；远景只在改变本地援助、撤离、视野或时间时进入。
- 规则或远程：只给当前动作所需的条件、视线、暴露、射界、冷却或媒介，不展开完整能力说明。

## Revision Lens

Preservation First。只在第一版存在明确失败时局部修：

- 读者不知道胜负尺时，补一个已授权的可观察条件，不补新机制。
- 招式或装备很多但删掉不改变下一拍时，压缩同功能交换，只保留状态改变链。
- 资源、伤势、距离或空间只是报数、疼痛或景观时，恢复一个已有的职责、位置、路线或选择变化。
- 对手连续吃招或震惊却不反制时，先确认其是否获得信息和执行条件；有则恢复最小真实反应，没有则不补“聪明反制”。
- 正文先讲完整机制再打时，改成可见阈值或失效、最短必要规则、下一行动。
- 胜负已经清楚仍继续交换、吹捧或二次证明时，删到结果第一次落在身体、目标、行动空间或现实后果处。
- 不新增第二阶段、强制逆转、伤势、旁观者、底牌或计划外胜负。

## Failure Patterns

逐招流水账；技能目录替代因果；弱打强无可信窗口；碾压战硬拖；强敌无信息就神奇看穿；大场面只增加破坏景观；伤势不改变动作；每拍解释谁占优；结果成立后重复证明。

**Stop when:** 胜负、撤退、目标得失、关键行动许可消失、无解边界成立，或新的高优先级目标接管。

# hunt_acquisition

**Primary Reading Question:** 这个目标为什么是人物现在必须争取的资源？候选在哪里，哪些候选真正适配，人物如何把“知道它存在”推进到“获得一种可控制的占有或使用资格”？

**Projection Guidance:** 仅当即时欲望、候选价值或控制权不清时，盯住缺口、筛选理由与取得证明；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物正在定位、验证、筛选、追逐、交换、截取、夺取或取得某个具体资源、资格、通道、信息资产、产地控制权或可兑现的使用权，并且这项取得会改变后续行动。

## Generation Lens

先给当前缺口和价值尺。让具体欲望落到一个现在无法绕开的瓶颈：生存、突破、进入、救治、撤离、继续行动或改变资源生产方式。稀有、昂贵、传说和品阶只能补充价值，不能代替为什么非它不可。

把搜索、选择、取得分成三种状态：

- 搜索改变它在哪里、是否真实、哪条路线能接近的信息；
- 选择在多个候选、路线、持有者或处置方式之间排除不适配、不可守或机会成本过高者；
- 取得使物品、资格、信息、租约、产地或使用权真正进入人物可调用的控制范围。

每次展开都应让其中一个状态变化。无新信息的移动、逐店询问和重复追踪压缩。

候选至少接受一次有后果的筛选，理由可涉及适配度、辨识可信度、取得成本、暴露、携带能力、保有能力或退出路径。人物可以选择低估值但可控制的候选，也可以放弃看似更大的目标；放弃必须留下排除结论、路线变化或交换条件。

阻力必须响应取得动作：位置转移、价格重写、护卫损耗、资格只开放尝试、入口即将关闭、目标反抗或撤离时钟出现。竞争者不必总是正面敌人，也可以验证目标、制造交接窗口或让独占机会消失。

“能拿到”与“能保有”分开。取得可以是暂时租用、信息交换、控制产地、隔离活资源或安全撤离窗口。若资源会逃逸、反噬、消耗、依赖环境或引来争夺，说明当前已控制的部分和仍未解决的保有条件。

取得后只做最低限度的近场兑现，不在同一场把完整升级、市场估值、社会展示和下一轮目标全部结算。

## Revision Lens

Preservation First：

- 有线索却没有当前欲望时，把候选绑定到一个已存在的即时瓶颈。
- 搜索、筛选、取得混成一步时，恢复一次可观察的选择或控制权转换。
- 主角一眼选中时，只有在确有多个候选时才补一个被排除者及其不适配理由。
- 资源到手却没有控制证明时，补交接、资格确认、保有条件或撤离窗口中的一个。
- 价值验证后仍继续搜刮时，在已改变下一行动处停止并交接。
- 不把竞争者固定写成正面战斗，没有既有第三方行动时不强加竞争者。

## Failure Patterns

先报稀有度和品阶，读者仍不知道为什么必须要它；看见候选直接等于得手；逐店逐路排列；主角只凭作者判断选中；取得只等于塞进储物空间；价值验证后继续横扫；固定截胡和强敌围攻替代具体条件；资源没有改变路线、关系或下一次行动。

**Stop when:** 候选已确认并作出投入或放弃决定，资源、资格、信息资产、产地或使用权进入可调用控制范围，并完成最低限度的适配或保有确认；后续转为配置、制作、展示、关系、追逃或战斗时立即交接。

# training_learning

**Primary Reading Question:** 人物怎样从做不出、做不稳或做不到压力下调用，变成当前任务所需的可重复能力？

**Projection Guidance:** 仅当目标、偏差或可重复性缺口不清时，盯住可观察偏差、修法结果与可用性停点；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物正在改变动作质量、稳定性、消耗、时机、适用范围或压力下的可调用性。

## Generation Lens

先让训练目标可观察，再保留会改变练法的偏差。反馈可以来自身体、对手、空间、数据或结果；它必须让人物调整方法，并使下一次执行可比较。

重复只有在错误、修法或读者判断仍变化时才展开，其余压缩。若错误—修法—结果关系不再变化，直接跳过稳定练习。

导师只交付当前需要的前提、观察锚点和边界，让人物自己承担执行与判断。导师可以纠正目标、拒绝错误模仿或指出求助阈值，但不能变成完整教程。

首次成功可以只是局部功能。稳定、压力调用和迁移按当前事件需要选择其一，不组成固定阶梯。做得出不等于压力下可调用，练熟不自动等于突破，突破也不自动等于公共证明。

训练升级前，只在现场已有条件时检查动作能否隔次保持、错误是否会被新形式放大，以及是否有可观察的止损边界。不把这些检查变成固定门槛。

## Revision Lens

Preservation First：

- “悟性不足”或“感觉不对”过于空泛时，改成一个具体偏差。
- 连续尝试不改变错误模型时，合并或删除。
- 一次成功被写成稳定能力时，保留已有限制、代价或下一验证目标。
- 导师变成教程时，压缩到足以知道不能照抄什么、该观察什么、何时求助。
- 场景声称压力调用却没有测试时，只有在事件已有空间时补一个最小压力条件。
- 双线训练中明确人物、分身、位置、合并时点，不新增未授权的位移或复制机制。

不要求每场证明间隔保持、迁移给他人或完整训练链。

## Failure Patterns

练习次数代替反馈；所有尝试按同一流程推进；一次偶然成功被当成能力完成；导师讲完理论而人物没有执行判断；训练偷偷完成突破或展示；只写数值增长；双线训练混淆身体拓扑。

**Stop when:** 当前任务所需的稳定度或可调用性已经成立，或瓶颈明确需要另一种方法、资源、理解或阶段。

# comprehension_insight

**Primary Reading Question:** 人物怎样把旧模型解释不了的现象重组为一次可用的理解？

**Projection Guidance:** 仅当旧模型到新模型的连接不清时，盯住反例、暂定解释与一次反馈；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物已有观察或知识，却无法预测、解释、控制或选择，核心障碍是工作模型不成立。

## Generation Lens

先让原有理解具体，再让一个反例、失败或结构差异迫使它松动。人物通过比较、拆分、模拟、回忆或最低限度试验形成暂定模型；这个模型必须改变一次预测、验证、动作或选择，并得到现实反馈。

导师若存在，只提供前提、辨认锚点、边界和回问阈值，然后退出。理解到当前行动需要的层级即可，不把理解扩写成完整法则。

Insight 解决为什么或怎样理解，不自动解决动作稳定、境界跨越或外部估价。事实、支持性推断和仍未知的原因分开。

## Revision Lens

Preservation First：

- “忽然明白”没有可见变化时，补一个已有反例与新模型之间的具体连接。
- 新理解没有改变行动时，接上一次最低限度的预测、试验或选择。
- 思考变成完整理论课时，删除不影响当前决定的解释。
- 推理超出已有观察时，降低结论，保留未知部分。
- 理解、训练和突破混在一起时，将段落收回当前真正完成的层级。
- 不为完整感补造世界机制、导师历史或未建立的过去。

## Failure Patterns

用灵光一闪跳过模型变化；只换抽象词没有新预测；解释越完整行动越少；把想明白写成稳定掌握；把最低反馈写成宇宙真理；事实和推断没有边界。

**Stop when:** 新模型已经改变一次判断、试验或行动，并获得最低限度的现实反馈。

# trial_challenge

**Primary Reading Question:** 这道外部门槛究竟授予或剥夺什么？人物拥有哪一个可见的决策权？哪个铰链会改变判定？多阶段试炼本场只结算哪一级权利？

**Projection Guidance:** 仅当资格、决策权、判定铰链或阶段权利不清时，盯住通过后的第一项行动权；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物必须在明确外部规则、判定线和失败后果下争取进入、资格、资源、位置或权限。

如果外部判定只提供合法身份，过程没有选择、代价或反馈，应压缩为结果。若主要问题是反复练习，转入 `training_learning`；若主要问题是证明能力价值，转入 `showcase_evaluation`。

## Generation Lens

先让读者知道判定物、阈值、失败后的损失和通过后的第一项行动空间。不要只说这场考试很重要。

把资格和真实故事分开。通过一层只授予该层已经承诺的权利，不自动完成救援、复仇、身份承认、资源占有或终局目标。

让人物拥有一个真正可见的决策权：改变顺序、押注强项、选择伙伴、分配资源、承担风险、利用规则或决定退出。若人物没有任何能改变结果的选择，试炼过程应压缩。

重点展开判定铰链，而不是完整考试流程。隐藏规则必须先由现场异常或失败支付验证成本，再让人物修正理解，不在结果揭晓时临时改写规则。

多阶段试炼每次切场都结算权利：保留什么、失去什么、下一层目标是什么、退出会付出什么。团队试炼重点写规则如何迫使队伍指挥、分工、重组或撤退，不平均展示成员。

## Revision Lens

Preservation First：

- 只说很重要时，写明通过后获得或失去的具体行动空间。
- 人物没有决策时，从已建立的选项中补一个改变结果的选择；没有既有选项则压缩场景。
- 资格通过被写成主线目标完成时，分开当前结算层和未结算目标。
- 隐藏规则像作者补丁时，补现场已有的异常、失败和一次验证成本；无依据则删除。
- 多阶段只换地点不换权利时，补每层的资格、退出代价和下一层目标。
- 重复操作没有新反馈时，合并同类尝试，保留真正改变判定的铰链。
- 通过后只有欢呼时，接上有行动权者改变资格、资源、待遇或策略的动作。
- 团队成员轮流炫技时，收回到一个改变整体结果的协作决策。

## Failure Patterns

把考试流程写成流水账；只写赢了一场而没有权利变化；主角没有选择；末尾突然揭露真规则；每过一层只换地图；资格通行证直接等于终极目标完成；团队试炼变成排队展示；确认通过后继续重复证明。

**Stop when:** 外部判定已经确认，本场应结算的资格或权利已经落地，且下一目标、退出代价或未结算层级清楚。

# breakthrough_advancement

**Primary Reading Question:** 旧能力、身份或生命结构究竟跨过了哪道门槛？当前属于尝试、局部成功、半步、稳定突破还是社会证明？每项资源解决什么，结构瓶颈是什么？跨过后最先能做什么？

**Projection Guidance:** 仅当阶段状态、资源瓶颈、同一判尺或首次新行动不清时，盯住最小差异与停点；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物的旧上限、权限、身体结构、生命层级或能力边界真正失效，并形成新的可用状态。

不因资源增加、感悟出现、称号变化、临时强化、练熟或看见更高方向自动调用。没有结构变化或新状态成立证据时，不称为完整突破。

## Generation Lens

先标出阶段，不把尝试、半步、局部成功、稳定突破和社会证明合并成一句“突破了”。

用同一判尺比较前后状态。若突破前问的是核心能否承载高压，突破后仍应让读者看到核心是否稳定，而不是突然换成气势、等级或围观反应。

拆开资源瓶颈和结构瓶颈：

- 资源可以提供燃料、承载条件、维持时间或关键材料；
- 理解、身体或结构变化才可能解决真正的跨层门槛；
- 每项条件只承担一个明确职责。

失败必须诊断出旧路径为何不够，并改变下一步资源选择、结构方案或行动目标。资源开始消耗、局部成形、看见方向，都不等于稳定突破。

突破后的第一行动优先解决当前已存在的问题：破困、救人、转移、反制、开启新通路或承担此前无法承担的责任。没有合适现场时，不强行安排展示，可延后社会证明。

连续跨越必须分别结算每一道门槛。高阶突破若依赖多种力量，应写出它们如何稳定共存，而不是只写同时暴涨。适应期、消耗或限制只有在已有依据时保留，不把受伤设为固定成长税。

## Revision Lens

Preservation First：

- 只有数值和气势变化时，用同一判尺补出具体状态差异。
- 感悟、资源吸收或半步被写成完成时，降回实际阶段，保留未解门槛。
- 资源被当成结构解法时，明确资源只解决承载、燃料或维持中的哪一项。
- 结构变化没有缺口时，补出已有前置条件中真正缺失、替换或重排的部分；无依据则降低突破结论。
- 突破后没有首次新行动时，在已有局势中补最小可行兑现；没有合适局势则保留延迟证明。
- 私密突破被硬塞围观和排名时，把社会证明延后。
- 同一变化被连续测试时，保留首次有效动作，切出到下一主场景。
- 不为制造重量追加未经支持的永久代价。

## Failure Patterns

能量暴涨替代真实门槛；资源数量直接等于突破完成；想明白直接等于结构改变；局部成功、半步和稳定状态混为一谈；突破前后更换判尺；新状态只存在于旁白和数字；突破后只打木桩；每次突破都受伤或立刻获得社会地位。

**Stop when:** 阶段状态、同一判尺下的前后差异、资源与结构职责、首次新行动或合理的延迟证明已经清楚；若只完成理解、局部成功或资格，则转交对应 Skill 或保留下一门槛。

# showcase_evaluation

**Primary Reading Question:** 谁必须按新的尺度重新估价这项能力、成果或人物，估价后现实改变了什么？

**Projection Guidance:** 仅当新尺度或现实后果不清时，盯住基准、代表性用途与重新估价后的待遇或行动；已清楚则 NONE

**Revision Watch:** NONE

## Use When

展示结果会迫使某个拥有分配、部署、资格、谈判或策略权的人改变原有待遇或行动。

## Generation Lens

先保留旧尺或旧报价，再让成果在一个有意义的实际条件下工作。优先选择一项不可逆的身体、空间、资源、保护或机会结果，而不是连续参数。

观察者按自身利害反应：识别者校准上限，受威胁者改防或改逃，分配者改价、资格或部署，普通人获得直接保护或行动信心。

只保留一个主结果和一个现实后果。公开承诺以执行者承担成本验真；若结果已经成立并改变待遇，立即转入新局面。若仍缺条件、授权或动员，只补最短的执行闭环。

## Revision Lens

Preservation First：

- 只有围观和夸赞而没有现实变化时，接上一个已有行动权人物改变待遇、资源、策略或资格的动作。
- 只有参数没有用途时，把已有结果落到一个可见的身体、空间或机会成本。
- 反转没有旧误判行动时，不硬造反转。
- 多个观察者重复震惊时，合并为不同利害中的一个代表性反应。
- 已经重新估价却继续测试时，停止追加同层级证明。
- 不要求每次展示都产生排名、订单或公众欢呼。

## Failure Patterns

好看的动作被误写成展示；排名成立但无人改变行为；无行动权角色轮流宣布很强；公开宣言没有执行成本；用回放战斗代替现实定价；展示完成后继续炫技。

**Stop when:** 尺度、用途和至少一项现实判断或行动后果已经清楚。

# resource_economy

**Primary Reading Question:** 人物手里的有限资源在当前价值体系中究竟能换来什么？该保留、出售、交换、分配还是投入哪一项，选择会关闭什么机会，又会让谁改变行动？

**Projection Guidance:** 仅当当前缺口、价格参照或配置后果不清时，盯住资源去向与关闭的机会；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物已经控制现金、学分、材料、装备、药物、能源、战利品、信息、时间、配额、资格或人情，并要决定如何留、卖、换、投入、共享、抵押或承诺，使下一行动变得可行或不可行。

若尚未找到或控制具体目标，转 `hunt_acquisition`；若材料正在经历关键转化，转 `crafting_creation`；若成果需要被新的尺度重新定价，转 `showcase_evaluation`。若配置本身是债务、保护、信用或亲密关系的主问题，转 `relationship`；若投入只回答还能否继续交战或撤离，局部转 `combat`。

## Generation Lens

先给欲望，再给资源。让读者知道人物要保住什么、进入什么、解决什么缺口或承担什么风险。价值尺来自一个熟悉的反事实：不用它会失去哪项行动，换掉它会关闭哪项未来选择，或它能把人物推到哪层权限。

先诊断稀缺类型：现金、流动性、配额、渠道、时间、安全边界、适配能力、机构权限或可出售资产不足。高收入仍可能买不到受限材料，资产很多仍可能不能安全出售。

价格只在改变接受、压价、保留、出售、路线或风险时进入正文。给一个熟悉参照物即可，不用完整预算、汇率表或库存清单替代选择。

机会成本必须是关闭的门。让人物在至少两个真实用途之间决定：保留未来权限或换取当前现金，购买武器或失去训练额度，接受高危任务换取材料，分配给同伴换取继续合作。被放弃的选项应有可感后果，但不机械附加损失。

配置必须成为交换。卖方、机构、同伴、家人或对手应回应价格、分配和承诺，交易完成后至少改变一项行动权、时间、身份、关系或路线。

奖励到账后优先兑现刚暴露的缺口，其余物资压缩。战利品分配只在它解决共同风险时展开，并让接受者以行动、态度、保密或下一次承诺回应。

高压场景中，资源选择只回答投入这一项能打开哪一拍窗口。投入后主问题转为交战、追逃或撤离时立即交接。

## Revision Lens

Preservation First：

- 只有价格没有欲望时，把金额落到人物正在失去或争取的一项行动。
- 只有“缺钱”没有机制时，指出是现金、配额、渠道、权限、时间或安全哪一种缺口，并删掉无关数字。
- 有取舍却没有机会成本时，明确被保留或放弃的一项真实选项及其后果。
- 资源到账后继续列清单时，让一项资源立即解决刚暴露的缺口，其余压缩。
- 分配没有关系后果时，只有在已有持续协作时接上贡献、共同成本或信用。
- 高压场景停下来做完整财务说明时，把选择缩成一次投入与一拍行动窗口。
- 经营流程吞掉成长主线时，保留许可、拒绝、转交或有限承诺，删除日常运营。

## Failure Patterns

数字很多却没有改变计划、态度或关系；高价自动等于值得；奖励只是获得某物；资产可无限出售或兑换；机会成本变成机械惩罚；分赃变成物品清单；战斗中插入账本；经营流程取代训练、冒险、关系和主线。

**Stop when:** 资源去向已确定，至少一项真实机会成本已关闭或被承担，配置已改变人物、同伴、机构或下一行动可做之事。

# crafting_creation

**Primary Reading Question:** 人物要把材料、工具和方法转成什么可用成果？哪一个中间状态一旦成立就能把风险传给下一阶段？当材料、时间、容器或身体进入不可逆窗口时，人物选择继续、保全还是报废，结果如何被证明并交给下一场？

**Projection Guidance:** 仅当目标性能、阶段门、不可逆选择或成果证明不清时，盯住中间态与下一交接；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物正在把材料、工具、能量、信息或既有部件加工、炼制、组装、调制、修复或改造为新的实物成果或可部署装置，并且当前张力来自转化过程中的选择与反馈。

若主要产出是理解原理而非实物状态变化，转 `comprehension_insight`；若主要问题是材料去哪找、怎么换或怎么分配，转 `hunt_acquisition` / `resource_economy`；若成品已形成且重点变成尺度、用途或待遇，转 `showcase_evaluation`。外部压力成为直接对抗时转 `combat`；交付带来保护、债务或合作承诺时转 `relationship`。

## Generation Lens

先定成品用途和证明尺。读者要知道成品要承受什么、解决哪个问题、给谁使用、必须达到哪项性能，以及失败会关闭什么行动。不要先列材料名、品阶或完整配方。

只选会改变结果的控制点：温度、顺序、比例、连接、空间、工具、环境、输入纯度或操作者状态，只有在改变成败、性能、成本、诊断或隐蔽时才展开。稳定守火、熟练装配和重复批次压缩。

设置阶段门，而不是进度条。真正的中间产物或中间状态必须有可观察信号，并改变下一阶段的可选项。中间态承担质量传递：上一阶段的稳定、纯度、兼容或残余风险直接决定下一阶段能否继续、需要何种调整或只能保全。

失败先分类，再动作。问题可来自材料、工具、工序控制、目标性能或解释模型；下一拍必须改变控制或目标，或选择修正防护、换条件、重定义成品、保住半成品、暂停等待或承认方案不可行。

当有限材料、倒计时、容器损坏、能量耗尽、身体临界或无法重做的输入成立时，人物在继续完成、保全已成立状态、立即报废止损之间作出可见选择。没有真实不可逆条件时，不强行制造三选一。

外部压力威胁已形成的中间产物时，先保护状态，再决定交付、失去或切入战斗。成果被安全交付、收容、丢失或正式裁决后停止制作叙事。

成果证明只选一条合适路线：首次使用、受用者反应、身体或空间结果、独立比较、市场估值、公开复验、稳定收容或新的部署权。成品出现不等于价值成立，也不需要把价格、掌声、疗效、排名和传说全部堆上来。

区分制作完成、首次使用、稳定保有、他人承认和社会待遇。长时制作只保留首次异常、关键等待、有效反馈和出关后的可做之事。

## Revision Lens

Preservation First：

- 有工序没有目标时，先写成品要解决的具体问题和一项性能尺。
- 有反馈没有阶段门时，标出一个中间态如何改变下一阶段，并删除同质步骤。
- 每一步都同等展开时，只保留改变成败、性能、成本或诊断的控制点。
- 失败只带来损失时，分类错误来源，并让下一次控制或目标真正不同。
- 事故后主角总能救回时，在有限输入成立时明确继续、保全或报废，保留真实不可逆后果。
- 外部危机中仍机械播报配方时，先保护已成立状态，再决定交付、失去或切战斗。
- 成品出现就宣布价值时，补一条与当前冲突匹配的证明路径；没有需要外部证明时不要硬加观众。
- 长时制作逐日复播时，压缩稳定运行，只恢复首次异常、关键等待和改变选择的读数。
- 制作完成后继续多轮同层级试用时，交接到展示、资源、关系或战斗。

## Failure Patterns

材料、温度、阵纹和步骤越写越多却不知道哪项改变结果；中间产物只是进度条；每次失败都被外援或巧合救回；失败类型未区分；成熟配方被强行炸炉；外部危机中仍播报配方；成品价值同时走价格、掌声、排名、疗效和传说；研究结论、成品和首次使用混成一句成功。

**Stop when:** 成品或关键中间态已形成并完成当前用途所需的最低检验，或不可逆故障已使继续、保全或报废之一成为事实，或瓶颈明确要求另寻材料、工具、理解或路线。

# recovery_restoration

**Primary Reading Question:** 人物当前失去的是哪一层功能？什么阻断使普通恢复无效？本场只需恢复到什么行动阈值？部分恢复会怎样改变下一步？

**Projection Guidance:** 仅当恢复层级、阻断条件、行动阈值或残余限制不清时，盯住目标层与首次再用；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物的核心问题是从受损、失去或中断状态重新获得可用功能。

不因出现伤势、药物或休养自动调用。若主要问题已经变成战斗、资源争夺、模型误判、境界跨越或他人定价，应转交对应 Primary。

## Generation Lens

先把“不能做什么”写成可观察事实，再选择本场真正要恢复的一层。不要默认身体、能量、意识、能力和社会位置同步恢复。

当普通疗法无法解释进展时，先处理已经建立的核心阻断，不用不断换药、加痛感或延长时间替代诊断。每个处理动作都应改变恢复判断：确认有效、暴露失败、解除阻断、恢复一项功能，或改变可承担的行动。

长疗程只保留诊断、关键失败、首次有效反馈和首次再用。稳定重复的服药、运功、等待与移动压缩。

部分恢复必须明确现在能完成什么、还不能完成什么，以及为什么当前程度已经足以启动下一项行动。首次再用优先选择已有局势中的必要动作：复工、履约、保护、逃生、谈判或出手。

恢复若带来新境界，先结算恢复，再转入 `breakthrough_advancement`。身体、意识、行动权和社会位置可以分层恢复，不自动同步。

## Revision Lens

Preservation First：

- “恢复了”过于抽象时，补出恢复前做不到、恢复后重新做到的动作。
- 部分恢复被写成全盛时，降回实际阈值，保留会影响下一步的限制。
- 普通治疗反复推进时，找出已建立的真正阻断；没有依据则删除新增阻断。
- 时间跨度很长但状态没有节点时，压缩过程，只保留方法、反馈、阈值或行动变化。
- 残余限制只作装饰时，让它约束下一次选择；做不到时删除该限制。
- 身体已愈但意识或行动权未回归时，分开处理不同恢复层。
- 恢复资源已被看见并争夺时，停止静态疗伤，转入资源或战斗场景。
- 不为制造代价临时添加永久伤残或新规则。

## Failure Patterns

默认恢复如初；用疼痛代替恢复判断；醒来、止血、能量回升和回到峰值被写成同一状态；数日后痊愈却没有行动证明；一次能动被写成稳定作战能力；恢复后继续重复证明同一功能；社会位置由旁白宣布恢复。

**Stop when:** 本场目标层已通过实际行动确认，人物知道当前能做什么、不能做什么，且残余限制已兑现或不再影响下一步。

# Shared References Verdict

以下保持为 shared reference，不进入 24 个 Primary Router：

- `character_voice_pressure`：用于判断压力下人物优先保护什么、注意什么、愿意支付什么。
- `world_entry_lived_texture`：用于把入口边界、生活锚点和他人对待投影到当前 Primary。
- `desire_temptation`：用于判断欲望是否改变注意顺序、风险阈值或退出权。

它们都不构成独立 Primary，也不形成每章配额。

# Provisional / Not Promoted

- `combat_protect_hold`：保留为候选或 pilot，不是 production Primary；保护/守点作为 `combat` 的 conditional posture。
- combat 的团队协同、战场局部、规则条件、远程暴露：保留为 `combat` 内部 modifier，不扩 taxonomy。
- `training_learning` 的固定 proof ladder、间隔保持、迁移给他人的高阶 ruler：暂不设为强制生产要求。
- `sacrifice_convergence` 的恢复层级、遗留能力边界、镜像危机和新代价校准：仍为 provisional。
- `handoff`：作为共享交接契约使用，但不新增为 Primary；只传递已发生状态、未解决压力和下一步可执行接口。
- 不把任何 source-specific 原著、书名、locator、人物名或证据标签带入 Runtime。
