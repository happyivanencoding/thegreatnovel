# Existing Skills To Deepen

- `social_bargain_decision`

  增强“拒答类型”的判断：拒绝进入正式程序、拒绝公开承诺、用较弱答案试探、因筹码未到位而延后成交。拒答后应留下可观察替代物：新问题、有限事实、担保、任务或行动。

  增强“谈判资格”与“说话成本”：动作、距离、旁观者、物件只有在改变谁能发言、谁必须表态、谁可旁听或谁承担风险时才进入对白结构。

  增强“暂不成交”：只有双方各自带走任务、时限、最低承诺或再进入入口时，才算有效结束。

- `relationship`

  增强“双层协议”：公共身份、制度、礼数和权力仍然成立；私人称呼、沉默、命令或行动只改变具体的人际边界，不自动抹平制度差。

  增强“结果分层”：被理解、态度软化、暂时停手、关系确认、路线改变、正式合作不是同一结果。关系兑现不能凭空改写责任、身份或既定路线。

  增强“沉默结算”：沉默只有在离席、收物、行礼、改道、继续留下等动作中获得可读含义时，才是关系行为。

- `comedy_banter`

  增强“功能与靶子”：玩笑必须服务于保密、试探、降格、拖延、缓冲或占便宜，并命中具体面子、旧账、责任、站位或当前选择。

  增强“媒介与可见性”：截图、照片、账号、文件、自动回复、禁言和私聊不是装饰，而是改变误解、归因、权限或责任链的道具。

  增强“紧急度切换”：当专业事实、身体风险、责任或不可逆结果出现，笑点应转为调查、救援、执行或后果，不靠作者旁白宣布严肃。

不建议新增 Hard Gate、固定轮数或新 Primary。上述内容应作为现有三个 skill 的判断深化。

# Voice Taxonomy Decision

`character_voice_pressure` 应成为 shared lens，不应成为 Primary，也不宜作为普通 Modifier。

理由：

- Primary 回答的是“这场戏读者持续追问什么”；声音压力回答的是“人物在这个问题下为何这样回应”。它不能替代谈判、关系或喜剧的主阅读问题。
- 它横跨三种现有 Primary，也能作用于审问、战斗、救援、调查等场景，范围比 Modifier 更基础。
- 四本书均支持其核心轴：首保对象、注意对象、支付边界、公共/私人协议、接话任务。
- 但它不应每场自动启用。只有当压力迫使人物在保密、尊严、行动空间、职责、关系债务或信息责任之间取舍时才激活。

如果把以下规则提升为 Primary，容易产生策略化或会议化：

- “每人先声明自己的首保对象”会把人物变成显式决策算法。
- “每人必须承担一个群体功能位置”会把自然对话写成会议流程。
- “专业信息必须逐项确认”会让角色轮流补充正确知识。
- “每次拒答必须解释替代策略”会消灭真实的停顿、误解和情绪反应。
- “每个声音都必须展示差异”会让人物为展示个性而说话。

因此，`character_voice_pressure` 只提供内部生成和修订视角，不进入 Primary 选择目录。

# Generation Lens

先保留当前场景的 Primary Reading Question，再观察压力如何穿过人物：

- 为核心人物识别一个当前最不能丢失的东西，以及一个实际注意对象；不要把它们写成台词中的心理标签。
- 让人物先做出符合该优先级的具体选择，再由对方的反应改变下一拍。声音从取舍中出现，而不是从口癖中出现。
- 重要对白必须留下结算痕迹：条件变化、信息边界移动、关系距离改变、发言资格变化、路线改变或行动启动。
- 多人场景只保留真正改变尺度的人；其他人的沉默、短回声或动作只有在改变温度、责任或可见性时才保留。
- 专业信息先落在一个未决问题上，再让答案推动命令、配置、选人、路线或风险控制。
- 玩笑先确认靶子和功能；一旦结果、责任、危险或权限不可逆地出现，立刻退出玩笑模式。
- 当读者主问题已经改写，或下一行动已经具备条件时停止对白。

# Revision Lens

必须遵循 Preservation First：

- 先保留已成立的事实、直接结果、角色已作出的选择、关系边界、媒介证据和原有情绪，不用“更聪明的对白”重写它们。
- 先判断缺陷属于哪一种：没有状态变化、角色可互换、群体重复、专业信息不可执行、笑点越过停止点。
- 只做最小修复：补一个真实反应、一个可观察动作、一个信息载体、一个被改变的选择，或删去重复回合。
- 不把沉默强行翻译成明确答案，不把私人亲近升级成制度豁免，不把情绪压平为谈判术语。
- 不为每个角色补一条“个性台词”，不为每个群体场景补齐功能岗位。
- 修复到读者能看见状态变化即可停止，不追加解释性总结或新危机。

# Failure Patterns

- 所有人都使用同一种成熟谈判腔，只是更换名字。
- 拒答只剩冷笑、沉默、转身，没有替代问题、有限事实或行动。
- 把每个眼神、停顿和物件都解释成潜台词。
- 群聊变成全员报观点，专业场景变成会议纪要。
- 专业角色只负责讲正确知识，不承担选择或风险。
- 误解只制造笑话，却不改变路线、身份、处罚、关系或身体状态。
- 笑点机械升级三次，已经出现真实后果仍继续抖机灵。
- 一次理解、告白或态度软化，被误写成合作、和解或路线改变。
- “暂不成交”没有双方任务和再进入条件，实际只是拖延结论。
- 为了证明声音差异，让聪明人物突然失智，或让严肃人物持续表演机灵。

# Evidence Gaps

- 当前证据覆盖《死人经》《全职高手》《将夜》《修真聊天群》四条 lane，但窗口集中于高压谈判、竞争、群体聊天和关系冲突；低压日常双人戏的支持较少。
- `character_voice_pressure` 是四条证据轴的综合判断，不是原始文本中现成命名的独立机制；目前足以支持 shared lens，不足以支持独立 Primary。
- 群体拓扑在三人以上场景中证据充分，但不应据此强行改造所有双人对白。
- 专业信息证据主要来自竞技、修行、制度和群体调度；不能泛化为所有职业场景都必须显式提出概率或配置。
- 现有材料支持停止规则和修订判断，但没有证明固定轮数、角色槽位或量化阈值能够提高正文质量。
- 未有材料支持迁移四本书的口癖、句法、签名表达或源文风；可迁移的只有场景发动机与判断方式。
