## 1. `chase_escape`

### Retained core

保留现有核心，不重写近义内容：

- 追逃以距离、路线、视野、速度、体力、载具和出口变化为基本状态。
- 地形只在改变可达性或相对态势时展开。
- 身体负担通过舍弃、改线、冒险和停留选择体现。
- 追逃结束后及时交接给 `combat`、`stealth_infiltration` 或 `survival_endurance`。

### New evidence-backed judgments

1. **距离必须写成功能距离。**
   近距、攻击距、观察距、失联但可追踪距，分别允许不同动作；只写“更近/更远”而不改变行动能力，不构成有效 beat。
   证据：仙逆 XIANNI-CHASE-04、08、09；永夜 YY-EM-05、YY-M-01、YY-M-02、YY-M-03。

2. **追踪是会变化的信息链。**
   直视、最后位置、真实痕迹、假痕、残余信号和搜索置信度必须分开；每次失去或恢复信息，都要改变搜索范围、延迟或拦截可能性。
   证据：仙逆 XIANNI-CHASE-09、12；永夜 YY-EM-03、YY-EM-04、YY-L-03。

3. **安全窗是“来源＋标尺＋失效机制”。**
   遮蔽、入口、第三方牵制、剩余位移次数或资源地都不能自动等于安全；必须让读者知道它还能撑多久、什么会使它失效。
   证据：仙逆 XIANNI-CHASE-02、04、07、11、12；永夜 YY-EM-06、YY-EM-08、YY-L-01、YY-L-02。

4. **资源、伤势和载具只有改写动作才进入追逃主景。**
   弹药、故障、伤势、负重和队伍速度必须改变追击、改线、掩护、撤离或敌方判断；否则压缩为结果。
   证据：仙逆 XIANNI-CHASE-01、03、07；永夜 YY-EM-02、YY-EM-03、YY-EM-04、YY-M-04。

### Source-blind v2 document

**Primary Reading Question**

当前功能距离、追踪置信度与出口状态，下一次怎样改变？

**Projection Guidance**

只展开会改变可达性、可见性、追踪置信度、资源续航或出口权限的动作；安全窗必须有来源、标尺和失效点。相对态势不再变化时压缩移动并交接。

**Revision Watch**

A：若“更近/更远”未改写任何行动，压缩重复跑动。
B：若安全窗只有“暂时安全”，补已有事实中的来源与失效触发，不新增机制。

**Use When**

双方仍在通过移动、追踪、改线、遮蔽、载具或出口争夺改变相对态势时使用。

**Generation Lens**

先给出当前功能距离与双方各自能做什么。每次移动至少更新一项：可达性、视野、追踪信息、资源余量、出口或目标价值。路线只因它改变下一步选择才展开。安全窗必须显示它为何成立以及如何崩溃。资源和伤势要落成速度、携带、开火、掩护或撤离能力。终点不是“跑了很久”，而是移动已不能解决当前问题。

**Revision Lens**

保留已经成立的距离、路线和资源事实。若动作没有造成状态变化，局部压缩；若资源只是报数，恢复一个已有的行动后果；若已转为战斗、潜入或生存，不补回重复奔跑。

**Failure Patterns**

直线距离替代功能距离；失去视野就自动脱逃；发现痕迹就自动追上；安全窗无来源或失效点；弹药、伤势和载具不改变动作；第三方区域自动成为安全区；交接后状态被重置。

**Stop when**

逃脱、截获、封路、出口隔绝、追踪链稳定断裂，或移动已不能改变结果而 `combat`、`stealth_infiltration`、`survival_endurance` 或调查问题接管。

**是否需要新 Primary/variant：** No。

## 2. `stealth_infiltration`

### Retained core

保留现有核心，不重写近义内容：

- 潜入围绕任务进度与暴露风险同步变化。
- 目标、路线、掩护、声音、痕迹和守卫反应必须产生真实反馈。
- 暴露不是二元状态，可以是怀疑、记住脸、发现异常或提高戒备。
- 真实身份暴露、潜入问题结束后，交接给追逃、谈判、战斗或调查。

### New evidence-backed judgments

1. **暴露必须挂在具体验证界面上。**
   观察者可能验证外形、习惯、关系反应、能力签名、时间结构、路线或声音；每场只启用实际可达的一两种验证，不使用笼统“对方很敏锐”。
   证据：诡秘 E04、E05、E06、E07、E10、E11；死人经 SC-03、SC-08、SC-11、SC-12。

2. **一张凭证只解决它被验证的那一层。**
   腰牌、制服、身份和暗号可以通过准入，但不能同时证明人数、路线、目的、时段和人物常识；后续检查应改变验证维度。
   证据：诡秘 E05、E06、E09；死人经 SC-03、SC-07、SC-08。

3. **退出权是独立状态。**
   取得目标不等于安全；需要持续判断谁已知情、谁能封路、谁会再次核验、哪条路线仍可用。
   证据：诡秘 E01、E09、E10、E11、E14；死人经 SC-04、SC-05、SC-06、SC-09、SC-10。

4. **异常顺利本身是信息，守卫注意力会重排。**
   过于精准的空档、过分完美的不在场证明或警报后的追击/留守分工，都应改变人物对对方意图和下一步风险的判断。
   证据：诡秘 E10、E11、E14；死人经 SC-02、SC-05、SC-08、SC-10、SC-12。

### Source-blind v2 document

**Primary Reading Question**

当前观察者能通过什么界面验证身份、位置或目的；人物的退出权何时消失？

**Projection Guidance**

先选一个真实可达的验证界面，再让观察、修补或绕开改变暴露边界；凭证只解决它被核验的那一层，异常顺利也必须改变判断。

**Revision Watch**

A：删去不能被现场观察验证的伪装细节。
B：保留一个能改变下一拍的核验细节并压缩其余内容。两者都不新增事实。

**Use When**

人物需要隐藏身份、位置、目的、关系或行动痕迹，并且现场存在真实观察者、制度核验或环境感知时使用。

**Generation Lens**

先明确目标、观察者知道什么，以及什么算失败。选择一个验证界面：外形、习惯、关系、能力签名、时间、路线、声音或凭证。让每次接近同时改变任务进度与暴露边界。守卫、熟人和调查者按各自知识行动，不共享全知。凭证只覆盖对应验证层。取得信息后立刻检查退出权：出口、知情者、下一次核验和追击调度是否仍可承受。局部怀疑不等于立即失败，但核心目的或位置失守时必须交接。

**Revision Lens**

保留已成立的身份和观察事实。若伪装写得过于万能，补一个已有事实支持的不同验证维度；若被发现后仍重复潜行，改为写知情者集合、出口和下一场景；若只写氛围，保留一个能改变判断的声音、视线或人流变化。

**Failure Patterns**

“伪装完美”却没有验证依据；一张凭证解决所有盘查；守卫静止不动；怀疑被直接写成确认；取得目标后风险清零；异常顺利只当奖励；被发现后机械全员开战；静态替身无法应答却被当作完整掩护。

**Stop when**

目标已取得且当前验证链不再追及，或核心身份、位置、目的已失守；主问题转为追逃、战斗、谈判、讯问或调查时停止潜入。

**是否需要新 Primary/variant：** No。

## 3. `survival_endurance`

### Retained core

保留现有核心，不重写近义内容：

- 生存围绕最低维持条件及最先崩溃的变量。
- 食物、能源、体温、伤势、暴露、睡眠、心理和倒计时必须进入优先级选择。
- 重复痛苦压缩为阶段或代表性瞬间。
- 生存窗口出现后，交接给撤离、反击、求援、战斗或长期恢复。

### New evidence-backed judgments

1. **生存戏应先击穿一个原行动前提。**
   救援不会及时抵达、路线不能继续、山中不能觅食、敌援即将到达等具体事实，必须迫使人物改宿营、改线、配给、撤离或转战。
   证据：第一序列 SE-DY-04、SE-DY-09、SE-DY-11；全球高武 SQ-03、SQ-09、SQ-11。

2. **资源分配必须变成行动再配置。**
   食物、药物、能源和战利品的意义不在库存，而在它们换回了谁的体力、守位、移动、士气、撤离距离或敌方迟滞。
   证据：第一序列 SE-DY-02、SE-DY-06、SE-DY-07、SE-DY-11；全球高武 SQ-02、SQ-05、SQ-06、SQ-10。

3. **群体生存需要明确拓扑。**
   外圈、内圈、伤员、后卫、接应者、运输者和管理者承担不同职责；“留下”与“撤离”由当前功能决定，而非勇气判断。
   证据：第一序列 SE-DY-05、SE-DY-07、SE-DY-08、SE-DY-10；全球高武 SQ-06、SQ-11、SQ-13、SQ-14、SQ-15。

4. **时间窗必须由承担者校准。**
   “拖一会儿”要落成某人能撑几秒、几分钟或几轮，并立即改变取物、击杀、恢复、接应和撤离顺序。
   证据：第一序列 SE-DY-08、SE-DY-10；全球高武 SQ-03、SQ-09、SQ-11。

### Source-blind v2 document

**Primary Reading Question**

当原计划被环境击穿且暂时无法结束问题时，谁以什么职责维持生命与行动能力，直到窗口出现？

**Projection Guidance**

先让一个具体前提失效，再把食物、伤势、时间、出口或敌情改写成职责与动作；资源必须换回可观察的移动、守位、恢复、士气或撤离余量。

**Revision Watch**

A：压缩重复疼痛、饥饿和库存报数。
B：保留一个功能损失及其对应回应。两者都不新增灾难或稀缺资源。

**Use When**

人物暂时不能直接获胜、撤离、求援或结束危险，必须通过补给、休息、协作、守备、改线或等待维持行动时使用。

**Generation Lens**

先写清原计划依赖什么，再让一个可观察事实击穿它。把关键变量分给具体责任人，并给出触发阈值与下一步动作。资源要转化为体力、岗位、路线、恢复、士气或敌方误判。多人场景要区分谁守、谁护、谁撤、谁运输、谁维持出口。伤势回答“此人现在还能承担什么”。时间窗由实际承担者校准。希望必须来自已经积累的信息、资源或环境变化。

**Revision Lens**

保留既有危险和资源边界。若环境只是景观，恢复一个已经成立的计划失效；若资源只被报数，补一项已有功能后果；若伤势不改变职责，改写为守位、携带、撤离或被保护对象；若战斗或撤离窗口已经成立，删除继续硬撑的重复段落。

**Failure Patterns**

只堆风雪、饥饿和疼痛；原计划从未真正失效；资源发下去后人人自动感恩；所有人承担同一职责；伤员要么一律留下、要么一律撤离；倒计时不改变排序；撤退写成无目标奔跑；生存窗口成立后仍反复描写痛苦。

**Stop when**

新路线、撤离、反击、求援、恢复或稳定长期生存已成为明确可执行窗口；或外部敌人已接触，主问题转为 `combat`、追逃或调查。

**是否需要新 Primary/variant：** No。

# Cross-family handoff rules

| 起点 → 接管 | 交接条件 | 必须携带的状态 |
|---|---|---|
| `chase_escape → combat` | 距离稳定进入可攻击关系、出口被封，或移动已不能改变胜负 | 最后位置、功能距离、伤势、弹药、保护对象、移动为何失效 |
| `chase_escape → stealth_infiltration` | 直视中断但仍存在可追踪链，局部遮蔽暂时成立 | 最后所见位置、追踪置信度、搜索延迟、遮蔽时限、出口 |
| `chase_escape → survival_endurance` | 速度、路线或资源无法继续，生存维持取代脱逃 | 最慢成员、资源余量、伤势、可用安全点、剩余窗口 |
| `stealth_infiltration → chase_escape` | 身份或位置已被确认，且对方开始追击或封路 | 哪些人知道、最后确认位置、追击力量、可用路线 |
| `stealth_infiltration → combat` | 隐藏不再保护人物，双方获得接触与攻击许可 | 谁看见谁、当前目标、出口状态、先手限制 |
| `stealth_infiltration → investigation` | 异常已足以改变调查方向，但尚无直接暴露 | 已验证异常、观察者知识、未解决问题、下一次核验时间 |
| `survival_endurance → combat` | 敌人已定位或接触，群体拓扑和防守职责转为即时胜负 | 外圈/内圈职责、承载时间、伤员、恢复资源、保护目标 |
| `survival_endurance → investigation` | 原计划被击穿，但威胁性质、来源或路线仍未知 | 触发异常、缺失资源、空间变化、当前未知边界 |
| `combat → chase_escape` | 胜负问题转为脱离、护送或夺回出口，移动重新成为主解法 | 伤势、弹药、敌方剩余追击力、保护对象、撤离边界 |

通用规则：交接不是换标签，而是把“上一场戏已经证明的状态”带入下一场戏；不得在新 Primary 开始时重置位置、资源、伤势、知情者或时间窗。
