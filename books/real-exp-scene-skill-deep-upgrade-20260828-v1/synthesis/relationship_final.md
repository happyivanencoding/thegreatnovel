# relationship v2

## Source-blind Generation Lens

- 先问“没有这个人时，他原本会怎么做”，再选择一个被关系改写的安全路线、风险阈值、底牌、时间、劳动或身体承受。
- 日常负荷只有在迁移、缺席、替换、争执或新责任迫使它重新分配时才展开；不要把每个家务动作都写成关系升级。
- 若双方必须据此共同决定去留、风险、照料或边界，使用具体直说，并立即由接受、拒绝、改线或共同动作承接。
- 若当前没有可共同执行的结论，才保留微反应或沉默；沉默必须满足“本可说，且说出会改变外部结果”。
- 明确区分单方选择、对方接受/拒绝、双向确认和竞争义务排序。一次救援或照料不得自动升级为互爱、承诺或永久位置。
- 关系成本可从日常负荷、私下暴露、公开对抗到不可逆牺牲递进，但不是固定情绪阶梯。

## Preservation-First Revision Lens

- 保留已经成立的非对称关系，不为“完整”补写另一方回应。
- 删除没有外部反事实、没有资源/路线/边界变化的装饰性沉默和微反应。
- 不把直说改成含蓄，也不把含蓄改成直说；先看当场是否存在可执行共同决定。
- 不把关系默认解释为 romance，不设置情绪配额，不以关系强度覆盖师门、群体、生存等既有义务。
- 已有关系 payoff 后保留停留与适应，不立即追加旁白总结或新危机。

# departure v2

## Source-blind Generation Lens

- 先建立离开前的使用基线：谁照料、谁守候、谁占据哪个位置、哪项日常由谁完成。
- 离开后尽快呈现第一件“不能再照旧完成的事”，并让人物、替代者或空间因此改路线、改责任或改风险。
- 明确区分主动分别与纯粹失去：前者必须有可见的留下选项和主动取舍；死亡、失联、沉眠、灾难撤离不能被伪装成主动牺牲。
- 等待必须行动化：留下、延后、替代看守、转向搜寻、拒绝离开或承担新风险至少发生一次。
- 遗留物、空位、旧路或习惯只有在“原来如何使用→现在如何空置、替代、改用或无法使用”时才承担缺席证据。

## Preservation-First Revision Lens

- 不把空位自动解释为死亡；保留文本尚未确认的失踪、转移或失联状态。
- 不凭遗物新增召回器、承诺、意志或未来回归。
- 删除只重复哭泣和告别、却没有行动权限变化的段落。
- 保留被离开者真实获得的自由、责任或新风险，不把所有 vacancy 都写成损失。
- 不把公共送别模板复制到私人关系。

# reunion v2

## Source-blind Generation Lens

- 旧物、旧动作或旧称呼只负责完成辨认；辨认之后必须进入一个新的、可执行的共同目的、目的地、边界或合作方式。
- 让回归者当前的恐惧、伤痕、身份、能力或新责任有机会改写原定方案；“回家”必须落到“哪个家、以什么风险回去”。
- 旧日常可以作为关系仍有连续性的有限回声，但不能作为关系自动复原的证明。
- 保留至少一个当前不匹配：公开身份、团队分工、第三方责任、无法同行或双方目标不同。

## Preservation-First Revision Lens

- 不把认出、拥抱或称呼恢复改写成旧关系全部恢复。
- 若只有辨认、没有新的共同动作或边界，不判定为完整 reunion payoff。
- 保留重逢后的现实限制，不用旧回忆抹平当前风险。
- 不强行补全长期分离期间未被 Canon 建立的心理、历史或承诺。

# sacrifice v2

## 已足以 Promotion 的新增判断

牺牲者不是主角时，应保留一条授权链：

1. 牺牲者有自己的最后愿望或独立利益；
2. 受托者通过既有关系或现场行动取得被授权资格；
3. 牺牲实际移交能力、时间、资格、生命或责任；
4. 幸存者必须在后续行动中回应这项托付。

《诛仙》的大巫师、田不易相关窗口与《斗罗大陆》的大明、二明、波赛西窗口共同支持这一点。它补充的是“为什么由这个幸存者接住”，不是再加一层煽情。

## Source-blind Generation Lens

- 先明确唯一出口与不可两全条件，再让牺牲成为可追踪的交接。
- 第三方牺牲必须留下独立意志、授权依据和幸存者责任。
- 不把死亡或付出直接折算成升级奖励、爱情证明或全书法则。

## Preservation-First Revision Lens

- 保留牺牲造成的具体缺口、责任与关系变化。
- 不因后续需要把牺牲者改写成纯资源，也不把幸存者自动写成合法继承人。
- 复活、治疗、恢复只可修复 Canon 已支持的层级，不能顺手抹除主体关系与行动缺口。

# identity v2

目前是候选升级，不作跨书冻结。

## Source-blind Generation Lens

- 揭露前先画知识席位：谁掌握秘密、谁能识别证据、谁只是受影响者、谁仍会按旧身份行动。
- 选择能改变关键人物权限、程序、成本或敌我判断的证明物；不要用百科说明替代识别。
- 揭露后明确至少一个行动权变化：谁不能再做什么，谁被迫承担什么，谁获得什么有限权限。
- 先决定公开目的：求保护、招募、锁定敌我、制度交接或家族归属；不同目的不能共用同一反应模板。
- 关系承认、身份获准进入和彻底解决必须分开。

## Preservation-First Revision Lens

- 保留不同人物的知识差异，不把全场改成同一种震惊。
- 不把身份揭露倒灌成未被文本建立的长期历史或旧关系。
- 若揭露没有改变任何行动权，只能视为线索重解释，不能硬判为完整 `identity_reveal`。
- 保护、招募或权限提升必须有限兑现，并保留既有敌意、旧债与制度阻力。
- 公开范围必须服从 Canon 已建立的保护能力；不为制造高潮提前扩散秘密。

# Revision-only checks

- 关系：检查“关系对象改变了什么具体选择”，而不是情绪词是否足够。
- 关系：检查沉默是否有真实反事实；检查单向行为是否被误写成双向确认。
- 离开：检查是否存在离开前基线，以及第一件无法照旧完成的事。
- 离开：检查主动分别是否有可留下的替代项；若没有，应写失去、失联或撤离。
- 重逢：检查“认出”之后是否产生新的可执行共同位置。
- 牺牲：分开记录肉体、局势、能力、主体性、关系和行动权的恢复层级。
- 牺牲：遗留能力第一次使用时，检查它是否解决既有短板，同时保留来源与限制。
- 牺牲：只有当前危机与旧牺牲在选择结构上真正同构，才使用镜像危机。
- 身份：检查知识席位、证明物、行动权变化和公开目的四者是否对齐。
- 全部 skill：不新增 romance 默认、不补情绪配额、不突破 long-history / Canon boundary。

# Still Provisional

- “日常负荷”作为长期累计机制的精确模型：已足以作为生成提醒，但还不能规定固定频率或固定升级顺序。
- 牺牲后的恢复层级。
- 牺牲遗留能力的来源痕迹、操作边界与非万能化。
- 镜像危机中的反牺牲。
- 代价因新信息而合法校准，但仍留下新负担。
- identity 的完整知识席位图、行动权差分和公开范围规则：目前主要由 `identity_douluo` 支撑，缺少第二个独立身份揭露 source。
