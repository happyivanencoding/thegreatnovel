成熟中文男频幻想成长长篇。全新虚构世界，主角长期真正变强。世界先于主角成立，不围绕未来主角定制锁孔；优先具体力量、奇观、强敌、价值物、关系与可探索空间，避免工程化、制度化、项目管理化叙事成为主发动机。不要预设主角现实履历、现代职业或现实身份。

这是一次“真正换世界创意指纹”的生成。上一版失败是因为又使用了天地能量流、潮汐、地脉、潮井、导流、承载、锚点这一整类 ontology。本次必须彻底避开：
- 不使用“潮 / 灵潮 / 潮炁 / 地脉能量 / 能量流 / 导流 / 锚点 / 承载网络 / 天地能量循环”作为力量体系根基。
- 不只是换名词；力量来源、获取方式、升级逻辑、战斗表现、稀缺资源与世界奇观都必须与“环境能量流动体系”明显不同。
- 世界仍然应当直观、具象、适合成熟男频成长爽文，不要为了求新改成抽象哲学设定。

本书力量成长体系必须是**10个大阶段 × 每阶段10级 = 总计100级**：
- 1—10级 = 第一大阶段；11—20级 = 第二大阶段；……；91—100级 = 第十大阶段。
- 每一级都让修炼者本人在身体、战斗、感知、移动、能力、生命状态或行动范围上获得可感知的真实增强。
- 每跨过一个十级门槛出现明显质变，但1—100级始终属于同一套力量体系。
- 70—100级仍保持具体、可见、可战斗、可探索、可占有、可失去的力量变化；不要默认写成因果、命运、天道、概念、世界定义等抽象哲学词。
- 等级名称、十个大阶段名称、每一级差异和人群分布由 World Vision 自己创造。
- 100级是已知顶端，不存在101级、第11阶段或隐藏更高境界。
