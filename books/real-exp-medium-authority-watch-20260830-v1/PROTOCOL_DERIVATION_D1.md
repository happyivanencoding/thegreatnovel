# Medium Authority Watch D1｜Derivation Protocol

> Stage: derivation-only screen on Held-out Novel 2 after it has already been consumed as evidence. Not production.

## Goal

Test whether Luna-medium Authority Reviser can recover most of Luna-high Authority quality when given one tiny deterministic end-of-prompt Watch, without changing rich Director, Curator, Primary, Final Facts Projection, or Reviser base contract.

## D1 Watch Source

Runtime may only repeat exact text already present in the frozen Reviser prompt:

1. Frozen Mission: 主角行动 / 直接结果 / 状态变化 / 结尾推动力.
2. Scheduled `READER RELEASE` section; omit if explicitly none.
3. `Curator Audit` bounded section; omit if it contains no substantive warning.
4. Frozen Power `永久边界` bounded section.

Then append one stable no-invention sentence:

`Authority 未明确给出的伤势、数字、物品来源/持有关系、旧史、他人内心/认知或新能力，一律保持未知；不要为了连贯补事实。`

No keyword/synonym parser, no LLM classifier, no new story fact, no reviewer, no rewrite checklist.

## Placement

Append the Watch after the existing Primary Draft so it is the last semantic input before generation.

## Comparison

Same eight Candidate-2 Treatment Primary drafts:

- Luna medium Reviser baseline (existing screen)
- Luna medium + D1 Watch
- Luna high Reviser reference

A D1 derivation pass requires:

- Story non-regression vs high;
- Authority mean close to high and hard-problem count materially closer to high than medium baseline;
- no new repeated failure family caused by the Watch;
- medium+D1 wall remains materially below high;
- evidence repeats across both generation repeats rather than a single chapter.

Only then freeze a Candidate 3 protocol before generating a third new held-out novel.
