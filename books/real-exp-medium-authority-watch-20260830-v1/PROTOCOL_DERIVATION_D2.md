# Medium Authority Watch D2｜Sparse Derivation Protocol

> D2 is the final derivation iteration. It is frozen before any D2 generation.

## Change from D1

D1 repeated too much frozen information and caused Story/latency regression. D2 removes 主角行动 / 直接结果 / 结尾推动力 and keeps only the smallest high-risk surfaces already present in the Reviser prompt:

1. exact Frozen Mission `状态变化` line;
2. exact scheduled `READER RELEASE` section, only when non-empty;
3. exact `Curator Audit` only when it contains a substantive uncertainty/conflict;
4. only the first sentence of Frozen Power `永久边界`;
5. one stable no-invention line covering unapproved injury / number / provenance / old history / mind-reading / new ability.

No semantic parser, classifier, new fact, reviewer, or checklist.

## Stop Rule

D2 must materially reduce medium-base Hard problems toward high while keeping Story non-regressing and Reviser wall materially below high. If it still has a clear Authority gap, stop this Watch family and do not generate Held-out Novel 3.
