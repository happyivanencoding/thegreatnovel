# RESULTS｜Reader Orientation / World Entry / Competence-Filler Final Regression

## Verdict

**总体：PASS WITH RESIDUAL RISK。**

这轮解决了 `SUBJECTIVE_AUDIT.md` 新暴露出的主要问题，而且没有回退上一轮已经有效的 `State Advance After Proof / Ruler = Compression / Choice → Consequence / Plot Pace ≠ Tier Pace / 主人公连续升格`。

最重要的变化不是“多写世界观”，而是把世界信息重新放回正确 authority 链：

> **Approved World → Reader Release timing → Curator bounded projection → Primary direct orientation。**

同时继续压缩：

> **决定后的普通实施 / 非核心 Supporting Skill / 为证明资格而补的流程。**

最终 reader copy 五章约 1.20 万字。相比 pace-ruler baseline 约 1.05 万字略长，但新增篇幅主要来自 Ch1 的 opening orientation 与 Ch3 的 World Entry，而原审计最慢的 Ch4 从约 3604 字降到约 **1575 字**。

---

## 1. 对原主观审计的归因修正

原审计大方向正确，但“Curator 把白角部背景丢掉”过于简单。

真实 root cause 是四层：

1. **World**：旧 World 已有猎墙、荒原部族等事实，但“无阶普通人怎样跨城 / 商队为什么是现实世界入口”不足。
2. **Outline**：Opening / World Entry / named faction 首次介绍的释放时机没有被保存为 authority。
3. **Runtime / Curator**：BOOK §2 过于摘要化；完整 World 又不能自由交给 Writer，缺一个安全、按章读取的世界事实通道。
4. **Primary realization**：决定已经完成后，仍会把停车、排布、绑缚等 Supporting Implementation 写成小型问题求解。

因此 production 没有新增“每章介绍世界观”的字段或 Agent，而是建立/强化：

- `WORLD AUTHORITY`：Approved World Vision 的安全章节事实投影；
- `Reader Release Map`：只保存 timing-sensitive、且与真实章节事件相交的首次释放；
- `World Entry threshold release`：人物真正跨门槛的当章就解释入口为何重要；
- named 势力安全公开类别：只说明“它是什么”，不泄露动机/未来 reveal；
- `Competence Filler` / `Access-Tax` / Supporting Skill effect-level compression。

---

## 2. Opening Orientation：PASS

原 baseline 第一章很快进入猎市、护肩、二阶异兽，但读者缺少最低生活世界位置。

最终 Ch1 没有增加 Prelude / 世界史，也没有推迟 Core Power payoff。异兽真正越过兽笼后，只用短旁白建立：

> 猎市外有猎墙，平时把荒野和镇子隔开；此刻安全边界在市内失效。

同时开场本身通过“公开估价、盐商、药铺、猎队”让读者看见猎市与异兽资源如何连接普通生活。

随后立即进入：

`二阶异兽失控 → 顾晚禾/护肩受威胁 → 闻野舟第一次夺势 → 二阶扑击偏半尺`。

**结论：Orientation 没有变成 Setup Tax。**

---

## 3. 商队 World Entry：PASS

原审计指出得最准确的一点之一是：旧 Ch3 只写“跟顾晚禾走”，没有让读者感到“地图打开了”。

最终 Outline 的 Reader Release Map 把移动事实排在**真正跨出南门的 Ch3**，不是提前塞 Ch1，也不是拖到 Ch4 遇险后再补：

> 对没有猎阶的普通人而言，跟随有护卫的跨城商队，是离开边镇、穿过荒野的现实方式。

正文在南门真正出现车队、护卫与荒野道路时才直接说出这件事。

随后又落到人物位置变化：

> 闻野舟从“站在猎市里等人挑拣的杂工”，变成跟着商队往南走的人。

这使“顾晚禾路线”同时成为：

- 私人关系选择；
- 世界移动方式；
- 第一次 World Entry payoff。

**这是本轮最成功的新释放之一。**

---

## 4. 白角部首次介绍：PASS

旧 Ch4 最大 onboarding 问题是：读者看到“白角部”，却无法快速判断这是兽群、军队、部族还是宗门。

最终 Reader Release Map 在 Ch4 只排安全公共事实：

> **白角部是一支荒原部族，其南迁被边军当作入侵。**

正文在远处人影真正进入现场后直接给出一句类别说明，然后立刻回到封路冲突。

同时严格保留 unknown：

- 白角部为什么盯着某辆车；
- 他们真正追什么；
- 幼年王种；

这些仍留到后续 reveal。

所以这次做到了：

> **先回答“它是什么”，不回答“真相是什么”。**

没有 writer-invented lore，也没有提前剧透。

---

## 5. Chapter 4 Implementation Expansion：PASS

原 pace-ruler Ch4 约 3604 字，是前五章明显慢点；大量篇幅进入三排停车、药车位置、缰绳、推车、水囊与反复争论。

最终 Ch4 约 **1575 字**。

仍然存在必要的车队动作，因为封路现场本来就在商队，但它不再成为独立“排车问题求解”。章节主问题变成：

`封路 → 白角部是什么 → 商队被夹在中间 → 白角部不盯贵重货物 → 它们一直逼近一辆不起眼的杂物车。`

这正是审计要求的注意力重新分配：

> **低价值实施更短，高价值世界信息与异常判断更长。**

没有把 Ch4 变成百科；也没有靠新增战斗强行提速。

---

## 6. Ch5 Core Power + Reveal：PASS

Ch5 保留了上一轮正确结构：

- 白角部 / 二阶异兽逼近车阵；
- 闻野舟第二次真实使用核心能力；
- 夺走冲击里最凶的一段；
- 用借来的冲势改变杂物车位置；
- 白角部视线进一步锁定杂物车；
- 车底传出幼叫。

所以 Orientation 没有挤掉 Core Fantasy recurrence。

本章也继续保留 reveal boundary：只出现“幼叫”，没有提前把它确定成王种。

---

## 7. Reader Release Map 本身：PASS

最终 Map 只排真正 timing-sensitive 的少量事实：

- Ch1：猎市 / 猎墙安全与生活坐标；
- Ch3：无阶普通人通过护卫商队跨城；
- Ch4：白角部 = 荒原部族，南迁被边军视为入侵；
- Ch6：幼年王种真相（未来 reveal）。

它没有变成每章必填 World KPI，也没有把所有 World Vision 搬进 Outline。

特别重要的是：

> **World Entry 在跨门槛的当章释放，而不是等下一章遇险再解释。**

这修正了第一次 orientation-final 的一个 timing bug。

## 9. Residual Risks

### A. Ch2 比上一轮极限压缩版更长

Ch2 仍保留猎队首领与桑照的一次公开说法冲突，以及桑照用落点/伤势确认“不只是运气”。

它没有恢复成旧版多轮验证，也没有再发明试工/考核/观察流程；但 2723 字比 pace-ruler 的 1533 字更长。

当前判断：**可接受，但继续观察。** 不为了追求短字数再新增规则。

### B. Ch3 有轻微 Choice Loitering

闻野舟已经口头选择南行后，又去北棚门外看了一眼再离开。

这比旧版“反复想一整章”轻得多，而且承担“真正放弃什么”的实体化作用；但若跨样本反复出现“决定后还去旧机会门口确认一次”，再回到既有 `Choice → Consequence` 检查，不新增新原则。

### C. Ch4 仍有少量车/缰绳空间细节

但已经从故事发动机降回现场必要动作，且总章长显著下降。当前不再追加 prose gate。

## 10. What This Did Not Solve

- 没有验证 20 / 50 / 100 章后的 Orientation Release 是否仍然克制；
- 没有证明每一种世界都会自然生成足够好的移动 / 社会事实；
- 没有验证完全不同题材（非猎墙/商队型）下 Reader Release Map 的泛化；
- 没有解决长期认知升格的全部质量问题；
- 没有证明 Ch2/Ch3 的最佳正文长度应该是多少。

这些都不应该从单本五章实验直接升级成更多 Prompt。

---

## 11. Integrity

- World / Power / Human / Character / Story Program 冻结；
- World Entry treatment 只调整已批准事实的 release timing 与下游 realization；
- named faction 只释放公开类别，没有提前释放动机或幼兽真相；
- Ch1–2 继承 access-tax treatment；Ch3–5 串行重跑并落 State；
- 当前全量回归：**294 passed**。

---

## Final

**保留当前 Orientation / World Authority / Reader Release / Competence-Filler 修复。**

本轮最值得冻结的表达是：

> **不是少解释，而是把解释权交给已批准 World，把解释时机交给真实事件。动作第一次让读者产生问题时，用最短充分的世界事实回答，然后继续故事。**

以及：

> **World Entry 在主角真正跨过门槛的当章就要让读者感到“他进入了过去进不去的世界”；不要等下一章遇险才补说明。**
