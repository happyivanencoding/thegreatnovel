# Proposed Active Scene State

地点：南门外、商队前路。
在场人物：闻野舟、顾晚禾、商队成员与护卫、边军传信人。
即时伤势：右肩至后背仍有伤，不能用右侧发力；背负行囊行走时疼痛明显。
手中关键物品：护肩、暗铜临时入场牌、装有衣物和干粮的布包、剔骨刀。
当前敌人或追兵：无；前路因边军封锁暂时无法通行。
当前倒计时：南行路线被封；入场牌十日期限仍在。
下一步直接目标：弄清封路原因与可通行路线。
当前主动目标：跟上顾晚禾，随商队继续南行。

# Proposed Persistent Canon

- 闻野舟已明确选择南行，拒绝暂时前往北棚接战具杂工机会。
- 商队已接纳闻野舟同行；顾晚禾要求他跟在自己身后，但未承诺照顾或等候。
- 闻野舟目前没有猎阶，也没有正式兽性。
- 右肩至后背伤势仍在，不能用右侧发力；长期影响未定。
- 南行途中突遇边军封路，南边暂不许普通人通行。
- 白角部正在向南迁移，已成为封路背景与潜在影响因素。

# Proposed Chapter Summary

闻野舟决定不去北棚，收拾行囊后在第三天清晨赶上顾晚禾所在的南行商队，并获准同行。车队刚离开边镇，边军传信人便赶来封路，称南边禁止通行，白角部正在南迁。

# Proposed Open Promises

- 南行商队前路被边军封锁，能否继续通行尚未确定。
- 白角部南迁将如何影响商队与闻野舟，尚未确定。
- 闻野舟能否在不使用右侧力量的情况下跟上商队并适应荒野行程。
- 闻野舟能否再次剥走异兽落势仍未确定。
- 右肩至后背伤口是否留下长期影响仍待观察。
- 桑照交付的北棚临时战具判断机会仍在十日期限内，但闻野舟已暂时选择南行。
