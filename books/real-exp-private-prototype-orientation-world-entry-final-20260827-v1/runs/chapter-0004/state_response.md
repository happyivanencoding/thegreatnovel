# Proposed Active Scene State

地点：南门外封锁线内、商队临时队形外侧。
在场人物：闻野舟、顾晚禾、陶遂、商队成员与护卫、边军、白角部。
即时伤势：右肩至后背伤口受牵扯后发麻，仍不能用右侧发力。
手中关键物品：护肩、暗铜临时入场牌、布包、剔骨刀、麻绳。
当前敌人或追兵：边军封锁道路；白角部逼近并持续压向杂物车。
当前倒计时：南行通道封锁，边军检查与白角部接近正在同时推进。
下一步直接目标：查明白角部持续逼近杂物车的原因，并守住车队队形。
当前主动目标：跟上顾晚禾，随商队继续南行。

# Proposed Persistent Canon

- 闻野舟在右侧受伤、不能发力的情况下，使用左肩和左手协助稳住失控驮兽与车队，避免车队外侧被冲散。
- 顾晚禾主动调度伤兽与药车，重视维持商队秩序；她提醒闻野舟不要逞强。
- 陶遂负责指挥商队防守与调车，边军正在收紧封锁线。
- 白角部南迁队伍持续逼近商队右侧，明确盯上杂物车，而非盐砖车、皮货车或药车。
- 白角部为何盯上杂物车尚未确认。

### Active Relationships

# Proposed Chapter Summary

边军因白角部南迁封锁道路，商队被迫在封锁线内重新排出防守队形。闻野舟忍着伤势用左侧协助稳住受惊驮兽与歪斜车辆，顾晚禾带走伤兽和药车。随后闻野舟发现白角部始终逼近一辆不起眼的杂物车，却没有盯上盐砖、皮货或药车。

# Proposed Open Promises

- 南行通道被边军封锁，商队能否继续通行尚未确定。
- 白角部为何持续逼近杂物车尚未确认。
- 商队如何在边军封锁与白角部接近之间脱身尚未确定。
- 闻野舟能否在不使用右侧力量的情况下继续跟上商队。
- 闻野舟能否再次剥走异兽落势仍未确定。
- 右肩至后背伤势是否留下长期影响仍待观察。
- 桑照交付的北棚临时战具判断机会仍在十日期限内，但闻野舟暂时选择南行。
