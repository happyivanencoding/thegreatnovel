# Proposed Active Scene State

地点：南门外封锁线内、杂物车旁。
在场人物：闻野舟、顾晚禾、陶遂、商队成员与护卫、边军、白角部前锋、受伤二阶异兽。
即时伤势：闻野舟右肩至后背伤口再次裂开，左肩承受重压，左手掌心发麻，仍不能用右侧发力。
手中关键物品：护肩、暗铜临时入场牌、布包、剔骨刀、麻绳。
当前敌人或追兵：受伤二阶异兽仍盯住杂物车；白角部前锋已逼近弩箭射程，目标同样是杂物车。
当前倒计时：白角部即将与商队发生近距离冲突，边军拒马仍封死南路。
下一步直接目标：查明杂物车内活物的身份与白角部追逼的原因，并守住杂物车。
当前主动目标：在不使用右侧力量的情况下，跟上顾晚禾并保住商队队形。

# Proposed Persistent Canon

- 闻野舟可通过左手接触剥走二阶异兽正在落实的冲势，并将其转移到其他方向；本次冲势已被用于推偏异兽、移动车轮，当前未确认还能否立即再次使用。
- 闻野舟在右侧伤势未愈时仍可用左侧短暂承受冲撞，但会加重伤口。
- 杂物车内藏有被乱布和木框严密包裹的活物，已发出两次幼叫；身份与来源未确认。
- 白角部与二阶异兽均明确盯上杂物车，目标并非普通货物。
- 南行通道仍被边军封锁，商队、白角部与边军形成三方僵局。
- 桑照交付的北棚临时战具判断机会仍在十日期限内，闻野舟此前选择南行。

### Active Relationships

顾晚禾｜维持商队队形并照看伤兽｜与闻野舟同行、保持独立｜确认闻野舟伤口裂开并制止其继续用右侧｜共同保护杂物车并应对白角部逼近
陶遂｜维持车队防守与秩序｜临时指挥商队行动｜确认白角部并非冲货而来｜决定如何处置杂物车及其中活物

### Tracked Assets

杂物车｜商队｜车队外侧、闻野舟与顾晚禾身旁｜车轮已滑向内侧，未翻；车尾油布破损，车底露出木框与活物幼叫｜车内藏有活物一事被多人听见

# Proposed Chapter Summary

白角部驱使一头二阶异兽扑向杂物车，闻野舟以左手剥走其冲势，救下车边人员并将异兽撞偏，又把残余冲势送入车轮避开第二次扑撞。白角部随即逼近，车底破席翻开，露出藏在木框中的活物幼叫，众人确认杂物车才是双方争夺的目标。

- 桑照交付的北棚临时战具判断机会仍在十日期限内，但闻野舟暂时选择南行。
