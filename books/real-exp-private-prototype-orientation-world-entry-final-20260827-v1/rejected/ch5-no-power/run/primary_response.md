# 正式正文

白角部的人忽然加快了脚步。

他们仍沿着山坡压下来，却没有扑向外侧的盐砖车。杂物车旁边刚有个护卫弯腰去捡掉下来的木桶，坡上的几个人便同时改了方向，像被那一下动静牵住，直直朝杂物车逼来。

闻野舟眼神一沉。

“别碰这辆车！”他喊道。

那护卫愣住，手已经碰到木桶，闻言立刻缩回去。可后方一辆车被人群挤得斜了一下，车辕擦过杂物车尾，撞得整辆小车往前滑了半尺。

山坡上的白角部彻底动了。

几道灰黑身影从坡上散开，绕开货车，直奔杂物车所在的缺口。

“拦住他们！”陶遂厉喝。

边军那边也响起号声。拒马后的士卒往前压，长枪不分白角部还是商队护卫，先把靠外的人都逼回车阵里。

杂物车的伙计吓得脸色发青，死死抱住车辕：“陶爷，他们要抢车！”

“先把车推回去！”陶遂抬手指向杂物车，“谁敢冲阵，按袭军处置！”

闻野舟没去推车。

白角部只盯着这里。有人靠近车，他们就转向；车一动，他们比谁都急。

车上那些木桶、破席子和杂物，不值这个阵仗。

车底一定有东西。

“让开。”闻野舟对赶车伙计说。

伙计看着他：“你要干什么？”

“查车底。”

“这车底能有什么——”

又一支短箭钉进车旁的土里。

箭从山坡方向射来，没伤人，却正扎在杂物车的轮边。

伙计的声音一下断了。

闻野舟抬脚踩住车轮前方的石块，左手抓紧车板。他右侧伤口还在发麻，不能硬拽，只能把肩背压低，用左边身子顶住车身。

“帮我扶住，别让它翻。”他说。

旁边一名护卫骂了句，还是扑上来按住车辕。伙计也回过神，连忙去拉缰绳。

闻野舟蹲下身。

杂物车底下全是泥。车轴旁垂着一块松动的木板，边缘被席子和麻绳遮住，乍看和普通车底没什么两样。

可木板钉得太新。

他伸手去抠木板边缘，右肩刚一牵动，伤口便像被火烫了一下。闻野舟额角渗出冷汗，手却没停。他换成左手，从腰间抽出短刃，顺着缝隙一点点撬进去。

“闻野舟！”顾晚禾的声音从内侧传来，“你在车底做什么？”

“这车有东西。”

顾晚禾刚要靠近，陶遂已经一步拦住她。

“别过去。”陶遂盯着闻野舟的动作，脸色比刚才更沉，“白角部冲的是这辆车。”

短刃一压，木板终于松开。

里面先露出一团沾满灰土的黑毛。

闻野舟动作顿住。

那团黑毛缩在狭窄的夹层里，身上缠着破布，胸口却还在起伏。它听到响动，勉强抬起头，露出一双湿漉漉的金褐色眼睛。

不是货物。

是一只还活着的幼兽。

幼兽的前爪被麻绳勒出血痕，爪尖却已经很尖。它想叫，喉咙里只挤出一声低哑的呜咽，随即又把头缩回去，像是连挣扎的力气都没剩多少。

车外忽然静了一瞬。

连杂物车的伙计都忘了喊。

山坡上，一声短促而尖锐的哨音传来。

白角部的人同时停住。

他们望着车底露出的黑毛，队形没有再往盐砖车偏半寸。几个人抬起手里的兵器，隔着混乱的车阵，死死盯住闻野舟。

闻野舟明白了。

白角部追的从来不是商队的货。

他们追的是这只被塞进车底、跟着商队一路走到这里的幼兽。

“把木板合上。”顾晚禾低声道。

她的声音不高，却很快。

闻野舟回头看她。顾晚禾没看那只幼兽的眼睛，只看着周围越来越紧的包围。

“先别让它再露在外面。”她说，“它现在露出来，谁都不会放手。”

陶遂已经走到车旁。

他看清夹层里的东西，眼里先是一惊，随即压成了冷硬的亮光。

“王种幼兽。”他开口，“怪不得白角部不肯退。”

闻野舟皱起眉：“你认得？”

“认不认得不重要。”陶遂伸手按住车板，“它现在在边军封锁线内，就是军府的东西。”

“它还活着。”顾晚禾说。

陶遂看了她一眼：“活着才值钱。”

闻野舟的手一下握紧短刃。

陶遂察觉到他的动作，语气更沉：“闻野舟，松手。你以为白角部是来讲道理的？他们一旦冲进来，商队里的人先死。把它交给军府，边军才有理由护住这支车队。”

“军府护不护，是你们的事。”闻野舟说，“车底是商队的车。”

“现在不是了。”

陶遂抬手。

两名边军护卫立刻往前，去抓车底的木板。

闻野舟没有起身让开。

右边伤口还在抽痛，他半蹲在泥地里，左手压着木板，挡在那只幼兽前面。那幼兽似乎听懂外面的声音，身子缩得更紧，湿冷的鼻息落在他手背上。

顾晚禾站在旁边，唇角绷得很紧。

她没有替闻野舟拔刀，却也没有后退。

山坡下的白角部已经逼到弓箭能稳稳射到的位置。边军的枪阵则从另一边收拢，枪尖全对着杂物车。

车队被夹在中间，连喘气都像要选方向。

就在这时，后方忽然传来一阵杂乱的脚步声。

有人从车队尾部撞开了一辆堆皮货的板车，几名护卫被撞得踉跄。紧接着，一个男人的声音从人群后面响起。

“蒋爷说了，车底的东西归他！”

话音未落，三个人已经从后方扑来。

他们没有冲白角部，也没有管边军的枪阵，目标同样是杂物车。为首那人手里拎着套索，直直甩向车底夹层。

陶遂的脸色猛地变了。

“拿下他们！”

白角部的哨声再一次响起。

闻野舟抬起头。

军府要收，蒋横的人要抢，白角部就在外面等着把幼兽带走。

而夹层里的小兽，正用那双金褐色的眼睛看着他。
