# Proposed Active Scene State

地点：南门外封锁线内、杂物车旁。
在场人物：闻野舟、顾晚禾、陶遂、商队护卫与伙计、边军、白角部、蒋横手下。
即时伤势：右肩至后背伤口持续发麻抽痛，不能用右侧发力。
手中关键物品：护肩、暗铜临时入场牌、布包、剔骨刀、麻绳、短刃。
当前敌人或追兵：边军准备收走幼兽；白角部逼近抢夺；蒋横手下从后方套取幼兽。
当前倒计时：三方即将围绕杂物车冲突，车队仍被封锁在内。
下一步直接目标：护住车底幼兽，阻止其被军府、蒋横手下或白角部夺走，同时避免车队被冲散。
当前主动目标：保护这只幼兽并守住杂物车。

# Proposed Persistent Canon

- 闻野舟确认杂物车底藏着一只仍活着的黑毛王种幼兽，前爪被麻绳勒伤，状态虚弱。
- 白角部追踪并逼近商队，目标是带走这只王种幼兽。
- 边军以封锁线内军府名义要求接管幼兽，陶遂认为交出幼兽才能获得护卫车队的理由。
- 蒋横手下突然从车队后方出现，试图用套索抢走幼兽。
- 闻野舟挡在幼兽与各方之间；顾晚禾未拔刀，但没有后退。
- 南行通道仍被封锁，商队处于边军、白角部和蒋横势力的夹击中。

### Active Relationships

顾晚禾｜维持商队秩序并应对夹击｜与闻野舟同行、保持独立但暂时支持其保护幼兽｜劝闻野舟先合上木板、避免幼兽暴露｜共同处理幼兽归属与车队安全

陶遂｜优先保住商队并服从军府处置｜临时指挥者，与闻野舟在幼兽归属上对立｜命边军护卫接管车底幼兽｜准备阻止闻野舟继续保护幼兽

### Tracked Assets

王种幼兽｜暂由闻野舟挡护｜杂物车底夹层｜活着、虚弱，前爪受勒伤｜白角部、边军和蒋横手下同时争夺

# Proposed Chapter Summary

闻野舟查开杂物车底夹层，发现里面藏着一只受伤虚弱的王种幼兽，确认白角部追踪的并非商队货物。边军要以军府名义接管幼兽，顾晚禾暂时协助遮掩，陶遂则命人取出。此时蒋横手下从车队后方冲来抢夺，三方势力将杂物车与幼兽夹在中间。

# Proposed Open Promises

- 边军、白角部与蒋横手下将如何争夺王种幼兽尚未确定。
- 闻野舟能否护住幼兽并阻止其被任何一方夺走尚未确定。
- 商队如何在三方夹击与边军封锁中脱身尚未确定。
- 王种幼兽的真实来历、价值与白角部追捕原因尚未确认。
- 闻野舟能否在不使用右侧力量的情况下继续行动尚未确定。
- 闻野舟能否再次剥走异兽落势仍未确定。
- 右肩至后背伤势是否留下长期影响仍待观察。
- 桑照交付的北棚临时战具判断机会仍在十日期限内，但闻野舟暂时选择南行。
