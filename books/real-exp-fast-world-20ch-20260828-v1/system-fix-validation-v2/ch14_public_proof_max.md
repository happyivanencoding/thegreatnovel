# 正式正文

炉钟第二声落下时，百炉会内侧的铁门彻底合拢。

顾停舟跟着唐绾穿过一道短廊，进了开炉场。

场地比外面的院子大得多，四周砌着黑石矮墙，墙上嵌满了旧潮灯。中央是一条被石槽围住的试潮道，槽里没有水，只有一股沉重的潮压贴着地面缓慢游走，压得石面不断发出细碎的响声。

十几名来验器、验潮路的人站在矮墙外。

阮青蜃也进来了。

他身后的两名随从抱着卷册，站得离试潮道不远不近，像是早已准备好在这里把账一笔笔翻出来。

唐绾走到试炉前，把袖口重新挽起。

“我先开炉。”

没人拦她。

她取出几枚薄潮片，按进试炉四角。炉膛里的暗红热意慢慢升起来，沿着石槽向前铺开。那股潮压原本只在炉前打转，随着唐绾掌心一压，忽然拉成一条直线，沿试潮道往尽头冲去。

石槽两侧的铜尺立刻震动。

“二十丈。”

有人报数。

潮压继续往前。

“三十丈。”

到了三十丈外，潮势开始散开。几块压在石槽边的黑石被震得翻滚出去，铜尺也摇得厉害。

唐绾收手。

潮势退回炉前，石槽里留下几道湿黑的压痕。

场边一名白须老人看着铜尺，开口道：“成炉者能把重压稳在身边，已经不差。想把一段潮势压住、送远，还不散，得有照域者的本事。”

普通成炉者守得住自己身边几步地，却很难把一股乱潮送到几十丈外，再让它按自己的意思转弯。

唐绾没有看那老人，只朝顾停舟伸出手。

“楔子。”

顾停舟把回潮楔放到她掌心。

乌黑的楔身落进试炉中央，浅裂在炉火映照下像一道暗线。

唐绾没有替他催动。

“这次你来。”

顾停舟点头，走到炉前。

试潮道尽头的闸口被人抬开，一股更重的潮压从地下冲出。它不像水，却比水更难拦。石槽里的黑砂被推得往前翻卷，连矮墙外几个站得近的人都下意识退了半步。

顾停舟抬起回潮楔。

他没有急着往下压。

那股潮压先冲到他面前，撞得他胸口发闷。旧伤被这一震牵动，他喉间泛起血腥气，却没有咳出来。

顾停舟盯着石槽。

潮势正往直道前冲。

再往前，就是百炉会立着验石的地方。若让它直撞过去，最多砸碎几块石头，谁也看不出回潮楔到底值不值钱。

他把楔尖对准石槽中央，手腕一沉。

回潮楔先亮起一道细潮纹。

冲来的潮压猛地停住，像一条冲到半路的洪流，被一道看不见的铁闸硬生生锁在石槽里。黑砂堆到楔尖前方，越堆越高，石槽两边的铜尺发出尖锐的颤鸣。

开炉场里的声音一下断了。

顾停舟的手背绷起青筋。

锁住这一股潮，比唐绾在炉边演示时重得多。那股力不断往前顶，想把他连人带楔一起掀出去。

他没有硬扛。

下一刻，顾停舟侧过楔身。

原本直冲试潮道尽头的潮压忽然偏向右侧。石槽右边原本封死的岔道被潮势撞开，黑砂卷着沉重的压意涌进去。那条岔道沿着矮墙向外延伸，绕过验石，又在四十丈外折回主槽。

整段从地下闸口冲出的潮势，被他拧进了另一条路。

矮墙外十几个人同时止声。

白须老人往前一步，盯着铜尺：“四十丈外还能稳住……”

阮青蜃脸上的笑意彻底收了。

顾停舟没有回头。

回潮楔在他掌中震得越来越厉害，楔身上的浅裂亮得发白。他知道该放了。

他把楔尖朝着岔道尽头的泄压石一压。

锁住的潮势猛然冲出。

轰的一声，泄压石被撞得裂成数块，碎石却全落在石槽内。那股潮压顺着已经改好的方向泄进地下，没有冲向人群，也没有撞翻试炉。

石槽安静下来。

回潮楔上的潮纹一点点暗下去。

顾停舟掌心一沉，差点没握住。

楔身冷得像一截刚从深井里捞出来的铁。那道浅裂没有再扩开，可里面残留的压意正顺着裂纹往外散，细得像一缕白雾。

唐绾看了一眼，直接道：“残压在散。今天不能再压第二次。”

顾停舟把回潮楔收回袖中。

他胸口终于压不住，偏头咳了一声。手背擦过嘴角，只擦掉一点血色。

没人再看他嘴角的血。

十几道目光都落在那条改过方向的岔道上，又落回他手里的楔子。刚才还站在矮墙外等着看追索的人，此刻不自觉地让开了试潮道边的位置。

白须老人走到试潮道旁，蹲下摸了摸岔道里留下的压痕。

“普通成炉者只能把重压稳在自己附近。”他抬起头，看向顾停舟，“刚才这一道，按住的是从闸口冲出来的整段潮势，再把它送到四十丈外。不是寻常助器能做到的事。”

灰袍验器人盯着回潮楔上散开的白雾，接道：“一次用完，残压要散，不能连压。代价看得见，效用也看得见。”

这一次，场边的议论才重新响起来。

有人看着裂开的泄压石，有人看着顾停舟，更多的人则看向阮青蜃和他手里的卷册。回潮楔不再只是阮家追索的旧物，顾停舟也不再只是等着别人算账的持有人。

唐绾站在炉前，指了指石槽右侧。

“我铸潮时只能替它把步骤走顺。刚才那一下，是顾停舟自己定的方向。”

阮青蜃终于往前走。

“价钱按今天的结果重谈。”

随从立刻展开卷册。

“回潮楔交还，矿路上的旧损失由我这边销去一半。剩下那部分，也不再追你个人。至于你手里的实测契和矿样，我按市价加三成收。”

他说得很平静，像是在给顾停舟一条体面的退路。

“你今天已经证明了它值钱。正因为值钱，放在你手里，未必是好事。”

顾停舟看着他。

“你想买的不是矿样。”

阮青蜃没有否认。

“我想买的是麻烦。”

“那你找错人了。”

阮青蜃眼神微冷。

顾停舟从袖中摸出那枚回潮楔，放在掌心。

刚才散出的残压还没干净，楔身边缘泛着一层淡白。

“这是我花钱修回来的。”他说，“怎么用，卖不卖，归我自己定。”

他又看向那两卷追索册。

“你的损失可以算。该算到我头上的，我不躲。”

“但你想拿一笔钱，把楔子、矿路和砺骨部的水路全装进自己的账里，不行。”

场边几个人交换了眼神。

阮青蜃的卷册里，首批矿脉标记确实是他的。

可砺骨部靠潮井和迁徙水路活着，这条水路并不是谁在矿脉上留过标记，就能一并划走的东西。

白须老人站起身，拍掉指尖黑砂。

“百炉会只认眼前能验的事。”

他看了一眼阮青蜃，又看顾停舟。

“首批矿脉标记，可算阮家的先占凭证。顾停舟带回来的实测，也该算个人功劳。砺骨部水路另行结算，不并进这一笔矿权里。”

灰袍验器人补了一句：“至于回潮楔，今日试过，器归持有人。阮家若要买，照买卖谈。不能拿旧追索直接压走。”

阮青蜃没有立刻说话。

他身后的随从握着卷册，脸色已经不太好看。刚才摊开的纸页慢慢收拢，没再往顾停舟面前递。

顾停舟却觉得胸口那团闷气松开了一点。

不是因为阮青蜃会就此罢手。

而是从今天起，对方再想把这些东西都说成自己的，得当着百炉会的见证者重新算价。

“矿利怎么分？”顾停舟问。

白须老人看向场边负责记档的人。

那人翻开新册，提笔道：“首批矿料开采后，按实测契记顾停舟个人矿利。砺骨部水路另列，不入阮家矿权。具体数额随第一批矿料核定，由百炉会留档见证。”

顾停舟点头。

这已经够他把该拿的那份写进账里。

阮青蜃收起笑意，转身要走。

“顾停舟。”他停了一下，“你今天拒绝的是一笔买卖，不是一场风浪。”

顾停舟看着他的背影。

“那就等风浪到了再算。”

阮青蜃没有再回头，带着人出了开炉场。

场里静了片刻。

唐绾把手上的黑灰擦在布巾上，瞥了顾停舟一眼。

“你刚才差点把楔子再压裂。”

“没裂。”

“运气好。”

顾停舟笑了一下：“那也是我的运气。”

唐绾懒得理他，转身去收炉里的潮片。

就在这时，开炉场另一侧有人走了进来。

来人穿着深青短袍，腰间没有挂旧主家的令牌，只带着一枚普通铜牌。他看见顾停舟，先看了一眼他嘴角那点没擦干净的血，眉头皱了皱。

“还站得住吗？”

顾停舟认得这声音。

“少东家。”

对方脚步一顿。

顾停舟又道：“不对。现在该怎么叫？”

少东家看着他，半晌才笑了一下。

“名字。”

“那就说事。”

少东家点头，从怀里拿出一张短契。

“旧关缺粮。下一次十二日地潮前，第一批货得送过去。”

“我这边缺一个能跑砺骨部水路的人。不是让你回去听令，是找你承运。”

顾停舟没有伸手接。

“价钱。”

“每趟固定八十潮铢，先付一半。”少东家道，“货损按出仓和到关的实数算。遇地潮封路，能撤就撤，撤回来的货不算你违约。你负责带路、押运和临场改道，货不是你的，回潮楔也不是我的。”

顾停舟看着他。

少东家继续道：“第一批货到了，后面的路你接不接，另谈。”

这不是召回。

也不是一句旧情，要他再替人把麻烦扛过去。

是一张写着报酬、责任和退路的合作短契。

顾停舟伸手接过来，逐字看完。

“个人矿利不动。”他说。

“不动。”

“回潮楔我自己用。”

“你自己用。”

“路上出了要命的事，我先保命。”

少东家看着他：“契上写了。”

顾停舟这才抬头。

他想起以前替对方跑事时，很多话根本不用说。因为说了也没用。上头一句交代，底下的人就得把命和路一起填进去。

现在不一样。

他可以把话写在前面。

也可以在签下去之前，告诉对方自己要什么。

顾停舟咬破指尖，在短契末尾按下血印。

少东家也按了印。

短契合上时，外面传来车轮声。

第一批粮车已经在百炉会外等着。

唐绾抱着收好的潮片，从炉边抬头：“你的楔子残压没散完。”

顾停舟把短契收进怀里。

“我知道。”

“路上别逞强。”

“我也知道。”

唐绾看着他，像是还有句话想说，最后却只摆了摆手。

“那就滚吧。别把我修的东西又弄裂了。”

顾停舟出了开炉场。

夜里的风从百炉会外吹进来，带着粮袋和牲口的味道。几辆压得很低的粮车停在巷口，车辕上绑着旧关的木牌。

少东家已经翻身上车。

顾停舟没有再回头看百炉会的铜牌。

他攥了一下袖中的回潮楔，又摸到怀里的短契。

十二日地潮前，粮得送到旧关。

他踩上车辕，坐进第一辆粮车。

车轮滚过石路，朝城门方向驶去。
