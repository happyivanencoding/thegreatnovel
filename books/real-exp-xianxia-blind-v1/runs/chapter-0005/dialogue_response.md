# Specialist Audit

- 许砺在重击逼近时说“刀背软了。现在它会把力转开。”，信息准确，但在车和人仍在受击的瞬间略像把机制写给读者看的说明；他的声音更适合先给出带方向的短命令，让读者从后续动作看懂用途。
- 货主在结账处连续说明“先替他把……拖欠清了”以及“按炉场的旧账号落账，别把这笔算成另外的赏”，责任边界是必要信息，但对白有重复的账务复述，货主本来务实、划清报酬边界的声音可以更利落。
- 卸货场上的第一笔外单对白把“东边有一趟活、先看、到地方再说、路线正好经过”逐项交代，功能齐全但略像投递任务信息；让邀约更像目击者在现场试探着开口，能保留同一钩子并增强人物声音。

# Proposed Patches

## Patch 1
目标锚点：许砺处理短刃时，宁枝喊“许砺！”之后、湿布从刃口滑下之前的两句对白。
操作：replace
建议文本：
“别正撞。刀背会让，前轮继续走！”
理由：把“刀背软化后转力”的机制压成许砺在现场会说的动作指令，保留准确用途，也让宁枝和车队有明确的下一步；不改变后续定硬、挡击和保车结果。

## Patch 2
目标锚点：货主向联账人说明结算时，从“押运的结算，先替他把赤栈炉场那笔拖欠清了”到“别把这笔算成另外的赏”的连续对白。
操作：replace
建议文本：
“这趟的押运钱，先把他赤栈的旧账划掉。按旧账落，别另立赏名。”
理由：保留债务清零和结算性质这两个必要事实，去掉两次解释同一账务安排的行政腔；“划掉”“别另立赏名”更像货主在把报酬边界说清楚，也不改变炉心另行交付的结果。

## Patch 3
目标锚点：登记处门外目击者把折好的短条放到柜台边后的邀约对白。
操作：replace
建议文本：
“东边有趟活，先去看一眼，动不动手到了再说。宁师傅的车正经过——你带炉，顺路看吗？”
理由：保留第一笔外单、先看后决定和宁枝路线经过三个既定信息，但把逐项说明改成带着现场试探的口吻；邀约更像目击者刚见过许砺后的自然开口，不提前改变接单决定或赔付边界。
