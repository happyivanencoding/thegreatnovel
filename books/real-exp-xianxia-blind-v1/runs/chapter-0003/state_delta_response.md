# Proposed Persistent Canon

- 许砺仍是赤栈炉场杂役；低阶修息失败、晋升未通过，工钱仍按杂役计算，尚无公炉以外的炉位、独立炉心或接单牌。
- 短刀上的一次正式复验仍只证明：在那把刀、那种固定、那种火候和那一下力中，裂口沿标记方向重现，停止施压后停止扩展；“受力记忆”“迟滞热线”仍是工作称呼，不是已知成因或稳定能力。
- 本章对照试验证明，固定点、露出长度和落锤位置大致对齐，仍不足以让不同退回材料产生同类方向；断夹、废钉与翻转前后的车环显示，材料状态、固定方式、热处理和加载条件共同影响结果，许砺尚不能将回弹方向普遍复制。
- 许砺仍必须依靠接触记录和可控对照判断异常，且误判边界尚未缩小到可用于晋升或独立接单的程度。
- 罗青衡仍维持管事与杂役的规则关系，只允许公炉空档试验，不改变晋升、工钱或炉位，结果由许砺自负；白迟继续记录原始现象和受限结论，长期立场与制度后果未定；宁枝尚未与许砺正式认识。
- 异常短刀仍是来源和痕迹成因未明的退回器物；黑水快淬的短期用途、衡炉会的统一产量逻辑与现场边界问题仍有效；当前没有确认的长期敌对人物、追兵或长期伤势。右手指端麻木为本章新增状态，持续性未定。
