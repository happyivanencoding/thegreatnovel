# Specialist Audit

1. 两截断夹在前文已明确存在先后取出、相差三息，但随后写成“同时夹入冷却槽”；单个操作者的夹持动作和两件材料的冷却先后因此不清，记录条件也会失真。
2. 两段车环先被一起拖到炉台，完整的一段又被“放到一旁”，结尾却从“脚边”拖出未进火的最后一段；留样车环的位置和它是否就是未试验段没有连续落点，容易与已经试验过的车环甲混淆。
3. 前文和世界规则都要求风门不为许砺调整，结尾却写罗青衡“伸手压了压风门”；这是一个实际触碰控制件的动作，读者可能理解为改变炉火，削弱了公炉边界。

# Proposed Patches

## Patch 1
目标锚点：
“只在白迟报出‘同一轮火、前后相差三息’后，把它们同时夹入冷却槽。”
操作：replace
建议文本：
“只在白迟报出‘同一轮火、前后相差三息’后，按取出的先后把两截铁料依次夹入同一槽水里，并把这三息间隔记下。”
理由：
把实际可执行的先后动作写清，同时保留同一轮火、同一冷却槽这一可比条件，避免“同时”与前文的先后顺序冲突。

## Patch 2
目标锚点：
“许砺把最后一段车环从脚边拖出来。它还没有进火，表面沾着箱底的灰。”
操作：replace
建议文本：
“许砺把那段完整的、一直没有进火的车环从炉台边上拖出来。它还没有进火，表面沾着箱底的灰。”
理由：
明确结尾取出的是此前放到一旁的留样，而不是已经试验过的车环甲；“炉台边上”也承接了两段车环被拖到炉台后的空间位置，让下一章保留材料的因果落点稳定。

## Patch 3
目标锚点：
“罗青衡伸手压了压风门，没有为他调火，只让旁边的人先把炉台边的热料移开。”
操作：replace
建议文本：
“罗青衡的手停在风门旁，没有碰它，只让旁边的人先把炉台边的热料移开。”
理由：
保留罗青衡清理炉台、维持边界的动作，但去掉会被读成调节风门的实际触碰，使公炉火候仍由炉场工作决定。
