# Specialist Audit

1. 冷却动作没有明确说明车环内弧和叠接处如何先接触冷却水，但后面的记录直接下了“内弧与叠接处先冷、外弧后冷”的结论，动作与观察之间缺少空间落点。
2. 木桩上环体的受击面、许砺的落锤站位和炉钳的接续没有完全对齐；“走到木桩另一侧”不能明确保证锤头先落在叠接边外侧离旧裂口一指的位置，且锤停在半空后如何腾手取炉钳未交代。
3. 正文先写裂口在取下叠件时仍扩大，随后记录却写成“受力停止后未继续扩展”，没有记录炉钳收紧这一动作对裂损停止的影响。

# Proposed Patches

## Patch 1
目标锚点：
“他让断夹一侧先入水，车环外弧留在水面上方……”

操作：replace

建议文本：
“他把炉钳往里转，让断夹压住的车环内弧和叠接处先沉进水里，外弧仍留在水面上方；等内弧的红色退尽，才放低炉钳，让外弧最后冷下来。”

理由：
把“断夹一侧先入水”具体落实为内弧、叠接处和外弧的相对位置，使后面的冷却记录由可见动作推出，不改变冷却顺序或结果。

## Patch 2
目标锚点：
“许砺走到木桩另一侧，左手握住铁锤。右手没有去扶桩，也没有碰叠件。炉钳被他横放在地上，钳口朝向环边，随时可以在锤下之后把东西压住。”

操作：replace

建议文本：
“许砺沿木桩转到叠接边外侧，让外弧上离旧裂口一指的受击点正对自己。左手握住铁锤，右手不扶桩，也不碰叠件；炉钳搁在左脚边，钳口朝向环边。锤头落下后，他先放开铁锤，再用左手拾起炉钳压住回弹。”

理由：
明确落锤方向、受击点与站位的关系，并补上单手落锤后接炉钳的动作链；受击位置、一次落锤和后续裂损均保持不变。

## Patch 3
目标锚点：
从“白迟问：‘受力停止后，裂损停止？’”至白迟记录“受力停止后未继续扩展”。

操作：replace

建议文本：
“白迟问：‘锤头停下后，裂缝还长了一段？’

许砺看着裂口，没有用手去摸。

‘叠件还在回弹。等它停了，才没再长。’

白迟写下：‘受击位置为叠接边外侧，离断夹旧裂口一指；铁锤一次落下，断夹先塌，车环承住并传力，木桩仅留浅痕；锤头回弹后，裂口由旧裂口旁起，沿车环内弧暗线扩展，叠接边压扁；叠件停止回弹、炉钳收紧后，裂缝未再继续扩展。’”

理由：
让记录如实包含“回弹期间继续扩展”和“炉钳收紧后停止”两个可见阶段，避免把已经写出的裂损过程压成相反结论，不增加第二次受击或改变一次性失效结果。
