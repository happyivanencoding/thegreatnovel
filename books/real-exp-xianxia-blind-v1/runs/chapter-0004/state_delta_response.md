# Proposed Active Scene State

- 赤栈炉场门口，次日天刚透亮；押运车已经停下，随队出发在即。
- 许砺、宁枝、罗青衡和押运队成员在场；宁枝已点名让许砺随队，白迟没有出现在本次收尾场面中。
- 许砺右手食指和中指指端仍持续麻木，精细夹持不可靠；落锤回弹又使左臂发麻，恢复情况未定；没有明确出血或重伤。
- 许砺携带用旧布包住的“回火环”，并有炉钳；回火环已在一次受击后沿完整车环内弧暗线裂损，但仍套得住木桩，尚未被再次使用。
- 无明确敌人或追兵。
- 押运车即将出发；罗青衡只允许许砺带一件器物去看现场，不替第二次使用或未来接单担保。
- 许砺的直接目标是随宁枝押运队离开炉场、按约查看炉料和现场；携带并记录回火环在实际受力环境中的表现，不把它当作能承受第二击的器物。

# Proposed Persistent Canon

- 许砺仍是赤栈炉场杂役；低阶修息失败、晋升未通过，工钱和炉位照旧，尚无独立炉心、公炉以外的炉位或接单资格。
- 在受限公炉条件下，许砺已证明可以把受过一次力的断夹与未入火的完整车环叠接，通过先让断夹软化贴合、让车环保住弧度，并按内弧与叠接处先冷、外弧后冷，做出只能替人挡住一锤的“回火环”；这不证明该方法可普遍复制，也不证明器物能承受第二击。
- 回火环的实测结果是：断夹先塌，车环承住并传力；锤头回弹后，裂口从断夹旧裂口旁沿车环内弧暗线扩展，叠件停止回弹并被炉钳收紧后没有继续扩展。两种退回材料只是暂时共同承力，没有因此变成稳定的好铁。
- 材料状态、固定方式、热处理、冷却顺序和加载条件共同影响回弹与裂损；许砺仍不能把一次结果当作普遍能力。
- 许砺右手指端麻木持续性未定，暂时不能依靠裸手进行精细试压；尚无确认的长期重伤。
- 罗青衡仍维持管事与杂役的规则关系，但允许许砺带一件回火环随押运队看现场；这不改变晋升、工钱、炉位或未来接单责任。白迟继续记录原始现象，并已将该器物命名为“回火环”；其制度立场与后果仍未定。宁枝已与许砺正式见面，并因押运队需要懂炉料的人点名让他随队，长期合作尚未建立。
- 异常短刀的来源及粗砂反复拖磨的痕迹仍未明；黑水快淬、衡炉会的统一产量逻辑与现场边界问题仍有效；目前没有确认的长期敌对人物或追兵。

# Proposed Chapter Summary

换档前，右手指端麻木的许砺用炉钳将受过一次力的断夹与未入火的完整车环叠接，按内弧与叠接处先冷、外弧后冷制成“回火环”；他让回火环在木桩上承受一锤，断夹先塌、车环传力，随后裂口沿暗线扩展而未再继续长。罗青衡仍保留他的杂役身份，却允许他把这件只能有用一次的器物带去次日押运；宁枝点名许砺随队，回火环随他离开炉场。

# Proposed Open Promises

- 短刀为何留下被粗砂反复拖过、平得不自然的痕迹；这是否就是与黑砂相同的被抹平痕迹？
- 黑水快淬由谁推广，衡炉会为何容许它存在？
- 许砺能否在不依赖公炉的情况下承担赔付和燃料成本？
- 宁枝与许砺能否从这次押运开始，建立不以单次救命或单次任用为基础的长期合作？
- 白迟会在制度内继续站在哪一边，并如何承担早期报告的后果？
- 齐湛的统一标准如何在不被摧毁的情况下接受现场差异？
- 母火与天衡旧炉的“保留/释放”问题，最终会要求许砺牺牲什么？
- 随押运队进入现场后，许砺能否在不越过杂役边界的前提下看清炉料问题，并确认回火环一次性承力的实际用途与失效边界？
