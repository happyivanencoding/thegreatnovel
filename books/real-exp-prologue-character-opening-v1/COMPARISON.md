# 结构比较：可选序章 → 人物型第一章

比较对象：冻结的 Hybrid Chapter 1 `books/real-exp-curator-primary-longform-v1/candidate-b/chapters/chapter-0001.md`，以及本目录的新 `PROLOGUE.md` + `chapter-0001.md`。

## 1. 世界认知与人物认知的分离

冻结 Hybrid Chapter 1 在同一正文里依次承担了炉火 / 灵脉生存逻辑、玄烬仙宗与封炉秩序、黑炉镇处境、沈燧的漏空炉体、矿道空间、伤员搬运、断镐残响、开出生路和废窟钩子。它的开头先用世界模型说明，再把主角和矿难行动接进来。

新版把宏观任务移到 `PROLOGUE.md`：从灵脉和炉火的具体后果，收束到玄烬仙宗、封炉令、黑炉镇，并停在“三天后封炉”。新版 `chapter-0001.md` 假定序章已读，从塌方现场直接进入沈燧、伤者、主井和旧风道的问题；世界信息只在封炉阵、裴照川和当前行动需要处局部出现。

这确实把“世界模型建立”和“人物 / 能力 / 当前事件”拆成了两个阅读阶段；它不是删掉世界介绍，而是改变世界介绍出现的位置。

## 2. 新 Chapter 1 与冻结 Hybrid Chapter 1 的结构差异

- 新版更早进入具体动作：塌方、救伤者、确认主井 / 符火 / 常规灵力无效，然后才拾起断镐。
- 新版把能力理解压到一个可操作的最小层级：断镐没有恢复，沈燧只是接到“还没有用完的一下”，把镐尖送进封死矿壁；原理和来源没有提前解释。
- 新版详细展开选择、风险、三息窗口、人员通过、掌心黑铁锋片、矿工反馈和裴照川回收反应；普通搬运和重复工程过程被压缩。
- 新版在开出生路后给出短暂落点：被困者活着到达旧风道尽头，矿工开始按沈燧手势行动，沈燧确认这一次锋力已耗尽；随后才进入被封存的废弃炼器窟。
- 新版正文为 4822 字符；冻结 Hybrid Chapter 1 为 5475 字符。序章另有 1867 字符，因此这是“分离认知任务”的结构实验，不是总字数缩减实验。

## 3. 第一次能力是否仍完整兑现

是。新版 Chapter 1 仍然在本章内完成：断镐残响明确指向“凿开一条让人活着出去的路” → 沈燧承受并把这一下送入矿壁 → 矿壁裂开、石梁被顶住三息 → 矿工与伤者实际撤出 → 断镐不成为完整道器，只留下黑铁锋片和身体损伤。

因此没有退化为“只发现能力”“只感知残响”“准备尝试”或“第二章才第一次兑现”。

在本次受控结构检查中，没有发现新的明显退化：没有 Chapter 2—10，没有裂路器提前完成，没有废窟体系或古战场提前展开，正式正文没有混入 Writer Audit / 事实摘要，也没有修改冻结故事事实的主要结果。
