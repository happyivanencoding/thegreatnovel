# RESULTS｜Power Ruler Held-out Validation

日期：2026-09-03

## Verdict

**有效 Story-level held-out：3/3 PASS；Atlantis 旧失败 0/3 复现。**

第三个空间世界第一次并行 Sol-high Story Program 会话超过约 30 分钟仍未返回，因此该次调用本身按实验纪律记为 transport-invalid；随后使用**完全相同的冻结 Prompt、同一 Sol-high、同一 effort 与同一 GBrain 输入**原样重试，752.729 秒成功返回，并继续由 Luna-high Outline 编译通过。没有换模型、降 reasoning、关 GBrain 或改 Prompt 凑结果。

本轮没有发现需要继续修改 production 的新根因。当前修复已跨三种完全不同的力量语法真正改变 Story Program 对大幅越级的规划方式：**高阶主尺基础盘继续存在；开局单一 Asymmetry 可以极强地拿走一个局部结果，但不能自动升级成跨明显大档完整击败；完整越级幅度随着主尺、异常掌握、新优势和 compound 历史扩大。**

## A｜血肉近战武道：PASS

### World / Ruler

公开主尺为 `炉级1—100`，当前可见到 72；炉级真实承载五个基础盘：爆发力量、身体承受、反应速度、持续作战、危险环境进入。World 明确说炉级不是把技巧/兵器/偷袭折算进去的总战力分，但给出可复用 benchmark，例如炉级12能折断厚木盾并持续作战，炉级25能承受普通兵器正面劈砍，炉级40能在逆风峡保持战斗。

结论：`Ruler Credibility = PASS`。

### Power / Ruler Coupling

固定采用 Candidate 1：`贴障穿行`。

它给的是高炉级强者也没有的“实体障碍直接变成通路”特权，但 Power Seed 明确保留：

> 炉级仍决定身体能承受的速度、压力和危险环境；穿行不会抹掉当前炉级在力量、速度、承受和持续作战上的差距。

结论：`Ruler Coupling = PASS`。

### Opening Upset Width

压力测试故意极端：`炉级0` 主角第一次稳定穿行后，立刻被 `炉级40` 军士发现。

Story Program 的 RSE-01 没有让他赢：他穿过骨盾和相邻店墙逃走；到了没有连续实体可贴的巷口，立刻挨中高阶者一击，只带着自己的钱和暗红护风短褂逃生。State residue 明确保留“仍是炉级0”“开阔地重新落回真实身体差距”。

后续越级曲线也没有坍缩：

- `炉级17 vs 27`：穿墙夺回短槊后完成**局部翻盘**，不恋战；
- `炉级41 vs 55`：已经拥有长期修炼 + 更成熟穿行 + 白响心骨感知 + 响背刀承受硬碰后，仍是多次受创；最终赢的是关口与封路骨印，不要求在开阔地正面打死炉级55。

Story Program 自己总结：到炉级41时三项优势复合，才能让炉级55“失去关口”，**而不是凭一种局部克制抹掉十四级差距**。

Outline 没有运输退化。第1章 Reader Release 直接写“炉级0与炉级40之间存在真实身体差距”；第1章实际计划仍是无障碍巷口挨中一击后逃生。

结论：`Opening Upset Width = PASS`；`Story → Outline Preservation = PASS`。

### Power Identity

Core 始终是 `贴障穿行`，没有被后续兵器拆成技能包。`响背刀`被明确写成外部兵器，不是身体的一部分；`白响心骨`是一个外部高价值器物，它与穿行形成“先摸到实体震动 → 再选择出口”的新复合。Story 有一处把白响心骨称作“新的非对称优势”，但同时始终保留其具体器物身份和所有权，没有把它伪装成主角天生器官/技能。

结论：`Power Identity = PASS`，但记录一个轻微表述观察：以后 State 若实际生成，应继续检查外部器物所有权是否稳定留在 Tracked Assets，而不是只看 Story Program 规划层。

## B｜浮空群岛驭兽：PASS

### World / Ruler

公开主尺为 `风阶·大境界1—9重`：引息 → 合鸣 → 御风 → 穿层 → 裂空 → 镇岛，共 54 个当前公开位置。

风阶真实承载：灵息总量、人与伙伴双方身体承载、反应速度、同步距离、共鸣持续时间和可进入风层。World 直接写明：技法、装备、伙伴习性、地形可造成越级/失手/逃脱/局部翻盘，**但不能凭一种特殊相性自动抹掉更高大档位在体魄、速度、持续和环境承受上的全部优势**。

结论：`Ruler Credibility = PASS`。

### Power / Ruler Coupling

固定采用 Candidate 1：`险瞬先见`。

持有者能提前看见自己或伙伴即将遭遇的一个致命瞬间。它可以让高阶者的关键一击落空，但 Power Seed 明确：当前速度、灵息输出、身体承载和风层适应仍由风阶决定，不能靠一次预见抹掉高阶者的持续压制。

结论：`Ruler Coupling = PASS`。

### Opening Upset Width

这是本轮最强证据。

开局主角 `风阶·引息2重`，对手韩铁衣 `风阶·御风6重`，相差**两个完整大档**。Story Program 的 RSE-01 直接写：

> 陆砚川没有击败高出两个大档的韩铁衣，只从原本必中的第一击下夺得逃生窗口。

具体动作是：提前看见致命一击 → 把青砾推入折帆 → 斩断舟索 → 韩铁衣杀招击空，反而替他们割开最后一道系索 → 旧风舟坠入上涌气流逃生。

这不是把爽点削掉：一个引息2重少年让御风6重强者势在必中的杀招落空，本身就是极强 Public Proof；但主尺没有死亡。

长期越级曲线非常清楚：

- 引息2重 vs 御风6重：只让第一击落空并逃生；
- 合鸣4重 vs 合鸣8重：通过真实训练、伙伴成长和赛道崩裂，在比赛结果上反超；
- 御风6重：取得遥鸣法并与险瞬先见复合后，第一次完整正面击败**同为御风6重**的韩铁衣；
- 穿层8重 vs 裂空3重：面对更高大档的区域压制，仍只夺走逆风帆骨并逃生；
- 镇岛1重 vs 镇岛3重：长期 compound 后，可以拿走决定两岛去留的结果，但 Story 明确镇岛3重仍拥有更强总量、身体承载与持续压制，主角没有完整击败对方。

Outline 完整保留这一结构。前十章成长表第一条就是“引息2重，只能让御风6重韩铁衣第一击落空并逃生”；第1章叙事功能明确“高阶差距仍然存在”。

结论：`Opening Upset Width = PASS`；`Upset Width is Progression = STRONG PASS`；`Story → Outline Preservation = PASS`。

### Power Identity / Asset Separation

`险瞬先见`始终只看一个危险瞬间，没有后期偷升级成全知未来。新的 `遥鸣法` 是人与青砾的稀有远距共鸣特权；两者复合后才形成“分处两地同步抢位”。

Story Program 特别明确：`照羽号、浮岩锚芯、逆风帆骨`始终是外部资产，不混入陆砚川自身能力；青砾也始终保有自己的身体、伤势、食欲和拒绝权。

结论：`Power Identity = PASS`；`External Asset Separation = STRONG PASS`。

## C｜折叠空间术：PASS

### World / Ruler

公开主尺 `折距1—100级`，当前可见到72。基础盘包括作用距离、质量、连续使用次数、持续时间与身体承受；高档位还决定能否进入危险夹层。

World 主动写明：

> 一次克制只能改变它实际克制的部分，不能凭空抹掉高阶者的速度、体力、作用范围和深层承受。

甚至对预注册的开局“新人撞上40级以上城关者”直接给出合法结果边界：可以夺物、局部翻盘、逼退或逃生，不能自动抹除高阶基础盘。

结论：`Ruler Credibility = PASS`。

### Power / Power Identity

固定采用 Candidate 1：`错后成路`。

持有者亲自做一次空间动作失败、并真正学会其中一个关键点后，可以把这一个正确环节永久留在身体里。折距级仍决定距离、质量、次数、持续和身体风险。

这是本轮最适合测“技能背包”的样本，而 Power Seed 自然形成了正确的统一语法：

> 不同失败留下的关键点，会自然形成一套个人折法语法。

也就是说积累的是同一棵能力树中的“正确环节”，不是失败一次就多一个无关技能。High-Tier 仍是把越来越多自己真正走过的危险折路变成个人路线，没有新增第二套公开力量系统。

结论：`Ruler Coupling = PASS`；`Power Identity = STRONG PASS`。

### Story / Opening Upset Width

开局压力测试比另外两本还极端：`折距1级` 主角祁砚声撞上 `折距47级` 封离。

Story Program 没有把“失败后保留正确落点”升级成越46级击杀。具体处理是：第一次强折整辆甜食车失败并摸到一个正确车轴落点 → 第二次只复用这一点，把车尾折过错门 → 从折距47级封离的封锁中带走青釉雨碟和旧路线铜签并逃生。Growth spine 直接说明：他只能改变一个车轴落点，**不能带人硬抗折距47级的连续封锁**；阶段1则明确“不与折距47级的封离硬拼”。

中期越级也保持“结果域”而不是等级失效：

- `折距9 vs 14`：在百门竞折这种复杂路线比赛里获胜，Story 明确“胜的是复杂路线而非等级基础盘”，不等于正面承受对方速度、体力和质量优势；
- 封离学会后不断改变落点，折距47级的速度、范围和持续真实压回主角，主角因此**失去阻止焚卷和当场清算封离的机会**；
- `折距57 vs 64`：此时主角已经进入同一最高公开大档，拥有多年累积的个人折路、空窗石、空鳞兽、定界钉等复合，才在连续压制下夺得城心祖钉并逼退对手。Story 明确总结：胜负来自“同档基础盘 + 历次失败积累 + 奇物 + 伴生关系 + 现场落点”，不由单一克制抹掉七级基础差。

结论：`Opening Upset Width = PASS`；`Upset Width is Progression = STRONG PASS`。

### Story 保住了统一 Power Identity

Story Program 没有把每次失败留下的正确点列成互不相关技能，而是把它们持续组织为：

- 单个落点修正；
- 两三个正确环节串联；
- 一条短路线；
- 不同地点、不同时间积成的“个人折路”。

空窗石、定界钉被明确写成“不是他自身的新能力”；空鳞兽也不是技能按钮，而是有自己行为的伴生关系。最终形成的是 `错后成路 × 个人折路 × 外部奇物 × 伴生关系`，而不是技能背包。

Outline 继续完整保留：第1章仍是 `折距1 vs 47` 夺物逃生，并专门写“建立折距1级对折距47级的基础盘差距”；`折距9 vs14` 仍强调不正面拼基础盘；`57 vs64` 才在同一大档复合夺钉。

结论：`Power Identity = STRONG PASS`；`Story → Outline Preservation = PASS`。

### Transport 注记

第一次三路并行的 Sol-high Story 会话超过约30分钟无 Response，被停止并保留为 invalid provenance。随后在其它并行 Story 已结束后，使用**完全相同**的 C Story Prompt / Sol-high / effort / GBrain 输入原样重试，752.729 秒成功；因此该次结果可用于语义判定。这个现象只说明 execution transport / queue 仍可能出现长尾，不改变本次力量语义结论。

## Cross-case conclusion

旧 Atlantis failure 是：`潮阶1 + 一个刚获得的局部静默克制 → 完整击败潮阶8`，从而让公共主尺失去可信度。

本轮三个完整 held-out 都主动给了比 Atlantis 更极端/更清晰的压力：

- 武道：`炉级0 vs 炉级40` → 穿墙、穿盾、带物逃生，但无墙处立刻挨打；
- 驭兽：`引息2重 vs 御风6重（跨两个大档）` → 让必杀第一击落空并逃生，明确没有击败对方；
- 空间：`折距1 vs 折距47` → 用一次失败留下的车轴修正夺物逃生，不回头交战；后续 `9 vs14` 只在复杂路线比赛赢，直到 `57 vs64` 同属最高公开大档并叠加多年个人折路/奇物/伴生关系，才夺钉逼退。

三本都允许越级幅度随着历史扩大：先局部结果，后在更接近的公开位置取得完整胜利或更重结果，再在高阶对手面前凭 compound 争夺越来越重的“结果”，而不是用第一章同一个克制不断无视等级。

**因此本轮结论为：3/3 PASS。** 目前没有证据要求再修改 production。继续加新 Prompt 条款反而会把一个已经工作的深层原则变成过度治理。

## What This Did Not Solve

- 本轮验证到 Story Program + Outline，没有继续生成 Batch prose / State；因此“最终正文是否把这些精确差距写得足够爽”“State 是否稳定分开外部资产与 intrinsic Power”仍未被本实验直接证明。
- C 第一次并行 Sol Story 调用出现 >30min 无返回、同输入单独重试正常完成的长尾；这是 execution transport / queue 的独立观察，不应混进本次力量架构结论。
- Candidate 1 是预注册固定选择，用于防 cherry-pick；这验证的是 production distribution 的三个随机切片，不代表每个候选都同样好。
- 本轮只验证这次 ruler/upset/power-identity 修复，不评价三本书整体文学质量是否已经达到顶级男频。
