# Power Ruler Held-out Validation — 2026-09-03

目的：在亚特兰蒂斯之外，用 3 个力量语法明显不同的全新世界验证当前 production 的：

- Reader Ruler ≠ Battle Formula ≠ Decorative Number
- Ruler Coupling
- Upset Width is Progression
- Power Identity beats Skill Inventory

## 预注册样本

### A｜血肉近战武道
主流力量必须来自身体、呼吸、血骨与近战兵器；不以法术、召唤、空间术或抽象规则为主。公共主尺必须真实改变输出、身体承受、反应、持续作战与危险环境进入能力。

### B｜浮空群岛驭兽
主流力量来自人与伴生兽/契兽的真实共鸣与共同作战；个人可以修炼，但不能把伙伴降成技能按钮。公共主尺必须真实改变共享强度、骑乘/承载、反应、作用距离/持续与可进入风层。

### C｜折叠空间术
主流力量是直接的移动、置换、折叠距离与空间切割；不以驭兽、纯体修或概念/定义/权限解释为主。公共主尺必须真实改变可作用质量、距离、连续使用、身体承受与可进入折叠层。

三个样本都要求开局较早出现一次：主角刚获得 Core Asymmetry 后，与公开主尺上明显更高一档/大档人物发生真实冲突。**不规定主角必须赢**，让 Story Program 自行决定完整胜利、局部翻盘、夺物、逃生、逼退或失败。

## 选择规则

为避免 cherry-pick：

- Premise Forge 显式跳过；
- World 使用 current production World prompt；
- Power / Human 都使用 current production candidate prompt；
- 三个样本都**确定性采用 Candidate 1**，不看输出后再挑；
- Story Program 使用 Sol-high current production prompt；
- Outline 使用 Luna-high current production prompt；
- GBrain 按当前 production 路由启用。

## 判定

### Ruler Credibility
PASS：World 的主尺不只是数字，至少有少量可复用基础盘；Story 没把单一克制自动解释成所有基础盘失效。

### Ruler Coupling
PASS：Power 能清楚说明主尺负责什么、Asymmetry 改变什么；能力输出/承载与主尺存在真实关系。

### Opening Upset Width
PASS：若对手跨明显大档，单一新能力最多先造成局部翻盘/失手/夺物/逃生/逼退；完整大幅越级必须已有多重独立因果。若只高少量位置，允许直接取胜。

### Power Identity
PASS：累积型 Core 能保持统一能力家族；非累积型不被硬造槽位。外部装备所有权不冒充人物自身 Power Identity。

### 总结等级
- PASS：目标原则稳定成立。
- PARTIAL：主原则成立，但输出仍有可见漂移。
- FAIL：再次出现“单一新克制 → 跨明显大档完整击败”或公共主尺仍只是装饰数字。
