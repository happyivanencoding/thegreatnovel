# 小说总体设计画像

批准状态：World Vision、Character Authority、Story Program 均已由作者明确批准。本 Outline 只负责执行编译，不把计划内容写成 Canon，不静默改写已批准产物。

## 0. 本书成长基因图

### 已批准幻想不变量

陆闻野拥有“贴障穿行”：实体墙、牢门、岩层、盾牌与封闭结构，只要亲手接触，就可能成为通路。炉级仍决定力量、速度、承受、持续作战和危险环境适应，贴障穿行不抹平正面实力差距。

### 已批准长期成长兑现

- 开局：炉级0，稳定穿过锁死仓房、骨盾与店墙，先获得进入和逃生特权。
- 前期：正常修炼至炉级6，再至炉级17；穿行从薄墙脱困发展为战斗中的夺物和出入。
- 中期：获得响背刀，以兵器承受穿出后的硬碰。
- 随后：获得白响心骨，能够隔着连续实体感知脚步、冲撞与裂纹，减少盲穿。
- 当前 Horizon 末段：炉级41，能贴峡壁改变一次方向并连续选择出口，三项优势复合后夺取回骨峡关口。
- 更高阶段：继续发展为城墙、山腹和地下岩层之间的立体近战路径，永久边界仍然有效。

### 已批准长期后果

暗红护风短褂、响背刀、白响心骨、压风车、回骨峡收益、陆禾的独立选择、林鸦与闻行的兵器和身份变化，都会在后续改变陆闻野的价格、去留、关系与行动入口。

### 核心不变量

- 墙不是墙，封闭处可以成为主角的路。
- 主角的优势持续复利，并与炉级、兵器、感知和身份复合。
- 钱、自由、即时享受与妹妹之间始终存在真实取舍。

### 退化风险

- 把贴障穿行写成普通战斗瞬移，抹掉炉级差距。
- 把世界冲突降成资源协调、流程管理或主角替各方收拾残局。
- 把已批准的具体奖励降格成资格、记录或责任结算。

## 1. 核心类型与读者承诺

成熟中文男频玄幻成长长篇。读者首先获得炉级0的穷小子把墙、牢门和封锁变成道路的直接爽感，再看到他用钱、修炼、兵器、异物和关系，把这种通行特权变成真正属于自己的生活与远方。

### 不可降格 Reader-Facing Story Event Registry

#### RSE-01

事件原子：陆闻野用路资买回暗红护风短褂 → 赤梁军府突查贺真槐的装车场并锁死后仓 → 炉级0的陆闻野在墙前第一次稳定贴障穿行 → 被炉级40军士发现后，他穿过骨盾和相邻店墙逃走，却在没有实体可贴的巷口挨中一击，仍把短褂和自己的钱带走。

状态残留：陆闻野确认实体障碍可以成为通路，军府与贺真槐各有少数人见过异常；他仍是炉级0，且已经知道开阔地会让自己重新落回真实身体差距。该状态不能替代上面的第一次穿墙、第一次被追和带着短褂逃走的现场。

排程边界：开书前段，阶段1内由 Outline 排章。

读者证明锚点：暗红护风短褂；炉级0；炉级40；赤梁军府；骨盾

#### RSE-02

事件原子：无鞘短槊登上三击试台 → 闻行以自己的名字持槊承受三次公开重击 → 第三击恰逢回骨峡方向逆风，短槊发出不应存在的回响却没有断裂 → 军府亲兵当场夺槊时，炉级17的陆闻野穿过试台骨墙和对方厚盾夺回短槊，在炉级27的追击下完成局部翻盘。

状态残留：无鞘短槊取得正式三击印，闻行以本人名义获得锻盟徒位，陆沉槌的“偷料失败品”定论被公开动摇；陆闻野仍是炉级17，没有因越级夺物自动升级。该状态不能替代三击、异常回响、夺槊与全场重新估价的现场。

排程边界：阶段4内由 Outline 排章。

读者证明锚点：无鞘短槊；三击试台；炉级17；炉级27；三击印；逆风回响

#### RSE-03

事件原子：踏髓兽迁徙踏开白响滩 → 陆闻野明知家中旧汤摊的冬货会被踩毁，仍继续争夺一块能把远处脚步与撞击传到掌心的完整白响心骨 → 他在闻行与猎队夹击前从封闭滩骨中将它亲手取出 → 随后第一次把心骨按在岩层上，先摸清兽群落脚，再选择出口穿出。

状态残留：白响心骨归陆闻野所有并可持续使用；陆家旧汤摊和冬货被兽群毁掉，母亲与陆禾都知道他这次先选了自己的高价值机会。该状态不能替代他在可回头时没有回头、亲手夺骨以及第一次“先听后穿”的现场。

排程边界：阶段5内由 Outline 排章。

读者证明锚点：白响滩；踏髓兽；白响心骨；陆家汤摊

#### RSE-04

事件原子：曹徙拆尽回骨峡旧骨桩并以炉级55镇守无掩体关场 → 炉级41的陆闻野放弃抢救自己入股的前车，贴住峡壁进入关体 → 借白响心骨摸到曹徙的追击落点，以响背刀连续从不同位置穿出，夺走封路骨印并破坏关门楔 → 曹徙没有在正面力量上被抹平，却在所有军士、商队与锻盟见证下失去自己声称绝不可能被通过的关口。

状态残留：回骨峡不再由曹徙个人封锁，曹徙失去守关职位；陆闻野公开位置为炉级41，并以低于炉级55的身体基础赢下关口结果而非虚构成正面碾压。该状态不能替代他舍弃前车、进入关体、连续穿出与当众夺印的现场。

排程边界：当前 World Horizon 最终阶段内由 Outline 排章。

读者证明锚点：回骨峡；炉级41；炉级55；响背刀；封路骨印；关门楔

## 2. 世界观结构

炉息来自骨风、食物、呼吸、血肉与骨髓，最终通过身体、贴身兵器或直接接触释放。炉级是连续数字主尺，真实影响爆发、承受、反应、持续作战和环境承受；炉级0不是修炼者位置，当前主角从炉级0开始。

故事前期集中在断梁城、回骨峡、黑脊窟与白响滩。军府控制驿路和封锁，背井商盟控制跨聚落运输，三击锻盟控制高品质兵器认证，食风部掌握荒原路线与兽迁消息。

### Reader Release Map

- 第1章｜触发：炉息由骨风、呼吸、血肉和骨髓承载；炉级是记录身体爆发、承受、反应、持续作战和环境承受的精确尺度，炉级0与炉级40之间存在真实身体差距。
- 第1章｜触发：骨风会造成肺部出血和骨节错位，居民出城需携带压风石、止血骨粉等护风用品；赤梁军府通过红梁旗和骨桩标记危险道路与封锁范围。
- 第2章｜触发：普通人通常通过息院、军府/猎队/护运队，或锻盟、骨医馆、商队改变身份与生活。
- 第5章｜触发：低炉级者通常不能独行穿过逆风峡和兽迁地，离开聚落需要跟随商队、猎队或军府驿路。
- 第8章｜触发：回骨峡正午会改变风向，旧骨桩标出相对安全落脚处，军府拆除骨桩会直接改变车队的可通行范围。

## 3. 世界如何持续制造剧情压力

军府、商盟、锻盟与食风部拥有不同利益，不会围绕主角自动合流。回骨峡旧路、白响骨、三击试、踏髓兽迁徙与旧兵器记录会在相同时间窗口发生碰撞。

世界压力主要来自力量差、危险地形、公开身份、稀缺资源、异兽迁徙和人物各自的欲望。主角只决定自己要拿什么、保什么、放弃什么，不负责协调车队、军府、锻盟或聚落的整体利益。

## 4. 主角模型、人物弧与核心矛盾

陆闻野想把自己从穷日子里买出来：攒钱、吃好东西、穿回暗红短褂、离开山坳，拥有不必听母亲安排的小摊与远方。

他舍不得陆禾，却不愿把自己的远方永久折成妹妹的路资。他会在具体现场为她改计划，但不会把“为家人牺牲”当成统一答案。

贴障穿行最先把他送到锁起来的钱、货、兵器和秘密面前，放大他“先抓住眼前能摸到的收益”的性格。长期矛盾是：他究竟能否把钱、路线、资产和力量变成自己的生活，而不是换一种长期服役。

## 5. 配角与关系系统

- 陆禾：想进入息院，不接受哥哥替她决定牺牲什么。她会收下帮助，也会拒绝被供养和安排。
- 母亲：把陆闻野视为摊子的半个主人，习惯把愿望折算成账目。她既依赖他，也会因他的选择重新估价他。
- 贺真槐：想保住车队、房产和运输路线。对陆闻野既有现实利用，也有必须重新定价的利益关系。
- 林鸦：想让无鞘短槊通过三击试，证明自己的锻兵判断。她不会因陆闻野需要兵器就放弃自己的目标。
- 闻行：想用自己的名字取得锻盟位置，不愿只作为旧兵器和父辈记录的附属。
- 曹徙：维护军府封路权与守关职位，亲眼见过贴障穿行后会调整战术，但不会自动知道能力的全部边界。

## 6. 核心情节发动机

生活发动机是钱、自由、妹妹、母亲和离开聚落的愿望；幻想发动机是把实体阻挡变成自己的道路；世界发动机是军府、商盟、锻盟、异兽与旧记录之间的利益碰撞。

三者不平均轮换，而是在具体对象上相撞：短褂与军府突查、车队与回骨峡、短槊与三击试、白响心骨与陆家冬货、关口与主角自己的车队份额。

## 7. 叙事结构

以贴近陆闻野的有限视角为主，先写人物正在面对的具体问题，再嵌入必要的公共世界定向。力量变化通过动作结果、身体感受、旁观者反应和精确炉级校准呈现。

场景优先保留选择、抢夺、关系变化和不可逆结果；普通移动、重复修炼、登记、赔付和实施过程压缩到最低。

## 8. 文风与可操作参数

动作要有重量、接触、骨风、反震和身体承受；贴障穿行要写出“触到障碍后，封闭处突然变成道路”的具体快感。

不把能力写成抽象规则说明。每次重要使用都要回答：陆闻野想拿什么、谁阻止、他触到了什么、穿出后谁承受了什么结果。

## 9. 对话特点

陆闻野常用讨价还价、装得漫不经心和突然改口掩饰真实欲望。陆禾直接拒绝被安排，母亲把情绪折成账目，林鸦把兵器和人的选择分开，贺真槐把风险包装成价格，曹徙用军府口吻制造既成事实。

对话必须改变价格、关系、行动或下一步，不用长篇解释隐藏旧史。

## 10. 节奏结构

第一阶段先兑现贴障穿行和暗红短褂，再让外界反应改变陆闻野的出路。之后按照“获得实际资源—进入更大场景—遭遇不同类型的竞争—优势复合—公开改价”推进。

胜利优先产生净收益，代价只在真正改变选择时出现。十章批次不构成章节配额，故事块完成后立即换入下一块。

## 11. 主题、价值观与长期问题

暂不预设抽象主题。当前人物和事件自然形成的问题是：自由是否必须用放弃某些亲近之物换来；真正属于自己的东西，究竟是钱、兵器、路线、身份，还是能够决定自己下一步去哪里的能力。

## 12. 当前设计最强点与最弱点

最强点是贴障穿行拥有清晰的生活特权，并能与炉级、兵器和白响心骨形成可复述的复合优势。

最弱点是阶段中存在车队、路线、封锁等支撑性公共冲突，若处理不当会把陆闻野写成协调者；同时要避免曹徙的开阔地反制变成单纯重复“能力被克制”。

# 当前中期规划窗口

规划范围：预计第1—40章。

窗口终点：第40章完成回骨峡的局部结算、曹徙失去守关职位、贺真槐清偿车队债务、无鞘短槊取得三击印并动摇旧案定论。陆闻野达到炉级41，拥有压风车、回骨峡收益、响背刀和白响心骨，并作出第一次不依附军府或商盟安排的封岭外出发决定。最后以封岭之后的陌生近战兵器作为世界边界的可见证明，停在 World Horizon Handoff，不越过新 World Authority。

## 第1—5章：暗红短褂穿过墙

具体发生：陆闻野刚把多年路资换成暗红护风短褂，就被军府突查卷进贺真槐的封闭装车场；他必须决定是丢下刚买回的东西求生，还是把自己的钱和短褂一起带走。

1. 陆闻野先买回暗红护风短褂，赤梁军府突查装车场并锁死后仓。失败意味着路资、短褂和离开聚落的机会全部丢失。
2. 炉级0的他在墙前第一次稳定贴障穿行，从锁死后仓进入另一侧；炉级40军士追来后，他穿过骨盾和相邻店墙。
3. 巷口没有可供持续接触的实体障碍，他被军士正面击中，却没有丢下短褂和自己的钱，狼狈逃出。
4. 贺真槐以预付雇金换他跟车出发；陆闻野接受交易，把一部分钱留下作为陆禾试台费。
5. 陆禾收下报名钱，却拒绝把它当成哥哥已经替她决定的人生；陆闻野选择在她报名日前夜随车离开。

主要阅读兑现：炉级0的人把锁仓、骨盾和店墙变成道路，带着刚买回的暗红短褂从炉级40军士手里逃走。

Block Delta：

- Possession：暗红护风短褂、贺真槐预付雇金。
- Relationship：陆禾收下报名钱，但决定自己去试台。
- Enemy State：曹徙知道有人异常越过实体封锁，但只掌握可观察表现。
- Knowledge：陆闻野确认开阔地仍会让自己落回真实身体差距。

推向下一块：他已经拿到预付并选择离开，贺真槐的车队也必须在军府拆除旧骨桩前出发。

## 第6—10章：回骨峡的第一笔远方钱

具体发生：陆闻野第一次离开山坳，必须在回骨峡正午变风与军府封路之间保住自己真正想要的那一辆车和未来路资。

1. 低炉级者不能独行穿过逆风峡和兽迁地，陆闻野随贺真槐车队上路，第一次进入聚落之外的危险环境。
2. 正午风向改变，军府推下巨骨封住旧路；陆闻野不接管车队，只选择自己要保住的那辆载着尾款和药材的压风车。
3. 他贴住封路巨骨穿到另一侧，切断军府锁链，让贺真槐自己决定如何驱车；军士将他逼入没有岩壁可贴的峡心。
4. 陆闻野放弃回头抢第二辆车，带着第一辆车穿进侧壁脱离追击，第一次用封路巨骨完成真正的远途通行。
5. 车队转入黑脊窟外避风后，他用尾款购买行脚压息法、骨盐和兽髓，经过修炼与试台记录进入炉级6，并取得断梁城夜市三个月摊位和背井商盟独行牌的申请机会。

主要阅读兑现：陆闻野第一次把封路巨骨当门使用，吃到过去只能端给客人的纯髓席，并获得真正能支持修炼和摆脱穷日子的资源。

Block Delta：

- Power：炉级0→炉级6；能带贴身短兵和衣物穿过普通骨墙，但不能携人。
- Possession：尾款、行脚压息法、骨盐、兽髓、夜市摊位。
- Identity / Access：贺真槐开始允许他以钱买车队份额。
- World State：一车成功通过，曹徙无法继续宣称旧路绝对不可通。

推向下一块：兽迁逼近，黑脊窟外出现林鸦的短槊试击，车队与兵器争夺撞在一起。

## 第11—17章：黑脊窟里各拿各的

具体发生：林鸦要让无鞘短槊承受成年裂背兽的正面攻击，陆闻野却先看见了足以锻成好兵器的白响骨材，并决定把它变成自己的东西。

1. 裂背兽因踏髓兽迁徙返回黑脊窟，林鸦必须在兽离巢前完成短槊试击；贺真槐的车队被骨风堵在窟外。
2. 陆闻野从塌缝看见完整白响骨材，先穿过封闭矿层争夺它，没有因为林鸦的试炼自动让路。
3. 裂背兽第一击把短槊打入矿壁，陆闻野用自己取出的骨材提出交换：林鸦负责把其中一部分锻成他要的兵器。

- Possession：白响心骨和一批普通白响骨片归陆闻野所有。
