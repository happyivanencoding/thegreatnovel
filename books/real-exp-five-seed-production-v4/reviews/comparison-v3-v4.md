# v3 ↔ v4 Seed-only Comparison

## 证据口径

本报告只依据两轮五份 Seed 候选及各自盲审文件。以下将“第一次力量兑现”区分为：

- 第一次使用能力；
- 第一次标志性奇观；
- 盲审所列的第一次核心/主要情绪或主动兑现。

不把这些层次混为同一事件。

## 1. v4 的第一次兑现是否更自然分散

### 已观察事实

| v4 候选 | 第一次主要兑现 | 直接受益者 | 是否属于救人/公共保护 |
|---|---|---|---|
| 1《未成之身》 | 闯入藏命库，夺回妹妹被烧剩的未来页 | 主角获得完整未来；妹妹获得未来页，但尚未复活或恢复行动 | 关系性追回，不是普遍救助 |
| 2《余烬最后一式》 | 打开战死坑，夺回姐姐的火种，使其脱离被利用状态 | 主角获得动作能力；姐姐火种脱离封存 | 主体性恢复，不是救人 |
| 3《影中有路》 | 穿过敌军城墙，夺走故乡残图，获得行动自由 | 主角 | 主要是自我通行与探索 |
| 4《欠天一笔》 | 将父亲的债移入自己心脏，承受天钉，并迫使河流保护城池 | 父亲、城中居民，同时包括主角 | 明确属于保护和公共风险承担 |
| 5《万物不肯沉默》 | 替被强行改名的旧剑说出原名，使其重新选择主人 | 主角与旧剑双向受益 | 对象是器物主体性，不是人类救助 |

v3 的盲审所列第一次核心兑现中，候选1救出工友，候选3为囚徒撑开出口；候选2主要是自我脱困，候选4修复自己的断刀，候选5挣脱刑台并第一次发声。若把“第一次标志性奇观”也计入，v3 候选1、3、4分别出现村庄、逃难者和城中百姓的公共风险保护。

### Reviewer 归纳

v4 的直接受益对象和行为目的明显更分散：

- 候选1是追回被抹除的亲属未来；
- 候选2是夺回死者意志；
- 候选3是个人通行权和故乡线索；
- 候选4是保护父亲与城池；
- 候选5是恢复器物的命名权和选择权。

这不是简单把“救人”换成另一种敌人。兑现目标本身已经分成关系追回、死亡主体性、个人自由、公共保护和非人主体性五种落点。

### Meta 判断

是，但范围有限：v4 的第一次主要兑现比 v3 更自然地分散，尤其是在“谁受益、主角为何行动”这一层面。v4 不再几乎都以拯救他人或守住公共对象作为大型兑现的显性结果；明确的公共保护主要集中在候选4。

但 v4 并没有摆脱“主角亲自承担危险成本”的共同机制。五案仍都要求主角进入禁区、吞食余烬、承受道路、承接债务或让外物声音进入身体。变化发生在价值落点和受益对象，不是从“承担风险”这一力量结构中脱离。

## 2. 是否出现反向价值偏置

### 已观察事实

- 候选1的“夺回”对象是妹妹被抹除的未来，财富没有出现，复仇未直接写明。
- 候选2具有最明显的破坏性和复仇向目标：要摧毁把死亡当作修炼资源的葬天司秩序。盲审明确称其为“复仇向目标”，但也说明文本没有直接将其命名为复仇。
- 候选3夺取故乡残图，核心是摆脱道路垄断、获得自由通行；没有财富追逐或明确复仇。
- 候选4以强制兑现债务对抗收债秩序，但行为目的写明是保护父亲和城池，不是财富积累。
- 候选5帮助旧剑恢复原名和选择权，核心是谈判、互换和主体性恢复。
- v4 盲审对五案均记载“财富未出现”。

### Reviewer 归纳

v4 确实比 v3 更常使用“夺回、夺走、收下、索取、切断”等对抗性动作词，但这些词分别服务于不同目标：找回未来、释放死者、取得通行权、兑现承诺、恢复命名权。动作词相近，不等于价值方向相同。

### Meta 判断

没有证据支持“五案统一走抢夺、复仇、利己、杀戮或财富追逐”的判断。

候选2可以单独归入较强的死亡秩序破坏和复仇向轨道；候选3有较明显的个人自由取向；候选4是保护性、契约性对抗；候选1和候选5分别偏向关系追回与主体性恢复。把候选2的局部特征扩大为 v4 的统一价值趋势，会超出 Seed 事实。

## 3. 行为与收益是否由不同主角欲望和局面推动

### 已观察事实

v4 五案的欲望—局面—行为—收益链条均有明确对应关系：

| 候选 | 主角欲望 | 触发局面 | 行为与收益 |
|---|---|---|---|
| 1 | 找回妹妹没有被写死的人生，夺回选择未来的权力 | 定命院焚烧并封存未来 | 调用不同人生进入藏命库，获得命页和第三条人生的可能 |
| 2 | 让姐姐以自己的意志结束死亡，摧毁死亡资源秩序 | 姐姐被炼成战争兵器，余烬被葬天司垄断 | 吞食死者最后动作，取得姐姐火种和战斗本能 |
| 3 | 找回故乡归途，获得不需许可的行动自由 | 故乡被从地图和记忆中裁掉，路籍宫垄断道路 | 走入影路、穿过城墙，获得残图和跨距能力 |
| 4 | 把家人债务转到自己身上，保护父亲与城池 | 收债日到来，父亲将被天钉贯穿 | 承受债务与天钉，获得债权身份和个人法则 |
| 5 | 找回原初名字，决定自己是谁 | 主角无名，旧剑被强行改名 | 与旧剑谈判并替其发声，获得裂隙感知和主体性确认 |

v3 也存在同样的对应关系：矿工身份推动候选1承接坠落，血肉衰败推动候选2猎杀灵兽，封闭山谷推动候选3寻找缝隙，被毁双手与旧剑推动候选4修复，失声经历推动候选5夺取声音。

### Meta 判断

是。仅根据 Seed 和盲审，行为与收益主要由各自不同的主角欲望和局面推动，而不是由一个脱离人物动机的通用升级模板随机分配。

不过，两轮都存在一个共同限制：无论主角想找回亲人、逃离故乡、修复自我还是取得声音，最终收益都必须先进入主角身体，成为可调用的能力。因此“人物动机不同”与“能力收益形态相近”同时成立。这是结构事实，不涉及哪种动机或结果更正确。

## 4. 机制、模板、成长和世界扩张

### 4.1 机制多样性

| v3 | v4 |
|---|---|
| 承接、储存并转向坠落之势 | 召回未走过的人生并组合 |
| 猎杀灵兽并移植生命器官 | 吞食死者余烬并炼入骨骼 |
| 识别缝隙并穿过边界 | 亲自走过道路并将其折入影子 |
| 读取断裂并接合、重构 | 收取债务并转化为个人法则 |
| 收集声音、叠加频率并释放 | 听见愿望、谈判并借用特性 |

v3 的表层对象主要来自物理力学、生物器官、空间边界、破损结构和声音震动；v4 则转向未成的人生、死亡动作、道路权限、承诺债务、名字与愿望。

因此，v4 在语义和规则层面扩大了机制空间，但不是简单地说“v4 比 v3 机制数量更多”。两轮各自都有五种可辨认的直接机制；变化主要是机制所处理的对象，从“外部物理现象”转向“被抹除、未完成或被压制的关系与意义”。

### 4.2 共同深层模板

两轮共同存在以下结构：

1. 主角先被既有秩序判定为残缺、无权、无用、受限或无法完成某件事。
2. 主角主动进入危险或禁制区域，接触外部规律。
3. 外部规律进入身体，成为能力、器官、经验、法则或感知。
4. 主角承担身体、意识、情绪或寿命成本。
5. 通过不断接触更大规模的对象，能力从个人层面升格到天地层面。
6. 世界扩张仍围绕同一机制的更大实例展开。

v3 的深层母型更接近“把危险、损坏或环境力量转化为身体能力”；v4 更接近“把被抹除、未完成、被垄断的主体性或承诺转化为身体能力和个人规则”。

所以，v4 有真实的深层变化，但没有脱离两轮共有的“身体作为世界规律接口”母型。

### 4.3 个人一级成长

v3 的一级成长几乎全部是身体承载与控制能力：

- 骨骼承受和分配坠势；
- 器官和生命循环重建；
- 身体厚度、边界和界门控制；
- 双手、经脉和修行结构修复；
- 喉咙、骨骼和神魂储存回响。

v4 仍然全部以身体为核心接口，但成长内容更偏向个人主体性的组织：

- 候选1从借用其他人生走向成为“第三人”；
- 候选2从使用死者动作走向形成不属于任何死者的个人力量；
- 候选3把道路经验和地形真正变成自身行动能力；
- 候选4把外部债务变成只听从自己的法则；
- 候选5从借用外物特性走向与自己的血肉谈判。

v4 因而改变了“主角个人变强”的内涵，但没有改变其身体中心。

### 4.4 非对称优势

v3 的非对称优势主要来自物理和资源转换：

- 敌人越强，重击和坠物越可能成为主角的储备；
- 极端环境本身成为器官改造材料；
- 防御结构的缝隙成为突袭和撤退通道；
- 破败战场提供别人无法使用的残片；
- 敌我碰撞和环境噪声成为声音武器库。

v4 的非对称优势更多来自规则、权限和关系漏洞：

- 依赖单一人生或预测的敌人难以处理“未成之身”；
- 敌人的临终动作和死者遗留意志可以成为主角的即时能力；
- 道路垄断和通行许可对主角失效；
- 高位敌人背负的未兑现承诺越多，越可能暴露债务缺口；
- 被命名、被驯服的法器可能因重新发声而拒绝原主人。

这是实质性的对抗结构变化：v3 更像利用物理输入和破损资源，v4 更像利用被压制的定义权、承诺和主体性。

### 4.5 10/30/100 章升格

v3 的升格轨迹大体是：

- 10章：局部、直接控制机制；
- 30章：多系统组合或大范围环境应用；
- 100章：身体承受天地级对象并跨越世界边界。

例如，坠势由单次兵刃攻击升到浮陆下坠；器官由单项适应升到完整生命循环；缝隙由穿墙升到跨界；修复由残兵升到重建自身修行道路；声音由钟声升到穿越无空气虚空。

v4 的升格轨迹更偏向：

- 10章：稳定控制一个外部主体或规则；
- 30章：组合冲突输入，形成个人系统；
- 100章：创造、命名、强制兑现或跨越既有世界定义。

例如，候选1从调用一条人生到创造概率外不存在的自己；候选4从承受债务到让未来成为天道欠下的事实；候选5从听见兵器到让现实承认此前不存在的行动。

但两轮的深层形状仍相似：10章是局部掌控，30章是组合为个人体系，100章是把身体能力提升为世界层面的通行或改写条件。v4 更强调“谁有权定义可能性”，v3 更强调“身体能承受和重建什么”。

### 4.6 重复玩法

v3 的重复循环是：

> 进入危险环境或废墟 → 获取外部力量/结构 → 让身体承受 → 储存、修复、组合或释放 → 处理更大对象。

v4 的循环是：

> 追踪被抹除或未完成之物 → 亲自经历、吞食、行走、收取或谈判 → 将其纳入身体 → 承担异己意志、债务或地形成本 → 组合并形成个人规则。

v4 改变了“输入材料”的语义，但没有消除重复玩法。五案分别反复召回人生、吞食余烬、折叠道路、收取债务、谈判借用特性。共同风险也更集中在身份和主体性侵入：其他人生、死者意志、债务后果和万物声音都可能反过来影响主角。

### 4.7 世界扩张

v3 主要沿物理尺度和环境复杂度扩张：

- 矿井、山崩、浮空城、浮陆和重力乱流；
- 毒泽、冰海、熔岩、真空和特殊生命圈；
- 封闭山谷、镜后世界、折叠天地和界伤；
- 残兵、城阵、遗迹、灵脉和天地结构；
- 雷暴、共鸣山脉、巨兽呼吸和虚空声音。

v4 主要沿规则层级和世界定义扩张：

- 个人未成之身扩展到废弃未来和多重世界；
- 死者余烬扩展到灭绝种族和死去文明；
- 个人影路扩展到断路海和互相否定的天地；
- 个人债务扩展到王朝、神明和创世之债；
- 物件声音扩展到山河、生命、死亡、星辰和未说完的语言世界。

表层上，v4 的世界更抽象、更概念化；深层上，两轮都让同一能力机制在更大对象上重复出现，并最终成为跨世界的接口。

## 5. v3→v4 输入/诊断词污染风险

### 已观察事实

v4 五案确实共享一组明显的语义族：

- 被抹除或未成的人生；
- 未完成的死亡动作；
- 被封锁的道路；
- 未兑现的债务；
- 被压低的名字、愿望和声音。

v4 盲审也明确将其归纳为“残缺补偿”和“外部规律进入身体”。同时，v4 与 v3 之间存在局部语义邻接，例如：

- v3 的缝隙、界门、穿行，与 v4 的道路、影路、跨界；
- v3 的声音、发声、雷声，与 v4 的声音、沉默、名字和愿望；
- v3 的外部能力进入身体，与 v4 的人生、余烬、道路和声音进入身体。

### Meta 判断

这些材料支持“v4 仍保留了部分主题连续性和身体接口结构”，但不支持“存在输入词或诊断词污染”的因果结论。

允许读取的文件中没有 Prompt、INPUT、诊断词原文、生成过程或版本间输入记录。因此无法判断这些相似性究竟来自有意的主题延续、候选编号的设计继承、共同母型，还是某种输入污染；也无法给污染风险定量分级。

最稳妥的 Seed-only 结论是：v4 不是深层结构上的完全换轨，但现有文件不足以证明这种连续性由输入或诊断词污染造成。
