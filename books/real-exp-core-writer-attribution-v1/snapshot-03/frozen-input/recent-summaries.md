第1章：回收令下达后，沈砚从被砸坏的旧矿车阵盘中听出一条仍在寻找出口的灵力回收路，用废铜、破阵盘和妖兽晶核铸成固定在左小臂上的铜环护腕。塌方和镇灵阵困住唐鹭与三名矿奴，沈砚耗尽自身灵力后借护腕聚拢地火和碎石间的散逸灵气，重新施出引砂诀，切断锁链，救出四人。霍沉因此命人重新登记并封存异常废器，要求沈砚解释矿车为何还能动；塌口下又传来与护腕内细震相同的更深脉动，护腕开始寻找地底更深的出口。
第1章：回收令下达后，沈砚从废矿车阵盘中辨认出仍在寻找出口的细微回收路，用废铜、破阵盘和妖兽晶核制成无法取下的护腕。塌方时，他先耗尽自身灵力，随后借护腕聚拢地火与散开灵气，重新施出引砂诀，断开锁链，救出唐鹭和三名矿奴。霍沉因此命人登记并封存异常废器，要求沈砚解释断灵矿车为何还能移动；塌口下又传来与护腕相同的更深脉动，护腕开始寻找地底更深的出口。
