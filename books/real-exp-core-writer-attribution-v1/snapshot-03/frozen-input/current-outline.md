触发事件：霍沉为确认灵回护腕是否造成废料异常，派矿工搜身，并把沈砚调去修一辆即将报废的运输矿车；旧坡道与主巷的镇灵压制同时加重，矿车被安排在塌陷风险上仍要运走一批矿奴。
推动事件的人：霍沉。他把这次维修当成查验沈砚、核对废料消耗的机会，既要看护腕能否再次起效，也要把沈砚重新放回炉籍和矿车的控制里。
主角行动：沈砚把灵回护腕藏进左腕炉印下，故意让运输矿车在旧坡道卡死，等阵盘再次断灵时主动启动护腕，收回车底与轨槽间散开的灵气；他连续施出两次修补诀，先补上矿车的承重骨，再把被截断的轨道重新接通。
对手或世界反应：镇灵阵压断阵盘后，主巷开始塌陷，碎石和地火逼近载有矿奴的矿车；护腕收回散灵使矿车重新有了牵引，矿车避开正在下沉的主巷。霍沉看见废车在断灵后自行恢复运行，无法再按废料拆解，只得把沈砚暂时扣留在废器堆继续查验；唐鹭趁车底混乱替他藏下一块破阵盘的回收片。
直接结果：灵回护腕在真实的断灵环境中完成第二次回环，沈砚用连续两次修补让运输矿车恢复承重、让断轨重新接通，并把这一批矿奴载过塌陷段送到安全的回收线；一块可拆卸的破阵盘回收片也留在他手里。
状态变化：沈砚现在可以保留并再次调用护腕回收的外部灵气，在自身灵力不足时连续延长修补施法，改变一小段矿道和工具的实际运行；他被调入废器堆，获得接触更多异常残件的工作位置，唐鹭也从共同脱险者变成主动替他藏材料的协作者。矿场对他的判断从“手够稳的矿奴”变成“可能改变废器价值的人”。
叙事功能：把第一章护腕救人的一次性震撼落实为可重复调用的能力、可保留的材料和一段关系收益，同时让沈砚不满足于只保住自己的护腕；他开始利用矿场对废器的盘查寻找更大的灵路结构，为后续主动追查地底脉动建立入口。
结尾推动力：沈砚将破阵片握在掌中时，回收路指向一条已被废弃、按理不该有灵气的支巷；他从片中听见成片矿奴的呼吸被同一阵法同步牵引，像有什么东西正在把他们的气息往地底吞。霍沉随即宣布下一班矿工全部转入中央矿脉，沈砚必须带唐鹭进入这条支巷，查清那股脉动究竟在吞噬什么。
