## 第2章：护腕收回第二口气

具体剧情：霍沉派矿工搜身并把沈砚调去修一辆即将报废的运输矿车，准备借维修过程确认废料消耗；沈砚把灵回护腕藏进炉印下，故意让矿车在旧坡道卡死。矿车阵盘再次断灵时，他主动启动护腕，把散灵收回手臂，连续施出两次修补诀，先修好矿车承重骨，再把被截断的轨道重新接通，矿车载着一批矿奴避过正在塌陷的主巷。霍沉不得不把他暂时留在废器堆，唐鹭则从车底替他藏下破阵盘的一块回收片。

结果 / 状态变化：护腕成为沈砚真正可以保留和再次调用的优势，能延长施法、修补工具并改变一小段矿道的行动结果；他得到一块可拆卸的回收阵片和进入废器堆的工作位置，唐鹭从被动跟随转为主动帮他藏材料。矿场对他的关注从“手够稳的矿奴”变成“可能改变废器价值的人”。

叙事功能：把第一章的震撼转成可重复调用的能力和关系收益，证明护腕不是一次偶然的光；同时让沈砚的欲望从保住自己的小器物，开始指向寻找更大结构。

结尾推动：破阵片在沈砚掌中指向废弃支巷，那里本应没有灵气，却有成片矿奴的呼吸被某个阵法同步牵引。霍沉宣布下一班矿工全部转入中央矿脉，沈砚必须带唐鹭进入支巷，确认那股脉动究竟在吞噬什么。
