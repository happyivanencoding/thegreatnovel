第1章：封炉令下的黑炉镇废脉发生塌方，沈燧没有抛下被困的矿工和伤者，而是以断镐中尚未完成的凿路锋力一次性劈开矿壁，带众人转入旧风道；锋力耗尽后，他的右臂留下黑色裂痕，黑铁锋片嵌入掌心。封炉阵定位到异常炉息，裴照川将撤离区改列为异常回收区并展开封锁，沈燧遂带着伤者推入被封存、余火将熄的废弃炼器窟。

第2章：沈燧和矿工、伤者在阮青禾辨认出的侧炉中重新引燃残火，用烧红的粗铁和掌中黑铁锋片锻成裂路器；他先以裂路器劈开侧炉后的石壁，又切断接入封锁阵的封钉，带队进入侧道。裴照川确认裂路器能够再次驱动后封死废窟前后出口；队伍随后沿残图向仍在发热的窟心炉心前进，而迎面的回火已经逼近。
