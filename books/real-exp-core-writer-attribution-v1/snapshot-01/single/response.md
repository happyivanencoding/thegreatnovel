# 正式正文

完整的灵脉像埋在大地里的血，灵炁沿着山脊和河床奔流，炉火便能把矿石、兵器和人的命都烧出一条去处。完整的东西会被修士称作资源，仍在运转的东西会被记入宗门的账。至于裂开的矿脉、熄灭的炉、断掉的器物和快要死去的人，账页上只有一个相同的归类：废。

黑炉镇就建在一条发黑的矿脉上。镇墙是烧结矿渣垒的，屋檐下挂着接火的铁槽，夜里每一扇门缝都透出地火的红。矿工们靠那点红活着，也被那点红拴住。灵脉一旦被封，炉火一旦熄灭，镇上的人连站在哪里都要等宗门重新划线。

黄昏时，玄烬仙宗的封炉令落进镇心。

来人只有十几名，走在最前的年轻人穿一件没有沾灰的玄色炉监袍。他抬手时，黑铜令牌在暮色里亮了一下，镇心那座废钟随即自己响了三声。声音穿过屋顶和矿井，像有人用铁锤敲在每个人的胸骨上。

“玄烬仙宗封炉。”年轻人说，“三日后，黑炉镇矿脉封闭，地火熄灭，炉工与矿材一并清点。未登记之人，不得离镇。”

镇管事连忙从人群里挤出来，双手接住落下的纸令。他看了一眼上面的宗印，先看封期，又看矿脉编号，脸上的肉便一层层沉下去。

“裴炉监，封期是不是还能往后缓几日？”

“不能。”

裴照川的声音不高，周围的人却都听得清楚。他把一枚细长的封钉插进镇心石台，黑色阵纹沿着街口爬开，挨家挨户地量过炉门和井口。

“废脉已经不值得再耗费宗门护阵。”他说，“三日，是给你们把可交的东西交齐。”

镇管事低头看着那道阵纹，目光落向下层矿道的方向。那里还有一批没有被掏干净的赤黑矿，按旧账算不上多少，却足以让他在清点时少填几行亏空。

当夜，他命人强开废脉。

沈燧就在下层。

他被安排在最靠近矿壁的位置，手里的铁钎比别人的短一截，柄上包着几圈拆下来的麻绳。有人从他身边经过时，低声叫了一句“漏炉废人”，像是在提醒旁人别把工具交到他手里。

沈燧没有抬头。他把一缕从岩缝里涌出的灵炁按进掌心，灵炁穿过皮肉，带着凉意从指缝漏下去，落在脚边的矿尘里，连一粒灰都没有吹动。

他收回手，捡起铁钎，继续凿。

阮青禾蹲在另一侧的旧支架旁，用一块沾油的布擦开矿壁上的刻线。她是镇里的记路人，腰间挂着几截不同颜色的绳头，眼睛一直盯着那些被新挖痕迹割断的旧标记。

“这条脉下面是空的。”她抬头说，“旧采层没有回填，不能再往里开。”

镇管事站在后面催：“先把矿材拿出来。封炉之后谁还管一条废脉能不能撑？”

第一声闷响从脚下传来时，沈燧还没来得及转身。

矿壁深处像有一头醒来的兽，先是轻轻顶了一下，接着整条旧采层同时向下沉。火把被黑暗吞掉，支架折断的声音一根接一根。有人喊着往主井跑，喊声刚冲出去，头顶的矿梁便砸了下来。

沈燧被碎石撞到膝盖，身体贴着地面滑出去。等尘土稍微落下，他听见四周全是咳嗽和呻吟。主井方向已经被一面斜压下来的石墙封死，唯一留下的缝隙只够一只手伸过去。

“救人！先救人！”

阮青禾的声音从右边传来。她的额角被石屑划开，血沿着眉骨往下流，却还在摸支架的根。一个矿工腿被压住，另一个胸口陷在断梁下，靠墙的人只剩短促的喘气。

沈燧先把能拖动的人拖向一条低矮的旧风道。那里的石顶已经裂了，至少还有两根完整支柱撑着。他把腿伤者的肩膀搭到自己身上，又回头去抱胸口受伤的人。

有人抓住他的袖子：“主井在那边，封炉阵还没合死。你先出去，叫宗门放人。”

沈燧看了一眼主井。缝后的火光正在变暗，外面传来铁片碰撞的声响，像有人已经在井口重新下封钉。

“他们不会放。”他说。

“那也比在这里等死强。”

“一起走。”

他说完便继续往前。不是为了让谁相信他，也不是因为他知道前面一定有路。风道里每多躺一个人，后面塌下来的石头就会多一分重量；他只是不能把活路先留给自己。

阮青禾看了他一眼，立刻转身去招呼其他人：“还能动的，抬伤者。别踩左边，那里是空腔。”

沈燧把最后一个伤者拖进旧风道，回身时，脚边的碎石里露出半截木柄。木柄已经被压裂，铁头从中间折断，只剩一面黑沉沉的锋口。

那是一柄采矿镐。

他握住它的一刻，右臂先失去了重量。

紧接着，一股冰冷的铁意从断口钻进肩胛，顺着骨头往下压。不是灵炁，也不像任何他见过的功法。那股意志没有声音，却在黑暗里反复撞着同一个方向：前面有矿壁，后面有人；这柄镐最后要做的事，不是把矿石带出去。

它要凿开一条让人活着出去的路。

沈燧的指节被木柄上的旧血硌得发疼。他抬起镐头，眼前的矿道没有变，石梁、碎土和被压弯的铁轨仍旧堵在那里，可那股锋意替他在岩层里指出了一条极窄的斜线。斜线的尽头不是主井，而是旧风道另一侧一块颜色更深的矿壁。

阮青禾已经把残图摊在地上。她用手背抹掉灰尘，盯着那条被折断的刻线。

“这里。”她说，“旧风道原本接过一处废弃炉窟。要是矿壁后面还空着，能绕到上层。”

“能撑多久？”

“不知道。”

“够不够人走？”

阮青禾看向挤在风道里的矿工和伤者，又看向不断落灰的石顶。“得有人先把口子凿出来。”

沈燧将断镐抵在那面深色矿壁上。铁头贴上石面时，右臂里的冷意骤然变沉，像整条矿脉把最后的重量都压到了他的骨头上。

他第一下没有凿进去。

断镐震得虎口发麻，锋意却没有散。那柄镐已经折断，木柄只剩半截，仍固执地把全部方向推向岩壁。沈燧咬紧牙关，把肩膀贴上镐柄，身体里的空处被那股力量硬生生撑开。

空炉体质从来留不住灵气。可这一刻，涌进来的不是可以被他抓住的灵气，而是一件东西没有做完的动作。那动作经过他的手臂，像要把他的骨头也当成凿尖。

第二下落下，矿壁里传出沉闷的裂声。

右臂从肩下到肘侧浮出一条黑线，皮肤像被烧过的瓷器一样裂开。沈燧闻到焦味，喉咙里涌上血腥气。他没有松手，反而将镐头往那条裂声里压得更深。

“沈燧！”阮青禾喝道，“再这样你的手会废！”

“先让他们走。”

第三下。

这一次，矿壁后面忽然空了。断镐的锋意穿过他的右臂，轰进石层深处。整块堵死风道的岩面从中间裂开，石缝像一张被强行撬开的嘴，先吐出一股带着冷味的风，随后吐出一线极远的微光。

上方的石梁同时下压。

沈燧双手抱住镐柄，膝盖在碎石里跪下。裂缝刚开的那一刻，他看见断掉的铁头正在一点点变红，锋口却没有继续扩大。石梁离他的肩只剩半尺，黑色裂痕沿右臂往下爬，像有细小的火在骨缝里烧。

第一息，阮青禾把腿伤者拖到裂缝边。

第二息，两个矿工抬着胸口受伤的人挤过石口。

第三息，风道里最后一个还能走的人回头看了沈燧一眼。

“走！”沈燧吼道。

那人咬着牙钻了出去。阮青禾没有走，她回身抓住沈燧的左臂。

“轮到你了！”

沈燧的手指已经没有知觉。断镐里那股要凿路的力道正在迅速变薄，像一根烧到尽头的芯。他松开一只手，身体顺着裂缝往外滚。就在他的掌心离开木柄的刹那，铁头里最后一点锋意折回镐身，凝成一片拇指宽的黑铁，贴着他的掌骨钉了进去。

疼痛没有声音。

他只看见掌心皮肉被黑铁顶开，血沿着锋片两侧流下。右臂的裂痕猛地收紧，像一张要把整条手臂缝死的网。沈燧想再握住那片黑铁，指节却只能轻轻抽动一下。锋片没有回应。

身后的矿壁轰然合拢，断镐的木柄和剩余铁头一同被埋进黑暗。

裂缝另一侧是一条比旧风道更窄的石廊。矿工们挤在廊壁两边，能站的扶着不能站的，没人再催沈燧先走。阮青禾把最后一名伤者交给两个炉工模样的矿工，自己回头看那道刚刚出现的出口。

“它撑住了。”有人低声说。

“不是它。”另一个人看着沈燧的右臂，“是他。”

沈燧没回答。他半跪在地，左手按着掌心，血从指缝里滴下去。风从石廊深处吹来，带着更浓的炉灰味。前方的岩壁上，残存的旧刻线在微光里转了一个弯，指向一扇被矿渣和铁栓封住的黑门。

黑门后面有火。很弱，像一条即将断掉的红线。

就在这时，裂开的矿壁外传来一声尖锐的鸣响。

黑炉镇上空的封炉阵捕捉到了异常炉息。黑色阵纹沿着塌方的矿层迅速收拢，原本标记为撤离区的旧风道被一笔抹去，换成了四个冷硬的朱字：异常回收。

裴照川站在主井口，抬头看着阵盘上不断闪烁的微光。

“封住主井。”他说。

旁边的巡炉人问：“下面还有活人。”

“异常回收区，不准擅自进入。”

他将手指按在阵盘上，微光立刻分成两股，一股沿着塌方处往下探，另一股顺着旧风道的刻线，朝黑门后的废窟追去。

“搜旧风道。”裴照川说，“把人和那件东西一起带回来。”

石廊里，沈燧听见了那道从岩层深处传来的细响。封锁正在逼近，身后的出口被重新压死，面前的黑门却在最后一线火脉里微微发红。

他站起身，把受伤的右手藏进衣袖。掌心的黑铁锋片隔着血肉发出一点热意，像一枚尚未冷却的钉子。

阮青禾看向黑门：“里面可能也是死路。”

“那就进去看。”

“回收队会追过来。”

“我知道。”

他扶住一名伤者，示意还能行走的人先把通道让开。没有人再问该往哪边走。

黑门上的旧铁栓在风里轻轻颤了一下，门缝里漏出的红光照亮了沈燧掌心那片黑铁。紧接着，远处传来第一声封锁符落地的闷响。

# 章节事实摘要

封炉令宣布黑炉镇三日后封脉熄火，镇管事为抢出最后矿材强开废脉，导致下层塌方。沈燧在主井被封、符火失灵的死局中，先将伤者拖入旧风道，再握住折断采矿镐，承受其“凿开一条让人活着出去的路”的最后锋意。他劈裂矿壁并顶住石梁三息，让矿工和伤者撤出；断镐锋意耗尽后凝成黑铁锋片嵌入掌心，封炉阵将他标为异常回收目标。众人随残图进入一扇通往废弃炼器窟的黑门，门后最后一线火脉正在熄灭。
