# Primary Draft

## 第四章　火线尽头

封锁符钉进岔口的声音很轻，像一根针扎进湿布。

下一刻，左侧石壁里便响起了密密麻麻的裂声。

红光从符纸边缘渗出来，沿着岩缝向里爬。原本贴在地面的火线被那层红光逼得抬高，火舌没有烧出来，热却先压到了人的胸口。干石上的尘土一粒粒跳起，落在伤者脸上。

阮青禾把耳朵贴在右侧残图旁的石面上，听了两息，抬头道：“左边封住了。不是暂时。”

“右边呢？”沈燧问。

“刻线还在。路未必还在。”

“那就先找路。”

沈燧转过身。

腿伤者靠着石头，裤腿已经被血和灰粘成一片；胸口受伤的矿工喘得像破风箱，每一次吸气都牵动肋下；额头伤者刚把布条重新系紧，血仍从眉骨旁慢慢渗出来。五名炉工挤在岔口内侧，手里还拿着从热道里带出来的短铁棍和断掉的抬架。

他们没有人催他。

也没有人能在这里等下去。

“胸口的两个人抬。”沈燧说，“腿伤的放中间。额头那个走前面，看见落灰就喊。炉工一人扶一个，剩下的跟着青禾。”

一个脸上全是炉黑的炉工朝左边看了一眼：“要是右边也是死路呢？”

“那就死在自己找的地方。”

他话音刚落，左边传来一声闷响。那面被封住的石门向内鼓了一下，红色火线顺着地缝扑出半尺，烤得最近的矿工急忙后退。

沈燧伸手按住了抬架的一角。

“现在走。”

没人再问。

阮青禾蹲到残图前，用手指刮开浮灰。残图刻在旧炉砖和岩壁交界处，线条浅得几乎断掉，三道短痕在窟心方向收成一条斜线，最后没入一片黑色炉渣。

“这里不是主道。”她说，“是旧风孔。以前给窟心送风，后来被填了。”

“能过人？”

“你先把炉渣清开。”

沈燧没有用裂路器。

左手的粗糙器物还带着从废炉闸上刮下来的黑灰，刃口边缘有一道新崩的豁口。它能切开门和闸，却不能替他们把眼前这堆炉渣变成空气。沈燧把它横在腰间，俯身用手去扒最上面的碎块。

炉渣烫得像刚出炉的铁砂。

他的右臂在袖子下面抽了一下，黑色裂痕从肩下往肘侧收紧，疼得像有一圈细铁丝缠住骨头。沈燧咬住牙，没有停。阮青禾把一块块松动的碎渣往后拖，五名炉工也跟着蹲下。有人用铁棍撬，有人用手臂护着脸，把石块推到一边。

低矮的风孔很快露出半边。

里面没有风，只有一股从地底顶上来的热气，带着旧铁和烧焦兽骨的味道。

沈燧把胸前的布包解开了一角。

火鳞胚贴在里面，暗红细纹一明一灭。它没有朝风孔正中偏，反而在他手边轻轻撞了一下，指向更右侧、被厚灰压住的那条刻线。

阮青禾看见了那一下。

“它不认风孔。”

“它认里面。”

“你知道里面是什么？”

“不知道。”沈燧重新系紧布包，“所以要进去看。”

阮青禾盯了他片刻，忽然起身，对身后的矿工说：“不是他替我们选路。想走的现在跟上，不想走的留在这里等封火。”

没人留下。

那个刚才问是不是死路的炉工把断抬架扛到肩上，先钻进了风孔。孔道只比一个人宽，炉砖被热气烤得发黑。他进去几步，回头伸手接住了胸口受伤的矿工。

沈燧让腿伤者在中间，自己走最后。

孔道的顶部很低，额头伤者弯腰时碰落一层黑灰。灰粉落下来，像下了一场极细的煤雪。后方的声音却越来越近，封锁阵驱动火线时，石壁里有沉重的摩擦声，一阵一阵，仿佛有人拖着烧红的铁锤沿矿道挪动。

“他们把热赶过来了。”阮青禾在前面说。

“听得出来？”

“旧窟的火不会这样响。”

“那就是有人在推。”

她没有回答。

孔道中段塌了一截，下面露出一道黑红相间的裂缝。裂缝不宽，却从底下往外吐火。火光照在每个人的膝盖上，先来的炉工停在那里，手脚不知道该往哪儿放。

阮青禾伸手摸了摸上方的砖缝：“等它收。”

“什么？”

“火。”

她话音刚落，裂缝里发出一声尖啸，火舌突然缩了回去，只剩岩缝深处一点暗红。

“现在！”

前面的炉工拖着抬架跨过去，第二个人扶着伤者跟上。腿伤者走到裂缝边时，脚下的一块炉砖忽然松动，整个人往下一歪。

沈燧从后面扑上去，左手抓住他的衣领，右臂却使不上力。裂痕猛地一紧，整条胳膊像被烧过的木头，麻意一直窜到指尖。

“别拽我！”腿伤者喘着说，“先让他们过去！”

“闭嘴，把腿抬上来。”

沈燧把肩膀顶进他腋下，腰腹压在孔壁上。上方的炉砖碎了一块，热灰顺着领口灌进去。他没有用力去扯那条腿，只一点点调整角度，把伤腿从裂缝边缘拖回实地。

阮青禾折返两步，抓住腿伤者的手腕。前面的炉工也转过身，几只手同时伸来。那人终于被拖了过去，鞋底在裂缝边擦出一串火星。

沈燧最后跨过。

他落地时，右掌的伤口被粗糙炉砖刮开，血一下涌出来。布包里的火鳞胚隔着布料热了一瞬，像有一根细针从掌骨里扎过。

沈燧低头看了一眼，没有解开布包。

“它又动了？”阮青禾问。

“没事。”

“你每次说没事，下一刻都要出事。”

“那就下一刻再说。”

风孔在这里向下倾斜，末端接着一间比矿道宽不了多少的旧料室。房顶的梁已经烧空，黑色灰烬堆到膝盖。料室另一头立着一扇半埋的铁栅门，门后没有炉火，只有一片漆黑。

阮青禾踩开灰，露出门槛上的刻痕。

“这是往窟心的料门。”

“能开？”

“门轴还在，门后被东西顶住了。”

她指着铁栅下方。

门缝里卡着一截扭曲的炉管，炉管另一端埋进塌落的石梁。那截管子没有火，却在不断发出低沉的嗡鸣。每一次嗡鸣，铁栅上的锈屑就往下落一点。

沈燧取下裂路器。

阮青禾立刻道：“它还能用几次，你不知道。”

“所以不拿它去砍门。”

沈燧把裂路器的刃口插进铁栅与门槛的缝隙，用它当作撬杆。五名炉工分开站好，按他的手势一起压住门框。门后的炉管被挤得发出一声尖响，铁栅只抬起了一指宽。

“还不够。”

“再来。”

沈燧换了个支点，把左肩抵上去。旧伤在热气里猛地抽痛，肩胛像要被撕开。他没让疼痛替自己决定松手，五名炉工同时发力，铁栅终于向上抬出一掌宽的缝。

“伤者先。”沈燧说。

胸口受伤的矿工被两个人从缝里送过去。腿伤者趴在抬架上，炉工抬着他侧着挪；额头伤者钻到另一边，回身去接阮青禾递过去的药布。原有矿工没有等沈燧命令，自己把能动的石块清到两旁，给后面的人腾出落脚处。

最后只剩沈燧和阮青禾。

铁栅后面传来一阵很远的水声。

不是水。

声音更沉，像一口巨大的炉子在地下缓慢换气。

阮青禾从缝里回头：“窟心。”

沈燧正要进去，后方的风孔忽然亮了。

一线红光沿着孔道底部爬来，越过刚才那道裂缝，烧得炉砖发白。封锁符的力量已经追到他们身后。红光没有立刻冲过来，而是在料室入口停住，凝成一层薄薄的火幕。

火幕上浮起一行暗金色的字。

“异常器修，停止深入。”

字迹只存在了一瞬，便被热浪吹得扭曲。紧接着，裴照川的声音从火幕之后传来，隔着石头和阵力，听起来比在矿镇上更冷。

“沈燧，把裂路器放下。窟心不是你这种人能碰的。”

料室里一片安静。

沈燧看着铁栅后的黑暗，问：“你要炉心，还是要人？”

“封炉令下，二者没有区别。”

后面有个矿工狠狠吸了一口气。阮青禾抬手，示意他不要出声。

裴照川继续道：“退回岔口，接受清点。封炉之后，至少能留下名字。”

沈燧看了看自己掌上的血，又看了看铁栅后那条没有光的路。

“名字不能拿来走路。”

他拔出裂路器，侧身钻过铁栅。

阮青禾在另一边伸手接住他，低声道：“你听见了，他会把整个窟心封死。”

“听见了。”

“前面可能没有出口。”

“后面一定有人替我们封口。”

阮青禾看着他，没有再劝。

料室后方是一条下沉的炉道。炉道两侧原本应该铺着送火管，如今只剩半截黑铁环，环内结满灰白色的硬壳。所有硬壳都朝同一个方向裂开，裂口里透出微弱的暗红。

队伍刚挪进去，铁栅便在身后轰然落下。

火幕撞上门面，发出一声长鸣。裴照川的声音被铁栅截断，只剩几个模糊的字飘过来：封……窟……心……

五名炉工把抬架放下，喘息着靠在墙上。胸口受伤的矿工已经说不出话，额头伤者把最后一段布条撕开，替他压住伤口。腿伤者疼得脸色发白，却还睁着眼。

没有人问沈燧下一步要去哪儿。

他们都在看那条暗红的裂口。

沈燧把火鳞胚从布包里取出来。

胚片很薄，边缘像一枚没有烧完的黑色鳞片。此前留在上面的细纹只是零散地亮着，此刻却有一条红线从鳞片根部缓慢延伸，贴着他的指节，指向炉道尽头。

那里立着一座半塌的圆炉。

圆炉的炉壁已经裂成数块，炉膛内没有跳动的火，只有一团被灰壳包住的暗红。它每隔一阵才亮一下，光不强，却能让整条炉道的黑铁环跟着震动。

窟心炉心还活着。

它后面没有现成的出口。炉壁下方倒是有一道窄门，门板被熔渣封住，门缝里垂着一根断裂的送火管。管子的断口朝外，像一只张开却没有接到下一处的手。

火鳞胚在沈燧掌中突然发烫。

他没有把手伸向炉心。

那团暗红也没有烧起来。

可就在封锁阵的红光隔着铁栅再次压下来的时候，断裂送火管里响起了一声极轻的脆鸣。

像有什么东西，在黑暗里找到了它还没有走完的方向。

阮青禾盯着那扇窄门：“那后面是什么？”

沈燧收紧手指。火鳞胚的红线沿着他的掌纹跳了一下，又安静下来。

“不知道。”

他抬起裂路器，走到被熔渣封住的门前。

“但火在往那里走。”

窟心深处又传来一次沉重的换气声。

门缝后的暗红随之亮起，照出一条还没有接上的火路。

沈燧把裂路器的刃口抵住门边。

“都靠墙。”

身后立刻响起挪动和扶持的声音。伤者被拖到炉壁旁，炉工们压住抬架，阮青禾站在最靠近窄门的位置，手指按在残图刻线的尽头。

沈燧看了一眼身后的铁栅。

红光已经爬满了门面。

他没有再等裴照川开口，也没有等炉心给出解释。

裂路器向前一送，熔渣里传出第一声断裂。

火鳞胚在他掌中亮了起来。

这一次，窟心的火没有向外扑。

它沿着那条尚未接上的火路，朝门后黑暗里送出了一线光。

# Primary Fact Summary

- 沈燧带着阮青禾、原有矿工、伤者和五名炉工，从旧矿道岔口进入残图所指的旧风孔与料室。
- 左侧封锁阵持续把火线推向队伍，裴照川通过封锁阵要求沈燧停止深入并接受清点；沈燧拒绝退回。
- 队伍在火流间歇中越过塌陷裂缝，沈燧救回腿伤者并让伤者、炉工和矿工依次通过半埋铁栅门。
- 沈燧没有再次驱动裂路器，只把它作为撬杆抬起铁栅，并在窟心炉道尽头将刃口抵住熔渣封住的窄门。
- 队伍看见仍在发热的窟心炉心，以及窟心后方一根断裂、尚未接上下一处的送火管；窄门后没有现成出口，只有一条暗红的未接火路。
- 火鳞胚在窟心附近发热并沿断裂送火管的方向亮起；沈燧开始撬动窄门，窟心的火沿未接上的火路向门后送出一线光。
