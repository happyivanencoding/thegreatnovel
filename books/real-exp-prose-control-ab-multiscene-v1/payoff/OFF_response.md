# Primary Draft

清晨的雾还没散尽，外门演武场前已经站满了候考弟子。

顾长川站在队列最外侧，右手垂在身边，手指没有完全收紧。肩上的伤隔了一夜没有好，衣袖碰到伤处时，里面还是一阵发紧。他没去揉，只把脚踩稳在石地上。

长案已经撤到场边，封存的名册摆在宁秋禾手边。

她翻开名册，当众点名。

“周既明。”

“在。”

“许照。”

“在。”

“顾长川。”

顾长川抬头：“在。”

几道目光随之落过来。

昨日之前，顾长川连能不能站进这支队伍都不确定。现在他的名字在名册上，身份却依旧只是外门候考弟子。今日若不能拿到合格牌，他还是得离开这条路。

执事从演武台前走出，袖口宽大，声音压过场上的低语。

“本轮升院考核，取台心合格牌，带回本人白线内。”

演武台中央放着一块巴掌大的黑木牌，牌面刻着“合格”二字。台子的两侧，各画着一条白线，顾长川的白线在东侧，另一侧则留给被点中的阻拦者。

“候考者可自行选择对手，也可接受点名。”执事继续道，“阻拦者可以阻挡、逼退、夺位，但不得伤人，不得毁牌。候考者拿牌后，双脚与牌同时回到本人白线内，便算通过。阻拦者若越过候考者白线，立刻离位，不得再拦。”

规则简单，场上的气氛却立刻绷紧。

拿牌不难，难的是有人会挡。

顾长川走进东侧白线，站定后没有看台心的牌，而是先看向对面。

周既明已经迈出队列。

“我来。”他说。

他站到西侧白线内，眼睛落在顾长川右肩上，停了片刻。

“顾师弟昨夜伤得不轻。”周既明语气平平，“这一轮，我替你试试还能不能上台。”

顾长川看着他：“那就试。”

执事抬手。

“开始。”

周既明没有立刻冲。

他右脚微微向外，肩膀沉下去，像是要从左侧切进。顾长川没有动。

昨夜周既明已经说过，他会改时机。眼前这半步未必是真攻，若他现在提前离线，周既明只要一收，顾长川就会先乱。

周既明脚跟压实，左肩忽然一沉。

顾长川仍没动。

下一刻，周既明的右脚收回，身体只往前探了半寸，便停住了。

场边有人低声吸气。

周既明盯着顾长川，像是在等他抢先露出破绽。

顾长川也盯着他。

他要的是周既明真正压上来的一刻。许照那一步只能用一次，不能拿去追一个假动作。

周既明脸色微沉。

他忽然向前踏出一步。

这一步比先前快得多，脚底砸在石台上，肩、胯、腰同时往前送。顾长川右肩的伤在这一瞬先紧了起来，身体下意识想往后退。

但周既明的重心已经过了前脚。

这次是真的。

顾长川动了。

他先换脚，右脚斜着退出正面，左胯随即转开。周既明的手臂从他原本站的位置压来，带起一阵劲风。顾长川没有抬伤着的右肩去硬挡，只把身体侧过去，前臂贴着来力往外一带。

周既明这一击没能压中顾长川胸口，力量从顾长川身侧擦了过去。

顾长川借着这一带，整个人转到周既明外侧。

他看见了台心的黑木牌。

一步。

他冲到牌前，弯腰把合格牌抓进左手。

“拿到了！”场边有人喊。

周既明已经转身追来。

刚才那一击落空，他前冲的势头却没有完全收住。顾长川没有回头和他拼，只把牌攥紧，朝东侧白线跑去。

回身卸力步已经用完了。

那套换脚、转胯、带开来力的动作，随着他拿到牌的一刻从身体里散掉。顾长川知道自己再想用，也用不出来。

剩下这段路，只能靠自己的脚。

周既明从后方逼近，脚步极快。他没有再做完整招式，只不断压向顾长川回线的方向，想把顾长川逼到白线外侧。

顾长川胸口发闷，右肩每次摆动都像有针扎进去。他没去抢更快的直线，而是贴着台边绕开周既明伸来的手。

周既明横步拦在前面。

顾长川脚下一停，左肩虚晃，随即从另一侧挤过去。

周既明转得更急。

他已经不想只把顾长川挡在牌外了。顾长川离白线只剩几步，只要再被逼偏一次，带着牌跨过线外，刚才的取牌就全白费。

“你过不去。”周既明低声道。

顾长川没有回答。

他看着白线，强压住右肩的痛，向前迈步。

周既明从侧面撞来。

顾长川没硬顶。他侧身让开半步，肩膀擦着周既明的衣袖过去。周既明为了继续截住他，脚下收不住，整个人又向前追了一步。

这一脚越过了东侧白线。

执事的声音当即落下。

“周既明越线，离位。”

周既明脚步猛地停住。

他站在白线内侧，离顾长川只剩一步，却不能再伸手。

顾长川没有回头。

他最后两步踏进白线，把黑木合格牌按在自己脚边。

执事走到台前，目光先落在合格牌上，又看向顾长川双脚的位置。

“取牌，回线，成立。”

宁秋禾从场边走来，翻开封存名册，在顾长川名字旁落下一笔。

那一笔很轻。

顾长川却盯着它，半天没有移开视线。

昨日他只是从分流名单前抢回了一个候考位置。今日这一笔落下，才说明他真的从公开考核里拿到了合格资格。

他喉咙有些发紧，手却仍压着那块牌。

周既明站在白线另一侧，脸色不好看。

他改了起手，藏了前面的动作，也没有再给顾长川看完整招式。可顾长川没有追着他的假动作跑，硬是在他真正压上来时，从正面脱开，先拿到了牌。

周既明盯了顾长川片刻，才道：“你昨夜看的，不止是步子。”

“我看的是你什么时候真要打。”顾长川说。

周既明没有反驳。

许照从队列里走出来，看了一眼顾长川，又看了看宁秋禾名册上的新笔迹。

有人忍不住问：“顾长川，你刚才那是什么步法？你什么时候学会的？”

顾长川把合格牌交给执事。

“我刚才用过一次。”他说，“现在没了。”

他没有提许照，也没有说那套步法的起手、转胯和落点。

许照听完，神色没有多少变化，只朝宁秋禾点了一下头。

“他守约了。”

顾长川看向她。

许照也只看了他一眼，便退回队列。两人之间那笔交易到这里没有变成什么交情，只是彼此都知道，对方没有赖账。

执事收起合格牌，宣布下一人入场。

场上的人散开，又有人走向白线。顾长川却没有立刻离开。他站在原地，肩上的伤终于在停下来后翻得更重，胸口也像压着一块石头。

宁秋禾合上名册，对他说：“本轮公开升院合格，记下了。”

顾长川抬起头。

“我现在算内门弟子了？”

“还不算。”宁秋禾说，“合格只是合格。正式入内门，要等后续报到。”

顾长川点头。

他没有失望。

至少从今天起，他不再是那个随时会被分流下山的外门候考弟子。前面的门还没有完全打开，但门上已经留下了他的名字。

周既明从另一侧走下演武台，经过顾长川身边时停了一下。

“下次，”周既明说，“我不会再让你等到这么好的位置。”

顾长川抬眼看他。

“那我就自己找。”

周既明看了他一眼，转身离开。

演武场上，清晨的雾终于散开了。

顾长川站在白线内，右肩还疼，胸口也还没缓过来。那一次借来的步法已经消失，手里也没有多出一门现成武技。

可他已经通过了这一轮公开考核。

接下来要去哪里报到、能拿到什么，都还没发生。

他只先把背挺直，走下演武台。

# Primary Fact Summary

- 宁秋禾按封存名册公开点名，顾长川仍以外门候考弟子身份参加升院考核。
- 执事宣布规则：候考者须在阻拦下取得台心合格牌，并把牌带回自己的白线；周既明主动成为顾长川的阻拦者。
- 顾长川没有追逐周既明的假动作，在周既明真实进攻后使用一次回身卸力步脱开正面、取得合格牌；该步法随即消失。
- 顾长川以普通脚步带牌回线，周既明为继续阻拦越过顾长川白线，被判离位。
- 执事与宁秋禾确认顾长川本轮公开升院合格；他尚未正式入内门，报到与后续资源仍未发生。
- 顾长川没有泄露许照的步法细节，也没有声称已经学会；许照当场确认他守约。
- 周既明成为顾长川公开竞争者；顾长川右肩和胸口的伤势仍在。
