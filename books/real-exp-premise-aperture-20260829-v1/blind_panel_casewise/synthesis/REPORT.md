# CASEWISE PANEL SYNTHESIS

评审列顺序：`commercial / cold_reader / longform`。均值按三位评审的 Overall 等权平均，保留一位小数。未使用此前 batched panel 分数，也未使用 Top 3/Decision 文本。

## Data Integrity

- 3 个题材 × 3 位评审 = 9 份独立 case-wise 盲评。
- 每题材 7 个匿名方案，均可由映射唯一解盲为 B0、S1-S3、C1-C3。
- 每个来源候选均有 3 个 Overall 分数。
- B0 作为单一现有方案；S 与 C 分别作为三候选池处理。
- 本报告只对表内 Overall 做算术汇总，不重新解释九轴分数。

## Generator Ceiling / Floor / Stability

定义：ceiling/floor 按候选三评审均值取最高/最低；pool mean 为三候选均值的等权平均。稳定性为同一来源候选的最大评审跨度。

| 题材 | B0 | S ceiling / floor / mean | C ceiling / floor / mean | 稳定性 |
|---|---:|---:|---:|---|
| 通用玄幻成长 | 76.3 | 88.7 / 83.7 / 86.2 | 76.7 / 69.7 / 72.6 | B0跨度7；S最大跨度5；C最大跨度19 |
| 20章一世界快节奏长篇 | 68.0 | 87.7 / 82.3 / 84.8 | 74.7 / 68.0 / 70.2 | B0跨度23；S最大跨度9；C最大跨度20 |
| 游戏副本／无限流 | 83.0 | 89.3 / 81.0 / 84.2 | 76.3 / 67.0 / 72.4 | B0跨度13；S最大跨度11；C最大跨度16 |

结论：

- S pool 均值在三个题材分别领先 C pool `13.6 / 14.6 / 11.8` 分。
- S pool 的评审跨度整体小于 C pool，稳定性更高。
- 游戏副本题材中 B0 很强，均值仅低于 S pool `1.2` 分；但 S3 仍形成最高 ceiling。
- 跨三题材等权平均：S pool `85.1`，B0 `75.8`，C pool `71.7`。

## Cross-Reviewer Consensus and Disagreement

共识：

- 通用玄幻成长：三位评审完全一致地给出 `S2 > S1 > S3` 的前三顺序；C1 三位均为该题最低分。
- 20章一世界快节奏长篇：三位评审都把 S pool 的三个候选放入前三，但 S2 与 S3 的第一名发生交换。
- 游戏副本／无限流：三位评审一致将 S3 评为第一、C2 评为最后。
- S2 对 C2 的方向性优势无一例外成立。

真实分歧：

- cold_reader 在三个题材都给出最低的整体分数均值，尤其在快节奏题材中明显低于另外两位。
- 通用玄幻成长中，C2 的三评审跨度为 `19` 分，C3 为 `15` 分；C pool 内部排序不稳定。
- 快节奏题材中，B0 跨度为 `23` 分，是九个来源候选中最分裂的一组；C2、C3 也分别有 `20`、`17` 分跨度。
- 游戏题材中，S3 与 S2 的评审跨度仅 `1` 分，属于最稳定的高分候选；B0 跨度为 `13` 分，说明其高分主要受到 longform 评审拉升。
- S2 对 C2 的优势幅度，cold_reader 始终最大：三个题材分别为 `26 / 25 / 24` 分；longform 三题材均为 `14` 分。

## Evidence-Bounded Freeze Implications

- 仅按 Overall，S pool 在三个题材都优于 C pool；这一来源级结论可冻结。
- 预注册比较 S2 vs C2 在三个题材均为 S2 胜出，合并优势为 `+16.3` 分；这一比较结论可冻结。
- 不能冻结“单一 S 候选跨题材统治”：通用玄幻成长 ceiling 是 S2，快节奏与游戏题材 ceiling 是 S3。
- 不能把 B0 统一判定为落后：它在通用玄幻和快节奏明显落后于 S pool，但在游戏题材高于 S1、S2，仅低于 S3。
- C pool 的 floor、内部排序和评审跨度均较不稳定；对 C1-C3 的细粒度排序应保留为分数事实，不应外推为更强的架构结论。
- 本报告支持冻结的是来源池与预注册对比的统计结果，不支持仅凭 Overall 冻结具体内容机制、商业解释或架构因果。
