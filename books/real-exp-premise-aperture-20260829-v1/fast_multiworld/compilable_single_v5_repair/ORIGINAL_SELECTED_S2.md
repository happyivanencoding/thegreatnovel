## S2｜《一城吞门》

### 一句话货架简介

他不是修士，而是一间刚出生的活房子；凡是穿过他门口的东西，都会变成他身体里的一部分。

### World-only Direction

这是一个所有强者都以“壳层”衡量的世界。

主力量尺只有一条：城壳尺。

- 0｜散物：没有稳定内部空间。
- 1｜室壳：拥有一间完整内部空间。
- 2｜院壳：拥有可自持的多个房间。
- 3｜堡壳：能承受小型攻城。
- 4｜坊壳：能庇护一片街坊。
- 5｜城壳：能独立承受一场城级战争。
- 6｜域壳：内部空间可容纳多座城。
- 7｜天城壳：能在空中或灾变地形中独立移动。
- 8｜山门壳：能封锁一条大型世界通道。
- 9｜界壳：能成为本地世界最高边界的承载体。

每七日一次“门潮”经过地表。门潮不会移动建筑，却会在一个时辰内重新交换完整门槛的连接方向：一间屋子的门可能通往邻屋，一座城门可能通往旧堡，仓库、牢房、庙宇和民宅因此不断改变进出口。

普通人最在意门锁、避门潮路线和能保持原位的老门。真正值钱的是完整的高阶壳体、不会被门潮改向的镇门，以及拥有巨大内部空间的古代建筑。

世界在没有主人公时也会持续发生：

- 城市因门潮突然失去粮仓；
- 高阶壳体被拆成战争材料；
- 一座没有主人公的古城试图吞并邻近堡垒；
- 普通人为了保住自己的门口而迁徙、结盟或反抗。

### World Interface-only Direction

凡是有五名以上清醒见证者同时看见的门口通行，门框两侧会留下十二小时“门影”。

门影只能无声回放谁从哪一侧进入、从哪一侧离开，不能被再次穿越，不能改变真实门的方向，也不能储存人或物。

门影会影响所有相关行动者的证词、所有权、追捕和交易，但不会复制、放大或改写任何 Power。

### Protagonist Ontology-only Direction

主角是“活城胚”，不是人类、灵魂或寄宿者。

活城胚的身体由以下部分组成：

- 核心地基；
- 内部空间；
- 门、窗、墙和承重结构；
- 能够通过震动、开合和回声表达意志；
- 内部储存的生物仍保有自己的意识和行动权。

活城胚可以移动，但必须保持核心与至少一段完整承重结构连接。它不是建筑的主人，而是建筑本身逐渐长出的生命。

### Initial Origin-only Direction

第一场事件发生前，一枚被拆下的旧城门基石埋在废墟下。

门潮经过时，基石吸收雨水、灰烬和周围三间倒塌房屋的承重力，凝成一间只有一扇门、没有窗户的活房子。

此时它：

- 只有一个房间；
- 没有语言；
- 没有历史记忆；
- 不知道自己属于哪座城市；
- 城壳尺位置为1｜室壳；
- 只能感受到门外有人踩在自己的地基上。

第一场事件从拆迁队准备砸开这扇门开始。

### Initial Scale Position-only Direction

适用主尺：城壳尺。

- 主角 T0 位置：1｜室壳。
- 副尺：不适用。World 没有定义第二条独立的公共力量尺。

### Power-only Direction

Power 名称：吞门成身。

触发条件：

- 一个目标完整穿过属于主角身体的真实门槛；
- 主角主动关闭该门；
- 目标在门关闭前没有主动退回。

目标类别：

- 非生物物件；
- 完整建筑结构；
- 动物；
- 人类或其他有意识生命。

可做的动作：

- 把目标收纳进自身内部；
- 保留目标的真实形态、重量和功能，不复制、不转化；
- 在自身任意现有门口重新打开目标；
- 重新排列内部房间、门和墙的连接关系；
- 把被吞入的建筑部件接到核心承重结构上，使身体扩大；
- 通过内部空间移动，改变自身外部出口的位置。

永久边界：

- 目标必须真实完整地穿过门槛，不能隔空吞入；
- 目标的真实体积仍然存在，内部空间不足时门无法关闭；
- 不能复制目标；
- 不能控制被吞入的活物；
- 被吞入的活物可以破坏内部结构、拒绝合作或寻找出口；
- 只有与核心形成实际承重连接的完整结构，才能提高城壳尺位置；
- Power 不赋予主角凭空造物、远程传送或意识支配。

### Story Interface / Opening Promise

第一章的承诺是：

一间只有一扇门的房子，被拆迁队当成废墟砸开；第一个闯进来的人发现房间内部比外面大得多，而他身后的整座棚屋正在被门一点点吞进去。

此后，主角每吞下一座房、一段城墙或一个活人，就会获得新的身体部位，也会获得新的内部冲突。

他的成长不是获得装备，而是逐渐变成一座谁也无法忽略的移动城市。

### Authority-Compilation Trace

1. 拆迁者完整走入活房子的门内
   → 来源：Initial Origin-only Direction、Power-only Direction
   → 触发已满足：目标完整穿过身体门槛
   → 目标：拆迁者及其携带的工具
   → 合法性：目标是可进入门槛的活物与非生物，属于 Power 明确覆盖类别。

2. 活房子主动关门
   → 来源：Protagonist Ontology-only Direction、Power-only Direction
   → 触发已满足：主角具备门与意志，可主动闭合
   → 载体：唯一真实门
   → 合法性：不是远程捕获，而是身体动作完成后的收纳。

3. 拆迁棚屋被收入内部
   → 来源：Power-only Direction
   → 触发已满足：棚屋的主体结构完整穿过门槛，内部空间足够
   → 目标：一座真实棚屋
   → 合法性：棚屋没有被复制或变成抽象道具，仍占据真实内部空间。

4. 主角把棚屋重新从后墙门口打开
   → 来源：Power-only Direction
   → 触发已满足：棚屋已经成为储存结构
   → 载体：主角已有后墙门
   → 合法性：Power 允许重新开启已吞入目标，但不允许凭空生成第二座棚屋。

5. 主角从1｜室壳升到2｜院壳
   → 来源：World-only Direction、Power-only Direction
   → 触发已满足：棚屋与核心通过实际承重结构接通
   → 目标：主角自身壳体
   → 合法性：城壳尺的升级条件由 World 与 Power 共同写明，不由 Story 临时发明。

6. 旁观者通过门影回看拆迁过程
   → 来源：World Interface-only Direction
   → 触发已满足：五名以上见证者看见通行
   → 载体：门框两侧
   → 合法性：门影只回放通行，不让任何人或物再次穿越。

### 第一章标志性画面

铁锤砸穿墙面。

墙后不是黑暗，而是一条比整座棚屋更深的长廊。

第一个拆迁者踏进去，脚下的地板忽然向后延伸。等他回头时，门已经关上，外面的棚屋正在从地基开始缩进这间小房子。

### 主角反复会做的新动作

- 把敌人的武器库、牢房和城墙吞进身体；
- 把活人困在自己的内部空间，却不能命令他们；
- 把体内不同房间重新接成陷阱、通道或战场；
- 让敌人从正门进来，却从厨房、塔楼或地下门出去；
- 用自己的身体承载一群必须共同生活、却彼此敌对的人；
- 在门潮改变世界路径时，成为唯一能保持内部秩序的移动地点。

### 第一次不公平兑现

一座棚屋正在被拆迁队点火。

主角只有一间小房子，却在火焰烧到门槛前把整座棚屋吞入体内，再从拆迁队身后打开同一座棚屋。

敌人以为自己在烧一间废屋，下一刻却被整座屋子的墙、梁和火焰从身后撞倒。

### 20章玩法扩张

- 第1—3章：活房子出生，吞下拆迁棚屋，第一次把人关进内部。
- 第4—6章：门潮改变周围村镇的连接，主角利用内部门路逃离追捕。
- 第7—10章：主角吞下一段街墙，内部出现互不合作的活人和建筑结构。
- 第11—14章：多个势力争夺一座尚未崩塌的高阶古堡；主角必须决定吞下古堡，还是把它留给原住者。
- 第15—17章：门潮扩大，整座城区的出口错乱；主角把既有建筑接入核心，成为真正的移动壳体。
- 第18—20章：本地最高壳体与门潮源头发生冲突。主角吞入现成的界壳核心并完成承重连接，达到城壳尺9｜界壳，决定本地城市与门潮的最终归属。

第20章后输出 World Horizon Handoff：只说明主角已经成为界壳、哪些建筑结构和关系被携带、下一次扩张由什么规则冲击触发，不预写下一世界的地点、敌人或解决方案。

### 100章以上仍能长出的不同故事

- 主角携带的建筑会成为身体、家园、牢笼和政治冲突的同时存在；
- 每个被吞入的活人都可以拒绝成为主角的一部分；
- 他的身体越大，越难假装自己只是一个人；
- 某些世界会把他当成城池，某些世界会把他当成怪物、灾害或移动圣地；
- 他可以失去一扇门、拆掉一段墙、舍弃一个内部区域，也可以为了保住其中的人而牺牲战斗优势；
- 后续世界只需要改变“什么东西能够成为壳、什么边界值得占有、谁有权住进身体”，不需要替他重置能力。

### 最小可信桥梁

只需成立三件事：

1. 门潮使“门”成为世界中真正决定生存、财富和战争的接口；
2. 活城胚的身体天然由门、墙、房间和承重结构组成；
3. Power 只收纳真实穿门目标，并通过真实连接扩大身体。

### 不可磨平的三点

- 主角必须是“一间刚出生的活房子”，不是住在房子里的灵魂。
- 吞入的活人必须保留自主意志，不能被降格成库存。
- 他的身体成长必须直接改变占有、移动、战斗和关系，不得退化成城建管理游戏。
