### Fixed Naming Craft Reference
source: syntheses/reader-facing-naming-craft-v1
role: Power Seed 固定 reader-facing 命名参考；不占 creative inspiration 名额

可用抽象：Guidance：先把对象写成白话：它是什么、对谁起什么作用、出现什么可见结果、有什么永久边界；若这层未成立，不造正式名。命名先保证读者不会误判当前行动，再补世界气味。类别可由名称、句法、持有动作或人物关系承担，不设固定字数、四字格式或统一后缀；高压战斗优先动作、对象、部位、轨迹或结果，器物优先形制、材质、用途与代价，境界优先可比较位置，势力和地点优先社会职能或空间结构。一个名称先突出一个主差异，只有会改变读者选择的来源、关系、限制或等级信息才并入，并须能拆读。抽象名或陌生名可以留白，但首见附近必须有类别、关系、风险、数量或一次兑现，不能让生词互相解释。只给反复出现、会影响决策、可争夺或社会流通的节点命名；普通动作、临时材料和无后续背景不命名。词族只在真实的来源、制造、持有、继承、制度或升级关系存在时建立，且每个派生项要有独立功能。lexique 只用于创意未成形时的“对象×变化”偏航；机制成立后，只有在**不牺牲语义准确**时才优先用世界已有具体词根，也可不用。已有普通短名如果已经准确、顺口、低学习成本，不为“更独特 / 更世界化”强行改写；世界贴合与气味都低于首读准确。气味不能补救语义错误；名字承诺的机制、代价和尺度必须由正文兑现。

使用边界：只迁移 source-blind 的 reader-facing 命名规律，不迁移任何来源作品专名、人物、势力、招式、地点、固定词根或句式。Lexique 不是经典证据、Canon 或待选名字库；它可以在 Power 创意期作为可丢弃的对象×变化 primitive，也可以在机制已经成立后提供少量 Naming Fragrance，但不得反向授权新机制。World 已有词根优先；名字若比已批准能力多承诺来源、对象、代价、等级或第二系统，应改名字而不是扩写能力迁就名字。

### Inspiration 1
source: syntheses/reader-facing-world-coordinates-batch-d-v3
type: synthesis
score: 0.1907

可用抽象：Guidance：World Vision 使用两类坐标。第一类是**世界前台尺**：至少建立一把当前主尺，生产注入优先从 `POWER / TECHNIQUE / THREAT / STATUS / VALUE / WORLD` 中选择；题材明显依赖装备/法宝或天赋上限时，可条件性加入 `GEAR_ARTIFACT / POTENTIAL_CEILING` 校准。它们回答“现在谁能做到什么、差距造成什么结果、什么东西真值、下一层世界有什么”。第二类是**读者体验 / 故事校准尺**：`ACTION_SPACE / MYSTERY_DEPTH / EXPECTATION_LADDER / IMPACT`（必要时 `REACH`）仍然必须真实参与生产设计，但只作为作者侧坐标——分别投影成“成长后多能做哪件以前做不到的事”“哪个旧锚点仍有可回收的更深解释”“下一层已经看得见但尚未取得的具体人/物/地点/能力/身份”“一次行动实际改变多少人物、关系、地点、阵营或世界状态”。它们不得变成世界内部正式术语、资源名、势力理念或主题命题。`TEMPORAL_SCALE` 继续 HOLD。不要逐项填满，也不要建立战力数据库。

使用边界：只迁移当前卡片的抽象机制，不迁移来源人物、事件、专名、世界设定或句式。

Repeatable Reader Loop：被迫提取或审问→展示资格/贡献→获得准入、庇护或记录位置→进入更稳定的关系与资源网络。
Core Progression Grammar：当前局部样本显示 progression 主要通过资格、贡献、登记和保护关系推进，而非可核验的境界数值。
Payoff Grammar：SURVIVAL_ESCAPE；STATUS_RISE；RECOGNITION；RELATIONSHIP_ADVANCE；RESOURCE_GAIN；WORLD_EXPANSION；FACTION_ADVANCE；STRATEGIC_ADVANTAGE
Advantage / Special Capability：稀有资格或可被组织识别的特征可能吸引保护；ability delight 与 power verification 在当前来源中 NOT_MATERIAL，不把社会资格伪写成战力能力。
World Expansion Grammar：局部可见的是审问/城市资格/登记与保护网络；更大修真世界 UNKNOWN。
Novelty / Recombination：把强制提取、资格审查、贡献登记和保护关系组合成以归属为核心的局部 progression。
Social / Relationship Dynamics：保护、登记、贡献与归属是当前最强证据，关系 payoff 直接成立，不应被自动降格为责任。
Resource / Economy：贡献、资格、城市准入、登记和庇护是局部可见资源；修炼资源、恢复和交易账本 UNKNOWN。
Optional Constraints / Costs：可见约束是审问、隐…

使用边界：只迁移社会闸门与归属变量；不迁移具体身份、修炼能力、人物关系、开篇或结尾。

### Inspiration 3
source: mechanisms/mech-disclosure-repricing-ripple-v1
type: mechanism
score: 0.0973

可用抽象：Creative Problem：主角有一项明显超出世界正常值的优势，但人物看见后仍照旧行动，导致“作者知道他特殊，世界却没有真正经历他的特殊”。
Mechanism：1. **限定证据**：先明确谁通过亲眼、专业推断或二手来源实际知道什么；不知道的机制与边界继续未知。
2. **观察者自己的尺子**：普通人、专家、rival、利益方、敌对者、亲近者用不同的正常值判断同一结果。
3. **Repricing 兑现成动作**：旧方案不再合理时，观察者必须换一种做法——例如重测、改报价、改战术、退距、保护、追问、控制消息或重新安排关系。
4. **Ripple 有后文门槛**：只有下一场或更后面的独立行动仍被该重估改变，才进入长期 Canon；当场震惊、口头威胁、招揽意向都不是 Ripple。
5. **保留部分知识与误读**：社会可以正确知道“这个人很危险/值得争夺”，同时错误理解为什么；角色依据自己的模型行动，不把推断冒充世界真相。
6. **停止**：新模型已经改变下一动作后，立刻进入该动作的新机会、风险、Counterplay 或关系压力，不继续证明大家有多震惊。

使用边界：迁移“信息状态 → 观察者定价 → 行为变化 → 有证据的后续涟漪”的因果，不迁移来源人物、势力、称号、测试制度、具体反制或台词。
