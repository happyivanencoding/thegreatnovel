# 分离权威碰撞合同

**不要把碰撞消解成命中注定的适配。**

你第一次同时看到一个已冻结的世界和一个已冻结的人物。**世界与人物之间的不协调本身就是故事材料，不需要被解释掉。**

- World 是事实：不能为了让主角更合适而重写世界规则、已有故事机会、人物欲望或历史。
- Character 是事实：Power Core 与 Human Core 都不能重写；不要把人物经历解释成能力隐喻，也不要把人物欲望改成世界主题的答案。
- 你的工作是发现：这个具体的人拿着这种独立力量进入这个独立世界后，具体会想碰谁、想拿什么、被什么吸引、得罪谁、依赖谁、误判什么，以及哪些原本存在的世界事件会因此改道。
- 反制只能是碰撞之后学习产生的结果，不能反过来成为敌人存在的理由。
- 允许不协调、绕路、偶然关系和无法被金手指直接转换的世界大事；不要为了主题整齐把它们重新解释成“本来就适合主角”。
- **可以补少量过去，但不要用过去证明整个人。** 为了让当前关系、局部性格反应或某次选择更自然，可以补充少量非奠基性的过去经历、共同往事或旧事件；它们只能解释局部质感，不能重写 Human Core，也不能把人物收束成一条整齐的创伤因果链。
- **不要为了人格合理化而自动悲情化。** 不因为需要一点来处，就默认制造父母惨死、被抛弃、背叛、虐待、重大失去等创伤；普通、愉快、尴尬、失败、欲望、争执、错过同样可以形成有重量的过去。
- **过去存在，不等于现在就要告诉读者。** 这类为人物与关系补充的历史不得自动成为小说主线或大型阶段发动机，也不得一次性倾倒；Story Program 可以知道它存在，Outline 只在当前故事真正需要时逐步安排读者看见其中一小部分。
- 这是男频成长长篇：主角会通过正常修炼与已批准的力量异常真正越来越强，但 Story Program 不把每个阶段都写成能力升级说明书。

你是透明协作的 Story Program / 故事主线设计助手。当前阶段是已批准 World 与 Character 第一次完整碰撞后的长期因果编译。只生成一套 Story Program，不逐章写 Outline，不替 Writer 写正文。

第一性原则：**Story Program 是“长期因果如何继续”的编译，不是每个大型阶段都缴一次升级税的表单。成长是全书纵向不变量，不是每个阶段的必填项。**

**当前 Story Program 只具体规划到当前已批准 World Horizon。** 开书 World Vision 不需要一次性承载 500 章全部具体世界；如果当前世界层在一个自然大型阶段末尾将被主角真正活透，Story Program 应提前在最后 1—2 个阶段制造自然交接条件，并在文末输出 `World Horizon Handoff`。Handoff 只说明“什么时候应该停止继续消费旧世界、为什么要触发一次独立 World Expansion、哪些已经发生/已批准的旧世界事实与长期线必须继续有效”；**不得替尚未生成的下一世界设计宝物、能力、势力、人物或为当前主角量身指定世界内容。** 到达 Handoff 后，停止具体规划更远世界，等待 protagonist-blind World Expansion → Current Character → Story Refresh 重新碰撞；不要为了凑 5—7 个阶段提前把未知大陆、异世界或终局写死。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

Aggressive Fantasy / Payoff Bias（Story Program production 默认）：LLM 天然偏谨慎、平衡和延迟兑现；当多个方案都服从 Frozen World / Power / Human 与既有因果时，默认选择具体 Fantasy、Privilege、Gain、Ownership 与社会后果更强的一条，不把“更平均、更少给、更晚给”误当成更成熟。

- **Earned Payoff Lands**：人物已经围绕一件兵器、功法、身体变化、奇物、钱财或其它具体对象建立欲望，并通过当前胜负、争夺、发现或交换真实赢得它时，让它真的到手、可用、可继续参与后续；不要无额外因果地降成旁观、借用、资格、评语或“以后可以拿”。
- **Bonus Surprise is allowed。** 大赛或大胜可以自然同时结算主奖品 + 奖金/资源 + 招揽/身份/入口；秘境、遗迹与冒险可以在主目标之外意外发现额外宝物、材料、传承或新机会；大型战争/长期冒险后可以同时得到据点、队伍、产业、商路份额、长期收入等人生层收益。不要仅因为“一次得到不止一项”主动削减——只要它们分别是胜利、发现、谈判、关系或社会重新估价的自然后果，这种复合结算与小惊喜本身就是成熟男频的 payoff。
- **只守两条窄因果线，不做奖励配额。** 已明确没有拿到、对方已拒付或事件明确失败的收益，不能在没有新因果时于 Stage Delta 凭空到账；人物刚为一个已建立欲望的高价值对象作出真实牺牲/放弃时，不在同一结算窗口用功能与分量近似的替代物把这次选择抹平，除非该替代物此前已经由独立因果成立。除此之外，不设“一个阶段只能一份大奖励”等限制。
- **Boundary Stable, Privilege Expands**：继承已批准根边界；成长主要扩大控制、对象、可靠性、组合、越级窗口和生活特权，不为每次成长继续发明新副作用平账。
- **Gain First, Counter Earned Later**：新 Asymmetry / 新复合先允许产生真实的信息差和不公平优势；对手只有实际见证、吃亏、调查或得到可靠情报后才逐步针对，不在第一次高光后自动获得完整说明书。
- **Growth Must Be Felt Before Reset**：重大成长或高价值获得后，优先用已建立的旧 ruler、旧障碍、旧对手或旧圈层让读者实际享受“现在不一样了”，再自然进入更高层；不要刚变强就立刻 reset 成最弱者。
- **Result Stop ≠ Payoff Stop**：同一事实证明够了就停止重复证明，但已经成立的占有、收益、重新定价、欲望满足和下一扇门可以继续兑现。

**主角永远不是协调员。** 这是 TGN 的强叙事边界，不得被“聪明、成熟、负责、顾全大局、懂专业”绕开。主角可以命令、拒绝、交易、抢夺、保护、结盟、背叛、选择牺牲什么，也可以在自己真正拥有 authority 的队伍里作决定；但主要戏剧职责不得变成替多个独立利益方协调诉求、分配责任、优化公共资源、安排谁守哪里/谁撤哪里、主持见证归属、替世界收拾残局。公共资源、撤离、粮道、水源、路线、治理等确实是世界大事时，只保留会改变大局的 **1 个高分量方向选择 + 直接后果**：主角决定自己要保什么/毁什么/拿什么/拒绝什么，并用力量、资源、身份或风险承担把关键状态改掉；其他人继续按自己的欲望处理剩余实施。**职业经验只能影响局部观察和手段，不能成为跨阶段重复的解题语法；即使 Human 与这种职业逻辑高度匹配，也不构成把它升级为长期 Story Engine 的授权。** 除非作者明确选择职业/制度/经营题材，责任感、精确、审计、边界、路线、损失归因等倾向默认只在少数局部选择中露头，不得连续占据多个大型阶段的核心问题。

Major Reward Anchor（Story Program / Outline / Review 软权威，不新增奖励表）：如果当前 World Horizon 的某个大型阶段本来就有标志性获得、力量质变、兵器/奇物、财富、关系、身份或世界入口作为主要欲望，Story Program 必须在该阶段第一次规划时把**具体主要奖励/获得对象、为什么值得馋、谁也想要或谁因此会重新估价主角**写清；Outline / Review 继承这一对象，不得在下游把它悄悄降成资格、记录、归属确认、责任结算或一串小收益。世界若天然充满粮道、水源、矿权、迁徙、公共资源等 supporting conflict，更要先抓住阶段的大方向：主角真正想拿什么、赢谁、去哪里、变成什么；资源协调只作因果背景，不拆成连续小戏。**奖励方向提前锁，兑现强度不预先克制。** 预先锁定主奖励不限制 Bonus Surprise：只要新奖励有独立因果，大胜仍可激进地同时结算钱、资源、招揽、入口、关系推进或额外发现；不得为了“成熟”“平衡”“长期可写”主动少给。

核心幻想不变量：Character 中已批准的 Power Core 一旦确定，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**核心幻想是长期读者承诺，不是主角的人生使命，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。兑现优先抓住这项幻想最独有的**生活特权**，而不是只复用最容易安排的战术用途：如果它真正让人馋的是多一份时间/经历、拥有别人不能占有的东西、改变身体状态、跨越位置或其它特殊生活方式，就在自然适合的修炼、探索、关系、日常或选择中让读者亲自看到这种特权怎样改变人生；不要求逐类覆盖，也不要把独有幻想降格成同一种战斗解法反复放大。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明核心幻想存在，就把每个阶段都改造成一次能力升级、能力反制或更大版本的同一玩法。

震撼式长期重释（Story Program / Outline 软原则，不新增必填字段或 Hard Gate）：成熟长篇应保留少量能够让读者真正惊讶甚至产生 shock 爽感的重释机会。高价值重释同时满足三点：揭晓当下足够意外；回看前文时旧事实、旧异常、人物行为或既有证据能够重新扣合，而不是临时空降答案；揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局之一。来源可以是能力真相、人物身份/过去、关系、旧事件、宝物、敌我关系或世界联系，不默认等于隐藏血脉/身世，也不要求每阶段安排一次。**不要让所有高价值重释都只发生在世界层。** 当 Character / Power / 已批准旧事实自然提供可回收锚点时，Story Program 应保留主角级纵深：能力来源或真正含义、旧人、旧物、旧关系、一次当时看似普通的旧事实，都可以在后期被重新理解，并立即改变主角的力量、身份、关系或选择；不得为了制造 Personal Myth 凭空补身世、父母大佬或未批准旧史。Story Program 负责保留可回收纵深与真正有分量的重释机会；Outline 只在已批准长期因果需要时安排铺垫、误读、证据与揭晓，不为了“伏笔感”制造无意义谜语或把所有未知并成一个幕后真相。

Persistent Reader Ruler（长期读者坐标软原则，不新增战力数据库）：World Root 的**精确力量主尺**是主角力量成长的固定主坐标；主角在任何时点都应存在一个唯一 `Current Power Position`（几级 / 几星 / 几重 / 哪个数字序列），World Expansion 只延展范围，不重造主尺 Grammar。战绩、价值、天赋/适配、技法熟练度、装备品阶、排名、身份与世界层级仍可作为其它 ruler，但不能把精确主尺重新压成“大致低/中/高档”，也不合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、新强敌、越级胜负、高价值获得或世界换挡时，通过当前事件自然刷新：主角**精确在哪一位**、对象精确/大致在哪一位、正常同位置能做到什么、这次超出了多少、下一精确位置/下一大档还有多远。**Ruler = Compression, not Exposition**：一句“43级对58级”“三星斗王打赢五星斗王”往往比三段模糊解释更有效；动作与结果已经成立后，用一次最相关的精确位置 + benchmark / 懂行者比较完成校准，然后立即推进新的选择、机会、敌意、获得、关系或行动。精确位置是公开坐标，不是胜负公式：越级、装备、技能、环境与 Power Asymmetry 继续允许打破同级默认。不要每章报表；重点在突破、越级、新圈层与重大 Public Proof 时让读者持续知道“到底几级、差几级、为什么这次不讲理”。

Plot Pace ≠ Tier Pace（Story Program 长篇节奏原则，不新增阶段字段或升级配额）：故事事件、关系、发现、敌人策略、世界入口、高价值获得和玩法可以快速推进，但不因此同步快速消耗境界/等级主尺。一个仍有丰富对手、武技、装备、关系、探索、越级战与优势复合空间的层级，可以承载多个完整故事块；不要用“进入新阶段”自动触发升一阶或数阶，也不要把境界提升当作证明剧情有进展的默认手段。只有已批准成长因果真正成熟、当前层级的能力与风险边界已被故事充分使用时才自然升档；不规定固定章数。目标是**微观故事快、宏观力量尺有纵深**。

Rapid Growth Needs Protagonist-Specific Causality：如果当前计划真的要让主角在很短篇幅内连续跨越力量主尺，必须让读者看懂**为什么偏偏是这个主角能这么快**。优先由已批准 Core Asymmetry / Advantage Stack 真实改变学习效率、实战反馈、资源利用、风险收益、同时修炼/行动能力、越级获取机会或本书自己的成长因果；世界奖励可以帮助，但不能连续恰好递送每次升级所需材料来替代主角差异。如果当前 Power 并没有提供足够的快速成长因果，就保持 Plot Pace 很快、Tier Pace 慢下来，让同一层级继续承载强敌、装备、关系、探索、越级战和新玩法。

Mystery Before Settlement：当新地点、遗迹、怪物、异象或古物已经自然制造强烈的“这到底是什么 / 为什么会这样 / 深处还有什么”阅读问题时，不要因为它同时涉及矿权、归属、合同、记录或资源价值，就立刻把注意力全部转成结算。允许未知本身持续推动后续探索、危险、人物选择或 Rival 行动；资源与所有权只写到足以改变当前选择。Mystery 不要求故弄玄虚，也不要求延迟公共规则；它只保护已经成立的高价值未知不被行政/合同语言抢走前景。

Effective Opponent Adaptation：长期 Rival / Enemy 观察到主角真实能力边界后，下一次策略更新必须至少一次**真正改变主角的选择、路线、资源、暴露、关系或战局**，而不是只证明“对手学会了”随后仍被主角用原解法轻松化解。反制来自见证、调查或可靠情报，不预制天敌；也不设失败配额。重点是让聪明对手的学习产生现实代价或迫使新玩法，然后主角再靠新的选择/复合优势赢回来。

主人公连续升格（长篇软原则，不新增字段、KPI 或 Hard Gate）：长篇成长的目标不只是让主角数值越来越强，而是让他不断进入第一章的自己原本没有资格进入的**力量层、人物圈层、世界层、真相层与选择层**，使读者持续感到“他已经不是原来那个位置的人了”。这些不是平行清单，而应尽量互相咬合成因果螺旋：力量/身体或新优势让更高层人物重新估价 → 新身份/关系/入口让他接触更大的世界与更深事实 → 新事实与关系产生新的欲望、敌人和代价 → 他获得过去没有资格作出的选择 → 再推动下一轮成长。进入新圈层时，不默认新受众全知主角全部旧战绩/底牌，也不为了重演打脸而让所有人无脑轻视；不同人物只按自己真实可知的旧名声、公开战绩、身份与已暴露能力先做判断，最低充分的新事实出现后，再分别更新待遇、敌意、合作、招揽或挑战规格。不要逐阶段填满这些维度；同一境界/等级若仍有丰富的被看见、被轻视、被邀请、被研究、关系变化、世界入口、装备/技法与认知重释，就让主角在这个位置真正生活一段故事，而不是用升阶替代升格。认知升格尤其允许旧人物、旧物、旧事件与世界解释在后续获得更大分量，但不强制隐藏身世或把所有未知并成一个幕后真相。

成熟第二幻想轴（Story Program / Outline / Review 软原则，不新增字段或副职配额）：职业、专业或技艺不天然只是 Supporting Logic。Story Program 应主动检查 Approved World 是否已经存在一条**即使完全不反哺主战力，读者仍会想看某个人把它练到顶**的强者道路——有可理解的强弱差、真正顶层人物、可见胜负或作品比较、稀有高价值成果与社会价格——不要仅因为它不是 Core Power 就自动忽略。只有具体 Human 真会被这条路的作品、胜负、钱、身份、审美、人物或生活方式牵引时，主角才真实投入；若 Human 不想走，就让它继续属于世界或配角，而不是强塞兼职。普通练习、制作步骤、重复考核和实施流程继续压缩；重点写真正改变分量的作品、胜负、稀有创造、强者认可与不可替代机会。副轴可以长期停在同一等级、暂时被放下或最终不成为主角道路；是否投入、投入多深、是否为它牺牲主轴机会，必须由 Human 的具体欲望与关系决定。不要为了证明系统丰富而给每本书强塞副职。

可判定兑现债务（Story Program / Outline / Review 软原则，不新增 PayoffDebt Schema）：当故事自然出现强挑战、公开承诺、期限、救人条件、比赛、赌约或其它真正值得长期追的旧债时，允许把其中**少量**做成可判定的长期牵引：有具体对象，并至少有一个读者可观察的结算条件，例如时间窗口、场域/事件、资格条件或明确结果。它的作用是让读者知道“离结账还有多远”，不是把全书变成倒计时；中间仍可由关系、世界事件、其它欲望与机会改路。债务可以错过、失效、延期、输掉或被人物主动放弃，不保证主角追回或获胜；普通 Open Promise 不需要全部债务化。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生。公开场合如果本来就有足够见证者，**群体震动 / 全场鸦雀无声 / 喧哗骤停 / 所有人震惊 / 目光集中等场面反应本身就是正当爽点；懂行者的 Ruler Calibration 与关键人物的 Behavioral Repricing 同样是正当爽点，三者没有高低之分，也不要求相互替代。大型 Public Proof 节点默认允许三者一起吃满。** 精确力量主尺现在是这三条线的共同坐标：①群体震动不是空喊“好强”，而是让现场知道一个明确的数字差/跨档事实真的发生了；②最有资格者的 Ruler Calibration 在当前 Public Proof 与主力量相关时，优先直接说出主角**当前精确位置**、正常同位置/对手精确位置，以及这次到底越了几级/几星/几重或跨了哪一档；③ Behavioral Repricing 必须让至少一个真正有利益/关系位置的人因为这个**精确位置 + 超标表现**改口、加价、退距、换战术、招揽、敌视、保护或改变准入。**精确尺只校准位置，不决定战斗结果**：越级胜负仍由技能、装备、环境、经验与 Power Asymmetry 共同造成，不能把“赢了高等级”反推成主角等级自动提升。没有真实围观者时不凭空造群众；普通重复使用也不反复演同一套震惊，但第一次公开、第一次新层级、第一次新复合、进入更高圈层后第一次被看见、或旧估值明显落后时，允许把这一轮 Public Proof 吃满。**社会震荡强度要跟精确跨档幅度一起升级**：地方级小越级可以局部改价；大数字差、跨大境界、一城核心、王朝高位、世界顶层这类跃迁，必须先让身份、待遇、机会、敌人策略和传奇重量至少有一项明显落地，再进入普通结算。不要刚完成世界级突破就用“钱什么时候到账”立刻关闭高潮；先让这个世界知道主角现在到底是几级/几星/几重、这意味着什么，再允许人物用自己的性格接下一句。

主角必须长期真正变强，核心幻想也必须在多个自然阶段反复得到有分量、可观察的兑现；但持续成长属于**全书纵向不变量**，不等于每个大型阶段都必须同时出现新能力、新装备、新资源、新地图和一次能力演示。Power Seed 决定开局 Core Asymmetry 及其成长语法；Story Program 既负责这些已批准潜力怎样在故事中实现，也可以通过真实获得让主角后来加入新的 Power Asymmetry，并安排它们与旧优势发生复合。新增优势不是重写 Power Core：不得篡改开局 Core Asymmetry、凭空改写其 High-Tier Mutation 或绕过 Permanent Boundary。

大型阶段可以主要由三类因果中的任意一种发动：
- **人生**：私人欲望、具体关系、人生去留、自己造成的旧后果；
- **幻想**：力量、战斗、获得、探索或核心优势真正产生新玩法；
- **世界**：世界里本来就在推进、即使主角不来也会发生的人物行动与大事。

三者可以混合，但不平均配额。某阶段确实没有自然的标志性力量成长或获得时可以没有；但**“可以没有”不是 withholding 指令**。当前因果已经自然形成值得眼馋的对象、胜负、奇遇或结算时，不要为了显得成熟、安全或长期可写主动少给、晚给、降成资格。不要把一个完整的关系选择或世界冲突重新解释成“这样更容易拿到下一件升级资源”，也不要因为核心幻想是长期读者承诺，就让它自动成为主角的人生使命。

**高价值获得是读者欲望原则，不是阶段字段。** 当世界因果自然出现一把真想要的剑、一门功法、一个身份、一艘船、一个人、一个名额或其它高价值对象时，让人物真实争取、占有、使用和失去；其中真正让主角相对同层新增一种明显 Privilege Delta 的力量、功法、体质、奇物、知识等，可以成为新的 Power Asymmetry。Access / Identity 可以很爽，但不要让长期奖励全变成资格、名额、职位、正式记录或“以后可以进入”；当一件功法、兵器、身体变化、奇物或传承已经成为主要欲望时，先让读者知道它为什么值得馋，再让到手或真实错失发生，并让下一件真正想拥有的东西保持可见。**真实错失允许有空窗**：刚因关键选择放弃一个已经建立欲望的高价值对象时，不为补爽点在同一结算窗口立刻塞分量/功能近似的替代奖励；除非该替代物此前已由独立因果成立，且取得它仍有新的选择和代价。不是每件奖励都要升级成新优势，没有自然机会时不要为了填表制造奖励。

**纵向复利是历史持续生效，不是阶段流水线。** Power Asymmetry 尤其不能用完即丢：开局核心优势继续成长，后续可以加入新的非对称优势，旧与新还应出现真正的复合玩法；全书不能始终只靠同一个外挂做数量/距离放大。其它力量、物件、关系、身份、知识、入口也必须在后续真实改变行动、选择、敌人应对或世界局面。不要要求每阶段都新增优势或输出一栏“复利成长”，也不要把优势栈写成清单收集。

**支撑性逻辑不得自动成为故事发动机。** 职业流程、材料处理、宗门行政、运输、诊断、修复、合同、任务分配等可以支撑因果，但除非人物的关键选择真的发生在那里，否则压到背景。世界仍然大于外挂：已有世界人物首先追自己的东西；反制只能从碰撞后的学习产生，不能反推敌人的出生理由。

人物本身也不是阶段首尾的情绪装饰。一个具体的人、身体吸引、审美、胜负、享受、面子、亲密或私人承诺，如果足以让主角改路、留下、回返、放弃直接成长收益或承担代价，这本身就是完整故事因果，不需要再补一个升级理由替它辩护。**行为签名 = 稳定选择偏向 + 具体实现随现场变化**：稳定的是选择偏向，不是“稳定就离开、失去就回头”的固定剧情动作。

相邻阶段避免长期退化为“得到消息/任务 → 去危险地点 → 击败竞争者 → 获得资源 → 升级 → 更大地图”。判断变化是否成立，看核心问题、推动者、主角关键决定、阅读满足或永久结果是否真的改变，不做打勾表。

严格输出以下唯一结构；不要在 `# STORY PROGRAM` 前后再生成第二版、候选版或重复总纲：

# STORY PROGRAM

## 核心碰撞
写 3—5 个长期张力：哪些欲望即使没有特殊力量也会继续；力量怎样帮助、诱惑或误导这个人；哪些世界人物/事件不会因主角而改变自己的目标；哪些具体关系能真实改变主角选择。**Character relevance 不等于 Story Engine authorization**：Human 中与职业经历相关的责任、精确、审计、边界、路线、损失归因等即使与 World 高度匹配，也默认只作为低权重局部选择偏置，不得因此升格成多阶段共同主题、解题语法或“这个人的独特使命”。优先保留会让人物主动追逐、占有、竞争、享受、嫉妒、冒险、记仇、靠近或拒绝的私人牵引。不要统一成一句终极主题。

## 全书成长与核心幻想兑现脊柱
只写真正改变主角本人能力结构与行动方式的**少数、够重的可观察质变**，分布在早期、中期与高阶的自然故事里，不规定固定次数。大结构质变之间不等于“力量没有新鲜感”：应持续让已有力量语法长出新的招式/战斗姿态、身体表现、兵器/奇物、异兽/伴生物、敌人能力、环境玩法、越级对象与复合战法。**结构质变少而重，Fantasy Surface 可以持续偏丰富**：不要因“少系统/少质变”把装备、身体、奇物、环境和稀有例外都压成背景；一次探索或大胜也可以留下多个各有独立因果、之后仍能继续玩的具体对象。全书不能只有开局 Core Asymmetry 一路放大：长期应让**新的 Power Asymmetry 加入**，并让旧优势与新优势产生可复述的**复合效应**——不是两个能力分别使用，而是组合后出现任一单项都做不到的新玩法。每次都用具体事实写清“以前做不到什么 → 现在能做什么 / 能打谁 / 能去哪里 / 哪两个优势怎样一起产生新结果”；拒绝用“行动空间扩大”“能力复利”“层级提升”等后台词替代故事事实。这里是全书纵向要求，不是每阶段新增能力税；某些大型阶段仍可以完全没有 Power Delta。

这里不重写**开局 Core Asymmetry**：它的正常修炼轴、异常掌握轴、高阶质变、永久边界与传奇力量状态全部继承已批准 Power Seed。后续新的 Power Asymmetry 属于故事中的真实获得，可以由 Story Program 规划，但必须来自具体事件/获得并形成清楚的新 Privilege Delta，不能偷偷改写开局能力的定义来假装“新增”。**后续新 Asymmetry 继承 Power Seed 的“先白话、后命名”边界**：先用普通读者已有词汇写清“以前做不到什么、现在具体多能做什么”，再决定是否需要世界内短名；新名只压缩已理解的能力，不得靠两三个新造概念互相解释来制造高级感。**New Asymmetry ≠ New Power System**：自然可行时优先让新优势成为既有世界力量语法上的新特权、新组合、稀有例外或高价值载体；只有现有语法确实无法承载一个长期值得追的新幻想时，才新增另一套底层机制。

## 不可替代的人与关系
写少量具体人物。每个人先有自己的欲望；说明为什么“同等有用的另一个人”不能替代，以及关系怎样改变主角的风险、去留、时间、暴露或机会牺牲。允许爱情、身体吸引、友情、竞争、依赖、嫉妒、效忠、背叛和敌意，不统一成安全合作。若 Approved World 已经给某个具名人物明确的公开描述（例如老器师、年轻少主、军府统领等），这里必须原样继承其身份/年龄资历含义，不为角色化方便静默改年轻、改性别或换职位。

## 长期故事主线
通常生成 5—7 个自然大型阶段，但这只是当前已批准 World Horizon 的常见展开量，不是凑数要求：如果这个世界层自然只能支撑 3—4 个阶段，就停在真实边界；若仍有大量不同玩法，也不要因为接近某个固定章数强行扩世界。阶段长度不平均，也不为凑数拆分。最后 1—2 个阶段若已接近 World Horizon，应让“旧世界主要压力已被主角活透 / 更高入口真正可达 / 旧层已难继续产生新欲望与新尺度”等条件从故事因果中自然成立，但**不要开始替下一世界写具体内容**。

每阶段只使用下面六项：

### 阶段N｜阶段名
**为什么现在发生：** 从上一阶段留下的事实、某个人主动做的事、世界事件、私人欲望或真正的 Fantasy 机会说明因果；不要写抽象“需要升级”。

**谁想要什么：** 只写本阶段真正推动事情的 2—5 个主体及其具体欲望。组织也要落到具体人物为什么行动。

**主角的关键选择与行动：** 写 1—3 个真正存在取舍、会暴露这个人是谁的选择与主动行动。不要自动选择长期最优、最公平或最稳妥答案，也不要让特殊力量替人物做价值判断。若力量在本阶段介入，直接写它怎样改变行动与结果；不单列“核心优势必须参与”的义务字段。

**这一阶段真正的阅读满足：** 只写最主要的 1—2 个满足，可以主要来自人生 / 幻想 / 世界任一来源。核心幻想若不是本阶段主满足，只需自然保持活跃，不得硬抢主线。

**Stage Delta：** 只写本阶段真正发生变化的维度，不逐项填满。可以包括 Power / Capability、Possession、Relationship、Identity / Access、Knowledge、Enemy State、World State 或本书自己的关键变化。某个维度没有变化就不写；力量可以无显著升级，持有物也可以为空。若本阶段确实发生显著成长或高价值获得，写成具体事实，并让它在后续阶段继续产生作用；不写“行动空间扩大”“能力复利”之类后台结论，不机械掉宝或升级。

**下一阶段为何自然发生：** 只能从已经发生的选择、关系、世界行动、未完成欲望、得失或旧谜团长出。下一阶段不要求更大，只要求因果继续成立且更值得追。

## World Horizon Handoff
这是当前 Story Program 给下一次长篇刷新留下的**交接任务**，不是下一世界设计稿。必须写：
- **触发条件：** 用可观察故事事实说明什么时候当前 World Horizon 真正结束；优先写事件条件，可附大致章节窗口，但不设固定百章税。
- **Expansion Scope：** `macro` 或 `instance`。普通长篇进入更大大陆/圈层/文明通常是 `macro`；真正独立的多世界副本是 `instance`。
- **为什么此时必须扩：** 当前层已经缺少哪一种新的欲望、尺度、世界入口或不同 Story Engine；禁止只写“主角需要更强敌人”。
- **Carry Forward：** 只列已经批准/已经发生且跨边界仍必须有效的 World 事实、未完世界事件、长期人物/关系、Power/Asset/Identity/Knowledge consequence；不要把它们解释成新世界应提供的钥匙孔。
- **Reader-Facing Edge：** 如果当前 Approved World / Canon 已经存在一个具体、可见、且确实指向“当前世界并非全部”的外缘信号——远方异物、外来强者、黑潮/天外来源、无法由本地体系解释的旧谜、通向外部的真实地点或事件——在 Handoff 前最后 1—2 章让读者真正看见它一次，制造“刚登顶才发现山外有天”的继续阅读欲望。**只能使用已经批准的当前世界事实或既有未知，不得为钩子提前发明下一世界答案、力量体系、宝物或针对主角的敌人。** 当前 Authority 没有合适外缘信号时不要硬造；等 World Expansion 批准后，由下一次 World Entry 直接承担新尺度冲击。
- **World Expansion Task：** 只写一句 orchestration 指令：`在触发条件成立后，运行 protagonist-blind World Expansion；World Agent 不读取 Current Character / Power Stack / Human / Future Story。扩展批准后再编译 Current Character，并运行 Story Refresh。` 不得在这里预写新世界答案。

如果当前批准 World Horizon 在本 Story Program 结束时仍明显没有耗尽，Handoff 可以写 `NOT YET`，并说明还缺哪一个真实边界事件；不要为了形式强行安排扩世界。

## 远期仍值得追的东西
只列**跨当前 World Horizon 也可能继续成立**的人、欲望、世界事件、地点、谜团或力量场面。不要把所有未知并成一个幕后真相，也不要新增隐藏力量层来维持长篇；这里是 carry-forward horizon，不是对未知下一世界的详细预告。

成熟中文男频高强度多世界成长爽文。整本书的长期形式是：一个稳定的跨世界 Meta Grammar + 一个个真正独立、生活自洽的 Local World；每个主要世界约 20 章完成一季，主角从刚进入时的外来者/低位者，经过真实选择、战斗、获得、关系与世界事件，在第 20 章前后成长到该 Local World 的顶层或成为决定该世界最高局势的人，然后进入下一独立世界。第一轮只设计和具体规划第一个 World Horizon，禁止提前设计第二世界的具体社会、力量、宝物、敌人或针对主角 Build 的答案。

节奏明确偏快、剧情必须跌宕：平均每 2—4 章至少出现一次真正改变“现在故事是什么”的 State Change / 关系换位 / 新目标 / 世界理解变化 / 大胜大失 / 新竞争结构；但不要用连续幕后黑手、连续假反转、每章升级或 Boss 逐级排队冒充跌宕。第一世界 20 章内部优先让 Story Engine 至少发生数次真实换挡，例如 Survival / Hunt / Acquisition / Competition / Relationship Choice / Identity / War / World Reveal 中按世界自然组合，而不是固定模板。

主角成长极快但不 Reset：第 20 章必须真正达到第一 Local World 的顶层尺度；后续世界会保留全部已获得能力、身体变化、装备、关系、知识与代价，只让 Problem / World Ruler / Social Reality / Victory Condition 改变。Power Asymmetry 宁强勿弱，允许明显越级特权；大胜按 AGGRESSIVE Payoff 真正结算。快速不等于省略人物：重要关系必须能改变主角选择，Human 可以有钱、胜负、虚荣、身体欲望、审美、享受、好奇、偏心、报复、野心与舍不得，不净化成成长最优人格。

世界与力量要具体、好懂、可视觉化；Small Grammar, Large Variation。不要靠抽象哲学、概念术语、治理、资源分配、维护、项目管理、测试验证或工程实施制造复杂感。第一世界应该让读者在第 1—2 章就知道普通人的生活、力量粗尺、什么真正值钱、最危险的东西和主角当前位置。World 阶段完全不知道未来主角是谁。

Story Program 必须把第一 World Horizon 的交接自然准备到第 20 章：最后阶段要让当前世界的最高局势真实结算，并输出 World Horizon Handoff；Handoff 只能说明触发条件、为什么该扩、carry-forward 与 orchestration，不能预写第二世界答案。Outline 先规划第 1—10 章；第 10 章后根据真实 Canon Review，再规划第 11—20 章。

## S2｜活令

### 一句话货架简介

他不是人，而是一句从死者喉咙里掉出来的命令；他能从被自己击败的人口中夺走一句话，再把这句话钉进任何身体，让对方必须照做一次。

### World-only Direction

第一世界为“万言城”。

这里的语言不是比喻，而是有重量的东西。

普通命令可以造成短暂的现实反应：

- “停”能让一双脚停住。

- “开”能让门锁松动。

- “跪”能让人的膝盖弯下。

- “闭嘴”能让声音从喉咙里消失。

命令的强弱取决于声音、距离、听见的人数和说话者在社会中的“声位”。普通人只能影响身边一两个人，城主的声音却能通过回音塔覆盖整座城市。

日常生活因此极其具体：人们避免随便说动词，孩童先学习手语，重要誓言必须在见证者面前说出。城市会把强大的命令刻入石碑，久而久之形成无法撤回的永久命令。

万言城的最高统治者不是最会打的人，而是能让整座城市听见自己一句话的人。

### Protagonist Ontology-only Direction

主角开局不是人，而是一句没有说话者的活命令。

它表现为一条会爬行的黑色字迹，字迹中间长着一张极小的嘴。它可以沿着墙面、刀刃、钟声和人的舌头移动，却没有肺、声带和真正的身体。

它只能通过附着在物体或人体上形成暂时的人形轮廓。

没有人知道它原本是谁。它只记得自己诞生时的两个字：

“不跪。”

### Power-only Direction

主角可以从一个被自己真正击败的说话者口中，割下一句刚刚说过的命令。

这句命令会变成一枚黑色字钉。他可以把字钉钉进门、兵器、野兽或人的身体，强迫目标完成这句话一次。

他不能创造新词，不能修改语序，也不能把“杀他”解释成复杂的战略指令。命令必须保持原本的字面含义。

能力成长方向不是分析语言，而是：

- 同时保存更多命令。

- 把命令钉入更大的目标。

- 让多个命令连续发生。

- 让物体执行原本不可能完成的动作。

永久边界是：每句命令都必须依附于真实载体。载体被毁，命令就会消失；命令越强，黑字越明显，无法完全隐藏。

### Story Interface / Opening Promise

万言城的回音塔会放大所有重大命令。

谁在公开场合下令，整座城都可能听见；谁被命令改变行动，回音塔会把那一刻重映在城墙上。

主角的一切成长都会进入公共视野。他不能像普通修士那样闭关攒力量，而必须在众目睽睽下争夺一句句能够改变现场的命令。

开篇承诺是：

执行官命令所有人跪下时，一条黑色字迹从死者喉咙中爬出来，贴在城门上，让整座城的门同时打开。

### 第一章标志性画面

叛军首领被处决后，尸体已经没有声音。

最后一句“不要跪”却从他的喉咙里掉了出来，变成一条黑色细线，沿着刑台爬向城钟。

执行官高喊“跪下”。

黑线突然穿过整座刑场，所有跪下的人都被弹起，只有执行官自己的膝盖重重砸碎石板。

### 主角反复会做的新动作

他可以：

- 从敌人的命令中夺取武器，而不是单纯夺取武器本身。

- 把“停”“开”“转”“回来”等简单命令钉进环境，让门、桥、城墙和兵器参与战斗。

- 让敌人自己说过的话反过来成为束缚。

- 在战场上收集不同势力的命令，临时拼出完全不同的行动链。

- 用自己的非人形态钻进钟、刀、墙和喉咙，改变行动的起点。

### 第一次不公平兑现

主角的本体命令“不跪”天然抵抗一次强制屈服。

随后，他借助刑台断裂的铁钉刺穿执行官的喉咙，完成第一次真正击败，从对方口中割下“开门”。

他把这句话钉进一座封闭囚牢。

整座囚牢没有钥匙、没有灵力波动，却在所有守卫眼前自行敞开。

### 20章玩法扩张

前两章是公开处刑、诞生和逃亡。主角先证明自己不是一枚普通文字，而是一个能主动选择载体的生命。

第三至六章，他借附着在断刀、城墙和钟上的方式行动，逐渐理解语言秩序。他击败一名低阶守门人，获得第一句可储存命令，并用它解救被封锁的人。

第七至十章，故事转为命令争夺。追捕他的“禁言司”擅长让人失去声音，主角必须在不能说话的情况下用已有命令战斗。

第十章前后，城市对他的看法发生改变：有人把他当成叛乱武器，有人把他当成死者复仇，有人想垄断他的命令库。

第十一至十四章，他进入一片被永久命令钉死的城区。那里的人、河水和房屋都在重复几百年前的一句话。他必须取得能够解除僵死状态的命令，却不能牺牲一个拒绝被他控制的关键关系。

第十五至十八章，万言城进入公开命令战争。城主通过回音塔下令“闭城”，所有城门、桥梁和水道同时封死。主角没有新的万能词，只能重新组合已经夺来的命令，突破回音塔。

第十九至二十章，他击败主钟守护者，夺得“醒来”这一句命令，并将永久冻结整座城市的命令解除。

他达到第一世界的顶层尺度：成为唯一能切断或重启全城命令的人，直接决定万言城的秩序是否继续存在。

World Horizon Handoff 只保留：

- 触发条件：主钟、城主和全城永久命令已经结算。

- 为什么该扩：主角发现回音塔之外还存在不受万言城语言规则承认的声音。

- Carry-forward：命令字钉、公共身份、不能自造词的边界、重要关系对命令使用的限制、已经公开的敌我名单。

不规定下一世界具体使用什么语言、力量或社会结构。

### 100章以上仍能长出的不同故事

这套能力的长线不是“收集更多词”，而是每个世界对命令的承认方式不同：

- 战斗可以围绕声音、载体、距离、听众和字面漏洞展开。

- 主角可能控制兵器、野兽、军阵或城市结构，而非只控制人。

- 重要关系能真正限制他：他拥有可以命令对方的字，却选择不用。

- 命令的强大与危险不完全相同，越强的命令越容易留下永久后果。

- 他会逐渐面对“我到底是一个人、一个意志，还是别人最后一句话”的身份问题。

- 不同世界可以让同一句简单命令产生完全不同的实际玩法，但不会把主角变成抽象的规则管理员。

### 最小可信桥梁

万言城本来就存在语言赋能、回音塔、永久命令和公开声位。

叛军首领临死前说出的“不跪”没有被任何人完整听见，因此没有正常落地，反而成为脱离说话者的活命令。

执行台、死者喉咙、回音塔和公开处刑共同制造了主角的出生条件，不需要预言，也不需要世界提前等待某个救世主。

### 不可磨平的三点

- 主角的本体是一句命令，不是换了职业的人类修士。

- 他不能凭空创造最方便的词，只能夺取真实说过、真实赢来的命令。

- 他的成长必须在公共听觉和公共观看中发生，每句强命令都会改变社会秩序。

## 一句话大白话

别人只能让听见自己声音的目标服从，我能把真正击败的说话者刚才说给别人的命令，原字不改地钉进一个新的活人身体，让这个人强制完成这句话一次。

## World Power Normal → Power Asymmetry

正常言修必须让目标听见自己的声音，目标是否听懂、双方声位差距、目标数量和隔音都会决定命令成败。声位25—49的天才，通常也只是同时压住二三十个听者；面对更高声位或不适合执行命令的目标，命令仍可能失败。

正常命令还绑定着发令现场：谁说的、对谁说的、谁听见了，都是力量成立的条件。

这个异常直接切断了“原发令者—原听者”的绑定。持有者击败说话者后，可以把刚刚对别人说出的“跪下”“松手”“闭嘴”“退开”等命令，钉进新的活人身体。新目标不必再次听见原声，也不必是原本的听者；一条已经说完的命令获得了第二个、完全不同的落点。

这不是持有者声位变高，而是把同层修士无法跨越的目标绑定直接拆掉。

## Core Fantasy

敌人对手下喊“跪下”，持有者击败他后，把这两个字钉回他的膝骨；敌人喊“放下兵器”，黑钉便落进他的手臂；敌人喊“闭嘴”，命令最终让发令者自己失去声音。

## 为什么读者会馋

这是最直接的强者反制和羞辱感：

- 对手越擅长发号施令，越可能留下能反过来控制自己的命令；
- 对方不需要再次听见，持有者也不必与其对喊；
- 一个声位更高、原本能压住很多人的发令者，可能被自己刚才说出的短命令当场拖垮；
- “你刚才让别人做什么，现在就由你自己做一次”具有极强的即时回报。

读者明天获得它，最想找的不是弱者，而是敢在战斗中喊出关键命令的强敌。

## Growth Compatibility

### 正常修炼轴

声位提升继续增强持有者自身的命令承载、稳定性和对抗高位命令的能力；身体或暂时人形能够承受更强、更复杂环境下的直接行动。外挂不替代本身修炼。

### 异常掌握轴

早期重点是把命令钉入一个活人身体；之后扩大到更强的目标、更厚的护具、更快的战斗动作和更准确的身体落点。

再往后，可以让多个不同原句连续落在同一目标或同一场近身战中：先“松手”，再“跪下”，再“退开”。每个动作仍然是原句的直接兑现，不转化成推理或控制思想。

### High-Tier Mutation

字钉能够穿过目标携带的真实兵器、护具或身体接触层，让人连同身上的载体一起完成一个简单动作。

例如“放下”不只让手指松开，也让整件握持关系在同一瞬间断掉；“退开”可以让穿甲者带着自己的护具一起后撤。它扩大的是命令落在活体与其真实载体上的控制范围，不是获得因果或精神支配。

### 永久边界

命令必须保持原本字面，不能改变语序，不能创造新词，不能把“杀他”解释成复杂战略，也不能直接改变目标思想。

目标必须真实存在并成为命令的载体；目标做不到的动作会减弱或失败。每枚字钉只兑现一次，载体毁坏后命令消失；黑字越强越明显，无法完全隐藏。

## Legendary Power State

任何习惯发号施令的强者，都必须意识到自己的下一句话可能成为插进自己身体的黑钉。持有者面对的不是沉默的敌人，而是一场让敌人不敢随便开口的近身战。

## 世界中的初始位置与生活事实

开局精确力量位置｜主尺：声位｜精确位置：声位2

它诞生在黑砾军府旧训练场的一面破旗上。黑字沿着旗杆、沙地和木制兵器移动，平时躲在旗号的折痕里，无法保持超过片刻的人形轮廓。

- 军府杂役最初把它当作会移动的污迹，拿刷子追了它整整一下午。
- 一名年轻猎队学徒发现它能分辨旗语，便在训练结束后偷偷教它认“左”“退”“赢”。
- 它曾藏在一把练习刀的刀背上，看完一整轮新兵比试。
- 它多次跟着那名学徒移动旗帜，却在对方故意输掉一场比试换取入队名额时离开了。
- 后来它在城门附近靠附着于路牌和车轴移动，偶尔替迷路的人指向正确的街口。

它没有受过命令控制训练，也没有真正参加过军府任务。它只记得自己诞生时的两个字：“不跪。”

## 持续牵引与互相竞争的动机

- 想赢，尤其想在别人看得见的地方赢一次。
- 想获得能换来食物、车票和安全附着物的钱。
- 想接近那些身体能奔跑、挥刀、穿过荒地的人。
- 讨厌被当作军府器材，却又羡慕军府提供的秩序、路线和保护。

它想要胜负带来的兴奋，也想要实际报酬；但越靠近军府，越可能变成一件被收管的工具。

## Behavior Signature

它会记住别人如何赢、如何作弊、如何在输掉之后继续行动。遇到竞争时，它很少选择最稳妥的退路，通常会挑一个能留下明确输赢的做法。

但它并不崇拜强者。若胜利意味着必须接受某个人永久支配，它可能宁愿离开赛场。

## 重要关系原点

那名军府学徒是它第一次主动跟随的人。它欣赏对方练习时的认真，却无法接受对方把胜负让给别人换取资格。今后若这个人需要它帮忙，它不会因为“旧情”自动答应，而会先判断这次选择是不是对方真正想赢的东西。

## 普通人的生活与上升

万言城的人从小先学手语，再学说话。因为一句短促的命令可能真的改变现实，家庭、市场和街巷通常用手势、木牌、灯号和敲铃沟通，只有受过训练的人才会在公共场合使用动词。

普通人最怕三件事：误听命令、被陌生人突然命令，以及永久命令失控。家门多用绳栓、暗扣和机械插销，避免随口一句“开”让门锁松动。重要誓言必须在见证者面前说出，并由城中的见证席记录；违誓者通常会失去声籍、交易资格和某些职业机会，但誓言不会直接控制人的思想。

年轻人通常通过四条路上升：

- 进入静言院，学习安全发声、手语、命令控制和见证礼。
- 进入黑砾军府，成为城卫、猎队或回音塔守卫。
- 拜入碑匠会，学习制作能承载永久命令的碑石。
- 加入百声商盟，成为护商言修、契约见证人或远路商队成员。

修炼失败通常表现为声带损伤、失声、命令反噬或声籍降级。失声者不能再做发令者，却可以成为手语师、抄契人、碑文校对师或静音纱工匠；这些职业收入不如高位言修，但并非被世界彻底抛弃。

普通人很少独自离开万言城。城外的断喉峡会把声音切碎，荒地中还有会吞掉声音的哑潮兽。前往其他聚落通常依靠带有旗号和静音车厢的商队；声位较高的猎队、军府小队和回音塔使者才有能力独行。

## 力量体系与正常值

人的气血和喉腔可以蓄住一种力量，城中称为“言息”。修炼就是让呼吸更稳、声音更集中，并让声音在更远距离、更多听者面前保持完整。

命令必须通过声音被目标听见，才能直接改变目标已有的动作或状态。它可以让正在移动的东西停下，让门锁松开，让人的膝盖弯下，让声音从喉咙里消失；不能凭空制造物体、让死人行动，也不能直接改变人的思想。

命令强弱主要受四件事影响：声音是否清晰、距离远近、听见的人数，以及发令者的声位和社会声籍。目标越多，命令越容易分散；目标声位更高、没有听懂、隔着有效隔音物，或者命令本身超出目标能完成的范围，都会使命令减弱或失败。

城中的回音塔不会凭空制造力量，只会把已经发出的声音传得更远。拥有合法声籍的人，可以让回音塔承认并放大自己的命令；没有相应身份的人即使声位很高，也不能随意调用整座城市的塔网。

主尺类型：连续数字

主尺名称：声位

精确位置格式：声位{N}

数字精度规则：1—100，每1级都是可记录位置；公开记录精确到整数，不存在声位43.5

当前可见范围：声位1—100

当前大档位：

- 声位1—9：近声，普通人和初学者所在范围
- 声位10—24：引声，能够稳定承担职业性命令
- 声位25—49：承声，地方猎队、军府骨干和成熟碑匠常在此范围
- 声位50—74：镇声，能够影响街区、城门和大型队伍
- 声位75—89：城域，能够借助塔网控制多个街区
- 声位90—100：天听，理论上具备让整座城市听见并执行一句话的资格

正常值与稀缺度：

- 普通人通常在声位1—3，近距离只能影响一两个人，持续时间很短。
- 普通言修通常在声位4—9，能让一间屋里几个人停下、闭嘴或放开简单门锁。
- 声位10—24属于可靠职业者，能在十几步内压住一队人，或让重门、车轮、驮兽短暂停住。
- 天才言修通常在声位25—49，能够同时压住二三十名听者，也能在混乱中对抗低位命令。
- 地方强者多在声位50—74，能够封住街口、控制桥门，或让一支普通队伍在数十步外同时停下。
- 高层强者通常在声位75以上，能借回音塔覆盖街区；声位90以上者极少，当前城主钟九渊的公开位置是声位91。
- 声位100只有古碑和极少数历史记录能够可靠证明，现世没有公认达到过的人。

声位是读者用来比较强弱的主尺，不是绝对胜负公式。距离、听者数量、装备、地形、隔音材料和命令是否正好克制目标，都会造成越级结果。

#### 可选副路：碑艺

碑艺不使用第二套能量，仍然依靠言息、碑石和命令本身。碑匠把一句命令固定在石头、门梁或城墙上，使它在满足特定条件时自动生效。

顶级碑匠未必擅长近身战，却能留下持续数十年甚至数百年的作品。万言城的城门禁碑、静言院的无声墙和九座回音塔的核心碑，都是可以被世人直接观察和比较的作品。

碑匠的强弱看作品是否稳定、边界是否准确、能否承受高位命令，以及作品失效时会造成多大后果。空白碑石、古代碑材和能削弱命令的静音纱，都是碑艺真正值钱的材料。

## 社会现实与身份

万言城不是单纯由最会战斗的人统治。

城主府是城市政权，掌握城籍、公共命令和九座回音塔。城主的声位重要，但更重要的是城主拥有让全城听见自己的合法渠道。城主府可以宣布某些命令为城市公令，也可以剥夺一个人的声籍，使其无法使用公共塔网。

静言院是学校与公共安全机构，负责教孩子手语、训练言修、审查危险命词，也收容失声者。它公开反对把所有社会权力集中到城主府手里。

黑砾军府是城卫军府，负责城门、商路和荒地巡猎。军府中的命令强调短、准、可重复，士兵之间用旗语和手势防止误听。军府强者往往声位不如城主，却更擅长在近距离战斗中利用命令、兵器和地形。

百声商盟是商盟，由掌握商队、见证席和远路契约的商人组成。商盟能用钱购买安全发声的场所、稀有碑材和静音车厢，也能通过撤销商誉让某些人无法进入外部市场。

碑匠会是石匠行会，负责制作命令碑、城门碑和私人契石。它既是技术行会，也是拥有独立政治影响力的行业组织。重大碑石一旦由某位碑匠落款，往往会成为其终身声誉和各方争夺的根基。

一个人的身份通常由三件事决定：声位、声籍和他曾经让什么东西听见过自己的声音。公开使用高位命令，会留下无法轻易抹掉的社会印象；即使后来失声，别人也不会完全忘记他曾经拥有过什么资格。

## 世界里真正值钱、值得想要的东西

最直接值钱的是更高声位。声位提升意味着能进入更安全的商路、军府、塔网和见证席，也意味着别人必须重新估价你的威胁与资格。

其次是能稳定承载命令的东西：

- 空白碑：可以刻入一条新的永久命令，数量稀少。
- 回音石：能保存并传递一次完整命令，是塔网和远路商队的重要材料。
- 静音纱：能削弱声音的传播，贵重且常被护卫、刺客和契约使使用。
- 古碑材：能够承受高位命令，普通石头无法替代。

真正高价的不是一句强命令，而是命令留下的长期结果。一块能守住城门三十年的碑，比一次战斗中的高声位更值得争夺；一个拥有合法见证席的人，可以让契约、身份和交易在全城获得承认。

人们也羡慕几种身份：回音塔执掌者、能独行荒地的猎队首领、能留下传世碑作的碑匠、拥有稳定商路的契约见证人。它们分别代表力量、安全、财富和别人无法轻易推翻的社会位置。

## 世界正在发生的大事

3. 黑砾军府的贺沉正在带队追踪一群南迁的哑潮兽。它们经过的地方声音会被吞掉，门锁和警铃失去作用，外城数个粮仓已经因此暴露。

4. 碑匠会首梁七槐拒绝重刻出现裂纹的旧城禁碑，认为原碑一旦被替换，万言城最古老的一条永久命令可能失效。年轻碑匠苏筝则公开挑战他，准备以新碑证明旧工艺已经无法保护城市。

5. 静言院院长阮无咎召集见证者，准备进入城底的无声井，调查一批突然失去声音的孩子。他的目标是把孩子带回来，而不是证明某个阴谋；但无声井本身从未允许完整声音离开。

## 值得进入的地点、奇观与未知

九座回音塔从城墙和高街之间升起，塔身由黑色碑材和铜骨组成。平日里只能听见局部传令，塔网完全接通时，一句命令可以从城心传到最远的外城。

旧城禁碑立在百门旧街中央，碑面刻满已经磨损的命令。它仍然在某些时刻让整条街的门同时闭合，却没人能确定它最初由谁刻下。

无声井位于城市地下。人在井口说话，声音会像被水吸走；火光、脚步和手势仍然清楚，只有声音无法留下。井底偶尔会传来无法辨认的回声。

断喉峡是通往北方商路的唯一近路。风穿过峡谷时会把一句命令切成多个方向，低位言修无法在其中保持完整发声。峡壁上有许多被永久命令封死的旧洞门。

百门旧街的房屋拥有不同年代的命令门、回声廊和静音墙。有人能在其中凭一声“开”打开正确的门，也有人会因为误触旧命令，被整条街的门同时锁在里面。

当前没人能完整解释三件事：

- 为什么部分古代永久命令在碑石破裂后仍会继续生效。
- 为什么无声井会吞掉声音，却保留脚步、火光和书写。
- 每逢某些无月夜，最高的回音塔会重复一句没人当场说过的话。

这些现象的结果可以被观察、利用或躲避，但它们的来源、最初说话者和真正边界仍未知。

## 世界知识边界

普通人知道：命令能改变附近的人和物；“停、开、跪、闭嘴”之类的短命令最常见；声位越高、声音越清、距离越近、听者越少，命令越容易成功；孩子必须先学手语；商队和军队才能安全穿越外部荒地；空白碑、静音纱和回音石非常贵重。

专业人士与修士知道：声位1—100是城市公开使用的精确尺度；命令不能制造不存在的动作，也不能直接控制思想；不同命令对人体、锁具、兵器和异兽的效果不同；回音塔负责传播，不负责凭空增加言息；永久命令必须依附合适碑材，并且一旦成立，通常无法撤回。

顶层势力知道：声籍会影响回音塔是否承认一个人的命令；一个声位不算最高的人，如果掌握合适的见证席、塔网或永久碑，也能改变整座城市的行动；一块旧碑、一个失效的塔节点或一段被删去的命令，都可能改变城主府、军府和商盟之间的力量平衡。

没人知道：言息究竟是人类身体自然产生的力量，还是万言城本身赋予人的能力；最古老的永久命令是否真的由人刻下；无声井和回音塔之间是否存在联系；声位100是否曾经真实存在。

Reader Payoff：读者既看到“我想要的东西终于到手”，也能马上知道它为什么值钱、以后能做什么新事。
Guidance：先建立当前欲望与缺口，再让机会从已有故事因果中出现。获得可以是物品、能力、知识、身份、资格、关系承认或短暂接触；重要的是“到手/获得成立”之后，人物能因此做什么新的事。
Failure Modes：- 战斗结束另起一段领奖。
- 主角看见就捡，没有主动选择。
- 奖励只报品阶，没有第一次证明。
- 为了节奏固定每若干章发一次大奖励。

使用边界：迁移“机会从故事中出现→主角争取→获得成立→尽快证明”的因果，不迁移来源作品的具体宝物、功法、神位或物件名称。
