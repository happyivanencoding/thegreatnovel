# PRE-AUTHORITY COMPILER STOP

The preregistered S2 remained commercially bold but failed the independent Authority compiler before any Authority was approved.

## Exact conflicts

1. The demolition worker can cross the protagonist's door, but the entire shed never physically crosses that same threshold. "Shrinking from the foundation" is an unwritten transport rule.
2. T0 has one real door; the Trace later releases the shed from an unapproved rear-wall door.
3. Door Shadow requires five conscious witnesses to see the crossing; the opening does not establish them.
4. Connecting one "realm-shell core" does not by itself satisfy the public rank-9 definition.

## Decision

Stop before `World → Power / Human → Story → Outline`. Continuing would spend downstream calls only to force a known invalid promise into Authority or to rediscover the same conflict later.

This result supports an independent one-time Premise Compiler between Forge and author selection. It does not support an automatic creative selector and does not make production default changes.
