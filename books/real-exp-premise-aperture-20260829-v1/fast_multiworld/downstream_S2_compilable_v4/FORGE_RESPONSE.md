## S1｜《死式》

### 一句话货架简介

他被当众处死后才真正出生；此后，谁亲手杀死他，谁就等于把自己最强的一击送给了他。

### World-only Direction

这是一个以“命火”维持身体与城市的世界。

主力量尺只有一条：命火尺。

- 0｜未燃：普通人，不能主动使用命火。
- 1｜点灯：能驱寒、增强身体，足以对付野兽。
- 2｜成炉：可以独自击败数名普通武人。
- 3｜贯脉：命火能离体数步，足以破门、断树。
- 4｜镇山：能正面摧毁小型堡垒。
- 5｜护城：能压制一片街区的战斗。
- 6｜封域：能让一座城的命火失效一段时间。
- 7｜改天：能改变局部风雪、雷火、昼夜。
- 8｜圣躯：能独自穿过死潮核心。
- 9｜天门：能关闭或开启一处死潮源头，是本地世界公认的最高尺度。

每十二日出现一次“死潮”：过去十二日内死亡的尸体会在入夜后站起，直到天亮才重新倒下。死潮中的尸体没有生前记忆，只会追逐活人的命火。

普通人最依赖命火灯、死潮预警和城墙避难。真正值钱的是高阶命火芯、能撑过死潮的城墙和死潮源头附近的遗物。人通常通过猎杀死潮、加入火城、争夺天门遗址来上升。

世界没有主人公时，也会持续发生：

- 死潮吞没边城；
- 高阶火城争夺死潮源头；
- 低阶平民被迫迁入命火更强的城市；
- 死潮遗物改变各城之间的力量平衡。

### World Interface-only Direction

凡是有三名以上清醒见证者同时看见的超常冲突，最近的石面、金属面或水面会留下七日“回声”。

任何人可以用回声镜回放这段影像，能看见现场发生过的动作与声音，但不能复制力量、改变事件、召回死者或隐藏未被看见的部分。

回声只能观看、记录、传播，并会改变证据、名声、报价、追捕和社会待遇。

### Protagonist Ontology-only Direction

主角不是转世者，也不是夺舍者，而是“回死体”。

回死体是一种由死亡残留凝成的非人生命：

- 初始没有人类记忆；
- 身体可以拥有近似人形，但不是任何死者的身体；
- 身体被真正杀死后，只有满足特定条件才可能重新聚合；
- 每次重新聚合都会留下无法消除的黑色死痕；
- 回死体不天然拥有命火，也不能正常修炼人类功法。

### Initial Origin-only Direction

第一场事件发生前，刑场排水沟里只有一团由九座焚尸坑灰烬、半截棺木和一枚死潮骨钉凝成的黑灰躯体。

它尚未醒来：

- 没有意识；
- 没有名字；
- 没有记忆；
- 命火位置为0；
- 只能感受到寒冷、潮湿和远处脚步声。

行刑队在天亮前发现它，把它当成死潮中爬出的怪物，拖上刑台。

### Initial Scale Position-only Direction

适用主尺：命火尺。

- 主角 T0 位置：0｜未燃。
- 副尺：不适用。World 没有定义第二条独立的公共力量尺。

### Power-only Direction

Power 名称：死式。

触发条件：

- 一个具有主观意识的行动者；
- 有意发动一次行动；
- 该行动直接造成回死体当前身体死亡；
- 回死体在死亡后重新聚合。

目标类别：

- 仅限造成致死结果的那个行动者的那一次具体杀戮动作。
- 疾病、自然坠落、死潮尸体、饥饿、自杀和无意识事故不能触发。

可做的动作：

- 重新聚合身体；
- 捕获造成死亡的完整“致死结果”；
- 把这次致死结果通过自己的身体或手中物体复现；
- 复现的是冲击方向、破坏程度和动作轨迹，不复制对方的命火、血脉、武器、火焰或特殊属性；
- 最多保留九道死式；
- 每道死式每昼夜只能复现一次。

永久边界：

- 第十道死式会覆盖最早的一道；
- 每次复现都会重新撕开对应死痕，短时间内身体会回到当时的受创状态；
- 不能把非致死动作变成死式；
- 不能从没有承受过的杀招中推导出新招；
- 如果当前身体承受不了该死式的反冲，复现会失败；
- Power 不提供主动修炼命火的能力。

### Story Interface / Opening Promise

第一章的承诺是：

一个没有名字、没有命火、刚被拖上刑台的死体，被当众砸碎胸腔；所有人确认它已经死了，它却在回声镜里再次站起来。

此后，主角必须在“让谁杀死自己”与“永远失去哪一道死式”之间做选择。

公开观看规则会让他的每次死亡都变成社会事件：

- 有人想隐藏他的死式；
- 有人会故意用弱招杀他；
- 有人宁愿不杀他，也不愿让自己的绝招被夺走；
- 有人会围观、下注、传播他的死亡影像。

### Authority-Compilation Trace

1. 主角被行刑者的命火掌击碎胸腔
   → 来源：Initial Origin-only Direction、Power-only Direction
   → 触发已满足：有意识行动者故意造成当前身体死亡
   → 目标：行刑者的这一次命火掌
   → 合法性：Power 明确允许捕获致死动作的破坏结果，但不复制命火本身。

2. 主角重新聚合并站起
   → 来源：Power-only Direction
   → 触发已满足：当前身体已死亡
   → 目标：主角自身身体
   → 合法性：回死体的重聚是 Power 的明确结果，不是 Human 或 Story 临时补出的复活。

3. 主角用自己的手复现命火掌的冲击结果
   → 来源：Power-only Direction
   → 触发已满足：已完成一次死亡与重聚
   → 目标：追捕者的身体
   → 合法性：Power 复制的是致死结果、方向和轨迹，不复制命火来源；主角仍需承受反冲。

4. 刑场回声镜回放主角死亡与站起
   → 来源：World Interface-only Direction
   → 触发已满足：现场有三名以上清醒见证者
   → 载体：刑场附近的金属刑架与石面
   → 合法性：Interface 只记录已经被看见的动作，不制造复活或放大死式。

5. 主角因死式被重新定价
   → 来源：World Interface-only Direction、Story Interface / Opening Promise
   → 触发已满足：回声被传播
   → 载体：回声镜、城中观众和追捕体系
   → 合法性：改变的是证据、名声和社会行为，不改变 Power 的因果覆盖。

### 第一章标志性画面

刑锤砸下，黑灰躯体的胸腔塌陷。

刑场上所有人都看见它倒下。

下一刻，黑灰从血泊里向上聚拢，先长出一只手，再长出半边脸。它站起来时，胸口还保持着刚才被砸碎的形状。

它抬手，对准最近的追兵，打出了行刑者刚才那一击。

### 主角反复会做的新动作

- 故意把自己送进强者的必杀范围；
- 先承受一次死亡，再用死亡结果反杀；
- 让不同敌人争夺“谁来杀他”；
- 把自己的旧死痕当成战斗资源，而不是伤疤；
- 在死潮中装死，等待真正值得夺取的杀招；
- 用死亡影像逼迫敌人改变报价、战术和追捕方式。

### 第一次不公平兑现

第一个行刑者以为自己只是杀死了一具无命火的尸体。

主角重聚后，用空手复现那一击，把同境界的两名追兵同时轰穿刑架。

差距不在主角原本的命火，而在于他把“对方已经证明能杀人的动作”直接带回了战场。

### 20章玩法扩张

- 第1—3章：刑场复起，夺得第一道死式，成为回声镜中的公开怪物。
- 第4—6章：不同势力试图用非致死手段捕获他；主角第一次主动选择让某个强者杀死自己。
- 第7—10章：死潮爆发，主角发现并非所有死亡都值得承受；他必须在救人、夺式和逃亡之间取舍。
- 第11—14章：一座火城利用公开回声悬赏他的死式，主角反过来操纵追捕者的杀戮顺序。
- 第15—17章：死潮核心开启，多个高阶修士争夺天门资格；主角以已有死式参与顶层冲突，而不是临时升级。
- 第18—20章：主角进入死潮源头，连续承受已经存在于该世界的最高层杀招，最终关闭本地死潮源头，达到命火尺9｜天门。

第20章前后，当前世界的最高局势必须真实结算，并输出 World Horizon Handoff：只记录下一次扩张的触发条件、当前世界为何已无法继续作为主要问题、死式与死痕如何携带、进入下一世界时由何种既有规则重新解释它们；不预写第二世界答案。

### 100章以上仍能长出的不同故事

- 主角每到新世界，过去的死式会被当地规则重新估价；
- 有的敌人会想杀他，有的敌人会拒绝杀他；
- 他携带的不是抽象等级，而是一组来自具体人物的死亡动作；
- 某道死式可能来自仇人、朋友、爱人或被他救过的人；
- 主角会逐渐面对一个不能靠战斗解决的问题：自己究竟是在继承强者，还是在把杀死自己的人永远带在身上；
- 后续世界可以让“死亡”成为法律、血统、战争、神明或身体规则，但不需要替第一世界提前设计答案。

### 最小可信桥梁

只需成立三件事：

1. 死潮让死亡在这个世界具有公共生活后果；
2. 回死体是一种可以被致死动作唤醒的非人生命；
3. Power 只复制已经发生过的致死结果，不复制完整修为体系。

### 不可磨平的三点

- 主角必须是“被杀后才真正出生”的回死体。
- 杀死他的人必须确实把自己的致死动作交给他。
- 公开回声必须让他的死亡与复起改变社会行为，而不能只做背景特效。

## S2｜《一城吞门》

### 一句话货架简介

他不是修士，而是一间刚出生的活房子；凡是穿过他门口的东西，都会变成他身体里的一部分。

### World-only Direction

这是一个所有强者都以“壳层”衡量的世界。

主力量尺只有一条：城壳尺。

- 0｜散物：没有稳定内部空间。
- 1｜室壳：拥有一间完整内部空间。
- 2｜院壳：拥有可自持的多个房间。
- 3｜堡壳：能承受小型攻城。
- 4｜坊壳：能庇护一片街坊。
- 5｜城壳：能独立承受一场城级战争。
- 6｜域壳：内部空间可容纳多座城。
- 7｜天城壳：能在空中或灾变地形中独立移动。
- 8｜山门壳：能封锁一条大型世界通道。
- 9｜界壳：能成为本地世界最高边界的承载体。

每七日一次“门潮”经过地表。门潮不会移动建筑，却会在一个时辰内重新交换完整门槛的连接方向：一间屋子的门可能通往邻屋，一座城门可能通往旧堡，仓库、牢房、庙宇和民宅因此不断改变进出口。

普通人最在意门锁、避门潮路线和能保持原位的老门。真正值钱的是完整的高阶壳体、不会被门潮改向的镇门，以及拥有巨大内部空间的古代建筑。

世界在没有主人公时也会持续发生：

- 城市因门潮突然失去粮仓；
- 高阶壳体被拆成战争材料；
- 一座没有主人公的古城试图吞并邻近堡垒；
- 普通人为了保住自己的门口而迁徙、结盟或反抗。

### World Interface-only Direction

凡是有五名以上清醒见证者同时看见的门口通行，门框两侧会留下十二小时“门影”。

门影只能无声回放谁从哪一侧进入、从哪一侧离开，不能被再次穿越，不能改变真实门的方向，也不能储存人或物。

门影会影响所有相关行动者的证词、所有权、追捕和交易，但不会复制、放大或改写任何 Power。

### Protagonist Ontology-only Direction

主角是“活城胚”，不是人类、灵魂或寄宿者。

活城胚的身体由以下部分组成：

- 核心地基；
- 内部空间；
- 门、窗、墙和承重结构；
- 能够通过震动、开合和回声表达意志；
- 内部储存的生物仍保有自己的意识和行动权。

活城胚可以移动，但必须保持核心与至少一段完整承重结构连接。它不是建筑的主人，而是建筑本身逐渐长出的生命。

### Initial Origin-only Direction

第一场事件发生前，一枚被拆下的旧城门基石埋在废墟下。

门潮经过时，基石吸收雨水、灰烬和周围三间倒塌房屋的承重力，凝成一间只有一扇门、没有窗户的活房子。

此时它：

- 只有一个房间；
- 没有语言；
- 没有历史记忆；
- 不知道自己属于哪座城市；
- 城壳尺位置为1｜室壳；
- 只能感受到门外有人踩在自己的地基上。

第一场事件从拆迁队准备砸开这扇门开始。

### Initial Scale Position-only Direction

适用主尺：城壳尺。

- 主角 T0 位置：1｜室壳。
- 副尺：不适用。World 没有定义第二条独立的公共力量尺。

### Power-only Direction

Power 名称：吞门成身。

触发条件：

- 一个目标完整穿过属于主角身体的真实门槛；
- 主角主动关闭该门；
- 目标在门关闭前没有主动退回。

目标类别：

- 非生物物件；
- 完整建筑结构；
- 动物；
- 人类或其他有意识生命。

可做的动作：

- 把目标收纳进自身内部；
- 保留目标的真实形态、重量和功能，不复制、不转化；
- 在自身任意现有门口重新打开目标；
- 重新排列内部房间、门和墙的连接关系；
- 把被吞入的建筑部件接到核心承重结构上，使身体扩大；
- 通过内部空间移动，改变自身外部出口的位置。

永久边界：

- 目标必须真实完整地穿过门槛，不能隔空吞入；
- 目标的真实体积仍然存在，内部空间不足时门无法关闭；
- 不能复制目标；
- 不能控制被吞入的活物；
- 被吞入的活物可以破坏内部结构、拒绝合作或寻找出口；
- 只有与核心形成实际承重连接的完整结构，才能提高城壳尺位置；
- Power 不赋予主角凭空造物、远程传送或意识支配。

### Story Interface / Opening Promise

第一章的承诺是：

一间只有一扇门的房子，被拆迁队当成废墟砸开；第一个闯进来的人发现房间内部比外面大得多，而他身后的整座棚屋正在被门一点点吞进去。

此后，主角每吞下一座房、一段城墙或一个活人，就会获得新的身体部位，也会获得新的内部冲突。

他的成长不是获得装备，而是逐渐变成一座谁也无法忽略的移动城市。

### Authority-Compilation Trace

1. 拆迁者完整走入活房子的门内
   → 来源：Initial Origin-only Direction、Power-only Direction
   → 触发已满足：目标完整穿过身体门槛
   → 目标：拆迁者及其携带的工具
   → 合法性：目标是可进入门槛的活物与非生物，属于 Power 明确覆盖类别。

2. 活房子主动关门
   → 来源：Protagonist Ontology-only Direction、Power-only Direction
   → 触发已满足：主角具备门与意志，可主动闭合
   → 载体：唯一真实门
   → 合法性：不是远程捕获，而是身体动作完成后的收纳。

3. 拆迁棚屋被收入内部
   → 来源：Power-only Direction
   → 触发已满足：棚屋的主体结构完整穿过门槛，内部空间足够
   → 目标：一座真实棚屋
   → 合法性：棚屋没有被复制或变成抽象道具，仍占据真实内部空间。

4. 主角把棚屋重新从后墙门口打开
   → 来源：Power-only Direction
   → 触发已满足：棚屋已经成为储存结构
   → 载体：主角已有后墙门
   → 合法性：Power 允许重新开启已吞入目标，但不允许凭空生成第二座棚屋。

5. 主角从1｜室壳升到2｜院壳
   → 来源：World-only Direction、Power-only Direction
   → 触发已满足：棚屋与核心通过实际承重结构接通
   → 目标：主角自身壳体
   → 合法性：城壳尺的升级条件由 World 与 Power 共同写明，不由 Story 临时发明。

6. 旁观者通过门影回看拆迁过程
   → 来源：World Interface-only Direction
   → 触发已满足：五名以上见证者看见通行
   → 载体：门框两侧
   → 合法性：门影只回放通行，不让任何人或物再次穿越。

### 第一章标志性画面

铁锤砸穿墙面。

墙后不是黑暗，而是一条比整座棚屋更深的长廊。

第一个拆迁者踏进去，脚下的地板忽然向后延伸。等他回头时，门已经关上，外面的棚屋正在从地基开始缩进这间小房子。

### 主角反复会做的新动作

- 把敌人的武器库、牢房和城墙吞进身体；
- 把活人困在自己的内部空间，却不能命令他们；
- 把体内不同房间重新接成陷阱、通道或战场；
- 让敌人从正门进来，却从厨房、塔楼或地下门出去；
- 用自己的身体承载一群必须共同生活、却彼此敌对的人；
- 在门潮改变世界路径时，成为唯一能保持内部秩序的移动地点。

### 第一次不公平兑现

一座棚屋正在被拆迁队点火。

主角只有一间小房子，却在火焰烧到门槛前把整座棚屋吞入体内，再从拆迁队身后打开同一座棚屋。

敌人以为自己在烧一间废屋，下一刻却被整座屋子的墙、梁和火焰从身后撞倒。

### 20章玩法扩张

- 第1—3章：活房子出生，吞下拆迁棚屋，第一次把人关进内部。
- 第4—6章：门潮改变周围村镇的连接，主角利用内部门路逃离追捕。
- 第7—10章：主角吞下一段街墙，内部出现互不合作的活人和建筑结构。
- 第11—14章：多个势力争夺一座尚未崩塌的高阶古堡；主角必须决定吞下古堡，还是把它留给原住者。
- 第15—17章：门潮扩大，整座城区的出口错乱；主角把既有建筑接入核心，成为真正的移动壳体。
- 第18—20章：本地最高壳体与门潮源头发生冲突。主角吞入现成的界壳核心并完成承重连接，达到城壳尺9｜界壳，决定本地城市与门潮的最终归属。

第20章后输出 World Horizon Handoff：只说明主角已经成为界壳、哪些建筑结构和关系被携带、下一次扩张由什么规则冲击触发，不预写下一世界的地点、敌人或解决方案。

### 100章以上仍能长出的不同故事

- 主角携带的建筑会成为身体、家园、牢笼和政治冲突的同时存在；
- 每个被吞入的活人都可以拒绝成为主角的一部分；
- 他的身体越大，越难假装自己只是一个人；
- 某些世界会把他当成城池，某些世界会把他当成怪物、灾害或移动圣地；
- 他可以失去一扇门、拆掉一段墙、舍弃一个内部区域，也可以为了保住其中的人而牺牲战斗优势；
- 后续世界只需要改变“什么东西能够成为壳、什么边界值得占有、谁有权住进身体”，不需要替他重置能力。

### 最小可信桥梁

只需成立三件事：

1. 门潮使“门”成为世界中真正决定生存、财富和战争的接口；
2. 活城胚的身体天然由门、墙、房间和承重结构组成；
3. Power 只收纳真实穿门目标，并通过真实连接扩大身体。

### 不可磨平的三点

- 主角必须是“一间刚出生的活房子”，不是住在房子里的灵魂。
- 吞入的活人必须保留自主意志，不能被降格成库存。
- 他的身体成长必须直接改变占有、移动、战斗和关系，不得退化成城建管理游戏。

## S3｜《镜外有人》

### 一句话货架简介

他出生在一面碎镜里；谁看见他的完整倒影并叫出一个指向他的名字，他就能从那个人身边的镜面伸手出来。

### World-only Direction

这是一个“显形”决定强弱的世界。

主力量尺只有一条：显形尺。

- 0｜镜影：只能存在于反光、影像或水面中。
- 1｜单点落地：能在一个现实位置留下完整身体。
- 2｜双点落地：能让两个现实位置同时存在身体投影。
- 3｜三点落地：能同时干涉一条街上的三个位置。
- 4｜四点落地：能封锁一片街坊。
- 5｜五点落地：能同时压制一座城的关键入口。
- 6｜六点落地：能在一片地域内维持多处身体。
- 7｜七点落地：能让局部天象与地形同时出现显形异常。
- 8｜八点落地：能撕开大型封闭空间的边缘。
- 9｜九点落地：能在九处现实位置同时稳定存在，是本地世界的最高显形尺度。

每九日出现一次“反光潮”：所有反射面会慢半拍，镜中动作可能在现实中提前重复一次。反光潮期间，村镇会遮住镜子、水井和刀面，避免被镜中残动作误伤。

普通人的生活依赖遮镜布、无反光灯和能辨认真实影子的守夜人。真正值钱的是完整古镜、能在反光潮中保持稳定的镜面和拥有多个显形点的旧时代遗物。力量上升通常意味着能够在更多位置保持真实身体。

世界在没有主人公时也会持续发生：

- 反光潮让城镇误判敌人位置；
- 镜匠和守镜人争夺古镜；
- 某些显形者利用多个落点控制交通与商路；
- 普通人会因一面镜子的归属而迁徙或封门。

### World Interface-only Direction

任何反光面会保存最近三十秒内看见的动作，持续到下一次月落。

触碰该反光面的人可以无声回放这段动作，但不能获得力量、声音、记忆或身体控制权，也不能让回放动作重新影响现实。

该规则只提供观看、记录、传播和证据；它可能改变名声、证词、追捕和交易，但不会替任何人触发 Power。

### Protagonist Ontology-only Direction

主角是“镜生者”。

镜生者不是肉身、魂魄或幻术，而是一种从反光面中凝成的独立生命：

- 初始只能以倒影存在；
- 没有正常体温和血液；
- 可以在短时间内形成真实身体；
- 真实身体受伤后会把裂痕带回镜面；
- 不天然拥有任何人的记忆；
- 不能通过普通修炼直接提高显形尺。

### Initial Origin-only Direction

第一场事件发生前，一面被遗弃在旧审判厅里的碎镜中，出现了一个只有手掌大小的倒影。

它没有意识，也没有名字。

它只能看见：

- 自己的半张脸；
- 镜外落灰的地面；
- 一把被放在桌上的短刀；
- 每天经过镜前的几双脚。

T0 时它仍然完全依附镜面，显形尺位置为0｜镜影。

第一场事件从一名审判官擦拭镜面、发现镜中多出一个陌生倒影开始。

### Initial Scale Position-only Direction

适用主尺：显形尺。

- 主角 T0 位置：0｜镜影。
- 副尺：不适用。World 没有定义第二条独立的公共力量尺。

### Power-only Direction

Power 名称：见名出镜。

触发条件：

- 一个具有意识的人；
- 看见主角的完整倒影；
- 亲口说出一个明确指向主角的称呼或名字；
- 该称呼必须是为了辨认、指责、呼唤或命令主角，而不是无意发音。

目标类别：

- 触发者本人；
- 触发者身边可反光的表面；
- 触发者当时正在持有或接触的非生物物件。

可做的动作：

- 从触发者附近最近的反光面伸出身体或身体的一部分；
- 进行一次真实的抓、打、推、割、夺取、开门或移动动作；
- 把非生物物件带回镜面；
- 在九名不同触发者身上各建立一个永久显形锚点；
- 利用已有锚点在多个现实位置同时落地；
- 每增加一个有效锚点，显形尺提高一格。

永久边界：

- 没有人看见完整倒影并指向性命名，Power 不会触发；
- 不能凭空制造反光面；
- 不能控制触发者的意识、语言或身体；
- 不能把活人完整带回镜面；
- 每个触发者只能贡献一个锚点；
- 最多九个锚点；
- 锚点依附于触发者的持续生命与记忆，触发者死亡或彻底失去对该称呼的记忆后，锚点失效；
- Power 不复制对方的显形能力，不改变 Interface 的记录规则。

### Story Interface / Opening Promise

第一章的承诺是：

审判官看见镜中多出的陌生人，脱口而出“镜妖”；下一刻，审判官手里的刀面伸出一只手，夺走钥匙，割断刑厅门绳。

此后，公开寻找主角反而可能给他更多入口。

敌人越想确认他是谁、当众叫他出来、用镜子追踪他，就越可能成为他的下一条路线。

### Authority-Compilation Trace

1. 审判官看见主角完整倒影
   → 来源：Initial Origin-only Direction、Power-only Direction
   → 触发是否满足：尚未满足，只有看见
   → 目标：主角倒影
   → 合法性：此时主角仍是0｜镜影，不能提前出镜。

2. 审判官说出“镜妖”并明确指向主角
   → 来源：Power-only Direction
   → 触发已满足：有意识者看见完整倒影并指向性命名
   → 目标：审判官本人及其身边镜面
   → 合法性：触发条件完整成立。

3. 主角的手从审判官手中短刀的反光面伸出
   → 来源：Power-only Direction
   → 触发已满足：第一枚锚点建立
   → 载体：审判官接触的短刀
   → 合法性：短刀是现实存在的反光面，主角通过其完成一次真实动作。

4. 主角夺走钥匙并割断门绳
   → 来源：Power-only Direction
   → 目标：非生物物件与绳索
   → 合法性：Power 明确允许抓取、夺取和割断，但不允许控制审判官或完整带走活人。

5. 刀面回放主角出镜动作
   → 来源：World Interface-only Direction
   → 触发已满足：刀面看见了三十秒内的动作
   → 载体：短刀表面
   → 合法性：回放只是无声影像，不产生第二只手，也不增强 Power。

6. 主角从0｜镜影升至1｜单点落地
   → 来源：Power-only Direction、World-only Direction
   → 触发已满足：第一枚永久显形锚点建立
   → 目标：主角自身显形位置
   → 合法性：显形尺明确将“一个现实落点”定义为1，不能把一次出镜直接解释成更高境界。

### 第一章标志性画面

审判官擦亮刀面。

刀面里，除了他自己的脸，还站着一个手掌大小的陌生人。

“镜妖。”

话音落下，一只手从刀背反光里伸出来，五指扣住他的手腕。

刑厅所有人看见那只手，却找不到它从哪里来。

### 主角反复会做的新动作

- 诱导不同的人看见完整倒影并叫出自己的称呼；
- 把自己的身体拆成手、眼、脚或半身，从不同反光面同时出现；
- 让敌人互相命名、互相确认，从而替他制造新的锚点；
- 从兵刃、酒杯、雨水、盔甲和眼睛里寻找出镜路线；
- 夺走关键物件后立即退回镜面；
- 故意让某个重要人物记住自己的名字，再决定是否保留这条锚点。

### 第一次不公平兑现

审判官以为自己只是确认了一个镜中怪影。

主角从他手中的刀面出镜，夺走钥匙，割断门绳，再从地面积水中退回去。

整个过程没有正面战斗，却让一名正常1｜单点落地的守卫无法保护自己手中的关键物件。

### 20章玩法扩张

- 第1—3章：镜中出生，获得第一枚锚点，从审判厅逃出。
- 第4—6章：主角发现不是所有称呼都有效，必须让目标真正看见并指向他。
- 第7—10章：反光潮来临，城中出现大量错误回放；主角借混乱取得第二、第三枚锚点。
- 第11—14章：多个势力开始故意传播他的称呼，试图利用命名规则反向锁定他。
- 第15—17章：主角必须在救出被利用的锚点持有者与扩大显形数量之间做选择。
- 第18—20章：一场围绕本地古镜和反光潮源头的冲突爆发。九名实际参与者先后完成有效命名，主角达到显形尺9｜九点落地，同时在九处关键位置现身，结算本地最高局势。

第20章前后输出 World Horizon Handoff：只携带九枚锚点的存续条件、主角的镜生身体与当前关系代价，说明下一次扩张需要什么规则冲击；不预写第二世界具体社会、力量、敌人或宝物。

### 100章以上仍能长出的不同故事

- 主角的力量上限由“谁愿意承认他存在”构成；
- 锚点不是库存，而是九个仍然活着、仍然记得他的人；
- 不同世界可能把命名视为祝福、契约、罪证、血统确认或战争宣言；
- 主角必须不断决定哪些人值得保留在自己的身体路线里；
- 有人会主动叫他的名字求助，有人会拒绝叫他以防被他利用；
- 他越接近最高显形尺度，越难把自己藏成一个单独的人；
- 后续世界只改变“什么算看见、什么算命名、什么东西能成为反光面”，不需要重置核心 Power。

### 最小可信桥梁

只需成立三件事：

1. 显形尺是世界公开存在的力量尺度；
2. 镜面天然是记录、观看和社会追踪的公共载体；
3. Power 把“被看见并被命名”直接转化为一次可见的身体出镜，而不是转化成分析、权限或抽象身份。

### 不可磨平的三点

- 主角必须是镜中出生的独立生命，不是躲在镜后的普通人。
- 命名必须真实创造一条可使用的显形锚点。
- 接近顶层意味着拥有更多真实关系与暴露面，而不是单纯收集数字。
