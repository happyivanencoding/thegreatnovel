# AUTHOR-SELECTED WORLD PREMISE CONSTRAINTS｜批准前非 World Canon
这些是作者已选择的 World-lane 硬约束，不是可被安全化、换义或删去的灵感。World Agent 仍不知道未来主角、Ontology、Power、Biography 与 Story；必须在 protagonist-blind 的前提下实现全部世界事实。

### World-only Direction

这是一个所有强者都以“壳层”衡量的世界。

主力量尺只有一条：城壳尺。

- 0｜散物：没有稳定内部空间。
- 1｜室壳：拥有一间完整内部空间。
- 2｜院壳：拥有可自持的多个房间。
- 3｜堡壳：能承受小型攻城。
- 4｜坊壳：能庇护一片街坊。
- 5｜城壳：能独立承受一场城级战争。
- 6｜域壳：内部空间可容纳多座城。
- 7｜天城壳：能在空中或灾变地形中独立移动。
- 8｜山门壳：能封锁一条大型世界通道。
- 9｜界壳：能成为本地世界最高边界的承载体。

每七日一次“门潮”经过地表。门潮不会移动建筑，却会在一个时辰内重新交换完整门槛的连接方向：一间屋子的门可能通往邻屋，一座城门可能通往旧堡，仓库、牢房、庙宇和民宅因此不断改变进出口。

普通人最在意门锁、避门潮路线和能保持原位的老门。真正值钱的是完整的高阶壳体、不会被门潮改向的镇门，以及拥有巨大内部空间的古代建筑。

世界在没有主人公时也会持续发生：

- 城市因门潮突然失去粮仓；
- 高阶壳体被拆成战争材料；
- 一座没有主人公的古城试图吞并邻近堡垒；
- 普通人为了保住自己的门口而迁徙、结盟或反抗。

# AUTHOR-SELECTED WORLD INTERFACE CONSTRAINTS｜仍保持 protagonist-blind
以下观看／记录／传播规则对世界中的所有相关行动成立；不得降格成偶尔使用的舞台效果，也不得偷接未来主角。

### World Interface-only Direction

凡是有五名以上清醒见证者同时看见的门口通行，门框两侧会留下十二小时“门影”。

门影只能无声回放谁从哪一侧进入、从哪一侧离开，不能被再次穿越，不能改变真实门的方向，也不能储存人或物。

门影会影响所有相关行动者的证词、所有权、追捕和交易，但不会复制、放大或改写任何 Power。
