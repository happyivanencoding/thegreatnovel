我会按 `tgn-system-steward` 的 Authority 审计边界处理：只检查字段能否编译、触发链和长期复合，不改写候选，也不把激进设定当作缺点。先核对本地约束，再做逐案独立审计。已确认当前工作树存在大量并行实验改动，我不会触碰它们。生产侧已出现 Premise Aperture 的实验文档、实现和测试；我正在只读核对其当前边界，避免把“候选输出合同”和“已冻结生产能力”混为一谈。三个候选的共同改进已成立：开篇 Power 触发不再像旧 S2 那样直接跳步，公共界面也都写成记录与社会重估而非能力来源。当前真正残留的是两类可定位问题：公开主尺之外的“零级”表述，以及少数标志性画面是否比已写 Power 多走了一步。# PREMISE COMPILE TRACE AUDIT

## Old S2 Failure Baseline

旧 S2 的四个硬冲突成立：

- 开篇群体反转与全城开门发生在 Power trigger 之前。
- 回音塔被当作字钉效果的复制/放大器。
- `声位0级`不在 World 定义的 `1—100` 尺内。
- “醒来”解除全城永久命令，假设主钟是未定义的共同载体。

另有从执行官口中夺得“开门”前，执行官必须真实说过该命令的来源缺口。

## S1

- Verdict: FAIL

- Exact conflicts:
  - World 只定义 `1—9火`；T0 仅为“低火命核”，第一次兑现却写“零火或未登记”。`零火`未被 World 容纳，“未登记”是身份而非力量尺，精确位置未闭合。
  - 第一章写的是“咬住”命核，Power trigger 要求“主动吞下”；Trace 把前者直接改写为后者。
  - 标志性画面明确的是拖钟尸体，Trace 却指定“死亡异兽”并产出“兽颚”；该异兽的尸令、最后动作“扑咬”及其命核均未在画面中成立。
  - Origin 已写主角“正站在灰坑里”，画面又写其“站起来”；这是状态表达冲突，不是新能力。
  - 百章中的“战争机械”若只是物体，不属于“有身体命核、已经死亡的生命”；不能自动成为吞食目标。20 章的高火遗骸也仍须处于尸令执行中。
  - Trace 的第 1、2、4、5 项方向正确，但第 3 项及“反咬尸令兽”没有以精确字段闭合。

- Boldness preserved:
  - `吞死者最后动作→长成可损坏器官→拆换组合身体`是清楚、可反复升级的 Changed Verbs。照骨镜只记录、转播、认证并改变尸体归属、价格与声誉，没有越权放大 Power。失败在可编译性，不在尸体/器官设定的激进度。

## S2

- Verdict: FAIL

- Exact conflicts:
  - World 的容阶只有 `1—9阶`，却使用“零容阶身份”；T0 的城门级内腔没有被映射到任何公开容阶。
  - Power 要求目标是“已脱离原位置、连续完整”的非生命物；画面写“半座城门”撞来，Trace 却改成“完整城门已断开”，没有字段支持。
  - Power 只允许在主角身体接触的边界开出口；“城门从追兵脚下的地面吐出”未证明该地面正被主角接触，Trace 只是重述限制。
  - 界碑只记录“登记边界”；旧城门及这次跨越是否属于登记边界未定义，Trace 不能直接声称已记录。
  - `吞入界钉→容积增加`已授权，但“成为九阶变量”没有容积与九阶之间的明确成长映射。
  - 没有共同载体、无限复制或质量消失：内腔有限且真实，吐出的仍是同一物体；这一部分合格。

- Boldness preserved:
  - 胸口吞下真实城门、房间、桥和掩体，再改落点部署，具有强烈且清楚的 Changed Verbs。界碑只记录跨越并改变产权、责任和信用，没有复制、减重或放大吞入。

## S3

- Verdict: FAIL

- Exact conflicts:
  - World 公开城阶为 `1—9阶`，T0 只写“低阶城核”，却称“零阶空城”；精确位置未被 World grammar 容纳。
  - 守门人自愿跨门并表达选择，trigger 已满足；但“铁骨门塔”“铁臂反击”没有来自该人物能力、体质或欲望的已写字段。Trace 用概括性“对应”代替来源。
  - Trace 漏记城门开闭、门塔反击等开篇动作，未做到逐项闭合。
  - World 有城阶，Power 有居民转换，但没有“居民/建筑/城核如何使主角从低阶升至九阶”的因果规则。
  - “道路追人”“城门咬住敌军”“吞并道路与敌城”超出已授权的自愿居民转换与建筑调用；尤其吞并道路、敌城不是现有 Power。
  - 居民只被授权选择进入；“自行决定成为城门、心脏或外墙”是额外一次形态选择，未被明确授权。
  - 天图钉可记录进出与城门开闭，但不能看见城内私人转换；“每次转换都成为公共事件”过度外推。

- Boldness preserved:
  - 主角就是行城、自愿者不可逆地成为活建筑、居民保留意识但不能离开、死亡即永久损失，均是高辨识度的核心承诺。没有无限复制或共同载体问题；失败来自未授权的门塔表现、升级路径和吞并动作。

## Architecture Verdict

- `Single-Agent Premise Forge`：是作者选择前的非 Canon 搜索器，只生成 S1/S2/S3，不自动选择、不是新 Authority。
- `Authority-Compilation Trace`：是候选输出合同，负责暴露“动作→字段→trigger→载体”的闭合与否；它不是合法性的自我声明，更不是新增 Judge。
- `lane-specific frozen contract`：只在作者选定后生效。World、Power、Human 各自只接收自己的硬约束；Story 在 Authority 批准后才看到完整承诺。冲突应显式报出，不能静默圆设定。
- 当前 production freeze：观察到的 Premise Aperture 文档仍标为 `EXPERIMENTAL / AUTHOR-GATED / NOT PRODUCTION DEFAULT`；本轮 S1/S2/S3 均未进入 Authority，更未改变当前 production freeze。

本审计不建议新增 Agent、Judge 或 Hard Gate。三个候选都保住了大胆前提；但在当前文字下，没有一个可无冲突进入 lane-specific frozen contract。
