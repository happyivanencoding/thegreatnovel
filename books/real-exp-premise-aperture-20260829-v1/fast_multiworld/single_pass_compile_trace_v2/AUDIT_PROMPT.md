# OLD S2
## S2｜活令

### 一句话货架简介

他不是人，而是一句从死者喉咙里掉出来的命令；他能从被自己击败的人口中夺走一句话，再把这句话钉进任何身体，让对方必须照做一次。

### World-only Direction

第一世界为“万言城”。

这里的语言不是比喻，而是有重量的东西。

普通命令可以造成短暂的现实反应：

- “停”能让一双脚停住。

- “开”能让门锁松动。

- “跪”能让人的膝盖弯下。

- “闭嘴”能让声音从喉咙里消失。

命令的强弱取决于声音、距离、听见的人数和说话者在社会中的“声位”。普通人只能影响身边一两个人，城主的声音却能通过回音塔覆盖整座城市。

日常生活因此极其具体：人们避免随便说动词，孩童先学习手语，重要誓言必须在见证者面前说出。城市会把强大的命令刻入石碑，久而久之形成无法撤回的永久命令。

万言城的最高统治者不是最会打的人，而是能让整座城市听见自己一句话的人。

### Protagonist Ontology-only Direction

主角开局不是人，而是一句没有说话者的活命令。

它表现为一条会爬行的黑色字迹，字迹中间长着一张极小的嘴。它可以沿着墙面、刀刃、钟声和人的舌头移动，却没有肺、声带和真正的身体。

它只能通过附着在物体或人体上形成暂时的人形轮廓。

没有人知道它原本是谁。它只记得自己诞生时的两个字：

“不跪。”

### Power-only Direction

主角可以从一个被自己真正击败的说话者口中，割下一句刚刚说过的命令。

这句命令会变成一枚黑色字钉。他可以把字钉钉进门、兵器、野兽或人的身体，强迫目标完成这句话一次。

他不能创造新词，不能修改语序，也不能把“杀他”解释成复杂的战略指令。命令必须保持原本的字面含义。

能力成长方向不是分析语言，而是：

- 同时保存更多命令。

- 把命令钉入更大的目标。

- 让多个命令连续发生。

- 让物体执行原本不可能完成的动作。

永久边界是：每句命令都必须依附于真实载体。载体被毁，命令就会消失；命令越强，黑字越明显，无法完全隐藏。

### Story Interface / Opening Promise

万言城的回音塔会放大所有重大命令。

谁在公开场合下令，整座城都可能听见；谁被命令改变行动，回音塔会把那一刻重映在城墙上。

主角的一切成长都会进入公共视野。他不能像普通修士那样闭关攒力量，而必须在众目睽睽下争夺一句句能够改变现场的命令。

开篇承诺是：

执行官命令所有人跪下时，一条黑色字迹从死者喉咙中爬出来，贴在城门上，让整座城的门同时打开。

### 第一章标志性画面

黑线突然穿过整座刑场，所有跪下的人都被弹起，只有执行官自己的膝盖重重砸碎石板。

他可以：

- 从敌人的命令中夺取武器，而不是单纯夺取武器本身。

- 把“停”“开”“转”“回来”等简单命令钉进环境，让门、桥、城墙和兵器参与战斗。

- 让敌人自己说过的话反过来成为束缚。

- 在战场上收集不同势力的命令，临时拼出完全不同的行动链。

随后，他借助刑台断裂的铁钉刺穿执行官的喉咙，完成第一次真正击败，从对方口中割下“开门”。

他把这句话钉进一座封闭囚牢。

整座囚牢没有钥匙、没有灵力波动，却在所有守卫眼前自行敞开。

### 20章玩法扩张

前两章是公开处刑、诞生和逃亡。主角先证明自己不是一枚普通文字，而是一个能主动选择载体的生命。

第三至六章，他借附着在断刀、城墙和钟上的方式行动，逐渐理解语言秩序。他击败一名低阶守门人，获得第一句可储存命令，并用它解救被封锁的人。

第七至十章，故事转为命令争夺。追捕他的“禁言司”擅长让人失去声音，主角必须在不能说话的情况下用已有命令战斗。

第十章前后，城市对他的看法发生改变：有人把他当成叛乱武器，有人把他当成死者复仇，有人想垄断他的命令库。

第十一至十四章，他进入一片被永久命令钉死的城区。那里的人、河水和房屋都在重复几百年前的一句话。他必须取得能够解除僵死状态的命令，却不能牺牲一个拒绝被他控制的关键关系。

第十五至十八章，万言城进入公开命令战争。城主通过回音塔下令“闭城”，所有城门、桥梁和水道同时封死。主角没有新的万能词，只能重新组合已经夺来的命令，突破回音塔。

第十九至二十章，他击败主钟守护者，夺得“醒来”这一句命令，并将永久冻结整座城市的命令解除。

他达到第一世界的顶层尺度：成为唯一能切断或重启全城命令的人，直接决定万言城的秩序是否继续存在。

- Carry-forward：命令字钉、公共身份、不能自造词的边界、重要关系对命令使用的限制、已经公开的敌我名单。

不规定下一世界具体使用什么语言、力量或社会结构。

### 100章以上仍能长出的不同故事

这套能力的长线不是“收集更多词”，而是每个世界对命令的承认方式不同：

- 战斗可以围绕声音、载体、距离、听众和字面漏洞展开。

- 主角可能控制兵器、野兽、军阵或城市结构，而非只控制人。

- 重要关系能真正限制他：他拥有可以命令对方的字，却选择不用。

- 命令的强大与危险不完全相同，越强的命令越容易留下永久后果。

- 他会逐渐面对“我到底是一个人、一个意志，还是别人最后一句话”的身份问题。

- 不同世界可以让同一句简单命令产生完全不同的实际玩法，但不会把主角变成抽象的规则管理员。

### 最小可信桥梁

万言城本来就存在语言赋能、回音塔、永久命令和公开声位。

叛军首领临死前说出的“不跪”没有被任何人完整听见，因此没有正常落地，反而成为脱离说话者的活命令。

执行台、死者喉咙、回音塔和公开处刑共同制造了主角的出生条件，不需要预言，也不需要世界提前等待某个救世主。

### 不可磨平的三点

- 主角的本体是一句命令，不是换了职业的人类修士。

- 他不能凭空创造最方便的词，只能夺取真实说过、真实赢来的命令。

- 他的成长必须在公共听觉和公共观看中发生，每句强命令都会改变社会秩序。

一个公共处刑场里，尸体还在拖着刑钟往前走。

炉灰中站起的主角发现，死人最后的动作不是遗言，而是可以被吞掉的身体。它每吃掉一个死者，就会把那个人或那头兽最后做过的事长到自己身上；而照骨镜会把它“穿着谁的死亡继续活着”传遍整座城。

长期 Meta Grammar：

- 每个世界提供不同的生命、尸体与高位身体边界。
- 主角已经获得的身体变化、经验、装备、关系与代价不 Reset。
- 跨界只改变“什么样的死亡值得争夺”，不抹掉已经长成的身体。

### Authority-Compilation Trace

1. **灰坑中站起**
   → 来源：`Protagonist Ontology-only Direction` + `Initial Origin-only Direction`
   → Power 触发：未满足
   → 目标／载体：自身焦灰身体、胸腔命核
   → 合法性：主角在零点已经成形并点亮命核，站起是本体动作，不是 Power 结果。

2. **尸令体重复拖动刑钟**
   → 来源：`World-only Direction`
   → Power 触发：未满足
   → 目标／载体：已死亡者留下的尸令
   → 合法性：尸令只重复死前最后动作，不需要主角或额外机制。

3. **主角吞下尸令命核，长出兽颚**
   → 来源：`Power-only Direction`
   → Power 触发：已满足——目标已死亡、尸令仍在执行、发生直接接触并主动吞食
   → 目标／载体：死亡异兽的胸腔命核，结果载体为主角下颌
   → 合法性：目标类别、接触条件、动作类型和身体载体全部明确。

4. **照骨镜记录并转播这一幕**
   → 来源：`World Interface-only Direction`
   → Power 触发：无关
   → 目标／载体：固定镜面与公共记录
   → 合法性：镜面只记录可见动作与结果，没有放大、复制或改变吞食行为。

5. **尸商改变报价，军队停止把主角当普通尸体处理**
   → 来源：`World Interface-only Direction` + 记录后的社会后果
   → Power 触发：已满足
   → 目标／载体：尸体归属、悬赏和公开身份
   → 合法性：社会估值改变，不等于 Interface 改变 Power 因果。

### 第一章标志性画面

焚尸炉刚熄，刑钟却还在响。一具尸体拖着半截铁链走出灰坑，主角从它身后站起来，咬住仍在抽动的胸腔命核。下一刻，主角的下巴裂成一张兽口，反咬住扑来的尸令兽。

### 主角反复会做的新动作

吞掉死人最后的动作；把死者的扑杀、奔逃、攀爬、护住要害和临死反击长成身体；拆下旧器官换成新器官；故意选择“谁的死法值得穿在自己身上”。

### 第一次不公平兑现

主角以零火或未登记状态，直接吞掉一头四火异兽的尸令，获得其咬合与爆发器官，在没有修炼、没有武器的情况下撕开尸潮缺口。

### 20章玩法扩张

- 前段：炉坑逃生、第一次吞食、确认命火尺与尸令规则。
- 中段：从低火尸体转向异兽、战士和高火战场遗骸；主角开始主动选择身体构型。
- 后段：尸商、熄场和军队争夺主角；公开记录让他从危险尸体变成可交易的异常战力。
- 最后阶段：主角参与九火级尸令危机，必须在“吞掉最高价值遗骸”和“保住仍活着的人”之间作出真实选择。
- World Horizon Handoff 的触发条件：本地九火级最高局势完成结算，主角已经获得可跨世界保留的身体结构，同时留下一个因尸令规则而无法在本地继续扩大的新问题。

### 100章以上仍能长出的不同故事

同一 Power 可以进入不同的本地因果：

- 某世界把死者视为资源，故事重点是猎杀、遗骸争夺与身体收藏。
- 某世界禁止死后动作，故事重点是主角的身体被视为违禁证据。
- 某世界的高阶生命死后会留下区域级动作，故事转为灾害探索。
- 某世界没有人类尸体，只有异兽、战争机械或被世界承认的其他生命形式。
- 关系线可以围绕“主角要不要吞掉重要人物留下的最后动作”展开。

### 最小可信桥梁

- 尸令只重复最后动作，不包含人格，避免主角直接获得完整人生。
- 主角的力量只作用于已死生命，第一章必须先出现真实尸令目标。
- 所有新能力都必须长成身体，读者能看见，也能看见被破坏。

### 不可磨平的三点

- 主角从第一章就是尸体，不恢复成普通人形。
- Power 是“吞死者最后动作并长成身体”，不能改写成吸收经验或复制技能。
- 每一次获得力量都意味着主角身上多出一段死者身体，但不等于拥有死者人格。

## S2｜《吞下城门的人》

### 一句话货架简介

他是一个胸口长着大嘴的空心人，别人只能搬运一间屋子，他却能把整座城门吞进身体，再从背后吐出来砸死追兵。

### World-only Direction

这是一个“内外尺寸不一致”的世界。

- 物体和空间都有可被辨认的边界；外面一间房，里面可能大如街区。
- 使用界术的人以“容阶”衡量最大稳定容积：一至三阶处理器物，四至六阶可以携带房屋或街巷，七至八阶可以折叠堡垒和城区，九阶能够稳定容纳本地最大规模的完整腹界。
- “内潮”会让封闭空间突然扩张、错位或塌缩，城市必须定期检查房屋、地窖、井道和城门。
- 真正值钱的是完整边界、界钉、未塌缩的内室和能够固定空间的公共建筑。
- 普通人的上升入口是界猎、空间搬运、内潮救援和边界争夺；边界猎团、城市折师、内室商队与废墟势力各自争夺稳定空间。
- 最大危险不是单纯的敌人，而是空间突然把人、房屋和道路折到错误位置。

### World Interface-only Direction

- 所有登记边界都安装“界碑”，界碑会记录物体或人员跨越公共边界的时间、方向、可见形态与结果。
- 记录只能观察边界外侧及跨越瞬间，不能看见未公开的内部空间，也不能改变空间结构。
- 多块界碑可以把记录同步到城市公共墙面和商路节点。
- 记录会影响物品归属、房屋产权、灾害责任、通行资格和交易信用，但不会让任何物体自动移动。

### Protagonist Ontology-only Direction

- 主角是一个活着的“空腔人”，保留人形外壳，但胸腔没有内脏，只有一张贯穿身体的真实开口。
- 他能感觉重量、温度、撞击和空间方向，却不需要普通消化系统。
- 身体内部不是无限空间，而是一个具有边界的真实内腔；内腔会受损、堵塞和挤压。
- 他不是空间精灵，也不是寄宿在人体内的意识，而是一个本身就以空腔为器官的生命。

### Initial Origin-only Direction

- 第一场事件发生前，主角已经在一座被内潮掏空的旧城门夹层中自然成形。
- 零点状态：他站在城门内部的空腔里，胸口开口已经存在，口径与普通城门相当。
- 他没有记忆、装备、身份和同伴，只能在夹层中缓慢移动。
- 此时还没有吞入任何物体，Power 的吞入条件尚未满足。

### Power-only Direction

- 触发条件：主角主动张开胸口开口，使目标完整穿过开口。
- 目标类别：已经与原位置断开的、连续完整的非生命物体，或拥有完整边界且内部没有有意识生命的空间。
- 口径边界：目标最大截面必须不超过当前口径；T0 时口径等于一座普通城门。
- 可做动作：
  - 将目标完整吞入内腔，保持其结构和功能。
  - 在身体接触到的任意边界处打开出口，将目标原样吐出。
  - 改变目标吐出的方向、角度和落点。
  - 用吞入的建筑作为盾牌、牢笼、落石、桥梁、掩体或临时道路。
  - 吞入界钉后扩大内腔容积；容积增长必须来自真实吞入，不能靠意念升级。
- 永久边界：不能吞入仍有活跃意识的生命；不能复制目标，不能减轻目标部署时的质量和冲击，也不能从远距离无接触取物。

### Story Interface / Opening Promise

城门塌下来时，所有人都在逃，只有胸口长嘴的主角张开身体，把整块城门吞了进去。

他不是储物袋，而是一个会带走战场的活人：城墙、牢房、桥、陷阱和敌人的退路，都可能在战斗中被他吞走、改向、吐回。

长期 Meta Grammar：

- 每个世界都提供不同的边界、空间尺度和可携带之物。
- 主角携带的内腔、已经吞入的东西、身体损伤和社会关系永久保留。
- 新世界只能改变“什么东西最值得搬走”，不能把主角重新变成普通修士。

### Authority-Compilation Trace

1. **主角在城门夹层中移动**
   → 来源：`Protagonist Ontology-only Direction` + `Initial Origin-only Direction`
   → Power 触发：未满足
   → 目标／载体：自身空腔身体
   → 合法性：移动是空腔生命的基础身体动作，不涉及吞入。

2. **内潮使旧城门脱离原位置并坍塌**
   → 来源：`World-only Direction`
   → Power 触发：未满足
   → 目标／载体：内潮与断裂城门
   → 合法性：内潮本来就会使边界错位和塌缩，不需要主角存在。

3. **主角吞下完整城门**
   → 来源：`Power-only Direction`
   → Power 触发：已满足——目标为非生命、已脱离原位置、完整穿过当前城门宽度的胸口开口
   → 目标／载体：城门进入主角内腔
   → 合法性：目标类别、断开状态、尺寸边界和主动吞入均已写明。

4. **主角从另一侧吐出城门，挡住追兵**
   → 来源：`Power-only Direction`
   → Power 触发：已满足
   → 目标／载体：同一块已吞入城门、主角身体接触的出口边界
   → 合法性：只改变出口方向，不复制、减重或远程召回。

5. **界碑记录城门跨越边界，商队重新估价主角**
   → 来源：`World Interface-only Direction`
   → Power 触发：无关
   → 目标／载体：界碑记录、产权与交易信用
   → 合法性：记录改变社会后果，不改变城门的物理移动。

### 第一章标志性画面

城墙像纸一样向内折叠，半座城门朝主角胸口撞来。主角胸腔张开一道黑色竖口，城门消失；数息后，城门从追兵脚下的地面吐出，把整队人砸进断墙。

### 主角反复会做的新动作

吞掉道路、转移房间、携带战场、把敌人的掩体变成自己的武器、从体内吐出一条原本不在此处的路；他每一次移动，都可能带走一块当地空间。

### 第一次不公平兑现

主角在零容阶身份下，直接拥有城门级内腔；他不需要修炼容阶，就能把普通六阶界师必须多人搬运的城门变成随身攻城器。

### 20章玩法扩张

- 前段：从塌缩城门逃生，确认“非生命、完整边界、断开位置”的吞入规则。
- 中段：吞入房间、桥梁、陷阱和界钉，把探索、战斗和逃亡合并成空间偷运。
- 后段：界猎团与城市折师开始争夺主角内腔中的稀有结构；主角必须决定哪些东西值得长期占据身体。
- 最后阶段：主角卷入本地最高级腹界的归属冲突，将自身从移动容器提升为能够改变本地空间战局的九阶变量。
- World Horizon Handoff 的触发条件：本地最大边界冲突完成结算，主角已拥有可跨世界保存的内腔与一组真实携带物，但仍受到“不能吞活跃意识生命”的永久限制。

### 100章以上仍能长出的不同故事

- 以空间盗窃为核心的城市冒险。
- 把一座废墟、监狱或战场带入另一处的战争故事。
- 主角体内藏着不同人物必须争夺的家园、证据或遗物。
- 某个世界把“内部空间”视为神圣禁区，主角的吞入行为成为最大禁忌。
- 关系线可以围绕“什么东西值得占据身体容量”展开：财富、武器、住所、遗物与某个人的家之间必须取舍。

### 最小可信桥梁

- 世界本来就存在可测量的空间边界和内潮。
- 主角的胸口开口、T0 口径和内腔有限容量全部在 Authority 中明写。
- 吞入不抹除质量、不复制物体，只改变其暂存与再部署位置。

### 不可磨平的三点

- 主角是空腔生命，不是普通人获得储物能力。
- Power 的核心是“吞下并搬走真实边界”，不是储物、分析或空间理论。
- 不能吞有意识生命，且吐出时仍保留原物的重量和破坏力。

## S3｜《他就是一座会走的城》

### 一句话货架简介

他不是住在城里的人，他就是一座刚出生的城；想活下去的人必须自愿住进他的身体，而每一个选择留下的人，都会变成一座能战斗的建筑。

### World-only Direction

这是一个地面会迁徙、固定聚落会被吞掉的世界。

- 大地存在周期性“地潮”，地面会整体位移、开裂或向地下塌陷。
- 固定房屋、道路和城墙无法长期抵抗地潮；人类依靠拥有城核的“行城”迁徙。
- 行城以“城阶”作为公开力量尺：一至三阶只能保护村落，四至六阶可以承载城镇，七至八阶能穿越大型地潮，九阶行城具备决定本地最高局势的力量。
- 重要资源是水源、城核碎片、锚钉、可迁徙的粮道和能让行城停留的安全地基。
- 普通人的上升入口是加入行城、争夺城核、护送迁徙路线和攻占失控聚落。
- 行城、锚钉商队、掠城团与地潮祭团会独立争夺路线和资源；即使没有主角，某些城市也会选择迁徙、合并、放弃居民或发动攻城。
- 最危险的不是单个敌人，而是城在移动中被切断、居民被迫离城，以及地潮让整片道路消失。

### World Interface-only Direction

- 每座行城的边界都装有“天图钉”，自动记录城体移动、城门开闭、外部攻城、人员进出和城体损毁。
- 天图钉将记录同步到附近行城和商路节点，形成公开地图与可回放的边界档案。
- 记录不能观看城内私人生活，不能控制城市移动，也不能制造人口、建筑或城核。
- 记录会改变商队路线、避难资格、盟约信用、战争责任和居民对某座行城的信任。

### Protagonist Ontology-only Direction

- 主角是一座刚出生的行城，不是人类操纵的城市，也不是寄宿在城核中的人格。
- 其身体由城核、城门、墙段、道路和附着建筑组成。
- 城核是心脏，城门是主要感官与沟通器官；主角可以通过城门发声、看见进入边界的人。
- 城内建筑和墙体都是主角身体的一部分；最初没有居民，因此身体空旷、迟缓且极易受损。
- 主角有人的欲望、偏心、享受、虚荣和占有欲，但其身体尺度是城市尺度。

### Initial Origin-only Direction

- 第一场事件发生前，主角已经在一处废弃锚坑中完成出生。
- 零点状态：一枚低阶城核、四段残墙、一座城门和一条短街组成最初身体。
- 城内没有居民、商队、军队和建筑功能，主角只能缓慢拖动自己的地基。
- 主角知道自己是一个新生的行城，但没有前身记忆、城市历史或既有身份。
- 此时尚未有任何居民主动进入，Power 的转换触发尚未满足。

### Power-only Direction

- 触发条件：一个具有独立意识的活人，自愿跨过主角城门，并明确表达“选择进入这座城”。
- 目标类别：自愿进入的活人；不能强迫、不能转换尸体、不能转换无意识物体。
- 可做动作：
  - 将该人的身体永久编入城体，形成一座与其能力、体质或欲望相关的活建筑。
  - 主角可以在城界内移动、展开或收回这座建筑。
  - 被编入者保留意识和自主意志，但其身体不再能够离开主角城界。
  - 主角可以调用该建筑对应的真实身体功能：猎人的身体成为远射塔，重甲武者成为城门撞槌，擅长奔跑者成为移动桥或城内运输器官。
  - 多个居民建筑可以组合成一次城体动作，但每个居民必须仍然存活，且建筑本身会承受伤害。
- 永久边界：
  - 转换不可逆，主角不能把居民恢复成原本的人形。
  - 主角不能控制居民的思想或强迫其主动行为。
  - 居民死亡就是永久损失，不能复活。
  - 未进入城界的人无法被调用，主角也不能复制未加入者的能力。

### Story Interface / Opening Promise

一座空城在废弃锚坑里睁开城门。

地潮即将吞没这里，一个受伤的守门人走进门内，自愿选择留下。下一刻，他的身体化为一座长满铁骨的门塔，城门第一次拥有了能反击的手臂。

主角要建立的不是势力，而是自己的身体；每一个愿意留下的人，都必须决定自己究竟愿意成为这座城的哪一部分。

长期 Meta Grammar：

- 每个世界提供不同的生存尺度、城市边界与居民价值。
- 主角的城体、居民建筑、装备、伤痕和关系永久保留。
- 后续世界不预设具体社会或力量答案，只改变什么样的人会选择进入，以及“成为城的一部分”会带来怎样的代价。

### Authority-Compilation Trace

1. **空城在锚坑中缓慢移动**
   → 来源：`Protagonist Ontology-only Direction` + `Initial Origin-only Direction`
   → Power 触发：未满足
   → 目标／载体：城核、残墙、城门和短街
   → 合法性：行城身体本来就能拖动地基，零点状态已明确身体构成。

2. **地潮逼近并吞没废弃锚坑**
   → 来源：`World-only Direction`
   → Power 触发：未满足
   → 目标／载体：迁徙地面与固定聚落
   → 合法性：地潮独立存在，不由主角制造。

3. **守门人自愿跨门并选择留下**
   → 来源：`Power-only Direction` + `Initial Origin-only Direction`
   → Power 触发：已满足——活人、明确自愿、跨过主角城门
   → 目标／载体：守门人的身体，被编入城体
   → 合法性：触发语言、目标类别和进入载体均明确，无额外考核或隐藏契约。

4. **守门人变成铁骨门塔**
   → 来源：`Power-only Direction`
   → Power 触发：已满足
   → 目标／载体：被转换者的身体与主角城门
   → 合法性：转换是永久的身体结果，门塔承担守门人与其身体特征对应的功能。

5. **天图钉记录城门开启与居民进入**
   → 来源：`World Interface-only Direction`
   → Power 触发：无关
   → 目标／载体：城界记录、公开地图和避难信用
   → 合法性：Interface 只记录边界事件，不制造转换，也不替主角控制居民。

6. **附近商队重新评估这座空城**
   → 来源：`World Interface-only Direction` + 可见建筑变化
   → Power 触发：已满足
   → 目标／载体：避难资格、路线和盟约信用
   → 合法性：社会价值改变，但转换的因果来自自愿进入与 Power，不来自观看本身。

### 第一章标志性画面

地面像海浪一样隆起，废弃锚坑正在下沉。一座只有四面残墙的空城打开城门，受伤守门人回头看了眼即将消失的旧路，走进去说：“我选这座城。”

城门合拢，他的骨头从门柱里长出来，变成一座会挥动铁臂的门塔。

### 主角反复会做的新动作

用城墙转身、用道路追人、用城门咬住敌军、让居民成为新的器官；主角的每一次关系选择，都会改变自己的身体结构和战斗方式。

### 第一次不公平兑现

一座零阶空城通过一个人的自愿选择，立刻获得远超普通村落的攻城门塔，并能把这个人的身体力量扩大到城体尺度。

### 20章玩法扩张

- 前段：空城逃离地潮，第一次获得居民建筑，确认城市身体与城阶规则。
- 中段：不同人物因不同欲望选择进入，主角必须面对“留下一个人，就永久占有其身体”的关系代价。
- 后段：敌对行城、商队和逃难者围绕主角重新定价；公开记录使每一次转换都成为社会事件。
- 最后阶段：主角从一座只能自保的小城，成长为能够穿越最高级地潮、决定本地行城战争结果的九阶行城。
- World Horizon Handoff 的触发条件：本地最高城核与地潮局势完成结算，主角的城体和核心居民关系已经稳定到可以跨界，而下一次扩张的触发原因仍只保留为条件，不预写第二世界答案。

### 100章以上仍能长出的不同故事

- 围城、迁徙、抢夺水源与道路的城市战争。
- 某个重要人物选择成为主角身体的一部分，却在成为建筑后改变立场。
- 居民之间的欲望冲突直接改变城体布局：谁成为城门，谁成为心脏，谁被放在最危险的外墙。
- 不同世界可以让“进入一座城”的意义完全不同，但不需要预先规定第二世界的具体社会。
- 主角既能成为庇护所，也可能成为会主动吞并道路与敌城的移动灾害。

### 最小可信桥梁

- 世界本来就存在城核、行城和公开城阶。
- 主角出生时只有低阶城核与少量城体，不需要额外解释为何能移动。
- Power 明确要求自愿进入且不可逆，因此每一次居民转化天然带有人物选择和真实代价。

### 不可磨平的三点

- 主角就是一座城，不得恢复成普通人类主角。
- 居民转换永久、可见且改变身体，不能软化成普通收编、契约或招募。
- 主角不能控制居民思想；城市力量必须持续经过关系、选择和损失才能扩大。
