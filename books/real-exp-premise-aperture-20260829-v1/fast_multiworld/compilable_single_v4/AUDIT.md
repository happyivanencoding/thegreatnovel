# V4 AUTHORITY COMPILER AUDIT
## S1
- Verdict: CONDITIONAL PASS
- Opening legality: 行刑者有意识地以命火掌击杀当前身体，随后重聚、复现该次致死结果，均由 `死式` 明文推出；回声也只负责记录与传播。需明确“同一击”在画面中是冲击结果与轨迹，而非复制命火本身。
- Scale legality: T0 的 `0｜未燃`被命火尺合法容纳。
- Long-form legality: 前17章可复合既有死式、死痕和死潮规则；但第18—20章从“承受高阶杀招”直接到 `9｜天门`、关闭死潮源头，没有已定义的死式—命火尺成长映射。Power 又明确不提供主动修炼命火，不能自行补足。
- Exact hidden bridges: 需要明写：九道高阶死式如何使回死体合法达到命火尺9，并获得关闭源头所需的天门资格；高火遗骸须在死潮尸令期间，战争机械不得被当作可吞食生命命核。
- Boldness preserved: “被杀后夺取致死结果、用死痕支付复现代价、让敌人争夺谁来杀他”仍强且清晰；失败不在激进度。

## S2
- Verdict: FAIL
- Opening legality: 拆迁者进入并关门可以触发；但棚屋“从地基缩进”不等于其完整、实际穿过唯一门槛。初始只有一扇门，Trace 所称“后墙门口”也无明文来源。门影还缺少五名见证者已实际看见通行的事实。
- Scale legality: T0 的 `1｜室壳`合法。由棚屋接入承重结构升至 `2｜院壳`，仍需满足“多个可自持房间”的公开定义，不能只由Trace宣称承重连接成立。
- Long-form legality: 既有吞入、收纳、接入承重结构和内部重排足以支撑中期玩法；但吞入“界壳核心”并接通承重结构，不能单独推出 `9｜界壳`或本地最高边界承载资格。
- Exact hidden bridges: 需要实际完成完整棚屋与界壳核心的过门过程；需要已有真实门而非临时出现后墙门；需要明确九阶壳体所需的完整边界承载结构及其与城壳尺9的对应。
- Boldness preserved: 吞下真实建筑、把城市身体化、让被吞活人保有意志，货架画面和新动词依然强；问题只在过门、门位和尺位闭合。

## S3
- Verdict: CONDITIONAL PASS
- Opening legality: 审判官看见完整倒影并指向性说出“镜妖”，从其持有短刀的反光面出镜，均在Power覆盖内；Interface只回放，不复制出镜。可是Power明写一次出镜只能进行“一次”真实动作，夺钥匙与割门绳是两个连续动作，当前未闭合。
- Scale legality: T0 的 `0｜镜影`合法；第一名有效命名者建立一枚锚点，并使主角进入 `1｜单点落地`，有明确映射。
- Long-form legality: 九名不同触发者完成有效命名、各自建立一枚锚点，至九处稳定落地，可以只复合已定义规则达到显形尺9。锚点依赖持续生命与记忆，也为百章关系代价提供已定义 runway。
- Exact hidden bridges: 需要把开篇兑现收束为一次真实动作，或明写首次出镜后还能在同次显形内连续执行夺钥匙、割绳的授权；并确保短刀确为审判官身边最近的可反光出口。
- Boldness preserved: “敌人确认并命名主角，反而给他建立路线”仍是强、怪异且可反复兑现的主押注；不是缺点。

## Architecture Result
当前 Forge 自带 Trace 不足够：它能列出声称的来源与触发，却不能独立阻止未写门、未完成过门、未定义尺位跃迁或多走一步动作。需要保留一个独立 compiler check，作为作者选择前的实验步骤。
