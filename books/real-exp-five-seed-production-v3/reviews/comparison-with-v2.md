# Seed-only comparison

## 1. v3 是否比 v2 更有多样性

是，但主要体现在直接机制层面，尚未达到深层故事模板完全分散。

v2 的五个 Seed 实际上只有四个力量家族：

- C01：拾取“差一步成立”的未生结果，并补足失败条件。
- C02：承载死物或死世界最后一刻的遗时。
- C03：让死亡真正杀死自己，再把死亡炼成死窍。
- C04、C05：从败相、败世或失败人生中借回替代结果。

其中 C04 与 C05 不是简单名词相似，而是共享“唯一正史删去结果—主角从失败中借力—被记录机构追杀—进入败世—让被删者获得选择”的同一条因果骨架。C01 也与它们共享“唯一现实压制替代结果、亲属被抹除、主角承载被删可能”的更深模板。

v3 的直接行动单位则确实分开了：

- C01 是承接、储存和转向下坠之势。
- C02 是猎杀灵兽并移植其生命结构。
- C03 是识别缝隙并穿越边界。
- C04 是读取断裂结构并重新接合。
- C05 是收取、叠加和释放声音震动。

这些差异被保留在第一次奇观、力量代价、10/30/100章成长和世界扩张中，不是只更换能力名称。因此，v3 的直接规则分布比 v2 更开。

但 v3 仍有共享母型。C01 与 C05 尤其接近：都让主角进入高危险环境，把外部力量收入身体，储存或调制后再释放，并因身体承载力提升而处理更大规模的自然现象。C02 也部分共享“把外部生命能力纳入身体”的循环，只是结果表现为器官重构，而非力量储存。C03 和 C04 的行动循环差异较大，一个是穿过边界，一个是修复断裂。

v3 的共同深层模板是：一个被判定为无用、残缺、受困、短命或沉默的人，把造成自身困境的外部规律转化为身体接口，重新夺回对自身存在的支配权。它因此比 v2 摆脱了“删史—败世—被抹亲属”的本体叙事母型，但没有摆脱“身体承受世界规律并以此成长”的深层母型。

## 2. v2 的“本体规则系吸引子”是否仍存在

作为一个完整的本体规则系，它在 v3 中不再存在。

v2 中反复出现的关键机制——被记录排除、亲属被删去、世界只承认唯一现实、未被选择的结果被抹除、主角最终获得现实定义权——在 v3 五份 Seed 中都没有形成实际的世界底层规则。

v3 的相近元素不能等同于这些机制：

- C01 的矿工被视为耗材，是阶层压迫，不是从现实记录中被删除。
- C02 的血肉衰败和短命判定，是疾病与生命结构问题，不是唯一正史。
- C03 的封闭山谷是空间边界，不是“世界只承认一个现实结果”。
- C04 的双手、经脉被毁并被判定为废人，是个人损伤与社会否定，不是被抹去的存在。
- C05 的无法发声是身体限制，不是姓名、记忆或现实资格被清除。

仍然保留的只有一个较抽象的组件：身体成为规则接口。五个 v3 主角都要亲身承受某种外部规律，再把它转化为骨骼、器官、身体厚度、经脉结构、喉咙或神魂的能力。但这不足以恢复 v2 那套“唯一现实—删去结果—被删者回归—主角决定现实”的本体吸引子。

## 3. “生成真正不同的候选”是否实际发挥作用

结论：部分有效。

有效的部分是，五份 v3 Seed 已经产生了五种可辨认的直接机制，且机制差异贯穿了能力对象、首次兑现、成长路径和世界扩张。它没有重现 v2 中 C04/C05 那种完整同构。

不充分的部分是，五份 Seed 仍共享明显的输出语法：

- 主角都处于无权、受损或被限制的位置。
- 主角都必须亲自进入危险环境。
- 外部危险都被转化为身体能力。
- 身体承载过量会产生痛苦、裂损、失控或自我边界问题。
- 力量都沿“身体承载更大规模世界现象”升级。
- 终局都由主角以自身突破更高天地的进入条件。

所以，这条要求实际改善了直接机制多样性，也降低了 v2 式本体规则重复；但它没有让五个候选在共同深层成长模板上真正彼此独立。
