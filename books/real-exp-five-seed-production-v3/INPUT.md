# 作者方向

创作一部成熟中文男频玄幻修仙成长长篇。

主角的长期一级成长应主要发生在主角本人身上，并持续产生可感知的能力、生命状态、行动空间或世界位置变化。

主角应拥有普通人难以轻易复制的非对称优势。这个优势需要产生具体实际收益，并能够随着长篇发展继续演化、组合、扩张或改变玩法。

财富、资源、身份、关系、组织、势力、领地与地图都可以存在，但不应长期替代主角本人的一级成长。

世界、力量体系、主角身份、核心优势、敌人、关系、冲突方式、主题、价值观、故事终局和开篇形式全部由系统自行创造。

生成五个真正不同的候选。

不要预先给五个候选分配题材桶或结构模板。

不要加入：

- v1/v2 诊断；
- “安全对齐”；
- “高概念本体规则”；
- “名字/记录/败世”；
- “不要重复”之外更具体的例子；
- 任何我们希望或不希望看到的题材。
