# Proposed Active Scene State

当前地点：鸣骨峡旧风门前、被副链封住的兽道。  
在场人物：贺临川、照雪、唐鹭、叶朔；段阙、钩翼兽及商盟护卫在场。  
即时伤势：贺临川左肘肿伤、背部擦伤、虎口震麻、疲惫；照雪右前腿旧伤、仍可行动。  
手中关键物品：撬刀、短刃；半页旧契随身；完整航契在唐鹭手中。  
当前敌人或追兵：段阙与钩翼兽封住兽道；商盟正在收紧三处副链锁点。  
当前倒计时：旧风门只能再撑一会儿，天将亮前仍需返回。  
下一步直接目标：在翼钩落下前破坏副链锁点，保护照雪进入风门寻找沉瓦。  
当前主动目标：保护照雪的自主选择，打开迁巢路并确认风门内的沉瓦回应。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
贺临川仍无法正面对抗共鸣级26的段阙；已能用撬刀针对门轴楔石和锁链结构制造短暂通路，不能正面硬撬整条铁链。

### Active Relationships

唐鹭｜协助打开兽道并阻止照雪落入王庭兽库｜与主角形成有限临时协作｜已把短刃交给贺临川并转为指示破坏三处锁点｜以航契换照雪的提议被拒，未再强行带走照雪。  
叶朔｜试图打开旧风门、恢复迁巢路｜与主角形成现场协作｜已使旧门短暂开启｜承诺门只能撑一会儿。  
照雪｜自主进入副链下方缝隙、追寻风门内回应｜与主角保持同行但不接受替它决定｜已明确自行选择进入风门方向。

### Knowledge / Enemy State

风门内确认存在沉瓦相关回应；旧风门正在短暂开启，灰羽兽已飞出，笼中幼兽开始撞栏；商盟已用三处副链和绞盘封堵出口。段阙确认贺临川不会以照雪交换航契。

### World State

旧风门被叶朔与贺临川撬开后，部分灰羽兽已经逃出，商盟封锁的迁巢路出现短暂缺口；商盟正在公开加固封锁，现场冲突升级。

### Tracked Assets

完整航契｜唐鹭｜旧风门前｜折叠保存｜贺临川拒绝交易后归还唐鹭。  
短刃｜贺临川｜旧风门前｜可使用｜唐鹭本章交给贺临川。  
半页旧契｜贺临川｜随身皮袋｜皱损并沾苔汁｜持续持有。  
撬刀｜贺临川｜旧风门前｜仍可使用｜持续持有。  
照雪｜贺临川附近｜副链下方、旧风门入口｜右前腿旧伤、主动进入缝隙｜持续同行。

# Proposed Chapter Summary

贺临川拒绝以照雪交换唐鹭的航契与船位，选择让照雪自行决定去留。他协助叶朔撬松旧风门，放出灰羽兽并使迁巢路短暂开启。段阙带钩翼兽封死兽道，商盟收紧三处副链。唐鹭交给贺临川短刃并指示破坏锁点，照雪循着风门内沉瓦回应钻入缝隙，翼钩随即落下。
