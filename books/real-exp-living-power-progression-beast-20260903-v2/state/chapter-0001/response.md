# Proposed Active Scene State

当前地点：折鹤岛北侧风苔坡，废弃运料坡道附近。  
在场人物：贺临川、照雪；商盟人员在断桥残端搜捕。  
即时伤势：贺临川背部受撞、肋侧擦伤；照雪右前腿被笼门夹伤。  
手中关键物品：小撬刀。  
当前敌人或追兵：持巢纹牌的百巢商盟人员，正在封锁北坡。  
当前倒计时：商盟人员即将封住北坡。  
下一步直接目标：沿废弃运料坡道逃离追捕，暂时保住照雪。  
当前主动目标：带照雪逃出北坡封锁。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
已与照雪完成第一次稳定共鸣，能够在动作中彼此借入并传回爆发力；目前仅真实成立过短暂的一借一还，照雪仍未完成正式登记。

### Active Relationships

照雪｜自行逃离笼车并选择北坡路线｜与贺临川形成初次稳定共鸣，仍保持警惕与自主判断｜右前腿受伤，已共同逃亡。

### Identity / Access

贺临川已形成未登记的共鸣关系；照雪仍被百巢商盟视为带有旧契标记、必须追回的幼兽。

### Knowledge / Enemy State

已确认照雪身上有旧契标记；百巢商盟正在追捕并封锁北坡。照雪尚未确认是否愿意长期跟随贺临川。

### World State

折鹤索桥在换风中断裂，商盟运载的幼兽脱笼；北坡因商盟追捕暂时进入封锁状态。

### Tracked Assets

照雪｜贺临川附近、北侧风苔坡｜右前腿受伤，已脱离兽笼｜由商盟兽笼转为自主逃离。

# Proposed Chapter Summary

换风中折鹤索桥断裂，贺临川借先见一瞬避开铁钩，并用旧铜扣撬开兽笼救出白兽。白兽借力协助他抓住副索，两者首次越过共鸣级1。坠落后，白兽右前腿受伤，商盟追兵发现旧契标记并封锁北坡，贺临川带它逃入风苔。

# Proposed Open Promises

- 贺临川与照雪能否逃出商盟对北坡的封锁。
- 照雪右前腿的伤势能否得到处理。
- 照雪身上的旧契标记及其契约归属。
- 贺临川与照雪能否真正保住彼此的自主权。
