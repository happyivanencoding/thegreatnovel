在场人物：贺临川、照雪、唐鹭、叶朔、韩狩、军府士卒、段阙及钩翼兽。

手中关键物品：装有乌金回脊索的黑色长匣、半页旧契、撬刀、短刃；完整航契在唐鹭手中。

下一步直接目标：带照雪撤离旧风门闭合范围，并保住黑匣、乌金回脊索与旧契线索。  
当前主动目标：确认乌金回脊索与苏渠、半页旧契及沉瓦的关系。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
贺临川无法正面对抗共鸣级26的段阙；已能借乌金回脊索的回脊扣与环境受力完成短距离借力救援，但索不能替代自身力量，强行借力会加重腰背负担。伤势与疲惫持续压低当前发挥。

### Active Relationships

唐鹭｜协助贺临川撤离并识别乌金回脊索｜与主角保持有限临时协作｜确认乌金回脊索由苏渠制作｜照雪与航契之间的交易仍未兑现。  
照雪｜与贺临川共同撤离｜与主角保持同行但保留自主选择｜救出被碎石压住、回应其鸣声的老兽后主动返回贺临川身边。  
段阙｜试图夺回黑匣及相关契物｜与主角公开敌对｜因风门闭合与断链牵制暂时放弃追击。

### Identity / Access

乌金回脊索现由贺临川持有；段阙已公开将其认定为“不该拿的东西”，后续可能因此追索。

### Knowledge / Enemy State

乌金回脊索扣环刻有“苏渠”，唐鹭确认其由苏渠制作，原本应与苏渠航契一同消失。  
照雪回应的兽是被碎石压住后腿的老兽，已由照雪和兽群带入高处风道。  
第三段副链已被逃出的岩背兽撞断；旧风门随后合拢，段阙未能追入。

### World State

商盟对旧风门迁巢路的三段副链封锁全部失效，大量伴生兽完成进入风道，现场交易秩序与押运封锁被打乱。

### Tracked Assets

乌金回脊索｜贺临川｜黑色长匣内｜温热、可用｜从坠落交易台上的黑匣中取得。  
黑色长匣｜贺临川｜随身｜匣盖曾翻开，现已收纳乌金回脊索｜从坠落交易台夺得。  
半页旧契｜贺临川｜随身皮袋｜皱损并沾苔汁｜持续持有。  
完整航契｜唐鹭｜旧风门外侧岩台｜折叠保存｜持续持有。  
旧钉｜韩狩｜布包内｜已拔出并保存｜从旧风门门柱取得。

# Proposed Chapter Summary

贺临川从坠落的黑匣中夺得刻有“苏渠”之名的乌金回脊索，并借其回脊扣救回进入裂缝的照雪。照雪先救出回应它的受困老兽，第三段副链随后被岩背兽撞断。唐鹭与军府士卒将贺临川和照雪拉回岩台，旧风门在段阙未能追击前合拢。
