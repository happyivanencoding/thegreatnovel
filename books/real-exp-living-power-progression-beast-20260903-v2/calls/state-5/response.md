# Proposed Active Scene State
当前地点：鸣骨峡入口岩台，临时交易棚屋与深峡道口之间。  
在场人物：贺临川、照雪、唐鹭；附近有叶朔、韩狩率领的裂云军府队伍、百巢商盟护卫。  
即时伤势：贺临川左肘肿伤、背部擦伤与疲惫；照雪右前腿旧伤已重新包扎。  
手中关键物品：撬刀、半页旧契；外套粗线缝补，旧铜扣遗失。  
当前敌人或追兵：段阙未现身，正在等待有人深入；商盟押运车载有铁笼兽只并已驶出峡口。  
当前倒计时：天将亮，必须尽快查明“夜交”并返回。  
下一步直接目标：跟住照雪听见的深峡道回应，确认旧契与货车旧印、苏渠遗留线索的关系。  
当前主动目标：保护照雪的自主权，查清旧契归属与商盟追索原因，并在天亮前返回。

# Proposed Chapter Summary
贺临川与照雪在天亮前抵达鸣骨峡入口，发现此处聚集着商盟交易、伴生兽迁徙和裂云军府等多方势力。披灰斗篷的唐鹭认出照雪属于苏渠，并指出段阙正在等待他们深入。贺临川又发现半页旧契的沉瓦印记与商盟货车旧印相同，而照雪正听向更深峡道传来的兽鸣。
