# Proposed Active Scene State

当前地点：鸣骨峡裸骨风口内侧，旧风门后方兽道。  
在场人物：贺临川、照雪、唐鹭；段阙与钩翼兽在上方追击；叶朔、韩狩及商盟人员仍在风口交易台。  
即时伤势：贺临川左肘肿伤、背部擦伤、疲惫；照雪右前腿旧伤。  
手中关键物品：撬刀、半页旧契；唐鹭持有完整航契。  
当前敌人或追兵：段阙与钩翼兽已锁定并追击；商盟封住旧风门兽道。  
当前倒计时：天将亮，需在此前返回。  
下一步直接目标：避开段阙，确认旧风门后的兽鸣与旧契线索。  
当前主动目标：保护照雪的自主权，拒绝以交出照雪换取离峡机会。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
贺临川与照雪仍无法正面对抗共鸣级26的段阙，只能依靠地形、旧索和照雪主动选路暂时避开追击。

### Active Relationships

唐鹭｜试图带走照雪并促成离峡｜与主角保持谨慎接触｜认识照雪及苏渠的兽｜提出以交出照雪换取完整航契与今夜商船座位，承诺未决。  
叶朔｜试图打开旧风门、恢复迁巢路｜与主角尚无关系｜与商盟争夺兽道使用权｜已公开要求卸下封路铁链。  
韩狩｜查验旧钉痕并封锁风口｜与主角尚无关系｜与商盟就税契和封道发生冲突｜已确认旧风门下存在旧钉痕。

### Knowledge / Enemy State

旧风门后确有回应照雪的兽鸣；商盟用铁链和负重兽封住迁巢路，准备将笼中伴生兽交给王庭兽库。段阙追索的不只是半页旧契，也包括照雪及其相关归属。

### World State

商盟押运货物与伴生兽迁巢路发生直接冲突；军府已因旧钉痕暂时封锁风口，四方行动者在旧风门处形成公开对峙。

### Tracked Assets

完整航契｜唐鹭｜鸣骨峡旧风门兽道｜折叠保存｜本章明确拿出并提出交换。  
半页旧契｜贺临川｜随身皮袋｜皱损并沾苔汁｜持续持有。  
撬刀｜贺临川｜随身｜仍可使用｜持续持有。  
照雪｜贺临川附近｜旧风门后方兽道｜右前腿旧伤、继续自主行动｜持续同行。

# Proposed Chapter Summary

贺临川与唐鹭沿窄道追入风口，确认商盟正用货车和铁链封住伴生兽迁巢路，并准备将笼中兽只交给王庭兽库。叶朔试图打开旧风门，韩狩发现旧钉痕并封锁岩台。段阙带钩翼兽追击，照雪借兽道避开攻击。唐鹭随后拿出完整航契和今夜商船座位，提出以交出照雪换取离峡。
