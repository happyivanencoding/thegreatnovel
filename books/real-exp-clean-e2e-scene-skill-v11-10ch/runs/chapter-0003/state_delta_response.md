# Proposed Chapter Summary

陆砚扒开石窝湿冷岩壁下的窄缝，带着受伤的韩铁衣和两只矿账穿过旧排水渠，避开已发现路印的玄衡宗搜捕者，抵达黑砾城外侧荒沟。两人决定前往回灯集，却在灯阵外被守门人以没有边荒行籍为由拦下，尚未进入集内，城墙方向的追兵仍在逼近。
