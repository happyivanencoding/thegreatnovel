# Proposed Chapter Summary

搜捕者找到废水槽并开始持续封井。陆砚返回逆潮水道，凭逐次出现的承重点抵达被旧支柱压住的韩铁衣处，并利用水流、铁钎和短矿木暂时支撑顶板，成功将韩铁衣救出。韩铁衣说明支柱旁的黑色铁匣是包含七号灵脉换柱记录、死者名单和过采深度的完整矿账，陆砚将其取出带走。两人带着两只铁匣和逆潮灵砂向更深处撤离，来路随后彻底塌堵，最终退入一处石窝，并发现湿冷岩壁下有吹出冷风和草根气味的窄缝。
