# Proposed Active Scene State

- 当前地点：七号灵脉下方的废水槽，靠近墙根与水道缺口；封锁台和坡上的火把在附近。
- 在场人物：陆砚；废水槽深处被困并以敲击回应的韩铁衣；正在逼近并搜查废水槽的玄衡宗执法矿役。
- 即时伤势：喉咙和胸口受矿尘及呛水影响，持续咳嗽；肩部擦伤；旧伤因撞击和攀爬加重；身体湿冷。
- 手中关键物品：矿账残匣；腰侧湿布中包着少量逆潮灵砂。
- 当前敌人或追兵：玄衡宗执法矿役搜捕者；阮青崖下令的封井处死和搜捕尚未解除。
- 当前倒计时：天黑前原定执行封井处死；天尚未完全黑，剩余时长不明；搜捕者正在接近。
- 当前主动目标：在搜捕者赶到前确认韩铁衣的位置和状况，并在不暴露自己的前提下建立接触或处理救援线索，同时脱离封锁台的搜捕范围。

# Proposed Persistent Canon

- 陆砚仍是黑砾城玄衡宗名下的低等矿役兼探道杂役，身份登记在矿籍中，正常出城需要许可。
- 七号灵脉坍塌后，陆砚被矿账记为事故主责；玄衡宗已对他实施封锁、追捕，并准备封井处死。
- 已证明能力：在不稳定的地下河和坍塌矿层中，陆砚能看见逐次出现的短暂可承重落脚点。
- 能力限制：他看不见完整道路，只能在行动前看到下一个落脚点；落脚点会受水流、落石和自身重量影响而迅速消失。
- 陆砚能够在湿泥墙面留下暂时不被水冲平、并短暂发白的路印；来源、机制和功能未知。
- 已确认矿道经验：灰岩冒白汗处只能短暂承重；三声矿鸣后旧道会错位。
- 长期伤势：身体持续受矿尘、灵脉压迫和旧伤影响；本章新增肩部擦伤、胸口疼痛及旧伤加重。

### Active Relationships

- 阮青崖｜以矿账认定陆砚为事故主责并下令封井、搜捕｜与主角处于敌对的定责与追捕关系｜从定责转为现场封锁和追捕｜是否发现废水槽并继续追捕未决

### Tracked Assets

# Proposed Chapter Summary

七号灵脉响起三声矿鸣后旧道错位塌方，陆砚带着矿账残匣进入逆流地下河，凭逐次出现的临时落脚点穿过坍塌矿层，从废水槽离开，并取得少量逆潮灵砂。他在墙根留下一个暂时发白的路印，随后在搜捕者逼近时听见废水槽深处传来韩铁衣惯用的敲击声，确认韩铁衣仍然活着。
