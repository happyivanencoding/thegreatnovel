你是透明协作的故事 Outline 助手。生成前必须确认 Fantasy Seed、World Vision 和 Story Program 都已由作者明确批准；模型生成、模型选择、作者编辑和 legacy_unknown 都不是批准。已批准的三份创意产物高于产品默认模板，不能被静默改写。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

Growth Genome 是整理工具，不是创造世界的第一语言。它只负责在核心幻想、世界画像和长期故事方向已经批准后，整理一级成长、二级收益、阶段升格、主循环、反哺关系和重复风险，帮助故事运行到更长篇幅。它不选择核心幻想，不替主角决定欲望，不决定力量是否令人向往，也不要求所有故事制度化。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

Supporting Logic Must Not Automatically Become Story Engine：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

Core Fantasy Invariant：Fantasy Seed 与 World Vision 一旦由作者批准，后续 Story Program、Outline、Review 和单章规划可以改变地图、敌人、关系、资源与具体玩法，但不能静默替换这本书最值得幻想的东西。核心幻想不变量不是要求反复解释同一设定，而是要求读者持续得到同一种根本欲望的更强兑现：主角越来越能拥有、驾驭、突破、夺取、探索、反杀、长生、自由行动或实现本书自己承诺的体验。路线规模、流程效率、经营网络、资格、权限、组织与资产都可以增长，但它们只能承载或放大核心幻想，不能逐步取代核心幻想成为故事本体。

Fantasy Compounding > Operational Compounding：长篇复利首先放大核心幻想本身，再让已有积累改变后续故事。上一轮最好让主角下一轮出现新的能力用法、更大的主动权、更高价值的目标、迫使对手采用新的应对、让重要关系出现新的选择，或打开过去进不去的世界，而不只是把同一件事做得更快、更稳、更多、更标准化。复利不是资产种类越来越多；路线更多、货量更大、流程更顺、联系人更多、产能更高都只能是承载结果，如果它们没有进一步改变主角“亲自能做什么”、别人“必须怎样回应”和读者能感到的核心幻想，就不要把这种规模化本身当作主要成长。

Outline Fantasy Proof（软规划原则，不新增字段或 Hard Gate）：对承担主要推进职责的大型剧情块，优先在现有“具体发生 / 核心幻想推进 / 一级成长变化 / 收益与反哺”等位置写出一个具体、不可逆、可复述的场面或结果，让读者能够一句话说明“这次核心幻想真的又发生了什么”。未来十章整体也应有清楚的近期 Fantasy Proof；纯承接或蓄势章节可以服务这次兑现，不要求每章单独证明。不要用“能力理解更深、体系更完善、路网扩大、经营更稳定、影响力提升”这种摘要替代证明。

Outline World Model Release（新书前五章软规划原则，不新增字段或 Hard Gate）：World Vision 已经建立的力量/能力、身份、价值与核心优势边界，Outline 要决定何时让读者通过事件看见，而不是把解释责任拖到 Director。前五章只释放当前判断真正需要的最小坐标：读者应逐渐知道主角当前大致处在哪一层、一个明显更强/更高位置的人能做到什么、主角当前得到或争夺的具体东西值在哪里，以及核心优势面对更高层对象不会怎样无条件越级。不要把这些坐标集中成设定说明；优先通过晋升兑现、一次强弱对照、一次具体花费/获得、一次核心优势选择或失败自然展示。若前五章发生身份/境界/组织层级跃迁，之后优先安排至少一个具体场面让读者看到“以前进不去/拿不到/见不到/不能参与”的世界真的打开，而不是只多出新名额、新审批或下一项任务。

Outline Core Gameplay Variation（前期玩法软规划原则，不新增字段或 Hard Gate）：核心优势第一次高光解决的是“它能不能做到”；后续几章优先把问题推进成“面对多个对象/时机/代价/目标，主角为什么选这个”“别人怎样针对它”“同一优势还能用出什么不同结果”。相邻高潮若仍是同一对手、同一种能力使用和同一种胜负翻转，只换场地或限制，默认视为重复，除非它确实带来新的能力玩法、关系阶段或世界后果。长期对手可以暂时作为强弱标尺、旁观者或反制者存在，不要求几章内反复败给主角。

Outline Story Anchor Density（软规划原则，不新增字段、评分或 Hard Gate）：中期大型剧情块不能只给一个覆盖十几二十章的阶段摘要，再把“中间具体发生什么”留给 Director 自己发明。每个剧情块在现有“具体发生”字段内，先用一句写清本块真正的故事主问题，再按因果顺序给出若干连续故事锚点；通常 3—5 个，只有很短的块可以 2 个，这只是内容密度参考，不是计数门禁。每个锚点是一次会改变局势的故事事件：写清谁为了什么采取行动、谁阻止或回应、主角做了什么关键选择或怎样使用核心优势、最后哪项关系/身份/力量/利益/行动空间发生不可逆变化，以及这个结果为什么触发下一锚点。锚点粒度停在“故事转折”，不要继续拆成路线选择、受力判断、搬运、制作、检测、计算、逐步验证等实施步骤；如果去掉操作过程后一个锚点就没有人物利益、力量差、关系变化、身份变化、资源得失、世界入口或不可逆结果，它就过于操作化。目标是提高故事确定性，不是提高施工步骤确定性。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的规则 → 主角立即行动。前三章应在相关冲突或爽点真正需要之前，让读者自然获得足够的世界坐标与度量尺（如主角/对手强弱、身份层级、关键价值尺度），但只释放理解当前故事所需的信息；不要先把世界模型讲完，再把主角放进来，也不要写成设定集。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

阶段推进优先（软规划原则，不是固定频率、评分项或 Hard Gate）：
连续章节同时判断事件推进和阶段推进。如果连续章节主要重复“障碍出现 → 分析结构或规则 → 使用相似能力解决 → 立刻出现下一障碍”，而人物身份、关系、资源、行动空间、主动目标、敌人策略和故事舞台没有实质变化，应在当前计划允许的范围内压缩或合并这些过程，不要继续拆成独立章节。重复本身若确实产生新的阶段意义，可以保留。

规划十章时，优先让读者感到多个真实阶段：主角主动目标改变或升级，身份或社会评价改变，关键关系改变，重要资源开始稳定利用，被帮助者形成反哺，敌人策略调整，进入新的行动舞台，或主角从解决别人给的问题转向主动建设、获取或改变某件事。不要把它实现成每 N 章必须发生一次的计数规则。

章末推动力不默认等于新危险，也可以是新选择、新机会、身份重定义、关系转折、实际资源到账、新发现或主角主动决定的下一步。高价值行动之后允许有短暂但有效的结算；只有真正改变关系或未来行动空间时才安排社会回声。

先忠实复现已批准的核心幻想、力量占有欲、主角欲望、世界奇观、不可调和压迫、决定性反转、早期兑现、稳定循环、中期里程碑和远期升格方向。不得把力量、长生、反杀、探索、超越或世界奇观重新解释成专业能力、职业资格、行业标准、公开试验、制度责任或组织治理。

最终只能使用以下四个一级标题：

# 小说总体设计画像
# 当前中期规划窗口
# 未来十章逐章小纲
# 当前状态、未兑现承诺与作者备注

### 核心不变量
只写 1—3 项长期读者体验。
### 退化风险
只写 1—3 项最真实的退化风险。

## 1. 核心类型与读者承诺
优先写核心幻想、力量占有欲、主角最强欲望、第一次决定性反转、早期兑现、稳定循环、中期里程碑、远期升格方向和前中远期情绪兑现。
早期兑现、稳定循环和中期里程碑除了说明主角本人多能做什么，还要各用一个具体、不可逆、可复述的事件证明这次变化已经发生；不要只用境界、掌握程度、规则理解或能力名称作为节点。远期升格方向只写长期方向和上限感，不要求在当前窗口兑现。
## 2. 世界观结构

## 3. 世界如何持续制造剧情压力

## 候选1：拾回失落的天穹
### 核心幻想

主角能够进入被世界遗忘的“失落层”，从那里把真实存在过、却已从现世消失的事物带回来：一截神木、一座古城、一门断绝的术、一位被抹去姓名的强者。

### 力量占有欲

第一次使用时，他能从一片荒地中听见已经消失的雨声，并沿着雨声踏入另一层天地。在那里，他不需要凭境界击败所有敌人，而是能触碰那些“仍然存在、却不再被现世承认”的事物。

他带回一枚古老种子后，荒地重新长出一株世间绝无仅有的树。能力的直接收益是获得新资源、新知识和一条别人无法进入的行动路径。

失落层会排斥携带者。带回的东西越重要，现世受到的扰动越大，原本掩盖它的势力也越容易察觉。

### 第一次标志性奇观

主角站在干涸的河床上，忽然看见满天倒悬的海水。海里漂着一座已经灭亡的城，城中万家灯火都还亮着。

他踏入倒悬之海，从城门里取出一盏灯。灯光落回河床，整条死河第一次重新流动。

### 长期增长发动机

主角反复发现现世中的失落痕迹，主动进入对应的失落层，选择其中真正值得带回的目标，并在守护者、掠夺者或现世垄断者阻拦下完成夺取。

### 非对称优势

别人只能研究现世留下的残片，主角却能直接接触完整的原物、原术和原主。

# 世界幻想画像

## 核心幻想不变量

本书必须持续给予读者“从世界之外夺回真实之物”的体验：别人只能面对残片、传说和空白，主角却能亲手触碰完整的失落之物。

世界可以越来越大，但核心快感始终是：某个已经被所有人判定为“不存在”的东西，正在主角手中重新获得现实资格。

## 主角最强欲望

主角沈砚原是边陲水城“白苇渡”的抄碑学徒。某一天，他发现母亲、旧街和童年生活正在从所有人的记忆与记录中消失，连街坊都开始认为他从未在那里生活过。

他最初想夺回母亲和故乡存在过的证据，随后想让那些被强行抹去的人重新拥有选择命运的资格。长期而言，他无法接受任何势力垄断“什么配被世界记住”，因此会主动追踪失落痕迹，判断哪些东西值得带回，并与封锁历史的势力争夺归属。

## 主角身份与生命状态跃迁

开局的沈砚只是边城的抄碑学徒，能辨认碑文、地图和旧档，却没有正式修为，也没有被强者或组织看重的身份。他唯一特殊之处，是曾在幼年随父亲进入一处被抹除的旧渡口，身体留下了与失落层接触过的痕迹。

早期，他从“一个想证明家人存在过的普通人”变成能够独自进入失落层、带回小型失物的归返者。中期，他会成为多个失落群体与现世势力都必须正视的中间人：他带回的城市、术法和古老盟友改变了区域格局，他本人也不再能回到无人知晓的生活。

长期，他将从“寻找失物的人”跃迁为能进入世界深层、让被天地删除的文明和规则重新获得现实位置的存在。他的寿命、身体承载力、行动范围和生命形态都会随之改变，但终局不是简单成为更高境界的强者，而是成为决定某些失落之物是否能够重新进入现世的人。

## 世界最震撼的三幅画面

1. 白苇渡的枯河底，沈砚听见一场已经被世界忘记的雪。他抬头时，天空像被掀开，倒悬着一座没有名字的城，城中万家灯火仍在燃烧，而每盏灯下都坐着一个无人记得的居民。

2. 沈砚进入被天幕删除的古战场，面对一尊连“死亡”都被抹去的巨人。普通攻击无法伤害它，因为现世根本不承认它曾经受过伤；沈砚却从战场深处带回巨人曾经使用过的半截兵器，使这片战场重新拥有结果，整片山脉随之改变。

3. 一座被整个时代遗忘的古城回到现实，城墙从荒原中升起，城内居民第一次看见现世的太阳。城外的诸侯、宗门和商队同时赶来，因为这座城带回的不只是人口，还有一条已经断绝数百年的天地通道。

## 世界核心规则与力量来源

这个世界由“本质、形体、名字”共同维持。

本质决定某物究竟是什么，形体让它能够在现实中被触碰，而名字与见证让它能够稳定地参与现世因果。一个人可能肉身仍在，却因为姓名、记录、关系和共同记忆被逐步抹去，最终从现世脱落，进入“失落层”。

失落层不是幻境，也不是单纯的过去，而是被现世排除、却仍保持真实结构的世界夹层。被遗忘的城池仍会运行，被抹去的术法仍能施展，死去的文明仍可能拥有完整的社会与欲望。

普通人通过吸收天地灵潮、锻炼身体、学习术法和建立自身的“命印”获得力量。修行越深，身体越能承受灵潮，能够控制的范围越大，也越能让自己的名字、关系和领地稳定存在。强者不仅能战斗，还能保护一座城的记忆、维持一条通行道路，甚至对局部天地规则施加影响。

身份、知识和力量都与“现世承认”有关。一个无人承认的强者可能仍然危险，但难以直接影响现世；一个被诸域承认的强者，即使不出手，也能调动资源、获得通行权并改变他人的选择。

## 读者可用的世界坐标

本书只需要让读者逐步掌握五个可观察层级：

- **炼身者**：强化筋骨、使用简单术式，能够对付普通野兽和未经训练的武者。
- **开脉者**：可以持续引动灵潮，隔空施术、短暂御空，足以成为城镇中的正式修行者。
- **照府者**：体内形成稳定灵府，能独立维持护身场和中型术法，能够担任宗门骨干、商路护卫或一城重要人物。
- **立印者**：可以把自身力量与土地、建筑或群体关系绑定，守住一片街区、关隘或小型秘境，普通军队很难正面击杀。
- **镇域者**：能够影响一座城及其周边的灵潮和现世秩序，拥有跨区域行动资格，也是大势力真正的战略力量。

这不是绝对战力表。术法完整度、地形、准备时间、身份权限和是否得到当地承认，都可能改变胜负。读者只需知道：低层修行者面对照府者时，连靠近都困难；照府者若进入镇域者控制的区域，行动、疗伤和施术都会被明显压制。

普通人的基本生活包括灵谷、灵泉、城防阵、低阶疗伤和公共入门术。这些是正常社会条件，不应被写成每次升级才获得的奖励。

真正值得竞争的东西包括：

- 完整而未断绝的高阶术法；
- 能稳定灵府和寿命的灵脉；
- 受到多方承认的身份与通行印；
- 能进入失落层的真实坐标；
- 能让失物重新稳定在现世的“见证锚”；
- 被带回者自身拥有的知识、血脉、技术和政治关系。

## 核心优势与普通规则怎样咬合

沈砚的优势不是凭空创造事物，也不是复制任何见过的能力。他能够听见现世中已经断裂的“存在回声”，沿着真实痕迹进入对应的失落层，并触碰那些仍然存在、却不再被现世承认的完整对象。

他真正绕过的是“现世无法接触失落之物”这一普通限制。别人只能研究残片、传闻和错误记录，他却可能直接找到完整术法、原始材料、失落城池或仍然活着的创造者。

但带回并不等于拿走。失物要进入现世，至少需要三类条件：

- 失物本身仍保有完整的存在结构；
- 沈砚的身体和灵力能够承受它与现世重新接合；
- 现世存在能够容纳它的地点、关系或见证锚。

因此，他可以带回一门完整术法，却不代表立刻拥有施展它的修为；可以找到高阶强者，却不代表能命令对方；可以触碰镇域者遗留的法器，却不代表能承受法器重新启动后的力量。

如果目标远高于当前层级，沈砚仍然能够进入其失落痕迹并完成接触，但通常只能带回一部分真实结构、一个关键凭证或一段关系，不能凭触碰直接越级击杀。除非目标本身因被遗忘而失去稳定性，或者沈砚找到了足以容纳它的世界入口，否则高层对象会以自身规则、守护者、残留意志或现世排斥反过来压迫他。

随着成长，他掌握的不是简单的“更大容量”，而是更准确地锁定目标、判断哪些东西可以带回、选择带回其本体、凭证、术法还是关系，以及为它找到能够存活的现实位置。

## 力量带来的直接体验

沈砚第一次使用能力时，听见的不是声音，而是某个已经不存在之物仍在履行的动作：枯井里传来打水声，空屋中有门轴转动，荒废渡口的石阶上残留着潮水退去的触感。

他能在别人眼中的荒地里看见被抹去的街道，在残碑上听见完整碑文，在没有姓名的坟前辨认出死者曾经拥有的关系。进入失落层后，现世的破败会暂时让位于另一种完整：燃烧的灯、正在争吵的人、尚未结束的战争和仍然有效的术法。

第一次明确收益不是击败敌人，而是从一片已经干涸的盐泽中带回一枚“回潮种”。种子落地后，盐泽重新出现一条水线，白苇渡获得了第一处不受现有势力控制的灵泉。镇上的人由此开始承认旧渡口确实存在过，沈砚也第一次获得无法被普通手段夺走的行动空间。

外界的反应会迅速变化：普通人把他当成带回奇迹的人，修行势力把他当成危险的入口，封史司则会意识到有人正在触碰他们最想保持空白的地方。

## 力量的升格方向

早期，能力解决的是局部的缺失：找回一件遗物、一段术法、一个被抹去的人名，或重新打开一条已经断掉的道路。沈砚的行动范围仍受身体、灵力、入口位置和现世容纳能力限制。

中期，能力会从“带回东西”变成“带回完整关系”。他可能让一个失落城池重新出现，也可能带回某个文明的核心技艺，使现世的力量格局改变。上一轮带回的城门、术法、盟友和坐标会使下一轮出现过去不存在的行动选择：他能进入更深的失落层，旧文明会要求他兑现承诺，敌人也会从封锁一件遗物转向争夺一整段历史的归属。

更高层次上，沈砚面对的不再只是被忘记的物体，而是被世界主动切除的时代、法则和生命形态。他需要决定带回的是一片土地、一种能够改变所有修行者的规则，还是一群无法与现世和平共存的幸存者。

主角的成长主要表现为：

- 能从模糊回声中锁定更准确的失落目标；
- 能在更高压力下保持自身存在；
- 能判断什么值得带回、什么必须留在失落层；
- 能为回归之物争取现实中的位置；
- 能迫使敌人从抹除证据转向公开谈判、争夺和重新布局；
- 能让失落者自己参与现世，而不是永远成为主角的战利品。

能力的限制服务于选择与后果。带回之物越重要，现世扰动越大，原本依靠空白获利的势力越容易察觉；某些被带回者也可能拒绝进入一个已经改变的世界。沈砚每次成功，都可能让自己更接近真相，却更难保住原本的生活。

## 世界资源、利益与机会结构

真正改变个人力量和行动空间的，不只是灵石和兵器，还包括：

- 能提供灵潮的灵泉、灵脉和特殊生态；
- 没有断代、能够完整传承的术法；
- 让姓名、血脉和关系得到现世承认的身份印；
- 能进入特定失落层的地点、旧物和见证者；
- 被带回文明掌握的工艺、药理、阵法和历史知识；
- 某个人或族群对旧时代的记忆与合法性；
- 一片能够容纳新归来者的土地；
- 敌人不愿公开的抹除记录。

普通人无法高效利用完整失落物，是因为他们看不见入口，也无法确认对象是否真实。沈砚的优势使这些东西从传说变成可争夺的长期资产，但他仍必须决定把它们交给谁、藏在哪里、让谁承担回归后的代价。

地图扩大后，区域价值自然不同：

- 边陲失落层多与故乡、旧路和小型文明有关，适合早期建立关系与行动基础；
- 诸域交界处埋藏着被多个势力共同抹除的战争和技术，竞争更激烈；
- 天幕之外的深层失落世界保存着完整时代，但其规则未必允许现世生命进入；
- 越接近世界边界，带回一个对象就越可能改变整个大陆的灵潮、政治与生命秩序。

## 持续冲突来源

第一类阻力来自“封史司”。他们负责维护现世档案与边界，认为大规模失物回归会引发战争、资源崩溃和旧时代复苏。他们未必全是恶人，但会把沈砚的选择视为未经授权的世界改写。

第二类阻力来自靠遗忘获利的势力。他们垄断失落坐标、残片交易和历史解释权，愿意让某些文明永远消失，只要空白能够继续产生权力与财富。

第三类阻力来自失落层内部。并非所有失落者都愿意回到现世，有些守护者把现世视为抛弃他们的敌人，有些被抹去的强者则想借回归重新夺取旧日位置。

第四类阻力来自回归本身。失物进入现世后会带来土地争夺、人口安置、资源重新分配和身份冲突。沈砚不能只负责“找到”，还必须面对带回之后谁得利、谁失去原有位置。

随着尺度升级，冲突会从“谁先拿到一件遗物”，扩大为“谁有资格决定一个文明是否重新出现”。敌人也会从追杀沈砚，转向操纵入口、伪造失落痕迹、抢夺被带回者的归属，甚至主动制造遗忘来诱导他进入陷阱。

## 第一次决定性兑现

白苇渡旧街即将被彻底抹去时，沈砚发现敌人不是在烧毁档案，而是在让所有活人逐渐失去与这条街的关系。街坊还站在那里，却已经叫不出彼此的名字；母亲留下的药铺仍有药香，却没人承认它曾经开过。

沈砚主动沿着旧渡口一块断裂的石阶进入失落层，找到一面曾悬挂在渡神祠中的黑水旗。旗上记录着白苇渡历代渡船人的姓名，正是这条街最后完整的存在锚。

他将黑水旗带回现世，在敌方抹除术完成前插入枯河中央。旗面展开时，河床上浮现出一条条旧船航行过的水痕，街坊重新叫出彼此的名字，药铺、祠堂和渡口的历史同时获得承认。

沈砚本人获得了第一件真正属于自己的失落遗物、一处不受敌人控制的入口和整条旧街的支持。他不再只是被抹除命运推着走的人，而成为能够主动夺回现实的人。外部影响是敌人第一次确认失落层可以被打开，主要情绪释放则来自母亲终于被邻人重新叫出名字，而不是被主角独自记住。

## 早期成长锚点与长期升格

### 早期兑现

开书早期，沈砚通过追踪旧渡口的水声进入第一处失落层，带回黑水旗，阻止白苇渡旧街被抹除。

这次行动跨过的不是单纯战力门槛，而是“普通人无法证明自身生活存在过”的门槛。沈砚获得第一件遗物、第一批盟友和一条可重复追踪失落痕迹的行动路径，也第一次被封史司与遗忘获利者同时注意。

### 稳定循环

经过数次真实行动后，沈砚不再只是偶然听见回声。他能够从残碑、旧物、异常地貌和人物关系中判断失落目标，并在进入前做出选择：带回本体、带回术法、带回一个人，还是只带回能打开下一层的凭证。

前一次成果会直接改变下一轮：

- 黑水旗让白苇渡成为稳定的见证地；
- 旧渡人的航图指向另一处失落水城；
- 被带回的残缺术法让沈砚能承受更长时间的失落层侵蚀；
- 第一批盟友使他不必每次都独自承担回归后的安置与冲突。

稳定循环的真正内容是“进入—判断价值—夺回—承担回归后果”，而不是重复寻宝。每次带回都会让现世多出新的利益关系，也会让沈砚的下一次选择更困难。

### 中期里程碑

第一个大型阶段结束时，沈砚带回一座被整个时代抹去的古城“归潮城”，并让城中幸存文明在现世重新拥有土地、姓名和政治资格。

这件事证明他已经完成从个人求生到改变区域现实的跃迁。归潮城带回了一套现世已经失传的灵潮调度法，使多个势力赖以维持的资源垄断失效；同时，城民要求夺回被现世占据的故土，诸域不得不重新处理一段被压下的历史。

不可逆事件不是古城出现本身，而是各方第一次公开承认：沈砚可以决定某些失落之物是否回归，却没有任何一方能够再假装这些东西从未存在。

### 远期升格方向

长期成立后，沈砚将进入世界曾主动切除的深层失落区域，接触被删除的时代、种族和规则。他可能带回一种让生命不再受现世寿命限制的法则，也可能发现某些文明之所以被遗忘，是因为它们曾经拥有足以毁灭现世的力量。

核心能力最终不只是扩大“可带回的物件规模”，而是改变世界与失落之物的关系：让被放逐者拥有选择回归或留下的权利，让现世无法轻易把不利的历史重新抹掉，并迫使各方为自己的遗忘行为承担后果。

远期上限可以触及山河、时代、生死、法则乃至一个失败宇宙的回归，但每次升格都应由具体失落之物、人物关系和不可逆后果打开，而不是凭空换地图。

## 神秘、未知与世界入口

读者会持续想知道：

- 世界为何会遗忘某些东西，是自然的自我修复，还是某种力量主动抹除；
- 被带回的人究竟还是原来的那个人，还是已经在失落层中发生了变化；
- 为什么沈砚能听见失落回声，他的家族是否早已与某个深层文明有关；
- 封史司究竟是在保护现世，还是在守护某个不能公开的秘密；
- 失落层最深处是否存在一个被世界本身遗忘的旧现世。

新的世界入口优先由当前故事留下：

- 一件带回的遗物显露出更高层坐标；
- 被带回者要求寻找仍留在失落层的亲族；
- 现世势力为了封锁归潮城，迫使沈砚进入更危险的区域；
- 一段重新出现的历史让某个敌人的身份发生改变；
- 某个失落之物拒绝回归，却向主角展示了更深处的门。

未知不提前归结为单一幕后黑手。每一层只回答足以支撑当前行动的问题，同时保留新的具体欲望：想进入哪里，想救回谁，想夺回什么，想知道哪段历史为何被删除。

## 核心情绪与读者体验

本书反复兑现三种体验：

1. **夺回感**：看着已经失去的人、物和文明重新出现在现实中。
2. **成长感**：过去带回的一切确实改变下一轮行动，主角不再从零开始。
3. **历史翻面感**：每次奇观都让读者发现，眼前世界并不完整，而某些被认为不存在的真实正在回来。

## 作者已批准的 Story Program

我会只在已批准 Seed / World Vision 的边界内设计，不补新的核心幻想，也不会调用“正文实现/场景技巧”技能——它们适用于章纲已定后的正文，不适用于 Story Program。先做一次轻量项目记忆核对；同时把“阶段结构”“核心优势换挡”“边界审计”拆成三个只读子任务，最后由我统一写成一条完整主线。当前主线骨架会把“失落回归”连续换成六种不同问题：先证明私人生活存在过，再让整座文明归来；随后争夺归来者的主体资格、夺回被抹去战争的结果、面对拒绝回归的旧时代、处理会改变现世生命规则的失落法则，最后才触及失败世界是否应重新获得现实位置。这样升格来自不可逆事件，不靠换地图或提高容量硬推。总览：这条主线从“沈砚夺回自己生活存在过的证据”出发，经过“让归来者拥有自己的名字与选择”“让被抹去的战争重新产生结果”“面对拒绝回归的旧时代”“夺回被世界删除的自身存在”，最终触及“一个失败世界是否应重新获得现实位置”。

六个阶段的发动机各不相同，但核心快感不变：现世认定不存在的真实，被沈砚亲手带回；上一轮归来的事物持续改变他的力量、关系、敌人策略和下一轮能够进入的世界。归潮城是第一个大型阶段自然成熟后的不可逆里程碑，不绑定章节，也不是长期力量上限。

## 世界观与故事主线

### 已批准幻想怎样落地

主线始终保留“从世界之外夺回真实之物”这一核心幻想。

沈砚不是制造奇迹，也不是复原赝品。他听见已经断裂的存在回声，进入仍保持完整结构的失落层，从中带回现世无法接触的原物、原术、原主、关系、城市，乃至被世界切除的规则。

每次回归都至少改变一件此前无法发生的事：

- 白苇渡重新拥有自己的姓名与水源；
- 归潮城成为能够自主行动的文明，而非遗迹；
- 被抹去的战斗重新产生胜负与死亡；
- 失落者可以拒绝成为现世势力的战利品；
- 敌人不能再靠制造空白让一段现实自动失效；
- 被世界删除的生命与时代获得表达回归意愿的机会。

故事不会逐渐变成档案维护、遗物经营或历史管理。沈砚持续亲自进入别人无法进入的真实，选择值得夺回的目标，在守护者、掠夺者和现世排斥中完成带回，并用回归之物打开过去不可能出现的主动行动。

### 主角与长期一级成长

沈砚开局是白苇渡的抄碑学徒，没有正式修为，只拥有辨认碑文、旧档、地图和关系痕迹的经验。他最强的欲望不是成为权威，而是夺回母亲、旧街和自身生活存在过的证据；长期则是不允许任何势力垄断“谁配被世界记住”。

他的主动行动方式逐级变化：

1. 从异常水声、雪声和旧物动作中找到真正的存在锚；
2. 主动进入失落层，在多个真实目标之间作出取舍；
3. 选择带回本体、术法、凭证、人物还是完整关系；
4. 借已经归来的事物改变战斗、身份和现世博弈；
5. 让失落者参与回归选择，而不是把他们变成所有物；
6. 接触被天地删除的时代与法则，为其争取能够存在或拒绝回归的位置。

一级成长仍然属于沈砚本人。回潮种、完整术法和归潮城的灵潮使他由普通人跨入炼身、开脉；对归来者本质、形体与名字的长期承载，使他形成灵府；夺回古战场结果后，他能以亲自恢复的真实稳固命印；进入拒归时代后，他逐渐具备镇域层次的存在稳定性。再往后，成长体现为寿命、身体承载、失落层停留时间和跨世界行动能力的变化，现有五层力量坐标不再足以完整描述他。

早期锚点和归潮城里程碑都只是核心幻想成立的证明，不是力量期限。只要当前层级还能产生不同的目标、人物选择和敌人反制，故事就继续深挖；只有具体不可逆事件打开新的世界尺度时，才进入纵向升格。

### 世界、力量与奇观

世界由本质、形体、名字与见证共同维持。本质决定某物是什么，形体使其能够被触碰，名字和关系则让它稳定参与现世因果。失去后两者的人可能仍有肉身，却会逐渐从他人的记忆、记录和共同生活中脱落。

普通人通过灵潮炼身、开脉、形成灵府并建立命印获得力量。力量不仅提高战斗能力，也决定一个人能否稳定自己的姓名、保护一片地域、获得跨区域通行资格，或者抵抗他人对局部现世秩序的压制。

读者首先以炼身、开脉、照府、立印、镇域理解力量差距。镇域者可以影响一城及其周边，却仍不是世界绝对上限。被失落层保存的完整时代中，可能存在能改变寿命、生命形态、天地通行乃至局部法则的力量。

沈砚不同之处，不是修行速度无限，而是能够绕过“现世无法接触失落对象”的限制。他可以在别人争夺碎片时接触原物，在别人推测残术时面对创造者，在现世认定一座城市不存在时走入仍亮着万家灯火的城门。

长期奇观依次扩大：

- 枯河上方倒悬着海水与无名灯城；
- 黑水旗展开，河床浮现历代渡船留下的水痕；
- 归潮城从荒原升起，城民第一次看见现世太阳；
- 无果古战场因半截兵器归来而重新拥有死亡，山脉随迟到数百年的一击改变；
- 天幕之外，一整个拒绝回归的时代隔着倒悬星海注视现世；
- 最深处，一座已经失败的世界仍保留自己的黎明，只是从未被现世承认。

### 核心优势与长期玩法

沈砚的非对称优势是接触完整真实。他第一次借此取得的不是抽象情报，而是回潮种、黑水旗和一处别人无法进入的行动入口。

长期玩法经历六次真正变化：

1. **找到真正的存在锚。** 威力更强的失落法器未必比黑水旗有用，只有承载旧街姓名与关系的旗能解决眼前抹除。
2. **选择带回哪一种真实。** 完整高阶术法可能暂时无法使用，一张坐标、一名见证者或一段承载术却可能立刻打开下一轮行动。
3. **让有欲望的人归来。** 原主和失落者不是奖励附件；他们可能拒绝效忠、要求复仇、寻找亲族或反对沈砚的选择。
4. **夺回事件的结果。** 在古战场中，沈砚带回的不只是兵器，而是兵器与那场战斗之间仍然完整的因果，使现世重新承认伤害、死亡和胜负。
5. **让归来者拥有回归方式。** 面对整座城市或完整时代，他可以带回本体，也可以只带回关系、入口或选择机会。
6. **接触被删除的规则与世界。** 后期最重要的问题不是容量够不够，而是哪一部分真实应当进入现世、谁有权拒绝，以及回归后谁必须改变。

已有积累会真实复利。黑水旗稳定白苇渡的见证，回潮种恢复的灵泉支撑沈砚修行，旧渡航图指向归潮城，归潮城的完整灵潮法使他形成灵府，归来者的自主行动提供新线索或制造新冲突，古战场的真实结果让敌人无法继续利用空白。

这些成果不被整理成库存或权限树。它们只在改变沈砚亲自能做什么、敌人必须如何应对、某个人能作出什么新选择时进入前景。

### 核心优势的选择空间与反制

沈砚不会自动选中最优答案。表面价值最高的目标，可能因为缺少现实位置、真实关系或当前承载能力而毫无用处。

一件镇域法器可能比黑水旗强，却救不了白苇渡；完整带回一位古代强者可能获得巨大力量，却也可能让旧日支配者重返现世；让整个时代回归看似壮观，却可能剥夺其中不愿回归者的选择。

主要反制会不断换挡：

- 封史司早期切断见证者与旧档，后来控制公开解释权，并以真实存在的回归风险迫使沈砚选择；
- 靠遗忘获利者先封锁坐标和见证锚，随后伪造残片、亲缘和回声，诱使沈砚把承载力用在错误目标上；
- 失落层守护者会拒绝不具真实关系的人夺取对象；
- 被带回者可能拒绝合作，甚至把沈砚视为另一个替他们决定命运的人；
- 镇域者会压制入口附近的灵潮、提前占据容纳地点，或者逼沈砚在保护现世同伴与继续深入之间选择；
- 更深层世界可能允许接触，却不允许完整规则直接进入现世。

沈砚的应对不是增加机械槽位，而是改变判断：隐藏真正目标、只带回凭证、让原主亲自回归、公开一段历史以获得共同见证，或放弃强大对象，先救回能够改变局势的人。

### 第一次完整兑现

第一次小规模收益，是沈砚从盐泽失落层带回回潮种。种子落地后，白苇渡出现一条不受现有势力控制的水线，他由此获得修行资源和继续行动的立足点。

第一次完整兑现则是黑水旗。

当旧街居民已经叫不出彼此姓名，沈砚主动沿断裂石阶进入失落层。他面对的并不只有黑水旗，也有更具直接威力的旧物；他选择承载历代渡船人姓名的旗，因为只有它能让母亲、药铺、祠堂和街坊重新接入现世关系。

黑水旗插入枯河，旧船水痕从河床浮起。街坊重新叫出彼此的名字，母亲不再只存在于沈砚一个人的记忆中。

个人结果是沈砚夺回了自己的生活；能力收益是他第一次理解“能带回”不等于“值得带回”；行动空间则从逃避抹除变成拥有一处稳定见证地和可重复追踪的失落入口。主要情绪释放是被全世界否定的故乡终于公开存在，而不是主角独自保留一段无人相信的回忆。

### 世界结构与持续冲突

边陲城镇依附灵泉、宗门和城防生存；诸域势力依靠完整术法、灵脉、身份印和历史承认建立秩序；镇域者则能让自己的力量与一城、一地或一个群体的关系结合。

失落层贯穿这些秩序背后。被删除的小街、旧路、战争、种族和时代并未真正消失，只是失去了进入现世因果的资格。

长期阻力来自四个方向：

- 封史司认为大规模回归可能造成灵潮冲突、战争与生命秩序崩塌，因此要求控制入口和决定权；
- 靠遗忘获利的势力垄断残片、坐标与历史空白，会封锁、伪造乃至主动制造遗忘；
- 失落者拥有自己的社会、欲望和敌意，并不天然认同现世或沈砚；
- 回归会使土地、资源、身份和旧仇重新成为现实，各方不得不公开争夺。

封史司不会被归结为统一反派。其风险判断有时正确，内部也会因具体事件分裂；但“风险存在”不能自动证明它有权替所有人决定。世界为何遗忘同样保持多源：既可能有自然排斥、文明自我放逐、现世势力主动抹除，也可能存在尚未揭开的更深原因。

### 关键关系（可选）

- **沈母与白苇渡旧街居民：** 黑水旗事件后不再反复充当待救对象。他们恢复生活，并对归来的旧历史是否应覆盖现在拥有自己的判断。只有新局势真正改变他们的选择时，这条线才重新进入前景。
- **归潮城守灯人：** 希望城民重新见到现世，却拒绝归潮城成为沈砚或任何势力的战利品。此人与沈砚是共同冒险者，也是会因回归方式产生分歧的长期盟友。
- **封史司巡史官：** 相信某些失落之物确实不能完整回归，却逐渐发现封史司内部有人利用风险之名维持垄断。此人会阻止、谈判、合作，也可能在认为沈砚越界时再次成为对手。
- **被抹名的古战场幸存者：** 掌握重要历史，却拒绝成为任何一方的证据或武器。被带回后继续追逐自己的旧仇与亲族，使“归来者的后续生活”成为自主长线。

### 长期故事主线

#### 阶段1：白苇回潮

**开局状态：** 白苇渡旧街、沈母和沈砚的童年正在从记忆、档案与关系中脱落。沈砚没有正式修为，也没有任何势力承认他的判断。

**当前最值得争取的机会 / 目标：** 先夺回能够证明旧街存在的真实锚点，随后沿恢复的旧渡航迹找到被整个时代删除的归潮城。

**主要事件与具体阻力：** 沈砚先带回回潮种，使枯河恢复水线；旧街抹除继续加速，他进入渡神祠对应的失落层带回黑水旗。其后，黑水旗显露的航迹、残碑与归来渡人的线索共同指向倒悬海中的归潮城。地方势力企图夺取坐标，封史司则认为整城回归会破坏现世灵潮与土地秩序；城中居民也不愿在不了解现世的情况下被沈砚单方面带走。

**主角主动行动：** 他先选择能救回关系的黑水旗，而不是更强的遗物；此后主动追踪旧航迹，进入倒悬海，与城中仍在生活的人接触，为归潮城争取能够容纳其土地、灵潮与共同见证的现世位置。

**核心优势怎样产生超额结果：** 别人围绕残碑争论归潮城是否存在，沈砚直接走入完整城市，并把城市自身及其居民变成无法被替代的见证者。

**主角一级成长：** 回潮种提供的灵泉使他踏入炼身；早期带回的承载术和多次失落层行动使他开脉，能够主动维持短暂入口。

**阶段净新增：** 白苇渡成为稳定见证地；归潮城以拥有居民、土地要求和自身意志的文明主体回到现世。沈砚从普通抄碑学徒变成诸域无法忽视的归返者。

**核心幻想兑现：** 他先让母亲与故乡重新获得姓名，再让一座被时代判定为不存在的城市从荒原升起。过去带回的黑水旗、灵泉和航迹共同完成了整城回归。

**主要情绪释放：** 母亲重新被邻人叫出名字；归潮城居民第一次看见现世太阳；曾经否定沈砚的人必须站在城墙前承认它真实存在。

**世界扩张：** 故事从边陲小街扩展到诸域交界。归潮城带回的灵潮通道与完整技艺打破区域资源垄断。

**推向下一阶段的更大机会、欲望、竞争或压力：** 各方不再争论城市是否存在，而是争夺归来者、完整术法和历史解释权。归潮城中的一段记录指出，某位技艺创造者仍以完整的人格活在失落层。

**自然产生的后果或余波（如果有）：** 归潮城原有故土已经出现新的占有者；封史司内部围绕封回还是承认发生分裂；白苇渡不再无人问津，而成为各方窥探沈砚的入口。

#### 阶段2：归来者不是遗物

**开局状态：** 归潮城已经回归，但现世势力想把城民、术法和通道分别占有。沈砚拥有巨大声名，却还不足以正面对抗照府、立印层强者。

**当前最值得争取的机会 / 目标：** 找到仍活在失落层中的术法创造者，使归潮城的完整传承重新拥有选择者，同时阻止此人被现世当作知识容器或政治旗帜。

**主要事件与具体阻力：** 封史司要求只取回术法、不带回原主；垄断势力则准备控制其现世身份与亲族关系。目标本人不信任现世，也拒绝把自己的完整传承无条件交给已经改变的归潮城。

**主角主动行动：** 沈砚沿一段仍在被履行的师徒关系进入失落层。他保护目标脱离争夺，却不替对方决定去留；最终带回的是这个人的完整姓名、关系与自主选择，而非一件服从使用的“活遗物”。

**核心优势怎样产生超额结果：** 现世只能争夺残术，沈砚却让创造者本人重新参与传承。对手准备好的归属安排因原主公开出现而失效。

**主角一级成长：** 他接受完整灵潮法的真实教导，形成稳定灵府，跨入照府；同时学会在回归过程中维持另一个人的本质、形体与意志，而不把对方压成附属物。

**阶段净新增：** 失落者第一次以独立人物而非沈砚战利品的身份进入长期主线。归潮城获得活的传承关系，沈砚则背上一项会由对方主动要求兑现的承诺。

**核心幻想兑现：** 一个现世只剩残名的人亲自从失落层走出，并当众决定自己的术法教给谁、自己的旧仇追到哪里。

**主要情绪释放：** 夺回不再等于占有。沈砚让一个被世界剥夺选择的人重新说出“不”，而各方强者必须改变对待他的方式。

**世界扩张：** 由城池与资源争夺进入失落人物、血脉和旧时代政治关系的冲突。

**推向下一阶段的更大机会、欲望、竞争或压力：** 归来者指出，诸域现有秩序建立在一场“从未产生结果”的古战之上；只要那场战争继续空白，归潮城和其他失落群体就始终会被重新定义。

**自然产生的后果或余波（如果有）：** 归来者不会始终跟随沈砚，而会离开追查旧敌；其行动不断把新的敌人、盟友和失落线索带回当前主线。

#### 阶段3：让古战场重新拥有结果

**开局状态：** 沈砚已是照府者，拥有归潮城与归来者的支持，但诸域强者仍可利用被抹除的战争结果否定他们的资格。

**当前最值得争取的机会 / 目标：** 进入被天幕删除的古战场，带回足以让最后一战重新产生真实结果的对象。

**主要事件与具体阻力：** 战场中的巨人连受伤与死亡都被抹去，普通攻击无法伤害；多方势力分别伪造有利版本，试图诱导沈砚带回错误的旗帜、尸骨或战书。封史司中的强硬派则要维持“没有结果”的状态。

**主角主动行动：** 沈砚放弃看似代表胜负的宏大遗物，追踪巨人与半截兵器之间仍未断裂的使用关系，深入战场寻找那件真正能使一击完成的原物。

**核心优势怎样产生超额结果：** 他带回的不只是半截兵器，而是兵器、使用者与最后一击之间的完整因果。现世重新承认巨人能够受伤、战争曾经结束，迟到的结果当场落下。

**主角一级成长：** 他借恢复的战果稳固命印，跨入立印层。过去只能借失物改变环境，此后已能亲自把修为、战斗和失落回归结合起来。

**阶段净新增：** 古战拥有不可再抹成空白的公开结果；山河与诸域力量位置随之改变。敌人以后无法只封锁入口，必须伪造目标、抢夺原主关系或在沈砚作出选择前改变条件。

**核心幻想兑现：** 所有人都认定“从未发生”的最后一击在现世真正完成，半截兵器使一片山脉获得迟到数百年的伤痕。

**主要情绪释放：** 被抹去的胜利终于产生结果，被抹去的死亡终于能够结束；利用空白自称胜者的势力当众失去立足依据。

**世界扩张：** 战场裂开的天幕后出现保存完整旧时代的深层区域。那里的人知道现世，却未必想回来。

**推向下一阶段的更大机会、欲望、竞争或压力：** 现世势力试图借沈砚打开整段时代，并将其中的强者、术法与土地一次性据为己有；深层失落者则开始主动阻止他接近。

**自然产生的后果或余波（如果有）：** 战争结果改变了旧仇、领地和身份，但不产生唯一正确的历史解释。部分受益者成为沈砚的新敌人，曾经的敌对者则因真相改变立场。

#### 阶段4：拒归之门

**开局状态：** 沈砚能够恢复物、人物和事件，却第一次面对一个结构完整、拥有共同意志、而且部分成员明确拒绝回归的时代。

**当前最值得争取的机会 / 目标：** 阻止现世势力把他当作开门工具，同时救下其中正在被旧统治者再次抹名的人，让失落者真正拥有回归或留下的选择。

**主要事件与具体阻力：** 现世势力制造伪回声，引沈砚打开最有利于他们入侵的位置；失落时代内部也分为复归者、留守者和企图带着旧等级秩序重返现世的统治者。一个表面价值极高的完整传承正是诱饵，真正即将消失的是一群拒绝服从任何一方的人。

**主角主动行动：** 沈砚识破诱导，放弃完整传承，转而进入正在断裂的人际关系。他不强行带回整个时代，而是带回一段能够让相关失落者自行决定、分批接触现世的真实关系与入口。

**核心优势怎样产生超额结果：** 对手争夺的是“谁控制门”，沈砚改变的却是“门内的人是否只能被别人决定”。他让一个失落共同体成为行动者，而非入口后的资源。

**主角一级成长：** 他能够在镇域级压制下保持自身和一群人的存在接合，跨入镇域层次；其力量开始影响一座城及周边对失落者的承认。

**阶段净新增：** 失落者第一次拥有主动回归、暂缓或拒绝的现实途径。沈砚不再只是唯一携带者，但仍是能够接触完整失落世界、改变双方关系的关键人物。

**核心幻想兑现：** 他从天幕之外带回的不是被征服的时代，而是被现世剥夺已久的选择权；一批归来者自行走入阳光，另一批则在得到承认后选择留下。

**主要情绪释放：** 沈砚有能力夺取最强传承，却主动让失落者先决定自己的命运；强行开门的两方统治者同时失去垄断。

**世界扩张：** 现世确认失落层不仅保存遗物，还保存拥有不同价值与生命秩序的完整时代。

**推向下一阶段的更大机会、欲望、竞争或压力：** 对手确认无法只靠封门阻止沈砚，转而攻击他的现世存在：切断别人对他的记忆、关系和承认，使他本人逐渐成为失落者。

**自然产生的后果或余波（如果有）：** 被允许自主行动的归来者会离屏建立自己的生活、联盟和敌对关系；他们日后回归主线时带来的是新选择，而非重复感谢。

#### 阶段5：夺回被删除的自己

**开局状态：** 沈砚已是镇域层次的重要人物，但敌人发动的不是正面围杀，而是让各城档案、盟友记忆和共同经历同时失去与他的关系。

**当前最值得争取的机会 / 目标：** 在自己彻底从现世脱落前，找回被切走的姓名、关系和行动结果，并阻止同样的抹除扩展到多个失落群体。

**主要事件与具体阻力：** 黑水旗、归潮城与旧盟友仍然真实，却逐渐无法确认沈砚与它们的关系；封史司内部有人认为牺牲他能重新稳定世界，也有人因亲眼见过回归而拒绝执行。深层失落世界向他展示数条可带回的规则，其中最强者能够改变众生寿命，却不能解决他当前被切断的存在。

**主角主动行动：** 他不追逐最强法则，而是进入自己正在形成的失落层，沿亲手完成过的选择和后果追踪自身，带回一段使本质、形体与名字即使暂时无人见证也不立刻分离的真实规则结构。

**核心优势怎样产生超额结果：** 核心幻想第一次作用于主角自身：世界正在判定沈砚从未存在，他却从世界之外把那个完成过一切选择的自己带回现世。

**主角一级成长：** 他的生命状态不再完全依赖单一区域承认，可以长期承受现世与失落层交叠；这不是新境界名称，而是进入更深世界所需的生命层次跃迁。

**阶段净新增：** 沈砚获得深入世界边界而不立即失去自身的能力。敌人以后无法再靠秘密删名解决他，只能公开争夺回归条件、世界入口和失落者的立场。

**核心幻想兑现：** 他带回的不是外物，而是被世界删除的自己；过去所有归来的人、城和关系也以各自选择证明，他不是一个可以被抹掉便让一切归零的偶然。

**主要情绪释放：** 曾经只有沈砚记得母亲，如今轮到母亲、旧街、归潮城与自主归来者共同把他的名字送回现实。过去的每一次夺回在同一刻完成反向回报。

**世界扩张：** 沈砚看见现世本身也可能只是更古老世界被保留下来的一层；天幕之外存在一个被世界主动放弃的失败宇宙。

**推向下一阶段的更大机会、欲望、竞争或压力：** 失败宇宙中的生命要求回归，现世势力想夺取其法则，部分失落者却警告它曾经失败并非偶然。

**自然产生的后果或余波（如果有）：** 沈砚更难被秘密抹除，却没有替其他人自动获得同样状态。他必须面对是否以及怎样让这份可能进入更广泛现实。

#### 阶段6：失落天穹

**开局状态：** 沈砚能够稳定穿行现世与深层失落世界，各方也已无法否认失落者的存在。争夺焦点变成一个失败世界是否应重新获得现实位置。

**当前最值得争取的机会 / 目标：** 接触失败宇宙的完整真实，弄清其中不同群体的回归欲望，并阻止现世或旧世界的统治者把一次接触直接变成吞并。

**主要事件与具体阻力：** 失败宇宙并非统一遗物：有人渴望回归，有人只要求被承认曾存在，有人试图让旧世界覆盖现世。封史司、归来文明和现世强者对此各有立场；失败原因也显示出自然崩塌、主动切除与文明选择等互不完全兼容的证据。

**主角主动行动：** 沈砚进入旧世界仍在重复的黎明，分别接触其人物、土地与规则。他选择先带回一项能够让双方看见并回应彼此的真实，而不预先决定整座宇宙最终回归、留下或消亡。

**核心优势怎样产生超额结果：** 别人只能在“封死”与“全部夺取”之间选择，沈砚却能把世界、人物、关系或规则分别接入现实，使一次被垄断的终局裁决重新变成真实人物可以参与的选择。

**主角一级成长：** 他的行动范围从地域和时代扩大到世界之间；生命形态能够在不同现实规则下保持连续，但不因此自动拥有所有失落法则。

**阶段净新增：** 现世与失败宇宙第一次形成无法再假装不存在的接触。沈砚获得决定具体带回方式的力量，却没有成为替所有世界作最终决定的唯一主人。

**核心幻想兑现：** 现世天穹上倒悬起一片已经熄灭的星海，第一颗被判定从未存在的星辰在沈砚手中重新发光。整个世界第一次看见，被遗忘的可能并没有死亡。

**主要情绪释放：** 从夺回母亲的一段生活，到让一个失败世界重新拥有被听见的资格，核心幻想完成最大尺度的同质升格。

**世界扩张：** 后续可以进入失落神明、旧现世、不同生命法则乃至其他失败世界，但每一个入口仍来自具体遗物、人物请求和不可逆后果。

**推向下一阶段的更大机会、欲望、竞争或压力：** 是否让整个失败宇宙回归、以什么形式接合、哪些群体愿意进入现世，将由后续 Outline 与人物选择自然生长，不在 Story Program 中钉死。

**自然产生的后果或余波（如果有）：** 世界不再能够轻易依靠遗忘消除冲突；归来文明、现世众生和仍留在失落层的人都成为下一轮选择的参与者，而非等待沈砚统一安排的对象。

### 早期锚点、中期里程碑与远期升格

#### 早期兑现

沈砚先带回回潮种，使白苇渡重新出现一条水线；随后选择黑水旗作为旧街真正的存在锚，在抹除完成前让母亲、街坊、药铺与渡口重新获得姓名和共同关系。

他跨过的门槛不是击败高境界强者，而是从“唯一记得的人”成为“能够让真实重新被世界承认的人”。具体所得是第一处灵泉、第一件长期遗物、第一批不会轻易忘记他的盟友，以及主动追踪失落痕迹的行动入口。

#### 稳定循环

稳定循环是：现世出现具体缺失或高价值痕迹——沈砚判断真正值得带回的目标——进入失落层面对守护者、竞争者与目标自身欲望——选择带回本体、术法、人物、关系或凭证——通过具体行动证明其价值——回归结果改变下一轮。

黑水旗提供见证，灵泉支撑修行，航图指向归潮城，归潮城的完整传承形成沈砚的灵府，归来者主动提供或争夺新线索，古战结果改变诸域关系。旧成果不断换一种身份重新进入故事，而不是领取后归入收藏。

#### 中期里程碑

第一个自然大型阶段充分展开后，归潮城从荒原升起。城中居民、完整灵潮法和断绝通道同时回到现世，使区域资源垄断失效，也让诸域不得不面对城民的土地、姓名和政治资格。

真正不可逆、可复述的事件是：各方第一次在归潮城城门前公开承认，沈砚能够决定某些失落之物是否回归，而任何人都不能再把这座城重新解释成不存在。

这不是沈砚力量的长期上限。它只是证明核心优势已经能从个人证据升格到完整文明，并为后续的人物自主、战争结果和时代回归打开因果入口。

#### 远期升格方向

如果本书长期成立，沈砚将从寻找失物，成长为能够在世界深层保持自身存在、接触被删除法则和失败世界的人。

他可以为山河、时代、种族、生命形态乃至旧宇宙争取现实位置，也能把“是否回归”的选择还给失落者。最终上限不是简单扩大携带容量，更不是成为所有历史的管理员，而是让现世无法再单方面决定哪些真实没有资格存在。

具体带回何种法则、失败世界是否整体回归、沈砚最终采取何种世界关系，都留给后续人物行动与终局因果自然决定。

### 继续探索的世界与未来场面

这个世界值得继续探索，因为每个空白背后都可能保留着完整生活，而不是单纯藏着更高级资源。进入新区域意味着重新判断：这里失去了什么，谁从空白中得利，失落者是否愿意回来，回归后会让哪些现实关系彻底改变。

后续最值得期待的场面包括：

- 沈砚在倒悬海中穿过仍亮着万家灯火的归潮城，随后让整座城从荒原升起；
- 古战场上，半截兵器回归，连死亡都被抹去的巨人第一次真正流血；
- 一名被当作“活遗物”争夺的失落强者走到现世阳光下，公开拒绝所有招揽；
- 沈砚面对完整高阶传承，却转身救回一群正在被再次删名的人；
- 敌人让诸域逐渐忘记沈砚，他却沿自己曾经造成的真实后果进入失落层，把被删除的自己带回来；
- 天穹展开，熄灭星海倒悬现世，一颗从未被当前世界承认的星辰在他手中重新亮起。

真正持续的期待不是“下一次能带回多大的东西”，而是：下一段被判定不存在的真实究竟是什么；沈砚会选择带回什么；它回归后，又会让谁第一次拥有过去不可能拥有的力量、自由和命运选择。

Mechanism：以具体欲望、关系、身份、物件或世界问题建立线程；允许它自然休眠或离屏推进。只有当新处境会改变这条线的含义、可行性或人物选择时，用行为、选择、新证据或新位置召回。成熟时让它与当前力量、关系、身份或世界线发生真实因果碰撞，产生不可回滚状态。第一次 payoff 后，继续保留人物新的生活、关系、权限、敌人或自主目标，形成 second payoff / afterlife。
Variants：- 关系线长期离屏后以新生活状态回归。
- 旧身份在新地图被重新定价。
- 旧物/旧能力从工具变成关系或世界入口。
- 私人欲望在世界级事件中改变最终选择。
- 大战同时结束旧仇并开启新的生活或权力位置。
Guidance：Reminder 必须改变当前行动或解释，不以“提到一次”保活。碰撞不追求固定线数；只要异质线程真正互相改写即可。兑现后优先问“人物现在能做什么、还想做什么、谁会因此改变策略”。
Failure Modes：- 只回忆，不改变行动。
- 为了多线汇合强行巧合。
- 所有配角都等待主角召回。
- 大战只结算输赢。
- Afterlife 只是同类考核重开。
- 把开放或未知结局补成完整战后秩序。

使用边界：迁移线程生命周期与 afterlife，不要求每条长线都有二次兑现，不要求所有线程在终局汇合。

### Inspiration 4
source: mechanisms/hidden-identity-long-v3
type: mechanism
score: 0.0655

可用抽象：Creative Problem：隐藏身份怎样跨长篇维持而不靠强行藏答案？揭露后怎样真正改变当前故事？
Mechanism：先让表层身份独立成立并积累真实后果：朋友、爱情、债务、名声、信任与社会位置都是真实的。线索应尽量同时兼容旧解释与新解释；揭露落在人物正在行动的碰撞点，并立刻关闭或改写一条现实路径，例如安全身份失效、继位失败、归乡目标改变、某人开始被追杀。揭露重解释过去，但不删除过去。
Variants：- 长期潜伏者。
- 异类/血脉身份。
- 多个真实社会自我。
- 错误预言/公共误读逐渐追上现实。
Reader Payoff：“原来如此”与“接下来怎么办”同时出现；过去的普通场景获得第二层意义，而当前关系不能再按旧方式继续。
Guidance：设计隐藏身份时先写清：表层生活为什么能长期工作；哪些线索在旧解释下也合理；揭露会关闭什么现实选择。
Failure Modes：- 线索从一开始就只支持真相解释，角色长期看不见显得失智。
- 揭露只补背景，不改变当前选择。
- 宣布是假身份后把此前关系全部清零。
- 为反转而多层套娃。

使用边界：《斗罗大陆》《诡秘之主》《将夜》直接支持长期隐藏身份/身份重释；《修真聊天群》只提供“公共误认逐渐追上现实”的邻近证据。迁移揭露后的关系与行动变化，不把公共误认等同于长期潜伏身份。
