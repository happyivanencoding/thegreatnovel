# Proposed Active Scene State

当前地点：白苇渡枯河中央、灵泉旁。  
在场人物：沈砚、沈母、白苇渡街坊；封史司巡史官陆沉舟及随员已在旧街两端设卡；水上势力首领及手下已离开。  
即时伤势：双腿发沉、身体发虚；掌心磨伤发痛。  
手中关键物品：插入河床的黑水旗、抄碑短刀。  
当前敌人或追兵：封史司封锁白苇渡，禁止沈砚离渡并监守灵泉；水上势力可能利用封锁迫使白苇渡谈判。  
当前倒计时：封锁已开始，药铺缺药、米铺缺粮等后果会随封锁持续加重。  
下一步直接目标：守住黑水旗和灵泉，寻找解除封锁或离开白苇渡的办法。  
当前主动目标：在不交出黑水旗的前提下，保住白苇渡继续追查归潮城航迹的可能。

# Proposed Persistent Canon

- 黑水旗能以水痕阻滞试图拔旗者，暂未显示出将其拖倒或直接伤人的力量。
- 黑水旗仍插在白苇渡枯河中央，暂由沈砚守护；封史司列为查验之物，但尚未强行取走。
- 沈砚拒绝交旗并拒绝随封史司问话，选择留在白苇渡承担后果。
- 白苇渡被封锁：旧街两端设卡，限制取水、离渡和外人进入；灵泉周边被封存。
- 白苇渡街坊公开站在沈砚和黑水旗一边，但已面临缺药、缺粮和进出受限的现实压力。
- 水上势力持有一张残缺泛黄航图，声称见过通往归潮城的水路，并指出真正城门不在现有航迹上；愿以带沈砚寻找城门为条件谈判。
- 封史司公开禁止再提“归潮城”，但未说明封锁和禁令的真实原因。

### Tracked Assets

残缺航图｜水上势力首领｜由其随身携带｜泛黄、部分河道缺失，标出另一处可能的归潮城城门｜尚未交给沈砚

# Proposed Chapter Summary

陆沉舟宣布封锁白苇渡、查验灵泉并带沈砚问话，沈砚当众拒绝交旗和离渡，街坊与沈母站在他身边。黑水旗以水痕阻止水上势力首领拔旗。陆沉舟暂不强取黑旗而设卡封锁，水上势力则拿出残缺航图，提出带沈砚寻找真正归潮城城门的交易。

- 黑水旗水痕阻滞外来者的力量和限制。
- 倒悬水流还能持续多久，会引发什么变化。
- 黑水旗上姓名对应的旧渡口历史及失踪原因。
- 地下祠堂中断裂铁索与黑色短矛的来历和危险。
- 河底祠堂与失落层之间的关系。
- 沈砚能否获得炼身、开脉及后续成长。
