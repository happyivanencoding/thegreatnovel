# Proposed Active Scene State

当前地点：白苇渡枯河中央、黑水旗旁。  
在场人物：沈砚、沈母、白苇渡街坊；陆沉舟及封史司随员；水上势力已退至旧街口。  
即时伤势：双腿发沉、身体发虚，掌心磨伤。  
手中关键物品：黑水旗、抄碑短刀。  
当前敌人或追兵：封史司加紧封锁，监视所有下水口；水上势力可能争夺旧渡航迹。  
当前倒计时：封锁持续，白苇渡缺粮缺药；各方已看见新航迹，追兵将增加。  
下一步直接目标：赶在封史司和水上势力之前，找到倒悬水光真正落下来的位置。  
当前主动目标：沿黑水旗认出的旧渡航迹，寻找通往倒悬水光的真实入口，保住白苇渡的生路。

# Proposed Persistent Canon

- 黑水旗只认可与旧渡人真实相连的水路痕迹，不认可将不同地点拼接出的伪航道。
- 水上势力的残缺航图确实将不同地点和水线拼接在一起，无法证明其通往归潮城；真正旧渡痕迹藏在图角。
- 黑水旗已认出一条从白苇渡向河外延伸的旧渡航迹，航迹上浮出多名彼此相关的旧渡人姓名。
- 旧渡航迹在夜间越过封锁并升入空中，显现为远处倒悬于天幕的大片水光；其是否为倒悬海入口尚未确认。
- 陆沉舟确认黑水旗正在借沈砚选择道路，已下令加派人手并监视河外所有下水口。
- 沈砚拒绝接受水上势力预设的带路路线，转而追查黑水旗认可的真实旧渡航迹。
- 白苇渡仍未脱离封锁，粮药短缺正在加重。

### Active Relationships

陆沉舟｜封锁白苇渡、追踪新航迹｜与沈砚及白苇渡对立｜确认黑水旗会显现真实航迹并加派人手｜等待新航迹再次变化或夺取沈砚的行动线索  
水上势力首领｜争夺旧渡航迹和归潮城线索｜与沈砚暂时互利但已转为竞争｜航图被识破后撤离并暗示会争夺该路线｜可能抢先占据旧渡航迹  
白苇渡街坊｜守住姓名、灵泉和黑水旗并应对封锁｜支持沈砚但承受缺粮缺药压力｜共同看见升空航迹｜需继续承担封锁代价

### Tracked Assets

残缺航图｜水上势力首领｜其手中｜已被识破为拼接路线，图角藏有真实旧渡痕迹｜被其收回，仍可能用于争夺航迹

# Proposed Chapter Summary

封锁导致白苇渡粮药短缺，水上势力以残缺航图再次提出带沈砚寻找归潮城。沈砚借黑水旗检验航图，识破其中拼接伪造的水线，并从图角引出一条真实旧渡航迹。航迹入夜后越过封锁升入天空，显现为远处倒悬的水光，陆沉舟随即加派人手封锁河外。沈砚决定赶在各方之前找到水光落处。

- 航迹上新浮出的旧渡人姓名与白苇渡、失落水路的关系。
- 白苇渡如何继续应对缺粮、缺药和封锁。
- 黑水旗水痕显现真实航迹的力量和限制。
- 黑水旗上姓名对应的旧渡历史及失踪原因。
- 地下祠堂中断裂铁索与黑色短矛的来历和危险。
- 河底祠堂与失落层之间的关系。
- 沈砚能否获得炼身、开脉及后续成长。
