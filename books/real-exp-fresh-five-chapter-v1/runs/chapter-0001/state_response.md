# Proposed Active Scene State
当前地点：白苇渡旧街后的枯河河床，近旧街处新生水线与嫩芽旁。  
在场人物：沈砚、沈母、药铺掌柜、卖米老头及围观街坊。  
即时伤势：盐泽寒意仍侵入骨头，双腿发沉，身体发虚，但尚能行动。  
手中关键物品：抄碑短刀；水囊已用尽。  
当前敌人或追兵：无明确敌人或追兵。  
当前倒计时：无明确倒计时。  
当前主动目标：保护新生水线与嫩芽，并查明河底石阶和深处传来的旗声。

# Proposed Persistent Canon
- 沈砚能够听见并追随失落层中的异常声响，能够进入失落层并在其消失前返回。
- 回潮种已从失落层带回并种入枯河，催生出持续向前流动的细水线。
- 沈砚尚无正式修为，但具备进入失落层、取回回潮种并成功带回现实的经历。
- 沈母已亲眼见证枯河重新出水；白苇渡街坊也共同见证水线出现。
- 枯河靠近旧街处露出向下延伸的石阶，深处传出抖开旗帜般的声响，具体来源未知。

### Active Relationships

### Tracked Assets

# Proposed Chapter Summary
沈砚为救正在被遗忘的药铺与母亲，进入失落层，在即将消失的盐泽中取回一粒回潮种。他将种子种入枯河并以最后的清水催发，河床终于涌出一线真正的水，白苇渡众人共同见证。随后河底塌陷，露出通往阴影深处的石阶，并传来像抖开旗帜的声响。

# Proposed Open Promises
- 回潮种催生的水线能否真正恢复枯河与白苇渡。
- 河底新露出的石阶通往何处。
- 阴影深处传来的旗声究竟来自什么。
- 黑水旗是否会在后续现身，并让白苇渡重新获得姓名与共同记忆。
- 沈砚能否获得炼身、开脉及后续成长。
- 倒悬海与归潮城的完整接触。
- 归潮城作为文明回到现世及其政治要求。
- 失落术法创造者是否愿意回归。
- 被抹去战争是否重新拥有胜负与死亡。
- 拒归时代是否获得自主回归或拒绝回归的资格。
- 沈砚能否夺回被世界删除的自己。
- 世界遗忘机制的真正来源仍未确定。
