# Proposed Active Scene State

当前地点：白苇渡枯河中央、灵泉旁。  
在场人物：沈砚、沈母、白苇渡街坊、封史司巡史官陆沉舟及数名持册随员。  
即时伤势：双腿发沉、身体发虚；握旗时掌心磨痛。  
手中关键物品：插入河床的黑水旗；抄碑短刀。  
当前敌人或追兵：封史司巡史官陆沉舟，要求收走黑水旗并停止追查失落航迹。  
当前倒计时：封史司即刻接管黑水旗与白苇渡调查。  
当前主动目标：守住黑水旗，保护白苇渡继续确认自身姓名与旧渡口历史，并查明归潮城航迹。

- 黑水旗可显现通往远方的失落航迹，并显示“归潮城”三字；具体位置与性质未知。
- 黑水旗的水痕可缠住并阻滞试图拔旗的人，但力量和限制未知。
- 白苇渡街坊已共同站出来守护灵泉、黑水旗及本地记忆。

- 封史司巡史官陆沉舟已带人抵达，宣布白苇渡停止追查失落航迹并要求交旗。

沈砚将黑水旗插入枯河，水痕沿旧河道汇聚，旗上姓名唤回白苇渡居民关于祖辈、祠堂和药铺的记忆，街坊共同挡住牙行势力。黑旗随后显现通往归潮城的失落航迹，封史司巡史官陆沉舟率人抵达，要求沈砚交旗并停止追查。

- 沈砚能否拒绝交出黑水旗并继续守住灵泉。

- 倒悬水流将持续多久，会带来什么变化。

- 黑水旗上众多姓名对应的旧渡口历史及失踪原因。
- 地下祠堂中断裂铁索与黑色短矛的来历和危险。
- 河底祠堂与失落层之间的关系。
- 沈砚能否获得炼身、开脉及后续成长。
- 失落术法创造者是否愿意回归。

- 沈砚能否夺回被世界删除的自己。
