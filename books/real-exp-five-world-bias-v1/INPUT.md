# 统一最小作者方向

创作一部成熟中文男频玄幻修仙成长长篇。

主角的长期一级成长应主要体现为主角本人越来越强、越来越自由，或在修为、战斗、神通、核心技艺、生命层次、规则掌控和世界通行能力上发生可感知的升格。

财富、资源、身份、宗门地位、关系、势力、领地和地图可以作为二级收益，但不能长期取代主角个人成长。

主角应拥有无法被普通人轻易复制的非对称优势，这种优势能够产生明确、令人向往的实际收益，并在长篇中不断改变玩法，而不只是增加数值。

世界、主角、力量体系、金手指、宗门、种族、敌人、地图、时代危机和开篇方式由系统自行创造。

不指定：凡人流、系统流、无敌流、苟道、固定境界、固定金手指、固定宗门、固定反派、固定感情线、工匠、调查、御兽、领主、诸天或第一章开法。

要求五个结果真正不同，但不要预先给五个结果分配固定题材桶。
