# Character GBrain Craft v3｜Abstract Transfer Only

### Inspiration 1
source: book-dna/rcv0-56-xuanhuan-zhushen-yuxi-character-hook-v3
status: REFERENCE_ONLY / experiment-only

可迁移抽象：人物辨识度不是固定怪癖或口头禅。更稳定的是他反复拒绝什么、保护什么、愿意为什么承担代价；具体手段则应由当前信息、能力边界、对手欲望与关系信任重新生成。读者可以逐渐预测人物核心，却不应因此按模板猜中下一步。人物选择本身可以成为场景 payoff，只要它真实改变关系、身份、责任或行动条件。

使用边界：不复制来源人物的身份表演、话术、荒诞行为、称号、能力或具体关系。

### Inspiration 2
source: book-dna/rcv0-48-dushi-dawang-raoming-story-craft-v3
status: PILOT / experiment-only projection

可迁移抽象：强主角优势可以与人物原本的生活处境、私人欲望和不体面的性格高度耦合，让“这个人本来就会做的事”突然产生额外收益；不要先造宏大系统再找人物用途。开局私人欲望可以很小、很俗，不必自动升级成公共责任。世界扩大后，早期人格与日常欲望仍应继续参与高层选择，而不是被成熟化抹掉。

使用边界：不复制情绪转资源、系统抽奖、具体人物关系或原作世界结构。

### Inspiration 3
source: book-dna/rcv0-41-xuanhuan-mushenji-story-craft-v3
status: PILOT / experiment-only projection

可迁移抽象：人物的异常必须相对于读者已知道的世界 Normal 可见；“不是常见天赋 / 与公开力量体系存在特殊兼容 / 由多种基础共同构成异常”等，都比脱离世界的万能能力更可信。核心优势可以是组合而非单件外挂，但必须服从世界规则：身体、环境或底层条件改变时，旧能力也可能失效。人格和好奇心可以驱动人物主动进入更大世界，而不是地图为了能力自动供货。

使用边界：不复制多师村落、具体体质、世界入口、历史人物、遗物或升级体系。
