# CHARACTER WORLD SLICE｜World Reality Only

## 世界基础现实
我会先快速核对已有的世界设计约束，确保这份设定保持“作者未知、主角盲、不可回滚状态优先”，然后直接给出可进入写作的完整世界观。# PROTAGONIST-BLIND WORLD VISION

这是一个已经延续了数千年的修行世界，名为“澜生界”。

它没有等待某个人来完成的终极使命，也没有唯一正确的修行道路。有人想长生，有人只想买下一座矿山；有人为宗门争名，有人想把仇人的祖坟迁走；有人探索古代遗迹，也有人只想让女儿嫁进一户不会被妖兽吃掉的好人家。

澜生界最显眼的自然周期，是每四十八年横渡天空一次的“归潮”。

归潮经过某片大地时，星尘会落入山川，灵植疯长，妖兽迁徙，旧时代的遗迹短暂复苏。有人靠它发财，有人因它破产，有人死在遗迹里，也有人借此发动战争。归潮只是这个世界的一种大气候，不是任何人的天命。

## 普通人的生活与上升

大多数人出生在河谷、山城、海港、盐场、矿镇或宗族村落。

普通人的生活围绕土地、水源、牲畜、商路、兵役、婚姻和税契展开。灵气并没有让所有人都衣食无忧：一块能稳定种出灵谷的田，往往比一间普通铺面贵；能避开妖兽迁徙的村子，比靠近遗迹的村子更适合养家。

没有修行天赋的人，也可以通过很多方式改变身份：

- 学一门能靠灵材吃饭的手艺，例如炼药、制符、驯兽、铸兵、辨矿、修船。
- 进入军府或城防营，靠战功获得田地、户籍和商路保护。
- 投靠宗门、商会、世家，成为账房、管事、护卫、外门弟子或附属家族。
- 和修士、贵族、商人联姻，改变家族的资源位置。
- 把握归潮、矿脉、遗迹开放等机会，用一辈子积蓄换一次翻身。

修士并不自动脱离日常生活。低阶修士仍要吃饭、治伤、交税、还债，也需要有人替他们种田、运货、照顾家人。一个会使三种常用符箓的匠人，未必打得过一名军府校尉，但他的收入和社会地位可能更高。

在许多地方，“有本事”比“能打”更重要。

## 力量体系与正常值

澜生界的修行，本质上是让身体、神识、术式和外物之间形成稳定配合。

施展力量不能凭空发生。修士通常需要经过长期锻炼的身体、可重复的术式，以及灵材、兵器、地势或天气中的至少一种支撑。越强的力量，越依赖具体条件；脱离熟悉环境后，很多修士会明显变弱。

世界中大致存在这样的正常层次：

- **普通人**：能辨认低等灵材，使用简单护身符，偶尔感知到妖兽或灵气变化。
- **纳息者**：可以吸收少量灵气，体力、视力、伤口恢复速度超过常人，能使用短暂的火、风、驱尘、止血等小术。
- **通脉修士**：地方武馆、军府精锐、宗门外门中的常见水平。能连续使用数种术式，独自对付数十名普通人，或猎杀低阶妖兽。
- **立相修士**：一城一镇中的真正高手。能够让兵器、身体或术法形成稳定特征，短距离御空，正面击溃一支普通军队的小队。
- **照域修士**：极其罕见，通常是大宗门长老、强国供奉、边关统帅或大商会的镇场人物。他们能影响一片街区、山谷或河段的战斗环境。
- **更高层次**：存在于传说、古籍和少数仍活着的人身上。其力量足以左右城池、山脉或一场国家战争，但没人能证明所谓“真正无上”是否存在。

世界中本来就常见的能力包括：

- 强化身体、夜视、闭气、抗寒、抗毒。
- 以符箓、阵盘、兵器放大有限力量。
- 驯养灵兽、辨识灵植、改变水火风势。
- 短距离腾挪、御剑或借器飞行。
- 用药物和灵气治疗伤势，但不能随意起死回生。

少数人能够做到：

- 在复杂地形中同时操纵多种术式。
- 让一件兵器随自身修为成长。
- 以声音、香气、梦境或血液影响他人的感知。
- 在归潮期间借助天象施展远超平日的法术。
- 与高阶妖兽建立长期而平等的联系。

这个世界不存在被普遍证实的逆转时间、真正复活、凭空创造生命、永久读心和绝对不死。古代传说里有类似记载，但所有现存证据都不足以证明它们曾经真实发生。

## 社会现实与身份

澜生界有王朝、城邦、宗门、世家、商盟、军府、海国和流动部族。它们彼此重叠，却没有一个机构能统治整个世界。

一个人的身份通常由几件事共同决定：

- 出身家族是否拥有田地、矿山、血缘传承或修士保护。
- 是否有正式师承，能否使用某个宗门的术式和资源。
- 是否拥有城籍、军籍、商籍或宗门凭证。
- 是否欠下债务、血仇或誓约。
- 是否在战场、商路、遗迹或地方灾难中证明过自己。

宗门既是修行场所，也是家族、学校、兵营、医院和产业主。不同宗门差异很大：有的培养剑修，有的经营药山，有的替城池镇压妖患，有的靠海上贸易维持山门，还有的专门替贵族处理不能见光的事情。

修士寿命越长，越容易和普通亲族产生隔阂。一个三十岁才纳息成功的人，可能要面对父母老去、兄弟分家、婚约失效；一个修行有成的人，也可能因为不愿加入宗门而被地方势力排斥。

法律无法覆盖所有力量。

城中严禁大范围术法，但贵族和宗门往往拥有豁免；平民杀死妖兽会得到赏金，杀死修士却可能被当成叛乱；同一件法器，在商会账本里是货物，在宗门眼里是传承，在军府眼里则可能是战略武器。

很多冲突不是善恶之争，而是不同身份的人对同一块土地、同一件遗物、同一段婚约拥有不同的合法解释。

## 世界里真正值钱、值得想要的东西

最值钱的东西不只有修为。

- 能连续三代产出灵谷的土地。
- 一条不会被妖兽和军队截断的商路。
- 记载真实地形、暗河和遗迹入口的旧地图。
- 能让伤势不恶化的高阶药材。
- 一件真正适合自己的兵器，而不是名声响亮的废物。
- 一个愿意在关键时候出面的人。
- 大宗门的正式身份，或某座强城的永久居留权。
- 一支训练有素、不会在归潮期间失控的灵兽队伍。
- 没有被任何势力登记过的矿脉。
- 一份能证明血缘、继承权、土地归属或旧日罪责的原始文书。
- 可以让普通人活得更久、让修士少走弯路的医术和传承。
- 一件能够打开旧时代建筑、但尚未被任何宗门完全破解的器物。

许多人愿意用修为、寿命、婚姻、家产和性命去换这些东西，因为它们不仅改变一个人的力量，也会改变他以后能住在哪里、能带谁同行、谁愿意与他交易，以及哪些敌人会开始认真看待他。

## 世界知识边界

普通人知道：

- 王朝、宗门、商盟和妖兽都真实存在。
- 归潮会带来财富，也会带来灾难。
- 低阶修士可以通过学习和药物产生，但高阶修士需要天赋、师承、资源和运气。
- 许多古代遗迹危险，却不一定藏着宝物。
- 海外和天外都存在未知，但没人能可靠地讲清楚那里是什么。

专业人士知道：

- 不同地区的灵气性质并不相同，某些术法离开原产地后会失效。
- 妖兽迁徙、灵植开花和归潮落点存在规律，但规律并不完整。
- 古代器物通常需要特定材料、血脉、地势或文字才能启动。
- 很多宗门保存的祖师传说经过改写，不能直接当作历史。
- 高阶修士失踪的原因各不相同，不能简单归结为飞升。

顶层势力知道：

- 已知大陆只是澜生界的一部分。
- 古代王朝曾经拥有远超今日的跨域交通和炼器技术。
- 某些力量并非失传，而是被故意拆散、封存或改写。
- 归潮不是自然界唯一的大周期。
- 过去数千年里，至少有三次大范围文明断裂，但断裂之间是否存在联系，没有完整证据。

## Character 生成边界
人物可以深受上述世界现实塑造，并应当相对于世界正常值形成特殊性。
成长环境必须来自世界真实社会层，但不要求所有人物从普通底层起步：可以来自普通家庭、富商、军户、宗门附属、专业家庭、地方权势或其它世界合法位置。关键是这个切片本身不是 named 大事件、named 秘境、named NPC、named 神兵或未来剧情路线，不是为了给剧情插座配钥匙。
特殊能力/际遇优先采用 World Normal → Legal Exception：先指出普通人或普通修士通常怎样，再说明人物合法偏离了哪一条正常分布，以及这种异常为什么在本世界可被察觉、嫉妒、利用或恐惧。异常不能只是一项更高效的职业技能、诊断流程、维护技巧或行政缝隙；若它主要体现专业能力，也必须进一步形成读者能直接想拥有的个人力量、身份、关系或行动自由。
人格优先采用 Formative Fact → Adaptation → Observable Behavior：先写世界内真实经历，再写人物形成的适应方式，最后落到可观察选择；不要从性格标签反推童年。
Character is world-conditioned, story-independent：人物属于这个世界，但不是为世界已经准备好的故事机会而出生。

### Inspiration 1
source: mechanisms/departure-vacancy-v3
type: mechanism
score: 0.0684

可用抽象：Creative Problem：角色离队、失联、沉眠或暂时不可用后，怎样让这次缺席真正改变后续故事，同时允许长线自然沉睡而不是频繁提醒？
Mechanism：离开前先让人物完成一个符合自身欲望的决定、期限、拒绝、交接或目标；离开后尽快用一个新的选择、失败、机会或敌人反应证明“旧状态已经结束”。有人会第一次自己行动，有人失去过去可依赖的选择，有人会利用空位，也可能有人因此获得新的自由。若 Canon 已有期限、物件、缺席位置或未完成承诺，可以把它作为召回器，然后允许人物长时间退出主镜头。
Variants：- 主动离队证明自己：离开源于人物自己的目标，回归时以行动证明变化。
- 保护者/核心人物离场：留下者开始重新决定怎么活、怎么行动。
- 沉眠/失联：共同目标拆成其他人物自己的长期行动。
- 群像换挡：旧中心离开后，配角不是接班工具，而是各自沿自己的欲望继续。
Reader Payoff：读者真正感到“这个人不在了”，同时拥有一个可记住但不需要每章提醒的长期期待。
Guidance：Dormancy 不是遗忘。保留一个高辨识召回器即可；下一次提醒最好来自当前事件重新碰到旧期限、旧物、缺席位置或人物留下的实际后果。
Failure Modes：- 告别很长，但离开后什么都没变。
- 每隔几章机械提醒“他还在外面成长”。
- 留下者自动无摩擦接替全部功能。
- 还没形成缺席感就立即回归。

使用边界：只迁移“离开→空位/新选择→长线沉睡/召回”的因果，不迁移具体离队理由或回归奖励。

### Inspiration 2
source: mechanisms/character-autonomy-v3
type: mechanism
score: 0.0608

可用抽象：Creative Problem：怎样让重要配角拥有自己的故事，而不是始终站在主角旁边提供功能？
Mechanism：配角先拥有一个不以“帮助主角”为宾语的持续欲望，并拥有主角无法替代的关系、损失、知识或限制。允许其离开主镜头，在离屏期间成功、失败、受伤、换目标或形成新联盟；回流时先展示只有“离场后的他”才会做出的新行为，再补最少量背景。
回流不应恢复旧队形，而应给当前主线带来新机会、摩擦或目标冲突。主角最好进入配角已经启动的行动，而不是重新给配角派任务。
Variants：- 为爱情/尊严离开并独立成长。
- 为家园、信仰、复仇或自由离屏推进。
- 团队分散后，各成员带着不同人生状态重聚。
- 主角沉眠/导师离开后，配角的故事发动机继续运转。
Reader Payoff：回归人物有“自己活过一段时间”的重量；读者重新见到的是改变过的人，而不是离开前角色的升级版工具。
Guidance：不必给每个配角独立 POV。只要离屏期间存在可信因果，并在回归时带来可见 delta 即可。
Failure Modes：- 离屏人物只是等主角召回。
- 回归只报等级和装备。
- 所有配角都围绕主角同一个目标。
- 为了“群像”强迫每个配角都拥有长篇支线。

使用边界：迁移自主欲望、离屏因果与 re-entry delta，不要求所有配角长期离队或单开篇章。
