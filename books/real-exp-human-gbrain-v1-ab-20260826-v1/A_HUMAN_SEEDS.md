# HUMAN CANDIDATE 1｜林砚川／守水田契的人

## 世界中的初始位置与成长环境

林砚川出生在河谷边一户有少量灵谷田的农家。家里不算贫寒，三代人都靠同一段水渠和几亩田过活。祖父熟悉水闸、田界和旧契，父亲却相信乡里熟人之间的口头约定。

一次分水争议中，家里因为没有拿出完整文书，错过了整季播种。父亲不愿与邻户撕破脸，母亲则拿出陪嫁物补上了亏空。此后，家里仍住在原处，却再也没有真正安稳过。

## Formative Facts → Adaptation → Observable Behavior

- 家里曾因一句“大家都知道的规矩”失去一季收成。  
  → 林砚川不再把共识当作保障。  
  → 他遇到任何约定，都会追问边界、时间、见证人和违约后果。

- 父亲习惯忍让，母亲习惯在事后补洞。  
  → 他把“没人负责”视为最危险的状态。  
  → 他会主动接下麻烦，但一定要求对方说清楚自己要承担什么。

- 弟弟从小羡慕商路，觉得家里的田和水渠是一种困住人的旧债。  
  → 林砚川把“离开”理解为可能发生、却未必有资格让别人替自己收拾残局的选择。  
  → 他不阻止别人走，却会提前替对方算清楚留下的人会失去什么。

## Core Obsession

他想把“回家”从一句安慰变成事实。

这不是单纯拥有土地，也不是经营一份产业，而是希望人在做出选择之后，仍有一个不会因为别人改口、变卦或失势就立刻消失的归处。

## Excess

普通人觉得有个能遮雨的地方、家人还没有饿死，就已经够了。

林砚川却会继续追问：明年呢？水断了怎么办？家里最弱的人还能不能留下？如果自己不在，谁来守住这件事？

他会为了一个不够体面、却能让人继续留下来的安排，放弃更快、更赚钱的出路。

## Behavior Signature

他习惯先看水痕、田界、门锁和人的站位，再听对方讲道理。

他不会轻易承诺“我会帮你”，而会直接说出自己能做什么、做不到什么，以及事情失败后谁要承担代价。

他的核心行为可预测：不会接受把别人的安稳建立在含糊之上。具体手段却可能相反——有时他会据理力争，有时会先替人做完事，再把证据留到对方无法装作不知情的时候。

## 重要关系原点

父亲已经接受把田卖掉，去城里做水工，认为一家人换个地方重新开始并不丢人。

弟弟则准备投奔商队，认为只有离开河谷，家里才不会永远被一段水渠决定命运。

林砚川既舍不得家，也不完全相信留下就是正确。他们之间的矛盾，不是一个想走、一个想留，而是三个人对“家是否值得被保住”有不同答案。

## Initial State Seed

林砚川仍住在家里的旧屋中，负责照看田地和水渠，也在暗中整理那些可能证明田界与分水权的旧文书。

### 当前私人欲望

在父亲卖田、弟弟离开之前，让一家人最后完整地过完一个不需要向任何人低头借水的收成季。

## Audition Metadata（非 Canon）

### 人物钩子

他在一次分水争执中，忽然把自家最后一袋种粮倒进水渠，只为了让所有人都看见：这条渠若继续被人私改，谁家都别想种出东西。

# HUMAN CANDIDATE 2｜许潮生／把东西送回岸的人

## 世界中的初始位置与成长环境

许潮生出生在海港的修船铺。母亲负责接活、算账和处理船员纠纷，父亲曾随一艘商船出海，之后只回来过一批损坏的工具和几件无法确认主人的物品。

港口的人习惯用一句“海上没消息就是没消息”结束谈论。母亲却把那些东西一件件擦干、编号、收进木柜，等着有人来认领。

许潮生从小在修补船板、辨认木料和清理遗物中长大。

## Formative Facts → Adaptation → Observable Behavior

- 父亲的去向被不同人讲成不同版本，每个版本都像真的。  
  → 他逐渐不相信完整的故事，只相信留下来的损伤、时间和物件。  
  → 他遇到争执时，先检查证物和行动痕迹，不急着判断谁更会说话。

- 母亲总替失踪船员保管东西，却很少得到报酬。  
  → 他把“无人确认的结束”视为一种仍未完成的事情。  
  → 他会记住别人随手丢弃的小物，甚至替陌生人保存一件看似无用的遗物。

- 港口的人把离开看得很轻，今天出海，明天可能换一条船。  
  → 他对“走了就算了”有本能抵触。  
  → 他不轻易告别，也不接受别人用一句平安或失踪替代真正的结果。

## Core Obsession

他想确认离开究竟意味着什么。

只要一个人、一件东西或一段关系还没有留下可以核对的终点，他就很难把它算作结束。

## Excess

普通人接受“不知道”是生活的一部分。

许潮生却会花掉本来用来修铺子、还债或过冬的钱，只为确认一条船最后停在哪里、一个人最后看见了什么，或者一件东西究竟该交给谁。

他未必能改变结果，但不能容忍自己凭方便替结果盖章。

## Behavior Signature

他喜欢拆开东西看内部的裂痕，喜欢问“最后一次被谁看见”，也喜欢在谈判前先找退路。

面对危险，他通常先确认人和物是否齐全，再判断自己是否安全。

他不会总是谨慎。有时一旦发现有人故意把某件事伪装成“已经结束”，他会立刻追上去，哪怕那条路明显不值得，甚至没人会感谢他。

## 重要关系原点

母亲希望他接下修船铺，把这间店变成一份能养活人的稳定生计。

他的儿时朋友沈遥如今在港口文书房做事，想攒够钱离开海港，去内陆生活。她认为有些离开必须干净，不能每次都留下一个人追问最后的真相。

许潮生总想替她保留一条回来的路，沈遥却认为那正是他不肯承认她有权结束旧生活。

## Initial State Seed

许潮生白天在修船铺干活，夜里整理母亲留下的旧物柜。他手里没有多少积蓄，却一直保留着一件父亲出海前留下的工具。

### 当前私人欲望

在母亲还愿意出海之前，带她亲自走一趟外海，确认她多年来不肯亲口谈起的那艘船究竟去了哪里。

## Audition Metadata（非 Canon）

### 人物钩子

有人把一只泡烂的木箱送来，说里面的尸骨不必辨认。许潮生没有打开箱子，而是先问：为什么箱上的钉子，是从里面钉上的？

# HUMAN CANDIDATE 3｜韩戍／先把责任背在身上的军户子

## 世界中的初始位置与成长环境

韩戍出生在山城军户家庭。父亲在城防营中做基层校尉，母亲替军户家庭缝补、记账，也负责追讨迟迟不到的抚恤。

家里不缺一口饭，却常常不知道下个月的钱从哪里来。军府的命令、地方贵族的承诺和实际送到手里的粮饷，经常不是一回事。

韩戍很早就知道，战功、名声和真正有人活下来，是三件不同的事情。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾因替部下垫付药钱而负债，后来却被上级用一句“军中当互相照应”带过。  
  → 韩戍不再把荣誉性语言当成责任。  
  → 他遇到任何宏大说法，都会追问具体由谁出钱、谁留下、谁处理失败。

- 母亲长期替别人追讨抚恤，最后仍有一些名字没有等到结果。  
  → 他把“无人认领的后果”看得比当场的胜负更重。  
  → 他会记住失败中的人，而不是只记住最后立功的人。

- 家里所有人都习惯让最能扛的人多承担一点。  
  → 他形成了先替自己做决定、再承担后果的习惯。  
  → 他很少把责任推给集体，却也不喜欢别人未经允许替他安排牺牲。

## Core Obsession

他想让自己的命运由自己签字。

他可以接受输、受伤，甚至接受付出代价，但不能接受自己在不知情、不表态的情况下，被某个模糊的命令、家族安排或“为你好”替他决定一生。

## Excess

普通人觉得有人替自己做决定、替自己挡风险，未必是坏事。

韩戍却会为了保留选择权，主动放弃更安全、更稳定的安排。他宁愿接受一个明确的坏结果，也不愿接受一个由别人替他承担、却因此能控制他以后人生的好结果。

## Behavior Signature

他会在众人都谈理想时，指出最难看的现实代价。

他喜欢把决定拆成“谁选择、谁执行、谁善后”三件事；如果没人愿意承担最后一项，他通常会直接退出。

但他并不总是冷静。只要有人把别人的牺牲包装成理所当然，他会变得极其固执，甚至为了不让对方轻易体面收场，故意把自己也拖进更糟的局面。

## 重要关系原点

父亲希望他进入城防营，认为军籍至少能给他一个明确身份。

妹妹却厌恶军户家庭的生活，想尽快嫁到外地，彻底摆脱每次归潮都要等城门消息的日子。韩戍认为她是在把风险交给未来的夫家，妹妹则认为他把自己的恐惧伪装成保护。

## Initial State Seed

韩戍暂时在城防营做杂役和传令，尚未真正获得军籍。他正在考虑接受一份稳定的军府安排，但那份安排附带着家人无法拒绝的条件。

### 当前私人欲望

在父亲替他答应之前，亲自决定自己是否加入城防营，并让妹妹不必因为他的选择被迫留下。

## Audition Metadata（非 Canon）

### 人物钩子

城门外的妖兽已经冲破第一道防线，所有人都在等校尉下令。韩戍却先问守门人：如果现在关门，里面那批运药车怎么办？没人回答，他便拔刀去找那批车。

# HUMAN CANDIDATE 4｜谢闻璧／被人当作自己的人

## 世界中的初始位置与成长环境

谢闻璧出生在一座强城中的商人世家。家族拥有铺面、仓库和多份土地契约，与地方宗族、宗门附属产业和军府都有往来。

他从小接受完整教育，学过账目、契约、礼仪和几种常见灵材的辨识。家里没有亏待过他，反而一直明确告诉他：每个人喜欢他，都有一部分原因是因为谢家需要他。

十二岁时，他替一位远亲谈妥了一笔医药债。家族夸他办事漂亮，那位远亲后来却再也没有主动见过他。

## Formative Facts → Adaptation → Observable Behavior

- 他从小被当作家族中的一个位置培养，而不是被当作一个独立的人询问。  
  → 他开始怀疑所有亲近是否都附带价格。  
  → 别人对他好时，他会下意识寻找对方真正想要的东西。

- 家族从不直接争吵，所有冲突都被转成婚约、分账、继承和互惠。  
  → 他学会用让利、拒绝和沉默测试关系。  
  → 他很少直接问“你是不是在乎我”，而会故意放弃一个对自己有利的选项，看对方是否仍愿意留下。

- 他拥有很多普通人一生难得的机会，却很少拥有不带条件的选择。  
  → 他对“被安排得很好”有强烈的反感。  
  → 越是人人都说合适的道路，他越想确认自己是否真的愿意走。

## Core Obsession

他想在关系里以自己的名字被留下，而不是作为某个有用的位置被保留。

他不要求别人无条件爱他，但希望至少有一次，别人选择他时，失去的东西不能立刻被另一项利益补回去。

## Excess

普通人接受互相有用也可以算亲近。

谢闻璧却会不断剥掉关系里的便利，直到双方必须面对真正的偏好。他有时明知这种试探会伤人，仍然会继续，因为一个建立在方便上的亲密，对他来说比孤独更难忍受。

## Behavior Signature

他擅长给别人一个体面的拒绝机会，然后观察对方是否仍然回来。

他会记住别人没有说出口的条件，也会在对方准备索取回报之前，先把回报送完，让对方失去借此控制他的机会。

他通常用精确和礼貌保护自己，但一旦有人把他的真心解释成交易，他可能会做出极不划算的反击，只为了证明自己不是那个被标价的人。

## 重要关系原点

姐姐谢棠负责家族账房，是真心希望他接手一部分生意。她不认为自己在利用弟弟，只觉得一个人既然拥有能力，就该为家里承担位置。

谢闻璧却无法分辨姐姐是在邀请他，还是在确认他仍然有用。姐姐越是替他安排好退路，他越想离开；他越想证明自己不需要家族，姐姐越觉得他在把家里最难的部分丢给别人。

## Initial State Seed

谢闻璧仍住在家族宅院中，正在被安排一段合适的婚约。他拥有离开的钱，却还没有真正离开过家族的名字。

### 当前私人欲望

在婚约正式定下前，去一座没人知道谢家身份的城里住满一个冬天，确认自己能不能只凭本名被人记住。

## Audition Metadata（非 Canon）

### 人物钩子

一位旧识当众说愿意帮他脱离家族。谢闻璧没有感谢，只问对方：“如果我什么都不带，你还愿意让我进门吗？”
