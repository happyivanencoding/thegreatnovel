# HUMAN CANDIDATE 1｜沈渡／把话送到的人

## 世界中的初始位置与成长环境

沈渡出生在河谷渡口，家里经营一间替行商、军户和附近村民传递口信的小铺。家境不富裕，但不至于挨饿。父亲识字不多，却熟悉每条水路；母亲负责替人誊写书信、保管凭据。

他从小见过许多事情因为一句话没送到、一个日期没说清、一个口头承诺没有凭证而改变。家里最常见的争执，不是没有道理，而是每个人都坚称自己记得的才是真的。

他接受过基础识字和契据抄写教育，知道城籍、税契、婚书、军令在不同人手里意味着不同的分量。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾替一名外出的军户传错回信，导致对方家人错过了最后一次见面。  
  → 沈渡开始把“传达”视为需要负责到底的事情。  
  → 他不接受“差不多就是这个意思”，会要求对方把原话、时间和收信人重新说一遍。

- 母亲替人保存契据时，被双方同时指责私自改过内容。  
  → 沈渡不再相信单一叙述能够保护任何人。  
  → 他习惯留下副本、见证人和交接时间，即使对方嫌麻烦，也会坚持让双方当面确认。

- 他曾经替一名老人送出一封信，却发现收信人已经搬走。老人不愿再写第二封。  
  → 沈渡意识到，有些话错过一次就不会重新出现。  
  → 他会在别人已经放弃的时候继续询问旧邻、旧路和旧称呼，直到确认这封话确实无处可去。

## Core Obsession

他想让重要的东西抵达真正该抵达的人。

这里的“东西”不只是信，也包括一句承认、一件遗物、一个迟到的解释，或者某个人不愿亲口说出的事实。沈渡并不热衷于替人解决人生，他只是无法忍受一件真正重要的事因为懒惰、含糊或中途放弃而消失。

## Excess

普通人觉得“对方不回信就算了”，沈渡却会继续确认对方究竟没有收到、拒绝收到，还是根本不知道有人在等回应。

即使这件事已经不再影响利益，也有人愿意替他承担结果，他仍可能绕路去完成一次没有报酬的交接。

## Behavior Signature

他总会先问：“你希望对方听见哪一句？”

他不轻易替别人润色情绪，宁可把难听但准确的话原样留下。他遇到争执时，不急着判谁更有道理，而是寻找哪一段信息从来没有被完整传递。

他会记住别人随口说过的时间、地点和称呼，却很少主动解释自己为什么记得。真正做决定时，他倾向于选择能让双方再次见面的方案，而不是最省事的方案。

## 重要关系原点

沈渡与父亲的关系始终没有收束。

父亲认为，替人送话只是讨生活，不值得拿自己的安稳去冒险；沈渡却认为，既然接下了，就不能只把它当成一件货物。父亲不理解他为什么对陌生人的事如此认真，沈渡也无法接受父亲把很多错过都归结为“没办法”。

两人之间真正没有说完的，不是对错，而是父亲曾经没有送到的一句话。

## Initial State Seed

### 当前私人欲望

沈渡想亲自找到一个多年没有回过渡口的人，确认一件旧事究竟是被拒绝，还是从未送达。

## Audition Metadata（非 Canon）

### 人物钩子

有人在渡口等他，只交给他一件没有署名的旧物，并说：“送到以后，不必把回信带回来。”


# HUMAN CANDIDATE 2｜顾迟／舍不得换掉的人

## 世界中的初始位置与成长环境

顾迟出生在海港城外的修船坊。家里不掌握高深术法，却能处理船底裂缝、灵木变形、旧符失灵和灵兽拖船时留下的损伤。

父亲是个手艺很好的修船匠，母亲负责拆解和分类旧材料。家里常年堆着报废的零件、断掉的桨、失去灵性的木片和没人愿意再用的器具。顾迟没有接受完整的宗门教育，但从小知道什么东西还能救，什么东西只是继续浪费时间。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾经修好一条被商队判定为无用的旧船，后来那条船救回了几名在海雾中失散的人。  
  → 顾迟不再把“被判定为无用”当成最终结论。  
  → 他看到损坏的东西，会先找它还能承担什么，而不是先问换新的要多少钱。

- 母亲为了省钱，长期使用一只裂口的药碗，最终在一次搬运中割伤了手。  
  → 顾迟明白，舍不得丢弃有时不是珍惜，而是把风险推迟。  
  → 他修东西时会明确说出还能用多久、哪里不能再碰，不会把“修好了”说成“和原来一样”。

- 父亲把最好的工具留给顾迟的弟弟，因为弟弟更愿意继承修船坊。  
  → 顾迟学会了不把“被需要”误认为“被重视”。  
  → 他很少抢别人手里的东西，但会暗中记住每件工具真正适合谁，并在关键时刻把它交到那个人手里。

## Core Obsession

他想让那些还没有彻底坏掉的东西，再被认真使用一次。

这不等于拯救一切。顾迟真正执着的是判断：一件东西究竟已经结束，还是只是被太早放弃。他对旧物、旧关系和被人否定的选择，都有一种难以割舍的回望。

## Excess

普通人觉得换一件新的更快、更安全，顾迟却会先拆开旧物，确认它到底为什么坏。

当一件东西已经不值得修，他仍可能保留其中一个部件，或者记住它曾经适合什么人。别人觉得他只是浪费时间，他却无法容忍未经判断就宣布结束。

## Behavior Signature

他不会立刻答应“能不能修”，而是先问：“你还想让它承担什么？”

他习惯从最不起眼的磨损处判断整体状况，不喜欢只看表面。他给出的帮助往往不是把东西恢复原状，而是改变使用方式，让它在新的限制下继续发挥作用。

他不轻易安慰别人，却会把对方已经放弃的那件东西放回手边，并告诉对方具体还能用几次。

## 重要关系原点

顾迟和弟弟的关系一直卡在“谁更适合留下”这件事上。

弟弟想继承修船坊，认为哥哥总是在修别人不再要的东西；顾迟则认为弟弟只愿意接手那些已经证明能赚钱的活。两人都知道父亲偏爱谁，却都没有真正问过父亲。

顾迟不恨弟弟，但他始终没有接受：一个人被留下，是否就代表另一个人必须被放弃。

## Initial State Seed

### 当前私人欲望

顾迟想在修船坊被出售之前，修好母亲年轻时亲手做的一只旧木匣。木匣里没有贵重东西，母亲却从不允许任何人打开。

## Audition Metadata（非 Canon）

### 人物钩子

顾迟在一堆报废灵材里发现一件明显还能运转的旧器物，所有人都劝他别碰，因为它已经被登记为“不可修复”。


# HUMAN CANDIDATE 3｜陆闻山／想被留下的人

## 世界中的初始位置与成长环境

陆闻山出生在一户经营药材和灵兽饲料的富裕商家。家族拥有稳定铺面、几处药田和城籍，家中每个人都早早被安排了用途：有人管账，有人谈婚约，有人负责和宗门往来，有人负责照料长辈。

他从小接受完整识字、账目和礼仪教育，也见惯了亲情如何与利益、名声和婚姻安排纠缠在一起。家人并不苛待他，反而总是给他最体面的衣服和最周全的安排，只是很少有人问他愿意去哪儿。

## Formative Facts → Adaptation → Observable Behavior

- 家族每次留客，都会根据对方身份重新摆放座次、茶具和礼物。  
  → 陆闻山逐渐把“被留下”与“有用”区分开来。  
  → 他会观察一个人在失去利用价值后是否仍被邀请进屋，也会故意把自己放到不方便的位置，看看别人是否还愿意为他留座。

- 他曾有一位关系亲近的同龄伙伴，因为家境变化突然被家族禁止来往。大人们没有解释，只说“以后不是一路人”。  
  → 陆闻山开始怀疑所有轻易的亲近。  
  → 他很少直接问“你是不是在乎我”，而是会提出一个小而麻烦的请求，观察对方是否愿意花时间完成。

- 家人习惯用礼物代替道歉，用安排代替陪伴。  
  → 他学会通过制造具体的共同经历来确认关系。  
  → 他记得别人喜欢什么食物、害怕哪种场合，却不愿只靠送东西维持联系。

## Core Obsession

他想知道，一个人在不再有用、不再体面、也不再方便的时候，是否仍然值得被留下。

这是一种私人而持续的牵引。它会影响他选择相信谁、拒绝什么、愿意承担多大的麻烦，也会影响他对“家”“朋友”和“归属”的理解。

## Excess

普通人觉得关系只要互相照应就够了，陆闻山却会继续追问：如果我什么也不能替你做，你还会不会让我坐下来。

他有时会拒绝一个明显更体面的安排，只因为那安排把他当成一件被摆放的物品；也可能为了证明一段关系没有变质，主动承担不必要的麻烦。

## Behavior Signature

他不会用直接表白换取确定感，而是把真实需求藏进一件具体小事里。

他送礼时很少挑最贵的，而会挑对方曾经随口提过、却不认为有人会记住的东西。他遇到冷淡时不立刻争吵，反而会突然减少所有主动，等待对方是否察觉。

他看似擅长周旋，真正需要做决定时，却容易为了一个人的态度放弃更稳妥的安排。

## 重要关系原点

陆闻山与母亲关系亲近，却始终没有真正靠近。

母亲对他照顾周到，也愿意替他挡掉许多家族压力，但她从不允许自己显得软弱。陆闻山一直分不清，母亲对他的好究竟来自爱、责任，还是因为他是最听话的孩子。

他想有一天让母亲在没有客人、没有账本、没有家族安排的情况下，单独为自己做一个决定。

## Initial State Seed

### 当前私人欲望

陆闻山想邀请那位已经多年不再往来的旧伙伴，参加一次只有两个人的饭局，并且不带任何礼物、不谈生意，也不让家族知道。

## Audition Metadata（非 Canon）

### 人物钩子

一个曾经拒绝过他的人突然来取回一件旧物，却没有解释为什么直到今天才来。


# HUMAN CANDIDATE 4｜谢临川／一定要亲眼看过

## 世界中的初始位置与成长环境

谢临川出生在山城外的一家驿站。驿站不属于大商会，只靠替过路商队、采药人和军府传递消息、照看牲口维持生计。

山城四面道路复杂，灵气和天气变化也快。大人们常用“那里很危险”“那条路已经断了”“那座城的人都不能信”来解释远方，但他们给出的说法互相矛盾。谢临川从小听着各种关于外地的故事长大，却很少有人真正带他走出山城。

他接受过基础地图、路线和牲畜照料教育，熟悉旅人留下的口音、食物和行路习惯。

## Formative Facts → Adaptation → Observable Behavior

- 驿站曾接待过三支分别来自同一方向的队伍，三支队伍对那条路的描述完全不同。  
  → 谢临川不再把多数人的说法当成事实。  
  → 他会追问“你在哪一段看见的”，并把亲眼见过的地形和听来的消息分开记录。

- 他的父亲年轻时走过很远的地方，却只愿意讲结果，不讲途中细节。  
  → 谢临川逐渐把别人的人生经历视为无法替代的东西。  
  → 他不满足于看地图或听故事，遇到感兴趣的地方，总想知道那里的水是什么味道、夜里有什么声音、普通人怎样过一天。

- 母亲认为远行意味着把稳定生活交给运气。她从不阻拦他读地图，却总在他准备出发时问：“知道这些，能让你留下来吗？”  
  → 谢临川把“留下”和“远行”都看成需要自己承担的选择。  
  → 他不会因为别人说某处值得去就出发，也不会因为害怕失去驿站的位置而永远不走。

## Core Obsession

他想把别人嘴里的远方，变成自己真正拥有的记忆。

他在意的不是征服未知，也不是证明自己勇敢，而是拒绝让一生只由别人替他描述。他希望亲自见过一些地方、吃过那里的普通食物、记住那里的人怎样生活，即使那些地方没有财富、名声或机会。

## Excess

普通人觉得地图和可靠记录已经足够，谢临川却仍想亲自确认。

即使一条路已经被证明没有收益，他也可能因为某个细节没有见过而想走一趟；即使别人已经替他拍胸脯保证，他仍会为了一处不起眼的岔路改变行程。

## Behavior Signature

他不先问“那里有什么机缘”，而会问“那里的人怎么过夜”。

他观察远方时，总先记住低处的水、牲口的状态、普通人的价格和当地人避讳的称呼。他不轻易相信宏大的传闻，却会认真对待一个路边人说出的半句话。

他做决定时常把最稳妥的路线改成能看见更多东西的路线，但一旦带了别人同行，又会把安全责任全部揽到自己身上。

## 重要关系原点

谢临川与母亲之间没有真正的争吵，却一直存在一场没有结束的谈判。

母亲希望他接手驿站，把熟悉的路走稳；谢临川认为，如果一辈子只经营熟悉的路，他就永远不知道母亲为何如此害怕远方。母亲知道他迟早会离开，却从不承认自己在等他回来。

他们都把“回来”当成对方应该主动完成的事。

## Initial State Seed

### 当前私人欲望

谢临川想在下一次换季前，独自走完一条父亲年轻时走过、却从未完整讲述过的旧商路。

## Audition Metadata（非 Canon）

### 人物钩子

一名刚从远方回来的旅人说：“那条路和你父亲讲的完全不一样。”
