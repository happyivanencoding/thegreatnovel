Director Narrative Salience：Director 面对十章计划和 Canon 中很多可执行细节时，八字段优先抓住本章最值得读的那一个人物冲突、关键选择、力量使用、反转、利益得失或兑现结果。操作步骤只有在它会改变人物选择、风险、胜负或结果时才进入“主角行动”；不要把“主角行动”写成施工单、路线单、检测流程或完整操作清单。**Discriminative Detail Only**：调查、手艺、医学、制作、检测、推理等 Supporting Skill 只保留足以改变判断的少量关键细节；一旦这些细节已经足以推出发现或决定，立即进入发现造成的选择、冲突或后果，不把实施过程继续展开成专业展示。**决定已经做完后的普通实施默认压缩**：除非实施中又出现新的选择、冲突、不确定性或失败风险，不把停车、搬运、排布、绑缚、登记、赶路等普通执行扩成主要场景。Director 的 `主角行动` 对这类内容优先只保留“关键决定 + 至多一个真正改变成败/判断的决定性动作 + 结果”，不要把“调整车位、补薄弱处、垫石、绑绳、摆盾”之类并列动作继续传给 Curator / Writer。 **如果这个动作依赖的是前文已经成立、且不是 Core Fantasy 的 Supporting Skill，事件合同默认连技能方法本身也不重述，只写它让主角完成了什么结果；只有本章发现该技能的新边界、失败方式或质变时才重新把方法写进“主角行动”。****不要用 Competence Filler 填动作空缺**：如果本章真正的价值是 World Entry、重要势力首次进入、关系立场、误判、选择或局势换挡，而 Outline 没安排一个值得展开的技术难题，主角只做站队、拒绝、观察、跟随、守住位置、说一句决定等简单行动也完全成立；不要为了让主角“显得有用/能干”临时制造排车、维修、诊断、路线、受力、清点或其它专业问题让他解决。**Access / Reward 不自动征收资格流程税**：Outline 已经把某个入口、邀请、名额、工作机会、身份待遇或奖励作为本章可选择/可获得的既定条件时，Director 不得为了“让它显得更合理/更配得上”自行补一轮试工、观察、检测、考核、证明、登记或专业展示；除非 Plan 明确把该过程本身列为故事事件，否则直接让人物面对这个已经成立的机会并作选择，让篇幅进入选择的后果。不能删改计划规定的结果，但可以把实现过程压缩到足够支撑因果的最小程度，让“谁逼谁、主角决定什么、局势怎样被改变”保持前景。


经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。




# Opening Three Chapter Contract

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的世界事实 / 规则 → 主角立即行动。**World fact 的选择权在 World + Outline，不在 Writer**：如果当前章 `具体剧情` 已排程某条开篇世界定向，Curator 必须保留，Primary 用最短直接方式落实；如果 Plan 没排程，Primary 不自己从完整 World 里挑一段补课。前三章只释放理解当前故事所需的信息，同时让读者获得必要的强弱、身份、价值与世界位置；核心优势第一次形成结果时，用一次世界内比较说明为什么超标。不要先把世界模型讲完再放主角进去，也不要把世界定向做成独立 Setup 事件。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

顾临川能把自己的影子剥成另一具完整的自己，让两具身体同时战斗、修炼、学习和生活；重新合并后，两边经历与伤势共同回到同一个人身上。

### 核心不变量

- 一个人同时过两种人生，并把两边的收益真正据为己有。
- 主角持续进入原本没有资格接触的力量层、人物圈层、世界层与选择层。
- 分影扩大行动可能，却不能替顾临川决定哪一边的人生更值得承担。

### 退化风险

- 早期反复把分影写成“同时上班、同时办事”的效率工具，削弱战斗、关系和人生选择。
- 用契约、资格和名声替代真正的兵器、功法、身体变化或高价值占有。
- 把沉昼城、盐港、北境长影和无光海强行串成单一谜底，压扁世界本身的独立冲突。

## T0 已成立事实

顾临川出生并生活在大晟中部一座有固定火盆与内街阴影的普通城镇。

父亲替商队做短途账目和货单，母亲经营一家能住六七人的小客舍，并偶尔修补衣物、缝制灯罩。顾临川已经完成基础识字、算术和官契辨认，也曾在本地武馆断续学习一年影术。

顾临川十五岁通过影性试验，但尚未进入宗门、军府或商盟，也尚未完成一阶凝影。

他目前最想靠自己攒出足够支撑半年的钱，去外城住上一季，不以客舍少东家或熟人的身份被认识；他还想接触陌生人和新货物，并学一门好看但未必有明显用途的手艺。

顾临川与陆绾在武馆相识，曾因她临时缺少同行者而放弃报酬更高的记账活，陪她走过五天山路。两人有吸引和共同经历，但没有被确定为稳定关系。

顾临川过去保留着一枚多年以前由陌生年轻护卫宋野送给他的磨损铜扣；铜扣的来历、用途和未来价值在 T0 时均未被顾临川确认。

## 作者当前章意图

成熟中文男频东方玄幻成长长篇。生成一本真正全新的书：使用全新的世界、力量因果、人物、势力、地理与长期故事，不复用近期实验的核心机制组合或标志性专名。可以自然使用境界、功法、兵器、异兽、宗门、王朝、血脉、火、雷、寒气等熟悉题材语言；原创不靠回避熟悉词，也不靠生造术语。

近期不得换名复用的核心机制组合包括：异兽心核/器官炼体获得兽性、景相/天景、重力/承力、潮炁/潮印、材料性质/真质/刻纹、地潮/潮力、地火/命炉、曜砂储热、断光/灯数、天蜕/壳层、兵器回响。不要只是给旧机制重新命名。

核心阅读欲望优先是主角本人持续变强、战斗、奇遇、稀有功法/兵器、身体变化、怪物/异族、秘境遗迹、强者竞争、公开比较、真正高价值获得，以及随着成长不断进入第一章时没有资格接触的人物圈层与世界层。治理、维护、运输、工程、资源分配只能作为必要背景，不得成为主要价值重心或长期故事发动机。

世界力量必须先用普通话说明“力量从哪里来、人具体能做什么、怎样变强、怎样失败”，再决定是否需要短名；新词只给已经理解、会反复出现的对象或层级贴标签。前台力量优先是身体、攻击、防御、移动、元素、兵器、异兽等直接可感知作用，不默认把路径、权限、定义、结构分析或验证过程本身做成力量核心。力量体系要有可长期反复比较的公开主尺、高阶强者样本和值得羡慕的高价值对象。

Core Power 默认宁强勿弱：同层普通人/天才第一次看到时应明显觉得“这也太占便宜了”，允许有条件越级；但能力要一句普通话能懂，直接型能力的成长继续扩大控制、战斗复合和危险场景下的稳定使用，不重新退化成结构分析、材料诊断、路线计算或验证流程。World 阶段完全不知道未来主角与金手指。
