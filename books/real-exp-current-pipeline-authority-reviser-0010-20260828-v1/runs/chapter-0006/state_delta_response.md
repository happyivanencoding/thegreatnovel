# Proposed Persistent Canon

已证明能力：顾临川可在强光与影缘不稳时形成影身，使本体与影身同时行动；两者共享伤势、撞击与疲劳反馈；能依据真实脚印和碎石痕迹辨认错影中的真实路径。  
能力限制：分影会造成胸闷、短暂失明并共享伤痛；影身远离本体后无法直接获知另一处所见；错影区域会误导方向并改变可行路径。  
关系阶段：陆绾与顾临川已形成互相协同行动关系；陆绾在危急时刻仍要求顾临川优先守住药车。  
持久资源：正式一阶记录；铜羽护卫契券；预付钱袋。  
长期身份：铜羽商盟临时随队护卫；武馆弟子；普通客舍家庭成员。  
确认知识：折日峡的偏折阳光能制造行动错位与假影；残破石墙后的石城同样存在危险错影；观日宗弟子已进入石城。  
长期伤势：小腿抓伤，尚不明确是否影响持续行动。  
重要敌我状态：一头异兽已被击杀；车队暂时稳住并向峡外撤退；陆绾被断门外错影困住；观日宗弟子出现在石城；探路队失联仍未查明。

# Proposed Chapter Summary

折日峡的错影导致驮车和药车险些翻覆，顾临川分出影身，一边击杀扑向药车的异兽并带队撤退，一边沿陆绾留下的痕迹追入峡谷深处。他在残破石墙外找到被断门错影困住的陆绾，却发现石城内已有数名观日宗弟子出现。
