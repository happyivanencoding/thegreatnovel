# 《借我一招》冻结实验核心设定

本文件只把用户本轮明确给出的固定设定整理成实验输入，不扩写完整世界、不生成长篇 Future 10，也不授权模型改变以下边界。

## 题材与主角

- 题材：经典玄幻 / 宗门成长 / 武学战斗。
- 主角：顾长川，十七岁，青崖宗外门弟子。
- 他进入宗门三年，境界普通、资源普通，没有显赫血脉。
- 他什么都学得会一点，却没有任何一门真正拿得出手。
- 外门马上进行年度升院考核；失败者会失去正式弟子身份，被分去山下产业。
- 顾长川不想离开宗门，首先因为他想变强，不想被淘汰。他亲眼见过内门弟子一剑斩断山瀑，因此明确知道人可以强到那种程度。
- 不把他的核心动力改写成保护所有人、承担责任、查身世或拯救宗门。

## 核心能力

顾长川可以在近距离看见别人真正使出一门武技时，短暂记住其中一次“最完整的发力”。之后，他可以让自己的身体完整复现这一次动作。

前三章的最低理解必须是：

> 看见别人完整打出一招 → 自己能够完整打出来一次。

第一阶段限制：必须亲眼近距离看到；对方必须真的完整使出；一开始只能保留一招；用掉以后消失；身体素质不足时仍然承受真实负担。

前三章不得提前展开：永久复制所有武学、看一遍彻底学会、保存多招、拆解组合、创造新武学或完整能力来源。

长期方向只作为远期边界：借一招 → 理解关键发力 → 自己练会一部分 → 同时保存多招 → 拆解不同人的招式 → 重新组合 → 创造自己的武学体系。前三章只验证前两步中的第一步和主动选择的开始。

## 三章必须保留的商业结构

### Chapter 1

发现能力并第一次真实逆转。顾长川必须面对考核前的现实淘汰压力和具体冲突；他看到别人完整使出一招，随后在一个必须立即行动的事件中主动借用，改变一个过去无法改变的结果。章末至少改变身份判断、关系、资源、考核机会或行动空间中的一项，并让他形成下一步主动目标。

### Chapter 2

把第一章的偶然优势变成主角主动可以利用的东西。顾长川应开始思考“既然我能借一次，那么我应该去看谁的招”，为了考核主动寻找合适对象，并通过拒绝、交换、试探、利用或关系选择取得真实资源 / 机会 / 新的借招选择。不能只是再打一场重复战斗。

### Chapter 3

让第一、二章所得进入正式竞争。升院考核正式开始，但不要写成三场同形擂台战；应让之前的观察、选择、关系或资源产生过去不可能取得的结果，使顾长川的身份、关系、资源或行动空间发生公开变化。

## 表达与信息边界

- 清楚 > 顺畅 > 有画面 > 文学感。
- 第一章优先：顾长川 → 他现在要什么 → 为什么马上可能失去 → 具体机会 / 冲突 → 能力第一次出现 → 主动使用 → 现实结果。
- 先让读者知道动作和结果，再决定是否命名概念；不创造借式印、回武痕、真式、武影、藏招槽、复刻脉等术语。
- 普通宗门、外门、内门、武技、灵石、妖兽等常识词可自然使用；专属术语前三章尽量不新增。
- 能直接说清就直接说清，减少连续“不是 A / 不是 B / 只是 C”句法。
- 战斗只写决定胜负和关系变化的动作；不逐步记录无新信息的工程式动作。
- 重要成功后必须有小而真实的社会反馈；不能成功后立刻堆叠长老追杀、神秘组织、血脉觉醒、第二能力、远古秘密。
- 前三章至少出现两个会继续存在的重要配角，他们有自己的目标，会拒绝、交换、试探、利用或改变计划，不只是能力说明员和震惊群众。

## Chapter 3 Frozen Event Facts

本隔离实验重跑 Chapter 3 时，以下事实是固定事件结果，不得被 Director 改成等价但不同的规则或身份结果：台心放置合格牌；顾长川必须在周既明阻拦下取牌并带回自己的白线；周既明最终越过判定线；顾长川取得本轮公开升院合格资格，但尚未正式入内门；顾长川只在真实进攻后使用一次回身卸力步且使用后消失；许照确认守约；周既明成为公开竞争者。
