# Proposed Active Scene State

当前地点：鸣骨峡旧风门下层骨台与副链风道。  
在场人物：贺临川、照雪、唐鹭、段阙、叶朔、商盟伙计、褐背大兽、钩翼兽、冲出的灰冠兽群。  
即时伤势：贺临川左肘肿伤、背部擦伤、手心磨破、疲惫；照雪右前腿旧伤裂开、行动跛行。  
手中关键物品：旧皮袋中的撬刀、半页旧契。  
当前敌人或追兵：段阙与共鸣级26钩翼兽；商盟伙计仍在现场；军府人员刚抵达。  
当前倒计时：天亮前必须返回；迁徙巢崖正在上移，叶朔已无法长久支撑风门。  
下一步直接目标：沿旧风门行动，保护照雪与被救出的幼兽，避开段阙追捕并查找沉瓦线索。  
当前主动目标：保护照雪的自主权，追查它愿意寻找的对象沉瓦。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
共鸣级1“引脉”能力与限制不变；伤势与手心磨破暂时压低贺临川发挥。

### Active Relationships

照雪｜主动靠近旧风门并救出被副链勒住的灰冠幼兽｜与贺临川保持稳定共鸣和自主判断｜仍受伤跛行｜已明确选择风门方向，等待贺临川同行。  
叶朔｜支撑旧风门、要求撤除副链让兽群迁巢｜与各方立场冲突但目标明确｜已公开介入交割现场。  
段阙｜继续追回照雪与旧契｜与贺临川、唐鹭、叶朔敌对｜钩翼兽已直接压制照雪，军府到场后行动受扰。  
唐鹭｜借褐背大兽撞开铁笼、使副链暂时松动｜与贺临川仍为信息提供者与潜在竞争方｜继续掌握沉瓦线索与离峡滑车。

### Identity / Access

贺临川与照雪仍按共鸣级1临时登记；已进入旧风门下层骨台，但未取得巢崖通行许可。

### Knowledge / Enemy State

旧风门已被叶朔推开至可通兽口；副链仍阻碍迁巢但已暂时松动，灰冠兽群开始冲出；军府人员已抵达鸣骨峡。

### World State

鸣骨峡迁徙巢崖已经沿高层风道上移，旧风门内兽群开始迁出；商盟交割、兽群迁徙与追捕现场新增军府介入。

### Tracked Assets

半页旧契｜贺临川｜旧皮袋｜与唐鹭瓦片具有相同墨印｜持续持有。  
撬刀｜贺临川｜旧皮袋｜仍可使用｜持续持有。  
照雪｜贺临川附近｜旧风门下层骨台｜右前腿旧伤裂开、跛行｜持续自主同行。

# Proposed Chapter Summary

旧风门在叶朔支撑下打开，迁徙兽群开始冲出，但商盟副链仍阻碍通道。照雪挣脱贺临川后救出被勒住的幼兽，贺临川绕行下层骨台追向风门。褐背大兽撞开铁笼使副链暂时松动，军府人员随即抵达。

# Proposed Open Promises

- 照雪能否在风门开启后的迁徙通道中找到沉瓦留下的对象或踪迹。
- 唐鹭持有的灰黑瓦片与半页旧契能否拼合出完整线索。
- 副链能否被彻底解除，灰冠兽群与迁徙巢崖能否安全通过。
- 段阙能否再次夺走照雪与半页旧契。
- 商盟笼兽交割的真实对象与目的。
- 苏渠是谁，以及其死前留下的契文为何被商盟追索。
- 军府介入后，各方能否继续行动或被迫交代。
- 贺临川与照雪能否在天亮前返回家中。
- 照雪要回来或逃走时，贺临川能否不替它答应任何契约。
