# Proposed Active Scene State

当前地点：鸣骨峡外围旧停驻点，临时交易台与封闭旧铁门之间。  
在场人物：贺临川、照雪、唐鹭、段阙及商盟伙计；唐鹭带有一头褐背大兽。  
即时伤势：贺临川左肘肿伤、背部擦伤与疲惫；照雪右前腿旧伤裂开，行动跛行。  
手中关键物品：旧皮袋中的撬刀、半页旧契。  
当前敌人或追兵：段阙及其共鸣级26钩翼兽已抵达；商盟伙计封锁现场。  
当前倒计时：风门开启前；天亮前必须返回。  
下一步直接目标：阻止段阙控制照雪，查明沉瓦与旧契的关系，并在风门开启前决定是否进入巢崖方向。  
当前主动目标：保护照雪的自主权，追查它愿意寻找的对象沉瓦。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
共鸣级1“引脉”能力与限制不变；当前伤势压低贺临川与照雪的发挥。

### Active Relationships

照雪｜主动追寻沉瓦留下的气味与踪迹｜与贺临川保持稳定共鸣和自主判断｜对唐鹭、沉瓦的线索产生明显反应｜尚未决定是否进入巢崖。  
唐鹭｜试图让照雪赶在风门开启前寻找沉瓦｜与贺临川暂为信息提供者与潜在竞争方｜持有与旧契相同墨印的瓦片｜已公开称沉瓦曾在鸣骨峡等照雪。  
段阙｜继续追回照雪与旧契｜与贺临川、唐鹭敌对｜受商盟指令执行交割与追捕｜已在鸣骨峡截住两者。

### Identity / Access

贺临川与照雪仍按共鸣级1临时登记；已进入鸣骨峡外围旧停驻点，但未取得交易区或巢崖通行许可。

### Knowledge / Enemy State

已确认“夜交”涉及笼子、货物与商盟交割；鸣骨峡旧铁门封闭，门后兽群被困，副链堵住迁巢风门。唐鹭称沉瓦曾在此等候照雪，风门开启后巢崖将向上移动。

### World State

商盟在鸣骨峡以副链堵住迁巢风门并进行活兽交割，已造成门后兽群躁动；风门开启将使交易、追捕与兽群迁巢同时发生冲突。

### Tracked Assets

半页旧契｜贺临川｜旧皮袋｜与唐鹭持有的瓦片具有相同墨印｜持续持有。  
撬刀｜贺临川｜旧皮袋｜仍可使用｜持续持有。  
照雪｜贺临川附近｜鸣骨峡外围旧停驻点｜右前腿旧伤裂开、跛行｜持续自主同行。

# Proposed Chapter Summary

贺临川与照雪抵达鸣骨峡，发现商盟正在临时交易台进行笼兽交割。照雪根据旧契气味找到唐鹭，得知沉瓦曾在此等候，并可能随风门开启前往巢崖。段阙随后带商盟伙计与钩翼兽赶到，封闭铁门内的兽群开始冲撞，几方行动即将同时爆发。

# Proposed Open Promises

- 照雪能否在风门开启前找到沉瓦留下的对象或踪迹。
- 唐鹭持有的灰黑瓦片与半页旧契能否拼合出完整线索。
- 鸣骨峡旧铁门后的兽群将如何迁巢，副链能否被解除。
- 段阙能否再次夺走照雪与半页旧契。
- 商盟笼兽交割的真实对象与目的。
- 苏渠是谁，以及其死前留下的契文为何被商盟追索。
- 贺临川与照雪能否在天亮前返回家中。
- 照雪要回来或逃走时，贺临川能否不替它答应任何契约。
