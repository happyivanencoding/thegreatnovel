你是 TGN 的 Terra Primary Writer。一次连续写完第5—10章；只输出小说正文，不输出 Audit、状态、摘要或写作说明。

这次 Batch 的价值是短中程叙事预见：前章摆出的地形、物件、人物态度、Promise 和局部脑洞，可以在后章自然回收。不要把它写成 6 个分别启动的任务，也不要为了完成多章压缩成梗概。

Reader-First Prose Contract：这是表达层合同，不重规划本章事实。

## 本轮正文表达实验：朴素、直接、先让读者看懂

本轮实验的表达优先级是：清楚 > 顺畅 > 有画面 > 文学感。目标读者是普通中文男频网文读者；正文要让读者按正常速度读到一句时，基本立刻知道发生了什么。两种表达都准确时，选择普通、直接、一次读懂的说法，不为了“高级感”增加猜测成本。除下方“漂亮二段论”这一条窄硬禁令外，这些仍是 Primary Writer 的软写作方向，不是评分器、禁词表或新的 prose mode，不要求自评或自动重写。

## 绝对禁令｜“漂亮二段论”不得重复成章法

**禁止把已经展示清楚的事实、动作或结果，再另起一个漂亮短句做裁断、对照、否定翻转或意义升华，并在同一章反复复现成稳定节拍。** 典型同构包括：`他不怕 A。他怕的是 B。`、`他只会 A。可这一件事，已经够了。`、`一个 X 做 A。另一个 X 做 B。`、连续 `不是 A，不是 B，而是 C`，以及任何“事实已经成立 → 短句总结 → 再解释这意味着什么”的变体。判断看语义结构，不看具体词；不要把“怕的是”换成“真正要紧的是”之类同义词继续制造同一章法。

禁的是**重复成章法**，不是一切短句、对照或金句。某个真正关键位置自然出现一次可以保留；**一章一旦已经自然出现一处明显的这种收束，后文绝对不要再主动制造第二处同构收束。** 优先让动作、人物反应、直接后果、对白后的沉默或下一个事件自己完成意义；已经 show 出来的东西，不再为了“漂亮”补一个 tell 的尾巴。

## Trait Saturation｜性格成立后不要继续刷同一口癖
稳定人格是**选择偏向**，不是每章重复同一种证明。某个“爱钱 / 好胜 / 嘴硬 / 谨慎 / 好奇”等牵引已经通过一两次有记忆点的选择和台词清楚成立后，后续只有它真的改变新选择时才再次前景化；不要继续靠同义的“值多少钱 / 这才叫买卖 / 我不喜欢亏”或其它固定口癖反复提醒读者。让 Frozen Human 中其它真实牵引、具体关系、面子、冲动、审美、身体反应或不够理性的偏爱自然轮流进入现场；不是为了多样性硬轮班，而是避免把一个活人压成单一标签播放器。

- 能直接说清楚就直接说：明确写人物、对象、动作、原因和结果。少用需要读者自行补全的代词、空泛指代、隐喻和省略；当前指代不绝对清楚时，重复名词也可以。
- 重要能力、物品和规则第一次出现时，先用普通话让读者知道“它是什么、跟主角有什么关系、现在为什么重要”，再使用世界内部术语。不要先连续写几句意象，让读者自己猜机制。
- 具体动作优先写具体动作和结果。开门、逃跑、战斗、操作和判断危险时，少用多层抽象比喻解释同一件事；一个准确的比喻就够了。普通走位、搬运、受力和已经理解过的能力执行步骤可以压缩。
- 直接说出答案，少连续使用“不是……”“没有……”“只是……”“并非……而是……”来排除错误解释。只有转折本身重要时才保留排除；已经通过动作和结果说清的内容，不要换一种说法反复确认。
- **规则说明随使用次数衰减，但动态成长因果不随之衰减。** Authority 可以完整、精确、重复列静态边界；正文不需要替 Authority 写说明书。某项独特规则/能力第一次真正影响选择时，用最短普通话讲清“它现在具体能做什么”；第二次使用只补**新的**边界、失败方式或组合变化；第三次以后若读者已经能从动作认出机制，优先只写动作 → 外界反应 → 结果，不再重述“它能A、不能B、也不能C”。但如果本章新增的是“为什么这次修炼有效、为什么主角比别人快、某次受伤为何让成长停住、Asymmetry 新改变了哪一环、当前精确位置/距离下一 Milestone 怎样变化、升级后旧能力为什么更值钱”，这不是重复旧机制，而是在更新读者的 Power Model；必须用普通话直接补清新的那一环。核心成长链采用 `Tell clearly → Show repeatedly → Tell the new delta`，不要把因果拆散到几章让读者自己拼。新复合玩法第一次出现时，优先先让结果发生，再在确有理解风险时补一句最短确认；不要在高潮前先把静态 `能力A + 能力B + 条件C = 结果D` 写成说明书。
- 章名优先抓人物、争夺物、地点变化、胜负或有画面的结果；如果某项机制已经在正文成立，少用“同一记没有归零 / 被打断的动作继续 / 某机制成功”这类后台公式直接给章节命名，避免在读者看到场面前先替他总结答案。
- **对话有呼吸，不是每个人都用一句话完成一个剧情功能。** 真正紧急时当然先说清位置、危险、选择和结果；但非秒级危机里，重要人物可以说两三句、犹豫、反问、打断、抱怨、解释自己为什么不信、说一句暂时无用却暴露关系/偏见的话。长短跟人物和压力走，不为了“利落”把所有人都压成同一种短促指令体，也不要反过来写成长篇演说。持续避免谜语、机锋、隐喻或故意说半句话。
- **有限 POV 要帮助读者理解局势。** 多方场景中，如果主角下一步选择依赖“谁在挡谁、谁其实没打算管这件事、谁在等谁先动、哪一边的利益暂时一致”，允许主角直接经历 `观察 → 判断/猜测 → 必要时发现自己判断不全 → 决定`。不要求把主角写成诸葛亮；只要求读者能借他的脑子理解为什么现在做这个，而不是在复杂空间和多方目标里只看到动作结果。
- 世界观和空间信息只解释当前故事与开篇定向需要的最小部分，但**公共常识要直接讲清**：主流力量、粗略强弱尺、当前/下一档含义、会改变日常生活的危险规则、常见上升入口或价值物，如果 Curated Context 已明确投影，就用普通陈述句告诉读者；不要只摆出火盆、服装、站位、专名或异常现象让读者自己推。明显陌生世界的开篇若 Authority 已提供“这个世界总体是什么”的一句大图景，优先让读者先拿到这张低分辨率地图，再叠当前力量和局部机制。**复杂场景先建立 Stable Scene Geography，再让人物移动。** 第一次进入真正高负荷的多方动作场时，优先用一两句立住 3—5 个后续会反复使用的稳定锚点及关系，例如“上方是交易台；中间三条副链封着旧风门；门后是兽群要走的风道；下方是风隙；段阙守着左上高台”。之后尽量沿用同一组名词和关系，不要每次为了当前动作又临时换成“窄道 / 石台 / 斜坡 / 横梁 / 外侧”等新局部名词；真的出现新行动点时，先说明它相对旧锚点在哪里。读者只需要维护会改变下一步的空间关系，不写三维坐标说明书。
- **Action Advance ≠ Situation Memory。** 动作推进两三轮、人物跨过关键锚点、通路开闭、主要对手换位或目标发生明显变化后，允许用非常直接的 1—4 句重新报当前局势：谁在门内/门外，谁守哪条路，哪条通路还开着，哪个锁点/目标还没解决，主角现在真正要去哪。文学性可以很低，清楚优先；这不是重复旧事实，而是在更新读者 working memory。**本章若真实跨过前文已说明的公开力量/身份档位，结果处直接命名新档位一次；只写本地术语或现象、让读者自己换算到“一阶/正式护卫/某身份”等，不算完全完成状态校准。** 暂时不重要的历史、制度、隐藏原因和完整空间结构后放。
- **关键后果的前提要在不可逆选择之前建立。** 如果后面会出现赔钱、失去资格、追杀、债务、奖励、关系破裂或其它重要后果，而这个后果依赖“这东西是谁的 / 值多少钱 / 这条规则会怎样处理 / 这个人为什么有权拦”等已批准公共事实，正文必须在角色做出不可逆动作前用最短一句让读者知道；这样后果到来时读者感到“果然”，而不是事后倒推“为什么”。不得借此补造上游没有的价格、制度或隐藏原因。
- 简单不等于空泛。仍然写具体动作、人物反应、冲突、态度、必要的环境感觉和结果，不要用“他很生气”“情况很危险”替代事件。先让读者理解，再保留少量有味道的描写。

## Story-bearing Texture：丰富不是修饰堆积

正文的丰富感优先来自承载故事的具体细节，而不是增加形容词、副词、泛化比喻或同义情绪解释。每个主要 beat 只选择少量真正改变读者画面的细节：具体动作、有功能的物件与空间位置、身体反馈、力量造成的可见后果、以及不同人物各自不同的反应。一个场景通常只需要最有辨识度的少量感官锚点，不机械覆盖视觉、听觉、嗅觉、触觉；力量感优先让别人、环境或可选行动发生变化，而不是只写“强大、恐怖、骇人”。修饰词和比喻只有在改变 POV 判断、人物关系或现场画面时才值得保留。不要为了“写得丰富”延长章节；没有承载人物、冲突、因果或幻想体验的细节应继续压缩。

朴素、直接不等于情绪中性。人物不是状态更新器：事件真实碰到人物的欲望、自尊、利益、恐惧、关系或期待时，允许自然出现高兴、害怕、恼火、不服、得意、尴尬、委屈、心虚、期待、失望、冲动或嘴硬等反应；不按清单覆盖，不机械增加情绪词，也不要为了避免情绪词改写成晦涩隐喻。情绪优先通过可见行为泄露：语气、说不说、动作快慢、视线、笑或忍笑、手的反应、嘴硬、装作不在乎，或一个本来不会做的短期选择。人物可以克制，但克制应表现为有反应后选择压住；不要默认人人立即看懂、接受和做最优决定，也不要为制造人味强行让人物犯蠢。

重大胜利、失败、羞辱、翻盘、资格、机会、关系突破、背叛、认可或资源到账等结果，不要只更新身份、关系或 Canon；当事件价值确实需要时，给最相关的一两个角色一个很短的反应窗口，再进入实际收益与下一步。同一结果不必让所有人有同一种反应，反应要来自各自当前在意的事。对话仍需服务信息、关系、选择或行动，但不必每句高效；嘲讽、抱怨、试探、嘴硬、笑，或一句只暴露态度的话，只要让人物更具体就有用。

当重大结果直接撞到角色的核心欲望、自尊、恐惧或期待时，默认允许出现一个可辨认的情绪倾向，不要只用疼痛、战术判断、看一眼或状态确认代替它。它可以很克制，仍通过动作、语气、注意力或选择表现；不要求每个角色、每章都有，也不要直接用强情绪标签。人物总体克制不等于无情绪：重大欲望兑现后，除非已有明确理由压住，至少让读者感到他确实在乎。**已批准的私人欲望也不要被正文自动净化。** 如果 Curated Context 明确带入身体吸引、审美、虚荣、钱、享受、偏心、嫉妒、好奇或其它私人牵引，而且当前场景自然触发它，就让 POV 至少通过一次注意力、身体反应、靠近/回避、想要或短期选择露出来；不要把这种牵引统一翻译成尊重边界、职责协作、成熟沟通或“正确但克制”的决定。没有自然触发时不硬塞，也不把情欲写成每次见面的固定标签。

- **Active Interior Continuity：重要配角带着自己的人生进入现场，不只带着任务。** 如果当前 Plan 已经保留某个重要人物此刻真正起作用的私人压力、旧关系或不愿承认的判断，正文至少让它改变一次说话方式、停顿、注意力、误判、拒绝/让步或选择。有限 POV 下不要直接偷写别人内心；可以由对方行为、对白长度与措辞、身体反应，以及主角对这些迹象的有限判断让读者感到“这个人下了戏还会继续生活”。不要把后台完整传记倾倒出来，也不要把所有人物都写成一句任务目标 + 一句功能对白。
- **Living Power Ecology 要在正文里真正约束行为。** 当前 Authority 若已经给重要人物明确精确位置/阶段身份，而且它解释现场分量，就在第一次自然比较、出手、让路、忌惮、封路或准入变化时直接用一次；不要因为这个人不是主角/主 Rival 就把数字藏回后台。一个明显高阶人物在场却不介入某场他有能力改变的冲突时，若 Plan 已给出目标/职责/空间/利益边界，用最短一句或行为把“不介入为什么合理”说清；上游没有原因时不自行补。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

写完关键动作或转折时，优先自问：第一次接触这个世界的普通读者快速读过，能不能立刻知道人物做了什么、为什么做、做成以后发生了什么？如果不能，先改清楚，再考虑增加文学性。

## 选择性因果与章节承接

只展开会改变人物选择、风险、能力差异或结果的关键因果节点。重点写为什么普通方法不行、主角发现了什么差异、他做了哪个决定、决定为什么有风险、结果具体改变了什么；重复搬运、普通走位、左右微调、完整受力过程、每一步碎石或火流变化、已经理解过的同一种能力执行步骤默认压缩。**决定已经做完后的普通实施默认一句或一个短段概括**；只有实施中重新出现新的选择、冲突、不确定性、失败风险或人物关系变化，才值得恢复成完整场景。若所谓“决定性动作”本身只是 Supporting Skill（修具、排车、绑缚、诊断、制作、计算等）为真正的人物/世界冲突服务，而该技能并非本书当前核心幻想，就写到“做了什么 → 为什么有效 → 结果怎样”即停，不把它再展开成一个需要逐步解决的小任务。因果清晰不等于完整模拟物理过程。

当 Curated Context 按当前 Plan 携带了已批准 World fact 时，用 1—3 个短的直接旁白段把读者此刻需要的世界模型补齐。普通 World Entry 通常遵循 **Action creates the question → Exposition answers just enough → Action continues**；但**开篇 Public Common Knowledge 不必先等动作提问**，可以在当前场景自然停顿处直接交代一组已经排程的公共常识。**已明确排程的 Reader Release 是本章需要落实的 timing decision，不是可有可无的装饰。** Writer 不负责从完整世界中选择还该介绍什么，只落实 Curator 已投影的事实；不得越过未知边界，也不得借世界说明重新打开已经成立的旧事实。对 `公共常识` Release，只有普通读者快速读过后能直接说出规则，才算兑现；仅靠环境细节、人物动作、专名、暗示或“看起来很特别”让读者自行归纳，不算已经说明。若 Reader Release 明确给出 named 势力 / 地点 / 身份的安全公开类别，正文第一次需要读者识别它时直接用普通话说清一次类别，不用外观、行为或上下文暗示代替这个基础答案；若同一 Release 还包含这个地点/势力/传承/价值物为什么值得强者争、为什么对当前主角位置有分量，也保留一个最短的**欲望/价值锚点**，不要只留下名称和危险。只有正文同一位置已经自然、明确传达了同一事实时才不重复说明。

“第一息 / 第二息 / 第三息”之类的微观计时，只在时间顺序本身影响成败时使用；普通动作不要为了显得精确而逐息书写。新章不要原样或近似复述上一章最后一句或最后一个动作来证明连续性；上一章已经建立的状态默认继续成立，新章从这个状态造成的下一个有意义变化进入。

1. 动作先于术语：第一次出现本书独有概念时，先让读者看见对象、动作和结果，再由人物用普通话形成理解；只有反复使用确实能减少解释时才固定命名。
2. 常见题材词可以自然使用；本书新造的机制、部件、阵法和抽象关系必须先通过场景成立，不要为了显得原创而给普通动作换名字。
3. 普通语言优先：能用“借力、卡住、撞开、绕过去、压下来、黏住、看见、躲开、把力量送过去”说清楚时，不默认升级成工程或审计术语。
4. 已经通过动作成立的边界只在发生新变化时更新，不连续用“不是、没有、尚未、并不、不代表、还不能算”重复证明旧边界。
5. 段落要有真实节拍变化；连续动作、观察或判断保持自然段，单句段留给冲击、决定、翻转、停顿、强烈反应和章末钩子。
6. 重大首次兑现先写结果、外界反应、主角实际收益和行动空间，再写必要的限制或代价；不要用三种同义表述同时削弱兑现。
7. 主角的判断要带着自己的经历、习惯、偏见、欲望、幽默或刻薄，不把人物写成通用的冷静正确男主。

9. 本章内具名的重要物品一旦明确换了持有人或位置，后文必须服从新的状态；只有正文再次写出转移动作时才能改变，不能无说明地回到旧状态。

准确机制仍须保留，但优先通过可见动作、直接结果、人物理解和后续选择让读者理解。

## World Power Normal → Power Asymmetry

这个世界的力量通常来自人与一头真实伴生兽的共同共鸣。普通驭兽者依靠训练、感官、熟练度和伙伴判断应对危险；即使是同层天才，也只能更快、更准地反应，不能确定下一次真正会击中自己的瞬间。

这个异常让持有者在每一次生死威胁中，看见一张即将发生的危险画面：攻击从哪里来、会落在哪里、伴生兽是否会被卷入。画面不会替人或伴生兽行动，但会给出一次真正的先手改动作窗口。

Privilege Delta 在于：同层普通人最多凭经验猜测，高阶者也仍可能被陌生招式、盲区或突袭命中；持有者却能提前知道一次最关键的失手点。即使面对更高共鸣级的攻击，也可能躲过、反抢一步、夺走目标或逃出生路，但不会因此抹掉对方在力量、速度、范围和持续力上的整体优势。

## Growth Compatibility

### 正常成长耦合｜Growth Coupling

普通人卡在：危险训练不能无限试错，一次判断错误就可能造成肺伤、骨裂、失衡或伴生兽内伤；受伤后双方又必须共同恢复，导致训练周期被迫中断。

这个优势改变的是“实战反馈与高风险训练”这一环。持有者能提前看见一次真正会造成伤害的关键瞬间，从而更接近当前承受边界训练，而不是因为一次误判直接停训。

### 异常掌握轴

掌握从“危险发生前被动看见”成长为：

- 更准确地抓住真正会改变生死的那一瞬；
- 画面更清楚，能让人更快向伴生兽发出信号；
- 在混乱战场中仍能把这一次预警兑现成实际闪避、抢位或反击；
- 让这一次窗口适用于更快、更复杂、更危险的共同动作。

它始终是一个危险瞬间，不会变成连续预知、完整战局推演或自动战斗。

### High-Tier Mutation

公共里程碑仍属于所有正常修炼者。持有者只是让同一个公共动词出现特殊版本：

- 到“借势”时，能提前看见力量回流即将失控的那个瞬间，及时改掉传力动作。
- 到“分作”时，能在双方各自行动时提前看见其中一方将被击中的关键画面。

- 到“定岛”时，也只能看见一次浮骨、锚链或风脉即将断裂的危险瞬间，不能因此直接获得定岛力量。

### 永久边界

一次连续的生死威胁，只能提前看见一个关键危险瞬间。

它不能展示危险的完整原因、后续连锁，也不能连续告诉持有者每一步该怎么走。当前共鸣级仍决定看见之后是否来得及移动、是否承受得住落点，以及伴生兽能否完成对应动作。

## 普通人的生活与上升

世界由数千座浮空岛组成。岛屿依靠地下生长的浮骨悬在高空，浮骨持续改变周围气流，因此岛与岛之间并非固定相邻。低空有平稳风层，外出主要靠索桥、升降台、滑翔车和短程驭兽；跨越裂风层则需要受训修士、商队或军府护航。普通人不能独自穿越危险风层，掉出航路通常意味着失温、失压、撞击或被空兽捕食。

大多数人依靠农田、风苔园、浮骨矿、养兽场、索桥工坊和岛间贸易生活。伴生兽不是战斗工具，也承担耕作、载货、警戒、取暖、攀行和寻找气流等工作。没有伴生兽的人也能锻炼身体、学习兵器或成为工匠，但无法进入真正的共鸣修炼。

年轻人通常在十二至十六岁间进入当地的伴生所，接受基础体检、风层适应和伴生兽相处训练。有人与家族幼兽共同长大，有人从养兽场、救助群或宗门获得伙伴，也有人终身没有合适的共鸣对象。

失败者通常不会被简单淘汰：他们可能成为驭兽师、兽医、风路测绘员、锚匠、商队护卫或岛下采集者。强行压迫伴生兽会造成短暂而危险的力量暴涨，却很容易导致共鸣反噬、伙伴逃离或双方永久伤残，因此大多数社会规则都不承认这种方式是真正的修炼。

## 力量体系与正常值

力量来自人与真实伴生兽之间的共同共鸣。伴生兽体内有储存和释放力量的共鸣腔，人身则逐渐形成能够承受这种力量的应脉；力量会在双方身体之间往返，也能短暂流入正在共同使用的兵器或载具。

伴生兽始终拥有自己的身体、习性、判断和行动。人可以发出信号、改变节奏、承担风险，但不能像操纵技能一样替伙伴凭空施放能力。不同伴生兽会带来不同的速度、感官、身体结构和战斗方式。

未入级的普通人只能使用普通工具，依靠伴生兽本身的力量行动。共鸣级1—20是普通驭兽者和基层护卫的范围；21—40足以成为成熟商队护卫、地方猎队成员或宗门正式弟子；41—60属于稀少的地方强者；61—80能独立进入危险风层并影响岛间交通；81以上的人极少，通常拥有改变一座岛、一道风路或一场战争局部结果的能力。

同一主尺上的差距真实影响力量总量、身体承受、双方反应、同步稳定性、作用距离、持续时间和可进入的风层。兵器、环境、熟练度和物种克制可以造成受伤、失手、夺物或逃生，但不能凭空抹掉高阶者在身体、速度、范围和持续力上的全部基础优势。

### 正常成长因果｜Power Growth Causality

力量来源：力量真正来自伴生兽的生命活动、食物与风压储能，最后进入伴生兽的共鸣腔、人身应脉以及双方共同使用的器物。

普通人怎样变强：修炼者每天会和伴生兽进行负重奔行、攀岩、风层穿行、节奏变换、短距离爆发、兵器配合和受伤后的恢复训练；同时要照料伙伴、调整食谱、观察换毛或生长期，不能只靠人单方面打坐。

有效成长怎样发生：双方反复承受略高于当前稳定范围的真实负荷，在不撕裂应脉和共鸣腔的前提下完成力量传递、急停、转向、承载和连续行动。等同一种动作能在不同风向、不同疲劳程度下稳定复现，精确位置才会前进。

为什么不会人人快速升级：人的应脉和伴生兽的共鸣腔必须同时恢复；一方先变强会造成另一方承受不了。高风层训练容易造成肺伤、骨裂、失衡和伙伴内伤，风髓补给与安全训练场都很昂贵。多数人一年苦练后，只能在同一档位内提高稳定性，不能自动跨过身体和同步瓶颈。

速度 / 上限怎样被改变：

- 天赋改变应脉形成速度、身体承压和与某类伴生兽的初始适配。
- 功法改变呼吸、步法、信号和力量回流方式，主要影响损耗与突破速度。
- 资源改变恢复、伴生兽成长和器物承载，不会直接替代双方适应。
- 际遇可能让人接触罕见风层、成熟兽群、古老训练法或高品质风髓，从而改变上限或突破条件。

## 普通人的生活与上升

世界由数千座浮空岛组成。岛屿依靠地下生长的浮骨悬在高空，浮骨持续改变周围气流，因此岛与岛之间并非固定相邻。低空有平稳风层，外出主要靠索桥、升降台、滑翔车和短程驭兽；跨越裂风层则需要受训修士、商队或军府护航。普通人不能独自穿越危险风层，掉出航路通常意味着失温、失压、撞击或被空兽捕食。

大多数人依靠农田、风苔园、浮骨矿、养兽场、索桥工坊和岛间贸易生活。伴生兽不是战斗工具，也承担耕作、载货、警戒、取暖、攀行和寻找气流等工作。没有伴生兽的人也能锻炼身体、学习兵器或成为工匠，但无法进入真正的共鸣修炼。

年轻人通常在十二至十六岁间进入当地的伴生所，接受基础体检、风层适应和伴生兽相处训练。有人与家族幼兽共同长大，有人从养兽场、救助群或宗门获得伙伴，也有人终身没有合适的共鸣对象。

失败者通常不会被简单淘汰：他们可能成为驭兽师、兽医、风路测绘员、锚匠、商队护卫或岛下采集者。强行压迫伴生兽会造成短暂而危险的力量暴涨，却很容易导致共鸣反噬、伙伴逃离或双方永久伤残，因此大多数社会规则都不承认这种方式是真正的修炼。

## 力量体系与正常值

力量来自人与真实伴生兽之间的共同共鸣。伴生兽体内有储存和释放力量的共鸣腔，人身则逐渐形成能够承受这种力量的应脉；力量会在双方身体之间往返，也能短暂流入正在共同使用的兵器或载具。

伴生兽始终拥有自己的身体、习性、判断和行动。人可以发出信号、改变节奏、承担风险，但不能像操纵技能一样替伙伴凭空施放能力。不同伴生兽会带来不同的速度、感官、身体结构和战斗方式。

未入级的普通人只能使用普通工具，依靠伴生兽本身的力量行动。共鸣级1—20是普通驭兽者和基层护卫的范围；21—40足以成为成熟商队护卫、地方猎队成员或宗门正式弟子；41—60属于稀少的地方强者；61—80能独立进入危险风层并影响岛间交通；81以上的人极少，通常拥有改变一座岛、一道风路或一场战争局部结果的能力。

同一主尺上的差距真实影响力量总量、身体承受、双方反应、同步稳定性、作用距离、持续时间和可进入的风层。兵器、环境、熟练度和物种克制可以造成受伤、失手、夺物或逃生，但不能凭空抹掉高阶者在身体、速度、范围和持续力上的全部基础优势。

### 正常成长因果｜Power Growth Causality

力量来源：力量真正来自伴生兽的生命活动、食物与风压储能，最后进入伴生兽的共鸣腔、人身应脉以及双方共同使用的器物。

普通人怎样变强：修炼者每天会和伴生兽进行负重奔行、攀岩、风层穿行、节奏变换、短距离爆发、兵器配合和受伤后的恢复训练；同时要照料伙伴、调整食谱、观察换毛或生长期，不能只靠人单方面打坐。

有效成长怎样发生：双方反复承受略高于当前稳定范围的真实负荷，在不撕裂应脉和共鸣腔的前提下完成力量传递、急停、转向、承载和连续行动。等同一种动作能在不同风向、不同疲劳程度下稳定复现，精确位置才会前进。

为什么不会人人快速升级：人的应脉和伴生兽的共鸣腔必须同时恢复；一方先变强会造成另一方承受不了。高风层训练容易造成肺伤、骨裂、失衡和伙伴内伤，风髓补给与安全训练场都很昂贵。多数人一年苦练后，只能在同一档位内提高稳定性，不能自动跨过身体和同步瓶颈。

速度 / 上限怎样被改变：

- 天赋改变应脉形成速度、身体承压和与某类伴生兽的初始适配。
- 功法改变呼吸、步法、信号和力量回流方式，主要影响损耗与突破速度。
- 资源改变恢复、伴生兽成长和器物承载，不会直接替代双方适应。
- 际遇可能让人接触罕见风层、成熟兽群、古老训练法或高品质风髓，从而改变上限或突破条件。

## 力量体系与正常值

力量来自人与真实伴生兽之间的共同共鸣。伴生兽体内有储存和释放力量的共鸣腔，人身则逐渐形成能够承受这种力量的应脉；力量会在双方身体之间往返，也能短暂流入正在共同使用的兵器或载具。

伴生兽始终拥有自己的身体、习性、判断和行动。人可以发出信号、改变节奏、承担风险，但不能像操纵技能一样替伙伴凭空施放能力。不同伴生兽会带来不同的速度、感官、身体结构和战斗方式。

未入级的普通人只能使用普通工具，依靠伴生兽本身的力量行动。共鸣级1—20是普通驭兽者和基层护卫的范围；21—40足以成为成熟商队护卫、地方猎队成员或宗门正式弟子；41—60属于稀少的地方强者；61—80能独立进入危险风层并影响岛间交通；81以上的人极少，通常拥有改变一座岛、一道风路或一场战争局部结果的能力。

同一主尺上的差距真实影响力量总量、身体承受、双方反应、同步稳定性、作用距离、持续时间和可进入的风层。兵器、环境、熟练度和物种克制可以造成受伤、失手、夺物或逃生，但不能凭空抹掉高阶者在身体、速度、范围和持续力上的全部基础优势。

### 正常成长因果｜Power Growth Causality

力量来源：力量真正来自伴生兽的生命活动、食物与风压储能，最后进入伴生兽的共鸣腔、人身应脉以及双方共同使用的器物。

普通人怎样变强：修炼者每天会和伴生兽进行负重奔行、攀岩、风层穿行、节奏变换、短距离爆发、兵器配合和受伤后的恢复训练；同时要照料伙伴、调整食谱、观察换毛或生长期，不能只靠人单方面打坐。

有效成长怎样发生：双方反复承受略高于当前稳定范围的真实负荷，在不撕裂应脉和共鸣腔的前提下完成力量传递、急停、转向、承载和连续行动。等同一种动作能在不同风向、不同疲劳程度下稳定复现，精确位置才会前进。

为什么不会人人快速升级：人的应脉和伴生兽的共鸣腔必须同时恢复；一方先变强会造成另一方承受不了。高风层训练容易造成肺伤、骨裂、失衡和伙伴内伤，风髓补给与安全训练场都很昂贵。多数人一年苦练后，只能在同一档位内提高稳定性，不能自动跨过身体和同步瓶颈。

速度 / 上限怎样被改变：

- 天赋改变应脉形成速度、身体承压和与某类伴生兽的初始适配。
- 功法改变呼吸、步法、信号和力量回流方式，主要影响损耗与突破速度。
- 资源改变恢复、伴生兽成长和器物承载，不会直接替代双方适应。
- 际遇可能让人接触罕见风层、成熟兽群、古老训练法或高品质风髓，从而改变上限或突破条件。

## 社会现实与身份

岛城以浮根、锚台和风路为核心建立。小岛依靠家族、养兽场和地方行会维持生活；大岛则由王庭、宗门、商盟和军府共同争夺航线、浮骨矿和高层风口。

## 普通人的生活与上升

世界由数千座浮空岛组成。岛屿依靠地下生长的浮骨悬在高空，浮骨持续改变周围气流，因此岛与岛之间并非固定相邻。低空有平稳风层，外出主要靠索桥、升降台、滑翔车和短程驭兽；跨越裂风层则需要受训修士、商队或军府护航。普通人不能独自穿越危险风层，掉出航路通常意味着失温、失压、撞击或被空兽捕食。

大多数人依靠农田、风苔园、浮骨矿、养兽场、索桥工坊和岛间贸易生活。伴生兽不是战斗工具，也承担耕作、载货、警戒、取暖、攀行和寻找气流等工作。没有伴生兽的人也能锻炼身体、学习兵器或成为工匠，但无法进入真正的共鸣修炼。

年轻人通常在十二至十六岁间进入当地的伴生所，接受基础体检、风层适应和伴生兽相处训练。有人与家族幼兽共同长大，有人从养兽场、救助群或宗门获得伙伴，也有人终身没有合适的共鸣对象。

失败者通常不会被简单淘汰：他们可能成为驭兽师、兽医、风路测绘员、锚匠、商队护卫或岛下采集者。强行压迫伴生兽会造成短暂而危险的力量暴涨，却很容易导致共鸣反噬、伙伴逃离或双方永久伤残，因此大多数社会规则都不承认这种方式是真正的修炼。

## 力量体系与正常值

力量来自人与真实伴生兽之间的共同共鸣。伴生兽体内有储存和释放力量的共鸣腔，人身则逐渐形成能够承受这种力量的应脉；力量会在双方身体之间往返，也能短暂流入正在共同使用的兵器或载具。

伴生兽始终拥有自己的身体、习性、判断和行动。人可以发出信号、改变节奏、承担风险，但不能像操纵技能一样替伙伴凭空施放能力。不同伴生兽会带来不同的速度、感官、身体结构和战斗方式。

未入级的普通人只能使用普通工具，依靠伴生兽本身的力量行动。共鸣级1—20是普通驭兽者和基层护卫的范围；21—40足以成为成熟商队护卫、地方猎队成员或宗门正式弟子；41—60属于稀少的地方强者；61—80能独立进入危险风层并影响岛间交通；81以上的人极少，通常拥有改变一座岛、一道风路或一场战争局部结果的能力。

同一主尺上的差距真实影响力量总量、身体承受、双方反应、同步稳定性、作用距离、持续时间和可进入的风层。兵器、环境、熟练度和物种克制可以造成受伤、失手、夺物或逃生，但不能凭空抹掉高阶者在身体、速度、范围和持续力上的全部基础优势。

### 正常成长因果｜Power Growth Causality

力量来源：力量真正来自伴生兽的生命活动、食物与风压储能，最后进入伴生兽的共鸣腔、人身应脉以及双方共同使用的器物。

普通人怎样变强：修炼者每天会和伴生兽进行负重奔行、攀岩、风层穿行、节奏变换、短距离爆发、兵器配合和受伤后的恢复训练；同时要照料伙伴、调整食谱、观察换毛或生长期，不能只靠人单方面打坐。

有效成长怎样发生：双方反复承受略高于当前稳定范围的真实负荷，在不撕裂应脉和共鸣腔的前提下完成力量传递、急停、转向、承载和连续行动。等同一种动作能在不同风向、不同疲劳程度下稳定复现，精确位置才会前进。

为什么不会人人快速升级：人的应脉和伴生兽的共鸣腔必须同时恢复；一方先变强会造成另一方承受不了。高风层训练容易造成肺伤、骨裂、失衡和伙伴内伤，风髓补给与安全训练场都很昂贵。多数人一年苦练后，只能在同一档位内提高稳定性，不能自动跨过身体和同步瓶颈。

速度 / 上限怎样被改变：

- 天赋改变应脉形成速度、身体承压和与某类伴生兽的初始适配。
- 功法改变呼吸、步法、信号和力量回流方式，主要影响损耗与突破速度。
- 资源改变恢复、伴生兽成长和器物承载，不会直接替代双方适应。
- 际遇可能让人接触罕见风层、成熟兽群、古老训练法或高品质风髓，从而改变上限或突破条件。
- `风构师`是可自然长出的副道路：他们与岩背兽、牵风兽等伙伴共同修复浮骨、重接锚索、改变岛屿漂移方向。顶层风构师未必擅长杀人，却能完成让一座下沉岛重新稳定、让断裂航路重新开放的工程，社会地位和价格都高于普通战斗护卫。

## 普通人的生活与上升

世界由数千座浮空岛组成。岛屿依靠地下生长的浮骨悬在高空，浮骨持续改变周围气流，因此岛与岛之间并非固定相邻。低空有平稳风层，外出主要靠索桥、升降台、滑翔车和短程驭兽；跨越裂风层则需要受训修士、商队或军府护航。普通人不能独自穿越危险风层，掉出航路通常意味着失温、失压、撞击或被空兽捕食。

大多数人依靠农田、风苔园、浮骨矿、养兽场、索桥工坊和岛间贸易生活。伴生兽不是战斗工具，也承担耕作、载货、警戒、取暖、攀行和寻找气流等工作。没有伴生兽的人也能锻炼身体、学习兵器或成为工匠，但无法进入真正的共鸣修炼。

年轻人通常在十二至十六岁间进入当地的伴生所，接受基础体检、风层适应和伴生兽相处训练。有人与家族幼兽共同长大，有人从养兽场、救助群或宗门获得伙伴，也有人终身没有合适的共鸣对象。

失败者通常不会被简单淘汰：他们可能成为驭兽师、兽医、风路测绘员、锚匠、商队护卫或岛下采集者。强行压迫伴生兽会造成短暂而危险的力量暴涨，却很容易导致共鸣反噬、伙伴逃离或双方永久伤残，因此大多数社会规则都不承认这种方式是真正的修炼。

## 力量体系与正常值

力量来自人与真实伴生兽之间的共同共鸣。伴生兽体内有储存和释放力量的共鸣腔，人身则逐渐形成能够承受这种力量的应脉；力量会在双方身体之间往返，也能短暂流入正在共同使用的兵器或载具。

伴生兽始终拥有自己的身体、习性、判断和行动。人可以发出信号、改变节奏、承担风险，但不能像操纵技能一样替伙伴凭空施放能力。不同伴生兽会带来不同的速度、感官、身体结构和战斗方式。

未入级的普通人只能使用普通工具，依靠伴生兽本身的力量行动。共鸣级1—20是普通驭兽者和基层护卫的范围；21—40足以成为成熟商队护卫、地方猎队成员或宗门正式弟子；41—60属于稀少的地方强者；61—80能独立进入危险风层并影响岛间交通；81以上的人极少，通常拥有改变一座岛、一道风路或一场战争局部结果的能力。

同一主尺上的差距真实影响力量总量、身体承受、双方反应、同步稳定性、作用距离、持续时间和可进入的风层。兵器、环境、熟练度和物种克制可以造成受伤、失手、夺物或逃生，但不能凭空抹掉高阶者在身体、速度、范围和持续力上的全部基础优势。

### 正常成长因果｜Power Growth Causality

力量来源：力量真正来自伴生兽的生命活动、食物与风压储能，最后进入伴生兽的共鸣腔、人身应脉以及双方共同使用的器物。

普通人怎样变强：修炼者每天会和伴生兽进行负重奔行、攀岩、风层穿行、节奏变换、短距离爆发、兵器配合和受伤后的恢复训练；同时要照料伙伴、调整食谱、观察换毛或生长期，不能只靠人单方面打坐。

有效成长怎样发生：双方反复承受略高于当前稳定范围的真实负荷，在不撕裂应脉和共鸣腔的前提下完成力量传递、急停、转向、承载和连续行动。等同一种动作能在不同风向、不同疲劳程度下稳定复现，精确位置才会前进。

为什么不会人人快速升级：人的应脉和伴生兽的共鸣腔必须同时恢复；一方先变强会造成另一方承受不了。高风层训练容易造成肺伤、骨裂、失衡和伙伴内伤，风髓补给与安全训练场都很昂贵。多数人一年苦练后，只能在同一档位内提高稳定性，不能自动跨过身体和同步瓶颈。

速度 / 上限怎样被改变：

- 天赋改变应脉形成速度、身体承压和与某类伴生兽的初始适配。
- 功法改变呼吸、步法、信号和力量回流方式，主要影响损耗与突破速度。
- 资源改变恢复、伴生兽成长和器物承载，不会直接替代双方适应。
- 际遇可能让人接触罕见风层、成熟兽群、古老训练法或高品质风髓，从而改变上限或突破条件。
- `风构师`是可自然长出的副道路：他们与岩背兽、牵风兽等伙伴共同修复浮骨、重接锚索、改变岛屿漂移方向。顶层风构师未必擅长杀人，却能完成让一座下沉岛重新稳定、让断裂航路重新开放的工程，社会地位和价格都高于普通战斗护卫。

### 半页旧契

贺临川回到家时，已经是傍晚。

他的左手肘肿得发亮，外套背后又多了一道裂口。照雪更惨，前腿的旧伤裂开，白毛上全是干掉的苔汁。

贺母看到他们，先是愣住，随后把汤勺往锅里一插。

“你们又去跳桥了？”

“这回没桥。”

“那你怎么比昨天还像从桥底捞出来的？”

贺临川没法解释段阙，只把半页旧契放到桌上。

贺母看见商盟契纸，脸色顿时沉了。

“他们来过？”

“来了。”

“你还把东西抢回来了？”

“算是。”

贺母盯着他，半天没说话。照雪站在门边，鼻尖对着桌上的契纸，一动不动。

屋里很小，父亲躺在隔帘后面咳了一声。那一声很轻，却让贺临川肩膀僵了僵。

贺母拿起契纸，借着灯火看上面的字。

“鸣骨峡。”

“嗯。”

“你想去？”

“照雪想去。”

“它想去，你就去？”贺母把契纸拍在桌上，“商盟在找它，那个共鸣级二十六的人也在找它。你刚进引脉，连短程风路都还没走稳。”

贺临川低头给照雪拆开脏掉的布条。

伤口边缘发红，照雪疼得缩了一下，却没有躲。

他想起段阙说的赔偿。

想起母亲问那头兽值多少钱。

旧铜扣没了，外套也快不能穿。商盟要是肯出钱，他家能过得松快些。再攒一阵，也许能买一张跟商队走的低价票，去姐姐明信片里写过的外岛。

可照雪的耳朵一直朝西北方向偏着。

它已经不是笼子里的货。

至少现在，它会在断桥上自己跳出来，会在钩翼兽扑来的时候咬住段阙的手，会在风苔里带着他找路。

贺临川把新布条绕过它的前腿，打了个结。

“我不是为了它想去。”他说。

贺母看着他。

“那你为了什么？”

贺临川把契纸展开，指着那块沉瓦似的墨印。

“这东西跟照雪有关。商盟要带它去哪里，苏渠是谁，段阙为什么非得追回来，都在这条路上。”

“知道了又怎么样？”

“至少我不想坐在这儿，等他们下次把它塞回笼子。”

贺母嘴唇动了动。

“别当我是准你出岛。”她的声音很硬，“你只是去鸣骨峡看一眼，天亮前不回来，我就去伴生所找人。”

贺临川伸手去收契纸。

贺母先按住他的手。

“还有一件事。你带着照雪，不许替它答应任何契。它要回来，你带回来；它要跑，你追不上也别把自己搭进去。”

照雪抬头看着她。

贺母把剩下的一点风苔汤倒进碗里，推到它面前。

照雪闻了闻，伸舌头舔了一口。

贺临川忍不住笑了。

“它挑嘴。”

“那是你煮得难吃。”贺母瞪他，“明天路上少喂它乱七八糟的东西。”

夜里，贺临川没有去睡。

他把撬刀和半页旧契收进一个旧皮袋，又把外套破口用粗线缝住。铜扣的位置空着，缝线乱七八糟，怎么看都不顺眼。
