# Proposed Chapter Summary

唐鹭提出以完整航契和商队座位换取照雪同行，承诺不强迫它接受。贺临川拒绝替照雪答应契约。风门深处传来短促回应，照雪随即冲入即将关闭的风门；段阙重新锁紧副链，贺临川放弃返程线，沿断索追下。
