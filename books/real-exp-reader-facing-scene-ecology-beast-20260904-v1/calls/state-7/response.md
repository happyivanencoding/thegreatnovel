在场人物：贺临川、照雪、唐鹭、段阙、韩狩、叶朔、商盟伙计、褐背大兽、钩翼兽、灰冠兽群。

下一步直接目标：在副链与交易台继续坠落前保护照雪和兽群，决定是否接受唐鹭带离峡谷的条件。

### Identity / Access

贺临川与照雪仍按共鸣级1临时登记；韩狩已以裂云军府身份接管现场调查。

### Knowledge / Enemy State

唐鹭持有完整航契，并提出以商队座位换取照雪同行与贺临川交出契纸。

### World State

裂云军府正式介入鸣骨峡旧风门现场；交易台因乱风与副链拉扯开始塌陷，返程线与迁徙通道同时面临失稳。

# Proposed Chapter Summary

裂云军府的韩狩以越风能力撑开返程线，并查问镇脉钉旧案。交易台在副链与乱风拉扯下塌陷，唐鹭凭载身能力救下货箱，随后提出用完整航契和商队座位换取照雪同行与半页旧契。贺临川没有立即答应。
