# HUMAN CANDIDATE 1｜沈砚舟／不肯把离开当作结局

## 世界中的初始位置与成长环境

出生在东部河网一处渡口镇。父亲替商队摆渡，母亲经营一间只接散客的小客舍。家里不算贫穷，却常年没有稳定积蓄：水期好时赚得多，商路改道或妖兽出没时，整季收入都会落空。

他从小见惯了客人临时改口、商队拖欠船钱、亲戚借走东西后再也不提。父亲有一次冬季摆渡后没有回来，尸身和船都没找到。家里没有真正的葬礼，母亲只能把他的衣物收进箱子，继续经营客舍。

## Formative Facts → Adaptation → Observable Behavior

- 许多离开都没有正式告别，也没有人承担最后一句话的后果。  
  → 他把“未完成”视为一种危险。  
  → 听到含糊承诺时会追问时间、地点和具体交付物；别人说“以后再说”，他会记在心里。

- 母亲靠等候、记账和重复确认维持客舍。  
  → 他相信关系不是靠誓言维持，而是靠一次次回来。  
  → 会为远行的人留下一件小东西，要求对方回来时带回；自己离开前，也总要把手边的事交代清楚。

- 父亲的失踪没有答案，家里人逐渐学会不再谈论。  
  → 他不接受“大家都习惯了”作为结论。  
  → 会主动寻找被人放弃的线索，却不一定公开自己的目的；他更在意事情是否仍有回头的可能。

## Core Obsession

他真正想要的不是成功，也不是名声，而是“离开的人仍然有地方可回”。

他会反复寻找一张有人等他吃饭的桌子，也会为了保住一次具体的相聚，放弃看起来更有利的安排。这个牵引可以随着人生改变形态：少年时是等父亲，后来是守住母亲的客舍，再后来可能变成确认某些人没有被世界悄悄抹掉。

## Excess

普通人觉得一家人还能过日子、旧事不必再提，就已经够了。

他却会继续追问那艘没有回来的船、那笔没有结清的钱、那句没有说完的话。即使事情已经无法改变，他仍想知道它究竟在哪里断掉。

## Behavior Signature

他总会给重要的人留下一个可以兑现的小约定，并观察对方是否回来兑现。

他处理问题时倾向于：

- 先确认谁还可能回来；
- 把模糊关系变成一次具体见面；
- 为自己保留一条能回去的路；
- 在别人准备翻篇时，重新捡起被放下的细节。

但他不固定使用温和方式。有时会耐心等候，有时会故意逼人当面说清楚，有时会突然离开，让对方体验一次真正的失去。

## 重要关系原点

他与母亲之间既亲近又彼此怨怼。

母亲靠“不再寻找”活了下来，沈砚舟却把这种活法看成对父亲的放弃。母亲希望他留在渡口，继承客舍；他认为留下只是把等待变成习惯。

两个人都没有真正说过：如果父亲当年回来，他们原本想过怎样的生活。

## Initial State Seed

### 当前私人欲望

在母亲彻底卖掉客舍之前，带她坐一次不载货的船，沿河走到她年轻时从未去过的地方。

## Audition Metadata（非 Canon）

### 人物钩子

他在一间外地客舍里看见一枚旧渡牌，背面刻着父亲当年惯用的记号。

# HUMAN CANDIDATE 2｜顾临川／一定要听见真话

## 世界中的初始位置与成长环境

出生在一座商路城镇的中等商户家庭。家里经营符纸、药材和护送契约，能够供他识字、学习算账，也请得起低阶修士教他辨认灵材。

他的父亲擅长谈判，家中遇到任何冲突，都会先写契约、谈条件、留后手。家人很少直接说“我想要什么”，更多时候说“这对大家都好”。

少年时，他的兄长因一次商路亏损被送去外地处理债务。家里对外说只是历练，对内却逐渐不再提起。顾临川曾写过许多封信，却没有一封真正寄出去。

## Formative Facts → Adaptation → Observable Behavior

- 家里人习惯用体面话掩盖真实交换。  
  → 他逐渐认为没有被说出口的欲望，最终一定会以更难看的方式出现。  
  → 会在谈判中主动问“你真正不愿意失去的是什么”，也会逼亲近的人说出不体面的要求。

- 他看见契约可以保护人，也可以把责任切割得干干净净。  
  → 他不把文字本身当作诚实证明。  
  → 签约前会观察对方是否愿意在旁人面前重复关键条款；若对方只肯私下承诺，他反而提高警惕。

- 兄长被家族从日常叙述中抹掉。  
  → 他对“大家都不提”极其敏感。  
  → 会记住被删去的人名、被改写的经过，以及每个人在某个问题上的停顿。

## Core Obsession

他想亲眼看见一个人承认自己真正想要的东西。

不是为了控制别人，也不是为了建立权威。他享受的是那一刻：一个人终于停止说正确的话，把真实愿望摆到桌面上。

这种牵引会进入他的友情、亲情和敌对关系。即使没有任何外力，他也可能为了让某个人当面说一句真话，主动承担关系破裂的风险。

## Excess

普通人觉得维持表面和平、让事情先过去，已经是成熟。

他却无法接受一段关系靠共同装作没发生过来维持。事情越重要，他越要把人拉到现场，让每个人听见同一件事。

## Behavior Signature

他习惯把抽象矛盾变成一次面对面的具体场景：

- 把两封互相矛盾的信放在同一张桌上；
- 要求对方重新说一遍刚才的话；
- 用一个很小的请求测试对方是否愿意承担真实代价；
- 在对话快要结束时，问出那个最不合时宜的问题。

他并不总是直截了当。有时会用玩笑诱导，有时故意保持沉默，有时先承认自己的难堪，让对方失去继续伪装的台阶。

## 重要关系原点

他与失踪多年的兄长之间，留下了一种没有被确认的亲情。

兄长离家前曾答应给他带回一件很普通的东西，但家里后来禁止再谈这件事。顾临川不知道兄长是主动断联、遭遇意外，还是根本不想回来。

他真正不能放下的，不只是兄长的下落，而是家里所有人都默认这件事已经结束。

## Initial State Seed

### 当前私人欲望

在下一次家族聚餐前，找到兄长留下的一封未寄出的信，并亲手把它送到兄长可能出现的地方。

## Audition Metadata（非 Canon）

### 人物钩子

家族准备签下一份人人都说“没有问题”的契约，他发现最后一页少了一个人的名字。

# HUMAN CANDIDATE 3｜裴照野／把无用之物做到最好

## 世界中的初始位置与成长环境

出生在西部山地的矿镇。父亲是矿场领班，母亲负责分拣灵矿和照料矿工家属。家里收入比普通矿工稳定，但身份始终依附矿场，任何一次矿脉枯竭或领主更换，都可能让全家重新寻找生计。

他从小接触矿石、木料和废弃器具。矿场只看产量，家里只看能不能换钱。一个哥哥曾经喜欢雕刻矿石，却因为几年没有赚到钱，最后放弃了。

## Formative Facts → Adaptation → Observable Behavior

- 许多东西只要“能用”就会被留下，稍微不合标准便被丢弃。  
  → 他开始把被忽略的细节视为一种私人尊严。  
  → 会修补别人认为不值得修的东西，也会记住一件器物原本的纹理、重量和缺口。

- 父亲习惯用产量判断一个人的价值。  
  → 他不愿让自己的满足完全依赖别人认可。  
  → 做事时常常先给自己设一个无人知道的标准；别人夸他时，他未必高兴，别人没看见时，他也会继续做。

- 哥哥因为“没有用”而放弃雕刻。  
  → 他对半途而废既鄙视又恐惧。  
  → 一旦决定完成某件事，会在已经足够好的地方继续修改，直到它失去原来的实用性。

## Core Obsession

他迷恋“只有自己知道它已经变好了”的瞬间。

可能是一块废石被磨出恰好的纹路，一把旧刀重新落在手里时不再偏斜，也可能是某个被所有人忽略的人终于被他准确看见。

这不是事业追求，也不必发展成工匠权威。它更像一种私人确认：世界可以不承认，但他知道自己没有敷衍。

## Excess

普通人觉得东西能用、日子能过、别人也认可，就已经够了。

他却会在无人奖励的地方继续修正。最危险的时候，他甚至可能为了保住一个微小而准确的结果，放弃更快、更安全、更有利的做法。

## Behavior Signature

他总会先找出别人忽略的那一道细缝，再决定自己要不要介入。

常见表现包括：

- 把废料翻过来重新看；
- 用手而不是眼睛确认器物是否合适；
- 在公开行动前私下重复一次；
- 对“差不多”产生身体上的不适；
- 不解释自己为什么坚持，直到结果已经无法否认。

他可以耐心修补，也可以突然砸掉一件已经完成的东西；可以独自完成，也可能故意把最关键的一步交给别人，看对方是否真的在意。

## 重要关系原点

他与哥哥之间没有真正的决裂。

哥哥离开矿镇前，把一块没有雕完的黑色矿石交给他，说“别替我做完”。裴照野一直没有碰最后几刀，却也没有把矿石还回去。

哥哥后来偶尔寄回钱，却从不问那块矿石。两个人都在等对方先承认：当年放弃的究竟是手艺，还是一种不愿再被生活评价的自己。

## Initial State Seed

### 当前私人欲望

在哥哥下一次可能回矿镇之前，把那块矿石磨到自己满意，但不替哥哥补上最后一道真正属于他的刻痕。

## Audition Metadata（非 Canon）

### 人物钩子

他在矿场废料堆里捡到一件被判定为报废的器物，发现它最关键的缺陷并不在器物本身。

# HUMAN CANDIDATE 4｜陆承安／不想过别人替他安排的人生

## 世界中的初始位置与成长环境

出生在中州一户拥有灵田、商铺和地方人脉的富裕家族。家族没有足以镇压一州的高阶修士，却能为子弟提供稳定的引灵试、入门功法、丹药和安全的师承选择。

他从小被安排得很好：住处有人打理，出行有人护送，犯错有人赔偿。家里人并不恶毒，甚至真心爱护他，只是所有人都认为“替他决定”就是保护。

他曾有一位年长的玩伴，出身于家族佃户。两人小时候一起在田间和集市上玩，后来家里给那人安排了一条更合适的差事。对方拒绝接受陆承安的帮助，也逐渐不再进宅院。

## Formative Facts → Adaptation → Observable Behavior

- 他的每一次选择都有人提前铺好代价。  
  → 他逐渐无法判断自己究竟喜欢什么，还是只是在接受最方便的选项。  
  → 会刻意选择没有人替他准备的路线，哪怕那条路更慢、更脏、更不体面。

- 家里人总能用钱和关系抹平后果。  
  → 他把“付出代价”看成确认选择属于自己的方式。  
  → 不喜欢欠人情，尤其不喜欢别人替他承担失败；但在真正想要的东西面前，又会冲动地接受不该接受的便利。

- 玩伴拒绝他的帮助后，两人的关系没有正式结束，也没有继续维持。  
  → 他对被照顾和被施舍之间的差别异常敏感。  
  → 送东西前会先问对方是否愿意收，却常常在对方拒绝后仍想办法靠近。

## Core Obsession

他想亲手触碰一种没有被家族安排过的生活。

不是为了证明自己比家里人高明，也不是为了抛弃财富。他想知道：如果没有熟人、护送、预先谈好的位置，他会如何吃饭、受伤、交朋友、做决定。

这种私人牵引会反复改变他的选择。即使已经获得更好的身份，他仍可能为了保留未经安排的体验，拒绝一条过于安全的上升路径。

## Excess

普通人觉得有现成的路可走、有人愿意替自己挡风险，就是幸运。

他却会不断把自己送进不熟悉的处境，直到“这是我自己选的”变成一种近乎执拗的证明。即使已经证明过一次，他仍不容易停下。

## Behavior Signature

他遇到重要选择时，往往先把问题变成一次亲身体验：

- 不先问价格，先去做一天最底层的活；
- 不先听别人描述，先走一遍那条路；
- 不借家族名号试着办一件小事；
- 明明可以被保护，却故意保留一个自己承担后果的部分。

但他不是稳定的苦行者。面对真正喜欢的人、食物、风景或新鲜事物，他也会毫不犹豫地花钱、享受，甚至用家族资源换取一次更远的体验。

## 重要关系原点

他与那位离开的玩伴之间，始终存在一场没有完成的交换。

陆承安曾送过对方一件昂贵的护身物，对方没有收，只说：“你每次伸手，都是在告诉我你站得比我高。”

陆承安当时没有反驳，也没有道歉。他只是把护身物收了回来。后来两人再见时，谁都没有问对方过得好不好。

## Initial State Seed

### 当前私人欲望

不用家族名号、不带护卫，独自走完一条普通商路，并用自己挣来的钱买下途中第一顿真正想吃的东西。

## Audition Metadata（非 Canon）

### 人物钩子

家族为他准备了一份人人称赞的身份凭证，他却先拿着它去做一件完全不需要凭证的小事。
