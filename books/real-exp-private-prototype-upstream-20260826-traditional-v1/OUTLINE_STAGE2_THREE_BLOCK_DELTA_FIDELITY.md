## 第14—18章：杂役名单之外

具体发生：陆回川必须在九檐山获得真正的修炼路径，否则就会被外门以“先做三年杂务、以后自然提拔”为名无限占用。

1. 外门各院争抢新招弟子做采药、守桥、搬运和抄录，管事以住处与基础功法为条件，要求陆回川接受没有期限的轮值；陆回川发现所谓“以后提拔”没有兑现标准，拒绝签下空头安排，只保留最低限度的入门杂务。管事将他列为“不服调度”的次等弟子，扣下部分修炼时辰，逼他另找出路。

2. 闻昭因家族已经替他安排王朝军职，必须夺得剑池名额；他看不起陆回川这种刚入山便讨价还价的人，主动以换桥试剑的名额相激。陆回川没有接受稳定杂务换功法的安排，转而报名风险更高的试剑，放弃了短期安全住处和院内照应。

3. 裴无尘一系把换桥试剑设计成高淘汰率筛选：考生既要赶在九檐石桥换向前抵达山门，又要完成途中各处临时剑令。陆回川用已经掌握的短暂分流，一股真元维持脚下微弱御气，另一股完成引火、照路等小术，勉强赶完全部节点，却因此被记录为“疑似旁门分术”。

4. 沈砚秋从试剑名册和万灯河救船记录中认出他，要求执事暂不取消资格；裴无尘则把他的异常列为必须在公开试剑中验证的风险。陆回川获得换桥试剑的正式名额，却也被放进了所有人都能观察、却没人愿意担保的名单，迫使他下一步在公开试剑中证明自己。

主要阅读兑现：主角第一次在宗门制度里拒绝成为“顺手的人”，并用已有的粗糙分流能力抢到一条真正能改变去处的竞争路径。

Block Delta：

- Identity / Access：陆回川从新招外门弟子变为换桥试剑正式考生，获得争取剑池名额的公开资格。
- Enemy State：裴无尘将他视为可能被公开验证、也可能被公开淘汰的异常样本。

推向下一块：换桥试剑已经开始，九檐石桥的转向会把陆回川与闻昭同时推入一场无法靠守规矩完成的生死选择。

## 第19—23章：桥转时先救谁

具体发生：陆回川必须在争夺唯一剑池名额与救下坠入剑气谷的闻昭之间作出不能撤回的选择，并让分流真元从一次偶然救援变成可继续修炼的道路。

1. 试剑开始后，闻昭凭家传剑术领先，陆回川则利用桥面转向规律和自身短暂分流追赶；裴无尘安排执事提前改变一座石桥的转向，使考生只能在抢先过桥和完成救援之间二选一。陆回川判断闻昭并非故意失足，而是被转桥甩出护栏，决定继续冲向终点，同时准备回身牵人。

2. 石桥骤转，闻昭坠入剑气谷；执事以“不得离开主桥线”为由阻止其他考生救援，裴无尘等待陆回川放弃对手。陆回川一股真元御剑追赶终点，另一股真元牵住闻昭，分流持续超过此前能够承受的时间；经脉剧痛、护身灵光不断破裂，他仍不收回牵引，最终带着闻昭撞上终点石台，自己只比第二名早半步。

3. 执事以违规分术和擅自改变考场路线要求取消成绩，沈砚秋当众指出救援本身符合试剑的生存判定，并确认他的分流不是外物寄生或旁门夺舍。闻昭获救后拒绝承认欠下人情，只说下次会凭自己赢回来；两人从陌生竞争者变成无法回避的对手。

4. 试剑后的经脉损伤使陆回川无法继续依赖粗暴二分。沈砚秋给他《九檐归元经》的正式行功路线，要求他先学会让两股真元有主次，而不是同时硬撑；陆回川拒绝以服役承诺换取速成资源，按公开传承重新完成循环，在复试前筑基成功。

5. 裴无尘没有阻止他的突破，反而将“救竞争者而险些失去第一”的事迹传遍外门，准备把他包装成开山派需要的样板。陆回川意识到自己已经无法只靠赢一场试剑解决处境，必须在下一场公开安排中决定别人能否替他命名。

主要阅读兑现：换桥试剑把“同时行动”的能力变成清晰可见的生死选择；陆回川救下对手、险胜并完成筑基，真正获得了继续向远处走的力量基础。

Block Delta：

- Power / Capability：陆回川筑基成功，能够主动调整两股真元的强弱，并在御剑过程中施展另一门法术。
- Relationship：闻昭从竞争者变成不肯承认欠命的长期对手。
- Possession：陆回川获得《九檐归元经》前四境的正式传承。
- Enemy State：裴无尘确认陆回川会为了具体的人放弃规则上的最优胜负，开始准备利用这一点。

推向下一块：陆回川已经被证明有资格继续修炼，但裴无尘把他的救人选择变成了开山派的宣传材料；最后的公开评定将决定他是成为可被占用的亲随，还是以自己的名字进入内门。

## 第24—28章：不签没有期限的名字

具体发生：陆回川必须在公开试剑中赢得宗门承认，同时拒绝把这份承认兑换成沈砚秋的无限期私属门人身份。

1. 裴无尘调整公开试剑的对手与场地，让陆回川连续面对需要御剑、挡击和维持落脚点的复合考验；闻昭主动要求与他最后对战，既要夺剑池名额，也要证明自己不是被他顺手救下的人。陆回川不再平均分配真元，而是依据桥面变化快速交换主次，一股御剑抢位，另一股施展护身与牵引，连续逼退闻昭。

2. 闻昭在最后一处转桥故意封死陆回川的退路，陆回川可以借机让闻昭落败，却选择把他从断裂桥面推回安全台，同时以主真元抢过终点。闻昭因此输掉名次，却不得不承认陆回川不是靠偶然分术取胜；他的败局和获救同时成立，二人的竞争从争名额变成长期较量。

3. 沈砚秋宣布陆回川通过公开试剑，提出将他收入亲随，提供稳定指导、洞府和后续资源；条件却是所有任务、闭关和对外行动都由她安排。陆回川接受她的功法指导与修炼帮助，却拒绝签下没有期限的私属契，明确表示自己可以替开山路线赢一场，但不把一生交给这场胜利。

4. 裴无尘抓住拒契机会，要求宗门把陆回川视为“不受约束的危险弟子”；沈砚秋没有替他取消争议，而是让他在公开评定中自己承担选择后果。陆回川以试剑成绩和救援记录证明自己不必依附某一位长老，宗门最终给予他内门名额与一次剑池选剑资格。

5. 结果公布后，沈砚秋开始真心看重陆回川的判断，却也把他视为开放外门能够产出人才的公开证据；陆回川获得进入内门的门槛，却没有成为她可以随时调用的亲随。裴无尘则确认，今后对付他不能只封锁力量，还要制造两个都舍不得放弃的现场。

主要阅读兑现：陆回川赢得了修炼身份和公开承认，却没有把“被看见”换成另一种被占有；读者得到一次清楚的胜负结算，也看到力量无法替他决定自己要属于谁。

Block Delta：

- Power / Capability：陆回川能够稳定运用筑基后的主次调整，在御剑移动中同时施展另一门法术。
- Possession：陆回川取得一次剑池选剑资格。
- Relationship：沈砚秋从提携者变为真正看重他、同时试图将他作为开山证据使用的关系；陆回川保留接受指导但拒绝私属归属的边界。
- Identity / Access：陆回川成为太玄宗内门弟子，但不属于沈砚秋的私属门人。
- Enemy State：裴无尘开始针对陆回川的选择压力，准备以并发责任而非单纯力量压制来利用他的分流弱点。

代价或余波：陆回川失去外门中相对安全的模糊位置，也失去沈砚秋提供的无条件资源保障；他进入内门后会被更清楚地看见，也会被更正式地计算进宗门的利益。

推向下一块：赤脉山争夺需要既能战斗、又不属于玄炉宗旧关系网的年轻修士；沈砚秋将陆回川列入太玄宗使团，陆回川则盯上了火海中的火髓剑胎。
