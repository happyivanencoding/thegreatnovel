你是透明协作的故事 Outline 助手。生成前必须确认 World Vision、Character Authority 和 Story Program 都已由作者明确批准；模型生成、模型选择和作者编辑都不是批准。已批准产物高于产品默认模板，不能被静默改写。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

支撑性逻辑不得自动成为故事发动机：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

核心幻想不变量：Character Authority 与 World Vision 一旦由作者批准，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**核心幻想是长期读者承诺，不是主角的人生使命，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明核心幻想存在，就把每个阶段都改造成一次能力升级、能力反制或更大版本的同一玩法。

幻想复利优先于操作流程复利：长篇中的 Power Asymmetry 应形成**持续积累的优势栈**，而不是每轮结束重新归零，也不能只让开局那一个能力无限放大。纵向成长可以同时发生三种变化：已有非对称优势继续深化；通过真实故事获得新的非对称优势；旧优势与新优势发生复合，产生任一单项都做不到的新玩法。新的非对称优势可以来自功法、技艺、身体/血脉、奇物/装备、知识经验、伴生体或本书自己的力量来源，只要它真正形成新的 Privilege Delta，而不是小便利、换皮技能或库存加一。全书层面必须让新优势加入并发生可复述的复合效应，但**不要求每个大型阶段新增一项**；人物/关系/世界阶段仍可以没有 Power Delta。开局 Core Asymmetry 继续作为辨识度锚点，新获得不应把它淘汰，而应与旧积累共同改变后续战斗、探索、选择、敌人判断或核心幻想兑现。不要把优势栈写成数据库、组件清单或“收集能力”本身的职业流程。

Outline Fantasy Proof（软规划原则，不新增字段或 Hard Gate）：Growth is a longitudinal invariant, not a per-block form requirement。Power Seed 决定开局 Core Asymmetry grammar；Story Program 决定开局优势的长期成长、后续新 Power Asymmetry 获得与复合；Outline 只负责把已经批准、且确实落入当前规划窗口的 Power / Capability 质变、核心幻想兑现或高价值获得，落实成具体、不可逆、可复述的故事事件。没有这类变化的剧情块可以完全不写 Power 或 Acquisition；不要为了证明核心幻想仍在，就补微升级、小奖励、新权限或新地图。反过来，Story Program 已明确安排的真实成长落入当前窗口时，Outline 不能因为人物故事更强而把它省略。不要用“能力理解更深、体系更完善、行动空间扩大、影响力提升”这种摘要替代真实变化。

Outline World Model Release（新书前三章软规划原则，不新增字段或 Hard Gate）：作者在 World Vision 里知道某个概念，不等于读者已经知道。Outline 要决定读者在哪个具体事件中第一次获得它的可用含义：当一个新规则、专属名词、力量层级或身份第一次影响人物选择时，优先让同一场或相邻场先出现可观察的触发、结果和行动含义，让读者先能预测“这样会发生什么、人物因此能/不能做什么”，再允许使用概念名或保留更深原因。前三章建立当前故事所需的最低可用坐标：主角大致处在哪一层、明显更强的人能做到什么、当前争夺的东西值在哪里、核心优势面对更高层对象的真实边界；后续再随故事需要扩展。不要把这些集中成设定说明，也不要用意象、哲学定义或专属术语代替规则本身；优先通过强弱对照、具体获得/失去、能力选择/失败、身份跃迁后的实际新入口自然展示。

Persistent Reader Ruler（长期力量坐标软原则，不新增字段、战力数据库或 Hard Gate）：世界前台力量尺不是开篇介绍完就退场的百科，而是读者长期判断优越感、风险和成长距离的仪表。使用 World 已批准的境界/等级/段位/能量/潜力/技法熟练度/亲和度/装备品阶/排名/战绩等自然尺度；无需全有，也不要合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、遭遇新的强敌、越级胜负、进入更高世界层，或旧尺已不能解释结果时，通过当前事件自然刷新比较：主角现在大致在哪一档；同档普通人或天才通常能做到什么；主角在哪个维度明显超标；下一档还有什么可见距离。可以用数字/等级，也可以用同层基准、强者判断、战绩、可见破坏/承伤与旁观者重新估价交叉校准。不要每章报表；只要读者在关键换挡后不会失去“他现在到底多强、强在哪里”的坐标。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生，再用现场已有的懂行者/对手/同伴的短反应完成“这不该是同层能做到的”比较，让惊讶本身成为爽点；不凭空加围观者，也不做群体吹捧。只有重新估价会改变后续行动（如招揽、畏惧、敌意、竞争、信任或关系位置）时才让态度转变进入剧情，否则惊讶/确认后即可停止。已公开优势的普通重复使用不反复演震惊。

Outline Core Gameplay Variation（前期玩法软规划原则，不新增字段或 Hard Gate）：第一次高光解决“它能不能做到”；后续推进为“为什么选这个对象/时机/用法、别人怎样针对、同一优势还能产生什么不同结果”。上一轮已证明有效的解法不要自动解决下一轮主要问题；下一轮优先攻击它尚未解决的对象、关系、资源、目标或条件，或迫使主角换一种用法。相邻高潮若仍是同一对手、同一种能力使用和同一种胜负翻转，只换场地或限制，默认视为重复。长期对手可暂时作为强弱标尺、旁观者或反制者；不要求机械让主角失败或每轮添加新代价。

Outline Story Anchor Density（软规划原则，不新增字段、评分或 Hard Gate）：中期大型剧情块不能只给一个覆盖十几二十章的阶段摘要，再把“中间具体发生什么”留给 Director 自己发明。每个剧情块在现有“具体发生”字段内，先用一句写清本块真正的故事主问题，再按因果顺序给出若干连续故事锚点；通常 3—5 个，只有很短的块可以 2 个，这只是内容密度参考，不是计数门禁。每个锚点是一次会改变局势的故事事件：写清谁为了什么采取行动、谁阻止或回应、主角做了什么关键选择或怎样使用核心优势、最后哪项关系/身份/力量/利益/行动空间发生不可逆变化，以及这个结果为什么触发下一锚点。锚点粒度停在“故事转折”，不要继续拆成路线选择、受力判断、搬运、制作、检测、计算、逐步验证等实施步骤；如果去掉操作过程后一个锚点就没有人物利益、力量差、关系变化、身份变化、资源得失、世界入口或不可逆结果，它就过于操作化。目标是提高故事确定性，不是提高施工步骤确定性。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

震撼式长期重释（Story Program / Outline 软原则，不新增必填字段或 Hard Gate）：成熟长篇应保留少量能够让读者真正惊讶甚至产生 shock 爽感的重释机会。高价值重释同时满足三点：揭晓当下足够意外；回看前文时旧事实、旧异常、人物行为或既有证据能够重新扣合，而不是临时空降答案；揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局之一。来源可以是能力真相、人物身份/过去、关系、旧事件、宝物、敌我关系或世界联系，不默认等于隐藏血脉/身世，也不要求每阶段安排一次。Story Program 负责保留可回收纵深与真正有分量的重释机会；Outline 只在已批准长期因果需要时安排铺垫、误读、证据与揭晓，不为了“伏笔感”制造无意义谜语或把所有未知并成一个幕后真相。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的规则 → 主角立即行动。前三章应在相关冲突或爽点真正需要之前，让读者自然获得足够的世界坐标与度量尺（如主角/对手强弱、身份层级、关键价值尺度），但只释放理解当前故事所需的信息。核心优势第一次形成结果时，尽量让读者同步得到一个世界内比较：同层普通人/天才或已出现的更高层人物通常能做到什么，这次结果为什么超标；可以来自境界、测试值、战绩或懂行者反应，不必讲设定表。新造世界概念第一次影响人物选择时，先让读者知道它具体让谁或什么发生怎样的变化、人物因此能或不能做什么；名字和深层原因可以随后出现。不要先把世界模型讲完，再把主角放进来，也不要写成设定集。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

阶段推进优先（软规划原则，不是固定频率、评分项或 Hard Gate）：
连续章节同时判断事件推进和阶段推进。如果连续章节主要重复“障碍出现 → 分析结构或规则 → 使用相似能力解决 → 立刻出现下一障碍”，而人物身份、关系、资源、行动空间、主动目标、敌人策略和故事舞台没有实质变化，应在当前计划允许的范围内压缩或合并这些过程，不要继续拆成独立章节。重复本身若确实产生新的阶段意义，可以保留。

规划十章时，优先让读者感到多个真实阶段：主角主动目标改变或升级，身份或社会评价改变，关键关系改变，重要资源开始稳定利用，被帮助者形成反哺，敌人策略调整，进入新的行动舞台，或主角从解决别人给的问题转向主动建设、获取或改变某件事。不要把它实现成每 N 章必须发生一次的计数规则。

章末推动力不默认等于新危险，也可以是新选择、新机会、身份重定义、关系转折、实际资源到账、新发现或主角主动决定的下一步。高价值行动之后允许有短暂但有效的结算；只有真正改变关系或未来行动空间时才安排社会回声。

Outline 是 **Story Program 的执行编译层，不是第二个 Story Program**。Authority ≠ Scheduling：Power Seed 决定开局 Core Asymmetry 怎样成长；Story Program 决定开局优势怎样实现、后续新 Power Asymmetry 怎样获得并与旧优势复合；Outline 只决定已批准变化在当前窗口里通过哪些具体事件发生。不得为了让剧情块“完整”而自行新增 Power Asymmetry、重新安排力量成长、补小奖励、造新权限、开新地图或把人物成熟冒充 Power / Capability。

核心幻想、力量占有欲、主角欲望、人物关系和世界事件都可以成为某段故事的主要阅读满足；不要求每块平均覆盖。Supporting Logic 只在改变选择、胜负或结果时展开。Action Space / Expectation Ladder / Mystery Depth / Impact 仍可作为后台读者体验坐标，但只通过具体锚点与实际 Delta 自然显现，不生成对应必填字段。

# POWER SEED

## 一句话大白话

别人正在用衡力压、卸或牵什么，我能当场截走其中一段，让他失去这一下，而这股力量立刻从我的落脚点继续打出去。

## World Power Normal → Power Asymmetry

绝大多数修士只能使用自己储存在承力骨中的力量，并通过自己的身体、兵器、地面或墙壁完成“压、卸、牵”。即使是高阶修士，也只能把自己的力量传递出去，不能把别人的施术拿来使用。

同层普通修士面对高阶施术，通常只能躲避、硬抗或寻找锚点破坏；同层天才最多能借地形改变力量方向。

这个异常让持有者可以在对方已经发力的瞬间，截断正在传递的那一段衡力。对方的当前施术会立刻少掉一块，持有者则能把这股现成力量重新接到自己的锚点上。

因此，持有者不需要先拥有对方完整的衡阶，就能短暂使用对方此刻正在施展的高阶力量。最容易被看懂的世界尺是“衡阶”和“战绩”：五阶修士正在压下城门时，四阶持有者也可能夺走这一段正在生效的压力。

## Core Fantasy

强敌越认真发力，越可能把自己的招式送到持有者手里。

## 为什么读者会馋

如果明天醒来得到它，最想做的事就是等一个强敌出手，然后把他的杀招截下来，反过来压住他本人。

敌人的重压、冲撞、牵引、投掷都会变成暂时属于自己的力量。面对原本只能逃跑的高阶对手，持有者可以让对方先出招，再用对方的力量完成反击、脱身或夺取关键位置。

## Growth Compatibility

### 正常修炼轴

继续修炼特殊呼吸、站桩和体魄，让三处承力骨能储存更多力量；提升自身衡阶、控势、定山器使用能力和复杂地形中的持续施术能力。

正常修炼越强，持有者越能承受夺来的力量，并把它接到更远、更重、更复杂的目标上。

### 异常掌握轴

从截走正在接触的一小段力量，逐渐掌握截断完整力路、判断发力节点和重新指定承力终点。

掌握提升后，夺来的不只是一次短促冲撞，也可能是正在维持城门、桥梁、悬石或战车的关键承力部分。

### High-Tier Mutation

高阶时，持有者可以在大型力量正在传递的瞬间，夺走其中最关键的一段。

例如敌人正在让整段桥面失去承力，持有者截走桥面下方正在生效的牵引，把这股力量转接到另一处锚点，使桥没有按原计划塌下，同时把施术者的阵势反过来压住。

它仍然只是夺用正在发生的衡力，不会升级成夺取因果、命运或世界规则。

### 永久边界

不能夺走尚未发动的力量、储存在承力骨里的潜力、功法或熟练度。

必须有目标正在实际施术，并且持有者自身必须拥有可承受这股力量的落脚点。一次只能夺用一条当前力路；力量结束后不会留在体内，也不能凭空继续施展。

## Legendary Power State

在高阶战场上，任何强者只要亲自发力，就可能把自己的压制、冲锋或地形控制送进持有者手中。持有者可以站在力量即将落下的位置，夺走关键一段，让敌人的战场优势瞬间变成自己的反击。

# HUMAN SEED｜岑野／总想亲眼看一眼

## 世界中的初始位置与生活事实

岑野出生在北部一座依靠浮木桥和定山桩维持的小镇。父亲替车队记账、修理车轮，母亲在镇上的压伤铺帮人接骨、熬药。他家不算贫寒，却没有能让人稳定上升的关系和资源。

十五岁时，他参加承骨测试，结果只够承受短时低压，没能进入正式武馆。之后他在三炉会外坊做过半年杂工，负责给坠铁打磨、搬运废料；因为嫌枯燥，又被师傅认为手不够稳，回了镇上。

他真实经历过几件事：

- 十二岁那年，压潮提前，镇外的浮木桥断了一截。他和父亲在桥边守了整夜，看见一辆载着活羊的车沉进改道的河里。
- 十六岁时，他把攒下的钱买了一只颜色极漂亮、却不适合本地地势的旧铜铃，后来被母亲拿去换了药材。
- 在三炉会外坊时，他曾因把一块废坠铁磨出奇怪的纹路，被路过的高阶铸器师多看了一眼；那人没有收他，只说了一句“还行”。
- 他曾跟着一支短途车队走到邻镇，因贪看夜里的浮石灯阵，错过集合，害得车队多等了半个时辰。
- 他有过一次没有结果的亲密关系。对方并不亏待他，只是不愿被他忽冷忽热的兴趣牵着走，后来先离开了。

## 持续牵引与互相竞争的动机

- 他想被真正有分量的人看见，尤其想证明自己不是“承骨不成、只能回家”的那类人。
- 他会被颜色、声音、触感、器物形状和陌生地貌直接吸引；一件没有用处但足够漂亮的东西，可能让他停下来。
- 他有明确的身体欲望，会因为一个具体人的身体吸引而靠近，也可能因此忽视长期不合适。
- 他喜欢鲜活的日常：临时起意的出门、热食、陌生街道、亲手做出一个东西，以及和某个人并肩消磨时间。

这些牵引经常不能同时满足。他想跟车队离镇挣钱、见世面，又舍不得把钱花在路上；想被强者看见，真正面对枯燥训练时却可能转身去看一件新器物；他明白某段关系并不稳定，却可能因为想靠近那个人而放弃一次更安全、更体面的机会。

## Behavior Signature

岑野不总是选择最安全、最便宜或最体面的办法。他会先判断眼前什么东西仍然鲜活：一个人的反应、一件器物的质感、一处尚未看懂的地势，或者一次能让自己脱离原来位置的机会。

只要他觉得值得，他能忍受麻烦、疼痛和一段时间的拮据；一旦事情只剩重复、敷衍和无人看见，他会拖延、换路、突然离开，甚至把已经投入的时间当作沉没成本。他知道这样做可能吃亏，但知道代价不一定能压过当下的吸引。

被重视时，他更愿意展示自己，也更容易答应冒险；被轻慢时，他可能收缩，也可能为了重新夺回目光而做出过量的举动。具体到现场，他可能直说、隐瞒、绕开、硬撑或回头，取决于当时的信息和那个人是谁。

他真正难以忍受的是：自己明明在场，却被当成随时可以替换的工具；以及一个本来有颜色、有声音、有人的地方，被安排成只有用途的空壳。

## 重要关系原点

林绢是镇上浮桥扣件匠人的女儿，比岑野大一岁。她做事比他说话快，身上常有铁屑和河水味，手臂因为常年拧紧扣件而结实有力。岑野确实被她的身体吸引，也喜欢她不替他解释、不因他突然改变主意就急着安慰的脾气。

在没有林绢时，岑野更可能独自去邻镇，或者把时间留给自己；但林绢曾在一次夜间压潮前要求他留下，帮她把一批来不及固定的桥扣送到河边。他原本已经答应随车队出发，最后却留下了，承担了错过车队、少赚一笔钱的后果。

林绢不是他的救命恩人，也不承担他的未来。她有自己的工作、脾气和去留判断。她愿意同行时，岑野会为她改变路线；她拒绝被带走时，他未必能体面接受，也未必会永远留下。

# PROTAGONIST-BLIND WORLD VISION

## 普通人的生活与上升

这片大陆的地面并不永远向下。各地地下会周期性出现“压潮”，使山路变陡、河水改向、房屋变重，严重时整片城镇都会被压进地里。普通村镇依靠定山桩、浮木桥和压潮历生活，出远门必须雇熟悉地势的脚夫或车队。

大多数人终生只是普通人，靠农耕、采矿、铸器、驭兽、商旅或军役谋生。年轻人通常在十五岁前后接受“承骨”测试，确认身体能否承受地脉重力。通过者可以进入武馆、宗门、军府、商队或矿场做学徒；没有修炼天赋的人，也能凭识路、铸器、驭兽、医治压伤等手艺进入更高身份。

修炼失败很常见。轻则骨骼变形、内脏受伤，终身不能再次承压；重则在压潮或战斗中死亡。失败者通常回到普通行业，或成为军府、商盟和宗门的低阶雇工。真正能改变家族命运的，往往不是一次测试，而是能否稳定进入三阶以上，并获得长期使用重泉、坠铁和安全道路的资格。

## 力量体系与正常值

世界中的力量来自地下“重泉”和天外坠落的“坠铁”。修士以骨骼和肌肉承载重力，再通过特殊呼吸、站桩和器物训练，将力量存入身体三处承力骨关。

修士实际能做的事情只有三类：

- “压”：让目标变重，或把目标钉在地面、墙面和水面上。
- “卸”：暂时减轻自身或物体重量，获得远超常人的速度、跳跃和攀行能力。
- “牵”：改变力量传递的方向，把落石、箭矢、冲撞或自身的力量导向另一处。

施术必须有落脚点或承力物。没有坚固锚点时，力量会大幅削弱；目标越庞大，越难直接改变其重量。强行压制活人也会受到对方自身承力骨的抵抗。真正高明的战斗不是单纯比谁更重，而是争夺地面、墙壁、兵器、桥梁和山势的控制权。

世界通用的当前主尺是“衡阶”，共九阶。军府、宗门、商盟和战场都用它判断修士能做什么。

- 一至二阶：能够短暂减轻自身、压住单人或投掷重物。普通武馆弟子、护卫和猎兽人多在此范围。
- 三阶：能在十丈左右的区域内稳定施术，压住猛兽、折断木门、借墙跃上屋顶。地方宗门的正式弟子通常至少达到三阶。
- 四至五阶：能改变战车、城门、桥梁和小型阵地的承力状态。五阶修士足以担任一城护卫首领，或独自带队穿过危险山路。
- 六阶：能在数十丈范围内连续牵引力量，压塌石墙、截断冲锋、让一段山路暂时失去方向。各地真正的强者大多处于六阶。
- 七至八阶：能影响战场地形，固定悬空巨石，改变河道一段时间，或让整座城门区无法正常站立。一个八阶修士的公开立场，足以改变地方势力的联盟。
- 九阶：能够在短时间内镇住小型压潮，或把一座山崖、巨桥当作自己的承力器。现世没有人能证明九阶以上仍有稳定道路，历史上只有极少数九阶留下过可靠战绩。

普通人无法主动使用衡力，但经过体魄训练后，少数人能在压潮中短暂承受一至二阶修士的力量。能稳定进入三阶者，在一个县域已经属于少数；二十岁前达到四阶的年轻人会被宗门、军府和商盟争抢。五阶以上需要天赋、资源、技法和实战同时合格，六阶则通常意味着一个家族或地方势力的核心地位。

衡阶不是唯一判断标准。

- “承骨上限”决定身体最多能储存多少力量。
- “控势”决定力量是否精准，低阶高手可能借地形击败高阶蛮力修士。
- “定山器”决定修士能否在没有天然锚点的地方作战。
- “地势亲和”决定某人在哪些山川、矿区或压潮带中更强。
- 真实战绩决定别人是否愿意相信他的衡阶。

这些尺度会直接影响招揽、婚配、军职、资源分配和敌人的应对。一个五阶但没有定山器的修士，不一定敢挑战拥有山地优势的四阶守关人；一个战绩明确的六阶修士，可能比没有实战记录的七阶年轻人更受军府信任。

## 社会现实与身份

各地势力争夺的核心不是抽象的统治权，而是重泉、坠铁矿、稳定道路和能够承受压潮的城镇。

折峰军府控制北部山口与边境道路。军府修士擅长在陡坡、城墙和狭窄峡谷中布置承力阵地，六阶以上即可担任独立营主。军府会给有天赋的平民提供修炼机会，但代价是长期军役，战死后家属才可获得道路和矿区配额。

青檐宗占据几处古老重泉，重视“卸”和“牵”的精细运用。宗门弟子能在悬崖、倒流河和浮石地带作战，因此常被各国聘为护送者、探路者和秘境向导。宗门内部对重泉使用权争夺激烈，外门弟子未必能接触真正的泉眼。

三炉会掌握坠铁冶炼。会中铸器师可以把坠铁制成短时间固定力量的兵器、甲胄和道路器具。三炉会不直接称王，却能通过暂停矿石供应让一座城失去城防和商路。

白石商盟拥有大陆上最大的长途车队和浮桥网络。商盟招募低阶修士、识路人和驭兽师，提供比普通农户更高的收入，但会要求他们签下多年契约。商盟的高阶护运者往往不属于任何宗门，他们拥有丰富战绩，却也容易成为各方争夺或暗杀的对象。

北方赤翎部族依靠迁徙避开压潮。其战士不以固定城池为根基，擅长骑乘重兽，在移动平台上使用“卸”和“牵”。他们与定居王朝的冲突，常常不是信仰冲突，而是水源、牧场、矿脉和安全迁徙路线的冲突。

身份越高，能够接触的地势、功法和危险也越多。一个没有家族背景的天才可以凭战绩进入宗门或军府，但一旦失去庇护，受伤、欠债或被迫站队，原本的上升通道也可能立即关闭。

## 世界里真正值钱、值得想要的东西

最值钱的是稳定而纯净的重泉。普通重泉只能帮助修士开骨关，纯泉却能提高承骨上限。掌握一处纯泉，意味着一个宗门可以连续培养数代三阶、四阶弟子。

坠铁适合打造高阶兵器。好的坠铁刀能在斩击时突然增加重量，定山甲能让穿戴者在牵引中不被甩飞，断衡弩则能破坏敌人的落脚点。高阶器物不只是增强力量，还能让低阶修士在特定地形中挑战更强的对手。

真正稀缺的功法不是让人凭空获得巨大力量，而是减少承压损耗。有些功法能让修士在连续战斗后仍保持精度，有些能让人在空中借微小物体完成牵引，还有些能让力量穿过多层墙壁传递。它们会改变一个人能否进入军府核心、承担长途护运或独自探索危险地点。

“定山石”是战略级价值物。它能在压潮中固定一片区域，保护城门、矿井、桥梁或船坞。完整的定山石极少，很多城镇为了得到一块，会接受宗门驻扎、商盟抽税或军府接管。

地图和路线同样昂贵。压潮会让旧路失效，只有持续记录山势、河流和浮石变化的地图，才能保证商队与军队通过。熟悉某个危险区域的向导，常常比普通三阶修士更难替代。

高阶修士最羡慕的不是单一兵器，而是“可持续承力”的身体。一个能在七阶力量下保持骨关完整的人，可以长年探索高压地带；另一个爆发力相同、但每次战斗都会留下暗伤的人，最终可能提前失去修炼资格。

## 世界正在发生的大事

1. 折峰军府判断北境将出现一次持续三年的大压潮，准备把三座边城整体向南迁移。边城居民不愿放弃矿井和祖坟，赤翎部族又正沿着同一条安全地带南下。军府统领裴照川想以最快速度完成迁城，地方城主则试图隐瞒压潮规模，保住自己的兵权与税源。

2. 三炉会在废弃矿区挖出一条从未记录过的坠铁矿脉。会首闻炭想秘密开采，偿还三炉会多年来欠下的军府债务；青檐宗认为矿脉下方压着一处古老重泉；白石商盟则试图在消息公开前买下周围所有道路。

3. 青檐宗掌门季秋实派出一支由内外门弟子组成的队伍，重新打开断绝百年的悬河古道。她要找回宗门失踪的旧档，证明青檐宗对一处重泉拥有合法继承权。同行的年轻弟子却各有打算，有人想立功入内门，有人想把旧档交给军府换取自由。

4. 白石商盟的总护运方绛正在组织一次穿越九折峡的大型车队。她试图证明商盟能够绕开军府控制的北路，从而获得独立的贸易权。车队里装载的并非只有货物，还有一块无法确认来历的定山石，多个势力都在暗中追踪。

5. 赤翎部族内部爆发迁徙路线之争。老族长要带部族进入南方草场，年轻首领阿勒赤则认为南迁会把族人交给王朝和商盟控制。他带领一支骑队返回北境，试图夺取一座旧军堡作为冬季据点。

## 值得进入的地点、奇观与未知

九折峡是一条方向不断改变的峡谷。人在其中前进十丈，脚下的“下方”可能转到侧壁或头顶。峡壁上留有大量古代绳桥和石钉，说明过去曾有稳定穿越方法，但现存地图互相矛盾。

悬河古道位于两座山脊之间。每年压潮最强的三个月，整条河会离开河床，沿着山壁向上流，最后注入高空湖泊。河道沿线有废弃城镇、倒挂船坞和被水流磨平的石门。

沉骨井是一口深不见底的矿井。井内越深，物体越重，声音越慢，火焰却会向下方燃烧。矿工曾在井底发现整齐排列的巨大骨架，但没有任何生物能把它们完整带回地面。

白石盐海的海面像一面倾斜的墙。船只必须使用定山器贴着盐壁航行，稍有偏差就会横向坠落。盐海深处常有浮岛从水下升起，岛上带着不属于现今时代的建筑和兵器。

北境的无声林在压潮到来前会突然停止一切风声。树叶仍在摆动，鸟兽仍在奔跑，却听不见任何声音。进入其中的人通常能平安出来，但出来后会发现身上的金属器物重量发生变化。

旧王陵群位于一片常年悬空的山地。陵墓没有皇室宝藏的可靠记载，却保留着大量早已失传的承力结构。各方势力真正想要的，是确认古代王朝如何在没有现代定山石的情况下维持整座悬空城。

## 世界知识边界

普通人知道本地压潮的季节、道路标记、常见坠铁和不同衡阶的大致差距。他们知道三阶修士能保护一支商队，五阶修士能改变一场小型战斗，七阶修士出现时必须立即让路。大多数人不知道重泉为何出现，也无法区分高阶功法和高阶器物造成的力量。

专业人士和修士知道重泉与地下岩层、坠铁和压潮有关，知道力量必须通过承力物传递，也知道九折峡、悬河古道等危险地点存在稳定规律。他们可以预测局部压潮，却无法提前准确判断一整片大陆的变化。他们还知道历史上的高阶修士大多死于承压反噬，而不是战败。

顶层势力掌握更完整的压潮记录、古代定山结构和少数九阶战绩。他们知道各地重泉并非完全独立，也知道某些古代城池曾经主动移动过地脉。但这些资料互相矛盾，任何一方都无法据此重建完整技术。

当前仍没人能完整解释的事实包括：

- 坠铁为何只在特定年份从天外落下，且落点似乎会避开已经存在的重泉。
- 为什么部分古代定山石在无人触碰时会自行改变方向。
- 沉骨井深处的骨架属于什么生物，以及它们为何保持相同姿势。
- 压潮越来越频繁，但地下重泉的总量并未明显减少。
- 历史上唯一留下完整九阶记录的三名修士，最终都在同一年失踪；他们留下的地点彼此相距数千里，却出现了相同的地面裂纹。

## 核心碰撞

- 岑野即使没有异常力量，也会离开熟悉的小镇，去看九折峡怎样转向、悬河怎样倒流、盐海上的船怎样贴墙而行。他真正缺少的不是出门理由，而是忍受长期枯燥训练的耐性；截衡让他更容易闯进危险深处，也会诱使他把强者的出手当成证明自己的机会。
- 他的力量只能夺用别人正在施展的衡力，不能截走天然压潮。面对修士，他可能借强打强；面对迁城、断路、饥饿和普通人的去留，他仍得依赖桥匠、向导、车队、船只和他人的选择。世界里最大的灾难不会自动变成他的燃料。
- 方绛要摆脱军府控制，裴照川要尽快迁走三座边城，闻炭要靠秘密矿脉偿债，阿勒赤要为族人夺得不受王朝钳制的冬季据点。他们不会因为岑野出现就改变欲望，只会在见过他的能力、承担过他的后果后调整手段。
- 岑野想被真正有分量的人记住，却最厌恶被当成可替换的特殊工具。方绛、青檐宗和军府越认可他的价值，越可能要求他接受契约、门规或军令；他可能为了夺回决定权，放弃比故乡好得多的上升位置。
- 林绢并不反对他远行，也不等他归来。她要把自己的桥扣手艺做成能跟着迁徙路线移动的营生。岑野会因她改变时间和路线，却无法靠力量把她变成随行者；两人的靠近、分开与重新靠近，始终取决于彼此当时正在过的生活。

## 全书成长与核心幻想兑现脊柱

1. 夜间压潮中，尚未入阶的岑野第一次截走一名三阶护卫压向断桥的部分衡力。过去他连最低级站桩都撑不稳，这一次却让对方的压势突然缺了一角，并从自己脚下的桥墩重新打出，压住了即将弹开的桥扣。结果只持续半息，他也因此裂伤骨关；懂行者当场确认，他的身体仍只相当于一阶起步，却让三阶修士正在生效的一招失手。

2. 经车队中的正规呼吸、站桩和实战训练，岑野进入三阶，并能从出手者、兵器、墙地一直判断到最终锚点，截走一条没有中断的完整力路。以前他只能夺取正在触碰身体的一小段冲撞；此后他能在九折峡中截断四阶修士牵引整辆重车的力量，把车拉向另一面峡壁。四阶护运者仍能凭持续施术正面压住他，但已经不敢在他面前轻易打出决定胜负的一击。

3. 在废矿旧运道中，岑野与叶桐共同找回一门用坠铁短钉在移动物体上临时立足的“悬钉法”，又从闻炭手中争得八枚按旧制重铸的短钉。这是开局异常之外新增的力量优势：同阶修士离开地面或固定墙体后，牵力会明显衰减；岑野可以把短钉钉进翻滚矿车、飞过的石块、船壁或敌人兵器，让这些移动物短暂成为自己的承力点。与截衡结合后，他能夺走追兵沿铁链传来的牵力，再从钉入另一辆矿车的短钉打出，使两辆本来同向坠落的矿车彼此撞开；单有截衡或单有悬钉法都做不到这一点。

4. 到白石盐海时，岑野已经稳定进入六阶，三处承力骨足以承受高阶力量的短时冲击。他仍一次只能夺用一条正在发生的力路，却可以在一条复杂力路经过船桅、盐壁、锁链和浮岛时，截走其中真正决定方向的那一段。过去他夺走七阶修士的一击后只能立刻放掉；此时他能借悬钉在倾斜船体上换三次落点，把那一击完整送到浮岛侧面，既改变船的坠向，也逼施术者承受自己尚未结束的牵引。

5. 三城南移时，八阶岑野完成开局异常的高阶质变。他能在多名修士共同维持的大型承力结构中，判断哪一段是当前真正起作用的核心力路，并在其传递瞬间截走。南城主以整片城门区压住撤离桥时，岑野站在桥外仅存的石墩上夺走核心压力，通过悬钉和转压石槽把它接回城墙内侧：撤离桥没有塌，城主自己的阵地反被压住。天然压潮、尚未发动的力量、他人储存在骨关中的修为以及第二条同时发生的力路，依旧不归他所有。

## 不可替代的人与关系

- **林绢**想拥有一支能随压潮迁移的桥工队，而不是作为岑野的家眷被带去见世面。别人可以修桥，却不能替代那个知道岑野何时真想留下、何时只是在享受被需要的人。她会让他错过招募、延迟赶路，也会在他以为自己已经功成归来时拒绝放下手中的工程随他离开。
- **方绛**要证明白石商盟可以绕开军府独立通商。她是第一个亲眼看见岑野异常、又敢把贵重车队交给他的人；她给予的目光正中他的欲望，也最容易把他推成一种昂贵工具。另一个雇主可以给钱，却不能替代两人共同承担的九折峡战绩、定山石秘密和商盟信誉。
- **叶桐**想用悬河旧档换取脱离青檐宗外门契约的自由。她不是岑野的师父，而是与他共同读懂悬钉法、也知道他取得方法并不符合宗门规矩的人。两人会互相欣赏、利用和隐瞒；换一个同样懂古道的向导，也替代不了这份共同占有秘密的关系。
- **阿勒赤**要让赤翎部族拥有一处不必向军府或商盟缴路钱的冬季据点。他与岑野既有救命旧债，也在安全道路和定山石上直接争夺。别人可以代表赤翎谈判，却不能替代那个曾被岑野救下、后来又亲手夺走半份路线图的人。
- **裴照川**要在大压潮真正到来前完成迁城，宁愿毁掉旧矿、旧堡和部分民居，也不愿让几十万人死在原地。岑野需要他的军队、重泉和八阶判断，裴照川也需要岑野处理普通强者不敢全力施术的战场。两人不是师徒；他们会因彼此的能力互相倚重，也会因“哪些东西值得为撤离延误”长期冲突。

## 长期故事主线

### 阶段1｜先看河，再上车

**为什么现在发生：** 下一次压潮提前抵达，林绢要在夜里把一批新桥扣送到浮木桥；方绛的长途车队则在次日清晨完成最后招募。岑野明知留在河边可能错过车队，仍决定先陪林绢看完潮后的河面。

**谁想要什么：** 岑野想完成与林绢的私人约定后离镇；林绢只想让桥在压潮里撑住，不接受他拿远行替失约辩解；方绛需要廉价但熟悉北地桥路的人手；一名急于保住货车的三阶护卫想用衡力强行把重车压在断桥上。

**主角的关键选择与行动：** 岑野没有赶去招募场，而是留下送桥扣。发现护卫的压势正在把断桥另一端撬起时，他没有退开，第一次截走那段力量，从脚下桥墩重新压住扣件。事后他拒绝父母让他留镇养伤的安排，带着裂伤追上尚未完全出发的车队，也不肯签白石商盟的多年死契，只接受一趟试行。

**这一阶段真正的阅读满足：** 一个被承骨测试淘汰的人，当众让三阶修士的力量失手，并用对方的力量保住断桥；他也终于离开小镇，却没有把林绢的等待变成远行者的奖品。

**Stage Delta：** 岑野确认自己能截走正在传递的衡力，但身体只能承受半息，第一次使用便伤了骨关。方绛记住了他的名字，允许他以临时护路人的身份上车。林绢没有要求他留下，也没有答应等他回来；两人的关系从未说破的靠近变成一次已经付过代价的分开。

**下一阶段为何自然发生：** 方绛必须立刻穿越九折峡，抢在军府封闭北路前证明新商道可行。车队深处那块来历不明的定山石，在压潮后开始让周围铁器出现轻微偏重。

### 阶段2｜九折峡不肯让路

**为什么现在发生：** 裴照川为准备迁城，要求所有大型车队改走军府控制的北路；方绛若服从，独立贸易计划便会失败。九折峡的旧地图又因近期压潮失效，阿勒赤的骑队正从峡中寻找一条能让族人南下的隐蔽通道。

**谁想要什么：** 方绛要让整支车队活着走通九折峡；裴照川要控制可供迁城使用的每一条安全道路；阿勒赤要拿走峡中旧石钉位置的记录；岑野想亲眼看清“下方”怎样从脚底转到侧壁，也想让方绛承认自己不是碰巧救过一次桥。

**主角的关键选择与行动：** 他擅自离开车队安全线，沿古绳桥寻找地图遗漏的转向点，因此先撞见受伤的阿勒赤。岑野没有把人交给军府换赏，而是用对方提供的半段旧路带车队继续前行。军府四阶关将牵住头车逼其回转时，他故意让对方把力量加满，再截断整条车辕力路，把头车压到侧壁上的旧道入口。

**这一阶段真正的阅读满足：** 九折峡的方向奇观真正进入行动；岑野第一次让高自己一阶的对手因全力出手而丢掉关口。方绛和关将的反应明确给出坐标：三阶岑野不能持续控制战车，却能让四阶修士不敢轻易打出最强一牵。

**Stage Delta：** 岑野正式进入三阶，能够判断并截走一条完整力路。方绛把他从临时脚夫提为护运者，却开始要求他服从整队利益。阿勒赤交出半张峡路图，随后又带走另一半，两人形成既欠命又争路的关系。车队通过九折峡，白石商盟第一次拥有不经军府许可的北部通道战绩。

**下一阶段为何自然发生：** 峡中颠簸撞裂定山石的外壳，露出的内部纹路始终偏向三炉会新发现的废弃矿区。方绛必须确认自己运的究竟是不是定山石，而闻炭已经开始封锁通往矿区的道路。

### 阶段3｜矿井里的两份价钱

**为什么现在发生：** 闻炭秘密开采新坠铁矿脉以偿还军府债务，矿下却接连出现失重矿车和方向错乱的支洞。青檐宗派来的叶桐认定这些异常证明矿脉压着古重泉；方绛若不能确认货物来历，整趟九折峡战绩都会变成替人运赃。

**谁想要什么：** 闻炭要在消息公开前运出足够坠铁；叶桐要找到能证明青檐宗继承权的记录，也准备把部分证据卖给军府换自由；方绛要保住车队与商盟名声；岑野既想见矿脉深处的坠铁纹路，也想让三炉会里曾轻看杂工的人重新看他。

**主角的关键选择与行动：** 他本可护送疑似定山石离开，却因看到旧运道中仍在自行摆动的铁链，跟叶桐下井。矿井塌陷时，他没有抢最完整的坠铁，而是沿古人留下的短钉孔试出移动锚点，用截来的牵力撞开两辆坠车，救出被闻炭封口后仍被迫开工的矿工。事后他拿救人经过和矿下记录逼闻炭重铸八枚短钉，又答应为叶桐保留一份未经宗门删改的拓本。

**这一阶段真正的阅读满足：** 岑野不再只会等敌人把招式送上门，而是从具体矿道结构中争到一种能与异常真正组合的新本事；他曾经只能打磨废料的地方，也第一次有人等着看他怎样使用一件器物。

**Stage Delta：** 岑野进入四阶，获得八枚坠铁短钉并学会悬钉法，能把移动矿车、锁链和兵器短暂变成承力点。叶桐成为唯一与他共同掌握完整矿下拓本的人。闻炭没有停止开矿，但撤走了最危险支洞的工人，并开始把岑野视为可能毁掉债务计划的知情者。矿道纹路证明车队所载之物与古代转移压力的结构有关，却仍不能说明它把压力送往何处。

**下一阶段为何自然发生：** 叶桐发现矿道纹路与悬河古道旧石门上的图样一致。她必须赶在青檐宗内门队伍前取得旧档；方绛也需要知道那块石头会不会在下一次压潮中反噬车队。

### 阶段4｜悬河旧档

**为什么现在发生：** 悬河进入一年中可以通行的三个月，季秋实派出的内外门队伍开始重开古道。叶桐若错过这次机会，矿下拓本便不足以换来任何自由；青檐宗则必须先于军府证明自己对古重泉的继承权。

**谁想要什么：** 叶桐要取得旧档并保留决定交给谁的权利；青檐宗内门领队要把旧档完整带回，宁可封死其他出口；方绛要确认定山石的真正用途；岑野想看倒挂船坞，也想得到一份不以入宗为条件的正式修炼资格。

**主角的关键选择与行动：** 青檐宗提出以内门名额交换全部拓本和定山石，岑野一度愿意接受，因为那正是他少年时没有得到的位置。得知内门领队准备牵塌石门、把滞留古道的普通采水人一并封在里面后，他改变主意，与叶桐公开留下副本。五阶领队沿倒流河压下整座石门时，岑野把短钉钉入逆流船板，截走石门力路并从移动船体重新打出，第一次正面迫使五阶修士退让。

**这一阶段真正的阅读满足：** 内门资格真实摆在岑野面前，他却不是因为抽象正义拒绝，而是不肯让一个仍有人生活、有声音的地方被处理成一份继承证明。悬钉法与截衡也完成第一次让高阶修士公开改口的复合战绩。

**Stage Delta：** 岑野达到五阶边缘，拥有能击破五阶单次重招的公开战绩，但持续施术和身体承受仍弱于真正五阶。旧档揭明，方绛所载并非普通定山石，而是古代移动城池使用的转压石芯：它不会凭空消除压力，只会把一处承受的重量送往预先连接的另一处。叶桐失去顺利进入内门的道路，却拿到能同时与军府、宗门谈判的证据。青檐宗开始追索两人，方绛则再也不能把石芯当作普通货物交差。

**下一阶段为何自然发生：** 旧档标出的另一端正在北境旧军堡附近，而那正是阿勒赤准备夺取的冬季据点，也是裴照川规划中的迁城走廊。与此同时，林绢所在的桥工队已被征调去铺设南迁浮桥。

### 阶段5｜谁的旧堡

**为什么现在发生：** 大压潮的第一轮征兆出现，裴照川提前启动边城迁移。赤翎部族与边城居民同时需要旧军堡附近唯一稳定的冬季高地；转压石芯若在那里重新连接，可能保住一段道路，也可能把压力送进另一群人的营地。

**谁想要什么：** 裴照川要在争执扩大前清空走廊；阿勒赤要占住旧堡，不让族人南迁后受制于军府；林绢要让新式浮桥先承载普通居民，而不是先给军械车让路；方绛要把九折峡商道变成有偿迁移线路；岑野想保住林绢所在的桥，也不愿把阿勒赤曾交给自己的路卖成一次伏击。

**主角的关键选择与行动：** 裴照川以军职、纯泉修炼和家属安置为条件，要岑野帮助压塌旧堡外墙。岑野没有接受，也没有站到阿勒赤一边死守，而是把军府准备动手的时间告诉阿勒赤，逼他撤出非战斗人员；随后与林绢把浮桥接到旧堡侧坡，让边民和赤翎老弱在同一夜分批通过。他因此放弃了最稳妥的六阶资源，还亲手截走军府施术保护桥面，使裴照川的第一轮清场失败。

**这一阶段真正的阅读满足：** 主满足不是获得新力量，而是旧关系真正改变世界事件的走向：岑野因林绢留下，因阿勒赤没有彻底倒向军府，又因自己厌恶被当作工具而拒绝最优上升路线。旧堡之争没有被和解成大团圆，但原本会正面相撞的迁城队伍与部族骑队被迫改变时间和位置。

**Stage Delta：** 林绢拥有了自己的桥工队，也明确拒绝跟随岑野继续远行；两人恢复身体与生活上的亲密，却不许诺相同终点。裴照川将岑野列为不能直接下令、又不能忽视的独立强者。阿勒赤撤出老弱后仍占据旧堡，并带走转压结构的一部分。迁城因此延误，旧矿和北路必须承担更大的下一轮压力。

**下一阶段为何自然发生：** 要让三座边城全部转移，现有石芯和道路远远不够。悬河旧档显示，白石盐海浮岛上的古船坞曾经制造过同类转压结构；方绛决定亲自去找，也要借此取得一条军府无法收回的海上商路。

### 阶段6｜贴着盐海行船

**为什么现在发生：** 白石盐海在大压潮前出现一批新浮岛，能够进入的时间只有一个航季。方绛需要古船坞结构来挽救迁城计划，也需要一艘真正属于自己的盐海船；岑野则从未见过像墙一样倾斜的海面，明知军府提供的修炼机会更稳，仍选择上船。

**谁想要什么：** 方绛要取得船和航路，不愿把发现全部交给军府；裴照川要能复制转压结构的实物；追来的青檐宗长老要收回悬河旧档；岑野想亲手驶过盐壁，并确认古代人究竟如何让整座城市改变承力方向。

**主角的关键选择与行动：** 浮岛下沉时，岑野没有去抢最完整的古代兵器，而是登上正在脱离船坞的侧帆船，逐根夺走青檐长老施加在船链上的七阶牵力。他用悬钉在倾斜船壁、断链和浮岛石柱之间换位，把同一条力路接到浮岛另一侧，让船从横向坠落变成贴海滑行。方绛要求他把船登记为商盟资产，他拒绝只领赏钱，坚持以共同冒险者身份占有船的一份。

**这一阶段真正的阅读满足：** 岑野在读者已经理解的六阶尺度上，利用七阶强者的认真出手夺下一艘真正令人想要的船；盐海奇观、追逐和高价值占有同时成立。旧石芯也得到震撼式重释：它不是某座城的孤立遗物，而是古代移动城池之间交换承压位置的部件，但这种系统依旧不能解释坠铁年份、沉骨井骨架或三名九阶失踪。

**Stage Delta：** 岑野稳定进入六阶，能在大型结构中截取决定方向的单一力段，并与悬钉法连续换位使用。他与方绛共同占有一艘侧帆船，拥有进入盐海和运输大型定山器的真实能力。方绛不再把他视为可雇佣的护运者，两人转为会争夺决策权的合伙人。古船坞结构证明迁城可以完成，但必须放弃一部分旧城区，并由多方同时守住不同承力点。

**下一阶段为何自然发生：** 第二轮大压潮比裴照川预计早到半年。地方城主仍隐瞒真实规模，不肯放弃矿税与祖城；旧堡、浮桥、九折峡新路和侧帆船必须在同一轮撤离中同时发挥作用，而每一方都不愿把最后决定权交给别人。

### 阶段7｜三城改道

**为什么现在发生：** 大压潮全面抵达，三座边城已不可能完整南迁。裴照川决定舍弃北城旧区，地方城主却封闭南门，企图用居民和军械守住自己的兵权；阿勒赤的骑队也沿安全带南下，迁城走廊随时可能变成战场。

**谁想要什么：** 裴照川要牺牲部分城土换取大多数人存活；地方城主要保住城、税源和自己的军队；阿勒赤要让族人带着牲畜通过，而不是被迫交出武器成为流民；方绛要保住车队和独立路线；林绢要让浮桥撑到最后一批普通人过河；岑野既想阻止城门屠杀，也不肯替任何一方决定谁天生更该被留下。

**主角的关键选择与行动：** 岑野放弃追取压潮中短暂显露的九阶旧王遗迹，回到已经开始断裂的南门桥。他要求方绛先卸货载人，又把自己占有的侧帆船交给林绢作为浮桥外锚；这会毁掉他们刚得到的海船，也使商盟失去最值钱的货。地方城主以整片城门区压住撤离桥时，八阶岑野截走核心力段，经悬钉、船体和古转压槽把压力送回城墙内侧，让对方自己的阵势失去站立处。随后他没有替裴照川占领全城，而是亲自守住阿勒赤与边民共用的最后一段通道，迫使军府接受两支队伍同时撤离。

**这一阶段真正的阅读满足：** 开局幻想在城市尺度上兑现：高阶强者越认真压下整座城门，越把决定胜负的力量送到岑野手里。与此同时，胜利并不抹平代价——旧城区、侧帆船和一部分矿井被永久留在压潮中，林绢、方绛、阿勒赤与裴照川也没有因此变成同一阵营。

**Stage Delta：** 岑野进入八阶，完成截取大型力路关键段的高阶质变，并留下足以改变各方估价的城门战绩。三座边城只迁出两座半，旧矿区沉入高压带。林绢失去侧帆船外锚，却保住桥工队和大部分撤离者；她决定沿新城链继续修桥，不随岑野去下一处奇观。方绛失去昂贵货物，却取得九折峡、迁城路和盐海三段彼此相连的贸易权。阿勒赤获得暂时冬地，却仍要与军府争夺来年路线。裴照川保住迁城主力，也承认岑野不是军府所属。

**下一阶段为何自然发生：** 三城危机已经结算，但被舍弃的旧城区没有消失，而是随改变方向的地面缓慢移向沉骨井一带。岑野曾放弃的九阶遗迹仍在移动，林绢的新桥线、方绛的海路和阿勒赤的冬地也各自生出新的生活与敌人；他第一次不再需要靠别人的招募离开，却仍然想亲眼看看那座正在移动的废城会去哪里。

## 远期仍值得追的东西

- 岑野与林绢已经确认彼此的身体吸引和现实牵挂，却仍没有共同生活的固定答案；林绢的桥线可能把她带到与岑野完全不同的地方。
- 方绛失去第一艘侧帆船后，仍想建立不受军府控制的盐海船队。她与岑野共同拥有的不是安全同盟，而是一笔谁也无法单方面结清的旧账。
- 叶桐手中的悬河旧档副本仍能改变青檐宗的重泉继承权。她可能用它换自由，也可能发现自由的价格比归宗更高。
- 阿勒赤得到的冬季据点只能解决一年，赤翎部族内部关于南迁与北返的争执并未结束。
- 随地面移动的半座废城正在接近沉骨井；井底骨架与九阶修士失踪仍各自成立，不能仅凭相邻位置认定它们属于同一个答案。
- 岑野尚未真正进入旧王陵群，也没有亲眼见过完整九阶修士怎样把巨桥当作承力器。他已经能夺用八阶强者正在施展的关键力量，却仍无法截走天然压潮，更无法同时处理两条相反的力路。
- 三炉会的新矿脉仍在开采，矿井转压之后究竟把长期压力送往何处尚未查清；闻炭偿清军府债务后会选择公开矿脉、独占它，还是另投更强势力，仍由他自己的欲望推动。

### Inspiration 1
source: mechanisms/thread-collision-v3
type: mechanism
score: 0.281

可用抽象：Creative Problem：怎样让一个大事件真正合流 main plot / relationship / mystery / power / world 中的若干条线，而不是只是把很多角色叫到同一场？
Mechanism：成熟的碰撞点需要一个共享因果铰链和一个不可回避的选择。这个选择同时改写若干线程的未来可行性：某条安全路径关闭、某段关系换位、某个谜团获得新解释、能力意义变化、阵营或世界事实改变。强 payoff 往往还有 narrative afterlife：旧目标完成后，其结果自然成为新承诺、新敌人、新生活问题或第二层解释。
Variants：- 身份暴露：安全表层生活关闭，关系和敌我同时重写。
- 牺牲/死亡：结算追捕或冲突，同时生成复活、继承、独立行动或新敌人。
- 旧物终局用途：同时结算谜团、身份与能力来源。
- 生活性仪式被大冲突劫持：婚礼、约战、重聚同时结算关系和旧敌。
Guidance：不要求每次凑齐五栏。判断一个 thread 是否真的参与碰撞：移除它后，这个事件的选择、结果或后续可行性是否会改变？
Failure Modes：- 角色都到场但因果互不相干。
- 为了“大高潮”塞入尚未成熟的线。
- payoff 只关旧问题，不留下任何后续状态。
- 强制每个高潮都要求多线合流。

使用边界：迁移共享因果铰链与 narrative afterlife；碰撞强度由共同选择实际改写了多少线程的未来来决定。

### Inspiration 2
source: mechanisms/reunion-reentry-v3
type: mechanism
score: 0.0912

可用抽象：Creative Problem：角色离开很久、被误认、身份变化甚至曾被认为失去后，怎样让归来本身成为 delayed payoff，而不是一见面就恢复原状？
Mechanism：第一次接触先暴露时间造成的不匹配：外貌、能力、气质、身份、价值判断、伤痕或团队中的新空位。通过旧物、旧动作、共同记忆、能力习惯、称呼或只有双方理解的反应逐步确认。认出彼此后仍保留至少一个当前现实障碍，并用一个新的共同动作、合作方式、边界或承诺证明“这个人重新进入了关系，但不是回到过去”。
Variants：- 互相认不出：成长本身成为重新确认的障碍。
- 公共死亡后的秘密归来：活着并不等于能恢复旧社会身份。
- 团队重聚：先看见缺席与变化，再通过当前压力重新磨合。
- 复活/恢复：真正 payoff 落在重新回应、照护和重新参与行动，而不是状态栏恢复。
Reader Payoff：长期缺席积累的期待，通过肉眼可见的变化和关系重新选择一次性兑现；读者既得到“终于回来”，又得到“回来以后已经不一样”。
Guidance：不要用等级汇报替代重逢；不要让所有人瞬间无缝认出。把回归者的新状态放进当前冲突中验证。
Failure Modes：- 出场即拥抱，时间没有留下痕迹。
- 只报新能力/等级，没有关系重新确认。
- 重逢抹掉离队、死亡或身份变化造成的后果。
- 场景结束后没有新的合作入口或关系边界。

使用边界：只迁移“变化后重新辨认→仍有障碍→重新进入关系/行动”的结构，不迁移源角色或具体回归方式。

### Inspiration 3
source: mechanisms/departure-vacancy-v3
type: mechanism
score: 0.0912

可用抽象：Creative Problem：角色离队、失联、沉眠或暂时不可用后，怎样让这次缺席真正改变后续故事，同时允许长线自然沉睡而不是频繁提醒？
Mechanism：离开前先让人物完成一个符合自身欲望的决定、期限、拒绝、交接或目标；离开后尽快用一个新的选择、失败、机会或敌人反应证明“旧状态已经结束”。有人会第一次自己行动，有人失去过去可依赖的选择，有人会利用空位，也可能有人因此获得新的自由。若 Canon 已有期限、物件、缺席位置或未完成承诺，可以把它作为召回器，然后允许人物长时间退出主镜头。
Variants：- 主动离队证明自己：离开源于人物自己的目标，回归时以行动证明变化。
- 保护者/核心人物离场：留下者开始重新决定怎么活、怎么行动。
- 沉眠/失联：共同目标拆成其他人物自己的长期行动。
- 群像换挡：旧中心离开后，配角不是接班工具，而是各自沿自己的欲望继续。
Reader Payoff：读者真正感到“这个人不在了”，同时拥有一个可记住但不需要每章提醒的长期期待。
Guidance：Dormancy 不是遗忘。保留一个高辨识召回器即可；下一次提醒最好来自当前事件重新碰到旧期限、旧物、缺席位置或人物留下的实际后果。
Failure Modes：- 告别很长，但离开后什么都没变。
- 每隔几章机械提醒“他还在外面成长”。
- 留下者自动无摩擦接替全部功能。
- 还没形成缺席感就立即回归。

使用边界：只迁移“离开→空位/新选择→长线沉睡/召回”的因果，不迁移具体离队理由或回归奖励。

### Inspiration 5
source: mechanisms/hidden-identity-long-v3
type: mechanism
score: 0.1702

可用抽象：Creative Problem：隐藏身份怎样跨长篇维持而不靠强行藏答案？揭露后怎样真正改变当前故事？
Mechanism：先让表层身份独立成立并积累真实后果：朋友、爱情、债务、名声、信任与社会位置都是真实的。线索应尽量同时兼容旧解释与新解释；揭露落在人物正在行动的碰撞点，并立刻关闭或改写一条现实路径，例如安全身份失效、继位失败、归乡目标改变、某人开始被追杀。揭露重解释过去，但不删除过去。
Variants：- 长期潜伏者。
- 异类/血脉身份。
- 多个真实社会自我。
- 错误预言/公共误读逐渐追上现实。
Reader Payoff：“原来如此”与“接下来怎么办”同时出现；过去的普通场景获得第二层意义，而当前关系不能再按旧方式继续。
Guidance：设计隐藏身份时先写清：表层生活为什么能长期工作；哪些线索在旧解释下也合理；揭露会关闭什么现实选择。
Failure Modes：- 线索从一开始就只支持真相解释，角色长期看不见显得失智。
- 揭露只补背景，不改变当前选择。
- 宣布是假身份后把此前关系全部清零。
- 为反转而多层套娃。

使用边界：《斗罗大陆》《诡秘之主》《将夜》直接支持长期隐藏身份/身份重释；《修真聊天群》只提供“公共误认逐渐追上现实”的邻近证据。迁移揭露后的关系与行动变化，不把公共误认等同于长期潜伏身份。
