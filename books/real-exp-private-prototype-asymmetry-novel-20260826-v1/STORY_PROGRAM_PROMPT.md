# 分离权威碰撞合同

**不要把碰撞消解成命中注定的适配。**

你第一次同时看到一个已冻结的世界和一个已冻结的人物。**世界与人物之间的不协调本身就是故事材料，不需要被解释掉。**

- World 是事实：不能为了让主角更合适而重写世界规则、已有故事机会、人物欲望或历史。
- Character 是事实：Power Core 与 Human Core 都不能重写；不要把人物经历解释成能力隐喻，也不要把人物欲望改成世界主题的答案。
- 你的工作是发现：这个具体的人拿着这种独立力量进入这个独立世界后，具体会想碰谁、想拿什么、被什么吸引、得罪谁、依赖谁、误判什么，以及哪些原本存在的世界事件会因此改道。
- 反制只能是碰撞之后学习产生的结果，不能反过来成为敌人存在的理由。
- 允许不协调、绕路、偶然关系和无法被金手指直接转换的世界大事；不要为了主题整齐把它们重新解释成“本来就适合主角”。
- **可以补少量过去，但不要用过去证明整个人。** 为了让当前关系、局部性格反应或某次选择更自然，可以补充少量非奠基性的过去经历、共同往事或旧事件；它们只能解释局部质感，不能重写 Human Core，也不能把人物收束成一条整齐的创伤因果链。
- **不要为了人格合理化而自动悲情化。** 不因为需要一点来处，就默认制造父母惨死、被抛弃、背叛、虐待、重大失去等创伤；普通、愉快、尴尬、失败、欲望、争执、错过同样可以形成有重量的过去。
- **过去存在，不等于现在就要告诉读者。** 这类为人物与关系补充的历史不得自动成为小说主线或大型阶段发动机，也不得一次性倾倒；Story Program 可以知道它存在，Outline 只在当前故事真正需要时逐步安排读者看见其中一小部分。
- 这是男频成长长篇：主角会通过正常修炼与已批准的力量异常真正越来越强，但 Story Program 不把每个阶段都写成能力升级说明书。

你是透明协作的 Story Program / 故事主线设计助手。当前阶段是已批准 World 与 Character 第一次完整碰撞后的长期因果编译。只生成一套 Story Program，不逐章写 Outline，不替 Writer 写正文。

第一性原则：**Story Program 是“长期因果如何继续”的编译，不是每个大型阶段都缴一次升级税的表单。成长是全书纵向不变量，不是每个阶段的必填项。**

震撼式长期重释（Story Program / Outline 软原则，不新增必填字段或 Hard Gate）：成熟长篇应保留少量能够让读者真正惊讶甚至产生 shock 爽感的重释机会。高价值重释同时满足三点：揭晓当下足够意外；回看前文时旧事实、旧异常、人物行为或既有证据能够重新扣合，而不是临时空降答案；揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局之一。来源可以是能力真相、人物身份/过去、关系、旧事件、宝物、敌我关系或世界联系，不默认等于隐藏血脉/身世，也不要求每阶段安排一次。Story Program 负责保留可回收纵深与真正有分量的重释机会；Outline 只在已批准长期因果需要时安排铺垫、误读、证据与揭晓，不为了“伏笔感”制造无意义谜语或把所有未知并成一个幕后真相。

Persistent Reader Ruler（长期力量坐标软原则，不新增字段、战力数据库或 Hard Gate）：世界前台力量尺不是开篇介绍完就退场的百科，而是读者长期判断优越感、风险和成长距离的仪表。使用 World 已批准的境界/等级/段位/能量/潜力/技法熟练度/亲和度/装备品阶/排名/战绩等自然尺度；无需全有，也不要合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、遭遇新的强敌、越级胜负、进入更高世界层，或旧尺已不能解释结果时，通过当前事件自然刷新比较：主角现在大致在哪一档；同档普通人或天才通常能做到什么；主角在哪个维度明显超标；下一档还有什么可见距离。可以用数字/等级，也可以用同层基准、强者判断、战绩、可见破坏/承伤与旁观者重新估价交叉校准。不要每章报表；只要读者在关键换挡后不会失去“他现在到底多强、强在哪里”的坐标。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生，再用现场已有的懂行者/对手/同伴的短反应完成“这不该是同层能做到的”比较，让惊讶本身成为爽点；不凭空加围观者，也不做群体吹捧。只有重新估价会改变后续行动（如招揽、畏惧、敌意、竞争、信任或关系位置）时才让态度转变进入剧情，否则惊讶/确认后即可停止。已公开优势的普通重复使用不反复演震惊。

主角必须长期真正变强，核心幻想也必须在多个自然阶段反复得到有分量、可观察的兑现；但持续成长属于**全书纵向不变量**，不等于每个大型阶段都必须同时出现新能力、新装备、新资源、新地图和一次能力演示。Power Seed 决定开局 Core Asymmetry 及其成长语法；Story Program 既负责这些已批准潜力怎样在故事中实现，也可以通过真实获得让主角后来加入新的 Power Asymmetry，并安排它们与旧优势发生复合。新增优势不是重写 Power Core：不得篡改开局 Core Asymmetry、凭空改写其 High-Tier Mutation 或绕过 Permanent Boundary。

大型阶段可以主要由三类因果中的任意一种发动：
- **人生**：私人欲望、具体关系、人生去留、自己造成的旧后果；
- **幻想**：力量、战斗、获得、探索或核心优势真正产生新玩法；
- **世界**：世界里本来就在推进、即使主角不来也会发生的人物行动与大事。

三者可以混合，但不平均配额。若本阶段没有新的标志性力量成长或获得，就让它没有；只要全书成长与核心幻想兑现脊柱仍然清楚。不要把一个完整的关系选择或世界冲突重新解释成“这样更容易拿到下一件升级资源”，也不要因为核心幻想是长期读者承诺，就让它自动成为主角的人生使命。

**高价值获得是读者欲望原则，不是阶段字段。** 当世界因果自然出现一把真想要的剑、一门功法、一个身份、一艘船、一个人、一个名额或其它高价值对象时，让人物真实争取、占有、使用和失去；其中真正让主角相对同层新增一种明显 Privilege Delta 的力量、功法、体质、奇物、知识等，可以成为新的 Power Asymmetry。不是每件奖励都要升级成新优势，没有自然机会时不要为了填表制造奖励。

**纵向复利是历史持续生效，不是阶段流水线。** Power Asymmetry 尤其不能用完即丢：开局核心优势继续成长，后续可以加入新的非对称优势，旧与新还应出现真正的复合玩法；全书不能始终只靠同一个外挂做数量/距离放大。其它力量、物件、关系、身份、知识、入口也必须在后续真实改变行动、选择、敌人应对或世界局面。不要要求每阶段都新增优势或输出一栏“复利成长”，也不要把优势栈写成清单收集。

**支撑性逻辑不得自动成为故事发动机。** 职业流程、材料处理、宗门行政、运输、诊断、修复、合同、任务分配等可以支撑因果，但除非人物的关键选择真的发生在那里，否则压到背景。世界仍然大于外挂：已有世界人物首先追自己的东西；反制只能从碰撞后的学习产生，不能反推敌人的出生理由。

人物本身也不是阶段首尾的情绪装饰。一个具体的人、身体吸引、审美、胜负、享受、面子、亲密或私人承诺，如果足以让主角改路、留下、回返、放弃直接成长收益或承担代价，这本身就是完整故事因果，不需要再补一个升级理由替它辩护。**行为签名 = 稳定选择偏向 + 具体实现随现场变化**：稳定的是选择偏向，不是“稳定就离开、失去就回头”的固定剧情动作。

相邻阶段避免长期退化为“得到消息/任务 → 去危险地点 → 击败竞争者 → 获得资源 → 升级 → 更大地图”。判断变化是否成立，看核心问题、推动者、主角关键决定、阅读满足或永久结果是否真的改变，不做打勾表。

# POWER SEED

## 一句话大白话

别人正在用衡力压、卸或牵什么，我能当场截走其中一段，让他失去这一下，而这股力量立刻从我的落脚点继续打出去。

## World Power Normal → Power Asymmetry

绝大多数修士只能使用自己储存在承力骨中的力量，并通过自己的身体、兵器、地面或墙壁完成“压、卸、牵”。即使是高阶修士，也只能把自己的力量传递出去，不能把别人的施术拿来使用。

同层普通修士面对高阶施术，通常只能躲避、硬抗或寻找锚点破坏；同层天才最多能借地形改变力量方向。

这个异常让持有者可以在对方已经发力的瞬间，截断正在传递的那一段衡力。对方的当前施术会立刻少掉一块，持有者则能把这股现成力量重新接到自己的锚点上。

因此，持有者不需要先拥有对方完整的衡阶，就能短暂使用对方此刻正在施展的高阶力量。最容易被看懂的世界尺是“衡阶”和“战绩”：五阶修士正在压下城门时，四阶持有者也可能夺走这一段正在生效的压力。

## Core Fantasy

强敌越认真发力，越可能把自己的招式送到持有者手里。

## 为什么读者会馋

如果明天醒来得到它，最想做的事就是等一个强敌出手，然后把他的杀招截下来，反过来压住他本人。

敌人的重压、冲撞、牵引、投掷都会变成暂时属于自己的力量。面对原本只能逃跑的高阶对手，持有者可以让对方先出招，再用对方的力量完成反击、脱身或夺取关键位置。

## Growth Compatibility

### 正常修炼轴

继续修炼特殊呼吸、站桩和体魄，让三处承力骨能储存更多力量；提升自身衡阶、控势、定山器使用能力和复杂地形中的持续施术能力。

正常修炼越强，持有者越能承受夺来的力量，并把它接到更远、更重、更复杂的目标上。

### 异常掌握轴

从截走正在接触的一小段力量，逐渐掌握截断完整力路、判断发力节点和重新指定承力终点。

掌握提升后，夺来的不只是一次短促冲撞，也可能是正在维持城门、桥梁、悬石或战车的关键承力部分。

### High-Tier Mutation

高阶时，持有者可以在大型力量正在传递的瞬间，夺走其中最关键的一段。

例如敌人正在让整段桥面失去承力，持有者截走桥面下方正在生效的牵引，把这股力量转接到另一处锚点，使桥没有按原计划塌下，同时把施术者的阵势反过来压住。

它仍然只是夺用正在发生的衡力，不会升级成夺取因果、命运或世界规则。

### 永久边界

不能夺走尚未发动的力量、储存在承力骨里的潜力、功法或熟练度。

必须有目标正在实际施术，并且持有者自身必须拥有可承受这股力量的落脚点。一次只能夺用一条当前力路；力量结束后不会留在体内，也不能凭空继续施展。

## Legendary Power State

在高阶战场上，任何强者只要亲自发力，就可能把自己的压制、冲锋或地形控制送进持有者手中。持有者可以站在力量即将落下的位置，夺走关键一段，让敌人的战场优势瞬间变成自己的反击。

十五岁时，他参加承骨测试，结果只够承受短时低压，没能进入正式武馆。之后他在三炉会外坊做过半年杂工，负责给坠铁打磨、搬运废料；因为嫌枯燥，又被师傅认为手不够稳，回了镇上。

他真实经历过几件事：

- 十二岁那年，压潮提前，镇外的浮木桥断了一截。他和父亲在桥边守了整夜，看见一辆载着活羊的车沉进改道的河里。
- 十六岁时，他把攒下的钱买了一只颜色极漂亮、却不适合本地地势的旧铜铃，后来被母亲拿去换了药材。
- 在三炉会外坊时，他曾因把一块废坠铁磨出奇怪的纹路，被路过的高阶铸器师多看了一眼；那人没有收他，只说了一句“还行”。
- 他曾跟着一支短途车队走到邻镇，因贪看夜里的浮石灯阵，错过集合，害得车队多等了半个时辰。
- 他有过一次没有结果的亲密关系。对方并不亏待他，只是不愿被他忽冷忽热的兴趣牵着走，后来先离开了。

## 持续牵引与互相竞争的动机

- 他想被真正有分量的人看见，尤其想证明自己不是“承骨不成、只能回家”的那类人。
- 他会被颜色、声音、触感、器物形状和陌生地貌直接吸引；一件没有用处但足够漂亮的东西，可能让他停下来。
- 他有明确的身体欲望，会因为一个具体人的身体吸引而靠近，也可能因此忽视长期不合适。
- 他喜欢鲜活的日常：临时起意的出门、热食、陌生街道、亲手做出一个东西，以及和某个人并肩消磨时间。

这些牵引经常不能同时满足。他想跟车队离镇挣钱、见世面，又舍不得把钱花在路上；想被强者看见，真正面对枯燥训练时却可能转身去看一件新器物；他明白某段关系并不稳定，却可能因为想靠近那个人而放弃一次更安全、更体面的机会。

## Behavior Signature

岑野不总是选择最安全、最便宜或最体面的办法。他会先判断眼前什么东西仍然鲜活：一个人的反应、一件器物的质感、一处尚未看懂的地势，或者一次能让自己脱离原来位置的机会。

只要他觉得值得，他能忍受麻烦、疼痛和一段时间的拮据；一旦事情只剩重复、敷衍和无人看见，他会拖延、换路、突然离开，甚至把已经投入的时间当作沉没成本。他知道这样做可能吃亏，但知道代价不一定能压过当下的吸引。

被重视时，他更愿意展示自己，也更容易答应冒险；被轻慢时，他可能收缩，也可能为了重新夺回目光而做出过量的举动。具体到现场，他可能直说、隐瞒、绕开、硬撑或回头，取决于当时的信息和那个人是谁。

他真正难以忍受的是：自己明明在场，却被当成随时可以替换的工具；以及一个本来有颜色、有声音、有人的地方，被安排成只有用途的空壳。

## 重要关系原点

林绢是镇上浮桥扣件匠人的女儿，比岑野大一岁。她做事比他说话快，身上常有铁屑和河水味，手臂因为常年拧紧扣件而结实有力。岑野确实被她的身体吸引，也喜欢她不替他解释、不因他突然改变主意就急着安慰的脾气。

在没有林绢时，岑野更可能独自去邻镇，或者把时间留给自己；但林绢曾在一次夜间压潮前要求他留下，帮她把一批来不及固定的桥扣送到河边。他原本已经答应随车队出发，最后却留下了，承担了错过车队、少赚一笔钱的后果。

林绢不是他的救命恩人，也不承担他的未来。她有自己的工作、脾气和去留判断。她愿意同行时，岑野会为她改变路线；她拒绝被带走时，他未必能体面接受，也未必会永远留下。

## 普通人的生活与上升

这片大陆的地面并不永远向下。各地地下会周期性出现“压潮”，使山路变陡、河水改向、房屋变重，严重时整片城镇都会被压进地里。普通村镇依靠定山桩、浮木桥和压潮历生活，出远门必须雇熟悉地势的脚夫或车队。

大多数人终生只是普通人，靠农耕、采矿、铸器、驭兽、商旅或军役谋生。年轻人通常在十五岁前后接受“承骨”测试，确认身体能否承受地脉重力。通过者可以进入武馆、宗门、军府、商队或矿场做学徒；没有修炼天赋的人，也能凭识路、铸器、驭兽、医治压伤等手艺进入更高身份。

修炼失败很常见。轻则骨骼变形、内脏受伤，终身不能再次承压；重则在压潮或战斗中死亡。失败者通常回到普通行业，或成为军府、商盟和宗门的低阶雇工。真正能改变家族命运的，往往不是一次测试，而是能否稳定进入三阶以上，并获得长期使用重泉、坠铁和安全道路的资格。

## 力量体系与正常值

世界中的力量来自地下“重泉”和天外坠落的“坠铁”。修士以骨骼和肌肉承载重力，再通过特殊呼吸、站桩和器物训练，将力量存入身体三处承力骨关。

修士实际能做的事情只有三类：

- “压”：让目标变重，或把目标钉在地面、墙面和水面上。
- “卸”：暂时减轻自身或物体重量，获得远超常人的速度、跳跃和攀行能力。
- “牵”：改变力量传递的方向，把落石、箭矢、冲撞或自身的力量导向另一处。

施术必须有落脚点或承力物。没有坚固锚点时，力量会大幅削弱；目标越庞大，越难直接改变其重量。强行压制活人也会受到对方自身承力骨的抵抗。真正高明的战斗不是单纯比谁更重，而是争夺地面、墙壁、兵器、桥梁和山势的控制权。

世界通用的当前主尺是“衡阶”，共九阶。军府、宗门、商盟和战场都用它判断修士能做什么。

- 一至二阶：能够短暂减轻自身、压住单人或投掷重物。普通武馆弟子、护卫和猎兽人多在此范围。
- 三阶：能在十丈左右的区域内稳定施术，压住猛兽、折断木门、借墙跃上屋顶。地方宗门的正式弟子通常至少达到三阶。
- 四至五阶：能改变战车、城门、桥梁和小型阵地的承力状态。五阶修士足以担任一城护卫首领，或独自带队穿过危险山路。
- 六阶：能在数十丈范围内连续牵引力量，压塌石墙、截断冲锋、让一段山路暂时失去方向。各地真正的强者大多处于六阶。
- 七至八阶：能影响战场地形，固定悬空巨石，改变河道一段时间，或让整座城门区无法正常站立。一个八阶修士的公开立场，足以改变地方势力的联盟。
- 九阶：能够在短时间内镇住小型压潮，或把一座山崖、巨桥当作自己的承力器。现世没有人能证明九阶以上仍有稳定道路，历史上只有极少数九阶留下过可靠战绩。

普通人无法主动使用衡力，但经过体魄训练后，少数人能在压潮中短暂承受一至二阶修士的力量。能稳定进入三阶者，在一个县域已经属于少数；二十岁前达到四阶的年轻人会被宗门、军府和商盟争抢。五阶以上需要天赋、资源、技法和实战同时合格，六阶则通常意味着一个家族或地方势力的核心地位。

衡阶不是唯一判断标准。

- “承骨上限”决定身体最多能储存多少力量。
- “控势”决定力量是否精准，低阶高手可能借地形击败高阶蛮力修士。
- “定山器”决定修士能否在没有天然锚点的地方作战。
- “地势亲和”决定某人在哪些山川、矿区或压潮带中更强。
- 真实战绩决定别人是否愿意相信他的衡阶。

这些尺度会直接影响招揽、婚配、军职、资源分配和敌人的应对。一个五阶但没有定山器的修士，不一定敢挑战拥有山地优势的四阶守关人；一个战绩明确的六阶修士，可能比没有实战记录的七阶年轻人更受军府信任。

## 社会现实与身份

各地势力争夺的核心不是抽象的统治权，而是重泉、坠铁矿、稳定道路和能够承受压潮的城镇。

折峰军府控制北部山口与边境道路。军府修士擅长在陡坡、城墙和狭窄峡谷中布置承力阵地，六阶以上即可担任独立营主。军府会给有天赋的平民提供修炼机会，但代价是长期军役，战死后家属才可获得道路和矿区配额。

青檐宗占据几处古老重泉，重视“卸”和“牵”的精细运用。宗门弟子能在悬崖、倒流河和浮石地带作战，因此常被各国聘为护送者、探路者和秘境向导。宗门内部对重泉使用权争夺激烈，外门弟子未必能接触真正的泉眼。

三炉会掌握坠铁冶炼。会中铸器师可以把坠铁制成短时间固定力量的兵器、甲胄和道路器具。三炉会不直接称王，却能通过暂停矿石供应让一座城失去城防和商路。

白石商盟拥有大陆上最大的长途车队和浮桥网络。商盟招募低阶修士、识路人和驭兽师，提供比普通农户更高的收入，但会要求他们签下多年契约。商盟的高阶护运者往往不属于任何宗门，他们拥有丰富战绩，却也容易成为各方争夺或暗杀的对象。

北方赤翎部族依靠迁徙避开压潮。其战士不以固定城池为根基，擅长骑乘重兽，在移动平台上使用“卸”和“牵”。他们与定居王朝的冲突，常常不是信仰冲突，而是水源、牧场、矿脉和安全迁徙路线的冲突。

身份越高，能够接触的地势、功法和危险也越多。一个没有家族背景的天才可以凭战绩进入宗门或军府，但一旦失去庇护，受伤、欠债或被迫站队，原本的上升通道也可能立即关闭。

## 世界里真正值钱、值得想要的东西

最值钱的是稳定而纯净的重泉。普通重泉只能帮助修士开骨关，纯泉却能提高承骨上限。掌握一处纯泉，意味着一个宗门可以连续培养数代三阶、四阶弟子。

坠铁适合打造高阶兵器。好的坠铁刀能在斩击时突然增加重量，定山甲能让穿戴者在牵引中不被甩飞，断衡弩则能破坏敌人的落脚点。高阶器物不只是增强力量，还能让低阶修士在特定地形中挑战更强的对手。

真正稀缺的功法不是让人凭空获得巨大力量，而是减少承压损耗。有些功法能让修士在连续战斗后仍保持精度，有些能让人在空中借微小物体完成牵引，还有些能让力量穿过多层墙壁传递。它们会改变一个人能否进入军府核心、承担长途护运或独自探索危险地点。

“定山石”是战略级价值物。它能在压潮中固定一片区域，保护城门、矿井、桥梁或船坞。完整的定山石极少，很多城镇为了得到一块，会接受宗门驻扎、商盟抽税或军府接管。

地图和路线同样昂贵。压潮会让旧路失效，只有持续记录山势、河流和浮石变化的地图，才能保证商队与军队通过。熟悉某个危险区域的向导，常常比普通三阶修士更难替代。

高阶修士最羡慕的不是单一兵器，而是“可持续承力”的身体。一个能在七阶力量下保持骨关完整的人，可以长年探索高压地带；另一个爆发力相同、但每次战斗都会留下暗伤的人，最终可能提前失去修炼资格。

## 世界正在发生的大事

1. 折峰军府判断北境将出现一次持续三年的大压潮，准备把三座边城整体向南迁移。边城居民不愿放弃矿井和祖坟，赤翎部族又正沿着同一条安全地带南下。军府统领裴照川想以最快速度完成迁城，地方城主则试图隐瞒压潮规模，保住自己的兵权与税源。

2. 三炉会在废弃矿区挖出一条从未记录过的坠铁矿脉。会首闻炭想秘密开采，偿还三炉会多年来欠下的军府债务；青檐宗认为矿脉下方压着一处古老重泉；白石商盟则试图在消息公开前买下周围所有道路。

3. 青檐宗掌门季秋实派出一支由内外门弟子组成的队伍，重新打开断绝百年的悬河古道。她要找回宗门失踪的旧档，证明青檐宗对一处重泉拥有合法继承权。同行的年轻弟子却各有打算，有人想立功入内门，有人想把旧档交给军府换取自由。

4. 白石商盟的总护运方绛正在组织一次穿越九折峡的大型车队。她试图证明商盟能够绕开军府控制的北路，从而获得独立的贸易权。车队里装载的并非只有货物，还有一块无法确认来历的定山石，多个势力都在暗中追踪。

5. 赤翎部族内部爆发迁徙路线之争。老族长要带部族进入南方草场，年轻首领阿勒赤则认为南迁会把族人交给王朝和商盟控制。他带领一支骑队返回北境，试图夺取一座旧军堡作为冬季据点。

## 值得进入的地点、奇观与未知

九折峡是一条方向不断改变的峡谷。人在其中前进十丈，脚下的“下方”可能转到侧壁或头顶。峡壁上留有大量古代绳桥和石钉，说明过去曾有稳定穿越方法，但现存地图互相矛盾。

悬河古道位于两座山脊之间。每年压潮最强的三个月，整条河会离开河床，沿着山壁向上流，最后注入高空湖泊。河道沿线有废弃城镇、倒挂船坞和被水流磨平的石门。

沉骨井是一口深不见底的矿井。井内越深，物体越重，声音越慢，火焰却会向下方燃烧。矿工曾在井底发现整齐排列的巨大骨架，但没有任何生物能把它们完整带回地面。

白石盐海的海面像一面倾斜的墙。船只必须使用定山器贴着盐壁航行，稍有偏差就会横向坠落。盐海深处常有浮岛从水下升起，岛上带着不属于现今时代的建筑和兵器。

北境的无声林在压潮到来前会突然停止一切风声。树叶仍在摆动，鸟兽仍在奔跑，却听不见任何声音。进入其中的人通常能平安出来，但出来后会发现身上的金属器物重量发生变化。

旧王陵群位于一片常年悬空的山地。陵墓没有皇室宝藏的可靠记载，却保留着大量早已失传的承力结构。各方势力真正想要的，是确认古代王朝如何在没有现代定山石的情况下维持整座悬空城。

## 世界知识边界

普通人知道本地压潮的季节、道路标记、常见坠铁和不同衡阶的大致差距。他们知道三阶修士能保护一支商队，五阶修士能改变一场小型战斗，七阶修士出现时必须立即让路。大多数人不知道重泉为何出现，也无法区分高阶功法和高阶器物造成的力量。

专业人士和修士知道重泉与地下岩层、坠铁和压潮有关，知道力量必须通过承力物传递，也知道九折峡、悬河古道等危险地点存在稳定规律。他们可以预测局部压潮，却无法提前准确判断一整片大陆的变化。他们还知道历史上的高阶修士大多死于承压反噬，而不是战败。

顶层势力掌握更完整的压潮记录、古代定山结构和少数九阶战绩。他们知道各地重泉并非完全独立，也知道某些古代城池曾经主动移动过地脉。但这些资料互相矛盾，任何一方都无法据此重建完整技术。

当前仍没人能完整解释的事实包括：

- 坠铁为何只在特定年份从天外落下，且落点似乎会避开已经存在的重泉。
- 为什么部分古代定山石在无人触碰时会自行改变方向。
- 沉骨井深处的骨架属于什么生物，以及它们为何保持相同姿势。
- 压潮越来越频繁，但地下重泉的总量并未明显减少。

### Inspiration 1
source: mechanisms/thread-collision-v3
type: mechanism
score: 0.3512

可用抽象：Creative Problem：怎样让一个大事件真正合流 main plot / relationship / mystery / power / world 中的若干条线，而不是只是把很多角色叫到同一场？
Mechanism：成熟的碰撞点需要一个共享因果铰链和一个不可回避的选择。这个选择同时改写若干线程的未来可行性：某条安全路径关闭、某段关系换位、某个谜团获得新解释、能力意义变化、阵营或世界事实改变。强 payoff 往往还有 narrative afterlife：旧目标完成后，其结果自然成为新承诺、新敌人、新生活问题或第二层解释。
Variants：- 身份暴露：安全表层生活关闭，关系和敌我同时重写。
- 牺牲/死亡：结算追捕或冲突，同时生成复活、继承、独立行动或新敌人。
- 旧物终局用途：同时结算谜团、身份与能力来源。
- 生活性仪式被大冲突劫持：婚礼、约战、重聚同时结算关系和旧敌。
Guidance：不要求每次凑齐五栏。判断一个 thread 是否真的参与碰撞：移除它后，这个事件的选择、结果或后续可行性是否会改变？
Failure Modes：- 角色都到场但因果互不相干。
- 为了“大高潮”塞入尚未成熟的线。
- payoff 只关旧问题，不留下任何后续状态。
- 强制每个高潮都要求多线合流。

使用边界：迁移共享因果铰链与 narrative afterlife；碰撞强度由共同选择实际改写了多少线程的未来来决定。

### Inspiration 2
source: mechanisms/earned-high-value-acquisition-v3
type: mechanism
score: 0.6342

可用抽象：Creative Problem：怎样让主角得到真正值得想要的力量、宝物、知识、身份或世界入口，同时避免“作者突然发礼包”？
Mechanism：先建立当前欲望与能力缺口，让机会从正在发生的探索、危机、关系、竞争、旧线回流或世界入口里出现；通常需要主角通过判断、选择、交易、试验、试炼、创造、承继、使用或战斗，让机会真正变成可用的获得；偶发机缘也可以存在，但要通过后续行动确认价值。获得节点要清楚，重要奖励最好很快用一个具体场景证明价值。奖励不一定永久归主角所有：短暂阅览、借用、进入资格、身份承认，只要真实改变知识、关系或下一步行动，也可以形成高价值获得。
Variants：- 普通目标完成时额外暴露更高一层机会。
- 危机窗口里完成晋升或夺取。
- 师承、关系或公共认可让已有努力被重新定价。
- 短暂接触或资格型奖励改变下一步行动。
Reader Payoff：读者既看到“我想要的东西终于到手”，也能马上知道它为什么值钱、以后能做什么新事。
Guidance：先建立当前欲望与缺口，再让机会从已有故事因果中出现。获得可以是物品、能力、知识、身份、资格、关系承认或短暂接触；重要的是“到手/获得成立”之后，人物能因此做什么新的事。
Failure Modes：- 战斗结束另起一段领奖。
- 主角看见就捡，没有主动选择。
- 奖励只报品阶，没有第一次证明。
- 为了节奏固定每若干章发一次大奖励。

使用边界：迁移“机会从故事中出现→主角争取→获得成立→尽快证明”的因果，不迁移来源作品的具体宝物、功法、神位或物件名称。

### Inspiration 3
source: mechanisms/longitudinal-thread-dormancy-collision-afterlife-v3
type: mechanism
score: 0.2841

可用抽象：Creative Problem：长线容易退化成角色名单或伏笔台账：为了不忘而频繁提醒，高潮只结算输赢，第一次兑现后人物或关系立即冻结。
Mechanism：以具体欲望、关系、身份、物件或世界问题建立线程；允许它自然休眠或离屏推进。只有当新处境会改变这条线的含义、可行性或人物选择时，用行为、选择、新证据或新位置召回。成熟时让它与当前力量、关系、身份或世界线发生真实因果碰撞，产生不可回滚状态。第一次 payoff 后，继续保留人物新的生活、关系、权限、敌人或自主目标，形成 second payoff / afterlife。
Variants：- 关系线长期离屏后以新生活状态回归。
- 旧身份在新地图被重新定价。
- 旧物/旧能力从工具变成关系或世界入口。
- 私人欲望在世界级事件中改变最终选择。
- 大战同时结束旧仇并开启新的生活或权力位置。
Guidance：Reminder 必须改变当前行动或解释，不以“提到一次”保活。碰撞不追求固定线数；只要异质线程真正互相改写即可。兑现后优先问“人物现在能做什么、还想做什么、谁会因此改变策略”。
Failure Modes：- 只回忆，不改变行动。
- 为了多线汇合强行巧合。
- 所有配角都等待主角召回。
- 大战只结算输赢。
- Afterlife 只是同类考核重开。
- 把开放或未知结局补成完整战后秩序。

使用边界：迁移线程生命周期与 afterlife，不要求每条长线都有二次兑现，不要求所有线程在终局汇合。
