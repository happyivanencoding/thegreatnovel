# Proposed Persistent Canon

- 长期身份：沈砚仍是九垣诸域烬脉深矿的矿奴，身有可被外力触发的炉印，没有完整修炼资格；他的拆解、修补和辨认经验长期服务于矿场。
- 已证明能力：他能从废器残留的细震中辨认断裂、残存和彼此呼应的方向，并通过翻面、调整距离、比对裂口和排列顺序筛出仍有回应的残件。
- 能力限制：这种异常感知尚未命名，不能直接告诉他完整成品或自动接通法器；三件残件目前只证明彼此保留方向性的回响，不能证明已经能够承接或回收灵力。
- 关系阶段：唐鹭已在一次验印中主动制造遮挡，沈砚与她形成低调、有限的实际互助；这不等于公开同盟或稳定的矿奴网络。
- 持久资源：沈砚有藏起来的修补工具、少量废铜，以及三件被藏入修补袋的残件；他仍没有自己的炉台、灵石来源、合法身份、稳定同伴网络或离开九垣边地的路线。
- 确认知识：残件可以沿原有裂痕互相传递断续回响，但尚未构成完整阵法；灵力耗尽的矿奴会有灰白散灵从身体逸出，沈砚已把解决散灵回体视为继续求生的前置问题。
- 长期伤势：本章未确认新增长期伤势；手掌划伤、手背烫红和炉印收紧造成的不适暂属即时状态。
- 重要敌我状态：太衡炉宗正在封闭矿场并集中回收废器，霍沉负责清点和追查异常，炉印控制尚未解除；唐鹭仍是已表现出实际帮助的少数可信矿奴之一。

# Proposed Chapter Summary

封矿回收令下，沈砚在拆解坏矿车和碎阵盘时凭异常回响筛出三件仍彼此应答的残件，唐鹭替他暂避一次验印并使其得以藏下；一名矿奴被击倒后散灵逸出，沈砚由此确认，这段尚未接通的回收灵路首先需要解决让散灵回到体内的问题。

# Proposed Open Promises

- 沈砚必须在矿场封闭、废器被彻底回收并被用于祭炉之前，找到带人逃出献祭的现实办法。
- 三件残件之间的“回收灵路”尚未完成；它们的真实用途、可承受的灵力范围和能否支持逃生仍待沈砚继续理解与试错。
- “先让散掉的灵回来”仍未兑现；沈砚需要找到散灵回体的可行办法，不能把残件的方向性回响误当成已经完成的救命手段。
- 沈砚异常回响感知的来源仍未揭示，应先由作品中的判断和实际作用建立其可信度。
- 深处天工遗构为何需要矿奴和灵脉作为祭炉燃料，以及九条天工脉是否原属同一件承界器，仍需通过残阵、器灵记忆和界隙行动逐步显现。
- 余响究竟是器灵、伙伴还是新的生命，仍取决于它后续持续提出的要求，尚未获得结论。
- 雨埋城、白烬战场和界脊中的具体居民与势力将因沈砚的作品重新选择站队；既有关系和人物的欲望仍待在后续行动中兑现。
- 洞天内部的公共维护规则、图纸公开范围和资源分配方式仍未定型，需要在具体运行与冲突中形成。
- 九垣改脉仍待展开：活矿、异族骨路、边城水渠和洞天供能模块将被接成可分段关闭的回潮链，沈砚必须面对不同生命与环境的运行节奏。
- 黑色界隙后续仍待验证：倒生金属森林、星骸、会自行繁殖的灵矿和活法则，以及让互相排斥的规则短暂共同运行的界隙炉，都尚未兑现；天工遗构的“修复天地”命令是否会把不合规格的生命当作待回收材料，也未解决。
- 文明承界器仍是最终未兑现的承诺：九垣断脉、星骸、活矿和回潮链将共同承担跨世界的呼吸、迁移与修补，但其关键定型不能以把居民和器灵固定为沈砚的命令来完成。
