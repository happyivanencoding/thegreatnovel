# Proposed Persistent Canon

- 长期身份：沈砚仍是九垣诸域烬脉深矿的矿奴，身有可被外力触发的炉印，没有完整修炼资格；他的拆解、修补和辨认经验长期服务于矿场。
- 已证明能力：他能从废器残留的细震中辨认断裂、残存和彼此呼应的方向，并通过调整受力、间隙和排列顺序把三件残件组成一条局部回收路径；他已制成第一件可拆卸的灵回护腕，可在灵力外逸时回收其中一部分。
- 能力限制：异常感知尚未命名，不能直接告诉他完整成品或自动接通法器；灵回护腕不是完整法器，回收只能部分发生，且小型妖兽晶核承压有限、已有裂线，无法保证持续或安全使用。
- 关系阶段：唐鹭已多次在验印和疗伤时提供实际帮助，沈砚与她保持低调、有限的互助关系；这不等于公开同盟或稳定的矿奴网络。
- 持久资源：沈砚拥有可拆卸的灵回护腕、修补工具、少量废铜和三件残件；妖兽晶核已作为护腕节点使用并接近极限。他仍没有自己的炉台、灵石来源、合法身份、稳定同伴网络或离开九垣边地的路线。
- 确认知识：三件残件能沿原有断口传递断续回响；给回收路径留下间隙并把晶核置于路径外侧后，散灵可以沿窄铜边的一段路径部分回到体内；灵力耗尽的矿奴仍会有灰白散灵逸出。霍沉能够从新鲜灵痕、回收记录和验印状态的矛盾中发现异常。
- 长期伤势：本章确认右手腕至小臂新增灵力反割伤，但尚未确认其为长期伤势；手掌划伤、手背烫红和炉印收紧造成的不适仍属当前状态。
- 重要敌我状态：太衡炉宗正在封闭矿场并加速集中回收废器；霍沉已提高对异常的警觉并改变回收流程，炉印控制尚未解除；唐鹭仍是已表现出实际帮助的少数可信矿奴之一。

# Proposed Open Promises

- 在矿场封闭、废器被彻底回收并用于祭炉之前，沈砚仍需找到带人逃出的现实办法；提前封口回收正在压缩可用材料和试制时间。
- 三件残件形成的灵回路径只被局部接通；灵回护腕能让部分散灵回体，但三件残件的完整用途、稳定回收能力、可承受范围以及能否支持逃生仍待验证。
- 灵回护腕中的妖兽晶核已有白线并接近承压极限；沈砚仍需找到更合适的承压节点、骨架或替代回收方案，避免下一次过载反割。

- 雨埋城、白烬战场和界脊中的具体居民与势力将因沈砚的作品重新选择站队；既有关系和人物的欲望仍待在后续行动中兑现。
