# Specialist Audit

- 唐鹭当前两次经过只呈现为鞋尖提醒和目光掠过，未让她替沈砚挡住检查的动作和沈砚对此的克制反应落地，关系变化因此停在功能提示。
- “他仍旧是那个受炉印控制的矿奴”一段在残件被确认后连续重述旧边界，削弱了首次确认带来的短暂抓握感，也让兑现后的余波依赖说明而不是动作。
- 矿奴被击倒后，沈砚的反应从“手停”很快直接转入回收结构推断；伤害对他的身体和选择缺少一拍可见的反应，使受害者主要承担机制触发功能。

# Proposed Patches

## Patch 1
目标锚点：从“唐鹭从他面前经过两次。”至“没有停。”的段落。
操作：replace
建议文本：
唐鹭从他面前经过两次。

第一次，她肩上的筐装满了碎铜。守阵修士正从车尾走来，她没有绕开，反而把筐沿横到两人之间，鞋尖在地上碰了一下，提醒沈砚有人来。她借着卸筐的动作挡住修士伸向车板的手，让那道检查先落到筐里的碎铜上。

第二次，她的袖口沾着黑灰，目光从他的修补袋上掠过，没有停。

沈砚也没有抬头。他把手从修补袋上收回，重新握住锤柄，等她走过检查线，肩膀才松开一线。
理由：把唐鹭的保护从提示性功能动作化，同时用沈砚收手、等待和短暂松弛留下关系余波，不增加解释或改变检查结果。

## Patch 2
目标锚点：从“他仍旧是那个受炉印控制的矿奴。”至“暂时还没有被人发现。”的段落。
操作：replace
建议文本：
沈砚按着修补袋，手掌没有松开。袋底三件残件隔着补布彼此应着，短促的震动一直传到指骨；这一次，他确认留下来的不是一堆碰巧响过的废铜，而是一段还没断尽的路。它们只能贴着工具藏着，棚外的回收车却还在拖走废器，霍沉的名册又翻过一页。沈砚抬头看向剩下的废器，重新把手伸向车板。
理由：保留受炉印控制、未获得灵力和残件尚未成品的事实，但用掌心触感、回收车和名册的压力呈现确认后的余波，避免连续否定句把新获得的可能性压平。

## Patch 3
目标锚点：“沈砚的手停在车轴上。”
操作：replace
建议文本：
沈砚的手从车轴上移开了一寸，胸口的炉印同时勒紧。他把掌心按回去，铁屑嵌进指缝。
理由：让矿奴受击先在沈砚身上留下一个短促、受约束的反应，再进入后续散灵观察；不改变无人救助和章节结尾的推动。
