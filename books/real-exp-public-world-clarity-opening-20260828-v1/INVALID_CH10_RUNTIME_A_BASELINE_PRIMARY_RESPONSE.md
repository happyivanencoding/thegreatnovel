# 正式正文

天还没黑，客舍前堂已经坐了两桌赶路人。

柜台上堆着湿斗笠，门口的马嚼子碰着木桩，叮叮当当响个不停。厨房里热汤滚开，母亲端着一盆刚切好的肉从后面快步走出来，额角全是汗。

“临川，把西边两间房收拾出来。”她把盆往案上一放，“还有，灶上那锅汤盯着，别叫它扑出来。”

顾临川刚应了一声，父亲已经从账房掀帘出来。

父亲手里夹着一沓货单，脸色不太好看：“商队的账今晚要交。货是上午卸的，数目、脚力钱、草料钱，全在账册里。你来记，我去把缺的两笔问清楚。”

顾临川接过货单，低头一扫。

几十匹骡马，十几车货，来回搬运的人不少。要是照着平日的法子，一笔笔对下来，天黑前都未必能完。

偏偏今天，武馆最后一次训练就在傍晚。

明天便是公开试场。

他若想站上那片场地，被武馆里的人真正看见，今天这次训练不能缺。

父亲见他不动，皱眉道：“怎么了？”

“武馆那边……”

“我知道。”父亲打断他，“可账不能自己长腿跑完。你去不去，自己掂量。”

厨房里又传来母亲的声音：“临川，汤！”

顾临川捏着货单，手指收紧。

客舍的活不是不能拖，但拖了，今晚这一屋子住客就得乱。父亲替商队做账，也不能拿一堆错账去交差。

可武馆的试场，不会等他。

他抬头看了一眼天色，没再争辩，只把货单塞进怀里。

“我先去内院。”

父亲看了他一眼，没说什么。

内院比前堂安静得多。墙角固定着一只火盆，盆里的炭烧得正旺，火光被铁罩压住，只往下铺出一片稳定的亮。亮处之外，顾临川的影子被墙根和石板托住，黑得完整。

聚落里家家都留着这样的固定火盆。

天色不好时照明，夜里防寒。对能用影力的人来说，整块、稳定的阴影也比街上的碎暗处好得多。

顾临川站进阴影里，抽出练刀用的短刀。

他的影子贴在地上，随着他抬臂，也抬起了一条模糊的手臂。

他沉下气，把影力往脚下送。

地上的黑色立刻向前拉长，贴着石板滑出去半丈。顾临川抬刀，影子也跟着收束，边缘渐渐变硬，像一截从地面拔出的黑铁。

一柄短刃在他身前成形。

顾临川挥刀。

影刃撞在墙边废木上，木头“啪”地裂开一道口子。影刃随即散回地面，只留下一层晃动的暗色。

一阶凝影能让影子变硬，做成短刃、绳索，或者挡一下攻击。

可那都是影子。

不是另一个人。

顾临川盯着脚下那团黑，胸口发紧。

前堂有人在喊房间，账册还在账房，武馆那边的训练时辰正一点点过去。他没有余裕等到明天，再慢慢试。

他转身要去拿账册。

就在这一转之间，脚下的影子没有跟着他的腿挪动。

它还留在原地。

顾临川猛地停住。

火盆的光照着石板，墙根那片黑里，影子像被什么东西钉住。下一刻，那团黑色从地上鼓起来，先是两条腿，再是腰背、肩膀，最后抬起一张和他一模一样的脸。

黑色褪去后，一个顾临川站在阴影里。

另一个顾临川站在亮处。

两人同时喘了一口气。

顾临川低头看自己的手，又看向对面。

对方也低头看手，眼神里的震惊和压不住的兴奋一模一样。

“真成了。”影身先开口。

声音不高，和他本人没有区别。

顾临川喉结动了一下。

他能感觉到对面那具身体。不是操纵一具木偶，更像把自己的意识掰成了两份。两边都能看，都能听，都能动。

“你留客舍。”顾临川说。

影身抬眼：“你去武馆。”

“账册在账房。把货单对完，住客的房间安排好。要是爹问，就说我在后头忙。”

影身扯了下嘴角：“你倒会使唤自己。”

“少废话。”

两个人同时动了。

影身进账房时，顾临川已经翻过内院侧门，沿着小巷往武馆跑去。

他跑得很快。

傍晚的街道上，火盆一盏接一盏亮起来。有人挑着菜担往家赶，有人把门外的货物收进屋檐下。顾临川从人群里穿过，心里却始终绷着另一根线。

那根线连着客舍。

影身坐在账桌前，翻开账册，拿起笔。

货单上的数目和院中堆放的麻袋、木箱一项项对应。脚力钱多记了一笔，草料钱少了一笔。影身抬头叫住正要离开的商队伙计，问清了数目，又重新落笔。

前堂的住客等着房间，母亲隔着帘子叫他帮忙搬一坛酒。

影身放下笔，起身搬酒，带客人去西厢，又回来继续记账。

顾临川能感觉到那边的忙乱。

一笔账写错又划掉时的烦躁，搬酒坛压到手臂时的酸麻，住客嫌房间窄时忍下去的一句解释，全都像隔着一层水传到他这里。

可他没有回头。

武馆的门已经在眼前。

院里的人比平日少，练刀的木靶却都竖了起来。几名学徒正轮流劈砍，木刀撞上木靶，闷响不断。

负责看场的师兄见顾临川赶来，脸色一沉。

“你还知道来？”

“家里有事，耽误了一阵。”顾临川抓起木刀，“还赶得上吗？”

师兄看了眼天色，抬手指向最边上的木靶：“最后半个时辰。练不出样子，明天别上去丢人。”

顾临川没有多说，提刀走过去。

木靶上已经满是旧痕。

他站定，先劈了一刀。

木刀落在靶上，震得虎口发麻。第二刀、第三刀，刀路还是熟的，可气息有些乱。客舍那边的影身正在抬一只沉箱，肩背传来的酸胀忽然钻进他身体里，让他的刀慢了半分。

顾临川咬住牙。

分出一具身体，不是多出一条命。

另一边干的活，他也躲不掉。

可那具身体写过的每一个字、看过的每一笔数，也正清清楚楚留在他脑子里。

顾临川收刀，重新起势。

这一次，他没急着去砍。

他盯着木靶下方的阴影，等火盆的光从侧面照过来。木靶的影子贴在地上，和他自己的影子交叠了一小块。

顾临川把影力压进脚下。

黑色沿着地面爬上木刀。

不是替木刀添一层薄影，而是让那团黑贴紧刀锋，凝成一柄更短、更实的影刃。

他一步踏前，挥刀斜劈。

咔！

木靶中间裂开，断成两截。

上半截木头斜着滑下来，砸在地上，扬起一片灰。

院里的声音停了一瞬。

旁边练刀的学徒看着断靶，又看顾临川手里散开的黑影，脸色变了变。

负责看场的师兄走近两步，盯着那道断口。

“你什么时候把影刃练得这么稳了？”

顾临川握住发麻的手掌，压下胸口翻涌的气息。

他知道答案。

不是他一个人练得更久。

是另一个自己在客舍里忙了一整晚，而他在这里多练了一整晚。两边的经历一起落回他身上，连握刀时该怎么收腕、该怎么把力送进木头里，都比刚才清楚得多。

但他只是抬起木刀。

“刚刚顺手了点。”

师兄看了他一眼，没有追问，只道：“明天别迟到。”

“不会。”

天彻底黑下来时，客舍那边的账也合完了。

影身在最后一笔后面按下手印，把账册递给父亲。父亲翻了几页，眉头松开一些，抬头时却只看见顾临川站在柜台旁。

“忙完了？”

影身点头：“忙完了。”

父亲嗯了一声，把账册收起来。

“去吃饭。”

影身没有动。

同一时刻，顾临川从武馆的巷口走回客舍。他脚步比来时沉得多，推开后门时，正看见内院火盆旁站着另一个自己。

两个人隔着一片阴影对视。

影身先抬起手。

顾临川也抬起手。

指尖碰到一起的瞬间，影身像被火盆的阴影重新吞回去。黑色从肩膀、手臂、胸口一路散开，贴着顾临川的脚下钻入身体。

下一刻，顾临川膝盖一软，重重扶住墙。

账房里坐了半天后的腰酸，搬酒坛时磨破的掌心，街上奔跑后的喘息，武馆练刀震裂虎口的疼，全在这一瞬间压了回来。

他像连续忙了两天两夜，连抬头都费劲。

母亲从厨房出来，见他扶着墙，皱眉道：“你这是怎么了？”

“累着了。”顾临川低声说。

这话不假。

他慢慢站直，掌心还在发抖，却忍不住低头看向脚下。

影子安安静静贴在石板上。

刚才那具影身已经不在了，可他闭上眼，账册上的数字还在，木刀劈进木靶时的手感也还在。

两边都是真的。

顾临川吐出一口气，嘴角一点点扬起来。

分影不能替他免掉疲惫。

可它能让他在同一天里，多活一次。

明天的公开试场还在等着。

他抬头看了眼客舍前堂忙碌的灯火，又看向武馆所在的方向。

明天，他还会再分一次。
