- 旧 Active Scene State 中前后出口的封锁尚未确定；本章正文确认第一道矿门和来时的石门均已被封锁，裴照川下令不追入窄隙并等待炉火逼出结果。
- 无法从正式正文确定：距三日封炉期限还剩多久；裂路器还能驱动多少次、再次驱动的具体条件与代价；窟心炉心的性质及其后方是否确有可通行出口；队伍中除已明确伤情者之外的精确人数和完整伤情。

# Proposed Active Scene State

- 当前地点：废弃炼器窟侧炉后的狭窄侧道，队伍已经通过新开的石壁裂隙；裂隙和来路已在封锁符与石门作用下合拢。侧道尽头连接残图所指的窟心炉心，迎面的回火正沿旧图刻线逼近。
- 在场人物：沈燧、阮青禾，以及跟随队伍继续前进的矿工和伤者。至少有一名小腿受伤且仍会出血的矿工、一名额头裂伤后已重新包扎的矿工、一名胸口受伤且持续咳嗽的矿工；其余人员的姓名和精确人数仍未确定。
- 即时伤势：沈燧右掌的黑铁锋片已取出，掌心留下空洞般的疼痛和取出造成的伤口；右臂黑色裂痕仍在发热，左肩旧伤被热浪重新撕开，衣角被火流烧焦。小腿伤者伤口重新渗血，胸口伤者呼吸困难并咳嗽，额头伤者已由同伴重新扎紧布条。
- 手中关键物品：沈燧手中的粗糙裂路器，由烧红粗铁、黑铁锋片和残余方向性力量锻成；黑铁锋片不再单独存在于掌心。裂路器已切开石壁并切断封钉，但接触迎面炉火时无法继续切开火流。队伍仍有符灯和用于照看伤者的布条、腰带等物资；断镐主体留在旧风道裂口边。
- 当前敌人或追兵：玄烬仙宗已封死废窟前后两道出口。裴照川亲眼确认裂路器能够再次驱动，将沈燧列入“失控器修”的追查记录，并下令不得进入窄隙抢回器物，暂以封锁和炉火逼迫为主。当前最直接的环境威胁是窟心炉心向侧道推进的回火。
- 当前倒计时：封炉令仍规定自下令起三日后封闭黑炉镇矿脉、熄灭地火，但正式正文没有确定剩余时间。短期倒计时是迎面火流抵达侧道、阻断队伍通行之前的时间，具体时长未知。
- 下一步直接目标：让伤者沿阮青禾指示继续向残图最深处移动，在回火抵达前确认并打开窟心方向的石壁或通路；保持队伍不被火流分开，同时判断裂路器在接近炉心时能否处理石壁而不直接接触、切割火流。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”；他的纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定力量来源。
- 沈燧能够感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。黑铁锋片在烧红粗铁并受锤击后脱离掌心，和粗铁合成了粗糙的裂路器；裂路器已被证明可以劈开石壁，并沿既有裂隙切断薄型封钉。
- 裂路器的能力边界尚不完整：它需要经过烧红粗铁和锤击的转化过程，接触迎面炉火时不能切开火流；本章只证明了两次驱动，剩余次数、具体触发条件和进一步代价均未确认。
- 沈燧的右掌锋片已取出但留下持续空痛和伤口，右臂黑色裂痕仍存在并会在驱动时发热；左肩旧伤在本章受热浪影响而加重。
- 阮青禾能够辨认旧炼器窟的侧炉标记和残图，并与沈燧形成了基于现场判断、路线指引和伤者转移的临时协作。矿工和伤者已从暂时服从转为愿意按沈燧、阮青禾的分工继续搬运和跟随，但尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认裂路器不是断镐锋力的单次回光，知道沈燧具备再次驱动异常器物的能力；沈燧已被列入“失控器修”的追查记录，宗门选择封住前后出口并利用炉火逼迫，而不是进入窄隙抢夺器物。
- 侧炉残图确认窟心炉心仍在发热，回火会沿旧图刻线向外推进；通往废窟外的旧路线已被宗门后补的封符截断，当前可确认的路线只剩通向窟心的最深段。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火，剩余时间尚未确定。

# Proposed Chapter Summary

第2章：沈燧和矿工、伤者在阮青禾辨认出的侧炉中重新引燃残火，用烧红的粗铁和掌中黑铁锋片锻成裂路器；他先以裂路器劈开侧炉后的石壁，又切断接入封锁阵的封钉，带队进入侧道。裴照川确认裂路器能够再次驱动后封死废窟前后出口；队伍随后沿残图向仍在发热的窟心炉心前进，而迎面的回火已经逼近。
