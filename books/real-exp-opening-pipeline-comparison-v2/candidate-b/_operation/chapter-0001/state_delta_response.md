# Proposed Active Scene State

- 当前地点：黑炉镇被封存的废弃炼器窟门内。沈燧刚推开半埋在矿壁中的黑色石门；身后是已塌合的旧风道和正在被外部挖掘、封锁的通路，门内透出正在变暗的暗红炉光。
- 在场人物：沈燧，以及跟随他进入炼器窟的多名矿工和伤者。队伍中至少有一名小腿被压伤的矿工、一名额头裂伤的矿工和一名胸口受伤、会咳嗽的矿工；其余人员的姓名和精确人数未由正文确定。
- 即时伤势：沈燧左肩擦伤；右手掌骨和右臂有从腕部蔓延至肩下的黑色裂痕，掌心嵌着黑铁锋片，右手只剩尖锐空痛，本次锋力已经耗尽。被救出的伤者仍需包扎、搀扶或拖行，小腿伤口仍有出血，其他伤情的恢复程度未确定。
- 手中关键物品：沈燧掌心嵌着从断镐脱落的薄黑铁锋片；断镐主体已留在旧风道裂口边，锋力不再可驱动。队伍有符灯照明，伤者得到照看。
- 当前敌人或追兵：玄烬仙宗封炉阵已定位旧采层的异常炉息；裴照川下令把撤离区改列为异常回收区，封住前后出口并回收活物与异常残响。后方已有人员用封锁器具敲击、挖掘刚合拢的碎石，前方封锁是否已完全就位未知。
- 当前倒计时：封炉令规定自下令起三日后封闭黑炉镇矿脉、熄灭地火，但本章没有给出当前已过去的时间。更紧迫的是炼器窟内最后一线火脉正在衰退，后方搜捕已经推进，突破时间未知。
- 下一步直接目标：带着矿工和伤者在炼器窟内确认可继续通行的安全路径或出口，利用仍在变化的炉窟环境继续撤离，并在封锁突破前处理黑铁锋片与门内残余火脉带来的直接阻碍。

# Proposed Persistent Canon

- 沈燧是黑炉镇的矿工和苦力，被称为“漏炉废人”；他的纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定的力量来源。
- 本章已证明：沈燧接触折断采矿镐时，能够感知其中尚未完成的具体动作，并将那股残留的锋力导入矿壁，完成一次“凿开让人活着出去的路”的动作。该锋力没有在丹田聚成灵气或火，也没有形成完整道器。
- 这次锋力已在开壁和顶住石梁的过程中耗尽，不能立即再次驱动；代价是沈燧右掌、右臂留下持续存在的黑色裂痕和掌骨伤痛，恢复程度未知。
- 断镐最后凝成的薄黑铁锋片嵌在沈燧掌心，能够对封存炼器窟的暗红炉光或石门产生热反应；其用途和性质尚未确认。
- 一同逃生的矿工已因实际结果开始服从沈燧的手势并暂时接受他领路，关系从疏离和蔑视转为有限的现场信任；这不是已确立的长期盟约。
- 玄烬仙宗已经把沈燧所在区域记录出的异常炉息列为回收对象，裴照川是目前明确的下令者；宗门掌握封炉、封锁和异常回收的执行权。
- 黑炉镇封炉令明确要求三日后封闭矿脉、熄灭地火；被账册划为废弃区域的旧炼器窟仍留有未登记的炉火，其存续状态会影响后续生路。

# Proposed Chapter Summary

封炉令下的黑炉镇废脉发生塌方，沈燧没有抛下被困的矿工和伤者，而是以断镐中尚未完成的凿路锋力一次性劈开矿壁，带众人转入旧风道；锋力耗尽后，他的右臂留下黑色裂痕，黑铁锋片嵌入掌心。封炉阵定位到异常炉息，裴照川将撤离区改列为异常回收区并展开封锁，沈燧遂带着伤者推入被封存、余火将熄的废弃炼器窟。
