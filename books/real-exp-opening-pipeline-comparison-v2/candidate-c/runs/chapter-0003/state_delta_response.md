# Proposed Active Scene State

- 当前地点：废弃支巷窄门后的阵眼后方，地下阀轮和大型废矿车旁；身后的窄门由旧矿车、左侧石骨、门栓和扁铁临时撑住，通向废弃支巷及回收线。
- 在场人物：沈砚、唐鹭。霍沉、下一班矿工及回收线上的其他人位于门外或中央矿脉方向，不在当前石台上。
- 即时伤势：沈砚掌心伤口重新裂开，手背被碎石擦伤；左腕护腕再次收紧发热，只剩贴着腕骨缓慢游动的一丝余灵。唐鹭手臂擦伤仍在出血，肩部被碎石砸过并有疼痛；没有确认的失能伤势。
- 手中关键物品：左小臂上已定型、无法取下的铜制护腕；黑铜回收片，半圈残纹旁新增分别指向矿脉、窄门和地下阀轮的三道浅分叉；霍沉交给沈砚、已经写入伪造维修记录但尚未交出的记录片；短锤。
- 当前敌人或追兵：霍沉仍是直接的审查和处置障碍，已下令祭炉提前蓄能并在三日内封死旧矿道。地下阵眼、阀轮和正在下沉的支道是持续运行的危险；正式正文没有确认其中存在具有敌我属性的有意识追兵。
- 当前倒计时：祭炉已经提前蓄能，地下阀轮按固定节拍继续转动；沈砚判断再蓄一轮会抽干与回路相连的矿奴。霍沉命令三日内封死所有旧矿道，但一轮阀轮的具体时长尚未确定。
- 下一步直接目标：先把伪造维修记录带回交给霍沉，把异常回收路引向西侧废槽；随后与唐鹭返回阵眼后方，拆解大型废矿车取火和可用车架，维持通道并为应对下一轮抽取、带出后来的人做准备。

# Proposed Persistent Canon

- 已证明能力：沈砚能通过接触辨认废器、轨道、牵引结构和阵壁中的细微震动及回路；护腕能聚拢可获得的外部热量、散灵、机械摩擦热和旧震，修复滑轮、门栓等结构并暂时重分配承重。
- 能力限制：护腕不产生新的力量，必须依赖可获得的外部热量、散灵或旧震；能量稀薄时只能缓慢积累，连续索取会使铜环收紧、灼痛并留下极少余灵，尚不能直接停止地下阵眼或阀轮。
- 关系阶段：沈砚与唐鹭已是主动互相掩护、共同承担风险的协作者；唐鹭接受把窄门保留为后来者的出口，并与沈砚共同返回取火。
- 持久资源：左小臂上无法取下的铜制护腕；黑铜回收片已显出连接矿脉、炉印通路和地下阀轮的三道分线。
- 长期身份：沈砚仍是受左腕炉印约束的烬脉矿场矿奴，也是能够辨认、修理和利用部分废器结构的劳力。
- 确认知识：废弃支巷并非死路，旧矿车牵引系统连接窄门后的阵眼；阵壁把矿脉、戴炉印者和地下天工遗构接成向下抽取的回路，地火、矿脉灵气和炉印中的热会被送入地下金属骨架及祭炉。地下阀轮仍在工作，至少有一部分呼吸者与该回路同步，但其确切身份、数量和深处位置未明。
- 长期伤势：没有新确认的长期伤势；本章掌心裂伤、手背擦伤、唐鹭的擦伤和肩部撞击仍属于当前伤情，护腕持续贴附、收紧和发热的身体负担仍然存在。
- 重要敌我状态：霍沉已宣布祭炉提前蓄能并在三日内封死旧矿道，仍在追查沈砚左腕与异常废器；唐鹭是主动协作者；地下阵眼、阀轮及与其相连的呼吸者尚未完成敌我定性。

# Proposed Chapter Summary

第三章中，沈砚奉霍沉之命以维修旧矿车为名，在唐鹭掩护下进入废弃支巷；他修复两只滑轮，并利用矿车、门栓和石骨把窄门暂时扩大为可供数人依次通过的通道。窄门后的阵壁显示矿脉、炉印与地下阀轮构成向下抽取回路，沈砚判断再蓄一轮可能抽干相连矿奴；霍沉随后传令祭炉提前蓄能、三日内封死旧矿道。沈砚写下尚未交出的伪造维修记录，把异常回收路指向西侧废槽，并与唐鹭决定返回拆解大型废矿车取火。
