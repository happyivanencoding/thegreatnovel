# Specialist Audit

- `空白记录片`在章末才首次出现，前文没有霍沉交付或沈砚取得它的动作；后续伪造维修记录因此缺少物品来源。
- `短锤`在修理滑轮时才首次出现，前文只写到唐鹭拿起窄口钳；沈砚后续多次使用短锤的动作缺少取得动作。
- 阵壁连线写成“向上，穿过他们脚下的门框”，与两人已经站在窄门后的石台、窄门位于身后的空间关系不一致，读者难以判断这条线如何连到外侧戴炉印的人。

## Patch 1

目标锚点：`“把它拖到废弃支巷口，写维修记录。”霍沉说，`

建议文本：

`霍沉从腰间取出一枚空白记录片，拍进沈砚手里：“修完带回来。”沈砚将记录片收进袖口。`

操作：insert_after
建议文本：

`沈砚从旁边散落的工具里拿起一柄短锤，别在腰后。`

理由：为随后敲平滑轮轴孔、撬动扁铁以及在记录片上划字的同一件工具建立来源，不增加新的能力或资源。

## Patch 3

目标锚点：`片上的半圈残纹没有发光，只是微微发热。原本断开的沟槽贴住阵壁之后，三条细线从黑铜片边缘显出来：一条向左，接进矿脉；一条向上，穿过他们脚下的门框，像是连着每一个戴炉印的人；还有一条向下，落在石壁下方一圈不断收缩的黑色凹槽里。`
操作：replace
建议文本：

`片上的半圈残纹没有发光，只是微微发热。原本断开的沟槽贴住阵壁之后，三条细线从黑铜片边缘显出来：一条向左，接进矿脉；一条向上，沿门框穿回窄门外，像是连着每一个戴炉印的人；还有一条向下，落在石壁下方一圈不断收缩的黑色凹槽里。`

理由：把连接炉印的线路明确落到窄门外的矿道，修正“脚下的门框”造成的方位冲突，同时保留三条线汇入阵眼及后续抽取判断。
