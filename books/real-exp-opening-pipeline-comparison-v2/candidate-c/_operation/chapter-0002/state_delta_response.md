# Proposed Persistent Canon
- 已证明能力：沈砚能通过接触辨认废器、车架和轨道中的细微震动及未完成的回收路径；护腕能在镇灵阵压制下拦截并聚拢外部热量与散灵，支撑他连续施出两次修补诀，修住矿车承重骨并接通断轨，使阵盘熄灭的矿车继续运行。
- 能力限制：护腕不产生新的力量，只能利用可获得的外部热量和散灵；能量过薄或继续索取会使铜环收紧、灼痛并使炉印变形，连续使用的上限和更广适用边界尚未确认。
- 关系阶段：沈砚与唐鹭已从临时协作发展为主动互相掩护的协作者；唐鹭暗中取出并转交黑铜回收片，并同意与沈砚进入废弃支巷。
- 持久资源：左小臂上与破阵盘、妖兽晶核定型且无法取下的铜制护腕；一块带残纹、能发出指向废弃支巷细震的黑铜回收片。
- 长期身份：沈砚仍是受左腕炉印约束的烬脉矿场矿奴，也是能够辨认和修理部分废器的劳力。
- 确认知识：灵潮正在沿九条天工脉退向太衡炉宗深炉；镇灵阵可以压灭法器阵盘，但外部热量和散灵仍可能沿金属、车轮与轨道形成可利用的回路；按规矩不该有灵气的废弃支巷内，黑铜残纹能感知成片呼吸同步向地底沉降，支巷之后连接中央矿脉入口。
- 长期伤势：尚无已确认的长期伤势；护腕持续贴附、收紧和发热造成的身体负担仍然存在，但本章的掌心割伤、烫伤和腕部麻痛暂不认定为长期伤病。
- 重要敌我状态：霍沉已确认阵盘熄灭后矿车仍能运行，并将异常明确关联到沈砚的左腕，因而把沈砚扣在废器堆持续审查；唐鹭已成为会主动掩护沈砚的协作者。废弃支巷下的未知存在尚未确认敌我属性。

# Proposed Chapter Summary
霍沉搜身后将沈砚押去修理一辆载有矿奴的破损运输车；镇灵阵压灭阵盘后，沈砚借护腕收拢车底外部热量与散灵，连续施出两次修补诀，修住承重骨并接通断轨，使矿车越过塌陷抵达回收线。霍沉因此封存矿车和阵盘，把沈砚扣到废器堆继续查验；唐鹭暗中将破阵盘黑铜回收片交给沈砚。黑铜片的细震指向被封闭的废弃支巷，沈砚听见成片呼吸被牵向地底，遂与唐鹭约定趁无人进入追查，地底随后传来吞咽声。
