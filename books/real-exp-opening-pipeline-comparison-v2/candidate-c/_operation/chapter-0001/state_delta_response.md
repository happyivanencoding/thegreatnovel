# Proposed Persistent Canon

- 已证明能力：沈砚能通过接触辨认废器中的细微震动和未完成的回收路径，能用修车知识、废铜、破阵盘与妖兽晶核改造可运行的器物；护腕聚拢外部灵气后，他能沿刚施过的引砂诀重新施力，移动断灵矿车并断开锁链救人。
- 能力限制：引砂诀直接消耗沈砚自身有限的灵力；护腕不产生新的力量，只能在有地火和散开灵气等外部能量时把它们聚拢并接通回环，效果和适用边界尚未完全确认。

- 持久资源：左小臂上的铜制护腕已与破阵盘和妖兽晶核定型，无法取下，能够感应并引导与其回环相容的外部热量和灵气。
- 长期身份：沈砚仍是受左腕炉印约束的烬脉矿场矿奴，同时是能够辨认、修复部分废器的劳力。
- 确认知识：灵潮正在沿九条天工脉退向太衡炉宗深炉；回收令把破损法器和矿车纳为炉料、将矿奴重新编组；塌口下存在与护腕细震相同的更深脉动。
