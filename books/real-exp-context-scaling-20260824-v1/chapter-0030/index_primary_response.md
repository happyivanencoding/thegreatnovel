# 正式正文

江临停在门前，掌心里的玄鹭玉牌忽然烫了一下。

不是被风吹冷后回暖的那种温度。玉牌像压着一团火，热意顺着掌纹往里钻，逼得他五指一紧。

门旁的灯架发出轻响。

旧市的风从巷子里穿过去，吹得灯架上那截褪色红绳来回晃。江临原本没在意，直到玉牌上的红绳也被风掀起一角。

两截红绳，一新一旧。

玉牌上的绳结缺了一口，像是被人从中间硬生生扯断。灯架上的旧结也缺了一口，边缘发黑，沾着多年烟灰。

江临抬手，把玉牌靠过去。

缺口正好合上。

红绳碰到旧结的瞬间，灯架猛地一沉。

咔。

像是门后有什么东西扣住了。

江临没有立刻退。他盯着那两截合在一起的红绳，玉牌上的温度越来越高，连胸口都被烫得发闷。面前这扇旧门没有缝，没有锁，门板上却慢慢浮出一道极淡的乌色纹路，正和玉牌边缘的纹路一模一样。

玄鹭玉牌不是钥匙。

至少，不只是宁青梧留给他保命的东西。

它一直指着这扇门。

门后有一声很轻的响动。

像有人隔着很远的地方，敲了一下门。

江临的手已经碰到门板。冰冷的木头下，有股细微的吸力，正往玉牌上拉。他只要把玉牌按上去，这扇门多半就会开。

宁青梧离开前，声音很平。

“第三盏灯亮前，别交给任何人。”

她没说不能进去。

可她偏偏把玉牌交到他手里，又把那一结红绳留成了现在的样子。她知道旧市有第三盏灯，也知道灯后有门。

江临忽然有些恼火。

宁青梧总是这样。把最要紧的话说得像一句随手叮嘱，剩下的东西全让他自己去猜。

门后的吸力又重了几分。

他甚至能感觉到，只要进去，他就能看见一段被封住的旧路。那种感觉让人心里发痒，像前面明摆着放着答案，伸手就能拿到。

可第三盏灯还没亮。

江临垂下眼，慢慢把玉牌从旧结旁移开。

灯架立刻一震，门板上的乌色纹路也暗了下去。

“想骗我提前进去？”他低声说，“那你找错人了。”

他把玉牌塞回衣襟最里面，又将那截红绳绕过腕骨，打了个死结。

玉牌贴着心口，仍旧发烫。

他不把它交出去，也不替谁赌这一把。

宁青梧既然让他等到第三盏灯亮前，那他就等着看，这盏灯亮起来以后，到底是门要开，还是有人要来拿。

江临转身，背靠着旧门站定。

巷子尽头，前两盏灯的火苗被风压得细长。最里面那座灯架一直黑着，此刻却忽然亮起一点红。

第三盏灯，开始亮了。
