# 正式正文

夜里的风从旧市尽头灌过来，吹得门环轻轻撞在门板上。

江临站在门前，手还停在半空，没有去推。

门对面的人也没有催他。

宁青梧站在檐下，衣角被风压在腿边。九十多章不见，她瘦了些，脸还是那张脸，眼神却像隔着一层没有散尽的雾。她没先看江临，也没叫他的名字。

她的目光落在江临腰间。

玄鹭玉牌垂在那里，缺了一结的红绳在风里晃了一下。

江临抬手，把玉牌从腰间解下来。

宁青梧的手指微微一紧。

“别问我去哪了。”江临把玉牌摊在掌心，声音不高，“先说这个。”

玉牌贴着他的掌心，凉得像刚从井水里捞出来。

“第三盏灯已经有人点过一次，是什么意思？”

宁青梧没有立刻回答。

她往前走了一步，又停住。两人之间只隔着两步路，可她没有伸手来拿玉牌，像是怕碰了它，什么东西就会立刻追上来。

江临盯着她。

第十八章那夜，她把这块玉牌塞进他手里，红绳还完整。她说，第三盏灯亮前，别交给任何人。

那时候他只当是她留下的一句怪话。

现在看来，她早知道这东西会把人逼到门前。

“有人点过一次，”宁青梧终于开口，“就说明有人拿它做过选择。”

江临眉头动了动。

“说清楚。”

“第三盏灯不是给你照路的。”宁青梧看着玉牌，声音有些发涩，“它亮起来的时候，会把该回来的人、该偿的约、该找的人，都照出来。”

风从两人中间穿过去。

江临没有低头去看玉牌。

“所以我被照出来了？”

“你带着它，一直都在灯下。”宁青梧说，“这次不一样。有人先点了一次灯，玉牌才会有反应。”

江临想起这一路上玉牌那些不合时宜的发冷，想起它在旧市外忽然沉得像块坠铁。他原本以为是追索的人逼近，原来还有另一只手，隔着看不见的地方，先碰了这条旧约。

“谁？”

宁青梧抬起眼，看向他。

她眼底那层雾终于裂开了一点，露出的不是重逢后的松快，而是压了太久的警惕。

“我不知道名字。”

江临的脸色沉下来。

宁青梧没有回避。

“我失踪以后，见过第三盏灯亮过。”她说，“那个人没有把玉牌拿走，也没有杀我。他只是问我，江临会不会还留着它。”

江临掌心收紧，玉牌的棱角硌进肉里。

“你怎么答的？”

宁青梧看着他，忽然很轻地笑了一下。那笑意只停了一瞬，像她从前被逼急了还要嘴硬的时候。

“我说你记仇。”

江临也扯了下嘴角，没笑出来。

“这算什么答复。”

“对他够用了。”宁青梧说，“他没再问。”

门环又响了一声。

江临侧过脸，看了一眼面前紧闭的门。刚才他停在这里，是想把这扇门推开。门后有什么，他不清楚；但旧市里被封起来的门，从来不会无缘无故挡在他路上。

现在宁青梧站在这里，带来的不是答案，是另一条更麻烦的路。

他把玉牌重新系回腰间。

“你回来，不是为了告诉我有人问过我吧。”

“不是。”

“那你想让我做什么？”

宁青梧沉默了一下。

她抬手，指尖碰到自己袖口一处磨破的线头，像是在压住某种下意识的动作。

“别进这扇门。”

江临看向她。

“你走了九十多章，回来第一句话就是拦我？”

“我不是拦你。”宁青梧说，“我是怕你进去以后，别人替你把路选完。”

这句话让江临的目光冷了下来。

宁青梧看得出来，却没有退。

“你最讨厌这个，我知道。”她继续道，“所以这次我回来，不是让你听我的。我要你带着玉牌，跟我去找点灯的人。”

江临没有马上答应。

她失踪太久，回来得太巧。她知道灯，知道玉牌，也知道有人在找他。换作旁人，他早就把话问到底了。

可宁青梧看着他的眼神里，有一种他熟悉的倔。不是求他信，也不是等他原谅。

是在等他自己做决定。

江临抬手，把门前垂下的一截断锁拨开。

“这门后面呢？”

“我不知道。”宁青梧说。

“你不知道，还不让我进。”

“因为你一进去，玉牌会被它看见。”

“它是谁？”

宁青梧摇头。

“我只知道，点灯的人在找这块牌，也在等你走错第一步。”

江临盯了她片刻。

宁青梧的肩背绷得很直。她明明站在风里，脸色也白，却没有再劝。像是把该说的话都摆出来了，剩下的由他自己选。

这倒比九十多章前那个总爱替人留后路的宁青梧，陌生得多。

也顺眼得多。

江临松开断锁。

“行。”他说，“这门先不进。”

宁青梧的呼吸明显停了一下。

“但不是因为你让我别进。”江临看着她，“是因为我想知道，谁敢先替我点灯。”

宁青梧望着他，眼里的紧绷慢慢松开。她没有说谢，只是抬手把被风吹乱的头发别到耳后。

“我带你去。”

“你带路可以。”江临道，“玉牌还在我手里。见到人，怎么问，什么时候进，都由我定。”

宁青梧点头。

“好。”

她答得很快，没有讨价还价。

江临转身离开门前。走出两步，他听见身后衣料擦过石阶的声音，宁青梧跟了上来。

不是从前那个总走在他前面、回头催他快些的人。

她落在他半步之后，像是把这半步的距离留给了他，也留给了他们之间还没说清的九十多章。

旧市的街口黑得像一口井。

江临摸了摸腰间的玉牌，冰凉的玉面贴着掌心。

“回灯楼在哪？”

宁青梧停下脚步。

她望向旧市更深处，那里的夜色压着层层屋檐，连风都像绕开了。

“真正点灯的人，”她说，“就在回灯楼里。”
