# 正式正文

江临的手停在门前，指节离门板只有半寸。

门内没有动静。风从巷子尽头穿过来，吹得檐下铜铃轻轻撞了一下。

宁青梧站在他身后两步，黑色短衣被风压在身上。她比从前瘦了些，左手手背上多了一道烧痕，从虎口一直爬到腕骨。她没有看他的脸，目光落在他腰间。

玄鹭玉牌垂在衣摆下，红绳缺了一结。

江临回过身，把玉牌从腰间取下来。

玉牌落进掌心，冰凉，边缘被他这些年磨得发亮。他没有递过去，只抬手让宁青梧看清。

“你说，第三盏灯已经有人点过一次。”江临盯着她，“什么意思？”

宁青梧终于抬眼。

那一眼和从前不一样。以前她看人时总像在算退路，如今却像先确认一件东西是不是还在。

“意思是，回灯楼没有等到我们。”她说。

江临没出声。

“第三盏灯本来该由拿着玉牌的人点。”宁青梧看着玉牌，“灯亮以后，楼里封着的路才会认人。可有人提前进去，替你点过一次。”

“替我？”江临冷笑了一声，“我连回灯楼的门朝哪边开都不知道，谁替得了我？”

“不是替你。”宁青梧说，“是抢你的位子。”

风声忽然紧了些。

江临的手指收拢，玉牌边缘压进掌心。他想起第十八章那场雨，宁青梧把玉牌塞给他时，红绳还是完整的。她当时只说了一句：第三盏灯亮前，别交给任何人。

他后来问过几次，她都没解释。

如今人回来了，第一句话却是有人先点了灯。

“那你当年为什么不说清楚？”

宁青梧沉默了一下。她抬起左手，指尖碰到那截断绳，却没有把玉牌接过去。

“因为我那时也不知道，点第三盏灯的人会活着出来。”

江临看着她手背上的烧痕。

宁青梧把手放下，声音平静下来：“回灯楼的灯不是照路的。三盏灯亮全，楼里会留下一个人的名字。后来的人进楼，只能走那个人允许走的路。”

“所以有人点过一次，楼里已经有主人了。”

“对。”

“玉牌呢？”

“玉牌是钥匙，也是证据。”宁青梧说，“拿着它进去的人，会被那个人看见。”

江临低头看了一眼玉牌，忽然把它重新系回腰间。

宁青梧眉头微动。

“看见就看见。”他说，“我不喜欢别人拿了我的东西，还躲在门后等我替他敲门。”

“江临。”

“你失踪了九十多章。”江临抬眼，语气不重，却压得很硬，“回来以后先看玉牌，再告诉我有人占了我的位子。你要是想让我掉头走，现在就把话说完。”

宁青梧望着他，半晌没有回答。

巷口的灯火晃了一下。她的脸在暗处显得有些陌生，只有那双眼睛还留着江临认识的东西——她想拦人时，先会把所有坏处都算出来；可真到了要走的时候，她从不自己退。

“我不是让你走。”她说。

江临等着。

宁青梧抬手，从袖中取出一截细细的红线。那红线颜色比玉牌上的旧绳更深，尾端系着一个小结，结法很丑，像是匆忙用牙咬紧的。

她把红线递过来。

“这是另一半。”她说，“当年我把玉牌交给你时，故意拆开了结。你拿一半，我拿一半。只要结没补上，玉牌就只是你的东西，回灯楼认不得完整的旧约。”

江临没有立刻接。

“现在补上呢？”

“楼会认出我们两个。”宁青梧说，“也会让里面那个人知道，真正拿玉牌的人来了。”

“你想让我把他钓出来。”

“我想进去。”

江临看着她。

宁青梧的嘴唇绷了一下，像是不习惯把话说得这么直白。

“我进去过一次，但没到第三层。”她说，“我带不走玉牌，也点不了灯。我能活着出来，是因为有人放我出来。”

“谁？”

“我没看见脸。”

“那你知道什么？”

“我知道他留在楼里。”

江临伸手接过那截红线。

宁青梧的指尖很凉，碰到他手背时停了一瞬。她没有立刻松开，像是确认他不会把线扔掉。

江临低头，把红线绕上玉牌原本缺开的地方。

宁青梧忽然伸手按住他的手腕。

“结要我来打。”

江临抬眉：“规矩？”

“旧规矩。”

“你还记得？”

“我没忘。”

她说得很快，像怕自己慢一点，江临就会追问她这些年到底去了哪里。

江临没问。

他把玉牌抬起来。

宁青梧靠近一步，低头替他打结。她的手指有些僵，绕了两次才把红线压紧。玉牌在两人之间轻轻一晃，红绳终于连成完整的一圈。

巷子里没有异象。

可门板后面，忽然传来一声很轻的响动。

像有人在很远的楼上，拨亮了一盏灯。

宁青梧的手还停在玉牌上，脸色变了。

江临顺着声音望向那扇门。

“回灯楼不在这里。”他说。

“门不在这里。”宁青梧收回手，盯着门缝里渗出的微弱光线，“路在这里。”

江临推开门。

门后原本该是一间废弃的铺子，此刻却只剩一段向下的木阶。阶下灯火昏黄，一盏、两盏，沿着看不见尽头的楼道往深处排开。

第三盏灯是亮着的。

宁青梧站到他身侧，没有再看玉牌。

“别把玉牌交给我。”她说，“进去以后，也别信第一个叫出你名字的人。”

江临迈上木阶。

“那你呢？”

宁青梧停了一下，随后跟上来。

“我会走在你前面。”

木门在他们身后缓缓合上。

第三盏灯下，有人轻轻笑了一声。

宁青梧的声音压得很低。

“真正点灯的人，就在回灯楼里。”
