# Proposed Active Scene State

地点：镜海界浮空黑石孤岛，北面通往黑色岛群与灰雾。
在场人物：宁烬、镜离、澜生、两名黑甲守卫；远处黑衣人；海陆两面黑舰队。
即时伤势：无明确新增伤势。
手中关键物品：黑门骨，宁烬持有。
当前敌人或追兵：赫连枢麾下黑舰队，奉命活捉宁烬、带回黑门骨并留下澜生；弩炮已瞄准宁烬。
当前倒计时：三日后白昼心在北面海陆交界显现。
当前主动目标：在黑舰队围攻中保住黑门骨并突围，履行与镜离、澜生北行争夺白昼心的约定。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 黑门骨仍对宁烬稳定响应，可排斥他人进入界门；未发生力量位置突破。

### Active Relationships

- 镜离｜希望取得黑门骨｜暂时合作｜与宁烬约定三日内共同向北寻找白昼心，黑门骨暂由宁烬保管｜白昼心出现后各自出力、按结果分配，事后再谈黑门骨归属。
- 澜生（镜海界海身）｜当前与宁烬并肩应敌｜暂时合作、对宁烬产生好感｜主动促成合作条件公开｜需共同应对黑舰队。
- 裴照临｜夺回黑门骨并追查宁烬｜敌对竞争｜仍被隔绝在闭合裂缝外｜后续可能报复。

### Knowledge / Enemy State

- 镜海界本地人通常拥有岸身、海身两具共享生命与记忆的真实身体；杀死一人需同时杀死两处真身。
- 镜离为岸身，澜生为海身；二者共享生命与记忆。
- 赫连枢已下令活捉宁烬并夺回黑门骨，同时要求留下澜生。
- 白昼心将在三日后于北面海陆交界显现，能影响区域真实位置稳定；具体位置尚未确认。
- 骨舟在镜离、澜生手中，但真实航线与白昼火屑尚未取得。
- 黑衣人的身份、能力与敌我立场仍未知。

### World State

- 赫连枢麾下黑舰队同时从海上与陆下压向孤岛，镜海界对宁烬的公开追捕已经展开。

### Tracked Assets

- 黑门骨｜宁烬｜镜海界浮空黑石孤岛｜持有中｜宁烬继续保管。
- 骨舟｜镜离、澜生｜镜海界某处｜可带宁烬向北，真实航线未取得｜本章确认由二人掌握。

# Proposed Chapter Summary

宁烬从镜离与澜生及守卫口中确认镜海界岸身、海身两具真身的规则，并与镜离、澜生约定三日内向北寻找白昼心，黑门骨暂由自己保管。随后赫连枢麾下海陆黑舰队包围孤岛，下令活捉宁烬、夺回黑门骨并留下澜生，宁烬握骨挡在两人之间。
