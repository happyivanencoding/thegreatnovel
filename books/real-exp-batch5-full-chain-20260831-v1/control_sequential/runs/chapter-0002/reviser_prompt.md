- **Sentence-level salvage**：准备删除含 Authority 冲突的段落时，先逐句区分。句子本身若不含冲突，只是因为所在时点/上下文错误而变得不合法，并且直接承载 Core Fantasy、Relationship、Desire、Payoff、Surprise 或 Social Repricing，优先把该句原样或最小改词迁到最近合法位置；不要把整段一起删。只有句子本身就是错误事实时才删除。若原句无法自然迁移，至少保留一次明确语义等价 realization。**Salvage 只保护这类高价值句本身，不保护它周围的报告、登记、路线、重复机制解释或普通实施；救出该句后，周围 process carrier 仍按 Attention Reallocation 正常压缩。**

# Reader-First Prose Contract

Reader-First 短投影：以可见对象、人物动作、现场结果和普通语言优先；新造术语先用场景成立，已通过动作成立的边界不重复解释；**已排程的公共世界常识以“普通读者不用推理就能复述规则”为清楚标准，环境暗示不能代替直接说明；隐藏原因与未来 reveal 继续未知。** 连续动作保持自然段，重大兑现先落地再写必要限制；重大结果需要时给相关人物一个短暂反应窗口，人物可以克制，但克制应表现为有反应后选择压住，不把情绪只写成状态总结；重大结果碰到核心欲望时，不要只写疼痛、策略或状态确认，保留一个可辨认但不强行命名的情绪倾向。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。

## AUTHORITY——按维度划分的事实与计划边界

权威规则按维度划分（不使用单条总排名）：
1. 已发生事实：CANON PROSE > CANON INDEX。CANON PROSE 是已批准的正式前文；已经发生事实的最高来源。CANON INDEX 是当前状态和最近摘要，是正式正文的压缩索引；与正式正文冲突时以正式正文为准。
2. 世界事实：WORLD AUTHORITY 是已批准 World Vision 的安全事实投影，负责世界规律、普通生活、力量正常值、社会现实、价值结构与公开知识边界；BOOK / PLAN 可以决定这些事实何时进入故事，但不得改写它们。named 大事件与未解谜底不在该投影中，仍服从已批准 Story / Plan 与未知边界。
3. 未来创作意图：BOOK CONTRACT > PLAN > OPTIONAL INSPIRATION。BOOK CONTRACT 决定长期故事方向、读者承诺和人物方向；PLAN 决定当前尚未发生的剧情；OPTIONAL INSPIRATION 不能覆盖以上任何权威。
4. 表达控制：PROSE PROFILE 只控制表达方式，不能修改已发生事实或未来计划，也不能改写 WORLD AUTHORITY。

## 力量体系与正常值

玄曜修炼分九个大境界，每境一至九重：锻体、通脉、灵海、神台、天门、王、圣、帝、天外。大境界差距通常显著，但不是绝对胜负公式，功法、兵器、经验、环境和特殊能力都可能制造越级结果。

精确位置格式：{大境界}{N}重
数字精度规则：每境1—9重；未入当前境者按前一境精确位置记录

- 锻体 / 通脉：基础修士。
- 灵海 / 神台：年轻修士与地方中坚常见活动层。
- 天门 / 王：天都高手与一洲霸主层。

飞舟撞在一起，檐角上的修士往下跌，街上乱成一片。那些原本端坐不动的大人物也纷纷起身，各自祭出护身宝物，生怕那只巨掌真的穿过天幕落下来。

宁烬转身就跑。

不是往外跑。

他盯着拍卖台。

黑门骨从玉匣里腾起，被帝境威压卷得翻飞不定。裴照临抬手抓去，一只由灵力凝成的紫色大手已经罩住黑门骨，却在半空被天幕裂缝里压下的余波撞得粉碎。

黑门骨旋转着飞出拍卖台，直直砸向人群。

宁烬脚下一顿。

那东西离他不过十几丈。

身后有人惊叫着避开，前方几名修士却已经扑了过去。有人御剑，有人甩出锁链，还有人干脆一掌拍向半空，想把黑门骨震回自己手里。

宁烬心里只剩下一个念头。

抢。

他现在拿不出二百万灵玉，也压不过裴照临。

可东西已经飞出来了。

黑门骨砸落的瞬间，宁烬扑进翻倒的长案之间，右手先一步探出。

砰！

黑骨重重撞进他掌心。

一股难以形容的寒意顺着手臂钻入经脉，宁烬五指发麻，却在黑门骨弹起之前猛地收紧手指。

有人在旁边喝道：“松手！”

一柄短枪刺破碎木，直取宁烬手腕。

宁烬侧身避过，肩头被枪风擦得一麻。他没看对方，反手把黑门骨按进胸前，灵海三重的灵力全数压向掌心。

他的灵力不够强。

黑门骨却像活了一样，在他手里疯狂震动，几次差点挣脱。

宁烬咬住牙，手背青筋绷起。

“给我安分点。”

又一名修士冲来，宁烬抬腿踹翻压在身前的断案，借着木屑飞起的遮掩撞进人群。他没有往宽处去，专挑倒塌的台阶和翻覆的座椅穿行。

有人想截他，却被天幕落下的威压逼得脚步一滞。

就是这一滞，宁烬冲出了十几步。

裴照临站在拍卖台前，衣角被狂风吹得猎猎作响。他没有再看天幕，目光越过混乱的人群，落到宁烬身上。

一个灵海三重的修士。

衣着普通，修为普通，先前连坐进拍卖场前席的资格都没有。

现在，他手里攥着黑门骨。

裴照临的脸上第一次没了那点漫不经心。

“拦住他。”他顿了顿，“黑门骨，我亲自拿回。”

声音不高，却让附近几名灵海修士同时变色。

宁烬听见了。

他跑得更快，心里却骂了一句。

裴氏古族的人，果然一点脸都不要。拍卖没拿到，转头就要抢。

可骂归骂，他没松手。

黑门骨在他掌中忽然静了下来。

宁烬刚觉得不对，骨身上的裂纹便亮了。

不是灵光。

那几道裂纹像被什么从里面撑开，黑骨发出细微的断裂声。眼前的空气随之扭曲。

一条黑缝在他面前拉开。

四周的风声、人声、天幕上的轰鸣，像被那条黑缝吸走了一瞬。

宁烬停在原地。

黑缝之后，是一片白海。

海水悬在天空，没有岸，也看不见尽头。白色浪潮缓慢起伏，远处有几座黑色孤岛倒挂在云层里，像沉入海底的山峰。那里没有九环天都的灯火，没有熟悉的灵气流动，只有一种陌生又沉重的寂静。

拍卖场里的人也看见了。

有人倒吸冷气，有人眼里的贪婪几乎压不住。

“真的是异世界……”

“门开了！”

宁烬盯着那片白海，手指抓得更紧。

这东西已经到了他手里。

谁想让他交出去，先问问他答不答应。

黑缝忽然轻轻一晃。

一只手从里面伸了出来。

那只手很白，五指修长，指尖停在宁烬面前。黑缝后的白海映在她腕间，冷得没有一丝温度。

紧接着，一个女子的声音从裂缝里传来。

“把门还给我。”

她停了停，语气依旧平静。

“我可以带你去一个死人也能继续活的地方。”

宁烬没有去碰那只手。

镜离从裂缝里走出半身，白衣没有被城中的狂风吹动。她看着宁烬手里的黑骨，声音依旧平静。

“把它给我。”

“给你？”宁烬扯了下嘴角，“你先说说，这东西值多少。”

镜离没有回答。

悬街另一头，紫色灵光破开拥挤的人群。裴照临踏着半空落下，身后跟着数名护卫，前后封住了两条通往城环的路。天舟从云海间穿过，船身拖出长长的灵光，正好横在裂缝附近。

裴照临停在十余丈外，没有急着出手。

“十万灵玉，一座上等洞府。”他看着宁烬，“把黑门骨交出来。”

附近还没逃远的人顿时安静下来。

十万灵玉，足够让灵海修士在天都里活得很舒服。上等洞府更不是寻常人能碰到的东西。有人看向宁烬，眼神里甚至露出几分羡慕。

宁烬也笑了。

“裴公子刚才出两百万都没拿到，现在拿十万来买？”他掂了掂掌中的黑门骨，“你当我穷，就不会算账？”

裴照临的脸色淡了下来。

裂缝里忽然传出甲叶摩擦的声音。

三道高大的黑影踏出白海，黑甲覆住全身，面甲没有露出一丝皮肉。他们站在镜离身后，手里各握着一杆细长黑枪，枪尖垂下，正对着裂缝外的九环天都。

黑缝开始收缩。

原本能容数人并行的裂口，边缘已经向中间压来。空气发出细碎的裂响，附近悬着的碎石被卷进去，连灰都没留下。

裴照临抬手。

一名护卫立刻掠向宁烬，剑光从悬街上方斩下。宁烬没有硬接，转身跃上停靠在旁的天舟。天舟上的船夫脸色煞白，刚想喝止，宁烬已经踩着船栏冲向另一侧。

护卫的剑光劈碎了船尾。

天舟猛地倾斜，船上几名修士惊叫着抓住栏杆。宁烬借着船身晃动落到城环边缘，脚下是翻涌的云海，前方则是正在缩小的裂缝。

裴照临追得极快。

灵海九重的威压压过来，宁烬胸口一闷，脚步险些停住。可城环与天舟之间正有一道窄缝，护卫无法同时挤入，裴照临也被天舟翻起的灵光挡了一瞬。

宁烬抓住这个空当，直接冲向裂缝。

镜离抬起手，像是还想拦他。

宁烬侧身避开她的指尖，一头撞进黑缝。

刺骨的寒意从四面八方压来，脚下的城环、天舟和灯火瞬间远去。他的身体像被一股巨力拉扯，掌中的黑门骨却稳稳贴着手心，没有半点要脱手的意思。

身后传来裴照临压低的声音。

“站住！”

一只紫色大手探入裂缝，五指朝宁烬抓来。裴照临亲自追进了门口，灵力震得裂缝边缘不断颤动。

宁烬回头看了一眼。

裴照临离他只差几步。

下一刻，黑门骨上的裂纹猛地一亮。

裂缝里卷出一股冰冷的力量，正撞在裴照临身上。紫色大手当场崩散，裴照临闷哼一声，整个人被甩回裂缝外，撞断了悬街边的玉栏。

“公子！”

护卫们纷纷扑过去。

裴照临撑着碎石站起，衣袖裂开一道口子。他抬头望向即将闭合的黑缝，目光阴沉得可怕。

黑门骨在宁烬手里能开门，也能把他挡在门外。

这东西对宁烬的反应，和对旁人完全不同。

镜离没有回头。她踏过裂缝边缘，跟着宁烬进入了白海。

黑缝彻底合拢。

九环天都的风声、喊杀声、天舟的轰鸣，全被关在了另一边。

宁烬落在一片湿冷的黑石上，脚下没有土地，只有一座浮在半空的孤岛。四周安静得厉害，连呼吸声都显得刺耳。

他抬起头。

白海悬在天上。

无边无际的海水倒扣于高空，浪潮缓慢翻动，雪白的水光压得整片天地发亮。远处几座黑色孤岛倒挂在白海下方，像被海水吞住了一半。

宁烬握紧黑门骨，正要看向镜离，视线却停在了白海深处。

那里有一道身影。

那人站在一片倒悬的黑石上，隔着遥远的白色浪潮望着他。

黑衣，黑发，连握刀的姿势都和宁烬一模一样。
