# Proposed Active Scene State

地点：九环天都天外珍宝拍卖场混乱区域，黑缝异世界入口前。
在场人物：宁烬；裴照临；拍卖场修士与各方来客；黑缝后的未知女子。
即时伤势：肩头被枪风擦过，暂时发麻；无明确重伤。
手中关键物品：黑门骨，已被宁烬夺得并开启黑缝。
当前敌人或追兵：裴照临已命人拦截，准备亲自夺回黑门骨；附近修士亦可能抢夺。
当前倒计时：无明确倒计时；黑缝已出现轻微晃动。
当前主动目标：保住黑门骨，决定是否回应未知女子并进入黑缝。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬可在混乱环境中凭灵海三重修为夺得并暂时压制黑门骨。
- 黑门骨能开启通往异世界的真实裂口；宁烬尚未永久跨界。

### Active Relationships

裴照临｜要夺回黑门骨｜敌对竞争关系｜确认宁烬持有黑门骨并亲自下令拦截｜正在追捕。
未知女子｜要求归还黑门骨，并声称可带宁烬前往“死人也能继续活”的地方｜首次接触、立场未明｜从裂缝中主动现身并提出交易｜等待宁烬回应。

### Knowledge / Enemy State

- 黑门骨确实能开启真实异世界入口，入口后方可见白海与黑色倒挂孤岛。
- 黑门骨原本可能属于黑缝后的未知女子。
- 裴照临及拍卖场众人已看见黑缝和宁烬持有黑门骨。

### World State

- 天外珍宝拍卖因帝境战场异变与天幕裂口陷入公开混乱。
- 真实异世界入口在九环天都公开出现，黑门骨的价值与争夺已被众人确认。

### Tracked Assets

黑门骨｜宁烬｜拍卖场混乱区域、黑缝入口前｜持有中并已开启裂口｜从拍卖台飞出后被宁烬抢到。

# Proposed Chapter Summary

天外商会拍卖的黑门骨在帝境战场余波中飞入人群，被宁烬抢到并暂时压制。黑门骨开启通往白海异世界的真实裂口，裴照临下令追截宁烬；裂缝中一名未知女子现身，要求宁烬归还黑门骨，并提出带他前往“死人也能继续活”的地方。

# Proposed Open Promises

- 宁烬必须在裴照临及其他修士追截下保住黑门骨。
- 宁烬将面对是否回应未知女子、归还黑门骨或进入黑缝的直接选择。
- 黑缝后的白海、黑色孤岛与未知女子的真实身份和目的仍待确认。
- 镜海界会让“一人两处都是真的”成为可见世界规则，但宁烬前5章不能提前永久获得双真。
