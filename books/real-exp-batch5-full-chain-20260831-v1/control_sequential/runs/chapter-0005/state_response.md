# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬未突破灵海三重。
- 宁烬能利用镜离、澜生与环境制造短暂夹击窗口突围。

### Active Relationships

- 镜离｜继续共同赶往昼皇宫｜暂时合作，信任稳定｜配合宁烬揭穿城主赌局漏洞｜继续争夺白昼心。
- 澜生（镜海界海身）｜协助北上并争取白昼心｜暂时合作，存在资源归属分歧｜带舰引入城门并参与揭穿赌局｜与宁烬继续谈判骨舟和白昼心归属。
- 裴照临｜夺回黑门骨并控制宁烬｜敌对竞争｜追入倒悬城｜继续追击。
- 倒悬城主（岸身、海身）｜维护赌命宴秩序并掌控赌注｜利益冲突、暂不明敌我｜两身不同步被当众揭穿并兑现赌注｜后续立场待定。

### Identity / Access

- 宁烬仍是被镜海界外来势力公开追捕、要求活捉的外界人。
- 宁烬获得骨舟与通往昼皇宫的真实航线，可直接参与白昼心争夺。

### Knowledge / Enemy State

- 倒悬城主的岸身与海身行动、结果并不同步，且赌局结果可被两厅观察者当众验证。
- 白昼心已提前出世，北方出现第二轮太阳，镜海界各方已确认异象。
- 裴照临已看见白昼异象并继续追入倒悬城。

### World State

- 白昼心提前出世，北方天空出现第二轮太阳；倒悬城及镜海界各方开始争相赶往昼皇宫。

### Tracked Assets

- 黑门骨｜宁烬｜倒悬城内长廊｜持有中｜宁烬继续保管。
- 白昼火屑｜宁烬｜倒悬城内长廊｜两枚，均已收起｜宁烬从二照妖兽与赌命宴中取得。
- 黑甲长枪｜宁烬｜倒悬城内长廊｜持有中｜宁烬继续持有。
- 骨舟｜宁烬｜倒悬城内长廊｜已取得，可在天海辨向｜由城主兑现赌注交给宁烬。
- 通往昼皇宫的真实航线｜宁烬｜随身掌握｜已取得｜由城主兑现赌注交给宁烬。

# Proposed Chapter Summary

宁烬借镜离、澜生和撞入城门的黑舰制造的空隙，带二人进入倒悬城，并在赌命宴中识破城主岸身、海身行动不同步的漏洞，赢得白昼火屑、骨舟与通往昼皇宫的真实航线。赌局结束后，北方出现第二轮太阳，白昼心提前出世，宁烬三人立即启程。
