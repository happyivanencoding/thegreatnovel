# Proposed Active Scene State

地点：镜海界北侧礁群断桥前，倒悬城外。
在场人物：宁烬、镜离、裴照临；澜生正带追兵向北牵引；黑舰队逼近。
即时伤势：宁烬衣角与肩侧衣料被妖兽爪风划裂，无明确重伤；镜离无明确伤势。
手中关键物品：黑门骨、白昼火屑、夺来的黑甲长枪。
当前敌人或追兵：裴照临（灵海九重）挡在断桥另一端；赫连枢麾下黑舰队与黑甲修士从后方逼近。
当前倒计时：白昼心将在三日后于北面海陆交界显现。
当前主动目标：保住黑门骨，突破裴照临与黑舰队的夹击，继续向北。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬利用二照妖兽两具身体的感知与动作错位，击杀二照妖兽；未突破灵海三重。
- 宁烬已获得并暂时收起白昼火屑。
- 宁烬可将断裂黑石柱粗略震成石矛；已夺得黑甲长枪。

### Active Relationships

- 镜离｜继续共同突围并寻找白昼心｜暂时合作，战斗配合与信任有所确认｜她将后背交给宁烬，宁烬及时救援｜继续向北并应对裴照临。
- 澜生（镜海界海身）｜牵引北侧海上追兵｜暂时合作｜主动把海上舰队引向北侧，为宁烬与镜离争取通路｜需继续脱离追兵并会合。
- 裴照临｜夺回黑门骨并控制宁烬｜敌对竞争｜现身于倒悬城外并斩断浮桥，正面阻截宁烬｜要求宁烬交出黑门骨。

### Identity / Access

- 宁烬仍是被镜海界外来势力公开追捕、要求活捉的外界人。
- 裴照临已重新进入镜海界，并能在北侧倒悬城外直接阻断宁烬去路。

### Knowledge / Enemy State

- 二照妖兽的岸身与海身共享感知但无法完全同步行动；可利用动作错位制造相互误伤。
- 宁烬已确认二照妖兽死亡后可产生白昼火屑。
- 黑舰队已观察到宁烬以灵海三重借二照规则击杀二照妖兽，因此对其实际威胁重新评估。
- 北侧倒悬城的浮桥已被裴照临斩断，原有北行通路失效。
- 裴照临当前明确为灵海九重。

### World State

- 宁烬击杀二照妖兽并取得白昼火屑的事实已被黑舰队目击，镜海界追捕方对其危险程度的公开判断提高。

### Tracked Assets

- 黑门骨｜宁烬｜倒悬城外北侧断桥前｜持有中｜宁烬继续保管。
- 白昼火屑｜宁烬｜倒悬城外北侧断桥前｜已收起｜宁烬击杀二照妖兽后取得。
- 黑甲长枪｜宁烬｜倒悬城外北侧断桥前｜持有中｜宁烬从黑甲修士手中夺得。
- 骨舟｜镜离、澜生｜镜海界某处｜可带宁烬向北，真实航线未取得｜仍由二人掌握。

# Proposed Chapter Summary

黑舰队围攻中，宁烬利用二照妖兽两具身体无法同步行动的错位，使其互相重创并将其击杀，取得白昼火屑。他与镜离击倒三名黑甲修士，随后来到倒悬城外，却被现身的裴照临斩断浮桥，堵住北行道路。面对黑舰队与灵海九重的裴照临，宁烬拒绝交出黑门骨。

# Proposed Open Promises

- 宁烬需要在裴照临与黑舰队夹击下保住黑门骨并突围。
- 裴照临已进入镜海界并正面阻截宁烬。
- 澜生仍需摆脱被她引向北侧的海上追兵并与宁烬、镜离会合。
- 宁烬、镜离、澜生将在三日内向北寻找白昼心。
- 白昼心将在三日后于北面海陆交界显现，具体位置待确认。
- 宁烬需要确认镜离索要黑门骨的真实目的。
- 宁烬需要确认镜海界黑衣人的身份、能力与敌我立场。
- 宁烬需要寻找穿过倒悬城北侧断桥、继续向北的方法。
- 宁烬需要在镜海界寻找返回九环天都或继续前进的方法。
- 黑门骨为何只对宁烬稳定响应、并能排斥裴照临，仍待确认。
- 白昼心争夺后，镜离与宁烬将重新谈判黑门骨归属。
