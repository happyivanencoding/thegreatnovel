# Proposed Active Scene State

地点：九环天都第七城环外的拍卖场裂口边缘。
在场人物：宁烬；镜离；裴照临；拍卖师、商会护卫与各方修士。
即时伤势：黑门骨钉入宁烬掌心，持续出血并造成剧痛。
手中关键物品：已钉入掌心的黑门骨，正在撑开通往白海与倒挂黑岛的异世界裂口。
当前敌人或追兵：帝境巨掌仍在冲击裂口；裴照临已关注宁烬，商会与各方修士处于混乱中。
当前倒计时：拍卖场天幕已破碎，裂口与石台随时可能继续崩毁。
当前主动目标：保住黑门骨并脱离拍卖场；决定是否接受镜离带路进入裂口后的世界。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 黑门骨已真实落入宁烬手中并钉入掌心，可开启通往玄曜大界之外真实异世界的裂口。
- 宁烬尚未永久进入或获得裂口后的世界；黑门骨造成的掌心伤势仍在。

### Active Relationships

裴照临｜试图判断并控制黑门骨归属｜与主角为公开竞争者，已产生明确关注｜确认宁烬持有黑门骨且可能无法承受其力量｜后续可能拦截或争夺。
镜离｜要求宁烬归还黑门骨，并提出带他进入裂口后的世界｜陌生的异世界来者、当前唯一直接交涉者｜从裂口中现身并声称黑门骨属于自己｜等待宁烬回应或作出选择。

### Knowledge / Enemy State

- 黑门骨确实能开启真实异世界裂口，裂口后的环境为白海与倒挂黑岛。
- 帝境力量可以穿过天幕映照，直接冲击拍卖场与黑门骨。
- 镜离声称黑门骨属于她，并称裂口后存在“死人也能继续活”的地方；真实性未确认。

### World State

- 黑门骨在公开拍卖中被宁烬夺得并开启异世界裂口，拍卖场天幕破碎、秩序失控。
- 拍卖场众人已亲眼确认黑门骨真实存在，且当前持有者为灵海三重的宁烬。

### Tracked Assets

黑门骨｜宁烬｜钉入掌心并维持裂口｜已从拍卖台转移至宁烬，归属引发公开争夺。

# Proposed Chapter Summary

九环天都拍卖黑门骨时，宁烬在帝境巨掌冲击拍卖场的混乱中接住黑骨，使其钉入掌心并开启通往白海异世界的裂口。众人见证黑门骨易主，镜离从裂口现身索要此物，并提出带宁烬进入门后的世界。

# Proposed Open Promises

- 镜海界会让“一人两处都是真的”成为可见世界规则，但宁烬前5章不能提前永久获得双真。
- 镜离声称黑门骨属于自己，要求宁烬归还。
- 镜离提出带宁烬进入裂口后的世界，并声称那里“死人也能继续活”。
