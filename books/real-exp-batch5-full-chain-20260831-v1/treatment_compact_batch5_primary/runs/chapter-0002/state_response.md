# Proposed Active Scene State

地点：镜海界黑色礁石边缘，白海倒悬于天，远处有倒挂黑岛。
在场人物：宁烬；镜离；三名黑甲骑士。
即时伤势：掌心被黑门骨钉入并灼痛；衣袍后背被剑意割裂。
手中关键物品：黑门骨，仍钉在掌心并发烫。
当前敌人或追兵：三名黑甲骑士正在逼近；裴照临已被裂口排斥回九环天都。
当前倒计时：暂无明确倒计时；黑门已闭合。
下一步直接目标：确认镜海界的环境与规则，避免被黑甲骑士夺走黑门骨。
当前主动目标：保住黑门骨并在镜海界活下来，查明镜离所说的“死人也能继续活”是否真实。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 黑门骨能接纳宁烬进入裂口后的镜海界，并排斥试图跟入的裴照临。
- 宁烬可借环境与黑门骨的反卷力量完成跨界；未发生力量境界突破。
- 黑门骨仍钉在掌心，持续灼痛。

### Active Relationships

裴照临｜以十万灵玉和上等洞府收购黑门骨｜与主角为公开竞争者｜出手追击但被门拒绝｜后续可能继续争夺。
镜离｜带宁烬进入镜海界并要求归还黑门骨｜暂时的引路者与潜在争夺者｜停止强抢，退入门内等待宁烬决定｜尚未取得黑门骨。
黑甲骑士｜要求留下黑门骨｜与主角敌对｜穿过裂口追逼宁烬｜正在镜海界内接近。

### Knowledge / Enemy State

- 镜海界真实存在，表现为天上白海、倒挂黑岛与黑色礁石。
- 黑门骨会接纳宁烬，但能将裴照临排斥出门外。
- 镜海界水面中的倒影不会同步宁烬动作，显示此地存在尚未解释的异常规则。
- “死人也能继续活”仍只是镜离的未证实说法。

### World State

- 宁烬已从九环天都进入镜海界，黑门闭合。
- 九环天都的拍卖场目击者已确认黑门骨选择宁烬而拒绝裴照临，裴氏与各方修士对黑门骨的争夺升级。

### Tracked Assets

黑门骨｜宁烬｜镜海界黑色礁石边缘｜钉入掌心并持续发烫｜宁烬通过黑门进入镜海界后仍持有。

# Proposed Chapter Summary

宁烬拒绝裴照临以十万灵玉和上等洞府收购黑门骨，在黑甲骑士与裴照临前后夹击、裂口即将闭合时主动跨入门内。黑门接纳宁烬却排斥裴照临。宁烬抵达镜海界黑色礁石，看见倒悬白海、黑岛，以及不随动作同步的异常倒影。

# Proposed Open Promises

- 镜海界会让“一人两处都是真的”成为可见世界规则，但宁烬前5章不能提前永久获得双真。
- 镜离声称黑门骨属于自己，仍要求宁烬归还。
- 镜离声称镜海界存在“死人也能继续活”的地方，真实性尚未确认。
- 三名黑甲骑士已进入镜海界并追逼宁烬，仍在争夺黑门骨。
- 镜海界水中倒影不随宁烬动作同步，其规则与后果尚未揭示。
