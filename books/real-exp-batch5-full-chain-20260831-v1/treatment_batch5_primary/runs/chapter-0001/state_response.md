# Proposed Active Scene State

地点：九环天都天外珍宝拍卖场。
在场人物：宁烬；裴照临；拍卖者、各方修士；黑缝另一端的陌生女子。
即时伤势：手臂被黑门骨震得发麻，无明确重伤。
手中关键物品：黑门骨，已在宁烬掌中裂开黑缝。
当前敌人或追兵：裴照临及拍卖场中试图夺取黑门骨的修士；有人正在传音召集援手。
当前倒计时：拍卖场已失控，争夺与围攻即将发生。
当前主动目标：宁烬拒绝交出黑门骨，并决定如何应对陌生女子的邀请。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬以灵海三重灵力激发黑门骨，使其裂开通往真实异世界的黑缝；这不代表力量境界突破。
- 黑门骨已成为宁烬当前掌握的真实异世界入口。

### Active Relationships

裴照临｜准备争夺黑门骨｜从漠视宁烬转为亲自关注与潜在敌对｜确认黑门骨在宁烬手中且能被其激发｜是否出手夺取未决。
陌生女子（黑缝另一端）｜要求宁烬归还黑门骨并邀请他同行｜首次接触，立场与目的未明｜主动提出“死人也能继续活”的去处｜等待宁烬回应。

### Identity / Access

- 宁烬因持有并激发黑门骨，成为拍卖场众人争夺与关注的目标。

### Knowledge / Enemy State

- 黑门骨确实能打开通往真实异世界的入口，另一端可见白海、倒挂海面与漂浮孤岛。
- 黑缝另一端存在一名自称能带宁烬前往特殊之地的陌生女子。

### World State

- 帝境战场余威穿透九环天都天幕，震裂拍卖场并意外改变黑门骨归属，引发拍卖场即时争夺。

### Tracked Assets

黑门骨｜宁烬｜九环天都拍卖场内，掌中｜已裂开通往真实异世界的黑缝｜由拍卖台意外震落并撞入宁烬手中。

# Proposed Chapter Summary

天外拍卖场中，帝境战场余威震断银链，黑门骨意外落入灵海三重的宁烬手中。宁烬以灵力将其激发，打开通往真实白海异世界的黑缝，随即遭到众人争夺。黑缝另一端的陌生女子要求他归还门户，并邀请他同行。

# Proposed Open Promises

- 宁烬必须在拍卖场失控、裴照临与众人争夺前，决定是否守住黑门骨以及如何回应陌生女子。
- 黑门骨另一端的白海世界及陌生女子的真实身份、目的与“死人也能继续活”的含义尚未揭示。
- 镜海界“一人两处都是真的”将成为可见世界规则，但宁烬前5章不能提前永久获得双真。
