# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 黑门骨仍可在宁烬手中开启、收紧并关闭异界裂缝；本章未发生力量境界突破。

### Active Relationships

镜离｜提供白昼心出现方向及骨舟、真实航线消息｜暂时合作关系｜与宁烬约定同行三日｜需共同应对赫连枢围捕。
澜生｜镜离的海身，与镜离共享记忆和性命｜暂时合作对象，态度警惕而强势｜现身并确认镜海界双真身规则｜需参与突围与同行。
裴照临｜潜在敌对｜曾被黑门骨挡回九环天都｜后续是否继续追查未决。

### Identity / Access

- 宁烬被镜海界本地人确认属于只有一处真身的外界“单身者”，尚无稳定准入或永久身份。

### Knowledge / Enemy State

- 镜海界本地人通常拥有岸身与海身，两处都是真身；两身共享记忆与性命，两处皆死才算真正死亡。
- 赫连枢已下令留下镜离海身并活捉宁烬，黑色舰队正从空中与陆地两面合围。

### World State

- 镜海界存在可同时占据陆地与白海的双真身者；该规则已被铜镜公开验证。
- 赫连枢势力已对镜离与外界来客宁烬展开跨区域舰队围捕。

### Tracked Assets

黑门骨｜宁烬｜宁烬怀中｜仍可使用，作为交易筹码｜宁烬主动声明暂不归还。

# Proposed Chapter Summary

宁烬从镜离与澜生处得知镜海界双真身的规则，并确认两人共享记忆与性命。他以黑门骨为筹码，与镜离约定同行三日，寻找三日后出现的白昼心、骨舟和真实航线。交易尚未开始，赫连枢麾下黑色舰队已从空陆两面围捕而来。
