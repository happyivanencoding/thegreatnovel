# Proposed Active Scene State
地点：镜海界倒悬城前的断裂浮桥。
在场人物：宁烬、镜离、澜生、裴照临；后方黑色舰队与披甲修士逼近。
即时伤势：肩头被二照妖兽冲势震得发疼，无明确重伤。
手中关键物品：黑门骨；新获白色火屑，疑似被压缩的白昼。
当前敌人或追兵：裴照临（灵海九重）正面截路索要黑门骨；赫连枢舰队从后方追来。
当前倒计时：白昼心三日后出现；舰队合围持续收紧。
下一步直接目标：突破裴照临封锁，进入倒悬城并继续北行。
当前主动目标：保住黑门骨，完成与镜离同行三日的交易并取得目标线索。

# Proposed Persistent Canon
### Power / Capability
Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬利用二照妖兽两具妖身动作不同步的弱点，将其同时击杀；未发生力量境界突破。

### Active Relationships
镜离｜带宁烬突围并继续同行｜暂时合作关系｜三人成功穿过石滩｜需共同应对裴照临与舰队。
澜生｜主动牵引黑舰制造空路｜暂时合作对象｜协助三人向北突围｜需继续参与逃脱。
裴照临｜索要黑门骨并阻断去路｜明确敌对｜在倒悬城前再次截住宁烬｜正面冲突未决。

### Knowledge / Enemy State
- 宁烬已确认二照妖兽共享感知与弱点位置，但两具妖身不能完全同步行动。
- 本地人已公开见证灵海三重的宁烬击杀二照妖兽，并改变对其的威胁评估。
- 裴照临已追至镜海界，并以灵海九重力量封锁倒悬城入口。

### World State
- 宁烬击杀二照妖兽的消息已在石坡附近本地人中形成即时公开影响，外界单身者不再被视为可任意拿捏。

### Tracked Assets
黑门骨｜宁烬｜宁烬手中｜仍可使用，作为交易筹码｜宁烬继续持有。
白色火屑｜宁烬｜宁烬掌心｜已获得，具体用途未明｜宁烬从二照妖兽尸身间取得。

# Proposed Chapter Summary
宁烬借二照妖兽两具妖身无法完全同步的弱点，将其同时击杀并取得一枚白色火屑。镜离与澜生协助他沿石滩突围至倒悬城，却在断裂浮桥前遭灵海九重的裴照临截住，后方黑舰也持续逼近。

- 白色火屑是否就是白昼心、具有什么用途尚未确认。
- 裴照临与宁烬在断桥前的冲突结果尚未确定。
- 宁烬三人能否突破裴照临与黑色舰队的夹击尚未确定。
- 镜海界白海、倒悬孤岛与双真身规则的更深层限制尚未揭示。
- 镜离的真实身份、目的及“死人也能继续活”的完整含义尚未揭示。
- 骨舟与真实航线的下落尚未确认。
- 黑门骨在镜海界的完整用途及后续开启条件尚未确定。
- 白海深处的宁烬倒影与“一人两处都是真的”之间的关系尚未确定。
