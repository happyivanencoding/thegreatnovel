- **Sentence-level salvage**：准备删除含 Authority 冲突的段落时，先逐句区分。句子本身若不含冲突，只是因为所在时点/上下文错误而变得不合法，并且直接承载 Core Fantasy、Relationship、Desire、Payoff、Surprise 或 Social Repricing，优先把该句原样或最小改词迁到最近合法位置；不要把整段一起删。只有句子本身就是错误事实时才删除。若原句无法自然迁移，至少保留一次明确语义等价 realization。**Salvage 只保护这类高价值句本身，不保护它周围的报告、登记、路线、重复机制解释或普通实施；救出该句后，周围 process carrier 仍按 Attention Reallocation 正常压缩。**

# Reader-First Prose Contract

Reader-First 短投影：以可见对象、人物动作、现场结果和普通语言优先；新造术语先用场景成立，已通过动作成立的边界不重复解释；**已排程的公共世界常识以“普通读者不用推理就能复述规则”为清楚标准，环境暗示不能代替直接说明；隐藏原因与未来 reveal 继续未知。** 连续动作保持自然段，重大兑现先落地再写必要限制；重大结果需要时给相关人物一个短暂反应窗口，人物可以克制，但克制应表现为有反应后选择压住，不把情绪只写成状态总结；重大结果碰到核心欲望时，不要只写疼痛、策略或状态确认，保留一个可辨认但不强行命名的情绪倾向。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。

## AUTHORITY——按维度划分的事实与计划边界

权威规则按维度划分（不使用单条总排名）：
1. 已发生事实：CANON PROSE > CANON INDEX。CANON PROSE 是已批准的正式前文；已经发生事实的最高来源。CANON INDEX 是当前状态和最近摘要，是正式正文的压缩索引；与正式正文冲突时以正式正文为准。
2. 世界事实：WORLD AUTHORITY 是已批准 World Vision 的安全事实投影，负责世界规律、普通生活、力量正常值、社会现实、价值结构与公开知识边界；BOOK / PLAN 可以决定这些事实何时进入故事，但不得改写它们。named 大事件与未解谜底不在该投影中，仍服从已批准 Story / Plan 与未知边界。
3. 未来创作意图：BOOK CONTRACT > PLAN > OPTIONAL INSPIRATION。BOOK CONTRACT 决定长期故事方向、读者承诺和人物方向；PLAN 决定当前尚未发生的剧情；OPTIONAL INSPIRATION 不能覆盖以上任何权威。
4. 表达控制：PROSE PROFILE 只控制表达方式，不能修改已发生事实或未来计划，也不能改写 WORLD AUTHORITY。

九环天都是玄曜大界著名天城，九座巨大城环悬在云海上方，跨洲天舟在城环之间往来。普通修士依靠宗门、古族、商会、武府、拍卖与远行机会接触更大的世界；灵玉是修士最常见的大额交易货币。

## 力量体系与正常值

玄曜修炼分九个大境界，每境一至九重：锻体、通脉、灵海、神台、天门、王、圣、帝、天外。大境界差距通常显著，但不是绝对胜负公式，功法、兵器、经验、环境和特殊能力都可能制造越级结果。

主尺名称：玄曜九境
精确位置格式：{大境界}{N}重
数字精度规则：每境1—9重；未入当前境者按前一境精确位置记录

当前大档位：
- 锻体 / 通脉：基础修士。
- 灵海 / 神台：年轻修士与地方中坚常见活动层。
- 天门 / 王：天都高手与一洲霸主层。

## 社会现实与身份

玄曜大界里，一个人正常只有一个真实身体和一个真实位置；幻身、傀儡与分身都被视为替代物，不会被天地当作第二个同等真实的本人。九环天都的天外商会能举行让古族、王侯与高阶修士参加的拍卖；裴氏是天都有分量的古族，裴照临作为同代灵海境9重天才，公开实力远高于宁烬。

十万灵玉，外加裴氏古族的名头，已经不是普通修士能碰的价。

拍卖者刚要落锤，天外忽然传来一声闷响。

九环天都上空的巨大天幕猛地亮起。

那里原本映照着极远处的帝境战场。帝境修士交手，隔着大洲都能改变山河天象，天都的天幕便是用来看清那些远战的。

此刻，天幕里一片灰白。

一只大得遮住半边天的手掌从战场裂口中探出，五指压下，隔着天幕都让拍卖场的地面裂开。

“帝境！”

有人失声大喊。

银链当场崩断。

黑门骨被巨掌余威震得翻飞，撞碎拍卖台，又穿过数层护栏，直直朝宁烬砸来。

宁烬本能抬手。

黑门骨撞进他掌心，骨头冰冷，震得他整条手臂发麻。四周的视线同时落下，像无数把刀。

裴照临也站了起来。

宁烬低头看了一眼掌中的黑门骨，心里只剩一个念头。

这东西已经到了他手里。

谁要，他都不给。

他五指收紧，灵海三重的灵力全部压进掌心。黑门骨剧烈震颤，骨纹忽然裂开一道缝。

黑缝里没有黑暗。

一片白海悬在天空，海面倒挂，远处还有孤岛漂浮其间。那不是秘境投影，而是一片真实存在、从未见过的天地。

拍卖场彻底乱了。

有人向宁烬扑来，有人退得更快，也有人已经在传音叫人。

有人看清宁烬身上的灵力波动，脱口道：“灵海三重？”

另一个声音紧跟着响起：“裴照临是灵海九重，他们之间足足差着六重！”

裴照临从玉席走下，目光第一次真正落在宁烬身上。

一个灵海三重的穷修士，本不该值得他亲自出手。

可黑门骨在宁烬手里裂开了。

黑缝另一端，忽然伸出一只白皙的手。

手指纤长，停在宁烬面前。

黑缝里传来女子冷淡的声音。

“把门还给我。”

宁烬没有松手。

那声音停了停，又道：

“跟我走，我带你去一个死人也能继续活的地方。”

“站住。”

裴照临的声音不高，却压过了整片喧声。

宁烬脚下不停。

“十万灵玉，一座上等洞府。”裴照临站在后方的悬街上，语气平静，“把黑门骨交出来。”

宁烬差点气笑。

十万灵玉和一座洞府，确实够让许多人拼命。可他掌里攥着的是一座真实异世界的大门。

“裴公子留着买茶吧。”

他踩上掠过街边的天舟边缘，借船身一翻，落到另一侧城环。后方护卫立刻追来，数道劲风擦着他的肩头掠过。

黑缝正在远处合拢。

镜离已经从裂缝里走出半个身子，黑衣贴着修长身形，身后跟着三名甲胄漆黑的骑士。她看着宁烬，目光冷得像在看一件本该归位的东西。

“门要关了。”镜离说道，“你进来，还是把它给我？”

宁烬没回答。

他从两座城环之间跃下，脚尖在一艘天舟的桅杆上借力，整个人贴着云海掠过。裴照临的掌风紧跟而至，震碎了他刚才踩过的桅杆。

灵海九重的追击，让他连回头都嫌浪费时间。

裂缝只剩下一人宽。

镜离身后的黑甲骑士已经逼近门口，裴照临也从另一侧横掠而来。宁烬看见裴照临伸出的手，心里很清楚，自己一旦停下，黑门骨就再也握不住。

他把最后一点灵力灌进双腿，撞开裂缝边缘翻卷的黑气，直接冲了进去。

天地颠倒。

身后传来裴照临一声冷喝，接着便是一股比先前更强的力量撞向裂口。

可黑门骨在宁烬手中震了一下。

裂缝边缘骤然收紧，裴照临的力量像撞上一堵看不见的墙，整个人被甩回九环天都的城环上。

宁烬落地时，脚下是冰冷的黑石。

裂缝已经闭合。

镜离从他身后走出，三名黑甲骑士停在更远处，没有立刻上前。

这里的海在天上。

白色海水横悬于高空，缓慢流过倒挂的孤岛。陆地在下方延展，黑石间长着一丛丛银白色的草。

宁烬抬头，看见白海深处有一道身影。

那人和他一模一样。

同样的脸，同样的站姿，隔着倒悬的海水，正安静地望着他。
