# Proposed Active Scene State

地点：镜海界陆地，倒悬白海下方。
在场人物：宁烬；镜离；三名黑甲骑士；白海深处与宁烬一模一样的倒影。
即时伤势：手臂仍有麻意，无明确重伤。
手中关键物品：黑门骨，仍在宁烬手中。
当前敌人或追兵：镜离与三名黑甲骑士立场未明；裴照临已被挡回九环天都。
当前倒计时：无明确倒计时；通往九环天都的黑缝已经闭合。
当前主动目标：确认镜海界与眼前倒影的关系，并决定如何回应镜离。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：玄曜九境｜精确位置：灵海3重
- 宁烬以灵海三重灵力冲入黑门骨开启的裂缝，未发生力量境界突破。
- 黑门骨可在宁烬手中收紧裂缝，阻挡并甩回裴照临的力量。

### Active Relationships

镜离｜要求宁烬归还黑门骨并邀请同行｜首次接触，立场与目的未明｜宁烬进入她所在的镜海界｜等待宁烬回应。
裴照临｜试图以灵玉与洞府换取黑门骨并随后强行阻拦｜潜在敌对｜被黑门骨的闭合力量甩回九环天都｜是否继续追查未决。

### Identity / Access

- 宁烬已进入镜海界，但尚未获得稳定准入或任何永久身份。

### Knowledge / Enemy State

- 通往九环天都的黑缝已经闭合。
- 镜海界存在倒悬于高空的白海与漂浮孤岛。
- 白海深处出现与宁烬外貌、姿态完全一致的倒影，其性质未知。

### World State

- 宁烬与黑门骨进入镜海界，入口闭合；九环天都与镜海界暂时隔绝。

### Tracked Assets

黑门骨｜宁烬｜镜海界陆地上｜仍在掌中，入口已闭合｜宁烬携带穿过黑缝。

# Proposed Chapter Summary

宁烬拒绝裴照临的利诱与追捕，携黑门骨冲入即将闭合的裂缝。黑门骨挡回裴照临的力量并彻底关闭入口。宁烬抵达镜海界，在镜离和三名黑甲骑士面前，看见白海深处映出一个与自己完全相同的倒影。

# Proposed Open Promises

- 镜海界白海、倒悬孤岛与“同一人两处都是真的”现象的真实规则尚未揭示。
- 白海深处的宁烬倒影是否真实、能否行动，以及与宁烬的关系尚未揭示。
- 镜离的真实身份、目的与“死人也能继续活”的含义尚未揭示。
- 黑门骨在镜海界的归属、用途与后续开启条件尚未确定。
- 镜海界“一人两处都是真的”将成为可见世界规则，但宁烬前5章不能提前永久获得双真。
