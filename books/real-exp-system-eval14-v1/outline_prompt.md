你是透明协作的故事 Outline 助手。生成前必须确认 Fantasy Seed、World Vision 和 Story Program 都已由作者明确批准；模型生成、模型选择、作者编辑和 legacy_unknown 都不是批准。已批准的三份创意产物高于产品默认模板，不能被静默改写。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

Growth Genome 是整理工具，不是创造世界的第一语言。它只负责在核心幻想、世界画像和长期故事方向已经批准后，整理一级成长、二级收益、阶段升格、主循环、反哺关系和重复风险，帮助故事运行到更长篇幅。它不选择核心幻想，不替主角决定欲望，不决定力量是否令人向往，也不要求所有故事制度化。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

Supporting Logic Must Not Automatically Become Story Engine：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

Core Fantasy Invariant：Fantasy Seed 与 World Vision 一旦由作者批准，后续 Story Program、Outline、Review 和单章规划可以改变地图、敌人、关系、资源与具体玩法，但不能静默替换这本书最值得幻想的东西。核心幻想不变量不是要求反复解释同一设定，而是要求读者持续得到同一种根本欲望的更强兑现：主角越来越能拥有、驾驭、突破、夺取、探索、反杀、长生、自由行动或实现本书自己承诺的体验。路线规模、流程效率、经营网络、资格、权限、组织与资产都可以增长，但它们只能承载或放大核心幻想，不能逐步取代核心幻想成为故事本体。

Fantasy Compounding > Operational Compounding：长篇复利首先放大核心幻想本身，再让已有积累改变后续故事。上一轮最好让主角下一轮出现新的能力用法、更大的主动权、更高价值的目标、迫使对手采用新的应对、让重要关系出现新的选择，或打开过去进不去的世界，而不只是把同一件事做得更快、更稳、更多、更标准化。复利不是资产种类越来越多；路线更多、货量更大、流程更顺、联系人更多、产能更高都只能是承载结果，如果它们没有进一步改变主角“亲自能做什么”、别人“必须怎样回应”和读者能感到的核心幻想，就不要把这种规模化本身当作主要成长。

Outline Fantasy Proof（软规划原则，不新增字段或 Hard Gate）：对承担主要推进职责的大型剧情块，优先在现有“具体发生 / 核心幻想推进 / 一级成长变化 / 收益与反哺”等位置写出一个具体、不可逆、可复述的场面或结果，让读者能够一句话说明“这次核心幻想真的又发生了什么”。未来十章整体也应有清楚的近期 Fantasy Proof；纯承接或蓄势章节可以服务这次兑现，不要求每章单独证明。不要用“能力理解更深、体系更完善、路网扩大、经营更稳定、影响力提升”这种摘要替代证明。

Outline World Model Release（新书前五章软规划原则，不新增字段或 Hard Gate）：World Vision 已经建立的力量/能力、身份、价值与核心优势边界，Outline 要决定何时让读者通过事件看见，而不是把解释责任拖到 Director。前五章只释放当前判断真正需要的最小坐标：读者应逐渐知道主角当前大致处在哪一层、一个明显更强/更高位置的人能做到什么、主角当前得到或争夺的具体东西值在哪里，以及核心优势面对更高层对象不会怎样无条件越级。不要把这些坐标集中成设定说明；优先通过晋升兑现、一次强弱对照、一次具体花费/获得、一次核心优势选择或失败自然展示。若前五章发生身份/境界/组织层级跃迁，之后优先安排至少一个具体场面让读者看到“以前进不去/拿不到/见不到/不能参与”的世界真的打开，而不是只多出新名额、新审批或下一项任务。

Outline Core Gameplay Variation（前期玩法软规划原则，不新增字段或 Hard Gate）：核心优势第一次高光解决的是“它能不能做到”；后续几章优先把问题推进成“面对多个对象/时机/代价/目标，主角为什么选这个”“别人怎样针对它”“同一优势还能用出什么不同结果”。相邻高潮若仍是同一对手、同一种能力使用和同一种胜负翻转，只换场地或限制，默认视为重复，除非它确实带来新的能力玩法、关系阶段或世界后果。长期对手可以暂时作为强弱标尺、旁观者或反制者存在，不要求几章内反复败给主角。

Outline Story Anchor Density（软规划原则，不新增字段、评分或 Hard Gate）：中期大型剧情块不能只给一个覆盖十几二十章的阶段摘要，再把“中间具体发生什么”留给 Director 自己发明。每个剧情块在现有“具体发生”字段内，先用一句写清本块真正的故事主问题，再按因果顺序给出若干连续故事锚点；通常 3—5 个，只有很短的块可以 2 个，这只是内容密度参考，不是计数门禁。每个锚点是一次会改变局势的故事事件：写清谁为了什么采取行动、谁阻止或回应、主角做了什么关键选择或怎样使用核心优势、最后哪项关系/身份/力量/利益/行动空间发生不可逆变化，以及这个结果为什么触发下一锚点。锚点粒度停在“故事转折”，不要继续拆成路线选择、受力判断、搬运、制作、检测、计算、逐步验证等实施步骤；如果去掉操作过程后一个锚点就没有人物利益、力量差、关系变化、身份变化、资源得失、世界入口或不可逆结果，它就过于操作化。目标是提高故事确定性，不是提高施工步骤确定性。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的规则 → 主角立即行动。世界尺度或宏观秩序可以用一句强信息提前出现，但必须迅速落回具体人物、地点和行动；不要先把世界模型讲完，再把主角放进来，也不要写成设定集。先让读者知道眼前的人要解决什么，再让核心异能打破当前常识。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

阶段推进优先（软规划原则，不是固定频率、评分项或 Hard Gate）：
连续章节同时判断事件推进和阶段推进。如果连续章节主要重复“障碍出现 → 分析结构或规则 → 使用相似能力解决 → 立刻出现下一障碍”，而人物身份、关系、资源、行动空间、主动目标、敌人策略和故事舞台没有实质变化，应在当前计划允许的范围内压缩或合并这些过程，不要继续拆成独立章节。重复本身若确实产生新的阶段意义，可以保留。

规划十章时，优先让读者感到多个真实阶段：主角主动目标改变或升级，身份或社会评价改变，关键关系改变，重要资源开始稳定利用，被帮助者形成反哺，敌人策略调整，进入新的行动舞台，或主角从解决别人给的问题转向主动建设、获取或改变某件事。不要把它实现成每 N 章必须发生一次的计数规则。

章末推动力不默认等于新危险，也可以是新选择、新机会、身份重定义、关系转折、实际资源到账、新发现或主角主动决定的下一步。高价值行动之后允许有短暂但有效的结算；只有真正改变关系或未来行动空间时才安排社会回声。

先忠实复现已批准的核心幻想、力量占有欲、主角欲望、世界奇观、不可调和压迫、决定性反转、早期兑现、稳定循环、中期里程碑和远期升格方向。不得把力量、长生、反杀、探索、超越或世界奇观重新解释成专业能力、职业资格、行业标准、公开试验、制度责任或组织治理。

最终只能使用以下四个一级标题：

# 小说总体设计画像
# 当前中期规划窗口
# 未来十章逐章小纲
# 当前状态、未兑现承诺与作者备注

### 核心不变量
只写 1—3 项长期读者体验。
### 退化风险
只写 1—3 项最真实的退化风险。

## 1. 核心类型与读者承诺
优先写核心幻想、力量占有欲、主角最强欲望、第一次决定性反转、早期兑现、稳定循环、中期里程碑、远期升格方向和前中远期情绪兑现。
早期兑现、稳定循环和中期里程碑除了说明主角本人多能做什么，还要各用一个具体、不可逆、可复述的事件证明这次变化已经发生；不要只用境界、掌握程度、规则理解或能力名称作为节点。远期升格方向只写长期方向和上限感，不要求在当前窗口兑现。
## 2. 世界观结构
说明最震撼的景象、最向往或恐惧的区域、力量怎样改变生命状态、主角成长后能进入什么过去不可触碰的地方，以及哪些未知无法只靠技术验证解决；如果本书需要且对当前故事重要，再补充空间/层级、权力关系和力量道路。
## 3. 世界如何持续制造剧情压力

## 候选1：借命成真

### 核心幻想

主角能够看见自己眼前几种“本来可能发生的未来”，并主动夺取其中一种，让它提前成为现实。

读者最想拥有的不是预知，而是在关键时刻亲手挑选命运：本来会落空的攻击突然命中，本来必死的逃亡忽然出现生路，本来不会相遇的人被强行拉入同一场因果。

### 主角最强欲望

开局驱动力：他必须摆脱一个即将发生、却几乎无法避免的死亡或失去。别人只能接受结果，他第一次看见了结果之间的缝隙，因此不得不行动。

长期扩张动力：当最初的危机被改写后，他发现未来并非一条答案，而是一片不断生成的可能性。他开始追逐那些只有在更大行动、更高风险中才会出现的未来：从活下来，到选择自己要成为谁、谁能留在身边、什么样的世界值得被保留下来。

他会主动把自己投入高价值、高危险的局面，让更多不可能的未来出现，再从中夺取最有利的一条。

### 力量占有欲

第一次使用时，他不是“知道答案”，而是亲眼看见数个自己同时行动：一个向左逃，一个迎面出刀，一个跪下求饶。随后他亲手抓住其中一个未来，把身体和现实拽向那条路。

直接收益是立刻获得原本不存在的行动选择，避开必死局面，或者把一次低概率的胜利变成既成事实。

限制不是简单消耗，而是被放弃的未来不会消失，可能以错位的伤势、失去的关系、陌生人的命运或未来敌人的变化形式留下后果。

### 第一次标志性奇观

暴雨夜，主角被逼到悬崖边。

他看见十七个自己从不同方向坠落、反击、求饶或死亡。真正的他伸手探入虚空，从那十七道身影中拽出一个正在斩断敌人手腕的自己。

下一刻，悬崖边只剩一具站着的身体，敌人的断腕却已经落进雨水。

### 长期增长发动机

主角反复寻找那些拥有多重结果的关键局面：争夺机缘、夺城、结盟、复仇、渡劫、进入禁地。他主动把局面推向更高烈度，使原本单一的选择变成多条可争夺的未来。

本轮永久留下的，是他曾经兑现过的未来经验、被改写的人际关系、已改变的敌我格局，以及某些原本不会存在的机会入口。

已有积累会让他更早看见关键分叉，更准确判断哪些未来具有真正价值，也让他逐渐能够把未来中的局部成果带回现实，而不是只能改变最后一瞬。

世界因此不断打开新的机会：更高层修士开始意识到，有些“注定结果”正在被人夺走；他们必须提前布局、封死可能性，甚至制造只有一种结果的绝境。

### 非对称优势

别人只能在现实中下注，主角可以先看到下注可能带来的数种结果，再选择最值得承担的一种。

早期，他只能夺取自己的未来；后来可以把某个未来中的动作、位置或短暂关系拖入当前现实；再往后，他能在多方势力交锋前制造新的分支，让敌人只能在他已经挑过的局面中应对。

多次使用后留下的不是单纯熟练度，而是被他亲手改写过的世界状态。曾经选择过的未来，会成为现实中的新基础，下一次选择便不再从原来的起点开始。

### 第一次主动兑现

主角主动让一个“自己已经夺得灵药”的未来成真。

现实中，他明明没有拿到灵药，却从濒死的敌人手里取出了一枚原本只会在另一条未来中出现的药瓶。直接收益是恢复行动能力，并取得继续追杀或逃亡的资格。

情绪释放不是庆幸，而是第一次确认：命运不是墙，而是可以被自己伸手撕开的帘子。

留下的第一笔积累，是那条被夺走未来中的敌人开始提前警觉，未来的追杀因此被改写。

### 早期兑现（约10章）

主角主动引导一场看似必败的截杀，先让自己进入所有人都认为无法逃脱的位置，再从数个未来中夺取唯一一条“敌人彼此误伤、他夺得关键物”的结果。

他得到关键资源、真正脱离追杀，并第一次让一个比自己强得多的人不得不重新评估他。

### 稳定循环（约30章）

主角已经多次使用能力，不再只靠临死关头翻盘。

他会主动寻找能够产生高价值未来的局面，先判断哪些结果值得争夺，再设计行动把局势推入分叉。早期夺来的身份、关系与资源开始反哺后续选择，使他能够接触更高层的争斗。

读者此时会清楚：这本书的快感不是等待主角预知答案，而是看他把自己押进最危险的棋局，再亲手挑走胜利。

### 中期里程碑

主角完全改变一个大型势力本来注定的覆灭结局，并让其中一部分人成为新世界格局中的关键力量。

不可逆事件是：一座本来必然被毁的古城在所有人眼前从毁灭未来中被“夺回”，但城中某些本应死去的人、某些本应存在的历史也因此同时进入现实。

从此，诸界开始把他视为能够争夺“既定结局”的人。

### 远期升格方向

他最终不再只选择自己的未来，而是能够在世界级灾变、诸界战争与文明兴亡之间争夺未来形态。

他的生命层次从“改变命运中的一人”，升格为“让某种未来获得存在资格的人”。

### 世界扩张欲望

更高层世界拥有更多可能性，也拥有能够封锁未来、垄断结果的强大存在。读者会想知道：当主角终于能选择世界的未来时，他会把哪个世界留下，又愿意让哪一种可能彻底消失。

## 已批准 World Vision

# 世界幻想画像

## 核心幻想不变量

这不是一本“提前知道答案”的故事，而是一个人亲手从多种可能中夺走命运的故事。每次力量兑现，都必须让读者看见“本来不会这样，却被主角强行变成这样”的瞬间。主角的胜利不能只停留在当场翻盘，还要改变关系、敌我判断、身份位置或未来入口。越到后期，他面对的不是更大的数字，而是越来越多值得争夺、也越来越难保全的未来。

## 主角最强欲望

主角最初只想摆脱一场即将发生的死亡：一场已经被所有人默认、甚至被安排好的死亡。

活下来之后，他逐渐不满足于“别死”。他想夺回被命运拿走的人、身份和选择权，想证明自己不是只能接受结果的人。最终，他必须面对更大的问题：当不同的未来代表不同的人、不同的文明和不同的世界时，他究竟要让什么存在，又愿意亲手放弃什么。

## 主角身份与生命状态跃迁

开局时，主角只是一个刚刚踏入修行门槛、即将被当作弃子的低阶修士。他的身体、寿命、身份和行动范围都受制于现实，连活过眼前一夜都需要借助别人不愿给他的机会。

中期，他会从“被结果决定的人”变成能够主动制造关键局面的行动者。过去夺来的未来会改变他的关系、名声、敌人和进入更大世界的资格，使他不再只是逃亡者，而成为各方必须考虑的变量。

长期，他的生命状态将从承受命运，升格为让某种未来获得存在资格的特殊存在。他不必成为全知全能的神，但他的选择会开始影响城市、势力、文明乃至诸界的存续形态。

## 世界最震撼的三幅画面

第一幅，是暴雨悬崖边。主角看见十七个自己从不同方向坠落、反击、求饶或死亡，随后伸手探入虚空，从其中拽出一个正在斩断敌人手腕的自己。雨幕里只剩一个站着的主角，而敌人的断腕已经落入现实。

第二幅，是诸界战争中，一道足以把天地切开的力量正在落下。主角没有挡住它，也没有复制施术者的力量，而是在无数世界被切开的未来里，拽出一个仍保留人名、历史和选择权的世界，把它从毁灭结果中拖回现世。

第三幅，是本来必然毁灭的古城。城墙、居民和历史都已经在众目睽睽下走向死亡，主角却从那条毁灭未来中夺回整座城。城活了下来，但城中本应死去的人、原本不该存在的旧史，也随同被夺回的未来进入现实。

## 世界核心规则与力量来源

天地间存在灵息，来源于山河、星辰、血肉、魂魄和天地运行留下的道痕。普通人可以通过锻炼身体、吸纳灵息、修习术法和承受环境淬炼，逐渐让自身成为能够容纳并操纵力量的生命。

修士的强弱，不只取决于灵息多少，也取决于身体能否承受、技艺能否稳定、知识能否判断局势，以及自身是否拥有合适的环境和身份。一个灵息深厚却不会战斗的人，可能输给善于利用地形和时机的低阶修士；但当差距大到一定程度后，高阶修士可以直接压制低阶修士的速度、感知、术法和生存空间。

天地本身并不存在一条写死的唯一未来。现实是无数可能在关键节点不断收束后的结果。普通修士只能通过经验、推演、占测和观察痕迹判断趋势，无法真正看见多个未来并主动夺取其中之一。

强大存在可以通过封锁环境、控制信息、提前布置、牺牲所有替代方案等方式，让一个局面只剩极少甚至唯一的结果。于是修行越高，越不只是增强力量，也是在争夺“谁有资格让某个结果成为现实”。

## 读者可用的世界坐标

本书只需要读者掌握四个可观察的力量尺度。

- 养息修士：身体明显超越常人，能使用一两种稳定术法，面对刀兵和普通围攻有生存优势，但仍会被数量、陷阱和重伤杀死。

- 成术修士：能够连续施展成熟术法，改变一场小规模战斗的地形和节奏。普通人无法正面对抗，低阶修士也很难靠人数弥补差距。

- 立域修士：力量可以覆盖街巷、山谷或战场一角，压制低阶术法，改变局部环境。此时身份通常意味着稳定的资源、法律保护和组织资格，但不等于拥有稀缺机缘。

- 见界层次：能够接触一地、一城或一方小世界的根本规则，影响空间通行、区域生死和大型势力的存续。此后不再适合用简单的个人战力比较，而要看谁掌握了更大的因果范围。

修士被组织承认后，通常能获得住所、基础灵息、疗伤条件、传承指导和最低限度的保护。这些是正常待遇，不应被写成每次冒险才获得的奖励。真正值得争夺的是高品质修炼地、续命灵药、完整传承、界门路引、灾变前的真实记录、公开名位以及能够改变他人立场的关系。

## 核心优势与普通规则怎样咬合

主角真正获得的是：看见自己眼前若干条正在成形的可能未来，并把其中一条提前拉入现实。他改变的是“结果归属”和“行动路径”，不是凭空获得所有条件。

他的身体仍然决定能否承受动作，灵息仍然决定术法威力，知识仍然决定他能否理解局势，材料和环境仍然决定某些行动是否可能，身份和关系仍然决定哪些入口会向他开放。未来中出现一枚灵药，不代表他可以在任何地方凭空创造灵药；只有当某条未来已经包含他取得、接触或使用它的因果，他才可能把“取得灵药”这一结果带回当前。

面对远高于自身层级的目标时，他不能直接复制对方的修为、法则或生命层次。他可能夺取一条“对方露出破绽”“某个旁观者介入”“自己从必死位置逃出”的未来，却不能凭空获得战胜对方的力量。如果所有可见未来都没有可利用的接触点，他只能承认无法改变结果，或先改变局面本身，让新的分支出现。

主角越强，越能把未来中的局部动作、位置、短暂关系和事件结果带回现实；但这会让他的行为更容易被高层存在察觉。敌人可以封死道路、制造单一结果、提前抹除关键关系，甚至故意制造多个伪未来诱导他选择。

## 力量带来的直接体验

第一次发动时，主角不会得到一段完整预言，而是看见多个自己同时活着：不同的呼吸、脚步、伤口和选择在眼前重叠。他会同时感到几种截然不同的恐惧，随后必须亲手抓住其中一个自己。

被夺取的未来会像已经发生过的记忆一样短暂压入身体：他知道刀该从哪里落下，脚该踩向哪块石头，哪一瞬间敌人会失去平衡。过去不存在的行动选择因此立刻出现。

第一次收益不是“赢得漂亮”，而是从必死局面中获得一条真正能走的路。旁观者看到的则是结果与过程脱节：没人看见他拿到药瓶，却看见药瓶已经在他手里；没人看见他完成斩击，却看见敌人的手腕已经断了。

## 力量的升格方向

早期，主角只能夺取自己的短期未来，用于躲避攻击、改变位置、完成一次本来失败的动作。

随后，他能把未来中的局部成果带回现实：提前取得某件物品，进入本来无法进入的位置，让短暂的盟友关系提前发生，或让一次偶然相遇变成现实中的契机。

中期，他不再等待危险发生，而是主动把争夺、截杀、结盟和复仇推向多方同时下注的状态，再从中选择最有价值的一条未来。过去的选择会改变下一轮的起点：救下的人可能成为盟友，也可能成为新的软肋；公开展现的能力会让敌人提前封锁未来；被改写的敌我关系会关闭某些旧道路，同时打开新的入口。

更高层次上，他可以在大阵、城池、天灾和世界边界中争夺集体结果。此时他的力量不再只是让自己做出某个动作，而是让某种局面获得继续存在的资格。

能力的风险不是机械消耗，而是被放弃的未来可能留下残响：错位的伤势、提前警觉的敌人、没有发生却影响现实的关系、被迫改写的陌生人命运。每一次选择都可能让他得到一条路，也让另一条路以代价的形式压回现实。

## 世界资源、利益与机会结构

这个世界真正改变行动空间的资源包括：

- 灵脉、灵泉和稳定修炼地：决定修士能否持续成长，通常属于重要但可被组织分配的基础条件。

- 灵药、续命物和修复神魂的材料：能够改变寿命、伤势和修行上限，数量有限，足以引发追杀和争夺。

- 完整术法、传承和高阶修士的指点：决定一个人能否把力量转化为可靠行动，而不是只有灵息没有办法。

- 界门路引、古城名册和灾变前记录：决定谁能进入新区域、谁知道真实历史，以及哪些人拥有合法身份。

- 公开名位、可信关系和活着的见证者：决定某个结果是否会被世界承认。主角夺来的未来如果没有现实中的关系或证据承接，可能只是一次孤立的奇迹。

主角的优势使他能把普通人只能押一次的机会，变成经过多种结果比较后的长期选择。他不一定得到更多资源，却更容易把资源投到真正能改变后续的地方，也更容易保住关键人物、抓住关键入口。

地图扩大后，价值增加不是因为“数字更大”，而是因为新的区域拥有不同的结果结构：某些地方未来分支极多，适合争夺机缘；某些地方由强者封死可能性，适合试探规则；某些古老区域保存着已经被现世抹去的历史。

## 持续冲突来源

早期冲突来自一场即将完成的灭口。主角被当作可以牺牲的替罪者，追杀者并不需要理解他的能力，只需让他没有第二条路。

随后，竞争者会争夺同一件机缘、同一名证人、同一条逃生路线或同一个势力位置。主角的能力让他在局部占优，却也会让敌人开始怀疑那些“过于恰好的结果”。

中期，掌握资源和身份的势力会试图控制多种可能：提前垄断道路、封锁消息、安排婚盟与继承、制造只能得到一种结果的战争。他们未必是纯粹邪恶，而是相信世界必须被少数人稳定下来。

另一类压力来自被放弃的未来。主角改变了一场战斗，可能让某个陌生人活下来，也可能让另一个人失去原本拥有的人生。这些后果会以追索、误会、关系换位和历史异常的形式回到他面前。

当世界尺度扩大后，真正的敌人不只是更强的修士，而是那些能让一城、一界甚至一段文明只剩一个未来的存在。

## 第一次决定性兑现

主角在濒死追杀中主动让一个“自己已经夺得灵药”的未来成真。

现实里的他原本两手空空，敌人已经封死退路。但在几种未来交叠的瞬间，他看见另一条路上的自己从濒死敌人身上取出药瓶，于是伸手把那一结果拽回当前。药瓶落入掌心，药力立刻恢复他继续行动的资格。

他首先得到的不是胜利，而是身体没有当场崩溃、可以继续追杀或逃亡的行动空间。随后，敌人开始意识到自己面对的不是普通的低阶修士，原本确定的追杀结果第一次出现了不可解释的偏差。

主角真正获得的第一笔积累，是一个被改写的敌我关系：那个敌人没有按原本的未来死亡，反而提前知道了“有人正在夺走结果”。

## 早期成长锚点与长期升格

### 早期兑现

开书早期，主角必须在一场暴雨、截杀和身份清算中跨过第一个小门槛。他不能凭能力直接打赢强敌，而要把自己主动放进所有人都认为无路可逃的位置，逼出足够多的未来分支。

他最终夺取“敌人彼此误伤、自己拿到关键物并脱离追杀”的结果，获得关键资源、继续修行的资格，并让一个明显强于自己的人不得不重新评估他。

### 稳定循环

约三十章时，能力已经从临死翻盘变成可持续玩法。主角会主动寻找多方利益同时冲突的局面：争夺机缘、营救人物、参与结盟、反向利用追杀和进入危险区域。

他不再只看哪条未来能让自己活下来，还会比较哪条未来能留下更好的关系、身份、证据和下一步入口。过去的选择开始真实反哺后续：救下的人提供新视角，夺来的身份带来新权限，暴露的能力则迫使敌人改变布局。

读者此时应明确感受到：主角不是等待预知答案，而是主动把自己押进最危险的棋局，再亲手挑走最值得承担的胜利。

### 中期里程碑

第一个大型阶段充分展开后，主角将改变一座古城本来注定被毁的结局。

他不是单独拯救所有人，而是在城内各方都已经做出选择、毁灭即将收束时，夺回一个让整座城继续存在的未来。不可逆的结果是：古城活下来，但部分本应死去的人、失落的历史和不属于当前现实的关系也一同进入现世。

从这一刻起，各界不再把他当成偶然逃生的修士，而会把他视为能够争夺既定结局的人。

### 远期升格方向

长期来看，主角可以把选择范围从自己的动作扩展到大型事件、世界边界和文明存续。他会面对的不再只是“我能不能活”，而是“哪一种未来值得被留下”。

他的战斗方式将从夺取瞬间结果，发展为制造分支、保存可能、争夺世界入口和改变集体命运。能力上限不是无条件改写一切，而是在多个真实存在、彼此竞争的未来中，让其中一条获得现实资格。

## 神秘、未知与世界入口

读者最想探索的不是“能力还有多少层”，而是三个问题：

主角看见的未来究竟来自哪里；被放弃的未来是否真的消失；世界上是否有人早已知道结果可以被夺走。

新世界不会靠突然传送打开，而会由旧剧情留下的后果逼出来。敌人身上的异常伤痕可能指向一座封闭古城；被主角救下的人可能携带进入更高势力的身份线索；灵药瓶上的旧印记可能证明某段历史曾经被改写；主角公开改变追杀结果后，专门封锁未来的势力会主动找上门。

每次进入更大世界，都同时改变主角能看见什么、别人怎样理解他，以及他下一步真正想要什么。

## 核心情绪与读者体验

本书反复兑现三种体验：

第一是从必死结果中撕出一条生路的惊险与释放。

第二是亲手挑选命运、把低概率胜利变成现实的掌控感。

第三是过去的选择持续压向未来：主角得到的每一样东西、救下的每一个人、放弃的每一条路，都可能在更大的局面中重新要求他付出代价。

## 作者已批准的 Story Program

## 总览

这条主线从一场已经安排好的灭口开始。主角先从十七种死亡里夺回自己，再逐渐发现：决定一个人能否活下来的，不只是力量，还有身份、见证、关系，以及世界是否承认这个结果存在。

故事采用六个自然大型阶段。核心能力始终是“从真实存在的多种未来中夺取一种”，但剧情发动机持续变化：从亡命翻盘，转向古城存续与历史争夺；再进入多方下注、无未来之地的探索、结果垄断下的诸域战争，最终抵达文明未来的选择。

主角不会靠不断增加能力组件成长。他的一级成长首先表现为身体、修为、生命层次和因果作用范围的提升；长期复利则来自那些已经被他改写、并且再也回不到原点的人、城市、敌我关系与世界入口。

## 世界观与故事主线

### 已批准幻想怎样落地

主线始终保留“亲手夺取命运”这一核心幻想。

主角不是站在局外预测结果，而是主动进入危险，使原本收束的局面重新产生分叉，再从几种真实可能中夺走最值得承担的一种。每次关键兑现都必须出现清晰的因果断裂感：过程本来没有完成，结果却被他从另一种未来带进现实。

能力的长期变化不改变这一根本体验：

- 早期夺取自己的动作、位置和即时结果。
- 随后夺取物品归属、短暂关系和局部事件结果。
- 中期主动制造多方下注的局面，让新的可能出现。
- 更高层次争夺城池、地域和群体能否继续存在。
- 远期让某种世界未来获得现实资格。

每次重要胜利都会留下不可回滚的变化。被救下的人继续行动，被揭穿的敌人改变策略，被夺回的城市成为现实中的新势力，被放弃的未来则可能通过伤势、记忆、误会或另一批人的损失回到主线。

### 主角与长期一级成长

主角开局是下层宗门的一名养息修士。修为刚够使用最基础的术法，身体留有旧伤，没有可信身份，也没有能够为他作证的人。他被选为一桩资源失窃案的替罪者，即将在暴雨夜被带到悬崖边灭口。

他最初只想活下来，随后要夺回被栽赃夺走的身份和选择权。当他发现自己的死亡只是更大布局中最容易牺牲的一环，他开始主动追索：谁有资格把某个人、某座城乃至某段历史判定为“可以不存在”。

他的主动行动方式是把局面推到真正存在多种结果的位置。早期是诱使追杀者分兵、争功或者彼此怀疑；中期是让多个势力同时下注，使任何一方都无法独占结果；更高层次则是保住关键人物、选择和世界入口，让原本被封死的局面重新出现未来。

一级成长沿着四个可观察层次展开：

- 养息阶段，他夺取自己能够承受的短期动作和结果。
- 成术阶段，他能稳定完成未来中的局部动作，并把已经具备因果条件的成果带回现实。
- 立域阶段，他能在一定范围内维持多个结果同时成形，使敌人无法轻易把局面压成唯一答案。
- 见界阶段，他开始触及城池、区域和小世界的存续结果，生命状态也逐渐从承受未来的人，变成能够让一种未来获得存在资格的人。

古城归来是第一个大型阶段的完成证明，不是他的长期力量上限。

### 世界、力量与奇观

天地灵息来自山河、星辰、血肉、魂魄和道痕。普通人通过淬体、吸纳灵息、修习术法和承受环境淬炼成为修士。修行首先改变身体承受力、寿命、感知和战斗能力，随后改变行动范围、社会位置以及接触世界规则的资格。

力量差距真实存在。低阶修士可以借助地形、时机和知识战胜更强者，但无法无视绝对压制。主角的不同不在于灵息无限，而在于他能看见正在成形的数种未来，并夺取其中一个结果。他仍然必须拥有完成那个结果的身体、环境、接触点和因果条件。

世界中最值得继续探索的奇观围绕“被现实放弃的可能”展开：

- 暴雨悬崖上，十七个主角同时坠落、反击和死亡，他从中拽出斩断敌人手腕的自己。
- 必然毁灭的烬河古城被从死亡未来中夺回，城墙、居民与一段不属于当前现实的旧史同时归来。
- 诸界战争中，天地被切开的无数未来重叠，主角从中拖回一个仍保留人名、历史与选择权的世界。

越高层的区域不只是灵息更强，也拥有不同的结果结构。有些地方未来繁盛，有些地方已经被强者压成近乎唯一的结局，还有些地方保存着现世主动删去的历史。

### 核心优势与长期玩法

主角的非对称优势，是能够在别人只能下注一次时，先接触几种真实可能，再决定夺取哪一种。

第一次使用带来的不是情报，而是现实行动能力。他从另一个未来带回正确的步伐、斩击和取药结果，因此获得活下去并继续行动的资格。

长期玩法经历五次主要变化：

第一种是绝境夺路。主角从几种即将发生的个人结果中，夺取唯一可行的动作或位置。

第二种是夺取局部成果。他可以把未来中已经通过真实因果取得的药物、证据、位置或短暂协作带回当前，但不能凭空创造不存在的东西。

第三种是主动制造分叉。他不再等待未来出现，而是通过挑战、救援、结盟、挑拨或者公开下注，让更多人物作出真实选择，使原本单一的局面产生可争夺的未来。

第四种是维持他人的选择。当敌人通过隔绝、恐惧和利益垄断压缩结果时，他开始保护那些能够继续产生变化的人、关系和行动，使一城一域不被提前锁死。

第五种是争夺集体存在。进入见界层次后，他可以让一座城、一方地域或一个世界未来获得现实资格，但不能无条件保存所有结果。

已有积累持续进入后续：早期救下的见证者使他的奇迹能够被承认；夺回的古城成为更大冲突中的真实立足点；公开暴露的能力迫使敌人改用诱导、封锁和伪未来；过去被他放弃的人生则在新阶段形成追索者、误解和新的立场。

### 核心优势的选择空间与反制

主角看见的未来不等于完整答案。未来越复杂，他越需要判断什么真正值得夺取。

一个表面更强的结果可能并不是最优选择：

- 他能杀死敌人，却因此失去唯一能够证明真相的活口。
- 他能独占机缘，却会让本可成为盟友的人认定他不可信。
- 他能救下一名重要人物，却可能使另一段本来稳定的关系彻底错位。
- 他能保住一城，却必须接受随那条未来一同归来的旧史与旧债。
- 他能赢得眼前战争，却可能帮助某个势力把更多人的未来压成唯一结果。

敌人的反制也会随阶段变化。

早期追杀者封死地形和退路，不给他产生第二种结果的条件。随后，对手会隐藏关键物、提前杀死见证者，或者让他即使夺得结果也无法得到现实承认。

知道他能看见未来的敌人，会故意制造多个诱人的伪分支，在其中放入错误信息、背叛或延迟发生的代价；也会逼迫他在次要冲突中提前出手，使真正的关键节点到来时，他已失去观察和准备条件。

更高层存在不再单纯防御他的能力，而是通过控制所有参与者的选择，把战争、继承、结盟甚至一域存亡压成唯一结果。主角因此必须先改变现实局面、让别人重新拥有选择，之后才有未来可夺。

### 第一次完整兑现

暴雨悬崖上，主角面对三名追杀者，其中一人携带能够暂时稳住他伤势的续命灵药。

他先看见十七种即将发生的结果：坠崖、被擒、求饶后遭灭口、反击却因身体崩溃而死。主角没有等待最好的结果自行出现，而是主动撞向携药之人，逼迫另外两名追杀者同时出手。

新的分支因此产生。

他从重叠的身影中抓住那个斩断敌人手腕的自己。现实中没有完整的挥刀过程，断腕却已经落进雨水。随后，他又从“自己已经从濒死敌人身上取走药瓶”的未来里夺回结果。

灵药入手后，他没有立刻变强，只是重新获得奔跑、战斗和追索真相的资格。他利用追杀者之间已经产生的猜疑冲出绝境，并带走能够证明自己只是替罪者的关键物。

主要情绪释放不是侥幸，而是确认：所有人都已经接受的结果，仍然可以被他亲手撕开。

余波随即产生。携药追杀者没有按照原来的未来死亡，反而带着失腕和错位记忆活了下来，成为第一个明确意识到“有人正在夺走结果”的人。

### 世界结构与持续冲突

世界由依附灵脉、山河险地和界门而生的宗门、城池、氏族与修行势力构成。稳定身份可以带来住所、基础修炼条件、疗伤和最低保护；真正稀缺的是完整传承、续命灵药、见界资格、界门路引、真实历史与能让结果被公开承认的名位。

早期阻力来自宗门内部的利益清算。主角知道了不该知道的资源流向，因此被选作最容易消失的替罪者。

烬河古城之后，持续冲突逐渐指向“一真道”。这个跨域势力相信，多种未来长期并存会导致历史错乱和世界崩解，因此主张由少数能够见界的人提前决定哪些结果可以存在。它确实阻止过灾难，却也由此垄断城市、继承、战争和世界入口的结局。

另一重压力来自被放弃的未来。被主角救下的人可能带回原本不存在的记忆；失去原定人生的人可能追索他；同一段关系在两种历史中可能拥有不同承诺。它们不是每次发动能力必付的固定代价，而是重要选择对现实造成的真实后果。

长期冲突由此形成：主角要不断创造并夺取新的可能，一真道及相似势力则试图证明，只有把未来压成唯一结果，世界才能继续存在。

### 关键关系（可选）

最初追杀主角并失去手腕的修士，是长期追索线的核心人物。他并非只想复仇，而是要确认自己的记忆为什么与现实不符。随着异常增多，他可能成为最了解主角旧成功的人，也最擅长针对主角。他与主角既可能短暂合作，也可能因“世界是否应当拥有多种未来”走向无法调和的对立。

烬河城的守籍人负责保存居民姓名、旧史和合法身份。此人最初需要主角救城，后来却会质问他：当两种历史都带着活生生的人归来时，他凭什么决定谁算真实。其目标是让城中之人不再被外界随意删去，因此即使离开主角视线，也会主动争取城的名位与生存空间。

来自高层势力的继承竞争者反对一真道垄断结果，却不认同无限放任未来。此人需要主角打破旧秩序，也担心主角成为新的结果垄断者。两人的关系会从互相利用，转为并肩下注，再转为必须重新谈判世界规则的盟友与竞争者。

### 长期故事主线

#### 阶段1：雨夜夺命，古城归来

开局状态：  
主角是即将被灭口的养息修士，重伤、无名、无证人，也没有能够返回的宗门位置。

当前最值得争取的机会 / 目标：  
先活过雨夜，取得续命灵药和能够证明自己被栽赃的关键物；随后追查关键物上的古城印记，为自己夺回合法身份。

主要事件与具体阻力：  
悬崖截杀之后，宗门宣布主角畏罪叛逃。追杀者争夺功劳，真正的幕后人则开始销毁证人。关键物将主角引向即将被舍弃的烬河古城。城中不同势力分别准备逃亡、夺取遗产或利用毁灭清除旧账，一真道的先行者则推动天地异变提前收束，使古城只剩毁灭一种结果。

主角主动行动：  
他利用追杀者之间的利益矛盾连续制造分支，从逃亡者变成反向追查者；进入古城后，不只寻找自己的清白，也主动保住能够让城市产生不同未来的关键人物、见证和选择。他迫使原本各自逃命的人在城毁之前公开下注。

核心优势怎样产生超额结果：  
早期夺取斩击、位置和药物归属；随后把未来中已经取得的证据带回当前。最终，在全城各方真实行动已经形成一条可行未来后，他从毁灭结果中夺回仍然存在的烬河城。

主角一级成长：  
身体旧伤得到真正修复，养息趋于圆满，并跨入能够稳定施术的门槛。他从只能在濒死瞬间抓住动作，成长为能够辨认局部成果是否具备现实因果。

阶段净新增：  
烬河城从必然毁灭的结果中真实归来，主角也从无人承认的逃犯变成这场异常唯一无法绕开的当事人。城中归来的旧史与活人，使世界再也无法恢复到此前的单一版本。

核心幻想兑现：  
他先夺回自己的命，再夺回一座本来不被允许继续存在的城。已有的药物、证人、身份线索和关系共同构成救城条件，而不是在高潮时凭空出现。

主要情绪释放：  
绝境反杀、洗去弃子身份、让决定牺牲他的人亲眼看见“必然结果”失败，以及把一座城从死亡中强行拖回来的巨大掌控感。

世界扩张：  
古城归来带出不属于当前历史的人名、伤痕和记录，证明现实曾经被更高层力量删改，也暴露出专门封锁未来的势力。

推向下一阶段的更大机会、欲望、竞争或压力：  
主角终于有了立足点，却必须面对更难的问题：归来的两种历史互相冲突，谁有资格决定城中哪些人、关系和权利算数。

自然产生的后果或余波（如果有）：  
最初的断腕追杀者带着与现实不符的记忆投向一真道；古城内部也有人认为主角救回的并不是原来的城，而是一个夺走他们人生的替代结果。

#### 阶段2：一城两史，谁算活着

开局状态：  
烬河城仍然存在，但城中同时出现两套互相冲突的亲缘、债务、继承与忠诚。主角拥有名声，却没有决定一切的权力。

当前最值得争取的机会 / 目标：  
让古城获得外界承认，保住其中真实活着的人，并找出哪一段旧史记录了主角能力的来历。

主要事件与具体阻力：  
周边势力争夺古城资源，并以历史矛盾为由要求接管。城中旧人与现世居民围绕身份和损失相互冲突。一真道不急于攻城，而是扶持彼此矛盾的当事人，证明“多种未来共存只会制造灾难”。

主角主动行动：  
主角不替所有人宣布唯一真相，而是保护能够公开作出选择的人，让不同群体通过行动重新建立现实关系。他追查伪造记忆与真实残响的区别，并主动放弃一个能让自己完全控制古城、却会把其他人降为附属结果的未来。

核心优势怎样产生超额结果：  
他开始夺取短暂关系和局部事件结果，例如让一名本来会在数日后选择作证的人提前站出来，或把一次尚未完成的救援结果带回当前。但关系只能提前发生，不能凭空忠诚；主角必须让对方在现实中继续认可自己的选择。

主角一级成长：  
稳定进入成术层次，能够承受更长的未来动作记忆，并把能力用于战斗之外的营救、公开见证和关系重构。

阶段净新增：  
烬河城获得不依附原有宗门的公开名位，主角也第一次拥有能够被外界承认的现实身份。一真道从追杀他转为研究和诱导他的选择。

核心幻想兑现：  
主角不是得到一座供自己经营的城，而是让一群本来会被历史抹掉的人保住重新选择人生的资格。他也因此获得进入更高层界门争夺的合法资格。

主要情绪释放：  
从被全世界定罪的人，变成能够迫使上位势力公开承认其结果的人；旧日可以随意命令和牺牲他的人，如今必须与他谈判。

世界扩张：  
古城旧史指向数座已经从地图和记忆中消失的地域，也显示一真道只是更大“归一秩序”的一部分。

推向下一阶段的更大机会、欲望、竞争或压力：  
一座通往高层地域的界门即将重新选择归属。谁能进入，不只决定修炼机会，也决定烬河城的历史能否被诸域正式承认。

自然产生的后果或余波（如果有）：  
部分被主角救下的人不愿继续依赖他，主动离城寻找属于自己的答案；他们的离开在后续形成新的盟友、竞争者与召回线。

#### 阶段3：万宗下注，先手成局

开局状态：  
主角是有名却根基不足的成术修士。烬河城为他提供身份，却也让所有人知道他有必须保护的对象。

当前最值得争取的机会 / 目标：  
夺得进入高层地域的界门资格，获得适合自身的完整传承，并查清一真道如何把多方争夺压缩成预定结果。

主要事件与具体阻力：  
诸宗、城邦和氏族围绕界门展开继承、结盟和争夺。一真道不直接禁止竞争，而是提前控制候选人、道路和见证，使表面众多的选择最终都指向同一个归属。主角看到的多个好未来中，开始出现敌人故意布置的诱饵。

主角主动行动：  
他不加入任何一方预设的胜负，而是找到各方真正无法让出的欲望，主动促成新的联合与背叛。他有意公开一部分能力，引诱对手围绕旧有使用方式布置，再从人物临场产生的新选择中夺取结果。

核心优势怎样产生超额结果：  
主角能够把未来中的位置、短暂协作或已经完成的关键动作提前带回现实。他不再只选择现成未来，而是通过改变谁能参与、谁愿意下注，制造敌人没有预先封锁的分支。

主角一级成长：  
突破成术极限，开始触及立域。力量不只让他完成一次动作，也能短暂维持周围数种行动可能，使强者的局部压制不再等同于唯一结局。

阶段净新增：  
主角取得真正属于自己的界门通行资格和完整修行道路，从被允许参与争夺的人变成能够改变争夺条件的人。高层势力此后必须针对他的关系与判断，而不能只针对他的战力。

核心幻想兑现：  
他把自己押进诸宗已经安排好的胜负中，最终夺走的不是某一方预备好的头名，而是一条原本不存在的入界道路，使烬河城和被排除者同时获得新的世界入口。

主要情绪释放：  
看穿却不服从上位者设计的选择，借所有人的下注撕开新局，并让那些只把他视作稀有工具的人失去定价资格。

世界扩张：  
界门之后不是单纯更强的修炼地，而是一片曾被现实删除的区域。那里几乎没有可见未来，证明有力量能够从源头上消灭分支。

推向下一阶段的更大机会、欲望、竞争或压力：  
主角必须进入“无未来之地”。那里可能保存着开局灭口案、古城旧史和他自身异常的共同源头，也可能让他的核心优势首次真正失效。

自然产生的后果或余波（如果有）：  
在界门争夺中被他提前拉入现实的联盟，并不天然永久忠诚。有人因获益继续同行，也有人认为主角夺走了本属于自己的胜利。

#### 阶段4：无未来之地

开局状态：  
主角初入立域，已经能够在复杂局面中夺取结果，却进入一个所有事情都仿佛只有唯一走向的封闭地域。

当前最值得争取的机会 / 目标：  
找回被现世抹去的历史，确认被放弃的未来去了哪里，并让这片地域重新拥有选择。

主要事件与具体阻力：  
此地的道路、居民和修行方式都被固定在重复结局中。主角几乎看不见其他自己，敌人也不必诱骗他，只要维持现有秩序。同行者开始怀疑，离开这里的唯一方法是否就是接受一真道给出的安全未来。

主角主动行动：  
他依靠此前获得的修为、关系、见证和知识行动，而不是等待能力给出答案。他寻找仍然能够作出真实决定的人，揭开被压抑的利益和记忆，迫使已经停滞的关系重新发生选择。主角第一次不是从未来中选路，而是先在现实中创造一条此前不存在的路。

核心优势怎样产生超额结果：  
当第一批真实选择重新出现时，他抓住的不再只是自己的动作，而是“这片地域仍能产生未来”这一局部结果，使被锁死的空间短暂恢复分叉。

主角一级成长：  
立域真正成立。他能够让一定范围内的选择不被高层力量立即抹平，并开始感知一地规则怎样决定哪些结果有资格存在。

阶段净新增：  
一片被删除的地域重新进入现世，证明一真道所宣称的唯一未来并非自然真理。主角从夺取未来的人，成长为能够重新创造未来条件的人。

核心幻想兑现：  
在能力最不占优势的地方，他靠此前积累的人、修为和选择重新制造可能，再亲手把这条不可能存在的出路变成现实。

主要情绪释放：  
核心能力被压制后的逆势突破；不是捡到更强力量，而是证明即使世界只允许一个答案，他也能让第二个答案出现。

世界扩张：  
主角得知被放弃的未来并未完全消失，而是沉积在诸界边缘。大量被删去的历史正在相互挤压，一真道的归一秩序既是垄断，也是在压制一场真实逼近的世界灾变。

推向下一阶段的更大机会、欲望、竞争或压力：  
诸域必须决定如何面对未来残响。一真道准备以更彻底的方式把天下压成唯一安全结果，主角则必须证明世界能够在拥有选择的同时继续存在。

自然产生的后果或余波（如果有）：  
重获选择的地域并不会自动支持主角。有人感激他，也有人因为重新出现的风险和痛苦怨恨他，成为一真道最有说服力的支持者。

#### 阶段5：天下只许一种结果

开局状态：  
主角已是成熟的立域修士，拥有古城、失落地域与多方人物形成的真实支持，但尚不能正面对抗控制诸域规则的见界存在。

当前最值得争取的机会 / 目标：  
阻止天下被压入一条不可更改的安全未来，同时找到不让被放弃可能直接冲垮现实的办法。

主要事件与具体阻力：  
世界残响引发地域错位、旧史回流和界门失控。一真道借灾变获得广泛支持，开始让各城各宗接受预定继承、预定牺牲和预定存续。反对者内部也互不信任，因为每一方都希望主角选择对自己最有利的未来。

主角主动行动：  
他不承诺保存所有结果，而是推动不同地域公开作出自己的选择，并亲自承担这些选择相互冲突的后果。他利用过去建立的关系同时发动多个真实行动面，让一真道无法通过杀死一个人、封闭一条路便让天下归一。

核心优势怎样产生超额结果：  
主角把一场已经被预定结局的诸域战争重新变成多方能够改变结果的战争，并首次从未来中夺取涉及大量人物的集体行动结果。超额之处不只是赢下一战，而是让敌人失去垄断“什么算现实”的资格。

主角一级成长：  
踏入见界层次，能够感知城池、界门和地域的存续边界。他的生命开始同时承受多种未来留下的记忆与痕迹，但仍不是全知，也不能让不存在的条件凭空出现。

阶段净新增：  
多个地域获得不经一真道许可也能保留自身未来的现实位置。主角从各方必须考虑的变量，变成能够与见界存在争夺集体结果的人。

核心幻想兑现：  
主角让此前救下的城市、人物、身份和世界入口全部回流到大战中。每一次旧选择都改变当前谁能行动、谁愿意承担风险，最终汇成开局时绝不可能存在的胜局。

主要情绪释放：  
从被安排死亡的弃子，成长为让安排天下结局的人失去绝对权力；敌人不能再通过宣布“只有这一条路”结束争论。

世界扩张：  
诸域之外显露出彼此竞争的世界未来。世界灾变不再只是一个敌人的阴谋，而是多种文明、历史和生存方式争夺现实资格。

推向下一阶段的更大机会、欲望、竞争或压力：  
主角即将面对无法只靠局部双赢解决的选择：不同世界都真实存在，却未必能够同时留下。

自然产生的后果或余波（如果有）：  
一些曾经支持主角的人开始要求他为自己选择世界；另一些人则担心他会成为比一真道更无法制约的结果决定者。

#### 阶段6：诸界留真

开局状态：  
主角已经能够争夺一城一域的集体结果，但诸界未来相互挤压，每一种存续方式背后都有真实人物、历史和代价。

当前最值得争取的机会 / 目标：  
在世界级灾变中保住仍然拥有姓名、历史与选择权的未来，同时拒绝成为替所有生命计算唯一答案的新主人。

主要事件与具体阻力：  
不同世界为自身存续结盟、背叛和争夺。原一真道内部也会分裂：有人坚持彻底归一，有人承认旧法已经失败。真正的冲突不预设为消灭某个终极恶人，而是围绕哪些未来具备现实条件、谁愿意为选择负责，以及如何面对无法全部保全的结果展开。

主角主动行动：  
他深入诸界冲突最激烈的位置，让本来只会互相毁灭的世界产生新的关系与选择。在天地被切开的时刻，他不是寻找没有代价的答案，而是根据一路上真实形成的人物行动、承诺和世界条件，亲手夺取一个仍保留人名、历史与选择权的世界未来。

核心优势怎样产生超额结果：  
他不复制斩开天地的力量，而是从无数世界被切开的未来中，把仍能继续产生选择的那个世界拖回现实。超额结果是某种未来不只没有毁灭，还取得了继续变化的资格。

主角一级成长：  
生命层次升格为能够让世界未来获得存在资格的人。他依然必须面对真实条件与互相竞争的结果，不能无条件改写一切。

阶段净新增：  
世界第一次确认，未来的存在资格既不天然属于强者，也不必由唯一秩序预先决定。主角本身成为诸界无法绕开的现实坐标。

核心幻想兑现：  
从悬崖边抓住一个活着的自己，到诸界中抓住一个仍允许众生选择的世界，核心幻想完成同质而更高层的兑现：本来不会留下的结果，被他亲手变成现实。

主要情绪释放：  
力量、身份与生命层次的终极升格；读者看到的不是主角终于知道正确答案，而是他拥有了选择、承担并让某种未来真实存在的力量。

世界扩张：  
现实之外仍有被放弃的世界、尚未相遇的文明，以及不同方式理解未来的高层生命。主线可以在此形成终局，也可以根据人物与世界因果继续生长。

推向下一阶段的更大机会、欲望、竞争或压力：  
如果故事继续，新的问题将不再只是“留下哪一个世界”，而是被留下的世界怎样面对那些仍在现实之外要求存在的未来。

自然产生的后果或余波（如果有）：  
主角没有获得一个自动正确的永恒答案。被留下的人会继续选择、争执和改变；被放弃的未来也可能以新的关系、记忆和世界入口重新提出要求。

### 早期锚点、中期里程碑与远期升格

#### 早期兑现

开书早期，主角在暴雨追杀中先夺取断腕与灵药结果，随后主动诱导一场看似必败的截杀。

他故意进入三方都认为无路可逃的位置，使争功、灭口和资源争夺同时发生，再夺取“敌人彼此误伤、自己取得关键物并脱离追杀”的结果。

他跨过的第一个门槛不是境界飞跃，而是从只能接受死亡的弃子，变成能够主动制造并夺取胜局的人。具体获得包括续命机会、关键资源、洗清身份的线索，以及一名强敌对他的重新评估。

#### 稳定循环

能力经过多次真实使用后形成稳定主循环：

主角发现高价值机会或无法接受的结果，主动进入多方利益交汇的局面；通过行动让参与者产生不同选择；判断哪一种未来不仅能赢，还能留下更好的关系、身份、证据或世界入口；夺取结果后，再承接它造成的新敌我格局。

过去获得的修为、证人、关系与身份会让他下一轮接触更高价值的局面。敌人对旧成功的研究则迫使他改变发动方式。主循环因此不是重复绝境翻盘，而是不断出现“同一种夺命幻想还能这样实现”的新体验。

#### 中期里程碑

第一个自然大型阶段充分展开后，烬河古城在众目睽睽下走向毁灭。

主角已经通过此前行动保住足够多的关键人物、见证和选择，使“古城仍然存在”成为真实但极低概率的未来。他最终从毁灭结果中夺回整座城。

不可逆、可复述的证明是：城墙、居民和历史重新进入现实，但部分本应死去的人以及不属于当前历史的关系也随之归来。

从此，主角不再是偶然逃生的低阶修士，而是诸域公认能够争夺既定结局的人。具体章节位置由古城人物、冲突和能力玩法是否充分展开决定，不绑定百章，也不代表长期力量封顶。

#### 远期升格方向

如果本书长期成立，主角的能力将从夺取个人动作，发展为制造分支、保存可能、争夺世界入口和改变集体命运。

他的修为与生命层次会让他看见更大范围的真实未来，但不会使他获得无条件创造结果的权力。他必须先让人物、势力和世界具备真实行动条件，才可能让某种未来获得现实资格。

最终上限感是：当世界级力量已经落下、诸界都在走向不同毁灭时，他能够从那些真实存在的未来中，拖回一个仍保留人名、历史和选择权的世界。

### 继续探索的世界与未来场面

这个世界值得继续探索，因为地图扩大意味着不同的“未来生态”，而不只是更高数值。

读者可以期待：

- 一座所有道路都会把人送回同一结局的封闭地域，主角必须先创造选择，能力才重新出现。
- 一场各宗都以为自己在自由下注、实际所有结果早已被一真道控制的界门争夺。
- 被古城归来改变人生的人，在数十章后以新的身份重新出现，并要求主角面对当初选择的另一面。
- 曾经被提前拉入现实的短暂盟友，后来主动拒绝主角为自己选择未来。
- 强敌制造多个看似完美的伪未来，主角反而选择一条收益较小、却能留下关键人物与后续入口的结果。
- 主角在立域强者封死空间时，不直接越级取胜，而是让旁观者、敌人内部和环境同时产生新的行动可能。
- 一真道曾经封锁的失落地域重新出现，居民却并不一致欢迎自由与风险。
- 诸界战争中，天地已经被斩开，主角从重叠的毁灭世界里，亲手拖回一个仍有人记得姓名、历史并能够继续选择的世界。

### Inspiration 1
source: mechanisms/thread-collision-v3
type: mechanism
score: 0.1315

可用抽象：Creative Problem：怎样让一个大事件真正合流 main plot / relationship / mystery / power / world 中的若干条线，而不是只是把很多角色叫到同一场？
Mechanism：成熟的碰撞点需要一个共享因果铰链和一个不可回避的选择。这个选择同时改写若干线程的未来可行性：某条安全路径关闭、某段关系换位、某个谜团获得新解释、能力意义变化、阵营或世界事实改变。强 payoff 往往还有 narrative afterlife：旧目标完成后，其结果自然成为新承诺、新敌人、新生活问题或第二层解释。
Variants：- 身份暴露：安全表层生活关闭，关系和敌我同时重写。
- 牺牲/死亡：结算追捕或冲突，同时生成复活、继承、独立行动或新敌人。
- 旧物终局用途：同时结算谜团、身份与能力来源。
- 生活性仪式被大冲突劫持：婚礼、约战、重聚同时结算关系和旧敌。
Guidance：不要求每次凑齐五栏。判断一个 thread 是否真的参与碰撞：移除它后，这个事件的选择、结果或后续可行性是否会改变？
Failure Modes：- 角色都到场但因果互不相干。
- 为了“大高潮”塞入尚未成熟的线。
- payoff 只关旧问题，不留下任何后续状态。
- 强制每个高潮都要求多线合流。

使用边界：迁移共享因果铰链与 narrative afterlife；碰撞强度由共同选择实际改写了多少线程的未来来决定。

### Inspiration 3
source: mechanisms/hidden-identity-long-v3
type: mechanism
score: 0.0655

可用抽象：Creative Problem：隐藏身份怎样跨长篇维持而不靠强行藏答案？揭露后怎样真正改变当前故事？
Mechanism：先让表层身份独立成立并积累真实后果：朋友、爱情、债务、名声、信任与社会位置都是真实的。线索应尽量同时兼容旧解释与新解释；揭露落在人物正在行动的碰撞点，并立刻关闭或改写一条现实路径，例如安全身份失效、继位失败、归乡目标改变、某人开始被追杀。揭露重解释过去，但不删除过去。
Variants：- 长期潜伏者。
- 异类/血脉身份。
- 多个真实社会自我。
- 错误预言/公共误读逐渐追上现实。
Reader Payoff：“原来如此”与“接下来怎么办”同时出现；过去的普通场景获得第二层意义，而当前关系不能再按旧方式继续。
Guidance：设计隐藏身份时先写清：表层生活为什么能长期工作；哪些线索在旧解释下也合理；揭露会关闭什么现实选择。
Failure Modes：- 线索从一开始就只支持真相解释，角色长期看不见显得失智。
- 揭露只补背景，不改变当前选择。
- 宣布是假身份后把此前关系全部清零。
- 为反转而多层套娃。

使用边界：《斗罗大陆》《诡秘之主》《将夜》直接支持长期隐藏身份/身份重释；《修真聊天群》只提供“公共误认逐渐追上现实”的邻近证据。迁移揭露后的关系与行动变化，不把公共误认等同于长期潜伏身份。
