# Proposed Chapter Summary

顾行舟在两道攻击落下的瞬间夺取黑玉续命药瓶，并用牙咬开瓶塞服下灵药。药力暂时压住虚弱后，他沿崖壁石缝和石梁逃离围攻。韩烬与两名修士未能追上，却察觉药瓶取得方式异常，韩烬开始追问顾行舟究竟从何处拿到灵药。
