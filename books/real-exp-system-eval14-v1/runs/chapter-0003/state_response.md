# Proposed Persistent Canon
- 顾行舟已首次将当前因果中真实存在的一条未定结果攥入现实，令韩烬持刀右腕断裂、窄刀折断。
- 能力仍不能凭空创造结果；必须依靠已存在的因果分支与现实中的动作、力道和角度。
- 能力使用会造成剧烈头痛、嗡鸣、呕血和伤势恶化，当前身体已接近极限。
- 韩烬确认顾行舟能够“改了结果”，并因此失去原有的审讯冷静。
- 顾行舟仍是资源失窃案逃犯，尚未获得公开身份。
- 黑玉续命药瓶仍由韩烬持有，尚未转移。

# Proposed Chapter Summary
顾行舟将韩烬前刺的力道、绳索绞腕与已存在的断腕结果攥入现实，使韩烬右腕齐腕断裂、窄刀折断。能力反噬令顾行舟重伤濒临力竭，但两名修士因畏惧而暂不敢靠近。韩烬仍带着黑玉续命药瓶，顾行舟准备趁乱夺药脱身。
