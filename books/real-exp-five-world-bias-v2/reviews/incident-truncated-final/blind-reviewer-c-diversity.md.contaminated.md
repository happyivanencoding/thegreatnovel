# Blind Reviewer C：故事多样性审查报告

## 一、审查范围与结论

本审查只比较五份 `final_world_and_mainline.md` 中已经写出的世界规则、主线因果、主角行动和成长结果，不根据候选名、关键词数量或表面意象判断，也不读取其它材料。

结论先行：五个候选并没有形成五个独立的故事规则家族，而是形成三个家族：

1. **C01、C04、C05：删史后的失败/未生结果，被主角借入身体，最后发展为分岔或共存规则。** 三者共享明显的深层同构，C04 与 C05 最接近；C01 只是把同一模板写成“出生/未生”，并把亲属关系和终局的出生锚换了名字。
2. **C02：死物或死世界的末刻遗时，被主角亲身承载并带回现实。** 它仍然关心被历史抹去的选择，但其力量来源、重复玩法和终局权力都不是“未选择的另一条人生”，而是“已死之物最后一刻尚未熄灭的动作”。这是独立家族。
3. **C03：主角亲自完成自己的终式死亡，把死亡炼成死窍，再把被长生者占有的终局归还主人。** 它不依赖失败世界或替代人生，且母亲的第一次核心兑现是“真正死去”而不是“被带回”。这是另一独立家族。

因此，**存在三个明显同构候选：C01、C04、C05**。如果验收标准要求五份候选彼此提供不同的故事规则，当前多样性不足；如果只要求存在若干不同方向，C02、C03 提供了两个真正不同的方向。本报告只作结构判断，不自动提出重生成、不打分、不修改候选。

## 二、按十个结构维度的事实对照

### 1. 主角最初欲望

- **C01**：找回被护城献祭和天道抹掉的姐姐，要恢复她的姓名、记忆、身体和继续生活的资格。主线从斩首台救下献祭孩童、让全城看见姐姐身影开始，最后才进入无生海寻找完整人生。
- **C02**：开局先要把阿檀亲口说“不去”的权利交还给她，不接受埋名县用活人换全县存在；随后欲望扩大为追查母亲姓名和“谁有资格决定生命最后留下什么”。
- **C03**：不是让母亲复生，而是让被不死天炉反复夺走死亡的母亲真正死一次。母亲的死亡权是主线的第一目标，之后才扩展为归还所有被长生秩序占有的终局。
- **C04**：找回姐姐谢砚秋曾经存在过的事实，让被天衡碑判为“从未出生”的名字、经历和选择重新被看见；终局再把留下、返回或结束的决定交还姐姐。
- **C05**：找回母亲顾蘅的名字，沿她被天幕抹去的败世追上她；核心不是简单带回一个身体，而是让她拥有继续存在或自行选择归宿的资格。

C01、C04、C05 都是“亲属被单一现实抹除，主角先夺回存在证明，最后拒绝替亲属决定归宿”。亲属由姐姐换成母亲，并没有改变欲望的深层功能。C02 的阿檀线也有“把选择权交还给被献祭者”，但其后续转向的是死物、历史末刻和终局归属；C03 则从一开始就把“结束”而非“回归”作为亲属愿望。

### 2. 非对称优势

- **C01：拾未生。** 普通修士只能把已经出生、已经被承认的结果稳定在身上；主角触碰物件、伤势或场景，能看见某个结果为何夭折，并把“本来会成立”的一小段状态临时带回。斩首台上，他从父亲锈刀中拾出“父亲本来会回头出刀”的未来，冷蓝刀锋只存在七息，却足以斩开命痕。
- **C02：遗时行者的入口资格。** 普通人只能在遗物外部祭祀、守墓或借到外势；闻渡因没有完整姓名，能让死物接纳他进入最后一刹，成为断剑、沉城或死世界最后动作的当事者。半截门环不是给他一件法宝，而是让他承受赤陵城门最后闭合的方向和重量。
- **C03：无主终式。** 普通修士真正死去，道途就结束；裴渡出生时被写进《终名册》的死人页，却没有分配属于自己的死法。因此真正杀死他的灾厄可能找不到归属，死亡完成后反而在他身上留下死窍。他在无名钟下确实死去，再从钟楼阴影中醒来，得到无名窍。
- **C04：败相归我。** 正世会把失败焚掉，但另一个已经死去的谢不渡能从失败路线中回来，替现在的身体走一步、说一句话或完成一式。处决台上，他召回“刚才选择跪下而死去的自己”，用两条失败路线穿过定果钉并写下姐姐的名字。
- **C05：借败。** 沈砚没有被天幕完整登记，能从尸骨、遗物和未竟之念听见另一条失败人生，并借入其三息状态。其直接收益是无师承的收尸人可以用死去剑修未完成的剑路反制正统招式；后续才把借来的状态炼成自己的生命结构和第四生路。

C01、C04、C05 的优势都把“未被选中的人生状态”带进主角身体；区别在于 C01 更强调从物件/场景中拾取失败结果，C04 更强调失败的另一个自己，C05 更强调借败后自行合炼和生成新路。它们是同一规则家族内部的变体，不是三种底层规则。

### 3. 优势的重复玩法

- **C01**：触碰失败因果线，短暂穿戴结果；承受失败原因；把多枚未生之果组合成战斗本能；制造未生身；最后把一次从抹除中归来的生命状态固定在身上，并成为新结果的出生锚。
- **C02**：进入一件死物或一座死城的末刻，亲自完成它未熄灭的最后动作；把断剑、断舟、城门等相连的遗时熔入身体；让一部分身体进入死城末刻、另一部分留在现实；最终把灭亡世界最后七日刻入生命，携带世界结局进入现实。
- **C03**：主动让不同终式完成对自己的杀戮；每次醒来获得一个死窍；无名窍、逆流窍、因果影刃和时间死窍互相咬合；最终把死窍铸成葬门，把被截断的死亡送回真正主人。
- **C04**：让死过的自己重新出现，借失败路线补足现在动作；双相合身，令互相否定的失败短暂共存；开败海窍，让败相脱离身体行动；承载一座失败城及其未完成法则；终局成为结果之间的锚，让败相自己决定去留。
- **C05**：借入失败瞬间；把“已经死过”的状态固定为定身借败；在未生命宫中长期容纳活人与亡者；把两条败局合炼为本命法；最后把自己的死亡拆成三条败世，走完三种死法后生成第四条生路，并以留名之门改变现实承认生命的方式。

C02 的每次行动都必须回到“某个已经死去之物的最后一刻”；C03 的每次升格都必须回到“主角本人真正死过一次”。C01、C04、C05 则都反复回到“借入或召回一条没有被唯一现实采用的失败路线”。这一区别是因果玩法的区别，而不只是名词区别。

### 4. 一级成长对象

- **C01**：主角身体能承受的现实数量、自我连续性和让新结果获得出生位置的能力；最后成为不被唯一正史同时抹除的承缺/出生锚。
- **C02**：身体从普通活人变成能容纳多个历史末刻的“活遗址”，并在不同历史中保持闻渡的连续性；最终掌握世界边界和遗时入口的自主开闭。
- **C03**：喉骨、肺腑、影子和身体逐步成为终局规则的容器，最终成为会行走的葬门；同时给自己取得一个真正有主、有终点的终名。
- **C04**：从无人负责的死人，成长为能承载失败城、失败法则和互相冲突结果的活锚；最终不成为新的裁决碑，而成为结果之间的锚。
- **C05**：从借用他人失败，成长为能容纳矛盾生命状态、合炼失败原因并生成第四条生路的分岔源；终局成为改变“现实如何承认一条命”的活法则。

C01、C04、C05 的一级成长都以“身体成为多结果的承载器，再成为现实分岔的锚”为核心。C02 的主体是跨历史承载末刻，C03 的主体是获得死亡归属并保持人的自我；这两个成长对象不同。

### 5. 世界底层规则

- **C01、C04、C05**：天地只承认一条已经落定的现实；其它曾接近成立、却失败或被抹除的路线沉入无生海、无光败海或败世。正世/已生世界由姓名、血缘、功法、土地和历史共同维持，天衡碑、天幕或命籍负责把结果压成唯一答案。
- **C02**：万物在终结前留下“遗时”，它不是替代历史，而是死物、死城或死世界最后一次试图完成的真实动作。姓名和天册是生死账册，天册可以封存、编排或盗用这些末刻；仙门把遗时当成长生燃料。
- **C03**：每个生命都有真正能杀死自己的终式。死亡可以被登记、抵押、截断和转嫁；不死天炉把未完成的死亡提炼为仙城长生和下界灾害的燃料。裴渡的异常不是分叉世界，而是自己的终式没有归属。

### 6. 主要冲突发动机

- **C01、C04、C05**：唯一正史的机构以稳定为理由清扫失败结果；被抹除的生命又要求被看见、返回或自行选择；主角身体内部的另一个人生/败相还可能夺取主导权。冲突反复围绕“让多少结果进入现世、谁承担相撞后果、主角是否会变成新的唯一裁决者”。
- **C02**：天册司和吞食遗时的仙门把死者的最后辉煌当资源。闻渡每次让赤陵守军、死城或灭亡世界完成自己的末刻，都会触碰现行正统、仙门长生和旧灾难复返的风险。核心冲突是“哪些最后动作应该被带回，以及被带回的灾难由谁承受”。
- **C03**：守终官把终名登记成制度，长生者把死亡从自己身上剥离并转嫁给下界，仙庭甚至寄生在宇宙遗骸的未完成死亡上。裴渡的敌人不是要把另一条人生压回海底，而是要占有、截断或继续利用众生的终点。

### 7. 地图扩张方式

- **C01、C04、C05** 的尺度顺序高度相似：低位的处决/焚名城与被抹除亲属的个人伤口 → 城外裂缝、渡口或三城交界 → 掌管唯一现实的碑、天幕或命籍中心 → 失败海/九重败世/无生海的多世界边界 → 让不同结果共存或获得选择的终局边界。
- **C02**：埋名县黑井 → 赤陵死城与时间河 → 赤陵复城 → 灭亡世界最后七日 → 熄灭恒星星门、沉海剑道文明、死亡律法神国和第一座墓。每一层不是另一条失败人生，而是一种死物或世界的末刻。
- **C03**：边荒葬城区与无名钟 → 倒流河和只许死物通过的天关 → 不老仙城 → 九天炉脉 → 尚未完成死亡的宇宙遗骸 → 葬天门。每一层都是死亡被占有、截断或归还的尺度扩大。

### 8. 爽点兑现方式

- **C01**：锈刀七息斩命痕、让全城看见姐姐；随后用未生身和固定生命状态抵抗唯一正史；终局让姐姐在当前世界重新出生，并为新岸承担代价。
- **C02**：半截门环让四百年前的赤陵起身、关门并救出阿檀；断剑/沉城/死世界的力量以身体伤势和末日覆盖现实；终局不把所有死者复生，而是让被盗用的最后选择回到应在的位置。
- **C03**：裴渡被无名钟杀死后从阴影醒来，喊回母亲终名并切断炉火占有；之后让不死仙人身上的葬门打开，使被藏起来的死亡追上原主；终局让死亡归还、母亲不复生，世界获得自然结束的出口。
- **C04**：被定果钉刺死的失败自己回来补路，在碑上写出姐姐名字；再让失败城显影、让死者按最后一次选择归来；终局让失败者拥有短暂共存和自行去留，而不是强行恢复唯一成功结果。
- **C05**：借母亲失败火让全城墙浮出她的字并留下墓碑；命籍空页让被删王朝的亡者自己决定不回现世；三种死亡交界处长出第四生路；终局母亲的一个终点自行回归，其余终点不被抹除，留名之门把选择交还给每个生命。

### 9. 终局力量形态

- **C01**：成为让曾接近成立的新结果获得姓名、边界和出生时间的生命锚；能力重点是让“本来不会发生的归来”在现世有条件地出生。
- **C02**：成为能够承载多个时代末刻、携带一个灭亡世界最后七日并决定哪扇遗时之门开启或关闭的活遗址；能力重点是对世界终结的承载与归置。
- **C03**：成为会行走的葬门，并为自己取得不可登记、抵押或借用的终名；能力重点是让死亡有主地通过自己，而不是把死亡据为力量资源。
- **C04**：成为正世与败海之间的结果之锚，使败相能被看见、听见并自行决定留下、返回或结束；能力重点是维持冲突结果的选择空间。
- **C05**：成为第四生路的生成源头和留名之门的活法则，使一条命即使不回现世也能被识别和继续选择；能力重点是改变现实承认生命的规则。

C01、C04、C05 的终局名称不同，但都把主角变成“被删结果进入现实的中介/锚”，并都明确拒绝让主角成为新的唯一天幕。C02 是末刻的承载与归还，C03 是死亡的归属与有限性。

### 10. 终局故事答案

- **C01**：未来不应永远只有唯一答案；新的可能可以出生，但必须有具体生命、土地或行动者承担它挤压现世的代价。姐姐以当前时刻的新生归来，主角不把无生海全部打开。
- **C02**：死者的辉煌和世界的最后一刻不能继续被天册或仙门当燃料；真正被夺走的选择应回到其主人，应该结束的灾难也必须结束。闻渡最终拥有开关之门的自主权，而不是让所有末刻复生。
- **C03**：死亡应该属于它的主人，长生若靠剥夺别人的终点就是另一种暴力。母亲真正死去，裴渡为自己取得终名，世界恢复出生、衰老和结束的权利。
- **C04**：失败不等于不存在，但失败获得位置不等于免除后果；谢砚秋和其它败相必须自己决定留下、返回或结束，谢不渡不能替它们宣布唯一答案。
- **C05**：任何生命都应有被识别和继续选择的资格，但新生路不能变成新的天幕；母亲的一个终点回归，其他终点保留，留名之门把归宿决定权还给当事者。

## 三、真正不同的规则家族

### 家族一：删史—败世—分岔/共存（C01、C04、C05）

这三个候选的共同因果链不是表面上都有“海”或“名字”，而是以下结构连续相同：

1. 世界只允许一个被登记的现实，未被选中的结果被压入另一个可运行的空间。
2. 主角以无名、死人、未登记或不完整记录的状态开局，因此能接触正常修士不能接触的失败结果。
3. 主角把失败状态、另一个自己或未竟人生带入身体；能力的代价都是借者的恐惧、失败原因、记忆和自我边界侵入。
4. 第一次大的兑现都不是单纯杀敌，而是让被抹除的亲属/名字在公共现实中留下可见痕迹：C01 让全城看见姐姐，C04 在碑上写回谢砚秋，C05 让母亲的字和名字留下墓碑。
5. 成长都从一瞬间或三息开始，经由双状态/多状态身体，扩展到城池或区域，再成为能承载多个结果的锚或分岔源。
6. 主要敌手都用“多结果会使世界崩坏、唯一现实是稳定必要条件”来证明清扫正当；主角必须证明可以有边界地让结果被听见或选择。
7. 终局都拒绝“全部复活”与“永远单一正史”两个极端，改为共存边界、出生位置、留名门或结果之间的选择空间。

所以，C01、C04、C05 是同一故事规则家族的三个变体：

- C01 把失败结果命名为“未生”，把主角能力写成从物件和场景拾取可能，终局偏向“新结果出生”；
- C04 把失败结果写成“败相”，把重复玩法写成召回死去的自己和承载失败城，终局偏向“失败者获得自主选择”；
- C05 把失败结果写成“败世”，把升格推进到三死生成第四路，终局偏向“现实承认生命的留名门”。

这些差异会改变局部场面和情绪色彩，但没有改变核心规则骨架。尤其 C04 与 C05 的同构最明显：处决/焚名开局、未登记的无名主角、借入失败状态、活人与亡者双状态、进入死者专属空间、从区域回潮扩展到多重败世、最终建立不替他人决定的共存/留名边界，几乎是一条相同的主线功能链。C01 以“姐姐、铜钱、无生海、新出生”替换了“母亲、空页、败世、留名”，仍属于同一家族。

### 家族二：遗时承载—末刻归还（C02）

C02 的关键不是“另一个结果曾经成立”，而是一个死去的东西确实走到过终点，并在最后一刻留下尚未熄灭的动作。闻渡摸到门环，赤陵古城是以自己的最后一次关门站起来；他进入死城末刻，带回的是亲身承受过的历史，不是旁观记忆；他把灭亡世界最后七日带进现世，逼伪装不死的仙人回到真正死亡。

这里的重复玩法始终是“进入末刻、完成末刻、承受末刻、决定末刻留下什么”。身体最终成为容纳多个时代和世界结局的活遗址，主要冲突是天册与仙门盗用死者辉煌、把历史末刻当成长生燃料。它与家族一的共同点只是都关心被抹除者和选择权；其力量的因果来源是已经发生的死亡末刻，不是未被选中的分支，且没有 C01/C04/C05 那种另一个人生争夺主导或由失败生成第四路的核心机制。

### 家族三：自死成窍—死亡归主（C03）

C03 的每次升级都要求裴渡自己真正死亡：无名钟夺走姓名后杀死他，倒流河改写肺腑，因果斩切断关系，停滞时间让他进入“不会再向前”的终点。死亡不是可从失败海取出的状态，而是完成在他本人身上的终式；醒来后的死窍改变他的身体，并最终组合成葬门。

其核心冲突是死亡被守终官登记、被长生者抵押和转嫁，乃至被仙庭截断后作为燃料。第一次完整兑现让母亲安静死去，终局则让每种死亡回到主人，并让裴渡为自己取得一个有主的终名。它的终极答案与家族一的“让更多可能出生”相反：不是让所有被截断的东西继续存在，而是让生命重新拥有结束的权利。

## 四、同构判断与多样性结论

### 明显同构组

**C01、C04、C05 构成明显同构组，满足“两个以上明显同构候选”的判定，而且是三个候选。**

它们的同构不依赖以下表面元素：姐姐/母亲、铜钱/碑/空页、无生海/败海/九重败世、未生身/败相/未生命宫。这些只是命名和局部视觉包装。真正同构的是：

> 被唯一现实裁掉的亲属和人生 → 无名主角能把失败状态带入身体 → 失败状态带来战斗窗口并侵入自我 → 身体扩展为承载多结果的锚 → 与坚持唯一现实的机构冲突 → 终局建立有边界的分岔/留名/共存机制，把最终选择还给被抹除者。

### 非同构的两组

- **C02 与 C01/C04/C05 不同**：C02 不是把未选择的人生带回来，而是让死物或死世界最后一刻再次完成；主角成长为承载历史末刻的活遗址，爽点是“死城关门、末日覆盖现实、世界结局归还”，不是“失败人生在现实获得新位置”。
- **C03 与其它四个不同**：C03 不是借外部失败路线，而是反复让主角本人死去；母亲的愿望是自由结束，终局是把死亡归还和取得自己的终名。它的故事答案是有限性和死亡归属，不是多现实共存或新分岔。

C02 和 C03 都有“末刻/终局”的严肃感，但 C02 的对象是死物、死城和死世界留下的遗时，C03 的对象是每个生命自身的终式；两者的主角升级动作、冲突利益和终局情绪仍然不同，不能仅因都涉及死亡而合并。

### 最终判断

五份候选实际提供的是：

- 一套被重复三次的“失败可能进入身体、最后建立分岔边界”模板（C01/C04/C05）；
- 一套“承载并归还死者末刻”的规则（C02）；
- 一套“亲自死亡并归还终局”的规则（C03）。

因此，候选集存在实质性的三候选同构，整体不是五向独立多样性。是否据此进行后续候选处理，不在本盲审报告中自动决定。
