# Proposed Active Scene State

地点：折日峡内左侧连续阴影带前，药车与货车之间。  
在场人物：顾临川、姚谦、陆绾、车夫、杂役、商队伙计及其他护卫。  
即时伤势：右肩持续疼痛；双身影术强行收回后胸口发紧、脚下发晃，暂未新增明确伤势。  
手中关键物品：护送契券、预付款钱袋、佩刀。  
当前敌人或追兵：峡内深处有不明目标沿坡地逼近，已传来沉重踩踏声。  
当前倒计时：不明目标即将抵达；商队尚未通过峡内狭路。  
下一步直接目标：保持车队紧密，确认逼近目标并应对。  
当前主动目标：守住药车与货物，带队通过折日峡。  

# Proposed Persistent Canon

- 顾临川已正式成为铜羽商队低阶护卫，负责货物与药车护送。
- 双身影术可执行双线侦察或行动，但在折日峡斜照、断裂阴影中会被拉散；距离增大时本体与影身联系迅速减弱，强行收影会造成明显反噬。
- 折日峡外围实际存在错乱影象；队伍必须依靠车辙、绳索、人声和实际人物判断位置，不能依赖地面影子。
- 左侧连续阴影带可供车队通行；右侧断裂阴影不适合车辆通过。
- 陆绾负责药车与药期，顾临川负责护送协作，药车与货车已保持紧密队形。
- 折日峡内有不明沉重目标正在逼近。

# Proposed Chapter Summary

铜羽商队进入折日峡后遭遇影象错乱，车队一度失去正常方位判断。顾临川以双身影术探路，确认右侧断裂阴影危险，并发现斜照会迅速削弱本体与影身的联系，遂收影返回。姚谦据此改令车队沿左侧连续阴影带紧密通行。队伍未掉队、货物与药箱完好，却在峡内听见不明重物逼近。

# Proposed Open Promises

- 峡内深处逼近的沉重目标即将与商队接触，其身份与意图未明。
- 商队必须在影象错乱与狭路条件下继续守住药车和货物。
- 顾临川的双身影术在折日峡中的距离与光线限制已被确认，后续行动不能再依赖远距离分影。
- 顾临川须完成第一趟护送，确保伤药按时抵达下一处驿城。
- 折日峡外围的实际路况与通行风险仍未完全确定。
- 顾斜阳将成为顾临川的现实竞争者。
- 陆绾将继续走药材与影伤医术道路。
- 阮青缨将因沉昼城古代影兵交易接触顾临川。
