# Opening Three Chapter Contract

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的世界事实 / 规则 → 主角立即行动。**World fact 的选择权在 World + Outline，不在 Writer**：如果当前章 `具体剧情` 已排程某条开篇世界定向，Curator 必须保留，Primary 用最短直接方式落实；如果 Plan 没排程，Primary 不自己从完整 World 里挑一段补课。前三章只释放理解当前故事所需的信息，同时让读者获得必要的强弱、身份、价值与世界位置；核心优势第一次形成结果时，用一次世界内比较说明为什么超标。不要先把世界模型讲完再放主角进去，也不要把世界定向做成独立 Setup 事件。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

## 前文章末必要衔接

一个杂役从街口跑进来，脸色发白：“姚管事！西巷有人冲车！”

话音刚落，货车前那匹角马猛地受惊，抬起前蹄，车辕被它拽得往旁边一歪。

它不是往空处冲。

它正对着药车。

“拉住它！”车夫扑过去。

角马挣开缰绳，拖着半挂货车朝院里横撞。货车的车轮碾过碎石，直直朝药车侧面压来。药车旁还有两个搬药的杂役，退路被堆在墙边的空箱堵住了。

顾临川本体先动。

他抓住货车侧面的绑绳，借着车身冲来的力道翻上车辕，一脚踹向角马颈侧。角马吃痛，头猛地偏开，却没停下，反而带着货车往另一边甩去。

车身一歪，最上面两只铁器箱滑脱了绳扣。

顾临川看见它们砸向车夫。

同一时间，药车那边的影身已经伸手。

影身没有去挡车。

它双手扣住药车车辕，脚下的黑影死死贴住地面。横冲过来的货车撞上药车一角，木板发出刺耳的裂响，药车被推得后滑半尺，却没翻。

那两个杂役连滚带爬地躲开。

货车上的铁器箱已经落下。

顾临川从车辕上扑过去，肩膀撞进箱底。他没硬接，只把箱子往外推偏半寸，让它砸在货车边缘。木板当场裂开，铁器散了一地，碎木屑擦过他的手背。

第二只箱子紧跟着砸下。

他来不及再推。

顾临川抬起左臂，狠狠干在箱角上。

箱子偏离了车夫的头顶，砸在他脚边。车夫腿一软，跌坐在地，脸上的血色瞬间没了。

顾临川却没松气。

药车那边传来的压力忽然加重。

影身还在抵住两辆车。

货车的轮子卡进石缝，角马却仍在挣动，药车车辕被压得咯吱作响。影身肩背上没有血，却出现了一道道被重物压开的黑痕。

顾临川的右肩随之一沉。

刚才只是伤口发疼，这一次却像有整辆车压到了他身上。他膝盖一弯，鞋底在碎石上拖出一道痕。

他咬住牙，抓起地上的缰绳，绕到角马身侧。

“看着我！”

角马听不懂，却被他近在眼前的动作逼得转头。

顾临川把缰绳绕过自己的手臂，借着角马扭头的力道猛地往下拽。肩膀像被人撕开，他眼前发黑了一瞬，手却没松。

角马终于失去平衡，前蹄重重落地。

它喘着粗气，挣了两下，被赶来的车夫和杂役重新套住缰绳。

货车不再往前压。

药车旁的影身仍扶着车辕，直到姚谦带人把两辆车彻底分开，它才缓缓松手。

影身回到顾临川脚下时，顾临川站着没动。

撞击的重量、车辕的压力、影身硬撑时每一次绷紧的力道，全都回到了他身上。他的呼吸一下沉了，额角沁出冷汗，手臂也垂了半寸。

可院子已经稳住了。

药箱没有翻，货物没有散出院门，车夫也没被铁箱砸中。

姚谦走到他面前，看了一眼药车，又看了一眼顾临川。

“够了。”姚谦说。

顾临川缓了口气：“够不够当护卫？”

姚谦终于露出一点笑意。

“不是候选人了。”他说，“从现在起，你是铜羽商队的正式低阶护卫。”

契券人员快步过来，把刚才那张护送契券重新递到顾临川手里。纸页上多了一行商盟的印记，名字和“双身影术”都清清楚楚。

姚谦又从腰间取出一个小钱袋，放到他掌心。

钱袋沉甸甸的，铜钱碰在一起，发出清脆的响声。

“第一笔预付款。”姚谦道，“你的。护送结束前，谁也拿不走。”

顾临川握紧钱袋。

这不是武馆临时塞给他的跑腿钱，也不是家里账桌上过一遍就要归进去的零碎铜子。

这是他靠自己拿到的钱。

他低头数都没数，直接把钱袋收进怀里。胸口像被那点重量压住，又像终于有了能撑住自己的东西。

陆绾已经检查完药车。

车辕裂了一角，但没伤到药箱。她抬手拍掉箱盖上的灰，走到顾临川面前。

“我明日就走。”她说，“伤药送去下一处驿城，不能慢。”

顾临川看着她：“铜羽商队也是明日出城。”

“是。”陆绾说道，“你可以同行，但别弄错一件事。”

她指了指药车。

“这批药不是给你立名头用的。路上有人受伤、货物丢了、商队改道，我先看的是药能不能准时送到驿城。你要护送，就按这个规矩护送。”

她说得很平，没有试探，也没有给他留什么好听的余地。

顾临川反而点了点头。

“行。”他说，“你的药走你的路。我拿了商队的钱，就守商队该守的东西。”

陆绾看了他一眼，没再多说，只转身去吩咐杂役重新加固车辕。

姚谦抬手一挥：“装车。半个时辰后离开客舍。”

院里重新忙起来。

角马被牵回车前，散落的铁器被收进木箱，药车上的铜丝又紧了一圈。顾临川把护送契券贴身收好，走到商队最前面的货车旁。

客舍院门已经打开。

门外的路通向城门，也通向他从没真正走出去过的地方。
