# Proposed Active Scene State

地点：半塌石城外墙撤离线、窄坡前。  
在场人物：顾临川本体、陆绾、车夫、药车上的伤员；顾斜阳与观日宗众人已从残墙撤离，和本体一行暂时分开。  
即时伤势：顾临川右肩伤口重新撕裂，左肩、胸口与腰腹出现影身受创后的剧烈撕裂痛，几乎无法站稳；伤员仍需药车护送。  
手中关键物品：药车、药箱、伤员携带的药包；影身佩刀遗落在半塌石楼下。  
当前敌人或追兵：石甲灰背异兽仍在后方石城区域，尚未确认是否继续追来。  
当前倒计时：药车必须尽快通过窄坡，不能停下；异兽可能追上。  
下一步直接目标：在顾临川重伤、无法稳定行动的情况下，让药车继续通过窄坡并保护伤员。  
当前主动目标：完成第一趟护送，让伤药和伤员脱离异兽追击范围。

# Proposed Persistent Canon

- 顾临川可将本体与影身分开执行任务，但影身遭受毁灭性破坏后，伤势与剧痛会回流至本体；本体可确认影身已出事，但影身是否能够恢复、重新形成尚未确认。
- 影身曾主动引开石甲灰背异兽，为顾斜阳和观日宗众人争取撤离时间，随后被异兽撕裂并在错乱影光中消散。
- 顾临川右肩旧伤严重加重，并新增左肩、胸口和腰腹的强烈撕裂痛，当前已影响站立与行动。
- 顾斜阳与顾临川形成过一次以顾临川牺牲影身为代价的临时协作；顾斜阳已带观日宗众人脱离残墙，双方仍保持竞争关系。
- 半塌石楼下存在异常影光与疑似传承路线；顾临川一行未进入，石楼随后继续坍塌，路线当前被异兽与塌落结构阻隔。
- 石甲灰背异兽可被狭窄地形限制，但能够持续破坏石墙和石道。

# Proposed Chapter Summary

影身发现地底影光前的通道无法让所有人同时通过，主动走出阴影引开石甲灰背异兽，使顾斜阳带着陆问山和腿伤弟子从残墙撤离。异兽攻击时影光失稳，影身被撕裂消散，佩刀遗落。与此同时，顾临川本体遭受强烈伤势回流，右肩重裂并出现胸腹撕裂痛，药车抵达窄坡前，陆绾必须决定是否继续前进。

# Proposed Open Promises

- 顾临川本体能否在重伤和影身消散后继续护送药车与伤员通过窄坡。
- 影身消散后能否恢复、重新形成，以及本体何时能确认最终结果。
- 石甲灰背异兽是否会追上外墙撤离线。
- 地底异常影光与传承路线的性质、用途及后续去向仍未确定。
- 顾斜阳与观日宗众人撤离后，是否会重新寻找传承路线或与顾临川会合。
- 观日宗进入半塌石城的目的及石城深处隐藏的事物仍未确定。
- 规则影术痕迹的施术者、留下时间与目的仍未确定。
- 姚谦分队及其带走的货物去了哪条路，能否再次会合。
- 折日峡深处是否仍有更多异兽或其他威胁。
- 顾临川须完成第一趟护送，确保伤药按时抵达下一处驿城。
- 陆绾将继续走药材与影伤医术道路。
- 阮青缨将因沉昼城古代影兵交易接触顾临川。
