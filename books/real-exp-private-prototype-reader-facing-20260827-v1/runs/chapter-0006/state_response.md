# Proposed Active Scene State

地点：半塌石城外墙墙影、墙根缺口旁。  
在场人物：顾临川、陆绾、车夫、顾斜阳、陆问山及三名观日宗弟子；伤员与两名伙计已沿窄坡撤离。  
即时伤势：顾临川右肩伤势持续发热；陆问山肩伤；观日宗一名弟子重伤、另一人腿伤。  
手中关键物品：药车、药箱、药包、护送契券、佩刀。药车已调头朝向来路。  
当前敌人或追兵：石甲灰背异兽正逼近顾斜阳一行。  
当前倒计时：异兽即将再次冲击，墙根窄坡无法同时容纳药车与观日宗众人。  
下一步直接目标：守住墙影退路，确保伤员和药车能撤离，并决定是否让观日宗借道。  
当前主动目标：护住药车与伤员，完成撤离，不进入石城。

# Proposed Persistent Canon

- 顾临川可利用较稳定的墙影和墙根缺口组织撤离；药车无法通过仅容一人侧身的窄坡。
- 顾临川已确认前方交战者为观日宗一行，主要人物包括顾斜阳、陆问山。
- 顾临川与顾斜阳已形成现实竞争关系：双方争夺石城外墙一带的退路与行动空间。
- 陆问山具备正面牵制石甲灰背异兽的战力，但已受肩伤。
- 药车已移至外墙墙影，车头朝向来路；伤员和两名伙计已先行撤入窄坡。

### Active Relationships

顾斜阳｜守住观日宗退路并继续处理石城方向事务｜与顾临川形成直接竞争，暂未完全敌对｜因异兽堵路而被迫面对顾临川掌握退路｜是否借用窄坡撤离未决  
陆问山｜挡住石甲灰背异兽、救回受伤弟子｜与顾临川暂时处于同一交战现场，尚未建立协作｜确认顾临川已控制墙影退路｜能否带人脱离未决

### Tracked Assets

药车与药箱｜陆绾负责、车夫驾驶｜石城外墙墙影｜车头朝向来路，可随时撤离｜已从正面交战路线上移开  
药包｜两名伙计随伤员携带｜墙根缺口后的窄坡｜仍在小队控制范围内｜已先行撤离

# Proposed Chapter Summary

石壁另一侧的交战者现身，顾临川确认其中有顾斜阳与陆问山。石甲灰背异兽逼近时，顾临川没有进入石城，而是发现墙根缺口和窄坡，指挥药车移入墙影，先将伤员与伙计撤走。观日宗退路随后被异兽堵住，顾斜阳一行也被迫面对同一条狭窄退路。

# Proposed Open Promises

- 石甲灰背异兽逼近墙影后，顾临川、顾斜阳与陆问山将如何脱离交战。
- 墙根窄坡无法同时容纳药车与观日宗众人，双方是否会达成临时借道或发生冲突。
- 顾临川需要在右肩伤势持续恶化的情况下完成药车与伤员护送。
- 观日宗进入半塌石城的目的及石城深处隐藏的事物仍未确定。
- 规则影术痕迹的施术者、留下时间与目的仍未确定。
- 姚谦分队及其带走的货物去了哪条路，能否再次会合。
- 折日峡深处是否仍有更多异兽或其他威胁。
- 顾临川须完成第一趟护送，确保伤药按时抵达下一处驿城。
- 陆绾将继续走药材与影伤医术道路。
- 阮青缨将因沉昼城古代影兵交易接触顾临川。
