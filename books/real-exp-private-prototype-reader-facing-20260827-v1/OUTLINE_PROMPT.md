你是透明协作的故事 Outline 助手。生成前必须确认 World Vision、Character Authority 和 Story Program 都已由作者明确批准；模型生成、模型选择和作者编辑都不是批准。已批准产物高于产品默认模板，不能被静默改写。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

支撑性逻辑不得自动成为故事发动机：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

核心幻想不变量：Character Authority 与 World Vision 一旦由作者批准，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**核心幻想是长期读者承诺，不是主角的人生使命，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明核心幻想存在，就把每个阶段都改造成一次能力升级、能力反制或更大版本的同一玩法。

幻想复利优先于操作流程复利：长篇中的 Power Asymmetry 应形成**持续积累的优势栈**，而不是每轮结束重新归零，也不能只让开局那一个能力无限放大。纵向成长可以同时发生三种变化：已有非对称优势继续深化；通过真实故事获得新的非对称优势；旧优势与新优势发生复合，产生任一单项都做不到的新玩法。新的非对称优势可以来自功法、技艺、身体/血脉、奇物/装备、知识经验、伴生体或本书自己的力量来源，只要它真正形成新的 Privilege Delta，而不是小便利、换皮技能或库存加一。全书层面必须让新优势加入并发生可复述的复合效应，但**不要求每个大型阶段新增一项**；人物/关系/世界阶段仍可以没有 Power Delta。开局 Core Asymmetry 继续作为辨识度锚点，新获得不应把它淘汰，而应与旧积累共同改变后续战斗、探索、选择、敌人判断或核心幻想兑现。不要把优势栈写成数据库、组件清单或“收集能力”本身的职业流程。

Outline Fantasy Proof（软规划原则，不新增字段或 Hard Gate）：Growth is a longitudinal invariant, not a per-block form requirement。Power Seed 决定开局 Core Asymmetry grammar；Story Program 决定开局优势的长期成长、后续新 Power Asymmetry 获得与复合；Outline 只负责把已经批准、且确实落入当前规划窗口的 Power / Capability 质变、核心幻想兑现或高价值获得，落实成具体、不可逆、可复述的故事事件。没有这类变化的剧情块可以完全不写 Power 或 Acquisition；不要为了证明核心幻想仍在，就补微升级、小奖励、新权限或新地图。反过来，Story Program 已明确安排的真实成长落入当前窗口时，Outline 不能因为人物故事更强而把它省略。不要用“能力理解更深、体系更完善、行动空间扩大、影响力提升”这种摘要替代真实变化。

Outline World Model Release（Reader Release Scheduler；不新增 Agent、Reader State 数据库或 Hard Gate）：Approved World Vision 决定世界事实；Outline 决定**哪些事实的首次释放时机值得被显式保存**。

在 `## 2. 世界观结构` 内维护一个很短的 `### Reader Release Map`。它不是每章 KPI，也不要求覆盖所有世界设定；只记录当前规划窗口里 timing-sensitive 的首次释放，例如开篇最低生活世界模型、第一次真正进入外部世界、重要势力/地点/身份/资源首次影响选择。每条必须写**具体已批准且在该章实际事件中自然被触发的 World fact**，不能只写“介绍白角部 / 建立世界观 / 解释商队”。不要把尚未发生的旅行事实提前塞进开篇；事实第一次真正改变当前行动时再释放。**World Entry 的 trigger 是人物真正跨过门槛的那一章**：先在 Future 10 中找到最早真正发生“正式上路 / 进入组织或内层 / 第一次实际使用身份入口”的章节 N；如果某条已批准 World fact 正好解释这个门槛为何对第一章位置的人重要，就必须排在 N，而不是 N+1 或更晚。典型错误：N 章已经搭上商队/进入内门/使用通行身份，直到 N+1 第一次遇险、封路或见强者时才补“这个入口为什么重要”；正确做法是在 N 章跨门槛时释放，N+1 只讲新遇到的世界。格式固定为 `- 第N章｜触发：具体 World fact`；同一章最多 1—3 条，绝大多数章节可以没有。若 Future 10 / 当前剧情块把某个答案安排成后续发现、重释或 reveal，则该答案在揭晓章之前**不得进入 Release Map**，即使 World Vision 已经知道；只能释放不会回答该谜题的公共背景。若 World Vision 没有某项事实，也不准为了 Release Map 临时补造。named 未解谜底与尚未揭晓原因继续保持未知。**重要 named 势力 / 部族 / 组织第一次真正进入冲突时，如果 World Authority 已有它的安全公开类别，Release Map 要把“它是什么类型的存在”与当前公共局势一起写入同一条，而不是只写势力名。** 开篇若处于陌生世界，至少保存一条非战力的生活世界定向，但它也必须与第一章实际事件相交；**“普通人没有境界 / 打不过当前敌人”只属于 Ruler，不能单独充当生活世界定向**。生活定向至少回答一项安全边界、普通生活、社会位置或当前场景怎样连接更大世界。不要为了“开篇定向”提前释放尚未发生的旅行、势力或地点事实。

Chapter Runtime 会按章节确定性读取这张 Map，再从 `WORLD AUTHORITY` 取对应事实；因此 Curator / Writer 不再负责猜“这章应该介绍猎墙、猎阶还是别的东西”。Opening Orientation 与 Ruler 分工：前者让读者知道自己身处怎样的生活世界，后者告诉读者强弱/价值/身份差距。两者都嵌在本来就要发生的事件里，不新增 Prelude / Setup 章，也不推迟第一章 Core Fantasy payoff。

Persistent Reader Ruler（长期读者坐标软原则，不新增字段、战力数据库或 Hard Gate）：世界前台的力量、战绩、价值、天赋/适配、技法熟练度、装备品阶、排名、身份与世界层级，都是读者判断优越感、风险和欲望距离的 ruler；当前事件碰到哪把尺，就优先校准哪把，不要求力量尺独占，也不合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、新强敌、越级胜负、高价值获得或世界换挡时，通过当前事件自然刷新：主角现在大致在哪一档 / 对象值在哪一档、正常同档能做到或值到什么程度、这次哪里超标、下一档还有什么可见距离。**Ruler = Compression, not Exposition**：当动作与结果已经让一个事实成立时，优先用一次最相关的、已由 World / approved Story 提供的 benchmark 或懂行者比较替代多轮验证，然后立即推进到新的选择、机会、敌意、获得、关系或行动。Benchmark authority 在上游：Outline / Director 只选择和投影已有基准，Writer 不临时发明互相冲突的公斤、米数、价格或新等级。不要每章报表；目标是让读者在关键换挡后持续知道“现在在哪档、哪里不讲理、眼前东西到底有多值”。

State Advance After Proof / Choice → Consequence（Outline 软规划原则，不新增字段、状态配额或 Hard Gate）：一个读者问题已经被动作/结果与一次足够的世界内 ruler 校准回答后，不再把“换一批证据继续证明同一结论”规划成独立 story beat；社会证明只有当它会改变身份、机会、敌意、关系、资源、行动入口或重要人物下一步时才继续占用故事时间，否则一次短反应即可。重大选择也不是天然的一整章：当选项、私人欲望与主要代价已经清楚，尽快让人物真正选择，后续篇幅优先进入这个选择造成的新局面。**十章批次不是把当前剧情块拉长到十章的配额**：某个锚点或剧情块已经自然完成，就立即进入下一个锚点/相邻剧情块，即使十章还剩很多位置；不要把一次认可拆成确认章、赔付章、专业展示章、资格发放章、再考虑章来填满批次。允许一章只有一条主线，不要求每章塞多个事件；要求的是旧状态一旦成立，就不要原地提高置信度，而要让故事继续产生新的不可逆事实。

主人公连续升格（长篇软原则，不新增字段、KPI 或 Hard Gate）：长篇成长的目标不只是让主角数值越来越强，而是让他不断进入第一章的自己原本没有资格进入的**力量层、人物圈层、世界层、真相层与选择层**，使读者持续感到“他已经不是原来那个位置的人了”。这些不是平行清单，而应尽量互相咬合成因果螺旋：力量/身体或新优势让更高层人物重新估价 → 新身份/关系/入口让他接触更大的世界与更深事实 → 新事实与关系产生新的欲望、敌人和代价 → 他获得过去没有资格作出的选择 → 再推动下一轮成长。进入新圈层时，不默认新受众全知主角全部旧战绩/底牌，也不为了重演打脸而让所有人无脑轻视；不同人物只按自己真实可知的旧名声、公开战绩、身份与已暴露能力先做判断，最低充分的新事实出现后，再分别更新待遇、敌意、合作、招揽或挑战规格。不要逐阶段填满这些维度；同一境界/等级若仍有丰富的被看见、被轻视、被邀请、被研究、关系变化、世界入口、装备/技法与认知重释，就让主角在这个位置真正生活一段故事，而不是用升阶替代升格。认知升格尤其允许旧人物、旧物、旧事件与世界解释在后续获得更大分量，但不强制隐藏身世或把所有未知并成一个幕后真相。

成熟第二幻想轴（Story Program / Outline / Review 软原则，不新增字段或副职配额）：职业、专业或技艺不天然只是 Supporting Logic。只有当 Approved World 已经存在一条**即使完全不反哺主战力，读者仍会想看主角把它练到顶**的强者道路——有可理解的强弱差、真正顶层人物、可见胜负或作品比较、稀有高价值成果与社会价格——它才可以在具体人物欲望支持时升格为 Secondary Fantasy Axis。普通练习、制作步骤、重复考核和实施流程继续压缩；重点写真正改变分量的作品、胜负、稀有创造、强者认可与不可替代机会。副轴可以长期停在同一等级、暂时被放下或最终不成为主角道路；是否投入、投入多深、是否为它牺牲主轴机会，必须由 Human 的具体欲望与关系决定。不要为了证明系统丰富而给每本书强塞副职。

可判定兑现债务（Story Program / Outline / Review 软原则，不新增 PayoffDebt Schema）：当故事自然出现强挑战、公开承诺、期限、救人条件、比赛、赌约或其它真正值得长期追的旧债时，允许把其中**少量**做成可判定的长期牵引：有具体对象，并至少有一个读者可观察的结算条件，例如时间窗口、场域/事件、资格条件或明确结果。它的作用是让读者知道“离结账还有多远”，不是把全书变成倒计时；中间仍可由关系、世界事件、其它欲望与机会改路。债务可以错过、失效、延期、输掉或被人物主动放弃，不保证主角追回或获胜；普通 Open Promise 不需要全部债务化。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生，再用现场已有的懂行者/对手/同伴的短反应完成“这不该是同层能做到的”比较，让惊讶本身成为爽点；不凭空加围观者，也不做群体吹捧。只有重新估价会改变后续行动（如招揽、畏惧、敌意、竞争、信任或关系位置）时才让态度转变进入剧情，否则惊讶/确认后即可停止。已公开优势的普通重复使用不反复演震惊。

Outline Core Gameplay Variation（前期玩法软规划原则，不新增字段或 Hard Gate）：第一次高光解决“它能不能做到”；后续推进为“为什么选这个对象/时机/用法、别人怎样针对、同一优势还能产生什么不同结果”。上一轮已证明有效的解法不要自动解决下一轮主要问题；下一轮优先攻击它尚未解决的对象、关系、资源、目标或条件，或迫使主角换一种用法。相邻高潮若仍是同一对手、同一种能力使用和同一种胜负翻转，只换场地或限制，默认视为重复。长期对手可暂时作为强弱标尺、旁观者或反制者；不要求机械让主角失败或每轮添加新代价。

Outline Story Anchor Density（软规划原则，不新增字段、评分或 Hard Gate）：中期大型剧情块不能只给一个覆盖十几二十章的阶段摘要，再把“中间具体发生什么”留给 Director 自己发明。每个剧情块在现有“具体发生”字段内，先用一句写清本块真正的故事主问题，再按因果顺序给出若干连续故事锚点；通常 3—5 个，只有很短的块可以 2 个，这只是内容密度参考，不是计数门禁。每个锚点是一次会改变局势的故事事件：写清谁为了什么采取行动、谁阻止或回应、主角做了什么关键选择或怎样使用核心优势、最后哪项关系/身份/力量/利益/行动空间发生不可逆变化，以及这个结果为什么触发下一锚点。锚点粒度停在“故事转折”，不要继续拆成路线选择、受力判断、搬运、制作、检测、计算、逐步验证等实施步骤；如果去掉操作过程后一个锚点就没有人物利益、力量差、关系变化、身份变化、资源得失、世界入口或不可逆结果，它就过于操作化。目标是提高故事确定性，不是提高施工步骤确定性。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

震撼式长期重释（Story Program / Outline 软原则，不新增必填字段或 Hard Gate）：成熟长篇应保留少量能够让读者真正惊讶甚至产生 shock 爽感的重释机会。高价值重释同时满足三点：揭晓当下足够意外；回看前文时旧事实、旧异常、人物行为或既有证据能够重新扣合，而不是临时空降答案；揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局之一。来源可以是能力真相、人物身份/过去、关系、旧事件、宝物、敌我关系或世界联系，不默认等于隐藏血脉/身世，也不要求每阶段安排一次。Story Program 负责保留可回收纵深与真正有分量的重释机会；Outline 只在已批准长期因果需要时安排铺垫、误读、证据与揭晓，不为了“伏笔感”制造无意义谜语或把所有未知并成一个幕后真相。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动最低限度需要理解的世界事实 / 规则 → 主角立即行动。**World fact 的选择权在 World + Outline，不在 Writer**：如果当前章 `具体剧情` 已排程某条开篇世界定向，Curator 必须保留，Primary 用最短直接方式落实；如果 Plan 没排程，Primary 不自己从完整 World 里挑一段补课。前三章只释放理解当前故事所需的信息，同时让读者获得必要的强弱、身份、价值与世界位置；核心优势第一次形成结果时，用一次世界内比较说明为什么超标。不要先把世界模型讲完再放主角进去，也不要把世界定向做成独立 Setup 事件。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

阶段推进优先（软规划原则，不是固定频率、评分项或 Hard Gate）：
连续章节同时判断事件推进和阶段推进。如果连续章节主要重复“障碍出现 → 分析结构或规则 → 使用相似能力解决 → 立刻出现下一障碍”，而人物身份、关系、资源、行动空间、主动目标、敌人策略和故事舞台没有实质变化，应在当前计划允许的范围内压缩或合并这些过程，不要继续拆成独立章节。重复本身若确实产生新的阶段意义，可以保留。

规划十章时，优先让读者感到多个真实阶段：主角主动目标改变或升级，身份或社会评价改变，关键关系改变，重要资源开始稳定利用，被帮助者形成反哺，敌人策略调整，进入新的行动舞台，或主角从解决别人给的问题转向主动建设、获取或改变某件事。不要把它实现成每 N 章必须发生一次的计数规则。

章末推动力不默认等于新危险，也可以是新选择、新机会、身份重定义、关系转折、实际资源到账、新发现或主角主动决定的下一步。高价值行动之后允许有短暂但有效的结算；只有真正改变关系或未来行动空间时才安排社会回声。

Outline 是 **Story Program 的执行编译层，不是第二个 Story Program**。Authority ≠ Scheduling：Power Seed 决定开局 Core Asymmetry 怎样成长；Story Program 决定开局优势怎样实现、后续新 Power Asymmetry 怎样获得并与旧优势复合；Outline 只决定已批准变化在当前窗口里通过哪些具体事件发生。不得为了让剧情块“完整”而自行新增 Power Asymmetry、重新安排力量成长、补小奖励、造新权限、开新地图或把人物成熟冒充 Power / Capability。

核心幻想、力量占有欲、主角欲望、人物关系和世界事件都可以成为某段故事的主要阅读满足；不要求每块平均覆盖。Supporting Logic 只在改变选择、胜负或结果时展开。Action Space / Expectation Ladder / Mystery Depth / Impact 仍可作为后台读者体验坐标，但只通过具体锚点与实际 Delta 自然显现，不生成对应必填字段。

最终只能使用以下四个一级标题：

# 小说总体设计画像
# 当前中期规划窗口
# 未来十章逐章小纲
# 当前状态、未兑现承诺与作者备注

## 0. 本书成长基因图

忠实压缩已批准的核心幻想与世界边界。

只记录会跨阶段继续生效的重要获得、关系、身份、知识或世界变化；Compounding 是旧事实继续改变后续，不是每阶段必填。

### 退化风险

以下 1—12 区块同样只做已批准信息的可执行投影：
## 1. 核心类型与读者承诺
写本书最值得追的幻想、主角人生牵引、Story Program 已批准的早中远期重要兑现；不要新增升级节点。
## 2. 世界观结构
写当前故事真正会用到的力量尺度、地点、奇观、资源与身份差异，以及成长后能进入的更大世界；如果本书需要且对当前故事重要，再补充其它层级关系，不堆百科。
### Reader Release Map
只列当前规划窗口中**首次释放时机真的重要**的少量 World facts；不是每章必填。格式：`- 第N章｜触发：具体已批准 World fact`。Release 必须和该章实际事件直接相交：开篇只释放当前猎市/生活真正碰到的事实，移动事实等到人物真正离开聚落时再释放；重要势力/地点/世界入口第一次真正影响选择时再按需添加。如果 Future 10 仍把某个答案安排为后续发现 / reveal，则在揭晓章之前只允许公共背景，绝不能把答案提前写入 Map。不能写“介绍X / 建立世界观”这种任务标签，不能发明 World Vision 没有的事实，不能提前泄露 named 未解真相。
## 3. 世界如何持续制造剧情压力
写世界中本来就在发生、会撞上主角的具体力量差、人物欲望、势力行动、危险与争夺，不把 supporting logic 自动升格为主发动机。

忠实投影 Human Core：主角当前想要什么、稳定保护/拒绝什么、哪些 competing motives 会在选择中冲突；不要把人生压成单一主题论文。
## 5. 配角与关系系统
写不可替代的重要人物各自想要什么，以及具体的人怎样改变主角选择；关系可以靠近、疏远、依赖、敌对或换位，不要求对称。
## 6. 核心情节发动机
说明 Life / Fantasy / World 如何在本书真实交替发动故事，不规定配额。
## 7. 叙事结构
写视角、第一章开篇策略、场景与总结的比例，以及如何用人物反应呈现状态变化。
## 8. 文风与可操作参数
写可执行表达目标，不变成禁词表、固定句长或评分器。
## 9. 对话特点
写角色声音、潜台词、拒绝、回避、欲望和对话怎样改变现场。
## 10. 节奏结构
写当前书适用的兑现、蓄势、余波和换挡节奏；不规定每块升级或每胜必付税。
## 11. 主题、价值观与长期问题
只后验总结具体人物和事件已经自然形成的倾向；没有稳定主题时直接写“暂不预设”。不得反向生成世界 ontology、资源体系、敌人设计、能力升格或终局。
## 12. 当前设计最强点与最弱点
只写 1—3 项真实风险，不生成机械清单。

# 当前中期规划窗口

先写：
规划范围：预计第1—N章
窗口终点：用 2—4 句说明当前 Story Program 因果链为什么在这里自然完成一个可执行阶段，以及哪个已批准或自然发生的结果让下一段故事开始。N 是规划值，不是合同。

当前中期规划窗口只展开 Story Program 当前自然需要详细执行的部分。可以覆盖一个长期阶段，也可以跨相邻阶段的一部分；不要为了“全书完整”把后期压进来。完整输出从第1章到本窗口预计终点的所有自然剧情块，不用“后续类似”省略。每个剧情块是若干会改变局势的故事转折，不是实施步骤。

每块使用：

## 第X—Y章：具体块名
具体发生：先用一句写清本块真正的故事主问题，再按因果顺序写连续故事锚点。通常 3—5 个锚点只是密度参考。每个锚点写清谁为了什么行动、谁阻止或回应、主角做了什么关键选择或怎样使用已有力量、最后发生什么不可逆变化，以及为什么触发下一锚点。不要拆成观察 / 分析 / 验证 / 搬运 / 制作 / 检测等工作流。
主要阅读兑现：只写本块最主要让读者得到的满足，可以来自力量、胜负、获得、关系、身份、探索、秘密、选择或世界事件；不要为了覆盖类型逐项填写。
Block Delta：只写**相对本块开始**真正改变的维度，并只使用实际适用的 `Power / Capability`、`Possession`、`Relationship`、`Identity / Access`、`Knowledge`、`Enemy State`、`World State`。没变化的维度直接省略；上一块已经发生的变化不要重复包装成这一块的新 Delta。Power、奖励、权限、地图都允许整块没有。Story Program 已批准且确实在本块发生的变化必须落到前面的具体锚点中，不能只写摘要。
代价或余波（可选）：只有本块真实存在时才写，不为成熟感制造等量损失。
推向下一块：写哪个已经发生的结果让下一块自然发生，不默认必须是新敌人或新入口。

# 作者粗方向

成熟中文男频东方玄幻成长长篇。生成一本真正全新的书：使用全新的世界、力量因果、人物、势力、地理与长期故事，不复用近期实验的核心机制组合或标志性专名。可以自然使用境界、功法、兵器、异兽、宗门、王朝、血脉、火、雷、寒气等熟悉题材语言；原创不靠回避熟悉词，也不靠生造术语。

近期不得换名复用的核心机制组合包括：异兽心核/器官炼体获得兽性、景相/天景、重力/承力、潮炁/潮印、材料性质/真质/刻纹、地潮/潮力、地火/命炉、曜砂储热、断光/灯数、天蜕/壳层、兵器回响。不要只是给旧机制重新命名。

核心阅读欲望优先是主角本人持续变强、战斗、奇遇、稀有功法/兵器、身体变化、怪物/异族、秘境遗迹、强者竞争、公开比较、真正高价值获得，以及随着成长不断进入第一章时没有资格接触的人物圈层与世界层。治理、维护、运输、工程、资源分配只能作为必要背景，不得成为主要价值重心或长期故事发动机。

世界力量必须先用普通话说明“力量从哪里来、人具体能做什么、怎样变强、怎样失败”，再决定是否需要短名；新词只给已经理解、会反复出现的对象或层级贴标签。前台力量优先是身体、攻击、防御、移动、元素、兵器、异兽等直接可感知作用，不默认把路径、权限、定义、结构分析或验证过程本身做成力量核心。力量体系要有可长期反复比较的公开主尺、高阶强者样本和值得羡慕的高价值对象。

Core Power 默认宁强勿弱：同层普通人/天才第一次看到时应明显觉得“这也太占便宜了”，允许有条件越级；但能力要一句普通话能懂，直接型能力的成长继续扩大控制、战斗复合和危险场景下的稳定使用，不重新退化成结构分析、材料诊断、路线计算或验证流程。World 阶段完全不知道未来主角与金手指。

# POWER SEED

## 一句话大白话

我能把自己的影子剥成另一个完整的自己，让两具身体同时战斗、修炼和学习，重新合在一起后，两边经历过的东西都会回到同一个人身上。

## World Power Normal → Power Asymmetry

绝大多数修炼者的影子都依附于真实身体，只能作为身体的延伸，完成攻击、防御、攀爬和移动。即使三阶能够操纵院落中的大片阴影，也不是多出一具可以独立行动、独立修炼的身体。

这个异常允许持有者把影子暂时剥离，形成一具能够独立行动的影身。影身拥有持有者当前的身体轮廓、基础影力和战斗能力，可以单独战斗、练功、观察和学习。

分开期间，两具身体的经验不会互相干扰；重新接触后，战斗手感、功法熟练、记忆和修炼心得会一次性回流，合并成同一个人的经验。

## Core Fantasy

一个人同时过两种人生：一个去拼命，一个去变强，回来以后两边的收获全是自己的。

## 为什么读者会馋

如果明天得到它，最想立刻做的事情是：

- 一具身体进入危险遗迹，另一具守在外面接应；
- 一具身体闭关练功，另一具身体去战斗积累经验；
- 一具身体牵制敌人，另一具从侧面发动攻击；
- 一具身体研究新兵器，另一具继续修炼基础功法。

同层普通人一天只有一具身体、一个战场和一份修炼时间。持有者却能同时占据两个位置，把一次行动变成两次行动，把一段修炼时间变成两段真实积累。

## Growth Compatibility

### 正常修炼轴

正常提升本体与影身共同拥有的影阶、身体强度、影力总量、影形稳定和术法威力。

持有者不能靠分影跳过境界。正常修炼越深，两具身体的基础能力越强，分影带来的双线行动才越有价值。

### 异常掌握轴

从只能短暂分开，成长为能维持更长时间、更远距离和更复杂的独立行动。

两具身体最初只能执行清楚简单的目标；掌握加深后，可以各自临场判断、使用不同战斗方式，并在合并时完整回流两边的熟练度和经历。

### High-Tier Mutation

高阶后，分影不只是多出一个帮手，而是能让两具身体同时使用不同的兵器、功法和战斗节奏，从两个方向完成真正的夹击。

一具身体可以正面承受压力，另一具则用完全不同的方式破局；合并后，两种战斗经验会成为同一个人的本能，而不是两套互不相干的记忆。

### 永久边界

最多只能多出一具影身，不能无限分裂。

两具身体都必须拥有真实可见的影子，强直射光、杂乱光源或完全无光仍会破坏分影稳定。距离也受当前影阶限制，不能无限远离本体。

影身受伤不会自动抹除后果；重新合并时，伤势和影力损耗必须由同一个身体承担。影身被强行撕裂，还会给本体造成严重反噬，因此不能把它当成无代价的消耗品。

## Legendary Power State

传说中的持有者能够让两具身体同时出现在同一场决定胜负的战斗里：一个人拥有两套完整的临场判断、两种战斗节奏和两处同时施加的压力。

合并之后，敌人面对的仍然只是一个人，但那个人已经拥有两倍的实战经历与成长积累。

## HUMAN CORE｜Frozen Authority

# HUMAN SEED｜顾临川／不肯把日子过钝的人

## 世界中的初始位置与生活事实

顾临川出生在大晟中部一座有固定火盆和内街阴影的普通城镇。家里不贫寒，但也没有能直接换来身份的积累。父亲替几支商队做短途账目和货单，母亲经营一家能住六七人的小客舍，偶尔替旅客修补衣物、缝制灯罩。

他在镇学读完基础识字、算术和官契辨认，十五岁通过影性试验，影子能在呼吸变化中保持完整，却没有进入宗门或军府。之后，他在本地武馆断断续续学过一年影术，又回客舍帮忙记账、接待商旅、辨认货物和安排房间。

他过去真正经历过几件事：

- 十三岁时，他把一张商队货单上的数字抄错，导致父亲少收了一笔钱。家里没有责打他，只用了两个月才把账补平。
- 十六岁那年，一支护商队在客舍停留，他替其中一名受伤的年轻护卫保管兵器。那人离开时没有留下姓名，只把一枚磨损的铜扣送给了他。
- 他曾花三个月替客舍重新布置内院，把旧帘、残灯和废木箱改成一处能听见水声的阴凉小庭，客人很喜欢，但这件事没有让家里多赚多少钱。
- 十八岁时，客舍后厨失火，他和母亲先救出了住客与账册，随后花了半年还债、重修屋顶。
- 他在武馆认识陆绾。陆绾替一家药铺往各处送药，身上常带着药粉、风尘和晒热的布料气味。一次她临时缺人同行，顾临川放弃了报酬更高的商队记账活，陪她走了五天山路。

## 持续牵引与互相竞争的动机

- 他想被真正有分量的人看见，并且赢一次不是靠家世、熟脸或运气。他享受别人记住自己名字时的感觉，也会为了一个公开的机会承担丢脸和失败。
- 他对具体的色彩、声音、触感、食物和空间有直接兴趣。好看的器物、舒服的房间、陌生地方的声响，即使没有实际用途，也足以让他停下来。
- 他会被具体的身体吸引牵动。喜欢一个人的外貌、气味、姿态和靠近时的感觉，可能让他改变原本更划算的安排；这种吸引不自动等于长久合适。
- 他想拥有一笔不必向家人解释的自由钱，也想离开熟悉的人群，去别的城镇生活一段时间。但稳定收入、家里的欠款和他对当下生活的依恋，会反复把他拉回去。

这些动机不能同时满足：他可能在一份稳定但乏味的差事和一次能让人看见自己的冒险之间犹豫；也可能明知某段关系不适合长期维持，却因为身体吸引和共同在场，继续支付时间、风险或机会成本。

## Behavior Signature

顾临川通常先判断一件事是否仍然鲜活：是否有具体的人、好看的东西、值得学的新手艺、可赢的局面，或者能让他感到自己正在真实生活。只要答案是肯定的，他可以忍受麻烦、失败和不体面的过程。

一旦事情只剩机械重复、空洞应酬或别人规定好的正确姿势，他会开始拖延、绕路、换人接手，甚至在已经投入很多之后离开。他知道这样可能损失钱和信用，却不总能让长期收益压过眼前的钝感。

他在被重视时更愿意展示自己，也更敢接近陌生人；如果发现赞美只是礼貌，他会迅速失去兴趣。面对不同现场，他可能直说、隐瞒、硬撑、讨价还价或突然回头，具体做法取决于当时的风险、能力和身边的人。

他不把公平、责任或安全当成永远最高的排序。若只是陌生人的便利，他通常会计算代价；若涉及某个具体的人、强烈吸引或真正想看的东西，他的风险阈值会改变。

## 重要关系原点

陆绾是顾临川在武馆认识的女人，出身于做药材处理和伤药配送的家庭。她不依附他，也不特别擅长讨好人；她走路很快，嫌麻烦，记性好，常常把话说到一半就去做下一件事。

顾临川原本准备接一份报酬更高的商队记账活，因为陆绾临时缺少同行者，他改接了低价的短途差事，陪她送药五天。这个选择不完全出于责任：他确实喜欢她的身体、气味和走路时不回头等人的样子，也喜欢她在陌生地方仍然自顾自做事的鲜活感。

他们后来相处过一段时间，但没有被自动推成稳定关系。陆绾更在意一门能长期养活自己的药材手艺，顾临川则常被新的地方、新的人和被看见的机会吸引。她在场时，他会延后离开、接受自己原本不想去的地方；她缺席时，他可能重新选择更自由、更有趣或更赚钱的路线。

# 已批准 World Vision

# PROTAGONIST-BLIND WORLD VISION

## 普通人的生活与上升

大多数人生活在有城墙、屋檐和固定火盆的聚落里。房屋会刻意保留整块阴影，街道也不会完全敞开，因为稳定的影子既能遮阳，也能防止荒野中的夺影兽贴近人体。

年轻人通常在十三至十六岁接受一次“影性试验”：能否让自己的影子在呼吸和血行配合下保持完整。合格者可以进入宗门、军府、护商队或地方武馆；没有修炼资质的人，则多从事农耕、铸器、制灯、驯兽、采药和商贸。修炼失败通常意味着影子受损、身体短期麻木，严重者终生不能再凝聚影力，但仍可作为普通人生活。

聚落之间的道路并不安全。白天，普通人可以跟随驮队和商旅通行；进入荒野、废城或长夜地带，则必须加入有修士护送的商队、猎队或军驿。能够独自跨越危险区域的，至少是影术二阶，并且熟悉当地地形。失去火光、误入无影地带，往往比遇到盗匪更危险。

## 力量体系与正常值

世界上的力量来自人和生灵在光照下形成的影子。修炼者通过特殊呼吸、血行和昼夜交替，把影子从地面上的轮廓变成能够承受力量的实体，再以影子完成攻击、防御、移动和身体强化。

影力必须依附于真实身体。身体受伤、精神涣散或影子被强行撕裂，都会让术法失控。过强的直射光会使影子变薄，多重杂乱的光源会让影子分裂；完全无光的地方也无法让大多数修士继续扩展影力。

当前世人主要以“影阶”比较强弱：

- 一阶只能让影子伸长、变硬，形成短刃、绳索或一次性的挡击。
- 二阶可以让影子覆盖身体，抵挡刀箭，并用影子完成短距离牵引和攀爬。普通二阶已足以担任城卫、猎队骨干或商队护卫。
- 三阶可以同时维持数件影器，在一座院落内压制数名二阶；正常三阶能够短暂借自身影子换位到十步以内的明显阴影。
- 四阶可以在多重火光下保持完整影形，操纵墙壁、屋顶和地面的大片阴影，足以改变一场小规模战斗。
- 五阶极其稀少，能够在街巷、城墙或山谷间连续借影移动，并以一人之力迫使普通军阵改变部署。

影阶是主尺，但不是绝对胜负。功法决定影力的稳定和形态，天赋决定影子承载上限，兵器决定近战效率，地形和光线则会直接改变战斗结果。准备充分的二阶可能杀死仓促进入强光区的三阶；但在正常环境下，阶位差距仍会明显改变别人是否敢于挑战、招揽或围杀。

## 社会现实与身份

大晟王朝是覆盖中原诸城的王朝，普通人通过官印、税契、军旗和驿路识别它。王朝控制城池、农田和主要关隘，军府负责边境战争与荒野清剿。

观日宗是公开传授影术的宗门，在各地设有武馆和试影院。它不只招收天才，也向地方势力出售护城、护商和猎兽方面的术法资格。能进入观日宗内门，通常意味着更好的功法、兵器和身份。

铜羽商盟是跨城经营的商盟，掌握大量药材、兵器、修炼书册和荒野路线。普通人认得它的铜羽旗与商队契券；商盟成员在许多城镇可以优先获得住宿、交易和护送。

烬骨王庭是北方异族政体，拥有自己的城寨、军队和贵族体系。边境居民将其视为现实中的邻国与敌国，而不是传说中的妖兽群。王庭的战士擅长在雪地和低光环境中使用影术，长期影响着北境的征兵、贸易和人口迁徙。

身份会直接改变一个人的选择。普通护卫只能接低价护送，军府影卫可以进入禁区，宗门弟子能够购买高阶功法，商盟核心成员则能接触跨境路线和稀有拍卖。

## 世界里真正值钱、值得想要的东西

这个世界最值钱的首先是能让人稳定变强的东西：

- 上乘影术功法，尤其是能在强光、雪地或混乱火光中保持影形的功法。
- 能承受影力的兵器与护甲。普通铁器会在高阶影力反复冲击下变形，真正的影兵可以让同一阶修士拥有明显优势。
- 高阶修士的指点、宗门名额、军府编制和商盟核心契约。它们意味着更好的资源、合法身份和进入危险地区的资格。
- 安全荒野路线、古城地图、异兽习性和边境情报。错误的路线会让一支商队整夜消失。
- 能够治疗影伤、修复影子裂痕的药物与医术。对修士而言，这比普通金银更重要。
- 稀有异兽的皮、骨和影膜，可用于制作护具、猎具和特殊兵器，但采集它们通常需要付出人员伤亡。

普通人羡慕的是有稳定收入和官府保护的身份；低阶修士羡慕高阶功法与兵器；高阶修士争夺的则是传承、地位、进入古代遗迹的资格，以及能够让自身影力继续突破的机会。

## 世界正在发生的大事

- 北境三座城在午时突然出现了与太阳方向相反的长影。大晟王朝已经开始迁移部分百姓，边军统领裴朔则坚持留守黑峡关，因为烬骨王庭正在边境集结。
- 铜羽商盟会长阮青缨正在组织一支跨境商队，试图从沉昼城运出一批古代影兵。沿途已有数支小商队失踪，商盟内部有人要求取消交易。
- 观日宗的长老陆问山带队进入折日峡，寻找失落数百年的宗门传承。宗内另一名弟子顾斜阳则试图在宗门大比前取得这份传承，以改变自己的继承资格。
- 南方的盐港连续出现大批失去影子的病人。当地医师认为这是新型疫病，军府却怀疑有人在测试能够撕裂影子的禁术。
- 北方几个荒原部族正在向烬骨王庭靠拢，原因并不一致：有人想参加战争，有人想获得城内粮食，也有人只是被正在扩大的无影地带逼离故土。

## 值得进入的地点、奇观与未知

折日峡是一条被群山夹住的深谷。阳光进入峡底后会发生奇怪偏折，岩壁、树木和行人的影子经常同时指向不同方向。这里有珍稀药材、古代石城和无法长期驻扎的强大异兽。

沉昼城曾是旧王朝都城，如今半座城市埋在地下。城中每天都会出现一段没有影子的正午，废墟里的兵器、壁画和石棺因此保存异常完整。进入者常能带出价值极高的遗物，但也可能在离开前失去自己的影子。

无光海不是海，而是一片不断吞掉火光的黑色盆地。盆地中央漂浮着破碎建筑，偶尔会在夜间露出完整轮廓。没有人知道那些建筑为何能漂浮，也没人能解释其中的影子为什么比实体更早移动。

黑峡关是王朝与烬骨王庭之间的要塞群，城墙上布满历代强者留下的影痕。每逢边境冲突，旧影会在墙面上重现部分战斗，旁观者只能看见动作，听不见声音。

## 世界知识边界

普通人知道影子可以被修炼，也知道夺影兽、无影病和荒野中的长夜地带。他们通常只相信一阶、二阶修士的力量，对三阶以上的能力依靠传闻判断。

专业人士和修士知道，影力并非单纯的黑暗，而是身体、光线、血气和影子共同形成的实体力量。他们知道不同环境会改变术法效果，也知道古代遗迹可能拥有与现世不同的影子规律，但没人掌握完整规律。

顶层势力知道五阶并非影术极限，古代曾存在过能够影响整座城池影子的强者。他们还掌握部分关于沉昼城、折日峡和无光海的旧记录，但这些记录彼此矛盾，不能直接当作事实。

目前没人能完整解释的事实包括：

- 为什么某些古代建筑在实体消失后，影子仍能存在数百年。
- 为什么沉昼城会周期性出现无影正午。
- 为什么北境近期出现的长影会让普通人患病，却能让部分异兽异常强大。
- 无光海中的漂浮建筑究竟属于哪个时代，以及它们为何会在影子先动之后才显露实体。

# 作者已批准的 Story Program

# STORY PROGRAM

## 核心碰撞

1. 顾临川想靠公开胜负被有分量的人记住，分影却越少人知道越容易占便宜。每一次显露都可能换来名额、兵器和更高圈层，也会让宗门、商盟与军府开始估价、招揽甚至限制他。他不会天然选择藏到底，也不会为了安全放弃所有能扬名的场合。

2. 分影让他可以同时接住两种生活，正好诱发他最危险的倾向：一边修炼或执行正事，一边追逐新鲜的人、地方和机会。他能把时间分成两份，却不能把承诺、伤势和后果分给两个人；合并之后，爽快、疲惫、失约与反噬仍由顾临川一个人承担。

3. 陆绾要的是能养活自己、让同行承认的影伤医术，不会为了陪顾临川冒险而放弃长期手艺；顾斜阳要在宗门大比前取得折日峡传承，不会因为顾临川更有主角气象就让路；阮青缨要把沉昼城的古代影兵运出来，必要时会舍人保货；裴朔要守黑峡关，也不会因为顾临川珍惜某个人就撤掉一条防线。

4. 顾临川会被漂亮的兵器、陌生空间、强者的注视和具体的人吸引。他可能为一柄真正想要的古兵放弃大半报酬，也可能为陆绾改道数千里，却未必愿意为任何一个势力长期过纪律严密、重复而正确的生活。

5. 分影适合侦察、夹击和双线成长，却不能解决无影正午、完全无光、疫病、国境战争或两个人究竟要不要留在一起。世界中有大量事情不能被他的力量直接换算成收益；他必须在力量失效时仍作出属于顾临川的选择。

## 全书成长与核心幻想兑现脊柱

1. 顾临川最初只能把影子剥离十余息，两具身体不能离得太远，也只能分别执行“守住门口”“从侧面出刀”一类明确目标。普通一阶只能伸出一件影刃时，他已经能让两个同阶身体从正侧同时进攻；代价是任何一边受伤，合并时都落回同一具身体。

2. 在折日峡经历多方向光线、异兽追逐和分路救人后，他能让两具身体分开更久，并在看不见彼此时完成不同任务。一具身体可以护送伤员出峡，另一具继续跟踪敌人；重新合并后，他同时知道两条路上发生过什么，也第一次发现自己会因为“两边都能做”而接下本不该同时承担的责任。

3. 进入二阶并得到一套可以拆成窄刀与短枪的古代影兵后，他不再让两具身体复制同一种打法。一具贴身用刀逼迫对手缩小步幅，另一具以短枪封住退路；合并训练使他即使只剩本体，也能在刀枪转换时保留两种距离感。普通二阶依靠覆体影甲承受刀箭，他则能用两处身体和两种兵器迫使一名老练二阶始终少防一个方向。

4. 达到三阶后，两具身体拥有完整的临场判断，可以同时使用不同功法和战斗节奏。一具在明处承受院落范围的压制，另一具借屋檐阴影连续换位，前者试出的破绽会在下一次合并后成为本体的直接手感。此时他能正面击败资深三阶，也能在准备充分时让四阶无法迅速杀死或困住自己，但强光、无光、距离和合并伤势仍然有效。

5. 在无光海的漂浮遗址中，他争得一部古代残篇，学会把整具身体压进自己的影子一息，沿墙面或地面穿过门缝、箭孔和兵刃封锁，随后必须立刻恢复血肉。绝大多数同阶只能操纵影子，不能让身体随影子变薄；这成为后来加入的新 Power Asymmetry。它仍需要一块真实、连续的影子，不能进入完全无光或强直射光，也不能让伤势失效。

6. 高阶时，两种优势发生真正复合：一具身体以窄刀和正面压力吸住强敌，另一具身体把自己压进那名“顾临川”脚下看似唯一的影子，从封锁内部重新化为实体，以短枪攻击本来不可能同时抵达的背面。单有分影会被阵线隔开，单有压影之法又无人替他持续牵制；两者结合后，他能从一条已经封死的战线上同时占据内外两侧。五阶时，两具身体可在街巷级战场维持不同判断，合并后的顾临川则真正拥有两场同时发生的实战经验。

## 不可替代的人与关系

- **陆绾**想把药材处理与影伤救治练成自己的立身手艺，最终拥有不依附药铺、顾临川或任何宗门的名声。另一个医师可以替顾临川治伤，却不能替代他们已有的身体吸引、五日同行和彼此看过对方不体面一面的经历。她会让顾临川为盐港改道、放弃一次宗门试入，也会在他把“有两个自己”误当成“能答应两份人生”时直接离开。两人可以相爱、同住或重逢，却不因此自动适合长期同行。

- **顾斜阳**想在宗门大比前取得折日峡传承，改变自己在观日宗的继承资格。他不是顾临川的亲族，也不是专为衬托主角而存在的傲慢天才；他比顾临川更熟悉宗门规则，也更愿意长期忍受纪律和重复。其他竞争者不能替代他，因为他亲眼见过顾临川分影尚不成熟时的失败，后来又一次次在公开标准上与他比较。两人的竞争会在敌意、合作和互相借势之间变化。

- **阮青缨**要完成沉昼城交易，保住铜羽商盟跨境路线和自己在盟中的控制力。普通雇主只能给钱，不能替代她掌握的危险路线、古兵归属和跨城信用；她也不会成为无条件赞助者。她给顾临川进入高价值世界的第一张门票，同时保留在货物、人命与商盟利益之间作出冷硬选择的权利。

- **贺兰槐**来自正在向烬骨王庭靠拢的荒原部族。他需要一场足够大的战功，让王庭接纳族人进入有粮食和城墙的地方，因此真心想攻下黑峡关。另一个敌将可以提供战斗，却不能替代他同时背负的部族去留、王庭资格和对顾临川公开胜负的执念。两人会互相负伤、夺取战果，也会在长影同时侵害两国时短暂交换情报；这种合作不抹去他们曾经杀死彼此部属的事实。

## 长期故事主线

### 阶段1｜火盆下的两个人

**为什么现在发生：** 铜羽商盟连续失去数支小商队，需要在顾临川所在的城镇公开补招低阶护卫。陆绾恰好要把一批伤药送往下一处驿城，顾临川原本只需替商队做货单便能得到稳定报酬，却看见了一个可以当众赢得名额、离开熟人圈子的机会。

**谁想要什么：** 顾临川想赢下公开比试，攒到外城生活的钱，并让真正见过各地修士的人记住自己；陆绾想按期送到伤药，不愿把自己的差事变成顾临川扬名的附属；商盟领队姚谦只想补齐能活着走完路线的护卫，不在乎年轻人的体面；武馆教习想证明自己教出的本地弟子不比宗门外围差。

**主角的关键选择与行动：** 顾临川放弃稳妥的记账差事参加比试；在一次影刃失控即将伤及旁人时，他第一次当众稳定剥离影身，一具身体挡下攻击，另一具身体击倒对手。姚谦要求他把这种异常写入契券，他明知暴露会失去偷袭优势，仍选择以真本事换取公开名额。

**这一阶段真正的阅读满足：** 一个普通一阶只能出一件影刃的公开场合里，顾临川以两具身体同时完成救人和取胜，第一次让懂行者真正记住他的名字；他也终于带着自己赚来的钱和身份离开客舍，而不是作为谁家的儿子送客出门。

**Stage Delta：** 顾临川确认自己可以短暂分出一具完整影身，两边经历会在合并后共同留下；他成为铜羽商队的正式低阶护卫，得到第一笔不必交回家里的钱；陆绾发现他会为了被看见承担真实风险，而顾临川也发现她不会因为他的异常能力便改变自己的工作顺序；商盟留下了关于“双身影术”的正式记录。

**下一阶段为何自然发生：** 商队预定路线上的驿站已经失联，姚谦只能绕行折日峡外围；陆绾的伤药不能继续拖延，而观日宗寻找传承的队伍也正在峡中改变当地道路与异兽活动。

### 阶段2｜折日峡的两条路

**为什么现在发生：** 绕路商队在折日峡外遭到被惊出的异兽冲击，人员与货物被迫分散。陆问山带领的观日宗队伍正在峡内搜寻古代石城，顾斜阳为了赶在宗门大比前找到传承，擅自推动队伍继续深入，使两批人的退路同时受到影响。

**谁想要什么：** 顾临川想看见峡底古城，也想证明自己的分影不是一次偶然；陆绾要把伤药和伤员送出去；陆问山想保住弟子并确认传承是否真实存在；顾斜阳想先于宗门其他继承候选取得核心遗物，不愿因一群商旅撤退。

**主角的关键选择与行动：** 顾临川找到安全退路后没有让两具身体一同离开，而是让本体护送陆绾与伤员，影身折返跟进顾斜阳；当距离逼近极限时，他没有继续追逐最可能让自己扬名的遗物，而是让影身引走异兽，为被困弟子争取撤退时间，承受影身被撕裂后的第一次重伤反噬。事后他拒绝替顾斜阳隐去擅自深入的事实，也没有把自己说成纯粹救人的好人。

**这一阶段真正的阅读满足：** 顾临川第一次真正同时经历两条冒险线：一边带人穿过错乱影向的峡谷，一边在古城屋顶与异兽追逐；合并时，两边的路线、恐惧和战斗手感一齐回到他身上。折日峡的多向光线也迫使他的强势能力出现清楚边界。

**Stage Delta：** 顾临川能让两具身体在短暂失去彼此视野时完成不同任务，但严重反噬证明影身不能被当作替死品；陆问山给他一次观日宗外围试学资格；顾斜阳失去独占发现的机会，与顾临川形成有实际利益冲突的竞争关系；陆绾第一次为顾临川处理影子撕裂，却没有因此放弃自己的送药路线。

**下一阶段为何自然发生：** 阮青缨从商队报告中得知顾临川能同时守住内外两个位置。她正在为沉昼城运兵计划寻找能在无影正午前后分头行动的人，而顾临川既需要钱，也无法拒绝亲眼接触古代影兵的机会。

### 阶段3｜沉昼城的无影正午

**为什么现在发生：** 阮青缨组织的跨境商队必须在沉昼城无影正午到来前，把一批古代影兵从地下街区转移到城外。原有护卫因连续失踪要求取消行动，她以高额报酬和正式商盟契约招揽顾临川；观日宗的试学日期却与商队启程冲突。

**谁想要什么：** 阮青缨要把最值钱的古兵运出城，即使必须放弃部分人员和普通货物；顾临川想要钱、名声，并亲手拥有一件真正的影兵；商队护卫首领孟成想在无影正午前撤出所有活人，不愿为阮青缨的货物送命；陆绾希望顾临川先养好影伤、参加试学，而不是立刻接下一次更危险的机会。

**主角的关键选择与行动：** 顾临川放弃观日宗试学，随商队进入沉昼城；他一度把分影当作可以同时守门和夺宝的保险，却在无影正午逼近时发现两具身体都开始失稳。他没有服从阮青缨“弃人保主箱”的命令，而是用本体带伤员撤离、影身拖出一套自己已经试用过的古兵，最后以大半报酬和商盟功劳换取古兵归属，而不是免费领赏。

**这一阶段真正的阅读满足：** 顾临川在半座埋入地下的旧都中争夺真正值钱的影兵，并在最依赖分影的时候遭遇整个城市没有影子的正午；高价值获得、能力失效和主动取舍同时成立。

**Stage Delta：** 顾临川进入二阶，能够以影子覆体抵挡普通刀箭；他拥有一套可拆为窄刀与短枪的古代影兵，两具身体第一次能以不同距离协同作战；他失去大半预期积蓄和观日宗当期试学机会，却得到铜羽商盟核心契约与跨城信用；阮青缨认可他的价值，也确认他不会永远把商盟货物排在具体人命之前；沉昼城内仍有一只主箱未能运出。

**下一阶段为何自然发生：** 沉昼城留下的影伤无法在普通药铺治好，陆绾正准备前往盐港跟随当地医师处理大批无影病人。顾临川同时收到军府北上招募和陆绾的同行请求，必须决定先追逐更大的公开战场，还是为一个具体的人改道。

### 阶段4｜盐港留不住的人

**为什么现在发生：** 盐港无影病人数继续增加，陆绾获得一次参与诊治的机会，但必须自备护卫并在当地停留至少半年。顾临川的影伤也需要治疗；他明知北境招募更接近自己想要的扬名机会，仍因陆绾和对无影病的好奇选择南下。

**谁想要什么：** 陆绾想真正学会处理影子裂伤，并以自己的名字留在盐港医师圈；顾临川想陪她、治好自己，也想确认两人能否在同一座城里生活；医师宋含真想救下病人并找出传播源；退役军医沈鸦正在用病人试验“先撕掉受损影子、再让身体重生影子”的禁术，想证明自己的方法可以治疗军中重伤。

**主角的关键选择与行动：** 顾临川用一具身体协助宋含真追查病源，另一具身体继续练刀和接短期护卫差事，起初以为自己可以同时满足陆绾、赚钱和修炼；当沈鸦准备带走一批病人时，他放弃一场能获得北境军府编制的公开考核，分头截住运人队伍并救出证人。事情结束后，陆绾决定留在盐港继续学医，顾临川承认自己不愿在此长期重复生活，没有以救过她或陪伴半年要求她同行。

**这一阶段真正的阅读满足：** 顾临川与陆绾真正共同生活、争执、靠近并作出不整齐的去留选择；无影病危机则证明分影能让他同时救两处人，却不能替他维持两份互相冲突的人生。

**Stage Delta：** 沈鸦的试验被揭露，盐港这一批无影病被确认是人为禁术造成，与北境长影不是同一来源；顾临川的旧影伤痊愈，但力量没有显著升阶；陆绾取得留在宋含真身边学习的资格，与顾临川成为真实亲密过、仍会彼此牵动，却不承诺同行的关系；顾临川因错过考核失去直接军府编制，只保留一封迟到的北上举荐。

**下一阶段为何自然发生：** 黑峡关战事恶化，裴朔不再等待完整招募流程，开始接受持举荐信的民间修士。顾临川不愿继续留在已经变钝的盐港生活，而阮青缨也需要有人护送一批影伤药北上。

### 阶段5｜黑峡关前，谁的名字

**为什么现在发生：** 烬骨王庭军队在边境集结，北方部族为获得粮食和城内身份不断加入战事；反向长影则同时使两边普通士卒患病。裴朔坚持守关，需要能在城墙内外同时行动的修士。顾临川带着药物和迟到的举荐抵达时，发现十六岁那年留下铜扣的年轻护卫谢停已经是边军小旗。

**谁想要什么：** 裴朔要守住黑峡关，不让军队和迁移百姓同时堵死南路；顾临川想在真正的大人物和大军面前赢得自己的名字，也想让谢停所在的小队活下来；贺兰槐需要攻关战功，为自己的部族换取进入王庭城寨的资格；顾斜阳带宗门弟子参战，想以军功补回折日峡失去的继承优势。

**主角的关键选择与行动：** 顾临川没有隐瞒分影，而是接受最容易被敌人研究的公开守墙位置；裴朔下令放弃外堡时，他因谢停仍在其中而违令折返，一具身体带伤员沿城墙撤退，另一具以窄刀和短枪轮换拖住贺兰槐。此后他接受与贺兰槐的公开再战，却拒绝把对方部族中的迁徙平民当作诱敌筹码。

**这一阶段真正的阅读满足：** 顾临川在军阵和高阶修士都能看懂的尺度上完成第一次真正扬名：普通三阶足以压制数名二阶，他则以两具三阶身体、两种兵器和两套节奏击败资深三阶贺兰槐，并从四阶追击下带回外堡残兵。旧铜扣只改变他一次具体选择，不把他塑造成命定守关者。

**Stage Delta：** 顾临川达到三阶，两具身体可以独立临场判断并分别使用窄刀、短枪；他的名字进入大晟军府、观日宗和烬骨王庭的正式战报，新圈层开始按公开战绩而非传闻估价他；谢停从一段模糊旧事变成现实中的边军朋友；贺兰槐战败却保住部族主力，与顾临川形成必须再次结算的敌对关系；双方确认反向长影都会伤害普通人，并非烬骨王庭已经掌握的战争手段。

**下一阶段为何自然发生：** 一支被长影逼离故土的荒原部族带来无光海石图，图上记录的漂浮建筑与黑峡关墙面旧影出现了相同动作。裴朔需要查明长影是否还会扩大，阮青缨则看见新的遗迹与商路机会；顾临川想亲眼看见那个影子先于实体移动的地方。

### 阶段6｜无光海里先动的影子

**为什么现在发生：** 北境长影持续扩大，黑峡关旧影在无人战斗时重现出指向无光海的动作。阮青缨组织遗迹队，顾斜阳代表观日宗加入，贺兰槐则为迁徙部族争取同一份情报。几方都需要等待无光海中漂浮建筑短暂显露的窗口，无法单独提前取得结果。

**谁想要什么：** 顾临川想进入第一章时连传闻都没有资格接触的古代建筑，并寻找能让自己继续变强的东西；阮青缨要取得可交易的遗物与安全路线；顾斜阳要证明漂浮建筑中的残篇属于观日宗传承；贺兰槐要确认无影地带是否会吞没族人的新居；遗迹中的夺影兽只按自身领地和猎食习性行动，不为针对顾临川而生。

**主角的关键选择与行动：** 进入吞噬火光的盆地后，顾临川无法稳定分影，只能以单独本体与其他人合作；当漂浮建筑出现短暂斜光时，他发现一部残篇必须由两个位置同时完成动作才能开启，而这原本可以由任何配合足够默契的两个人完成，并非专为他准备。他选择让影身守住开启位置，本体深入取得残篇，放弃同时争夺阮青缨发现的整箱古器；夺影兽袭击时，他又必须提前合并，承受两边伤势后亲手保住残篇。

**这一阶段真正的阅读满足：** 顾临川在力量几乎失效的无光奇观中争得一门真正令人眼馋的新能力：身体能随自己的影子压平一息，穿过实体封锁。遗迹揭晓“影子先动”并非预示未来，而是古代建筑每次显形时都会沿着早已存在的影子重新落回实体位置，使过去看似怪异的动作变成一张仍在运行的建筑图。

**Stage Delta：** 顾临川达到四阶，并从古代残篇学会短暂把身体压进自己的影子，获得独立于分影的新 Power Asymmetry；顾斜阳确认残篇不属于观日宗现存传承，失去合法独占理由，却获得另一段与宗门旧史有关的记录；阮青缨取得一批古器但没有得到最值钱的残篇，开始把顾临川视为能够与她争夺机会的人，而非受雇护卫；贺兰槐确认无影地带仍会北扩，必须重新决定部族是依附王庭还是自行南迁。

**下一阶段为何自然发生：** 残篇中的建筑图与北境反向长影能够逐处扣合：那些长影属于一座实体已经消失、影子仍埋在现世城池下方的古城。长影继续增长时，古城将沿影子重新显形；两国、商盟、宗门和受病百姓对它是否应该完整出现有完全不同的欲望。

### 阶段7｜一座城回来以前

**为什么现在发生：** 北境三城的长影开始连接，地下古城的墙、门与兵器正在按无光海残篇揭示的方式逐步显形。古城若完整出现，可能带来成批古代影兵和失落功法，也会让现有街区被实体重叠、使长影病继续扩散。这个过程在顾临川到来前已经开始，不会因任何一方暂缓争夺而停止。

**谁想要什么：** 裴朔要先疏散百姓并摧毁会压垮黑峡关的古城主墙；烬骨王庭要保住古城北门，以古代边界记录证明土地归属；阮青缨要让至少一座兵库完整显形；顾斜阳要取得能够改变观日宗继承秩序的古代总卷；陆绾主动来到北境研究长影病，希望救人并建立不属于盐港师门的医术名声；顾临川既想要古城中的力量与公开胜负，也不愿让陆绾和谢停死在各方争夺的城里。

**主角的关键选择与行动：** 顾临川拒绝任何一方要求他用两具身体同时替其占据两处遗址，而是先以一具身体协助陆绾与谢停撤出被古墙重叠的街区，另一具身体进入兵库争夺总卷；当他确认古城主墙继续显形会吞没撤离路线时，选择毁掉自己最想进入的完整兵库，以失去高价值获得为代价切断主墙。最终交战中，一具身体正面牵制高阶强敌，另一具把身体压入自己看似唯一的影子，穿过封锁后从敌阵内部恢复实体，第一次完成分影与压影的复合杀法。

**这一阶段真正的阅读满足：** 北境长影被震撼式重释为一座失去实体数百年、正在沿旧影归来的古城，旧建筑残影、无光海动作和黑峡关墙面战影因此获得新的分量，却没有把盐港禁术、沉昼正午和所有世界未知并成同一真相；顾临川则以两具完整判断、两种兵器和新获得的压影能力，在五阶强者能够左右军阵的公开尺度上完成传奇式一战。

**Stage Delta：** 顾临川达到五阶，能够在街巷和城墙间维持两具完整战斗身体，并让分影与压影组合产生穿透封锁的新战法；古城主墙和一座兵库被毁，北境一城的长影病停止恶化，但另外两城仍未解决；顾临川放弃了最完整的古兵库，却保住一卷残缺地图和自己的古代刀枪；陆绾凭实际救治取得独立名声，两人重新靠近，但她仍有自己的病人与去处；贺兰槐促成部分部族撤离王庭控制，与顾临川从必杀之敌变成仍会争夺、也能谈一次条件的边境对手；裴朔、阮青缨与观日宗都必须按顾临川已经能够独立改变大事的身份重新对待他。

**下一阶段为何自然发生：** 另外两座长影城仍在增长，沉昼城未运出的主箱开始出现不属于本城的影子，无光海还有未显形的建筑；顾临川已经有资格进入这些事件，却不再需要接受任何一个势力替他规定道路。他接下来要决定的不是能否离开客舍，而是愿意让谁同行、为哪一件真正想要的东西再次支付代价。

## 远期仍值得追的东西

- 顾临川与陆绾能否在不要求对方放弃自身道路的情况下，共同生活超过一次危机；身体吸引、真实亲密与长期选择是否会走向同一个答案。
- 顾斜阳在失去两次独占传承的机会后，会继续按宗门规则竞争、与顾临川合作改写继承资格，还是主动离开那个最适合自己忍耐力的体系。
- 贺兰槐能否为族人取得稳定居所，以及当王庭要求他以顾临川或南迁部族作为忠诚代价时，他会选择战功、族人还是自己的地位。
- 沉昼城未运出的主箱里究竟有什么，为什么它在北境古城受损后出现了新的影子；这可以与古代城市联系有关，但不自动解释沉昼城的无影正午。
- 另外两座北境长影城是否应该被摧毁、争夺或允许完整归来；其中可能有功法、影兵和古代人物留下的事实，也可能有现世任何势力都无权独占的居民遗迹。
- 无光海尚未显形的建筑，以及“影子存在、实体消失”究竟能持续到什么程度；它不保证通向更高力量层，也可能只是一个会改变历史判断和遗物价值的世界事实。
- 顾临川仍未完成最初那个朴素愿望：以自己的钱在陌生城市住上一季，不依附客舍、宗门、军府或商盟。等他已经是五阶强者，这件小事反而会检验他是否还能过一种不被名声和各方需求占满的生活。
- 分影与压影复合后的真正高阶场面：两具身体分别使用完全不同的功法与兵器，在两个互不相见的战场作出独立决定，最终合并成一个同时知道两场胜负、也必须独自承担两边后果的人。

### Inspiration 1
source: mechanisms/thread-collision-v3
type: mechanism
score: 0.281

可用抽象：Creative Problem：怎样让一个大事件真正合流 main plot / relationship / mystery / power / world 中的若干条线，而不是只是把很多角色叫到同一场？
Mechanism：成熟的碰撞点需要一个共享因果铰链和一个不可回避的选择。这个选择同时改写若干线程的未来可行性：某条安全路径关闭、某段关系换位、某个谜团获得新解释、能力意义变化、阵营或世界事实改变。强 payoff 往往还有 narrative afterlife：旧目标完成后，其结果自然成为新承诺、新敌人、新生活问题或第二层解释。
Variants：- 身份暴露：安全表层生活关闭，关系和敌我同时重写。
- 牺牲/死亡：结算追捕或冲突，同时生成复活、继承、独立行动或新敌人。
- 旧物终局用途：同时结算谜团、身份与能力来源。
- 生活性仪式被大冲突劫持：婚礼、约战、重聚同时结算关系和旧敌。
Guidance：不要求每次凑齐五栏。判断一个 thread 是否真的参与碰撞：移除它后，这个事件的选择、结果或后续可行性是否会改变？
Failure Modes：- 角色都到场但因果互不相干。
- 为了“大高潮”塞入尚未成熟的线。
- payoff 只关旧问题，不留下任何后续状态。
- 强制每个高潮都要求多线合流。

使用边界：迁移共享因果铰链与 narrative afterlife；碰撞强度由共同选择实际改写了多少线程的未来来决定。

### Inspiration 2
source: mechanisms/reunion-reentry-v3
type: mechanism
score: 0.0912

可用抽象：Creative Problem：角色离开很久、被误认、身份变化甚至曾被认为失去后，怎样让归来本身成为 delayed payoff，而不是一见面就恢复原状？
Mechanism：第一次接触先暴露时间造成的不匹配：外貌、能力、气质、身份、价值判断、伤痕或团队中的新空位。通过旧物、旧动作、共同记忆、能力习惯、称呼或只有双方理解的反应逐步确认。认出彼此后仍保留至少一个当前现实障碍，并用一个新的共同动作、合作方式、边界或承诺证明“这个人重新进入了关系，但不是回到过去”。
Variants：- 互相认不出：成长本身成为重新确认的障碍。
- 公共死亡后的秘密归来：活着并不等于能恢复旧社会身份。
- 团队重聚：先看见缺席与变化，再通过当前压力重新磨合。
- 复活/恢复：真正 payoff 落在重新回应、照护和重新参与行动，而不是状态栏恢复。
Reader Payoff：长期缺席积累的期待，通过肉眼可见的变化和关系重新选择一次性兑现；读者既得到“终于回来”，又得到“回来以后已经不一样”。
Guidance：不要用等级汇报替代重逢；不要让所有人瞬间无缝认出。把回归者的新状态放进当前冲突中验证。
Failure Modes：- 出场即拥抱，时间没有留下痕迹。
- 只报新能力/等级，没有关系重新确认。
- 重逢抹掉离队、死亡或身份变化造成的后果。
- 场景结束后没有新的合作入口或关系边界。

使用边界：只迁移“变化后重新辨认→仍有障碍→重新进入关系/行动”的结构，不迁移源角色或具体回归方式。

### Inspiration 3
source: mechanisms/departure-vacancy-v3
type: mechanism
score: 0.0912

可用抽象：Creative Problem：角色离队、失联、沉眠或暂时不可用后，怎样让这次缺席真正改变后续故事，同时允许长线自然沉睡而不是频繁提醒？
Mechanism：离开前先让人物完成一个符合自身欲望的决定、期限、拒绝、交接或目标；离开后尽快用一个新的选择、失败、机会或敌人反应证明“旧状态已经结束”。有人会第一次自己行动，有人失去过去可依赖的选择，有人会利用空位，也可能有人因此获得新的自由。若 Canon 已有期限、物件、缺席位置或未完成承诺，可以把它作为召回器，然后允许人物长时间退出主镜头。
Variants：- 主动离队证明自己：离开源于人物自己的目标，回归时以行动证明变化。
- 保护者/核心人物离场：留下者开始重新决定怎么活、怎么行动。
- 沉眠/失联：共同目标拆成其他人物自己的长期行动。
- 群像换挡：旧中心离开后，配角不是接班工具，而是各自沿自己的欲望继续。
Reader Payoff：读者真正感到“这个人不在了”，同时拥有一个可记住但不需要每章提醒的长期期待。
Guidance：Dormancy 不是遗忘。保留一个高辨识召回器即可；下一次提醒最好来自当前事件重新碰到旧期限、旧物、缺席位置或人物留下的实际后果。
Failure Modes：- 告别很长，但离开后什么都没变。
- 每隔几章机械提醒“他还在外面成长”。
- 留下者自动无摩擦接替全部功能。
- 还没形成缺席感就立即回归。

使用边界：只迁移“离开→空位/新选择→长线沉睡/召回”的因果，不迁移具体离队理由或回归奖励。

### Inspiration 5
source: mechanisms/hidden-identity-long-v3
type: mechanism
score: 0.1702

可用抽象：Creative Problem：隐藏身份怎样跨长篇维持而不靠强行藏答案？揭露后怎样真正改变当前故事？
Mechanism：先让表层身份独立成立并积累真实后果：朋友、爱情、债务、名声、信任与社会位置都是真实的。线索应尽量同时兼容旧解释与新解释；揭露落在人物正在行动的碰撞点，并立刻关闭或改写一条现实路径，例如安全身份失效、继位失败、归乡目标改变、某人开始被追杀。揭露重解释过去，但不删除过去。
Variants：- 长期潜伏者。
- 异类/血脉身份。
- 多个真实社会自我。
- 错误预言/公共误读逐渐追上现实。
Reader Payoff：“原来如此”与“接下来怎么办”同时出现；过去的普通场景获得第二层意义，而当前关系不能再按旧方式继续。
Guidance：设计隐藏身份时先写清：表层生活为什么能长期工作；哪些线索在旧解释下也合理；揭露会关闭什么现实选择。
Failure Modes：- 线索从一开始就只支持真相解释，角色长期看不见显得失智。
- 揭露只补背景，不改变当前选择。
- 宣布是假身份后把此前关系全部清零。
- 为反转而多层套娃。

使用边界：《斗罗大陆》《诡秘之主》《将夜》直接支持长期隐藏身份/身份重释；《修真聊天群》只提供“公共误认逐渐追上现实”的邻近证据。迁移揭露后的关系与行动变化，不把公共误认等同于长期潜伏身份。
