# EXPERIMENT REVIEW｜私人原型 × Reader-facing Power × 前五章

## 结论

这轮实验对“新书从零生成时，世界与能力是否还会重新变成难懂抽象术语”这个目标，可以判 **PASS**。

对“匿名私人原型是否已经真实进入剧情因果”可以判 **DIRECTIONAL PASS / 明显成立但仍有一处投影损失**：被有分量的人看见、获得自己的钱与身份、对新地方和新机会的偏爱，已经真实改变顾临川的选择；陆绾也不是陪衬，而会改变他的路线。但 Human Seed 中很明确的感官审美与身体吸引，在前五章 Primary prose 中明显被压淡，关系现场更容易退成工作边界与条件对话。

这轮没有发现需要在 Writer 端继续增加“少术语”补丁的证据。

## 实验链

固定匿名私人原型：`prism-wanderer-alpha`。它只投影 Appetite / Behavior / Relationship 的选择偏向，不迁移现实身份、履历、地点或真实关系对象。

完整链：

`World(Luna high) → Power(Luna high) / Human(Luna high) → blind Power Selector(Luna high) → deterministic Character → Story Program(Sol high) → Outline(Luna high) → 5 × [Director Luna high → Curator Luna high → Primary Terra high → State Luna low]`

Power Novelty seed 在生成前固定为 `2026082800`，没有看输出后重抽。三个候选分别是“截取别人招式最关键的一步 / 延后一场死亡 / 分出另一个自己并让经验回流”；盲选器完全看不到 Human，最终选择第三个“分影”。

## 新世界是否还是术语词典

没有。

World 的核心规则先直接成立：

> 人把自己的影子练成可以承受力量的实体，用它攻击、防御、移动和强化身体。

之后才使用少量短名：`影阶 / 影刃 / 影身`。这些词都只是压缩已经看懂的东西，不需要 `A 新词 → B 新词 → C 新词` 才能解释。

一到五阶也都给可观察效果：一阶是影刃/绳索/挡击；二阶覆体挡刀箭、牵引攀爬；三阶能维持多件影器并短距借影换位；高阶再扩大到街巷和战场。强弱尺在世界和正文中都可以直接比较。

五章正文额外检索 `结构 / 受力 / 路线计算 / 验证 / 诊断 / 流程 / 权限 / 分析`，命中为 0。更重要的是直接阅读也没有发现换一种词继续做同类工程推理。

## Core Power 是否仍然直接

盲选后的能力是一句话可懂的：

> 顾临川能把自己的影子分成第二个完整的自己；两边可以同时战斗、修炼、学习，重新合并后两边的经历都会回来。

Permanent Boundary 同样直接：最多一具影身；距离和光线有限制；影身受伤与消耗不会白送，合并后回到同一个身体；影身被撕裂会反噬。

前五章没有把它重新写成“先分析影子结构才可使用”。第4章是最危险的回归点：折日峡的光线把影子照乱，Director 只允许顾临川做一次短暂分影比较，Primary 也只写了“左侧影子连续、右侧正在被光切断 → 立刻收影 → 告诉姚谦边界”，随后马上推进商队入峡和异兽逼近，没有展开成测绘/验证流程。

## 前三章闭环

第一章不是发现能力后停住。影刃失控即将伤到场边人员时，顾临川第一次真正分出第二个自己：影身挡刀，本体击倒对手。现场马上有一阶比较——普通一阶只能把影子做成短刃、绳索或一次挡击，两具完整身体同时行动不是同层常规能力。顾临川赢下公开考核，并被姚谦要求在契券中正式记录异常。

第二章把震撼变成保留收益：顾临川选择公开能力，实际用双身同时守住两处位置并应对事故，得到正式低阶护卫身份、商盟印记契券和第一笔真正由自己支配的钱。

第三章再把收益投入下一轮人生行动：他以“铜羽商队正式护卫”的身份离开客舍，不再只是替家里跑腿；陆绾明确保留自己的送药顺序，顾临川仍选择同行。章末驿站失联，商队必须绕行折日峡。

所以前三章是：

`能力真实结果 → 社会重新估价 → 身份/钱 → 离开原生活位置 → 新世界入口`。

不是“发现 → 再确认 → 再测试”。

## 人格真的改变了什么

最成立的是“被有分量的人看见”。第一章能力刚暴露，顾临川听见人群真正叫自己的名字时，得到的满足明确不是抽象成长，而是终于不再只被当作客舍里会记账的人。第二章签契券时，他主动问“按这个本事用，价钱也按这个本事算？”——他并没有默认把能力藏到底，也没有被系统统一成低调安全型主角。

“自己的钱 / 自己的身份”也成立。第一笔预付款在正文里有重量：那不是家里账桌上的钱；第三章他把带商盟印记的契券拿给父母看，明确说这次不是替客舍送货，而是自己作为护卫出发。

陆绾也真实改变选择，但没有吞掉人物。她的药有自己的截止时间和工作顺序，顾临川没有把她自动收编成主角队伍；第五章异兽袭击时，顾临川优先保住药车、伤员和具体的人，放弃最值钱的货箱，这个选择同时来自现场人命、陆绾这条具体关系和他的能力无法包办两边，而不是“主角必须道德正确”的抽象宣言。

## 个性化仍然损失在哪里

Human Seed 中还有两股很鲜明的私人牵引：对空间、器物、声音、触感等审美/感官兴趣，以及对具体人的身体吸引。这些东西在 Story Program 中仍被承认，甚至明确写成顾临川可能为漂亮古兵、新地方和陆绾改路。

但在前五章正文里，Primary 对这部分明显变淡了。

尤其第3章是天然可以出现少量身体/感官牵引的场景：顾临川与陆绾在客舍门口正式谈同行，Human Seed 已经明确他们之间的身体吸引和五日同行经验。最终正文主要写成：

> “你的药按你的顺序走 / 我守我的商队。”

这让关系因果是成立的，却更像两个理性工作伙伴在划边界。对“这是顾临川为什么愿意和**这个具体的人**一起走”呈现不足。

这不是要求每章塞情欲，也不是把所有 Human motive 做成 checklist。问题只在于：**当前场景本来就自然触发了这条已经批准的关系牵引，但 Curator / Primary 没有把它投影出来。** 后续值得单独定位是 Outline 没排到、Curator 没保留，还是 Primary 把私人/身体动机自动净化成了更安全的工作逻辑；不应为了这一个样本立刻在 Writer 堆新规则。

## 正文层真实瑕疵

第一章只有 1624 个正文字符，但事件完整。旧实验 helper 原本硬要求正文不少于 1800 字符，导致流水线误报失败。直接读稿后确认章内现实危险、能力真实结果、同层比较、社会反应、人物欲望与章末选择都已完成，因此删除的是**临时实验脚本的任意长度阈值**，正文没有为了过门槛灌水。production validator 没有被改动。

第二章末尾“半个时辰后离开客舍”与前文“明日出城”初读容易产生时间误解。State 最终解释为“半个时辰后离开客舍去城门附近集结，明日正式出城”，第三章也按这个事实执行，因此不是 Canon 硬矛盾；但文字层可以更清楚，例如直接写“半个时辰后带车去城门集结”。这是一个小的 reader-clarity 瑕疵。

第二章为了证明双身可以同时守两个位置，先安排两辆必须分别看守的车，随后又发生角马冲车事故，戏剧设计感略明显。它仍产生了身份与预付款的真实新状态，所以没有退化成“换证据再证明一次能力”；但作为正文体验，它比第一章和第五章更像为机制展示搭出的场面。

第4章总体是成功的 World Entry：没有百科式补课，折日峡“多方向光线使人的影子错位”先通过车夫和地面异常直接出现，随后才让顾临川亲身确认分影边界。

第5章是目前五章中最强的动作章。能力既产生爽感又不能包办目标：顾临川可以两处同时行动，却因距离、错乱光线和本体承压必须放弃一部分货物；结局真正改变商队状态，且自然把观日宗和更深峡谷拉进下一章。

## 最终判定

**Reader-facing ontology / Power concreteness：PASS。** 这是本轮最主要的验证目标，真实五章没有回归。

**前三章早期兑现 / 复利：PASS。** 能力 → 名声 → 契券/钱 → 离开原生活位置，状态持续向前。

**Supporting Logic 不成为 Story Engine：PASS。** 第4章最接近路线验证，但被压缩到一次决定性使用，故事马上进入环境限制与异兽冲突。

**Human → Choice → Story Route：PASS。** 顾临川不是换一个名字也完全相同的标准男主；公开暴露、自己挣钱、离开家庭身份、接受陆绾的独立工作路线都由其私人牵引参与。

**完整 Personality Realization in prose：DIRECTIONAL PASS。** 选择层已经成立，但感官审美与身体吸引在前五章 prose 中投影偏弱，尤其陆绾场景被理性工作语言压平。这是下一轮最值得观察的残余，而不是“再加更多人格字段”。
