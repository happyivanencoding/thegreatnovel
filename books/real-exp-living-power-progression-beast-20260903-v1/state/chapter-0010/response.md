# Proposed Active Scene State

地点：折鹤岛锚台外侧。  
在场人物：贺临川、照雪、钟砚、顾槐、悬灯城人员、围观岛民。  
即时伤势：贺临川右肩擦伤、双掌磨裂；照雪右后腿伤口重新渗血，行动受限。  
手中关键物品：乌金回脊索、半页《苏渠旧契》、白脊首航候补木牌。  
当前敌人或追兵：暂无确认追兵；悬灯城正在抽取折鹤岛辅助浮力。  
当前倒计时：下一次换风前必须验候补位；锚台下沉与索桥、工坊支柱损坏正在加剧。  
下一步直接目标：处理辅助锚链抽力造成的锚台与家中工坊危机。  
当前主动目标：保住折鹤岛及家中工坊，同时决定是否保留白脊首航候补位。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
乌金回脊索已被贺临川掌握基本收紧与缓冲用法；当前伤势仍限制发挥。

### Active Relationships

照雪｜继续追踪沉瓦气味并与贺临川协同行动｜保持主动合作｜右后腿伤势未愈。  
贺母｜维持汤摊与家中工坊｜与贺临川保持直接照料和约束关系｜交出积攒工钱支持其购买白脊首航候补位。  
钟砚｜执行悬灯城抽取折鹤岛辅助浮力｜与折鹤岛居民形成直接利益冲突｜已压下抽力扣，导致锚链与索桥承压。  
顾槐｜向岛民公开旧账册｜与悬灯城处于公开账目争议关系｜已在锚台组织岛民查看浮力、索税与修补账目。  
段阙｜携黑漆木匣旧物撤离｜与主角处于线索争夺关系｜行踪暂时不明。  
唐鹭｜未取回目标旧物并失踪｜与主角的路线和旧契线索仍有未决关联｜行踪暂时不明。

### Identity / Access

贺临川获得白脊首航候补位；须在下一次换风前验位，船出航后候补费不退。

### Knowledge / Enemy State

折鹤岛辅助浮力被悬灯城抽取后，锚台与外缘索桥将先承压；贺临川家中工坊已有支柱裂开。  
白脊首航北侧风口与半页《苏渠旧契》上的风箭路线接近，但并非完整路线。

### World State

悬灯城开始在主浮根持续下沉期间抽取折鹤岛辅助浮力，锚台下沉、外缘索桥异响、工坊支柱开裂，折鹤岛公共交通与居住结构受到直接影响。顾槐已公开旧账册，引发岛民与悬灯城的现场账目争议。

### Tracked Assets

乌金回脊索｜贺临川｜随身携带｜可用于稳定、缓冲和协同行进｜第8章取得。  
半页《苏渠旧契》｜贺临川｜随身携带｜仍未解读完整｜本章用于购买白脊首航候补位。  
白脊首航候补木牌｜贺临川｜随身携带｜候补位，须换风前验位｜以多年工坊工钱换得。  
油布包裹旧物／黑漆木匣｜段阙｜随身撤离｜已被带走｜第8章明确转移。

# Proposed Chapter Summary

贺临川带着受伤的照雪回到折鹤岛，得知悬灯城将在主浮根下沉时抽取辅助浮力。他用母亲交给他的工钱和半页苏渠旧契换得白脊首航候补位，却在锚台看见钟砚压下抽力扣、工坊支柱随之裂开，顾槐也公开旧账册质问悬灯城。
