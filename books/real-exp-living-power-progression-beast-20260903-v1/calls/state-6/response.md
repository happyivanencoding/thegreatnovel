# Proposed Active Scene State

地点：鸣骨峡旧栈道、半塌石门下方。  
在场人物：贺临川、照雪、唐鹭、叶朔；附近有百巢商盟护卫。  
即时伤势：贺临川右臂割伤、肩部擦伤、胸口撞伤；照雪右后腿未愈，行动踉跄。  
手中关键物品：半页《苏渠旧契》；唐鹭持完整旧航契；短绳已解下。  
当前敌人或追兵：无新确认追兵；峡内巢崖迁移造成即时危险。  
当前倒计时：旧风门开启，巢崖正在沿高层风道移动；商盟副链压住数只未起飞幼兽。  
下一步直接目标：沿照雪登上的岩脊行动，处理被副链压住的幼兽并追查沉瓦。  
当前主动目标：救出受困幼兽，继续追踪沉瓦。

# Proposed Persistent Canon

### Power / Capability

Current Power Position｜主尺：共鸣级｜精确位置：1  
已与照雪稳定完成引脉、借势和短促回弹配合；共鸣级一只能应急借力，无法正面抗衡共鸣级二十六；伤势限制当前发挥。

### Active Relationships

照雪｜主动追踪沉瓦并进入迁移中的巢崖｜与贺临川保持真实合作但不受其控制｜已拒绝唐鹭的带离路线｜继续共同追踪沉瓦。  
唐鹭｜跟随贺临川进入旧栈道｜与贺临川仍为交易对手，暂时共同面对峡内变化｜完整旧航契和商队座位的交换未成立。  
叶朔｜开启旧风门并警告巢崖迁移｜栖脊宗成员，与贺临川暂无直接关系｜其开门行为已改变峡内局势。

### Identity / Access

贺临川与照雪仍具备登记为正式共鸣者、进入短程风路和低危矿场的条件；尚未完成登记。离开折鹤岛的商队座位未取得。

### Knowledge / Enemy State

唐鹭确认段阙追索的是可被送入王庭兽库的特殊幼兽；照雪正追踪峡内沉瓦气味。旧风门开启后，巢崖开始迁移，商盟副链压住数只幼兽。

### World State

叶朔开启鸣骨峡旧风门，冷风改变栈道与索台状态，交易车辆滑移；巢崖沿高层风道迁移，峡内兽群开始密集鸣叫。

### Tracked Assets

半页《苏渠旧契》｜贺临川｜胸前收好｜残缺｜继续持有。  
完整旧航契｜唐鹭｜手中｜可与半页契印对合｜未转移。  
旧短褂｜贺临川｜身上｜完好、略宽大｜继续持有。  
短绳｜鸣骨峡旧栈道附近｜石台/岩缝旁｜已解下，未明确转移｜贺临川为追踪照雪解除拴缚。

# Proposed Chapter Summary

唐鹭以完整旧航契和白脊方向的商队座位换取照雪，并透露段阙想把它送入王庭兽库。照雪选择追踪峡中的沉瓦气味，贺临川随之进入旧栈道，唐鹭也跟随其后。叶朔开启旧风门，导致巢崖迁移、交易车滑移，照雪登上升起的岩脊，而商盟副链压住了数只幼兽。
