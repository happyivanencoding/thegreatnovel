# Proposed Active Scene State

- 当前地点：天未亮，三号废器堆外的封存木牌与验器台附近；沈砚和唐鹭刚从封死支巷撤回，账册、空铁盘仍在原处，木匣里的钝锉沾有地火灰。
- 在场人物：沈砚、唐鹭。霍沉不在现场，但其传令已通过矿道和镇灵阵传达；下一班矿奴正等待被送入中央矿脉。
- 即时伤势：沈砚脚踝旧伤在撤退时被碎石再次顶到，腕骨曾受中央牵引；自身灵力近枯竭。唐鹭腰伤未愈，掌心擦伤重新裂开。
- 手中关键物品：无名回收护腕仍在腕下；回收片已从护腕取下并藏回袖中；旧炉籍环、账册、空铁盘和木匣在身边。账册已写入指向北侧/西支线的假维修记录，并用三道受力浅痕暗记真正的回收路、可拆车骨和地火阀门位置。
- 当前敌人或追兵：霍沉仍在追查九号车异常修补与废料账目缺口，已宣布中央矿脉提前蓄能、三日内封死旧矿道，并禁止私自检修、离班和带走废器；中央镇灵阵及持续向阵眼塌陷的废支道也是当前直接威胁。霍沉尚未确认护腕的具体构造。
- 当前倒计时：废支道随镇灵阵脉动继续塌陷，下一轮脉动可能填死来路并让门后回收路重新被阵眼认领；霍沉的全面旧道封锁期限为三日。
- 下一步直接目标：利用假账册让霍沉先查错路，争取最多一晚；随后在三日封锁前返回封死支巷，保住窄门门栓和车骨下的回收路，利用可拆车骨与每八次沉脉开启一格的地火阀门，做出能让里面被同节拍锁定的人群脱离中央回路的通道，而不是只保留两人的出口。

# Proposed Persistent Canon

- 沈砚能通过接触器物和脉动听见回收路及受力关系；可施展引砂诀，并能用护腕从附近散灵、车轮余温和残留回收路中回收极少量灵气，沿原有受力方向施展修补诀。第三章中他修复了旧矿车滑轮和窄门门栓各一次；护腕不能凭空补充灵力或材料，连续两次修补后只剩针尖大小余灵，不足再支撑一记修补诀。
- 回收片接入护腕后可把散乱牵引收束成只够指路的细线，并暂时压低九号车残留回收路向阵眼的泄漏；断开时仍会受到中央阵眼向下的强牵引。回收片、无名回收护腕、旧炉籍环仍在沈砚手中。
- 唐鹭已从掩护、藏片发展为实际共同探查和救援协作：她知道回收路、护腕和阵中异常，能协助承重、守门并同意返回；双方仍未完全摊开全部秘密。她的腰伤未愈，掌心擦伤已再次裂开。
- 中央镇灵阵的三层回路已确认：矿脉灵气负责供给，矿奴炉印负责把人固定在同一节拍，地底天工遗构负责承受并向阵眼下方传送力量。阵中的呼吸仍各自存在，但被强行同步；下一次蓄能时，留在阵中的人会先被抽干。被困者不止一人，具体人数和身份未确认。
- 阵壁下方的地火阀门仍在工作，每八次沉脉会向旁边让出一格，短暂露出通往更深处的入口。窄门门栓用于压住向外泄漏的回收路；门旁旧矿车的三根承重骨中，贴阵壁的一根不能动，靠近地火阀门的一根可以拆下，最外侧一根可在不影响回收路的情况下暂时承重。
- 沈砚仍是受太衡炉宗炉籍与回收制度约束的烬脉矿场矿奴，且被霍沉固定在三号废器堆监管；他已秘密违背旧道封锁、不得私自检修和不得带走废器的命令，并在账册中制造了可误导霍沉的假维修方向。霍沉仍未掌握护腕的具体构造。

# Proposed Chapter Summary

沈砚与唐鹭借九号车残留回收路进入封死支巷，修复被岩层压住的旧矿车滑轮和窄门门栓后抵达中央镇灵阵边缘，确认矿脉供给、炉印锁定与地底天工遗构承压构成向下回路，阵中有多个被同一节拍锁定的矿奴且下一次蓄能会先抽干他们；霍沉传令三日内封死旧矿道，二人撤回三号废器堆，沈砚在账册上制造假维修方向以拖延追查，并决定返回筹备让里面人群脱离中央回路的通道。

# Proposed Open Promises

- 霍沉对九号车异常修补、废料账目缺口和沈砚的异常行动仍在追查；假维修记录能否把他引向错误路线、护腕是否会暴露尚未兑现。
- 中央镇灵阵与回收体系的三层回路关系已经确认，但阵眼下方的地底天工遗构究竟是什么、完整的向下回路通向何处，以及护腕和回收片为何会被其牵引仍未揭示。
- 无名护腕后续还能从有限散灵中回收多少、两次以上修补的间隔与代价仍未确定；当前余灵不足以立即再施一记修补诀。
- 封死支巷内被炉印同步锁定者的具体人数、身份和身体状态仍未确认；如何让他们脱离中央回路并避免下一次蓄能抽干仍未解决。
- 旧矿车可拆车骨、窄门门栓、保留回收路与地火阀门构成的救援路径尚未做成；沈砚与唐鹭能否在废支道彻底塌陷及三日旧道封锁前返回并扩大出口仍未兑现。
