# State Delta Audit

- 旧 Active Scene State 的现场已结束：正式正文将行动推进至九号运输车脱离塌方并返回三号废器堆；当前不再是七号旧道塌方外侧，霍沉也不再处于要求伸手查验的当场步骤。
- 霍沉完成搜身但未确认护腕的具体构造；他改为把沈砚留在三号废器堆，在账册和炉耗监管下逐块清点废器。旧的即时查验状态应替换为这一持续监管状态。
- 正文确认护腕第二次回收散灵，并将回收来的力量用于连续两次修补：承重骨和一小段断轨都借原有废铁接合，没有新增材料；修补后力量已只剩最后一线并随之降温。旧 Canon 对护腕后续总量、持续性和代价的未知仍未完全解决。
- 尚不能确定修补诀可处理的范围、持续时间和灵力成本；不能确定回收片所指封死支巷内的对象、同步呼吸的来源，也不能确定镇灵牵引与该支巷脉动是否同源。唐鹭腰部伤势仍未明确。

# Proposed Active Scene State

- 三号废器堆最外侧、封存堆口与验器台附近，天色已暗，沈砚正在被迫清点废器。
- 沈砚和唐鹭在场；霍沉及两名收炉役已经离开当前堆口，但监管命令仍在生效。
- 沈砚脚踝被落石擦伤，手指和掌心因连续修补而发木，灵力已近枯竭；唐鹭腰部伤势仍不明，手掌有擦伤。
- 无名回收护腕藏在旧炉籍环与袖口下，已接通的回收片藏在沈砚袖中；旧炉籍环、账册、空铁盘和修车木匣在身边。
- 霍沉是直接控制者：三号废器堆已封存，沈砚必须逐块查验并按炉耗登记，矿场镇灵与回收体系以及中央矿脉分班命令构成持续压力。
- 没有可量化的时间限额；中央矿脉开矿钟已经响起，下一班全部转入中央矿脉、旧支巷封死的命令已经宣布，霍沉可继续复核账目与废器。
- 在不暴露护腕与回收片的前提下，先与唐鹭避开当晚中央矿脉分派，确认钉死支巷后成片同步呼吸与深层脉动的来源以及可进入路径。

# Proposed Persistent Canon

- 沈砚能通过接触器物和近处脉动听见未断的灵路、回收路并判断废器是否仍有复用可能；会施展引砂诀；已证明可以用回收来的少量散灵施出修补诀，沿原有受力将断裂的承重骨和短段旧轨暂时接合。
- 引砂诀会迅速耗尽自身灵力；护腕只能从附近已经散掉的残灵中回收极少量，不能凭空补充灵力或新增材料。本章第二次回收只够支撑九号车上的两次紧急修补，后续总量、间隔和代价仍未知。
- 唐鹭已实际掩护沈砚、藏下回收片并注意到封死支巷中的同步呼吸；她知道异常器物和回收路的存在，双方形成实际协作但仍未完全摊开秘密。
- 沈砚拥有无名回收护腕，材料为废铜、破阵盘薄片和妖兽晶核，现藏在炉籍环下；旧炉籍环仍是他的身份器物；从旧阵盘剥下的回收片已在袖中重新接通，能够指向一条被钉死的深处支巷。
- 沈砚仍是烬脉矿场、受太衡炉宗炉籍与回收制度约束的矿奴；霍沉已将他固定留在三号废器堆监管。
- 矿场镇灵阵能够沿旧回收路重新牵引并认领器物；断灵矿车在接入新的回收路后仍能短暂移动；回收片接通后指向七号旧道更深的封死支巷，那里传出成片、同一间隔的呼吸，但支巷内的对象尚未确认。
- 尚无正文确认的长期伤势。
- 霍沉确认九号车在无对应废料消耗的情况下绕过塌方，已明确怀疑沈砚并把查验、清点和账册控制收紧，但尚未确认护腕的具体构造；唐鹭处于实际协作一侧，立场仍未完全摊明。

# Proposed Chapter Summary

霍沉搜身并封存三号废器堆后，将沈砚调去修理载有七名矿奴的九号运输车；沈砚第二次用护腕回收散灵，连续施出两道修补诀，借原有废铁修复承重骨和断轨，使矿车避开塌陷的主巷并解救车内矿奴。霍沉无法用废料账解释修补结果，遂把沈砚留在三号废器堆逐块清点；唐鹭暗中留下旧阵盘回收片。夜间，沈砚重新接通回收片，白光指向七号旧道深处一条封死的支巷，二人听见其中成片同步的呼吸；霍沉同时宣布下一班全部转入中央矿脉，沈砚要求唐鹭当晚不要前往。

- 镇灵阵和矿场回收体系对护腕的牵引来源、牵引后果，以及它与七号旧道更深脉动的关系尚未揭示。
