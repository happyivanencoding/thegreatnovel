# State Delta Audit

本章正式正文与旧 CANON INDEX 无直接事实冲突。断镐在第1章崩毁后仍留下可用残片，并被重新嵌入粗铁铸成裂路器，是同一事件的后续，不与“断镐崩毁”冲突。

无法从正式正文确定的状态：

- 裂路器及其所承载的锋意能否在后续稳定复用、还能使用几次、具体代价是什么，尚未确定；本章只证明了本次两次敲击开路。
- 旧矿图所指的旧炉路是否确实能熔断封炉印，尚未验证。
- 火流、宗门封钉和废窟出口封锁还剩多长时间，正文没有给出可量化的短时限。
- 最终进入侧道的矿工人数及多数矿工的具体伤势未确定。

# Proposed Active Scene State

- 当前地点：废弃炼器窟外门内、由侧炉开出的狭窄侧道深处；众人已越过第二道裂隙，前方冷风通向矿图所指的真正废弃炼器窟，后方侧炉和来路正被火流与宗门封锁收紧。
- 在场人物：沈燧、阮青禾，以及已经选择继续前进的一批矿工；具体人数未由正文确定。
- 即时伤势：沈燧右臂自肩至指尖仍然麻木，掌心灼裂纹持续发亮并曾亮至腕骨，肩部伤势未进一步确认。随行矿工中至少一人脚踝烫伤，其他人的矿尘、咳嗽和擦伤未逐一确认。
- 手中关键物品：沈燧左手持裂路器——由侧炉粗铁、残火和断镐残片铸成的短厚偏刃铁锥；锥尖仍完整但靠近火流的一面已软化发黑，器身多出细痕。阮青禾持旧矿图，图上显出通往更深废窟的路线。沈燧仍未取得灵矿。
- 当前敌人或追兵：裴照川与玄烬仙宗回收队在后方封钉、落印并封死通往废窟的出口；裴照川已将沈燧记为“失控器修”。他暂未进入侧道，但仍在执行封锁和活捉后的回收控制。
- 当前倒计时：火流已逼近侧炉并持续倒灌，宗门封钉正在收窄来路和封闭废窟出口；必须在火流与封锁彻底切断深处路线前行动。具体剩余时间未确定。封炉令规定的三日清空矿脉、熄灭矿火和按册撤离期限仍在继续。
- 下一步直接目标：沿旧矿图和墙上的旧凿痕继续进入真正的废弃炼器窟，寻找仍在发热的炉心以及可能熔断封炉印的旧炉路，同时让随行矿工通过侧道，避免被火流和封锁截断。

# Proposed Persistent Canon

- 沈燧的能力已有第二次明确表现：断镐残片中的锋意可在残火与粗铁中形成裂路器，并引导敲击沿既有旧凿痕开裂；本章第一次敲击开出石壁裂路，第二次敲击撕开薄封钉并扩大侧道。
- 裂路器是当前持久资源，由侧炉粗铁、矿镇残火和断镐残片铸成；锥尖尚完整但已局部软化发黑并出现细痕。它不能阻挡倒灌炉火，后续耐久度和使用代价未定。断镐本体已毁，沈燧仍未取得灵矿。
- 右臂麻木和掌心灼裂纹仍在，裂纹会随裂路器和炉火发亮并牵连至腕骨；是否会恢复或造成更长期损伤未定。
- 沈燧与阮青禾保持共同突围、互相执行判断的协作关系；阮青禾协助辨认矿图、引导火口和带领矿工，尚未证明更深关系。
- 玄烬仙宗已将沈燧列为异常器物关联者，并在见到裂路器后由裴照川记为“失控器修”；裴照川与回收队正在封锁废窟出口并继续追索。
- 封炉令仍使黑炉镇矿脉处于关闭、清空和撤离周期，封炉阵此前出现的逆纹仍未解释。
- 旧炼器窟的外门并非终点。旧矿图在火光下显出与旧凿痕重合的路线，指向更深处真正的废弃炼器窟；路线尽头存在仍有炉火和缓慢回响的炉心。该炉心的性质、用途以及是否存在能熔断封炉印的旧炉路尚未确认。

# Proposed Chapter Summary

裴照川带回收队以封钉封住来路并逼迫沈燧交出断镐残片，倒灌的火流又将矿工逼回侧炉；沈燧借残火、粗铁和断镐残片铸成裂路器，沿旧凿痕两次敲开石壁和薄封钉，带阮青禾及一批愿意跟随的矿工进入更深侧道。裴照川将他记为“失控器修”并封锁废窟出口；火光显出旧矿图通往仍有炉心发热的真正废弃炼器窟，沈燧一行随即继续向深处前进。

- 本 Pilot 的实验范围仍只允许运行至 Chapter 3。
- 封炉令规定的三日清空矿脉、熄灭矿火和矿工撤离期限尚未结束，其后果尚未发生。
- 旧炼器窟外门周期性呼吸的地火、深处炉心的来源与用途，以及外门和真正废弃炼器窟之间的关系，尚待揭示。
- 旧矿图显示的路线是否准确，深处是否确有能够熔断封炉印的旧炉路，尚待验证。
- 封炉阵出现逆纹的原因及其与沈燧、断镐、裂路器或废弃炼器窟的关系尚未确定。
- 沈燧掌心灼裂纹和裂路器锋意的触发条件、耐久度、代价及后续能否继续开路，尚待确认。
- 裴照川及玄烬仙宗已封锁废窟出口；沈燧、阮青禾和随行矿工如何突破封锁并应对后续追索，尚待发生。
