# State Delta Audit

- 旧 Active Scene State 将旧矿图前方的路线概括为直接通向真正废弃炼器窟；本章正文明确阮青禾此前看错，三道斜痕是旧通风门门框，真正路线在门后先向下、再贴着炉壁走。队伍随后经旧排灰道回到岔台，并已确认真正窟口。
- 旧 Persistent Canon 记载裂路器锥尖仍完整；本章正文明确锥尖崩掉一小块，器身细纹继续增加，能否再敲尚未确定。
- 旧 Persistent Canon 将深处炉心的存在和发热状态列为未确认；本章正文已确认真正窟口后的深处仍有炉火，炉心会回应火鳞胚。炉心的来源、用途及与封炉系统的关系仍未确定。
- 正式正文无法确定原先随行矿工的准确人数、最终分组及各自完整伤势；无法确定当前火流和封钉收紧还剩多久；也无法确定火鳞胚要补足什么、裂路器是否还能继续工作，以及三道炉路中可行路线的最终状态。

# Proposed Active Scene State

- 沈燧一行当前位于侧道外较宽的岔台，靠近经旧排灰道连接的真正废弃炼器窟石拱入口；入口已经确认，但尚未正式深入炉窟。
- 在场有沈燧、阮青禾、五名刚从旧通风道救出的炉工及原先随行矿工。五名炉工全部存活，其中三名伤势较重留在岔台，另两名熟悉炉温的炉工准备随沈燧和阮青禾进入；原先矿工的准确人数未确定，至少三人负责留守岔口，愿继续前进者可跟随。
- 沈燧右臂仍从肩至指尖麻木，已难以抬起；掌心灼裂纹曾亮到腕骨并烧回指根，肩头和衣物有被熔渣、热浪灼焦的痕迹。五名炉工中至少一人右脚或脚踝严重烫伤，年长炉工的手掌被热地面灼伤，三名伤势较重者不适合继续进入高温处；其余伤势未逐一确定。
- 沈燧左手握着已出现细纹、锥尖崩掉一小块的裂路器；阮青禾持旧矿图，图上新亮出一条从火鳞胚通向深处炉心的未完成引火线；火鳞胚已包在沈燧衣襟内。此前用于分流火潮的焦黑火鳞已经在掌中化为细灰。
- 裴照川和玄烬仙宗回收队在外部封锁：三处上层通路、废窟外门和侧门都在落印或已被封钉。裴照川的当前意图是封住能出来的地方，把沈燧一行困在窟内，并未进入炉室直接追击。
- 火流已经从侧道和炉室下方抬高，红光逼近岔台；真正窟口后的炉心仍一下一下回应，封钉声还在继续。封炉令规定的三日清空、熄火和撤离期限尚未结束，距离火流或封锁彻底切断路线的具体时间未确定。
- 下一步是带着能走的人沿已确认的旧排灰道和窟口进入真正废弃炼器窟，依火鳞胚指向寻找炉心，处理接往炉心的烧毁火脉，同时让三名伤势较重的炉工和其他不能继续者留在较安全的岔台，避开外部封锁。

# Proposed Persistent Canon

- 沈燧已证明能用裂路器沿旧凿痕打开旧通风门和倒悬废炉闸；裂路器由残火、粗铁和断镐残片铸成，现已器身多裂、锥尖崩角，是否还能继续开路及其使用代价未定。
- 沈燧握住焦黑火鳞后，曾借出一层半弧形暗红鳞光，把猛烈火潮分向两侧，形成仅供数人通过的窄路；这片火鳞的承火力量已经耗尽并化为灰，未留下完整器物。
- 沈燧持有一枚掌心大小的火鳞胚，焦黑表面有两片未合拢的鳞片，根部连着烧白炉壳。它能在旧矿图上显出通往仍有回应的炉心的未完成引火方向，但本章没有发生真正传火。
- 沈燧右臂麻木和掌心灼裂纹持续存在，使用裂路器及火鳞力量会牵动、加深灼痛；伤势能否恢复或造成长期损伤仍未定。
- 沈燧与阮青禾保持高信任的协作关系，双方已经形成由阮青禾辨路、读炉温和组织人员，沈燧执行开路与承受火势的配合方式，尚未证明更深关系。
- 被困旧通风道的五名炉工已被救出且存活；其中两名熟悉炉温并愿意进入窟内，三名伤势较重留在岔台。年长炉工确认石拱后是真正炉窟，并提供了三道炉路的旧知识：第一道烧断，第二道被熔渣压住，第三道过去只有炉监能走。
- 旧矿图通往真正废弃炼器窟的路线已被修正并确认：三道斜痕是旧通风门门框，门后先下行、再贴炉壁，经旧排灰道可绕回窟口。真正窟口门槛没有宗门封纹，留有从炉心方向伸出的断续引火痕。
- 真正废弃炼器窟深处仍有活动炉火和炉心回应；火鳞胚的红线可以接到炉心，但炉心的来源、用途及其与外门火流、旧炉路和封炉阵的关系尚未确认。
- 玄烬仙宗仍将沈燧视为异常器物关联者；裴照川已从单纯封锁外门升级为封住上层通路、外门和侧门，意图把沈燧一行困在废窟内。
- 封炉令的三日清空、熄火和撤离周期仍在进行，封炉阵逆纹的成因及其与沈燧、断镐残片、裂路器和废弃炼器窟的关系仍未解释。

# Proposed Chapter Summary

封炉震动抬高火流，沈燧和阮青禾依据修正后的矿图打开旧通风门与倒悬废炉闸，救出被困的五名炉工。沈燧借焦黑火鳞短暂分流火潮，代价是火鳞化灰、右臂伤势加重，裂路器也崩掉一角。队伍经旧排灰道回到岔台，取得一枚尚未完成传火的火鳞胚；火鳞胚在矿图上连出通往仍有炉火回应的深处炉心的方向。裴照川封闭上层通路、废窟外门和侧门，沈燧、阮青禾及两名熟悉炉温的炉工决定带能走的人进入真正废弃炼器窟。

# Proposed Open Promises

- 本 Pilot 的实验范围仍只允许运行至 Chapter 3。
- 封炉令规定的三日清空矿脉、熄灭矿火和矿工撤离期限尚未结束，最终后果尚未发生。
- 深处炉心为何仍有火、其用途和来源是什么，以及它与外门周期性火流、旧炉路和封炉阵的关系，尚待揭示。
- 旧矿图通往真正窟口的路线已经确认；窟内三道炉路的可行状态，以及是否存在能够熔断封炉印的旧炉路，尚待验证。
- 封炉阵逆纹的原因及其与沈燧、断镐残片、裂路器或废弃炼器窟的关系，尚未确定。
- 火鳞胚尚未完成传火；它需要补足什么、能否把烧毁的火脉接到炉心，以及完成后会产生什么结果，尚待验证。
- 沈燧掌心灼裂纹和裂路器锋意的触发条件、使用代价、裂路器剩余耐久度及沈燧伤势的长期影响，尚待确认。
- 裴照川已封闭多条外部通路；沈燧一行能否在封锁和火流中抵达炉心，并保留可撤出的路线，尚待发生。
