第四章　黑市余波

排水道出口的冷风贴着墙根打转。公告上“报名”两个字还没有看仔细，身后的水声又响了一次。

马赫的人还在排水道里。

林砚把米拉拉到墙影下。再往下层逃，是旧管廊、废井和数不清的分岔，米拉撑不住第二夜；逃得越远，铁钉帮越认定他藏着值得追的东西。他把公告按回墙上，转身朝旧升降桥的方向走。

“去哪？”

“回黑市。”

米拉看了他一眼，没有再问。

回去的路要穿过一段废管廊。林砚走在前面，专挑灯少、堆货高的地方绕，两次停下来听身后的动静。追兵的吆喝还留在排水道那一带，没有人往旧升降桥的方向搜。米拉的呼吸慢慢稳下来，手却一直攥着他的袖口。

旧升降桥阴面的黑市比白天安静，摊主的灯一盏一盏熄下去，只有葛宁的铁板后还亮着一盏。看见两人湿透的裤脚，葛宁的手停在法器上。

“铁钉帮在追你。”

“马赫在后面。”林砚说，“我要找的不是马赫。”

葛宁听懂了。他把灯压低半寸，声音压得更低：“今晚有人从井口方向一路问到排水道。问话的不是马赫的人，是钉四的人。你要等他，就站在这儿等。”

林砚站到铁板前。

“那枚火符还在？”

葛宁从货堆底摸出那只旧布包，隔着铁板按住，没有推过来。

“你卖了它，又回来找它？”

“钉四要看痕迹。”林砚说，“今晚要谈的也不是火符。你把它留着，别出手。”

葛宁盯着他看了两息，把布包压回货堆。

冷风从废管堆里灌出来。黑市里收摊的人都朝这边看过一眼，又飞快移开。

脚步声从窄道另一头传来，不急，也不慢。马赫的声音先到：“在那儿！”

“站住。”另一个声音更平，却把前一个压住了，“在这里动手，等于替他把消息再传一遍。”

来的人个子不高，袖口磨得发白，左手缺了小指。他在铁板前站定，先看米拉，再看林砚。

“钉四。”葛宁低声说。

钉四没有理会葛宁。

“火符的来源，查清了。”他说，“旧炉区的维修废料，一枚失效符。你在葛宁摊上修好它，卖出去，它只烧了三息。马赫要的是方法。我要的也是。”

“方法用不了第二次。”林砚说，“不信，看一眼那枚符。”

钉四朝葛宁抬了抬下巴。葛宁把布包打开，火符躺上铁板。红光熄了，符骨却完整。

林砚翻过符骨，指向末端一道发黑的窄缝。

“这道缝是我留的。回流只能接一次，第二次往符骨里压法力，它就从这里崩。”他说，“三息不是我收手，是符骨只撑得住三息。”

钉四俯身，指甲刮过那道焦痕。

“铜丝呢？”

“烧断了。”林砚说，“接回流的铜丝撑不过一次。你找得到同样粗的丝，也找不到第二道能接它的槽。”

林砚又从工具箱里取出烧黑的火符残片，放在铁板上。半面符骨焦脆得像一片枯叶。

“井里用它开路，连点了六次，这是剩下的。现在连一粒火星都点不出。”

“一枚符，修一次，废一枚。”钉四直起身，“我要你的眼睛有什么用？”

“眼睛只能看，不能教。”林砚说，“拆开讲，也是一枚符一条路，换个符就换条路。你要的如果是能传出去的方法，它不存在。你要的如果是废符还能不能再活一次——整个第七下层，只有我这双眼睛认它们。”

窄道里静下来。马赫站在两步外，风刃在指间聚了又散。

“说价。”钉四说。

“先做一件事。”林砚说，“旧炉区把供热恢复。”

马赫嗤了一声：“你替穷人讨暖气？”

“我替我自己的渠道讨。”林砚没有看他，“旧炉区停炉，废符、废件全冻在原地，没人拆，也没人收。炉子点起来，那里才有不断流出来的废术式。我接触它们，你们看着。这是我的价。”

钉四盯着他看了一会儿。

“旧炉区不归铁钉帮管。”

“管道归。阀门在你们手里。”

马赫的脸色变了一下，却没有开口。

钉四没有立刻回答。他把目光转回黑市窄道。几个摊主装作收摊，正往这边看；他一个一个看回去，那些人便低下头，手里的动作快了几分。他这才收回视线。

钉四伸手，把铁板上的火符和残片一起收进布包，系好，推到林砚面前。

“东西收好。下一次修复，我们看着。”他说，“修成了，旧炉区的阀门今晚就开。修不成，井里的事，重新算。”

他从怀里摸出第二样东西，放在铁板上。

那是一枚巴掌大的炉芯，芯面结着一层灰白的霜纹，像很久没有见过火。

“旧炉区第三座炉的芯。停摆半年，没人敢碰。”钉四说，“今晚它点不亮，旧炉区还会有人冻死。”

米拉往前挪了半步，站到林砚身侧。

林砚伸手按住炉芯。霜纹底下的回路没有一丝温度，像一段被冻住的河。

他收回手。

“先看。”

钉四转身走进窄道的暗处。马赫盯了林砚两息，跟了上去。

葛宁直到脚步声散尽，才把铁板上的布灰抹掉。

“钉四看上的东西，”他低声说，“还没有能退回去的。”

林砚没有接话。他望着那枚停摆的炉芯——旧炉区今晚还会有人冻死，这句话不是威胁，是期限。

林砚收回布包，压进工具箱底层。

他扣上工具箱。

“走。”他对米拉说。

“去哪？”

“先回棚屋，拿导法丝。”

米拉点头，又摸了摸衣襟里的药瓶。瓶里的药还剩大半，省着用，能再撑几天。她把药瓶按回原处，快步跟上。
