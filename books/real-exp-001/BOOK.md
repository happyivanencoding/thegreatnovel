# 小说总体设计画像

## 0. 本书成长基因图

### 作者明确保留
传统奇幻成长爽文。

主干：
识别失效术式
→ 修复并掌握
→ 实战验证
→ 学院/猎团身份
→ 更高术式与遗迹。

创新主要放在缺失条件可视化、动态战斗改写和术式组合。不要改成纯管理或纯谜团小说。

### 核心组合
失效术式识别 × 条件修复 × 动态战斗改写 × 学院/猎团身份 × 遗迹探索。

### 关键变量
术式缺失条件、修复稳定度、法力负荷、已掌握术式、战斗构筑、学院评价、猎团权限、遗迹坐标和身体承载力。

### 转换网络
读取缺失条件 → 修复低阶术式 → 形成可重复施法 → 反推术式语法 → 改写战斗用途 → 实战胜利 → 获得学院权限 → 接触复杂术式 → 进入遗迹并获得新语法。

战斗反馈 → 发现术式缺陷 → 改进构筑 → 新的战斗优势。
学院身份 → 获得老师、资料和任务 → 进入遗迹 → 带回新术式。

### 循环族
主循环是失效术式修复与实战验证；辅助循环是学院/猎团身份循环和遗迹探索循环。主循环负责持续能力成长，辅助循环负责提供新场景、关系、权限和规则。

### 阶段变异
前15章是贫民区术式修复与第一次生存兑现；16—35章转为学院试炼和战斗构筑；36—60章转为猎团任务和遗迹探索；61—80章转为术式组合与浮空城危机；81—100章转为古代术式语法和更高世界入口。

### 核心不变量
主角每次学会新术式，都必须在具体场景中改变他能做什么；作者明确的成长主干持续保留；术式修复不能变成无成本万能答案。

### 退化风险
学院内容变成解释设定；每次战斗都只是换一个法术；遗迹只提供新技能而不改变主角的理解和行动方式。

## 1. 核心类型与读者承诺

本质是传统奇幻成长爽文。前期读者追主角如何修复失效术式、保护贫民区并获得第一次实力提升；中期追他如何在学院和猎团试炼中把术式变成独特战斗体系；远期追他如何进入遗迹、理解古代术式语法并获得更高世界的通行权。读者持续期待主角从被术式体系排除的底层人，变成能够改写术式并影响世界层规则的强者。

## 2. 世界观结构

浮空城由城顶学院与法力主阵、中层商贸和升降桥、第七下层贫民区、外环碎石带与云海下方的废弃结构组成。学院控制完整术式图谱和修行准入，上层家族控制法力井、浮力晶矿和主阵权限，城卫厅控制升降桥与天穹护罩，猎团负责城外遗迹和危险任务。

术式的基本语法只有几种核心关系：条件决定术式何时、向谁和以什么方式生效；媒介承载并放大法力；回路让法力按顺序流动；承载结构限制一次施法能承受的负荷；回流或确认条件则负责让多余力量返回、让术式结束或进入下一步。普通人看到的是亮不亮、能不能发动，真正的术式师还要判断这些关系是否完整。林砚的特殊之处不是凭空看见答案，而是能在术式出现异常时察觉某个关系像被挖走了一块。

当前最重要的力量路线有三条。标准术士依靠完整图谱建立稳定循环，擅长以较低风险重复施放成熟术式，学院和上层家族掌握最多；工匠与术式构筑者依靠媒介、回路和承载结构解决复杂装置，单次爆发不一定强，却能改变术式的用途，维修队和部分学院研究者走这条路；城卫与猎团施术者把术式放进移动、地形和队伍协作中，重视临场条件、短时组合和生存判断。遗迹研究者不是独立的更高等级，而是通过古代语法、残缺规则和未知媒介进入另一种成长方向。

正常人的成长不是换一串等级名称。第一阶段是感知法力，能分辨法力是否存在；第二阶段是建立循环，能让力量安全经过身体或媒介；第三阶段是掌握稳定术式，能独立完成一种可重复的能力；第四阶段是理解条件关系，能在不同环境调整术式而不立刻失控；第五阶段才是组合或构筑，能让多个术式、媒介或施术者共同完成过去做不到的事。学院或猎团提供的是训练、媒介和进入更高问题的资格，但身份不能替代这些能力质变。当前时代的变化是外环碎石带扩大、护罩老化、下层被主阵权限切断，而学院更换新阵却不愿修复旧术式。

## 3. 世界如何持续制造剧情压力

贫民区的基础术式正在失效，学院名额被上层家族控制，猎团任务会暴露施法者的真实能力，浮空城之间存在资源和航路争夺，遗迹中的旧术式会主动改变环境。主角越频繁修复术式，越容易被学院、猎团、竞争者和遗迹守卫注意。

## 4. 主角模型、人物弧与核心矛盾

主角最强欲望是摆脱底层身份，让妹妹米拉不再依靠失效的贫民区护罩生活。稳定决策模式是观察缺失条件、做最小修复、隐藏完整能力、在高压场景验证、把胜利转成身份和新术式。人物弧从底层修补工到学院试炼胜者、猎团核心施法者、术式构筑者和遗迹语法继承者。核心矛盾只保留一个自然问题：他越能改写术式，越需要决定哪些力量可以被公开。

能力历史必须保持连续：林砚小时候并不能完整看见“缺失条件”，只能隐约察觉术式哪里不协调、哪里像少了一块，所以维修时比普通人敏锐，却无法理解缺失内容，也无法凭此重构术式。第一章碎石雨中，他第一次真正看见“回流确认”这样的抽象条件，这是能力的第一次质变。后续能力可以在剧情中自然发展为看见破损、看见缺失条件、看见条件关系、反推术式语法、动态改写、组合与创造，但这不是预设的万能成长链。

## 5. 配角与关系系统

米拉是主角的情感锚点，直接让主角的成长有现实目标；莱恩是出身优越的学院竞争者，先轻视主角、再承认其战斗判断；奥林是退役术式师，提供语法线索但不替主角解决问题；维拉是猎团队长，提供危险任务和现实检验。关系可以承担信任、竞争、师徒、保护、嫉妒和重新评价。风险是老师变成说明书、竞争者只负责失败、米拉只作为被保护对象。

## 6. 核心情节发动机

主循环：发现失效术式 → 修复条件 → 掌握新用途 → 在具体危机中验证 → 获得学院/猎团权限 → 接触更复杂术式。辅助循环一：同辈轻视 → 主角隐藏底牌 → 实战胜利 → 外界重新评价。辅助循环二：遗迹任务 → 获得旧语法 → 改变术式构筑 → 新任务。每次运行改变术式对象、施法环境、对手、身体负荷和世界层级。

## 7. 叙事结构

主要使用贴近主角的第三人称；必要时切换巡查员、竞争者或猎团成员视角，展示他们如何重新评价林砚。前期以场景叙事为主，世界信息通过生活事实、维修、对话和危机进入；后期才用少量总结连接城市层级和遗迹。

### 第一章开篇策略
作者明确选择讲述者宏观开场：世界远景 → 浮空城上下层 → 权力与术式 → 下层居民的位置 → 护罩正在恶化的时代危机 → 镜头收束到林砚正在维修报废护罩。只解释前30章读者需要的部分，不提前揭示上层遗迹真相。

## 8. 文风与可操作参数

目标单章约2000—3000中文字符；短到中等段落；高信息密度；环境描写服务于术式条件和危险；对话用于试探和博弈；战斗要写施法顺序、条件改写和临场选择；每章推进一个明确变化。禁止用说明书替代场景，也禁止所有角色都像主角一样分析。

## 9. 对话特点

主角说话克制，先问条件再承诺；米拉直接、具体、会指出主角逃避的问题；莱恩礼貌但带竞争；奥林喜欢用反问测试理解；维拉短促、重视行动结果。对话承担任务交换、身份试探、战斗前判断、师徒边界和态度反转。

## 10. 节奏结构

单章完成一次发现、选择、施法或结果；约十章完成一个局部术式/身份闭环；大型块改变施法对象、战斗规模、地图或世界理解。小兑现是修复和新用途，中兑现是试炼胜利和新术式，大兑现是遗迹突破和公开改写术式；兑现后产生新的法力负荷、敌人或世界入口。

## 11. 主题、价值观与长期问题

故事赞赏理解规则、主动选择和把被拒绝的能力变成新道路。它警惕出身垄断、把术式当身份门槛、只会背诵规则却不能处理真实危机。主角相信能力应该通过实际结果获得资格；主题来自术式、学院和遗迹的运行，不强行追加伦理惩罚。

## 12. 当前设计最强点与最弱点

最强点是“缺失条件识别”同时连接能力、战斗、学院和遗迹。最弱点是术式解释可能过重、莱恩可能功能化、遗迹可能只变成技能仓库。写作时防止主角每次都提前知道答案、战斗只换法术名称、妹妹只承担动机，以及后期脱离最初的术式逻辑。

# 未来100章大型剧情块

## 第1—15章：贫民区的失效术式

具体发生：主角在浮空城底层修补公共护罩，发现法阵不是法力不足，而是缺少一个被学院删掉的条件。他冒险补出临时护罩，救下米拉和一批居民；随后在黑市施法器交易中用同一能力修复一枚失效火符，并在追捕中用火符改变逃跑路线。
阶段结果：主角掌握“看见缺失条件”的能力，完成第一次稳定施法，贫民区获得短暂保护；但学院开始追查护罩异常。
叙事功能：建立作者主干，第一次让读者看到能力直接改变生存和战斗。
成长基因路径：失效条件识别 → 低阶术式修复 → 生存空间扩大。
推向下一块：主角必须进入学院试炼，才能接触更完整的术式语法。

## 第16—30章：学院试炼与动态战斗构筑

具体发生：主角报名学院底层奖学试炼，莱恩认为他只是贫民区修补工。主角修复一套残缺的风刃术，把缺失条件改成短距连续触发；试炼中他先隐藏真正的施法方式，再利用场地中的断墙和风向击败高一阶对手。学院导师奥林发现他不是背诵术式，而是在重写术式条件。
阶段结果：主角获得学院学徒身份，掌握第一套可重复战斗构筑，莱恩从轻视转为竞争；米拉获得学院附属区的安全居住权。
叙事功能：完成第一次公开实力证明，把底层能力转成学院身份和战斗优势。
成长基因路径：术式修复 → 战斗构筑 → 试炼胜利 → 学院权限。
推向下一块：学院要求主角参加猎团任务，证明他的术式不是只适合训练场。

## 第31—45章：猎团任务与失效魔兽

具体发生：维拉带队进入城外浮岛，调查一群魔兽体内失效的防护术。主角发现魔兽不是被污染，而是进化术式缺了一段共同条件；他修复其中一只幼兽的防护，让它带队穿过风暴区。猎团内部有人想把幼兽卖给学院，主角必须在任务奖励和队伍信任之间做选择。
阶段结果：主角获得猎团正式权限，学会在移动、战斗和队伍协作中动态改写术式；他得到一枚指向旧遗迹的术式碎片。
叙事功能：让术式能力从个人对决扩展到任务、队伍和非人规则。
成长基因路径：术式修复 → 生态/战场理解 → 猎团权限 → 遗迹线索。
推向下一块：术式碎片显示，学院现行法术来自一套被人为删改的古代语法。

## 第46—60章：下层遗迹与双重施法

具体发生：主角与维拉、莱恩和奥林进入下层遗迹，遗迹会把同一条术式拆成两种互相矛盾的条件。主角先修复一扇门，再将风刃和护盾的缺失条件叠加，形成可以移动的防护斩击。遗迹守卫不允许任何人带走完整语法，主角必须用一条临时规则骗过守卫，并在出口处击败抢夺碎片的学院队伍。
阶段结果：主角获得双重施法能力、古代语法残页和一件能够储存术式条件的法器；学院对他的能力从招揽变成争夺。
叙事功能：改变术式的组合方式，让能力不再是逐个修复，而是组合和改写。
成长基因路径：遗迹探索 → 古语法 → 术式组合 → 新战斗体系。
推向下一块：浮空城上层发生术式崩坏，主角必须把遗迹知识带回现实城市。

## 第61—80章：浮空城危机与术式构筑

具体发生：上层浮空城的动力核心出现大范围术式断裂，学院和贵族法师互相推诿。主角发现动力核心缺少的不是一项条件，而是一组能够让不同术式共享法力的连接规则。莱恩带学院学徒守住外环，维拉带猎团进入核心区，主角在两支队伍之间不断改写术式连接，使原本互相冲突的护罩、推进和攻击法阵同时运行。
阶段结果：浮空城得以维持，主角被承认为术式构筑者，米拉和贫民区居民获得迁入安全层的资格；但主角也被更高层势力盯上。
叙事功能：把个人能力扩大为城市级行动能力，完成一次大规模公开兑现。
成长基因路径：术式组合 → 城市危机 → 组织协作 → 构筑者身份。
推向下一块：动力核心暴露出一条通往上层世界的古代入口。

## 第81—100章：第一语法与上层遗迹

具体发生：主角进入动力核心后的上层遗迹，发现现行术式体系只是古代第一语法的残缺版本。守护遗迹的古代术式要求施法者同时承担记忆、法力和身份条件；主角不能靠单独修复解决，只能让米拉、莱恩、维拉和奥林分别承担不同条件。外部贵族法师在遗迹入口发动争夺，主角把队伍的术式和遗迹规则连接，完成一次所有人都认为不可能的联合施法。
阶段结果：主角掌握第一语法的一部分，获得进入更高世界的通行权；他的核心能力从修复失效术式发展为重新组合术式条件，但也承担被更高层势力追踪的长期压力。
叙事功能：完成从底层修补工到上层术式构筑者的阶段性跃迁，打开新的世界层，而不是结束在学院资格或城市职位。
成长基因路径：古代语法 → 多人条件组合 → 上层入口 → 更高世界问题。
推向下一块：上层世界存在另一套术式规则，主角必须决定是继续修复旧语法，还是创造自己的术式体系。

# 未来十章逐章小纲

## 第1章：下层护罩的缺口

具体剧情：主角在贫民区修补公共护罩，发现法阵并不是法力不足，而是缺少一个被学院删掉的条件。护罩即将崩溃时，他冒险补上最小条件，短暂挡住从浮空城外坠落的碎石雨。
结果 / 状态变化：贫民区暂时安全，主角确认自己能看见术式缺失条件，但身体承受了第一次法力反噬。
叙事功能：在场景中展示能力和主角的主动选择。
结尾推动：学院巡查员发现护罩出现了不属于现行法术的连接痕迹。

## 第2章：不能登记的火符

具体剧情：主角为了给米拉买药，拿一枚失效火符到黑市出售。买家发现火符无法点燃，主角读取缺失条件后当场补完，却故意只让火符燃烧三息。
结果 / 状态变化：主角赚到第一笔钱，米拉得到药物；黑市买家记住了他的修复方式。
叙事功能：完成第一次明确利用，让能力同时改变生活和市场位置。
结尾推动：买家说有人正在寻找会修复失效术式的人。

## 第3章：三息火焰

具体剧情：追查火符来源的地痞到贫民区索要术式，主角带米拉逃进废弃升降井。地痞封住出口后，主角使用未出售的火符残片连续短爆，利用热流打开侧门，带米拉脱身。
结果 / 状态变化：主角第一次用修复后的术式改变战斗和逃生结果，米拉开始相信哥哥真的能保护她。
叙事功能：把“修复术式”连接到行动优势，而不是停留在说明。
结尾推动：逃出排水道后，在出口附近看到下层公开试炼报名公告。

## 第4章：黑市余波

具体剧情：林砚带米拉回到黑市，发现钉四已经查到火符来源，却没有立刻交出修复方法。他用三息火留下的痕迹证明自己只能做一次性修复，并要求铁钉帮先让旧炉区恢复供热，换取继续接触废术式的机会。
结果 / 状态变化：主角保住能力秘密，获得一条可以重复接触失效术式的黑市渠道；铁钉帮从追问方法转为观察他的下一次修复。
叙事功能：承接升降井逃生，把第一次战斗兑现转成可持续的低层行动空间。
结尾推动：钉四拿出一枚停摆的炉芯，说明旧炉区今晚还会有人冻死。 

## 第5章：炉芯里的第二个条件

具体剧情：林砚检查铁钉帮送来的炉芯，发现它不是缺火，而是缺少让热量均匀回流的条件。他拒绝直接修好整座炉子，只补出一段能撑过一夜的回路，并让阿铆按他的顺序重新装回炉芯。
结果 / 状态变化：旧炉区恢复短时供热，林砚第一次让别人按照自己的术式判断协作；他的身体负荷增加，修复能力的限制也被钉四看见。
叙事功能：把能力从个人操作扩展到可复现的协作过程。
结尾推动：炉芯恢复后，灰银凝温片出现同样的回流缺口。 

## 第6章：凝温片的用途

具体剧情：林砚在棚屋里拆解葛宁送来的凝温片，发现它能把一次性热量储存到媒介中，却缺少释放条件。他先用小片凝住米拉的药液，再在洗矿场的漏水管旁验证它能短暂保存热量。
结果 / 状态变化：主角获得第二种可重复用途，能够把修复后的术式保存而不是立即消耗；米拉开始参与测试，而不是只等待被保护。
叙事功能：推进能力纵向成长，并改变前几章只靠临场施术的玩法。
结尾推动：学院巡查员到第七下层调查护罩异常，要求查看最近维修记录。 

## 第7章：巡查员的记录

具体剧情：学院巡查员瑟琳带人检查东廊，林砚故意只展示标准紧固和旧线替换，不承认自己看见过“回流确认”。瑟琳却从护罩残痕中发现一条学院图谱没有的连接，转而询问米拉和维修学徒。
结果 / 状态变化：林砚暂时保住能力秘密，但学院正式把东廊列入观察区；米拉第一次主动替哥哥挡住一个不该回答的问题。
叙事功能：让身份暴露压力进入主循环，同时强化兄妹关系的行动性。
结尾推动：瑟琳留下下层试炼公告的副本，说明下个月会开放一个报名名额。 

## 第8章：风行纸

具体剧情：林砚用修复炉芯换到一张被学院淘汰的风行纸，发现它缺少的不是速度，而是落地时重新稳定身体的条件。他只把风行纸修成一次短距横移，在废弃排水沟中测试，第一次感到自己可以把不同术式的条件联系起来。
结果 / 状态变化：主角获得一个尚未成熟的移动术式，行动空间从固定平台扩大到复杂地形；风行纸只能使用一次，不能替代修炼。
叙事功能：为学院试炼的战斗构筑埋下能力基础，但不提前进入试炼。
结尾推动：黑市有人认出风行纸来自学院旧仓，开始向钉四打听林砚。 

## 第9章：一次公开救援

具体剧情：第七下层的维修平台突然断裂，林砚用凝温片暂存热量、用风行纸改变落点，先把两名孩子送到安全台，再修复平台边缘的承载条件。围观居民第一次亲眼看见他用两种失效术式完成连续行动。
结果 / 状态变化：林砚获得贫民区居民的信任和一笔公开报酬，但铁钉帮与学院都确认他已经能组合使用不同术式。
叙事功能：完成第一次不靠擂台的外界反馈，把能力价值转成社会位置。
结尾推动：学院公告正式写明，报名者必须提交一项可重复施放的术式。 

## 第10章：报名之前

具体剧情：林砚没有立即进入学院，而是先把风行纸的条件写成一份只够报名使用的简化版本，拒绝中介购买完整修复方法。瑟琳允许他提交下层报名申请，却提醒试炼要等到第16章后的正式阶段才开始。
结果 / 状态变化：主角获得学院试炼的报名资格，米拉继续留在第七下层；他还没有身份跃迁，却拥有了明确的下一阶段入口。
叙事功能：把第1—10章收束在贫民区能力复利和报名准备上，与第1—15章大型块保持一致。
结尾推动：报名材料要求林砚在接下来几天公开演示一项稳定术式，铁钉帮也准备在演示前逼他交出方法。
