# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”。他的纳灵体质不能稳定留住普通灵气；他能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 裂路器的锋口已经钝化，但已反复证明能沿已有裂口剥开旧铸层、熔渣、旧铁、旧楔和封炉锚根部；本章又以同一限制打开南侧、东侧及中央交口的封炉连接。它没有恢复连续切割，进一步使用条件、边界和代价仍未知。
- 火鳞胚已铸成沈燧第一件真正属于自己的下品道器“火鳞器”。它能在有限时间内托住并分开高温火流，但连续使用会加重沈燧右掌和右臂的伤势；本章结束时器物未碎而彻底暗下，只剩灰红烧痕和微弱温度，当前不能再分火或承热，能否恢复、再用及其长期边界和代价仍未知。
- 黑炉镇下层三座公共废炉通过旧炉槽、东侧通风井和南侧矿车线形成了已被实际验证的连通退路；第二、第三座封炉锚及中央交口被沿既有裂口剥开后，三座炉按顺序重新点亮，封炉印的三处内部连接熔开缺口，暂时不能再把三炉扣回原位。镇外墙总门和完整封锁火线仍是独立的外部阻断，三炉退路不能绕过它。
- 旧火能够借助重新打开的旧槽、风路和炉轨在三座公共废炉之间传递并依次复燃，但旧火持续工作的完整根因、三炉更深处的连接和封炉印的完整抽火与转压机制仍未揭示。传火后的空炉在无新燃料、炉壁不完整时仍可能积热爆裂。
- 未完成炉心内部的红线会寻找接合处；在五名炉工持续托持、抬高并对准旧槽时，它曾短暂沿炉心与旧铁的纹理接上交口，使第二座余火传向第三座，但没有进入沈燧身体、没有完成，也没有成为沈燧的稳定力量。炉心仍需炉工托持，完成条件、长期作用、与三座炉网络的关系及代价仍未知。
- 沈燧右掌灼痕已裂至肘侧并会在承受火力时出血发亮；左肩旧伤被回火灼重，右肩有封炉热伤，连续使用火鳞器使腕臂承压加剧；腹腔热意不稳定，本章未再次出现，不能替代普通灵气体系或承担炉心重量。
- 阮青禾与沈燧已形成以现场判断、路线分工、开路、守井和人员转移为核心的实际协作；五名炉工、矿工及部分居民已在两座废炉的开路和撤离中协同工作。居民中至少有一名原本要求交人的人转为实际护人、推车和维持撤离秩序，但黑炉镇居民整体仍未形成长期盟约。
- 玄烬仙宗和裴照川已确认沈燧能够驱动异常器物；沈燧本人、火鳞器、未完成炉心及其使用过的炉路和炉法仍是回收或封存目标。裴照川所执行的炉权令明确要求毁掉未完成炉心、保住黑炉镇矿权，并允许以封死旧炉路作为强制手段。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火；正文已进一步确认封炉印将在今夜闭合，但确切剩余时间仍未知。
