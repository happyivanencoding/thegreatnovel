# State Delta Audit

- 旧 CANON INDEX 的 Active Scene State 仍记录左侧封锁符封死退路、回收队从岔口左侧及后方逼近；本章正式正文已明确左侧封锁符被回火烧裂，裴照川率回收队沿上层检修道转至炉心前封截，旧项必须替换。
- 正式正文未确定封炉令三日期限的剩余时长、原有队伍的精确总人数、窟心炉心及传火闸的完整机制、炉心后检修门通向何处、裂路器的剩余可用性与进一步代价、火鳞胚能否完成传火及其代价，以及队伍能否在反烧和封截中脱身。

# Proposed Active Scene State

- 当前地点：废弃炼器窟窟心外围的分火环、环形石台内侧。队伍已沿外环通过空炉，窟心炉心位于中央；炉心前方有被炉砖从内部顶住的传火闸，后方还能看见被炉砖卡住的检修门轮廓。
- 在场人物：沈燧、阮青禾、原有矿工、腿伤者、胸口伤者、额头伤者，以及五名已获救并轮换扶持伤者的炉工。裴照川和玄烬仙宗回收队在炉心前、断裂引火链另一侧的上层检修道封截窄口。
- 即时伤势：沈燧右掌灼痕已从腕侧裂到肘边并持续出血；右臂黑色裂痕在承受过境炉火时从腕骨至肘侧发热，短时热意已经熄灭并回缩一截；左肩旧伤再次被回火灼重。腿伤者、胸口伤者和额头伤者仍需扶持，队伍整体尚未被火流分开。
- 手中关键物品：沈燧左手持粗糙裂路器，锋口在剥开熔渣后出现暗哑钝痕，当前不能继续连续切割；沈燧仍持有火鳞胚，外层完整，暗红细纹已经散乱但仍偏向被炉砖顶住的传火闸；阮青禾持符灯。
- 当前敌人或追兵：裴照川已带回收队封住炉心前的窄口，明确要求回收炉心和火鳞胚；回收队可沿已开启的上层检修道转移和封截。
- 当前倒计时：传火闸后连续炉鸣，闸前空炉向内抽火，两条断裂引火链把剩余火线反向汇向闸口；外环火已越过沈燧鞋尖并沿环槽向队伍卷回，下一次火势推进前的处理时间具体未知。封炉令的三日期限仍未确定剩余时长。
- 下一步直接目标：在反烧火线冲散队伍前压住或重新导开外环火，处理被炉砖卡死的传火闸和最后断口，保住火鳞胚并避开裴照川的封截，为继续接近检修门或找到生路争取通道。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”；他的纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定力量来源。他能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 由烧红粗铁和黑铁锋片锻成的粗糙裂路器已被证明可以切开石壁、薄型封钉、旧通风门、倒悬废炉闸、分火环的两枚旧铁扣，并沿已有裂口剥开堵塞引火槽的熔渣；它仍不能直接切开火流。最新使用后锋口出现明显钝痕，不能继续连续切割；剩余可用性、触发条件和进一步代价仍未确定。
- 沈燧的黑铁锋片已不再嵌在掌心。右掌灼痕已从腕侧裂至肘边，右臂黑色裂痕曾在承火时发热并随后回缩，左肩旧伤被回火进一步灼重；这些状态尚未构成稳定的力量来源。
- 火鳞胚仍是尚未完成传火的器物，外层保持完整、暗红细纹尚未接成回路。它已被证明能够在接触过境炉火时改变火流角度，并将旧火沿分火环和引火槽导向空炉；空炉仅亮起三息便未能稳定，火鳞胚的完成方式、可用作用和代价仍未确认。
- 阮青禾能够辨认旧炼器窟的通风门、炉闸、分火环和传火顺序，并与沈燧形成基于现场判断、路线指引和伤者转移的临时协作。五名炉工已获救并能协助扶持伤者；原有矿工与伤者可以互相扶持，但尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认裂路器能够再次驱动，知道沈燧具备驱动异常器物的能力，并将其列入“失控器修”的追查记录；裴照川已将窟心炉心和火鳞胚一并列为回收目标，并能利用上层检修道实施封截。
- 窟心炉心仍在发热，空炉短暂受火后会把火线经两条断裂引火链抽向被炉砖卡住的传火闸；炉心后方还存在一扇被炉砖从内部顶住的检修门。炉心的性质、持续燃烧原因、断裂引火链和传火闸的完整机制，以及检修门后是否存在出口，尚未确认。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火，确切剩余时间尚未确定。

# Proposed Chapter Summary

第4章：沈燧一行在窟心回火与封锁夹击下，阮青禾辨认出分火环，沈燧先后切开压住分火环的两枚铁扣，并以火鳞胚承接和导引旧火，使队伍沿外环通过，回火烧裂左侧封锁符，旧炉砖也开启了上层检修道。沈燧随后沿已有裂口剥开堵塞引火槽的熔渣，让旧火流入空炉；空炉亮起三息，显出窟心炉心、两条断裂引火链和被炉砖顶住的检修门，却没有稳定燃烧，反而把火线抽向被卡死的传火闸。裴照川率回收队封到炉心前，沈燧右掌灼痕裂至肘边，裂路器锋口出现钝痕，火鳞胚仍未完成传火，外环反烧在结尾逼近队伍。
