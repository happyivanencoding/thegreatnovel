# State Delta Audit

- 旧 Active Scene State 已被正式正文推进并替换：队伍已打开旧通风门、救出五名炉工，切开倒悬废炉闸，穿过热道，现位于旧矿道岔口；左侧外路被新封锁符封死，右侧仍通向窟心。
- 旧 Persistent Canon 中“裂路器本章只证明两次驱动”已不再成立：本章正文又确认它切开旧通风门和倒悬废炉闸；对火墙的直接切割仍失败。
- 正式正文不能确定三日期限的剩余时间、热流和封锁抵达岔口的具体时长、原有矿工总人数与全部伤势；也不能确定火鳞胚的完成条件、作用边界、代价，或窟心炉心的性质及是否存在出口。

# Proposed Active Scene State

- 队伍位于旧矿道岔口，刚从废炉热道的暗口撤出；左侧外路已被新钉封锁符封死，右侧残图刻线仍通向窟心深处。
- 在场有沈燧、阮青禾、原有矿工和伤者，以及刚从旧通风门救出的五名炉工。原有队伍的精确总人数仍未确定。腿伤者在岔口左侧干石上，胸口伤者靠墙喘息，额头伤者已重新扎紧布条；五名炉工均已出来并能协助扶持伤者。
- 沈燧右掌有取出锋片后留下的伤口和被火鳞灼出的弧形红痕，右臂黑色裂痕从肩下暗至肘侧并仍在收缩；左肩旧伤在热浪中加重。他已因热浪和火墙冲击明显受损，但仍能行走。
- 沈燧左手持粗糙裂路器；裂路器已切开旧通风门和倒悬废炉闸，不能直接切开火墙。火鳞胚被布包住并由沈燧护在身前；此前用于分开火流的焦黑炉鳞已经在撤离后碎灭。
- 玄烬仙宗回收队仍由裴照川指挥，已封住岔口左侧并沿侧门布置更深的封锁，意图把队伍逼向窟心；左路的封锁符和逼近的火线是当前后方威胁。右侧深处仍有持续发热的炉火。
- 近程倒计时是左侧火线和封锁继续逼近岔口、压缩队伍行动空间的时间，具体时长未知；封炉令规定的三日期限仍在，剩余时间未知。
- 下一步直接目标是沿右侧残图刻线继续向窟心深入，保持伤者、五名炉工和原有矿工不被火流分开，并确认火鳞胚所指的通路或用法，在封锁和回火彻底截断行动前寻找生路。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”；他的纳灵体质无法把普通灵气留在体内，符火和常规灵力不能成为稳定力量来源。
- 沈燧能够感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。由烧红粗铁和黑铁锋片锻成的粗糙裂路器，已被证明可以切开石壁、薄型封钉、旧通风门和倒悬废炉闸；它仍不能直接切开火流。剩余使用次数、触发条件和进一步代价尚未确认。
- 沈燧的黑铁锋片已不再嵌在掌心；右掌伤口和灼痕仍在，右臂黑色裂痕仍会发热并收缩，左肩旧伤已加重。
- 沈燧从废炉炉膛取出一枚尚未完成传火的火鳞胚。它保留未接成回路的暗红细纹，能隔着布料朝窟心方向偏动，已在一次火潮中保持完整；它能否完成、如何发挥作用及代价均未确认。
- 阮青禾能够辨认旧炼器窟的通风门、炉闸和残图，并与沈燧形成基于现场判断、路线指引和伤者转移的临时协作。五名炉工已从通风门后获救并加入队伍；原有矿工和伤者已能按分工互相扶持，但尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认裂路器能够再次驱动，知道沈燧具备驱动异常器物的能力，并将其列入“失控器修”的追查记录。
- 废弃炼器窟的窟心炉心仍在发热，外引火线多已断裂，但残图仍有一条未被抹掉的深处刻线与窟心相连；炉心性质、持续燃烧原因和其后方是否存在出口尚未确认。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火，确切剩余时间尚未确定。

# Proposed Chapter Summary

回火和封锁同时逼近时，沈燧依次切开旧通风门与倒悬废炉闸，救出被困其中的五名炉工并带队穿过废炉热道；一片从炉壁剥落的焦黑炉鳞短暂分开火流后碎灭，沈燧又从炉膛取出一枚仍未完成传火、指向窟心的火鳞胚。队伍抵达旧矿道岔口后，裴照川封死左侧退路并命令回收队将他们逼向窟心，沈燧遂携带裂路器和火鳞胚沿右侧残图刻线继续深入。
