# Proposed Active Scene State

- 当前地点：旧炉门后的收窄道，队伍正向上方、废窟外和黑炉镇方向前进；前方已经能听见并感到外面的风，右侧有回火缝，尚未抵达安全出口。

- 当前敌人或追兵：裴照川和回收队被空炉爆裂后倒塌的炉壁、半截炉门和砖梁隔在窟心一侧，暂时不能直接进入队伍所在收窄道。裴照川已将沈燧本人、火鳞器、未完成炉心以及沈燧使用过的旧炉路和炉法列为追收或封存目标，后方封截仍在合拢。

- 下一步直接目标：保持队伍不分散，护送三名伤者和未完成炉心沿收窄道向废窟外、黑炉镇方向前进；避开右侧回火缝，在封炉印闭合前找到阮青禾所说的三座旧炉连接点并确认可行生路，同时防止裴照川恢复追收。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”。他的纳灵体质不能稳定留住普通灵气；他能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 火鳞胚已经铸成沈燧第一件真正属于自己的下品道器“火鳞器”。它已证明能够托住并分开一段高温火流、保护未完成炉心并维持人员通过；它不能直接斩开封线，连续承火能力、长期作用边界和代价仍未确定。本章末它仍可分开贴地热流，但鳞面红光已经变暗。
- 裂路器仍可被沈燧驱动，但锋口已经钝化；它已证明可以沿既有裂口，以器背和器柄剥开旧铸层、熔渣、旧铁和卡住炉门的旧楔。它恢复连续切割的条件及进一步代价仍未确定。
- 传火后的空炉在没有新燃料、炉壁不完整的情况下仍能储住被旧火重新点醒的热，并在热力积聚后发生爆裂，将热回吐向窟心；这确认了空炉的短时异常工作和爆裂反应，但没有确认旧火持续燃烧的完整根因。
- 未完成炉心仍未完成，内部红线会缓慢寻找接合处。它曾在沈燧托住底部时短暂停止移动两息，并与沈燧腹腔的不稳定热意发生短暂牵引；牵引结束后热意散开，炉心仍不能由沈燧承重或转化为稳定力量。其性质、完成条件、最终作用和代价仍未确认。
- 沈燧右掌灼痕已裂至肘侧，右臂黑色裂痕会在承受火力和铸器时发亮；左肩旧伤被回火灼重，右肩新增封线灼伤；腹腔热意仍不稳定，不能替代普通灵气体系。
- 阮青禾能够辨认旧炼器窟的炉门、火槽、旧铸道和收窄道，并与沈燧形成以现场判断、路线指引和伤者转移为核心的临时协作。五名炉工已能在她和沈燧指挥下轮换扶持伤者、托运炉心并执行撤离，但尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认沈燧能够驱动异常器物。裴照川已将沈燧本人、火鳞器、未完成炉心以及沈燧使用过的炉路和炉法列为回收或封存目标，拒绝交付仍会遭到追收。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火；正文进一步确认黑炉镇退路将在今夜随封炉印闭合，但确切剩余时间仍未知。
