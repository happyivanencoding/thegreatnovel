# Proposed Active Scene State
- 当前地点：黑炉镇外墙总门外的外坡，队伍已经离开门洞，正沿东南方向前往旧矿场迁走后废弃的侧炉。总门已经形成可供人员通过的门洞，原有总封炉印的闭合处已断，但门楣、外墙和门内炉场仍在持续下沉，门后旧路正在塌落。
- 在场人物：沈燧、阮青禾、五名持续托持未完成炉心的炉工，以及已经越过总门的伤者、老人、孩子、愿意同行的居民和矿工。东侧通风井的六名矿工、南侧旧轨留守人员和最后一辆废矿车已经出门；队伍仍在清点和互相扶持。裴照川及回收队在外坡后方，尚未放弃追收。
- 即时伤势：沈燧右掌灼伤裂口持续出血，右腕至肘侧的黑色裂痕和灼痛加重，右肩旧热伤仍在，左肩旧伤受压；左腕在剥开门内环和旧门栓时被震得发麻。火鳞器残片擦过时又把热意透入掌背。五名炉工双臂麻木、手指发抖，其中一人的虎口已经裂开，仍必须共同托住炉心；既有伤者、老人和孩子仍需要扶持。
- 手中关键物品：火鳞器完整但鳞片全暗，已经无法分火、承热或张开鳞缝，只剩沉重器身和正在消退的微弱余温；裂路器锋口仍然钝化，刚沿旧裂口剥开总门内环并拆出旧门栓，仍不能视为恢复连续切割；沈燧把拆下的旧门栓带在腰间，门栓残留的动作方向已被称为“无名通路”，目前指向东南废弃侧炉。五名炉工托着未完成炉心，红线仍在旧布内急促寻找接合处，炉心不得落地，布包可能被继续升高的热意烧穿；阮青禾持有旧矿图。
- 当前敌人或追兵：裴照川和回收队退到不会被总门反卷线波及的外坡后方，仍以沈燧、未完成炉心以及沈燧使用过的炉路和炉法为追收目标。原有总封炉印已不能重新把黑炉镇从门到炉场完整勒死，但残余火线仍能灼烧、施压，塌落的外墙和炉场也构成即时危险。
- 当前倒计时：封炉令规定的三日期限尚未到达，但封炉印将在今夜闭合，确切剩余时间未知。更紧迫的是黑炉镇炉场和外墙正在下沉，队伍必须在塌落扩大前通过外坡；炉心在无安置炉火的情况下继续升温，托持它的布包和炉工的体力也即将到达极限。
- 下一步直接目标：带着未完成炉心和需要扶持的人群穿过外坡抵达东南废弃侧炉，在炉膛、残存粗铁和炉灰仍可用的前提下，把三座旧炉留下的火带入侧炉并找到暂时安置炉心的办法；同时保持队伍脱离塌落区，防备裴照川的追收，不把总门打开误认为已经摆脱封炉令或宗门追兵。

# Proposed Persistent Canon
- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”；他的纳灵体质不能稳定留住普通灵气，但能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 裂路器的锋口已经钝化。它已反复证明只能沿已有裂口剥开旧铸层、熔渣、旧铁、旧楔、封炉锚和总门旧门栓的接合处，不能恢复连续切割；继续驱动的条件、边界和代价仍未知。
- 火鳞胚已铸成沈燧第一件真正属于自己的下品道器“火鳞器”。它曾在有限时间内托住并分开高温火流，但连续使用会加重沈燧右掌和右臂伤势；本章再次确认它在火鳞耗尽后不能主动张开鳞缝或承接封炉残片，目前只是一件沉重器物，能否恢复、再用、修复及其长期边界和代价仍未知。
- 黑炉镇下层三座公共废炉已通过旧炉槽、东侧通风井和南侧矿车线形成实际连通，三座炉的旧火曾共同接入总门内环；沈燧沿既有裂口拆出旧门栓并打开外墙总门，使原有总封炉印失去完整闭合处，玄烬仙宗不能再用这一完整总封炉印把黑炉镇从门到炉场一圈圈勒死。但外墙、门内炉场和三炉旧路的支撑正在塌落，旧火网络的长期稳定性仍未确定。
- 旧火能够借助重新打开的旧槽、风路和炉轨在三座公共废炉之间传递并依次复燃，也能沿三道旧槽短暂进入总门内环；旧火持续工作的完整根因、三炉更深处的连接、封炉印的完整抽火与转压机制，以及塌落后旧路是否仍能工作，都未揭示。传火后的空炉在无新燃料、炉壁不完整时仍可能积热爆裂。
- 未完成炉心内部的红线会寻找接合处。在五名炉工持续托持、抬高并对准旧槽时，它曾接上旧铁和三座炉的火路；越过总门后仍未完成，不能落地，不能进入沈燧身体，也没有成为沈燧的稳定力量。其完整接合条件、最终作用、与沈燧腹腔热意的关系、对炉工和炉心的代价仍未知。
- 沈燧右掌灼痕已裂至肘侧并会在承受火力时出血发亮；左肩旧伤被回火灼重，右肩有封炉热伤，连续使用火鳞器使腕臂承压加剧；本章左腕又因剥门受震发麻。腹腔热意不稳定，正文没有再次出现，不能替代普通灵气体系或承担炉心重量。
- 阮青禾与沈燧已形成以现场判断、路线分工、开路、守井、门内组织和人员转移为核心的实际协作；五名炉工、矿工及部分居民已共同完成开门和撤离。居民中原本要求交人的人实际参与护人、推车和救出孩子，但黑炉镇居民整体仍未形成正式长期盟约。
- 沈燧从总门封炉印中拆出一截旧门栓，并感知到其中“让没有宗门印记的人通过”的未完成动作；这股残响随炉心和人群越过门洞，继续向东南废弃侧炉延伸，沈燧将其称为“无名通路”。其性质、可重复性和与未完成炉心的关系尚未确定。
- 玄烬仙宗和裴照川已确认沈燧能够驱动异常器物；沈燧本人、火鳞器、未完成炉心及其使用过的炉路和炉法仍是回收或封存目标。裴照川撤出总门内环反卷线，却明确保留追收命令。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火；正文进一步确认封炉印将在今夜闭合，但确切剩余时间仍未知。
