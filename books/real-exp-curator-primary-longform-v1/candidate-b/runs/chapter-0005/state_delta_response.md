- 旧 CANON INDEX 记载火鳞胚仍未完成传火、暗红细纹未接成回路，且空炉只能短暂亮起；正式正文显示最后断口已被剥开，旧火经两条引火链进入空炉并持续点燃，火鳞胚已与粗铁炉箍、炉心边角和残响铸成火鳞器，最后一道细纹已经接合。
- 旧状态记载沈燧右臂承火后的热意已经回缩；正式正文显示铸器和承接炉心时右臂裂痕再次亮至肘侧，并在腹腔形成一圈不完整、会散开的热意。
- 旧 Active Scene State 仍把队伍置于窟心外围的分火环内侧；正式正文显示队伍已穿过炉心台，进入旧检修砖道入口并向废窟外撤离。
- 正式正文无法确定火鳞器可持续承火的时长、长期作用边界和代价；未完成炉心的性质、最终接合条件和作用也未确定；沈燧腹腔内新形成热环能否稳定保留未确定；旧检修砖道是否通向真正出口以及封炉令确切剩余时长仍未确定。

# Proposed Active Scene State
- 当前地点：队伍已离开窟心炉心台，进入通往废窟外的旧检修砖道入口；前方砖道正在变窄，后方窟心的封截重新压入。
- 在场人物：沈燧、阮青禾、原有矿工、腿伤者、胸口伤者、额头伤者和五名炉工。阮青禾在队伍后方照路；炉工轮换扶持伤者，其中一人用两层旧布托持未完成炉心；沈燧在队伍最后护送。
- 即时伤势：沈燧右掌灼痕再次裂开并出血，右臂黑色裂痕由腕骨亮至肘侧；肩头被封炉钉擦过，左肩旧伤仍被回火灼重。腹腔内形成一圈尚不稳定的热意，收紧腹部会散开一半，不能替他承重。三名伤者仍需扶持，队伍尚未脱离危险。
- 手中关键物品：沈燧持有刚铸成的火鳞器；它能托住并分开一段高温火流、护住未完成炉心，并把热力传给相邻器胚以暂时撑开通道，但不能直接斩开封线。裂路器仍在沈燧手中，锋口已钝，只能沿既有裂口剥撬并以器身、器柄辅助，不具备连续切割的已知状态。阮青禾持符灯；未完成炉心由炉工携带。
- 当前敌人或追兵：裴照川已带回收队进入窟心，命令一并回收炉心和火鳞器；持器者拒绝时按“失控器修”处理。回收队正沿东侧检修道和窟心封截追来，封截可重新合拢。
- 当前倒计时：旧检修砖道的红光正在一段段熄灭，通道持续收窄；火鳞器只能保证当前一段撤离通道，具体可支撑时长未知。窟心封截正在重新压入，黑炉镇的退路将在今夜随封炉令封死，但三日期限的确切剩余时长仍未知。
- 下一步直接目标：沿旧检修砖道快速护送伤者和未完成炉心向废窟外撤离，利用火鳞器维持必要的火流通道，避免队伍分散并摆脱裴照川的追收，在退路完全封死前找到真正生路。

# Proposed Persistent Canon
- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”。他的纳灵体质不能把普通灵气稳定留在体内；他能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 火鳞胚已完成传火并铸成沈燧第一件真正属于自己的下品道器“火鳞器”：主体由粗铁炉箍、炉心边角和赤色鳞光成形，柄端嵌有炉心边角，鳞片状前端仍保留不平整的旧炉棱。它已证明能够承受、托住并分开一段高温火流，保护未完成炉心，并把热力传给相邻器胚；它不能直接斩开封线，持续时间、长期作用边界和使用代价尚未确定。
- 裂路器仍可被沈燧驱动，但锋口已有钝痕，不能继续连续切割；本章证明它还能沿已有裂口剥撬熔渣、旧铁和炉砖，并以器背和器柄参与铸造，恢复连续切割的条件与进一步代价仍未确定。
- 传火闸前的最后断口已经被打开。旧火经两条断裂引火链进入空炉，使空炉持续点燃成为第二座炉；窟壁中被封存的器胚因此显出轮廓并被热力短暂唤醒，火力能够从一个器胚传到相邻器胚。第二座炉的完整机制、旧火持续燃烧的根因以及引火链为何断裂仍未确认。
- 沈燧一行已从宗门回收架上取下未完成炉心，当前由炉工携带。炉心表面只有一道从内部缓慢移动的红线，仍在寻找最后的接合处；其性质、完成条件、作用和代价尚未确认。
- 沈燧右掌灼痕已裂至肘侧，右臂黑色裂痕会在承受火力和铸器时发亮，左肩旧伤被回火灼重；承受炉心热力后，腹腔曾形成一圈不完整热意，尚不能视为稳定力量来源，也不能替代普通灵气体系。
- 阮青禾能够辨认旧炼器窟的通风门、炉闸、分火环、传火顺序和检修砖道，并与沈燧形成以现场判断、路线指引和伤者转移为核心的临时协作。五名炉工已能在她指挥下轮换扶持伤者并执行撤离，但尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认沈燧能够驱动异常器物；裴照川当场将火鳞器称为“下品道器”，并将火鳞器与未完成炉心列为回收目标，拒绝交付者将按“失控器修”处理。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火；正文同时确认退路将在今夜随封炉令封死，但确切剩余时长尚未确定。

# Proposed Chapter Summary
沈燧在反烧与回收队封截中以火鳞胚和已钝的裂路器剥开传火闸前的最后断口，使旧火沿两条引火链进入空炉并持续点燃；他用粗铁炉箍、炉心边角和残响将火鳞胚铸成火鳞器，借其暂时托开火流和封截，从回收架取下未完成炉心，带领队伍进入旧检修砖道撤离；裴照川率回收队进入窟心继续追收，后方封截重新压入，退路仍在收窄。
