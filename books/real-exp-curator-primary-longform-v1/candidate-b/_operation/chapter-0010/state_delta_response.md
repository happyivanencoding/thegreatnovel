- 旧状态中火鳞器“耗尽且不能承热”的当前能力已改变：它重新托住了红热粗铁，鳞片没有张开或碎裂，且没有继续变暗；但它仍不能分开火流或进行连续切割。

- 旧状态把沈燧腹腔热意记为不稳定且“正文没有再次出现”；正式正文中炉心接合时热线首次穿过腹腔后没有立即散开，并持续随呼吸、炉心和炉匣火起伏。但它仍未被证明是可以自由调用的稳定力量，不能改写为普通修炼力量或承重能力。
- 原先“队伍能否抵达废弃侧炉并保住炉心”的开放状态已经完成：炉心已在侧炉旧槽中接合并稳定在可抽换炉匣内。固定炉腹留在侧炉，移动炉匣与固定炉腹仍由旧槽保持火路连接。

- 裴照川本章将沈燧从“矿镇废人”改列为“失控炉主”，并把沈燧、炉心、炉场以及他使用过的炉路和炉法一并列为追收目标。回收队已沿旧矿道追至外坡，但裴照川没有在总门处引爆人群和炉心，而是准备封前路追收。
- 无法从正式正文确定炉渣残图与半截战旗的归属：裴照川先让弟子拾取渣片，并把渣片和战旗夹入回收册；结尾又明确写沈燧把半截战旗放到炉匣旁并按住渣片。后续不得假定这两件物品的持有人或取得过程，除非正文补足。

# Proposed Active Scene State

- 当前地点：黑炉镇已经塌落的外墙总门外坡、熄灭封炉台附近的旧矿道边。固定侧炉留在东南后方，仍与移动炉匣保持旧槽火路连接；装有炉心的可抽换炉匣已安在矿车上，队伍正准备把它推上炉渣残图指向的古战场方向旧路。
- 在场人物：沈燧、阮青禾、五名炉工，以及随炉匣同行的伤者、老人、孩子和愿意同行的居民、矿工。五名炉工不再直接托住炉心，但轮换扶持炉匣和矿车；部分居民留在固定侧炉、东侧风口或南侧旧轨旁，阮青禾已记录他们的路线。裴照川和回收队在外坡后的旧矿道上追近，尚未冲入人群。
- 即时伤势：沈燧右掌灼伤裂口仍出血，黑色裂痕已从腕部延至肘侧，右肩封炉热伤和左肩旧伤仍在，左腕因剥门受震发麻；炉心接合后的腹腔热线仍会随炉火、呼吸和车轮颠动收紧，压短呼吸，但尚未证明能提供可自由使用的力量。五名炉工双臂和手指仍因长时间托持而麻木，其中一人虎口裂伤；同行的伤者、老人和孩子仍需扶持。
- 手中关键物品：装有未完成炉心、粗铁托架和炉灰承托的移动炉匣及矿车；固定侧炉的炉腹留在原处并持续燃烧。裂路器仍不能连续切割，但钝锋缺口已有红黑铁皮填补，可沿既有裂口剥开。火鳞器的鳞片大半仍暗，已显出细红纹，可承住红热材料，但不能张开鳞缝分火。旧门栓仍在沈燧腰间，其残留方向已实际带队抵达侧炉，能否继续指路或开路尚未确定。阮青禾掌握记录了留守路线的矿图。正文结尾显示炉渣残图和半截焦黑战旗在炉匣旁，但两者此前又被写为裴照川收存，归属按审计项保留不确定。
- 当前敌人或追兵：裴照川已把沈燧列为“失控炉主”，回收目标包括沈燧本人、炉心、炉场及其使用过的炉路和炉法。回收队已追到外坡，符光和金属声沿矿道逼近；裴照川暂不在总门处引爆，而是准备沿旧矿道封住前路。塌落的墙体、炉场和旧路仍是即时地形危险。
- 当前倒计时：没有从本章确定的可量化封炉时刻；总门最后封炉锁已经熔断，原完整总封炉印的闭合处已失效。眼下更紧迫的是回收队已经到达外坡并准备封前路，且塌落会继续收窄旧路，队伍必须在追收队闭合前路前把炉匣和人群推离外坡。封炉令三日期限是否仍对新的路线或其他封锁生效，尚未确定。
- 下一步直接目标：将移动炉匣推上炉渣残图指向的古战场方向旧路，先让炉心、伤者和同行人群脱离外坡及回收队的封截；保持固定侧炉与炉匣的火路，继续观察古战场路线、残旗和炉渣线索，不把腹腔热线或两件器物的部分恢复当成无代价、可反复使用的能力。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，曾被称为“漏炉废人”；他的纳灵体质不能稳定留住普通灵气，但能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。玄烬仙宗现已将他改列为“失控炉主”。
- 裂路器仍不是连续切割器。它能在已有裂口、旧槽、铸层或接缝中寻找原有退路并剥开；侧炉烧料后其钝锋缺口被红黑铁皮粗略填补，已证明可以恢复这种沿旧裂剥开的工作，但补层的耐久、再次驱动条件和代价仍未知。
- 火鳞器仍不能主动分火、张开鳞缝或连续切割。侧炉重新烧料后，它恢复了有限的承热能力：可以托住红热粗铁而不碎裂、不让热意直接穿入沈燧的手，鳞面会留下细红纹；其能否进一步恢复、修复及长期边界和代价仍未知。
- 未完成炉心的红线在三座旧炉最后的火光进入侧炉、粗铁和炉灰形成承托且炉心对准旧槽后，已经找到侧炉旧槽的接合处，并稳定卡在炉匣中；五名炉工不必再直接托住炉心。炉心的完整性质、最终作用、长期稳定性、脱离炉匣的条件及对炉工的代价仍未知。
- 炉心接合时，沈燧腹腔首次留下没有立即散开的热线，一端连着炉心，另一端通向侧炉更深处；热线受呼吸、炉心火和炉匣移动牵动，会收紧并压迫身体。它尚未成为沈燧可以自由调用的稳定力量，也未证明可以脱离炉心独立存在。
- 侧炉已形成固定炉腹与可抽换移动炉匣之间的旧槽火路。装有炉心的炉匣能够安在矿车上随队移动，固定炉腹仍可燃烧并与之互相应答；炉匣已经第一次真正烧入粗铁和炉灰，并产出带有红黑色铁皮和带线渣片的炉渣。这个移动炉场的持续时间、燃料要求、可重复产物和长期边界仍未知。
- 三座公共废炉通过东侧通风井、南侧旧轨和第一座炉的旧气道重新接入总门并支持矿车往返，旧火没有因总门外火线熄灭而立即消失。黑炉镇外墙、炉场、旧灵脉、宗门账册和炉场身份已随塌落不可逆地沉没；旧火网络在塌落后的更深连接、完整抽火与转压机制及长期稳定性仍未揭示。
- 阮青禾与沈燧已经形成围绕路线判断、炉匣安置、开路、人员转移和留守路线记录的实际协作。炉工、矿工和部分居民共同完成了炉心安置与总门通行；部分居民选择留守固定侧炉或旧路并自行往返，黑炉镇居民整体仍未形成正式长期盟约。
- 沈燧的右掌灼痕已裂至肘侧并会在承受火力时出血发亮，右肩封炉热伤、左肩旧伤和左腕麻木仍是持续伤势；腹腔热线构成新的身体负担。五名炉工保留长时间托持造成的手臂、手指和虎口伤势，但当前主要扶持移动炉匣而非直接承托炉心。
- 裴照川和玄烬仙宗已经确认沈燧能驱动异常器物，并将沈燧、炉心、炉场及其使用过的炉路和炉法列为追收对象。裴照川在总门处选择避免把人群和炉心一起卷入回火，随后带队沿矿道追击；其封截前路和夺取炉场的行动仍在继续。
- 炉匣烧料产生的薄平渣片上出现一条从黑色山口、经过三道断路和赤黑平地、指向裂开圆阵的路线，并伴随一面只剩半截的焦黑战旗；阮青禾判断其指向古战场。路线、圆阵、战旗来历和它们与炉匣或旧火网络的关系尚未确认，物品当前归属也存在正文内部歧义。

# Proposed Chapter Summary

第10章：队伍在东南废弃侧炉利用三座旧炉最后传来的鳞光、粗铁和炉灰，沿既有裂口剥出烧死的炉匣，使未完成炉心接入旧槽并稳定下来；沈燧腹腔首次留下与炉心和侧炉相连、随呼吸与炉火起伏的热线，固定炉腹与装有炉心的移动炉匣由旧槽保持连接。炉匣第一次烧料后，裂路器恢复沿既有裂口剥开的能力，火鳞器恢复有限承热；队伍返回总门熔断最后封锁，让人群和矿车通过。黑炉镇外墙、旧灵脉和宗门炉场身份随塌落沉没，裴照川将沈燧列为“失控炉主”继续追收；炉渣烧出一条指向古战场的路线和半截战旗，追兵逼近之际沈燧命人把炉匣推上路。
