# State Delta Audit

- 旧 Active Scene State 记载队伍仍在旧炉门后的收窄道、尚未抵达出口；正式正文已明确队伍抵达黑炉镇下层旧炉场，第一座废炉的旧气道已经打开，首批居民、老人孩子和伤者已通过外部风口，因此旧位置和“尚未抵达安全出口”的状态已被正文替换。
- 旧 Active Scene State 记载三座旧炉的连接点仍待寻找和确认；正式正文已确认三座废炉是封炉印抽火的连接处，并已熔断第一座废炉的封炉锚。尚未解决的是第二、第三座连接的处理方式。
- 正式正文没有说明裴照川和回收队在队伍抵达旧炉场后的位置，也没有确认旧窟倒塌造成的隔离是否仍然有效；不能继续把他们写成当前确定被隔在窟心一侧。
- 正式正文没有明确未完成炉心在外部风口的具体站位，也没有明确随部分炉工返回炉场的人员是否仍直接负责托持它；只确定炉心已经被带出地底，仍需要炉工支撑。
- 黑炉镇封炉印闭合的确切剩余时间、第二与第三座废炉还能维持多久，以及第二、第三座是否必须同时处理，正文均未确定。
- “熔废阵”只被居民提出，阮青禾没有确认这一名称；正文确认的是宗门把第一座断开后的压力转向另外两座，不能把该名称或完整阵法机制当作已证实 Canon。

# Proposed Active Scene State

- 当前地点：黑炉镇下层旧炉场的三座公共废炉之间。第一座废炉的封炉锚已熔断，旧气道已经打开并通向山体下方的外部风口；沈燧和阮青禾从气道返回炉场。第一座炉仍沿旧气道送出热风与冷风交错的气流。
- 在场人物：沈燧、阮青禾，以及留在旧炉场的居民，包括拄杖的老矿工和此前要求交人的男人。五名炉工分散在炉场与外部风口之间，部分已返回炉场，部分仍在风口照看三名伤者、老人和孩子。首批自愿同行的居民及其照看的人已经到达外部风口；其余留镇居民仍贴着旧墙观察第二、第三座废炉。
- 即时伤势：沈燧右掌灼痕在持续握持中抽痛，右臂自腕至肘侧的黑色裂痕目前较暗；左肩旧伤仍发紧，右肩又被从封炉锚裂口冲出的热流擦过并加重焦痛。腹腔中此前被炉心牵动的半圈热意已经完全散开，不能承重或作为稳定力量。三名伤者已到外部风口，仍需人员扶持。
- 手中关键物品：沈燧持有火鳞器，鳞面只剩少量暗红亮光，刚才因炉心短暂牵引而扩开的分火缝已经收回，剩余作用时长和承火能力未知；裂路器仍在左手，锋口钝化并沾有第一座炉的黑渣，只能沿已有裂口剥开熔渣、旧铁和封炉锚根部，不能视为恢复连续切割。阮青禾持符灯，旧矿图仍在炉场炉砖上。未完成炉心已被炉工带到外部风口，红线尚未接合，仍需炉工托持，但正文未明确它是否已随部分炉工返回炉场。
- 当前敌人或追兵：封炉印或宗门正在把第一座断开后的火力反压到第二、第三座废炉；两座废炉的未断连接在同一轮火潮中同时收紧，余火接近熄灭。裴照川和回收队本章没有在旧炉场现身，是否已恢复追收、是否仍被旧窟结构隔开均未确定。
- 当前倒计时：黑炉镇封炉印将在今夜闭合，确切剩余时间未知。第二、第三座废炉正在同步失火，若当前反压继续，两座会一起熄灭，但具体剩余火力和时间未知。火鳞器已接近耗尽。
- 下一步直接目标：立即判断第二座东侧旧路与第三座南侧旧路的同步火潮，找到能够阻止两座废炉同时熄灭的分路、断压或开路办法；同时保持第一座旧气道作为已验证的通行线，确保伤者、居民、炉工和未完成炉心不被新的火潮截断，并确认裴照川一方是否重新逼近。

# Proposed Persistent Canon

- 沈燧仍是黑炉镇矿工和苦力，被称为“漏炉废人”。他的纳灵体质不能稳定留住普通灵气；他能感知器物中尚未完成的具体动作，并把残留的方向性力量导入新的金属载体。
- 火鳞胚已铸成沈燧第一件真正属于自己的下品道器“火鳞器”。它能托住并分开高温火流、保护人员和未完成炉心通过；未完成炉心曾短暂牵动沈燧腹腔的热意，使分火范围扩大约三个呼吸，牵引结束后热意散尽，火鳞器的鳞面也进一步变暗。它不能直接斩开封炉连接，连续承火能力、长期作用边界和使用代价仍未确定。
- 裂路器仍能被沈燧驱动，但锋口已钝化。它已证明可以沿已有裂口剥开旧铸层、熔渣、旧铁和旧楔，并沿炉壁老裂缝剥开封炉锚根部，使第一座废炉的封炉锚熔断；这不等于恢复连续切割，后续可用边界和代价仍未确定。
- 黑炉镇下层三座公共废炉原本通过旧炉路相连，封炉印把这些连接处作为抽走火力的封炉锚。第一座废炉的封炉锚已断，旧气道重新打开并通向外部风口，能够持续交换冷风和热风；第二、第三座的连接仍在，且封炉印能够把一座断开后的压力转压到另外两座，使它们同步衰弱。三座炉更深处的完整连接和封炉印的完整机制仍未确认。
- 传火后的空炉在无新燃料、炉壁不完整时仍能储住被旧火点醒的热并在积热后爆裂；旧火为何能持续工作、以及它与三座公共废炉系统的完整根因仍未揭示。
- 未完成炉心内部的红线会缓慢寻找接合处，尚未完成；它需要炉工持续托持，不能由沈燧承重或转化为稳定力量。它与沈燧腹腔热意及旧炉网络的关系、完成条件、最终作用和代价仍未确认。
- 沈燧右掌灼痕已裂至肘侧，右臂黑色裂痕会在承受火力和铸器时发亮；左肩旧伤被回火灼重，右肩有新增封炉热伤；腹腔热意不稳定，不能替代普通灵气体系。
- 阮青禾与沈燧已形成以现场判断、路线指引、开路和人员转移为核心的临时协作；五名炉工和部分居民已实际协助护送伤者、老人孩子及炉心，但黑炉镇居民立场仍不统一，尚未形成长期盟约。
- 玄烬仙宗和裴照川已确认沈燧能够驱动异常器物；沈燧本人、火鳞器、未完成炉心及其使用过的炉路和炉法仍是回收或封存目标。封炉印具备通过连接处抽取、转移和压低火力的能力，但裴照川和回收队当前位置未确认。
- 黑炉镇封炉令仍要求三日后封闭矿脉、熄灭地火；正文进一步确认封炉印将在今夜闭合，确切剩余时间仍未知。

# Proposed Chapter Summary

沈燧一行抵达黑炉镇下层旧炉场后，阮青禾确认三座废炉是封炉印抽火的连接处；沈燧用火鳞器护送愿意先走的居民、老人孩子和伤者进入第一座废炉，又用已钝化的裂路器沿旧裂口剥开后壁，熔断第一道封炉锚，使旧气道打开并让首批人从外部风口离开地底。未完成炉心曾再次短暂牵动沈燧腹腔的热意，使火鳞器扩大分火，随后热意散去。宗门随即把压力转向第二、第三座废炉，两座废炉在同一轮火潮中同时接近熄灭；沈燧和阮青禾返回炉场，尚未作出应对两座同步衰弱废炉的分路选择。

# Proposed Open Promises

- 黑炉镇封炉令规定的三日期限仍未到达，但封炉印将在今夜闭合，确切剩余时间尚未揭示。
- 第一座废炉的封炉锚已断、旧气道已开并通向外部风口；这条气道能否在后续反压中保持稳定通行，以及它能否进一步连出黑炉镇的安全路线，尚未确认。

- 裂路器在锋口钝化后的可用边界、再次驱动的条件和进一步代价尚未确定。
- 火鳞器在接近耗尽后还能维持分火多久、能否稳定用于后续脱险、长期作用边界和使用代价尚未确定。
