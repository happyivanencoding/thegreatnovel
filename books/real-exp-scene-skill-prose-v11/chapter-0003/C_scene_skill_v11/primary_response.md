# Primary Draft

清晨，外门演武场前已经站满了候考弟子。

顾长川站在队列中，右肩仍然垂着，胸口每吸一口气，肩背便跟着牵动一下。他没有抬手去揉，只把视线投向演武台。

演武台中央立着一方矮石台，石台上放着一块巴掌大的青色木牌。木牌正面刻着一个“合”字，牌边压着细铜线，在晨光里很醒目。

宁秋禾站在长案后，手掌按着封存的考核名册。执事站在演武台旁，向面前的候考弟子说明规则。

“本轮为公开取牌。候考者从自己的白线出发，取到台心的合格牌，再把牌带回自己的白线，才算通过。对手负责阻拦，可以在台上截住、逼退，但不得越过候考者的回线。候考者丢牌、失去合格牌，或者未能回线，均判失败。结果由现场判定。”

人群安静下来。

这条规则听起来简单，真正难的是回线。

取牌时，候考者要主动走到台心，回去时却必须带着牌从对手面前退开。对手不需要抢牌，只要把人逼出白线，或者逼得人松手，就能阻止这一轮。

宁秋禾低头看了一眼名册。

“顾长川。”

队列里有人回头。

顾长川走出队列，站到演武台东侧的白线后。他仍然是外门候考弟子，名字还在封存名册的候考栏里。今天能不能留下，不由名册上的一个位置决定，而由台心那块牌决定。

执事看向另一边。

“谁负责阻拦？”

“我来。”

周既明从人群中走出，站到演武台南侧。他没有像往常那样把手藏进袖中，也没有刻意挡住自己的脚步。

他抬手指向顾长川。

“这一轮，我点顾长川。”

台下顿时响起一阵低低的议论声。

周既明也是候考弟子，基础拳脚和发力都在众人之上。顾长川右肩带伤，刚才站入队列时就被不少人看见了。周既明在这个时候主动点名，显然不是为了给他一个轻松的对手。

顾长川看见周既明的目光在自己右肩停了一瞬。

“可以。”他说。

周既明站到另一条白线后，双脚一前一后，肩膀微微压低。

许照站在候考队列靠后的位置，正看着台上。她没有朝顾长川示意，只把手臂抱在身前，目光落在顾长川的脚下。

执事抬起手。

“开始。”

周既明没有立刻冲上来。

他的右脚向外点了半步，肩线随之下沉，像是准备从侧面切进。顾长川的视线落在他的脚、胯和胸口之间。

右脚落得很轻，后脚没有压实，重心也没有真正往前送。

顾长川不动。

周既明收回脚，换成左脚向台心滑进。肩膀比刚才更低，右手从肋侧抬起一点，掌心似乎要向前。

顾长川仍站在白线内。

周既明的手没有送出去，左胯也没有带动腰身。他只是把一个动作摆到半途，等顾长川先动。

顾长川看着他的脚尖。

假动作还停在脚下，重心没有进来。

他向旁边挪了半步，让自己的身体仍处在白线内侧，随后重新站稳。

周既明的眼神沉了一点。

他已经改变了出手时机。过去那种先落脚、再转胯、最后把掌力送出来的完整顺序，他不会再完整摆给顾长川看。此刻每一次抬肩、落脚，都可以在真正发力之前收回。

可顾长川要等的也不是一整套招式。

他只需要确认周既明什么时候真的进来。

周既明又停了片刻，忽然向台心踏出一步。

这一次，他先送出的仍然是肩膀。

顾长川没有动。

周既明的脚掌落地，后脚却只在地面上擦过，腰胯没有跟上。那股逼人的势头只到肩线，便停了下来。

台下有人发出一声轻笑。

周既明没有理会。他收回肩膀，脚尖转向顾长川的右侧，像是要逼他先往受伤的那边退。

顾长川的右肩隐隐发麻。

他看着周既明的脚跟终于压实地面。

下一刻，周既明的后脚猛地蹬地。

这次没有停。

他的右脚抢进，左胯同时转开，胸口和肩线在同一刻压向前方。右掌从肋下穿出，掌根直奔顾长川受伤的右肩。

真实进攻到了。

顾长川等的就是这一刻。

掌根逼近肩头时，他先换脚，斜着踏到来力外侧。左胯跟着转开，腰身从正面让出，原本要撞上右肩的掌力擦着衣襟掠过。

他没有抬臂硬接。

前臂贴住周既明逼来的力，顺着身体的转向向侧方一带。周既明的前冲没有撞中目标，肩膀擦过顾长川身前，整个人被自己的重心带向侧面。

顾长川的胸口被气流震得发紧，右肩也在转胯的瞬间传来一阵剧痛。

可他已经从周既明的正面移开。

周既明的身体冲过他的身侧，顾长川则顺着这一转落到台心石台旁。他伸出左手，一把抓住了那块合格牌。

牌面硌在掌心，冰凉而坚硬。

他没有停留，转身就往自己的白线走。

脚下那套换脚、转胯的步子已经走完。顾长川想再照着刚才的节奏调整重心，身体却接不上那一下，只能靠普通脚步向后退。

周既明的反应很快。

他在台心收住前冲，立刻转身追上来，没有去看顾长川刚才那一下步法，而是直接封住他回线的方向。

“牌留下。”

周既明横移一步，手臂从侧面压过来，逼向顾长川握牌的左手。

顾长川把合格牌贴到胸前，左脚向后退，右脚跟着收回。他没有和周既明正面撞在一起，只沿着白线方向斜着走。

周既明的手掌擦过他的袖口。

顾长川向左让开半步，胸口的牵扯立刻加重。他咬住牙，没有把右手抬起来，只用左肘护住胸前的牌。

周既明再次压近。

他看出顾长川的右肩不能发力，脚步开始专门往顾长川的右侧切，把顾长川一点点往自己的回线方向逼。

顾长川的后跟已经靠近白线。

再直退一步，他就会把自己逼出判定范围。

周既明也看见了这个位置。他没有急着伸手，而是先横跨一步，堵住顾长川左侧的空隙。

顾长川停在白线内侧，牌尖已经碰到线边。

周既明从另一侧压来，肩膀几乎贴到顾长川身前。顾长川没有后退，只把身体向旁边让开一掌宽。

那条缝很窄。

周既明为了封死缝隙，脚下猛地跨进来。左脚落地时，鞋尖已经越过顾长川身后的白线。

“周既明，越线！”

执事的喝声立刻响起。

周既明没有收脚，仍伸手去挡顾长川手里的牌。

顾长川抓住这一瞬，用普通脚步向后退回自己的白线内侧。左手将合格牌带过线边，牌底稳稳落在白线以内。

他站住了。

周既明的手停在半空，脚却已经踩过判定线。

台上所有动作同时停下。

执事抬手指向顾长川手里的牌。

“顾长川，取牌回线，合格。”

他又看向周既明越线的脚。

“周既明越过判定线，阻拦失判。”

演武场前先是一静，随后议论声从队列里散开。

顾长川没有立刻松手。

直到执事走过来接走合格牌，他才发现自己的左手指节已经因为用力而发白。胸口仍然疼，右肩也像被重新扯开了一遍，可那股一直压在喉咙里的气终于松了下去。

执事将牌收回，转身向宁秋禾示意。

宁秋禾走到白线旁，看了看牌回线的位置，又看向封存名册。

“现场判定成立。”她说，“顾长川，本轮公开升院合格。”

顾长川站在白线内，没有说话。

这句话落下来时，他先看了一眼自己的右手。五指仍然不能完全合拢，肩膀也没有因此恢复。可他已经在众人面前拿到了结果。

不是候考名册上的一个位置，而是执事当众念出的“合格”。

“刚才那一下是什么步？”

队列里有人忍不住问。

另一个声音接着问：“你什么时候学会的？”

顾长川转过身，视线从人群上掠过，没有去看许照。

“刚才用过一次。”他说。

那人还想再问，顾长川已经收回了目光。

周既明拔出越线的脚，站在台上看着他。刚才那一下进攻落空，顾长川取牌后的回线也没有停手，直到他为继续阻拦越过白线，现场判定才结束。

“你一直等我真的进来。”周既明说。

“假动作不值得我动。”顾长川回答。

周既明看了一眼自己的脚，又看向台下的候考队列。他没有再把手脚藏起来，也没有像前两天那样只想着不让顾长川看见完整招式。

今天他点名顾长川，是当众阻拦。

顾长川也在当众从他面前取走了合格牌。

许照从队列中走过来，在顾长川身侧停了一瞬。她没有看周既明，只压低声音说：“你守约了。”

顾长川点了点头。

“我确认。”

许照看了他一眼，随后退回队列。两人之间没有多出一句客气话，也没有因此变成同伴。

宁秋禾合上名册，对顾长川说：“正式报到和后续安排，等宗门通知。今天只结算这一轮。”

“明白。”顾长川说。

他转身走下演武台，回到候考队列旁。

右肩的疼痛还在，胸口的牵扯也没有消失。刚才那一次换脚、转胯的步子已经无法再从身体里调出来，台心的合格牌也交回了执事手中。

可他仍然站在自己的白线之后，听见周既明重新站回另一条白线外。

这一次，周既明没有移开目光。

# Primary Fact Summary

清晨公开升院考核开始，宁秋禾按封存名册点名，执事宣布候考者必须在对手阻拦下取到台心合格牌并带回自己的白线。周既明主动点名顾长川并负责阻拦。顾长川在右肩和胸口伤势仍在的情况下等待周既明真实进攻，识别出假动作后只调用一次回身卸力步，取得合格牌，再用普通脚步完成回线。周既明为继续阻拦越过判定线，执事和宁秋禾确认顾长川本轮公开升院合格。回身卸力步使用后消失，顾长川没有声称自己已经学会；许照确认他遵守了交易约定。顾长川尚未正式入内门，报到和后续资源安排尚未发生，周既明成为公开竞争者。
