# Primary Draft

顾长川迈出演武场，脚步只落了一次，便停在了场外。

右肩的疼痛随着胸口起伏牵到腋下，右臂仍旧麻着，五指合不拢。这样的身体回住处躺一晚，明日照样要站上考核场。可他现在手里没有一门能用的招，回澜掌已经在滚石上用完，周既明也不会再把完整招式摆到他眼前。

他转过身，重新走向长案。

宁秋禾抬头看他：“还不回去养伤？”

“先问一件事。”顾长川停在案前，没有把右手撑上去，“今晚还能不能找到一门完整的招式给我看？”

宁秋禾看了一眼他垂着的右臂。

“名册已经封存。明日是公开考核，候考弟子各凭本事出手。我不会替你安排私斗，也不会泄露别人的底牌。”

“我不是来要名册，也不是来请师姐替我安排胜负。”顾长川说，“我只想找一个愿意示范的人，在规则内看一招。”

“你想看什么？”

“主要靠腿和腰改变站位的招。”顾长川顿了顿，“我现在不能再让右臂承担主要发力。比起更重的掌力，我需要先从正面脱开，换到合适的位置，明日还能有出手机会。”

宁秋禾没有立刻答应。

“若有人自愿，我可以在场见证一次。”她说，“示范必须在我看得清的距离内完成。你们不能互相试招，不能交换攻击，只能确认一次自愿、完整的观察机会。”

“可以。”

“只能一次。”

“我只看一个人。”

宁秋禾的目光在他脸上停了片刻，随后移向演武场边散去的候考弟子。

顾长川没有再看周既明。

周既明正在试石旁重新检查铁架，身体侧着，双手收在袖中。那种站位已经说明了他的选择。顾长川若再等他完整出招，只会等到明日。

场边还有几名候考弟子没有离开。顾长川的目光掠过他们，最后停在许照身上。

他以前在合练时见过许照的脚步。有人从正面逼近，她很少直直后退，而是先让开正面，再用腰胯把身体带到侧边。顾长川没有看过她完整做完一遍，却知道那正是自己现在需要的东西。

许照也看见了他。

她没有走近，只隔着几步看着他的肩膀：“你想看我的回身卸力步？”

“我想借的是一门能让开正面、把来力带偏，再改变站位的步法。”顾长川说，“招式名字可以等你愿意给我看之后再说。”

许照轻轻挑眉。

“明日我靠它上台。你凭什么觉得我会现在给你看？”

“因为我能告诉你周既明的回澜掌从哪里起力。”

许照的神情变了些。她没有说话，目光越过顾长川，落到试石旁的周既明身上。

顾长川继续说：“他的回澜掌不是先用右掌硬打。左胯先转，腰和肩把力量送出来，最后才从侧面把目标带开。你若等右掌到了眼前再躲，已经晚了。盯住他的左胯和腰肩，能看出他什么时候真正把力送出来。”

许照没有马上相信：“你只看了一遍。”

“看一遍够我把整套动作用一次。”顾长川说，“但回澜掌已经用完了。我现在要的是另一门适合伤势的招。”

许照看着他，像是在判断这句话里有没有藏着别的打算。

“你明日若借我的步对付别人，别人很快就会知道。到时候我自己的底牌也没了。”

“所以我接受你的条件。”

“你还没听。”

“你说。”

许照抬了抬下巴：“宁师姐在场。我只做一次完整示范。今晚你不能把我的步法告诉其他候考弟子，也不能把这次借招说成自己已经学会。”

顾长川点头：“我答应。”

“只答应得这么快？”

“我需要的是明日完整用一次的机会，不是把你的招式变成我的名字。”

许照盯着他看了一会儿，转向宁秋禾：“我自愿。”

宁秋禾从长案后走出来，站到能够同时看清两人的位置。

“顾长川站在原地。”她说，“许照，你自己决定示范范围。谁都不许靠近，谁都不许把示范变成交手。”

顾长川站到白线外，右臂自然垂在身侧。

许照走到空地中央，先没有开始。她看了看顾长川，又看向宁秋禾，忽然向斜前方落了半步。

她的肩背跟着偏过去，腰却只转了一半，后脚没有跟上。身体刚让出一点正面，她便把脚收了回来，重新站稳。

顾长川的视线停在她的脚下，没有向前追。

“这是试探。”他说，“不是完整示范。”

许照问：“你不抢着看？”

“你的重心没有换完，后脚也没跟上。半步对我没用。”

“如果我再藏一半呢？”

“那就不看。”

右肩的麻痛在这时又往胸口牵了一下。顾长川没有抬手，也没有往前跨。他只站在约定的位置，等许照自己决定。

宁秋禾看着许照：“示范是否继续，由你决定。”

许照收回目光。

她已经听见了自己想要的东西。周既明的力量不是从右掌突然出现，而是从左胯开始，经过腰肩，再沿侧面送出去。只要提前看住起力的位置，她明日就不用等掌风压到身前才躲。

这个消息值得她放弃一次保密机会。

许照转身走到空地中央。

“你把我当成从正面压过来的人。”她对顾长川说，“你不要动。”

顾长川站在原地。

许照双手自然垂下，先将前脚斜着让开。她没有直直后退，膝盖微微下沉，身体的正面随脚步移开一线。随后，她的左胯带着腰背回身，肩线同时转开，仿佛正面压来的力量沿着她转开的身体擦了过去。

她的后脚贴地跟上。

脚跟落稳时，她已经从原来的正面位置移到了斜侧，身体也重新对向前方。那股假想的来力没有撞在她身上，而是被她的转身带到了一旁。

她没有多走一步，立刻收住。

“这就是回身卸力步。”许照说。

顾长川看完了整套动作。

他记住了前脚让位的方向、膝盖下沉的时机、左胯带腰回身的顺序，以及后脚跟进后如何重新站稳。右肩没有参与发力，胸口也不需要承受正面硬撞。

他的右脚本能地想跟着落下，最后停在原地。

他没有试。

宁秋禾看完全过程，说：“完整，自愿，没有交手。”

顾长川对许照说：“周既明左胯转起来时，腰肩还没有把力量送足。你不要等右掌到面前，再让开正面。”

许照看向周既明，轻轻换了一点脚尖方向。

“这消息有用。”她说，“明日我会先看他的左胯。”

“我今晚不会告诉别人你的步法。”顾长川说，“也不会说自己已经学会。”

许照没有回应承诺，只看了他一眼。

她还在等明日，等着看他是否真的守约。

周既明已经从铁架旁直起身。他显然听见了刚才的话，目光先落在许照的脚下，再落到顾长川身上。

“你把我的起手卖出去了。”他说。

“我只说你从哪里起力。”顾长川回答，“你若明日换时机，没人逼你照今晚的顺序出掌。”

周既明没有立即发火。他看向许照，发现她的注意力已经不再停在自己的右掌上，而是落在左胯和腰肩之间。

他把原本向外斜出的右脚收回，重新换了一个站位。

“明日，我不会在你们想看的时候出手。”

顾长川说：“那就看你什么时候出手。”

周既明没有再说话。他低头将铁架旁一块松动的木片踢到边上，之后不再站在刚才那条完整力路上。

宁秋禾走回长案，把名册重新压在案面中央。

“示范结束。”她说，“许照自愿，顾长川只观察一次。名册不改，明日按原候考名册公开考核。”

顾长川点头。

他没有再向场边其他人看，也没有再问第二门招式。

离开演武场后，他走得很慢。右肩仍然疼，右手仍旧使不上力。回到住处前，他在院门外停了一下，低头看了看自己的脚。

回身卸力步的顺序清楚地留在身体里。

可他没有抬脚试走。

这门步法明日可以完整调用一次。现在多走一步，便可能把明日唯一的机会丢在今晚。

天亮时，青崖宗外门演武场已经重新站满了人。

长案摆在白线旁，候考弟子按照名册排成队列，执事和围观的外门弟子站在场边。宁秋禾站在长案前，手边放着已经封存过的考核名册。

许照站在队列另一侧，回头看了顾长川一眼。她没有开口。

周既明站在靠前的位置，脚尖没有摆成昨晚回澜掌的起手。他也看见了顾长川，却没有再把身体侧过来。

顾长川站在队列里，右肩仍未痊愈，回身卸力步还没有用过。

宁秋禾展开名册，叫出第一名候考弟子的名字。

白线之内，公开考核开始了。

# Primary Fact Summary

顾长川因明日必须参加公开升院考核，返回长案寻找一门适合伤势的完整招式。他明确要求招式主要依靠腿腰改变站位，不让受伤右臂承担主要发力。

宁秋禾拒绝替顾长川安排私斗或泄露他人底牌，但同意见证一次自愿、完整、受控的示范，规定双方不得试招或交换攻击。

顾长川选择许照作为出招对象，并以周既明回澜掌的关键力路作为交换信息：左胯先转，腰肩送力，右掌从侧面带开目标。

许照先用半步和假转身试探顾长川是否会抢看后半招。顾长川停在约定位置，没有把试探当成完整招式，也没有消耗借招机会。

许照在宁秋禾见证下完整示范一次回身卸力步。顾长川获得明日可完整调用一次的临时借招，但本章没有使用，没有永久学会，也没有同时保存多招。

许照得到应对周既明回澜掌的关键时机信息，并继续观察顾长川是否守约。周既明得知顾长川可以通过信息交换获得别人的招式，开始调整明日的出招时机。

宁秋禾确认名册不变，明日按原候考名册公开考核。章末公开升院考核已经开始，顾长川带着未使用的回身卸力步和未痊愈的右肩进入候考队列。
