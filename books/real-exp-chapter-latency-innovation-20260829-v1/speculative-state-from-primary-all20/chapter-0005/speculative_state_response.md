# Proposed Persistent Canon

### Power / Capability

顾停舟已证明可从影子中分出一个自身，短时间同时执行另一处的简单动作；分身曾定住矿车。分身不能承担复杂自主行动，持续时间与完整代价仍未知；回归后会造成胸闷、腿软。

### Active Relationships

乌合｜保护砺骨部迁徙道并维持水路控制｜与主角形成有限度的相互承认，尚非盟友｜顾停舟让砺骨部先行，承担实测延误与赔付风险｜顾停舟以后能否通行仍未定。

### Identity / Access

顾停舟拥有合法独立行潮籍，可用本人名义接案、登记路线结果、持有潮器并独立承担潮路风险；已签署阮青蜃名下的新裂槽实测契。

### Knowledge / Enemy State

砺骨部迁徙道横穿界桩后的浅滩，关键石脊由砺骨部看守；矿队暂缓钉标并承担延误后果。新裂槽尽头已显出倒悬峡及残破建筑入口；倒悬峡内部情况未知。顾停舟已明确承担让路造成的期限、尾款扣减及护卫耗费风险。

### Tracked Assets

实测契｜顾停舟｜本人内袋｜仍有效，但延误责任与尾款风险已由顾停舟承担｜本章继续持有

### World State

砺骨部完成本次迁徙并重新划明水路看守边界；倒悬峡及其下方残破建筑因退水首次显露，成为新裂槽实测入口。

# Proposed Chapter Summary

界桩前，顾停舟发现矿队钉下黑铁长桩会堵住砺骨部唯一可通行的迁徙石脊，遂让矿队暂缓钉标并由自己承担实测延误、尾款扣减与护卫耗费。砺骨部完成迁徙后重新封守水路。低潮继续下退，倒悬峡与残破建筑入口显露，矿队立即携测路杆和绳索抢先进峡，顾停舟也面临进入实测的窗口。
