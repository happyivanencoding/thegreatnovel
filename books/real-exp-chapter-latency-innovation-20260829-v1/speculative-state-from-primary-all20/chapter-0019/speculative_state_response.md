# Proposed Active Scene State

地点：旧关内侧与外层废墟交界。  
在场人物：顾停舟、顾沉戈、旧关守将、镇潮军府人员。  
即时伤势：旧伤撕裂，胸口剧痛，衣袍被血浸透，照域消散后近乎失力。分身手腕裂伤。  
手中关键物品：照域潮谱、回潮楔、结算文书、潮钱票据、战功牌。  
当前敌人或追兵：镇海潮兽已被推回旧关外深潮，暂未再次冲入。  
当前倒计时：无明确倒计时。  
下一步直接目标：养伤并寻找能够修复回潮楔的人。  
当前主动目标：修好回潮楔，并评估结算所得是否足以购买潮舟、离开旧关。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟以照域正面承受镇海潮兽冲击，并配合分身与回潮楔改向潮路，保住粮道、三座新井、居民与粮车。
- 照域可在顾停舟判断下承接并引导镇海潮兽级别的潮压，但会造成严重伤势，当前无法再次硬撑。
- 分身可用“定住”暂时钉住关键潮眼；本次与顾停舟完成正面承压、侧面定潮的协同。
- 回潮楔新增贯穿性裂痕，持续散出细碎潮压，暂时不能再强行承压，否则可能碎裂。
- 顾停舟正式战绩被镇潮军府公开入册。

### Active Relationships

- 顾沉戈｜协助顾停舟养伤并处理后续事务｜可信任的临时协作关系｜共同挡住镇海潮兽并保住内侧设施｜暂无未决承诺
- 旧关守将／镇潮军府｜承认并记录顾停舟的战功，已完成矿利与护粮结算｜正式协作关系增强｜公开确认战绩并兑现账目｜后续可能继续合作
- 阮青蜃矿队｜已撤离，矿权标记失效｜仍存在矿利与矿权追索背景｜顾停舟放弃尾款但保留个人矿利已完成结算｜后续追索仍可能发生

### Identity / Access

- 顾停舟仍是照域潮谱持有人。
- 顾停舟获得镇潮军府公开战功记录及战功牌，后续在军府体系中的待遇与可信度提升。

### Knowledge / Enemy State

- 镇海潮兽会循照域改开的潮路追来，并能持续对照域施加正面冲击。
- 镇海潮兽本次被改向潮水推回旧关外深潮，暂时没有继续冲击内侧。
- 顾停舟确认自己无法在当前伤势与照域负荷下连续承受第二次同等冲击。

### World State

- 旧关外层残墙、空屋、石仓及遗留潮车、压潮器被潮水吞没，外层防线实质失守。
- 粮道、三座新井、北侧高地居民与粮车均保住。
- 镇潮军府已公开承认顾停舟在镇海战局中的战绩，相关战功进入正式记录。

### Tracked Assets

- 照域潮谱｜顾停舟｜手中｜本次完成镇海级正面承压后已收起｜未转移
- 回潮楔｜顾停舟｜手中｜新增贯穿性裂痕，持续散压，暂不可强行使用｜本章由分身带回并交还
- 承运短契｜顾停舟｜顾停舟｜仍有效｜本章未变化
- 个人矿利与护粮结算｜顾停舟｜防潮木匣内｜已兑现为结算文书与潮钱票据｜本章正式交付
- 镇潮军府战功牌｜顾停舟｜防潮木匣内｜已获得，战功正式入册｜本章正式交付
- 黑铜矿权标记｜阮青蜃一方｜矿坑口泥中｜纹路失效，已无现场独占效力｜未变化

# Proposed Chapter Summary

顾停舟与顾沉戈、镇潮军府协同，将镇海潮兽的冲击引向已放弃的旧关外层，并以照域、分身和回潮楔改退潮路，保住粮道、三座新井、居民与粮车。镇海潮兽被推回深潮，顾停舟重伤，回潮楔再添裂痕。军府公开记功并兑现矿利、护粮结算，顾停舟开始考虑寻找修楔者和购买潮舟。

# Proposed Open Promises

- 镇海潮兽为何循照域改开的潮路而来，以及它与照域潮谱的关系。
- 镇海潮兽被推回深潮后是否会再次追来。
- 回潮楔新增裂痕能否修复，以及修复所需代价。
- 顾停舟重伤后的恢复与照域再次使用条件。
- 顾停舟能否用结算所得买到合适的潮舟。
- 顾停舟寻找修楔者与潮舟时将进入何种新的关系或势力。
- 地潮提前涌入的原因、范围与后续推进速度。
- 第一批承运完成后，顾停舟与少东子的后续合作边界。
- 唐绾以反潮记录铸成的作品及其实际用途。
- 阮青蜃对矿权标记失效及矿利分配的后续追索。
