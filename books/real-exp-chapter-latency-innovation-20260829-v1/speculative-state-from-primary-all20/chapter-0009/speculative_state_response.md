# Proposed Persistent Canon

### Power / Capability

- 回潮楔可被牵引拖入侧壁潮口，并通过改变楔面朝向将蓄积潮压导向另一侧。
- 回潮楔释放潮压后会造成定向冲击；当前楔体出现细裂，仍残留持续余震与潮压。
- 分身可在裂缝另一侧持续牵引回潮楔，与本体协同完成跨壁转移。
- 回潮楔残留潮压可灌入顾停舟体内，与兼容潮髓共同撑大腹中潮炉，但尚未形成真正的炉。
- 合体会集中分身期间分担的撞击、牵引与割伤。

# Proposed Chapter Summary

顾停舟发现正面逆潮与侧壁潮口相通，借分身牵引将蓄满的回潮楔拖入侧壁并重新钉入黑石，成功把潮压导向侧壁，冲开撤路，救出两侧全部人员。矿权标记被冲碎，回潮楔出现细裂；合体后的残留潮压与兼容潮髓撑大腹中潮炉。阮青蜃随后提出契约追索。
