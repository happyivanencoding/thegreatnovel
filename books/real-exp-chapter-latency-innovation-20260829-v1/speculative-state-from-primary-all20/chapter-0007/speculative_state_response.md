# Proposed Active Scene State

地点：倒悬峡峡底，侧室坍塌后的石脊与高石区域。  
在场人物：顾停舟、分身、乌合、矿队人员、砺骨部前哨。  
即时伤势：顾停舟手背磨伤、胸闷腿虚；分身肩部受撞；一名前哨腿伤。  
手中关键物品：顾停舟持有金属楔；测路杆仍在身边。  
当前敌人或追兵：无明确敌人；逆潮、坍塌石堆与残余水势构成危险。  
当前倒计时：逆潮仍在冲击，峡底通行条件尚未稳定。  
下一步直接目标：带幸存人员撤离危险区，确认金属楔的作用与安全携带方式。  
当前主动目标：保住救援成果并掌握金属楔，重新争取倒悬峡实测的主动权。

# Proposed Persistent Canon

### Power / Capability

- 分身已在侧室内完成牵引救援，并强行取出金属楔；本体与分身可协同完成救援及目标夺取。
- 金属楔接触逆潮后能够吸收并锁住正面潮压；具体机制与限制未知。
- 分身承担强力牵引后出现肩部撞伤与明显负荷代价。

### Active Relationships

乌合｜优先救援砺骨部人员并撤离｜与主角形成更高程度的现场信任｜亲眼见证顾停舟将救援置于矿权与入口之上｜救援后仍需确认通行与责任边界

### Identity / Access

- 原矿权标记已损毁，矿队对倒悬峡入口的现场控制与实测权限暂时失效。
- 顾停舟实际掌握从坍塌侧室取出的金属楔。

### Knowledge / Enemy State

- 侧室内部存在金属楔，其牵扯会吸收周围水流与碎石。
- 金属楔脱离石座后，侧室牵扯失稳并导致入口彻底坍塌。
- 矿队首领曾试图同时利用分身救人、守门并保住金属楔，已与顾停舟形成明确利益冲突。
- 实测尾款、入口坍塌责任与人员救援责任尚未结算。

### World State

- 倒悬峡古代建筑侧室入口已被逆潮与坍塌彻底掩埋。
- 矿队原有黑铁矿权标记已裂毁并被埋入石堆，现场矿权秩序失效。

### Tracked Assets

金属楔｜顾停舟｜倒悬峡峡底石脊｜已从侧室石座取出，接触逆潮时产生锁潮反应｜分身从侧室交给顾停舟  
黑铁矿权标记｜矿队｜坍塌侧室石堆中｜裂成两半并被掩埋，暂时失效｜被逆潮卷入坍塌处

# Proposed Chapter Summary

顾停舟利用半截矿索救出左侧两名矿工，并让分身从侧室救出两名砺骨部前哨。面对矿队首领试图兼顾守门与夺取金属楔的要求，他压住拉索，命分身取出楔子。侧室随后坍塌，矿权标记被掩埋；金属楔在顾停舟手中显现出锁住逆潮潮压的异常作用。

# Proposed Open Promises

- 顾停舟确认金属楔锁住潮压的具体作用、限制与使用风险。
- 逆潮持续冲击下，幸存人员撤离与峡底通行条件是否稳定。
- 矿权标记损毁、入口坍塌后的实测权限、尾款与赔付责任。
- 新裂槽实测的入口、走向、危险点与承载路线仍未完成。
- 顾停舟使用兼容潮髓后，对养潮与影中分身代价的影响。
- 少东家与顾停舟在裂槽或货运利益上的具体冲突与合作边界。
- 乌合与顾停舟形成具体的信任边界、吸引和未被安全化的长期关系。
- 第一世界终局完成带母亲远游，并触发已批准的 World Horizon Handoff。
