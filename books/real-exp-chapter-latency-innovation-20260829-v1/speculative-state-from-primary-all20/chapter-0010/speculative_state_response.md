# Proposed Persistent Canon

### Power / Capability
- 顾停舟已正式成炉，潮息可在体内稳定结炉，能够独自稳定撤离车并承受短时余震重压。
- 成炉后的力量无法完整传给分身；分身只能携带一种超凡本事，承载潮炉会出现潮纹并失稳。
- 回潮楔仍可导向潮压，但细裂继续加深，残压与成炉状态的后续影响未明。

# Proposed Chapter Summary

顾停舟在峡外余震中独自稳住即将翻落的撤离车，体内潮炉由暂时撑大正式成炉，但成炉力量无法完整传给分身。面对矿队与阮青蜃，他承认尾款落空，却拒绝将回潮楔并入矿契，归属与损失由对方正式追索。乌合确认救命人情仍在，但要求未来协作先谈价格。此时唐绾传讯索要反潮记录。
