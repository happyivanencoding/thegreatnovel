在场人物：顾停舟、母亲；潮市船客与商贩。

# Proposed Persistent Canon

### Power / Capability

- 照域与回潮楔曾共同改退镇海潮兽，但回潮楔已严重开裂，暂时无法承压。
- 分身使用“定住”后手腕受伤，恢复情况未明确。

### Active Relationships

- 顾沉戈｜负责旧关撤防、补粮与安置｜并肩协作关系｜为撤离居民和顾停舟承担旧关外层责任｜未来是否再会未定
- 少东家｜愿按独立合作谈生意｜独立合作关系｜撕毁旧账房契并取消长期债契｜未来合作待定
- 唐绾｜继续铸潮器，暂时无法修楔｜保持合作可能｜明确表示当前修不了回潮楔｜待其具备修复能力
- 阮青蜃｜若有争议自行下场争，合作需另谈｜边界明确的潜在合作/竞争关系｜不再以长期债契相压｜后续动向未定
- 母亲｜随顾停舟离开旧关前往远方潮市｜亲近家人关系｜接受同行并登上潮舟｜共同适应新生活

### Identity / Access

- 顾停舟拥有自己购置的小型潮舟、船契与行潮凭据，可独立出发，不再受旧账房契约束。

### Knowledge / Enemy State

- 旧关外层已正式废弃，居民迁往北侧与粮道内圈。
- 粮道与三座新井由军府及各方共护。
- 镇海潮兽与照域潮谱之间的关系仍未确认。

### World State

- 旧关外层不再复建，旧有部分规矩与账目体系随废墟终止。
- 顾停舟与母亲已乘潮舟抵达一座此前未知的远方潮市。

### Tracked Assets

- 小型潮舟｜顾停舟｜远方潮市泊位｜已购置，可载人和少量行李｜本章以票据换回船契
- 行潮凭据、船契｜顾停舟｜防潮木匣内｜有效｜本章购船取得
- 回潮楔｜顾停舟｜潮舟上防潮布包裹于木匣内｜严重开裂，暂不可承压｜唐绾托人送来防潮布
- 照域潮谱｜顾停舟｜潮舟上木匣内｜持有，作用边界未明｜随顾停舟离开旧关

# Proposed Chapter Summary

旧关外层被正式宣布废弃，居民、新井与粮道转入新的共护安排，顾停舟与少东家、唐绾、阮青蜃分别划清旧账并确定新的合作边界。他用战后所得购置一条小型潮舟，带母亲离开旧关，数日后抵达陌生的远方潮市。

- 唐绾何时具备修复回潮楔的能力。
