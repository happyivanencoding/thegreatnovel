# Proposed Active Scene State

地点：旧关内侧残余潮场、矿脉外至照域边缘。  
在场人物：顾停舟、顾沉戈、旧关守将、镇潮军府人员；镇海潮兽已进入潮场。  
即时伤势：旧伤剧烈牵动、胸闷咳血；照域持续承压。  
手中关键物品：照域潮谱、回潮楔、承运短契。  
当前敌人或追兵：镇海潮兽，正朝顾停舟冲来。  
当前倒计时：镇海潮兽即将撞入旧关内侧；黑水持续抬高。  
下一步直接目标：在旧关内侧挡住镇海潮兽，守住人员、粮道与新井。  
当前主动目标：守住旧关内侧最后防线，阻止镇海潮兽突破照域潮场。

# Proposed Persistent Canon

### Power / Capability
- 照域潮谱可沿既有潮路照出通行石路，并使矿权标记上的矿纹熄灭、失效。
- 照域在镇海潮兽冲入潮场后受到强烈震荡，持续承压会加重顾停舟旧伤并引发吐血。

### Active Relationships
- 顾沉戈｜协助守住粮道与旧关内侧｜与主角保持临时执行关系｜随主角前往矿脉并制止管事强留人员｜共同迎战镇海潮兽
- 旧关守将｜封住南坡、守住新井与撤离路线｜与主角保持临时协作｜军府见证尾款放弃与矿权标记失效｜继续守住旧关内侧
- 乌合／砺骨部前哨｜接续迁徙水路｜与主角保持有限互用｜带领矿队与迁徙人员通过北侧水路｜后续维持水路撤离
- 阮青蜃矿队｜已撤离矿脉坑口｜与主角存在未决追索关系｜放弃继续守坑，个人矿份额暂保留｜后续可能追索尾款、矿利与矿权
- 少东家｜完成第一批粮运｜与主角保持契约合作｜粮车已脱离最窄危险段｜承运仍未最终完成

### Identity / Access
- 顾停舟仍是照域潮谱当前持有人，并在军府、砺骨部与幸存者见证下取得矿脉公共水路边界的现场处置权。

### Knowledge / Enemy State
- 镇海潮兽明确盯住照域潮谱，并已进入照域撑开的潮场。
- 镇海潮兽进入潮场后堵塞引流空间，使黑水翻涌、照域边缘震荡。
- 阮青蜃一方的黑铜矿权标记已在众目睽睽下失效并被踩入泥中。
- 首批矿脉不再由阮青蜃一方独占；顾停舟公开放弃全部实测尾款，但个人矿利仍保留。

### World State
- 矿队已撤离矿脉，砺骨部迁徙窗口重新接通，北侧水路开始承担迁徙。
- 旧关外层潮场被镇海潮兽堵塞，旧关内侧成为当前最后可承受冲击的防线。

### Tracked Assets
- 照域潮谱｜顾停舟｜手中｜持续启用并承受镇海潮兽冲击｜照出矿脉至北侧水路并使矿权标记失效
- 回潮楔｜顾停舟｜袖中｜残压紊乱，暂不可连续使用｜状态未改变
- 承运短契｜顾停舟｜怀中｜仍有效，粮运未最终完成｜状态未改变
- 三座新潮井｜顾沉戈及守井人员｜旧关外粮道旁｜仍可用，需防潮水倒灌｜旧关守将已部署防守
- 黑铜矿权标记｜阮青蜃一方｜矿脉坑口泥中｜矿纹熄灭、标记失效｜被乌合踩入泥中

# Proposed Chapter Summary

顾停舟得知阮青蜃矿队为首批矿物拒绝撤离，决定放弃全部实测尾款换取人员撤出，并在军府、砺骨部与幸存者见证下使黑铜矿权标记失效。矿队与迁徙人群成功转移，镇海潮兽却进入潮场并冲向旧关内侧，顾停舟选择留下迎击。

# Proposed Open Promises

- 镇海潮兽为何循照域改开的潮路逼近，以及它与照域潮谱的关系。
- 顾停舟能否在旧伤与照域负荷下挡住镇海潮兽。
- 地潮提前涌入的原因、范围与后续推进速度。
- 第一批粮能否完成旧关承运。
- 照域在镇海潮兽冲击下的持续时间、范围与承受上限。
- 回潮楔残压何时散尽，以及下一次使用的代价。
- 砺骨部迁徙水路能否持续容纳撤离居民。
- 顾停舟个人矿利的首批核定、开采与兑现。
- 阮青蜃对尾款放弃、矿利及失效矿权标记的后续追索。
- 唐绾以反潮记录铸成的作品及其实际用途。
- 第一批承运完成后，顾停舟与少东家的后续合作边界。
