# Proposed Persistent Canon

### Power / Capability

顾停舟已证明可从影子中分出一个自身，短时间同时执行另一处的简单动作；分身曾定住矿车。分身不能承担复杂自主行动，持续时间与完整代价仍未知；回归后会造成胸闷、腿软。

### Active Relationships

少东家｜经营商号并独立接案｜旧友兼前实际雇主，现为有利益冲突的同行者｜双方明确不再互相代替做主或承担账目｜未来同路相遇时按价谈、按事互助  
阮青蜃｜等待新裂槽路线结果｜正式委托人｜已通过承事签下个人实测契｜待顾停舟提交结果  
校路官｜维持独立行潮籍与实测登记｜认可顾停舟的独立实测资格｜已核准行潮籍并盖章实测契｜待接收路线结果  

### Identity / Access

顾停舟拥有合法独立行潮籍，可用本人名义接案、登记路线结果并收取赔付；已签署阮青蜃名下的新裂槽实测契。实测队认可其凭行潮牌和实测契入队。

### Knowledge / Enemy State

新裂槽实测范围、赔付条件与风险中止权已写入契约；砺骨部控制新裂槽前方水路边缘，商盟契约在界桩处不再自动有效；继续通行规则与砺骨部立场未知。

### Tracked Assets

独立行潮牌｜顾停舟｜本人身上｜合法接案与登记资格｜校路台核发  
实测契｜顾停舟｜本人身上｜阮青蜃名下，下一次低潮前核查新裂槽｜承事交付并由校路台盖章

原路线册｜顾停舟｜本人身上｜仍为个人现场对照依据｜顾停舟持续持有
