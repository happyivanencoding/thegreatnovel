# Proposed Active Scene State

地点：旧关外层，第三座新潮井与粮道之间。  
在场人物：顾停舟、少东家、顾沉戈、守将、砺骨部传话人及粮车队、撤离居民。  
即时伤势：胸闷，旧伤未愈；未再次使用回潮楔。  
手中关键物品：残压未散的回潮楔、承运短契。  
当前敌人或追兵：提前涌入的地潮；黑潮、塌坡、裂井和倒塌建筑正阻断道路。  
当前倒计时：地潮已提前到达，粮车和撤离行动正在即时受阻。  
下一步直接目标：处理第三井前的潮水与障碍，避免粮车、井位和撤离人群被一起冲垮。  
当前主动目标：在不硬压回潮楔的前提下，保住粮车和三座新井，并打开居民撤离通路。

# Proposed Persistent Canon

### Power / Capability
- 回潮楔残压仍未散尽，顾停舟尚不能再次硬压地潮。
- 顾停舟已证明能在多方冲突中现场划分井、粮道、城门与水路的责任，并促成各方执行。

### Active Relationships
- 顾沉戈｜守三座新潮井与粮道｜与主角存在分歧但已接受其分工｜在粮车可撤回的压力下答应守井守粮道｜需继续处理第三井与粮道阻断
- 守将｜负责外层居民撤离｜与主角形成临时行动协作｜接受“撤人而非守屋”的方案｜撤离通道已被地潮部分堵塞
- 砺骨部传话人｜负责西侧水路及优先撤出西侧居民｜与主角形成有限互相承担责任的协作｜承诺先带外层西侧居民过水路｜土坡塌陷，水路当前受阻
- 少东家｜完成第一批粮运｜与主角维持契约合作｜在主角提出可按契撤回时仍允许车队待命｜粮车已卡在第三井前

### Identity / Access
- 顾停舟仍以独立承运人身份行动，承运短契允许在道路不可行时撤回。

### Knowledge / Enemy State
- 地潮已确认提前涌入旧关外层，不再是十二日后的远期威胁。
- 第三座新潮井井口破裂，潮压会同时威胁粮道、粮车与撤离路线。
- 西侧水路存在泥软、塌坡和不可贸然下水的现实风险。

### World State
- 旧关外层已进入提前地潮灾情，外层石屋、居民撤离线、三座新潮井和粮道同时受到影响。
- 旧关当前已形成临时分工：守将撤人，顾沉戈守井和粮道，砺骨部负责西侧水路。

### Tracked Assets
- 第一批粮｜少东家粮车队｜旧关外层第三井前｜第一辆车前轮过井后全队受阻｜本章由驶入粮道转为被地潮卡住
- 回潮楔｜顾停舟｜袖中｜已修复、残压未散｜本章未使用
- 承运短契｜顾停舟｜怀中｜有效｜主角以道路不可行时可撤回为依据施压

# Proposed Chapter Summary

粮车抵达旧关外层后，顾停舟在顾沉戈、守将和砺骨部传话人之间划分守井、运粮、撤民与水路责任，促成临时协作。第一辆粮车刚过第三座新潮井，提前到来的地潮便冲裂井口、冲垮石屋与水路，堵住粮车和撤离通道，三方安排同时陷入危局。
