# Proposed Active Scene State

地点：前往百炉城的撤离车队上。  
在场人物：顾停舟、乌合、砺骨部前哨、矿工与撤离人员；阮青蜃和矿队暂留断路处。  
即时伤势：胸闷咳血，肩背与手臂受伤，腿虚；成炉后仍有过载风险。  
手中关键物品：细裂加深的回潮楔、矿路实测契原件、反潮记录原件、矿样余存。  
当前敌人或追兵：矿队与阮青蜃继续追索撤路损失、尾款及回潮楔归属。  
当前倒计时：百炉会开炉试窗口即将关闭，回潮楔修复也不能久拖。  
下一步直接目标：赶往百炉城，寻找修复回潮楔的办法并争取开炉试机会。  
当前主动目标：保住回潮楔与实测证据，赶在开炉试窗口关闭前进入百炉城。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟已正式成炉，潮息可贯通潮脉与四肢，能在重压下稳定撤离车。
- 成炉力量持续承载能力与身体代价尚未确认。
- 分身只能承载一种超凡本事，无法承受完整潮炉力量。

### Active Relationships

- 乌合｜按价协作并取得现钱、矿样｜与主角形成已结清本次合作的互惠关系｜本次救援费用已结清｜未来进百炉城时优先替砺骨部搭一次问路或换货的线
- 阮青蜃｜维持现场契约与证据秩序｜与主角处于公开契约冲突但暂未强行夺楔｜确认现场暂由顾停舟持有回潮楔｜矿队损失与古器归属仍待继续结算
- 矿队首领｜追索撤路、尾款与回潮楔相关损失｜与主角公开对立｜其先毁撤路的事实已被现场证人指出｜后续追索与责任争议未决
- 唐绾｜接收反潮记录并协助判断回潮楔修复与开炉试机会｜与主角保持信息合作｜已收到反潮记录副本并回信确认修复可能｜修复方式与百炉城安排未决

### Identity / Access

- 顾停舟仍以个人持有者身份公开持有回潮楔，矿队归属异议持续存在。
- 顾停舟持有矿路实测契原件、反潮记录原件及部分矿样。
- 已获得进入百炉城并争取开炉试窗口的现实方向，但准入尚未确认。

### Knowledge / Enemy State

- 现场已确认矿队首领先毁撤路；回潮楔由顾停舟实际使用并完成救援。
- 获救者不能被矿队单方面归为无主损耗。
- 回潮楔仍有修复可能，但裂痕已继续加深。
- 百炉会开炉试窗口即将关闭。

### Tracked Assets

- 回潮楔｜顾停舟｜撤离车队上｜细裂加深，仍有残压｜持续持有
- 矿路实测契原件｜顾停舟｜贴身携带｜受潮、印记模糊｜持续持有
- 反潮记录原件｜顾停舟｜贴身携带｜受潮后半干，内容完整｜副本已送往唐绾处，原件未转移
- 反潮记录副本｜唐绾｜由传信人送达｜已封存送出｜顾停舟交付，唐绾已收到
- 矿样余存｜顾停舟｜撤离车队｜部分已按市价交给乌合，深色样料仍保留｜本章部分转移给乌合

# Proposed Chapter Summary

顾停舟在撤离车旁以三项事实厘清责任：矿队首领先毁撤路，回潮楔由他使用并完成救援，获救者不能被算作无主损耗。乌合按价取得现钱、矿样及一次未来搭线承诺。阮青蜃暂定回潮楔仍由顾停舟持有。顾停舟将反潮记录副本送给唐绾，得知回潮楔尚可修复且百炉会开炉试窗口将闭，遂决定立即前往百炉城。
