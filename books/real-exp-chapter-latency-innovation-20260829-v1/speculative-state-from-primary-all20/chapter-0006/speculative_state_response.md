# Proposed Active Scene State

地点：倒悬峡峡底，建筑侧室与左右石林、断墙之间的逆潮水域。  
在场人物：顾停舟、分身、矿队矿工与护卫、乌合及砺骨部前哨。  
即时伤势：顾停舟腿部仍虚乏、胸闷，手背被绳索磨伤；一名砺骨部前哨腿部受伤；多名人员被逆潮困住。  
手中关键物品：测路杆；绳索分散在救援人员手中。  
当前敌人或追兵：无直接敌人；逆潮、水幕、侧室牵引持续造成威胁。  
当前倒计时：逆潮持续翻卷，侧室牵引可能将右侧人员拖入；左侧矿工所在石台正在失稳。  
下一步直接目标：本体将左侧两名矿工带到可接绳位置；分身进入侧室，只拉出被困人员，不触碰内部物品；乌合稳住右侧前哨。  
当前主动目标：在不触碰侧室内部未知事物的前提下，先完成两侧人员救援并维持实测现场。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟已在逆潮现场再次形成可行动分身。
- 分身可替顾停舟额外占据一个救援位置，但只能执行一种预先选定的能力；本次分身携带牵引能力。
- 分身可独立进入侧室执行预先限定的拉人任务，但不得据此推断其能处理侧室内部未知事物。

### Active Relationships

乌合｜救住砺骨部前哨并维持队伍位置｜从有限认可进入现场协同行动｜顾停舟将救援分工交给她，她立即收紧绳索执行｜未决：双方如何处理本次救援后的通行与信任边界

### Knowledge / Enemy State

- 建筑外层潮泥压制峡底潮向；撬开后引发逆潮翻转。
- 半开的石门与侧室存在持续牵引，会将附近水流和碎石拖入；内部情况仍未知。
- 矿队黑铁矿权标记已被逆潮拔出并损坏，未能稳定占住石台。

### World State

- 倒悬峡建筑的外层结构与峡底潮向存在直接关系；外壳破坏会引发大范围逆潮。
- 砺骨部前哨已进入倒悬峡并与矿队共同受逆潮影响。

### Tracked Assets

黑铁矿权标记｜矿队｜建筑前石台附近泥水中｜牌面裂开、短桩被拔出｜被逆潮冲离原石台

# Proposed Chapter Summary

顾停舟随矿队进入倒悬峡，发现倒流水幕、倒置石林与被潮泥覆盖的古代建筑。矿队强行撬开外层潮泥后引发逆潮，黑铁矿权标记被拔出，多名矿工与砺骨部前哨受困。顾停舟让分身携带牵引能力进入侧室救人，本体则前往左侧石林救援矿工。
