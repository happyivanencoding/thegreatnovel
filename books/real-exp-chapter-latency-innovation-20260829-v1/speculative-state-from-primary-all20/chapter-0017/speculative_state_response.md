# Proposed Active Scene State

地点：旧关内侧石脊与粮道交界、照域潮场边缘。  
在场人物：顾停舟、顾沉戈、旧关守将、粮车队、守井人员；撤离居民已通过石脊；镇海潮兽正在逼近。  
即时伤势：胸口旧伤受潮压重击，咳血、眼前发黑；仍可维持照域潮场。  
手中关键物品：照域潮谱、回潮楔、承运短契。  
当前敌人或追兵：镇海潮兽沿照域改开的潮路逼近，目标疑似为照域潮谱。  
当前倒计时：镇海潮兽即将抵达石脊与粮道；阮青蜃的矿队仍在矿脉附近，可能即将遭遇潮兽或潮势。  
下一步直接目标：判断并应对镇海潮兽，同时确认阮青蜃矿队的位置与生死。  
当前主动目标：保住照域潮谱，并处理镇海潮兽对矿队、粮道和新井造成的威胁。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟已正式进入照域，能够借照域潮谱铺开潮场，改变一整段潮势的冲向，暂时稳住石脊并为粮道让出通行空间。
- 照域潮场仍受正面潮压冲击；维持范围越大，顾停舟承受的身体负荷越重。
- 分身可进入潮势正面承压，与本体的伤害和冲击同步反馈；镇海级潮压已令本体重创。

### Active Relationships

- 顾沉戈｜继续守住粮道与新潮井｜与主角保持临时执行关系｜见证顾停舟正式进入照域｜需协同应对镇海潮兽
- 旧关守将｜保护撤离居民并守住石脊｜与主角保持临时协作｜确认照域已救出撤离队伍｜需应对镇海潮兽逼近
- 少东家｜完成第一批粮运｜与主角保持契约合作｜粮车已在照域让出的窄路继续通行｜承运仍未最终完成
- 阮青蜃矿队｜仍在矿脉附近｜与主角存在矿利及旧损失牵连｜被确认尚未撤离｜生死与位置待确认

### Identity / Access

- 顾停舟已成为照域者，获得以照域潮谱介入整段潮场的现实权限。

### Knowledge / Enemy State

- 照域潮谱被顾停舟从石台取出并正式掌握。
- 镇海潮兽已出现，能够沿照域改开的潮路逼近，并将注意力锁定在照域潮谱上。
- 阮青蜃的矿队仍滞留矿脉附近。

### World State

- 照域暂时压开石脊外侧潮水，在粮道与新潮井之间形成一片可通行、可防守的区域。
- 撤离居民已通过石脊，最慢的队伍暂时脱离黑水追击。

### Tracked Assets

- 照域潮谱｜顾停舟｜手中｜已取下并激活，持续维持潮场｜本章由石台转入顾停舟掌握
- 回潮楔｜顾停舟｜袖中｜残压紊乱，暂不可再次使用｜未转移
- 承运短契｜顾停舟｜怀中｜仍有效，粮运未完成｜未转移
- 第一批粮｜少东家粮车队｜旧关内侧粮道｜已脱离最险窄段，继续通行｜未完成承运
- 三座新潮井｜顾沉戈及守井人员｜旧关外粮道旁｜仍可用，暂受照域保护｜未转移

# Proposed Chapter Summary

顾停舟从即将被潮压吞没的石台取下照域潮谱，正式进入照域。他以潮谱铺开潮场，配合分身承压，暂时推开黑水、稳住石脊，让撤离居民和粮车通过。潮场稳定后，镇海潮兽沿改开的潮路逼近，并锁定顾停舟手中的潮谱；同时有人报知阮青蜃的矿队仍困在矿脉附近。

# Proposed Open Promises

- 镇海潮兽为何锁定照域潮谱，以及顾停舟能否应对其逼近。
- 阮青蜃矿队是否仍存活，能否从矿脉附近撤出。
- 照域潮场能维持多久，以及继续扩大或承压的代价。
- 地潮提前涌入的原因、范围与后续推进速度。
- 第一批粮能否完成旧关承运。
- 回潮楔残压何时散尽，以及下一次使用的代价。
- 砺骨部迁徙水路能否持续容纳撤离居民。
- 顾停舟个人矿利的首批核定、开采与兑现。
- 阮青蜃对回潮楔、矿利及旧损失的后续追索。
- 唐绾以反潮记录铸成的作品及其实际用途。
- 第一批承运完成后，顾停舟与少东家的后续合作边界。
