# Proposed Active Scene State

地点：倒悬峡峡底逆潮边缘、峡壁旧裂缝与高石之间。  
在场人物：顾停舟、分身、乌合、腿伤砺骨部前哨、两名被困矿工、受伤矿工、矿队首领及护卫。  
即时伤势：顾停舟胸闷、腿虚、喉间带血；分身持续承受牵引负荷；腿伤前哨与受伤矿工行动受限。  
手中关键物品：测路杆插在裂缝中；回潮楔已钉入峡壁；湿透且印记模糊的矿路实测契仍在顾停舟衣襟内。  
当前敌人或追兵：逆潮持续增强；矿队首领主动破坏撤路，逼迫顾停舟暴露分身限制。  
当前倒计时：回潮楔已蓄满，峡壁正在开裂；继续承压将导致两侧人员与石坡、残墙一同陷落。  
下一步直接目标：寻找空当，将回潮楔锁住的潮压导向峡壁另一侧，同时救出左右两侧伤员。  
当前主动目标：放弃替矿队守住原矿路，保住现场幸存者并夺回撤离主动权。

# Proposed Persistent Canon

### Power / Capability

- 回潮楔能暂时锁住潮压的重量与冲击方向，并将连续潮压蓄入楔体。
- 回潮楔蓄满后会使峡壁承压开裂，必须及时转移或释放潮压。
- 分身可在维持回潮楔稳定的同时分出较弱牵引，但力量会被多目标与多任务分散，无法同时有效救援多人。

### Active Relationships

乌合｜优先保护砺骨部人员并撑住右侧残墙｜与主角保持现场协作，但已质疑其只守回潮楔的选择｜顾停舟承认她的判断｜需共同完成伤员撤离。

矿队首领｜保住矿队可走路线并追究实测尾款｜与主角公开对立｜主动破坏撤路、利用伤员测试分身边界｜矿路责任与回潮楔处置仍未解决。

### Knowledge / Enemy State

- 矿队首领已明确表现出：会通过改变救援目标、破坏撤路来测试并牵制顾停舟。
- 原路线已无法通行；顾停舟明确表示不再替矿队守住该矿路，但账务与责任未结。
- 回潮楔的锁潮反应具有方向锁定与蓄压效果，存在蓄满和压裂峡壁的上限。

### Tracked Assets

回潮楔｜顾停舟／分身维持｜峡壁旧裂缝中｜已钉入并蓄满潮压，峡壁开始开裂｜顾停舟重新钉入峡壁  
矿路实测契｜顾停舟｜衣襟内｜受潮、印记模糊但仍保留｜顾停舟取出后重新收回

# Proposed Chapter Summary

顾停舟确认回潮楔不仅能锁住潮压重量，还能暂时固定潮水冲击方向并持续蓄压。他以放弃矿路尾款为代价拒绝继续替矿队守路，却发现分身的牵引被回潮楔、左右伤员与残墙撕裂。矿队首领趁机破坏撤路，回潮楔最终蓄满，峡壁开始开裂，顾停舟必须寻找空当转移潮压。

# Proposed Open Promises

- 回潮楔蓄满后如何将潮压导向峡壁另一侧，以及释放后的代价。
- 逆潮持续增强的真实来源与塌毁侧室牵扯的原因。
- 左右两侧伤员及幸存人员能否在峡壁开裂前全部撤离。
- 矿权标记损毁、入口塌毁后，实测权限、期限、收益与赔付责任如何重新冲突。
- 顾停舟放弃原矿路尾款后，矿队首领将如何追究责任或反制。
- 顾停舟使用兼容潮髓后，对养潮与影中分身代价的影响。
- 少东家与顾停舟在裂槽或货运利益上形成具体冲突与合作边界。
- 乌合与顾停舟形成具体的信任边界及未决行动。
- 第一世界终局完成带母亲远游，并触发已批准的 World Horizon Handoff。
