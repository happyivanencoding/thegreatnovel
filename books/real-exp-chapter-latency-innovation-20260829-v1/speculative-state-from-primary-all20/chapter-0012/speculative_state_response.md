地点：百炉城城门内侧。  
在场人物：顾停舟、乌合、撤离车队、城门接应人；阮青蜃与追索者停在城外远处。  
即时伤势：持续胸闷咳血，承载车队重压后旧伤加重。  
手中关键物品：细裂回潮楔、反潮记录原件、矿路实测契原件、矿样、唐绾回信。  
当前敌人或追兵：阮青蜃已确认分身只能维持单一既定任务；追索者暂未进入城门。  
当前倒计时：百炉会开炉试入口即将关闭。  
下一步直接目标：立即进入百炉会保留的开炉试入口，寻找回潮楔修复机会。  
当前主动目标：保住回潮楔与原始记录，赶在入口关闭前进入开炉试。  

# Proposed Persistent Canon

### Power / Capability

- 顾停舟可将成炉力量持续压入车轮、车轴与地面，稳定护住一辆撤离车并强行通过泥沟。
- 持续承载多辆车、伤员与关键物品会迅速加重身体代价，已实际引发咳血。
- 分身只能维持一个既定牵引任务，无法在任务未解除时切换应对突发阻断；阮青蜃已看出这一限制。

### Active Relationships

乌合｜继续带领车队进入百炉城｜与主角形成带防备的互惠协作｜共同穿过追索者阻断与旧沟｜后续合作仍须定价

唐绾｜为顾停舟保留开炉试入口｜信息往来｜安排接应人在城门等候｜修复回潮楔的具体安排未决

### Identity / Access

- 顾停舟已抵达百炉城，并获得唐绾保留的一个开炉试入口。
- 该入口即将关闭，当前准入机会仍有效但时限极短。

### Knowledge / Enemy State

- 追索者已采用前后夹堵、侧坡逼近和滚木阻断等方式追击撤离车队。
- 阮青蜃确认分身无法脱离既定任务并即时换目标，后续不会重复使用同一追索方式。
- 追索者暂时止步于百炉城外。

### World State

- 百炉城城门仍开放，但开炉试入口正在关闭前的最后时限内。

### Tracked Assets

回潮楔｜顾停舟｜百炉城城门内侧｜细裂、未修复、仍有残压｜持续持有

反潮记录原件｜顾停舟｜内袋｜未再次受潮、仍需保护｜持续携带

矿路实测契原件｜顾停舟｜随身｜受潮、印记模糊｜持续携带

矿样｜顾停舟｜随身｜未说明变化｜持续携带

# Proposed Chapter Summary

撤离车队遭追索者前后夹堵，被迫绕入积水旧沟。顾停舟以成炉力量连续稳定车队、护住伤员和关键物品，却因承载过重咳血；分身无法切换任务的限制也被阮青蜃看出。车队最终抵达百炉城，唐绾留下的接应人告知开炉试入口即将关闭。
