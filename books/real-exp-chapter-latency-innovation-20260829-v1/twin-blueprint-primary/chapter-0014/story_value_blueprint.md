# CORE READER QUESTION

顾停舟能否当众证明回潮楔真正改变整段潮势，并借此保住自己的器物、矿利与自由，把旧主从关系换成一条由自己选择的赚钱道路？

# PROTAGONIST AGENCY CHAIN

A1. 炉钟响起、入口将封时，顾停舟不再被阮青蜃的追索牵着走，直接携回潮楔进入开炉试，把公开判定变成自己的机会。  
A2. 他坚持亲自让回潮楔只完成一次完整的锁潮、改向、释放：先锁住试炉中正在形成的潮力，再把整段潮势拧向另一处，最后释放出明确结果。  
A3. 他不靠连续硬压制造假象，接受回潮楔一次使用后必须散尽残压的边界，让这次展示既有收益，也有真实代价。  
A4. 面对阮青蜃的高价买断与部分追索豁免，他先看清代价和归属，再拒绝用一次大价钱换掉自己以后决定如何使用回潮楔的权利。  
A5. 面对少东家的独立粮路承运条件，他没有因旧友和旧上级身份直接回到主从关系，而是确认固定报酬、损失边界、个人矿利与自主使用权，接受有价合作。  
A6. 公开结算落定后，他带着回潮楔、个人矿利和独立合作入口随队出发，把选择立即推入下一次地潮前的现实期限。

# HUMAN / RELATIONSHIP BEATS

H1. 阮青蜃仍把古器和矿路损失当作可以追索的筹码，试图用钱与契约重新压住顾停舟；顾停舟的拒绝必须带着“自己的东西不能再交回别人手里”的偏爱，而不只是讲公平。  
H2. 少东家既是旧友也是原上级，他提出合作时会唤起顾停舟过去替商号承担麻烦的惯性；顾停舟短暂迟疑后，用价格、责任和边界把关系改成双方都要履约的承揽。  
H3. 唐绾作为独立铸潮者只完成展示与实测，不替顾停舟谈判，也不替他拒绝阮青蜃；她的旁观和专业判断让顾停舟必须自己站到公开争议中央。  
H4. 顾停舟真正想保住的不只是回潮楔的市场价值，还有“花自己的钱修回来、由自己决定用途”的持有感。这个私人欲望要进入他的选择和语气。

# FANTASY / PAYOFF BEATS

F1. 回潮楔必须让读者看见三步连续发生：潮力被锁住，原本的方向被改开，释放后改变一整段潮势，而不是只在楔身附近挡住冲击。  
F2. 现场比较必须清楚：普通成炉者通常只能稳定自身附近的重压；回潮楔却把改变推到更远、更完整的一段潮势上。  
F3. 高光之后立刻落下代价：回潮楔残压未散，不能连续硬压；它的独特价值因此更像一次昂贵而关键的改路机会，而非无限使用的万能器。  
F4. 懂行者、普通成炉者和关键利益方的反应要不同：有人校准尺度，有人意识到原先的估价错了，有人重新计算是否还能把顾停舟当作可压低价码的人。  
F5. payoff必须具体落地：回潮楔仍归顾停舟自主持有，个人矿利公开确认，砺骨部水路不被并入阮青蜃的完整矿权；粮路合作成立，但报酬与第一批货的最终结果仍未到账。

# FULL SCENES

1. 炉钟与入场：入口封闭和阮青蜃当众追索形成双重压力。顾停舟不在巷口继续争执，而是携楔跨入开炉试；落点是争议被带到百炉会见证者面前。  

2. 一次改向展示：顾停舟选择只用一次真实机会，回潮楔锁住试炉潮势、改向并释放。冲突在于有限器物必须承担公开判定，落点是整段潮势改变，且楔中残压留下无法连续使用的代价。  

3. 现场重新估价：懂行者把回潮楔与普通成炉者的近身承压放在一起比较。冲突在于阮青蜃原本依靠古器和损失追索建立的压价位置，落点是见证者不再把首批矿脉标记等同于完整矿权，顾停舟获得个人矿利确认。  

4. 两份条件：阮青蜃用高价和追索豁免买断，少东家以固定报酬、损失边界提出独立承运。冲突是钱、旧情、器物自主权与未来退路同时摆上桌；落点是顾停舟拒绝买断，接受有边界的独立合作。

# ENDING ACTION

顾停舟收好回潮楔，确认它暂时不能再次硬压，随少东家的队伍带上第一批货出发，赶在下一次十二日地潮前送到旧关；合作已经开始履行，报酬和货运结果仍在路上。

# DO NOT FLATTEN

- 回潮楔“锁潮—改向—释放”一次完成的视觉与力量体验。  
- 改变整段潮势和普通成炉者近身承压之间的尺度差。  
- 回潮楔使用后的残压、散压与不能连续硬压的真实代价。  
- 顾停舟舍不得交出自己花钱修回、能自行决定用途的器物。  
- 阮青蜃从压价追索者变成公开利益对手的换位。  
- 少东家从旧上级重新变成必须讲价格和责任的合作方。  
- 个人矿利、水路归属与首批矿权标记的实际结算。  
- 结果之后立刻出发的现实期限，以及尚未到账的合作报酬。
