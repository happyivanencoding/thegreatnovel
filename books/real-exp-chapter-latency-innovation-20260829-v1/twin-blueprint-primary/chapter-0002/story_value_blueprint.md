# CORE READER QUESTION

顾停舟能不能把一条被地潮改写的废路，变成脱离商号、由自己掌握的第一份实测机会？

# PROTAGONIST AGENCY CHAIN

A1. 顾停舟接受校路官主动带路，却坚持带上原路线册，因为他不愿让现场事实重新落回别人的口头判断。

A2. 他沿断路外缘亲自查看裂槽，不把校路官的判断当成结论，主动用册上旧石桩位置、路向记录与眼前地形逐项对照。

A3. 当裂槽、石桩和新鲜矿层彼此印证后，他明确选择承认旧路已经失效，同时把新裂槽当成一条需要独立确认的新通道。

A4. 面对校路官要登记事实副本的安排，他选择留下姓名、路线册依据和现场见证身份，而不是只做一个替别人传话的账房。

A5. 记录完成后，他立即追问这条新通道能否在下一次低潮前实测，并争取以个人名义接下工作；他要的是入口和实际报酬，不是空泛认可。

# HUMAN / RELATIONSHIP BEATS

H1. 校路官主动带顾停舟离开石坡，说明两人的关系已从“查阅他的记录”转向共同承担一次现场判断；校路官应把他当作能一起确认事实的人，而非随手带来的商号账房。

H2. 顾停舟在身体仍有胸闷、腿软的情况下继续跟进，不能写成被官差或流程拖着走；他的坚持来自不愿再替别人承担错误路线的后果，也来自想亲自判断道路的长期愿望。

H3. 顾停舟与校路官之间的信任不靠互相夸赞完成，而要落在“校路官愿意听他的对照，顾停舟愿意把原册和自己的见证交进正式记录”这次共同选择上。

H4. 校路官确认旧路不能继续使用后，应短暂重新估价顾停舟：不是把他正式提拔，而是承认他具备独立实测所需的现场判断价值。

# FANTASY / PAYOFF BEATS

F1. 本章不重复展示借身。核心满足来自另一种独特优势：顾停舟能把纸面路线、现场裂槽和矿层变化接成别人无法忽略的事实链。

F2. 新裂槽必须让读者看见它确实是改向的新通道：裂槽走向、石桩原位与现位的错开、新鲜矿层露出，共同推翻“旧路局部偏移”的安全解释。

F3. 深潮矿样要作为真实可见的价值落点出现，但不扩写潮髓机制或矿脉历史；读者只需知道它不是旧路损耗，而是独立事件，值得被单独登记和争取。

F4. “下一次低潮前短暂可行”必须改变顾停舟的行动空间，让独立实测成为迫近的机会，而不是遥远的计划。

F5. 校路台事实副本被正式送入，顾停舟保留原册并成为现场见证人；这份记录要实际改变他与商号账目的关系，成为个人接活的依据，但不能提前兑现行潮籍、预付款或兼容潮髓。

# FULL SCENES

1. 校路官带顾停舟绕到断路外缘。冲突是天色将暗、旧册仍可被当作依据，而眼前道路已经改变；落点是顾停舟坚持打开原册，要求用现场而非商号旧账判断。

2. 顾停舟对照裂槽与石桩。冲突是“旧路局部偏移”和“路线已经改向”两种判断争夺；落点是新裂槽与旧石桩位置无法重合，且裂口露出新鲜矿层，顾停舟明确确认这是独立的新通道。

3. 校路官取样、登记并制作事实副本。冲突是新矿样和新路线是否继续挂在商号旧线名下；落点是副本单独送入校路台，原路线册仍由顾停舟持有，他以本人见证留下名字。

4. 顾停舟在短暂通行窗口前提出独立实测。冲突是他仍没有合法行潮籍，也尚未正式受聘；落点不是立即拿到工作，而是校路台记录传入沉灯商盟，阮青蜃开始寻找能以个人名义完成实测的人，同时顾停舟必须面对这个尚未兑现但已经逼近的入口。

# ENDING ACTION

校路台的事实副本传入沉灯商盟后，阮青蜃开始寻找能以个人名义完成实测的人；顾停舟收好仍在自己手里的原路线册，在下一次低潮前短暂可行的新裂槽入口处，选择留下来准备争取这次独立工作，而不是随商队返回旧账体系。

# DO NOT FLATTEN

- 顾停舟主动坚持带原路线册，以及他为什么不信口头结论。
- 裂槽、石桩、新鲜矿层三者的现场对照，不能压成“确认路线改变”。
- 旧路线从“账面存在”到“现实彻底失效”的不可逆变化。
- 新裂槽和深潮矿样被拆出、单独登记的价值重量。
- 校路官对顾停舟身份与能力的重新估价。
- 原册仍归顾停舟、现场见证身份落到他本人身上的实际收益。
- 独立实测机会已经出现但尚未付款、尚未受聘、尚未取得行潮籍的悬而未决。
- 结尾必须留下短暂低潮窗口和顾停舟的下一次主动选择，不能用“等待后续安排”收束。
