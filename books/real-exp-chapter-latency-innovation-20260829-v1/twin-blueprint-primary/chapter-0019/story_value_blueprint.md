# CORE READER QUESTION

当镇海潮兽把所有人逼到只能保一处的位置时，顾停舟能否让两个真实的自己同时承担两处最不能失守的战场，并用一面外层残墙的牺牲换来人、粮道、新井与属于自己的战绩和钱？

# PROTAGONIST AGENCY CHAIN

A1. 顾停舟主动承认旧关外层保不住，拒绝把有限承受力浪费在“全都保全”的幻想上，明确选择居民、粮道和三座新井。

A2. 他展开照域，让本体站到镇海潮兽正面，自己承担最重的第一撞；这不是被军府安排，而是他判断只有自己能把这处位置顶住。

A3. 他让分身脱离正面，明确只携带“定住”，不带完整潮炉，带着回潮楔赶往第二个关键潮眼，把唯一的分身优势押在侧面改向上。

A4. 当照域边缘被冲垮、旧伤加重时，他不撤回分身，也不改保外层的决定，而是继续让本体承压，让侧面的回潮楔获得释放机会。

A5. 他用两具身体分别卡住正面与侧面，使潮压转入可牺牲区域；胜利不是凭空压服潮兽，而是他亲自决定谁承担损失。

A6. 战后他主动确认自己的个人矿利、护粮结算与公开战绩，不把放弃实测尾款扩大成放弃全部收益，再把所得钱财转化为“是否带母亲远行”的现实选择。

# HUMAN / RELATIONSHIP BEATS

H1. 顾停舟必须在关键选择里露出对钱的真实在意：实测尾款已经放弃，个人矿利却仍要保住。他不是无私圣人，而是清楚知道自己正在拿身体和旧伤换取一笔能改变生活的钱。

H2. 顾沉戈、旧关守将和镇潮军府对他的态度发生现场重估：他们亲眼看见他把最危险的位置留给自己，也看见他没有用“救所有人”的漂亮话掩盖外层牺牲。

H3. 母亲不在现场，不强行制造亲情互动；她应作为战后最具体的生活牵引出现——顾停舟终于有钱、有战绩、有行动空间，却必须决定这份收益究竟要不要换成带母亲远行的自由。

H4. 顾停舟与自己的分身形成一种极具私人意味的默契：两个身体不能共享完整能力，却都在执行他本人主动作出的同一项取舍，谁都不能替另一个位置承担代价。

# FANTASY / PAYOFF BEATS

F1. 两个真实身体同时占据两个不可替代的位置：本体被镇海潮兽正面撞入照域，分身只凭“定住”携回潮楔改动侧面退潮路线，让读者明确感到“别人只能二选一，他能同时做两件都值得做的事”。

F2. 回潮楔不是被轻松甩出的一件工具，而是在完整承压后真正吃住镇海潮兽的冲击，再沿重新钉定的方向改变退潮路线；释放完成后必须留下清晰裂痕和长期散压代价。

F3. 旧关外层确实塌成牺牲区域。它的毁坏要与居民、粮道、三座新井保住形成同一画面里的对照，让胜利带着不可逆的重量。

F4. 现场力量尺必须被结果校准：普通入潮者、成炉者、照域者与镇海战局中的承压能力被众人直接看见；顾停舟取得公开战绩，但不把这次承压偷换成稳定境界突破或新身份认证。

F5. 战后收益真正落地：公开战绩、护粮结算和个人矿利成为顾停舟可以支配的现实资源，且个人矿利与此前放弃的实测尾款明确区分。

# FULL SCENES

1. **照域正面接撞**：潮兽冲破外侧，照域边缘同时威胁旧关、粮道和新井。顾停舟必须在本能撤退与主动放弃外层之间作选择。落点是他把本体钉在正面，外层残墙开始被潮压吞掉。

2. **分身携楔转入侧潮眼**：分身只有“定住”，不能像本体一样完整运转照域；它必须在潮压和位置变化中把回潮楔送到第二个关键潮眼。落点是侧面潮流被重新钉住，两个顾停舟各自改变一处战局。

3. **完整承压与退潮改向**：正面冲击压过照域，顾停舟胸伤爆开；侧面回潮楔同时承受镇海潮兽的力量。冲突是两处都可能先失守，落点是楔子裂开、潮压被导向可牺牲区域，潮兽被压回远潮。

4. **公开战绩与生活选择**：众人确认外层已毁、粮道和新井保住，军府与相关方把战绩、护粮结算和个人矿利落到顾停舟手里。落点不是总结胜利，而是他拿着这笔钱，第一次必须认真决定是否购买或使用小型潮舟，带母亲远行。

# ENDING ACTION

战后结算当众落定，顾停舟收下个人矿利与护粮所得；他没有宣布远行已经完成，而是转身去确认小型潮舟的价格与可行性，同时回潮楔在袖中再次传出裂响，把“带母亲走”与“先承担修复代价”推到下一章的现实选择上。

# DO NOT FLATTEN

- 顾停舟主动选择牺牲旧关外层的瞬间。
- 本体正面承压、分身侧面改向的双位置体验。
- 分身只能携带“定住”的限制与由此产生的风险。
- 回潮楔吃住镇海冲击、改变退潮方向并留下新裂痕。
- 旧关毁坏与人、粮道、新井保全之间不可逆的交换。
- 现场所有人对力量差距和顾停舟战绩的重新估价。
- 他对尾款、个人矿利、行动自由和生活享受的真实欲望。
- 公开战绩、护粮结算和个人矿利真正到账。
- 结尾从宏大战局落回“要不要带母亲远行”的具体人生选择。
