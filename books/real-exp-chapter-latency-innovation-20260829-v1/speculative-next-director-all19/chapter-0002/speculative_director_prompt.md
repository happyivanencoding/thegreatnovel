长期旧线本章新事实具体化（软执行原则，不新增字段）：当本章触及沉睡人物、旧承诺、身份谜团、长期秘密或 OPEN PROMISE 时，必须在现有“直接结果 / 状态变化 / 结尾推动力”里写清本章结束时**哪一个具体事实第一次成为确定事实**；如果过去原因、隐藏身份或机制仍未获上游计划授权揭晓，就明确它仍未解决，并把本章不可逆变化落在当下选择、现场证据、公开立场、职责、关系动作、持有关系或行动入口上。不要只写“至少一条旧线发生不可逆变化”“真相进一步揭露”“关系发生变化”等抽象结果，再让 Writer 自己决定隐藏答案。上游没有给出过去真相时，不为填满事件合同补造几十 / 几百章前发生过的秘密经历、对话、动机或世界机制。

支撑性逻辑不得自动成为故事发动机：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

核心幻想不变量：Character 中已批准的 Power Core 一旦确定，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**核心幻想是长期读者承诺，不是主角的人生使命，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。兑现优先抓住这项幻想最独有的**生活特权**，而不是只复用最容易安排的战术用途：如果它真正让人馋的是多一份时间/经历、拥有别人不能占有的东西、改变身体状态、跨越位置或其它特殊生活方式，就在自然适合的修炼、探索、关系、日常或选择中让读者亲自看到这种特权怎样改变人生；不要求逐类覆盖，也不要把独有幻想降格成同一种战斗解法反复放大。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明核心幻想存在，就把每个阶段都改造成一次能力升级、能力反制或更大版本的同一玩法。

Persistent Reader Ruler（长期读者坐标软原则，不新增字段、战力数据库或 Hard Gate）：世界前台的力量、战绩、价值、天赋/适配、技法熟练度、装备品阶、排名、身份与世界层级，都是读者判断优越感、风险和欲望距离的 ruler；当前事件碰到哪把尺，就优先校准哪把，不要求力量尺独占，也不合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、新强敌、越级胜负、高价值获得或世界换挡时，通过当前事件自然刷新：主角现在大致在哪一档 / 对象值在哪一档、正常同档能做到或值到什么程度、这次哪里超标、下一档还有什么可见距离。**Ruler = Compression, not Exposition**：当动作与结果已经让一个事实成立时，优先用一次最相关的、已由 World / approved Story 提供的 benchmark 或懂行者比较替代多轮验证，然后立即推进到新的选择、机会、敌意、获得、关系或行动。Benchmark authority 在上游：Outline / Director 只选择和投影已有基准，Writer 不临时发明互相冲突的公斤、米数、价格或新等级。不要每章报表；目标是让读者在关键换挡后持续知道“现在在哪档、哪里不讲理、眼前东西到底有多值”。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生，再用现场已有的懂行者/对手/同伴的短反应完成“这不该是同层能做到的”比较，让惊讶本身成为爽点；不凭空加围观者，也不做群体吹捧。只有重新估价会改变后续行动（如招揽、畏惧、敌意、竞争、信任或关系位置）时才让态度转变进入剧情，否则惊讶/确认后即可停止。已公开优势的普通重复使用不反复演震惊。

Named Opportunity Value Orientation（Story Program → Outline → Director 编译保真软原则，不新增字段或 Reader Release 类型）：当 Story Program / Approved World 已经**具名**一个试场、选拔、招募、拍卖、传承机会、契约或其它具体机会，并明确它的公开目的、通常回报或成功后可打开的身份/资源/行动入口，只要某章的训练、准备、取舍或行动**因这个机会而发生**，Outline 就必须从第一次因果使用开始保留它的具体名字与已批准价值。**不能把上游的“某商盟公开试场 / 某宗门招募 / 某份契约”降成“公开机会 / 一个资格 / 更大的机会”，再等真正获得时才解释它为什么值。**

第一次成为主角当章欲望、取舍或行动理由时，用一句普通话说清“为什么值得争、成功参与通常能打开什么”。这不是提前宣布主角会赢，也不是 Future Result 预支；只是在诱惑真正进入选择前建立它的已批准价值。通用的“以后会有更大机会 / 可以去宗门军府”不能代替眼前这个具名机会的具体价值。如果上游没有批准其回报，不准临时编造；继续保持未知。

Outline 在 Future 10 的该章 `具体剧情` 中保留“**具名机会 + 当前已知价值**”；Director 若该机会仍是本章行动理由，就把同一信息保留进八字段最相关位置，使 Curator / Writer 无需自己猜机会为什么重要。它与 Reader Release 分工：World 公共事实走 Reader Release；Story/Plan 批准的具名机会价值走当前章 Plan。

Director Plan Compression Recovery（不新增 authority）：Future 10 的单章条目只是当前剧情块的压缩投影，不能反过来擦掉同一 Outline 剧情块里已经批准的具体因果。若当前章条目写“某试场前训练 / 为某招募准备 / 争取某资格”等泛化措辞，而 `当前剧情块` 已明确这是哪个**具名机会**、为什么值得争、成功参与通常打开什么，Director 必须恢复“具体机会名 + 当前已知价值”到本章八字段最相关位置。**Long Block 补足 Chapter Plan 的压缩损失，但不能改变章事件、提前宣布结果或从未来章偷新事实。** 只有两层计划明显指向同一当前行动理由时才恢复；无法确认同一对象时保持章计划原样。

Director Narrative Salience：Director 面对十章计划和 Canon 中很多可执行细节时，八字段优先抓住本章最值得读的那一个人物冲突、关键选择、力量使用、反转、利益得失或兑现结果。操作步骤只有在它会改变人物选择、风险、胜负或结果时才进入“主角行动”；不要把“主角行动”写成施工单、路线单、检测流程或完整操作清单。**Discriminative Detail Only**：调查、手艺、医学、制作、检测、推理等 Supporting Skill 只保留足以改变判断的少量关键细节；一旦这些细节已经足以推出发现或决定，立即进入发现造成的选择、冲突或后果，不把实施过程继续展开成专业展示。**决定已经做完后的普通实施默认压缩**：除非实施中又出现新的选择、冲突、不确定性或失败风险，不把停车、搬运、排布、绑缚、登记、赶路等普通执行扩成主要场景。Director 的 `主角行动` 对这类内容优先只保留“关键决定 + 至多一个真正改变成败/判断的决定性动作 + 结果”，不要把“调整车位、补薄弱处、垫石、绑绳、摆盾”之类并列动作继续传给 Curator / Writer。 **如果这个动作依赖的是前文已经成立、且不是 Core Fantasy 的 Supporting Skill，事件合同默认连技能方法本身也不重述，只写它让主角完成了什么结果；只有本章发现该技能的新边界、失败方式或质变时才重新把方法写进“主角行动”。****不要用 Competence Filler 填动作空缺**：如果本章真正的价值是 World Entry、重要势力首次进入、关系立场、误判、选择或局势换挡，而 Outline 没安排一个值得展开的技术难题，主角只做站队、拒绝、观察、跟随、守住位置、说一句决定等简单行动也完全成立；不要为了让主角“显得有用/能干”临时制造排车、维修、诊断、路线、受力、清点或其它专业问题让他解决。**Access / Reward 不自动征收资格流程税**：Outline 已经把某个入口、邀请、名额、工作机会、身份待遇或奖励作为本章可选择/可获得的既定条件时，Director 不得为了“让它显得更合理/更配得上”自行补一轮试工、观察、检测、考核、证明、登记或专业展示；除非 Plan 明确把该过程本身列为故事事件，否则直接让人物面对这个已经成立的机会并作选择，让篇幅进入选择的后果。不能删改计划规定的结果，但可以把实现过程压缩到足够支撑因果的最小程度，让“谁逼谁、主角决定什么、局势怎样被改变”保持前景。


经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。




# Opening Three Chapter Contract

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动与开篇定向需要理解的公共世界事实 / 规则 → 主角立即行动。**World fact 的选择权在 World + Outline，不在 Writer**：如果当前章 `具体剧情` / Reader Release 已排程开篇公共常识，Curator 必须保留，Primary 用普通陈述句直接落实；如果 Plan 没排程，Primary 不自己从完整 World 里挑一段补课。明显陌生/架空世界的前三章不是阅读理解题：读者应能很轻松地知道“这个世界主要靠什么力量运行、粗略怎样分强弱、主角大致在哪、下一档意味着什么、哪些危险/生活习惯是大家的常识、什么入口或东西值得往上争”。这些是公共常识时可以直接说，不要求先靠火盆、服装、动作或对白让读者自己猜。不要先把世界模型讲完再放主角进去，也不要把世界定向做成独立 Setup 事件；只释放前几章会反复使用的坐标，隐藏原因和未来 reveal 继续后放。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

脚夫们脸色发白，却还是跟着他动了。

顾停舟踩进没过小腿的潮水，借着入潮者强过常人的力气，把一个被车辕压住腿的脚夫拖出来。另一个脚夫脚下打滑，他抓住对方后领，直接往高地的方向推去。

“快走！”

一头潮兽从左边冲过，撞翻了无人看管的杂货车。

木箱裂开，盐砖、布包和零散陶罐全滚进潮水。没有车签，也没有人认领，潮水卷着那些东西往深沟里去，很快就没了影。

有人想回头抢。

顾停舟厉声喝道：“命比一箱破罐子值钱！上坡！”

那人僵了一下，咬牙跟着跑。

右侧，第二个顾停舟还按着矿车。

潮水越涨越急，矿车的铁轮磨得发红，车身一寸寸向沟边扭。分身没有退，手掌压着车辕，肩背绷得笔直。

他只会定住。

可这一件事，已经够了。

成炉护卫从另一侧赶来，手里提着一杆沉铁枪。他原本是去截一头冲散队伍的潮兽，半路却看见高地上的脚夫，又看见沟边那辆始终没有翻下去的矿车。

他的动作停了半拍。

一个顾停舟带着人撤离。

另一个顾停舟守着车。

成炉者通常能独自护住一辆商车，也才有资格独自穿过短距离荒地；可那是成炉者。顾停舟只是个基础入潮者，平日里抱着账册、记着路线，连正式行潮籍都没有。

可现在，他在两处危险里同时留下了手。

“护住矿车！”成炉护卫朝后面吼了一声，“别让他一个人扛！”

两名护卫扑到车旁，合力顶住另一侧车轮。顾停舟的分身这才缓缓收回手。

矿车重新落回平地时，车轴发出一声闷响。

第二个顾停舟站在原地，看了本体一眼，身影无声散开，重新落回顾停舟脚下。

顾停舟胸口一阵发闷，腿也有些发软。他扶着石坡站稳，先低头数了一遍撤上来的脚夫。

一个不少。

潮兽群还在远处穿行，没有再冲向高地。商队剩下的人缩在石坡后，望着被撕开的潮路和冲走的杂货，谁也没说话。

少东家从马车里下来，衣摆湿了半截。

他先看那辆保住的矿车，又看顾停舟。

“你刚才……”

“先核车。”顾停舟打断他，“人齐了，车还在，别等回去以后再说。”

少东家张了张嘴，最后没发作，只沉着脸点头。

天黑前，潮水退了一些。

保住的矿车被拖上高地，车签还挂在栏杆上。无主杂货车则只剩半截车架卡在泥里，货物大多已经没了。

顾停舟坐在一块平石上，摊开被油纸包好的账页。

少东家看了他一眼，没再接话。

一只小布袋被放到顾停舟面前。

里面是沉甸甸的潮钱，数目不大，却一枚不少。

少东家说：“记你名下。不是商号预支，也不从你月钱里扣。”

顾停舟伸手拿起布袋，指腹摸过粗糙的袋口。

这是第一笔真正属于他的钱。

不是替人抄账，不是领一份随时能被停掉的工钱，也不是谁一句“先记着”就能抹平的数。

他把钱袋收进怀里，嘴角压不住地动了一下。

少东家看见了，忽然有些不自在，转开脸道：“别高兴得太早。路断成这样，回去以后还有一堆烂账。”

顾停舟把路线册压在掌下。

“深潮矿脉方向来的潮兽。”

“是。”顾停舟说，“只知道它们从那边来。为什么迁，不知道。”

校路官没有逼问，只把册页翻回去，又看见那笔急单和损失。

“这条路得重新核。”

少东家冷声道：“急单怎么办？”

少东家沉默下来。

他第一次没有把顾停舟当成那个只会替商号补齐数字的账房。

风从断路上吹过来，带着潮水和兽腥气。

少东家没有立刻答应。
