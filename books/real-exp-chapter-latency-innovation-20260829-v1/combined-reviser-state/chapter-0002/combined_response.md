# 正式正文

校路官没有回石坡。

天色已经沉下去，断路外缘的雾被风推开一线，露出一条刚从地下翻出来的裂槽。裂槽不宽，最窄处只能并肩走两个人，槽底却一直斜着往深处延伸。湿泥贴在两侧岩壁上，里面夹着一层暗青色矿石，边缘还带着新断开的白茬。

“兽迹不用再看了。”校路官踩着一块歪倒的石桩，望向裂槽，“地潮把路顶成这样，旧路走不走得通，已经不是兽迹能定的事。”

顾停舟跟在他身后，腿还有些发虚，脚步却没慢。

他把原路线册从怀里取出来，翻到石桩标记那页。册页边缘被潮气浸得发软，上面仍清楚记着旧路的转折、石桩间距和一处绕开低洼地的弯道。

校路官回头看他：“还带着？”

“带着才好分清楚。”顾停舟说，“旧路是什么样，新路从哪里冒出来，不能混成一笔。”

校路官点头，没再说什么。

两人沿着断路外缘往前走。原本指向前方的石桩已经倒了三根，最后一根还立着，却偏离裂槽半丈多远。旧路该从石桩右侧绕过一片硬泥坡，如今那片坡已经塌进地下，裂槽则从石桩左侧斜斜切出去，像有人拿刀在荒地上重新划了一道线。

顾停舟蹲下身，用手背擦去一块露出的矿层上的湿泥。

暗青色的矿石贴着裂槽往下延伸，刚从地下翻出来，表面还带着潮气，没有被风砂磨钝。

校路官也蹲下来，取出细凿，在矿层边缘轻轻敲下一小块。

矿石落进掌心，发出清脆的一声。

“新鲜的深潮矿样。”他说。

顾停舟翻着路线册，手指停在旧路标记上。

“旧路是往北绕，避开软泥坡，再接外侧石桩。”他说，“现在石桩倒了，软泥坡塌了，裂槽却往西南走。”

校路官看着他。

顾停舟抬起头，语气很直。

“这不是旧路被潮水冲偏了一点。旧路到这里就断了。裂槽是另一条通道。”

风从槽底涌上来，带着湿冷的矿气。

校路官没有立刻回答。他先往裂槽里走了几步，靴底踩在新露出的硬岩上，又抬头看了看远处地势。

裂槽一路往深潮矿脉外缘斜去。

这条路现在能走，是因为潮水暂时退下去了。可它只在下一次低潮前短暂可行，水势一变，槽底就会重新积水，边缘也可能继续塌。

校路官走回来，停在顾停舟面前。

“下一次低潮前，这里能短暂通行。”他说，“但旧路线不能用了。”

顾停舟合上路线册。

这句话落下来，比少东家那句“回去再算”更干脆。

商号账上那条路还可以写着，车队也可以拿旧货签说事，可现实里的石桩、塌坡和裂槽已经把它撕开了。谁再说这只是旧线的一段偏移，谁就是睁着眼睛往死路上赶车。

校路官拿出一张空白的校路纸，铺在一块平石上。

“你说，我记。”

顾停舟看了他一眼。

“你记？”

“我记校路台的副本。”校路官说，“原册还是你的。”

顾停舟这才走过去。

他没有把路线册交出去，只翻开册页，照着上面的旧桩位、旧转折和损坏时间，一条条说下去。校路官写得很快，写到裂槽方向和矿层位置时，抬头确认了两次。

“裂槽起于旧路塌陷处，避开旧桩线，向深潮矿脉外缘延伸。”

“对。”

“露出新鲜深潮矿层，与旧路浅层碎矿不属同一段。”

“对。”

“旧路线废止，新裂槽另列现场记录。”

顾停舟顿了顿。

“再加一句。”他说，“旧路线册由我持有，今日现场对照由我和你一起看过。”

校路官手里的炭笔停了一下。

顾停舟看着他，没有回避。

“我不替商号说旧线还能用，也不替他们把新裂槽算回旧账里。你要记，就把这点记清楚。”

校路官看了看他掌下那本已经被潮气浸软的路线册，随后在纸上补完了最后一行。

“顾停舟，持原路线记录，现场见证。”

他写完，把校路纸递过来。

“按个手印。”

顾停舟伸出拇指，在随身墨盒里按了一下，稳稳压在纸角。

校路官也按了自己的印。

两枚印并排落在纸上。

不远处，商队的人还缩在石坡后。少东家站在高处，隔着雾看见他们，却没有走过来。

他显然也明白，校路台既然另立了记录，商号再拿旧路线说事，至少还得面对这张纸。

校路官把副本卷好，塞进防潮筒里。

“我现在送回校路台。”

顾停舟问：“原册呢？”

“你留着。”校路官说，“以后有人要查旧线怎么失效，先找你这本。”

顾停舟把路线册重新收进怀里。

那册子并没有忽然变成通行凭证，也没替他拿到行潮籍。可它不再只是商号账房手里一摞会被改写的旧纸。

它记着旧路死在哪里，也记着新路从哪里出来。

校路官看向裂槽深处。

“想接实测活？”

“想。”

“那就把腿养好。”校路官说，“这条裂槽留不了几天。校路台要核，矿脉边上也会有人要核。到时候，能拿着原册、看得懂石桩和矿层的人，不会只剩商号里那些会抄账的。”

顾停舟嘴角动了一下。

“我不会白跑。”

“先有资格接，再谈价钱。”

“价钱也得先谈。”

校路官看着他，竟笑了一声。

“行。你这脾气，倒是适合自己接活。”

夜色彻底压下来时，校路官带着事实副本离开了断路。

顾停舟站在裂槽边，没有再往下走。

他知道自己现在还不能进。没有行潮籍，没有正式委托，也没有人替他承担下一次低潮后的风险。可裂槽就在眼前，深潮矿层也在眼前。旧路已经断了，新的入口却刚刚露出来。

他把手按在怀里的路线册上，转身往石坡走去。

与此同时，校路台的传递筒穿过夜里的潮灯，一路送进沉灯商盟。

阮青蜃拆开那份现场记录时，桌上的潮灯正烧得安静。

她先看见“旧路线废止”，又看见“新裂槽另列现场记录”，最后看见纸角那枚陌生的手印。

顾停舟。

她把这个名字念了一遍，指尖停在“持原路线记录，现场见证”那一行。

片刻后，她合上记录，叫来门外的人。

“去找这个人。”

“找来做什么？”

阮青蜃抬眼看向灯外的黑潮。

“找一个能以个人名义完成实测的人。”

# Proposed Active Scene State

地点：断路旁的石坡高地与新裂槽入口。  
在场人物：顾停舟、少东家与商队众人仍在石坡；校路官已带事实副本返回校路台。  
即时伤势：胸口发闷，双腿发软；暂无明确重伤。  
手中关键物品：原路线册、第一笔个人潮钱、油纸分账记录。  
当前敌人或追兵：无直接追兵；裂槽通往深潮矿脉外缘，地势仍有塌陷与积水风险。  
当前倒计时：下一次低潮前的短暂通行窗口。  
下一步直接目标：取得正式委托并争取以个人名义完成裂槽实测。  
当前主动目标：争取一份不挂在商号账下的独立矿路实测活。

# Proposed Persistent Canon

### Power / Capability

顾停舟的借身能力及其既有边界不变；本章未新增能力表现。

### Active Relationships

校路官与顾停舟从查阅路线记录推进为共同确认现场事实，并在事实副本上共同留印。校路官认可顾停舟争取独立实测工作的可能性。

### Identity / Access

顾停舟仍未取得合法行潮籍，也未正式获得独立实测工作。原路线册仍由顾停舟持有；校路台记录其为“持原路线记录，现场见证”。

### Knowledge / Enemy State

旧路线已彻底失效。新裂槽确认通向深潮矿脉外缘，露出的新鲜深潮矿样被列为独立事件。裂槽只在下一次低潮前短暂可行。潮兽迁徙原因仍未知。

### World State

校路官已将旧路线废止、新裂槽与新鲜矿样的事实副本送入校路台；记录随后传入沉灯商盟。阮青蜃开始寻找能以个人名义完成实测的人。

### Tracked Assets

- 原路线册｜顾停舟｜本人怀中｜记录旧路、石桩、损坏时间及现场对照  
- 第一笔个人潮钱｜顾停舟｜本人怀中｜已取得，独立归属  
- 油纸分账记录｜顾停舟｜本人怀中｜记录矿车救回部分及份额  
- 校路事实副本｜校路台｜已由校路官送回｜记录旧路线废止、新裂槽独立及顾停舟现场见证

# Proposed Chapter Summary

天色将暗，顾停舟跟随校路官沿断路外缘查看裂槽。他用原路线册对照石桩、塌坡和新鲜矿层，确认旧路已经彻底失效，裂槽是通往深潮矿脉外缘的新通道。校路官将事实副本送入校路台，顾停舟保留原册并留下现场见证。记录传入沉灯商盟后，阮青蜃开始寻找能以个人名义完成实测的人。
