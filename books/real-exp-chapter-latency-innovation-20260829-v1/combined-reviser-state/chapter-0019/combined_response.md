# 正式正文

镇海潮兽低下头的瞬间，旧关内侧的地面先裂开了。

兽首还没真正撞到，黑水已经被它顶成一面高墙，压着残墙、石坡和照域边缘一起往里推。顾停舟脚下的淡光猛地收缩，胸口像被铁锤正面砸中，喉间那口血再也压不住，直接溅在衣襟上。

“退到粮道后面！”旧关守将厉声喝道，“外层不要了！”

镇潮军府的人立刻收线。潮灯、潮车和压潮器被迅速撤下，压潮器的铜臂转向外层。它们挡不住镇海潮兽，只能把剩下的潮压往已经空掉的地方引。

入潮者只能借潮力进黑水救人，成炉者能护住一辆商车和一小段路，照域者能把潮力推出体外压住院落或街巷。可在镇海战局里，决定胜负的是谁能承住整片潮场的正面冲击。

现在，镇海潮兽把这份压力全压到了顾停舟身上。

顾沉戈站在他右侧，刀锋插进地面，双臂青筋暴起。

“你顶得住多久？”

“顶到另一边钉住。”

顾停舟抹去嘴角的血，抬眼望向侧面的潮场。

那里离兽首正撞的位置很远，却是退潮唯一还能改向的缺口。黑水正从那里往粮道和三座新井漫去。一旦让它合拢，旧关内侧就算守住，也只是把人和粮全困在潮里。

顾停舟的另一具身体已经立在那片缺口边。

分身身上的衣袍被潮水打得贴在身上，手里没有照域潮谱，也没有完整潮炉。他只带着“定住”——那股能把一小块潮压暂时钉死、不让它继续偏移的力量。

而回潮楔，就在他掌中。

那是一截裂过又被强行压住的黑铜短楔。它本该用来承接潮压，再把潮势送回原本的方向。可上一次残压紊乱后，它已经不能连续使用。

这一次若承不住，裂的就不只是楔子。

“顾沉戈。”顾停舟开口。

“说。”

“兽首撞过来时，你带军府把潮压往旧关外层放。”

顾沉戈看了一眼外侧残墙。

那里还有半片旧关屋舍，几座已经空掉的石仓，还有先前来不及拆走的潮车。

“全放？”

“全放。”

顾停舟的声音很平。

“人、粮道、新井，才是要留的。墙留不住了。”

顾沉戈咬了咬牙，随即转身。

“军府听令！潮器全部转向外层残墙！别跟兽首硬耗，给顾停舟让出正面！”

命令落下，镇潮军府的人没有犹豫。原本护住残墙的潮力开始往外泄，旧关外层的淡光迅速暗下去。黑水灌进空屋，撞塌木门，卷走散在地上的器具。

旧墙终于失守。

镇海潮兽也在这一刻撞了上来。

顾停舟向前一步，照域潮谱在掌心亮起。

淡光从他脚下铺开，挡在兽首与内侧潮场之间。那层光并不厚，像一片撑在暴雨里的薄幕，可当兽首撞上去时，整片地面还是被压得往下沉了半尺。

顾停舟双脚陷进碎石里，肩背向后弯了一瞬。

胸口旧伤像被硬生生撕开，他能听见自己骨头发出闷响。

可他没有退。

照域不是墙。

它是顾停舟把潮力推到外面，硬生生划出的一个范围。在这个范围里，潮水会先经过他的判断，先撞上他的承受，再决定往哪里去。

镇海潮兽又压了一步。

淡光边缘开始碎裂。

“现在！”顾停舟喝道。

侧面的分身抬起手。

“定住。”

他脚下那片乱成一团的潮压骤然停了一下。

不是整片黑水都静了，只是最关键的潮眼被钉在原地。奔涌的潮水从两侧绕过去，像被一根钉子拦住的布，瞬间拉出一个清楚的缺口。

分身趁着这一息，冲进潮眼中央。

黑水没过他的膝盖，又没过腰。他把回潮楔狠狠插进石地。

“咔！”

黑铜短楔入地，楔身上的旧裂痕先亮了起来。

紧接着，沿照域边缘转来的潮压撞进回潮楔。

顾停舟本体承住兽首。

分身钉住侧面潮眼。

两处力量同时扣紧，原本要漫向粮道的黑水忽然改了方向。

潮水先是向后一顿，随后沿着重新钉定的潮路斜斜冲出，直扑旧关外层。残墙、空屋、被留下的潮车和压潮器一齐被黑水吞没，石墙一段段倒下，像被潮兽亲口咬碎。

可粮道还在。

三座新井旁的石台还在。

北侧高地上的居民也还在。

旧关守将站在粮道口，眼看黑水从脚下那条岔路偏过去，手里的令旗猛地落下。

“守住了！”

镇潮军府的人先是一静，随即爆出一阵压不住的喊声。

镇海潮兽却没有退。

它被回潮楔改了潮路，兽首仍死死抵着照域。它低吼一声，黑水从背后翻起，第二股冲击比刚才更重。

顾停舟眼前一黑，照域边缘被压得只剩一圈贴着地面的淡光。

他知道自己不能再硬撑第二次。

“沉戈，往左！”

顾沉戈早等着这句话。他带着十几名镇潮军府的人从内侧斜插出去，把所有还能运转的潮器一起推向旧关外层。

那些潮器不是去挡，而是去引。

潮压被推向已经放弃的残墙，兽首脚下的黑水失了支撑，猛地向外塌陷。

顾停舟抓住这一瞬，抬起右手。

照域潮谱的淡光压到兽首前方。

“回去。”

分身仍以“定住”压着潮眼，回潮楔也在这一刻发出刺耳的裂响。

裂痕从楔尖一路爬到楔尾，像有一把看不见的刀在黑铜里慢慢劈开。分身手腕被反震得裂出血口，身形一晃，却仍没有松开。

终于，镇海潮兽脚下那片潮场先退了。

它庞大的身躯被改向的潮水推得侧偏，前爪踩碎最后一截残墙，兽首从照域前挪开半寸、一尺、数丈。

顾停舟立刻收紧照域，把它往远潮方向压。

黑水倒卷。

镇海潮兽在潮场中发出低沉的咆哮，兽躯被推回旧关之外。它没有再往内侧冲，只在远处翻起一片高浪，随后沉入更深的黑水里。

潮声还在。

可压在众人头顶的那股力量，已经退了。

顾停舟站在原地，半晌没有动。

照域消散时，他膝盖一软，差点直接跪下。顾沉戈一把扶住他，手掌碰到他后背，才发现衣袍已经被血浸透。

“你还活着吧？”

顾停舟喘了口气。

“暂时。”

顾沉戈想骂他，见他脸白得吓人，最后只重重拍了他一下。

“回去养伤。”

侧面的分身从潮眼边走回来，掌中的回潮楔已经不再发亮。楔身多出一道新裂痕，裂口没有彻底断开，却不断往外散出细碎的潮压，像握着一块没熄透的炭。

顾停舟接过它，掌心立刻一阵刺痛。

这东西暂时不能再用力了。

再强行承压，它很可能直接碎掉。

旧关守将从粮道方向赶来，先看了一眼仍在冒黑水的外层废墟，又看向顾停舟。

“居民无伤，粮车都在，三座新井也保住了。”他停了停，抱拳行礼，“镇海军府记下这一战。顾停舟，正面承兽冲、改退潮、护粮道，战绩公开入册。”

周围的人都听见了。

有人看着顾停舟掌里裂开的回潮楔，有人看着已经塌成一片的旧关外层，也有人看着仍然完整的粮道和新井。

没人再把他当成只会借潮路护住一小片地方的照域者。

顾停舟抬头望了一眼远潮，没有回应那些目光。

他只问：“矿利和护粮结算，什么时候给？”

旧关守将愣了一下，随即笑了。

“你倒是记得清楚。”

“我放掉的尾款已经够多了。”

“今日战后就结。”

守将转身吩咐随军文吏：“把矿脉个人份额、护粮结算和战功凭据一并封好，送到顾停舟手里。军府不拖他的账。”

不久后，文吏抱着一只防潮木匣赶来。

木匣里放着结算文书、封好的潮钱票据，还有一枚刻着镇潮军府印记的战功牌。矿利和护粮的账没有再悬着，属于顾停舟的那一份，终于落进了他手里。

顾停舟掂了掂木匣，胸口还在疼，心里却稍微松开了一点。

这些钱不只是补他今日的伤。

也许能换一艘小些的潮舟，带母亲离开旧关，走远一点，不必永远守着潮声和残墙过日子。

顾沉戈看他盯着木匣出神，问道：“想什么？”

顾停舟把回潮楔和文书一起收好。

“想先找个会修楔子的人。”

他顿了顿。

“再看看，够不够买一条船。”

# Proposed Active Scene State

地点：旧关内侧粮道与外层残墟之间。  
在场人物：顾停舟、顾停舟分身、顾沉戈、旧关守将及镇潮军府人员。  
即时伤势：旧伤明显加重，胸口疼痛、失血，照域负荷尚未缓解。  
手中关键物品：照域潮谱、持续散压的回潮楔、承运短契、防潮木匣。  
当前敌人或追兵：镇海潮兽已被压回远潮，暂未再次冲击。  
当前倒计时：回潮楔散压与修复代价尚未处理，第一批粮运仍未最终完成。  
下一步直接目标：处置旧伤与回潮楔，并面对是否用结算所得购置小型潮舟、带母亲远行的选择。  
当前主动目标：保住已取得的结算与战绩，确认后续行动代价。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟在一次镇海冲击中完成本体正面承压、分身携带“定住”钉住侧面潮眼，并借回潮楔改变退潮方向。
- 照域、分身与回潮楔可以在两个战斗位置同时改变潮场，但分身仍只携带“定住”，不是完整复制体。
- 回潮楔承受并释放镇海潮压后出现新裂痕，持续散压，暂不可再次强行承压。
- 顾停舟旧伤与照域负荷进一步加重。

### Active Relationships

- 顾沉戈｜协助顾停舟完成正面承压与潮器引流｜临时协作关系｜共同守住内侧并见证战果｜继续协助战后处置。
- 旧关守将／镇潮军府｜承认并记录顾停舟的镇海战绩｜公开协作关系｜完成居民、粮道和新井的保护及结算｜后续仍涉及粮运与军府凭据。
- 阮青蜃矿队｜矿权与尾款仍有追索可能｜未决利益关系｜顾停舟放弃尾款但保留个人矿利并完成结算｜阮青蜃可能继续追索。

### Identity / Access

- 顾停舟持有照域潮谱。
- 镇潮军府已将其正面承兽冲、改退潮、护粮道的战绩公开入册。
- 顾停舟取得个人矿利、护粮结算文书、潮钱票据及战功牌。

### Knowledge / Enemy State

- 镇海潮兽已被压回远潮，仍与照域潮谱存在明确牵引关系，但原因未知。
- 镇海潮兽的冲击导致旧关外层彻底成为牺牲区域。
- 居民、粮道和三座新井在本次冲击中保住。

### World State

- 旧关外层残墙、空屋及部分潮器被黑水吞没并倒塌。
- 镇海军府、顾停舟及现场人员共同见证了镇海潮兽冲击后的力量差距与战局结果。

### Tracked Assets

- 照域潮谱｜顾停舟｜手中｜持续掌握，可展开照域｜未转移。
- 回潮楔｜顾停舟｜手中｜新裂痕并持续散压，暂不可强用｜由分身交回本体。
- 承运短契｜顾停舟｜怀中｜仍有效，粮运未最终完成｜未转移。
- 个人矿利与护粮结算｜顾停舟｜防潮木匣内｜已取得文书与潮钱票据｜战后由军府交付。
- 镇潮军府战功牌｜顾停舟｜防潮木匣内｜已取得，战绩公开入册｜战后由军府交付。

# Proposed Chapter Summary

镇海潮兽撞击照域时，顾停舟主动放弃旧关外层，令军府将潮压引向残墙；本体正面承压，分身携“定住”把回潮楔钉入侧面潮眼，最终改向潮路，保住居民、粮道与三座新井。回潮楔出现新裂痕并持续散压。战后，顾停舟取得公开战绩、个人矿利和护粮结算，开始考虑买船带母亲远行。
