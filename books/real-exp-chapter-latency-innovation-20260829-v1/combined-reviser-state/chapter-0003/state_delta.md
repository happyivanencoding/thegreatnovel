# Proposed Persistent Canon

### Power / Capability

顾停舟仍可从影子中分出一个自身，分身只能携带一种本事；已知分身不能完整复制本体，回归后会造成胸闷、腿软。本章未改变该能力边界。

### Active Relationships

少东家与顾停舟的主从关系进一步松脱，双方转为保留旧情但存在利益冲突的同行者。阮青蜃已通过具名承事正式委托顾停舟，以预付款、兼容潮髓和赔付条件与其建立直接合作关系。

### Identity / Access

顾停舟取得合法独立行潮籍，可用个人名义接案、登记路线结果并收取赔付；该身份不等于成炉，也不等于能够无风险独行荒地。

### Knowledge / Enemy State

旧路线已正式废止，新裂槽另列；新裂槽仍未核查进入。过去事故是否有人蓄意掩盖仍未知。

### World State

商号无法改写校路台关于加车决定与杂货损失的事实记录，也不能再以雇主身份收回顾停舟的原路线册。

### Tracked Assets

兼容潮髓、矿路实测预付款与侧路实测契均登记在顾停舟个人名下；原路线册仍由顾停舟持有。

# Proposed Chapter Summary

校路台正式收下事实副本，确认旧路线废止、新裂槽另列，加车与杂货损失不能改写。顾停舟拒绝交回原路线册并取得独立行潮籍。阮青蜃以个人名义提出侧路实测案，给出预付款、兼容潮髓和赔付条件。顾停舟确认契约边界后签约，下一次低潮前核查新裂槽成为他的直接责任。
