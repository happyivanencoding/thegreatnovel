# Proposed Active Scene State

地点：断裂潮路旁的石坡高地，商队暂时避险处。  
在场人物：顾停舟、少东家、商队众人；校路官已携副本离开。  
即时伤势：胸口发闷，双腿仍发虚，需养好腿。  
关键物品：原路线册、第一笔个人潮钱、油纸分账记录。  
当前敌人或追兵：阮青蜃已获现场记录，正派人寻找顾停舟。  
当前倒计时：新裂槽只能留存数日，下一次低潮后可能积水或继续坍塌。  
下一步直接目标：养好腿，取得接取裂槽实测工作的资格与正式委托。  
当前主动目标：争取以个人名义接下矿路实测活，脱离商号账目获得独立收入。

# Proposed Persistent Canon

### Active Relationships

校路官｜将现场记录送回校路台并推进核验｜潜在独立工作入口｜认可顾停舟对旧路废止与新裂槽另列的判断，并以其原册作现场见证｜裂槽实测资格、正式委托与价钱待定  
少东家｜处理商队损失与急单｜旧友兼实际雇主，存在利益边界的同行者｜隔雾见证顾停舟与校路官立记录，未介入｜顾停舟能否脱离商号独立接活待定

### Identity / Access

顾停舟以“持原路线记录，现场见证”身份，与校路官共同确认旧路线废止、新裂槽另列现场记录；原路线册由其保留，未来旧线失效核查可先找他。仍未取得合法行潮籍或正式实测委托。

### Knowledge / Enemy State

旧路线至断路处已废止；裂槽是通往深潮矿脉外缘的另一条短暂通道，非旧路偏移。裂槽在下一次低潮前可短暂通行，之后可能积水或坍塌。阮青蜃已得知顾停舟能以个人名义完成实测的潜在价值，开始派人寻找他。

### Tracked Assets

原路线册｜顾停舟｜本人怀中｜记录旧路死点、新裂槽出现处，已作为现场见证依据｜校路官确认顾停舟保留  
校路台现场记录副本｜校路官｜送往校路台途中｜载明旧路线废止、新裂槽另列及顾停舟现场见证｜本章由校路官携走  
第一笔个人潮钱｜顾停舟｜本人怀中｜数目不大且独立归属｜少东家第1章支付  
油纸分账记录｜顾停舟｜本人怀中｜记录救回矿车的车号、货签与份额｜少东家第1章交付

# Proposed Chapter Summary

顾停舟与校路官核验断路，确认旧路线已在塌坡处废止，裂槽是通往深潮矿脉外缘的短暂新通道。两人以原路线册对照立下现场记录，校路官保留副本并让顾停舟持有原册。校路官提出未来可接裂槽实测活；记录传入沉灯商盟后，阮青蜃下令寻找顾停舟。
