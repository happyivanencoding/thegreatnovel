# Proposed Active Scene State
地点：倒悬峡内，顾停舟正前往左侧石林救援；分身已进入建筑侧室。  
在场人物：顾停舟及分身、矿队领队与矿工护卫、乌合及砺骨部前哨、猎人。  
即时伤势：顾停舟腿虚、胸闷未散，手背被绳索磨出血；砺骨部一名前哨腿部受伤。  
手中关键物品：路线册、测路杆、绳索、实测契、行潮牌、潮钱、兼容潮髓。  
当前敌人或追兵：逆潮及侧室内未知牵扯。  
当前倒计时：逆潮持续翻卷，被困者随时可能被卷入裂槽或侧室。  
下一步直接目标：本体将左侧矿工带至可接绳处；分身仅救出右侧被困的砺骨部前哨，不触碰侧室物件。  
当前主动目标：以个人名义完成新裂槽实测并取得路线结果，追回倒悬峡入口的先手。  

# Proposed Persistent Canon
### Power / Capability
顾停舟可在逆潮中分出完整分身，并将牵引交由分身承担；本体与分身可分头执行明确救援行动。

### Active Relationships
乌合｜稳住砺骨部前哨并保护迁徙道｜有限认可、仍有边界｜顾停舟在矿工与砺骨部前哨同时被困时，安排分身进入侧室救人｜共同救援结果未定  
矿队领队｜抢占倒悬峡矿路与实测收益｜直接利益冲突的同行者｜无视顾停舟警示撬开潮泥，导致逆潮翻卷｜要求顾停舟优先救矿工  

### Knowledge / Enemy State
建筑潮泥外壳一旦破开，会令峡内潮向翻转并引发逆潮。建筑侧室存在会牵扯水流、碎石与人员的未知力量。  
矿队黑铁矿权标记已被逆潮击裂、拔出，未能在石台立稳。

### World State
倒悬峡内的古代建筑会影响周边水流；其外层潮泥被撬开后，峡内已发生逆潮翻卷，现场通行与实测暂时中断。

### Tracked Assets
黑铁长桩｜矿队｜倒悬峡石台附近泥水中｜矿记牌面断裂、短桩被逆潮拔出｜逆潮冲毁  
测路杆与长绳｜顾停舟及分身｜倒悬峡内｜用于逆潮救援｜顾停舟与分身各自持用  

# Proposed Chapter Summary
顾停舟随矿队进入倒悬峡，发现古代建筑外层潮泥会维持峡内潮向，却未能阻止领队撬墙。潮泥炸裂后逆潮翻卷，矿队、砺骨部前哨与猎人均被困险地，矿权标记被毁。顾停舟分出分身进入侧室救人，本体则前往左侧石林救援矿工。

# Proposed Open Promises
- 顾停舟与分身分别救出左侧矿工及右侧受困的砺骨部前哨。  
- 建筑侧室内的未知牵扯及其对逆潮的影响将被确认。  
- 顾停舟在逆潮后完成新裂槽入口、走向、危险点与承载路线实测。  
- 矿队矿权标记被毁后，顾停舟与领队将继续争夺实测权限、期限与收益。  
- 顾停舟使用兼容潮髓，观察其对养潮与影中分身代价的影响。  
- 倒悬峡中取得并拥有回潮楔。  
- 少东家与顾停舟在裂槽或货运利益上形成具体冲突与合作边界。  
- 乌合与顾停舟形成具体的信任边界、吸引和未被安全化的长期关系。
