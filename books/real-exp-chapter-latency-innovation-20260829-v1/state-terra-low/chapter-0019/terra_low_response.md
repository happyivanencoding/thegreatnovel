# Proposed Active Scene State
地点：旧关内侧粮道旁。
在场人物：顾停舟、顾沉戈、旧关守将、镇潮军府人员、随军文吏；居民、粮车与新井均已保住。
即时伤势：胸口旧伤严重撕裂，后背被血浸透，体力透支。
手中关键物品：裂损回潮楔、矿利与护粮结算文书、潮钱票据、镇潮军府战功牌。
当前敌人或追兵：镇海潮兽已被逼退至旧关外远潮，未被击杀。
当前倒计时：回潮楔持续散出残压，暂时不能再强行承压。
下一步直接目标：寻找能修复回潮楔的人，并核算潮钱是否足以购置潮舟。
当前主动目标：修复回潮楔、购置潮舟，带母亲离开旧关。

# Proposed Persistent Canon
### Power / Capability
- 顾停舟以照域承住镇海潮兽正面冲击，并与分身、回潮楔配合改退潮路，将潮兽逼退旧关之外。
- 照域正面承受兽冲后已自行消散；顾停舟无法继续硬撑。
- 回潮楔新增裂痕并持续散出残压，暂不可强行承压，否则可能彻底碎裂。
- 分身可用“定住”短暂钉死关键潮眼，但本次反震令其手腕开裂。

### Active Relationships
- 顾沉戈｜协助守潮与照料顾停舟｜临时执行关系｜率军府潮器引潮、扶住重伤顾停舟｜共同应对后续潮兽威胁
- 旧关守将｜守住粮道、新井与撤离路线｜临时协作关系｜公开记录顾停舟战绩，并承诺当日结清账目｜军府战功入册后的后续待遇
- 阮青蜃矿队｜撤离并保全人员｜与主角存在未决追索关系｜矿队已撤离，主角矿利已结算｜阮青蜃对矿权变化的后续追索

### Identity / Access
- 顾停舟以“正面承兽冲、改退潮、护粮道”的战绩公开入镇潮军府战功册，并持有军府战功牌。
- 顾停舟已取得矿脉个人份额与护粮结算。

### Knowledge / Enemy State
- 镇海潮兽可被照域、定住潮眼、回潮楔与军府引潮共同改退，但已退入旧关外远潮，仍是持续威胁。
- 照域者可压住局部潮场，却难以长期正面承受镇海潮兽冲撞。

### World State
- 旧关外层残墙、空屋、遗留潮车与部分压潮器已被主动放弃并遭黑水吞没；内侧粮道、三座新井及北侧居民得以保全。

### Tracked Assets
- 照域潮谱｜顾停舟｜已收起｜本章承兽冲后消散｜本章用于逼退镇海潮兽
- 回潮楔｜顾停舟｜手中／收存中｜新增裂痕、持续散压、不可强行承压｜本章由分身插入潮眼后取回
- 承运短契｜顾停舟｜怀中｜仍有效、粮运未最终完成｜未变化
- 个人矿利份额｜顾停舟｜防潮木匣中｜已结算为文书与潮钱票据｜本章由军府文吏交付
- 护粮结算｜顾停舟｜防潮木匣中｜已结算｜本章由军府文吏交付
- 镇潮军府战功牌｜顾停舟｜防潮木匣中｜有效｜本章由军府文吏交付

# Proposed Chapter Summary
镇海潮兽正面冲撞照域，顾停舟命军府放弃旧关外层，以本体承兽冲、分身定住潮眼并插下回潮楔，成功将黑水改向外层废墟，保住粮道、三座新井和居民。潮兽被逼退远潮，顾停舟重伤，回潮楔新增裂痕；军府随后结清矿利与护粮账，并将其战绩公开入册。

- 顾停舟重伤后的恢复，以及照域再次展开的条件与上限。
- 回潮楔的修复可能、残压散尽时间与彻底碎裂风险。
- 第一批粮能否完成旧关承运。

- 顾停舟能否用已得结算购置潮舟，并带母亲离开旧关。
- 阮青蜃对矿权标记失效、矿利结算及撤离结果的后续追索。
- 唐绾以反潮记录铸成的作品及其实际用途。
