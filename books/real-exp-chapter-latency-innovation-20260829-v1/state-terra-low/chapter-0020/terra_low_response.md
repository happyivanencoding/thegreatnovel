# Proposed Active Scene State
地点：远方潮市外的泊位水面。  
在场人物：顾停舟、母亲。  
即时伤势：顾停舟肩背旧伤仍在包扎，尚未痊愈。  
手中关键物品：小型潮舟、船契、行潮籍、防潮木匣（内有结算文书、潮钱票据、战功牌、照域潮谱、开裂回潮楔）。  
当前敌人或追兵：无明确追兵。  
当前倒计时：无明确倒计时。  
下一步直接目标：在远方潮市安顿母亲、养伤，并寻找修复回潮楔的途径。  
当前主动目标：修复回潮楔，以自有潮舟和资金带母亲离开旧关，建立自主潮路。

# Proposed Persistent Canon
### Power / Capability
- 顾停舟以照域正面承受镇海潮兽冲击，并与分身、回潮楔配合改退潮路，保住粮道、三座新井与北侧居民。
- 照域可在军府潮器配合下将镇海潮兽及其潮压推回旧关外，但连续承兽会造成严重伤势与脱力。
- 分身可用“定住”短暂钉住关键潮眼，但本次使用造成手腕受伤。
- 回潮楔新增裂痕，暂不可承压，唐绾明确表示目前无法修复。

### Active Relationships
- 母亲｜随顾停舟在远方潮市安顿｜共同离开旧关｜接受乘自有潮舟同行｜需陪伴其养伤与适应新处境
- 顾沉戈｜留在旧关处理军府事务｜并肩协作关系｜接受顾停舟离开｜后续是否重逢未定
- 少东家｜按独立合作处理未来生意｜平等合作关系｜当面撕毁旧账房契｜可按书面价格另谈合作
- 唐绾｜继续铸造潮器｜互有边界的同行关系｜送来防潮布并说明暂不能修楔｜待其具备修楔能力后再议
- 阮青蜃｜自行处理自身争端与行动｜关系转为可竞争、可合作的对手｜接受不再以长期债契相压｜后续合作或争夺待其自行提出

### Identity / Access
- 顾停舟的“正面承兽、改退潮、护粮道”战绩已公开入册，并获得镇潮军府战功牌。
- 顾停舟持有行潮籍，并以个人名义购得一条小型潮舟。

### Knowledge / Enemy State
- 镇海潮兽会追随照域改开的潮路，并能以连续冲击压迫照域。
- 镇海潮兽本次被改向潮水推回旧关外，但与照域潮谱的关系仍未确认。
- 旧关外层不再复建，毁弃责任由镇潮军府承担，不再摊及撤离居民与已结清个人账目。

### World State
- 旧关外层残墙、空屋及部分潮车、压潮器在引潮过程中被黑水吞没。
- 粮道、三座新井与北侧居民区域在镇海潮兽冲击中保住。
- 居民撤往北侧，粮道与三座新井由各方共护；砺骨部迁徙窗口及首批矿脉归属已定。

### Tracked Assets
- 小型潮舟、船契｜顾停舟｜远方潮市泊位｜船契已落顾停舟个人名下，可载人及少量行李｜顾停舟以潮钱票据购得
- 回潮楔｜顾停舟｜防潮木匣内｜新增裂痕，暂不可承压，已用防潮布包好｜唐绾托人送防潮布
- 结算文书、潮钱票据、战功牌、照域潮谱｜顾停舟｜防潮木匣内｜已持有｜随顾停舟登船离开旧关

# Proposed Chapter Summary
旧关外层确定毁弃、居民转往北侧后，少东家当面撕毁旧账房契，转为与顾停舟独立合作；唐绾说明暂不能修复回潮楔，阮青蜃也接受不再以旧债相压。顾停舟带母亲离开旧关，以行潮籍和战后所得买下小型潮舟，抵达一座陌生的远方潮市。

- 顾停舟肩背旧伤与分身手腕伤势的恢复情况。
- 顾停舟如何在远方潮市安顿母亲，并以自有潮舟开启自主生活。
- 少东家与顾停舟的独立合作会以何种生意展开。
- 阮青蜃在矿权失效、尾款放弃及矿利分配后的后续行动。
