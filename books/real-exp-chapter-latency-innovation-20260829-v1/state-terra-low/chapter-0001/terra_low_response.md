# Proposed Active Scene State

断裂潮路旁的石坡高地；顾停舟、少东家、校路官、商队伙计与护卫在场。顾停舟胸口发闷、双腿发软，无重伤；怀有个人潮钱袋，持有路线册与已签分账油纸。潮兽群已向远处迁行，无直接追兵。旧路已断，需重新核路。当前主动目标：跟随校路官勘查侧路，争取不挂在商号账下的独立活计。

# Proposed Persistent Canon

### Power / Capability

- 顾停舟首次使用借身：可从影子分出一个无多余表情的分身；分身能执行单一明确任务，本章表现为定住矿车。
- 借身结束后回归本体；顾停舟出现胸闷、腿软的消耗。

### Active Relationships

顾停舟｜争取独立路务机会｜与少东家仍是旧友兼上下级｜少东家按约结算救货份额，并开始重新评估其能力｜是否同意其随校路官勘侧路  
校路官｜重新核验断路与侧路｜与顾停舟形成待确认的合作入口｜认可其路线记录并接过路线册｜是否允许顾停舟随行勘路  

### Identity / Access

- 顾停舟仍无合法行潮籍，但已提出随校路官勘查侧路的请求。

### Knowledge / Enemy State

- 深潮矿脉方向出现受驱迁路的潮兽群；迁徙原因未知。
- 原潮路石桩偏移、地潮裂路，旧路不能再按旧账和原计划通行。
- 少东家已见证顾停舟同时救人、守车及其借身表现。

### Tracked Assets

潮钱袋｜顾停舟｜贴身携带｜第一笔明确归其个人所有的钱｜少东家按救货份额结算  
路线册｜校路官暂持查阅，顾停舟主张原始记录不得改动｜断路现场｜记录石桩偏移、兽印、加车与断路经过｜顾停舟交予校路官核验  
分账油纸｜顾停舟｜贴身携带｜少东家已按印确认救货分账依据｜本章签立  

# Proposed Chapter Summary

商队强行加车赶路，顾停舟发现石桩偏移与新鲜兽印后，先逼少东家签下救货分账。地潮裂路、潮兽群迁行时，他首次借身，一身定住矿车，本体带脚夫撤上高地，保住人和一车矿货。少东家按约给出第一笔个人潮钱；校路官决定重核道路，顾停舟提出随行勘查侧路。

# Proposed Open Promises

- 顾停舟能否随校路官勘查侧路，并以真实路线判断取得独立活计。
- 断裂旧路与深潮矿脉方向潮兽迁徙的原因仍待核验。
- 少东家是否接受顾停舟不再完全挂靠商号账目的选择。
- 借身的持续时间、更多可执行范围与首次消耗边界仍待后续事实确认。
