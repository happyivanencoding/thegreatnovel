# Proposed Persistent Canon
### Power / Capability
顾停舟已证明可从影子中分出一个自身，短时间同时执行另一处的简单动作；分身曾定住矿车。分身不能承担复杂自主行动，持续时间与完整代价仍未知；回归后会造成胸闷、腿软。  
获得兼容潮髓，可用于入潮人养潮；不能即时增强战力或替代实测风险。

### Active Relationships
少东家｜继续经营商号货路｜旧友转为独立同行者与潜在竞争者｜双方明确各接各案，裂槽相遇时按价谈路、按路相争｜未来裂槽货路中的合作或竞争  
校路官｜依规核验并管理路线登记｜认可顾停舟的独立实测资格｜准其落独立行潮籍，并为实测契盖印｜等待实测结果登记  
阮青蜃｜取得新裂槽路线结果｜委托人，尚未直接见面｜以个人名义委托顾停舟并支付预付款、潮髓｜顾停舟完成具名侧路实测案

### Identity / Access
顾停舟已取得独立行潮籍，具备合法接案、登记路线结果和收取赔付的资格；已签下阮青蜃名下的具名侧路实测契。

### Knowledge / Enemy State
旧路线正式废止；新裂槽通往深潮矿脉外缘，低潮时短暂可通行，仍有积水、塌陷与潮水回涨风险。  
实测契允许顾停舟在风险超出约定范围时中止并交回当时记录，不算违约。  
少东家与商号不能再将加车误判及杂货损失改写为校路记录中的潮灾损耗。

### Tracked Assets
