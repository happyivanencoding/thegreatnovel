# Proposed Active Scene State

地点：倒悬峡外撤离石道与撤离车旁。  
在场人物：顾停舟、乌合及砺骨部前哨同伴、矿工、阮青蜃、矿队首领及护卫。  
即时伤势：顾停舟仍胸闷吐血、肩背手臂与腿部受伤；成炉后力量暂稳，但体力消耗大。  
手中关键物品：细裂加深的回潮楔、受潮印记模糊的矿路实测契、唐绾要求查看反潮记录的消息。

下一步直接目标：带人安全撤离，并整理反潮记录、处理回潮楔修复与契约追索。  
当前主动目标：保住救出的人与回潮楔，掌握后续契约谈判主动权。

- 顾停舟已成炉；潮息可贯通胸腹与四肢，在重压下稳定输出，独自稳住一辆撤离商车。
