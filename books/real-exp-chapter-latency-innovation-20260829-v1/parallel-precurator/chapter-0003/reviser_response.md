# 正式正文

校路台的门槛比商号库房高半寸。

顾停舟抬脚跨进去时，腿上的酸胀还没退干净。屋里一股潮纸和灯油混在一起的味道，靠墙的木架上平码着防潮筒，校路官坐在长案后，正把昨夜那份断路记录压进红泥封袋。

少东家站在另一边，手里拿着商号的账册。

账册翻到一页，墨迹很新。

“加车是为了避险。”少东家开口，声音压得平稳，“杂货被潮水冲毁，也该算潮灾。商号照例担着损失，你把原路线册交回来，后面的账我会让人补齐。”

顾停舟没去看账册，先看了眼案上的封袋。

封口已经压实，外面写着校路台的收档日期。

校路官抬起头：“副本收下了，旧路线废止、新裂槽另列，这两条已经落档。”

少东家手指顿了一下。

顾停舟这才开口：“加车是你下的令。旧路断了，是现场对着石桩和塌坡看的。杂货损失是车队走在断路上出的事。”

“我没有说不是。”少东家皱眉，“我是在给商号留一条能结账的路。”

“你能给商号结账。”顾停舟说，“不能把路重新结回去。”

屋里安静下来。

顾停舟从怀里取出路线册，放在案上，却没松手。

册页被潮气浸过，边缘发皱。可上面的旧桩位、转折和记号都还在。

“旧路线到断处为止，新裂槽另列。”他看着少东家，“这本原册记的是旧路怎么死的，也记着新路从哪里冒出来。校路台副本已经收档，商号拿回去改几个字，现实里的石桩不会重新立起来。”

少东家盯着那本册子，脸色不太好看。

他不是没见过顾停舟顶嘴。以前顾停舟也会为了车次、潮钱、损耗跟账房争几句，但争完还是会把账册递过去，等商号给个结果。

今天不一样。

今天顾停舟按着的是自己的东西。

“你真要自己拿着？”少东家问。

“对。”

“你现在连行潮籍都没有。”

“所以我来校路台，不是回商号。”

少东家眼里的火气压了压，最后变成一点无奈：“停舟，你以为离了商号，路就好走？”

顾停舟笑了笑，笑意没到眼底。

“我知道不好走。可难走和替人背账，不是一回事。”

校路官把一枚黑底铜牌放到案上。

铜牌不大，正面是潮纹，背面留着一处空白。

“现场记录够了。”校路官说，“你持有原册，又在现场签过印。校路台可以给你落独立行潮籍。”

顾停舟看着那枚铜牌，没立刻伸手。

行潮人不是商队里跑腿的杂役。拿了籍，才能合法持有潮器、独立承接潮路和矿路上的活，也得自己担得起事故和赔付。

以前他总觉得这种身份离自己很远。商号给他一口饭，给他一辆车边的位置，他就该把路看好，把账做平。至于谁拿走路线，谁决定加车，谁在出事后把损失写成一句潮灾，都轮不到他多问。

现在铜牌就在眼前。

校路官提笔，问道：“顾停舟，以个人名义落籍。日后独立接案，路线结果和契约赔付自己承担。确认吗？”

顾停舟抬起头。

“确认。”

校路官在铜牌背面刻下他的名字，又让他按印。

顾停舟拇指压下去时，指腹微微发麻。

那不是商号的印，也不是谁替他盖的章。

是他自己的。

校路官把铜牌推到他面前。

“从今天起，你是行潮人。”

顾停舟把铜牌拿起来，入手冰凉，边缘却很稳。

少东家沉默了一会儿，忽然伸手合上账册。

“商号那部分损失，我会照实记。”他说，“加车是我的决定，旧路废止也不是你一句话写出来的。只是以后你拿着原册接活，商号也会找人看新路。”

“可以。”顾停舟说。

少东家看向他。

顾停舟把路线册收回怀里，语气没变：“谁出的价合适，谁的责任写得清楚，我就跟谁谈。商号也一样。”

少东家扯了下嘴角，像是想骂他，又没骂出口。

“行。”他说，“以后我们按这个谈。”

门外这时进来一个穿灰青短褂的人。

那人没有看少东家，径直走到长案前，先对校路官行了礼，才把一只细长木盒放下。

“沉灯商盟，阮姑娘座下承事。”他说，“奉命来找顾行潮。”

顾停舟握着铜牌的手指收紧了一点。

承事把木盒打开。

里面放着一张契纸、一只封口钱袋，还有一枚拇指大小的暗青色圆髓。那东西表面像被水打磨过，里面却有极细的潮光缓缓游动。

校路官看了一眼：“兼容潮髓。”

少东家的视线也落过去。

承事把契纸推到顾停舟面前。

“侧路实测案。”他说，“新裂槽下一次低潮前可以短暂通行。我们要你带着原路线记录，实测裂槽能走到哪里、能过什么车、哪些地方要封，写明结果即可。”

顾停舟没有碰钱袋，先拿起契纸。

契纸写得很直。

实测结果交付后，余款结清；若路线与现场不符，由委托方承担入槽后的人员与器材损耗；顾停舟只对实测结果负责，不替任何一方保证矿路归属，也不替商盟争取裂槽后的利益。

他从头看到尾，又问：“预付款多少？”

承事报了数。

顾停舟抬眼：“不够。”

少东家眉梢一动。

承事倒没有不耐烦：“顾行潮觉得哪里不够？”

“裂槽只在低潮前通行。进去以后遇到塌口、积水，退路未必还在原处。你们要的是能落档的实测结果，不是一趟替人探风的闲路。”

顾停舟点着契纸上的赔付条目。

“预付款加三成。兼容潮髓现在交付。还有，实测案只能挂在我个人名下，不挂商号，不借商号的名。”

承事看了看少东家。

少东家站在旁边，没替谁说话。

承事收回目光：“阮姑娘原本想买下原路线册。”

顾停舟的神色没变。

“原册不卖。”

“所以现在是侧路实测案。”承事说，“我们要的是你走这一趟，不是那本册子。”

顾停舟盯着他。

承事把钱袋往前推了半寸。

“预付款加三成，潮髓当场交付。契约只约路线结果和赔付，不约你日后归属。这样可够？”

顾停舟又把契纸翻到最后。

他不怕有人出高价。

他怕的是高价后面拖着一根看不见的绳，等他把脚踏进去，才发现脖子已经套上了。

“这句改掉。”他说，“‘委托方可优先续聘后续勘验’，删了。”

承事看了片刻，拿起笔，把那一行划去。

“可以。”

顾停舟这才问：“什么时候入槽？”

“下一次低潮前。”承事说，“窗口不长。”

“我签。”

校路官把印泥推过来。

顾停舟在契纸上写下名字，又按下手印。承事随即盖上沉灯商盟的承事印。

钱袋落进顾停舟掌心，沉得很实。

承事把那枚兼容潮髓递来时，顾停舟停了一瞬，才接住。潮髓贴着掌心，微凉，里面的潮光在暗青色的表面缓缓游动。

少东家看着他手里的钱袋和潮髓，忽然道：“你倒是谈得快。”

“路不会等人。”顾停舟把潮髓收好，“钱也一样。”

少东家哼了一声。

顾停舟抬头看他：“商号若要查新裂槽，照样可以接案。只是别再拿旧账压我。”

少东家沉默片刻，点了点头。

“不会了。”

承事向顾停舟拱手。

“顾行潮，侧路实测案已经生效。低潮一到，裂槽前见。”

他转身离开，灰青短褂很快消失在校路台外的人流里。

顾停舟站在原地，手里一边是新落籍的铜牌，一边是个人名下的预付款。

原路线册还在怀里。

新裂槽也还在前面。

他没急着数钱，只把铜牌挂到腰间，听见它轻轻撞在衣带上。

那一声不大。

却像有人终于把一扇原本不许他进的门，推开了一条缝。
