# MUST LAND

M1. 天色将暗，校路官主动决定不再回头核对旧路线册上的兽迹，直接带顾停舟沿断路外缘查看地潮顶出的新裂槽。

M2. 顾停舟用原路线记录与现场裂槽、石桩和新鲜矿层对照，确认这不是旧路的局部偏移，而是已经改向的新通道。

M3. 地潮改变通行结构；裂槽通向深潮矿脉外缘，并只在下一次低潮前短暂可行。

M4. 校路官据此判定旧路线不能继续使用；旧路线彻底失去可用性。

M5. 新裂槽与露出的深潮矿样被确认为独立事件，双方不再把它当作商号旧线的延续。

M6. 顾停舟保留原路线册，并接受作为本次现场事实的实际见证人；校路官将事实副本送入校路台。

M7. 顾停舟仍未取得合法行潮籍，也未正式获得独立实测工作；但原路线册与现场见证身份已成为他脱离商号账目、争取个人接活的现实依据。

M8. 校路官与顾停舟的关系从查阅记录转为共同确认现场事实。

M9. 结尾必须落到：校路台的事实记录传入沉灯商盟，阮青蜃开始寻找能够以个人名义完成实测的人；裂槽的短暂通行窗口使顾停舟下一步必须面对这次独立工作的入口。

# MUST NOT INVENT

N1. 不补写顾停舟已经取得合法行潮籍、正式独立实测资格或已接到个人工作。

N2. 不把新裂槽写成旧路线的局部修补、延伸或商号旧线的继续使用。

N3. 不新增下一次低潮的具体时间、持续时长、路线距离或通过条件。

N4. 不解释地潮为何改变、潮兽为何迁移，也不补写深潮矿脉的旧史、成因或未解谜底。

N5. 不新增校路台、沉灯商盟、阮青蜃之外的人物到场、制度流程、审批层级、支付方式或报酬数额。

N6. 不把事实副本扩写成完整报告、公开公告、商盟订单或已经兑现的独立收入。

N7. 不把规划备注中的“价值推进”“章节功能”写成角色自知的总结或正文硬事实。

N8. 不新增借身的能力规则、使用次数、感知方式、持续时间或力量上限。

# REALIZATION PRIORITIES

R1. World：现场必须让读者感到旧路不是“需要再看看”，而是通行结构已经被地潮改写；新裂槽与深潮矿样构成独立现场事实。

R2. Power：如触发借身或相关能力描写，只呈现 Authority 与既有 Canon 已支持的效果，不借本章偷加能力升级、精确力量尺或新限制。

R3. Human：顾停舟不是被动随行者；他坚持带原路线册、主动完成现场对照，并承担见证人的位置。

R4. Public Proof / Payoff：事实副本进入校路台后，顾停舟的路线判断必须获得脱离商号账目的现实分量；外部机构开始寻找个人实测者，形成可见的社会价格变化。

R5. Relationship：校路官与顾停舟的关系变化要落在共同确认现场事实的行为上，而非只靠称赞、评价或抽象表态。

# GLOBAL CLOSURE WATCH

G1. 持有人：顾停舟仍持有原路线册；它不能被交出后永久失去，也不能被改写成商号所有的普通账册。

G2. 状态：顾停舟仍无合法行潮籍，仍未正式获得独立实测工作；“现实依据”不等于资格已经成立。

G3. 时间窗口：新裂槽只在下一次低潮前短暂可行；不得改成长期开放或已经错过。

G4. 事实对象：裂槽、新鲜矿层、露出的深潮矿样、石桩与旧路线记录必须保持为本次现场核查的对应证据。

G5. 名称与关系：校路官、校路台、沉灯商盟、阮青蜃及顾停舟的关系转变不得错置；事实记录先进入校路台，再传入沉灯商盟。

G6. 力量档位：如引用力量正常值，只能保持既有“基础入潮者”与“成炉护卫”的边界，不新增精确数值或跨档能力。

# PRESERVE VALUE
