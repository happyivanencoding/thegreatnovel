# MUST LAND

M1. 镇海潮兽撞向照域边缘，顾停舟在旧伤加重、照域受损的情况下立即接战。  
M2. 顾停舟展开照域，本体进入镇海正面承受冲击；分身不携带完整潮炉，只携带“定住”，将回潮楔送到第二个关键潮眼。  
M3. 两具身体分别承担正面承压与侧面改向，使回潮楔承住冲击，并沿重新钉定的方向改变退潮路线。  
M4. 潮兽冲击压过照域边缘，旧关外层残墙彻底失守；照域、镇海军府与潮场将潮压导向可牺牲区域。  
M5. 镇海潮兽被压回远潮，居民、粮道和三座新井保住；旧关外层没有被强行保全。  
M6. 现场公开校准普通入潮者、成炉者、照域者与镇海战局承压能力之间的清晰差距。顾停舟取得镇海战局的公开战绩，并获得后续个人矿利与护粮结算的现实依据。  
M7. “借身＋照域＋回潮楔”完成最高局势下的双位置闭环；回潮楔在完整承压、释放后再次出现裂痕，进入长期散压与后续修复状态，顾停舟旧伤与照域负荷成为后续行动限制。  
M8. 战后矿利、护粮结算和公开战绩落到顾停舟手里；个人生活选择成为新的未决问题：是否把这笔钱和小型潮舟用于带母亲远行。下一章从这项选择及回潮楔的修复后果展开。

# MUST NOT INVENT

N1. 不得把本章最高战局中的承压表现写成稳定境界突破、临时境界变化或社会认证。  
N2. 不得新增精确力量数值、档位、承压上限、时间长度或潮压计算方式；“清晰差距”必须通过现场结果成立。  
N3. 不得新增潮域、分身、回潮楔或“定住”的能力规则、使用条件、代价机制、旧史和未解谜底。  
N4. 不得让分身携带完整潮炉，或凭空获得本章未授权的额外能力、人员支援或第三具身体。  
N5. 不得把旧关外层写成成功保全，也不得把居民、粮道、三座新井的保住扩写成无损全保。  
N6. 不得把第18章已放弃的实测尾款改写为本章重新收回；不得把仍保有的个人矿利与已放弃尾款混为一项。  
N7. 不得擅自确定矿利、护粮结算的支付者、支付方式、具体金额、结算制度或兑现细节。  
N8. 本章没有排程 Reader Release；不得凭空加入额外谜底、私人信息释放或超出 Authority 的人物到场。

# REALIZATION PRIORITIES

R1. World：读者必须感到顾停舟的取舍改变了受灾对象——牺牲旧关外层，保住居民、粮道与三座新井，而非抽象地“挡住攻击”。  
R2. Power：两具真实身体同时占据不可替代的位置；本体承受正面潮场，分身以“定住”完成侧面改向，不能写成普通分工或远程操控。  
R3. Human：顾停舟主动放弃继续保外层，把有限承受力集中到活人和后续生计；旧伤与照域负荷必须成为真实代价。  
R4. Public Proof：现场力量尺通过潮兽冲击、照域边缘失守、潮压改道和最终保全结果被公开校准，不靠讲解或空泛赞叹。  
R5. Payoff：公开战绩、个人矿利与护粮结算必须形成可使用的现实收益，并推动“带母亲远行”的具体生活选择。  
R6. Cost：胜利必须带着外层残墙牺牲与回潮楔再裂的代价，不能退化成单纯境界升级。

# GLOBAL CLOSURE WATCH

G1. 顾停舟仍保有个人矿利；此前放弃的是实测尾款。战后矿利与护粮结算的具体兑现不得互相混淆。  
G2. 回潮楔的顺序为：承受冲击、释放后再次出现裂痕、进入长期散压与后续修复；不得提前修复或无故恢复完好。  
G3. 顾停舟的旧伤与照域负荷在本章后仍构成行动限制；不得写成接战后毫无损耗。  
G4. 关键对象与地点须保持一致：镇海潮兽、照域、旧关外层与内侧、远潮、第二个关键潮眼、粮道、三座新井、回潮楔。  
G5. 分身只携带“定住”，不携带完整潮炉；双身体分别对应正面承压与侧面改向。  
G6. Ending 中矿利、护粮结算、公开战绩与小型潮舟的持有或可用关系，须足以支撑顾停舟作出是否带母亲远行的选择。

# PRESERVE VALUE

P1. 保留顾停舟在最高战局中的主动决断：不再试图保住旧关外层，而是集中有限承受力保护居民与生计。  
P2. 保留“两个真实身体同时占据两个不可替代位置”的核心幻想，不把分身降成传话、搬运或背景辅助。  
P3. 保留个人矿利这一具体占有与收益，也保留它最终转化为生活选择的可能。  
P4. 保留顾停舟带母亲远行的私人欲望，使章末收益落到人物生活，而不只落到战功。  
P5. 保留公开战绩带来的群体震动、懂行校准与行为重估，但价值应来自实际战果和力量差距。  
P6. 保留胜利的代价：外层残墙牺牲、旧伤加重、照域负荷与回潮楔裂痕。

# COMPRESS ONLY IF PRESENT

C1. 若出现军府布阵、路线协调、引流操作或撤离调度，只保留支撑“潮压被导向牺牲区域、三项目标保住”的必要流程。  
C2. 若出现多轮力量解释或重复证明，压缩为一次由现场结果完成的公开校准。  
C3. 若出现冗长登记、报告、账目或结算谈判，只保留建立现实依据及章末收益落地所必需的部分。  
C4. 若反复描写外层失守、旧伤或回潮楔裂痕，只保留第一次明确成立及其后果。
