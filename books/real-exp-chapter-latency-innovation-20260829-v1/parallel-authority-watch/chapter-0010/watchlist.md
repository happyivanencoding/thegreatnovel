# MUST LAND

M1. 峡外余震未平，分身回收后的伤势与回潮楔残压同时压入顾停舟体内；他在余震中用刚被撑开的潮炉，独自稳住撤离车，完成经验回收，并沿全身潮脉成炉。

M2. 顾停舟确认：成炉力量尚不能无条件传给分身。

M3. 面对矿队索楔，顾停舟指出实测契只约定路线与矿样，拒绝把回潮楔并入矿契，并接受原定尾款落空的后果。

M4. 矿队无法按原条件交付尾款，仍主张回潮楔属于矿队；阮青蜃正式启动契约损失与古器归属追索。

M5. 回潮楔仍由顾停舟个人持有，但器体出现细裂，残留潮压尚未稳定；归属争议与尾款责任均未解决。

M6. 乌合确认顾停舟守住了水窗，却没有替砺骨部夺路；双方的救命协作被重新定价，关系转为带戒备的欠情协作。

M7. 唐绾传来消息，要求查看反潮记录。章末保留回潮楔细裂、残压未稳、阮青蜃正式追索与唐绾索取记录形成的现实压力；古器修复与反潮实测成为下一章直接入口。

# MUST NOT INVENT

N2. 不断言矿队首领及护卫在谈判时是否仍在顾停舟面前；不补充其绕行、返回或具体站位。

N3. 不新增尾款金额、支付方式、责任比例、追索程序、矿契条款或古器归属裁决。

N4. 不把成炉扩写成精确力量尺、等级、稳定上限、残压机制或可复制能力规则；不提前写出修复方法、反潮实测结果或后续验证结论。

N5. 不添加 Reader Release、私人欲望、具体奖励、额外财富、持有人变化、人物到场、旧史、制度或未批准谜底。

# REALIZATION PRIORITIES

R1. [Power] 成炉必须作为顾停舟第一次正式完成的不可逆力量跃迁落地，让读者感到力量已经从“暂时扩张”进入“成炉已成”，但稳定性与残压代价仍真实存在。

R2. [Boundary] 分身不能无条件承载成炉力量必须清楚可感，不能被正文的动作结果或解释悄悄抹平。

R3. [Payoff] 顾停舟的个人持有与行动空间必须通过明确取舍成立：他保住回潮楔，却失去原定矿路实测尾款，收益与代价同时落地。

R4. [Public/Human] 矿权标记毁损、尾款无法交付、古器归属争议和正式追索必须改变现场各方对这次行动的判断；乌合的欠情协作与阮青蜃的追索要通过立场或行动显形。

# GLOBAL CLOSURE WATCH

G1. 力量状态统一为“成炉已成”，不能退回“潮炉暂时扩张”；稳定性、残压代价与分身承载边界仍未知。

G2. 回潮楔由顾停舟个人持有；器体细裂，残留潮压未稳定，归属争议与尾款责任未解决。

G3. 原定矿路实测尾款已落空；不能写成尾款已收、责任已结或古器已完成归属裁决。

G4. 乌合是带戒备的欠情协作关系；阮青蜃已转入正式追索；唐绾的反潮记录请求尚待回应。

G5. 时间与压力保持为峡外余震未平、残压未稳；古器修复和反潮实测是后续直接入口，不在本章提前完成。

# PRESERVE VALUE

P1. 保留顾停舟主动稳住身体、独自承担契约损失并守住个人持有的选择。

P2. 保留成炉完成带来的真实成长感，以及用尾款换取行动自由的具体代价。

P3. 保留“分身不能复制完整力量”的核心边界，不为追求爽感把能力写成无条件扩散。

P4. 保留乌合关系中的救命回报、戒备与欠情，不磨平成无条件盟友。

P5. 保留回潮楔细裂、追索启动和记录被索取造成的章末压力，使本章结算后仍有真实后果。
