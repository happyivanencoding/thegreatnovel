# FROZEN POWER SEED 3｜温折／受力成路

## World Power Normal → Exception

普通修士可以通过炼体、护符、兵器和术式抵抗外力。力量接触身体后，通常只剩下伤害、反震或消散。少数人能针对某种火、毒、寒或兵器形成抗性，但不能随意记录陌生力量。

温折的异常是“受力留向”：他在承受一次真实力量后，可以留下这股力量的方向关系，而不是留下力量本身。

## Core Fantasy / 特殊际遇

如果我是他，我不能直接偷走对手的力量，但我可以记住那股力量怎样进入身体、怎样寻找目标、怎样被地面或兵器承受。

下一次交手时，我能让自己的力量沿着那条关系转向，让对手的重击穿过墙面、让自己的冲撞借着旧有方向加速，或者把已经接触身体的力量导向另一个承载物。

他不是免疫攻击，而是逐渐学会让攻击走错地方。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：体魄越强，他越能承受不同方向、不同层级的力量；神识和灵力越强，越能分辨受力过程并把它转化为自己的术式。
- **异常掌握轴**：从留下单一方向，成长到同时保留多种受力关系；从身体受力，扩展到兵器、地面、水流、风势和术式之间的传导；最终能在复杂战斗中连续借力、转力和错位。
- **永久边界**：他必须先真实承受过那种力量。第一次遇到远超承载上限的攻击时，他可能直接死亡。留下的是“方向关系”，不是攻击者的灵力、境界或完整术式。

## 为什么读者会馋

他的成长不是单纯变硬，而是每一次挨打都会让他对世界的受力方式理解更深。

读者会期待强敌的招式，因为越强、越独特的攻击，越可能成为他下一次突破战斗方式的材料——但第一次接触仍然可能要命。

## HUMAN CORE｜Frozen Authority

# HUMAN SEED CANDIDATE 3｜魏执／我要让别人按我的判断活下来

## 世界中的初始位置与成长环境

魏执出生在一户普通军户家庭。父亲曾在城防营负责粮秣和伤员转运，母亲经营军营外的小食摊。家里有军籍，却没有修士背景，也没有足够的战功换来真正稳固的田地。

魏执识字不多，却熟悉队列、粮道、伤亡登记和军府里如何把责任推给一个最没有靠山的人。他不崇拜英雄，只相信一件事：在真正出事的时候，谁有资格下令，谁就决定谁承担代价。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾因上级改动粮车数量而被罚，明知不是他的错也无法申辩 → 魏执学会了“没有决断权的人只能替别人承担结果” → 他在任何集体行动中都会主动确认谁下令、谁承担、谁能改变计划。

- 他第一次带一小队人押送伤员时，按照老兵经验绕开危险路，却在半途遇到更大的妖兽迁徙，最后只能丢下部分物资 → 他误学会不能把命交给“大家都这么做”，必须自己判断最坏结果 → 他后来宁愿被骂擅作主张，也要在行动前重新查看地形、粮水和撤退方向。

- 他曾因抢先承担一次错误决策，被长官当众称为“自作聪明的军户子” → 他发现承认责任并不会自动换来尊重，只有让结果逼别人承认自己 → 他开始主动争取那些成败清楚、旁观者足够多的差事。

## 当前私人欲望

“我要有一次，所有人都知道该不该走、该不该守，最后只能听我的。事情办成以后，他们不能说是上头安排的；事情办砸了，也不能把我推出来顶罪。”

## Core Obsession

他想不断扩大自己能够作出关键判断、并让别人愿意把性命交给这个判断的范围。

他追逐的不是官位本身，而是从一队人、一座营寨、一段粮道，逐渐进入更大局面中的决定位置。地位越高，能被他改变的结果越多，他就越难接受只做一个执行命令的人。

## Excess｜哪里过量

他已经获得一个安全的文书职位，只要熬几年就能换到稳定俸禄和一块军田，却主动申请去接手一支装备最差、每逢归潮都缺人的巡逻队。

不是因为他想救谁，而是因为那里的结果足够清楚：只要他判断错一次，所有人都会知道错在什么地方。

## Behavior Signature

面对高价值机会，他会选择能让自己真正承担结果的位置，而不是看起来最体面的升迁。

受到羞辱时，他不会立刻动手，而会把对方逼到必须接受自己判断的局面里。

面对恐惧，他先确认能牺牲什么、必须保住什么；面对关系压力，他不会许诺“你不会死”，只会给对方一个明确的位置和撤退条件。

重大损失发生后，他会反复重建当时的决策顺序，既不轻易自责，也不允许别人用一句“运气不好”结束讨论。

## 重要关系原点

- 父亲魏川：只想攒够军田和退籍的功劳，让儿子离开军府。魏执认为父亲一生都在替别人承担后果，却从未争取过真正的决定权。父亲则认为儿子把“能下令”误当成了活着的资格。

- 老兵周魁：想用多年经验换一个不再上前线的位置。他愿意教魏执如何让疲惫的人继续听令，却不愿接受一个年轻军户取代自己成为队伍真正的依靠。

- 军府文吏许闻达：想把魏执培养成一把敢担责、好控制的刀。魏执需要许闻达提供调令和记录上的支持，却清楚对方真正想要的是一个替自己背锅的人。

## 人物钩子

一次押运中，上级给出模糊命令，所有人都等着别人先动。魏执当众撕掉原本的路线图，指着三条路说明哪一条会丢货、哪一条会死人，然后要求所有人先听完他的判断，再决定是否跟他走。

读者会记住：他最危险的地方不是敢拼，而是他真的想让别人把命交给他的判断，并且愿意为这种资格承担别人不愿承担的后果。
