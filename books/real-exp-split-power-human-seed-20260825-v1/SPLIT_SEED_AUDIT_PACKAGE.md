# CHARACTER LIFE CONTEXT｜Upbringing Authority

## 普通人的生活与上升

大多数人出生在河谷、山城、海港、盐场、矿镇或宗族村落。

普通人的生活围绕土地、水源、牲畜、商路、兵役、婚姻和税契展开。灵气并没有让所有人都衣食无忧：一块能稳定种出灵谷的田，往往比一间普通铺面贵；能避开妖兽迁徙的村子，比靠近遗迹的村子更适合养家。

没有修行天赋的人，也可以通过很多方式改变身份：

- 学一门能靠灵材吃饭的手艺，例如炼药、制符、驯兽、铸兵、辨矿、修船。
- 进入军府或城防营，靠战功获得田地、户籍和商路保护。
- 投靠宗门、商会、世家，成为账房、管事、护卫、外门弟子或附属家族。
- 和修士、贵族、商人联姻，改变家族的资源位置。
- 把握归潮、矿脉、遗迹开放等机会，用一辈子积蓄换一次翻身。

修士并不自动脱离日常生活。低阶修士仍要吃饭、治伤、交税、还债，也需要有人替他们种田、运货、照顾家人。一个会使三种常用符箓的匠人，未必打得过一名军府校尉，但他的收入和社会地位可能更高。

在许多地方，“有本事”比“能打”更重要。

## 社会现实与身份

澜生界有王朝、城邦、宗门、世家、商盟、军府、海国和流动部族。它们彼此重叠，却没有一个机构能统治整个世界。

一个人的身份通常由几件事共同决定：

- 出身家族是否拥有田地、矿山、血缘传承或修士保护。
- 是否有正式师承，能否使用某个宗门的术式和资源。
- 是否拥有城籍、军籍、商籍或宗门凭证。
- 是否欠下债务、血仇或誓约。
- 是否在战场、商路、遗迹或地方灾难中证明过自己。

宗门既是修行场所，也是家族、学校、兵营、医院和产业主。不同宗门差异很大：有的培养剑修，有的经营药山，有的替城池镇压妖患，有的靠海上贸易维持山门，还有的专门替贵族处理不能见光的事情。

修士寿命越长，越容易和普通亲族产生隔阂。一个三十岁才纳息成功的人，可能要面对父母老去、兄弟分家、婚约失效；一个修行有成的人，也可能因为不愿加入宗门而被地方势力排斥。

法律无法覆盖所有力量。

城中严禁大范围术法，但贵族和宗门往往拥有豁免；平民杀死妖兽会得到赏金，杀死修士却可能被当成叛乱；同一件法器，在商会账本里是货物，在宗门眼里是传承，在军府眼里则可能是战略武器。

很多冲突不是善恶之争，而是不同身份的人对同一块土地、同一件遗物、同一段婚约拥有不同的合法解释。

## 世界里真正值钱、值得想要的东西

最值钱的东西不只有修为。

- 能连续三代产出灵谷的土地。
- 一条不会被妖兽和军队截断的商路。
- 记载真实地形、暗河和遗迹入口的旧地图。
- 能让伤势不恶化的高阶药材。
- 一件真正适合自己的兵器，而不是名声响亮的废物。
- 一个愿意在关键时候出面的人。
- 大宗门的正式身份，或某座强城的永久居留权。
- 一支训练有素、不会在归潮期间失控的灵兽队伍。
- 没有被任何势力登记过的矿脉。
- 一份能证明血缘、继承权、土地归属或旧日罪责的原始文书。
- 可以让普通人活得更久、让修士少走弯路的医术和传承。
- 一件能够打开旧时代建筑、但尚未被任何宗门完全破解的器物。

许多人愿意用修为、寿命、婚姻、家产和性命去换这些东西，因为它们不仅改变一个人的力量，也会改变他以后能住在哪里、能带谁同行、谁愿意与他交易，以及哪些敌人会开始认真看待他。

## 世界知识边界

普通人知道：

- 王朝、宗门、商盟和妖兽都真实存在。
- 归潮会带来财富，也会带来灾难。
- 低阶修士可以通过学习和药物产生，但高阶修士需要天赋、师承、资源和运气。
- 许多古代遗迹危险，却不一定藏着宝物。
- 海外和天外都存在未知，但没人能可靠地讲清楚那里是什么。

专业人士知道：

- 不同地区的灵气性质并不相同，某些术法离开原产地后会失效。
- 妖兽迁徙、灵植开花和归潮落点存在规律，但规律并不完整。
- 古代器物通常需要特定材料、血脉、地势或文字才能启动。
- 很多宗门保存的祖师传说经过改写，不能直接当作历史。
- 高阶修士失踪的原因各不相同，不能简单归结为飞升。

顶层势力知道：

- 已知大陆只是澜生界的一部分。
- 古代王朝曾经拥有远超今日的跨域交通和炼器技术。
- 某些力量并非失传，而是被故意拆散、封存或改写。
- 归潮不是自然界唯一的大周期。
- 过去数千年里，至少有三次大范围文明断裂，但断裂之间是否存在联系，没有完整证据。

## Upbringing 生成边界
本区块只负责塑造出身、阶层、家庭生态、教育、欲望、偏见、恐惧、关系与行为适应，不负责决定 Core Fantasy 的异常类型。
人物可以来自世界任何合法社会位置：贫寒、普通、富裕、宗门家庭、军户、商人、专业家庭、地方权势、既得利益或天赋优越者都可以；不默认底层受压迫者。
采用 Formative Fact → Adaptation → Observable Behavior：具体经历先发生，人格是长期适应留下的选择偏差，不从性格标签或道德使命反推经历。
不得引用未提供的 named 大事件、named NPC、named 秘境、named 神兵或未来剧情路线。

# CHARACTER CANDIDATE 1｜祁砚／借万物一锋

## World Power Normal → Exception

澜生界绝大多数修士，依靠身体、神识、术式和外物形成稳定配合。一个人通常有一两种最熟悉的灵材、兵器、地势或天气，离开这些条件后，力量会明显下降。

常见的是强化身体、符箓、兵器、火风水势；少数人能同时操纵多种术式，或让一件兵器随自身成长。

祁砚的异常是“复合借相”：他能在短时间内把多种外物同时接入自己的力量回路。它们不属于他，也不会被他炼化，但能被他临时组合使用。

## Core Fantasy / 特殊际遇

如果我是他，我可以把断枪当作锋，把墙面当作盾，把雨水当作传力媒介，再借对手打来的力量完成同一招。

我不是单纯会用更多兵器，而是能把原本互不兼容的物件、地势、天气和残余力量拼成一套临时术式。

边界是：他不能凭空制造力量，必须有真实可用的外物；外物越强，对自身承载要求越高；他也不能永久夺走兵器、法器或他人的力量。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：纳息、通脉、立相、照域会提升他的体魄、神识、灵力总量和术式稳定性。否则他即使接入更多外物，也只能让自己先崩溃。
- **异常掌握轴**：从同时借用两种外物，成长到多种力量的精确切换；从物件组合，扩展到地势、天气、术式残势和敌我力量的短暂衔接；逐渐减少接入时的停顿与反噬。
- **永久边界**：不相容的力量始终可能互相冲撞。高阶以后他仍不能无条件拼接所有力量，错误组合会直接损伤经脉、神识，甚至让术式反噬自身。

## 为什么读者会馋

他能把战场上不起眼的东西变成自己的武器，越陌生、越破碎、越混乱的环境，越有发挥空间。

读者会期待他拿到一件东西后，不是问“它值多少钱”，而是问：“它能不能被他接进下一招？”

## 成长环境切片

他出生在拥有稳定商籍的押运家庭，家里不缺资源，却极重视货物归属、契约和损耗。贵重器物从不让他碰，他从小接触的都是被判定为残次、过期或无主的东西。

## 形成经历 → 适应 → 行为

- **经历**：他曾因一次贵重货物损坏，被所有人先问责任归属，没人先问还能不能使用。
- **适应**：他逐渐认为“身份和标价都不可靠，真正重要的是东西在当下能承担什么”。
- **行为**：他习惯先摸、先试、先判断承载极限；战斗中很少依赖单一武器，总会给自己留下第二种接力方式。

## 人物钩子

他表面精于算计，实际上最怕的是“自己没有可替代方案”。他不迷信名器，也不轻易把命交给某件东西。

## 当前私人欲望

拥有一套任何势力都无法收回的力量。他想证明自己不是家族货物、商会资产或某件法器的附属品。

## 行为签名与执念

他会随手保存别人丢弃的零碎物件，并在关键时刻突然用上。越是被人断言“没用”，他越想验证它究竟能做到什么。

## 重要关系原点

家中掌契的长辈把他视为适合处理损耗和烂账的人；一名长期押运他的护卫则曾教他基础炼体。前者希望他变得可控，后者只要求他别把命押在单一招式上。

## 为什么世界里的人会立刻察觉他特殊

普通修士更换外物需要重新适应，祁砚却能在一次交手中连续切换多种支撑，而且每种支撑都真实参与了术式。

## 第一次暴露特殊性的场面

仓库中的货架突然倾倒，他手里的护身符只能挡住一面。祁砚先用断裂木杆撑住货架，再借湿绳传力，把地上的铁环弹出，最后让墙面承受余震。几件互不相干的废物被他连成了一次完整的卸力术。

## 世界不容易消化他的地方

他会模糊物品的归属边界。别人眼中的祖传兵器、阵法核心和战略物资，在他手里都可能只是某一招的临时组件。商会、宗门和军府都会担心他把本不该组合的东西组合起来。

# CHARACTER CANDIDATE 2｜陆未／留着未完

## World Power Normal → Exception

澜生界的术式通常需要完整施展。灵力进入术式，术式完成动作，力量随之释放。高阶阵法可以分段启动，但必须依靠提前布置好的阵盘、灵材和地势。

陆未的异常是“未完承载”：他能把一个已经启动、却尚未完成的术式保持在不稳定状态，并将它带入之后的动作中。

## Core Fantasy / 特殊际遇

如果我是他，我可以挥出一半的刀，先不让刀势落下；我可以让火术停在燃烧之前，把这股“即将完成的力量”藏进刀锋、墙缝或自己的经脉，再在真正需要的时候完成它。

这不是时间停止，也不能让已经发生的事情重新变回未发生。它只能保存尚未结算的术式结构。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：正常境界提升会增强他的体魄、灵力和神识，使他能承受更多未完术式，也能在术式即将失控时重新接管。
- **异常掌握轴**：从保存一个简单术式，成长到同时维持多个不同阶段；从延后释放，扩展到改变完成顺序、转换承载位置，并让不同未完术式在最后一刻互相衔接。
- **永久边界**：未完术式会持续消耗灵力和注意力，不能无限保存；外力干扰可能让它提前爆发。它不能保存超过自身承载上限的力量，也不能撤销已经完成的结果。

## 为什么读者会馋

他的力量天然制造“这一招还没结束”的期待。

敌人以为他失手，实际上他只是没有让结果落地；读者会不断猜测那些被他刻意留住的半招，最后究竟会在什么位置完成。

## 成长环境切片

他出生在一个生活宽裕、规矩严密的内城家族。家中所有重要事务都要等长辈盖章、定案、收尾，年轻人只能执行已经决定的事情。

他小时候经常被安排处理别人留下的半成品：没写完的账、没修完的器物、没有收尾的家务和争执。

## 形成经历 → 适应 → 行为

- **经历**：一次迟迟没有定案的家族事务拖过期限，最终造成实际损失，但所有人都把责任推给最后经手的人。
- **适应**：他不再相信“尽快结束就是正确”，认为未完成本身也可以是一种筹码。
- **行为**：他很少立刻给出完整答案，习惯保留一个出口；战斗中经常故意收招，让对手误判他已经力竭。

## 人物钩子

他不是优柔寡断，而是讨厌别人替他决定什么时候结束。他愿意承担拖延的风险，也不愿把最后一步交给别人。

## 当前私人欲望

获得不被任何人催促、强迫或替他收尾的人生。他想让所有重要选择都在自己手里完成最后一步。

## 行为签名与执念

他会把事情做到九成，然后停下来观察别人如何反应。别人越急着替他完成，他越可能利用那个动作改变结果。

## 重要关系原点

家中长辈一直把他的迟疑视为无能，要求他做事必须“有头有尾”；一名年幼亲属却习惯把未完成的麻烦交给他，因为相信他总能找到重新接上的方法。

## 为什么世界里的人会立刻察觉他特殊

普通修士收招后，灵力会自然散去或反噬；陆未却能让术式停在完成前，并在之后继续调用。观者会发现他的招式存在不合常理的第二个落点。

## 第一次暴露特殊性的场面

练习火术时，他的灵力不足以完成术式。所有人以为火焰已经失败，他却把半成形的火光压进手背，数息后用它点燃远处一张尚未启动的符纸。两处术式因此同时完成。

## 世界不容易消化他的地方

城防、比试和契约都依赖“术式何时完成”来判断责任。陆未的力量会让人无法确认攻击是否已经结束，也让别人害怕他在看似平静的动作里藏着未结算的危险。

# CHARACTER CANDIDATE 3｜温折／受力成路

## World Power Normal → Exception

普通修士可以通过炼体、护符、兵器和术式抵抗外力。力量接触身体后，通常只剩下伤害、反震或消散。少数人能针对某种火、毒、寒或兵器形成抗性，但不能随意记录陌生力量。

温折的异常是“受力留向”：他在承受一次真实力量后，可以留下这股力量的方向关系，而不是留下力量本身。

## Core Fantasy / 特殊际遇

如果我是他，我不能直接偷走对手的力量，但我可以记住那股力量怎样进入身体、怎样寻找目标、怎样被地面或兵器承受。

下一次交手时，我能让自己的力量沿着那条关系转向，让对手的重击穿过墙面、让自己的冲撞借着旧有方向加速，或者把已经接触身体的力量导向另一个承载物。

他不是免疫攻击，而是逐渐学会让攻击走错地方。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：体魄越强，他越能承受不同方向、不同层级的力量；神识和灵力越强，越能分辨受力过程并把它转化为自己的术式。
- **异常掌握轴**：从留下单一方向，成长到同时保留多种受力关系；从身体受力，扩展到兵器、地面、水流、风势和术式之间的传导；最终能在复杂战斗中连续借力、转力和错位。
- **永久边界**：他必须先真实承受过那种力量。第一次遇到远超承载上限的攻击时，他可能直接死亡。留下的是“方向关系”，不是攻击者的灵力、境界或完整术式。

## 为什么读者会馋

他的成长不是单纯变硬，而是每一次挨打都会让他对世界的受力方式理解更深。

读者会期待强敌的招式，因为越强、越独特的攻击，越可能成为他下一次突破战斗方式的材料——但第一次接触仍然可能要命。

## 成长环境切片

他出身于有军籍、有田产的武官家庭，生活并不贫困。只是家中长辈擅长进攻，他从小体格普通，长期被安排在防守、承伤和记录位置。

## 形成经历 → 适应 → 行为

- **经历**：他在一次训练中替别人承受了本不该由自己承担的重击，事后却只得到一句“你本来就是防守位”。
- **适应**：他开始把疼痛视为信息，却极度厌恶自己被当作可以牺牲的那个人。
- **行为**：他很少抢先出手，总先观察对方第一击的方向、落点和余势；但一旦看清，就会用极其冒险的方式改变力量去向。

## 人物钩子

他愿意受伤，但不愿意白受伤。别人把他的忍耐当作服从，他却把每次伤害都记成未来反击的依据。

## 当前私人欲望

拥有一种不会因为年龄、出身或职位变化就被替代的战斗方式。他想让任何把他当成消耗品的人，最终都必须重新计算代价。

## 行为签名与执念

他会要求对手再出一次同样的招，哪怕已经看出危险。他不相信一句“我知道了”，只有身体真正走过那条受力路径，才算掌握。

## 重要关系原点

家中年长者认可他的耐打，却习惯把他放在最危险的位置；一名训练教习则第一次告诉他，承受不是服从，关键在于决定力量最后落在哪里。

## 为什么世界里的人会立刻察觉他特殊

普通修士被同一种力量击中，通常只会越来越伤；温折第二次面对相同方向时，身体和兵器却会出现明显不同的承力方式，像是已经提前走过那条路。

## 第一次暴露特殊性的场面

公开训练中，对手用钝器击中他的肩膀。第二次同样的重击落下时，他没有硬挡，而是让肩、腰、脚下石板形成一条斜向受力线，整个人借力滑开，钝器的余劲穿过石柱，将石柱打裂。

## 世界不容易消化他的地方

别人会怀疑他偷学术式，甚至不敢轻易让他接触自己的招法。但许多毒、梦、领域和无形侵蚀并没有清晰的受力方向，若他误以为自己能够适应，反而会死得更快。

## World Power Normal → Exception

这是极强的探索自由和战斗位置感。

他可以从封锁中脱身，可以同时处理两个方向的威胁，可以把“退路”变成实际存在的战斗位置。读者会期待他如何利用空间关系，而不是只看他把灵力数值堆高。

## 成长环境切片

他出生在一个合法往来于两座城镇的家庭。父母分别承担两边的家产与亲族事务，他从小在两处住处之间往返，两个家庭都承认他，却都认为他最终应该选择其中一边。

## 形成经历 → 适应 → 行为

- **经历**：一次重要家族安排中，两边同时要求他到场，他无论选择哪边，都会被另一边视为拒绝。
- **适应**：他逐渐不再认为“只能选一个地方”是正常秩序，也不把归属感寄托在单一住处上。
- **行为**：他习惯保留两条退路、两套物资和两种说法；别人逼他立刻站队时，他往往先创造第三个位置。

## 人物钩子

他不喜欢被谁完全拥有，却也不愿意彻底失去任何一段关系。他的核心矛盾不是逃避选择，而是坚信自己有权同时保留多个选择。

## 当前私人欲望

拥有一个不需要任何人许可就能进出的私人空间，并让两边的人都无法再用“你不在这里”来否定他的存在。

## 行为签名与执念

他从不把所有东西放在同一个房间，也很少只和一个人谈关键事情。他会在谈判桌下提前留下第二个位置。

## 重要关系原点

父母双方都希望他继承自己的家庭事务；两边的同辈亲属则把他视为竞争者或中间人。他与其中一名年幼亲属关系较好，因为那个人从不要求他证明自己属于哪一边。

## 为什么世界里的人会立刻察觉他特殊

普通腾挪只会让人从一处消失、在另一处出现。沈回却可能让两个位置同时出现同一个人的视线、声音或动作反馈，旁观者无法用正常移动解释。

## 第一次暴露特殊性的场面

术式训练场发生坍塌，他的身体被压在墙边，另一只手却从此前触碰过的屋檐瓦片旁伸出，抓住了远处的绳索。随后他把两个位置的受力合在一起，硬生生把身体拖出坍塌范围。

## 世界不容易消化他的地方

他的能力会直接冲击“人在何处”的法律和常识。城门、牢狱、契约、决斗和领地禁制，都无法轻易判断他是否已经离开、是否仍在场，以及某个动作究竟发生在哪个位置。

# FROZEN POWER SEED 1｜祁砚／借万物一锋

## World Power Normal → Exception

澜生界绝大多数修士，依靠身体、神识、术式和外物形成稳定配合。一个人通常有一两种最熟悉的灵材、兵器、地势或天气，离开这些条件后，力量会明显下降。

常见的是强化身体、符箓、兵器、火风水势；少数人能同时操纵多种术式，或让一件兵器随自身成长。

祁砚的异常是“复合借相”：他能在短时间内把多种外物同时接入自己的力量回路。它们不属于他，也不会被他炼化，但能被他临时组合使用。

## Core Fantasy / 特殊际遇

如果我是他，我可以把断枪当作锋，把墙面当作盾，把雨水当作传力媒介，再借对手打来的力量完成同一招。

我不是单纯会用更多兵器，而是能把原本互不兼容的物件、地势、天气和残余力量拼成一套临时术式。

边界是：他不能凭空制造力量，必须有真实可用的外物；外物越强，对自身承载要求越高；他也不能永久夺走兵器、法器或他人的力量。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：纳息、通脉、立相、照域会提升他的体魄、神识、灵力总量和术式稳定性。否则他即使接入更多外物，也只能让自己先崩溃。
- **异常掌握轴**：从同时借用两种外物，成长到多种力量的精确切换；从物件组合，扩展到地势、天气、术式残势和敌我力量的短暂衔接；逐渐减少接入时的停顿与反噬。
- **永久边界**：不相容的力量始终可能互相冲撞。高阶以后他仍不能无条件拼接所有力量，错误组合会直接损伤经脉、神识，甚至让术式反噬自身。

## 为什么读者会馋

他能把战场上不起眼的东西变成自己的武器，越陌生、越破碎、越混乱的环境，越有发挥空间。

读者会期待他拿到一件东西后，不是问“它值多少钱”，而是问：“它能不能被他接进下一招？”

# FROZEN POWER SEED 2｜陆未／留着未完

## World Power Normal → Exception

澜生界的术式通常需要完整施展。灵力进入术式，术式完成动作，力量随之释放。高阶阵法可以分段启动，但必须依靠提前布置好的阵盘、灵材和地势。

陆未的异常是“未完承载”：他能把一个已经启动、却尚未完成的术式保持在不稳定状态，并将它带入之后的动作中。

## Core Fantasy / 特殊际遇

如果我是他，我可以挥出一半的刀，先不让刀势落下；我可以让火术停在燃烧之前，把这股“即将完成的力量”藏进刀锋、墙缝或自己的经脉，再在真正需要的时候完成它。

这不是时间停止，也不能让已经发生的事情重新变回未发生。它只能保存尚未结算的术式结构。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：正常境界提升会增强他的体魄、灵力和神识，使他能承受更多未完术式，也能在术式即将失控时重新接管。
- **异常掌握轴**：从保存一个简单术式，成长到同时维持多个不同阶段；从延后释放，扩展到改变完成顺序、转换承载位置，并让不同未完术式在最后一刻互相衔接。
- **永久边界**：未完术式会持续消耗灵力和注意力，不能无限保存；外力干扰可能让它提前爆发。它不能保存超过自身承载上限的力量，也不能撤销已经完成的结果。

## 为什么读者会馋

他的力量天然制造“这一招还没结束”的期待。

敌人以为他失手，实际上他只是没有让结果落地；读者会不断猜测那些被他刻意留住的半招，最后究竟会在什么位置完成。

# HUMAN SEED CANDIDATE 1｜季衡／把名字钉在纸上

## 世界中的初始位置与成长环境

季衡出生在河谷小城的契书户。父亲替乡绅、商户和军府小吏抄写税契、地契与借据，母亲经营一间卖纸墨和晒药的小铺。家里不贫寒，却始终没有真正属于自己的田，也没有能让人高看一眼的身份。

他识字早，熟悉印章、见证、地界和账目，却没有正式师承。家里人希望他继承父亲的手艺，安稳地替别人把话写成凭据。

## Formative Facts → Adaptation → Observable Behavior

- 父亲年轻时替一户农人抄过土地转让契，因为原始契书遗失，最后被双方同时指认为骗子 → 季衡误以为口头承诺和多年情分都不可靠，只有能被追溯的凭据才算数 → 他替人办事时总要留下副本、见证和时间顺序，哪怕因此得罪急着成交的客户。

- 他曾花掉家中半个月的进项，替一个已经死去的佃户追回一份被水泡烂的旧契 → 他发现自己无法容忍一段真实经历被一笔勾销 → 对于无人争夺的旧账、旧地界和被改写的家谱，他会持续追查，直到确认自己手里有足够证据。

## 当前私人欲望

“我不想一辈子替别人写他们的田、他们的债、他们的身份。我想有一块地，契书上写的是我的名字，谁来查都抹不掉。”

## Core Obsession

他想把一切容易被人改口、抢走、否认的东西，变成自己能够掌握的确证。

最初是土地和家产，后来会扩大到商路、血缘、旧案、继承权、地图和人与人之间的承诺。东西越大，他越想知道它真正属于谁、谁有资格证明、谁在故意留下空白。

## Excess｜哪里过量

他已经有足够的钱买一间小铺，却把积蓄全部拿去收购一批被虫蛀的旧账册，只因为其中几页可能证明一座荒废渡口的归属。

普通人会认为那些账册不值得冒险，他却愿意因此推迟婚事、得罪客户，甚至亲自去找已经搬走几十年的见证人。

## Behavior Signature

面对高价值机会，他先问“东西真正属于谁”，而不是先问能赚多少。

受到羞辱时，他很少当场争辩；他会记下对方说过的话，寻找能让对方无法抵赖的证据。

面对恐惧，他会把风险拆成凭据、见证、退路和损失上限；关系逼迫他表态时，他不会轻易说“我相信你”，而会要求对方留下某种可以承担后果的承诺。

重大损失发生后，他不会立刻报复，而会先查清楚自己究竟在哪一个环节失去了证明权。

## 重要关系原点

- 父亲季文安：只想守住这门不显赫但能养家的手艺，不愿儿子去碰地方势力的旧账。季衡想证明父亲一生替别人保存凭据，却从未保存住自己的位置。两人都认为对方正在把家拖进危险里。

- 妹妹季兰：想嫁进城里，获得一份不用看账房脸色的生活。她认为哥哥把什么都变成证据，连亲情也变得难以相处。她可能需要季衡帮她查清一桩婚约，却不愿接受他因此掌握自己的秘密。

- 盐商沈百川：想通过季衡找回几份旧契，稳住一条盐运支线。沈百川愿意给他身份和钱，却要求他替自己把某些事实写得“更方便解释”。两人都需要对方，却无法接受对方对事实的处理方式。

## 人物钩子

别人争一块地时，他不急着站队，先冒雨跳进河里捞出一卷烂掉一半的原契；捞出来后，他发现契书对自己也不利，却仍然当众照实念完。

读者会记住：这个人不是靠嗓门和拳头证明自己，而是会为了“不让真实被抹掉”，把本来能安稳过完的日子主动变复杂。

# HUMAN SEED CANDIDATE 2｜冯渡／先拥有一条船

## 世界中的初始位置与成长环境

冯渡出生在海港外的船户区。父亲是替商会修船的木匠，母亲替水手缝补帆布，家中没有城籍，只能依附不同商队接活。冯渡从小在船坞、潮沟和货栈之间长大，认识木料、绳结、潮汐、船工和码头规矩，却没有接受完整的文字教育。

他见过太多人把性命交给一条船，却连那条船的半成所有权都没有。

## Formative Facts → Adaptation → Observable Behavior

- 父亲修好一艘商船后，商会以“途中损坏”为由扣掉大半工钱 → 冯渡学会手艺只有在货物、船契和分成中留下位置才算真正属于自己 → 他接活时总要争取材料采购权、维修记录或货运份额，不愿只拿一次性的工钱。

- 他少年时跟船出海，船队遇上妖兽迁徙，船主先保自己的货，把几名临时水手留在后船 → 他误以为被雇佣的人永远是最先被舍弃的那批 → 他后来会优先修船、买备用绳索和掌握退路，却不愿把生死交给一个只会说“照规矩办”的船主。

- 他曾用母亲准备给自己成婚的积蓄，买下一艘被判定无法远航的旧船 → 他第一次拥有了可以自行决定去哪里的东西，也第一次承担了不能转嫁给别人的亏损 → 从那以后，他会把挣来的钱优先换成船具、货舱、航图和码头份额，而不是改善眼前生活。

## 当前私人欲望

“我不想再替别人把货送到岸上。我想有一条自己的船，船往哪里走、装谁的货、挣来的钱进谁的口袋，都由我来定。”

## Core Obsession

他追逐的不是单纯的远方，而是让每一次移动都变成自己的资产和筹码。

一条船之后是第二条船、稳定的泊位、属于自己的货源、不会轻易断掉的航线，以及一支愿意跟他出海的人。只要他还在替别人承担风险，他就会觉得自己没有真正走远。

## Excess｜哪里过量

旧船已经能维持近岸运输，收入足够让他在城里买屋成家，他却把所有积蓄投入一条更破的远洋船，只因为那条船曾经走过一条如今无人愿意承担风险的航线。

他可以连续数月睡在船坞，宁愿让母亲继续住漏雨的旧屋，也要先买下一个能让船队在风季停靠的废弃泊位。

## Behavior Signature

面对高价值机会，他先计算自己能留下什么：船份、货份、航权、港口关系，或者一个以后无法绕开他的节点。

受到羞辱时，他不会急着证明自己有本事，而会把对方拒绝给他的条件，变成下一次谈判中对方必须付出的价格。

面对恐惧，他会保护能让自己继续移动的东西；面对关系压力，他不承诺“我一定带你走”，只会问对方愿意拿什么赌在这条船上。

重大损失发生后，他不会停船休整太久，而会立刻寻找下一件仍能归自己所有的东西，仿佛只要手里还有一部分航行权，就还没有真正输掉。

## 重要关系原点

- 母亲冯柳：想让儿子拥有一间靠岸的铺子，结束船户随时被赶走的生活。她愿意卖掉自己的船工工具帮他一次，却无法接受儿子把整个人生继续押在海上。

- 老船长段七：想保住自己在港口的名声和一条稳定的商队路线。段七看中冯渡的修船本事，却要求他永远做最可靠的副手。冯渡需要段七教他真正的航路，却迟早会把段七视为自己必须超过的人。

- 货栈女掌柜韩青禾：想扩大自己的药材货源，不愿把生意绑在任何船主身上。她和冯渡彼此提供稀缺资源，也彼此防着对方把临时合作变成长期占有。

## 人物钩子

港口所有人都把一艘搁浅旧船当废木头，冯渡却先去找它的船契；确认船契无人继承后，他用三个月替债主跑最差的货，换来船身一半的所有权。

读者会记住：他不是想“闯荡天下”，他想让每一段冒险最终在账面上、船身上和自己的生活里留下无法被别人拿走的部分。

# HUMAN SEED CANDIDATE 3｜魏执／我要让别人按我的判断活下来

## 世界中的初始位置与成长环境

魏执出生在一户普通军户家庭。父亲曾在城防营负责粮秣和伤员转运，母亲经营军营外的小食摊。家里有军籍，却没有修士背景，也没有足够的战功换来真正稳固的田地。

魏执识字不多，却熟悉队列、粮道、伤亡登记和军府里如何把责任推给一个最没有靠山的人。他不崇拜英雄，只相信一件事：在真正出事的时候，谁有资格下令，谁就决定谁承担代价。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾因上级改动粮车数量而被罚，明知不是他的错也无法申辩 → 魏执学会了“没有决断权的人只能替别人承担结果” → 他在任何集体行动中都会主动确认谁下令、谁承担、谁能改变计划。

- 他第一次带一小队人押送伤员时，按照老兵经验绕开危险路，却在半途遇到更大的妖兽迁徙，最后只能丢下部分物资 → 他误学会不能把命交给“大家都这么做”，必须自己判断最坏结果 → 他后来宁愿被骂擅作主张，也要在行动前重新查看地形、粮水和撤退方向。

- 他曾因抢先承担一次错误决策，被长官当众称为“自作聪明的军户子” → 他发现承认责任并不会自动换来尊重，只有让结果逼别人承认自己 → 他开始主动争取那些成败清楚、旁观者足够多的差事。

## 当前私人欲望

“我要有一次，所有人都知道该不该走、该不该守，最后只能听我的。事情办成以后，他们不能说是上头安排的；事情办砸了，也不能把我推出来顶罪。”

## Core Obsession

他想不断扩大自己能够作出关键判断、并让别人愿意把性命交给这个判断的范围。

他追逐的不是官位本身，而是从一队人、一座营寨、一段粮道，逐渐进入更大局面中的决定位置。地位越高，能被他改变的结果越多，他就越难接受只做一个执行命令的人。

## Excess｜哪里过量

他已经获得一个安全的文书职位，只要熬几年就能换到稳定俸禄和一块军田，却主动申请去接手一支装备最差、每逢归潮都缺人的巡逻队。

不是因为他想救谁，而是因为那里的结果足够清楚：只要他判断错一次，所有人都会知道错在什么地方。

## Behavior Signature

面对高价值机会，他会选择能让自己真正承担结果的位置，而不是看起来最体面的升迁。

受到羞辱时，他不会立刻动手，而会把对方逼到必须接受自己判断的局面里。

面对恐惧，他先确认能牺牲什么、必须保住什么；面对关系压力，他不会许诺“你不会死”，只会给对方一个明确的位置和撤退条件。

重大损失发生后，他会反复重建当时的决策顺序，既不轻易自责，也不允许别人用一句“运气不好”结束讨论。

## 重要关系原点

- 父亲魏川：只想攒够军田和退籍的功劳，让儿子离开军府。魏执认为父亲一生都在替别人承担后果，却从未争取过真正的决定权。父亲则认为儿子把“能下令”误当成了活着的资格。

- 老兵周魁：想用多年经验换一个不再上前线的位置。他愿意教魏执如何让疲惫的人继续听令，却不愿接受一个年轻军户取代自己成为队伍真正的依靠。

- 军府文吏许闻达：想把魏执培养成一把敢担责、好控制的刀。魏执需要许闻达提供调令和记录上的支持，却清楚对方真正想要的是一个替自己背锅的人。

## 人物钩子

一次押运中，上级给出模糊命令，所有人都等着别人先动。魏执当众撕掉原本的路线图，指着三条路说明哪一条会丢货、哪一条会死人，然后要求所有人先听完他的判断，再决定是否跟他走。

读者会记住：他最危险的地方不是敢拼，而是他真的想让别人把命交给他的判断，并且愿意为这种资格承担别人不愿承担的后果。

# HUMAN SEED CANDIDATE 4｜林问川／不接受“大概”

## 世界中的初始位置与成长环境

林问川出生在山城的一间民间伤药铺。父亲会辨药、接骨和处理妖兽伤，母亲负责收账和照顾病人。家境比普通农户好，却没有正式医籍，也没有宗门师承，只能靠口碑与药材商维持生意。

他从小见过很多人因为买不起高阶药材、找不到真正懂病的人，最后只能接受“命不好”“伤太重”“再熬几天”这种解释。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾按祖传经验救治一名商队护卫，病人短暂好转后突然恶化，最后没人说得清究竟是哪一步出了问题 → 林问川学会了“有效一次不等于知道为什么有效” → 他会记录药量、时间、饮食和症状变化，不愿把成功归功于祖传，也不愿把失败归咎于命数。

- 一位富商为家人买走铺中最好的药材，普通病人只能使用便宜替代品 → 他看见药材、身份与判断权如何互相影响 → 他后来会把稀缺药材留给最需要的人，但收费时极其强硬，认为穷人可以欠账，却不能让掌握资源的人白拿他的判断。

- 他曾为一个并不亲近的病人追查旧病历，耽误了自己参加城中医馆考核的机会 → 他逐渐把“弄清一个人究竟怎么坏掉的”视为比眼前机会更重要的事 → 任何未解释的症状都会在他心里留下未完成的账。

## 当前私人欲望

“我想知道一个人到底为什么会坏掉，然后让真正有钱、有身份的人也得来问我，而不是随便找个名医开张贵药就算了。”

## Core Obsession

他追逐的是对身体和病因越来越细的判断权，并希望把这种判断变成别人无法绕开的价值。

他不会满足于治好一批病人。治病越多，他越想建立自己的记录、方法、病例和声誉；见过的病越复杂，他越无法容忍任何人用一句“差不多”替代真正的答案。

## Excess｜哪里过量

他已经能靠处理常见伤病稳定挣钱，却会花掉一整月收入，去购买一名陌生死者留下的病历和药方，只因为那人的症状与自己曾经误判的一例相似。

遇到没有报酬的疑难病，他会连续数夜守在病床旁，甚至错过最赚钱的出诊，只为了确认病情究竟在哪个环节改变。

## Behavior Signature

面对高价值机会，他先看能否接触完整过程和真实记录，而不是只看报酬与名声。

受到羞辱时，他不会急着证明自己医术高明，而会追问对方是否愿意让自己的判断接受复盘。

面对恐惧，他会把恐惧转成观察、记录和试验；关系逼迫他直接给出保证时，他往往会让人不舒服地听见风险，而不是说一句让人安心的假话。

重大损失发生后，他不会把失败包装成无可避免，而会追查每一个被忽略的细节，即使最后证明自己确实无能为力。

## 重要关系原点

- 父亲林守拙：想守住祖传药铺，不愿儿子把普通伤药铺变成承担巨大风险的疑难医馆。林问川认为父亲靠经验活了一辈子，却留下了太多无法解释的病案；父亲则担心儿子会为了答案耗尽自己。

- 药材商女儿许青禾：想接管家中药材渠道，证明自己不只是替父亲跑账的女儿。她能给林问川稀缺药材，却要求他把病例和配方变成可交易的东西。两人彼此需要，也都担心对方把知识变成控制自己的筹码。

- 年轻学徒赵平：想学一门能快速赚钱的手艺，将来开自己的铺子。他崇拜林问川追根究底的本事，却无法接受师父为了一个答案放弃眼前收益；赵平迟早会面对“先救人还是先弄清楚”的选择。

## 人物钩子

前三章里，他治好一个伤势不重的富家子弟，却拒绝收下对方送来的名贵药材，转身去买一个普通脚夫失败的旧药方。

理由很简单：富家子的伤为什么会好，他已经知道；脚夫为什么会死，他还不知道。

# FROZEN POWER SEED 1｜祁砚／借万物一锋

## World Power Normal → Exception

澜生界绝大多数修士，依靠身体、神识、术式和外物形成稳定配合。一个人通常有一两种最熟悉的灵材、兵器、地势或天气，离开这些条件后，力量会明显下降。

常见的是强化身体、符箓、兵器、火风水势；少数人能同时操纵多种术式，或让一件兵器随自身成长。

祁砚的异常是“复合借相”：他能在短时间内把多种外物同时接入自己的力量回路。它们不属于他，也不会被他炼化，但能被他临时组合使用。

## Core Fantasy / 特殊际遇

如果我是他，我可以把断枪当作锋，把墙面当作盾，把雨水当作传力媒介，再借对手打来的力量完成同一招。

我不是单纯会用更多兵器，而是能把原本互不兼容的物件、地势、天气和残余力量拼成一套临时术式。

边界是：他不能凭空制造力量，必须有真实可用的外物；外物越强，对自身承载要求越高；他也不能永久夺走兵器、法器或他人的力量。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：纳息、通脉、立相、照域会提升他的体魄、神识、灵力总量和术式稳定性。否则他即使接入更多外物，也只能让自己先崩溃。
- **异常掌握轴**：从同时借用两种外物，成长到多种力量的精确切换；从物件组合，扩展到地势、天气、术式残势和敌我力量的短暂衔接；逐渐减少接入时的停顿与反噬。
- **永久边界**：不相容的力量始终可能互相冲撞。高阶以后他仍不能无条件拼接所有力量，错误组合会直接损伤经脉、神识，甚至让术式反噬自身。

## 为什么读者会馋

他能把战场上不起眼的东西变成自己的武器，越陌生、越破碎、越混乱的环境，越有发挥空间。

读者会期待他拿到一件东西后，不是问“它值多少钱”，而是问：“它能不能被他接进下一招？”

# HUMAN SEED CANDIDATE 1｜季衡／把名字钉在纸上

## 世界中的初始位置与成长环境

季衡出生在河谷小城的契书户。父亲替乡绅、商户和军府小吏抄写税契、地契与借据，母亲经营一间卖纸墨和晒药的小铺。家里不贫寒，却始终没有真正属于自己的田，也没有能让人高看一眼的身份。

他识字早，熟悉印章、见证、地界和账目，却没有正式师承。家里人希望他继承父亲的手艺，安稳地替别人把话写成凭据。

## Formative Facts → Adaptation → Observable Behavior

- 父亲年轻时替一户农人抄过土地转让契，因为原始契书遗失，最后被双方同时指认为骗子 → 季衡误以为口头承诺和多年情分都不可靠，只有能被追溯的凭据才算数 → 他替人办事时总要留下副本、见证和时间顺序，哪怕因此得罪急着成交的客户。

- 母亲曾收下一批来路不明的药材，病人出事后，供货商凭一枚伪印逃脱责任 → 他学会先追查东西从哪里来，再判断它值不值得用 → 他买旧货、接手遗物或替人鉴定时，会先找原始记录，宁愿错过便宜货，也不愿接受“大家都这么说”。

- 他曾花掉家中半个月的进项，替一个已经死去的佃户追回一份被水泡烂的旧契 → 他发现自己无法容忍一段真实经历被一笔勾销 → 对于无人争夺的旧账、旧地界和被改写的家谱，他会持续追查，直到确认自己手里有足够证据。

## 当前私人欲望

“我不想一辈子替别人写他们的田、他们的债、他们的身份。我想有一块地，契书上写的是我的名字，谁来查都抹不掉。”

## Core Obsession

他想把一切容易被人改口、抢走、否认的东西，变成自己能够掌握的确证。

最初是土地和家产，后来会扩大到商路、血缘、旧案、继承权、地图和人与人之间的承诺。东西越大，他越想知道它真正属于谁、谁有资格证明、谁在故意留下空白。

## Excess｜哪里过量

他已经有足够的钱买一间小铺，却把积蓄全部拿去收购一批被虫蛀的旧账册，只因为其中几页可能证明一座荒废渡口的归属。

普通人会认为那些账册不值得冒险，他却愿意因此推迟婚事、得罪客户，甚至亲自去找已经搬走几十年的见证人。

## Behavior Signature

面对高价值机会，他先问“东西真正属于谁”，而不是先问能赚多少。

受到羞辱时，他很少当场争辩；他会记下对方说过的话，寻找能让对方无法抵赖的证据。

面对恐惧，他会把风险拆成凭据、见证、退路和损失上限；关系逼迫他表态时，他不会轻易说“我相信你”，而会要求对方留下某种可以承担后果的承诺。

重大损失发生后，他不会立刻报复，而会先查清楚自己究竟在哪一个环节失去了证明权。

## 重要关系原点

- 父亲季文安：只想守住这门不显赫但能养家的手艺，不愿儿子去碰地方势力的旧账。季衡想证明父亲一生替别人保存凭据，却从未保存住自己的位置。两人都认为对方正在把家拖进危险里。

- 妹妹季兰：想嫁进城里，获得一份不用看账房脸色的生活。她认为哥哥把什么都变成证据，连亲情也变得难以相处。她可能需要季衡帮她查清一桩婚约，却不愿接受他因此掌握自己的秘密。

- 盐商沈百川：想通过季衡找回几份旧契，稳住一条盐运支线。沈百川愿意给他身份和钱，却要求他替自己把某些事实写得“更方便解释”。两人都需要对方，却无法接受对方对事实的处理方式。

## 人物钩子

别人争一块地时，他不急着站队，先冒雨跳进河里捞出一卷烂掉一半的原契；捞出来后，他发现契书对自己也不利，却仍然当众照实念完。

读者会记住：这个人不是靠嗓门和拳头证明自己，而是会为了“不让真实被抹掉”，把本来能安稳过完的日子主动变复杂。

# FROZEN POWER SEED 2｜陆未／留着未完

## World Power Normal → Exception

澜生界的术式通常需要完整施展。灵力进入术式，术式完成动作，力量随之释放。高阶阵法可以分段启动，但必须依靠提前布置好的阵盘、灵材和地势。

陆未的异常是“未完承载”：他能把一个已经启动、却尚未完成的术式保持在不稳定状态，并将它带入之后的动作中。

## Core Fantasy / 特殊际遇

如果我是他，我可以挥出一半的刀，先不让刀势落下；我可以让火术停在燃烧之前，把这股“即将完成的力量”藏进刀锋、墙缝或自己的经脉，再在真正需要的时候完成它。

这不是时间停止，也不能让已经发生的事情重新变回未发生。它只能保存尚未结算的术式结构。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：正常境界提升会增强他的体魄、灵力和神识，使他能承受更多未完术式，也能在术式即将失控时重新接管。
- **异常掌握轴**：从保存一个简单术式，成长到同时维持多个不同阶段；从延后释放，扩展到改变完成顺序、转换承载位置，并让不同未完术式在最后一刻互相衔接。
- **永久边界**：未完术式会持续消耗灵力和注意力，不能无限保存；外力干扰可能让它提前爆发。它不能保存超过自身承载上限的力量，也不能撤销已经完成的结果。

## 为什么读者会馋

他的力量天然制造“这一招还没结束”的期待。

敌人以为他失手，实际上他只是没有让结果落地；读者会不断猜测那些被他刻意留住的半招，最后究竟会在什么位置完成。

# HUMAN SEED CANDIDATE 2｜冯渡／先拥有一条船

## 世界中的初始位置与成长环境

冯渡出生在海港外的船户区。父亲是替商会修船的木匠，母亲替水手缝补帆布，家中没有城籍，只能依附不同商队接活。冯渡从小在船坞、潮沟和货栈之间长大，认识木料、绳结、潮汐、船工和码头规矩，却没有接受完整的文字教育。

他见过太多人把性命交给一条船，却连那条船的半成所有权都没有。

## Formative Facts → Adaptation → Observable Behavior

- 父亲修好一艘商船后，商会以“途中损坏”为由扣掉大半工钱 → 冯渡学会手艺只有在货物、船契和分成中留下位置才算真正属于自己 → 他接活时总要争取材料采购权、维修记录或货运份额，不愿只拿一次性的工钱。

- 他少年时跟船出海，船队遇上妖兽迁徙，船主先保自己的货，把几名临时水手留在后船 → 他误以为被雇佣的人永远是最先被舍弃的那批 → 他后来会优先修船、买备用绳索和掌握退路，却不愿把生死交给一个只会说“照规矩办”的船主。

- 他曾用母亲准备给自己成婚的积蓄，买下一艘被判定无法远航的旧船 → 他第一次拥有了可以自行决定去哪里的东西，也第一次承担了不能转嫁给别人的亏损 → 从那以后，他会把挣来的钱优先换成船具、货舱、航图和码头份额，而不是改善眼前生活。

## 当前私人欲望

“我不想再替别人把货送到岸上。我想有一条自己的船，船往哪里走、装谁的货、挣来的钱进谁的口袋，都由我来定。”

## Core Obsession

他追逐的不是单纯的远方，而是让每一次移动都变成自己的资产和筹码。

一条船之后是第二条船、稳定的泊位、属于自己的货源、不会轻易断掉的航线，以及一支愿意跟他出海的人。只要他还在替别人承担风险，他就会觉得自己没有真正走远。

## Excess｜哪里过量

旧船已经能维持近岸运输，收入足够让他在城里买屋成家，他却把所有积蓄投入一条更破的远洋船，只因为那条船曾经走过一条如今无人愿意承担风险的航线。

他可以连续数月睡在船坞，宁愿让母亲继续住漏雨的旧屋，也要先买下一个能让船队在风季停靠的废弃泊位。

## Behavior Signature

面对高价值机会，他先计算自己能留下什么：船份、货份、航权、港口关系，或者一个以后无法绕开他的节点。

受到羞辱时，他不会急着证明自己有本事，而会把对方拒绝给他的条件，变成下一次谈判中对方必须付出的价格。

面对恐惧，他会保护能让自己继续移动的东西；面对关系压力，他不承诺“我一定带你走”，只会问对方愿意拿什么赌在这条船上。

重大损失发生后，他不会停船休整太久，而会立刻寻找下一件仍能归自己所有的东西，仿佛只要手里还有一部分航行权，就还没有真正输掉。

## 重要关系原点

- 母亲冯柳：想让儿子拥有一间靠岸的铺子，结束船户随时被赶走的生活。她愿意卖掉自己的船工工具帮他一次，却无法接受儿子把整个人生继续押在海上。

- 老船长段七：想保住自己在港口的名声和一条稳定的商队路线。段七看中冯渡的修船本事，却要求他永远做最可靠的副手。冯渡需要段七教他真正的航路，却迟早会把段七视为自己必须超过的人。

- 货栈女掌柜韩青禾：想扩大自己的药材货源，不愿把生意绑在任何船主身上。她和冯渡彼此提供稀缺资源，也彼此防着对方把临时合作变成长期占有。

## 人物钩子

港口所有人都把一艘搁浅旧船当废木头，冯渡却先去找它的船契；确认船契无人继承后，他用三个月替债主跑最差的货，换来船身一半的所有权。

读者会记住：他不是想“闯荡天下”，他想让每一段冒险最终在账面上、船身上和自己的生活里留下无法被别人拿走的部分。

# FROZEN POWER SEED 3｜温折／受力成路

## World Power Normal → Exception

普通修士可以通过炼体、护符、兵器和术式抵抗外力。力量接触身体后，通常只剩下伤害、反震或消散。少数人能针对某种火、毒、寒或兵器形成抗性，但不能随意记录陌生力量。

温折的异常是“受力留向”：他在承受一次真实力量后，可以留下这股力量的方向关系，而不是留下力量本身。

## Core Fantasy / 特殊际遇

如果我是他，我不能直接偷走对手的力量，但我可以记住那股力量怎样进入身体、怎样寻找目标、怎样被地面或兵器承受。

下一次交手时，我能让自己的力量沿着那条关系转向，让对手的重击穿过墙面、让自己的冲撞借着旧有方向加速，或者把已经接触身体的力量导向另一个承载物。

他不是免疫攻击，而是逐渐学会让攻击走错地方。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：体魄越强，他越能承受不同方向、不同层级的力量；神识和灵力越强，越能分辨受力过程并把它转化为自己的术式。
- **异常掌握轴**：从留下单一方向，成长到同时保留多种受力关系；从身体受力，扩展到兵器、地面、水流、风势和术式之间的传导；最终能在复杂战斗中连续借力、转力和错位。
- **永久边界**：他必须先真实承受过那种力量。第一次遇到远超承载上限的攻击时，他可能直接死亡。留下的是“方向关系”，不是攻击者的灵力、境界或完整术式。

## 为什么读者会馋

他的成长不是单纯变硬，而是每一次挨打都会让他对世界的受力方式理解更深。

读者会期待强敌的招式，因为越强、越独特的攻击，越可能成为他下一次突破战斗方式的材料——但第一次接触仍然可能要命。

# HUMAN SEED CANDIDATE 3｜魏执／我要让别人按我的判断活下来

## 世界中的初始位置与成长环境

魏执出生在一户普通军户家庭。父亲曾在城防营负责粮秣和伤员转运，母亲经营军营外的小食摊。家里有军籍，却没有修士背景，也没有足够的战功换来真正稳固的田地。

魏执识字不多，却熟悉队列、粮道、伤亡登记和军府里如何把责任推给一个最没有靠山的人。他不崇拜英雄，只相信一件事：在真正出事的时候，谁有资格下令，谁就决定谁承担代价。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾因上级改动粮车数量而被罚，明知不是他的错也无法申辩 → 魏执学会了“没有决断权的人只能替别人承担结果” → 他在任何集体行动中都会主动确认谁下令、谁承担、谁能改变计划。

- 他第一次带一小队人押送伤员时，按照老兵经验绕开危险路，却在半途遇到更大的妖兽迁徙，最后只能丢下部分物资 → 他误学会不能把命交给“大家都这么做”，必须自己判断最坏结果 → 他后来宁愿被骂擅作主张，也要在行动前重新查看地形、粮水和撤退方向。

- 他曾因抢先承担一次错误决策，被长官当众称为“自作聪明的军户子” → 他发现承认责任并不会自动换来尊重，只有让结果逼别人承认自己 → 他开始主动争取那些成败清楚、旁观者足够多的差事。

## 当前私人欲望

“我要有一次，所有人都知道该不该走、该不该守，最后只能听我的。事情办成以后，他们不能说是上头安排的；事情办砸了，也不能把我推出来顶罪。”

## Core Obsession

他想不断扩大自己能够作出关键判断、并让别人愿意把性命交给这个判断的范围。

他追逐的不是官位本身，而是从一队人、一座营寨、一段粮道，逐渐进入更大局面中的决定位置。地位越高，能被他改变的结果越多，他就越难接受只做一个执行命令的人。

## Excess｜哪里过量

他已经获得一个安全的文书职位，只要熬几年就能换到稳定俸禄和一块军田，却主动申请去接手一支装备最差、每逢归潮都缺人的巡逻队。

不是因为他想救谁，而是因为那里的结果足够清楚：只要他判断错一次，所有人都会知道错在什么地方。

## Behavior Signature

面对高价值机会，他会选择能让自己真正承担结果的位置，而不是看起来最体面的升迁。

受到羞辱时，他不会立刻动手，而会把对方逼到必须接受自己判断的局面里。

面对恐惧，他先确认能牺牲什么、必须保住什么；面对关系压力，他不会许诺“你不会死”，只会给对方一个明确的位置和撤退条件。

重大损失发生后，他会反复重建当时的决策顺序，既不轻易自责，也不允许别人用一句“运气不好”结束讨论。

## 重要关系原点

- 父亲魏川：只想攒够军田和退籍的功劳，让儿子离开军府。魏执认为父亲一生都在替别人承担后果，却从未争取过真正的决定权。父亲则认为儿子把“能下令”误当成了活着的资格。

- 老兵周魁：想用多年经验换一个不再上前线的位置。他愿意教魏执如何让疲惫的人继续听令，却不愿接受一个年轻军户取代自己成为队伍真正的依靠。

- 军府文吏许闻达：想把魏执培养成一把敢担责、好控制的刀。魏执需要许闻达提供调令和记录上的支持，却清楚对方真正想要的是一个替自己背锅的人。

## 人物钩子

一次押运中，上级给出模糊命令，所有人都等着别人先动。魏执当众撕掉原本的路线图，指着三条路说明哪一条会丢货、哪一条会死人，然后要求所有人先听完他的判断，再决定是否跟他走。

读者会记住：他最危险的地方不是敢拼，而是他真的想让别人把命交给他的判断，并且愿意为这种资格承担别人不愿承担的后果。

# CHARACTER CARD 4｜Split Authority

## POWER CORE｜Frozen Authority

# FROZEN POWER SEED 4｜沈回／两处同身

## World Power Normal → Exception

澜生界的短距离腾挪、御器和借地移动，都要求身体沿着某条真实路径完成转移。高阶修士能扩大移动范围，或用领域压缩距离，但一个人仍然只有一个身体、一个当下位置。

沈回的异常是“双锚驻身”：他能在身体已经到达某处后，保留另一处与自身稳定对应的位置。那不是分身，也不是时间倒流，而是同一个身体与两个空间支点保持联系。

## Core Fantasy / 特殊际遇

如果我是他，我可以让屋顶和街巷都成为自己的落脚点；我能从一个位置观察，从另一个位置伸手、发声或借力，在危险来临时把身体沿着两处支点迅速拉回。

随着掌握加深，我甚至能在两个相距很远的地方同时维持行动影响，让敌人无法判断我究竟是在进攻、撤退，还是已经换了位置。

## Growth Compatibility｜怎样真正越来越强

- **正常修炼轴**：修为提升会增强他的身体承载、神识覆盖、灵力总量和术式稳定性，决定他能否承受空间转移与位置分裂带来的负担。
- **异常掌握轴**：从只能保留第二处感知，成长到交换声音、视线、手臂和兵器，再到短暂转移部分身体；锚点的距离、持续时间、数量和行动独立性都会扩张。
- **永久边界**：他始终不能制造两个完整身体，也不能让两个位置同时拥有完整战力。锚点必须依附真实地势、物件或完成过的术式；锚点遭到破坏时，他会承受剧烈反噬，强大领域也能切断他的转移。

## 为什么读者会馋

这是极强的探索自由和战斗位置感。

他可以从封锁中脱身，可以同时处理两个方向的威胁，可以把“退路”变成实际存在的战斗位置。读者会期待他如何利用空间关系，而不是只看他把灵力数值堆高。

## 新版 Power Seed 暂不回填的字段
High-Tier Mutation / Legendary Trajectory / Future Legend Image 属于新版 schema；本轮为了冻结 v4 Power 变量，不用新模型补写，也不从 Biography 反推。

## HUMAN CORE｜Frozen Authority

# HUMAN SEED CANDIDATE 4｜林问川／不接受“大概”

## 世界中的初始位置与成长环境

林问川出生在山城的一间民间伤药铺。父亲会辨药、接骨和处理妖兽伤，母亲负责收账和照顾病人。家境比普通农户好，却没有正式医籍，也没有宗门师承，只能靠口碑与药材商维持生意。

他从小见过很多人因为买不起高阶药材、找不到真正懂病的人，最后只能接受“命不好”“伤太重”“再熬几天”这种解释。

## Formative Facts → Adaptation → Observable Behavior

- 父亲曾按祖传经验救治一名商队护卫，病人短暂好转后突然恶化，最后没人说得清究竟是哪一步出了问题 → 林问川学会了“有效一次不等于知道为什么有效” → 他会记录药量、时间、饮食和症状变化，不愿把成功归功于祖传，也不愿把失败归咎于命数。

- 一位富商为家人买走铺中最好的药材，普通病人只能使用便宜替代品 → 他看见药材、身份与判断权如何互相影响 → 他后来会把稀缺药材留给最需要的人，但收费时极其强硬，认为穷人可以欠账，却不能让掌握资源的人白拿他的判断。

- 他曾为一个并不亲近的病人追查旧病历，耽误了自己参加城中医馆考核的机会 → 他逐渐把“弄清一个人究竟怎么坏掉的”视为比眼前机会更重要的事 → 任何未解释的症状都会在他心里留下未完成的账。

## 当前私人欲望

“我想知道一个人到底为什么会坏掉，然后让真正有钱、有身份的人也得来问我，而不是随便找个名医开张贵药就算了。”

## Core Obsession

他追逐的是对身体和病因越来越细的判断权，并希望把这种判断变成别人无法绕开的价值。

他不会满足于治好一批病人。治病越多，他越想建立自己的记录、方法、病例和声誉；见过的病越复杂，他越无法容忍任何人用一句“差不多”替代真正的答案。

## Excess｜哪里过量

他已经能靠处理常见伤病稳定挣钱，却会花掉一整月收入，去购买一名陌生死者留下的病历和药方，只因为那人的症状与自己曾经误判的一例相似。

遇到没有报酬的疑难病，他会连续数夜守在病床旁，甚至错过最赚钱的出诊，只为了确认病情究竟在哪个环节改变。

## Behavior Signature

面对高价值机会，他先看能否接触完整过程和真实记录，而不是只看报酬与名声。

受到羞辱时，他不会急着证明自己医术高明，而会追问对方是否愿意让自己的判断接受复盘。

面对恐惧，他会把恐惧转成观察、记录和试验；关系逼迫他直接给出保证时，他往往会让人不舒服地听见风险，而不是说一句让人安心的假话。

重大损失发生后，他不会把失败包装成无可避免，而会追查每一个被忽略的细节，即使最后证明自己确实无能为力。

## 重要关系原点

- 父亲林守拙：想守住祖传药铺，不愿儿子把普通伤药铺变成承担巨大风险的疑难医馆。林问川认为父亲靠经验活了一辈子，却留下了太多无法解释的病案；父亲则担心儿子会为了答案耗尽自己。

- 药材商女儿许青禾：想接管家中药材渠道，证明自己不只是替父亲跑账的女儿。她能给林问川稀缺药材，却要求他把病例和配方变成可交易的东西。两人彼此需要，也都担心对方把知识变成控制自己的筹码。

- 年轻学徒赵平：想学一门能快速赚钱的手艺，将来开自己的铺子。他崇拜林问川追根究底的本事，却无法接受师父为了一个答案放弃眼前收益；赵平迟早会面对“先救人还是先弄清楚”的选择。

## 人物钩子

前三章里，他治好一个伤势不重的富家子弟，却拒绝收下对方送来的名贵药材，转身去买一个普通脚夫失败的旧药方。

理由很简单：富家子的伤为什么会好，他已经知道；脚夫为什么会死，他还不知道。

# Experiment Results / Manual Audit

# Split Power Seed × Human Seed Experiment — Results

## Verdict

**Split authority PASS. Human appetite diversity PARTIAL PASS. Do not spend Sol yet.**

The experiment reuses the exact same protagonist-blind `澜生界` and the exact same four v4 Power cores. Only one new GPT-5.6 Luna high Human batch was generated.

## What changed

v4 used one Character inference:

`Power Normal → Exception → Core Fantasy → Upbringing → Adaptation → Behavior`

This allowed post-hoc semantic rhyme inside Character: an unfinished-spell ability acquired a childhood full of unfinished things; a two-anchor spatial ability acquired a two-home childhood.

v5 freezes two independent authorities:

- **Power Seed**: anomaly, reader fantasy, growth grammar. In this A/B it is extracted deterministically from v4 and frozen before Human generation.
- **Human Seed**: upbringing, formative causality, current desire, Core Obsession, Excess, Behavior Signature, relationships, Character Hook. It sees only `LIFE_CONTEXT + Human GBrain`; it sees no Power content and no Story Opportunities.

The final Character Card is deterministic concatenation. No Character Composer is allowed to reconcile the two seeds.

## Hard isolation result

Human generation leakage check:

- frozen Power terms / names: **0 hits**
- named Story Opportunity terms: **0 hits**

Pairing is fixed by index. No model selects a compatible Human for a Power.

## Human Seeds

1. **季衡／把名字钉在纸上** — contract-scribe household; wants durable proof/ownership; will complicate his own life to establish what is true and traceable.
2. **冯渡／先拥有一条船** — harbor/ship household; wants ownership and expanding movement assets; willingly delays comfort to own ships, berths and routes.
3. **魏执／我要让别人按我的判断活下来** — ordinary military household; wants genuine decision authority and responsibility; seeks situations where success/failure can be visibly attributed to his judgement.
4. **林问川／不接受“大概”** — medicine-shop household; wants to understand why bodies fail and make his judgement indispensable; will sacrifice profitable opportunities to resolve unexplained cases.

## v4 → v5 post-hoc-rhyme comparison

### Pair 1
Power: `借万物一锋 / 复合借相`  
Human: `季衡 / evidence, ownership, traceability`

There is a weak shared preference for concrete support/evidence, but the Human biography no longer explains why the supernatural anomaly exists. **Improved.**

### Pair 2
Power: `留着未完 / 未完承载`  
Human: `冯渡 / own a ship, berth, routes, keep moving`

The Human seed contains no unfinished-life metaphor. Power and Human are clearly separate creative sources. **Strong pass.**

### Pair 3
Power: `受力成路 / 受力留向`  
Human: `魏执 / decision authority, responsibility, command`

The two sources are independent but can later create useful tension: a Human obsessed with making others trust his judgement is paired with a Power whose strength depends on personally encountering force. This chemistry was not pre-explained. **Pass.**

### Pair 4
Power: `两处同身 / 双锚驻身`  
Human: `林问川 / diagnostic certainty and unexplained illness`

This is the clearest proof of architectural separation. No two-home biography, no forced-choice life philosophy, no spatial metaphor in childhood. **Strong pass.**

## Psychological-distribution result

The old v4 batch strongly converged on autonomy / anti-control:

- do not make me an asset;
- do not finish my choices for me;
- do not treat me as expendable;
- do not force me to choose one place.

The v5 Human batch is more diverse:

- proof / ownership;
- acquisitive mobility and asset expansion;
- command / decision authority;
- epistemic certainty / diagnosis.

So the explicit `Core Obsession + Excess + batch-collapse` changes helped.

However, the distribution is **not fully open yet**. All four still lean toward rational, legible, manageable desires: evidence, assets, decision rights, correct diagnosis. There is relatively little wasteful appetite, vanity, sensory pleasure, rivalry-for-its-own-sake, romantic fixation, aesthetic obsession, or other non-instrumental life force.

This residual should **not** be fixed by reconnecting Power and Human. It belongs only to future Human Seed craft, likely by restoring the useful core of old `Narrative Appetite Before Defensive Balance` without giving the model a personality menu.

## Schema changes now justified

### Power Seed
Keep / support:
- World Power Normal → Legal Exception
- Core Fantasy
- Growth Compatibility
- High-Tier Mutation
- Legendary Trajectory
- non-Canon Future Legend Image

For this A/B, the last three new ambition fields were intentionally **not backfilled** into frozen v4 Power, to avoid changing the Power variable.

### Human Seed
Keep:
- initial world/social position
- Formative Facts → Adaptation → Observable Behavior
- current private desire
- Core Obsession
- Excess
- Behavior Signature
- important relationship origins
- Character Hook

Do **not** put Power, first Power reveal, world reaction to Power, or `world cannot digest him` into Human Canon.

### Character Card
For now: deterministic `POWER CORE + HUMAN CORE` only. Do not add an LLM Composer.

### Collision Authority
Only here should the system first decide:
- how this Human discovers/uses this Power;
- how pre-existing relationships react;
- which Story Opportunities collide with them;
- what the first actual reveal scene is;
- how the world changes after real events.

## Cost / next step

This experiment used no new World, no new Power, no Sol, no Outline and no chapter generation. It used one fresh Luna high Human batch.

The architecture is now strong enough to justify a **single** future Sol Collision test, but because Human appetite still shows a rationality bias, the recommended order is to let the user audit these four Human Seeds / pairings first before spending Sol.
