## S1｜遗骸王座：我从龙心里醒来

### 一句话货架简介

强者死后，尸体会继续执行死前最后一个动作；主角是一颗会吞尸拼身的活龙心，靠把死者的最后一击装进自己身体，二十章内从拍卖台上的废物长成一具能左右整座城生死的天阶遗骸。

### World-only Direction

这个世界里，生物死亡时若仍有未完成的动作，尸体会留下“遗命”。

遗命会驱使附近的死肉、骨骼和血液，反复完成死者临终前最后一个明确动作。战场不会真正安静：断臂仍会挥刀，死兽仍会扑咬，倒下的巨人仍可能继续压向城墙。

人类的日常生活围绕三件事展开：

- 清理会继续行动的尸体；
- 猎取完整遗骸；
- 把遗骸制成兵器、坐骑、护甲或城防机关。

世界公认的力量尺只有一条：`遗骸阶`。

- `核胚`：只能保存遗命，不能独立驱动完整身体。
- `一阶·骨片`：能驱动一块肢体。
- `二阶·人具`：能驱动一具普通人尸。
- `三阶·兽具`：能驱动大型猛兽尸体。
- `四阶·城骸`：遗骸规模足以改变一座城的攻守。
- `五阶·天骸`：遗骸复苏会改变整个区域的生存条件。

普通人最值钱的不是修炼速度，而是完整遗骸、强者死前的最后动作，以及能够承载遗命的特殊尸体。

### World Interface-only Direction

所有公开处刑、战场清理和遗骸拍卖场，都设置有固定的“遗照镜”。

遗照镜只负责观看、记录、回放和传播死者最后的动作，并把记录发送到各地的遗骸市场与猎人榜。

遗照镜不能制造遗命、驱动尸体、增强遗骸，也不能替任何行动者改变结果。它只会让某具遗骸的价值、名声、归属争议和追捕等级迅速扩散。

### Protagonist Ontology-only Direction

主角不是人，而是一颗拥有自我意识的“活遗骸核”。

它的本体是一颗龙心，外层带有少量血管、筋膜和残缺肋骨。它没有完整四肢、没有人类声带，也没有独立的人类身份。

它必须依靠拼接死肉，才能获得移动、抓握、行走和战斗能力。

### Initial Origin-only Direction

T0 时，主角诞生在一条被剖开的白脊龙胸腔内。

它位于铜制拍卖箱中，周围有三根断肋、半截龙脊和一枚尚未熄灭的遗命核。

零点经历只有：

- 第一次心跳；
- 感知到铜箱外有人搬运尸块；
- 感知到一条断肋仍在重复“合拢”的动作；
- 不能移动，不能说话，不能离开铜箱。

### Initial Scale Position-only Direction

本 World 只定义一条公共力量尺：`遗骸阶`。

主角 T0 的精确位置为：

- `遗骸阶：核胚`
- 当前能力范围：只能保存自身意识，不能独立驱动完整外部尸体
- 不适用：一至五阶，因为主角 T0 尚未拥有可独立行动的完整遗骸载体

`核胚`是世界对所有未形成完整驱动体的遗骸核的通用分类，不是为主角临时发明的“零级”或“尺外”。

### Power-only Direction

触发条件：

主角的本体必须直接接触带有遗命的死去生物组织。

合法目标类别：

- 带遗命的死去生物组织；
- 主角自身已经接入的死肉；
- 主角已经拼接完成的遗骸结构。

核心动作：

- `吞入`：把一块带遗命的死肉纳入自身。
- `拼接`：把死肉接到自己的身体结构上。
- `重演`：让某块死肉完成它死前最后留下的那个动作。
- `剥离`：把已拼接的死肉从本体上甩出，保留一次遗命重演机会。

永久边界：

主角不能让死肉执行遗命之外的新动作，也不能直接控制活着的肉体。每块死肉都保留原主临终时的动作倾向；拼得越多，身体越强，但越容易被互相冲突的遗命拉扯。

### Story Interface / Opening Promise

第一章让读者立即看见：

一颗龙心在拍卖台上跳动，拍卖师正准备剖开它取出遗命核；箱外，一条死去刽子手的断臂仍在挥刀。

第一章到第十章：

1. 龙心在拍卖台上醒来，借断臂完成第一次斩击，撞破铜箱。
2. 拍卖场所有遗照镜同步记录，龙心从“死物”被重新定价为活遗骸。
3. 遗骸商会追捕，主角第一次拼接龙肋，得到短暂移动能力。
4. 一名想夺回亡兄尸体的少女救走主角，双方形成不稳定合作。
5. 主角为逃离猎人，吞入死兽腿，第一次以兽身奔跑。
6. 商会用遗骸猎犬围堵，主角把猎犬死前的扑咬动作剥离成一次性杀招。
7. 主角与少女进入战场废墟，发现大量尸体仍在执行同一个“守城”遗命。
8. 主角选择帮助死者守住一段废墙，而不是立刻吞掉所有遗骸。
9. 城中势力确认龙心属于一条曾经改变过边境的天阶巨龙。
10. 城外真正的天骸开始苏醒，主角被迫决定：吞掉它，还是让它继续完成临终遗命。

第 20 章前后，主角必须真正进入`五阶·天骸`，并结算城内各方争夺的最高遗骸归属。World Horizon Handoff 只在“天骸的遗命完成或被主角接管、当前世界最高遗骸争夺结束”后触发，不预写下一世界内容。

### Authority-Compilation Trace

- 铜箱破裂  
  → `Power-only Direction：吞入、拼接、重演`  
  → 触发已满足：主角接触刽戮断臂上的遗命  
  → 目标：死去刽手的断臂  
  → 合法，因为主角只让断臂完成原本的挥刀动作。

- 借断臂斩开箱锁  
  → `吞入 + 拼接 + 重演`  
  → 触发已满足  
  → 载体：带遗命的死臂与铜箱锁  
  → 合法，因为主角没有创造新招，只重演断臂的最后斩击。

- 拼龙肋获得移动能力  
  → `吞入 + 拼接`  
  → 触发已满足：龙肋仍是带遗命的死组织  
  → 目标：主角自身身体结构  
  → 合法，因为主角只是把死肋接成身体支架。

- 吐出一次性命刺  
  → `剥离 + 重演`  
  → 触发已满足  
  → 载体：已经拼接的遗命肉刺  
  → 合法，因为肉刺只能完成原主最后的突刺动作。

- 第 20 章天骸复身  
  → 多次`吞入 + 拼接 + 重演`  
  → 触发已满足：主角接触五阶天骸死组织  
  → 目标：天骸肋骨、脊柱、巨兽肌肉  
  → 合法，因为终局动作仍由天骸原本的临终遗命组合而成，没有新增能力类别。

### 第一章标志性画面

拍卖锤落下时，铜箱里的龙心突然跳动。

箱外那条被砍掉的手臂，已经挥了三百年的刀，在这一刻第一次换了方向。

它不是砍向箱子，而是砍向拍卖师。

### 主角反复会做的新动作

- 借死人手完成自己没有的抓握与斩击。
- 把龙骨拼成腿，在战场尸堆上奔跑。
- 把整头死兽穿成临时外壳。
- 吐出一块仍在执行遗命的肉刺。
- 让两条互相冲突的遗命在体内同时爆发。
- 主动拆掉身体的一部分，把它当作一次性杀招。
- 用敌方强者的尸体完成敌方最害怕的最后一击。

### 第一次不公平兑现

主角只是一个核胚，却能同时拼接多种遗骸。

普通遗骸只能被一个主人、一具尸体或一件兵器使用；主角可以把龙心、死臂、兽腿和断脊装进同一具身体。

拍卖场观众亲眼看见它越打越不像一颗心，也越打越不像任何已知遗骸。

### 20章玩法扩张

- 从肢体拼接发展为兽身拼接。（`吞入 + 拼接`）
- 把敌方遗骸的临终动作转为自己的攻击节奏。（`拼接 + 重演`）
- 将多个死者的动作同时释放，制造互相冲撞的身体爆发。（多次`重演`）
- 把庞大遗骸改造成移动城防。（大量`拼接 + 重演`）
- 让一具天骸在城市边缘完成原本未完成的最后冲锋。（`吞入 + 拼接 + 重演`）

### 100章以上仍能长出的不同故事

未来每个 Approved World 只能提供新的、明确存在的死去生物实例。

同一套原语可以在不同实例上产生：

- 不同身体形态；
- 不同临终动作；
- 不同尸体组合；
- 不同社会归属与争夺；
- 不同“主角究竟该不该吞掉某个死者”的关系选择。

不预设新世界会出现什么遗骸类别，也不预设跨世界传送或无限复制。

### 最小可信桥梁

- 遗命是所有生物死亡时可能留下的自然现象。
- 遗骸阶是世界通用的公共尺。
- 主角只是罕见的活遗骸核，异常点在于能把多份遗命拼进同一具身体。

### 不可磨平的三点

- 主角永远不是“人拿着武器”，而是会把尸体穿在身上的活龙心。
- 每次变强都伴随死者最后动作的侵入。
- 主角获得的不是抽象等级，而是新的身体部位、新的移动方式和新的杀人姿势。

## S2｜一间屋子吞下整座城

### 一句话货架简介

这个世界的房屋都是活物，主角却是一间只有一扇门的废屋；它能把闯入者收进屋内、折叠自己的房间、从另一个出口吐出，二十章内长成一座能吞住城兽心脏的活城屋。

### World-only Direction

这个世界里，所有真正的房屋都有生命。

房屋会饥饿、迁徙、受伤和死亡。大型聚落不是人建成的城，而是由一头头“城兽”背负着房屋群，在荒原上移动。

人类日常生活包括：

- 在活屋内睡觉、储存食物和躲避空地；
- 交换房间、门、炉心和屋脊；
- 跟随城兽迁徙；
- 防止自己的房屋被别的城兽吞掉。

荒原上的空地在夜间会吞噬没有屋顶遮护的生物。真正值钱的是活屋的炉心、稳定房间和能承载更多住户的屋阶。

世界公认的力量尺只有一条：`屋阶`。

- `屋胚`：不能稳定承载生命。
- `一阶·棚`：一个房间。
- `二阶·屋`：两个以上稳定房室。
- `三阶·院`：可容纳多个家庭。
- `四阶·街`：可连续承载商铺和战斗通道。
- `五阶·堡`：能承受大型兽群冲击。
- `六阶·城`：能改变城兽迁徙和攻守。
- `七阶·山屋`：本地世界的最高房屋尺度。

### World Interface-only Direction

所有活屋都必须在屋门、窗洞和炉口安装固定的“窗眼”。

窗眼只负责记录房屋的外观、住户数量、门窗变化、房屋迁徙和所有权争议，并把记录传播到附近的迁城市场。

窗眼不能收纳物体、折叠房间、改变出口，也不能替房屋完成任何动作。它只会让某间屋子的价值、危险等级和所属关系公开化。

### Protagonist Ontology-only Direction

主角是一间有意识的废屋，不是人类。

它拥有：

- 一间狭小主室；
- 一扇正门；
- 一个破损屋顶洞；
- 一颗尚未稳定的屋心；
- 墙体、地基和屋脊组成的身体。

它没有手脚，也没有人类外貌，只能通过门、窗、地基和墙体做出行动。

### Initial Origin-only Direction

T0 时，主角诞生在荒原边缘一间被废弃的泥屋中。

它的地基已经裂开，正门歪斜，屋顶有一个拳头大的破洞。屋心刚刚形成，只能维持一间主室。

零点经历只有：

- 感知到夜风从屋顶洞穿过；
- 感知到三名拆屋人正在靠近；
- 感知到一只受伤的荒原兽在门外喘息；
- 尚未收纳过任何物体或生命。

### Initial Scale Position-only Direction

本 World 只定义一条公共力量尺：`屋阶`。

主角 T0 的精确位置为：

- `屋阶：屋胚`
- 当前结构：一间主室、一个正门、一个屋顶洞
- 当前承载：不能稳定承载生命居住
- 不适用：一至七阶，因为屋心尚未完成第一次稳定承载

`屋胚`是所有刚形成、未完成稳定承载的活屋通用分类，不是临时的“零级”。

### Power-only Direction

触发条件：

目标必须真实穿过主角自身的门、窗或其他物理开口。

合法目标类别：

- 物理物品；
- 活着或死去的生物；
- 与主角外墙直接接触的房间、墙段和建筑模块；
- 主角自身已经拥有的门、窗和房室。

核心动作：

- `收纳`：把穿过自身开口的目标放入屋内。
- `接驳`：把与自身外墙接触的房间或建筑模块接入身体。
- `换门`：把已收纳目标的出口改为自身另一个现有开口。
- `折室`：改变自身房室之间的内部距离和排列。
- `吐出`：把屋内目标从现有开口释放出去。

永久边界：

主角不能收纳没有穿过自己开口的目标，也不能创造不存在的出口、房间或物质。所有改变都只能发生在自己的外壳、现有开口和已经进入屋内的目标之间。

### Story Interface / Opening Promise

第一章让读者立即看见：

三名拆屋人闯入一间废屋，准备挖出屋心。最里面的人刚跨过门槛，屋子的正门便消失在他的身后，屋内距离突然变长，他从屋顶破洞被吐进城兽张开的嘴里。

第一章到第十章：

1. 废屋诞生，拆屋人进入，主角第一次收纳并吐出活人。
2. 窗眼记录同步传播，废屋从废品被重新定价为活屋。
3. 拆屋公会派出堡阶屋兽追捕。
4. 一名无家可归的少年主动住进主角，成为第一个真正住户。
5. 主角第一次接驳一段破墙，身体从单室变成双室。
6. 少年与主角因“是否吞掉追兵”发生第一次关系冲突。
7. 主角把追兵收进屋内，折叠房间，让他们互相撞入不同出口。
8. 城兽迁徙改变方向，主角被迫挂在它的背部移动。
9. 主角发现城兽正在主动吞食自己的房屋群。
10. 主角进入城兽体内，第一次尝试接驳一段受伤的活城墙。

第 20 章前后，主角必须达到`六阶·城屋`，并在城兽与房屋群的最高冲突中结算“谁拥有这座移动聚落”。Handoff 只由当前城兽事件结算和主角达到本地最高可用屋阶触发，不预写下一世界。

### Authority-Compilation Trace

- 拆屋人被收进主室  
  → `Power-only Direction：收纳`  
  → 触发已满足：目标真实跨过主门  
  → 目标：活人  
  → 合法，因为主角只处理进入自身开口的生物。

- 拆屋人从屋顶洞被吐出  
  → `收纳 + 换门 + 吐出`  
  → 触发已满足  
  → 载体：主门、主室、屋顶洞  
  → 合法，因为屋顶洞是 T0 已有开口，并非临时创造的出口。

- 追兵在屋内互相撞击  
  → `收纳 + 折室`  
  → 触发已满足  
  → 目标：已经进入主屋的多个活人  
  → 合法，因为主角只改变自身房室之间的距离，不改变屋外空间。

- 接驳破墙  
  → `接驳`  
  → 触发已满足：破墙与主角外墙接触  
  → 目标：物理建筑模块  
  → 合法，因为接驳对象属于 World 已定义的房间与墙段类别。

- 第 20 章吞住城兽心脏入口  
  → `收纳 + 折室 + 吐出`  
  → 触发已满足：城兽的头部和心脏通道进入主角的城门  
  → 目标：活着的巨大生物组织  
  → 合法，因为城兽实体穿过了主角自己的大型开口，主角没有远程控制城兽全身。

### 第一章标志性画面

拆屋人的铁镐落下。

整间废屋忽然安静。

三个人明明只走了十几步，却走了半刻钟；最后一个人从屋顶破洞掉出去时，下面正好是城兽张开的喉咙。

### 主角反复会做的新动作

- 把闯入者收进屋里。
- 把同一个人从门口换到屋顶、烟囱或地基裂口。
- 将房间折叠成短路或长路。
- 接驳墙段，把废屋变成更大的身体。
- 把敌方武器储存进墙体，等合适时吐出。
- 把自身门口变成捕兽口。
- 让大型生物的一部分先进入屋内，再用折室切断其退路。

### 第一次不公平兑现

普通活屋只能保护住户。

主角却能把敌人本身变成屋内物件，任意改变其出口。它不需要比拆屋人更强，只需要让对方先踏过门槛。

### 20章玩法扩张

- 单室捕杀变成多室迷宫。（`收纳 + 折室`）
- 把武器、尸体和敌人分开储存，再从不同开口吐出。（`收纳 + 换门 + 吐出`）
- 接驳废墟，使身体拥有多重出入口。（`接驳 + 换门`）
- 把城兽的嘴、背和胸腔变成连续战场。（`收纳 + 折室`）
- 接驳城墙后，把一座移动聚落变成自己的身体。（`接驳 + 折室 + 吐出`）

### 100章以上仍能长出的不同故事

未来每个 Approved World 只能提供新的房间、建筑模块、实体住户和物理开口实例。

既有原语可以产生：

- 不同结构的活屋；
- 不同住户关系；
- 不同建筑组合；
- 不同“收容还是放走”的选择；
- 不同规模的身体战与空间战。

不预设未来世界会出现什么新房屋类别，也不预设无限房间、全城网络或远程出口。

### 最小可信桥梁

- 活屋是本世界所有建筑共有的生命现象。
- 屋阶是普通人和屋兽都理解的公共尺度。
- 主角只是罕见的屋心变异体，优势来自“能把敌人收进身体并重排出口”。

### 不可磨平的三点

- 主角不是住在房屋里，而是房屋本身。
- 战斗不是交换招式，而是争夺谁先跨过门。
- 重要关系天然具有身体意义：住户离开，等同于主角失去一部分自身生活。

## S3｜门胚：把敌人的攻击翻回去

### 一句话货架简介

只要有两面，世界就会长出门；主角是一枚刚出生的门胚，能贴上盾牌、铠甲和城墙，把穿门而过的攻击翻到敌人那一面，二十章内长成能倒扣整座天门的活门。

### World-only Direction

这个世界里，所有具有清晰正反两面的实体，都会自然长出门。

房屋有门，盾牌有门，铠甲有门，棺材有门，城墙有门。普通门只能开合，不能凭空制造空间，也不能让人穿过不存在的实体。

战争、贸易和刑罚都围绕门展开：

- 盾门决定近战胜负；
- 城门决定领地归属；
- 棺门决定尸体是否能被带回；
- 天门决定荒原上的季节与光线是否进入城市。

世界公认的力量尺只有一条：`门阶`。

- `门胚`：四指宽以下，只能让空气和光线通过。
- `一阶·人门`：可容一人通过。
- `二阶·车门`：可容车辆通过。
- `三阶·屋门`：可容一间房屋的主要通行。
- `四阶·墙门`：可改变墙体攻守。
- `五阶·堡门`：可承受堡垒级冲击。
- `六阶·城门`：可改变一座城的战局。
- `七阶·天门`：本地世界的最高门阶。

### World Interface-only Direction

所有公共门、城门和战争盾门都必须安装固定的“门眼”。

门眼只负责观看、记录、回放和传播门的开启、关闭、承压和归属变化，并把记录发送到门榜、城防台和交易市场。

门眼不能让门开启，不能替门翻面，不能把攻击转向，也不能为任何行动者提供力量。

它唯一改变的是社会后果：一扇门若在众目睽睽下反转强敌攻击，其价格、归属和追捕等级会立即改变。

### Protagonist Ontology-only Direction

主角不是人，而是一枚活着的门框。

它由门板、两只短铰、锁舌和会发光的门缝组成。它没有手脚，也没有人类脸部，只能像一只小型甲虫一样沿着实体表面移动。

它的身体本身就是一个可开合的门。

### Initial Origin-only Direction

T0 时，主角诞生在一座被攻破的城门断裂铰链中。

它只有四指宽，门板半透明，锁舌尚未闭合。它躺在碎石之间，尚未贴附任何载体。

零点经历只有：

- 看见城门两侧的火光；
- 感知到一面掉落的圆盾正在滚近；
- 听见长矛撞击盾面的声音；
- 尚未开启、翻面或锁住任何目标。

### Initial Scale Position-only Direction

本 World 只定义一条公共力量尺：`门阶`。

主角 T0 的精确位置为：

- `门阶：门胚`
- 门幅：四指宽
- 载体：无
- 可通过目标：空气与光线
- 不适用：一至七阶，因为主角尚未贴附到任何可承载生命或器械的实体上

`门胚`是本世界所有新生门的公共前阶，不是主角专属的“零级”或“尺外”。

### Power-only Direction

#### Legal Primitive Set

- `贴`：身体直接接触合法载体后，贴附在其表面。
- `开`：打开自身门框，显露载体真实存在的另一面。
- `翻`：交换门框所朝向的载体正面与反面；正在穿过门缝的目标会随其门向改变出口面。
- `锁`：在目标穿过门缝时闭合门框，把目标或目标的一部分夹在门缝中。
- `移`：贴附状态下，沿同一连续载体表面移动一段不超过自身门幅的距离。

#### Legal Carrier / Target Classes

合法载体：

- 固定建筑墙体与门体；
- 盾牌、铠甲等刚性防具；
- 棺材、箱体等具有明确两面的刚性容器。

合法目标：

- 正在穿过门缝的活人或死者；
- 正在穿过门缝的武器、箭矢、攻城器械等实体物件。

#### 永久边界

主角不能脱离实体载体创造出口，不能在远处开门，不能把两个互不接触的地点相连，也不能影响没有穿过自身门缝的目标。

### Story Interface / Opening Promise

第一章让读者立即看见：

一枚四指宽的门胚贴上敌方盾牌。

长矛刺入盾门。

门胚翻面，长矛的尖端从持矛者自己胸前穿出，随后门缝锁死，整面盾牌变成敌人的绞刑架。

第一章到第十章：

1. 城门崩塌，门胚被火焰和盾牌带入战场。
2. 门眼同步记录，废铰从垃圾变成战争奇物。
3. 城门氏族追捕门胚，想把它焊进自家盾门。
4. 一名守门少年把门胚藏进铠甲，成为它第一个移动载体。
5. 主角学会沿铠甲、盾面和城墙移动。
6. 它选择救出被锁在棺门后的守军尸体，而不是直接逃走。
7. 门氏族公开围猎，主角把所有穿门攻击翻回各自持有者。
8. 城内关系换位：原本保护主角的少年被门氏族宣布为叛门者。
9. 城上方的天门开始下沉，荒原光线与怪潮一同压入城市。
10. 主角第一次贴上城墙，发现天门并非自然关闭，而是被一支跨过城界的军队强行顶住。

第 20 章前后，主角必须达到`七阶·天门`，结算天门关闭、城市覆灭与门氏族归属的最高局势。Handoff 只说明当前天门冲突已结算、主角已达到本地最高门阶，以及哪些能力和关系继续携带，不预写第二世界答案。

### Authority-Compilation Trace

- 盾门反刺  
  → `贴 + 开 + 翻 + 锁`  
  → 触发已满足：主角直接接触盾牌，长矛正在穿过门缝  
  → 载体：盾牌  
  → 目标：长矛与持矛者  
  → 合法，因为翻面只交换盾牌两侧，锁定只作用于正在穿缝的长矛。

- 沿城墙移动  
  → `贴 + 移`  
  → 触发已满足：门胚贴在连续墙面  
  → 载体：城墙  
  → 合法，因为主角没有瞬移，只沿同一实体表面移动。

- 借铠甲换位  
  → `贴 + 开 + 翻`  
  → 触发已满足：铠甲是合法刚性载体  
  → 目标：正在穿过铠甲门缝的身体或武器  
  → 合法，因为主角只改变铠甲的正反面出口。

- 棺门放出尸体  
  → `贴 + 开 + 翻`  
  → 触发已满足：棺材是合法容器  
  → 目标：正在穿过棺门的死者  
  → 合法，因为主角没有支配尸体，只改变它从哪一面出来。

- 城墙锁住攻城槌  
  → `贴 + 开 + 锁`  
  → 触发已满足：攻城槌穿过城墙门缝  
  → 载体：城墙  
  → 目标：攻城槌  
  → 合法，因为锁只夹住实际穿过门缝的实体。

- 第 20 章倒扣天门  
  → `贴 + 开 + 翻 + 锁 + 移`  
  → 触发已满足：主角贴附天门，入侵军与攻城器械正在穿越天门门缝  
  → 载体：天门  
  → 目标：实际穿越门缝的军队前锋、器械和旗车  
  → 合法，因为终局动作仍是同一扇门的开、翻、锁，没有产生远程出口、共同网络或无限复制。

### 第一章标志性画面

敌军最强的枪手一枪刺穿盾面。

四指宽的门胚贴在盾上，门缝亮起。

下一瞬，枪尖从枪手自己胸口穿出；门胚咔哒一声锁死，整个战场都听见了这声响。

### 主角反复会做的新动作

- 把盾牌翻成反刺门。
- 沿铠甲表面爬到敌人身后。
- 把棺门变成尸体的出口。
- 把墙门移动到攻城器械必经之处。
- 把攻城槌锁在城墙门缝里。
- 把城门正面翻向城内。
- 把天门的压力倒扣回正在穿越它的敌军。

### 第一次不公平兑现

主角只有门胚大小，却能借用更大的载体。

它不需要拥有盾牌、铠甲或城墙，只要贴上去，就能把自己的门规则放大到载体的尺度。

普通门只能让攻击通过，主角却能决定攻击从哪一面出来。

### 20章玩法扩张

- 小门胚借盾牌完成越级反杀。（`贴 + 开 + 翻 + 锁`）
- 借铠甲和城墙连续移动。（`贴 + 移`）
- 把穿过门缝的兵器固定成敌人的负担。（`贴 + 开 + 锁`）
- 在同一座城墙上移动门位，改变攻城路线。（`贴 + 移 + 开`）
- 把整座城门的正反面翻转，重排战争双方的受力方向。（`贴 + 开 + 翻 + 锁`）
- 在天门处锁住真正跨界的先头部队，迫使本地最高战争局势当场结算。（`贴 + 开 + 翻 + 锁`）

### 100章以上仍能长出的不同故事

未来每个 Approved World 只能提供新的、明确存在的两面实体、刚性载体和实际穿门目标。

既有原语可以在新实例上产生：

- 不同身体载体；
- 不同移动路径；
- 不同门面交换；
- 不同实体穿越冲突；
- 不同社会归属和战争用途。

若未来 Authority 要增加新的合法载体类别，必须由未来 World 单独定义；当前候选不提前假设新类别，也不增加跨世界出口。

### 最小可信桥梁

- 两面实体会自然长门，是所有人都知道的世界事实。
- 门阶是普通人、城防和战争都使用的公共力量尺。
- 主角只是一枚罕见的活门胚，优势来自贴附、翻面和锁定，不来自另一个隐藏系统。

### 不可磨平的三点

- 主角始终是一扇门，不会被磨平成“会门术的人”。
- 它的战斗核心不是破坏，而是决定敌人从哪一面承担自己已经发出的力量。
- 每次越级都需要找到更大的真实载体；它不能凭空把一扇小门变成远程世界通道。

三者均为非 Canon 候选，未自动选择。
