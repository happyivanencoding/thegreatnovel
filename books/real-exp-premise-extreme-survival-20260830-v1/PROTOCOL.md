# Extreme Premise Survival + Matched Mutation Ladder｜Protocol

状态：RESEARCH_ONLY。基于已冻结 Premise Aperture F1–F5，不修改 production default。

## Phase A｜E7 Extreme Premise Survival

- 固定题材：20章一个独立世界、快速升到该 Local World 顶层的男频多世界成长长篇。
- Forge：沿用 frozen Single-Agent Premise Forge；只追加一个 `EXTREME RIGHT-TAIL` Treatment。
- 预注册选择：**S3**。生成前写死，不因 S1/S2 更好或更易编译而改选。
- S3 要求：一个主押注；一句话可懂；优先打碎一个深层类型默认；必须显著改变主角反复动作；第一章即有不公平兑现和第二层外界反应；不允许用更多术语/更多系统冒充大胆。
- Independent Compiler：沿用 production `build_selected_premise_compiler_prompt`，模型 Terra high，fresh context。
- 只有 strict `PASS` 才进入真实 downstream；`CONDITIONAL PASS / FAIL` 都停止，不自动 Repair、不换候选。
- downstream 若启动：World=Luna high；Power/Human=Luna high 并行；固定 Power Candidate 2 / Human Candidate 2；Story=Sol high；Outline=Luna high；正文前5章走当前 Director→Curator→Terra Primary→Luna Authority Reviser→State。
- 目标不是证明“越疯越好”，而是定位 Premise 电压在哪一层第一次被普通化、抽象化或换回旧动词。

## Phase B｜E1 Matched Mutation Ladder

- 母体固定为 Phase A 同一 S3；不换 premise DNA。
- 一次生成 M0→M4 五档：conservative / commercial / aggressive / extreme / overdrive。
- 只能沿同一个核心异常提高电压，不得每档换世界、换主角本体或增加新的独立系统。
- M4 被允许真实过头；不由 Judge 自动裁掉。作者后续直接看真实版本决定 sweet spot。
