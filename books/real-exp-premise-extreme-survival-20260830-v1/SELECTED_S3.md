## S3｜《天下第一道伤口》

### 一句话货架简介

主角不是受伤的人，而是一道刚刚长出意识的伤口；谁制造了这道伤，他就能沿着伤口留下的因果线钻进对方身体，从内部把伤口还回去。

### World-only Direction

这是一个伤口永远不会自然愈合的世界。

- 生灵通用武力尺：凡身、开脉、铸炉、照海、天门、王域。
- 伤口开度尺：细痕、指隙、肢隙、门隙。
  - 细痕：不超过三分；
  - 指隙：三分至一寸；
  - 肢隙：一寸至三尺；
  - 门隙：超过三尺。
- 任何真实伤口都会保留一道可见的“创线”，指向造成该伤口的确切生物、武器或自然力量。
- 伤口不会自行闭合；只有取回伤口中央的“伤芯”，或由造成伤口的力量主动终止，伤口才会消失。
- 创线只记录伤害来源，不会自动攻击、传送或改变双方位置。
- 伤口越大，创线越粗，越容易被其他人发现；因此杀人、行刑、决斗和医疗都受到公开追溯。

### World Interface-only Direction

- 每座城的“疤石”会自动记录公共区域内出现的伤口、创线方向、武器动作和现场证词。
- 记录可即时观看，保留七日。
- 疤石只能观看、记录和传播，不能制造伤口、拉动创线、替人取伤芯或改变攻击结果。
- 重大伤口记录会同步到城门、医馆和军府，形成公开的责任链。
- 疤石无法判断动机，只能记录谁造成了什么伤口、伤口何时出现、创线指向哪里。

### Protagonist Ontology-only Direction

主角是一道长九寸、宽一尺的竖直伤口，没有肉身、骨骼和固定脸孔。

- 身体由两道不断张合的伤口边缘组成。
- 伤口内部不是黑暗空间，而是一段极薄、极长、可以穿行的“创腔”。
- 他不能像人一样走路，只能沿伤口边缘爬行、张开、闭合和撕裂周围的附着物。
- 他能感知接触自己的刀、手、血液、皮肤和创线。
- 他不能独立产生普通拳脚力量；他的动作必须依托伤口、创线或被他并入身体的伤口边缘。
- 他没有人类形状，但能用创腔吞入和拖出小型物体。

### Initial Origin-only Direction

T0 时，主角诞生在一头已经死亡的石甲狮胸口。

- 石甲狮死于一场公开处刑，胸口留下了一道长九寸、宽一尺的竖伤。
- 行刑者离开后，伤口中央的伤芯没有被取回，创线仍然指向那名行刑者。
- 伤口边缘在 T0 聚合出意识，主角第一次知道自己不是石甲狮，而是这道伤。
- T0 零点经历：只能贴着石甲狮胸腔内壁张合，能够感知外界触碰，不能离开原伤，不能反向沿创线移动。
- 他没有见过行刑者，也没有主动攻击过任何人。

### Initial Scale Position-only Direction

- 生灵武力尺：不适用。原因：主角是世界通用分类中的“有意识伤口现象”，没有独立肉身，不能直接占据凡身至王域的位置。
- 伤口开度尺：肢隙档下限；宽一尺、长九寸。
- 创线长度：已连接一名明确行刑者；这是 T0 既有伤害来源，不是主角新获得的 Power。
- 独立施力：不适用。原因：主角 T0 只能张合和感知，尚未满足 Power 的触发条件。

### Power-only Direction

能力名：夺伤回创。

- 触发：主角的伤口边缘接触一处仍然开放的真实伤口，并触碰该伤口的创线。
- 目标类别：该伤口的确切制造者，以及这道伤口本身。
- 可做动作：
  - 沿创线钻入制造者身体，在对方身上打开一个与原伤口同等开度的出口。
  - 从出口进入对方体内，再从原伤口或对方身上的其他开放伤口折返。
  - 将原伤口的一部分边缘并入自身，永久扩大自己的开度。
  - 拖出或塞入不超过自身开度的物体。
- 他不复制敌人的境界、力量或技能；他只是把真实存在的伤口和创线变成可穿行的身体通道。
- 永久边界：主角必须始终依托至少一道现实中仍然开放的伤口；没有开放伤口作为锚点时，他会失去行动能力，不能凭空制造第一道伤口。
- 除这一条根边界外，Power 不主动设置对称代价。

### Story Interface / Opening Promise

开篇是石甲狮的公开处刑。

行刑者为了取出石甲狮胸口的伤芯，再次把手伸进主角所在的伤口。触发成立，创线从伤口内部亮起，主角沿线钻入行刑者的手臂，在他的手腕上直接裂开一道同样宽度的出口。

行刑者的手臂从内部被自己的处刑伤口撕开。

天上的疤石立即记录这一幕。

第二层后果立即发生：

- 围观者看见伤口第一次主动反咬制造者。
- 医馆、军府和各大宗门立刻重新估价所有旧伤：伤口不再只是弱点，也可能是一扇通往敌人体内的门。
- 现场强者开始互相检查身上的旧伤。
- 没有受伤的人争抢火、药和铠甲，生怕给主角留下入口；已经受伤的人则变成各方势力最想争夺的战场节点。

前十章推进：

1. 主角沿石甲狮创线反创行刑者，公开暴露。
2. 行刑者试图取回伤芯，反而被主角拖入石甲狮胸腔。
3. 主角第一次并入行刑者手腕伤口，开度扩大。
4. 一名少女医者发现主角不是妖物，而是会选择目标的伤口。
5. 城中势力封锁所有伤者，主角被迫借一名重伤囚徒逃城。
6. 主角穿过囚徒胸口创线，第一次反杀追兵首领。
7. 疤石回放使主角的存在传遍附近城镇，围猎与供奉同时开始。
8. 少女医者故意保留一道浅伤，成为主角唯一稳定的移动锚点。
9. 主角进入一名天门强者的旧伤，发现伤口能够绕过对方正面防御。
10. 城主发动公开无伤处刑，试图消灭所有可供主角使用的入口；主角转而利用城墙、刑台和旧战争伤痕制造反攻网络。

### Authority-Compilation Trace

- 主角感知外界触碰 → `Protagonist Ontology-only Direction` 的伤口触觉 → T0 已成立 → 目标为石甲狮胸口与外部行刑器具 → 合法。
- 行刑者再次触碰胸口伤口 → `Power-only Direction` 的开放伤口接触触发 → 触发已满足 → 目标为原伤口及其明确制造者 → 合法。
- 主角沿创线进入行刑者手臂 → `World-only Direction` 的创线指向规则 + `Power-only Direction` 的穿行动作 → 触发已满足 → 载体为真实创线 → 合法。
- 行刑者手腕出现同等开度出口 → `Power-only Direction` 的出口动作 → 目标为创线制造者 → 合法；没有复制行刑者武力。
- 主角并入手腕伤口并扩大自身 → `Power-only Direction` 的伤口边缘并入动作 → 原伤口仍开放，触发已满足 → 载体为真实手腕伤口 → 合法。
- 疤石记录反创过程 → `World Interface-only Direction` 的公共伤口记录 → 事件发生在公共刑场 → 载体为疤石 → 合法；疤石没有参与反创。
- 主角无法在无伤环境中凭空出现 → `Power-only Direction` 的永久根边界 → 没有开放伤口时触发不满足 → 结果为暂时失去行动能力 → 合法。

### 第一章标志性画面

行刑者把手伸进石甲狮胸口的伤口，下一刻，他自己的手腕从里面裂开；那道伤口像一扇门，从死去妖兽的胸腔里通向制造它的人。

### 主角反复会做的新动作

- 沿创线钻进制造者体内。
- 把旧伤撕成新的出口。
- 把敌人的伤口边缘并入自身。
- 借一名伤者的身体穿过封锁。
- 从刀口、箭孔和裂甲中突然出现。
- 拖动物体穿过人体或墙体上的开放伤口。

### 第一次不公平兑现

主角刚出生就把一名负责公开处刑的天门级行刑者的手臂从内部撕开；对方的强大境界无法防御一个从自己伤口因果线里钻出来的敌人。

### 20章玩法扩张

主角通过并入不同大小的伤口，把自身从一尺级扩大到门隙级，逐渐获得：

- 个人伤口通道；
- 兵器伤口通道；
- 城墙战争伤痕；
- 妖兽撕裂伤；
- 天门强者旧伤；
- 战场上成千上万条可追溯创线。

第 20 章前，第一世界的最高战争围绕一座拥有古老战争伤痕的城池展开。主角利用所有仍开放的创线，把最强的几名敌人拖进彼此的伤口网络，最终决定城池归属。当前世界最高局势结算后，输出的 Handoff 只说明：主角已拥有足以跨越当前世界最大身体与战场结构的创腔，下一次扩展由新的 Local World 规则决定。

### 100章以上仍能长出的不同故事

- 主角永远不是连续的人形生命，而是由伤口、边缘和创线组成。
- 不同 Local World 可以让伤口连接个人、武器、建筑、巨兽或其他可受伤实体，但具体答案必须到对应世界重新定义。
- 人物关系会直接改变主角是否保留某人的伤口、是否救治锚点、是否把伤口还给真正的制造者。
- 他的成长不是单纯变硬，而是从一道小伤口变成能让一个世界的暴力彼此相连的身体。
- 每个世界最终都能围绕同一个直接问题展开：谁有资格决定伤口归谁？

### 最小可信桥梁

只需世界承认：伤口不会自然愈合，并且每道伤口都保留指向制造者的真实创线。主角只是第一道获得意识、能够沿创线行动的伤口。

### 不可磨平的三点

1. 主角不是受伤的人，而是伤口本身。
2. 每次攻击都可能成为敌人进入自己的门。
3. 死亡、身体边界和“伤害只能单向发生”的默认认知都不能恢复原状。
