我会按 TGN 的 Authority 审计口径，只判定已写规则是否闭合，不评价创意强弱或替它补设定。我将使用系统审计技能来约束这次复核的边界。# SELECTED PREMISE AUTHORITY COMPILER

## S3

- Verdict: CONDITIONAL PASS
- Opening legality: 开篇反创的目标、真实载体与疤石见证都已有文字依据；疤石只记录，未偷做 Power。唯独触发尚未严丝合缝：主角即原伤口时，“伤口边缘接触一处开放伤口并触及创线”是否可由行刑者伸手满足，未明写。必须明确原伤口可作为触发伤口，且伸入动作实际触及创线。闭合后，“沿线入手臂→在制造者手腕开同开度出口”合法，不构成复制天门力量。

- Scale legality: T0 不占生灵武力尺本身合法；首次撕开天门手腕亦是 Power 的直接例外，不等于主角升级为天门。但“并入伤口”如何从肢隙稳定增长至门隙、开度如何对应可穿越的身体／战场尺度、为何可持续压过不同生灵档位，均未被现有公共尺和成长规则明文化。不能把“永久扩大”直接推成全部后续尺度跃迁。

- Long-form legality: 未闭合。第二章“把行刑者拖入胸腔”没有对活人搬运及体积的授权；第五至九章的借囚徒移动、少女移动锚点、进入天门强者“旧伤”，都缺少主角抵达该伤口或伤口所有者恰为制造者的既有路径。第十章及二十章的城墙／兵器／战争伤痕、多人互拖网络、跨 Local World，也分别缺少合格伤口载体、共同网络机制与跨世界出口。

- Remaining hidden bridges:
  - 原伤口是否能自触发；行刑者的手、创线与主角边缘在何一步实际接触。
  - 创线的目标始终是“制造者”，不是受伤者；因此“进入某强者的旧伤”及“从刀口、箭孔、裂甲出现”只有在该人／该处就是制造者端时才成立。
  - 主角如何从石甲狮原伤转移到囚徒或医者身上的伤口，以及如何随移动锚点移动；现有 Power 只授权沿创线与在制造者端折返。
  - “拖入”活人是否属于可拖物体、是否受自身开度限制；现有文字只明确小型物体与不超过开度的物体。
  - 武器、铠甲、城墙、建筑和战争遗迹是否都是“真实伤口”的合格承载者；当前 World 明写的是生灵伤口，后续扩张不能默认外推。
  - 多条创线如何相互接驳、让数名敌人进入彼此网络；现有能力是单一伤口—其制造者的定向通道，没有共同载体或网络控制。
  - 伤口并入的几何累积规则，以及门隙为何足以跨越“最大身体与战场结构”。
  - 疤石的同步范围只到本城城门、医馆、军府；“附近城镇皆知”需要既有的人为传播链，不能由 Interface 自动补足。
  - 新 Local World 的入口不能仅写“由新的规则决定”；若百章结构包含换世界，必须已有可到达该世界的出口。

- Protected creative core:
  - 一句话货架承诺完整：主角是有意识的伤口，沿制造者创线把伤还回去。
  - 非标准 Ontology 完整：无肉身、由伤口边缘与创腔构成、依托开放伤口行动。
  - Changed Verbs 完整：沿创线钻入、在制造者身上开出口、并入伤口边缘、借伤口穿行、拖动物体。
  - 不可磨平项完整：主角不是伤者；攻击会成为反向入口；死亡与身体边界不可恢复为单向伤害。
