# Primary Writer Audit

前章正式正文已经把断镐中那次向前的锋力用尽，而当前事件合同要求“未尽锋意”参与铸器。本 Draft 将两者桥接为：黑铁锋片中只留下一个尚未收拢的成形方向，它能牵引粗铁完成铸造，但不是断镐锋力的恢复，也不让断镐再次驱动。其余已发生事实按正式正文处理。

# Primary Draft

石门合上的第三声闷响还没散，门外的铁凿已经落了下来。

一下。

又一下。

声音隔着厚重的石板传进来，沉而稳，像有人在门外量着他们的呼吸。门缝里最后一线冷风被挤断，窟内的暗红炉光也跟着缩了一下。原本贴在石壁上的那层微光往炉膛深处退，露出一圈被烟灰熏黑的砖口。

沈燧回头看了一眼。

石门外的敲击没有停。那不是矿工挖石时乱落的锤声，每一下都落在相同的位置，石屑从门缝上方细细地往下掉。旧风道那头的人已经摸到了这里。

前方忽然传来一阵闷响。

炉台下的灰被一股看不见的风卷起，贴着地面往门边流。黑灰中有几粒红星亮了亮，随即整条地缝都透出暗红色，像烧过的铁在石头底下翻了个身。

胸口受伤的矿工弯下腰，咳得肩背发抖。小腿受伤的人靠着墙，裤管上的血还没有止住。额头裂伤的矿工把手掌压在眉骨上，指缝里又渗出一线红。

“能走的，先把伤者送到右边矮口。”沈燧说，“腿伤的用腰带拖。胸口伤的两边扶，别让他平躺。”

没人问右边是什么。

他已经抬手指了过去。黑色石壁下方有一处被炉灰埋住的窄口，刚够一个人弯腰钻入，里面没有红光，只有一缕贴着地面吹出来的冷风。

“阮青禾。”沈燧说，“看路。”

阮青禾提着符灯走到那面墙前。她没有先去看窄口，而是把灯举高，照向石壁上半截被烟灰盖住的刻痕。三道短斜槽挨在一起，最下方又有一笔向旁边折去，像一只被炉火燎断的手。

她用指节敲了敲。

石壁里面传来空响。

“旧窑工的记号。”她说，“三短槽是侧炉，折下去的是低温风道。这里不是主炉的退火口，火走不满，伤者能在里面撑住。”

“通到哪里？”

阮青禾把灯贴近刻痕，沿着那道折下去的线往墙根看。她的手指拨开一层黑灰，露出一条更细的刻线。刻线没有通向门外，反而穿过侧炉的炉脚，朝窟内深处延伸。

“旧图还在墙后。”她说，“能不能出去不知道，但侧道在这边。”

“先把人送进去。”

沈燧说完，自己弯腰去抬小腿受伤的矿工。那人刚把腿挪动半寸，便咬住了袖口，额角的冷汗混着灰往下流。沈燧将腰带绕过他的胸口，朝旁边两个能动的人点了点头。

“一起拉。”

腰带绷直，三个人同时用力。伤者的身体在石地上拖出一条暗色的痕迹，裤管里渗出的血沾在灰上，很快被热气烘成了褐色。

阮青禾已经蹲到矮口前。她用短刀撬开堵住入口的炉砖，里面的冷风顿时清楚了一些。额头受伤的矿工举灯进去，胸口受伤的人由两人架着往前挪，另一个矿工回身接过腰带。

“别把入口堵死。”阮青禾说，“里面还有风。”

沈燧把腿伤者送过门槛，又回头看向那座正在变暗的炉台。

炉灰还在往门边流。

门外的凿击声突然停了。

片刻后，石门上亮起一条赤色的线。那条线不是从门缝里透进来的，而是沿着石板的纹理一点点爬出来，先绕过门框，再在门中央交错成几个细小的符结。符结落定时，门外传来沉闷的钉击声。

“第一道矿门，封。”一个陌生的声音在门外喊。

裴照川的声音紧接着传来，隔着石门依旧清楚：“窟内所有炉息列入回收。活物、矿材和异常残响一并封存，不得自行损毁。”

矮口里的矿工停了一下。

有人低声问：“他是来救人的？”

沈燧看着门上的赤线。

第二根符钉落下，石门里侧的石头随之一震。那道赤线从门框压进石壁，像一根烧红的铁丝，顺着地面朝他们这边伸来。

“他来收东西。”沈燧说。

“那片铁呢？”

说话的人看着他的右手。黑铁锋片仍嵌在掌心，隔着破布把指节烫得发红。沈燧把手往袖中收了收。

“也收。”

他没有把手伸向石门。

第三根符钉敲入时，窟顶的灰尘忽然向上飘起。下一刻，炉台深处传出一声低沉的吸气，暗红色的火线沿着地缝猛地往回一缩，随即从侧炉脚下冲出一股热风。

矮口边的石砖被吹得发白。

“进去！”沈燧喝道。

最后一个扶人的矿工赶紧低头钻入风道。胸口受伤的人被热风一冲，胸腔里又挤出一阵咳嗽。阮青禾用手臂护住他的脸，回头朝沈燧喊：“侧炉要回火了！”

“把人送到风道尽头，别停在口上。”

“尽头有封着的东西。”

“我去看。”

沈燧转身走向侧炉。

炉门已经被灰封住大半。旧砖缝里没有完整的火，只有一层埋在灰底的暗红。阮青禾说的刻痕从炉脚往上爬，正好绕过炉口，通向侧炉后方那面厚重的石壁。

他用左手拔开炉门上的碎砖。

一股焦苦的热气扑到脸上，里面的残火像一只缩在灰里的眼睛，刚被风碰到，便亮出细细的红边。

侧炉旁堆着几根粗铁。

它们被废渣埋住，长短不一，表面结着黑壳，露出来的一端仍有暗红色的锈痕。炉口下方还压着一截弯掉的火夹和半柄炉锤。东西都旧得厉害，却没有完全烂掉。

“这里还能起火。”阮青禾钻出来，目光在炉口和墙上的刻线之间来回，“但风只能从低温道走。风道一旦被热流堵住，里面的人会先闷死。”

沈燧抓起弯火夹，撬开炉底的铁栅。

栅下积了厚厚一层灰。灰里面有一粒红炭，随着铁栅移动滚到一旁，短暂地亮了起来。阮青禾立刻让人把矮口旁的一块旧炉砖搬开，冷风从低处钻来，擦过炉底。

红炭被风一碰，忽然烧出一圈火。

“压住上面的灰。”沈燧说。

两个矿工把粗铁横在炉口，另一个人用炉砖压住两侧。阮青禾蹲在低风口边，看着风向，时不时伸手摸一下石面。

“火还在往主槽走。”她说，“最多撑一会儿。”

“够了。”

沈燧把粗铁一根根送进炉里。

门外又响起了敲击声。裴照川的人没有继续敲石门，而是在门外沿着地面布符。赤色的光从石缝里一闪一闪地透进来，每闪一次，炉里的残火便往外窜一点。

沈燧伸出右手。

黑铁锋片已经热得像贴在骨头上的烙铁。它的边缘从掌心露出一线薄光，皮肉被烫开，血刚冒出来便被火气烘干。

阮青禾看见他的动作：“你要把它取出来？”

“它卡在这里，什么也做不了。”

他说得很平，手却没有停。

沈燧用左手按住掌心两侧，把弯火夹的尖端卡在锋片露出的边缘。他先试着往上挑，黑铁没有动，右臂的裂痕却从腕侧一起疼了起来，像有一条细线在骨头里被拉直。

他换了角度，再往外拔。

锋片离开皮肉的一瞬，右手五指猛地收紧。掌心像被从里到外剜去一小块，血沿着手腕流进袖口。黑铁落在火夹里，薄得几乎没有重量，却把火夹压得一沉。

沈燧没有看伤口。

他把锋片放到烧红的粗铁上。

金属接触的一刻，炉火突然向内一缩。不是火势变大，也不是力量从他身体里涌出来。只是那片黑铁贴上粗铁后，原本散乱的红光被一条细细的黑线拢住，像一件没有收口的东西终于找到了另一边的边缘。

沈燧的右臂一麻。

那条停在掌骨里的黑线顺着腕骨往上爬，又从肘侧折回炉锤下的铁块。它不再向前冲，只在粗铁里留下一个极窄的方向。

他抡起半柄炉锤。

第一下落在锋片边缘。

粗铁发出一声闷响，黑铁往下陷了半分。火星溅到沈燧手背，右臂上的裂痕随之亮了一下。他没有松手，第二下、第三下接着落下，把烧红的铁皮压到锋片两侧。

炉锤很重，柄又短，每一下都要借着腰背送出去。沈燧的左肩还在疼，右掌脱出锋片后只剩空洞似的骨痛，手指握不紧，便用掌根顶住粗铁，任由灼热顺着手臂往上爬。

“左边薄了。”阮青禾说。

沈燧将铁块翻过来。

她不懂铸器，却看得出哪里会在敲击时崩开。她捡起一块扁石压住粗铁的一端，另一只手指向炉口：“火头往下，别让它烧穿。”

沈燧把铁块往灰里压了一下，借灰压住火。火焰被闷得只剩红光，他趁着这个空隙连续敲下。粗铁包住锋片，尾端渐渐变厚，前端则被压成一个不规整的扁楔。

那片黑铁没有被熔掉。

它沿着粗铁中间留下了一条细缝，缝隙一端收在厚重的尾部，另一端分出两道薄边。沈燧每敲一下，黑线便往金属里更深地沉一点。到最后，炉锤落下时，铁块内部传来一声极轻的回响，像石头远处有一道缝应了一声。

沈燧把扁楔从火里夹出来，埋进炉灰。

灰面被烫得发白，扁楔仍在里面缓慢发热。它不漂亮，边缘也不齐，厚重的尾部甚至有一处凸起，握在手里会硌掌。可那条黑缝没有散开。

门外忽然传来裴照川的声音：“符钉入门。”

石门轰然一震。

侧炉里的残火被震得冲高，几根粗铁从炉口滚落。阮青禾在低风口边抬头，脸色被红光照得发白。

“门封死了。”

沈燧用左手从灰里捞出那件刚成形的东西。

它比看上去更沉，热度隔着炉灰仍能传进掌心。右手的伤口在空痛，黑色裂痕停在臂上，没有因为锋片离开而消失。

阮青禾指向侧炉后的石壁：“墙上那条线就是旧侧道。可石壁中间被补过，补石后面还有一层门。”

沈燧提着扁楔走过去。

主炉方向又传来轰鸣。暗红色的火沿着地面的裂纹往侧炉聚来，碎灰在热风里打着旋。低温风道里有人喊了一声，随后是伤者压低的痛哼。

“沈燧！”阮青禾说，“他们到尽头了！”

墙上的旧刻线在灯光下断断续续，最后停在一块颜色略深的石面上。那里的灰比周围干净，像曾经有一扇门从里面被封过。阮青禾用刀尖一刮，石面下露出一道细窄的黑缝。

沈燧把扁楔抵在缝旁。

它在手里轻轻一热。

不是对着整面墙，而是对着黑缝另一侧一处更薄的地方。那股细细的方向从尾端传到前刃，短促，清楚。

沈燧抬起炉锤，敲在扁楔的尾部。

石壁没有炸开。

黑线先从扁楔前端钻入石中，沿着旧刻线无声地走了一段。接着，整面墙像被一把看不见的窄刀从里面划过，裂缝穿过灰层，直达墙顶。

石头向两边错开。

一股冷风从新裂隙里冲出来，把炉灰和符灯火焰同时吹向后方。裂隙只打开到能让一个人侧身通过，边缘却没有新的碎石落下，像有什么东西暂时替他们撑住了石壁。

“走！”沈燧喊。

阮青禾先钻入裂隙，转身接住额头受伤的矿工。两个能动的人把胸口受伤者架过去，另一个人用腰带拖住小腿受伤者的肩背。伤者经过裂口时，裤管被石边划开，血又渗出来，却没有人停。

沈燧站在最后。

外面的赤光顺着第一道封门的缝隙压进来。门后隐约有人影移动，铠甲和符器碰撞的声音清晰可闻。裴照川的回收队已经抵到门外，只隔着几层石和一条刚刚裂开的黑线。

裂路器在沈燧手里发热。

他把它从石缝中拔出，最后一个矿工正拖着伤者通过。那道裂隙开始缓慢收拢，石壁的重量重新压回来。

“快！”阮青禾在前方喊。

沈燧刚迈入侧道，炉火便追了上来。

这一次不是热风。

一片暗红的火流从主炉底部冲进旧侧炉，卷着灰和细碎的金属渣扑过来。火流沿着他们刚打开的裂隙钻入，墙面上的旧刻线一根根亮起。低温风道里的冷气被压退，伤者身后的石地迅速升温。

“前面有门！”阮青禾摸着侧道尽头的石面，“两根薄封钉，钉在裂缝里！”

她的声音被热浪撕得发哑。

侧道窄得只能容一人弯腰前进。小腿受伤的矿工卡在中间，前面的人不敢硬拖，后面的火已经贴到脚边。胸口受伤的人伏在石壁上咳嗽，额头受伤的矿工用灯照着阮青禾的手，灯火被热风压得只剩一粒蓝点。

沈燧把裂路器递给阮青禾。

她没有接：“你来。”

“看钉子。”

阮青禾把灯压低。

薄封钉藏在新裂隙的左侧，一根横着，一根斜着，钉头被黑色符泥封住。那不是整面石门的封锁，只是把侧道最后一段压死的两枚细钉。她抬手指向第一根，又指向第二根。

“沿刚才的缝走。别碰中间。”

沈燧弯下腰。

火流已经到了身后。裂路器的前端被热气舔过，粗铁表面立刻泛起一层暗红，夹在中间的黑缝却仍然清晰。沈燧把扁楔贴进新裂隙，先对准横钉。

他没有把它伸进火里。

炉锤落下。

第一枚薄封钉发出一声尖响，从中间断开。黑色符泥沿着钉身裂成两半，石门向前松动了一寸。火流撞在沈燧背上，热得他眼前发白，右臂上的裂痕像被重新烧了一遍。

他咬紧牙，顺着裂缝把裂路器往下拖。

第二枚封钉正好卡在扁楔前方。

沈燧将尾端一转，扁楔的薄边贴住钉身，再敲下第二下。

钉子断了。

没有巨响，只有一声短促的脆裂。那道压在侧道尽头的石板向旁边滑开，后面露出一条更窄的黑路。冷风从黑路深处涌出来，带着陈年的炉灰味。阮青禾立刻回身，抓住腿伤矿工的腰带。

“先送他！”

这一次，最靠近出口的两个矿工没有等沈燧发令。他们一个托住伤者的肩，一个抓住腰带往前拉。胸口受伤的矿工扶着墙让开位置，额头受伤的人把符灯递到前方，自己留下来替他挡住身后的热浪。

伤者被拖过石板。

第二个人跟上。

火流冲到裂路器前端，粗铁上的红色迅速加深。沈燧感到扁楔在手里发软，立刻把它从裂缝中抽出来。前刃已经热得发白，却没有被火流吞掉。那条黑缝仍在，像一只闭紧的眼睛。

阮青禾在黑路另一边伸手：“沈燧！”

他把裂路器夹在腋下，单手撑住石板，侧身钻了进去。

就在他收回脚的刹那，第一道裂隙外传来一声金属撞击。

裴照川赶到了。

赤色封光从石壁后面照进侧道，映出他站在裂隙另一侧的身影。年轻炉监没有立刻拔剑，也没有命人冲进来。他先看见横在沈燧手里的扁楔，又看见两枚断开的封钉，最后看见那件东西从灼热的裂缝里被完整地取出来。

他的目光在扁楔上停了一瞬。

“不是断镐的最后一击。”他说。

身后的回收修士问：“炉监，要不要进？”

裴照川抬手压住了对方。

“裂隙窄，火流正在改变。进去只会把人和器物一并堵死。”

他看着沈燧，声音隔着石缝传来，仍旧没有起伏。

“记录异常器物，可再次驱动。持有者沈燧，改列失控器修。”

回收队的人立刻展开符纸。

裴照川继续下令：“前后出口同时封。旧风道的门不要再挖，废窟侧道也落钉。活物若自行冲出，按异常回收处理。”

赤光沿石缝一寸寸退去。

沈燧没有回答。

他把裂路器换到左手。右掌脱出锋片后的空痛仍在，五指每收紧一次，掌骨便像碰到一块看不见的硬石。可那件粗糙的铁器沉沉压在手里，没有散掉，也没有重新回到他掌中。

侧道里的人都在看他。

小腿受伤的矿工靠在石板后喘息，两个帮他拖行的人还抓着腰带。胸口受伤的人咳了一阵，抬头朝阮青禾点了点头。额头受伤的矿工把符灯举高，照出侧道两旁被炉灰覆盖的旧墙。

阮青禾没有看裴照川离开的方向。

她沿着墙面往里走了几步，手指擦过一层被热气烘裂的黑灰。灰下面露出几道交错的刻线，线条比侧炉记号更细，像有人用烧红的针在石上画过。

“这里还有图。”她说。

众人挤到她身后。

那不是完整的地图。大半线条被后来的炉灰和封泥盖住，只能看见一条从侧炉延向深处的弯线。弯线尽头有一枚圆形炉印，印子的边缘已经发黑，中心却隔着石壁透出一点暗红。

阮青禾把灯靠近。

圆形炉印随灯光一晃，里面的红意也跟着跳了一下。

“窟心。”她说。

沈燧抬眼。

侧道更深处传来一声低沉的炉鸣。声音很远，又像就在脚底，先是沉下去，接着沿着刚才切开的石缝往外回响。残火从他们身后的侧炉重新亮起，火线没有朝原来的主槽退回，反而顺着裂路器劈开的新缝向侧道里爬。

阮青禾看着那条越来越红的线，脸色变了。

“火出来了。”

“它本来就在里面。”

“现在它找到路了。”

沈燧低头看了一眼手里的裂路器。

粗铁仍然粗糙，尾端的凸起硌着掌心。两次敲击留下的热度正在慢慢退去，前刃却承受不了刚才那股迎面的火流。它能切开石头和薄封钉，不能替他们挡住窟心涌来的火。

身后，封锁符一枚接一枚钉入石门。前方，残图上的圆形炉印又亮了一次。

没有人再问外面会不会放他们出去。

沈燧把裂路器握紧，朝阮青禾抬了抬下巴。

“带他们往里。”

阮青禾看了他一眼，转身去扶胸口受伤的矿工。其余人也跟着动起来，抬人的抬人，举灯的举灯，贴着残图指向的石壁往窟深处挪。

沈燧走在最后。

他们刚刚劈开的路后面，火正在一点点填满；更深处的窟心却像一口尚未熄灭的炉，隔着石壁缓慢地呼吸。

# Primary Fact Summary

- 沈燧在石门封闭、后方回收队逼近和窟内回火的压力下，按阮青禾辨认出的旧标记，把伤者和矿工转移到侧炉后的低温风道。
- 阮青禾确认侧炉、低温风道和一条指向窟心的旧残图；矿工在沈燧和阮青禾的手势下完成了伤者搬运与照看。
- 沈燧拒绝交出掌心黑铁锋片，从掌心取出锋片，以侧炉残火、粗铁和锋片中未收拢的锋意铸成一件粗糙、沉重、带黑色裂缝的裂路器；右掌空痛和右臂黑色裂痕仍然存在。
- 裂路器第一次切开侧炉后方石壁，打开一条短时裂隙；火流逼近后，裂路器沿新裂隙第二次切断两枚薄封钉，队伍带着伤者进入废窟侧道。
- 裴照川亲眼看见裂路器连续开路，确认它不是断镐锋力的最后一次回光，改令回收队封住前后出口，并把沈燧标记为失控器修。
- 侧道残图指向仍在发热的窟心；裂路器打开的通路使残火开始向外回流，宗门封锁仍在队伍身后，沈燧和众人继续向窟内移动。
