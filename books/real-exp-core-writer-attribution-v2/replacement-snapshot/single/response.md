# 正式正文

石门在沈燧身后合拢时，门轴里最后一粒红灰落了下来。

那粒灰没有落到地上。它贴着门缝滑过去，碰到他袖口，便碎成了一线暗红。

身后的敲击声又响了一次。

比刚才近。

旧风道已经塌死，门外的人正在从碎石里掏出新的路。矿工们挤在窟门后的黑地上，谁也没有出声。额头裂开的那人还在按着伤口，血从指缝里渗出来；压伤小腿的矿工被两个人架着，脚尖拖过地面，带出一串湿冷的血痕。胸口受伤的人弯着腰咳嗽，咳声被窟里的热气裹住，听起来像一只破风箱。

阮青禾忽然蹲到了门侧。

她把符灯举近，灯火照出石壁上三道短斜痕。斜痕下面还有一圈被烟熏黑的旧印，缺了一角，正好指向左侧。

“别往窟心走。”她说，“这里有旧引风标。”

沈燧看了一眼那几道痕迹。

石壁后传来很轻的风声，风里没有炉心的灼热，只有潮冷的石味。

“侧炉？”他问。

“废弃侧炉。”阮青禾用指甲沿着那圈缺口划过，“以前给窟里的小炉送风，炉温低，旁边应该有一条检修风道。能进去，先把伤者放下。”

门外传来一阵金属摩擦声。赤红的阵光从石门缝下钻进来，照亮沈燧垂在身侧的右手。掌心那片黑铁锋片隔着血肉微微发热，热意一跳一跳，像在催促他把什么东西握紧。

“沈燧。”裴照川的声音穿过门缝，仍旧清楚得没有一丝喘意，“封炉令下，废窟内一切矿材、炉火、器物和活物，均列入玄烬仙宗回收册。交出异常残响，退到门边，回收队可以给你们留一条登记路。”

一个矿工低声骂了一句。

裴照川没有理会。

“拒不交回者，按失控器修处置。”

沈燧低头看着自己的掌心。

黑铁锋片嵌在骨头里，薄得像一片没有收回的刀口。它不是矿材，也不是宗门册子上能写清楚的东西。可门外的人已经替它定了归处。

“这条路能走吗？”有人问阮青禾。

“能。”她说，“但要先把人送过去。”

沈燧把目光从门缝收回，落在那名压伤小腿的矿工身上。

“还能走的，先抬人。”

没人动。

不是不肯，是刚才那一击留下的余震还在每个人身上。谁都知道门外的封锁器已经找准了位置，谁也不知道这座被账册抹掉的窟还能撑多久。

沈燧伸出左手，指向侧壁。

“听不懂？”

那个额头受伤的矿工咬紧牙，先俯身把伤者的肩膀架起来。另一个人托住伤腿。胸口受伤的矿工喘着气站直，接过符灯，照向阮青禾指出的方向。

队伍终于动了。

侧壁下半截被矿渣埋住。阮青禾用一截断木杆拨开灰，露出一条窄窄的黑缝。缝里嵌着旧炉砖，砖面上的焦痕一层压一层，最深处还藏着一点没有熄灭的赤色。

“那里。”她说，“侧炉在里面。”

一股热风突然从废窟深处倒卷而来。

它先掠过石门，再撞上众人的后背。符灯的火舌被压得贴在灯芯上，额头受伤的矿工脚下一滑，差点把伤者摔在地上。更远处传来炉壁开裂的声音，像有一头沉睡很久的兽在地底翻了个身。

沈燧伸手挡了一下迎面的灰。

右臂的黑色裂痕从袖口下露出来，裂到肩下的地方，随着那阵热风轻轻发疼。

“火在往外走。”阮青禾看着窟顶，“封炉阵牵动了窟心。”

“侧炉还能撑多久？”

“如果不再动它，也许一炷香。”

“那就动。”

阮青禾看他一眼：“动了就会把回火引过来。”

“人先进去。”

他没有解释。两个能走的矿工已经把伤者送进了侧壁黑缝，里面果然有一截向下的低温风道。风道窄得只能弯腰通过，石壁却没有主窟那种随时要塌的脆响。额头受伤的人留在入口接应，胸口受伤的人扶着石墙往里挪。

沈燧最后看向门边。

赤色阵光又亮了一次。

门外的封锁器落下，石门上方随即传来沉重的震动。三枚黑色封钉从门缝外穿进来，钉头撞在石面上，发出短促的铿鸣。第一道矿门正在被封死。

“交出锋片！”裴照川的声音压过了震动，“这是最后一次命令。”

沈燧走到石门前，把右手从袖中抽出来。

黑铁锋片的尖端已经顶破了掌心。血沿着黑色裂纹往下流，流到腕骨便停住，像被什么无形的沟槽截住。

他没有把手伸向门缝。

“你们要的是片。”他说。

门外静了一瞬。

“人也要。”

“活物一并回收。”

“那就没什么好说的。”

沈燧转身，跟着最后一个矿工进入侧炉。

侧炉比外面想象得更低。半塌的炉顶压在石梁上，炉膛被灰白的废渣填了大半，只在底部留着一个拳头大的暗红火眼。火眼不亮，却一直没有灭。旁边堆着几段粗铁，有的是废弃炉箍，有的是被砸弯的支架，铁面上凝着黑色氧皮。

阮青禾先把伤者安置到低温风道入口，又回身检查侧炉四壁。

“这里有旧风箱。”她说。

炉壁后伸出一根已经发黑的木柄。她双手握住，用身体重量往下一压，风箱发出一声干哑的呻吟。炉膛里的灰被吹开，暗红火眼陡然多了一圈颜色。

“粗铁够用。”她又说，“但没有引火符。”

“不要引火符。”

沈燧走到那堆粗铁旁。

“把最直的那一段给我。”

阮青禾看向他右手：“你还要用它？”

“不是用它。”

“你的锋力已经耗尽。”

“我知道。”

他蹲下来，从粗铁里挑出一截手臂长的铁条。铁条一端被炉箍压扁，另一端还有一道折痕，拿在手里沉得发坠。沈燧把它横在炉膛前，用左手压住，右手悬在黑铁锋片上方。

掌骨里的空痛立刻变尖。

那不是刚才凿壁时的力量。刚才的锋意已经随着石梁和断镐一起耗尽了。现在留在他右臂里的，只是一道没有合拢的裂口，像断镐最后停在半空的动作，被硬生生嵌进了他的骨头。

沈燧把指节贴上锋片。

黑铁没有立刻脱落。

他加了一点力。

掌心像被从里面剜开，血沿着锋片的两侧涌出。黑色裂纹从腕骨往上收紧，肩头一阵麻木，右臂几乎失去知觉。阮青禾伸手来扶他，被他用左肘挡住。

“别碰。”

“你这样会把手废掉。”

“已经不好用。”

“废掉和不好用不是一回事。”

沈燧没有回她。他盯着那截粗铁，看见铁面上有一条极细的旧裂痕，从折痕一直延到中央。那条裂痕没有方向，却像在等一件东西把它劈开。

他把右臂的黑裂痕贴向铁条。

锋片终于松动。

它脱离掌骨时没有声音，只有一阵冷意突然穿过整只手。紧接着，空痛从掌心直撞到胸口，沈燧的身体往前一伏，血滴进炉灰里，瞬间被火眼吞掉。

黑铁锋片落在粗铁上。

没有火花。

炉膛里的暗红却向前爬了一寸。

阮青禾按下风箱。火眼在灰底张开，热气贴着铁条升起。沈燧用左手翻动粗铁，右手五指仍压着黑铁锋片，不让它滑开。铁条渐渐发红，原本僵硬的折痕在热里软下来，像一条被重新唤醒的旧伤。

门外又是一声巨响。

“第一道封钉落完！”有人喊。

石门的震动传进侧炉，炉顶的灰簌簌落下。伤者在风道里闷哼，额头受伤的矿工回头看了一眼，立刻把身体挡到低梁下，替他们托住一块松动的石砖。

沈燧把粗铁从火眼里拖出来。

红铁刚离开炉膛，冷风便在表面结起一层黑皮。他抡起旁边的废锤，第一下砸在折痕旁边。

沉闷的声音在侧炉里炸开。

第二下，粗铁下陷。

第三下，黑铁锋片被压进红铁中央，像一线暗夜落入熔红的肉里。

沈燧的右臂突然往下一沉。黑色裂痕里传来一股向前的拉力，细而固执，不再寻找石壁，也不再顶住石梁，只沿着铁条那道旧裂痕往前走。

他顺着它落锤。

一下。

两下。

每一次落下，裂痕便向铁条的另一端延伸。粗铁没有变得锋利，反而在锤击中不断变薄，边缘被挤出参差的黑口。它不像一柄刀，也不像一柄完整的镐，更像一块被谁从路上撬下来、还没来得及磨平的铁。

“它想做什么？”阮青禾问。

沈燧抬眼看向侧炉后方。

那里是石墙。

石墙后有风。

“往前。”

阮青禾顺着他的视线看去，脸色变了：“那面墙后是检修道，但已经被封炉砖堵死。”

“能不能开？”

“用你现在这东西？”

沈燧没有回答，抬锤砸下最后一下。

红铁上的黑线骤然亮了一瞬。

侧炉里的火眼随之收缩，所有热意都朝那枚粗糙器胚聚过去。黑铁锋片彻底沉进铁身，留下了一道歪斜的刃口。沈燧伸手握住它，铁柄没有完整的柄，只有一段尚未冷却的粗铁从掌中探出，刃面微微向前弯着，像一条被石头压住仍不肯停下的路。

他握紧了。

掌心只剩下空洞的疼。

没有新的锋力涌入身体，也没有灵气在丹田里聚成火。可那件东西在他手里稳住了，像某个已经完成一半的动作，终于找到了可以继续落下的位置。

阮青禾看着器身上的黑线：“它还没成。”

“够开一条路。”

“外面还有人。”

“先开。”

沈燧走到侧炉后的石墙前。

此时，第一道封钉彻底钉死了石门。门内的赤光被压成三条细线，裴照川的声音从缝里传来。

“回收队，确认炉火位置。封住前后两道矿门。任何人不得离开。”

沈燧把裂路器抵在石墙上。

墙面很厚，旧砖之间没有一点缝。他闭了闭眼，右臂的黑裂痕像一串冷却的火星，从肩下慢慢收向手腕。器身里的黑线也随之亮起来。

他不知道这一次该落在哪里。

但风从墙后吹来。

风指向一处被废砖压住的空腔，那里有极轻的回声，仿佛很久以前有人在墙后推过一扇门，门没有打开，手却一直没有收回。

沈燧抬起裂路器。

阮青禾忽然说：“左下，两寸。那是旧检修缝，不是承重墙。”

他立刻转腕。

裂路器落下。

没有金铁交击的响声。

石墙先在刃口下陷进去，随后，一道细黑的裂线沿着旧砖缝横开。裂线从沈燧手边向两侧爬，穿过半塌的炉壁，最后在墙中央停住。下一刻，墙后的冷风猛地冲出来，带着潮湿的灰味，把侧炉里的热气吹得向后翻卷。

“走！”沈燧说。

额头受伤的矿工先钻进裂隙，进去后立刻回身接住伤者。两个人抬着压伤小腿的矿工，胸口受伤的人扶着墙跟在后面。裂口只有一人肩宽，伤者的衣服被砖边刮破，血又渗了出来。

“别停。”沈燧压低声音，“进去再喘。”

最后一个矿工刚跨过裂缝，裴照川便看见了那道黑线。

石门外，回收队的封锁符正在门框上成形。裴照川抬起手，原本准备落下的第二道封钉停在半空。

他看着石墙内侧裂开的缝。

又看向沈燧手里的粗铁。

“不是断镐。”他说。

旁边的回收弟子问：“炉监？”

“断镐的锋力已经耗尽。”

裴照川的目光落在那道裂隙上。裂缝正在缓慢收拢，石粉一层层落下，却没有立刻合死。那件粗糙器物还在沈燧手里，刃面的黑线随着裂缝一明一灭。

“他把残响铸进去了。”裴照川说。

那名弟子迟疑：“要不要追入？”

裴照川没有立即回答。

裂隙太窄，里面有侧炉余火，石墙又刚被从内侧撕开。若强行挤入，回收队会被迫排成一线；一旦炉火倒灌，前面的人连退路都没有。

他抬手压下封钉。

“停止追入。”

“可是异常器物——”

“从前后两端封住废窟。把内侧裂隙列为二级回收口，等火势稳定再拆。”

他在回收册上划下一笔。

“沈燧，失控器修。器物与活物分列追收。”

侧炉里，沈燧听不清每一个字，只听见门外的脚步退开，又有更多符纸贴上石门。前方的冷风很快被一层薄薄的红光染上颜色。

“他不进来了。”阮青禾说。

“他在封前面。”

她把符灯往前举。

裂隙后的检修道比侧炉更窄，地面向下斜去。两侧石壁上留着旧风槽，槽里没有火，却有一股越来越热的气息从深处涌来。伤者被放在一处稍宽的凹地，能动的矿工围着他们重新包扎。额头受伤的人把最后一截干净布条递给压伤小腿的同伴，手指抖得厉害。

“这边不是出口。”他说。

“我知道。”阮青禾答。

她走到右侧石墙前，抹去一层灰。

灰下露出一幅烧黑的旧图。

图上画着侧炉、检修道和更深处的一口圆形炉心。原本连接炉心的线已经断了大半，只剩几段暗红色的痕迹，在灰尘里慢慢发亮。最靠近他们的那一段红线，正从侧炉底部向外爬。

沈燧伸手碰了一下石墙。

掌心的空痛还在。

墙后的炉心没有回应他的手，却让那条红线突然亮了起来。

轰——

热浪从检修道深处冲出。

它不是一阵散乱的火，而是一股沿着旧炉路奔行的回火。石壁上的黑灰被整个掀起，红色从图上的断线里流出来，转眼逼到众人脚边。最前面的矿工抱起伤者往后退，裂隙外的侧炉也在同一刻发出坍塌声。

“回去！”有人喊。

可身后的第一道裂隙正在合拢。

更远处，裴照川的封锁符一张接一张亮起。红光透过石缝，像把他们刚打开的路重新钉在黑暗里。

沈燧把裂路器横在身前。

火流撞上器身，粗铁表面立刻烧红。热意顺着柄端冲进他的右手，掌骨的空洞疼得发麻。他咬住牙，器物却没有像石墙那样裂开。它能切石，能撕开封钉，不能挡住迎面灌来的炉火。

阮青禾已经看清了前方。

在旧图标出的炉心入口处，三枚细薄的封钉交错钉在一扇下沉的石门上。那扇门不是挡住火流，而是把火流锁在检修道里。封钉一断，门后的侧道便会打开；若不斩断，回火会把他们连同伤者一起烧回侧炉。

“左前！”阮青禾喊，“沿第一道裂线过去，门下有三枚薄封钉！”

沈燧看了一眼那扇门。

火已经卷到他的靴面。

“能过去吗？”他问。

“只能一次！”

“够了。”

他回身对矿工们抬起左手。

“能走的先过去。伤者在中间。”

“那你呢？”

“开门。”

额头受伤的矿工没有再劝。他和另一个人一人托住伤者的肩，一人抬起伤腿，转身冲向石门。胸口受伤的矿工跟在后面，咳嗽声被热浪撕碎，却没有停。

火流越来越近。

沈燧沿着刚才的裂隙往前踏了一步。石墙上的裂纹还在收缩，碎砖从两侧挤下来，第一道路只能再撑几息。阮青禾站在门边，手指按着旧图，替他指向门下那三点微弱的白光。

“第二道，不要劈门心！”她说，“左下，贴着旧缝切！”

沈燧抬起裂路器。

火光把他的右臂照得发黑。那一道道裂痕从腕上爬到肩下，像一条条已经冷却的河。他的掌心没有锋片，只有被剜空后的痛；器物却在他手中发出低沉的震动，仿佛里面那道未完的动作终于找到了另一处需要裂开的地方。

他把刃口贴上门下。

第一枚薄封钉露出半截。

裂路器落下。

黑线从器身窜到刃口，沿着旧裂缝一闪而过。第一枚封钉没有断，先是向内弯折，随即从根部裂开。第二枚钉在火流里发出尖鸣，沈燧的手腕被震得向后一偏，刃口擦过石门，切出一道斜痕。

阮青禾喊：“再往下！”

沈燧压住手腕，第二次敲动裂路器。

这一击比第一次更沉。

薄封钉从中间断开，门后的火声陡然一空。石门向内塌下一寸，紧接着，一道只容一人侧身通过的黑色裂隙从门底向上拉开。冷风从里面涌出，和灼热的回火撞在一起，发出一声长长的嘶响。

“过！”阮青禾推了最后一个矿工一把。

众人拖着伤者挤入侧道。

火流擦过沈燧的背。他的衣角瞬间卷焦，皮肤却只被热气烫出一层刺痛。他没有回头，抬脚踏进裂隙。裂路器的刃口还贴着第三枚薄封钉，最后一枚钉在他身后断成两截，半扇石门轰然落下，把回火截在门外。

落门的力量震得他右臂发麻。

他握住裂路器，没有松手。

第三枚封钉的黑色残片滚到脚边，外面传来裴照川短促的命令。

“前口封死。”

另一边立刻有人回应：“后口也封。”

“所有回收队退到窟外，封锁炼器窟。”

裴照川没有再试着追入。

他已经看见了两道裂隙。

第一道从石墙里撕开，第二道斩断了薄封钉。两次动作都不是断镐最后残留的回光。那件粗铁仍在沈燧手里，刃面虽被烧红，却没有崩散。

门内的矿工也看见了。

没人再问该往哪边走。阮青禾用符灯照着旧图，最前面的矿工照着她的手势辨认风槽；后面的人轮流抬伤者，胸口受伤的那人已经咳不出声，仍用肩膀顶住低梁，让其他人先通过。刚才还只是在沈燧示意下挪动的队伍，此刻已经开始彼此接手。

沈燧走在最后。

他每走一步，右掌都像少了一块骨头。黑色裂痕停在肩下，没有继续向上，也没有消失。裂路器的热意顺着掌心传来，粗糙的铁柄硌着伤口，提醒他这东西还在。

侧道尽头没有天光。

只有更深的红。

阮青禾把旧图摊在石地上，图上的圆形炉心已经亮了大半。那几道原本断开的路线，正一寸寸接上侧炉和检修道。火从炉心向外走，沿着他们刚才切开的两道裂隙回流，像有人在黑暗里重新铺一条燃烧的路。

“这不是出口。”她说。

沈燧看向图上那口炉心。

“我知道。”

“裂路器切不了火。”

“也知道。”

前方的石壁忽然鼓起一线红光。

热流从缝里挤出来，吹动了符灯的火焰。伤者被矿工们护在身后，所有人的影子都被拉向更深处。外面，裴照川的封锁符一枚枚亮着，把废窟的出口封成了没有缝隙的黑门。

沈燧把裂路器垂在身侧。

器身上的黑线还在发热，却没有替他挡住那股火。

他抬起左手，示意队伍继续往后退，直到伤者靠住石壁。然后他转回身，站在那条逐渐亮起的红线上。

炉心深处传来一声低沉的回响。

不像爆裂。

更像一座已经熄了很久的炉，在最后一口气里，把火朝下一座炉推去。

# 章节事实摘要

石门合拢后，裴照川率回收队从后方逼近，并以封锁符将活人与黑铁锋片一并列为回收物。沈燧在阮青禾辨认旧标记后，带伤者进入废弃侧炉，以粗铁、残火和掌心锋片铸成裂路器。器物两次开裂，分别劈开石壁、切断薄封钉，队伍进入侧道；裴照川确认其可重复驱动，改令封锁废窟。窟心回火逼近，沈燧只能带着新器继续面对未完成的传火。
