# Proposed Persistent Canon

- 闻野舟能在接触冲撞中的异兽时，短暂削去其冲势中最凶猛的一截，使其撞击偏转；无法停止整体冲势，使用会剧烈牵动右肩。
- 闻野舟右肩伤势加重，右臂暂时无法抬起，持续限制搬运、推车和拽缰。
- 白角部已围住商队，明确追踪商队后方藏匿的某件东西。
- 商队后方驮车受撞裂开，但车阵未被冲散；伤驮兽已被闻野舟拉回车阵内侧。
- 边军从空货车底搜出一名满身泥血、抱着染血包裹的陌生男人；包裹内传出幼兽般的尖利叫声。
- 顾晚禾与闻野舟仍处于亲近但有冲突的关系；她承认他救下车阵，但坚持商队损失必须事后清算。

# Proposed Chapter Summary

白角部冲撞商队后方，闻野舟再次触发削弱兽性冲势的能力，使白角兽撞偏，借力救回伤驮兽并稳住车阵，但右肩伤势加重。白角部随即包围商队，边军搜车时拖出一名藏在空货车底的泥血男人，并发现一只传出幼叫的染血包裹。
