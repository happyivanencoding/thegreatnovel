## 复核修正｜2026-08-27

后续对真实 runtime 与独立 Steward 再核后，需要修正本文一处归因：**Chapter 4 不能简单归结为“Curator 看见完整 World 后删掉白角部背景”。** 本实验 runner 没有经过产品 `/api/prompt` 已有的 World→Curator 小型世界投影；而当时 production 投影本身又被定义成“0—1 个生活性点缀”，不是按当前章相关性提供 Reader Orientation。因此更准确的 earliest-layer 排序是：

1. **World 缺口**：当前 World 已有猎墙、普通生活、猎阶和荒原部族等事实，但没有明确“普通人怎样安全跨越聚落 / 商队为什么是外部世界入口”这类移动现实。
2. **Outline 调度缺口**：已有安全 / 社会事实没有被明确安排在开篇；白角部第一次真正影响选择时，也没有调度少量公共背景进入正文。
3. **更深的结构问题是 Approved World Vision 没有进入 ChapterContextPacket**：章节 Runtime 只把 Outline 生成的 `BOOK §2` 摘要当世界输入，再由 API 外围附加一个装饰性的 World→Curator side channel；这使 Curator 实际在“二次压缩世界 + 启发式补片”上工作。正确方向不是继续调 selector，而是让 Approved World Vision 成为章节期一等 `WORLD AUTHORITY`，由 Outline 排程释放、Curator bounded prefetch。
4. **Primary 残余**：Chapter 4 Director 已经很干净，停车、排车、绑缰等决定后的普通实施仍被正文自行扩写，这一点仍然成立。

同时，本文后文举出的“白角部长期与王朝交易/冲突”“整支部族迁徙通常意味着什么”等更具体说法，若当前 World 没有明确批准，就只能作为实验假设，不能直接交给 Writer。稳定结构应是：**Approved World Vision 提供事实 → Outline 把当前要释放的具体事实写进 `具体剧情` → Chapter Runtime 从 `WORLD AUTHORITY` bounded prefetch → Curator 保留/压缩 → Primary 表达；未知仍保持未知。**

## 一、总判断

**这一版比上一版又明显进步。** `State Advance After Proof` 与 `Reader Ruler` 已经真实改善正文：第二章不再用一整章反复验证第一次能力高光，第三章也更快完成“留下还是南行”的选择，第五章重新出现第二次真正的 Power payoff。

但新问题也因此暴露得更清楚：

> **系统现在更会“删掉不该解释的东西”，却还不够会“在最需要的时候主动解释值得解释的东西”。**

当前最主要的两个问题正是用户指出的：

1. **第一章世界进入过于突兀。** 读者一上来就面对猎市、护肩、顾晚禾、二阶异兽、无阶等信息，却还不知道这是一个怎样的世界、猎市在这里意味着什么、闻野舟为什么困在这里、商队为什么是他离开当前生活的重要道路。
2. **第四章明显偏慢，而且浪费了一个极好的世界介绍窗口。** 白角部第一次真正进入故事，本来最适合顺势解释“白角部是谁、荒原部族与王朝/猎手世界是什么关系、为什么一次迁徙足以让边军封路”；正文却把大量篇幅花在三排停车、药车位置、缰绳、推车、水囊以及闻野舟与顾晚禾反复争论“该不该留下”。

和顶级男频相比，这一版已经开始有正确的爽点和推进速度，但仍缺一种非常重要的能力：

> **用短而直接的旁白，在动作之间不断给读者补世界地图、力量常识、身份常识和价值常识。**

不是百科式设定说明，而是**Reader Orientation**：读者每进入一个新场景、新势力、新地区、新层级时，都顺手多懂一点这个世界。

## 二、本轮修改真正成功的部分

### 1. 第二章的 Result Stop 已经明显成功

上一版第二章最大问题是：

> 高光已经发生 → 斧痕证明 → 木栏证明 → 路人证明 → 老猎手证明 → 桑照再次询问 → 终于复测。

这一版第二章只保留：

> 一次现场复述 → 桑照检查落点 → 一次“二阶对无阶不该这样”的校准 → 直接给限期入场牌 → 顾晚禾提出三日后南行。

这是实质进步。

新版本 Chapter 2 文件约 4.5KB，而上一版约 12.1KB；减少的主要不是故事，而是重复置信度。

这说明当前原则：

> **Proof once → Calibrate once → Consequence immediately**

是有效的，应保护。

### 2. 第三章也明显更紧

闻野舟没有再花一整章反复论证“修具场更稳、顾晚禾会走、自己为什么想走”。

他较早就说：

> “我跟你走。”

后面三日准备被压缩，商队直接出发，随后边军封路。

这符合：

> **Choice → Consequence。**

人物选择仍然成立，但故事不再停留在“证明这个选择符合他的人设”。

### 3. 第五章重新出现第二次 Power payoff

闻野舟再次面对白角兽冲击时，不是重复第一章的猎市事故，而是在：

- 已经选择相信边军；
- 商队被封锁；
- 顾晚禾被卡在后方；
- 白角部正在逼近；

这个新的世界冲突里再次使用能力。

他让白角兽最凶的一截冲势缺掉，再借力调整驮车和顾晚禾的位置。

这是正确的 Core Fantasy recurrence。

### 4. Story Program 的主人公升格轨迹也更健康

本版不再急着让闻野舟每个阶段都升猎阶。

已经出现：

> 无阶杂工 → 桑照记住名字 → 获得限期入口 → 主动离开 → 白角部事件 → 二阶猎手 → 公开越级但不升阶 → 宗门开始私下打听 → 蜕壳城内层入口 → 更深世界与新能力。

这比单纯：

> 无阶 → 三阶 → 五阶 → 七阶 → 八阶

更接近真正的男频“人不断进入过去没资格进入的世界”。

因此本轮 Pace / Ruler / Ascension 修改总体仍然应判 **DIRECTIONAL PASS，值得保留**。

## 三、第一章的问题：不是节奏慢，而是 Reader Orientation 不够

第一章动作节奏本身很好。

开头很快进入：

> 猎市 → 护肩 → 顾晚禾 → 二阶异兽挣笼 → 闻野舟迎上去 → 第一次剥走落势。

问题在于它**过快假设读者已经熟悉世界**。

第一段就出现“猎市”“试戴处”“猎手”；很快又出现“二阶异兽”“无阶”。

读者虽然能理解眼前动作，却还不知道：

- 这个世界为什么到处是异兽？
- 城镇和野外是什么关系？
- 猎手在社会里是什么位置？
- 猎市是普通集市，还是这个世界最重要的资源/力量交易场？
- 一个没有猎阶的人通常能过什么生活？
- 闻野舟为什么这么在意被猎手看见？

这些信息不需要全部讲，但第一章至少应该让读者形成一个**粗糙但正确的世界模型**。

例如只需要两三段非常朴素的旁白，就可以建立：

> 城墙之外大部分地方都有异兽活动，普通人不会单独离开猎墙。真正能进山、杀兽、把心核带回来的人叫猎手。
>
> 猎市就是这些人卖兽皮、心核、兵器和雇人的地方。对闻野舟这种没有猎阶的人来说，想被真正的猎手看见，比在普通皮料铺里做十件活都更接近外面的世界。

这不是“设定倾倒”。

这是**Orientation**。

读者一旦知道这两件事，后面的护肩、桑照、入场牌、猎阶都会自动变得更有价值。

## 四、“商队为什么重要”目前确实没有被写清

这个问题不是读者漏看了，而是正文没有真正给出完整答案。

目前能看见的是：

- 闻野舟想离开小镇；
- 顾晚禾三日后跟商队南行；
- 他选择跟她走。

Human 层能解释：

> 他被顾晚禾和移动生活吸引。

但**世界层没有告诉读者商队是什么意义上的道路**。

World Vision 目前只明确：

> 城镇外有猎墙，村庄夜里封门，异兽会改变活动路线。

却没有明确写：

- 普通无阶者如何安全跨城；
- 商队在猎墙之间承担什么作用；
- 为什么一个无阶青年想去别的城市时，跟商队走是自然选择；
- 南边有什么比当前城镇更大的世界入口。

因此闻野舟第三章跟商队走，人物动机是成立的，但**世界意义不足**。

读者感受到的是：

> “他跟顾晚禾走了。”

而不是：

> “他第一次真正离开猎墙内的生活，进入只有猎队、商队和有战力的人才能长期走的外部世界。”

后者才有 World Entry 的感觉。

这是一个上游信息缺口，不建议让 Writer 临时发明完整交通制度。正确方向是：当 Story Program 把商队选成早期重要世界入口时，下游必须获得少量已批准的**普通移动 / 城镇与荒野关系**事实，足够解释这条路为什么重要。

## 五、第四章的问题非常明显：它是前五章唯一真正重新变慢的章节

前五章文件体量大致为：

- Chapter 1：约 5.0KB
- Chapter 2：约 4.5KB
- Chapter 3：约 4.7KB
- **Chapter 4：约 10.5KB**
- Chapter 5：约 6.0KB

第四章几乎是第二、三章的两倍多。

问题并不是它发生了更多值得看的故事。

它真正的重要状态只有：

1. 商队被边军封路；
2. 白角部正在逼近，但不像攻城，更像在追某个被带走的东西；
3. 闻野舟暂时选择相信陶遂；
4. 顾晚禾因此不满；
5. 白角部夜里逼近，边军开始查车。

这些内容完全成立。

但中间正文展开了大量：

- 三排停车；
- 药车放中间；
- 驮兽拴车后；
- 推空车；
- 拽缰绳；
- 车轮陷土；
- 水囊；
- 谁去找水；
- 顾晚禾再次解释药、草料、损失；
- 闻野舟再次解释为什么不赌；
- 两人再次确认谁承担损失。

这就是典型：

> **决定已经做完，普通实施继续被完整展开。**

## 六、第四章的最早责任已经下移：这次主要不是 Outline 在规划施工

这一点和之前几版有区别。

Chapter 4 Director 的合同其实很干净：

> 封路 → 观察白角部 → 闻野舟选择相信陶遂 → 商队被固定 → 顾晚禾不满 → 夜里白角部逼近。

Director 并没有要求：

> 三排停车、药车居中、如何推车、如何绑牲口、水囊如何分。

Curator 也明确提醒：

> 本章重点是一次具体判断及其后果。

因此第四章大量实施细节主要发生在 **Primary realization**。

这意味着上一轮“Outline 先把低价值流程规划出来”的问题已经明显改善；现在残留的是：

> **Primary 看到一个需要执行的决定，仍容易把第一次实施过程完整写出来。**

这是进步后的更下游问题。

## 七、但第四章还有一个更重要的问题：Curator 把高价值 World Context 丢掉了

这比“Primary 写得长”更值得注意。

World Vision 明明已经存在这些信息：

> 荒原部族有不同于宗门的身体训练和驯兽方法；有些部族与特定异兽共同狩猎；它们与王朝既有交易也有长期冲突。

并且白角部这条世界事件已经明确：

> 白角部正在南迁；乌妲说他们不是来攻城，而是在追一头被人类猎队掳走的幼年王种；边军把迁徙视作入侵。

这正是第四章最应该让读者知道的东西。

但是 Chapter 4 Curator 给 Writer 的 `Relevant World Rules` 只有：

- 白角部迁徙期间边军禁行；
- 白角部没有立即攻城；
- 他们正在追某个被人类带走的东西；
- 具体目标未知。

于是 Writer 知道：

> **不能揭晓幼兽。**

却不知道应该告诉读者：

> **白角部究竟是什么样的存在。**

这产生了一个很典型的信息分配失衡：

> **低价值的车队操作信息可以自由生成；高价值的世界介绍因为 Curator 没投影，Writer 反而不能安全写。**

所以第四章不只是 prose 问题，也有一个 **Curator context selection** 问题。

## 八、你说“第四章明明是解释白角部的绝好时机”，我完全同意

而且这就是顶级男频常用的介绍方式。

不是第一章把所有势力列表讲完。

而是：

> **势力第一次真正挡住主角的路时，再告诉读者它是谁。**

第四章里陶遂一句：

> “白角部正在迁徙。”

后面完全可以顺势插一两段：

> 白角部不是一支普通猎队，也不是荒野里临时聚起来的流民。他们是长期生活在荒原上的部族，很多人不靠宗门的融合方式修炼，而是跟特定异兽共同狩猎。边军和他们打过，也做过生意；真正麻烦的是，一旦白角部整族换路，通常意味着荒原上有什么东西逼得他们不得不走。
>
> 所以南关封路并不稀奇。奇怪的是，这一次白角部没有朝关口来。

然后回到现场：

> 它们在追车辙。

这段信息会让“追某个东西”立刻更有悬念。

而不是只让读者看到一堆白色影子，不知道白角部到底是兽群、人类部落、半兽人、军队还是宗门。

## 九、一个新的系统判断：Exposition 不能被统一当成坏东西

TGN 过去几轮为了反 AI 解释、反设定倾倒、反程序化，越来越强调：

> 先动作、先结果、只解释当前选择需要的内容。

这个方向本身是对的。

但这一版说明存在**过度纠偏**风险。

必须区分两种解释：

### A. 低价值解释——应该压缩

例如：

- 已经知道能力成功，再换证据证明；
- 车怎么排、绳怎么绑；
- 一个选择为什么符合人物性格反复说；
- 已经发生的结果重复总结。

这类解释应该 Result Stop。

### B. 高价值 Orientation——应该主动释放

例如：

- 这个世界为什么普通人怕异兽；
- 猎手为什么有分量；
- 猎市为什么值得主角来；
- 商队为什么是普通人离开一座城的重要道路；
- 白角部是什么；
- 为什么部族迁徙会让边军封路；
- 桑照在猎榜是什么分量；
- 一个王种心核为什么所有人都抢。

这不是“水”。

它是在建立：

> **Power / Status / Value / World / Expectation。**

这种信息甚至本身就是爽点和期待。

## 十、建议形成的更深原则：Context-Triggered Exposition

不建议新增一个“每章必须有世界介绍段落”的字段或 Hard Gate。

也不建议回到开篇先写三页世界史。

更好的原则是：

> **当一个新地点、势力、身份、资源、力量层或生活方式第一次真正影响主角选择时，允许并鼓励使用 1—3 个短的直接旁白段落，回答读者此刻最自然会问的“它是什么、为什么重要、普通人通常怎么看它”。解释完立刻回到现场。**

也就是：

> **Action creates the question → Exposition answers just enough → Action continues.**

这比单纯“show, don't tell”更适合长篇网文。

顶级男频大量依赖这种直接旁白来压缩世界信息。

---

## 十一、Opening 应有“最低世界定向”，不只是“最低规则理解”

当前 `World Model Release` 主要关心：

- 主角在哪一层；
- 强者能做到什么；
- 当前东西值在哪里；
- 核心优势边界是什么。

这些都对。

但第一章还缺一个更基础的问题：

> **读者现在身处怎样的世界和生活位置？**

建议未来开篇至少自然建立三个很粗的坐标：

1. **安全坐标**：城墙内 / 猎墙外分别意味着什么；
2. **社会坐标**：猎手与无阶普通人的差别；
3. **移动 / 世界坐标**：主角当前生活有多小，离开这里通常意味着什么。

不需要地图，不需要百科。

两三段就够。

这一版第一章已经有第2项的一部分：

> 无阶正面接二阶必然重伤。

但第1项与第3项明显不足。

---

## 十二、商队这条线应该承担“第一次世界打开”的情绪

现在第三章商队出发写得比较平：

> 车排开 → 上车 → 出东门 → 半日后封路。

实际上这里应该是一个很好的 **World Entry payoff**。

闻野舟刚从：

> 猎墙内的皮料杂工

变成：

> 第一次带着桑照给的入口牌，跟商队真正离开熟悉城镇的人。

哪怕只加少量介绍：

> 猎墙外的道路由猎队和商队维持；没有猎阶的人很少独自远行；每跨过一段安全路，外面的异兽、宗门、部族和城镇都会换一种活法。

读者就会感到：

> **“地图真的打开了。”**

这也会让第四章“刚出门就撞上白角部迁徙”更有重量。

---

## 十三、第五章总体是好的

第五章重新回到紧凑状态：

> 白角部逼近 → 商队缺口 → 顾晚禾被困 → 白角兽冲击 → 闻野舟第二次剥取 → 陶遂重新估价 → 查车 → 染血包裹 → 幼叫。

相比第四章，状态变化明显更多。

尤其章末：

> 包裹里传出幼叫。

是很好的下一章推动力。

它说明系统并没有整体失去节奏能力，问题集中在：

> **低冲突过渡章如何分配篇幅。**

这种章节最容易让 Writer 在“没有战斗可以写”的地方，用实施与对白把长度补满。

正确替代物不应该是更多程序细节，而应该是：

- 世界介绍；
- 强弱 / 价值 / 身份尺度；
- 新人物的分量；
- 新地点的生活差异；
- 旧事实的新解释；
- 未来值得想要的东西。

---

## 十四、和顶级男频相比，目前最大的差距已经进一步收窄

前两版的差距是：

> 核心幻想弱 / 世界太玄 / 机制太复杂 / 支撑逻辑抢戏。

这一版已经不再是这些为主。

现在更像是：

> **“故事骨架已经对了，但作者旁白的调度还不像成熟商业网文。”**

顶级男频通常非常敢直接告诉读者：

> 这个人有多强；
> 这个地方是什么；
> 这个势力为什么没人愿意惹；
> 这个东西到底值多少；
> 主角以前为什么没资格；
> 外面的世界比现在大多少。

它们不会把所有信息都藏在对话、动作、暗示里。

相反，**直接叙述是一种压缩器。**

一段好旁白可以替代：

- 五轮问答；
- 三次观察；
- 一整套操作流程；
- 十段旁观者猜测。

TGN 下一步需要学的不是“少解释”，而是：

> **解释值得解释的东西，并用解释压缩不值得展开的东西。**

---

## 十五、根因排序

### 第一层：World / Story Collision 的 Reader Orientation 信息不足

World Vision 对异兽、猎阶、部族有基础，但没有给出足够的：

- 普通人的跨城移动；
- 商队在猎墙世界中的意义；
- 当前城镇在更大世界的位置。

当 Story Program 把“随商队南行”选成重大 World Entry 时，这些信息没有同步变成可释放的 reader-facing facts。

### 第二层：Curator 对首次新势力的上下文投影过窄

第四章第一次真正碰到白角部，但 Curator 只投影当前战术事实，没有投影 World 已存在的荒原部族背景。

因此 Writer 没有高价值世界信息可写。

### 第三层：Primary 在低动作章节仍有实施扩写倾向

当 Director 只给：

> 协助车队退入封锁线

Primary 会自然扩成：

> 三排、药车、驮兽、绳索、推车、水囊。

这仍是当前 prose-level residual risk。

### 第四层：当前 World Model Release 对“Opening Orientation”定义偏窄

它目前主要强调规则、力量、价值与身份坐标，但没有充分强调：

> **开篇还要让读者知道“这里是什么样的生活世界”。**

这是本轮新暴露的系统缺口。

---

## 十六、应保护的部分

1. **State Advance After Proof**：明确有效，不回退。
2. **Ruler = Compression**：明确有效，不回退。
3. **Choice → Consequence**：第三章已经证明有效。
4. **Plot Pace ≠ Tier Pace**：Story Program 明显健康。
5. **主人公连续升格**：长期结构比上一版更像真正成长长篇。
6. `异兽 → 心核 → 兽性 → 猎阶` 世界体系。
7. 闻野舟核心 Power Asymmetry。
8. 顾晚禾 / 桑照 / 乌妲等 Human 与关系权威。
9. 第五章“第二次 Power payoff + 幼叫 reveal”的推进方式。

不能因为第1/4章的 onboarding 问题把这些一起推倒。

---

## 十七、优先修复方向

如果下一步进入 production 修复，我建议顺序是：

### 1. 扩展现有 World Model Release，而不是新增 Agent

从：

> 规则 / 强弱 / 价值 / 身份最低坐标

补成：

> **规则坐标 + 最低世界定向。**

尤其开篇要让读者知道：

> 我在哪里、这里的人怎样活、谁有力量、外面的世界如何进入。

### 2. 首次出现重要势力 / 地点时，Curator 投影 2—4 条“Reader Orientation Facts”

不新增永久 Schema；可以并入现有 `Relevant World Rules / Reader-Facing Language`。

例如白角部首次成为当前冲突主体时，应带入：

- 他们属于荒原部族；
- 与王朝有长期冲突与交易；
- 有不同于宗门的身体训练 / 异兽关系；
- 整族迁徙为什么会让边军紧张。

只投当前场景真正有用的几条。

### 3. Primary：决定完成后，实施默认一句带过

例如第四章：

> 商队被迫把车缩进北侧空地，药和牲口都被压在边军枪阵内。

一句就够。

不用再写完整停车过程。

### 4. 允许短直接旁白成为高价值信息通道

不是把所有设定都改成 Dialogue。

顶级男频非常常用：

> “要知道……”
> “在这一带……”
> “对白角部，边军最忌惮的从来不是……”
> “普通人若想离开猎墙……”

这类作者旁白。

TGN 应允许并善用。

---

## 十八、最终主观结论

**这一本已经比上一版更接近成熟男频。** 上一轮的核心修复——Result Stop、Reader Ruler、Choice → Consequence、主人公升格——都已经真实生效，不应该因为新问题而回退。

现在最值得解决的新问题是：

> **TGN 已经学会“别在结果后面废话”，但还没有完全学会“空出来的篇幅应该拿什么填”。**

答案不是再塞事件，也不是再塞操作细节。

更成熟的答案是：

> **在读者刚好产生问题的时候，用一小段清楚、直接、有分量的旁白，告诉他这个世界更多一点。**

第一章应该更早让读者知道：

> 这是一个猎墙之外遍布异兽、猎手掌握真正力量、猎市连接力量与普通生活的世界；闻野舟现在只是站在门外的人。

第三章商队出发时应该让读者知道：

> 这不是简单“跟顾晚禾坐车”，而是一个无阶青年第一次真正进入猎墙之外的道路。

第四章白角部出现时应该让读者知道：

> 他们是谁、为什么边军害怕、为什么这次迁徙不同寻常。

这样正文既不会回到百科，也不会只剩动作骨架。

**下一阶段的核心不是“更快”，而是“更会分配叙事注意力”：低价值实施更短，高价值世界信息更长。**
