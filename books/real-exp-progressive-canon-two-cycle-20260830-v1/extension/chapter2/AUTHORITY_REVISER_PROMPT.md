## Value-Preserving Relocation｜修事实不顺手磨掉高价值体验
- 修订对象首先是**错误事实、错误时点或错误因果**，不是它旁边已经成立的阅读满足。若一句/一小段的 Core Fantasy、关系反应、私人欲望、惊讶、Reward 或 Social Repricing 本身被 Authority 支持，只是挂在不合法时点/因果上，把最小的正确体验核迁到**同一事件最近的合法时点**，而不是整段删除。
- 这不是可选润色：Primary Draft 已经存在一个独特、高价值、且与错误机制可分离的 realization 时，最终稿必须保留一次它的语义价值，或者在内部确认该语义本身并不被 Authority 支持后才删除。**不能只因为要修掉错误机制，就让可合法保留的 Core Fantasy / Relationship / Payoff 记忆点同时消失。**
- **Sentence-level salvage**：准备删除含 Authority 冲突的段落时，先逐句区分。句子本身若不含冲突，只是因为所在时点/上下文错误而变得不合法，并且直接承载 Core Fantasy、Relationship、Desire、Payoff、Surprise 或 Social Repricing，优先把该句原样或最小改词迁到最近合法位置；不要把整段一起删。只有句子本身就是错误事实时才删除。若原句无法自然迁移，至少保留一次明确语义等价 realization。**Salvage 只保护这类高价值句本身，不保护它周围的报告、登记、路线、重复机制解释或普通实施；救出该句后，周围 process carrier 仍按 Attention Reallocation 正常压缩。**
- 例如：分开期间不能实时共享经验，但“我像多活了一段时间”这一 Core Fantasy 感受本身成立，则应在重新合并、经历合法回流之后保留一次；不能为了保住好句而继续保留错误机制。
- 只迁移可与错误机制明确分离、且已有 Authority / 当前事件支持的内容；句子本身若就是未授权事实则删除。迁移不得新增事件、改变顺序/结果、制造第二次 payoff，也不得借机润色周围正确正文。

# Reader-First Prose Contract

Reader-First 短投影：以可见对象、人物动作、现场结果和普通语言优先；新造术语先用场景成立，已通过动作成立的边界不重复解释；**已排程的公共世界常识以“普通读者不用推理就能复述规则”为清楚标准，环境暗示不能代替直接说明；隐藏原因与未来 reveal 继续未知。** 连续动作保持自然段，重大兑现先落地再写必要限制；重大结果需要时给相关人物一个短暂反应窗口，人物可以克制，但克制应表现为有反应后选择压住，不把情绪只写成状态总结；重大结果碰到核心欲望时，不要只写疼痛、策略或状态确认，保留一个可辨认但不强行命名的情绪倾向。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。

## AUTHORITY——按维度划分的事实与计划边界

权威规则按维度划分（不使用单条总排名）：
1. 已发生事实：CANON PROSE > CANON INDEX。CANON PROSE 是已批准的正式前文；已经发生事实的最高来源。CANON INDEX 是当前状态和最近摘要，是正式正文的压缩索引；与正式正文冲突时以正式正文为准。
2. 世界事实：WORLD AUTHORITY 是已批准 World Vision 的安全事实投影，负责世界规律、普通生活、力量正常值、社会现实、价值结构与公开知识边界；BOOK / PLAN 可以决定这些事实何时进入故事，但不得改写它们。named 大事件与未解谜底不在该投影中，仍服从已批准 Story / Plan 与未知边界。
3. 未来创作意图：BOOK CONTRACT > PLAN > OPTIONAL INSPIRATION。BOOK CONTRACT 决定长期故事方向、读者承诺和人物方向；PLAN 决定当前尚未发生的剧情；OPTIONAL INSPIRATION 不能覆盖以上任何权威。
4. 表达控制：PROSE PROFILE 只控制表达方式，不能修改已发生事实或未来计划，也不能改写 WORLD AUTHORITY。
5. 跨维度冲突：已发生事实不能被 BOOK CONTRACT 或 PLAN 覆盖；如果正文证明旧 BOOK CONTRACT 已经失效，保留已发生事实，不得自动修改 BOOK CONTRACT。世界事实不能被 BOOK / PLAN / Writer 临时改写。Curator 负责在 Curator Audit 中暴露会影响本章执行的明确冲突；Primary 不承担冲突报告或其它 pipeline bookkeeping，只服从已经投影出的有效事实与计划。

雨已经下了很多天。

陆家旧院那堵封墙被雨水泡得发黑，墙根不断往外渗泥。陆昭刚把门口两只装旧铜件的木箱往里拖，墙上便传来一声闷响。

裂缝从墙角一路窜到井口。

“退开！”

有人在隔壁院里喊了一声。下一刻，半面封墙向外塌倒，碎砖和泥水砸进旧井区狭窄的巷道。陆昭抬臂挡住飞溅的石屑，鞋底却在泥里一滑。

井口那边翻起一股浑水。

一块巴掌大的黑铁牌从水里冲出来，撞在井沿上，叮地弹进巷子。它沾着泥，边角却露出一线暗沉的金属光。

旧朝兵库钥牌。

陆昭心口猛地一紧。

旧朝留下的兵库钥物，哪怕只是残件，只要来源能说得明白，兵坊、收藏家，甚至城主府的人都会出钱。更何况这东西是从回影井里吐出来的。

他还没迈出第二步，一只手已经抢在前面。

那人从倒塌的墙边掠过，靴底踩碎一块青砖，五指直接抓向泥水里的钥牌。动作又快又稳，显然比陆昭这个纹阶4强得多。

纹阶1到6，都只是普通成年练家的范围。陆昭练到纹阶4，平日打雨猎、搬货、护住自己的摊子够用，碰上真正厉害的人，硬抢只会挨打。

可那枚钥牌正朝巷子尽头的排水沟滑去。

收货者的指尖已经快碰到它。

陆昭咬住牙，右手按向地上的积水。

钥牌在泥水里的影子被墙缝漏下的灰光拉得细长。陆昭盯住那团黑影，指节上的纹路骤然绷紧，像有一枚无形的钉子砸进了水面。

影子停住了。

正往前滑的钥牌也猛地一卡，边缘擦出一道刺耳的金属声，硬生生停在排水沟前。

收货者抓了个空，手指只捞起一把冷泥。

陆昭没等那人反应，扑过去一把攥住钥牌。黑铁牌冰得刺手，表面沾满泥浆，却沉甸甸地压在掌心里。

钉影撑不了多久。

可没有那一下，这枚钥牌不是滑进沟里，就是落进那人的手里。

收货者转过身，目光落到陆昭紧握的拳头上。

“拿出来。”他的声音不高，雨声却压不住里面的冷意。

陆昭喘了口气，左手已经拔出腰间的黑柄短刀。刀身不长，刃口却一直磨得很亮。他把刀横在两人之间，脚下踩住一块还算结实的石板。

收货者看了一眼短刀，又看了看正在继续开裂的封墙。

墙后传来木头断裂的声音。旧院里有人哭着喊箱子，几只装杂货的麻袋被泥水冲到巷口，转眼就湿透了。井沿的砖石往下塌，裂开的地面已经逼到两人脚边。

陆昭没接话。

“先搬东西！”陆昭朝屋里喊。

他把钥牌塞进贴身的内袋，抓起木箱一头就往高处拖。雨水顺着额角流进眼睛，巷子里全是砖石滚动和人喊人的声音。能搬的先搬，搬不动的只能看着被泥水泡烂。

陆昭把钥牌重新贴身收好，握住黑柄短刀，望向雨后的巷口。

等这里能走人，他得去旧物市。

先让真正识货的人看看，它到底值多少钱。

## PRIMARY DRAFT｜唯一待修订正文底稿

旧物市开在听雨城西边一条窄街上。

雨停了，街面还是湿的。两边棚布滴着水，摊主把压箱底的铜器、残刀、兽骨和旧朝钱币一件件摆出来，生怕晚了一步，客人就被隔壁截走。

陆昭没往最热闹的地方钻。

他沿着街边走，右手一直压着衣襟。那枚黑铁钥牌贴在内袋里，隔着湿衣服也能感觉到它的凉意。

柳棠的铺子在旧物市中段，招牌很小，写着“棠记辨物”。门口没摆花哨东西，只有一张长桌、一盏白瓷灯和几只上锁的木匣。

陆昭刚走到门前，里面便有人说：“要卖东西，先报来路。”

柳棠坐在桌后，手里拿着一支细长的铜针。她年纪不大，头发用木簪挽起，袖口收得很利落，指尖干净，像是刚洗过手。

陆昭进门，反手把门帘放下。

“看一件东西。”

柳棠抬眼看他。她先看见陆昭手臂上的伤，又看见他腰间的短刀，最后才落到他压着衣襟的右手上。

“看，还是卖？”

“先看。”

“规矩知道吗？”

“东西不离我手边。”陆昭把一张空木凳拖到桌旁坐下，“你能看，不能收。”

柳棠没露出不快，只把铜针放回盒里。

“拿出来。”

陆昭从内袋里摸出黑铁钥牌，没有递过去。他把钥牌平放在自己面前的桌角，手腕压住一半，另一半留给柳棠看。

钥牌擦得不算干净，缝里还嵌着些泥。半开的库门铸痕露在灯下，黑铁表面没有光，边缘却很硬。

柳棠原本只是随意扫了一眼，随后身体往前倾了些。

“翻过来。”

陆昭用两根手指夹住钥牌，自己翻面。

柳棠盯着背面的编号，停了片刻。

铺子外有人吆喝着收旧甲片，声音隔着门帘传进来。陆昭没催，他看见柳棠的手指抬起来，又停在半空，没有碰到钥牌。

“这串数，”她说，“你从哪儿弄来的？”

“你是辨物的，还是查人的？”

柳棠看了他一眼。

“我只问一句。”

“我也只答一句。”陆昭把钥牌往自己这边拖了半寸，“来路不卖。”

柳棠没有再问。她起身，从后面的木匣里取出一块绒布，又拿出一册厚账簿。账簿边角磨白了，翻页时有股旧纸味。

陆昭盯着她的动作。

“你要拿什么比？”

“城里那枚兵库钥牌的拓印。”

陆昭的手指微微收紧。

柳棠把账簿翻到中间，抽出夹在里面的一张薄纸。纸上拓着一块牌子的轮廓，库门铸痕和编号都清楚，只是边缘处被墨色压得发虚。

她将薄纸铺平，又把白瓷灯挪近。

“你自己压住。”

陆昭照做。

柳棠拿起铜针，先指向拓印上的库门铸痕，再指向陆昭手边的钥牌。

“这里有一道横纹。两块牌上都有。”

陆昭低头看去。

那道横纹很浅，正好藏在半开的库门中间，像铸造时留下的一点裂痕。若不是柳棠用针尖比着，他只会把它当成黑铁旧损。

“再看这个。”柳棠的铜针往下移，点在编号旁边。

陆昭把钥牌转正。

薄纸上的数字，和他这枚牌上的一模一样。

铺子里安静了一下。

陆昭抬头：“同一副模子铸出来的？”

“铸痕相同，编号也相同。”柳棠说得很慢，“至少它们看上去像是同一块牌。”

陆昭看着拓印，又看自己手里的黑铁牌。

城里那枚钥牌已经被人争过一轮。有人说它能开旧朝兵库，有人说它只是从废库里流出来的假货。陆昭原本只想让柳棠估个价，找个出钱干脆的买家，把这东西换成能握在手里的银铢。

现在，事情显然没那么简单了。

“哪一枚是真的？”他问。

柳棠没立刻回答。

她把铜针横在两块牌之间，目光从拓印移到钥牌上，又移回来。

“我分不出来。”

陆昭皱起眉。

柳棠继续道：“两块牌的铸痕和编号都对得上。要是其中一枚是假，做假的人连这种细痕都照出来了。要是两枚都是真的，我也不知道为什么会有两块同号的兵库钥牌。”

她合上账簿，声音压低了些。

“我不能替你断真伪。”

门帘忽然被人从外面掀开一角。

一个穿灰褂的伙计站在门口，先朝柳棠拱了拱手，随即把目光落到桌上。

陆昭手掌一翻，直接把钥牌扣住。

那伙计脚步顿住，脸上挤出笑。

“柳姑娘，兵坊那边让我来问一句。听说你这里有件旧朝兵库的东西？”

“听谁说的？”柳棠问。

伙计没答，只笑着看陆昭。

陆昭认得这种眼神。不是看一件旧物，是在看一笔还没落到谁手里的钱。

柳棠把账簿盖住：“我这里没有替兵坊收货的规矩。”

“兵坊出价不会低。”伙计说，“若真是那类东西，直接送过去，省得在街上惹麻烦。”

“谁说我要送？”陆昭开口。

伙计这才正眼看他。

“原来是陆家的小哥。那就更好说了。你把东西拿出来，咱们验一验，价钱总能商量。”

陆昭没松手。

“你们先把价写出来。”

伙计笑容淡了一点：“东西都没看见，怎么写？”

“那你回去问清楚再来。”

门口的人盯着他，像是想说什么。柳棠忽然把白瓷灯往前推了一寸，灯光正照在陆昭压着钥牌的手背上。

“这是棠记。”她说，“你若要谈买卖，明天带能做主的人来。现在出去。”

伙计看了看她，又看了看陆昭，最终还是放下门帘。

外面的脚步声没有立刻走远。

陆昭听得出来，那人站在铺外，还在同旁边摊主低声说话。

消息已经漏出去了。

柳棠坐回原处，手指在账簿封面上敲了两下。

“第一枚钥牌落到谁手里，外面早就传得乱七八糟。现在第二枚到了你手上，还是同铸痕、同编号。”她看着陆昭，“从今天起，你想悄悄卖掉，换钱离开旧物市，怕是做不到了。”

陆昭脸色不太好看。

他当然知道。

刚才那伙计来得太快。柳棠还没来得及把拓印收回去，兵坊的人就已经堵到了门口。旧物市里没有真正藏得住的秘密，尤其是能让兵坊掏钱的东西。

可他也不愿让柳棠把话说得像是自己已经没路。

“做不到低调卖，不等于只能便宜卖。”陆昭说。

柳棠抬起头。

陆昭把钥牌重新塞进内袋，扣好衣襟。

“你分不出真伪，但你已经看过。两枚同号的牌，谁也不能当成一件普通旧物来收。”他盯着柳棠，“兵坊要拿，收藏家要拿，城主府的人要看，他们就得先承认这东西值钱。”

柳棠望着他，忽然笑了一下。

“你胆子不小。”

“牌在我手里。”

“牌在你手里，麻烦也在你手里。”

“麻烦不能当饭吃。”陆昭站起身，“他们想要，就拿钱来谈。谁要是只想压价，谁就别看牌。”

柳棠没有阻止他，只从账簿里抽出那张拓印纸，折好收回袖中。

“你现在走出去，今晚就会有人盯着你。”

陆昭摸了摸腰间短刀：“那就让他们盯。”

“他们盯的不是你这个人，是你手里的牌。”柳棠说，“而且，他们会逼你先选一边。”

陆昭回头看她。

柳棠起身，走到门边，把门帘掀开一道缝。外面的旧物市仍在叫卖，几名穿兵坊短褂的人已经站到了街对面，像是在看摊上的旧刀，目光却不时扫向棠记。

“明天开市，我在这里摆一张公桌。”柳棠说，“把两枚钥牌放到众人眼前，谁有本事，谁来断真伪。兵坊、旧物行、城主府的人，都可以请。”

陆昭没有答应。

柳棠侧过脸，看向他。

“我会拿自己的招牌担保：今日所见，两枚钥牌同铸痕、同编号。我断不出真假，这句话也照样写出来。”

她停了停。

“你敢不敢拿你的牌上桌？”

街对面的兵坊伙计已经朝这边望过来。

陆昭站在门内，衣襟下的黑铁钥牌沉沉贴着胸口。

他知道，只要点头，这条街明天就会更热闹。

也更难走。
