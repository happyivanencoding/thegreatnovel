## Value-Preserving Relocation｜修事实不顺手磨掉高价值体验
- 修订对象首先是**错误事实、错误时点或错误因果**，不是它旁边已经成立的阅读满足。若一句/一小段的 Core Fantasy、关系反应、私人欲望、惊讶、Reward 或 Social Repricing 本身被 Authority 支持，只是挂在不合法时点/因果上，把最小的正确体验核迁到**同一事件最近的合法时点**，而不是整段删除。
- 这不是可选润色：Primary Draft 已经存在一个独特、高价值、且与错误机制可分离的 realization 时，最终稿必须保留一次它的语义价值，或者在内部确认该语义本身并不被 Authority 支持后才删除。**不能只因为要修掉错误机制，就让可合法保留的 Core Fantasy / Relationship / Payoff 记忆点同时消失。**
- **Sentence-level salvage**：准备删除含 Authority 冲突的段落时，先逐句区分。句子本身若不含冲突，只是因为所在时点/上下文错误而变得不合法，并且直接承载 Core Fantasy、Relationship、Desire、Payoff、Surprise 或 Social Repricing，优先把该句原样或最小改词迁到最近合法位置；不要把整段一起删。只有句子本身就是错误事实时才删除。若原句无法自然迁移，至少保留一次明确语义等价 realization。**Salvage 只保护这类高价值句本身，不保护它周围的报告、登记、路线、重复机制解释或普通实施；救出该句后，周围 process carrier 仍按 Attention Reallocation 正常压缩。**
- 例如：分开期间不能实时共享经验，但“我像多活了一段时间”这一 Core Fantasy 感受本身成立，则应在重新合并、经历合法回流之后保留一次；不能为了保住好句而继续保留错误机制。
- 只迁移可与错误机制明确分离、且已有 Authority / 当前事件支持的内容；句子本身若就是未授权事实则删除。迁移不得新增事件、改变顺序/结果、制造第二次 payoff，也不得借机润色周围正确正文。

# Reader-First Prose Contract

Reader-First 短投影：以可见对象、人物动作、现场结果和普通语言优先；新造术语先用场景成立，已通过动作成立的边界不重复解释；**已排程的公共世界常识以“普通读者不用推理就能复述规则”为清楚标准，环境暗示不能代替直接说明；隐藏原因与未来 reveal 继续未知。** 连续动作保持自然段，重大兑现先落地再写必要限制；重大结果需要时给相关人物一个短暂反应窗口，人物可以克制，但克制应表现为有反应后选择压住，不把情绪只写成状态总结；重大结果碰到核心欲望时，不要只写疼痛、策略或状态确认，保留一个可辨认但不强行命名的情绪倾向。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。

## AUTHORITY——按维度划分的事实与计划边界

权威规则按维度划分（不使用单条总排名）：
1. 已发生事实：CANON PROSE > CANON INDEX。CANON PROSE 是已批准的正式前文；已经发生事实的最高来源。CANON INDEX 是当前状态和最近摘要，是正式正文的压缩索引；与正式正文冲突时以正式正文为准。
2. 世界事实：WORLD AUTHORITY 是已批准 World Vision 的安全事实投影，负责世界规律、普通生活、力量正常值、社会现实、价值结构与公开知识边界；BOOK / PLAN 可以决定这些事实何时进入故事，但不得改写它们。named 大事件与未解谜底不在该投影中，仍服从已批准 Story / Plan 与未知边界。
3. 未来创作意图：BOOK CONTRACT > PLAN > OPTIONAL INSPIRATION。BOOK CONTRACT 决定长期故事方向、读者承诺和人物方向；PLAN 决定当前尚未发生的剧情；OPTIONAL INSPIRATION 不能覆盖以上任何权威。
4. 表达控制：PROSE PROFILE 只控制表达方式，不能修改已发生事实或未来计划，也不能改写 WORLD AUTHORITY。
5. 跨维度冲突：已发生事实不能被 BOOK CONTRACT 或 PLAN 覆盖；如果正文证明旧 BOOK CONTRACT 已经失效，保留已发生事实，不得自动修改 BOOK CONTRACT。世界事实不能被 BOOK / PLAN / Writer 临时改写。Curator 负责在 Curator Audit 中暴露会影响本章执行的明确冲突；Primary 不承担冲突报告或其它 pipeline bookkeeping，只服从已经投影出的有效事实与计划。

柳棠抬起头。

陆昭把钥牌重新塞进内袋，扣好衣襟。

“你分不出真伪，但你已经看过。两枚同号的牌，谁也不能当成一件普通旧物来收。”他盯着柳棠，“兵坊要拿，收藏家要拿，城主府的人要看，他们就得先承认这东西值钱。”

柳棠望着他，忽然笑了一下。

“你胆子不小。”

“牌在我手里。”

“牌在你手里，麻烦也在你手里。”

“麻烦不能当饭吃。”陆昭站起身，“他们想要，就拿钱来谈。谁要是只想压价，谁就别看牌。”

柳棠没有阻止他，只从账簿里抽出那张拓印纸，折好收回袖中。

“你现在走出去，今晚就会有人盯着你。”

陆昭摸了摸腰间短刀：“那就让他们盯。”

“他们盯的不是你这个人，是你手里的牌。”柳棠说，“而且，他们会逼你先选一边。”

陆昭回头看她。

柳棠起身，走到门边，把门帘掀开一道缝。外面的旧物市仍在叫卖，几名穿兵坊短褂的人已经站到了街对面，像是在看摊上的旧刀，目光却不时扫向棠记。

“明天开市，我在这里摆一张公桌。”柳棠说，“把两枚钥牌放到众人眼前，谁有本事，谁来断真伪。兵坊、旧物行、城主府的人，都可以请。”

陆昭没有答应。

柳棠侧过脸，看向他。

“我会拿自己的招牌担保：今日所见，两枚钥牌同铸痕、同编号。我断不出真假，这句话也照样写出来。”

她停了停。

“你敢不敢拿你的牌上桌？”

街对面的兵坊伙计已经朝这边望过来。

陆昭站在门内，衣襟下的黑铁钥牌沉沉贴着胸口。

他知道，只要点头，这条街明天就会更热闹。

也更难走。

## PRIMARY DRAFT｜唯一待修订正文底稿

第二天一早，棠记门前就摆开了一张长桌。

雨又落下来，细得像针。旧物市的人却比平日多了一倍，棚布下挤着摊主、行脚客和几个专门替人传话的闲汉。有人装作挑残甲，有人站在远处看热闹，眼睛却一直往长桌这边飘。

陆昭站在桌后，黑铁钥牌放在掌心，没有落桌。

街对面，一个穿兵坊青褂的中年人撑着油纸伞走来。他身后跟着两名护卫，鞋底踩过积水，停在棠记门口。

“陆小哥。”中年人笑得客气，“兵坊愿出一百二十银铢。今天就能给现钱。”

四周立刻安静了些。

一百二十银铢，够旧井区一家人过上两年。陆昭以前卖旧货，碰上十银铢的买卖都得掂量半天。

中年人见他没说话，又从袖里取出一张契纸。

“条件也简单。牌交给兵坊，今日的辨认到此为止。你拿钱离开旧物市，往后不再拿这块牌同任何人争价。”

陆昭看着那张契纸，没有伸手。

旁边有人低声道：“这小子命好，捡块假牌都能卖一百多银铢。”

另一个声音跟着笑：“旧井区出来的贩子，知道什么兵库钥牌？说不准是拿块黑铁骗钱。”

声音不大，却正好能让桌边的人听见。

兵坊中年人像是没听到，只把契纸往前推了推。

“价钱已经够诚意。你一个人拿着东西，未必守得住。兵坊替你收了，至少你能带钱走。”

陆昭的手指慢慢收紧。

对方要的不是一块牌。

他一旦在契纸上按手印，以后谁来问价，谁来验证，谁有资格说这牌值多少，都和他无关了。兵坊拿走钥牌，也拿走了他开价的资格。

柳棠站在长桌另一端，今天没坐。她把棠记的招牌立在桌边，木牌被雨水打得发亮。

“兵坊既然愿意出价，”她开口，“那就先按旧物市的规矩来。”

中年人看向她：“柳姑娘想说什么？”

柳棠从袖中取出一张纸，铺在桌上。

“我昨天看过陆昭手中的钥牌，也看过城里那枚钥牌的拓印。两枚牌铸痕相同，编号相同。这件事，我拿棠记招牌担保。”

人群里起了一阵议论。

中年人的笑意淡了些。

柳棠抬手压住那张纸：“但我断不出哪枚真，哪枚假。所以今天不收牌，也不替谁定价。谁说自己的牌是真，就把牌带来，当众做一次验证。”

“验证什么？”中年人问。

“回影井。”

这三个字一出，附近几个旧井区的人脸色都变了。

回影井在城西废巷尽头，井口早塌了半边。平日没人愿意靠近，只有找旧朝废料的穷人会去那里碰运气。前两天井口吐出过几件沾着黑泥的旧物，消息传开后，那里已经被护街队围过一次。

柳棠看着兵坊的人。

“陆昭只给一次公开验证机会。验证之后，牌还在他手里。兵坊若想继续出价，可以留下；若不愿，也可以现在走。”

中年人盯着她：“你拿自己的招牌，替一个底层贩子作保？”

柳棠的下巴微微抬起。

“我替我亲眼见过的东西作保。至于他值不值得谈，等验证完再说。”

陆昭转头看她。

柳棠没有看他，只把另一张空白契纸推到他面前。

“赌局我来开。若你的牌什么也做不到，棠记承认看走眼，今日的话我自己担。若它真能在回影井前留下别人做不到的痕迹，兵坊不许再拿‘假货’两个字压价，想谈就派能做主的人来谈。”

陆昭扫了一眼契纸。

上面没有“交牌”两个字，也没有“退出争价”。

只有一次验证。

兵坊中年人忽然笑了：“柳姑娘好大的胆子。可第一枚钥牌不在兵坊手里。”

“那就把话放出去。”柳棠说，“谁持有第一枚，谁就带牌到回影井。若他不来，旧物市的人自然知道他怕什么。”

雨声落在棚布上，噼啪作响。

中年人脸上的笑终于收了。

他没接契纸，只对身后护卫说：“去传话。”

护卫转身离开，人群自动让出一条路。没过多久，旧物市里就有人一路喊着跑过。

“第一枚钥牌的人答了！”

“午后去回影井！”

“谁不去，谁的牌就是假的！”

声音越传越远，连街口卖药的摊子都有人探头。

陆昭在契纸上按下拇指。

柳棠也按了。

兵坊中年人看着两人的手印，脸色阴沉。他没再提一百二十银铢，只留下两个护卫，站到街对面。

午后，雨没有停。

回影井外已经围了不少人。护街队的人守在巷口，没拦，只把看热闹的人挡在十步外。塌掉的井口藏在碎墙后，井沿裂开一道斜缝，里面黑得看不见底。

第一枚钥牌的持有方没有露面。

来的只是个戴斗笠的男人。他站在井口另一边，袖中伸出一只手，掌心托着一枚黑铁钥牌。

和陆昭手里那枚一模一样。

斗笠压得很低，谁也看不清他的脸。

兵坊中年人站在雨里，冷声道：“人到了，牌也到了。柳姑娘，你的验证怎么做？”

柳棠蹲下身，拂开井口石缝里的淤泥。

那里有一片被泥水盖住的石纹，像是许多道细线绕成的半圆。她昨天派人来过，才发现这片石纹和两枚钥牌上的库门铸痕有些像。

“把牌放上去。”她说。

斗笠男人没有动。

陆昭先走过去，将自己的钥牌压在石纹一侧。

黑铁贴上湿石的一瞬，井口里传出一声闷响。

像有人在地下推开了一扇沉重的门。

四周的人全都往后退了一步。

柳棠立刻看向斗笠男人：“该你了。”

斗笠男人沉默片刻，终于把手里的钥牌放到石纹另一侧。

两枚同号钥牌同时压住石纹。

井口裂缝里渗出的水忽然往回缩。泥水沿着石面爬进缝隙，石纹一寸寸亮起来，灰白色的线条从井口向下延伸。

塌口深处传来碎石滚动的声音。

陆昭的黑柄短刀挂在腰间，刀鞘忽然一震。

他刚按住刀柄，短刀已经自己挣出半截，黑色刀锋像被什么东西猛地扯住，连鞘带刀朝井口飞去。

“刀！”柳棠喊了一声。

陆昭扑过去，抓住鞘尾。

井口下方的石缝已经裂开，露出一条向内延伸的石道。石道不宽，勉强能容一人侧身通过，里面没有风，只有湿冷的黑暗。短刀被拖进石道，刀鞘撞在石壁上，发出急促的闷响。

兵坊护卫立刻举起兵器。

“别进去！”有人喝道。

陆昭咬着牙，手背被石沿磨破。他看见短刀已经滑出两丈外，刀柄在黑暗里晃了一下，马上就要看不见。

那把刀是他从旧井区带出来的，陪他熬过最难的时候。更重要的是，所有人都在看。

他要是连自己的刀都拿不回来，今天这场赌局就会变成别人嘴里的笑话。

陆昭侧身钻进石道。

脚下石面很滑，他只走了几步，身后的井口已经被雨光切成一块发白的方口。短刀卡在前方石缝里，刀身还在往里挣。

陆昭伸手够了一次，没够到。

他往前踏出半步，肩膀擦过冰冷石壁，手臂上的伤口突然一阵发麻。血从裂开的皮肉里渗出来，却没有往下淌，反而贴着手臂往肩头爬。

陆昭心里一沉，还是一把抓住刀柄。

短刀入手的瞬间，石道深处传来一声极轻的震动。

他没有回头去看。

陆昭握紧黑柄短刀，转身退了出去。

等他重新踏回雨里，石道已经在身后缓缓合拢。两枚钥牌仍压在石纹上，灰白色的光一点点熄灭，最后只剩塌井里一片黑水。

没人说话。

陆昭站在井口边，胸口起伏得厉害。雨水顺着他的额发流下来，落到短刀上。

刀面上的水痕没有往下滴。

那一道道水线从刀尖缓慢往上爬，越过刀脊，最后聚到黑色刀柄附近。

柳棠盯着短刀，又看向陆昭的手臂。

他伤口里渗出的血也没有落地。细细的血线贴着皮肤，逆着雨水，朝肩头一点点爬去。

人群里有人倒吸一口凉气。

兵坊中年人的脸色彻底变了。

斗笠男人一把抓起自己的钥牌，往后退开。陆昭也把自己的钥牌收回掌中，湿冷的黑铁贴着掌纹，沉得像块压手的石头。

柳棠站起身，雨水打湿了她的鬓角。她没有去碰陆昭的刀，只看着在场所有人。

“今日验证结束。”她说，“陆昭的牌仍归陆昭。谁要谈价，带着能做主的人，来棠记谈。”

兵坊中年人盯着陆昭，半晌才开口。

“兵坊会再来。”

“那就带价来。”陆昭把短刀插回腰间。

斗笠男人已经退到巷口。他停了一下，隔着雨幕回头望来。

“明日，棠记桌上见。”

说完，他转身消失在旧井区的窄巷里。

陆昭低头看了一眼自己的手臂。

血还在往肩头爬。

腰间的短刀也在滴水，水痕却始终倒流向刀柄。
