# 当前中期规划窗口

规划范围：预计第1—36章。

窗口终点：第36章完成听雨城阶段最后一次开启、封井冲突和第一轮关系结算。陆昭达到纹阶12，保留钥牌、锁镰、陆峥实物与完整旧井地图；柳棠关系发生不可逆变化。

第36章只确认已知地图边界：地图在断墙前结束，但断墙后的石道仍可通行。不得具体规划石道之外的环境、势力、资源、规则或新能力；随后执行 `protagonist-blind World Expansion → deterministic Current Character → Story Refresh`。

## 第1—6章：墙内第二枚

具体发生：陆昭必须保住回影井吐出的第二枚兵库钥牌，并把一次安全卖货机会变成由自己控制的公开翻价机会。

1. 异常长雨令封墙坍塌，回影井吐出第二枚钥牌；更强的收货者先一步抢夺。陆昭用钉影制造短暂空当，将钥牌真正抓回自己手里。
2. 陆昭带钥牌进入旧物市找柳棠，只让她在自己控制下查看。柳棠确认它与城中第一枚钥牌存在同铸痕、同编号，但现有手段不能判定哪一枚是假。
3. 兵坊买家开出安全高价，要求陆昭先交物并退出；旧物市又散布他卖假的说法。陆昭拒绝交出所有权，接受柳棠提出的公开真伪赌局。
4. 三大兵坊代表、旧物贩子和围观者聚集。第一枚钥牌的持有方被迫带牌到场，两枚钥牌第一次公开并置。
5. 材质、铸痕和编号无法直接判定第二枚为假。陆昭把赌注压在“你们不能证明是假”上，而不是替任何人解释来源。
6. 有人试图强行拿牌，陆昭用第二次钉影制造脱手窗口，保住钥牌并拿到第一笔赌局收益。一家兵坊从压价者转为夺物、压服或收买者。

主要阅读兑现：底层旧物贩子用有限能力和主动押注，让兵坊在众目睽睽下重新报价。

Block Delta：

- `Possession`：陆昭持有第二枚兵库钥牌。
- `Relationship`：柳棠以鉴定声誉与陆昭形成临时共同利益。
- `Identity / Access`：陆昭成为必须被直接交涉的钥物持有人。
- `Knowledge`：两枚钥牌同铸痕、同编号，但关系和来源未知。
- `Enemy State`：至少一家兵坊开始准备夺物、压服或收买。

代价或余波：陆昭失去低调卖牌、拿钱离开的安全路线；柳棠的声誉被押上赌局。

推向下一块：公开判断无法解决两枚钥牌的关系，各方必须把争夺推进到真正的石锁验证。

## 第7—15章：两把钥牌开同一道锁

具体发生：陆昭必须在安全买断、保留所有权、公开验证和地下兵器机会之间下注，并把赌局收益转成真实成长与资产。

1. 兵坊提出更高买断价，条件是陆昭交出钥牌并退出；柳棠提出的“公开石锁验证”价值较低但能保留钥牌、公开验证结果，并打开地下兵器选择机会。陆昭选择后者。
2. 陆昭把部分收益投入正规纹师教习，同时以自己的风险接雨猎，不把自己变成兵坊护送人。经过教习、雨猎和真实冲突，他从纹阶4达到纹阶7。
3. 两枚钥牌必须同时到场，柳棠坚持共同见证，陆昭坚持自己的钥牌始终由自己保管；更强的兵坊人员因此进入现场。
4. 两枚钥牌先后作用于同一道旧朝石锁。“其中一枚是假货”的解释失效，兵坊、旧物市和城主府被迫重新估价钥牌与地下兵器。
5. 一名纹阶10的护街骨干公开强夺。陆昭不能正面击败对方，只用钉影钉住兵器影子，保住钥牌易手的决定性瞬间；现场看见纹阶7对纹阶10的差距，也看见三次短暂机会的价值。
6. 因公开验证结果与强夺事件，陆昭获得地下兵器优先挑选机会。他没有选最顺手的兵器，而选择价值最高、能承载多重纹路的旧朝锁镰。
7. 兵坊和城主府不再把陆昭视为单纯卖货者，而是视为必须收买、限制或击败的入口持有人。

主要阅读兑现：两枚不能同时成立的“真物”共同开启同一道锁；陆昭拿到钱、纹阶7、社会估值和真正属于自己的高价值锁镰。

Block Delta：

- `Power / Capability`：陆昭达到纹阶7；钉影边界不变，但在强夺中证明了决定性空当价值。
- `Possession`：陆昭取得旧朝锁镰。
- `Identity / Access`：进入地下兵器争夺与公开验证的直接参与者。
- `Knowledge`：两枚钥牌都能作用于同一道石锁，彼此关系仍未知。
- `Enemy State`：兵坊转为收买、威胁与强夺。
- `Relationship`：陆昭与柳棠成为共同持有关键事实、必须彼此结算的利益同盟。

代价或余波：陆昭公开暴露纹阶位置和钉影边界；敌人开始针对他的身体、路线和见证关系。

推向下一块：石锁开启使地下兵器价值暴涨，城主府把封井从远期计划变成有明确期限的现实行动。

## 第16—24章：封井前的最后一场生意

具体发生：封井期限逼近，兵坊争抢最后一批地下兵器；陆昭必须决定是否用钥牌、短刀和进入事实换安全巨款，直到陆峥的具体实物改变他的排序。

1. 城主府推动封井，三大兵坊抢在封锁前争夺剩余兵器。陆昭凭两枚钥牌有效这一事实取得最后一场交易的谈价位置。
2. 兵坊要求整体买断钥牌、异常短刀、验证记录和地下进入权；柳棠要求按双方原定共同结算。陆昭暂时不交出所有权，先保留自己的进入条件。
3. 封井前的混乱中，一件随井水冲出的实物被发现。陆昭凭当场有效证据确认它属于失踪两年的陆峥；这只确认归属，不确认生死、去向或与回影井的完整关系。
4. 最高买家提高报价，要求陆昭交出钥牌、陆峥实物和全部验证记录，并放弃亲自进入最深井区。没有陆峥实物时，陆昭会接受；实物出现后，他改变选择。
5. 陆昭拒绝整体出售，要求换取封井前一次亲自进入的机会，并保留陆峥实物所有权。
6. 柳棠因共同结算和声誉安排被改变而遭受现实损失；她不接受一句道歉就把损失抹平。兵坊失去买断机会，转为公开敌对，城主府也把陆昭视为封井行动中的不稳定变量。

主要阅读兑现：一个陆昭嘴上认定已经死去的人，以具体实物击穿他的收益排序；陆昭没有无偿交出东西，而是把私人偏心换成一次亲自进入的机会。

Block Delta：

- `Possession`：陆昭保有陆峥实物和钥牌所有权。
- `Relationship`：柳棠因改约受损，双方从共同获利进入利益与私人偏心冲突。
- `Identity / Access`：陆昭取得封井前亲自进入最深井区的机会，成为各方无法预测底价的关键变量。
- `Knowledge`：陆峥与异常实物链出现可追联系，具体原因未知。
- `Enemy State`：一家兵坊转为公开敌对；城主府开始限制陆昭。
- `World State`：封井成为明确行动压力。

代价或余波：陆昭失去安全现金和柳棠原本可得的结算，真实机会成本不由同场奖励抵消。

推向下一块：进入权已经争到，但封井期限没有消失；两枚钥牌、各方兵力和关系裂痕必须在最后一次开启中同时兑现。

## 第25—36章：回影井的开口

具体发生：城主府只允许最后一次开启，陆昭必须在优先取得最贵兵器与救出柳棠之间作出不可兼得的选择，并把已知地图走到边界。

1. 最后一次开启前，城主府强者、掌握第一枚钥牌的兵坊和陆昭分别提出控制条件。陆昭拒绝转让钥牌，只接受以持有人身份进入。
2. 两枚钥牌同时到场，石锁再次开启。柳棠负责保留现场事实，兵坊准备在入口打开后独占兵器、地图与通路。
3. 陆昭在持续教习、雨猎和冲突中达到纹阶12，进入通常可独自猎杀大型雨兽的正常门槛，但仍不能正面抗衡纹阶21以上的城级名手。
4. 石锁之后出现可供人通行的空间与地下兵器。陆昭取得覆盖已知旧井段的完整地图，并保留钥牌、陆峥实物和锁镰。
5. 地下兵器优先挑选权与柳棠被坍塌石门困住同时发生。陆昭可以先拿走价值最高的兵器，也可以用最后一次钉影卡住石门。
6. 陆昭选择先为柳棠打开生路，失去优先挑选权；钉影与锁镰第一次形成复合，使锁镰在半途急停或换向，改变救援和战斗空间。
7. 柳棠确认陆昭为她放弃了真正昂贵的收益，也确认他没有趁乱带走共同证据。两人的关系进入私人选择会改变账目、但仍会为价格和所有权争执的阶段。
8. 城主府封闭其他危险井道，最深入口却未能彻底封死。完整地图在断墙前结束，断墙后的石道仍向未知黑暗延伸。

主要阅读兑现：纹阶、钉影、锁镰、贪欲、胜负心与私人关系在一次不可兼得的选择中同时兑现。陆昭没有变成无私英雄，但承认一个具体的人不能被简单用钱替代。

Block Delta：

- `Power / Capability`：陆昭达到纹阶12；钉影与锁镰形成一次急停或换向复合，共享每日三次额度。
- `Possession`：陆昭保有完整旧井地图、锁镰、钥牌和陆峥实物。
- `Relationship`：柳棠确认陆昭会为她放弃真正昂贵的利益。
- `Identity / Access`：陆昭成为掌握异常钥物、地图和公开旧井战绩的人。
- `Enemy State`：兵坊敌意固定，城主府把陆昭视为不稳定变量。
- `World State`：大部分危险井道被封闭，最深入口成为受多方制约的新争夺边界。
- `Knowledge`：地图边界之外仍有可通行石道，其尺度、环境、规律和尽头未知。

代价或余波：陆昭失去地下兵器优先挑选权；柳棠此前损失没有立即被补偿。

推向下一块：听雨城阶段已经自然完成，地图边界之外超出当前 World Authority，必须先执行 World Expansion 与 Story Refresh。

# 未来十章逐章小纲

批次定位：本批覆盖“墙内第二枚”并进入“两把钥牌开同一道锁”的起点。主要故事问题是陆昭能否保住第二枚钥牌，并把安全卖货转成自己控制的公开翻价机会。本批完成钥牌占有、柳棠共同押注、公开赌局、第一笔收益，并在第10章完成两枚钥牌开启同一道石锁的第一次证明。

## 第1章：墙里落下第二枚

具体剧情：异常长雨震裂陆家旧院封墙，回影井吐出第二枚旧朝兵库钥牌。更强的收货者先一步伸手夺物，陆昭用钉影钉住滑动钥牌的影子，在极短窗口内夺回钥牌，并用黑柄短刀保住继续脱身的空间。

结果 / 状态变化：陆昭真正持有第二枚钥牌；钉影第一次产生可见、不可替代的现实结果。读者知道陆昭处于纹阶4，旧井坍塌会直接威胁活命、住房和财物。

叙事功能：完成开篇公共世界定向与核心优势第一次兑现，建立“先占有，再决定卖不卖”的主角选择。

结尾推动：陆昭看见钥牌上的铸痕与编号，意识到它可能与城中正在争抢的第一枚有关，决定去旧物市估价。

## 第2章：旧物市不替人保货

具体剧情：陆昭带钥牌进入旧物市找柳棠，只把物件放在自己手边，不让她先收走。柳棠确认它与第一枚钥牌有同铸痕、同编号，但现有手段不能判定哪一枚是假；她的鉴定声誉因此被卷入。

结果 / 状态变化：钥牌价值升高，真伪关系仍未解决；柳棠成为可能共同押注的人。

叙事功能：把异常物转成公开交易、声誉和势力冲突。

结尾推动：柳棠提出公开真伪赌局，兵坊买家已经知道第二枚钥牌到了陆昭手里。

## 第3章：只卖一次验证

具体剧情：兵坊买家给陆昭安全高价，要求先交钥牌并退出；旧物市又出现“底层贩子卖假货”的议论。陆昭判断对方不只想买物，还想让他失去以后定价的资格，于是拒绝出售所有权，接受柳棠提出的公开真伪赌局。

结果 / 状态变化：陆昭只出售一次验证机会，钥牌仍由自己持有；第一枚钥牌的持有方被迫出面应战。第3章的 Reveal Event 按 deterministic runtime transport 注入，具体答案与 State Residue 不在本 Outline 中提前展开。

叙事功能：[MYSTERY-REVEAL:M-WELL-01] 明确本章是唯一揭晓时点；同时说明具名赌局为何值得争：钥牌若站住，陆昭能取得更高收益和直接议价位置，而不是只换一笔安全钱。

结尾推动：公开赌局即将开始，第一枚钥牌持有方必须把牌带到同一张桌上。

## 第4章：两枚牌站上同一张桌

具体剧情：三大兵坊代表、旧物市商贩和围观者聚集。第一枚钥牌被带到现场，陆昭把第二枚放上桌，却拒绝让任何人单独拿走；柳棠以自己的鉴定声誉押注公开判断。

结果 / 状态变化：两枚钥牌第一次在公开场合并置，铸痕与编号的相似性成为所有人都无法回避的事实。

叙事功能：扩大见证范围，让钥牌从私人高价物变成会改变城市定价的异常事件。

结尾推动：比对开始，兵坊准备以材质或纹路差异直接判陆昭手里的牌为假。

## 第5章：判不了假的牌

具体剧情：材质、铸痕和纹路逐项比对，仍找不到足以判假的差异。兵坊代表转而攻击陆昭的出身和信誉，要求他先交牌接受更深入检查；陆昭当众拒绝，把赌注压在“他们无法证明是假”上。

结果 / 状态变化：公开判断暂时无法得出假牌结论；柳棠的声誉与陆昭的所有权站在同一边。

叙事功能：让悬疑停留在高价值未知，不用解释替代冲突；让陆昭主动决定公开哪一条证据。

结尾推动：无法赢得判断的兵坊不再准备继续争辩，而准备直接夺物。

## 第6章：赌输的人改口

具体剧情：争执中有人伸手抢第二枚钥牌，陆昭用钉影钉住钥牌影子，借短暂空当收回钥牌并脱离抓取。现场见证者迫使兵坊按赌局结果认赔，兵坊代表却把“不能判假”改说成“必须由兵坊保管”。

结果 / 状态变化：陆昭拿到第一笔足以改变生活的赌局收益，钥牌仍归自己；一家兵坊由压价者转为明确敌意。

叙事功能：完成第一块阶段兑现：占有、公开胜负、即时收益和社会改价同时落地。

结尾推动：柳棠认为继续私下卖牌只会让陆昭失去后续机会，公开石锁验证成为下一次更高价值的选择。

## 第7章：安全价码之外

具体剧情：兵坊提出更高买断价，承诺陆昭拿钱退出；柳棠提出“公开石锁验证”，成功后陆昭可以保留钥牌、公开验证结果，并参与地下兵器选择。陆昭选择后者，并把赌局收益拿去接受正规纹师教习。

结果 / 状态变化：陆昭拒绝安全现金，锁定保留钥牌、验证结果和地下兵器机会的路线；成长获得真实资源起点。

叙事功能：把第一章的占有欲转成长期行动选择，并明确“公开石锁验证”的已批准价值。

结尾推动：为了继续保住钥牌和训练费用，陆昭必须接下一次雨猎。

## 第8章：纹阶七之前

具体剧情：陆昭以自己的风险接下一次雨猎，不把自己变成兵坊护送人。面对雨中危险，他用黑柄短刀和钉影完成一次脱身与取物，再将收益投入正规教习。

结果 / 状态变化：经过教习与真实战斗，陆昭达到纹阶7，进入护街、雨猎骨干的正常起点，但仍明显弱于纹阶10以上的强手。

叙事功能：完成第一轮力量真实成长，让等级变化来自个人行动和资源转化。

结尾推动：纹阶7的陆昭获得进入石锁验证现场的资格，但兵坊已经为验证后的强夺准备人手。

## 第9章：钥牌必须同时到场

具体剧情：石锁验证前，柳棠坚持两枚钥牌必须同时到场，不能由一家兵坊单独带牌进入。陆昭接受现场验证，却要求自己的钥牌始终由自己保管；第一枚钥牌的持有方为保住原有主张，只能带牌赴约。

结果 / 状态变化：两枚钥牌和公开见证被固定在同一场验证中；陆昭保住所有权，但无法避免更强对手进入现场。
