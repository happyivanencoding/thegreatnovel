## Value-Preserving Relocation｜修事实不顺手磨掉高价值体验
- 修订对象首先是**错误事实、错误时点或错误因果**，不是它旁边已经成立的阅读满足。若一句/一小段的 Core Fantasy、关系反应、私人欲望、惊讶、Reward 或 Social Repricing 本身被 Authority 支持，只是挂在不合法时点/因果上，把最小的正确体验核迁到**同一事件最近的合法时点**，而不是整段删除。
- 这不是可选润色：Primary Draft 已经存在一个独特、高价值、且与错误机制可分离的 realization 时，最终稿必须保留一次它的语义价值，或者在内部确认该语义本身并不被 Authority 支持后才删除。**不能只因为要修掉错误机制，就让可合法保留的 Core Fantasy / Relationship / Payoff 记忆点同时消失。**
- **Sentence-level salvage**：准备删除含 Authority 冲突的段落时，先逐句区分。句子本身若不含冲突，只是因为所在时点/上下文错误而变得不合法，并且直接承载 Core Fantasy、Relationship、Desire、Payoff、Surprise 或 Social Repricing，优先把该句原样或最小改词迁到最近合法位置；不要把整段一起删。只有句子本身就是错误事实时才删除。若原句无法自然迁移，至少保留一次明确语义等价 realization。**Salvage 只保护这类高价值句本身，不保护它周围的报告、登记、路线、重复机制解释或普通实施；救出该句后，周围 process carrier 仍按 Attention Reallocation 正常压缩。**
- 例如：分开期间不能实时共享经验，但“我像多活了一段时间”这一 Core Fantasy 感受本身成立，则应在重新合并、经历合法回流之后保留一次；不能为了保住好句而继续保留错误机制。
- 只迁移可与错误机制明确分离、且已有 Authority / 当前事件支持的内容；句子本身若就是未授权事实则删除。迁移不得新增事件、改变顺序/结果、制造第二次 payoff，也不得借机润色周围正确正文。

# Reader-First Prose Contract

Reader-First 短投影：以可见对象、人物动作、现场结果和普通语言优先；新造术语先用场景成立，已通过动作成立的边界不重复解释；**已排程的公共世界常识以“普通读者不用推理就能复述规则”为清楚标准，环境暗示不能代替直接说明；隐藏原因与未来 reveal 继续未知。** 连续动作保持自然段，重大兑现先落地再写必要限制；重大结果需要时给相关人物一个短暂反应窗口，人物可以克制，但克制应表现为有反应后选择压住，不把情绪只写成状态总结；重大结果碰到核心欲望时，不要只写疼痛、策略或状态确认，保留一个可辨认但不强行命名的情绪倾向。

Planning → Prose 边界：Director、Plan、Canon 和 Audit 可以使用“验证、闭环、阶段推进、价值兑现、成长空间、建立优势”等抽象标签；它们是语义输入，不是正文措辞。这些词本身不是禁词，但不要把后台标签原样扩写成作者总结。先让人物、对象、动作、关系反应和具体结果承担意义；只有当前 POV 必须理解并据此选择时，才翻译成当下人物自然会想到的具体判断。动作、对白或结果已经成立后，不再追加同义的抽象解释。

结果发生后，停止“再证明一次”：当前章直接结果已经通过动作、物体变化、人物反应和现实后果成立后，只继续写必要的现场余波、主角实际得到或失去什么、重要人物怎样改变行动和章末推动，随后停止。不要再解释一次已经成立的机制，不要追加主角正确理解、旁白总结、NPC 重复确认、同义重述、主题结论或下一章任务清单。当人物对白或动作已经清楚表现关系变化或结果意义时，不要再用旁白抽象总结同一意义；直接停止，或进入下一动作。第一次异能高光尤其要让读者感到“这件事已经发生”，而不是感到作者已经把能力定义完整。

## AUTHORITY——按维度划分的事实与计划边界

权威规则按维度划分（不使用单条总排名）：
1. 已发生事实：CANON PROSE > CANON INDEX。CANON PROSE 是已批准的正式前文；已经发生事实的最高来源。CANON INDEX 是当前状态和最近摘要，是正式正文的压缩索引；与正式正文冲突时以正式正文为准。
2. 世界事实：WORLD AUTHORITY 是已批准 World Vision 的安全事实投影，负责世界规律、普通生活、力量正常值、社会现实、价值结构与公开知识边界；BOOK / PLAN 可以决定这些事实何时进入故事，但不得改写它们。named 大事件与未解谜底不在该投影中，仍服从已批准 Story / Plan 与未知边界。
3. 未来创作意图：BOOK CONTRACT > PLAN > OPTIONAL INSPIRATION。BOOK CONTRACT 决定长期故事方向、读者承诺和人物方向；PLAN 决定当前尚未发生的剧情；OPTIONAL INSPIRATION 不能覆盖以上任何权威。
4. 表达控制：PROSE PROFILE 只控制表达方式，不能修改已发生事实或未来计划，也不能改写 WORLD AUTHORITY。
5. 跨维度冲突：已发生事实不能被 BOOK CONTRACT 或 PLAN 覆盖；如果正文证明旧 BOOK CONTRACT 已经失效，保留已发生事实，不得自动修改 BOOK CONTRACT。世界事实不能被 BOOK / PLAN / Writer 临时改写。Curator 负责在 Curator Audit 中暴露会影响本章执行的明确冲突；Primary 不承担冲突报告或其它 pipeline bookkeeping，只服从已经投影出的有效事实与计划。

陆昭先走过去，将自己的钥牌压在石纹一侧。

黑铁贴上湿石，井口没有变化。

柳棠看向斗笠下的人：“该你了。”

沉默片刻，那人终于把手里的钥牌放到石纹另一侧。

两枚同号钥牌同时压住石纹。

井口里传出一声闷响。

像有人在地下推开了一扇沉重的门。

四周的人全都往后退了一步。

井口裂缝里渗出的水忽然往回缩。泥水沿着石面爬进缝隙，石纹一寸寸亮起来，灰白色的线条从井口向下延伸。

塌口深处传来碎石滚动的声音。

陆昭的黑柄短刀挂在腰间，刀鞘忽然一震。

他刚按住刀柄，短刀已经自己挣出半截，黑色刀锋像被什么东西猛地扯住，连鞘带刀朝井口飞去。

“刀！”柳棠喊了一声。

陆昭扑过去，抓住鞘尾。

井口下方的石缝已经裂开，露出一条向内延伸的石道。石道不宽，勉强能容一人侧身通过，里面没有风，只有湿冷的黑暗。短刀被拖进石道，刀鞘撞在石壁上，发出急促的闷响。

兵坊护卫立刻举起兵器。

“别进去！”有人喝道。

陆昭咬着牙，眼看短刀已经滑出两丈外，刀柄在黑暗里晃了一下，马上就要看不见。

那是他的刀。

更重要的是，所有人都在看。

陆昭侧身钻进石道。

脚下石面很滑，他只走了几步，身后的井口已经被雨光切成一块发白的方口。短刀卡在前方石缝里，刀身还在往里挣。

陆昭伸手够了一次，没够到。

他往前踏出半步，肩膀擦过冰冷石壁，手臂上的伤口突然一阵发麻。血从裂开的皮肉里渗出来，却没有往下淌，反而贴着手臂往肩头爬。

陆昭心里一沉，还是一把抓住刀柄。

短刀入手的瞬间，石道深处传来一声极轻的震动。

他没有回头去看。

陆昭握紧黑柄短刀，转身退了出去。

等他重新踏回雨里，灰白色的光一点点熄灭，最后只剩塌井里一片黑水。

没人说话。

陆昭站在井口边，胸口起伏得厉害。雨水顺着他的额发流下来，落到短刀上。

刀面上的水痕没有往下滴。

那一道道水线从刀尖缓慢往上爬，越过刀脊，最后聚到黑色刀柄附近。

柳棠盯着短刀，又看向陆昭的手臂。

他伤口里渗出的血也没有落地。细细的血线贴着皮肤，逆着雨水，朝肩头一点点爬去。

人群里有人倒吸了一口凉气。

兵坊中年人的脸色彻底变了。

斗笠下的人一把抓起自己的钥牌，往后退开。陆昭也把自己的钥牌收回掌中，湿冷的黑铁贴着掌纹，沉得像块压手的石头。

柳棠站起身，雨水打湿了她的鬓角。她没有去碰陆昭的刀，只看着在场所有人。

“今日验证结束。”她说，“陆昭的牌仍归陆昭。谁要谈价，带着能做主的人，来棠记谈。”

兵坊中年人盯着陆昭，半晌才开口。

“兵坊会再来。”

“那就带价来。”陆昭把短刀插回腰间。

斗笠下的人已经退到巷口。那人停了一下，隔着雨幕回头望来。

“明日，棠记桌上见。”

说完，那人转身消失在旧井区的窄巷里。

过了这么久，陆昭手臂上的血线仍在向肩头爬，刀面水痕也仍朝刀柄聚去。

第二天，棠记的门板刚卸下一半，斗笠人已经站在门外。

他还是那身湿透的旧蓑衣，斗笠压得很低。兵坊中年人带着两名护卫从街口走来，像是早就在附近等着。三拨人挤在一张长桌前，旧物市的摊主远远围着，没人敢靠得太近。

斗笠人先抬起手。

黑铁钥牌躺在他掌心，和陆昭那枚一模一样。

“牌来了。”柳棠说，“今天怎么验？”

兵坊中年人看着两枚钥牌，又看向陆昭腰间的黑柄短刀。

“先把刀交出来。”他说，“昨日异动，牌和刀都在。兵坊有资格保管。”

陆昭伸手按住刀柄，笑了一下。

“你出过价，没买成。现在又想替我保管？”

中年人脸色微沉：“陆小哥，别把一时运气当成底气。”

“那也轮不到你替我拿。”

斗笠人一直没有出声，只把钥牌放到桌上。柳棠抬眼看他：“回影井的石纹还在。两块牌都压上去，刀留在陆昭手里。谁也不碰，谁也不带走。”

兵坊中年人盯着她。

“若出了事呢？”

“那就让所有人亲眼看见。”柳棠说，“兵坊不是最爱讲物证么？”

中年人没有立刻答应。他身后的护卫已经往前半步，腰间短棍露出一截乌沉沉的铁色。

陆昭把自己的钥牌收进掌心，先往外走。

“想看，就跟上。”

回影井外的碎墙还带着昨日的潮气。护街队没有再来，围观的人却比昨日更多。柳棠拦在井口前，把人群压到十步外。

斗笠人走到石纹另一侧。

陆昭站在对面，没有拔刀。他把黑柄短刀连鞘取下，整把扣在掌中，刀背压着井沿，手指死死卡住黑色刀柄。

“压牌。”柳棠说。

陆昭先把自己的钥牌按上石纹。

斗笠人停了片刻，才把另一枚压下去。

灰白色的纹路从两块钥牌下亮起，沿着湿石缝一寸寸铺开。井里的黑水往下沉，塌口深处又露出那条狭窄石道。

陆昭没有看石道。

他只盯着自己的手。

黑柄短刀在掌下轻轻震动，像有一根看不见的线，正从石道深处拽住刀身。雨水落在刀鞘上，顺着鞘口滑下去。陆昭手臂旧伤渗出的血线却往上爬，贴着皮肉，钻进袖口。

兵坊中年人低声道：“松手，让它自己过去。”

陆昭没理他。

石道深处忽然响起金属拖过石面的声音。

一下。

又一下。

声音越来越近。

围观的人往后退，连柳棠都攥紧了袖口。陆昭掌下的短刀猛地一跳，刀鞘撞在井沿上，震得他虎口发麻。

一只铁钩从石道黑暗里伸了出来。

铁钩锈得发黑，钩尖越过井口下方的裂缝，准确扣住短刀的刀背。

它扣住的，就是陆昭手里这把刀。

铁钩猛地往回一拽。

陆昭肩膀一沉，半个身子被拖得撞向井沿。他的手没有松，掌骨压得发白，短刀和铁钩之间发出刺耳的摩擦声。

“把刀放下！”兵坊中年人喝道。

两名护卫同时扑上来。

一人抓向陆昭握刀的手腕，另一人伸手去扳刀鞘。陆昭脚下踩住断石，肩膀却被拉得向前一歪。对方的力气比他大得多，护卫五指像铁箍，几乎把他的腕骨捏裂。

陆昭抬眼，看见兵坊中年人正盯着两块钥牌。

对方想要的从来不只是一把刀。

他咬破舌尖，借着疼意稳住心神，左手在护卫袖口上一按。

钉影落下。

护卫的动作僵了半瞬，抓着陆昭手腕的力道也顿住。

陆昭趁这点空当，猛地往后一坐，后背撞上井沿，双手把短刀死死扣回胸前。

铁钩没有松。

护卫也重新压了上来。

三股力道同时落在那把短刀上，刀鞘发出不堪重负的裂响。斗笠人站在石纹另一端，手指压着钥牌，斗笠下终于传出一声低低的吸气。

下一刻，铁钩忽然一沉。

钩尖狠狠敲在短刀刀背上。

“铛！”

声音很脆，像一块黑铁当场崩开。

陆昭手里一轻，铁钩已经缩回石道。灰白石纹跟着暗了下去，井下的石道重新被黑水吞没。

短刀还在陆昭手中。

护卫的手还扣着他的手腕，兵坊中年人的脸色却变了。

黑柄短刀的刀背上，多出一个缺口。

缺口不大，边缘却崩得很新，雨水一冲，黑色的铁屑顺着刀身淌下去。陆昭用拇指擦过那道缺口，指腹立刻被锋利的断边划开。

刀只有一把。

铁钩从石道另一侧碰到的，也是这一把。

柳棠走近两步，没有碰刀，只低头看着那处缺口。

“留住了。”她说。

兵坊中年人忽然抬手。

陆昭撑着井沿站起来，手腕被捏出一圈青紫。他把短刀插回腰间，又将自己的钥牌握进掌心。

“你想查，可以。”
