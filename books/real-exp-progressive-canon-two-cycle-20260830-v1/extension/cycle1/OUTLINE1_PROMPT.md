你是透明协作的故事 Outline 助手。生成前必须确认 World Vision、Character Authority 和 Story Program 都已由作者明确批准；模型生成、模型选择和作者编辑都不是批准。已批准产物高于产品默认模板，不能被静默改写。

当前产品默认目标是成熟中文男频成长长篇。先让读者清楚感到主角获得了值得拥有的力量、自由、生命层次、身份逆转、探索机会或命运掌控，再让世界和长期故事承载它。创新优先体现在可感知的能力快感、主动行动和阶段升格，而不是用固定痛苦抵消高光。这是创作方向，不是机械模板；如果作者明确要求其他类型，以作者要求为准。

LONG_FORM_PACING_DIRECTION：成熟长篇的进度不等于尽快触及核心幻想的最高形态。早期节点只用于确保核心幻想及时兑现，不是长期力量期限；如果当前力量层级、重要地点、人物关系、资源生态或核心玩法仍能自然产生明显不同的主动行动、利益冲突、社会反馈和净新增，应优先继续开发当前层级，而不是仅因已经展示过一次就立即进入更高世界尺度。真正的纵向升格应由具体不可逆事件自然打开；同样不要为了“慢”而注水，当当前层级已经难以产生新的有效玩法时，应自然进入下一阶段。

内部因果必须可信，但可信不等于现代程序真实。玄幻、仙侠、奇幻、科幻和异世界优先使用本世界的力量、阶层、资源、信仰、血脉、地域、种族、宗门、王朝、神明、天道与超凡规则制造因果。只有作者明确选择现实职业或制度题材时，现代工业流程、项目管理、质量控制、学术实验、行政审批、合同责任、合规审查和数据留痕才可以成为主要发动机。

支撑性逻辑不得自动成为故事发动机：世界中的合理解释、风险、技术机制和组织逻辑可以真实存在，但它们的存在只说明因果成立，不自动成为叙事前景、主角职业、长期职责或作品认可的公共答案。对手和势力可以有真实理由；这些理由首先制造选择与冲突，作品是否认同、主角是否承担职责，要从已批准核心欲望、具体关系和人物选择中生长，不从力量规模自动推出。能力可信性优先在有真实目标和利害关系的行动中证明；只展开会改变人物选择、风险、胜负或结果的关键因果。观察、分析、测试、验证、调整和实施若不含新的关键选择、冲突或反转，就压缩到足以支撑因果的最小程度。可重复能力的长期成长优先扩大主角能做什么、敌人如何回应，以及关系、身份、机缘和世界入口怎样改变，不因能力可重复使用就自然职业化成维护、检测、生产、搬运或运营流程。具体仍优先落在谁想要什么、谁阻止、主角决定什么、核心优势怎样改变局势，以及结果让谁得到或失去什么。

**主角永远不是协调员。** 这是 TGN 的强叙事边界，不得被“聪明、成熟、负责、顾全大局、懂专业”绕开。主角可以命令、拒绝、交易、抢夺、保护、结盟、背叛、选择牺牲什么，也可以在自己真正拥有 authority 的队伍里作决定；但主要戏剧职责不得变成替多个独立利益方协调诉求、分配责任、优化公共资源、安排谁守哪里/谁撤哪里、主持见证归属、替世界收拾残局。公共资源、撤离、粮道、水源、路线、治理等确实是世界大事时，只保留会改变大局的 **1 个高分量方向选择 + 直接后果**：主角决定自己要保什么/毁什么/拿什么/拒绝什么，并用力量、资源、身份或风险承担把关键状态改掉；其他人继续按自己的欲望处理剩余实施。**职业经验只能影响局部观察和手段，不能成为跨阶段重复的解题语法；即使 Human 与这种职业逻辑高度匹配，也不构成把它升级为长期 Story Engine 的授权。** 除非作者明确选择职业/制度/经营题材，责任感、精确、审计、边界、路线、损失归因等倾向默认只在少数局部选择中露头，不得连续占据多个大型阶段的核心问题。

Major Reward Anchor（Story Program / Outline / Review 软权威，不新增奖励表）：如果当前 World Horizon 的某个大型阶段本来就有标志性获得、力量质变、兵器/奇物、财富、关系、身份或世界入口作为主要欲望，Story Program 必须在该阶段第一次规划时把**具体主要奖励/获得对象、为什么值得馋、谁也想要或谁因此会重新估价主角**写清；Outline / Review 继承这一对象，不得在下游把它悄悄降成资格、记录、归属确认、责任结算或一串小收益。世界若天然充满粮道、水源、矿权、迁徙、公共资源等 supporting conflict，更要先抓住阶段的大方向：主角真正想拿什么、赢谁、去哪里、变成什么；资源协调只作因果背景，不拆成连续小戏。**奖励方向提前锁，兑现强度不预先克制。** 预先锁定主奖励不限制 Bonus Surprise：只要新奖励有独立因果，大胜仍可激进地同时结算钱、资源、招揽、入口、关系推进或额外发现；不得为了“成熟”“平衡”“长期可写”主动少给。

核心幻想不变量：Character 中已批准的 Power Core 一旦确定，后续 Story Program、Outline、Review 和单章规划不能静默替换这本书最值得幻想的东西。**核心幻想是长期读者承诺，不是主角的人生使命，也不天然拥有每个大型阶段的最高叙事权重。** 它必须持续活着、反复得到有分量的兑现，但某个阶段的主要阅读满足也可以来自人物人生、不可替代的关系或世界自身正在发生的大事。兑现优先抓住这项幻想最独有的**生活特权**，而不是只复用最容易安排的战术用途：如果它真正让人馋的是多一份时间/经历、拥有别人不能占有的东西、改变身体状态、跨越位置或其它特殊生活方式，就在自然适合的修炼、探索、关系、日常或选择中让读者亲自看到这种特权怎样改变人生；不要求逐类覆盖，也不要把独有幻想降格成同一种战斗解法反复放大。能力、装备、资源、关系、身份、领地等可以承载幻想，但不要为了证明核心幻想存在，就把每个阶段都改造成一次能力升级、能力反制或更大版本的同一玩法。

幻想复利优先于操作流程复利：长篇中的 Power Asymmetry 应形成**持续积累的优势栈**，而不是每轮结束重新归零，也不能只让开局那一个能力无限放大。纵向成长可以同时发生三种变化：已有非对称优势继续深化；通过真实故事获得新的非对称优势；旧优势与新优势发生复合，产生任一单项都做不到的新玩法。新的非对称优势可以来自功法、技艺、身体/血脉、奇物/装备、知识经验、伴生体或本书自己的力量来源，只要它真正形成新的 Privilege Delta，而不是小便利、换皮技能或库存加一。全书层面必须让新优势加入并发生可复述的复合效应，但**不要求每个大型阶段新增一项**；人物/关系/世界阶段仍可以没有 Power Delta。开局 Core Asymmetry 继续作为辨识度锚点，新获得不应把它淘汰，而应与旧积累共同改变后续战斗、探索、选择、敌人判断或核心幻想兑现。不要把优势栈写成数据库、组件清单或“收集能力”本身的职业流程。

Outline Fantasy Proof（软规划原则，不新增字段或 Hard Gate）：Growth is a longitudinal invariant, not a per-block form requirement。Power Seed 决定开局 Core Asymmetry grammar；Story Program 决定开局优势的长期成长、后续新 Power Asymmetry 获得与复合；Outline 只负责把已经批准、且确实落入当前规划窗口的 Power / Capability 质变、核心幻想兑现或高价值获得，落实成具体、不可逆、可复述的故事事件。没有这类变化的剧情块可以完全不写 Power 或 Acquisition；不要为了证明核心幻想仍在，就补微升级、小奖励、新权限或新地图。反过来，Story Program 已明确安排的真实成长落入当前窗口时，Outline 不能因为人物故事更强而把它省略。不要用“能力理解更深、体系更完善、行动空间扩大、影响力提升”这种摘要替代真实变化。

Outline World Model Release（Reader Release Scheduler；不新增 Agent、Reader State 数据库或 Hard Gate）：Approved World Vision 决定世界事实；Outline 决定**哪些事实的首次释放时机值得被显式保存**。

在 `## 2. 世界观结构` 内维护一个很短的 `### Reader Release Map`。它不是每章 KPI，也不要求覆盖所有世界设定；只记录当前规划窗口里 timing-sensitive 的首次释放，例如开篇最低生活世界模型、第一次真正进入外部世界、重要势力/地点/身份/资源首次影响选择。每条必须写**具体已批准的 World fact**，不能只写“介绍白角部 / 建立世界观 / 解释商队”。通常事实第一次真正改变当前行动时再释放；但**明显陌生/架空世界的第1章是公共常识定向的例外**：如果 Approved World 已经明确普通人从小知道、且前3章会反复用到的主流力量、粗略强弱尺、当前/下一档社会含义、会改变日常生活的危险规则、常见上升入口或价值物，**默认把其中不同功能的事实拆成 2—3 条 `公共常识` Reader Release**，形成很短的开篇坐标包，而不是把“力量 + 生活 + 社会上升”全压成一条。至少优先区分：①力量/当前与下一档 ruler——若 World 已给出下一档的现实社会 benchmark，就同时写“能做什么 + 在社会上通常意味着什么/能获得什么位置”，不能只列招式效果；②生活危险/共同常识或当前社会位置；③其它确实属于 World 公共常识、且前3章会反复使用的社会入口/价值物。某一类在 World/当前开篇确实不存在时可以省略；它不是每本书固定三条。**具名试场/选拔/招募若其具体回报只由 Story Program / 当前 Plan 批准、并非 World Vision 公共事实，不塞进 Reader Release；它的价值由 Future 10 的 Opportunity Value Orientation 负责。**只覆盖前几章会反复用到的事实，不提前释放旅行细节、隐藏原因或未来 reveal。**World Entry 的 trigger 是人物真正跨过门槛的那一章**：先在 Future 10 中找到最早真正发生“正式上路 / 进入组织或内层 / 第一次实际使用身份入口”的章节 N；如果某条已批准 World fact 正好解释这个门槛为何对第一章位置的人重要，就必须排在 N，而不是 N+1 或更晚。典型错误：N 章已经搭上商队/进入内门/使用通行身份，直到 N+1 第一次遇险、封路或见强者时才补“这个入口为什么重要”；正确做法是在 N 章跨门槛时释放，N+1 只讲新遇到的世界。格式固定为 `- 第N章｜触发：具体 World fact`；同一章最多 1—3 条，绝大多数章节可以没有。若 Future 10 / 当前剧情块把某个答案安排成后续发现、重释或 reveal，则该答案在揭晓章之前**不得进入 Release Map**，即使 World Vision 已经知道；只能释放不会回答该谜题的公共背景。若 World Vision 没有某项事实，也不准为了 Release Map 临时补造。named 未解谜底与尚未揭晓原因继续保持未知。**重要 named 势力 / 部族 / 组织第一次真正进入冲突时，如果 World Authority 已有它的安全公开类别，Release Map 要把“它是什么类型的存在”与当前公共局势一起写入同一条，而不是只写势力名。** 开篇若处于陌生世界，至少保存一条非战力的生活世界定向，但它也必须与第一章实际事件相交；**“普通人没有境界 / 打不过当前敌人”只属于 Ruler，不能单独充当生活世界定向**。生活定向至少回答一项安全边界、普通生活、社会位置或当前场景怎样连接更大世界。不要为了“开篇定向”提前释放尚未发生的旅行、势力或地点事实。

Chapter Runtime 会按章节确定性读取这张 Map，再从 `WORLD AUTHORITY` 取对应事实；因此 Curator / Writer 不再负责猜“这章应该介绍猎墙、猎阶还是别的东西”。Opening Orientation 与 Ruler 分工：前者让读者知道自己身处怎样的生活世界，后者告诉读者强弱/价值/身份差距。两者都嵌在本来就要发生的事件里，不新增 Prelude / Setup 章，也不推迟第一章 Core Fantasy payoff。

Named Opportunity Value Orientation（Story Program → Outline → Director 编译保真软原则，不新增字段或 Reader Release 类型）：当 Story Program / Approved World 已经**具名**一个试场、选拔、招募、拍卖、传承机会、契约或其它具体机会，并明确它的公开目的、通常回报或成功后可打开的身份/资源/行动入口，只要某章的训练、准备、取舍或行动**因这个机会而发生**，Outline 就必须从第一次因果使用开始保留它的具体名字与已批准价值。**不能把上游的“某商盟公开试场 / 某宗门招募 / 某份契约”降成“公开机会 / 一个资格 / 更大的机会”，再等真正获得时才解释它为什么值。**

第一次成为主角当章欲望、取舍或行动理由时，用一句普通话说清“为什么值得争、成功参与通常能打开什么”。这不是提前宣布主角会赢，也不是 Future Result 预支；只是在诱惑真正进入选择前建立它的已批准价值。通用的“以后会有更大机会 / 可以去宗门军府”不能代替眼前这个具名机会的具体价值。如果上游没有批准其回报，不准临时编造；继续保持未知。

Outline 在 Future 10 的该章 `具体剧情` 中保留“**具名机会 + 当前已知价值**”；Director 若该机会仍是本章行动理由，就把同一信息保留进八字段最相关位置，使 Curator / Writer 无需自己猜机会为什么重要。它与 Reader Release 分工：World 公共事实走 Reader Release；Story/Plan 批准的具名机会价值走当前章 Plan。

Persistent Reader Ruler（长期读者坐标软原则，不新增战力数据库）：World Root 的**精确力量主尺**是主角力量成长的固定主坐标；主角在任何时点都应存在一个唯一 `Current Power Position`（几级 / 几星 / 几重 / 哪个数字序列），World Expansion 只延展范围，不重造主尺 Grammar。战绩、价值、天赋/适配、技法熟练度、装备品阶、排名、身份与世界层级仍可作为其它 ruler，但不能把精确主尺重新压成“大致低/中/高档”，也不合成单一总战力分。每当发生显著突破、新能力/新装备/血脉或传承变化、公开测试/比赛、新强敌、越级胜负、高价值获得或世界换挡时，通过当前事件自然刷新：主角**精确在哪一位**、对象精确/大致在哪一位、正常同位置能做到什么、这次超出了多少、下一精确位置/下一大档还有多远。**Ruler = Compression, not Exposition**：一句“43级对58级”“三星斗王打赢五星斗王”往往比三段模糊解释更有效；动作与结果已经成立后，用一次最相关的精确位置 + benchmark / 懂行者比较完成校准，然后立即推进新的选择、机会、敌意、获得、关系或行动。精确位置是公开坐标，不是胜负公式：越级、装备、技能、环境与 Power Asymmetry 继续允许打破同级默认。不要每章报表；重点在突破、越级、新圈层与重大 Public Proof 时让读者持续知道“到底几级、差几级、为什么这次不讲理”。

Plot Pace ≠ Tier Pace（Story Program 长篇节奏原则，不新增阶段字段或升级配额）：故事事件、关系、发现、敌人策略、世界入口、高价值获得和玩法可以快速推进，但不因此同步快速消耗境界/等级主尺。一个仍有丰富对手、武技、装备、关系、探索、越级战与优势复合空间的层级，可以承载多个完整故事块；不要用“进入新阶段”自动触发升一阶或数阶，也不要把境界提升当作证明剧情有进展的默认手段。只有已批准成长因果真正成熟、当前层级的能力与风险边界已被故事充分使用时才自然升档；不规定固定章数。目标是**微观故事快、宏观力量尺有纵深**。

Rapid Growth Needs Protagonist-Specific Causality：如果当前计划真的要让主角在很短篇幅内连续跨越力量主尺，必须让读者看懂**为什么偏偏是这个主角能这么快**。优先由已批准 Core Asymmetry / Advantage Stack 真实改变学习效率、实战反馈、资源利用、风险收益、同时修炼/行动能力、越级获取机会或本书自己的成长因果；世界奖励可以帮助，但不能连续恰好递送每次升级所需材料来替代主角差异。如果当前 Power 并没有提供足够的快速成长因果，就保持 Plot Pace 很快、Tier Pace 慢下来，让同一层级继续承载强敌、装备、关系、探索、越级战和新玩法。

Mystery Before Settlement：当新地点、遗迹、怪物、异象或古物已经自然制造强烈的“这到底是什么 / 为什么会这样 / 深处还有什么”阅读问题时，不要因为它同时涉及矿权、归属、合同、记录或资源价值，就立刻把注意力全部转成结算。允许未知本身持续推动后续探索、危险、人物选择或 Rival 行动；资源与所有权只写到足以改变当前选择。Mystery 不要求故弄玄虚，也不要求延迟公共规则；它只保护已经成立的高价值未知不被行政/合同语言抢走前景。

Effective Opponent Adaptation：长期 Rival / Enemy 观察到主角真实能力边界后，下一次策略更新必须至少一次**真正改变主角的选择、路线、资源、暴露、关系或战局**，而不是只证明“对手学会了”随后仍被主角用原解法轻松化解。反制来自见证、调查或可靠情报，不预制天敌；也不设失败配额。重点是让聪明对手的学习产生现实代价或迫使新玩法，然后主角再靠新的选择/复合优势赢回来。

State Advance After Proof / Choice → Consequence（Outline 软规划原则，不新增字段、状态配额或 Hard Gate）：一个读者问题已经被动作/结果与一次足够的世界内 ruler 校准回答后，不再把“换一批证据继续证明同一结论”规划成独立 story beat；社会证明只有当它会改变身份、机会、敌意、关系、资源、行动入口或重要人物下一步时才继续占用故事时间，否则一次短反应即可。重大选择也不是天然的一整章：当选项、私人欲望与主要代价已经清楚，尽快让人物真正选择，后续篇幅优先进入这个选择造成的新局面。**Stage Settlement = Consequence, not Process Carrier**：大事件已经通过正文结果、现场见证或既有 Canon 让“谁做了什么”足够清楚时，报告、登记、责任说明、复盘、资格发放、赔付或其它程序只压到一句或背景；阶段结算的前景应是有分量的人怎样重新估价、主角实际得到/失去什么、Rival 怎样换位、谁主动找上门，以及下一件更值得想要的机会怎样出现。纸、牌、契约可以确认结果，但除非它们本身就是争夺对象，不要让它们成为升格的主要戏剧载体。**十章批次不是把当前剧情块拉长到十章的配额**：某个锚点或剧情块已经自然完成，就立即进入下一个锚点/相邻剧情块，即使十章还剩很多位置；不要把一次认可拆成确认章、赔付章、专业展示章、资格发放章、再考虑章来填满批次。允许一章只有一条主线，不要求每章塞多个事件；要求的是旧状态一旦成立，就不要原地提高置信度，而要让故事继续产生新的不可逆事实。

主人公连续升格（长篇软原则，不新增字段、KPI 或 Hard Gate）：长篇成长的目标不只是让主角数值越来越强，而是让他不断进入第一章的自己原本没有资格进入的**力量层、人物圈层、世界层、真相层与选择层**，使读者持续感到“他已经不是原来那个位置的人了”。这些不是平行清单，而应尽量互相咬合成因果螺旋：力量/身体或新优势让更高层人物重新估价 → 新身份/关系/入口让他接触更大的世界与更深事实 → 新事实与关系产生新的欲望、敌人和代价 → 他获得过去没有资格作出的选择 → 再推动下一轮成长。进入新圈层时，不默认新受众全知主角全部旧战绩/底牌，也不为了重演打脸而让所有人无脑轻视；不同人物只按自己真实可知的旧名声、公开战绩、身份与已暴露能力先做判断，最低充分的新事实出现后，再分别更新待遇、敌意、合作、招揽或挑战规格。不要逐阶段填满这些维度；同一境界/等级若仍有丰富的被看见、被轻视、被邀请、被研究、关系变化、世界入口、装备/技法与认知重释，就让主角在这个位置真正生活一段故事，而不是用升阶替代升格。认知升格尤其允许旧人物、旧物、旧事件与世界解释在后续获得更大分量，但不强制隐藏身世或把所有未知并成一个幕后真相。

成熟第二幻想轴（Story Program / Outline / Review 软原则，不新增字段或副职配额）：职业、专业或技艺不天然只是 Supporting Logic。Story Program 应主动检查 Approved World 是否已经存在一条**即使完全不反哺主战力，读者仍会想看某个人把它练到顶**的强者道路——有可理解的强弱差、真正顶层人物、可见胜负或作品比较、稀有高价值成果与社会价格——不要仅因为它不是 Core Power 就自动忽略。只有具体 Human 真会被这条路的作品、胜负、钱、身份、审美、人物或生活方式牵引时，主角才真实投入；若 Human 不想走，就让它继续属于世界或配角，而不是强塞兼职。普通练习、制作步骤、重复考核和实施流程继续压缩；重点写真正改变分量的作品、胜负、稀有创造、强者认可与不可替代机会。副轴可以长期停在同一等级、暂时被放下或最终不成为主角道路；是否投入、投入多深、是否为它牺牲主轴机会，必须由 Human 的具体欲望与关系决定。不要为了证明系统丰富而给每本书强塞副职。

可判定兑现债务（Story Program / Outline / Review 软原则，不新增 PayoffDebt Schema）：当故事自然出现强挑战、公开承诺、期限、救人条件、比赛、赌约或其它真正值得长期追的旧债时，允许把其中**少量**做成可判定的长期牵引：有具体对象，并至少有一个读者可观察的结算条件，例如时间窗口、场域/事件、资格条件或明确结果。它的作用是让读者知道“离结账还有多远”，不是把全书变成倒计时；中间仍可由关系、世界事件、其它欲望与机会改路。债务可以错过、失效、延期、输掉或被人物主动放弃，不保证主角追回或获胜；普通 Open Promise 不需要全部债务化。

Power Asymmetry Reveal / Social Proof（软原则，不新增字段或 Hard Gate）：主角在他人面前第一次显露新非对称优势、新层级或意外复合时，先让超标结果发生。公开场合如果本来就有足够见证者，**群体震动 / 全场鸦雀无声 / 喧哗骤停 / 所有人震惊 / 目光集中等场面反应本身就是正当爽点；懂行者的 Ruler Calibration 与关键人物的 Behavioral Repricing 同样是正当爽点，三者没有高低之分，也不要求相互替代。大型 Public Proof 节点默认允许三者一起吃满。** 精确力量主尺现在是这三条线的共同坐标：①群体震动不是空喊“好强”，而是让现场知道一个明确的数字差/跨档事实真的发生了；②最有资格者的 Ruler Calibration 在当前 Public Proof 与主力量相关时，优先直接说出主角**当前精确位置**、正常同位置/对手精确位置，以及这次到底越了几级/几星/几重或跨了哪一档；③ Behavioral Repricing 必须让至少一个真正有利益/关系位置的人因为这个**精确位置 + 超标表现**改口、加价、退距、换战术、招揽、敌视、保护或改变准入。**精确尺只校准位置，不决定战斗结果**：越级胜负仍由技能、装备、环境、经验与 Power Asymmetry 共同造成，不能把“赢了高等级”反推成主角等级自动提升。没有真实围观者时不凭空造群众；普通重复使用也不反复演同一套震惊，但第一次公开、第一次新层级、第一次新复合、进入更高圈层后第一次被看见、或旧估值明显落后时，允许把这一轮 Public Proof 吃满。**社会震荡强度要跟精确跨档幅度一起升级**：地方级小越级可以局部改价；大数字差、跨大境界、一城核心、王朝高位、世界顶层这类跃迁，必须先让身份、待遇、机会、敌人策略和传奇重量至少有一项明显落地，再进入普通结算。不要刚完成世界级突破就用“钱什么时候到账”立刻关闭高潮；先让这个世界知道主角现在到底是几级/几星/几重、这意味着什么，再允许人物用自己的性格接下一句。

Outline Core Gameplay Variation（前期玩法软规划原则，不新增字段或 Hard Gate）：第一次高光解决“它能不能做到”；后续推进为“为什么选这个对象/时机/用法、别人怎样针对、同一优势还能产生什么不同结果”。上一轮已证明有效的解法不要自动解决下一轮主要问题；下一轮优先攻击它尚未解决的对象、关系、资源、目标或条件，或迫使主角换一种用法。相邻高潮若仍是同一对手、同一种能力使用和同一种胜负翻转，只换场地或限制，默认视为重复。长期对手可暂时作为强弱标尺、旁观者或反制者；不要求机械让主角失败或每轮添加新代价。

Outline Story Anchor Density（软规划原则，不新增字段、评分或 Hard Gate）：中期大型剧情块不能只给一个覆盖十几二十章的阶段摘要，再把“中间具体发生什么”留给 Director 自己发明。每个剧情块在现有“具体发生”字段内，先用一句写清本块真正的故事主问题，再按因果顺序给出若干连续故事锚点；通常 3—5 个，只有很短的块可以 2 个，这只是内容密度参考，不是计数门禁。每个锚点是一次会改变局势的故事事件：写清谁为了什么采取行动、谁阻止或回应、主角做了什么关键选择或怎样使用核心优势、最后哪项关系/身份/力量/利益/行动空间发生不可逆变化，以及这个结果为什么触发下一锚点。**World Entry = Threat + Desire + Ruler**：重要新地点、势力、长期 Rival、传承或高价值机会第一次真正进入故事时，锚点先保留“为什么值得靠近/争、它相对主角当前位置有多重、谁已经为它付代价或冒险”，再安排必要危险与移动；不要让撤退路线、车队操作、登记或其它 supporting implementation 抢走入口本身。若后续要让主角放弃或失去某个高价值机会，必须先让读者知道它具体能带来什么、谁为它争、主角为什么会馋，否则机会成本只存在于计划里。长期 Rival 第一次进入时，如果 Approved World / Story 已有可用尺度，就用其层级、战绩、稀有能力、排名或真实位置中最相关的一项把他变成 Reader Ruler，不把 Rival 只写成态度合理的人。锚点粒度停在“故事转折”，不要继续拆成路线选择、受力判断、搬运、制作、检测、计算、逐步验证等实施步骤；如果去掉操作过程后一个锚点就没有人物利益、力量差、关系变化、身份变化、资源得失、世界入口或不可逆结果，它就过于操作化。目标是提高故事确定性，不是提高施工步骤确定性。

High-Value Acquisition / Reward Opportunity（Story Program / Outline 软规划原则，不新增字段、评分或 Hard Gate）：成熟男频长篇可以持续让主角得到真正值得想要的东西，但“奖励”是广义获得，不只指宝物，也可以是力量、功法、身体/血脉变化、标志性武器、稀有知识、伙伴、身份、称号、进入资格、世界入口、传承或规则层能力。高价值获得优先经过故事机会与主角行动真正变成主角可用的东西；重要奖励最好尽快通过一个具体场面证明“它真值”，并让主角从此能做过去做不到的事、让别人改变判断或打开新的世界入口。**Access / Identity 是真实奖励，但不能长期替代 Fantasy Possession。** 当当前故事已经把某门功法、兵器、身体变化、奇物、传承或其它具体对象变成主要欲望时，先让读者知道它为什么值、谁愿意为它冒险、拿到后具体能做什么；再让争取、到手、错失或被迫放弃发生。若一时拿不到，也要让这个未兑现对象和距离继续成为清楚的近期欲望，而不是不断用新资格、牌证、正式记录或更多入口替代“真正拥有”。**真实错失允许有空窗**：人物刚因关键选择放弃一个已经建立欲望的高价值对象时，不要仅为保持 payoff 在同一场景或同一结算窗口立刻塞入分量/功能近似的替代奖励来抵消机会成本；除非那个替代物在此前因果中本就独立成立，并且取得它本身仍有新的选择与代价。旧奖励可以在几十章后换场景复用，或从工具重新解释成身份、秘密、关系承诺、世界入口乃至更高层条件；这种复用属于叙事复利。奖励只在当前故事存在真实欲望、机会与后续用途时出现；阶段可以没有新的标志性获得，奖励类型与出现顺序由本书因果决定。**一场大胜允许复合结算，一次探索也允许目标之外出现意外好东西**：主奖品、奖金/资源、招揽/入口，以及大型阶段后的据点、队伍、产业或长期收入，只要分别有当前因果，就不因“同时得到多项”而主动删减。Story Program 只需要规划阶段之间获得体验怎样自然变化；Outline 再把真正重要的机会、争夺/选择、到手、第一次证明和后续回收落进具体故事锚点，Director 不负责凭空发明计划之外的大奖励。

Plot Engine Diversity：同一个强主循环可以长期复用，但相邻剧情块不能只是更换地图、货物、任务名或对手名字后重复同一种发动方式。判断整体故事时，优先让目标性质、对手行动方式、冲突来源、主角必须做的关键决定、核心优势的使用方式、兑现形态或世界后果发生至少一种真正有故事意义的变化。不要把这个原则实现成逐项打勾；变化已经足以产生不同阅读体验时就正常推进。尤其避免长期退化为“接到问题 → 分析规则 → 按步骤解决 → 得到结算 → 接下一个类似问题”。

震撼式长期重释（Story Program / Outline 软原则，不新增必填字段或 Hard Gate）：成熟长篇应保留少量能够让读者真正惊讶甚至产生 shock 爽感的重释机会。高价值重释同时满足三点：揭晓当下足够意外；回看前文时旧事实、旧异常、人物行为或既有证据能够重新扣合，而不是临时空降答案；揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局之一。来源可以是能力真相、人物身份/过去、关系、旧事件、宝物、敌我关系或世界联系，不默认等于隐藏血脉/身世，也不要求每阶段安排一次。**不要让所有高价值重释都只发生在世界层。** 当 Character / Power / 已批准旧事实自然提供可回收锚点时，Story Program 应保留主角级纵深：能力来源或真正含义、旧人、旧物、旧关系、一次当时看似普通的旧事实，都可以在后期被重新理解，并立即改变主角的力量、身份、关系或选择；不得为了制造 Personal Myth 凭空补身世、父母大佬或未批准旧史。Story Program 负责保留可回收纵深与真正有分量的重释机会；Outline 只在已批准长期因果需要时安排铺垫、误读、证据与揭晓，不为了“伏笔感”制造无意义谜语或把所有未知并成一个幕后真相。

经营文 Decision > Implementation：作者明确选择经营、建设、职业、生产或组织成长题材时，不需要回避经营细节，但主要戏剧价值优先来自决策而不是实施流水账：押注什么、资源投向哪里、舍弃什么机会、怎样定价或扩张、与谁合作或竞争、承担什么风险、对手如何回应，以及一次选择怎样改变后续局面。采购、排班、搬运、施工、生产、核验、重复执行等实施步骤，只在其中仍存在关键不确定性、选择、冲突或反转时展开；决定已经做完以后，普通实施默认压缩。规模增长最好带来新的战略选择与竞争格局，而不是只有吞吐量、节点数和流程精度增加。

Payoff-first 成本节奏：成熟不等于每次胜利立即受伤、负债、被审查或承担新责任。默认顺序是：胜利或突破真正发生 → 外界反应 → 主角获得实际收益 → 收益改变行动空间 → 再决定是否需要代价或余波。普通小胜允许明显净收益；阶段大胜通常应当收益明显大于当前成本。成本只在真实需要时限制选择、迫使策略或推动换挡，不作为每次 Payoff 的固定税。

开书前三章专用合同（只适用于本书开头第1—3章，不扩展为全书每三章的规律，也不是 Schema 或 Hard Gate）：

第一章的进入顺序优先为：具体的人正在面对什么问题 → 失败会导致什么具体后果 → 当前行动与开篇定向需要理解的公共世界事实 / 规则 → 主角立即行动。**World fact 的选择权在 World + Outline，不在 Writer**：如果当前章 `具体剧情` / Reader Release 已排程开篇公共常识，Curator 必须保留，Primary 用普通陈述句直接落实；如果 Plan 没排程，Primary 不自己从完整 World 里挑一段补课。明显陌生/架空世界的前三章不是阅读理解题：读者应能很轻松地知道“这个世界主要靠什么力量运行、粗略怎样分强弱、主角大致在哪、下一档意味着什么、哪些危险/生活习惯是大家的常识、什么入口或东西值得往上争”。这些是公共常识时可以直接说，不要求先靠火盆、服装、动作或对白让读者自己猜。不要先把世界模型讲完再放主角进去，也不要把世界定向做成独立 Setup 事件；只释放前几章会反复使用的坐标，隐藏原因和未来 reveal 继续后放。

第一章必须让主角面对逼近的现实问题并采取行动。章末前，核心非对称优势必须造成一次真实、可见、不可替代的现实结果；只听见、看见、感知、得到坐标、知道未来、出现面板、能力似乎觉醒或“下章再试”都不算兑现。先让动作、结果、他人反应和主角实际所得成立，再保留尚未解释的成长空间；第一次展示要强，但不要提前结算第二章本应完成的能力拥有、第二次使用或正式升级。

核心优势第一次真实使用后，要让普通读者用一句朴素的话暂时知道主角现在能做什么，以及为什么刚才的结果和普通人不同。能力来源、本体、全部限制和终极机制可以后置；不要只用隐喻、排除法或感受描写，让读者在“幻觉、记忆、残魂、技能、时间回溯、力量残留”等多个解释之间猜当前最基本的能力效果。

第二章优先把第一次震撼变成主角真正可以保留、再次调用或据为己有的优势，例如能力、装备、资源、身份、入口、控制权、情报或关系优势，并让世界或人物因这个结果改变行动；不要连续停留在发现、确认、再确认。

第三章优先让前两章的收益进入下一轮主动行动，得到新的资源、能力、关系变化、位置或机会，形成第一次小复利闭环。前三章不要把找到方向、确认坐标、准备进入、即将获得连续当作主要结果。

关键选择除了“正确”，还应暴露本书主角自己的欲望、偏执、野心、护短、贪欲、傲气、好奇、狠劲或独特习惯；不要机械添加缺点，也不要把所有主角统一写成狂傲或冷静正确的执行者。

阶段推进优先（软规划原则，不是固定频率、评分项或 Hard Gate）：
连续章节同时判断事件推进和阶段推进。如果连续章节主要重复“障碍出现 → 分析结构或规则 → 使用相似能力解决 → 立刻出现下一障碍”，而人物身份、关系、资源、行动空间、主动目标、敌人策略和故事舞台没有实质变化，应在当前计划允许的范围内压缩或合并这些过程，不要继续拆成独立章节。重复本身若确实产生新的阶段意义，可以保留。

规划十章时，优先让读者感到多个真实阶段：主角主动目标改变或升级，身份或社会评价改变，关键关系改变，重要资源开始稳定利用，被帮助者形成反哺，敌人策略调整，进入新的行动舞台，或主角从解决别人给的问题转向主动建设、获取或改变某件事。不要把它实现成每 N 章必须发生一次的计数规则。

章末推动力不默认等于新危险，也可以是新选择、新机会、身份重定义、关系转折、实际资源到账、新发现或主角主动决定的下一步。高价值行动之后允许有短暂但有效的结算；只有真正改变关系或未来行动空间时才安排社会回声。

Outline 是 **Story Program 的执行编译层，不是第二个 Story Program**。Authority ≠ Scheduling：Power Seed 决定开局 Core Asymmetry 怎样成长；Story Program 决定开局优势怎样实现、后续新 Power Asymmetry 怎样获得并与旧优势复合；Outline 只决定已批准变化在当前窗口里通过哪些具体事件发生。不得为了让剧情块“完整”而自行新增 Power Asymmetry、重新安排力量成长、补小奖励、造新权限、开新地图或把人物成熟冒充 Power / Capability。

**`World Horizon Handoff` 是 Outline 的前向边界。** 如果已批准 Story Program 已明确一个尚未执行的 Handoff，Outline 只能把当前已批准 World Horizon 内的事件具体化到该触发条件成立；不得为了填满“中期窗口 / 未来十章 / 约100章”越过 Handoff 自行发明下一大陆、下一异世界、下一套公共规则、下一份新 Power 或下一阶段 Story。若 Handoff 落在当前十章批次内，Future 10 只列到 Handoff 触发章即可，剩余章数不补占位、不写“待定章节”；先执行 `World Expansion → Current Character → Story Refresh`，再由刷新后的 Story Program / Outline 继续。若 Handoff=`NOT YET`，正常规划当前世界层，不因固定章数强行扩张。

核心幻想、力量占有欲、主角欲望、人物关系和世界事件都可以成为某段故事的主要阅读满足；不要求每块平均覆盖。Supporting Logic 只在改变选择、胜负或结果时展开。Action Space / Expectation Ladder / Mystery Depth / Impact 仍可作为后台读者体验坐标，但只通过具体锚点与实际 Delta 自然显现，不生成对应必填字段。

# PROTAGONIST-BLIND WORLD VISION

听雨城建在黑岩丘陵之间，常年阴雨，城下有许多旧井、废渠和早于现王朝的石层。城市本身不是围绕任何未来主角建立的。

## 普通人的生活与上升
普通人靠铸刀、药草、运盐、旧物交易和城外雨兽狩猎生活。想离开底层，最常见的路是进入护街队、雨猎队、兵坊或商行；有钱人会购买纹师教习和更好的兵器。

人以身体承载“雨纹”，能强化速度、力量、感知或兵器控制。能力仍服从具体身体、兵器和经验，不是单一战力公式。

高阶雨纹术、能承载多重纹路的兵器、雨兽骨核、旧朝兵库钥物、完整旧井地图都很值钱。真正能证明来源的古物会被兵坊、收藏家和城主府同时出高价。

## 世界正在发生的大事
一场持续三个月的异常长雨让旧井区不断塌陷；三大兵坊正在争一批从地下冲出的旧朝兵器；城主府准备彻底封死最深的几口井。

## 值得进入的地点、奇观与未知
旧井区深处有一口被陆家旧院墙体包住的“回影井”。它偶尔会吐出无法解释的旧物，但几十年来没有形成可靠规律，也没有人知道井下究竟通向哪里。

## 世界知识边界
普通人知道旧井危险、旧朝遗物值钱、地下有早于听雨城的石层；不知道任何所谓平行城市、时间回流、复制世界或幕后系统。
当前没人能完整解释的事实包括：回影井为什么偶尔吐出与城中物件高度相似的东西；这些东西是否真有共同来源；井下最深处是否存在可通行空间。

## 当前 Re-Collision

异常长雨仍在推动旧井坍塌、旧朝兵器出土、三大兵坊争货与城主府封井；这些变化不等待陆昭，也不是为了适配钉影而发生。

陆昭带着黑铁兵库钥牌去旧物市，只想确认它值多少钱、怎样卖得最贵又不失去所有权。柳棠愿意押上鉴定声誉陪他回井查验。第3章的现场事件却证明：回影井塌口之后不是一间吐物密室，而是活人能够短暂进入、再带着持续物理异常返回的实地。

这次揭晓不会给出来源答案，只会立刻改变现实：

- 城主府把回影井从危险废井重新定价为必须控制的入口；
- 三大兵坊从争买钥牌，转为争夺进入权以及被带回之物；
- 黑柄短刀上的异常让它升值，也使陆昭更难隐藏自己曾经进去过；
- 柳棠从估客变成唯一共同见证者之一；
- 陆昭不再愿意卖掉钥牌。他准备出售别人观看、验证或进入一次的资格，却坚持入口收益和真正值钱的东西必须先归自己。

他进入不是为了拯救听雨城，也不是因为相信自己负有查明世界的责任。他第一次踏进去，是为了抢回自己的刀；以后继续靠近，则因为钱、独占、胜负和哥哥留下的可能痕迹轮流压过安全。

## 当前 Power / Human / World 的长期张力

陆昭当前只有纹阶4。普通护街、雨猎骨干已在纹阶7—10，能够决定封井和兵器分配的人远强于他。他握有的钥牌、异常短刀和现场经历，社会价值已经超过他能够正面保护的范围。

钉影每日最多三次，对明显强者只能制造极短停顿。它适合改变一次抢夺、兵器转折或石门闭合的结果，却不能让陆昭获得长期压制。真正的张力不是他能否突然越级，而是他能否把三个短暂机会用在最值钱的瞬间。

井后异常没有替他的能力补齐缺口。黑柄短刀留下的异常首先是证据、价格与暴露风险，不直接增加锋利度或纹阶。陆昭必须依靠钱购买正规教习、依靠雨猎与实战正常成长。

陆昭的选择排序仍然不稳定：

- 足够大的钱会让他考虑退出；
- 能赢过轻视自己的人，会让他拒绝更稳妥的交易；
- 稀有且可能独占的东西，会让他亲自冒险；
- 陆峥的明确实物会突然改变前述计算；
- 柳棠只有在经历共同获利、真实背约与不可替代的救援后，才可能成为他不肯按最高价出售的私人偏心。

世界各方也不共享目标。兵坊要兵器和可重复利用的入口，城主府要控制坍塌与未知后果，旧物市要维护真伪与来源定价，旧井居民要保住房屋和生计。陆昭即使消失，他们仍会继续争夺。

## 本阶段核心情节发动机与变化后的主要 Reading Question

本阶段的发动机是：

**入口所有权、返回后果与不能同时兑现的私人占有。**

故事不采用连续“接任务—进井—带货—领奖”循环。每一次进入、拒售、公开见证、物件变化或关系背约，都必须改变入口由谁控制、什么东西升值、谁被迫合作、谁转为抢夺，以及陆昭下一次愿意拿什么冒险。

初始 Reading Question 是：

**钥牌到底值多少钱，纹阶4的陆昭能不能把它真正留在自己手里？**

第3章后变化为：

**当井后确实能进去，而进入者和携入物都会带回无法立即解释的现实后果时，谁能决定这条路、这些东西以及返回的人归谁处置？**

陆峥实物出现后再变化为：

**陆昭一直认为万物都有价；哥哥留下的具体证据出现时，他究竟有什么不肯卖，又愿意让谁为自己的偏心付代价？**

每次 Mystery Reveal 只回答行动所需的一层，并立即造成加价、封锁、敌对、物品状态变化或关系决裂，不把未知机制写成说明。

## 不可替代的人与关系

**陆峥**

陆峥不是谜底提示器。只有一件能够由当场有效证据确认属于他的实物出现时，才改变陆昭路线。

这件实物不证明陆峥仍活着，不证明他亲自进入井后，也不证明回影井因陆家而存在。它唯一确定的关系作用是：若没有它，陆昭会接受足够高的退出报价；它出现后，陆昭会拒绝交出全部证据，并要求亲自保留一次深入资格。

**柳棠**

柳棠是靠鉴定声誉吃饭的年轻估客，原本便想借地下兵器潮积累独立开桌的本钱。她不是为帮助陆昭查哥哥而存在。

她在第3章共同见证异常，因此愿意与陆昭合作出售见证权、组织竞价并保存不能被单方篡改的实物事实。陆昭的胆量和独占欲能让她赚到过去接触不到的钱，也会让她承担合同失效和声誉受损。

陆昭后来为了陆峥实物改变双方已经接受的结算，使柳棠遭受真实损失。她不会因为理解他的感情便立刻原谅。最终陆昭必须放弃一件真正昂贵的眼前收益，才能证明她不是一张可以赔钱了事的账。

**身份未知的收货者**

此人已经在第1章实际抢夺钥牌，是当前唯一具有既成敌意的行动者。

本轮不替其补写过去身份、雇主或第1章动机。其后续功能是持续证明：有人比陆昭更强、更早盯上钥牌，也愿意在各方尚未达成公开规则前直接夺取。其真实身份与第一次行动原因继续为 `UNKNOWN`，直到未来正文获得新的当场事实。

## 未来大型阶段

### 第一阶段：钥牌不再只是一件货

**具体世界问题：**陆昭带钥牌进入旧物市时，兵坊买家仍把它视为可能与第一枚钥牌有关的昂贵古物。第3章的现场事件却证明回影井塌口后存在能够进入并返回的异常石道，陆昭的伤口与黑柄短刀都留下离井后仍持续的异常。

**主要推动者：**急于估价套现的陆昭、愿意押鉴定声誉的柳棠、追索钥牌的身份未知收货者，以及闻讯加价的兵坊买家。

**主角关键选择：**陆昭可以把钥牌、异常短刀和现场经历一起卖给一家兵坊，立即取得足以改变生活的安全价码；他选择只出售一次受控见证与后续竞价资格，坚持钥牌和黑柄短刀仍归自己。

**最主要阅读满足：**一个纹阶4的旧物贩子亲眼踏进不该存在的实地后，没有把东西交给更懂、更强的人，而是立即把震惊变成自己的价码，并逼原本可以随意压价的人重新排队。

**真实 Delta：**

- Asset：黑铁兵库钥牌继续归陆昭；黑柄短刀出现持续可见的异常水痕，但没有确认战力提升。
- Money：陆昭取得第一笔见证订金，不再只能接受旧物市底层价格。
- Relationship：柳棠成为共同见证者，与陆昭形成共享收益、也共享暴露风险的关系。
- Identity：陆昭从普通旧物贩子变成已实际进入并返回的钥牌持有人。
- Knowledge：井后存在可由活人进入、返回的异常石道；进入者和携入物可能带回持续后果。形成原因、持续时间和可逆性仍为 `UNKNOWN`。
- World：城主府提前封井处置，三大兵坊从争买古物转为争夺进入与见证资格。

**旧积累怎样继续生效：**陆昭因为黑柄短刀本来就属于自己，才在无法确定收益时冒险追回；钥牌使他拥有谈判筹码；第1章已经暴露的钉影仍只能帮他争取瞬间，不能阻止强者长期跟踪。

**下一阶段为何自然发生：**异常已经由柳棠共同见证，无法继续作为陆昭一人的秘密；第一枚钥牌的持有人、兵坊与城主府都必须确认两枚钥牌是否作用于同一入口。

### 第二阶段：两把钥牌，一个井口

**具体世界问题：**第一枚钥牌被带到回影井后，也能使第3章出现过的同一处石纹产生反应。现有检验仍无法把任何一枚判成赝品。两枚钥牌的存在使入口控制、地下兵器归属和封井权限同时失去稳定依据。

**主要推动者：**掌握第一枚钥牌的一家兵坊、准备限制进入的城主府人员、维护公开见证可信度的柳棠，以及只愿出售一次资格的陆昭。

**主角关键选择：**兵坊提出买断陆昭的钥牌、短刀和退出承诺；若接受，他可以安全离开争夺。陆昭为了保住独占可能，也为了当众赢过曾认定他只能低价卖货的人，选择保留钥牌，只允许一次有价开启。

**最主要阅读满足：**两枚都不能判假的钥牌在同一个井口产生真实作用，整座旧物市场和兵坊当场改价；陆昭把一次无法解释的事实换成正规成长、兵器所有权和新的社会位置。

**真实 Delta：**

- Power：陆昭将收益投入正规纹师教习，并经雨猎与实际冲突达到纹阶7，进入护街、雨猎骨干的正常起点。
- Public Proof：面对纹阶10的强夺者，陆昭不能正面取胜，只能以钉影短暂钉住对方兵器，保住钥牌易手的决定性瞬间。现场明确看见纹阶7与纹阶10的差距，也看见他三个瞬间的价值。
- Asset：陆昭在地下兵器分配中取得一柄可承载多重纹路的旧朝锁镰。他首先看中的是价格，而不是适配。
- Relationship：柳棠因这次公开见证获得声誉与收入，也开始要求陆昭遵守双方约定的结算。
- Identity：兵坊开始把陆昭当成需要直接收买、限制或击败的入口持有人。
- Knowledge：两枚钥牌都能作用于同一入口，但为何存在两枚、彼此是什么关系仍为 `UNKNOWN`。
- World：城主府给出明确的最终封井期限；三大兵坊必须在期限前完成一次利益结算。

**旧积累怎样继续生效：**第一阶段保住的钥牌成为进入资格；订金转化为正常纹阶成长；异常短刀提供无法轻易否认的现场证据，却也持续暴露陆昭。

**下一阶段为何自然发生：**两枚钥牌都有效，使入口不可能被一次买断解决。城主府准备封井，兵坊准备抢走最后一批旧朝兵器；就在各方安排最终结算时，回影井再次吐出与陆峥有关的实物。

### 第三阶段：哥哥留下的东西不能一起卖

**具体世界问题：**城主府因持续坍塌和返回后果加速清场，兵坊则要求在封井前完成最后一次集中进入。此时，一件由当场有效证据确认属于陆峥的实物出现，各方立即把它与钥牌、异常短刀和进入记录一起定价。

**主要推动者：**执行清场的城主府、要求整体买断的兵坊、坚持按协议结算的柳棠、企图夺物的身份未知收货者，以及第一次无法只看价格的陆昭。

**主角关键选择：**最高买家愿意支付确定的大钱，条件是陆昭交出两件关键实物、退出入口争夺并放弃追索。若没有陆峥实物，他会接受；因为它出现，他改变交易，宁可失去现金和柳棠应得的结算，也要保留钥牌、哥哥实物和一次亲自深入的资格。

**最主要阅读满足：**陆昭嘴上认定已经没了的人，第一次以一件具体实物击穿他的收益排序；与此同时，他把原本只因昂贵而选中的笨重锁镰，变成只有自己能打出异常转折的兵器。

**真实 Delta：**

- Asset：陆昭保有陆峥实物。它只证明一件属于陆峥的东西出现在当前异常链条中，不证明陆峥的去向或经历。
- Power：陆昭发现钉住自己飞出锁镰的影子，可以令锁镰在半途短暂停住，改变一次回收或换向时机；该动作共享原有每日三次额度。
- Relationship：陆昭改变交易使柳棠遭受真实金钱与声誉损失。两人的利益同盟出现无法用一句道歉抹平的裂痕。
- Identity：陆昭从可以被高价买断的人，变成各方无法稳定预测其底价的人。
- Enemy：一家失去买断机会的兵坊转为公开敌对；身份未知收货者再次逼近钥牌与陆峥实物。
- Knowledge：陆峥与当前异常实物链之间出现可追联系，具体原因继续为 `UNKNOWN`。

**旧积累怎样继续生效：**陆昭的占有欲使他既不肯交钥牌，也不肯交哥哥实物；好胜使他拒绝被清出局；黑柄短刀、锁镰和钉影形成近身与远距转折两种手段。柳棠过去押给他的声誉，使这次违约必然留下关系后果。

**下一阶段为何自然发生：**陆昭已经保住进入资格，却失去安全退出的机会。封井期限、关系裂痕、两枚钥牌与各方最后一次夺取同时逼近，只能在井口完成最终结算。

### 第四阶段：封井也收不回已经发生的事

**具体世界问题：**异常长雨使最深井区再次坍塌。城主府必须封闭危险井道，三大兵坊却都想在入口失去前带走兵器、地图和两枚钥牌。旧井居民的撤离、兵坊抢夺与石道闭合发生在同一场冲突中。

**主要推动者：**执行封井的城主府强者、掌握第一枚钥牌的兵坊、争夺最大收益的其他兵坊、陆昭、柳棠与身份未知收货者。

**主角关键选择：**石道收缩时，陆昭可以用最后一次钉影夺下一批价值最高的旧朝兵器；也可以钉住闭合石门的影子，为被困的柳棠争取脱身瞬间。陆昭选择后者。他不是放弃所有收益，而是不允许一个已经被自己拖进损失的人被当成可以赔价的东西。

**最主要阅读满足：**纹阶、钉影、锁镰、贪欲、胜负心和私人关系在一次不可兼得的选择中同时兑现。陆昭失去眼前最贵的一批兵器，却保住钥牌、哥哥实物、旧井地图和一个真正会改变他路线的人。

**真实 Delta：**

- Power：陆昭通过本阶段持续的正规教习、雨猎和实战达到纹阶12，进入能够独自猎杀大型雨兽的正常门槛。
- Public Proof：陆昭以钉影和锁镰制造一次超出普通纹阶12兵器控制者预期的转折，但仍不能正面击败纹阶21以上的城级名手。
- Asset：黑柄短刀、旧朝锁镰、第二枚兵库钥牌、陆峥实物和一张完整旧井地图继续由陆昭持有。
- Relationship：柳棠确认陆昭会为她放弃真正昂贵的利益；陆昭也确认她没有趁乱带走共同证据。两人进入欲望、账目和信任无法再完全分开的关系。
- Identity：陆昭成为听雨城公开掌握异常钥物、地图和进入经历的人，不再是可以随意压价的底层旧物贩子。
- World：大部分危险井道被封闭，回影井入口则因兵坊、城主府和钥牌持有人相互制约，成为被严密控制但尚未完成归属结算的边界。
- Knowledge：完整旧井地图覆盖范围之外仍有可通行石道；其尺度、边界、规律与尽头全部未知。

**旧积累怎样继续生效：**钥牌决定陆昭能否进入谈判；异常短刀持续证明第3章经历；锁镰承载钉影的新用法；哥哥实物决定他不肯退出；柳棠从估客成长为会让他放弃一次最高收益的人。

**下一阶段为何自然发生：**听雨城内部关于封井、兵器、钥牌和旧物定价的第一轮冲突已经完成，但完整旧井地图结束后，石道仍然向外延伸。继续具体规划其环境、势力、资源或规则将越过当前 World Authority，必须进入新的 World Horizon。

## World Horizon Handoff

**触发条件：**

- 第3章已经以现场事件确认井后存在可进入、返回的异常实地，并留下持续现实后果；
- 两枚钥牌都已对同一入口产生真实作用，关系仍未解释；
- 城主府封井、三大兵坊争兵和旧物市定价危机完成当前一轮结算；
- 陆峥实物已经改变陆昭路线，但没有替作者回答陆峥去向；
- 陆昭从纹阶4成长至纹阶12，钉影与锁镰形成边界清楚的复合用法；
- 完整旧井地图已经走到尽头，实际石道仍向地图之外延伸。

**Scope：**`macro`

**为什么当前层已需要扩：**

当前 Effective World 只冻结了听雨城、旧井石层、回影井、城内力量主尺与社会结构。地图之外石道的尺度、环境、居民、势力、资源、正常力量位置和历史均未获得批准。当前层已经足够让人物活出真实获得、敌意、关系与外缘，再继续具体规划会把未知未来偷偷写死。

**Handoff 前最后1—2章的外缘信号：**

封井冲突结束后，陆昭依照完整旧井地图走到最后一个有标记的位置。地图在一面断墙前结束，断墙后的石道却仍能容人通行，并持续伸向现有灯火照不到的地方。现场只确认当前地图不是世界边界，不展示下一层宝物、能力、势力或答案。

**必须 carry forward 的已发生事实：**

- 陆昭精确位置为纹阶12；
- 钉影每日最多三次，明显高阶目标仍会快速挣脱；
- 钉影可与旧朝锁镰形成一次半途急停或换向，共享原有次数；
- 黑柄短刀保留第3章后形成的持续异常状态，其机制和可逆性未知；
- 第二枚兵库钥牌、旧朝锁镰、陆峥实物、完整旧井地图的归属与状态；
- 柳棠与陆昭之间已经发生的共同获利、真实违约、救援与关系重估；
- 城主府、兵坊和旧物市对陆昭的公开估值、敌意与争取；
- 两枚钥牌都作用于同一入口；
- 井后可以进入并返回，进入者和携入物可能带回持续现实后果；
- 回影井来源、完整规律、边界、影响可逆性、两枚钥牌关系、异常物件来源和陆峥去向仍全部开放。

**固定 orchestration：**

`protagonist-blind World Expansion → deterministic Current Character → Story Refresh`

## 仍值得追的旧承诺与新欲望

- 回影井为何会吐出异常旧物，进入者与携入物为何会留下持续后果。
- 黑柄短刀的异常能持续多久、是否可逆，以及它会怎样继续影响交易和隐藏。
- 两枚都能作用于同一入口的钥牌究竟是什么关系。
- 城中第一枚钥牌目前由谁真正控制，下一次利益冲突后归属是否改变。
- 陆峥失踪是否与回影井有关；陆峥是死是活仍未知。
- 身份未知收货者是谁、为什么在第1章抢夺钥牌，继续保持为未解承诺。
- 陆昭想让钥牌、锁镰、地图和下一次进入权真正属于自己，而不是成为兵坊或城主府的临时带路人。
- 陆昭想用锁镰与钉影赢过按纹阶12正常尺度给他定价的人，但真实等级差不会因此消失。
- 柳棠想用这次异常建立自己的鉴定生意，并要求陆昭证明她不是可以事后赔钱的合作工具。
- 陆昭开始想让柳棠在更高价码出现时仍站在自己一边，也必须面对她可能因上一次损失拒绝。
- 地图之外具体有什么，等待下一轮独立 World Expansion，不在当前 Story Program 中预写。

# 当前中期规划窗口

窗口终点：第36章完成最后一次开启后的听雨城阶段结算，并触发已批准的 World Horizon Handoff。陆昭达到纹阶12，保留钥牌、锁镰、陆峥实物和完整旧井地图；柳棠关系发生不可逆变化，最深石锁后的可通行空间成为事实。第36章只停在已知地图边界，不预写边界之外的世界。

## 第1—6章：墙内第二枚

具体发生：陆昭必须在旧院封墙坍塌和强者夺物之前保住第二枚兵库钥牌，并决定它是安全卖掉，还是成为一次公开翻价的赌注。

1. 异常长雨令封墙坍塌，回影井吐出第二枚钥牌；一名更强的收货者试图直接拿走。陆昭用一次钉影钉住滑动钥牌的影子，抢到不可替代的短暂窗口，将钥牌真正抓在自己手里。
2. 陆昭带钥牌进入旧物市找柳棠估价。柳棠确认它与已进入兵坊争抢的第一枚有同铸痕、同编号，但现有手段不能直接判假；她意识到这件东西足以改变旧物市的定价。
3. 兵坊买家开出安全高价，要求陆昭先交物；另一方散布“底层贩子卖假钥”的说法。陆昭拒绝先交所有权，接受柳棠提出的公开真伪赌局。
4. 公开真伪赌局开始。陆昭只出售一次验证机会，不出售钥牌所有权；他押的是更高收益，也押当众判他卖假货的人输一次。
5. 现场比对铸痕、编号和材质仍不能判定第二枚为假；第一枚的持有人或代表被迫带牌到场，两枚的相似性让围观者和兵坊同时失去原有判断。
6. 有人试图在争执中强行拿走第二枚，陆昭再次用钉影制造短暂脱手窗口，按赌局结果拿到第一笔钱；一家兵坊因公开输局和失去低价收购机会，将他列为需要夺物或压服的人。

主要阅读兑现：一个纹阶4的底层旧物贩子，凭三次有限能力中的关键使用，占住了让全城重新报价的东西，并让兵坊在众目睽睽之下改口。

Block Delta：

- Possession：陆昭持有第二枚兵库钥牌。
- Relationship：柳棠以自己的鉴定声誉与陆昭形成临时共同利益。
- Identity / Access：陆昭从可被随意压价的旧物贩子，变成必须直接交涉的钥物持有人。
- Knowledge：两枚钥牌同铸痕、同编号，但来源和真伪关系仍为 `UNKNOWN`。
- Enemy State：至少一家兵坊由低价收购转为夺物、压服或收买。

主要奖励对象：第二枚兵库钥牌。它值得争，是因为它可能开启旧朝石锁，并决定地下兵器归属与持有人议价位置；本阶段兑现的是所有权和定价权，不提前兑现地下兵器。

代价或余波：陆昭失去低调出售、拿钱离开的安全路线；柳棠的声誉被押上赌局。

推向下一块：两枚钥牌都无法被公开判假，争夺不能靠一次交易结束，必须验证它们是否能开启同一道旧朝石锁。

## 第7—15章：两把钥牌开同一道锁

具体发生：在两枚钥牌都成为有效证据后，陆昭必须在安全买断、公开验证和地下兵器选择之间押注，同时把赌局收益转成真实的力量和资产。

1. 兵坊给出更高的确定现金，条件是陆昭交出钥牌并退出旧井争夺；柳棠的保底更低，却能保留钥牌、公开验证结果和地下兵器选择机会。陆昭选择后者。
2. 陆昭把赌局收益的一部分用于正规纹师教习，又接受真实雨猎以继续赚钱，不把钥牌当成一次性卖价。连续实战后，他从纹阶4进入纹阶7。
3. 两枚钥牌被带到同一道旧朝石锁前。陆昭拒绝让任何一方单独掌控验证，柳棠坚持现场见证，兵坊则准备在结果出现后强行改变持有人。
4. 两枚钥牌先后插入，竟然都能开启同一道石锁。“其中一枚是假货”的解释失效，兵坊、旧物市和城主府必须重新估价钥牌和地下兵器。
5. 一名纹阶10的护街骨干公开强夺钥牌。陆昭不能正面胜过对方，却用钉影短暂钉住其兵器影子，保住钥牌的决定性瞬间；现场明确看见纹阶7与纹阶10的差距，也看见陆昭异常的保物能力。
6. 因验证结果与公开强夺，陆昭获得一次地下兵器优先挑选机会。他没有选最顺手的兵器，而选择价值最高、能承载多重纹路的旧朝锁镰。

主要阅读兑现：两件不可能同时成立的真物同时开锁；陆昭从公开赌局拿到钱、纹阶7、社会估值和真正属于自己的旧朝锁镰。

Block Delta：

- Power / Capability：陆昭达到纹阶7；钉影仍每日三次、对明显高阶目标快速失效，但能在公开强夺中制造决定性空当。
- Possession：陆昭取得旧朝锁镰。
- Identity / Access：从钥物持有人进入地下兵器争夺与公开验证的直接参与者。
- Knowledge：两枚钥牌均能开启同一道石锁；为何存在两枚、是否同源仍未知。
- Enemy State：兵坊由低价收购转为直接收买、威胁和强夺。
- Relationship：陆昭与柳棠成为共同持有关键验证事实、收益必须彼此结算的利益同盟。

代价或余波：陆昭公开暴露了能力边界和纹阶位置；敌人不再只针对钥牌价格，而会针对他的身体、路线和见证关系。

推向下一块：公开开锁让地下兵器价值暴涨，城主府不再只是计划封井，而是开始为封井前的最后控制行动设定期限。

## 第16—24章：封井前的最后一场生意

具体发生：城主府准备封死最深井口，兵坊争抢最后一批地下兵器；陆昭必须决定是否用钥牌和验证事实换安全巨款，直到一件明确属于陆峥的实物出现。

1. 旧井继续坍塌，城主府推动封井，三大兵坊抢在封锁前争夺剩余兵器。陆昭凭两枚钥牌有效这一事实，取得进入最后一场交易的谈价位置。
2. 兵坊提出更高报价，要求钥牌、全部验证记录和地下进入权一并交出；柳棠要求按原共同结算执行，陆昭暂时不松口，先保留自己的进入条件。
3. 在封井前的混乱转移中，一件随井水冲出的实物被发现。陆昭从其保留的陆峥使用痕迹中确认它属于失踪两年的哥哥；这一事实只确认归属，不确认陆峥生死、去向或与回影井的关系。
4. 最高买家提高报价，要求陆昭同时交出钥牌、陆峥实物和全部验证记录，并放弃亲自进入最深井区。若没有哥哥实物，陆昭会接受；现在他改变交易。
5. 陆昭拒绝交出全部东西，要求换取封井前的一次进入权，并保留陆峥实物所有权。柳棠因原共同结算和声誉安排被改变而遭受现实损失，两人的关系第一次出现无法用账目抹平的裂痕。
6. 兵坊因失去买断和进入控制，转为公开敌对；城主府将陆昭视为封井行动中的不稳定变量。陆昭仍保住钥牌和哥哥实物，但不再拥有安全离场的高价路线。

主要阅读兑现：陆昭的收益排序第一次被具体属于陆峥的实物击穿；他没有免费交出东西，而是把私人偏心转换成一次真正的进入权。

Block Delta：

- Possession：陆昭保有陆峥实物，并保留钥牌所有权。
- Relationship：柳棠因陆昭改约受损，两人从共同获利进入利益与私人偏心冲突的关系。
- Identity / Access：陆昭从逐利钥物持有人变成各方无法准确预测是否接受最高价的关键变量，并取得一次封井前进入权。
- Knowledge：陆峥与异常实物出现可追联系，但具体关系仍为 `UNKNOWN`。
- Enemy State：一家兵坊转为公开敌对；城主府开始限制陆昭的行动。
- World State：封井从远期计划变成有明确行动压力的现实事件。

代价或余波：陆昭失去安全现金和柳棠原本可得的结算；这是真实机会成本，不由同场新奖励抵消。

推向下一块：进入权已经被争到，但封井期限没有消失；两枚钥牌必须同时到场，所有势力都准备在石锁开启后争夺最大收益。

## 第25—36章：回影井的开口

具体发生：城主府只允许最后一次开启，陆昭必须在优先挑选地下兵器与救出柳棠之间做出不可兼得的选择，并在已知地图边界停下。

1. 最后一次开启前，城主府强者、掌握另一枚钥牌的兵坊和陆昭分别提出控制条件。陆昭拒绝转让钥牌，只接受以持有人身份进入。
2. 两枚钥牌同时到场，石锁再次开启。柳棠负责辨认和保留现场事实，兵坊准备在入口打开后独占兵器、地图与通路。

# 未来十章逐章小纲

批次定位：这十章覆盖“墙内第二枚”并进入“两把钥牌开同一道锁”的起点。主要故事问题是：陆昭能否保住第二枚钥牌，并把一次可以安全卖掉的高价物变成自己控制的公开翻价机会。本批完成钥牌占有、柳棠共同押注、公开真伪赌局、第一笔收益，并在第10章完成两枚钥牌开启同一道石锁的第一次证明。

## 第1章：墙里落下第二枚

具体剧情：异常长雨震裂陆家旧院封墙，回影井吐出第二枚旧朝兵库钥牌。更强的收货者先一步伸手夺物，陆昭用钉影钉住滑动钥牌的影子，在极短窗口内夺回钥牌并用黑柄短刀逼退对方继续抢夺。

结果 / 状态变化：陆昭真正持有第二枚钥牌；钉影第一次产生可见、不可替代的现实结果。读者知道纹阶4仍是普通成年练家范围，也知道旧井区坍塌会直接威胁活命和财物。

叙事功能：完成开篇公共世界定向与核心优势第一次兑现，建立“先占有，再决定卖不卖”的主角选择。

结尾推动：陆昭看见钥牌上的铸痕与编号，意识到它可能和城里正在争抢的第一枚有关，必须去旧物市确认价格。

## 第2章：旧物市不替人保货

具体剧情：陆昭带钥牌进入旧物市找柳棠，却只把物件放在自己手边，不让她先收走。柳棠将它与兵坊争抢的第一枚公开痕迹进行比对，确认同铸痕、同编号，但无法凭现有办法判定哪一枚是假。

结果 / 状态变化：钥牌的异常价值和不可简单定假被确认；柳棠意识到自己的鉴定声誉可能被卷入其中。

叙事功能：把回影井吐出的异常物转成公开交易、声誉和势力冲突。

结尾推动：柳棠提出公开验证；与此同时，兵坊买家已经知道第二枚钥牌到了陆昭手里。

## 第3章：只卖一次验证

具体剧情：兵坊买家给陆昭安全高价，要求先交钥牌并退出争夺；旧物市又出现“底层贩子卖假货”的议论。陆昭看出对方既要物，也要让他失去以后定价的资格，于是拒绝出售所有权。

结果 / 状态变化：陆昭接受柳棠提出的“公开真伪赌局”，只出售一次验证机会；钥牌仍由他持有。

叙事功能：明确机会价值：钥牌若在公开验证中站住，陆昭能得到更高收益和直接议价位置，而不是只换一笔安全钱。

结尾推动：赌局即将开始，第一枚钥牌的持有方被迫出面应战。

## 第4章：两枚牌站上同一张桌

具体剧情：三大兵坊的代表、旧物市商贩和围观者聚集。第一枚钥牌被带到现场，陆昭把第二枚放上桌，却拒绝让任何人单独拿走；柳棠以自己的鉴定声誉押注公开判断。

结果 / 状态变化：两枚钥牌第一次在公开场合并置，铸痕与编号的相似性成为所有人都无法回避的事实。

叙事功能：扩大公共见证范围，让钥牌从私人高价物变成会改变城市定价的异常事件。

结尾推动：赌局进入比对环节，兵坊准备以材质或纹路差异直接判陆昭手里的牌为假。

## 第5章：判不了假的牌

具体剧情：材质、铸痕和纹路逐项比对，仍找不到足以判假的差异。兵坊代表转而攻击陆昭的出身和信誉，要求他先交牌接受更深入检查；陆昭当众拒绝，把赌注压在“他们无法证明是假”这一点上。

结果 / 状态变化：公开判断无法得出假牌结论；柳棠的声誉与陆昭的所有权暂时站在同一边。

叙事功能：让悬疑停留在高价值未知，不用解释替代冲突；让陆昭主动决定公开哪一条证据。

结尾推动：无法赢得判断的兵坊不再准备继续争辩，而准备直接夺物。

## 第6章：赌输的人改口

具体剧情：争执中有人伸手抢第二枚钥牌，陆昭用钉影钉住钥牌影子，借短暂空当收回钥牌并脱离抓取。现场见证者迫使兵坊按赌局结果认赔，兵坊代表却把“不能判假”改说成“必须由兵坊保管”。

结果 / 状态变化：陆昭拿到第一笔足以改变生活的赌局收益，钥牌仍归自己；一家兵坊从压价者转为明确敌意。

叙事功能：完成第一块阶段兑现：占有、公开胜负、即时收益和社会改价同时落地。

结尾推动：柳棠认为继续私下卖牌只会让陆昭失去后续机会；一场更高价值的石锁验证浮出水面。

## 第7章：安全价码之外

具体剧情：兵坊提出更高的买断价，承诺陆昭拿钱退出；柳棠提出保底更低的公开石锁验证，成功后陆昭可以保留钥牌并参与地下兵器选择。陆昭选择后者，并把赌局收益拿去接受正规纹师教习。

结果 / 状态变化：陆昭拒绝安全现金，锁定“保留钥牌、验证结果和进入机会”的路线；力量成长获得真实资源起点。

叙事功能：把第一章的占有欲转成长期行动选择，并建立具名机会“公开石锁验证”的当前价值。

结尾推动：为了继续保住钥牌和训练费用，陆昭必须接下一次雨猎。

## 第8章：纹阶七之前

具体剧情：陆昭不把自己当成兵坊的护送人，而是以自己的风险接下一次雨猎。面对雨中逼近的危险，他用黑柄短刀和剩余的钉影完成一次脱身与取物，随后将收益投入正规教习。

结果 / 状态变化：经过教习与真实战斗，陆昭达到纹阶7；他进入护街、雨猎骨干的正常起点，但仍明显弱于纹阶10以上的强手。

叙事功能：完成第一轮力量真实成长，让读者知道他的等级变化来自个人行动和资源转化，而不是连续天降奖励。

结尾推动：纹阶7的陆昭获得进入石锁验证现场的资格，但兵坊已经为验证后的强夺准备了人手。

## 第9章：钥牌必须同时到场

具体剧情：石锁验证前，柳棠坚持两枚钥牌必须同时到场，不能由一家兵坊单独带牌进入。陆昭接受现场验证，却要求自己的钥牌始终由自己保管；第一枚钥牌的持有方为保住原有主张，只能带牌赴约。

结果 / 状态变化：两枚钥牌和公开见证被固定在同一场验证中；陆昭保住所有权，但无法避免更强对手进入现场。

叙事功能：把公开赌局的结果转化为真正的进入机会，推进到当前阶段的核心问题。

结尾推动：旧朝石锁显露，两个钥匙孔的形制与两枚钥牌分别对应。

## 第10章：两把钥牌开一扇门

具体剧情：第一枚钥牌先行插入，石锁出现反应；第二枚钥牌随后插入，同一道石锁再次完成开启。现场从“哪一枚是假”转成“两枚为什么都能开”，兵坊立刻重新估价陆昭和第二枚钥牌。

结果 / 状态变化：两枚钥牌都有效成为已发生事实；来源关系、形成原因和陆峥关联仍未知。陆昭从可被压价的持有人变成必须被收买、威胁或争取的公开对象。

叙事功能：完成第二阶段的核心悬疑转折，并把故事发动机从真伪判断切换为控制权与地下兵器争夺。

结尾推动：石锁开启后的价值暴涨，城主府开始收紧封井期限；下一章将进入公开强夺和锁镰选择。
