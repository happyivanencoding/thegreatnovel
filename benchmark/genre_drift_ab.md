# Genre Drift A/B：近未来体修

## 旧路径的结构风险

旧 Bootstrap 在一次语义任务里同时解释 premise、题材、九维 Profile 与三个 Foundation。`genre` 只是自由文本，Reader Promise 没有作者确认边界；worldbuilding/themes 的具体描述容易获得更高注意力，造成基础设施、公开听证、身体法权或制度风险分配成为主发动机，而修炼只剩 setting skin。

## 新路径的合同证据

Seed：“近未来的气修修仙小说，体修成神的故事。”

- Primary Adapter Proposal：`MYTHIC_BODY_ANCIENT_WORLD`，Secondary 为 `CULTIVATION_ESCALATION`。
- Setting Skin：`NEAR_FUTURE`，不等于 Primary Genre。
- 核心成长：体修、肉身蜕变与生命层级。
- Topology：`TRANSFORMATIVE + ACCUMULATIVE`。
- Author adjustment 可将修炼成长、资源机会和突破提高到 `VERY_HIGH`。
- `SOCIAL_THEME=LOW`，除非作者明确提高。
- Foundation handoff 冻结同一 Reader / Genre / Progression Proposal，并要求三案只在发动机和因果结构上分化。

## Remove-the-skin 结果

新结构要求资源、身体变化、能力验证和新世界入口至少一项改变解决方法；单纯替换专名后仍是普通制度故事会得到 `GENRE_SKIN_ONLY` 软警告。只有明确否认已确认核心承诺时才是 Hard Failure。

限制：系统可以确定性校验合同共享、数量、状态与显式结构字段；“三个 Foundation 的文学质量与真实结构差异”仍需 handoff 产物和作者人工审阅，不能用关键词伪装成自动文学判断。
