# Custom / OOD Progression 验收

## 失去未来

主体为 Character；成长资源是被放弃的未来；Gate 是不可逆选择；Cost 是永久失去人生路线；Topology 为 Branching + Tradeoff；Delta 支持 Sacrifice 与 Lock-out。Scheduler 可以把战略优势期待映射到承接当前因果，而非强行安排境界突破。

## 城市获得自然法则

主体为 Settlement；Topology 为 Network + Accumulative；共同解决此前不能解决的问题构成 Gate；城市地图、居民权限或自然规则变化构成 Verification。Scheduler 能理解 Team Growth，不寻找单一主角等级。

## 灭亡语言打开现实层

主体为 Character，但成长轴是 Knowledge；知识 Gate、Mystery 与 World Expansion 深度绑定；Combat Priority 为 Off。Knowledge Payoff 进入 `MYSTERY_ADVANCE`，不被替换为传统战斗升级。

三个 seed 均生成 `DerivedAdapterSpec`，经同一 Adapter-free `GenreContract` / `ProgressionContract` / `PayoffChannelProfile` / Scheduler Runtime；结构表面不包含宗门、秘境、学院或擂台回退。

测试：`tests/unit/test_custom_progression_ood_benchmark.py`。
