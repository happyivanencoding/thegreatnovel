# Longitudinal Threads

## 1. 六岁妖灾 → 人族战争 → 英雄归来

- **Thread name**：私人血债如何长成人族战争线
- **Length class**：long
- **Setup**：孟川六岁经历妖灾，十余万人死亡；他以为母亲被杀，在墓前立誓成为神魔、斩妖报仇。战争首先是逃亡、亲人和尸体，不是“守护世界”的抽象命题。`《学其上，仅得其中》L130-L160；《这是好事》L315-L324`
- **Dormancy**：少年阶段主发动机是练刀、道院比试与进入元初山，但服兵役、斩妖盛会、乡下坞堡持续提醒战争一直存在。`《人族和妖族》L1048-L1142`
- **Reminder**：东宁府出现世界入口，柳七月、孟大江、柳夜白、道院弟子、家族长老同时被卷入；近万人死亡，孟川第一次看到故乡级战争的完整后果。`《东宁府之战》L3970-L5249`
- **Escalation**：战争从城关攻防换成放弃府县、集中人口建大城、百万妖王潜入地底，再换成世界间隙内五重天精英战。`《天下动荡》L20038-L20070；《建城》L20102-L20160；《百万妖王的威胁》L23859-L23947`
- **Collision**：真武王燃烧元神和寿命杀死重玄妖圣，妖族绘制连接点地图的计划失败；战争胜利与重要同伴死亡在同一事件结算。`《最后的袭杀（下）》L33156-L33193；《新的时代》L33243-L33267`
- **Payoff**：妖族最后通过妖圣通道强攻，孟川独守入口，以七次坠月击摧毁全部防护，三名入侵者全灭；人族九百余年战争正式获胜。`《战争终章（上）》L38917-L39028；《战争终章（下）》L39031-L39090`
- **Second Payoff / Afterlife**：孟川把无数神魔、凡俗战士画入《脊梁》，战争胜利推动其心灵与元神突破；成为元神八劫境后，他终于能够让薛峰、真武王等历史英雄重返和平世界。`《世界外显》L39450-L39509；《功成》L56482-L56490`
- **Why Reader Cares**：每次战争升级都会夺走具体的人、城和共同生活，而不是只把敌军数字调大。终局“英雄归来”因此回收的是整本书积累的遗憾。
- **Story State Change**：`私人复仇` → `故乡生存` → `天下多点战争` → `主动清剿` → `世界入口终战` → `和平后修复历史遗憾`。
- **Evidence Anchors**：`L130-L160；L3970-L5249；L20038-L20160；L23859-L23947；L33156-L33267；L38917-L39090；L39450-L39509；L56482-L56490`

## 2. 快刀少年 → 救援者 → 地底猎人 → 跨界行动者

- **Thread name**：速度优势不断改变行动半径
- **Length class**：long
- **Setup**：孟川明确选择雷霆神体，不是为了补齐弱点，而是让已有的快刀、身法优势更极端。`《孟大江隐藏的奇珍》L1718-L1733`
- **Dormancy**：早期速度主要用于同辈比试、越阶和自保；面对真正神魔、妖王时，仍然存在清晰的生命层级差距。`《秘技“三秋叶”》L651-L711；《东宁府之战》L4723-L4987`
- **Reminder**：成神魔后，速度首先兑现为战场救援；成为封侯后，他能在三十八息内跨越一千七百二十里，迫使妖王把五十息撤退规则压缩到二十息。`《三十八息时间》L18273-L18345`
- **Escalation**：不死境雷磁领域让速度与探查结合，孟川从等待求援转为主动进入地底搜巢；三个月杀八千余妖王。`《上天垂怜》L19347-L19375；《地下探查的第一天》L19499-L19567；《三月后》L19620-L19624`
- **Collision**：妖族撤入海洋、伪造诱饵、布置因果血咒；孟川的成功方式反过来把自己变成最高价值目标。`《逃向海洋》L26617-L26632；《五重天“千蛐”》L27129-L27153；《拜九日》L28455-L28469`
- **Payoff**：滴血境把地底探查扩大到十里，百万妖王的数量威胁被实质压低；人族随后从被动防守转为主动进入世界间隙猎杀五重天妖王。`《滴血境（下）》L26878-L26905；《主动进攻》L29755-L29780`
- **Second Payoff / Afterlife**：洞天境后可潜入深层虚空破阵；元神七层后九个分身可多点镇守；元神八层后元神世界覆盖整个沧元界。旧优势不断换用途，而不是被新境界淘汰。`《洞天境（下）》L32177-L32212；《元神七层》L34663-L34718；《传送》L39727-L39744`
- **Why Reader Cares**：突破结果始终可见——以前只能逃，后来能带人逃；以前赶到一城，后来覆盖六州；以前等妖王出现，后来主动进入地底清剿。
- **Story State Change**：人族战争姿态从“等敌人暴露”变成“主角主动搜索、选择目标、控制交战地点”。
- **Evidence Anchors**：`L1718-L1733；L18273-L18345；L19347-L19624；L26617-L26632；L26878-L27004；L29755-L29780；L32177-L32212；L34663-L34718；L39727-L39744`

## 3. 柳七月：共同长大 → 夫妻战友 → 燃寿守城 → 沉睡与苏醒

- **Thread name**：并肩关系的寿命代价与第二人生
- **Length class**：long
- **Setup**：柳七月与孟川自幼共同生活、练箭练刀，都在幼年失去母亲；亲密首先由吃饭、比试和共同做事建立。`《孟川和云青萍》L40-L68`
- **Dormancy**：两人长期保持“七月妹妹”的日常关系，没有直接跳成爱情；元初山修炼期间以书信、等待和共同目标维系。`《这一生一起走》L8174-L8226`
- **Reminder**：两人成亲、生子，继续分别承担守城和救援；柳七月的凤凰涅槃始终是夫妻共同生活旁边的一枚倒计时。`《成亲》L12114-L12176；《生了！》L16165-L16217`
- **Escalation**：黑岩大妖王围杀夫妇，柳七月燃寿拖住敌人，孟川为救她临阵悟道、突破封侯；关系线与力量线第一次正面合流。`《凤凰涅槃》L17550-L17617；《封侯》L17767-L17917`
- **Collision**：风雪关超大型入口扩张，柳七月选择继续用凤凰火焰保护一千多万凡俗，燃烧两百二十余年寿命并击杀毒龙老祖。`《救援》L34006-L34061；《选择》L34137-L34223；寿命结算 L34273-L34280`
- **Payoff**：柳七月只余五十三年寿命、白发衰老；孟川主动陪她变老，两人把少年时期“一生一起走”的约定落成可见生活。`《白头偕老》L34235-L34268`
- **Second Payoff / Afterlife**：柳七月进入千年殿沉睡。孟川以七十二幅画保存共同生活，在孤独中突破；两百六十四年后唤醒她，再以火源液将其寿命提升至四千三百年。`《千年》L34396-L34492；《柳七月苏醒》L46147-L46171；《圆满（下）》L46250-L46309`
- **Why Reader Cares**：她不是主角的远程武器。每次涅槃都是她本人对城中生命、夫妻未来和自身寿命作出的选择；沉睡又造成真实的时间差。
- **Story State Change**：`青梅战友` → `夫妻与父母` → `共同封侯/封王` → `寿命几乎耗尽` → `长期沉睡` → `在新时间尺度中重新共同生活`。
- **Evidence Anchors**：`L40-L68；L8174-L8226；L12114-L12176；L17550-L17917；L34137-L34268；L34396-L34492；L46147-L46309；L56473-L56484`

## 4. “母亲已死” → 白念云仍活着 → 三代团聚

- **Thread name**：被误认的死亡与家庭重组
- **Length class**：long
- **Setup**：孟川相信母亲死于六岁妖灾，画画和成神魔誓言都从这项认知出发。`《这是好事》L315-L324；《学其上，仅得其中》L160`
- **Dormancy**：孟大江多年隐瞒白念云身份，并用夫妻积累的奇珍培养孟川；读者只看到父亲持续付出，不知道完整原因。`《父与子》L1637-L1644；《孟大江隐藏的奇珍》L1753-L1783`
- **Reminder**：父亲被构陷勾结天妖门，孟川无法把长期认识的父亲与罪名拼在一起，决定亲自查清。`《我是孟川》L16602-L16645`
- **Escalation**：孟川闯地牢带父亲上元初山；尊者确认记忆被篡改，并确认白念云正是当年救人的太阴圣女。`《恕师侄无礼了》L16749-L16803；《洗刷冤屈》L16827-L16870`
- **Collision**：孟川完成大周地底清剿后，没有把帮助黑沙洞天换成普通宝物，而是要求白念云获准返回，与孟大江永久团聚。家庭愿望与世界级战绩直接碰撞。`《神秘神魔》L26468-L26490`
- **Payoff**：黑沙洞天在战争压力下答应要求；白念云返回，夫妻重逢，孟川第一次当面喊她“娘”。`《要求》L29117-L29177；《一家团聚》L29431-L29508`
- **Second Payoff / Afterlife**：父母不再只是被救回的奖励，而是共同旅行、生活、衰老、沉睡和延寿；域外阶段仍持续存在于家庭日常。`《出征世界间隙》L29784-L29790；《延寿》L40229-L40304；《圆满（下）》L46268-L46296`
- **Why Reader Cares**：早期私人创伤没有被“世界责任”覆盖。主角解决世界级危机后，最想换取的仍是父母能在一起。
- **Story State Change**：`母亲已死`是孟川的旧认知；它被重写为`母亲活着但无法回家`，最终变为`父母公开共同生活`。
- **Evidence Anchors**：`L315-L324；L1753-L1783；L16602-L16870；L17029-L17043；L26468-L26490；L29117-L29508；L40229-L40304；L46268-L46296`

## 5. 母亲教画 → 众生相 → 雷霆与脊梁 → 画世界

- **Thread name**：绘画作为记忆、观察与元神道路
- **Length class**：long
- **Setup**：绘画最初是母亲遗产和日常安宁；孟川明确认为它不能杀妖，却仍每天坚持。`《这是好事》L312-L324`
- **Dormancy**：它长期只是个人爱好、柳七月赌局筹码和保存生活的方式，不立即被解释为战斗系统。`《镜湖道院的决选》L597-L612`
- **Reminder**：孟川画《众生相》，把家族、帮派、普通人、兵士、城关放进同一卷，随后产生心魂之力。`《众生相（上/下）》L2427-L2584；《蜕变》L2593-L2638`
- **Escalation**：《路》整理四年战争经验；进入世界间隙后，他把创世雷霆分解成十五相，由绘画重新理解自己的刀法。`《路》L15339-L15433；《画“雷霆”》L22652-L22772`
- **Collision**：洞天境意境自然进入画笔，绘画反过来促成元神六层；战争获胜后，《脊梁》又将真武王、薛峰和无数无名者的牺牲转为心灵突破。`《画笔融意境》L32488-L32597；《世界外显》L39450-L39509`
- **Payoff**：孟川最终承认自己的元神法门不是“磐石与水”，而是展开的画卷；其修行本质是从万物中提取认知，再绘成自己的世界。`《画世界》L51720-L51739`
- **Second Payoff / Afterlife**：第八次元神之劫把旧体系全部压低为凡俗驱魔道路，孟川仍靠画道智慧重新理解陌生世界；渡劫成功后，元神八劫境能力又让《脊梁》中积累的遗憾获得现实兑现。`《功成》L56353-L56434；L56482-L56490`
- **Why Reader Cares**：画道同时连接母亲、夫妻生活、战争见闻、力量理解和最终心灵道路；不是“画画增加元神经验”。
- **Story State Change**：`私人记忆` → `观察众生` → `理解雷霆/规则` → `保存战争与关系` → `形成元神世界`。
- **Evidence Anchors**：`L312-L324；L2427-L2638；L15339-L15433；L22652-L22772；L32488-L32597；L39450-L39509；L51720-L51739；L56353-L56434`

## 6. 孟安、孟悠、孟御：被保护的孩子 → 自主路线 → 域外家庭

- **Thread name**：下一代离开主角轨道
- **Length class**：long
- **Setup**：孟川夫妇遭刺杀后，把孩子隐姓培养，让他们在普通道院成长；孟安选枪、孟悠选剑。`《刺杀》L18400-L18421；《十年》L18441-L18480`
- **Dormancy**：姐弟长期不知道完整家世，暗中却有保护；父母没有把自己的战绩直接换成孩子的公开身份。
- **Reminder**：姐弟主动要求看妖灾现实，孟川带他们看屠城遗址、地底居民和船上家庭；他们不能再退回无知状态。`《真实的世界》L19632-L19707`
- **Escalation**：孟安选择轮回神体并通过轮回试炼，成为沧元祖师真传；孟悠则按自己的判断选择成神魔路线，没有机械追求父亲同款圆满。`《轮回神体》L19964-L20003；《轮回试炼（下）》L24016-L24079；《孟安出关》L29396-L29428`
- **Collision**：孟安按祖师要求离开沧元界，拒绝父亲拖延安排；在坤云秘境中建立自己的婚姻与家庭。孟川即使已是劫境，也无法直接进入秘境替他生活。`《传送》L39780-L39803；《寿命》L39921-L39938；《秘境内的孟安》L43399-L43445`
- **Payoff**：孟安为了妻子和未出生的孩子主动离开天界争斗；后来面对六劫境敌人，他先让妻子切割有关孩子的记忆，自己逃回家乡求生，而非把全家拖入必死战。`《孟安这些年》L45054-L45113`
- **Second Payoff / Afterlife**：孙辈孟御在域外独自闯荡，形成自己的剑道、同伴和风险；终局时他出生于坤云秘境，不在沧元界时空长河内，不能被孟川的家乡能力直接包办。`《祖孙再重逢》L51791-L51824；《半步八劫境“孟川”》L54429-L54453`
- **Why Reader Cares**：父亲越强，“是否让下一代仍有自己的道路”越重要。原作让后代真正离屏成长，并带着新家庭、新秘密和新困境回流。
- **Story State Change**：`需要隐藏的孩子` → `知道真实战争` → `选择不同道路` → `离开家乡` → `建立父亲无法完全控制的新血脉线`。
- **Evidence Anchors**：`L18400-L18480；L19632-L19707；L19964-L20003；L24016-L24079；L29396-L29428；L39780-L39938；L43399-L43445；L45054-L45130；L51791-L51824；L54429-L54453`

## 7. 薛峰—晏烬—安海王：未完成的兄弟修复与父辈余波

- **Thread name**：配角家庭的自主战争线
- **Length class**：medium / long
- **Setup**：晏烬因母亲遭遇而恨薛家；薛峰知道弟弟不会接受薛家礼物，主动请孟川隐瞒来源转交冰莲花。`《薛峰的请求》L22454-L22503`
- **Dormancy**：兄弟共同镇守、切磋；薛峰把万剑宗传承留给晏烬，晏烬嘴上抗拒，却实际沿着传承成长。`《万剑宗》L24416-L24453`
- **Reminder**：薛峰转投黑沙洞天前提出的条件不是为自己索利，而是要求晏烬下山后与自己同城。`《薛峰的要求》L24364-L24373`
- **Escalation**：黄摇老祖袭杀薛峰，孟川赶到也无法救回；薛峰彻底湮灭，没有留下普通意义上的尸体。`《五重天的黄摇老祖》L24630-L24692`
- **Collision**：孟川告知冰莲花真相，晏烬终于承认薛峰永远是自己的兄长，并接过其未完成的斩妖目标。`《永远是我哥》L24724-L24769`
- **Payoff**：安海王后来暴露与妖族交换绝学、利用妻妾和孩子进行“磨炼”的完整记忆；宗派将其改造为寒冰生命，放逐世界间隙三百年。`《安海王的记忆》L31185-L31238；《生命改造》L31242-L31357`
- **Second Payoff / Afterlife**：三百年后晏烬亲自质问父亲。安海王临死才承认道路走歪；终局时薛峰又被列入孟川准备从时空长河带回的英雄。`《安海王的落幕》L46761-L46811；《功成》L56482-L56488`

## 8. 鹏皇：战争统帅 → 域外追猎者 → 因果终结

# Short / Medium / Long Thread Grammar

## Short Thread

`明确威胁 → 能力差距可见 → 角色选对象/时机 → 对手反制 → 单一状态改变`

适合一场救援、陷阱或突破战。例：黑水宫主利用领域克制速度，孟川必须求援并与领域型、力量型同伴协作。`《四重天天妖的追杀》L13129-L13532`

短线不需要强行休眠；关键是结果必须改变下一步，而不只是展示招式。

## Medium Thread

`具体礼物/秘密/局部目标 → 低频回响 → 身份或能力跨门槛 → 与主线碰撞 → 关系或行动位置改变`

例：冰莲花、万剑宗传承、薛峰死亡、晏烬承认兄长。`L22454-L24769`

Medium thread 最适合承载配角自主和阶段内情绪重量。

## Long Thread

`私人欲望/伤口 → 自然休眠 → 新处境提醒 → 敌人或关系升级 → 大事件碰撞 → 第一兑现 → 新生活/余波/第二兑现`

《沧元图》的有效长线提醒物不是抽象口号，而是：

- 母亲留下的绘画；
- 柳七月燃烧掉的寿命；
- 千年殿中的冰块和七十二幅画；
- 薛峰没有留下的尸体；
- 鹏皇血液；
- 世界入口与连接点地图；
- 孟安离开沧元界这一事实。

# Story Program Engine Variation

## 核心玩法怎样跨阶段换发动机

1. **地方天才期**：练刀、公开比试、越阶证明、斩妖盛会。
2. **故乡危机期**：守城、亲人失散、多点战场、神魔差距。
3. **元初山期**：路线选择、长期苦修、神魔血池、传承门槛。
4. **城关期**：固定小队、阵地攻防、伤亡和救援。
5. **巡查期**：同时多点求援、速度排序、诱敌与陷阱。
6. **百万妖王期**：人口迁移、大城防线、地底主动狩猎。
7. **世界间隙期**：探索奇物、观看创世、夺宝、精英猎杀与战略地图。
8. **战争终章期**：妖圣通道、预设战场、情报隐藏、世界入口决战。
9. **域外新人期**：伪装、生存、遗迹风险、陌生势力与交易中心。
10. **域外强者期**：城主、河系、联盟、禁忌生物和高阶势力冲突。
11. **宇宙后期**：时间线、生命世界存亡、八劫境力量与宇宙之外。
12. **终局**：渡劫、家乡扩张、修复历史遗憾。

原作后期确实出现东宁城、永恒楼分部、贸易与资源交换；这是原文真实的阶段发动机之一。但它们的作用是制造新入口、新敌友和新行动尺度，不能自动改写成运营系统或治理模板。

## 敌人怎样改变策略

- 五十息撤退 → 二十息撤退；
- 地面巢穴 → 深层地底 → 海洋；
- 城池正攻 → 伪装求援与伏击；
- 普通妖王波次 → 四重天小队 → 五重天精英；
- 直接杀主角 → 因果血咒、跨界咒杀；
- 世界间隙正面战 → 连接点地图与夺舍妖圣；
- 入侵失败 → 鹏皇域外追踪；
- 普通虚空封锁 → 黑河阵、九命茧、八劫境阵图与生命世界庇护。

## 配角怎样获得自主目标

- 柳七月选择是否继续涅槃；
- 薛峰选择如何帮助晏烬、是否转投黑沙洞天；
- 晏烬选择是否接受兄长、是否追问父亲；
- 真武王选择燃烧自己确保战略目标死亡；

## 换地图如何不 reset

- 东宁府的母仇、柳七月、父母和绘画全部进入元初山与战场；
- 地面战争的伤亡、寿命债和身份秘密进入世界间隙；

- 鹏皇和妖界把旧战争追到域外；

- **选突破时机**：洞天境已足够突破尊者，但孟川为了继续进入世界间隙，主动暂缓突破。`L32457-L32470`
- **选是否暴露**：面对鹏皇时隐藏正面实力，把信息差保留给妖圣通道终战。`L38639-L38640`
- **选交战地点**：故意让五队妖王进入沧元界，再由八个分身同时收网。`L37177-L37413`

- 领域减速，直接克制高速移动。`L13208-L13249`
- 利用救援本能布置假求援和伏击。`L13719-L14021`
- 虚空蛛网、绝天地/绝时空类阵法封锁遁逃。`L25959-L26087`
- 妖王撤入海洋，使探查半径优势需要再次升级。`L26617-L26632`
- 重玄妖圣冻结深浅层虚空，保护绘图位置。`L32872-L32932`
- 鹏皇利用因果锁定分身与真身。`L38339-L38520`

# TGN Story Program Inspirations

1. 先给主角一个具体私人伤口，再让世界危机逐步反复触及它；不要一开篇就替主角宣布宏大责任。
2. 每次突破都必须回答“现在能做哪件以前做不到的事”，最好用救援距离、交战对象或地图入口证明。
3. 主角上一阶段最成功的能力，应成为敌人下一阶段重点反制的对象。
4. 长线提醒必须改变当前选择或旧因含义；单纯回忆、点名旧人不够。
5. 一个大碰撞点最好同时结算力量、关系、敌人策略和世界状态，但每条线保留自己的因果。
6. 强力大招的限制可落在真实人生时间、使用窗口或不可并存的路线选择上，不必机械征税。
7. 配角离屏后应继续选择、结婚、失败、修行或改变目标；回归时不必恢复原队伍配置。
8. 阶段兑现宜短而硬：先在冲突中证明新能力，再立即让新身份对应新任务或新生活。
9. 换地图要携带旧伤亡、旧关系、旧敌人与旧能力的新用途；不能只换敌人名字。
10. 最终高阶能力若能重写旧死亡或历史，应把它放在全书级第二兑现，不能变成可频繁调用的复活按钮。

# Anti-Systemization Check

## 真正的故事状态改变

- 东宁府遭入侵、长老和凡俗死亡；
- 府县被放弃、人口迁入大城；
- 柳七月燃烧寿命并沉睡两百六十四年；
- 薛峰、真武王等人死亡；
- 白念云与孟大江公开团聚；
- 孟安离开沧元界并建立域外家庭；
- 人族九百余年战争结束；
- 鹏皇等三名战争主导者死亡；
- 沧元界时空支流独立并扩张；
- 历史英雄在终局获得重返现世的可能。

这些状态会改变人物关系、敌我策略、地图和后续可行动范围。

## 仅是资产或技能增加

- 冰心果、星灵草、凤凰羽毛；
- 血刃盘、青云天、九命茧、时空令；
- 功劳、宝藏、域外元晶；
- 分身数量、境界称号、技能名称；
- 东宁城或永恒楼分部本身。

它们只有在实际改变救援、战争、身份、关系或世界入口时，才转化为故事状态。

## 边界案例

- **沧海派宝藏**：若只写获得大量物品，就是资产；原作让群星楼、心海殿、战神塔回归并开放新培养路径，因此才成为世界底盘变化。`L27229-L28325`
- **元神分身**：数量增加不是长线；八分身改变多点镇守与域外分线行动后，才产生叙事复利。
- **绘画**：不是元神经验条，而是母亲记忆、观察方式、关系档案和心灵道路的同一来源。
- **英雄归来**：终局确实削弱了部分旧死亡的最终性，但此前死亡造成的数百年战争、人物选择和时间损失并未被抹去。它应被理解为八劫境终局第二兑现，不应迁移成常规复活循环。
- **世界责任**：孟川并非因为“力量大所以道德上必须负责”而行动；原文不断让其能力成为唯一能解决具体入口、地底、救援或跨界敌人的手段，责任由行动位置和故事后果生成。

## 保留的 UNKNOWN
