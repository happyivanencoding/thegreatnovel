# 《大王饶命》纵向故事线蒸馏

> **REFERENCE_ONLY / PILOT**  
> 原文按 GB18030 读取，共约 66,400 行；章节索引仅作导航。以下剧情事实均回到原文复核。分析重点是长篇编织、人物差异、喜剧后果与玩法变异，不把原作改写成治理或工程模型。

## 1. “让人不舒服”从生存燃料变成世界级博弈

- **Thread name**：负面情绪—成长—社会回声
- **Length class**：long
- **Setup**：吕树发现恐惧、怨念等负面情绪能兑换抽奖和果实。最早的资源来自路人、司机、知微与吕小鱼；他想要的是改善病弱身体、养活两人并获得自保力量。`第4—5章，L226–L297`
- **Dormancy**：能力不真正停摆，而是退入日常低烈度循环：漂流瓶、斗嘴、摆摊持续供给；旧套路收益变弱时，吕树寻找新对象、新规模。`第6章，L300–L337；第87章，L4629–L4642`
- **Reminder**：班级群让他第一次确认“群体规模”会放大收益；臭豆腐又把金钱收入、陌生人反应和负面情绪合成一次事件。`第13章，L709–L737；第46—47章，L2473–L2564`
- **Escalation**：对象从亲友、同学扩展到论坛、海外组织、军队和整座城市；制造情绪的方法也从一句话扩展到身份伪装、公共事件、作业、舆论与战争威慑。`第247章，L12606–L12657；第912章，L45460–L45487`
- **Collision**：黄石遗迹后，幸存者把吕树的行为解释成保护，英雄化反而切断了原本应有的怨念；吕树试图在论坛骂自己，却被删帖、封号，核心优势第一次被公众关系反向限制。`第1212—1214章，L60629–L60719`
- **Payoff**：他利用“老神王诗词归属”引发大规模争论；更重要的是，终局敌人准确理解负面情绪机制，并故意制造死亡、恐惧与压力，想等他点亮星图后夺走成果。`第1287—1288章，L64181–L64218；第1296—1305章，L64601–L64624、L65041–L65044`
- **Second Payoff / Afterlife**：负面情绪不只用于主角升级，也被转为吕小鱼的成长时机、武卫军训练后的回馈以及大战中的恢复资源；但原文没有给出可稳定预测的产出公式。`第1255章，L62640–L62649；第1323章，L65919–L65934`
- **Why Reader Cares**：每个笑点都可能留下关系、名声或敌人判断。读者看的不是点数上涨，而是“这次气人会让谁记住他、误判他、喜欢他或决定对付他”。
- **Story State Change**：吕树从偷偷收割熟人怨念的孤儿，变成其公众身份、敌人恐惧和跨世界战争都会影响成长方式的人。
- **Evidence Anchors**：`第4—5章，L226–L297；第13章，L709–L737；第46—47章，L2473–L2564；第912章，L45460–L45487；第1212—1214章，L60629–L60719；第1305章，L65041–L65044`

## 2. 两个孤儿从单向照顾走到双主体互相选择

- **Thread name**：吕树—吕小鱼的“家”
- **Length class**：long
- **Setup**：两人没有血缘，以逃离孤儿院后的共同生活形成家庭。吕树承担生计，小鱼选择一次次回到他身边；两个雪人把这种关系落成可记忆的物象。`第1—5章，L97–L108、L278–L297`
- **Dormancy**：关系长期藏在做饭、零食、家务、银行卡和斗嘴里，不靠连续表白推进。`第88—89章，L4681–L4714`
- **Reminder**：小鱼在遗迹石壁留下“保护吕树一辈子”的承诺，吕树回应；保护由哥哥对妹妹的单向责任变成双方约定。`第450章，L23263–L23282`
- **Escalation**：小鱼要求进入遗迹、参加战斗；她并不愿成为被养着的附属者。长白山危机时，也是她对李弦一安危的判断推动吕树入局。`第251—252章，L12892–L12899；第799—801章，L40015–L40136`
- **Collision**：暗图真相把家庭线与力量线正面相撞：更高层星图可能以小鱼为代价，吕树明确宁可放弃；小鱼则坚持以自己的意志陪伴并承担行动。`第1211—1212章，L60532–L60620`
- **Payoff**：面对旧神王恶念，吕树以当下关系回答“我不孤独”。小鱼、李弦一、天罗地网和已发生的陪伴，使旧身份不能完整接管现在的吕树。`第1297章，L64625–L64655`
- **Second Payoff / Afterlife**：小鱼拥有自己的命令、成长资源和战场作用，但仍主动保留两人的家庭关系。战后的完整日常未被详细展开，具体长期状态为 `UNKNOWN`。
- **Why Reader Cares**：读者看到的是两个本来只剩彼此的人，逐渐各自拥有力量、朋友和选择之后，仍然选择对方。
- **Story State Change**：小鱼从吕树需要保护的人，变成能推动他的战争决定、身份决定和终局选择的共同主角。
- **Evidence Anchors**：`第5章，L278–L297；第252章，L12892–L12899；第450章，L23263–L23282；第799—801章，L40015–L40136；第1211—1212章，L60532–L60620；第1297章，L64625–L64655`

## 3. 会被徒弟气到的老剑仙，最终接回十八年前的旧账

- **Thread name**：李弦一的邻居—导师—旧案见证者线
- **Length class**：long
- **Setup**：李弦一以隔壁老人身份寻找传承者；吕树谨慎试探，最终开始学剑，吕小鱼则把高人拖入辅导功课、换灯泡和零食交易。`第56章，L2971–L3004；第75—80章，L3943–L4283`
- **Dormancy**：李弦一离开洛城，留下房屋、联系方式和剑道；人物离场，但训练成果和家庭位置继续存在。`第309—310章，L15921–L15981`
- **Reminder**：他在遗迹回流，以战力改变吕树的安全边界；高人用手电筒、吕树趁机戳血妖收情绪等笑点，没有削弱双方已形成的信任。`第420章，L21738–L21819`
- **Escalation**：随着剑阁—剑庐、傀儡师和婴儿旧案浮出，李弦一不再只是技能导师，而成为十八年前误判与追杀的见证人。`第1232—1234章，L61564–L61705`
- **Collision**：基金会曾追杀护送婴儿的泪诀，而那个婴儿极可能就是吕树。师徒关系必须面对真实旧伤，不能只靠插科打诨跳过。`第1235章，L61710–L61753`
- **Payoff**：吕树以“第九天罗吕树”定义现在的自己；双方谈明泪诀之死与基金会责任，没有假装旧账不存在，也没有因此把现有关系全部推翻。`第1235—1237章，L61734–L61840`
- **Second Payoff / Afterlife**：李弦一得知剑阁传承在吕宙仍有延续，产生前往剑庐的愿望；原文未写他最终成行，记为 `UNKNOWN`。`第1234章，L61687–L61696`
- **Why Reader Cares**：长期笑点让李弦一先成为“家里人”，所以旧案揭露不是历史说明，而是会真正伤害一段已建立关系的事实。
- **Story State Change**：导师与学生从传承关系变成共同背负旧案、仍能继续合作的关系。
- **Evidence Anchors**：`第56章，L2971–L3004；第75—80章，L3943–L4283；第310章，L15940–L15981；第420章，L21738–L21819；第1234—1237章，L61660–L61847`

## 4. 从组织外的刺头，到公开选择成为第九天罗

- **Thread name**：吕树—天罗地网—聂廷
- **Length class**：long
- **Setup**：吕树先听说天罗层级，再旁观聂廷拜访李弦一；他认识到天罗地网既提供秩序，也会明确划定边界。`第71—73章，L3797–L3885`
- **Dormancy**：吕树正式加入，但仍把自由理解为“能够拒绝”，不认为自己会长期服从组织。`第203章，L10224–L10267`
- **Reminder**：聂廷持续给任务、身份、退路和资源，也不断试图把吕树推向更高职位；吕树用黑市、灵石和故意气聂廷回应。`第499章，L25658–L25667；第564—566章，L28771–L28878`
- **Escalation**：刘修牺牲后，第九天罗职位不再只是奖励，而意味着吕树必须面对“别人会因自己的决定而死”。`第524—526章，L26870–L26947`
- **Collision**：长白山危机中，聂廷不能随意出手；吕树原本想让最强者解决问题，最终决定亲自参战。`第799—803章，L39998–L40244`
- **Payoff**：吕树公开讲述神集任务与刘修之死，接受第九天罗身份，走廊里的黑影画像换成他本人。`第800—801章，L40052–L40136`
- **Second Payoff / Afterlife**：跨世界战争中，聂廷与石学晋进入吕宙支援；终局聂廷替吕树拦截背后敌人并斩杀吕神恶念，胜后双方立刻恢复抢人头式斗嘴。`第1244章，L62147–L62158；第1329章，L66235–L66310`
- **Why Reader Cares**：归属不是一次宣誓解决的。吕树可以持续顶撞聂廷，同时在关键处把天罗地网当作自己的同袍。
- **Story State Change**：从被组织安排的成员，变成公开承担身份、能把自己在另一世界获得的力量带回来支援组织的人。
- **Evidence Anchors**：`第71—73章，L3797–L3885；第203章，L10224–L10267；第565章，L28804–L28864；第799—801章，L39998–L40136；第1329章，L66235–L66310`

## 5. 豪门胖子与老实少年，互损到能独立决定战局

- **Thread name**：陈祖安—成秋巧—物种研究专业群像
- **Length class**：long
- **Setup**：陈祖安以善于分析、讲究家族和名车、又能吃的豪门子弟登场；吕树的草根、姜束衣的冷淡、高神隐的好战，使同一帐篷内就出现清晰人设差异。`第251—252章，L12805–L12930`
- **Dormancy**：两人暂时退到任务和课程背景，却逐渐吸收吕树的说话方式，同时保留各自的胆怯、谨慎和互损关系。`第810章，L40521–L40555`
- **Reminder**：吕树不在场时，他们开始自己判断并追向危险，而不只是等待主角带队。`第810—811章，L40505–L40607`
- **Escalation**：龙门要塞战斗中，陈祖安和成秋巧互相推动突破；彼此的缺点、烂梗和信任同时存在，友情第一次直接改变战场。`第1070—1071章，L53249–L53311`
- **Collision**：武卫军跨界回援，把校园群像、天罗地网守城和吕宙军队放进同一战场；陈祖安以“吕树的兄弟”确认自己的新关系位置。`第1072章，L53314–L53365`
- **Payoff**：陈祖安拒绝家族用资源和职位收编，明确选择与朋友并肩；随后他与成秋巧不是靠家族支持，而是被天罗地网核心成员共同认可为补位天罗。`第1226—1227章，L61275–L61363`
- **Second Payoff / Afterlife**：终局中成秋巧以自己的选择发动决死一击，陈祖安和青铜洪流继续入场。其后金色粉末重塑、伤者恢复，但原文未逐人交代完整战后状态，不能把所有个体恢复细节写死。`第1327—1329章，L66141–L66177、L66320–L66324`
- **Why Reader Cares**：他们不是被“修正”为完美配角；贪吃、嘴硬和怕死仍在，但关键行动已能脱离主角指令。
- **Story State Change**：陈祖安从追求家族认可变为以战友与自我认可定义身份；成秋巧从跟随者变成能独立改变终战局部结果的人。
- **Evidence Anchors**：`第251—252章，L12805–L12930；第810—811章，L40505–L40607；第1070—1072章，L53249–L53365；第1226—1227章，L61275–L61363；第1327章，L66141–L66159`

## 6. 从薯片收买的松鼠，到跨世界族群行动者

- **Thread name**：小凶许—鼠潮
- **Length class**：long
- **Setup**：小凶许最初是守果树、会偷袭的灵兽，后来被带回家庭；识字和写作业既制造笑点，也为其获得独立沟通能力。`第149—166章，L7625–L8485；第200章，L10077–L10107`
- **Dormancy**：它长期洗碗、做家务、被吕树和小鱼使唤；同时在场外扩张鼠群，而不是一直跟在主角肩头。`第532章，L27242–L27266`
- **Reminder**：吕树发现它已能精确掌握鼠群数量和等级，小凶许开始承担城市治安任务。`第532章，L27248–L27281`
- **Escalation**：鼠潮清理地下虫群时制造城市恐慌，随后围杀可能进入城区的蝎群；喜剧配角第一次承担族群伤亡和城市后果。`第720—724章，L36219–L36449`
- **Collision**：吕树、小鱼进入吕宙后，小凶许因“家人不会抛下自己”而自主率领鼠潮穿越通道；肥皂上的头像又让旧笑点成为寻找武卫军的现实线索。`第974章，L48394–L48434`
- **Payoff**：昆城奴隶主事件中，它自己选择澡堂、下水道与通风口作为侦查位置，鼠潮成为天罗地网针对奴隶印记的有效奇兵。`第1090—1091章，L54224–L54283`
- **Second Payoff / Afterlife**：返回吕宙后，鼠潮铺开数百里暗哨，敌军无法秘密接近御龙班直；小凶许也被确认继承了择梦能力。`第1237章，L61828–L61830；第1257章，L62730–L62773`
- **Why Reader Cares**：识字、作业、薯片、小书包都没有被成熟战力替换，而是继续成为它的辨识度与行动工具。
- **Story State Change**：从家庭宠物变成有族群、有资源分配、有侦查判断、会主动跨界寻找家人的非人类角色。
- **Evidence Anchors**：`第200章，L10077–L10107；第532章，L27242–L27281；第720—724章，L36219–L36449；第974章，L48394–L48434；第1090章，L54224–L54269；第1257章，L62730–L62773`

## 7. 被派来接近主角的少女，最后选择自己重建阵营

- **Length class**：medium
- **Setup**：樱井以保守派成员身份接近伪装中的吕树，公开人设、刺客训练与私人情感互相冲突；双方始终保留戒备。`第474—487章，L24405–L25092`
- **Dormancy**：神集内斗后，她离开旧位置，随后长期在主线外重建组织。`第489—502章，L25157–L25776`
- **Reminder**：神集高端力量崩溃后，她没有跟随吕树离开，而是带着保守派资源尝试重建神集；几天内获得隐匿家族支持。`第523章，L26797–L26844；第529章，L27112附近`
- **Escalation**：她压下神集对第九天罗的复仇声音，并保护吕树真实身份；个人关系因此留下组织外交后果。`第802章，L40140–L40156`
- **Collision**：奴隶主试图用奴隶印记控制神集，樱井本人变成诱饵；吕树回到岛国救援，旧潜伏关系、邻国安全和吕宙敌人同时合流。`第1091—1093章，L54284–L54416`
- **Payoff**：危机后，她主动提出加入天罗地网，但没有放弃神集、立即迁居或把组织交给主人公；最终以普通外籍成员身份加入，同时继续留在神集。`第1134章，L56470–L56510`
- **Second Payoff / Afterlife**：她为未来保留可能性，但后续定居或关系结果没有明确完成，记为 `UNKNOWN`。`第1134章，L56511–L56522`
- **Why Reader Cares**：初期的诱惑、误会和身份喜剧最终改变了一个组织的领导者与对外方向，笑点没有停在暧昧奖励上。
- **Story State Change**：樱井由别人派出的棋子，变成能决定神集存续、外交方向与自己未来去向的角色。
- **Evidence Anchors**：`第474—502章，L24405–L25776；第523章，L26797–L26844；第802章，L40140–L40156；第1091—1093章，L54284–L54416；第1134章，L56470–L56522`

## 8. “烂军”保留荒诞画风，却成长为只认吕树的军团

- **Thread name**：武卫军—御龙班直
- **Length class**：long
- **Setup**：武卫军由流浪儿把持，贪腐、卖名额、军纪混乱，被各军视作笑话；吕树恰因其弱、容易取得剑庐名额而选择它。`第881章，L43969–L43990`
- **Dormancy**：吕树先以土匪、花生和肥皂与其发生关系；这时军队仍只是谋生和喜剧背景。`第887—895章，L44285–L44667`

# Core Gameplay Choice & Counterplay

## 主角的可选择空间

- **选对象**：吕树会区分曾经帮助自己的街坊与可以反复刺激的同学、敌人；能力没有自动消除他的关系判断。`第47章，L2527–L2552`
- **选规模**：从一对一嘴损、班级群、臭豆腐人流，到军队、城市和老神王舆论。
- **选时机**：负面情绪可以积攒后集中用于突破；吕小鱼的深渊果实被保留到西都战场，以天劫破局。`第1269—1270章，L63334–L63355`
- **选保留/舍弃**：果实既可供自己升级，也可给小鱼、灵兽、武卫军和同伴；屯下的盔甲、三叉戟最终被用于军团。`第1051章，L52239–L52260`
- **选组合**：负面情绪并非唯一按钮，可与真名、葫芦、暗图、鼠潮、地下移动、军队与公共身份组合。
- **选不杀/暂留**：部分敌人与人口被留作情报、行动空间或持续反应来源；但跨世界距离和同一群体的适应会降低收益。`第1259—1260章，L62847–L62908`

## 对手怎样反制

- **早期**：调查身份、封锁行动、设置伏击；多数敌人并不知道负面情绪机制，所以反制的是吕树本人而不是“点数条”。
- **中期**：利用组织舆论、朋友、公开身份与边境危机，使吕树不能只靠隐藏或等待更强者出手。
- **后期**：密谍保持距离，军队改变编制，奴隶主以印记控制组织领导者。
- **终局**：敌人理解星图机制后，不再阻止成长，而是用吕树的羁绊制造大规模负面情绪，等他达到可被夺取的阈值。`第1305章，L65016–L65048`

最有长篇价值的反制，是对手从“避开主角优势”升级到“把主角优势变成自己计划的前置条件”。

# Stage Transition & World Opening

- **地球日常 → 修行社会**：通过家长会、学校编制、军衔、遗迹伤亡和同学反应展示，而不是只宣布“灵气复苏”。`第175章，L8874–L8944`
- **国内 → 海外**：通过语言、货币、伪装身份、学校日常与本地组织派系展示；吕树仍用原有抠门、嘴损与戒备理解新环境。
- **地球 → 吕宙**：吕树先失去力量，醒在土坯房，面对窝头、农具、口音、逃奴身份和奴隶印记；读者首先看到的是如何活、如何说话、谁能支配谁。`第857—858章，L42818–L42918`
- **乡镇 → 城池/军队/王城**：通过报名参军、买卖名额、功法垄断、军队声誉、普通百姓和豪门反应逐层展开，不靠一段世界说明。
- **吕宙 → 地球回归**：武卫军、小凶许、奴隶主和空间通道一起回到旧地图，使地球本身发生变化；旧伙伴也已成长，不是原地等待。`第1071—1076章，L53304–L53559`
- **终局重新合图**：神王宫、剑庐、地球空间门、青铜洪流、御龙班直和旧法器处于同一战场。换地图最终增加的是关系交叉密度，而非只增加称号。

# TGN Story Program Inspirations

1. **把核心能力写成社会行为选择，不只是资源入口**：每次获得力量，都问“谁因此记住、误判或改变了对主角的态度”。

2. **笑点必须留痕**：一次玩笑至少留下一个后果——关系亲疏、公众标签、敌人误判、配角目标或可复用物象。

3. **长期关系靠日常锚点蓄能**：食物、作业、房屋、银行卡、小书包、称呼，比反复声明“关系很深”更能支撑终局兑现。

4. **配角离场时给他一项场外欲望**：重建组织、带领族群、争取身份、寻找旧人；回流时用新行动结算，而非等主角召回。

5. **人物成长不必消除喜剧缺点**：能吃、嘴硬、怕死、耿直、爱面子可以与关键战力并存；辨识度本身就是长期资产。

6. **同一玩法跨阶段换对象、规模与后果**：嘴损可以从家庭斗嘴变成班级群体反应，再变成组织舆论、军队心理战和终局诱饵。

7. **大碰撞优先结算不同性质的线**：一次事件同时结算力量、关系、身份、世界入口和配角自主，比连续安排五场单线兑现更有复利。

8. **换地图先夺走旧便利，再重释旧能力**：让主角先用原有人设和关系求生，再逐步发现旧技能在新社会里的不同意义。

9. **敌人应学习主角玩法**：初期躲优势，中期攻击关系与身份，后期反过来利用主角的成长条件。

10. **身份揭露必须产生选择题**：揭开“你是谁”后，至少重排敌我、关系或行动方向；只增加血统、称号和战力不算长篇兑现。

# Anti-Systemization Check

| 类型 | 本作中的例子 | 是否构成不可回滚故事状态 |
|---|---|---|
| 单纯数值增加 | 更多负面情绪、果实、星辰、等级 | 否 |
| 单纯资产增加 | 盔甲、三叉戟、灵石、肥皂收入、鼠群数量 | 否 |
| 单纯头衔增加 | 上校、天罗、统领、神王相关称呼 | 单独看不构成 |
| 关系被公开重写 | 吕树接受第九天罗；樱井由敌对组织棋子变成外籍同袍 | 是 |
| 配角获得自主方向 | 小凶许率族群跨界；陈祖安拒绝家族收编；樱井选择继续掌管神集 | 是 |
| 群体形成共同记忆和忠诚 | 武卫军经历作业、山歌、胜利、跨界后改名御龙班直 | 是 |
| 地图互相承担后果 | 地球伙伴进入吕宙，吕宙军队和敌人进入地球 | 是 |
| 身份谜底重排敌我 | 老神王不再只是主角的荣耀前身，而被拆成当前吕树与旧恶念 | 是 |

需要特别防止的误读：

- 武卫军的价值不在“五千高阶单位”，而在它形成了自己的记忆、行动判断、外界声誉与忠诚对象。
- 小凶许的价值不在鼠群数量，而在它会自主跨界、选择侦查办法并承担族群后果。
- 樱井的成长不等于升到 A 级，而是她从棋子变成组织决策者。
- 吕小鱼的暗图不是“副系统”，关键是她的选择会改变吕树是否入局、是否继续升级及如何理解自己。
- 原文没有完整写出战后治理、制度重建或稳定跨界秩序，不能把军团、星图人口、奴隶印记和负面情绪自动拼成行政或运营系统。

最终可迁移的核心是：**资源增长只有在改变人物下一次选择、敌人的下一种策略、关系的下一层含义或世界中不可撤回的事实时，才真正成为长篇故事增长。**
