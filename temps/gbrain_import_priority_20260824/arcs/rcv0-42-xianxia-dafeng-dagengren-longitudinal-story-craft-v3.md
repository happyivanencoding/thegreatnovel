## 1. 查案者成为公共信用：税银案 → 许银锣

- Thread name：查案能力转化为公共信用
- Length class：long
- Setup：许七安为救许家，从税银重量、运输时间和“入水爆炸”这些具体矛盾入手，推翻“妖物劫银”的共识，证明税银被人为调包。原文 L195-L443。
- Dormancy：破案成果先被转化为打更人职位；他仍只是低品铜锣，公共身份尚未形成。原文 L5009-L5428。
- Reminder：桑泊案让此前的小案方法进入皇室级案件——仍先查硝石、火药、运输、灭口，再触及封印与高品势力。原文 L9916-L10709。
- Escalation：佛门斗法把个人聪明、战力和表达能力变成全城共同观看的事件；百姓由畏惧佛门转为把许七安视作大奉的公开代表。原文 L32818-L34196。
- Collision：楚州案中，他公开斩国公、斩断官牌；朝廷随后试图污名化他，百姓却拒绝官方叙事。原文 L48280-L48537。
- Payoff：弑君时，贞德也承认许七安“一人声望胜朝廷”，并以京城百姓逼他硬接一剑；早期声望因此成为敌人可以针对、主角不能随意舍弃的行动条件。原文 L64125-L64299。
- Second Payoff / Afterlife：怀庆政变和登基需要借用许银锣的军中、地方和民间信用；浔州大捷又反过来验证新朝。原文 L105263-L106411、L107623-L108457。
- Why Reader Cares：读者看到的不是抽象“声望值”，而是一个死刑犯怎样通过一连串可见行动，取得百姓、军队和盟友宁可违抗皇权也愿意相信的身份。
- Story State Change：官职可以被他主动舍弃，公共信用却无法复原到“小捕快”状态；此后敌我双方都必须把“百姓相信谁”纳入策略。

## 2. 桑泊求救 → 神殊残躯 → 佛陀身份 → 大劫

- Thread name：被封印者究竟是谁
- Length class：long
- Setup：祭祖时，只有许七安听见桑泊中的求救；镇国剑和湖面异变先制造“谁在求救、为什么只找他”的具体谜团。原文 L8451-L8739。
- Dormancy：封印被破后，桑泊断手寄生于许七安；僧人自称神殊，却缺失身份、封印原因和其余残躯记忆，只以有限力量换取温养。原文 L14490-L14540。
- Reminder：每找到一部分残躯，只补回一层能力或记忆；“神殊头颅可能在阿兰陀”“甲子荡妖与万妖国有关”等信息长期保持未闭合。原文 L72103-L72158、L92051-L92926。
- Escalation：南疆复国战中，神殊失控、身份自述和佛门反应互相冲突；“神殊是否就是佛陀”先成为待验证假说，而不是立即定论。原文 L99351-L100059。
- Collision：神魔岛之门同时重写神殊、佛陀、监正和许七安四条线：荒以为监正是守门人，监正却指定武夫许七安；太平刀开始吸收“门”。原文 L125559-L125727。
- Payoff：大劫真相将旧日封印谜团升级为现实战争——超品不是争夺一个法宝，而是在争夺气运和天道；佛陀覆盖西域、吞噬九州的行为让谜底变成可见灾难。原文 L126051-L126245、L127810-L128102。
- Second Payoff / Afterlife：神殊成为正面对抗佛陀的半步武神；许七安则继承守门人资格并晋升武神。神殊不再是主角体内的外挂，而是拥有独立过去、敌人和终局位置的角色。原文 L127131-L127409、L132555-L132849。
- Why Reader Cares：每次“找回一块身体”都可能改变读者对救援目标的理解——是在救盟友、释放凶物，还是复原佛门最危险的历史秘密。
- Story State Change：桑泊封印已毁；神殊已被重新拼合；西域已经异质化；太平刀已经吸收光门。它们都不能退回早期“神秘断手”状态。

## 3. 楚州屠城 → 贞德旧案 → 弑君

- Thread name：地方惨案追到王朝源头
- Length class：long
- Setup：北境任务表面是护送与巡察，实际逐步暴露血屠三千里、镇北王炼制血丹和多方封口；许七安必须先判断王妃、蛮妖、使团和朝廷各自隐瞒了什么。原文 L41059-L46336。
- Dormancy：镇北王被杀并不等于案件结束；为什么元景愿意支持代价失衡的屠城计划、为什么急于掩盖真相仍未得到解释。
- Reminder：郑兴怀要求让楚州死者进入公开历史；许七安、国子监学子、文官和百姓从不同欲望出发，把边境案带回京城。原文 L46747-L48369。
- Escalation：起居录、浮香旧事、失踪人口、魂丹、龙脉和“贞德二十六年”被串联，调查对象从元景的错误决策转为先帝、元景、淮王是否为同一人的问题。原文 L54005-L55023、L57919-L59375。
- Collision：魏渊远征、巫神教陷阱和贞德分身在靖山城碰撞；魏渊之死又把许七安的私人情感、楚州旧账和皇位危机推到同一场弑君行动。原文 L59819-L60412、L62671-L64220。
- Payoff：许七安斩灭贞德的元景肉身，并继续破坏其晋升和复活条件；楚州案留下的公共信用使京城百姓更愿意相信他而非皇帝。原文 L63668-L64299。
- Second Payoff / Afterlife：旧帝死亡没有恢复稳定，反而打开永兴继位、云州叛乱、议和和怀庆夺位的新阶段。
- Why Reader Cares：一个最初可以被解释成“坏王爷屠城”的案件，最终证明皇帝、王爷、战争和修道阴谋属于同一因果链；每次扩大都保留前一阶段的具体死者和选择。
- Story State Change：镇北王、郑兴怀、贞德均已死亡；许七安已与旧皇权决裂；朝廷再也不能把楚州案降回地方事故。

## 4. 魏渊：被压住的军神 → 靖山死局 → 死后继承

- Thread name：魏渊未完成的战争
- Length class：long
- Setup：魏渊因许七安的办案能力、行为选择和问心结果破格接纳他；同时把他放入天地会，服务于自己的国家情报目标。原文 L5374-L5428、L6990-L7011。
- Dormancy：前期他主要以靠山、上司和朝堂操盘者出现，真正想重掌兵权、处理巫神教以及私人创伤长期不说透。
- Reminder：出征前，他结束对皇后“守了半生”的旧生活，明确表示要去做自己想做的事；京城老人和旧军则重新认出二十年前的军神。原文 L57054-L57420。
- Escalation：靖山城战役中，他以断补给、示弱、刻刀和锦囊推进一个连部下也无法完整理解的计划；目标是重创巫神教并加固巫神封印。原文 L58579-L60064。
- Collision：贞德、萨伦阿古和魏渊的目标在靖山城交汇；魏渊之死随后触发打更人内部清洗、许七安闯宫和弑君。
- Payoff：魏渊留下血丹、暗子、遗言和政治班底，把“巫神教战场由我处理，京城战场交给许七安”的分工延迟到死后兑现。原文 L62784-L63370。
- Second Payoff / Afterlife：春祭相关行动使魏渊重新进入当前故事；但他回来后面对的已经是怀庆、新朝和完成独立成长的许七安，无法恢复旧有上下级配置。原文 L111800-L112199、L133558-L133561。
- Why Reader Cares：他的离场首先夺走主角的靠山与缓冲，随后遗产又迫使主角承担原本由魏渊承担的第二战场。
- Story State Change：靖山城伤亡、军队损失、旧朝崩溃以及许七安的独立都没有因魏渊回归而复原。

## 5. 被藏起来的气运 → 许平峰身世 → 父子战争

- Thread name：作为气运容器出生的人反查设计者
- Length class：long
- Setup：许七安最初只知道原主父母双亡、父亲死于山海关战役，自己是普通许家大郎。原文 L20-L33。
- Dormancy：“出狱后开始捡银子”、灵龙异常、监正关注等被当作轻松机缘；金莲与洛玉衡后来才确认这不是普通福缘，而且监正一直替他屏蔽天机。原文 L34336-L34381。
- Reminder：天蛊婆婆的“二十年前两个小偷”信息、神殊对炼化气运的判断，以及税银案时间点不断提示：气运是有人主动放入，而非天生幸运。原文 L36515-L36523、L40401-L40505。
- Escalation：白衣术士试图在秘地抽取气运；许七安从屏蔽天机造成的记忆断裂、监正大弟子空缺和敌人刻意投放的信息中反查其身份。原文 L64881-L65288。
- Collision：父子大阵同时结算了许平峰身份、气运来源、许家记忆、税银案、龙牙、龙脉和监正后手。
- Payoff：许七安确认自己被当成气运容器出生，许平峰是亲生父亲；他以预留后手和盟友介入阻止气运被稳定抽走。原文 L65209-L65616。
- Second Payoff / Afterlife：父子冲突转入潜龙城、云州起兵和犬戎山大战；私人身世因此成为王朝战争的一条发动机，而不是揭完即止的血统秘密。原文 L66517-L66976、L87722-L88437、L102191-L108317。
- Why Reader Cares：养大他的家庭是真的，亲生父亲的容器计划也是真的；揭露迫使主角选择自己承认哪种关系，而不是自动接受“高贵血统”。
- Story State Change：许平峰已从幕后术士变成亲生父亲和叛乱主脑；许家人的记忆开始恢复；税银案被重新解释为把气运容器推出京城的行动。

## 6. 匿名地书 → 身份互揭 → 自主角色联盟

- Thread name：天地会不是固定队伍
- Length class：long
- Setup：金莲用地书碎片连接分处各地的人，以序号代替真名；成员可以互相求援，却彼此防备，金莲的目标是清理入魔的地宗道首。原文 L6713-L6780。
- Dormancy：成员长期只通过信息、交易和有限求援联系；每个人仍在自己的地图追逐目标。
- Reminder：恒远为寻找师弟和被拐儿童杀平远伯；李妙真在云州剿匪；怀庆关注朝局；楚元缜追查修行和旧案。主线先撞上他们的行动，身份才逐步显现。原文 L7193-L7273、L19215-L19351。
- Escalation：金莲善念、黑莲、怀庆一号身份与各成员早期误判被揭开；组织信任被重写，但个人目标没有消失。原文 L57502-L58577。
- Collision：雍州会合、围杀黑莲及后续云州战争中，成员分别带来军队、侦察、救济、心剑、元神控制和政治判断。原文 L107230-L107496、L110468-L110614。
- Payoff：许新年定位卓浩然，恒远负责联络，李妙真、李灵素、楚元缜等完成各自战术环节；敌人随后被迫改为高品三人一组。配角行动实际改变了敌方策略。
- Second Payoff / Afterlife：大劫结束后，成员仍保留各自生活、关系和修行道路；天地会没有被收束成正式军团或治理机构。原文 L133747-L133856。
- Why Reader Cares：匿名号码每次回流都可能带来一个此前在离屏处成长、受损或改换目标的人，而非等待主角召集的功能单位。
- Story State Change：天地会已从匿名群聊变成知道彼此身份、共同经历战争的联盟；但成员没有因此共享一个终极政治目标。

## 7. 怀庆：地书一号 → 夺位者 → 女帝

- Dormancy：她以皇长女和地书一号双重身份观察案件与朝局，没有立刻公开争位。

## 8. 李妙真：飞燕女侠 → 军队领袖 → 脱离天宗

# Short / Medium / Long Thread Grammar

## Short Thread

`具体异常 → 两三个可竞争解释 → 立即验证 → 局部结果 → 给中长线留一个余波`

典型用途是税银重量、县衙尸体姿势、梦巫仪式等。短线必须真的改变当前决定，不能只负责展示聪明。

## Medium Thread

`地方任务或公开比赛 → 多方欲望进入 → 能力规则在行动中显形 → 局部真相关闭 → 一个未闭合问题流向长线`

桑泊案、云州案、佛门斗法、柴家案都能在阶段内结算主要目标，同时把封印物、身份或幕后势力留给后续。

## Long Thread

`早期具体欲望/异常 → 自然休眠 → 新处境中的提醒 → 旧解释失效 → 与另一条人物或国家线碰撞 → 不可逆兑现 → 新生活或新敌策`

长线重量不来自提醒次数，而来自旧事实回流时真的改变当前行动条件。

## 选择怎样成为长篇玩法

1. 信息选择  
   选择相信哪条线索、向天地会公开多少、用什么信息换援助。过早公开可能暴露三号身份；保留则可能错过救援窗口。

2. 身份选择  
   捕快、打更人、三号、许银锣、徐谦等身份不是皮肤；每次揭露都会改变谁愿意合作、谁会围杀以及旧承诺是否还能履行。

3. 技能与时机组合  
   中后期优势来自把武夫、七绝蛊、法器、盟友能力和战场位置组合起来，不是始终使用一个必胜招式。

4. 保留与舍弃  
   是否保留龙气、是否暴露众生之力、何时使用玉碎、是否让太平刀吸收光门，都会关闭或打开未来行动空间。

## 对手怎样反制

- 梦巫让傀儡代替本人完成仪式，绕过“不给巫师施法时间”的战术。L22463-L22479。
- 佛门把斗法设计成开放式规则，并试图把胜者直接度入佛门。
- 贞德以京城百姓为目标，迫使许七安不能躲开蓄力一剑。L64226-L64250。
- 许平峰利用屏蔽天机和真假混合的信息，让许七安误认“初代监正”。L65248-L65263。
- 荒扩大体型、主动割裂身体并封印监正，分别反制空间切割、时间限制和守门人路线。
- 佛陀在西域直接修改规则，试图禁止出刀、攻击和复生。

对手反制的对象始终是主角当前最依赖的选择，不只是把数值抬高。

# TGN Story Program Inspirations

1. 先给超凡谜团一个可触摸的异常：尸体、重量、求救声、消失人口或一座被毁的庙。
2. 中线结案时关闭当前行动目标，但保留一个足以改变后期选择的问题，不要只留含糊“还有幕后黑手”。
3. 公开爽点必须产生后续权力：群众记忆、军队选择、敌人嫉恨或主角不能回避的责任场景。
4. 让配角先有离屏目标，再与主线相交；相交不等于永久归队。
5. 同一组织容纳不同欲望：组军、救济、复仇、修行、夺位和查案可以暂时合作，不必统一成组织纲领。
6. 力量说明只展开到足以判断当前战术；随后安排一次敌方反用或变体，证明规则会被人物利用。
7. 每次换地图至少携带三种旧状态：一段未清关系、一个未闭谜团、一项敌人已见过的优势。
8. 身份揭露的价值不在惊讶本身，而在揭露后谁改换策略、谁拒绝原关系、谁获得新的行动窗口。
9. 大碰撞点应同时结算案件、人物欲望和世界状态；只结算战力胜负的大战不足以承担长篇回收。
10. Payoff 后继续展示新生活：官职失去后的公共身份、复活后的新关系、登基后的战争、脱离宗门后的道路。

# Anti-Systemization Check

## 属于不可回滚的故事状态

- 桑泊封印被毁，神殊残躯进入现实。
- 楚州死者被公开承认，镇北王和旧朝声誉崩塌。
- 许七安失去官职，却获得超越官职的公共信用。
- 许平峰身份暴露，父子关系成为战争关系。
- 天地会成员身份互揭并共同经历战争。
- 怀庆称帝，军队、党派和国家敌人重新站位。
- 李妙真脱离天宗，飞燕军损失无法撤销。
- 西域被佛陀异质化，太平刀吸收光门。
- 监正的人性意识进入许七安，旧监正无法原样回归。

## 只是资产、技能或数值增加

- 捡到银子；
- 升任铜锣、银锣；
- 获得黑金刀、地书、宝塔或新蛊术；
- 单纯升品；
- 临时增加一个高品盟友；
- 战斗中多一种技能组合。

这些获得只有在改变身份、关系、敌人策略、地图事实或未来选择时，才升级为长篇故事状态。原作没有把所有机缘整理成可自由配置的技能树，因此不应反向拼成资产网络、权限树或运营系统。

方法层沿用了此前 SOURCE-FIRST 的“不可回滚状态—自然休眠—新处境回流—兑现后余生”与角色自主边界；本书剧情事实和 locator 均在本轮重新回到指定原文核对。
