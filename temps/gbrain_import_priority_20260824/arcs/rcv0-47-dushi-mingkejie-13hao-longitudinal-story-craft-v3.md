# Longitudinal Threads

## 1. Thread name：家不是后方，而是所有大线的最终落点

- **Length class：long**
- **Setup：** `[F]` 茵默莱斯家既是住宅、饭桌，也是“逝者关怀公司”；狄斯同时掌握家庭与生意。卡伦最初借原主身份进入这个家，后来狄斯以“只要你喊我爷爷”正式承认他。`第二章 L299-L337；第三十章 L6879-L6947`
- **Dormancy：** `[F]` 狄斯沉睡，卡伦离开罗佳市；家人照料狄斯，卡伦则在维恩继续生活、工作和晋升。狄斯临睡前要求卡伦有朝一日“回家来”叫醒他。`第七十七—七十九章 L17887-L18016`
- **Reminder：** `[F]` 丧仪社、做饭、冰水、电话、回家探亲不断回流；它们提醒读者，卡伦在外面的每一个身份后面仍有一个具体家庭。`第一百一十章 L24718-L24748；第五百六十九章 L107222起`
- **Escalation：** `[F]` 神殿准备处理狄斯时，卡伦没有把明克街疏散成战场，而是回家做饭、摆好狄斯的位置；外面封城、堵门，里面仍准备晚餐。`第八百八十四—八百九十章 L167911-L169317`
- **Collision：** `[F]` 狄斯在饭桌前苏醒；卡伦把康娜介绍为女儿，狄斯接受这个新家庭成员。家庭团聚、神殿冲突、卡伦的政治身份和下一代关系在同一场晚餐中碰撞。`第八百九十章 L169332-L169417`
- **Payoff：** `[F]` 狄斯先以审判官身份反击神殿，后来借地穴之神的攻击震碎自身神格碎片并成神；成神没有替换“爷爷”身份。`第八百九十三章 L170064-L170083；第九百五十三章 L181231-L181256`
- **Second Payoff / Afterlife：** `[F]` 终局中狄斯愿意代替卡伦承担结局，随后在阿尔弗雷德劝说下交出神格、选择相信孙子。`最终章 L183666-L183672`
- **Why Reader Cares：** `[I]` 世界尺度越大，家庭动作越小、越具体：端茶、做饭、留座、叫醒、回家。读者关心的不是“神级爷爷”，而是神位能否破坏或保全爷孙关系。
- **Story State Change：** 卡伦从把家庭当作身份掩护，变成主动承担家庭后果的人；“家”从安全屋升级为决定神教、神位和世界选择的尺度。
- **Evidence Anchors：** `第二章 L307-L337；第三十章 L6758-L6947；第七十九章 L17940-L18016；第八百九十章 L169189-L169417；最终章 L183666-L183672`

## 2. Thread name：借来的名字、饿瘾与“新的秩序”

- **Length class：long**
- **Setup：** `[F]` 周勋在卡伦身体中醒来，决定以后作为卡伦生活；狄斯的神降原本想召回孙子，却召来了现在的卡伦。`第二章 L240-L297；第三十章 L6840-L6868`
- **Dormancy：** `[F]` 卡伦长期无法确认自己的终极本源；阿尔弗雷德、霍芬、普洱等人分别把他理解成邪神、伟大存在或未知降临者。`第二十一—三十章 L4630-L5261、L6757-L6947`
- **Reminder：** `[F]` 净化时，光明之神的力量引来秩序之神；卡伦身后的秩序之眼与他自身发生联系，但这仍未给出完整身份答案。`第九十一—九十二章 L20819-L20935`
- **Escalation：** `[F]` 饿瘾逐渐由被镇压的内在威胁变成卡伦可调用的力量；其雕塑外形也逐步变成卡伦。`第七百九十五章 L149459-L149503；第九百零四章 L172359-L172369`
- **Collision：** `[F]` 秩序之神亲自看见卡伦体内的饿瘾，确认他是传承者；到神位交接时，卡伦必须同时承接秩序力量并防止饿瘾取代自己。`第九百零四章 L172256-L172370；第九百六十二章 L182785-L182800`
- **Payoff：** `[F]` 饿瘾吞噬诸神后反客为主，开始以卡伦为基础塑造新的自我；阿尔弗雷德的声音唤醒卡伦，使他重新取得主体位置。`最终章 L183638-L183740`
- **Second Payoff / Afterlife：** `[F]` 卡伦以自己的意志恢复形态、走入天堂并关闭大门。完成动作的是卡伦，而不是自动运行的饿瘾。`最终章 L183741-L183759`
- **Why Reader Cares：** `[I]` 这条线持续追问“当所有人都把你当成某种存在时，你还是否是自己”。最终胜负不是谁的能量更大，而是谁能保留对关系和过去的回应。
- **Story State Change：** 借名生存者→被误认的邪神→自选秩序路线的神官→秩序传承者→能够压住饿瘾的新秩序。
- **Evidence Anchors：** `第二章 L240-L297；第三十章 L6840-L6947；第九十二章 L20819-L20935；第七百九十五章 L149459-L149503；第九百零四章 L172256-L172370；最终章 L183638-L183759`

## 3. Thread name：从编外队员到代理大祭祀的关系阶梯

- **Length class：long**
- **Setup：** `[F]` 帕瓦罗死后，卡伦尝试苏醒他，继承其未完成之事，并使用其脸皮制作身份面具，借此进入秩序体系。`第一百三十四—一百四十八章 L29540-L29630、L32107-L32337`

- **Collision：** `[F]` 荒漠战争结束后，原本平级的区长主动以近似下属的姿态迎接他；弗登在高层面前把卡伦立为政治接班人。`第八百一十七章 L153723-L153824`
- **Payoff：** `[F]` 卡伦成为纪律部部长后，退休高层集体向他行礼；职位带来的不只是资源，而是过去不能触碰的行动空间正式开放。`第八百二十一章 L154468-L154578`
- **Second Payoff / Afterlife：** `[F]` 克雷德在就职典礼上任命卡伦为代理大祭祀，并亲手把大祭祀神袍披到他身上；全体神官依据他的姿态准备接受法旨。`第九百四十四章 L179623-L179687`
- **Why Reader Cares：** `[I]` 地位变化一直通过人际行为可见：谁来接车、谁替他整理衣领、谁不能再拍他的肩膀、谁必须站起来、谁愿意把未来押给他。
- **Story State Change：** 借别人编制行动→拥有自己的小队→城市权力节点→军团指挥者→系统接班人→实际教廷领袖。
- **Evidence Anchors：** `第一百四十七—一百四十八章 L32107-L32337；第三百一十五章 L62808-L62961；第六百零八章 L114747-L114787；第七百七十四章 L145683-L145817；第八百一十七章 L153723-L153824；第九百四十四章 L179623-L179687`

## 4. Thread name：尼奥——队长、求死者与光明教皇

- **Length class：long**
- **Setup：** `[F]` 尼奥第一次真正进入卡伦生活，是为爱人办理葬礼；他的冷酷队长、失去爱人的男人和被压制的强者三种身份同时出现。`第一百六十一章 L34741-L34868`
- **Dormancy：** `[F]` 两人长期以队长和队员相处，各自隐瞒光明等秘密，却都避免主动窥探对方。`第一百六十八—二百一十八章；L36266、L45354-L45471`
- **Reminder：** `[F]` 他们用分层下注的方式交换秘密；尼奥发现卡伦与自己共享超出职位关系的光明经验。`第二百一十八章 L45454-L45508；第二百六十二章 L53289-L53318`
- **Escalation：** `[F]` 尼奥不断用任务、污染和战斗寻找合适的死亡方式；卡伦知道他的真实意图，却一再把他拉回更大的行动。二人的合影直接把“谁先死”变成关系玩笑。`第五百二十一章 L98493-L98555；第七百零八章 L132183-L132202`
- **Collision：** `[F]` 尼奥死亡后，凯文提出光明传承方案，普洱交出陪伴自己两百年的光明手指，卡伦完成苏醒。`第八百七十三—八百七十五章 L165809-L166216`
- **Payoff：** `[F]` 尼奥重建光明神教，但不以扩张为目的；他要让光明在终极战中站到卡伦身后。`第九百六十一章 L182630-L182650`
- **Second Payoff / Afterlife：** `[F]` 光明准备带尼奥一同消散，饿瘾却因不愿刺激卡伦而把尼奥强行送回地面；求死线再次被关系改写。`最终章 L183673-L183678`
- **Why Reader Cares：** `[I]` 尼奥有自己的终极欲望——不是变强，而是找到一个自己认可的结束。他会隐瞒、借势、重建另一座神教，始终不是主角的功能型队友。
- **Story State Change：** 被压制的队长→卡伦的秘密同盟→主动求死者→光明传承者→独立教皇；每次“复活”都产生新路线，不恢复旧状态。
- **Evidence Anchors：** `第一百六十一章 L34741-L34868；第二百一十八章 L45354-L45471；第五百二十一章 L98493-L98555；第七百零八章 L132183-L132202；第八百七十三—八百七十五章 L165809-L166216；最终章 L183673-L183678`

# Short / Medium / Long Thread Grammar

## Short

基本句法：

> 一个具体生活场景 → 异常进入 → 人物作出选择 → 当场改变一段关系或一个身份。

短线通常在一至数章内结算，但必须留下可回收的痕迹。例如政治葬礼结案，却留下卡伦的苏醒方式、丧仪职业和“死者也能改变活人”的长期语法。`第四十一—四十四章 L9512-L10573`

## Medium

基本句法：

> 一宗案件、任务、葬礼或仪式 → 数次局部提醒 → 身份与关系在一次行动中翻面 → 余波进入下一地图。

如帕瓦罗线：查案、死亡、遗体、脸皮面具、丧仪社、审判官身份依次相接；案件结束后，帕瓦罗不再活跃，但他的名字、工作和未竟责任继续塑造卡伦。`第一百三十四—一百八十八章 L29540-L40266`

## Long

基本句法：

> 先建立可依恋的关系或欲望 → 让它沉睡而不消失 → 在新地图用旧物或旧动作提醒 → 提高力量差和身份差 → 让一次大事件同时结算旧关系与新世界问题 → 再留下第二次兑现。

长线不是“一直在场”，而是每次回流都改变意义：

- “回家”从保命变成唤醒狄斯；
- “面具”从伪装变成真实人生；
- “葬礼”从家庭生意变成神的送别；
- “收音机里的声音”最终变成叫醒新秩序的声音。

# Story Program Engine Variation

## 核心发动机如何换挡

1. **家庭／城市怪谈阶段**

   发动机是“这个家藏着什么、谁会伤害家人、这具尸体为什么异常”。世界通过饭桌、医院、客户、教堂和丧仪社进入。敌人多以附身、谋杀、仪式和局部身份威胁行动。

2. **离家／身份潜入阶段**

   发动机变成“卡伦能以什么身份进入神教、谁愿意承认这张脸、死者留下了什么位置”。敌人开始回收尸体、调查身份、操纵基层程序。

3. **小队／任务阶段**

   发动机变成“选谁进入队伍、谁愿意服从、谁值得被救”。敌人不再只追杀个人，而会拆散小队、利用地图规则、制造必须牺牲某个成员的局面。`第三百一十五章 L62808-L62961；第三百四十八章 L68607-L68650`

4. **城市权力阶段**

   发动机变成“谁能调查、调兵、任命和控制办公室”。敌人使用替身、身份面具、代理人、内部派系和制度缝隙；卡伦的反击也变成公开抓捕和重写权力结构。`第五百六十四—六百零八章`

5. **战争／军团阶段**

   发动机变成“旧小队能力如何放大为军团协作”。凯文负责视野，普洱改变战场，尼奥负责非常规指挥，卡伦承担公开身份与最后命令。敌人会摧毁阵法师、欺骗视野、切断组织协调，而非只提升单体强度。`第七百九十五章 L149293-L149403`

6. **诸神归来阶段**

   发动机变成“哪些旧存在必须阻止、谁继承火炬、谁还能保留自我”。敌人由教会和派系升级为分支神、纪元霸主与旧世界的自我复归。

## 配角如何获得自主目标

- **尼奥：** 寻找自己认可的死亡、处理光明传承、最终重建光明神教。
- **阿尔弗雷德：** 传教、上壁画、编写历史并证明自己对卡伦的理解。
- **普洱：** 恢复力量、重新面对艾伦家族、维护自己的历史位置和形象。
- **凯文：** 消磨封印、取回神力，同时主动选择保护普洱与卡伦。
- **皮亚杰：** 与琳达共同生活，哪怕代价是主动进入画中。
- **狄斯：** 保护家人、坚持自己的审判、成神后继续学习，而不是只替卡伦挡刀。

## 换地图为什么不 reset

- 卡伦到维恩后仍经营丧仪社，而不是丢掉开篇职业。
- 尼奥的葬礼把新组织关系接回旧仪式。
- 普洱回艾伦庄园，使新地图成为旧人物线的结算地。
- 小队进入轮回之门时，原有忠诚被换算成谁愿意替谁承担献祭。
- 卡伦成为高层后，饭桌、冰水、烟、车、制服和称呼仍承担地位显示。
- 神战终局仍由明克街记忆和阿尔弗雷德早期声音决定。

# Core Gameplay Choice & Counterplay

**适用。** 但它不是技能树，而是“选谁、选什么对象、何时暴露、保留什么关系、让谁进入下一阶段”。

## 长篇玩法

- **选对象：** 苏醒不是见尸体就收；卡伦逐步保留萨曼、雷卡尔等具有独立关系与未竟目标的人。十二口棺材不要求为了凑数而降低标准。`第四百二十二章 L80735-L80755`
- **选队友：** 卡伦建队时优先确认对方是否付出、是否愿意进入关系，而非只按战斗力排序。`第三百一十五章 L62810-L62838`
- **选身份：** 帕瓦罗面具、席尔瓦身份、光明余孽身份分别打开不同门，也分别带来被识破、继承责任和政治污染。
- **选时机：** 卡伦经常保留身份和饿瘾，不在最早时刻公开；真正公开会改变别人对他的称呼、站位和敌对策略。
- **保留／舍弃：** 普洱交出光明手指，使尼奥获得新路线；狄斯交出神格，是对卡伦主体性的信任；卡伦最终保留自我，舍弃让饿瘾自动完成终结。
- **组合：** 苏醒者、普洱的神国、凯文的神力、尼奥的非常规判断和阿尔弗雷德的叙事能力，只有在关系允许协作时才形成复利。

## 对手怎样反制

- 教会回收或彻底净化尸体，使苏醒失去对象。`第三十章 L6783-L6785；第五百二十一章 L98401-L98404`
- 使用身份面具、替身和潜伏，使卡伦无法确认该把哪种权限对准谁。`第五百六十五章 L106630-L106732`
- 用神性污染破坏身体、灵魂和身份验证；卡伦从污染地洞出来时，“过分干净”本身就可能暴露异常。`第七百一十六章 L134139-L134152`
- 拆散队伍或要求牺牲某个成员，迫使主角在任务成功和关系保留之间选择。`第三百四十八章 L68607-L68650`
- 神殿以家族、老师、传承与神的所有权争夺角色解释权。
- 纪元霸主联手阻断空间、攻击卡伦尚未完成的神位交接。

核心规则应抽象为：

> 优势必须绑定一个可失去的对象、一段关系或一次暴露时机；否则它只会变成库存。

# Stage Transition & World Opening

原作不是更新称号后让旁白宣布“世界更大了”，而是让读者实际看到：

1. **丧仪社世界**

   遗体推车、工作间、福利单、殓妆、棺材价位和家人分工先建立生活，尸体坐起才打开异常世界。`第二章 L307-L412；第三章 L615-L655`

2. **维恩与艾伦庄园**

   海怪接船、先祖画像、禁止养猫、主座安排、衰落家族的具体礼数，让“古老超凡家族”变成可进入的生活空间。`第七十九—八十三章 L18339-L19275`

3. **约克城秩序体系**

   神仆证、身份面具、办公室、丧仪社编制、任务分配和审判庭把神教变成有人际摩擦的真实组织，而非百科设定。

4. **轮回之门**

   旅游手册、鬼魂游行、巨人运输、门内居民与战场器具同时出现；新世界既有奇观，也有具体生活方式。`第三百五十一—三百五十二章 L69056-L69247`

5. **区长／军团长阶段**

   饭局席位、同僚改口、公开授牌、别人不再随意拍肩、会议因他沉默而改变节奏，使地位实际可见。`第七百二十八章 L137446-L137471；第七百七十四章 L145683-L145817`

6. **大祭祀／新纪元阶段**

   教尊主动寒暄、内厅座次、大祭祀亲手披袍、全教等待法旨；随后神战让天气、航运、物价和各教归来仪式同时变化。`第九百四十三—九百四十四章 L179383-L179687`

7. **神的世界**

   永恒之神出现在漏雨点心铺的旧沙发上；真正进入安拉冥德山后，历史尺度与普通生活并置。神没有脱离人物生活，而是被强行拉进人物已经建立的关系场。`第九百四十三章 L179383-L179479`

# TGN Story Program Inspirations

1. **先让读者爱上一个可触摸的生活单位，再让世界观从里面裂开。**  
   家、店铺、饭桌、宿舍都比百科更适合作为第一世界入口。

2. **人物声音必须能发动行动。**  
   阿尔弗雷德的夸张会建立组织；尼奥的嘲讽会改变计划；普洱的护短会开启家族与战斗线。

3. **地位变化至少安排一个他人行为证明。**  
   改称呼、让座、交钥匙、授牌、披袍、等待命令，比宣布“晋升”更有效。

4. **长期谜团每次回流只回答一层。**  
   先回答“卡伦不是原主”，再回答“狄斯承认他”，再回答“他与秩序的关系”，最后才解决“谁控制最终身体”。

5. **把短案写成长线的入口，而不是孤立副本。**  
   案件可以留下名字、遗体、身份、葬礼、办公室或一个新关系。

6. **大事件至少重写三条线。**  
   一个合格碰撞点应同时改变关系、身份和世界事实，而不只是击败敌人。

7. **配角自主目标应能暂时偏离主角任务。**  
   尼奥可以求死，皮亚杰可以进入画中，阿尔弗雷德可以自行传教；主角不是所有欲望的源头。

8. **换地图时携带旧动作，不只携带旧角色。**  
   做饭、办葬礼、喝冰水、开车、整理衣领等动作，能比设定回顾更自然地保存连续性。

9. **第二兑现应改变第一次兑现的意义。**  
   第一次“回家”是普洱回艾伦家；第二次是卡伦回明克街叫醒狄斯；终局则把天堂也解释成家族墓园。

10. **终局胜负应调用全书形成的关系能力。**  
    如果最终只有最新技能有效，前面的长线就是装饰；阿尔弗雷德叫醒卡伦证明早期生活经验仍是终局资源。

# Anti-Systemization Check

| 类型 | 原作中的例子 | 是否属于 Story State |
|---|---|---|
| 单纯资产增加 | 新神器、新办公室、新坐骑、新神格碎片 | 否；除非改变后续关系或行动权 |
| 单纯技能增加 | 多一种属性、术法、探查或战斗手段 | 否 |
| 单纯称号增加 | 队长、部长、区长、军团长的文字变化 | 否 |
| 关系不可回滚 | 狄斯承认卡伦为孙子；阿尔弗雷德成为其信仰锚点 | 是 |
| 身份不可回滚 | 卡伦继承帕瓦罗未竟责任；尼奥死后成为光明传承者 | 是 |
| 组织不可回滚 | 约克城权力重组、卡伦被立为接班人 | 是 |
| 世界不可回滚 | 第一骑士团消耗、诸神全面归来、天堂之门关闭 | 是 |
| 人物选择不可回滚 | 皮亚杰进入画中；普洱交出光明手指；狄斯交出神格 | 是 |

最关键的区分：

- **十二口棺材不是“十二个召唤栏位”**；重要的是谁因什么关系被保留、苏醒后还想做什么。
- **饿瘾不是“吞噬升级系统”**；它既能提供力量，也会取代卡伦，终局必须由关系锚点夺回主体。
- **秩序之鞭不是“势力资产包”**；职位只有在别人服从、敌人改策、主角必须承担新后果时才形成故事状态。
- **普洱、凯文、尼奥、阿尔弗雷德不是技能组件**；他们会隐瞒、拒绝、自主选择、改变主角计划。
- **最终不可回滚状态**是卡伦亲手关闭天堂，而不是他收集了多少神格。

`[U]` 原文没有展开天堂关闭后的具体政体、神教制度和众人长期职位；不得据此补写成完整的新世界治理系统。
