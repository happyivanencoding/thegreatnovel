# Longitudinal Threads

## 1. 技能图鉴：从复制捷径到成长选择器

- **Thread name**：复制—教学—融合—推演
- **Length class**：long
- **Setup**：图鉴能复制、教学技能，但必须目击、限时接触，教学还受宠兽契合度限制；重复教学能增加熟练度，新技能不能凭空产生。
- **Dormancy**：图鉴经常退居幕后。日常章节转而处理身体恢复、赚钱、冥想、找技能来源和宠兽自身训练，使外挂不会持续占据正面剧情。
- **Reminder**：每次新增宠兽，图鉴页数增加；但容量、冷却和体力消耗不断迫使时宇选择“给谁、教什么、现在是否值得教”。
- **Escalation**：早期复制单项技能；中期争夺世界树祝福解锁技艺融合；星际阶段再得到技能推演，开始根据宠兽自身方向开发新能力。
- **Collision**：职业考核、全国赛、世界赛分别提供技能来源、资源和世界树祝福；比赛奖励不是终点，而是图鉴下一阶段功能的钥匙。
- **Payoff**：核心优势由“把别人的技能教给宠兽”升级为“围绕每只宠兽的种族、愿望和既有能力创造专属组合”，因此多宠不会被练成同一模板。
- **Second Payoff / Afterlife**：图鉴最终说明自身来自上纪元，并明确宇宙级道路上难以继续提供直接帮助；外挂完成使命后退为遗迹雷达，时宇和宠兽必须自行突破。
- **Why Reader Cares**：每次成长都包含取舍、赌组合与马上可见的结果，不是自动领取等级；读者既期待新技能，也期待它会落到哪只宠兽、改变哪种玩法。
- **Story State Change**：图鉴从早期个人秘密，变成塑造整支队伍差异化能力的创作工具，最后又失去“代替成长”的作用。
- **Evidence Anchors**：
  - 第2章：复制、接触、时限、体力、契合度，L139-L150；重复教学与主动寻找来源，L423-L439。
  - 第8章：冷却与身体消耗，L1029-L1041、L1061-L1077。
  - 第100章：契约虫虫后新增页面，御兽师成为宠兽之间的纽带，L11734-L11745。
  - 第134章：页数只剩两个，必须精打细算，L18045-L18064。
  - 第451—454章：世界树祝福后解锁技艺融合，L82656-L82840、L83128-L83183。
  - 第527章：新增技能推演，L98389-L98423。
  - 第664章：图鉴来历与能力终点，L123313-L123340。

## 2. 十一：被嫌弃的食铁兽到宇宙霸主

- **Thread name**：不被选择者成为最强者
- **Length class**：long
- **Setup**：十一先天羸弱、屡次不被御兽师选择，因此把“训练、变强、得到认可”当成基本欲望。时宇主动选择它，并承诺不会因低种族而替换宠兽。
- **Dormancy**：重大进化之间，十一以自律训练、队内领袖、争第一和训练过度的喜剧回流。人物识别点不依赖新技能维持。
- **Reminder**：进化圣泉只激活远古血脉，没有直接给出答案；十一得到更多体力后首先想到的是增加训练量。
- **Escalation**：聆听食铁兽遗址历史，发现武装进化；进化法公开后改变整个食铁兽种族的市场与地位；此后继续追索铭文、魔神、混沌等更高形态。
- **Collision**：职业考核公开进化形；全国赛证明多次进化后的战力；世界赛使神话路线对外曝光；万族排名战又把个体强度转化为整个食铁兽种族的排名。
- **Payoff**：十一不再只是时宇的第一王牌，而成为食铁兽进化、训练和战斗文化的公共证明。
- **Second Payoff / Afterlife**：时宇契约宇宙期间，十一独立击败赛波斯，成为新的宇宙霸主，并建立食铁兽战斗军团。
- **Why Reader Cares**：最早陪伴、最朴素的“我会努力”不断在更大舞台得到重新证明；成长尺度扩张，但它想训练、想当第一的性格不变。
- **Story State Change**：十一从可被替换的低种族幼崽，变成不可替代的伙伴、种族进化源头，最终重写宇宙最强者的位置。
- **Evidence Anchors**：
  - 第7—13章：被嫌弃、自律、接受契约及不抛弃承诺，L789-L849、L1098-L1163。
  - 第71章：进化可能出现，但道路需要自行寻找，L7410-L7460。
  - 第96—97章：武装进化历史影像与现实验证，L10872-L11028。
  - 第127—129章：国家奖励、进化形公布并火遍全国，L16679-L16690、L17257-L17280。
  - 第155章：十一正式武装进化，L21454-L21494。
  - 第675章：熊猫学姐策划以十一提升食铁兽万族排名，L125410-L125416。
  - 第707—709章：独立目标与宇宙霸主兑现，L130342-L130344、L130563-L130565。

## 3. 虫虫：弱小青绵虫的“大梦”不断换壳

- **Thread name**：从“梦见自己是龙”到创世梦蝶
- **Length class**：long
- **Setup**：虫虫主动选择空间、精神、龙三条方向：空间用于逃生，精神来自爱做梦，龙则因为它梦见过自己成为强大巨龙。
- **Dormancy**：早期长期维持青绵虫外形，以虫丝、梦境、幻影积累潜力；它并不因暂时弱小退出队伍。
- **Reminder**：虫虫反复挑战十一、准备队内赛，并通过梦境具现不同对象，持续提醒读者“它要让幻想成真”。
- **Escalation**：青虫茧与空想之蝶证明其个人成长；青虫茧研究又把个体成果变成普通家庭可负担的新进化路线。
- **Collision**：世界赛中，过去只会做梦的青绵虫以青龙形态灭杀图腾；个人幻想、星象信仰、世界级赛事和考古发现同时结算。
- **Payoff**：虫虫让虚构青龙成为现实，取得星空生命入口。
- **Second Payoff / Afterlife**：终局不继续依附青龙身份，而是融合虫族女王血脉、回到“虫”的本体，进化为创世梦蝶；十万年后建立连接各大宇宙势力的梦境网络。
- **Why Reader Cares**：每次进化都兑现旧梦想，却又保留更高一层“不满足”；它不是换皮升级，而是在“幻想能否变成现实”上反复升级答案。
- **Story State Change**：最低层青绵虫先改写自身命运，再改写青虫进化产业、青龙信仰事实和宇宙交流方式。
- **Evidence Anchors**：
  - 第74、82章：选择空间、精神、龙与梦境方向，L7712-L7752、L8749-L8772。
  - 第100、164章：正式契约及青虫茧阶段，L11720-L11745、L22927-L23070。
  - 第199—208章：空想之蝶与青虫茧研究扩散，L28860-L30728。
  - 第442—443章：青龙由梦成真，L80890-L81008。
  - 第639、680章：舍弃青龙外壳、以虫族本体冲击更高道路，L119957-L119980、L126218-L126270。
  - 第700、709章：创世梦蝶与宇宙梦网，L129312-L129390、L130567-L130569。

## 4. 参宝宝：补品身份、战斗欲望与“参天帝”

- **Thread name**：从备用食材到补品种族的反抗样本
- **Length class**：long
- **Setup**：参宝宝厌恶被切片、煲汤和当作食材，希望掌握战斗力量、主宰自己的命运。时宇选择它，既因为恢复能力，也明确答应开发其战斗方向。
- **Dormancy**：它长期承担补品制造、体力恢复和队伍资源生产，看似回到“补品”位置；但队内排名焦虑与攻击果研究持续保留个人欲望。
- **Reminder**：它战胜普通植物宠兽后仍因队内垫底而不甘；弱点不是“没有价值”，而是它拒绝只以辅助价值定义自己。
- **Escalation**：进化为时间系不死参；把能量果、月爆、时光印记组合为自爆—复活玩法。
- **Collision**：世界赛中主动成为诱饵，被敌人吞食后从内部自爆，灭杀、重创多只图腾并凭时光印记归来。
- **Payoff**：封神战被时宇改成队内赛后，参宝宝靠针对队友的知识和果实战术夺冠；“补品植物”成为公开冠军和植物种族偶像。
- **Second Payoff / Afterlife**：它停止单纯追求队内第一，创造低门槛《天帝经》，让弱小补品种族至少拥有反抗机会；十万年后自身成为宇宙级并持续为时宇输送力量。
- **Why Reader Cares**：喜剧性的“萝卜翻身”不断获得更大兑现，且每次成功仍来自最初的补品能力——香气、果实、恢复——而非换成无关的新职业。
- **Story State Change**：参宝宝从可食用资源变为主动战斗者、冠军、知识创造者和补品种族的长期参照。
- **Evidence Anchors**：
  - 第134—135章：拒绝食材命运与接受邀请，L18140-L18180、L18326-L18354。
  - 第149—152章：契约后反哺图鉴与战斗果实，L20701-L20755、L21037-L21105。
  - 第259、305章：不死参进化与首次稳定自爆—复活，L40274-L40309、L48703-L48734。
  - 第世界赛试炼：自爆、灭敌、时光印记归来，L81580-L81643。
  - 第581—583章：针对素素的知识战与队内冠军，L109640-L109685。
  - 第675—676章：放下队内第一、创造《天帝经》，L125424-L125448。
  - 第708—709章：宇宙级与族群影响，L130406-L130418、L130571-L130573。

## 5. 素素：净化欲望从小岛走到宇宙级宿敌

- **Thread name**：弱小水史莱姆与污染之敌
- **Length class**：long
- **Setup**：沧海精灵转世不断退化，最新转世体成为低种族水史莱姆；素素即使弱小，也主动对抗污染海洋的生物。
- **Dormancy**：它没有立即得到完整沧海力量，而是先契约、训练、吞噬资源，数百章内保留“想净化污染”的具体愿望。
- **Reminder**：不能前往污染海域时会难受；成为星际环保协会成员后，主动把净化污染当作愿意长期做的工作。
- **Escalation**：面对要求解除契约、沉睡十年的旧传承，素素和时宇拒绝照单全收，选择只接收必要部分，再走自己的星海精灵路线。
- **Collision**：净化能力同时克制陨族、深渊、暗王势力，并反过来为全队提供资源、恢复和宇宙身份。
- **Payoff**：素素在污染之地形成超神意志，击杀深渊超神；终局又以净化暗王的长期积累突破宇宙级。
- **Second Payoff / Afterlife**：宇宙抹除时宇的历史后，素素用记忆水滴长期恢复重要人物的记忆，成为事实上的历史记录者。
- **Why Reader Cares**：它的战力、工作、宿敌和终局任务都来自同一个早期欲望，读者能看见愿望在不同地图上不断放大，而不是作者临时分配职责。
- **Story State Change**：素素从无人在意的水史莱姆变成沧海精灵、星海精灵、暗王克星，并保住被宇宙改写的人际历史。
- **Evidence Anchors**：
  - 第273—278章：沧海转世、素素的意志及契约成长，L42984-L43010、L43209-L43224、L43550-L43933。
  - 第401章：拒绝解除契约和十年完整传承，L70060-L70225。
  - 第402章：接受调整后的传承，获得全球遗迹入口与净化能力，L70314-L70409。
  - 第535—539章：星海精灵、本源波动与环保协会资源循环，L100430-L100677、L101293-L101327。
  - 第610—611章：超神意志与深渊超神首杀，L114443-L114532。
  - 暗王战与宇宙级突破，L127964-L128004、L129018-L129042。
  - 第707—709章：恢复被抹除的记忆，L130375-L130391、L130575-L130578。

## 6. 凛：比赛奖品变成拥有自主判断的“团魂”

- **Thread name**：研究型机械生命接管队伍协作
- **Length class**：long
- **Setup**：全国冠军奖励的百变石与机械材料没有直接变成装备，而被用于创造研究型机械生命凛。
- **Dormancy**：凛初生时分析队友甚至会过载；它先从制订训练计划、提升智能和研究机械幻兽做起，并不马上抢战斗焦点。
- **Reminder**：每当队伍需要新进化、装备、合体方式或数据分析时，凛重新出现；它逐渐获得“自己决定研究顺序”的能力。
- **Escalation**：机械幻兽、风麒麟、风之祝福、合体机甲、星空风暴依次扩大其作用；换到界王星后，凛进入宇宙灾害研究所，而不是重置为普通新宠。
- **Collision**：全国赛奖励、考古化石、虫虫梦境、参宝宝补给和其他宠兽能力都在凛身上发生交叉；后期合体机甲又把分散宠兽重新聚焦为一个战斗动作。
- **Payoff**：在霸主疆域，凛仅用机械分身就以压缩星空风暴击败完美神，过去的研究积累获得独立战斗证明。
- **Second Payoff / Afterlife**：时宇契约宇宙的十万年里，凛统筹所有宠兽的反馈、用暗号穿过宇宙干扰，并同时维持梦网、机械技术和食铁兽舰队供应。
- **Why Reader Cares**：它不是“第六件装备”，而是团队新增一种人格和决策方式：认真、计算、操心、在幕后修正主人。
- **Story State Change**：一块比赛材料变成能自行研究、管理、战斗并维系全队协作的独立伙伴。
- **Evidence Anchors**：
  - 第319—321章：百变石等奖励，L52270-L52289。
  - 第320—324章：研究型机械选择、凛诞生与自主训练要求，L52476-L52497、L52995-L53121。
  - 第324、328章：自主研究路线与机械幻兽，L53184-L53191、L54053-L54124。

  - 第477—483章：究极机械凛与合体机甲，L87908-L89736。
  - 第535章后：宇宙灾害研究所与星空风暴，L100207-L100371、L101458-L101555。

## 7. 考古：过去不再是背景，而是宠兽、资源和敌人的现役来源

- **Thread name**：抗拒重操旧业，却一路把历史变成现在
- **Length class**：long
- **Setup**：时宇前世因考古事故死亡，今生明确想远离危险；但石像的历史声音重新激活好奇心。
- **Dormancy**：考古不连续霸屏。训练、比赛和养宠之间，历史线以遗迹、古物或宠兽身份间歇回流。
- **Reminder**：食铁兽进化、冰原真相、穆徽音英灵、凤凰血脉、机械化石，都提醒读者“旧事实会改变当前行动”。
- **Escalation**：个人听见石像，升级为十一局成员；再升级为公开考古学家、世界考古大会发言者、历史穿越者和纪元遗迹寻找者。
- **Collision**：每次考古发现都同时服务另一条线：食铁兽遗址服务十一；英灵遗迹服务赤瞳；沧海遗迹服务素素；化石服务凛；神话真相重写世界赛风险。
- **Payoff**：世界考古大会上，时宇将神话复苏时间、外星灾害和历史发现公开，随后得到世界树验证；考古从“寻宝职业”成为世界开放机制。
- **Second Payoff / Afterlife**：地球遗迹与图鉴留言将个人穿越、上纪元和契约宇宙连接；宇宙后来试图删除时宇的历史，反而把“谁还记得真实发生过什么”变成终局冲突。
- **Why Reader Cares**：历史信息很少只作解释，它通常马上带来宠兽、资源、身份、敌人或新地图。
- **Story State Change**：时宇从逃避考古的个人，成为能把失落历史转化为现实力量、公共认知和宇宙方向的人。
- **Evidence Anchors**：
  - 第26—31章：前世抗拒、石像与十一局，L2464-L2576、L2857-L2948。
  - 第96章：食铁兽历史影像改变进化事实，L10881-L10908。
  - 第145—146章：冰原真相与正式十一局身份，L20111-L20275。
  - 第174—180章：穆徽音与赤瞳，L24480-L25699。
  - 第425—427章：世界考古大会及世界树验证，L76322-L77034。

## 8. 比赛：不是重复擂台，而是阶段性“总清算器”

- **Thread name**：职业考核—全国赛—世界赛—封神战
- **Length class**：long
- **Setup**：职业考核把野外生存、资源获取、身份认证和宠兽实战放在同一结构中。
- **Dormancy**：两次大赛之间用研究、探索、进化和队内赛蓄积新变量，避免连续擂台。
- **Reminder**：队内大会维持宠兽之间的横向竞争，让未获得外部主场的宠兽也能持续产生目标。
- **Escalation**：
  - 职业考核：证明能成为职业御兽师。
  - 全国赛：证明多宠体系并获得凛的材料。
  - 世界赛：从七国青年赛升级为七国、图腾国、复苏神灵共同参与的世界冲突。
  - 封神战：进入宇宙万族竞争，时宇把公开赛事改造成宠兽之间的队内赛。
- **Collision**：每场大赛同时结算宠兽成长、主角身份、公开证明、奖励资源和下一阶段世界入口。
- **Payoff**：封神战八强全部是时宇的宠兽，参宝宝夺冠；宠兽不再只是主人阵容中的卡牌，而以不同公开身份独立参赛。
- **Second Payoff / Afterlife**：冠军挑战取得永久传送阵，使赛事结果反哺蓝星与界王星的长期连接；胜利不止留下称号。
- **Why Reader Cares**：比赛通常在几章内提供清晰期待和早兑现，同时又推动更长线的身份、资源和地图变化。
- **Story State Change**：每次夺冠都关闭一个旧问题并打开新发动机：合法身份、机械宠兽、神话能力、星际通道。

# Short / Medium / Long Thread Grammar

## Short Thread Grammar

观察到的常见结构是：

> 一个具体欲望或小麻烦 → 马上选技能/资源/战法 → 一场短战或测试 → 立即证明 → 喜剧性收尾或新钩子

例如图鉴第一次教学、十一训练毁家风险、虫丝赚钱、宠兽小型对战。短线通常几章内兑现，使长篇不会长期只靠远期承诺吊着读者。

关键不是“每章派奖”，而是每个新概念尽快得到一个可见结果：能不能打、能不能卖、能不能进化、别人是否认可。

## Medium Thread Grammar

> 明确奖励或问题 → 20—80章准备 → 研究/探索/训练分流 → 赛事或遗迹统一验收 → 奖励立刻进入下一发动机

典型包括：

- 食铁兽进化法发现→验证→公布。
- 虫虫结茧→化蝶大会→青虫茧研究。
- 全国赛目标→多宠进化→夺冠→百变石变成凛。
- 素素转世体→养成→调整传承→沧海精灵。

中线的重要作用，是让长线每隔一段时间获得完整阶段性满足。

## Long Thread Grammar

> 一个不可替代的欲望/关系承诺 → 多阶段暂退 → 用行为特征提醒 → 在不同发动机中升级问题 → 大碰撞完成第一次兑现 → 新身份继续产生 Afterlife

长线不依赖同一种任务重复。十一始终想变强，但发动机从训练、进化、比赛、种族排名一路换到宇宙霸主；虫虫始终把幻想变成现实，但外壳从幻影、空想蝶、青龙换到创世梦蝶。

真正维持连续性的，是欲望、关系和旧结果，不是同一套副本。

## 选择怎样成为长篇玩法

- **选对象**：契约位与图鉴页面有限，选择十一、虫虫、参宝宝、素素、凛，等于选择不同的长期矛盾，而非只比较初始战力。
- **选技能**：技能必须有来源、满足契合度，还会占页面；早期参宝宝加入时只剩两个位置，文本直接让“留什么、舍什么”进入戏剧。
- **选时机**：教学消耗时宇身体；高阶教学、融合和推演必须配合补品、休养、比赛节点与御兽等级。
- **保留/舍弃**：虫虫终局舍弃强大的青龙外壳，回到虫系本体；素素舍弃旧传承的十年完整方案，只取能继续共同成长的部分。
- **组合**：单技能在中后期失去决定性，转向奥义、融合、资源爆发、宠兽配合和凛的合体机甲。
- **轮换焦点**：一次大阶段通常突出一至两只宠兽，其余宠兽通过辅助、队内竞争或研究参与，避免七八只宠兽同时争夺同一段正面篇幅。

## 对手怎样反制

- 早期对手根据公开表现增加针对模块，例如高轩为赤瞳准备火免系统，L41618-L41696。
- 全国赛高轩使用五位一体机械合体和霸主级超频，试图以单一高完成度机甲压制多宠体系；时宇用赤瞳、十一、素素、虫虫组合破解，L51977-L52060。
- 虚空螳螂使用魔禁领域切断自然能量和外部操控，逼十一依靠内部储备、体魄和多轮极限爆发，L56939-L57034。
- 七岛冠军之路从普通守关升级到妖刀、诅咒和副作用转移，专门针对持续爆发与资源续航，L60257-L60918。
- 青龙公开后，图腾势力不再把时宇当普通选手，而是“必须提前除掉”的战略风险，L80929-L80949。
- 四圣家族判断正面处理代价过高，改用遗迹公共性、道德压力、代理人和战场事故阻止时宇，L110012-L110019、L114991-L115029。
- 暗王用“污染概念仍存在即可复生”反制单次击杀，迫使素素、鸭鸭、凛和全队同时处理净化、权柄夺取与合体输出，L127964-L128017。

因此，长篇反制不是把外挂直接封死，而是让敌人针对其已经公开的表现，迫使主角换对象、换组合、换战场。

# Stage Transition & World Opening

1. **见习→职业御兽师**：不只拿执照；时宇获得进入封锁野外、参与资源分配和进入古都大学的实际权限。L18095-L18104。

2. **平城→古都**：读者实际看到大学、英灵遗迹、研究组、社团、校际对战和十三局，而不是只说“进入大城市”。

3. **国内→龙宫城**：第一次看见海洋势力、龙族宴会、非人组织、岛屿生态和素素的出生环境；同时产生第五宠和环保部。L41196-L41220、L42917-L43933。

4. **国内冠军→世界赛**：七国、图腾国、复苏神灵和世界树同时登场；原本体育赛事被改写成生死阵营冲突。L46770-L46790、L76949-L82695。

5. **神话复苏→星空时代**：外星污染者不再只是古代传说，陨犴说明自己的星外来源；随后空帝一脉外星御兽师真正降临蓝星。L93017-L93092、L96336-L96595。

6. **蓝星→界王星**：新世界通过城市、协会、封神战、宇宙灾害研究所、星际货币与传送限制被具体展示；旧能力获得新用途——素素净化污染赚钱、凛研究灾害、参宝宝进入植物协会。

7. **界王星→霸主疆域**：航行时间、星空风暴、合法海盗“规矩战”、宇宙霸主军团与纪元遗迹形成与界王星不同的生活和冲突方式。L116318-L116440。

8. **宇宙级→平行时空/宇宙维系者**：力量提升后，读者实际看到历史被抹除、宠兽离队独立行动、十万年格局变化和重聚，不只是更新“宇宙之主”称号。L130302-L130640。

# TGN Story Program Inspirations

1. **给每个一级成长对象一个不可混淆的欲望动词**：不同长期伙伴分别拥有“争强、实现幻想、摆脱被支配、解决污染、研究并协调”等不可混淆的欲望动词。

2. **新增对象必须改变玩法，不能只增加人数**：新宠至少应带来一种此前不存在的行动——新地图入口、新资源循环、新战斗结构或新信息能力。

3. **主角优势最好是选择器，而非自动胜利器**：限制选择数量、对象契合和使用时机，让每次选择决定后续数十章的玩法。

4. **大赛应当一次结算三条以上的线**：人物成长、公开身份、奖励资源、敌人反应和下一阶段入口至少同时变化两三项，否则容易变成可跳过擂台。

5. **高价值奖励尽快转成下一发动机**：阶段奖励不在库存里沉睡，而应很快转化为新伙伴、新能力形态或真实世界入口；跨域通行类奖励应直接改变后续移动与关系条件。

6. **长线提醒优先使用性格动作**：让伙伴通过继续训练、持续追逐自己的幻想、私下研究新的针对方案等性格行动提醒长线，比反复解释“它仍有梦想”更有效。

7. **敌人反制公开表现，不必凭空知道秘密**：先看到技能或战绩，再增加火免、禁魔、诅咒、代理人或围杀策略。

8. **换地图时携带旧人物的事业，而不只携带主角资产**：研究者继续研究，配角继续升级，旧组织在新世界获得新位置。

9. **第一次 Payoff 后继续写 Afterlife**：进化、夺冠、揭露身份不一定是终点；让结果改变种族、关系、敌人策略或十万年后的世界事实。

10. **轻快节奏来自“短兑现＋反差”，不是降低长线复杂度**：重大世界信息之后接宠兽反应、队内攀比或资源算账；但笑点之后仍留下真实状态变化。

| 时宇买补品缩短图鉴冷却 | 否 | 只是提高加点效率，除非因此决定能否参加某场事件 |
| 契约十一并承诺不替换它 | 是 | 关系与队伍核心不可回到“随时换宠” |
| 食铁兽进化法被国家验证并公布 | 是 | 市场、研究、时宇身份和整个种族认知被改写 |

| 参宝宝取得新果实配方 | 未必 | 队内夺冠、停止追第一并创造《天帝经》才真正改变人物方向 |

| 获得永久传送阵 | 是 | 蓝星与界王星的实际移动、资源和势力关系改变 |
| 宠兽全部达到更高等级 | 否 | 若仍只能做原来那些事，就是规模升级 |

| 时宇契约宇宙时被历史抹除 | 是 | 全宇宙人物知识状态改变，迫使素素和宠兽展开十万年独立行动 |

最终可提炼为一句：

> 原作的“系统性”主要存在于能力规则；真正产生长篇复利的不是技能表，而是技能何时让某只宠兽获得新选择、让敌人改策略、让身份被公开承认，或让世界事实无法回到原状。
