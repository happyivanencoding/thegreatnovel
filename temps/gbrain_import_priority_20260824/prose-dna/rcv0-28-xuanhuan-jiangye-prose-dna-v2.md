## Attention DNA

### Core Selection Strategy

在已观察窗口中，带宽优先给正在改变场面状态的细节：

- 改变空间尺度、危险距离或可行动范围的细节；
- 让抽象恐惧、贫困、身份压力落到物件、预算、身体或边界上的细节；
- 能够确认行动回报、代价或新选择的连续结果；
- 能让关系压力从对白、停顿和行为中显形的细节。

稳定背景、未改变的抽象说明和不能影响当前选择的旁支信息相对压缩。

### Scene-Conditioned Behavior

- **OPENING / 空间进入**：优先选择温度、声音、光线、距离、尺度等可感知锚点，再给一个人物或身体反应。
- **ORDINARY / 生计与共同生活**：优先选择门、床铺、银钱、租金、食物、工作选项等能改变日常行动范围的细节。
- **ACTION / PAYOFF**：优先写位置、资源、方向、轨迹、使用顺序和结果，让读者看见状态怎样变化。
- **EMOTION / IDENTITY**：把高层恐惧压回呼吸、疼痛、冷、奔跑或照护行为。
- **ENDING / 大尺度收束**：在宏大结果之后选择低强度的生活动作或关系互动，恢复人物尺度。

### Compression / Omission Boundary

当抽象判断尚未获得空间、物件或身体承接时，不急于给它完整解释。若当前行动所需的局部因果已经清楚，可压缩重复说明；规则说明应在形成任务、选择或风险出口后停止。

未被当前行动验证的更广身份、历史或世界解释只能保持未展开状态，不能从此卡升级为确定规则。

## Knowledge DNA

### Core Selection Strategy

知识披露跟随当前叙述位置和行动需要：先让角色看见、判断、验证或计算，再补充能够支撑下一步的规则与背景。知识并不因“存在于世界中”就自动进入当前文本。

### Scene-Conditioned Behavior

- **ACTION_SETUP**：先给地图、路线、声音和站位，让危险通过角色计算逐步显形。
- **EXPOSITION_TO_ACTION**：让身份验证、物件线索、制度术语和问答承载规则，并立即落到一个任务。
- **EXPOSITION_DIALOGUE**：通过问答、反问、停顿和轻微顶嘴分配规则带宽，使解释留在关系场中。
- **LATE / 大尺度场景**：允许短暂拉远到自然灾害、神性或世界尺度，再以醒来、走路、面对来者等动作收回观察点。
- **STRATEGIC_DIALOGUE**：让私人话语在公共场面中逐句转述，以听众视线和停顿显示知识如何变成压力。

### Compression / Omission Boundary

当局部规则足以支持当前动作时，不必同时解释其完整历史、全部层级或最终意义。相反，若角色无法凭现有信息完成当前选择，则需要补足与物件、身份或风险直接相关的最小知识。

解释的停止点是“读者已能理解当前行动为何可能、角色下一步要面对什么”，而不是把世界规则讲完。

### Evidence / Anti-Evidence

Evidence: `w04`、`w08`、`w11`、`w12`、`w13`；旧卡 `narrative_distance`、`exposition` 与 `scene_entry` observations。

Anti-Evidence / Boundary:

- `interior_thought`、`character_voice` 均为旧卡 `UNKNOWN`，不能据此建立稳定的全书 POV 或心理知识规则。
- 不能推断叙述者在所有场景中都掌握同样范围的背景知识。
- 未被当前窗口行动验证的解释保持 `INSUFFICIENT`，不应被写成确定的知识层级。

## Causal DNA

### Core Selection Strategy

因果带宽主要用于保持以下链条可追踪：

> 空间或资源条件 → 可见动作 → 物理/社会结果 → 新行动空间、代价或关系压力

说明通常停在读者已经能看见结果的位置；回报不由单句判断替代，而由连续的物件、动作、环境或旁观反应确认。

### Scene-Conditioned Behavior

- **ACTION_SETUP**：先确定路线、距离、位置和威胁怎样形成。
- **ACTION**：先明确谁在哪里、使用什么资源、资源怎样消耗，再加入速度、声音和反常反应。
- **PAYOFF**：按物理结果逐项确认能力或策略是否奏效，并转入伤亡、仇恨或无人欢迎等余波。
- **ACTION_REVERSAL**：反转来自对既有资源或知识的重新理解，而不是突然添加未铺垫的新名词。
- **STRATEGIC_DIALOGUE**：重复私人话语、停顿和公共视线，使语言本身产生新的政治压力。
- **ENDING**：让宏大规则最终改变到普通空间中的动作和关系状态。

### Compression / Omission Boundary

可以压缩不影响当前选择的总体系解释，但不能压缩位置、资源、动作方向和结果之间的关键连接。不要用“成功”“失败”一类总括判断替代可见结果，也不要为回报补造旧卡没有支持的动机、惩罚或后果。

当反转的资源性质、因果链或代价没有窗口证据时，结论应写 `INSUFFICIENT`。

### Evidence / Anti-Evidence

Evidence: `w04`、`w05`、`w08`、`w09`、`w13`、`w14`、`w15`；旧卡 `sentence_realization`、`exposition`、`action` 与 `payoff_realization` observations。

Anti-Evidence / Boundary:

- 旧卡的 `action_combat` 字段为 `UNKNOWN`，因此这里只能描述所选动作窗口中的因果呈现，不能概括全部战斗写法。
- 不能据此推出固定的能力系统、世界规则或反转结构。
- 旧卡没有提供所有 payoff 类型的统计，不能断言每次回报都必须具备同样数量的确认步骤。

## Reaction DNA

### Core Selection Strategy

人物状态优先通过动作、对白、停顿、视线、物件处置和身体变化泄露。关系或情绪可以同时包含礼貌与不满、轻松与危险、照护与恐惧，不急于收束成单一标签。

### Scene-Conditioned Behavior

- **ORDINARY / 关系生活**：用门声、银钱、床铺、食物、工作等物件和短对白显示共同生活的压力。
- **DIALOGUE / 关系谈判**：让礼仪、恭敬、安全感、不喜、反问或轻微顶嘴改变关系压力。
- **EMOTION / 身份恐惧**：从梦境、黑夜和日常语气切入，再用冷、痛、病发或奔跑把情绪身体化。
- **EXPOSITION_DIALOGUE**：让停顿、答非所问和轻微互损同时承载关系声线与规则风险。
- **STRATEGIC_DIALOGUE**：用逐句转述、停顿和视线把私人态度转成公共场面压力。
- **ENDING**：以低强度生活动作或关系互动把宏大状态收回人物尺度。

### Compression / Omission Boundary

不以单个情绪词代替反应过程，也不把同一反应用心理说明重复一遍。可以保留跑题、嘴硬、生活计较或不合时宜的玩笑，但必须让目标、威胁、关系压力或选择仍然可追踪。

### Evidence / Anti-Evidence

Evidence: `w03`、`w06`、`w10`、`w11`、`w13`、`w15`；旧卡 `dialogue`、`emotion`、`human_irregularity` observations。

Anti-Evidence / Boundary:

- `character_voice` 与 `interior_thought` 为 `UNKNOWN`，不能提炼固定口头禅、固定心理句式或稳定内心独白模式。
- 不能把某一种身体反应或生活动作变成所有人物的通用反应。
- 旧卡支持“反应显形”的窗口观察，不足以支持完整人物心理系统。

## Rhythm DNA

### Core Selection Strategy

节奏不是固定长短句比例，而是随 scene beat 和状态变化重新分配：

- 空间、规则和战局建立时允许展开；
- 危险逼近、动作确认和突然反应时压缩；
- 重大状态变化前后留出独立的一拍；
- 回报、伤亡、代价和终局收束允许恢复较长的静段；
- 对白、视觉镜头、旁观反应和解释之间快速轮换。

### Scene-Conditioned Behavior

- **ACTION_SETUP**：让路线、站位和威胁逐步累积。
- **ACTION / REVERSAL**：以短促的动作结果、指令或反应切开连续动作，并保持空间方向。
- **PAYOFF**：先密集确认结果，再放慢进入伤亡、仇恨或代价。
- **STRATEGIC_DIALOGUE**：用逐句重复、停顿和视线累积公共压力。
- **ENDING**：先处理高强度规则或灾害，再用生活动作延长收束。
- **转折前后**：可以保留空白、重复或停顿，使状态变化本身获得带宽。

### Compression / Omission Boundary

不以固定段落长度或持续短句制造危险感。稳定状态可以压缩；关键转折、结果确认和代价显现不应被同一段落中的说明吞掉。节奏判断应服从当前 beat，而不是服从预设模板。

### Evidence / Anti-Evidence

Evidence: `w04`、`w05`、`w09`、`w13`、`w14`、`w15`；旧卡 `sentence_realization`、`paragraph_rhythm` 与 `sentence_rhythm` observations。

Anti-Evidence / Boundary:

- 旧卡明确指出 `sentence_rhythm` 只来自 bounded windows，未作全文统计。
- `punctuation` 为 `UNKNOWN`，不能推出标点偏好。
- 不能把“危险时变短、终局时变长”写成每一场戏都必须执行的硬规则。

## Lexical DNA

### Core Selection Strategy

句子更值得落在能够承载状态变化的具体名词、动词、材质、尺度、资源和身体变化上；抽象判断通常在这些细节已经提供证据之后出现。

旧卡观察到的语体可以在同一场景中按功能混合：

- 机构和制度术语；
- 军营、家庭和生活口语；
- 诗性自然词；
- 轻微荒诞或不合时宜的表达。

这种变化服务于场景层级、人物态度和节奏，不构成固定词表。

### Scene-Conditioned Behavior

- **OPENING / 空间**：温度、声音、光线、尺度、微小生命和边界。
- **ORDINARY / 生计**：现金、租金、吃饭、床铺、门声、工作选项。
- **ACTION / PAYOFF**：场景中的资源、操作性物件与制度线索，以及它们造成的移动、阻挡、命中、消耗或确认。
- **EXPOSITION**：制度凭证、可见痕迹与身份线索和问答中的操作性术语。
- **EMOTION**：冷、痛、呼吸、奔跑、身体变化等身体名词和动作。
- **DIALOGUE / ENDING**：私人话语、视线、低强度生活动作或关系互动，使语体从公共尺度回到人物尺度。

### Compression / Omission Boundary

选择少量高辨识度的声音、温度、材质、食物或物件，不让每个句子都保持同等感官强度。抽象名词不能替代具体动作；具体比喻和专名必须由新文本自身的世界生成。

本维度不输出高频词表、禁词表或模仿句式。

### Evidence / Anti-Evidence

Evidence: `w01`、`w02`、`w03`、`w04`、`w05`、`w07`、`w08`、`w09`、`w10`、`w12`、`w13`、`w15`；旧卡 `lexical_texture`、`diction / lexical texture` 与 `sensory_density` observations。

Anti-Evidence / Boundary:

- 没有全文词频、句法或标点统计，不能把语体混合写成固定比例。
- `description` 与 `concrete_vs_abstract` 相关字段不足以支持完整词汇系统。
- 不能迁移原作人物、事件、专名、签名比喻或原句结构。

## Detail Selection Across Dimensions

| 维度 | 值得进入文本的细节 | 删除后会失去什么 | 主要 Evidence |
|---|---|---|---|
| Attention | 一个可测的空间、感官或资源锚点，以及它引起的身体/行动反应 | 失去尺度、危险、身份压力或场面重心 | `w01`、`w03`、`w10`、`w12` |
| Knowledge | 与当前身份、物件、风险或任务直接相连的局部规则 | 失去读者理解当前行动边界所需的知识 | `w04`、`w08`、`w11` |
| Causal | 位置、资源、动作、连续结果，以及结果带来的代价或新选择 | 失去空间可追踪性、回报可信度或反转因果 | `w05`、`w09`、`w14` |
| Reaction | 物件处置、停顿、视线、对白反应或身体症状 | 失去关系变化、内在压力和人物状态的可见泄露 | `w03`、`w06`、`w10`、`w13` |
| Rhythm | 状态变化前后的独立一拍、短确认或 aftermath 静段 | 失去 beat 的重音、转折的可感知性和代价回声 | `w05`、`w09`、`w15` |
| Lexical | 与场景功能匹配的具体名词、动词、材质、尺度和身体词 | 失去身体感、因果触感、世界尺度和语体层级 | `w01`、`w04`、`w07`、`w15` |

Detail Selection 的目标不是增加细节总量，而是选择能够同时承担身份、因果、关系、身体感、尺度或 payoff 的细节。

## Production Implications

- 当 Curator 判定场景正在建立新空间或新威胁时，可编译为“一个可感知锚点 + 一个立即可见的反应”。
- 当场景承担规则说明时，可优先选择与物件、身份或风险绑定的局部知识，并为其连接一个当前行动出口。
- 当场景承担动作或回报时，可优先编译“位置/资源 → 可见结果 → 代价或新行动空间”的信息顺序。
- 当场景承担关系或情绪变化时，可优先选择一个物件处置、身体反应、停顿或对白回避，让状态自行显形。
- 当场景进入关键 beat 时，可为状态变化单独分配一拍，并让段落长度随危险、确认和 aftermath 改变。
- 当场景需要语体辨识度时，可从当前世界和场景功能选择少量具体名词、动词与判断方式，不调用固定词表或模仿模板。

## Limits / Insufficient Evidence

- 本卡是单书、15 个 bounded scene-function windows 的观察，不是全文统计。
- `sentence_rhythm`、`concrete_vs_abstract`、`character_voice`、`interior_thought`、`action_combat`、`description`、`transitions`、`punctuation` 等旧卡字段存在 `UNKNOWN` 或证据不足。
- 本 v2 只保留窗口中能够支持的 scene-conditioned selection，不推出全书固定比例、固定句式、固定反应方式或固定节奏模板。
- 普通章节是否完成、未选 segment 的规则与关系功能，保持 `INSUFFICIENT`。
- 不迁移原作人物、事件、专名、世界规则、原句或作者身份。
