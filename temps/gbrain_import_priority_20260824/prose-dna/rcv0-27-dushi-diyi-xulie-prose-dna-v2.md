## Cross-Scene Invariants

1. **带宽优先给当前会改变判断或选择的东西。** 场景通常先呈现危险、任务、异常物件或正在发生的动作；背景解释延后到人物必须判断时。证据见 `rcv0-27-prose-w01`、`w04`、`w05`、`w06`、`w11`。

2. **状态变化通过连续的可见推进承载。** 行动场景沿观察→判断→触发→身体执行→反馈→撤离推进；谈判和关系场景则通过信息、权力或关系位置的变化推进。证据见 `w04`、`w05`、`w09`、`w12`。

3. **抽象判断通常附着在具体物件、身体、价格、环境或制度操作之后。** 先出现制度入口、资源物件、价格或治理操作等具体载体，再给价值或机制判断。证据见 `w06`、`w07`、`w08`、`w13`。

4. **结果之后仍保留现实余波，或留下新的可执行选择。** 回报落到实际效用、现金、身份、能力、胜利或退让后，还会回到生活条件、私人生活、可用物资、疲劳或更大尺度余波或下一步目标。证据见 `w02`、`w08`、`w12`、`w14`。

## Attention DNA

### Core Selection Strategy

文本带宽主要投向四类细节：

- 会改变人物即时判断的少量环境信号。
- 会改变行动空间的任务、物件、价格、奖励和能力反馈。
- 会改变关系或社会位置的对白、退让、命令、交易、礼物与生活条件变化。
- 会把大尺度变化压缩成可操作模型的数字、规模指标、行动路径、群体力量与角色称谓。

因此，细节的价值不在于装饰性密度，而在于它是否让读者看到压力、选择、关系位置或结果发生了变化。

### Scene-Conditioned Behavior

- **OPENING / ACTION / ATMOSPHERE：**优先选择少量会改变判断的感官信号，并迅速接入等待、触发、身体执行、受伤或撤离。
- **DIALOGUE / ORDINARY：**给资源处置、防备动作、错位回答、命令、讨价还价和退让足够带宽，使关系与位置在互动中显露。
- **EXPOSITION / PAYOFF：**从交易、行走、可操作物件、功能性物件或其他物件开始，说明只跟随当前行动需要。
- **EMOTION / AFTERMATH：**优先等待、误会、物件处置、身体反应、生活条件等行为与生活结果，情绪判断后置。
- **LATE / ENDING：**治理场景可用数字、规模指标、迁徙和角色称谓压缩规模；收束时把技术或公共结果降回人群和生活尺度。

### Compression / Omission Boundary

可以压缩或暂时省略：

- 当前判断尚未需要的背景；
- 不改变行动判断的环境感官信息；
- 没有改变关系、权力或目标的对白往返；
- 尚未被行为、物件或选择支撑的情绪宣言；
- 已经由一个动作节点收束后的群体发散。

不应压缩：

- 关键动作的物理约束与结果反馈；
- 让奖励成为下一步选择的具体物件或状态；
- 让关系变化落地的行为、礼物、距离或身体反应；
- 让宏大治理变化可被理解的数字、规模指标或角色操作。

### Evidence / Anti-Evidence

**Evidence：**`w01`、`w02`、`w05`、`w06`、`w07`、`w08`、`w09`、`w11`、`w12`、`w13`、`w14`。

**Anti-Evidence：**旧卡没有支持“所有场景都以高压动作开场”、固定感官密度或固定章节收束方式。普通章节覆盖不足，未选窗口不能被假定具有相同带宽分配。

## Knowledge DNA

### Core Selection Strategy

知识释放遵循“当前人物能感知并必须处理什么”的范围。高压行动贴近身体、武器、地形与时间；普通场景允许带判断的旁观视角；关系节点回到人物内心近景。规则通常先作为人物遇到的限制、价格、物件或交易条件出现，再给出必要解释。

### Scene-Conditioned Behavior

- **ACTION：**知识围绕可执行的身体限制、武器、地形、距离和时间组织。
- **EXPOSITION：**通过进入制度空间、交易、比较价格等行动释放货币、阶层和制度信息。
- **PAYOFF：**先呈现可操作的物件、货币或交易对象，再让角色估算价值。
- **DIALOGUE：**信息与身份、关系、威胁、酬劳和条件同时释放。
- **LATE：**用规模指标、迁徙、制度操作、群体行动和角色称谓让治理变化保持可操作性。

### Compression / Omission Boundary

在人物尚未需要判断时，背景和机制可以留白。说明的停止点是：当前行动已经获得足够知识，能够解释人物为什么做出下一步。不能从旧卡推出全书统一的 narrator 知识边界、全知程度或信息隐藏时长。

### Evidence / Anti-Evidence

**Evidence：**`w04`、`w05`、`w06`、`w07`、`w11`、`w13`。

**Anti-Evidence：**旧卡明确说明叙述距离未检查所有章节，普通章节保持 PENDING；不能据此建立稳定的全书 POV 规则。精确的“解释几句后必须停止”证据不足，标记为 **INSUFFICIENT**。

## Causal DNA

### Core Selection Strategy

因果通常解释到“可观察限制→人物判断或触发→身体/物件执行→可见反馈”的粒度。能力或价值不靠抽象判断单独成立，而在冲突、功能性物件、交易、可操作装置或治理操作中显示结果。

### Scene-Conditioned Behavior

- **ACTION：**保留观察、等待、触发、身体执行、受伤、反馈和撤离中的关键节点。
- **ACTION_REVEAL：**让能力或身份在动作冲突中被读者看到，而不是先用概念说明。
- **EXPOSITION：**将货币、商品、制度入口和阶层规则绑定到行走、买卖和比较。
- **PAYOFF / AFTERMATH：**先展示回报如何生效，再展示其对生活条件、家庭、可用物资、疲劳或身份的影响。
- **LATE / ENDING：**用规模指标、行动路径、群体力量、技术退化和人群反应把宏大因果压缩成连续结果。

### Compression / Omission Boundary

可以省略不影响当前决定的远因、抽象机制和泛化说明；不能省略导致选择成立的限制、触发和反馈。长因果链只在当前决策需要时展开。对于隐藏机制、人物动机或未被窗口覆盖的远期因果，证据不足，标记为 **INSUFFICIENT**。

### Evidence / Anti-Evidence

**Evidence：**`w02`、`w05`、`w06`、`w07`、`w08`、`w09`、`w13`、`w14`。

**Anti-Evidence：**旧卡没有证明所有能力、奖励或事件都遵循同一种因果展开长度，也没有支持把单个世界机制迁移为通用规则。

## Reaction DNA

### Core Selection Strategy

人物状态主要通过动作、对白和物件处置泄露，而不是先用宣言说明：

- 防备、等待、购物、进食、赠礼、拥抱等行为显示关系和压力；
- 错位回答、反向回答、命令、讨价还价和退让显示身份与权力；
- 夸张反应、认真执行荒谬逻辑和食物争执承担压力缓冲；
- 发烧、伤口、撤离、沉默和疲劳把风险转成身体余波。

### Scene-Conditioned Behavior

- **ORDINARY / DIALOGUE：**通过资源细节、防备动作、错位回答和条件谈判显示关系位置。
- **HUMOR：**允许阶层、职业、字面或资源错位产生笑点，但笑点同时暴露压力。
- **EMOTION：**先排列购物、等待、误会、礼物、距离和身体接触，再以选择或承诺确认情绪。
- **ACTION：**以受伤、压制、撤离和偷袭等反馈显示人物状态变化。
- **AFTERMATH：**用发烧、生活条件、礼物、可用物资或文明代价显示风险并未在动作结束处消失。

### Compression / Omission Boundary

应压缩没有改变关系、权力、选择或身体状态的内心解释；应保留能使状态变化可见的动作、停顿、物件处置和对白转向。幽默可以缓冲压力，但不能抹平死亡、伤害或其他结果。

### Evidence / Anti-Evidence

**Evidence：**`w03`、`w04`、`w08`、`w09`、`w10`、`w12`。

**Anti-Evidence：**旧卡没有支持固定的情绪命名顺序、固定的幽默频率或所有人物都使用相同的反应机制。人物内心的完整范围为 **INSUFFICIENT**。

## Rhythm DNA

### Core Selection Strategy

节奏随 scene beat 和状态变化调整，而不是固定句长或段落比例：

- 动作、惊讶和反转处压缩反应间隔；
- 解释处允许较完整的因果链；
- 群体场面可以先发散，再由一个动作节点收束；
- 峰值之后用具体余波放慢并落地；
- 终局从战场推进转入技术、人群和生活尺度。

### Scene-Conditioned Behavior

- **ACTION：**使用连续动词和必要的短句群，选择能推进观察、选择、动作或反馈的句群。
- **EXPOSITION：**允许较长句段承载当前行动所需的因果关系。
- **DIALOGUE：**在错位回答、笑点、威胁和条件转折处改变推进速度，笑点后回到当前目标。
- **GROUP CONFLICT：**先容纳群体争执，再以食物、武力或偷袭等单一动作节点收束。
- **PAYOFF / ENDING：**峰值后补实际效用、生活条件、技术、群体与私人反应等具体余波。

### Compression / Omission Boundary

选择能推进观察、选择、动作或反馈的句群；普通段落可围绕当前主要状态变化组织。可以删去不改变 beat 的重复反应和环境回声，但不能用短句数量制造空洞紧迫感，也不能把长句当成固定文风。

### Evidence / Anti-Evidence

**Evidence：**`w01`、`w05`、`w09`、`w10`、`w11`、`w14`。

**Anti-Evidence：**旧卡未做词频、句长、标点或全书段落统计；固定句长比例、固定段落长度和固定标点模式均为 **INSUFFICIENT**。

## Lexical DNA

### Core Selection Strategy

句子更常落在与当前功能直接相关的具体名词、动作和判断上：

- 生存物件、价格、身体、武器、地形和制度称谓承载现实压力；
- 口语化反应承载人物位置与压力缓冲；
- 抽象价值通常在物件、交易或关系动作之后出现；
- 晚期治理用数字、规模指标、行动路径、群体力量和角色称谓压缩规模。

这不是高频词表，也不是禁词表或模仿句式。

### Scene-Conditioned Behavior

- **ACTION / ATMOSPHERE：**优先身体、武器、地形、时间、温度、光线、声音和移动动词。
- **EXPOSITION / PAYOFF：**优先价格、商品、货币、可操作物件、交易和制度称谓。
- **ORDINARY / DIALOGUE / HUMOR：**优先口语反应、错位回答、命令、讨价还价和退让。
- **EMOTION / AFTERMATH：**优先物件处置、生活条件、距离、等待、身体反应和生活状态。
- **LATE / ENDING：**优先规模指标、迁徙、群体力量、技术、群体与私人反应等可落地名词或动作。

### Compression / Omission Boundary

可以省略不能改变判断的抽象评价和同义重复；不能省略让读者看见物质压力、身体反馈、社会位置或规模变化的具体承载物。旧卡未做词频统计，因此不存在可报告的稳定高频词、词性比例或全书 lexical profile，相关结论为 **INSUFFICIENT**。

### Evidence / Anti-Evidence

**Evidence：**`w03`、`w06`、`w07`、`w08`、`w10`、`w13`、`w14`。

**Anti-Evidence：**旧卡仅有窗口观察，没有词频、句长或标点统计；不能把“具体名词占主导”进一步改写成词表、禁词表或固定句法规则。

## Detail Selection Across Dimensions

| Dimension | 值得进入文本的细节 | 删除后会失去什么 |
|---|---|---|
| Attention | 会改变判断的危险信号、任务、异常物件、奖励、身份或下一步选择 | 当前压力、问题方向或行动带宽 |
| Knowledge | 与当前 POV 可感知范围相符的身体、武器、地形、价格、交易和限制 | 读者对人物为何知道、为何判断的定位 |
| Causal | 限制、触发、身体执行、物件反馈和结果余波 | 行动的可理解性与因果闭合 |
| Reaction | 防备、等待、食物处置、礼物、沉默、错位回答、命令、退让和拥抱 | 关系、权力、压力和情绪的可见泄露 |
| Rhythm | 能标记观察、选择、动作、峰值、反馈和余波的动作或反应 | beat 的阶段感与状态变化速度 |
| Lexical | 生存名词、价格、身体动作、制度称谓、规模指标数字和口语反应 | 物质感、社会位置、尺度或人物压力 |
| Cross-dimensional payoff | 具体回报及其生活条件、家庭、可用物资、疲劳、身份或文明余波 | 奖励的实际价值、代价和后续行动空间 |

## Production Implications

以下仅供 Curator 编译为场景条件选择，不是 Writer hard gates：

- 当场景功能是 **OPENING / ACTION / ATMOSPHERE** 时，优先选择少量会改变判断的感官锚点，并把它们接入当前任务、触发、受伤或撤离。
- 当场景功能是 **EXPOSITION / PAYOFF** 时，优先寻找一个交易、可操作物件、功能性物件、价格或其他具体物件作为知识入口，只编译当前决策所需的解释。
- 当场景功能是 **DIALOGUE / ORDINARY / HUMOR** 时，优先选择能够改变信息、权力或关系位置的对白轮次，并把口语或笑点编译为压力调节，而非脱离目标的装饰。
- 当场景功能是 **ACTION / ACTION_REVEAL** 时，优先编译观察、判断、触发、身体执行和反馈中的关键节点，使能力或身份通过冲突结果显露。
- 当场景功能是 **EMOTION / AFTERMATH** 时，优先编译礼物、等待、距离、身体反应、生活条件或可用物资等行为与生活结果，再决定是否需要短的情绪命名。
- 当场景功能是 **LATE / ENDING** 时，优先用规模指标、数字、行动路径、角色操作或技术状态压缩规模，并在峰值后选择一个人群或生活尺度的具体余波。

## Limits / Insufficient Evidence

- 本卡为单书、单一来源、14 个有界 scene-function windows 的观察，不是全文风格统计。
- `segment-0002` 同时承担 OPENING 与 ENDING/HOOK 窗口，但 locator 范围不同；不能将其视为两个独立来源。
- 未做词频、句长、标点或全书段落统计；Lexical DNA 与 Rhythm DNA 只能停留在窗口观察层面。
- 普通章节覆盖不足，未选场景的带宽分配、叙述距离和幽默机制保持 **INSUFFICIENT**。
- 不能据此推出固定句长比例、固定段落长度、禁词表、人物口癖、模仿句式或作者永久文风。
- 精确的解释停止阈值、全书统一 POV 知识边界、所有能力的因果展开长度，均为 **INSUFFICIENT**。
- 本 Selection DNA 只描述“什么条件下什么类型的细节值得被选择”，不替代 Chapter Mission、Canon、当前书籍 Prose Profile 或作者明确意图。
