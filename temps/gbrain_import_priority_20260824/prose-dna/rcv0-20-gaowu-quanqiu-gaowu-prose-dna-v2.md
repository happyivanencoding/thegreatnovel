## Cross-Scene Invariants

1. 当场景发生可追踪的状态、选择或尺度变化时，文本优先给出日期、数量、协议、体力、动作、结果或世界状态等具体锚点，再补充价值判断或抽象解释。  
   证据：W01、W02、W03、W04、W08。

2. 解释通常嵌入闲聊、追问、反应、试探、拒绝或方案争论；解释的停止点是读者已经能跟随当前判断或下一步变化，而不是把机制全部讲完。  
   证据：W02、W04、W07。  
   终局的世界状态说明是特殊窗口，不能外推为常规章节模式。

3. 人物状态多通过心算、自我辩解、互损、追问、拒绝和短句承诺泄露；重大行动后的情绪常被关系互动或生活噪声重新落地。  
   证据：W01、W05、W06、W08。

4. 句段节奏随 scene beat 改变：规则与价值说明放慢，战斗随动作反馈推进，日常与余波切回短促互动，终局在代价和世界状态处放慢后再完成关系与未来安排。  
   证据：W02、W03、W05、W06、W08。

## Attention DNA

### Core Selection Strategy

带宽主要给“会改变读者判断、人物选择、行动结果、关系温度或世界状态”的细节。具体细节不是为了增加画面数量，而是为了让当前状态变化可见、可追踪、可回收。

### Scene-Conditioned Behavior

- `OPENING`：给校园日期、当前处境、内心盘算和同学插话足够带宽；异常设定通过误听、自嘲和反应显出。
- `EXPOSITION`：把注意力放在信息差、名词如何影响当前理解，以及对白如何继续推动，而不是独立铺开百科式说明。
- `ACTION`：优先保留目标、人群、积分、体力、出手和结果，使主角的算计能够改变节奏。
- `DIALOGUE`：先让协议、数字或资源价值落地，再把带宽给角色反应、追问和关系变化。
- `ORDINARY / AFTERMATH`：压缩宏大事件本身的重复回响，把带宽转给互损、自我辩解、闲谈和关系推进。
- `LATE / ENDING`：后段难题关注试探、拒绝、新方案与未决空间；终局关注代价、世界状态、关系承诺和未来生活。

### Compression / Omission Boundary

可压缩：

- 没有新目标、新状态、新结果或新选择的重复动作。
- 不改变当前关系的泛化情绪说明。
- 普通场景中不承担身份、因果或身体感的感官细节。
- 已经通过动作或对白明确呈现、再重复一次也不增加判断的信息。

不宜压缩：

- 能确认异常、资源价值、行动结果或代价的具体锚点。
- 使读者理解主角算计、人物关系或世界状态变化的反应。
- 终局中连接代价、关系回报与未来安排的必要节点。

### Evidence / Anti-Evidence

证据：W01、W02、W03、W04、W05、W06、W07、W08；旧卡的 `concrete_vs_abstract`、`action_combat`、`payoff_realization`、`description`、`transitions` observations。

Anti-Evidence / INSUFFICIENT：

- 没有证据支持固定的描写密度、每段细节数量或所有场景都采用同一带宽分配。
- 中期战斗与日常变体覆盖不足。
- W08 是高密度终局窗口，不能作为常规章节注意力规则。

## Knowledge DNA

### Core Selection Strategy

知识选择围绕“当前人物如何理解并处理眼前问题”展开。规则、机制和价值优先以信息差、数量、协议、行动反馈或角色争论进入文本；不要求在当前场景一次性完成全局解释。

### Scene-Conditioned Behavior

- `OPENING`：先让读者跟随校园处境、日期和重生确认，再通过误听与自嘲感知异常；知识缺口本身成为开场反应的一部分。
- `EXPOSITION`：让世界规则通过同学闲聊、信息误差和吐槽逐层显形。
- `ACTION`：知识集中在当前可操作的信息：目标、人群、积分、体力、出手和结果。
- `DIALOGUE`：资源和价值先通过协议、数字或口头问题呈现，再由追问和反应补足含义。
- `LATE`：抽象机制通过试探、拒绝、再讨论和新方案显形；结尾可以保留未决空间。
- `ENDING`：先交代代价与世界状态，再转向关系承诺和未来安排；不把开放余地抹平成全知说明。

### Compression / Omission Boundary

可省略不影响当前判断、选择或行动反馈的背景信息。若一个机制已经通过当前对白、行动结果或方案变化变得可用，就不必再次用抽象段落完整复述。

应保留：

- 当前人物必须知道才能行动的数量、协议、状态或结果。
- 信息误差、追问、拒绝和争论所造成的理解变化。
- 后段和终局中尚未解决、但已经被场景明确保留的问题。

### Evidence / Anti-Evidence

证据：W01、W02、W03、W04、W07、W08；旧卡的 `narrative_distance`、`concrete_vs_abstract`、`dialogue`、`chapter_ending` observations。

Anti-Evidence / INSUFFICIENT：

- 旧卡没有足够证据细分 narrator/POV 的稳定知识边界。
- 没有足够证据判断人物私下知识、群体知识和读者知识之间的全部差异。
- 没有证据支持所有场景都必须保留同等程度的信息缺口。

## Causal DNA

### Core Selection Strategy

因果选择落在“具体锚点如何改变判断或行动”上：日期、数量、协议、动作、体力、结果和世界状态先构成可见链条；抽象机制在角色追问、争论、试探和新方案中补足到当前场景可用的粒度。

### Scene-Conditioned Behavior

- `EXPOSITION / DIALOGUE`：先给协议、数字或信息误差，再由角色反应、追问和口头判断说明其价值。
- `ACTION`：保持目标、人群、状态反馈、出手结果之间的连续关系；力量差异通过击倒、结果或环境变化确认。
- `LATE`：用试探→拒绝→再讨论→新方案展示因果链；机制的理解来自方案如何改变，而不是来自单独定义。
- `AFTERMATH`：先确认公开行动的结果与后续状态，再用自我辩解和旁人调侃处理社会与关系余波。
- `ENDING`：先处理代价和世界状态，再安排关系承诺与未来生活，使 payoff 不只停在胜负结论。

### Compression / Omission Boundary

可压缩：

- 已经由动作结果直接证明、但不会改变人物判断的重复解释。
- 战斗中没有带来新状态或新结果的重复动作。
- 只提供抽象评价、却没有连接到协议、数量、行动或结果的空泛因果说明。

应保留：

- 让读者能追踪目标、状态和后果的最小链条。
- 使方案变化、关系变化或世界状态变化成立的关键反应。
- 终局中代价与未来安排之间的顺序关系。

### Evidence / Anti-Evidence

证据：W02、W03、W04、W07、W08；旧卡的 `concrete_vs_abstract`、`action_combat`、`payoff_realization`、`transitions` observations。

Anti-Evidence / INSUFFICIENT：

- 没有证据支持固定的解释长度、因果步骤数量或所有场景都必须完成闭环。
- 没有证据支持把终局因果安排直接迁移为中段普通场景规则。
- 对不可见机制、幕后原因和人物长期动机的因果写法证据不足。

## Reaction DNA

### Core Selection Strategy

人物状态通过能改变互动的反应进入文本：心算、自我辩解、追问、拒绝、互损、调侃、动作反馈和关系承诺，比抽象情绪命名更有选择价值。

### Scene-Conditioned Behavior

- `OPENING`：用内心盘算、误听和自嘲泄露异常状态与轻松现实感。
- `DIALOGUE`：让角色的追问、停顿感、反驳或喜剧反应承担资源与价值信息的落地。
- `ORDINARY`：通过互损和闲谈推进人物关系；动作结果被轻松语气吸收。
- `AFTERMATH`：以自我辩解和旁人调侃处理公开行动后的状态，避免情绪持续停留在抽象抒情中。
- `LATE`：用试探、拒绝和再讨论显示立场变化，并使新方案从反应中出现。
- `ENDING`：用关系承诺和连续玩笑承接代价与世界状态，让重大结果回到人物关系和生活层面。

### Compression / Omission Boundary

可压缩：

- 已由对白、动作或关系互动显示出来的重复情绪判断。
- 不改变关系温度的泛化赞叹、震惊或悲喜说明。
- 事件结束后没有新社会反应、身体后果或行动选择的情绪滞留。

应保留：

- 会改变选择或关系温度的追问、拒绝、自我辩解和承诺。
- 能让身体状态或行动代价可见的动作反馈。
- 承接宏大结果与日常关系的具体反应。

### Evidence / Anti-Evidence

证据：W01、W04、W05、W06、W07、W08；旧卡的 `character_voice`、`interior_thought`、`dialogue`、`human_irregularity` observations。

Anti-Evidence / INSUFFICIENT：

- 旧卡没有足够证据建立稳定的物件处置、停顿类型或私密身体反应系统。
- 没有证据支持某一种固定口癖、固定反应格式或统一情绪表达。
- 配角在不同关系、知识和利益条件下的反应分布仍然不足。

## Rhythm DNA

### Core Selection Strategy

句子与段落节奏跟随 scene beat、动作反馈和状态变化切换，不以固定的短句比例、句长模板或标点格式作为规则。

### Scene-Conditioned Behavior

- `OPENING / DIALOGUE`：内心盘算、插话、吐槽和追问形成短快交替。
- `EXPOSITION`：规则与价值解释允许使用中长句，但仍嵌入对白推动。
- `ACTION`：动作、数字或状态反馈连续出现，节奏随结果加速；重复动作可压缩。
- `ORDINARY / AFTERMATH`：回到短句、互损和闲谈；严肃结果与轻松语气之间可以突然换挡。
- `LATE`：试探、拒绝、讨论和新方案形成连续但有转折的段落推进。
- `ENDING`：代价与世界状态处适度放慢，再通过关系承诺、未来安排和玩笑完成释放。
- 场景切换可由日期、地点、协议、争论、战斗结果或世界状态承担明确铰链。

### Compression / Omission Boundary

不应把所有段落平均写成快节奏，也不应把所有解释平均拉成长段。

可压缩：

- 没有新反馈的重复动作。
- 没有新关系或新信息的普通过渡。
- 已被下一拍结果取代的节奏性重复。

应保留：

- 从一个 beat 切到另一个 beat 的结果、反应或选择。
- 使严肃与轻松发生换挡的关键停顿或对白。
- 终局从状态说明转入关系与未来安排的节奏转折。

### Evidence / Anti-Evidence

证据：W01、W02、W03、W05、W06、W07、W08；旧卡的 `sentence_rhythm`、`paragraph_rhythm`、`punctuation`、`transitions` observations。

Anti-Evidence / INSUFFICIENT：

- 没有证据支持固定句长、固定段落长度、固定标点比例或固定笑点间隔。
- 没有证据证明所有战斗、所有日常段落都采用同一节奏。
- 旧卡只支持功能性换挡，不支持表面句式模仿。

## Lexical DNA

### Core Selection Strategy

词汇选择首先服务当前 scene function：把句子落在日期、数量、协议、体力、军务、目标、动作和结果等具体名词或动词上，再用对白、吐槽、判断或争论把它们拉到价值和关系层。

语域可以并置：

- 网络口语；
- 武道或宇宙尺度词；
- 数量化、系统化表达；
- 生活化语言。

这不是高频词表，也不是禁词表。

### Scene-Conditioned Behavior

- `OPENING`：校园、日期、当前处境、内心算计和生活化误听共同建立入口。
- `EXPOSITION`：世界规则名词进入对白、吐槽和信息误差，而不是脱离互动单列。
- `ACTION`：词汇集中在目标、人群、积分、体力、出手和结果，使战斗状态可见。
- `DIALOGUE`：协议、数字、资源价值和追问承担判断功能。
- `ORDINARY / AFTERMATH`：军务、休息、生活细节、互损和自我辩解把高压结果拉回日常语域。
- `LATE / ENDING`：抽象机制、代价、世界状态、关系承诺和未来安排通过争论、判断与生活化玩笑共同落地。

### Compression / Omission Boundary

可省略：

- 不改变当前功能的专名链。
- 只用于制造作者身份感、但不承担身份、因果、关系、身体感、尺度或 payoff 的签名比喻。
- 已经由具体名词、动作和结果表达清楚的重复抽象形容。

应保留：

- 能使场景身份、行动因果、身体状态或尺度变化可辨认的具体名词与动词。
- 能让庄重概念回到人物关系和生活语境的判断方式。
- 能区分协议、战斗、闲谈、余波和终局安排的功能性语域差异。

### Evidence / Anti-Evidence

证据：W01、W02、W03、W04、W05、W06、W07、W08；旧卡的 `lexical_texture`、`concrete_vs_abstract`、`description`、`human_irregularity` observations。

Anti-Evidence / INSUFFICIENT：

- 没有证据支持具体高频词、词频排名、固定口癖或固定名词—动词比例。
- 没有证据支持把该书的专名、人物、事件或原句迁移为通用写作规则。
- 不同人物的词汇差异只能保留为场景、利益、知识和亲密度相关的观察，不能细化为稳定模板。

## Production Implications

- 当 Chapter Mission 要求读者理解一个新的状态或选择时，Curator 可优先选择一个具体锚点，再配一个局部判断或反应。
- 当场景属于规则说明、资源交换或方案讨论时，Curator 可把信息编译为“协议/数字/现象 → 角色反应或追问 → 当前选择”的场景化组合。
- 当场景属于行动或战斗时，Curator 可优先保留目标、状态反馈和结果链，并把没有新 beat 的重复动作标为可压缩区域。
- 当场景属于 ordinary 或 aftermath 时，Curator 可选择一处互损、自我辩解或闲谈，让关系温度承接事件结果，而不是继续堆叠抽象情绪。
- 当场景进入高尺度结果或 ending 时，Curator 可按“代价/世界状态 → 关系承诺 → 未来生活”的顺序选择 payoff 细节，并保留适度的生活化落点。
- Curator 可根据 beat 在短促互动、中长解释、连续行动和放慢收束之间选择节奏模式；不把句长、标点或语域混搭编译成 Writer hard gate。

## Limits / Insufficient Evidence

- 证据范围只有 8 个 scene-function windows，属于单书、阶段性纵向快照。
- 未覆盖中期所有战斗、日常和过渡变体，细粒度差异保持未知。
- W08 含高密度世界状态说明，不能作为常规章节样式直接推广。
- 来源卡记录了解码替换字符与未识别章节标题问题；本轮不重新读取原著，也不修复原始证据。
- narrator/POV 的精确知识边界、人物私密知识、物件处置、细粒度身体反应和长期人物词汇分布均为 `INSUFFICIENT`。
- 本卡不输出禁词表、模仿句式、固定句长模板、人物专属规则或 Writer hard gates。
