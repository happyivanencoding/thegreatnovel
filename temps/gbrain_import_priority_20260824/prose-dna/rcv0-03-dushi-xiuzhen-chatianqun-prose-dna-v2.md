## Attention DNA

### Core Selection Strategy

文本带宽优先给“正在改变读者判断或人物关系”的细节：

- 开篇与日常场景先给校园、身体状态、天气、书店、屏幕等可信对象，再给异常信息。
- 动作场景提高雷光、危险结果和身体反应的可见度，同时保留人物的现实误认或迟疑。
- 对话和说明场景把带宽分给发言、回应、误解、补充和求证，使信息变化同时成为关系变化。
- 情绪、余波和结尾场景减少宏大背景的前景占比，把带宽转给等待、归来、旁观、私人话题和生活方向判断。

Detail Selection：细节之所以值得进入文本，是因为它能固定当前场景的现实尺度，显示认知或关系正在变化，或让回报落到可感知的反应上；删掉后，读者可能只剩抽象设定、抽象情绪或抽象身份。

### Scene-Conditioned Behavior

- `OPENING / ORDINARY`：具体日常对象承担可信度与认知基线。
- `DIALOGUE / EXPOSITION`：发言或旁白转换优先承载信息、误解、判断或关系的实际变化。
- `ACTION`：优先呈现动作结果和即时反应，再逐步解释异常性质。
- `EMOTION / AFTERMATH`：让关系状态通过等待、归来、旁观或私人话题停留。
- `PAYOFF / LATE / ENDING`：把前置信息转译为身份确认、他人反应或生活方向，而不是只宣布“已经回收”。

### Compression / Omission Boundary

可以压缩：

- 已建立、当前不改变行动的普通背景。
- 不影响当前判断的宏大世界背景。
- 已经由动作、对白或反应明确表达的抽象总结。

不宜压缩：

- 异常首次进入日常认知的具体落点。
- 危险结果与人物即时反应之间的连接。
- 回报发生时的关系确认、身份确认或旁观反应。

### Evidence / Anti-Evidence

支持：`ev-001`、`ev-004`、`ev-006`、`ev-007`、`ev-009`、`ev-010`。

Anti-Evidence：现有窗口不足以证明全书在所有战斗、群像或复杂世界说明中都遵循同样的带宽分配；不能把“日常锚点优先”扩展为所有场景必须先写日常。

## Knowledge DNA

### Core Selection Strategy

知识进入文本时，通常先经过当前人物的现实认知、自我解释或错误判断，再由消息、疑问、专业评价、实际效果或旁观反应逐步修正。知识不是一次性铺开，而是在读者的问题被触发后显形。

Detail Selection：细节值得进入，是因为它能显示当前人物“知道什么、误解什么、正在验证什么”；删掉这些细节，信息会变成脱离 POV 和行动的设定陈述。

### Scene-Conditioned Behavior

- `OPENING / ORDINARY`：先守住普通人的现实解释，让异常从具体生活场景的边缘进入。
- `DIALOGUE`：通过多人不同知识范围、回应速度和补充方式分配信息。
- `EXPOSITION`：把规则拆成消息、疑问、现实求证和专业评价。
- `ACTION`：先给可见结果与身体反应，原因解释随后到达。
- `PAYOFF / LATE`：先让身份或关系以姿态、吐槽或反应出现，再由鉴定、判断或旁人反应确认。

### Compression / Omission Boundary

可暂时留白：

- 尚未影响当前行动的完整规则体系。
- 仍处于现实误认中的异常原因。
- 已由现场反应承担的重复解释。

应明确到足够支撑当前读者判断的程度：

- 某个异常是否真实发生。
- 某个身份或关系是否被确认。
- 某个消息、行动或结果为什么改变了当前局面。

### Evidence / Anti-Evidence

支持：`ev-002`、`ev-003`、`ev-004`、`ev-005`、`ev-007`、`ev-009`。

Anti-Evidence：旧卡没有提供足够证据，归纳出一套覆盖全书的 narrator/POV 信息权限规则，也不足以确认所有未知信息都采用同一种延迟揭示方式。关于系统性的知识留白边界，部分为 `INSUFFICIENT`。

## Causal DNA

### Core Selection Strategy

因果解释通常跟随可见结果推进，粒度以读者能判断“发生了什么、人物如何理解、关系或行动因此如何变化”为止：

1. 具体对象或动作受到异常影响。
2. 人物先做现实解释、否认、惊疑或自我修正。
3. 消息、疑问、专业评价或现实求证补足原因。
4. 身份、能力或关系通过鉴定、姿态和旁人反应得到确认。

Detail Selection：因果细节值得进入，是因为它连接动作、判断和后果；删掉后，危险会像特效，回报会像公告，人物判断也失去转折依据。

### Scene-Conditioned Behavior

- `ACTION`：先呈现雷光、危险结果、动作和迟疑，再允许原因解释进入。
- `EXPOSITION`：只解释到当前疑问和现实验证需要的粒度。
- `PAYOFF`：让前置关系、玩笑或小线索先产生姿态或反应，再由确认动作完成回收。
- `EMOTION / ENDING`：当核心因果已经转化为关系或生活方向时，允许用一句判断收束，而不继续展开宏观机制。
- `LATE`：宏大身份或世界背景可以被压缩进一个日常反应，但前提是该反应确实承载判断变化。

### Compression / Omission Boundary

可以停止解释：

- 读者已经看见动作结果，人物也已经作出足够清晰的判断。
- 设定解释不再改变当前选择、关系或情绪落点。
- 回报已经通过鉴定、旁人反应或实际效果成立。

不应跳过：

- 异常结果与人物误认之间的关键转折。
- 说明信息如何被现实求证或他人评价支撑。
- 回报为何改变身份判断或关系理解。

### Evidence / Anti-Evidence

支持：`ev-004`、`ev-005`、`ev-007`、`ev-009`、`ev-010`。

Anti-Evidence：动作窗口有限，不能据此建立所有战斗或复杂机制场景的通用解释粒度。关于深层世界规则、长期因果链和多阶段战斗机制，`INSUFFICIENT`。

## Reaction DNA

### Core Selection Strategy

人物状态优先通过外显反应泄露：迟疑、否认、自问、自嘲、快速回应、跑题、补充、等待、归来、旁观、私人话题，以及他人对身份或结果的反应。内心表达需要与现实动作、消息或新证据同步。

Detail Selection：反应细节值得进入，是因为它把抽象情绪和身份变化变成身体、对白和关系中的可见证据；删掉后，人物会只剩“震惊”“感动”“确认”等结论。

### Scene-Conditioned Behavior

- `ORDINARY / ACTION`：保留现实常识带来的误认、惊疑、否认和迟疑。
- `DIALOGUE`：用回应速度、知识范围、身份姿态和补充方式区分人物状态。
- `EMOTION`：用等待、旁观和亲密关系中的轻巧评价承载情绪。
- `AFTERMATH`：让人物缓慢归来、猜测或谈论私人话题，使事件余波继续存在。
- `PAYOFF`：先让回报落在吐槽、姿态或旁人反应上，再给出明确确认。

### Compression / Omission Boundary

可以压缩：

- 已经被动作、对白和他人反应充分显示的情绪标签。
- 不改变关系或判断的重复内心说明。
- 仅为解释人物“应该有什么感觉”而添加的抽象总结。

不宜压缩：

- 误认被证据纠正的那一拍。
- 回报改变关系或身份时的第一反应。
- 情绪场景中承担亲密度的等待、旁观或私人话题。

### Evidence / Anti-Evidence

支持：`ev-003`、`ev-004`、`ev-006`、`ev-007`、`ev-008`、`ev-010`。

Anti-Evidence：旧卡没有足够证据支持“物件处置”作为稳定的状态泄露机制；关于沉默时长、细微面部动作和持续身体反应，`INSUFFICIENT`。

## Rhythm DNA

### Core Selection Strategy

节拍不是固定的长短句配方，而是跟随 scene beat 重新分配：

- 消息、多人回应和误解：快速往返，短段交替。
- 解释、背景和视角补充：允许段落拉长。
- 危险与认知翻转：缩短反应链，提高可见动作和即时结果的密度。
- 情绪、余波与结尾：放慢，让等待、归来、关系判断或生活方向留下回声。

Detail Selection：节奏细节值得进入，是因为它决定读者何时感到推进、停顿、冲击或余味；删掉后，不同状态变化会被写成同一种速度。

### Scene-Conditioned Behavior

- `DIALOGUE`：消息、现实动作和旁白反应分层交替。
- `EXPOSITION`：可用较长旁白或多轮对话容纳背景，但应让关键轮次带来疑问、补充、求证或判断变化。
- `ACTION`：缩短动作—反应之间的距离，避免先解释后行动。
- `AFTERMATH / EMOTION`：允许动作和私人话题之间留出安静段落。
- `ENDING`：根据结尾是新消息、认知翻转、突发危险还是生活确认，选择相应的速度。

### Compression / Omission Boundary

可以压缩：

- 没有新信息、反应、关系变化或选择变化的连续动作。
- 已经完成功能的重复回应。
- 不改变节拍的格式性转场。

不应压缩：

- 一个 beat 从误认转为确认的过渡。
- 危险结果后的即时反应。
- 余波或结尾中承担情绪落点的安静停留。

### Evidence / Anti-Evidence

支持：`ev-003`、`ev-004`、`ev-005`、`ev-006`、`ev-008`、`ev-010`；旧卡的 `sentence_rhythm`、`paragraph_rhythm`、`punctuation` 与 `human_irregularity` observations。

Anti-Evidence：旧卡明确说明 normalized 行边界不等同于阅读界面排版，因此不能从行长直接推导固定段落格式。标点中的部分格式痕迹也可能来自站点习惯。

## Lexical DNA

### Core Selection Strategy

词汇选择随功能变化，而不是形成固定词表：

- 日常与开篇：具体生活名词、天气、空间、食物、屏幕等，建立现实尺度。
- 动作与危险：可见动作、结果和身体反应相关的动词与感官词。
- 对话与群体互动：当代口语、即时判断、误解、补充和回应。
- 说明与求证：现实常识、专业评价、疑问和仙侠设定术语并置。
- 回报与结尾：身份判断、关系判断和生活方向相关的明确判断。

Detail Selection：词汇细节值得进入，是因为它能同时标记场景尺度、人物认知位置和动作结果；删掉后，文本容易只剩抽象术语、抽象情绪或没有媒介感的说明。

### Scene-Conditioned Behavior

- 当场景从日常进入异常，优先使用熟悉对象和现实判断承接异常。
- 当场景以动作推进，优先落在可见结果和身体反应，而非先给机制名词。
- 当场景依靠多人互动推进，允许不同发言者以知识范围、姿态和回应速度形成差异。
- 当场景需要解释设定，术语应与疑问、求证或实际效果一起出现。
- 当场景进入情绪或余波，词汇可回到私人话题、亲密评价和具体生活判断。

### Compression / Omission Boundary

可以压缩：

- 不参与当前判断的术语堆叠。
- 不能改变人物行动或关系的网络化表达。
- 已由具体动作和反应承担的抽象形容。

不宜压缩：

- 日常尺度的具体名词。
- 异常产生可见结果时的动作词。
- 身份、关系或生活方向发生改变时的判断词。

### Evidence / Anti-Evidence

支持：`ev-001`、`ev-002`、`ev-003`、`ev-004`、`ev-005`、`ev-006`、`ev-009`、`ev-010`；旧卡的 `concrete_vs_abstract`、`description`、`dialogue`、`lexical_texture` observations。

Anti-Evidence：现有证据只支持功能性的词汇层次和媒介反差，不支持高频词统计、固定句法模板或全书词汇分布结论。

## Detail Selection Across Dimensions

| 细节类型 | 进入文本的理由 | 删除后的损失 |
|---|---|---|
| 日常对象、天气、空间、食物、屏幕 | 固定现实尺度，让异常有落点 | 失去身份感、可信度与尺度对比 |
| 可见动作、危险结果、身体反应 | 让因果先被读者看见 | 失去动作清晰度与身体感 |
| 消息、回应、误解、补充、求证 | 让知识变化同时推动关系变化 | 失去信息显形的过程与对话节拍 |
| 迟疑、否认、自问、自嘲、等待、旁观 | 让人物状态通过行动和对白泄露 | 失去人物反应与关系温度 |
| 鉴定、姿态、旁人确认、实际效果 | 把前置线索转成可见回报 | 失去 payoff 的确认感 |
| 段落长度、回应间隔、安静停留 | 让节奏跟随 beat 和状态变化 | 失去冲击、推进或余味 |
| 现代生活语感与设定术语的功能性并置 | 标记认知错位与场景功能 | 失去媒介感、幽默反差或解释清晰度 |

## Production Implications

- 当场景承担“日常认知被异常打断”时，Curator 可选择“具体生活锚点 → 可见异常 → 人物现实反应”的带宽顺序；若场景已处于持续异常状态，则不强行补写日常入口。
- 当场景的主要阅读问题是规则、身份或结果确认时，Curator 可选择由“消息/疑问/求证/反应”承载说明，而不是单独调用背景说明。
- 当场景 beat 转入危险或直接后果时，Curator 可提高动作结果与即时反应的优先级；当后果已成立，转而选择关系或生活层面的余波。
- 当场景依靠多人互动推进时，Curator 可按信息任务、认知差异和关系反应编排回应顺序，并优先让关键回应带来可观察的判断或关系变化。
- 当场景进入情绪、余波或结尾时，Curator 可优先选择等待、归来、私人话题、旁观反应或生活判断作为落点，让宏大背景退到不抢夺情绪的位置。
- Curator 可按场景功能选择词汇层次：日常用具体对象，动作用结果性动词，说明用必要术语与求证，回报用身份或关系判断；不把任何层次固化为 Writer 的硬门禁。

## Limits / Insufficient Evidence

- 这是单书、单卡、10 个有界窗口的观察，不能代表所有阶段、所有战斗、所有群像或所有叙事视角。
- `INSUFFICIENT`：没有足够证据建立全书统一的 narrator/POV 知识权限模型。
- `INSUFFICIENT`：没有足够证据证明物件处置、面部细节、沉默时长或持续身体反应是稳定核心机制。
- `INSUFFICIENT`：没有足够证据推导复杂战斗、长期因果链或完整世界规则的解释粒度。
- 聊天消息、窗口格式、章节小标题属于旧卡观察到的部分转场装置，不应迁移为所有作品或所有场景的必要形式。
- 本卡只迁移场景条件化的选择机制，不迁移人物、专名、事件、原句、口癖、签名比喻或固定模仿句式。
