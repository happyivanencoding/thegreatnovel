## Attention DNA

### Core Selection Strategy

优先给改变以下至少一项的细节带宽：

- 人物对当前局面的判断；
- 可执行的行动空间；
- 威胁、限制或代价；
- 人物之间的距离、信任与筹码；
- 回报之后仍需承担的维护压力；
- 宏大变化在身体或日常生活中的落点。

细节的价值不在于丰富现场，而在于让状态变化变得可见、可感或可继续行动。

### Scene-Conditioned Behavior

- OPENING：优先选择身体异常、异常物件、光线和碎片记忆，先建立可感知的问题。
- ORDINARY：选择煤气、金钱、食物、家庭动作等能承载生活压力和关系结构的细节。
- RITUAL / ACTION：选择重复操作、材料、声音、距离、站位和不可逆变化，逐步压向临界点。
- DIALOGUE：选择称号、待遇、条件、威慑、停顿和回应，使信息交换同时改变关系或资源。
- PAYOFF / EMOTION：选择能力是否可用、资源是否变化、能否接近某物、日常动作是否恢复等细节。
- LATE / ENDING：选择身体、认知、信仰、家庭仪式和极小互动，使抽象变化落到可见生活。

### Compression / Omission Boundary

可压缩：

- 尚未影响当前选择的背景；
- 暂时不可验证、不可操作的完整机制；
- 不改变人物判断的重复环境描写；
- 已由动作充分呈现的情绪解释。

不应压缩：

- 当前威胁、空间限制、行动结果；
- 关系或交易中的关键条件；
- 回报带来的新能力、资源或后续压力；
- 终局或余波中决定“生活如何继续”的小动作。

### Evidence / Anti-Evidence

证据：`rcv0-29-prose-w01`、`w02`、`w04`、`w07`、`w08`、`w10`、`w11`、`w12`、`w14`、`w15`。

Anti-Evidence：全书感官密度、细节密度和不同章节的带宽分布为 `INSUFFICIENT`；不能把上述窗口外的场景一概视为同样处理。

## Knowledge DNA

### Core Selection Strategy

先给当前 narrator / POV 能观察、验证或使用的局部知识，再补足能够改变下一步行动的规则。暂时不影响行动的信息保持留白；知识段的终点是“读者能理解当前限制和下一步”，不是“解释完整世界”。

### Scene-Conditioned Behavior

- OPENING：身体、物件和碎片记忆先于完整背景解释。
- DIALOGUE：通过问答、称号、交换和信息不对称逐步建立可操作的世界入口。
- EXPOSITION：把规则嵌入练习、身体反应、负担、限制和退出操作。
- IDENTITY_ENTRY：先给能使新身份运作的局部条件、媒介或资源，再补身份说明。
- LATE：宏大历史或高位概念通过身体裂解、精神污染、祈祷等可见状态承载。

### Compression / Omission Boundary

解释可以暂缓于：

- 当前尚未需要的历史来源；
- 不会改变本轮选择的规则分支；
- narrator 目前无法确认的知识；
- 仅用于制造百科完整感的信息。

但不能省略当前行动所需的条件、风险、限制和结果。不得用模型记忆补齐旧卡未提供的知识。

### Evidence / Anti-Evidence

证据：`rcv0-29-prose-w01`、`w05`、`w06`、`w07`、`w12`、`w13`、`w14`。

Anti-Evidence：全书 narrator 知识边界、叙事可靠性、所有 exposition 类型和未选章节的信息释放方式为 `INSUFFICIENT`；不能据此建立固定 POV 模板。

## Causal DNA

### Core Selection Strategy

因果解释停在足以让读者理解“限制为何存在、动作为何发生、结果如何产生、代价为何出现”的粒度。优先呈现：

`具体条件 → 身体/空间/操作变化 → 判断或选择 → 可见结果 → 新压力`

更深的起源、完整机制或历史解释，只有在改变当前行动时才进入。

### Scene-Conditioned Behavior

- RITUAL / EXPOSITION：把规则绑定到材料、练习、负担、观察或关闭操作。
- ACTION：先明确空间、威胁、限制、队形和结果，再加入幽默或非典型反应。
- DIALOGUE：把待遇、危险、条件和身份反差放进交换过程，而不是事后统一解释。
- PAYOFF：让能力可用性、旁观反应、资源变化或行动空间扩大可被确认，并引出维护压力。
- LATE：用身体与认知变化承载抽象代价，使宏大因果仍可落回现场。

### Compression / Omission Boundary

可以停止于当前行动已经可理解的位置，不必同时解释：

- 完整世界机制；
- 所有潜在因果分支；
- 当前不影响选择的历史背景；
- 角色尚未掌握的因果判断。

不能压缩：

- 威胁与限制；
- 动作和结果之间的关键连接；
- 回报与后续压力之间的连接；
- 对白中决定立场或资源变化的条件。

### Evidence / Anti-Evidence

证据：`rcv0-29-prose-w04`、`w07`、`w08`、`w09`、`w10`、`w13`、`w14`。

Anti-Evidence：全书机制解释的完整粒度、不同战斗类型的因果组织和普通章节的统一模式为 `INSUFFICIENT`。

## Reaction DNA

### Core Selection Strategy

人物状态优先通过身体动作、物件处置、距离、停顿、误读、对白回应和选择顺序泄露。情绪命名可以存在，但不应替代已经能够显示状态变化的行为。

### Scene-Conditioned Behavior

- ORDINARY：用经济盘算、家务动作、物件使用和对话显示关系，而非静态介绍亲属关系。
- ACTION：用重复动作、互相监视、站位、手势和距离显示压力与协作。
- DIALOGUE：让待遇、澄清、威慑、回避或反常语气改变理解、信任或筹码。
- EMOTION：用远望、不能接近、现金盘算、迁移计划和小型日常动作承载失去。
- LATE / ENDING：用身体变化、祈祷、家庭仪式、阳光和轻微互动承载高位变化后的关系余波。

### Compression / Omission Boundary

可以压缩：

- 没有改变身体、关系或选择的泛化情绪说明；
- 已被动作清楚表达的重复心理判断；
- 不产生新信息的反应性对白。

不能压缩：

- 能显示人物立场变化的停顿或回应；
- 体现压力、距离或代价的物件处置；
- 关系试探中的关键误解与澄清；
- 让情绪进入下一次选择的行为后果。

### Evidence / Anti-Evidence

证据：`rcv0-29-prose-w03`、`w05`、`w06`、`w08`、`w09`、`w11`、`w13`、`w14`、`w15`。

Anti-Evidence：旧卡明确不能据此声称全书没有直接情绪词；直接情绪命名的分布、所有人物的反应模式为 `INSUFFICIENT`。

## Rhythm DNA

### Core Selection Strategy

句子和段落的长短、停顿与切换服务于 beat 和状态变化：

- 长句群承载物件、规则、关系和因果链；
- 短句或独立落点承载确认、惊吓、方向改变、动作结果和情绪落点；
- 高危行动压缩时间和段落；
- 失去、余波与终局允许更长停留，并保留转折后的空拍。

### Scene-Conditioned Behavior

- OPENING / RITUAL：用连续的物件、感官和操作逐层推进压力。
- DIALOGUE：在问答、停顿、即时判断和空间变化之间快速换挡。
- ACTION：以短促的结果落点和清楚的空间转换保持行动可追踪。
- PAYOFF / EMOTION：放慢到资源整理、距离感和生活余波。
- ENDING：减少新信息密度，把节拍交给关系、仪式和继续生活的动作。

### Compression / Omission Boundary

不要设固定句长比例、短句配额或段落模板。应在以下位置切换节拍：

- 一个镜头完成；
- 一个反应发生；
- 一次状态变化落地；
- 一个转折需要留出理解空间。

### Evidence / Anti-Evidence

证据：旧卡 `sentence_rhythm` 与 `paragraph_rhythm` observation；`rcv0-29-prose-w01`、`w08`、`w09`、`w11`、`w15`。

Anti-Evidence：这是质性窗口观察，不是全文统计；固定句法比例、全书节拍曲线和统一段落长度为 `INSUFFICIENT`。

## Lexical DNA

### Core Selection Strategy

词语选择随场景任务、人物位置和压力变化。句子更值得落在能承载状态的具体名词与动词上：身体、物件、空间、操作、文件、资源、距离、站位、交换和结果；抽象判断应与这些载体连接，而不是维持恒定的神秘或宏大强度。

### Scene-Conditioned Behavior

- ORDINARY：生活词与制度词通过使用、计费、家庭安排进入文本。
- EXPOSITION：材料、练习、负担、限制和退出动作承担规则。
- DIALOGUE：职业、交易、待遇、纲领、危险和身份词随筹码变化切换。
- ACTION：空间方向、手势、距离、限制和结果动词优先保持动作清晰。
- EMOTION / ENDING：远望、触碰、阳光、信件、仪式和小动作让抽象情绪落地。
- LATE：身体、认知和精神状态承载高位概念；宏大词语不脱离可见变化。

### Compression / Omission Boundary

可以压缩：

- 不服务当前任务或人物位置的抽象修饰；
- 为维持单一“神秘感”而重复的高强度词汇；
- 不改变空间、关系或判断的同义替换。

不能压缩：

- 能标示制度条件、交易筹码或行动限制的词；
- 能让读者确认身体、空间和结果的具体名词与动词；
- 能显示语体切换和人物位置变化的表达。

### Evidence / Anti-Evidence

证据：`rcv0-29-prose-w02`、`w03`、`w07`、`w09`、`w12`、`w13`、`w14`、`w15`。

Anti-Evidence：旧卡未进行词频、句法或长期词汇分布统计；不存在可迁移的高频词表，词汇不变量为 `INSUFFICIENT`。

## Detail Selection Across Dimensions

| 维度 | 值得进入文本的细节 | 删除后会失去什么 |
|---|---|---|
| Attention | 异常、风险、行动能力变化、资源变化、余波动作 | 身份感、压力尺度、下一步选择 |
| Knowledge | 当前可观察的条件、局部规则、操作结果、信息差 | 当前理解、行动可执行性、未知感 |
| Causal | 触发、限制、动作、结果、代价 | 因果链、威胁可信度、payoff 的实际意义 |
| Reaction | 动作、停顿、物件处置、距离、回应、误解与澄清 | 人物状态、关系变化、身体感 |
| Rhythm | beat 转折、结果落点、停顿、转折后的空拍 | 状态变化的时间感、压力和余味 |
| Lexical | 具体身体/物件/空间/操作名词与结果动词，以及随任务变化的语体 | 场景身份、尺度、抽象信息的可感落点 |

## Production Implications

- Curator 可先标出本场唯一或主要的状态变化，再选择少量能显示“变化前—变化后”的现场锚点。
- 对知识释放，优先编译当前行动所需的条件与结果；暂不改变选择的信息保留为 `UNKNOWN` 或延后。
- 对因果解释，编译到读者能理解限制、动作、结果和代价即可，避免把未被当前场景调用的完整机制提前展开。
- 根据人物状态选择泄露通道：动作、对白、停顿、物件、距离或资源安排；不要求所有情绪都转为直接命名。
- 根据 scene beat 编译句群与段落的收放：行动强调压缩和结果，余波与终局保留停留，不使用固定句长比例。
- 根据场景任务与人物位置选择词汇注册，并优先让抽象判断落在具体身体、物件、空间或操作上。

## Limits / Insufficient Evidence

- 本卡仍是单书、15 个有界窗口的质性观察，不代表全文分布。
- 未进行全文词频、句法比例、感官密度或节奏曲线统计。
- 未选章节的 atmosphere、dialogue、action、emotion、chapter-ending 形态为 `INSUFFICIENT`。
- 所有战斗类型、全书 narrator 知识边界和叙事可靠性为 `INSUFFICIENT`。
- 不能据此建立固定 POV、固定句长、禁词表、模仿句式或作者身份规则。
