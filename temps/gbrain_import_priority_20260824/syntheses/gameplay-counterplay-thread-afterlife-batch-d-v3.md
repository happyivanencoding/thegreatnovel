# Shared Story Program Principles

1. **首个高光只是可靠性证明，不是长期玩法本身。**  
   长篇期待应逐渐转向“这次选谁、何时用、暴露多少、怎样组合、保留什么、舍弃什么”。

2. **对手升级首先应改变胜负条件。**  
   可攻击的不是抽象等级，而是使用窗口、距离、信息来源、恢复条件、对象可达性、公众身份、关系网络或主角不在场的位置。

3. **阶段换挡要换当前问题。**  
   新阶段不只是更强敌人，而应改变主角正在追求什么、与谁发生关系、胜利怎样兑现，以及结果会改写哪一层世界事实。

4. **旧状态续燃，新发动机才不会 reset。**  
   新阶段不必保留全部旧资产，但应让仍然重要的欲望、关系、敌人、能力边界、身份后果或未解问题继续影响选择。

5. **提醒必须是行动性的。**  
   长线回流应让人物改变选择、让旧因获得新解释，或让敌人重新站位；仅点名旧人、回忆往事或展示收藏品不构成有效回流。

6. **大型碰撞的价值在异质线互相改写。**  
   力量、关系、身份、配角自主目标与世界事实可以在同一事件中发生因果碰撞，但不需要机械追求固定线数。

7. **兑现后要留下新的行动位置。**  
   突破、身份公开、复活、登位或结婚之后，人物仍应能够选择、拒绝、工作、探索、建立关系或面对新的世界问题。

8. **故事增长以不可回滚状态衡量。**  
   技能、等级、宝物、舰队、称号或资源只有在改变人物选择、敌人策略、关系、身份、世界入口或历史事实后，才进入 Story Program。

# Important Differences / Anti-Universalization

- **《不科学御兽》**偏向多对象差异、组合创造、纯享受窗口与伙伴自主事业；不能抽成“每次成长必须牺牲”。
- **《沧元图》**以救援距离、战争姿态、寿命、家庭和历史修复承载成长；后期贸易与城市只证明新入口，不能自动转成运营文。
- **《超神机械师》**依赖版本历史、玩家自主、组织社会化与信息反制；穿越、面板和两个世界的根本来源仍有 `UNKNOWN`。
- **《大奉打更人》**把办案能力转成公共信用、身份与合法性博弈；不宜把所有能力都翻译成战斗技能树。
- **《大王饶命》**以社会反应、喜剧留痕和家庭关系驱动核心玩法；Sol 明确没有稳定可预测的负面情绪产出公式。
- **《全球高武》**确有数字、资源和系统，但数字必须被翻译成报名、战果、组织、战争与世界选择；不能把财富—学分—军功拼成运营系统。
- **《乱世书》**的选择经常落在关系、机缘归属、身份和因果；配角有拒绝主角、失去力量或选择自己道路的权利。
- **《莽荒纪》**允许私人愿望长期驱动宇宙级升级，合道失败确实更换发动机；但“失败＋寿命倒计时”不是通用升级节拍。
- **《明克街13号》**特别擅长以改称呼、让座、授牌、披袍和服从行为证明地位；这不代表所有作品都需要职位晋升。
- **《牧神记》**包含变法、文明自主、历史回流和宇宙冷寂；配角继续行动不等于所有故事都要进入治理或接班结构。
- 旧地图可以有意义地毁灭。需要保留的是连续性接口，而不是所有地点、人物与资产的物理存续。
- 责任、治理、负面成本、公开认可与终局复活都只是可能变体，不是统一的成长意义。

# Candidate Mechanisms

## Candidate 1

- **Name**：首个高光后的选择空间化
- **Stage**：第一次能力证明之后；后续每次稳定优势或阶段突破。
- **Shared Creative Problem**：能力已经证明有效，但相邻高潮仍重复同一对手、同一能力与同一翻转。
- **Mechanism**：把下一轮乐趣转成对象、路线、时机、公开程度、保留/舍弃、组合、战场或社会用途的选择。新能力不必立即更强，但应让人物能够作出此前不存在的决定。
- **Evidence Books**：10本均支持。
- **Evidence Anchors**：
  - 《不科学御兽》`bukexue.md:275-286`；L139-L150、L1029-L1077、L18045-L18064。
  - 《沧元图》`cangyuantu.md:306-315`；L1718-L1733、L25274-L25320、L32457-L32470。
  - 《全球高武》`gaowu.md:198-212`；L19092-L19110、L270279-L270575。
  - 《乱世书》`luanshishu.md:226-249`；L8291-L8303、L1695-L1870。
  - 《明克街13号》`mingkejie.md:278-302`；L80735-L80755、L62810-L62838。
  - 《牧神记》`mushenji.md:306-318`；L30713-L30718、L56242-L56249、L70780-L70794。
- **Guidance**：一次场景优先突出一个主要选择轴，必要时搭配一个互补轴；让选择通过行动和结果可见，不展示抽象菜单。
- **Failure Modes**：
  - 选择只存在于旁白；
  - 所有选项实际导向同一结果；
  - 把“舍弃”误作每次成长的必需代价；
  - 新能力只换名称或数值；
  - 同一组合反复解决同类敌人。
- **Relationship to Existing Cards**：**MERGE**。扩充 `mech-action-space-expansion` 的适用阶段与选择轴；交叉调用 `mech-old-ability-new-use`、`mech-power-verification-visible` 和 `mech-rule-boundary-visible-cost`，不新增独立卡。

  - 把开放结局或 `UNKNOWN` 补成完整战后秩序。
- **Relationship to Existing Cards**：**NEW**。现有 `mech-mystery-reveal-action`、`mech-map-transition-without-reset`、`mech-status-recognition` 与 `mech-pure-upside-payoff` 各覆盖局部，但没有完整覆盖休眠、提醒、Thread Collision、Second Payoff 与 Promotion Afterlife。晋升余生不另立第六张卡。

- **Stage**：Outline / First-Five-Chapter Gameplay。

# Story Program Transfer

Story Program 可采用下面的阶段描述面，而不是只写地图、境界和终极敌人：

| 规划面 | 要回答的创作问题 |
|---|---|
| **核心不变量** | 读者长期等待主角反复作出哪一种决定？它可以是选择伙伴、救援对象、身份、知识路线、关系归属或世界入口。 |
| **当前发动机** | 当前阶段真正推动场景的事情是什么：生存、查案、比赛、战争、探索、潜入、关系选择、组织冲突还是世界存续？ |
| **Choice Space** | 主角现在可以选择谁、什么、何时、暴露多少、保留什么、舍弃什么、怎样组合？ |
| **已公开成功条件** | 哪些能力边界、使用习惯、关系或资源依赖已经被敌人看见？ |
| **Opponent Adaptation** | 敌人会改变哪个条件，而不是只增加等级？ |
| **续燃旧线** | 哪个旧欲望、关系、身份、物件、敌人或世界问题在新阶段获得新功能？ |
| **不可回滚结果** | 这一阶段结束后，谁能做什么、敌我怎样站位、关系或世界事实发生了什么永久变化？ |
| **Afterlife** | 突破、奖励、登位、复活或组织升格之后，人物获得了什么新的生活与行动位置？ |

可迁移的抽象链为：

`具体欲望或可失去对象 → 首次可见证明 → 选择空间扩大 → 敌人改写成功条件 → 发动机换问法 → 旧线碰撞 → 不可回滚兑现 → 新行动位置`

这是一组可选择的因果关系，不要求每个阶段完整走完全部环节。

# Outline / First-Five-Chapter Transfer

## 快速证明型

适用于核心幻想需要尽早显效的开篇：

1. 用一个具体问题、对象或生活压力建立能力为何值得期待。
2. 让能力通过动作和可见结果完成第一次证明。
3. 紧接着给出第一次真实选择：对象、路线、时机、公开、保留或组合。
4. 让环境或知情对手改变一个成立条件，迫使不同用法。
5. 以关系、身份、敌人判断或下一入口的变化结束首轮，而不是再次等待同类考核。

## 欲望先行型

《全球高武》的 Sol 证明，前五章也可以先完成：

- 力量欲望为何具体；
- 进入道路需要什么真实成本；
- 家人或关系如何参与决定；
- 主角作出什么不可轻易撤回的承诺。

能力试验、测量和公开证明可在随后章节展开。前五章没有完整展示系统，不自动构成缺陷。

## 避免相邻高潮换皮

- 第一次高光若是正面能力证明，下一次可改成对象、身份、关系、资源或时机选择。
- 第一次高光若是身份揭露，下一次应让身份改变合作、权限或敌策。
- 第一次高光若是获得奖励，下一次应展示奖励的新用途或 Afterlife，而不是立刻领取更大奖励。
- 第一次高光若依赖秘密，第二次不必马上让敌人识破；可以先让环境暴露边界，再逐步形成真正的敌方学习。

# Anti-Systemization Boundary

- “选择”是人物在具体处境中的判断，不是必须显示完整选项的菜单。
- “对手适应”是观察、推断和行动，不是敌方读取系统说明书。
- “发动机换挡”改变的是故事问题，不是任务名称、地图名或 KPI。
- “长线”不等于高频出场；低频角色只要每次回流都改变当前博弈，同样可以拥有时间重量。
- “Thread Braid”不是伏笔台账，也不要求所有线程同章汇合。
- “Promotion Afterlife”不等于立即追加惩罚、责任、治理或新考核。
- “换地图不 reset”不要求所有旧资产继续存在；地点、组织乃至安全家园都可以有意义地结束。
- 技能、等级、宝物、舰队、办公室、城市、称号和资源本身不构成 Story State。
- 只有当获得改变人物下一次选择、敌人下一种策略、关系/身份位置、世界入口或不可回滚事实时，才进入 Story Program。
- 来源中的宠兽、系统、神教、变法、玩家、历史复活与宇宙结构都不能直接迁入 TGN Canon。
- Sol 的摘要与 locator 是本轮唯一来源边界；没有证据的完整战后社会、最终机制或人物去向继续保持 `UNKNOWN`。

# What Not To Turn Into Hard Gates

- 不规定每次能力证明后都必须立即出现敌方反制。
- 不规定每个敌人都必须理解主角完整机制。
- 不规定每次升级都必须改变对象、路线、时机、关系和地图全部维度。
- 不规定每次突破都必须付出负面成本。
- 不规定每次身份跃迁都必须扩大公共责任。
- 不规定每次奖励都要在同一回合被新压力抵消。
- 不规定每个阶段都必须换地图。
- 不规定新地图必须保留固定数量的旧资产。
- 不规定每个碰撞点必须精确结算三条线。
- 不规定每条长线必须拥有两次兑现或在终局闭合。
- 不规定每个配角都必须回归、战斗、接班或加入主角阵营。
- 不规定 Promotion Afterlife 必须进入治理、组织管理或战争责任。
- 不规定前五章必须完成能力命名、公开证明、身份揭露和敌人学习。
- 不把选择轴、长线提醒、碰撞数量或 Afterlife 做成评分表、必填字段或新的 Hard Gate。
