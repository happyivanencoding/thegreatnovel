# Shared Selection Principles

1. 带宽给正在改变状态的节点，而不是给所有细节平均篇幅。优先级是：当前选择与阻力、动作与结果、关系或社会估值、身体代价、尺度变化；稳定背景和无新功能的过桥信息压缩。六书均有支持。

2. 抽象判断先由具体承载物进入文本，再由人物或社会反馈命名。承载物可以是物件、价格、数量、身体、空间、资源、制度动作、称呼或旁观者行为。删掉承载物，强弱、价值和身份就会退化成旁白结论。

3. Knowledge 与 Causal 的停止点都是“读者能复原当前选择为何成立”：看见证据，形成局部判断，完成动作或交换，读到结果及其下一约束。未知只有在仍影响风险、路线、关系或选择时才保留；不影响当前行动的未知不必为了神秘感继续悬置。

4. 人物状态不是“人味配额”，而是通过不同的压力处理方式泄露。相同压力可以被不同人物转化为计算、纠正、嘴硬、玩笑、质问、回避、礼貌、命令、讨价还价、物件处置或继续执行。声音的区别来自选择通道及其后果，不来自统一的短句或冷静语气。

# Character Voice Differentiation Findings

人物声音要区分，关键不是给每个人分配口头禅，而是保留四个差异：

- 他首先注意什么：价格、危险、关系距离、制度资格、身体异常、面子或任务。
- 他误解或拒绝什么：误听、自嘲、答非所问、纠正、回避、拒绝承诺。
- 他用什么方式争取主动：计算、试探、命令、互损、礼貌、交易、转述、沉默或继续行动。
- 他的回应怎样改变下一拍：改变筹码、关系距离、风险判断、公共评价或行动路线。

本轮 6 书共同支持“压力路由不同”，但不支持固定人物声线模板。尤其：

- 《修真聊天群》与《全球高武》突出误听、自嘲、互损、闲聊和自我辩解，但不应泛化成所有人物都必须幽默。
- 《第一序列》突出错位回答、资源争执、阶层错位与反向坚持；它提供的是“反应逻辑”，不是固定口语。
- 《道诡异仙》突出临床平静、纠正、回避、命令冲突和压制情绪；不能迁移成普遍冷峻。
- 《将夜》突出礼仪、恭敬、不喜、轻微顶嘴，以及私人话语进入公共场面的转述压力。
- 《诡秘之主》突出职业、经济、待遇、称号和风险条件对语体的改变。

对 TGN 正文，最有增量价值的不是“让角色更有个性”，而是让 Curator 在已有 Canon、当前关系和 Chapter Mission 中指出：同一压力下，人物各自会保护什么、回避什么、拿什么交换、怎样错误判断。没有输入证据时不要替角色补造稳定性格。

# Strength / Status Readability Findings

强弱、价值和身份需要分开承载。

- 强弱：通过位置、接触、受力、击退、受伤、资源消耗、行动范围和环境结果读出。
- 价值：通过数量、价格、积分、协议、货币、药效、库存、资源交换和他人重新报价读出。
- 身份：通过称呼、资格、证件、礼仪、待遇、权限、站位、公共目光和关系承诺读出。

最有效的组合是：

`具体结果 → 他人改变对待方式 → 人物获得或失去下一行动`

社会反馈不等于“众人震惊”。更可靠的反馈包括：

- 报价、待遇、条件或风险重新定价；
- 称呼、礼仪、站位、距离或权限改变；
- 对手改变策略，旁观者改变判断；
- 资源、住房、证件、合作或行动范围发生变化；
- 重大结果被拉回家庭、工作、疲劳、照护或继续执行任务。

《全球高武》的数字与行动反馈、《第一序列》的价格和生活余波、《将夜》的公共目光与制度位置、《诡秘之主》的运行条件与资源安排，提供了不同类型的状态证明。它们共同支持“社会反馈必须具体”，但不能迁移具体数字体系、制度名词或来源作品的奖励方式。

# Knowledge + Causal Stop Findings

Knowledge 边界应保持四层分离：

1. 当前 POV 能观察到什么；
2. 人物据此如何判断，且判断可能错误；
3. 当前行动必须知道什么；
4. 哪些机制、动机、历史和身份仍然未知。

只要读者能理解“人物为何现在这样做、动作造成了什么、下一步受到什么约束”，解释就可以停止。

Causal stop 的具体判断：

- Action：谁在哪里、目标是什么、发生了什么接触或阻隔、结果改变了什么。
- Dialogue：谁提出了什么条件、谁回避或拒绝了什么、关系或筹码怎样变化。
- Discovery：什么证据推翻了旧判断，当前风险或路线如何改变。
- Payoff：结果已经被物件、动作、环境或社会反馈证明后，不再追加“这意味着……”。
- Aftermath：只有余波仍改变关系、身体、资源或下一选择时，才继续写。

未知不能替代行动清晰；行动清晰也不要求补齐完整世界机制。

# Reaction Findings

反应的作用是让状态变化可见，而不是为每个情绪添加“人味”。

本轮稳定支持的反应通道包括：

- 嘴硬、自嘲、互损、玩笑；
- 追问、纠正、回避、答非所问；
- 停顿、视线、距离、站位；
- 命令、退让、讨价还价、继续执行；
- 物件使用、资源处置、礼物、住房、食物、文件；
- 错误判断、误听、过度自信、错误坚持；
- 身体症状、伤口、疲劳、发烧、病发；
- 旁观者、对手、权威或制度的重新反馈。

这些通道不能统一分配给所有人物。反应只有在改变判断、关系、身体代价、社会位置或下一选择时才值得保留。直接命令、判决、威胁或交易已经完成状态确认时，不应再补一层心理解释。

# Rhythm + Attention Findings

节奏随真实 scene beat 改变：

- 空间、规则、路线、资源和多方条件建立时，可以展开；
- 危险逼近、动作确认、拒绝、认知翻面和结果落地时，压缩并给结果独立一拍；
- 结果之后，重新给代价、社会重估、私人关系或新风险带宽；
- 终局或大尺度变化可以短暂拉远，但应回到普通身体、物件或生活动作；
- 对白不必轮流发言；应按筹码变化、回避、转述、停顿和关系重定价换挡。

可以跳过：

- 没有新目标、限制、证据、关系变化或选择变化的程序；
- 已由结果取代的重复动作；
- 已经完成功能的过桥信息；
- 不改变当前判断的背景和抽象复述。

不能跳过：

- 程序本身就是资格、价格、风险、身份或关系压力时；
- 动作结果无法复原时；
- 关键反应决定下一步时；
- 低压日常承担基线，删除后会使异常失去反差时。

# Candidate Controls（最多2个；可为空；写 NEW/MERGE/HOLD）

## 1. `character-voice-pressure-routing-v1` — NEW / HOLD

现有 `dialogue-state-pressure` 能处理对白如何改变筹码，但没有明确处理“同一压力下不同人物为何不像同一个人”，尤其是普通场景、余波和非谈判场景。

候选策略：

> 只从当前 Canon、关系和已有人物行为中选择不同的压力处理通道，例如计算、纠正、嘴硬、玩笑、礼貌、回避、命令、交易或继续行动；让通道改变当前判断或下一选择，不新增口癖、背景动机或性格事实。

证据至少来自《修真聊天群》《道诡异仙》《第一序列》《全球高武》《将夜》《诡秘之主》的不同类型窗口。暂不激活，因为现有证据仍是 bounded windows，且多本旧卡明确将稳定 `character_voice` 标为 `UNKNOWN`。

## 2. `social-repricing-status-proof` — MERGE / HOLD

不是新增 Control。它应归并到：

- `payoff-consequence-conversion` 的 shared result-stop；
- `dialogue-state-pressure` 的资格、待遇与筹码变化；
- `scale-anchored-wonder` 的数字、等级与比较关系；
- 现有 synthesis 的 Public Proof / detail-selection 原则。

只在强弱、价值或身份已经发生，但读者仍看不出“别人从现在起如何对待他”时，编译一个具体社会反馈；不默认加入群众反应或额外代价。

# Curator Projection Implications

- 先定位一个真实阅读风险：声音合流、状态不可见、未知被解释完、动作因果丢失，或节奏没有换挡。
- 若是声音合流，只编译人物各自正在保护、回避、交换或误判的内容，以及不同的反应通道；不编译口癖、短句比例或统一“人味”。
- 若是状态不可见，选择一个承载结果的具体动作、物件、数字、称呼或身体后果，再选择一个真正改变待遇、关系或行动空间的反馈。
- 若是 Knowledge 风险，按“证据—局部判断—当前选择”编译；未知只有继续改变风险或下一步时才保留。
- 若是 Causal 风险，只前景化位置、资源、接触、结果和新约束；动作或对白已经成立后立即停止翻译。
- 若是 Rhythm / Attention 风险，指出本场哪个 beat 需要展开、哪个过桥段可以跳过；不指定句长、段长或反应次数。
- Projection 仍应是场景专用的短提醒，默认最多激活一个现有 Control；没有真实 prose conflict 时输出 `NONE`。

- 《修真聊天群》的现代生活语感、消息媒介、现实误认与群体反应。
- 《全球高武》的数字化反馈、积分、体力、协议、互损和终局玩笑。
- 《第一序列》的资源／阶层错位、价格、住房、库存、容量与生活余波。
- 《道诡异仙》的临床距离、感知不稳定、身体恐怖、命令冲突和未决本体。
- 《将夜》的礼仪秩序、公共目光、诗性尺度、逐句转述和从神性回到厨房的收束。
- 《诡秘之主》的经济操作、职业制度、证件、资金、仪式、组织交换和高位代价。
- 所有来源作品的专名、人物习惯、固定玩笑、签名物件、称呼、世界规则和原句。
- 固定 POV 权限、固定口癖、固定反应格式、固定句长比例与固定感官密度；本轮证据不足之处继续标记为 `INSUFFICIENT`。

# Anti-Humanizer Boundary

“更像人”不等于添加更多停顿、手部动作、食物、家务、玩笑、身体反应或私人回忆。

必须守住：

- 反应要改变判断、关系、身体代价、社会位置或选择；
- 声音来自压力处理方式，不来自统一口语化；
- 玩笑可以暴露防御、阶层或关系，但不能抹平死亡、伤害和现实后果；
- 物件只有在承载状态变化时才进入，不为制造生活感强行添加；
- 社会反馈必须是具体待遇、条件、称呼、权限或策略变化，不是“众人震惊”；
- 未知不能被解释成谜语，已成立的动作和结果也不能被重新翻译；
- 不新增 Hard Gate、禁词表、反应配额、句长模板或自动重写回路。
