# Shared Principles

1. 世界需要一把“读者能立即使用的尺”。

   这把尺不必是完整战力表，但必须让读者迅速判断：

   - 这个人能否继续行动；
   - 能否保护或击败什么；
   - 能否进入某个地方；
   - 能否调动什么资源或组织；
   - 他人的态度是否已经改变；
   - 这个东西为什么值得争。

   明确等级适合承担快速定位；可观察阈值适合承担高层差异和真实危险。

2. 核心优势的兼容方式是“不对称转换”，不是“世界规则失效”。

   优势可以把知识变成入口，把资源变成动作，把关系变成协同，把观察变成理解，把身份变成权限；但不能自动变成高层对象的完整力量。高层场景仍需保留至少一种真实世界阻力：境界差、材料、寿命、空间规则、组织态度、身体承受力、他人自主或未知规则。

3. 晋升的读者回报来自世界真实开放。

   晋升后至少应让过去不可得的一种东西变得可得：新的空间、新的敌人、新的资源、新的身份、新的知识层或新的关系位置。过去的努力不是装饰，而是新阶段的入场条件、谈判筹码或解释钥匙。

4. 价值不是“资源名称”，而是行动后果。

   钱、药、资格、战功、情报、血脉、法器、组织名额、身份、关系和空间都可以成为价值，但只有当它改变了人物的选择、进入权、战术、关系或未来目标时，才是故事中的具体价值。

5. 世界阶梯的每一步都应该生成新欲望。

   “更高一层”不能只意味着更多敌人和更大的地图。有效的新层会让主角开始想要以前无法想象的东西，同时重新解释旧物、旧关系、旧损失或旧能力。

# Important Differences / Anti-Universalization

- 不能规定所有世界必须使用数字等级。《大王饶命》《全球高武》《不科学御兽》高度依赖等级与数值；《大奉打更人》还依赖官牌、职位、权限与公共身份；《明克街13号》主要用“能否继续行动、保护别人、调动组织、改变制度结果”来比较。

- 不能把“境界”当作唯一真相。《全球高武》的榜单会低估缺乏公开战绩的强者；《沧元图》《莽荒纪》《牧神记》都反复用越阶战斗、领域、火候、空间或一击结果修正境界标签。

- 不能规定所有核心优势都必须带对称成本。《大王饶命》《明克街13号》确实有失控、反噬和关系风险；《不科学御兽》《超神机械师》则大量保留先享受新能力、再在更高阶段出现新压力的空间。

- 不能规定所有晋升都是修炼突破。进入大学、军部、组织、榜单、遗迹、世界间隙、神殿或新身份，都可以是晋升；反过来，正式突破也可能伴随旧体系失效，如《牧神记》第897章。

- 不能把所有价值翻译成金钱、材料和后勤。《大奉打更人》的金牌是行动权限，《乱世书》的天书是观察和复盘入口，《明克街13号》的家与歌声是身份和关系锚点，《莽荒纪》的复活是长期欲望对象。

- 不能把世界扩大默认成治理升级。《牧神记》《沧元图》《超神机械师》有文明和规则尺度；《明克街13号》《大王饶命》则主要通过家庭、关系、身份和生活回扣宏大世界。治理只是某些作品的后果，不是普遍的更高答案。

# Candidate Mechanisms

## Candidate 1：读者可用的多轴世界坐标

### Stage

World Vision；Outline；关键场景的首次能力验证。

### Shared Creative Problem

世界中有等级、身份、资源和高层对象，但读者无法快速判断谁更强、更危险、更有价值，或者主角晋升后究竟获得了什么。

### Mechanism

用一组少量、当前场景可观察的坐标共同承载比较：

- 一个快速定位坐标：等级、品级、职业、榜单或身份；
- 一个结果坐标：能否击败、保护、穿越、封锁或改变战局；
- 一个权限坐标：能否进入某地、接触某人、调用某资源；
- 一个反应坐标：对手、组织、群众或同伴是否重新估价。

不要求每次都全部出现。等级负责让读者快速落位，行动结果负责证明，权限和反应负责显示“强大之后能改变什么”。

### Evidence Books

不科学御兽、沧元图、超神机械师、大奉打更人、大王饶命、全球高武、乱世书、牧神记、明克街13号。

### Evidence Anchors

- 《不科学御兽》：第25章 L2351–2379；第60章 L6031–6111。
- 《大奉打更人》：第八章 L24983–25000；第一百五十三章 L114132–114249。
- 《全球高武》：第9章 L993–1024；第127章 L18406–18513。
- 《明克街13号》：第200章 L42313–42353；第700章 L130631–130668。
- 《牧神记》：第921章 L72935–73023。

### Guidance

开篇只需展示一两个坐标。例如先让读者知道“能否对抗某种现实威胁”或“能否进入某个关键场所”，再逐步补充等级、身份和组织价值。

### Failure Modes

- 只有称号和数字，没有现场结果；
- 坐标太多，读者无法判断当前最重要的差距；
- 把榜单、等级或身份写成绝对真相；
- 把“有资格进入”误写成“有能力取胜”。

### Relationship to Existing Cards

`MERGE`：并入 `mech-power-verification-visible` 与 `mech-status-recognition` 的 World Vision 指导；不新增独立 card。

## Candidate 2：高层兼容的非替代型转换

### Stage

World Vision；Story Program；高层对象首次出现时的 Outline 设计。

### Shared Creative Problem

核心优势面对远高于主角的对象时，常见两种失效：要么优势直接抹平世界尺度，要么主角只能被动逃跑，核心幻想暂时消失。

### Mechanism

先明确核心优势真正能转换出什么：

- 信息优势 → 找到入口、提前布局、识别规则；
- 资源优势 → 形成一次新动作或新工具；
- 关系优势 → 获得协同、掩护或谈判筹码；
- 理解优势 → 看见局部规律、改造旧能力；
- 身份优势 → 取得有限权限或调动他人。

同时保留一项不可被优势替代的世界门槛。高层遭遇应让优势产生真实的局部收益、选择权或逃生路径，但不能让高层对象的尺度失效。

### Evidence Books

不科学御兽、沧元图、超神机械师、大奉打更人、大王饶命、全球高武、乱世书、莽荒纪、牧神记、明克街13号。

### Evidence Anchors

- 《沧元图》：世界间隙 L22064–22135；雷霆画道 L22663–22795。
- 《超神机械师》：第001章 L19–117；第324章 L21655–21724。
- 《全球高武》：第1396章 L327705–327748。
- 《乱世书》：第300章 L21154–21188；第358章 L25285–25327。
- 《莽荒纪》：第二元神 L24468–24631；终局真灵规则 L116124–116138。
- 《牧神记》：第969章 L77171–77252。
- 《明克街13号》：第900章 L172649–172708；第966章 L183602–183762。

### Guidance

为核心优势写“它给予什么 / 它不替代什么”，但不要把“不替代什么”机械化成固定成本表。高层场景最好同时包含：

- 一个优势产生的可见转机；
- 一个世界规则仍然有效的障碍；
- 一个因此改变的下一步选择。

### Failure Modes

- 优势成为万能钥匙；
- 高层对象只因主角使用优势就突然降智；
- 为了保尺度而让主角完全没有有效回报；
- 把所有优势都强行附加同一种反噬或资源税。

### Relationship to Existing Cards

`MERGE`：并入 `mech-rule-boundary-visible-cost`、`mech-action-space-expansion` 与 `mech-pure-upside-payoff`；不新增独立 card。

## Candidate 3：晋升后的旧资产回流与新入口

### Stage

Outline 的阶段转场、组织加入、新地图开启、突破后的首个兑现段。

### Shared Creative Problem

主角晋升、换地图或进入新组织后，旧能力和旧关系失效，世界只剩“换称号、换敌人、换地图”。

### Mechanism

把晋升写成旧资产在新尺度中的再定价：

1. 旧能力、关系、身份、战绩、物件或未解问题仍然携带进入；
2. 新阶段给予过去不可得的入口、权限、敌人或知识；
3. 旧资产在新场景中承担一种不同的行动功能；
4. 新入口同时生成一个过去不存在的新欲望；
5. 旧事实可以被重新解释，但不必立即完全解释。

晋升可以是正式突破，也可以是入学、入军、入组织、登榜、跨空间、身份公开或进入新文明。

### Evidence Books

不科学御兽、超神机械师、全球高武、莽荒纪、牧神记、大奉打更人、乱世书、明克街13号。

### Evidence Anchors

- 《超神机械师》：第125–126章 L9157–9287；第509–510章 L33500–33696；第653–654章 L45514–45699。
- 《全球高武》：第125章 L18086–18161；第234–235章 L38026–38278。
- 《莽荒纪》：第七卷 L12559–13594；第十三卷 L30733–30898。
- 《牧神记》：第897章 L70767–70856；第987章 L78669–78749。
- 《明克街13号》：第399章 L76866–77047；第404章 L77793–77831。
- 《大奉打更人》：第九十七章 L81940–82010；第一百二十八章 L86996–87066。

### Guidance

每个大阶段转场时，优先问：

- 过去什么仍然有效？
- 什么过去拿不到的东西现在开放了？
- 旧资产在新场景中改变了什么动作？
- 新入口让主角开始想要什么？

这是大纲设计提示，不是每个转场都必须逐项完成的格式。

### Failure Modes

- 晋升只增加称号或数值；
- 新地图把旧人物、旧问题和旧投入全部清空；
- 旧资产只作为怀旧道具，没有新功能；
- 新地图只增加百科名词，没有新的欲望对象。

### Relationship to Existing Cards

`MERGE`：并入 `mech-map-transition-without-reset`、`mech-old-ability-new-use` 与 `mech-mystery-reveal-action`；不新增独立 card。

## Candidate 4：具体价值到新欲望的复利

### Stage

World Vision 的价值结构；Story Program 的奖励设计；Outline 的阶段回报与新世界入口。

### Shared Creative Problem

世界不断用“更多资源、更高价格、更大地图”推动升级，最后变成资源管理或重复刷取；新奖励也只是填补下一层缺口，没有产生新的幻想。

### Mechanism

先区分两类价值：

- 基础条件：食物、现金、恢复、身份文件、训练、普通装备、进入日常组织的资格；
- 稀缺获得：改变上限的血脉、稀有资格、关键情报、独特法器、特殊关系、跨层入口、复活或改写世界的权限。

然后让稀缺获得完成三次转化：

1. 先在当前场景中产生可见、可使用的直接收益；
2. 再改变主角能够采取的行动、能够进入的空间或能够谈判的关系；
3. 最后把新能力或新入口转化为一个过去不存在的新欲望。

下一轮压力可以来自新欲望、新对象或新世界，不必立即把刚获得的自由抵消掉。

### Guidance

设计每个重要获得时，先问“它具体让主角现在能做什么”，再问“它使主角接下来想要什么”。资源、身份、情报、关系和世界入口可以互相转化，但不要全部改写成货币或容量。

### Failure Modes

- 奖励只有数值变化；
- 奖励刚兑现就被下一层稀缺立即收回；
- 所有价值都变成材料、金币、积分或后勤；
- 新地图只提供新资源，没有新的欲望；
- 把“资源压力”误当作所有长篇的默认发动机。

### Relationship to Existing Cards

`MERGE`：并入 `mech-resource-liberation` 与 `mech-resource-pressure-progression`，借用 `mech-exploration-world-layer` 的世界入口部分；不新增独立 card。

# World Vision Transfer

以下是结构迁移建议，不是 TGN Canon。

- 世界 Vision 不必先列完整等级百科。先确定读者最需要知道的比较问题：谁能对抗什么、谁能进入哪里、谁能保护谁、什么东西值得争。

- 核心优势应写成“转换能力 + 不可替代的世界门槛”。优势可以带来行动自由，但不能自动取消世界的高层对象、规则和他人自主。

- 世界入口必须同时带来新可欲望对象。新地图不是“更远的地方”，而是过去不可见、不可进、不可争或不可理解的东西开始出现。

- 具体价值要落在结果上：资格、空间、关系、身份、情报、稀缺能力和资源都可以成为价值，但必须改变下一步行动。

- 新阶段优先保留旧锚点的功能，而不是保留旧名词。旧锚点可以被重新解释、换用途、改变关系，也可以在完成兑现后真正失效。

- 对 TGN 而言，“路”应服务于力量、机缘、探索、反杀、自由、势力冲突和世界奇观；不能把这些结构转译成路线管理、物流系统或工程项目。

# Outline First-Five-Chapter Transfer

以下是无具体 TGN Canon 前的结构放置建议，不是剧情提案。

| 章节 | 推荐承担的读者任务 | 可放置的结构 |
|---|---|---|
| 第1章 | 让读者站在一个具体生活或危险现场，看到主角当前能做什么、不能做什么，以及一个可触摸的核心欲望。 | 建立第一把世界坐标；展示一个基础条件与一个值得争的具体对象；用行动而非百科打开世界入口。 |
| 第2章 | 让核心优势第一次有效，但只解决一个局部问题。 | 展示优势的真实转换能力，同时让一个不可替代的世界门槛保持有效；让他人或环境对结果产生反应。 |
| 第3章 | 让主角主动争取、交换或冒险取得一个具体价值。 | 价值必须改变行动空间、关系位置或进入权限；奖励可以先完整兑现，不必立刻制造下一层缺口。 |
| 第4章 | 给主角一次公开或半公开的比较。 | 用战斗结果、权限变化、他人态度、专业结果或实际保护效果校准读者坐标；可以让主角看见一个暂时无法正面解决的高层对象。 |
| 第5章 | 打开下一阶段，而不是结束当前小回报。 | 让旧物、旧关系、旧能力或未解问题成为新入口；新入口应带来一个新的欲望对象，并以主角选择收束，而不是以设定说明收束。 |

# What Not To Turn Into Hard Gates

- 不要求所有世界都有数字等级。
- 不要求每个阶段固定使用三轴或四轴坐标。
- 不要求每次力量提升都必须附带成本、反噬或责任。
- 不要求每次奖励都立刻制造新的稀缺。
- 不要求每次晋升都获得公共称号或组织认可。
- 不要求所有新地图都保留全部旧资产；已经完成、毁灭或失效的旧资产可以真正结束。
- 不要求所有世界扩张都导向治理、文明建设或责任半径扩大。
- 不要求所有具体价值都写成资源、经济或后勤系统。
- 不要求每个新世界都解释旧谜团；保留部分未知本身可以是有效回报。
- 不要求每章同时完成坐标、奖励、晋升、世界扩张和欲望重释。
- 不把这些候选变成自动评分表、固定章法或验证器。
- 不把参考作品的专名、事件顺序、人物关系或事实直接写入 TGN Canon；本批材料只能提供结构灵感，不能替代作者批准。
