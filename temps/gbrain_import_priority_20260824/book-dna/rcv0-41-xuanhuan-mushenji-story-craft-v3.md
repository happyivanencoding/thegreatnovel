# Evidence Coverage

覆盖窗口：

- 开篇：第 1–4、7–9、17–25 章。
- 前中期：第 45–94、150–264 章。
- 中期：第 500–675 章。
- 中后期：第 731–923、957–1322 章。
- 后期与终局：第 1402、1413、1426、1478、1600、1655、1770、1781、1824、1827、1830–1834 章。

抽样重点覆盖：

1. 残老村与大墟的封闭生存规则。
2. 太阳船、暗界、无忧乡等世界入口。
3. 延康、幽都、天庭、祖庭、弥罗宫的尺度跃迁。
4. 七大神藏、天宫、道境、新神藏体系的变化。
5. 残老村人物、开皇、旧友与转世人物的跨世界回流。
6. 终局中的宇宙扩张、寂灭、返乡与再次出发。

# Core Reader Fantasy

核心读者幻想不是单纯“不断升级”，而是：

> 从一个连天黑都不能出门、只能在残老村接受保护的孩子出发，逐步获得进入更大世界、理解更古老历史、挑战更高存在、重写未来并最终回到故乡的资格。

读者持续追读的原因有四层：

- 每次主角以为自己已经理解世界，都会发现当前世界只是更大结构的一层。
- 新世界不是静态地图，而是会改变主角的身份、敌人、朋友、能力和下一阶段欲望。
- 早期的物件、禁忌、老人、村规和小谜题，后面会升格成身世线、历史线、宇宙线。
- 世界尺度越大，主角越强，但“回家、找故人、保住未来”的私人欲望没有被宏大设定吞没。

核心阅读承诺可概括为：

> 看见更大的奇观；发现旧地图不够用；获得进入新尺度的能力；让早期旧物和旧人重新产生意义；再把新尺度的结果带回个人关系。

# Protagonist Desire & Agency

秦牧的欲望会随世界扩大而变形，但不是被动接受命运。

## 欲望阶梯

1. **生存与归属**  
   在残老村被老人们养大，首先要理解“天黑别出门”和黑暗为何存在。第 1 章中，他的出生、收养和村规同时建立了生存欲望与家庭归属。

2. **离开封闭世界**  
   他想走出大墟，见识延康的新法术、新时代和外部人物。灵毓秀明确告诉他，大墟只是偏僻一隅，外面还有更广阔的天地（第 82 章）。

3. **寻找身世与父母**  
   玉佩、无忧乡、暗界逐渐把“我从哪里来”变成行动目标，而不是静态身份揭晓。

4. **理解并改变历史**  
   他不满足于知道开皇、天庭、天尊和宇宙纪元的往事，而是介入它们，改变原本被认为固定的未来。

5. **保住故乡与故人**  
   中后期的秦牧不再只是追求力量，而是试图让延康、妻子、朋友、旧师和未来生命继续存在。

6. **回到故乡，再次出发**  
   终局中，他回到延康，但发现故乡已发生巨大变化；返乡不是结算，而是确认牵挂仍在，然后继续逆溯第一纪寻找解决大寂灭的办法。

## agency 机制

秦牧的主动性主要来自：

- 好奇心：遇到未知世界时主动靠近。
- 多师学习：不依附单一传承，吸收刀、拳、腿、书画、炼药、造化、神识等不同方向。
- 现场判断：在规则不明时保留多个解释，不急于把传闻当事实。
- 重新组合：把旧技能放入新世界使用，创造不同于前人的道路。
- 谈判与利用：会交易、讨价、借势，也会偷取资源；原作并未把这种行为一律道德化。
- 未来介入：不是只预测未来，而是主动回到过去、安排后手、改变人物和事件的连接方式。

# Advantage / Power Experience

本书没有一个可以单独解释全部成长的金手指。秦牧的核心优势是一个组合：

1. **异常身体与深厚基础**  
   他没有四大灵体，却用最低级的导引功、长期灵血供给和残老村的极限训练，形成远超常规的根基（第 2、4 章）。

2. **无属性元气**  
   无属性使他早期难以直接显露威力，但也让他能处理不同属性的力量，并在炼药、造化和多体系融合中获得特殊适应性（第 4、94 章）。

3. **残老村的多方向教育**  
   他不是得到一件宝物，而是同时拥有多个极端高手的训练成果。每位老人都给他一种不同的“看世界方式”。

4. **模仿、观察与再创造能力**  
   他能从神像、画、战斗和遗迹中观察结构，再转化为自己的招式，而不是只背诵秘籍。

5. **跨世界经历带来的知识复利**  
   进入幽都、天庭、无忧乡、祖庭和过去宇宙后，经验本身成为力量；但经验越多，也越容易面对旧体系失效的问题。

## 他真正获得什么

- 进入危险世界的资格。
- 将不同力量体系组合起来的能力。
- 把旧物、旧人和旧知识放入新环境重新解释的能力。
- 在高层冲突中拥有谈判筹码。
- 逐步成为能改变世界坐标的人。

## 他没有获得什么

- 不是全知。
- 不是免伤。
- 不是所有体系都能直接使用。
- 不是只要境界高就能赢。
- 不是知道未来就能无代价改变未来。

秦牧重生后只剩一个特殊灵胎，旧有七大神藏和功法无法顺畅运转，修为一度只剩原来的五分之一（第 897 章）。这说明核心优势服从世界规则：基础变了，旧能力就会失效。

# Reader-Facing World Coordinates

本书给读者的“尺”不是单一等级表，而是多种可观察阈值叠加。

## 早期：明确境界与身体效果

读者通过七大神藏、破壁、灵胎、五曜、六合、七星、天人、生死、神桥比较强弱（第 2 章）。

同时还有直接可见的效果：

- 能否在黑暗中活下来。
- 能否踏风、踏水、踏空。
- 能否控制雷霆、火焰、刀气。
- 能否抵抗神通、斩断神藏。
- 是否能打开多重神藏。

## 中期：一招造成什么结果

强弱越来越由行动后果显示：

- 一击是否能摧毁神桥。
- 是否能让对手永久跌落境界。
- 是否能压制天人、帝座、古神或天尊。
- 是否能改变城市、天庭、诸天的地理与结构。

第 921 章中，秦牧一剑斩断云渐离神桥，使其终生无法再成神，读者无需计算复杂数值，就能立刻理解双方差距。

## 身份尺：称号、背后关系与公共反应

身份不是装饰，而是可观察的社会力量：

- 天圣教主。
- 人皇。
- 天尊。
- 变法核心人物。
- 弥罗宫公子。
- 古神、造物主、开天众。

但称号不能单独决定强弱。第 897 章中，秦牧被天庭神人视作“废人”，但第 921 章又以一击让一批天骄无法抵抗，说明“身份标签”与“现场实力”之间可以发生冲突。

## 终局：道行、火候与世界尺度

后期比较的是：

- 大罗天、道树、道花、道果。
- 道境三十六重、三十九重、四十重。
- 能否承受宇宙纪元的破灭与创生。
- 能否进入、改变或对抗终极虚空。
- 是否具备足够“火候”，即经历过多少历史与宇宙尺度。

第 1833 章明确显示，到了极高层级，境界相近仍可能因为经历差异形成巨大差距。

# Core Advantage ↔ World Compatibility

适用，但不是单件金手指。

## 玉佩

玉佩真正承担的是：

- 身世线入口。
- 与无忧乡相关的识别物。
- 偶尔提供保护或引导。
- 把个人出生问题连接到暗界、无忧乡与跨世界历史。

它不替秦牧完成：

- 穿越黑暗。
- 破解所有门户。
- 战胜高层存在。
- 直接找到父母。
- 解决宇宙寂灭。

第 80–81 章中，太阳守只能根据玉佩判断它可能来自无忧乡；无忧乡仍然神秘，暗界仍然危险。

## 多师教育与异常根基

这是更重要的核心优势，但它也不替代：

- 境界修炼。
- 对新世界规则的理解。
- 对具体敌人的判断。
- 资源和盟友。
- 付出时间与承担损失。

第 969 章中，无忧乡入口要求复杂且危险的开门顺序；错误会落入造物主陷阱。优势只能提高试错和理解能力，不能取消规则。

## 最高层兼容原则

本书的核心优势始终受到三种限制：

1. **世界规则限制**：新世界有自己的门、道、时空和代价。
2. **体系失效限制**：身体或世界条件变化后，旧功法会失效。
3. **历史后果限制**：知道未来不等于可以任意改写未来。

# World Fantasy Ladder

## 1. 残老村：被保护的封闭微世界

关键词：黑暗、石像、残老、收养、村规。

世界奇观首先不是远方大陆，而是“村外天黑后有什么”。对秦牧来说，世界边界就是村子的四角石像。

## 2. 大墟：废墟中的远古世界

关键词：黑暗、遗迹、龙宫、石像、太阳船。

大墟把“荒凉”变成远古文明的残骸。龙宫、龙魂、太阳船说明这里不是贫瘠边地，而是一个被更大灾变遮蔽的旧世界。

## 3. 明界与暗界：同一空间的双重世界

白天和黑夜不再只是时间变化，而是明界与暗界的交替。秦牧第一次看见黑暗中的世界后，原本的地图被直接推翻（第 81 章）。

## 4. 延康：社会与文明尺度

走出大墟后，问题从“如何活下来”变成：

- 谁拥有土地。
- 谁控制神通。
- 旧宗派如何回归。
- 变法如何改变人族未来。
- 新法术如何与旧世界冲突。

## 5. 幽都、酆都、人皇殿：死者仍然参与世界

死亡不是关系终止。历代人皇、祖师、旧友可以在幽都和酆都继续影响后人，并通过传承、打斗、护短和重聚回到当前故事。

## 6. 诸天与天庭：世界成为多层文明网络

太皇天、罗浮天、天庭、天河、古神和半神把世界从单一大陆推到诸天体系。第 731 章中，秦牧和老牛误入远古天庭，看见天河、天宫和年轻时代的开皇。

## 7. 无忧乡、祖庭与造物主世界

无忧乡不是简单的“理想故乡”，而是与开皇、造物主、太帝和历史战争纠缠在一起的真实世界。秦牧进入后发现，早期传说的壮举也可能包含欺骗与误读（第 987 章）。

## 8. 弥罗宫与十七个宇宙纪

世界扩张到跨宇宙历史，人物不再只在空间中移动，也在破灭劫、创生劫和过去未来之间移动。旧人物可以在不同纪元以不同身份重新出现。

## 9. 终极虚空：宇宙本身成为危机

终局的敌人不是某一个更强的角色，而是虚空扩张、灵能耗尽、宇宙逐渐失去物质和时间。故事最终仍保留“黑暗中重新亮起一点光”的读者期待。

# Major Character & Relationship Engines

## 残老村：家庭保护与能力传承

残老村人物同时承担三种功能：

- 家人：收养、保护、争吵、隐瞒。
- 老师：每人提供一种独立技能和判断方式。
- 远古人物：后来在天庭、幽都、祖庭等尺度重新显露真实层级。

他们不是静态的“导师团”。关系会反转：早期秦牧被他们保护，后来秦牧反过来治疗他们、救援他们、改变他们的未来。

## 开皇：祖先、理想与被重新解释的历史

开皇先是秦牧想象中的祖先和英雄，随后变成需要调查、怀疑和重新理解的人物。秦牧对开皇的想象在第 600、987、1770 章不断修正。

这条关系线的动力不是“认祖归宗”，而是：

> 如果祖先并不符合自己的幻想，后人是否仍然要继承他的未完成事业？

## 灵毓秀：并行成长与跨时间牵挂

灵毓秀不是只等待主角的伴侣。她有自己的政治、教育和修炼路径；后期即使双方经历漫长岁月，关系也会从热烈恋爱转化为深层寄托（第 1827 章）。

## 旧友回流

瘸子、瞎子、药师、村长、历代人皇、孟云归、阆涴等人物会在新的世界和新的身份中回流。

回流通常带来三种变化：

- 旧人物证明早期世界比读者想象得更深。
- 旧关系在新规则中出现新的障碍。
- 主角的新身份必须接受旧人对他的重新判断。

## 对手与旧秩序

太帝、天庭、弥罗宫、凌霄等对手，不只是“更强的敌人”，还代表旧世界对未来的解释方式。

冲突因此会从：

- 谁更强；
- 谁能活下来；

逐步变成：

- 谁定义未来；
- 谁承担牺牲；
- 哪种旧秩序值得保留；
- 一个拯救众生的组织如果失去目标，是否还应继续存在。

# Payoff Grammar

## 1. 早期禁忌 → 更大世界入口

“天黑别出门”先是村规，后来变成暗界入口，终局又变成成道者对小宇宙生灵的保护警告（第 1、81、1834 章）。

## 2. 小物件 → 身世与世界坐标

玉佩从出生物件，逐渐变成无忧乡、父母、暗界和跨时空关系的入口。它的价值随着尺度增加，而不是一次性解释完毕。

## 3. 残废老人 → 远古强者

早期的独臂、瘸腿、无手无脚不是单纯的弱者形象。后面他们分别以天刀、如来、人皇、佛界强者等身份回流。

## 4. 旧能力 → 新场景中的新价值

刀法、画法、腿法、炼药等早期能力不会被简单淘汰，而会在天庭、祖庭、神识、时间和宇宙战争中获得新的用途。

## 5. 传说 → 证据冲突 → 重新解释

无忧乡、开皇、造物主、太帝等线索不是一次揭开。主角进入新世界后，旧传说会被现实证据重新解释。

## 6. 获得 → 体系过时

新能力往往伴随着旧能力失效。第 897 章中，秦牧获得新生，却发现原有功法体系无法继续使用。这让成长不是单纯叠加，而是不断换底层规则。

## 7. 回流 → 不一定恢复原样

转世者可能失去记忆，旧爱可能只剩模糊熟悉感，故乡可能已经找不到原址。回流提供情感兑现，但不保证完整复原（第 1781、1827 章）。

# Repeatable Story Engines

## 1. 破尺度探索

安全区 → 外部禁区 → 发现更大世界 → 获得进入资格 → 旧目标被重新定义。

这是全书最主要的长篇发动机。

## 2. 多师传承与现场合流

获得不同老师的局部能力 → 在挑战中暴露不兼容 → 重新组合 → 形成自己的道路 → 进入更高尺度。

它避免了单一路线升级，也让每个旧人物的价值可以持续回流。

## 3. 旧锚点跨世界回流

旧人、旧物、旧承诺或旧传说重新出现 → 新身份与旧认知发生冲突 → 主角获得新的事实或情感动力 → 下一阶段目标被启动。

# World Expansion Grammar

本书的世界扩张不是“地图越来越大”这么简单，而是五种东西同时升级：

1. **空间尺度**：村庄 → 大墟 → 延康 → 诸天 → 祖庭 → 宇宙纪。
2. **规则尺度**：村规 → 神藏 → 世界法则 → 道境 → 创生与寂灭。
3. **身份尺度**：弃民 → 教主 → 人皇 → 天尊 → 七公子。
4. **关系尺度**：养育者 → 师友 → 祖先 → 跨纪元同伴 → 未来生命。
5. **时间尺度**：当前事件 → 远古历史 → 过去宇宙 → 改变后的未来。

每次跃迁最好满足：

> 新世界必须重新解释至少一个旧锚点，并改变主角下一步真正想要的东西。

因此世界扩张的有效单位不是“新名词”，而是：

- 一个可进入的新世界；
- 一个可观察的新阈值；
- 一个被重新解释的旧事实；
- 一个回流的旧关系；
- 一个因此改变的行动目标。

# TGN Transfer

## Fantasy Seed

最有价值的迁移原则：

- 从一个具体、可行动的个人欲望开始。
- 给主角一个明确但有限的世界入口。
- 入口可以是物件、禁忌、老人、地理异常或关系，但不要一开始解释完。
- 不预设“力量越大就必须承担更大责任”是正确答案。
- 先让幻想成立，再观察故事自身产生什么代价和价值冲突。

## World Vision

- 给读者一把可用的尺：身体效果、环境反应、战斗结果、社会称号、他人态度、可进入的世界。
- 让每个新尺度都推翻或扩展上一层地图。
- 奇观必须改变行动空间，而不是只增加背景名词。
- 早期奇观最好同时具有私人意义和世界意义。
- 不要把超凡世界自动改写成工程流程、权限树或运营系统。

## Story Program

- 优先使用“破尺度探索”“多师合流”“旧锚点回流”三个发动机。
- 让每次成长改变敌人策略、关系结构、身份位置或未来事实。
- 奖励不只增加力量，也可以增加进入资格、解释能力、谈判筹码或关系选择。
- 允许旧体系失效，让成长包含换底层规则。
- 不把世界扩张做成重复任务和等级清单。

## Outline

- 在开篇埋下可反复回收的旧锚点。
- 每个大阶段至少完成一次“旧事实重新解释”。
- 在新世界中安排旧人物回流，但让其身份、记忆、立场或关系发生变化。
- 把个人欲望放在世界奇观前面：找父母、救朋友、回家、守住未来，才是奇观持续产生阅读动力的原因。
- 让新尺度带来新问题，而不只是更强敌人。
- 允许兑现带有失去、错过、记忆消除和关系变形，不强行恢复原状。

# Bias Check

原作实际存在以下内容，但不能自动提升为本书的“成熟答案”：

- **治理与制度**：延康变法、神位分工、天庭体系、教育体系、灾后恢复确实存在（第 264、675、1781 章）。
- **治理失效**：宗派复起、土地争夺、教育差距、宇宙扩张导致统治范围失效，也都被原文直接描写。
- **责任**：村长因为仍有责任而没有选择死亡；秦牧后期明确把未来生命的生存放在行动目标中。
- **牺牲**：持戟神人兵解、成道者自我化为祖庭大罗天等情节真实存在，但并不构成所有力量都必须对称付出的规则。
- **代价**：死亡、重伤、失忆、转世、旧体系失效、漫长分离和宇宙寂灭反复出现。
- **机会主义**：秦牧也会交易、抬价、窃取资源、利用敌人弱点；原作没有把“克制、责任、制度”始终放在个人力量与奇观之前。
- **终局治理**：成道者共同尝试阻止虚空扩张，但多次方案失败；最终仍以自我牺牲延续局部生命。原作记录的是一种实际选择和失败过程，不是制度万能论。

**核心偏差结论：**

> 《牧神记》的主轴是力量、奇观、探索、关系回流、历史重释与未来争夺；治理、责任和牺牲是其中真实存在的支线与后果，不应被反向提升为所有情节的解释中心。
