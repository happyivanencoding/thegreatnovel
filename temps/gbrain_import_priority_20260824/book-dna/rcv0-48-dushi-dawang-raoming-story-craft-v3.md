# Core Reader Fantasy

核心幻想是：

> 一个贫穷、体弱、被世界冷落的少年，不靠传统英雄资格，而靠自己的嘴、机灵和不体面的“惹人烦”能力，把别人的情绪转化成资源；他因此获得自由、力量、金钱、身份、家人与更大的世界入口，却不必放弃自己的俗气、懒散、毒舌和日常欲望。

开篇的现实愿望非常小：给吕小鱼买吃的、维持学费、在贫民区活下去；超凡世界出现后，吕树首先想要的也不是拯救世界，而是“比别人更强”、拥有更多选择权，并保护吕小鱼（第1章，L12-L37、L97-L109；第2章，L91-L96；第9章，L489-L501）。

读者继续阅读的主要原因：

1. 每次对白都可能立刻变成可见的数值收益。
2. 每次收益又能兑换下一次能力、金钱或场景入口。
3. 吕树的优势越荒诞，放入正式组织和高层世界后反差越强。
4. 早期笑点不会被清零，而会变成持续关系、声望、敌意或团队记忆。

# Protagonist Desire & Agency

## 欲望

吕树的欲望逐层扩大：

- 生存：养活自己和吕小鱼。
- 自由：不被抓走、研究、征召或强迫效力。
- 选择权：有钱、想去哪就去哪、让吕小鱼过得更好。
- 力量：能保护自己与重要的人。
- 归属：从“只有两个人的家”扩展到朋友、战友和组织。
- 回家：即使进入更大的世界，最终仍想回到洛城与吕小鱼身边。

“自由”被他明确解释为更多选择权，而不是抽象正义；他也明确拒绝把“力量越大责任越大”自动当作自己的原则（第9章，L489-L501、L577-L587；第14章，L801-L812）。

## Agency

吕树的主动性不是“被任务推动”，而是：

- 主动测试系统边界。
- 主动制造负面情绪。
- 主动把臭豆腐变成收入来源。
- 主动加入群聊、扩大受众。
- 主动观察组织、身份和资源分配。
- 主动选择是否介入战斗。
- 关键时刻被个人关系改变选择，而非被抽象责任改变选择。

他早期拒绝救助梁澈，不是因为没有能力，而是因为风险、金钱和自身安全优先；后来他因为吕小鱼、李弦一、战友等具体关系改变选择（第9–10章，L472-L587；第799–800章，L39998-L40049）。

# Advantage / Power Experience

本书的核心优势不是单纯“无限变强”，而是三层结合：

## 1. 情绪账本

系统把他人可识别的负面情绪变成明确数值，且能看到来源：

- 恐惧、怨念、尴尬、愤怒都可以产生收益。
- 收益来自具体人物，因此每次数值都带着关系信息。
- 自己的怨念不能直接转化为收益。
- 数值可以持续累积，形成“社交行为—资源增长”的即时反馈。

（第5章，L240-L297；第6章，L301-L337）

## 2. 不稳定的兑换

系统不会稳定发放理想奖励：

- 抽奖会出现“谢谢参与”。
- 金色纸页、洗髓果实带来真正的能力跃迁。
- 臭豆腐只是普通食物，却意外成为稳定收入来源。
- 普通物品并非废物，而可能改变吕树的生活空间。

（第6–7章，L338-L390；第44–48章，L2395-L2585）

## 3. 能力与关系互相嵌套

系统给予资源，却不替代：

- 选择如何制造情绪。
- 如何隐藏身份。
- 如何理解新世界。
- 如何处理不同修行体系。
- 如何建立队伍。
- 如何承受关系造成的风险。

吕小鱼获得的功法与吕树不同，甚至排斥星辰果实；核心优势因此不是万能钥匙，而是世界中的一种特殊修行路径（第53–54章，L2842-L2896）。

# Reader-Facing World Coordinates

本书早期给读者一把非常可用的尺，不需要先读完整百科：

| 坐标 | 读者可观察阈值 |
|---|---|
| F级 | 力量型强化，仍无法稳定对抗超自然能力 |
| E级 | 拥有明确超现实能力，如元素能力 |
| D级 | 能有效躲避热武器 |
| C级 | 能对抗大部分热武器，但并非绝对免疫 |
| B级 | 可借用天地力量 |
| A级 | 可与天地共鸣 |

这些等级不是抽象称号，而是直接翻译成“面对热武器能做到什么”（第15章，L820-L855）。

随着世界扩大，读者还会使用其他可观察坐标：

- 是否能独立战斗。
- 是否能改变战局。
- 是否拥有组织、情报和后勤。
- 是否有资格影响普通人安全。
- 是否能让强者主动投靠。
- 是否拥有领地、队伍和稳定关系。
- 是否能在不同世界之间往返。

因此，本书的强弱判断不是只看数字，而是“等级＋实际战场效果＋组织声望＋关系网络＋世界入口”。

# Core Advantage ↔ World Compatibility

本书存在明确核心金手指，N/A 不适用。

## 它真正获得什么

- 将社会反应转化为资源。
- 将资源转化为金钱、体质、修行、武器和能力。
- 把吕树最不体面的性格，变成可重复的成长优势。
- 让他在资源匮乏时仍拥有自主修行路径。

（第5章，L240-L297；第14章，L763-L812；第47章，L2521-L2564）

## 它不替代什么

- 不替代现实选择。
- 不替代战斗判断。
- 不替代身份伪装。
- 不替代团队合作。
- 不替代情报与组织。
- 不替代关系承诺。
- 不保证每次兑换都得到高价值奖励。

吕树即使拥有独特系统，早期仍只是较弱的 F 级；他必须通过行为、风险和长期积累追上其他觉醒者（第15章，L835-L867）。

## 高层对象如何仍服从世界规则

核心优势并没有跳出世界规则：

- 负面情绪需要由他人产生，不能自我循环。
- 高层敌人可以理解并利用他的成长节点。
- 御扶摇明确知道第六层星云与负面情绪的关系，并故意制造“大量负面情绪”帮助他达到可被夺取星图的状态。
- 吕树最终仍需要依靠关系、战斗、武器、组织和世界通道完成突破。

（第1305章，L65003-L65048；第1328–1329章，L66203-L66324）

# World Fantasy Ladder

1. 贫穷日常：糖葫芦、学费、泡面、卖鸡蛋、照顾妹妹。  
2. 世界偏离：灵异新闻、觉醒者、黑风衣、被删视频。  
3. 私人超凡：情绪账本、果实、星图、小星星修行。  
4. 社会尺度：道元班、资质等级、基金会、组织与国家机器。  
5. 世界入口：遗迹、海外组织、黑市、不同修行文明。  
6. 身份与领地：天罗、神王、王城、军队、世界通道。  
7. 回归与继承：失踪、重聚、牺牲、旧身份重新解释，最终回到关系和选择。

这条阶梯的特点是：每一次世界扩大，都由人物反应和关系后果带入，而不是先铺一张完整地图。

# Major Character & Relationship Engines

## 吕树—吕小鱼：共同贫困形成的双人世界

两人从“买不起糖葫芦”开始，靠互相嫌弃、互相照顾维持关系。吕树用吕小鱼的怨念升级，吕小鱼又是他最重要的生活与情感锚点；后期她的选择直接改变吕树是否参战（第1章，L16-L27；第5章，L278-L297；第799–800章，L40029-L40069）。

## 吕树—知微：一句对白变成长期关系债务

“有多高兴”并非一次性笑点。知微长期记住这次被噎，后来专门找机会回击，却再次被吕树打断；尴尬变成持续负面情绪，也变成两人识别彼此的关系标志（第2章，L84-L90；第52章，L2771-L2808）。

## 吕树—群体：对白改变群体状态

朋友圈、班级群和觉醒者群不是背景板。吕树一句话能让群体从同仇敌忾变成集体沉默，再转化为大量收益；但收益也意味着他被视为另类、被防备，甚至被排斥（第37–38章，L2026-L2062；第48–49章，L2602-L2649）。

## 吕树—陈祖安—御龙班直：笑点制造战友身份

火车上的玩笑、作业、荣华富贵等日常梗，逐渐成为战友之间的共同记忆。战争中这些人物不再只是搞笑配角，最终有人牺牲，笑点因此获得反向情感重量（第350–352章，L18158-L18252、L18254-L18294；第1323–1328章，L65894-L66159）。

## 吕树—剑庐：冒犯造成冲突，也制造归属

吕树水淹剑庐、偷取典籍、用“各退一步”继续刺激顾凌绯，表面是持续搞笑，实际迫使剑庐重新表态并加入共同战场（第1299–1301章，L64707-L64848）。

## 吕树—千叶真寻：身份骗局留下真实情感后果

吕树顶替桐原洋介，却无法消除原身份留下的感情。千叶通过性格差异识破他，坦诚、悲伤与觉醒同时发生；这不是笑点回收，而是身份行为造成的不可逆关系后果（第500–502章，L25730-L25757）。

# Payoff Grammar

1. 先用一句不合常理的对白制造即时反应。
2. 反应被记录为数值、声望、敌意或记忆。
3. 主角把反应转化为资源或下一次行动。
4. 新行动扩大受众，进入更大场景。
5. 原笑点在新场景中被重新解释。
6. 关系或社会状态发生真实变化。

典型例子：

- 噎知微 → 持续怨念 → 再次见面时形成私人对抗。
- 抽出臭豆腐 → 街道集体难受 → 获得资源与现金 → 改变吕树和吕小鱼的生活。
- 群聊毒舌 → 集体沉默 → 负面情绪暴增 → 吕树意识到“人”才是成长来源。
- “抢人头”玩笑 → 发生在真正战争中 → 让顶级战斗仍保留吕树的日常人格。
- 吕小鱼代课 → 纪念吕树 → 群体把等待回归变成实际行动。

# Repeatable Story Engines

## 1. 激怒／尴尬 → 情绪收益 → 兑换 → 新玩法

这是最稳定的长篇发动机。它可以发生在家庭、群聊、街道、组织、海外任务和战争中，但每次收益的用途不同，避免完全重复（第5章，L240-L297；第47–49章，L2521-L2649；第1328章，L66203-L66208）。

## 2. 进入新场域 → 破坏默认秩序 → 关系重排

吕树进入道元班、海外组织、黑市、王城或剑庐后，先用异常说话方式和异常行为破坏场域规则，再产生新的敌人、盟友、身份和资源（第37–39章，L2017-L2149；第500章，L25686-L25724；第1299–1301章，L64707-L64848）。

## 3. 小家／关系受到威胁 → 主动选择 → 群体跟进 → 真实代价

吕树早期只想保护吕小鱼；后期关系扩展到李弦一、剑庐、御龙班直和学院。关键选择会带来战争、牺牲、离别或重聚，而不是只带来奖励（第799–800章，L39998-L40069；第856章，L42768-L42815；第1326–1328章，L66050-L66194）。

# World Expansion Grammar

- 从可触摸的日常物件开始：糖葫芦、泡面、煮鸡蛋、臭豆腐。
- 通过异常人物进入超凡世界：火焰表演者、黑风衣、知微。
- 用删视频、班级群和网站制造社会认知变化。
- 用等级和热武器阈值给读者快速比较强弱。
- 再引入组织、训练、任务、黑市、海外势力。
- 通过身份、遗迹和关系把世界扩大到不同文明。
- 终局不是单纯“地图更大”，而是旧关系、旧笑话、旧身份获得新含义。
- 世界扩展始终由人物选择和群体反应推动，而不是单独插入百科说明。

# TGN Transfer

## Fantasy Seed

可迁移的不是“负面情绪系统”，而是：

> 让主角拥有一种与其性格、生活处境和核心幻想高度耦合的优势。

设计时先确定主角想要的具体自由、关系或生活，再寻找一种能把主角现有特质转化为行动空间的优势；不要先设计宏大系统，再寻找人物用途。

## World Vision

为读者尽早提供一把可观察的尺：

- 强弱能否对抗什么。
- 身份能调动什么。
- 组织能保护什么。
- 资源能改变什么。
- 某人出现后，周围人会怎样反应。

世界观不必一开始完整，但必须让读者知道下一次升级意味着什么。

## Story Program

长篇发动机应保持：

> 人物行动 → 他人反应 → 可用资源 → 新选择 → 关系或世界状态变化。

同一个核心机制要在家庭、学校、组织、任务和战争中变异，而不是反复复制同一场“刷资源”。

## Outline

大纲最值得迁移的是兑现安排：

- 早期笑点要留下可回收的关系记忆。
- 资源奖励要改变下一次行动空间，而非只增加数值。
- 新场域要让旧人设遭遇不同社会规则。
- 离场、身份替代、失踪和回归要改变群体状态。
- 重大能力提升必须伴随新敌人策略、关系风险或世界入口。
- 不要把这些原则写成工程流程；应落实为具体场景中的欲望、对白、行动和结果。

# Bias Check

- 原作实际存在“自我保护优先”。吕树早期不接受“力量越大责任越大”，不主动承担陌生人的命运（第9章，L489-L501）。
- 原作实际存在关系驱动的责任变化，但触发点是具体的人，而不是抽象治理原则：吕小鱼、李弦一、战友、学生（第799–800章，L40029-L40069；第856章，L42768-L42815）。
- 原作实际存在组织治理：保密条例、道元班、训练、任务分组、战术、间谍清洗和战场纪律（第15章，L820-L860；第350–351章，L18177-L18218；第798章，L39961-L39986）。
- 原作实际存在后勤与资源管理：津贴、灵石、食物、洗髓果实、城防和休息轮换（第350章，L18193-L18199；第1323–1324章，L65911-L65934）。
- 这些治理与纪律主要作为组织生存和战争手段出现，原文没有把它们自动写成最高价值答案。
- 原作实际存在代价：贫困、抽奖失败、身份压力、战斗受伤、关系离别、战友死亡；但代价并不总是与收益对称，核心系统仍然允许吕树通过群体反应获得大规模资源。
- “成熟”在本书中不等于克制、制度化或牺牲更多；吕树的成长更接近：从只想守住两个人的家，到愿意让更多具体的人进入自己的关系范围。
