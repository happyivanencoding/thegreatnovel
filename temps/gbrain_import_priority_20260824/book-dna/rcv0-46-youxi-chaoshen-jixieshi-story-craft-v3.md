# Core Reader Fantasy

核心幻想不是“穿越者知道百科”，而是：

> 我知道这个世界原本会怎样，所以我能比所有人更早行动；我还能把知识变成装备、任务、势力、玩家和新的世界事实。

具体由五层组成：

1. 从实验体和凡人困境中脱身，获得主动权。[第001—004章，L19-L451]
2. 以玩家经验识别世界规则、隐藏任务、阵营路径和未来事件。[第054—063章，L4100-L4823]
3. 通过机械职业把经验、材料和知识转成武器、机器人、基地与军团。[第089章，L6688-L6766；第320—324章，L21407-L21724]
4. 把玩家从“不可控蝗灾”变成可招募、可消费、可组织的长期力量。[第055—059章，约L4173-L4509；第1270—1271章，L107349-L107571]
5. 让早期投资穿过多个版本继续产生意义，最后从地方角色变成时代和宇宙格局的中心。[第441—442章，L28914-L29081；第1270章，L107349-L107463]

读者想继续读，是因为每一次“我知道未来”都会被主角的行动改写；改写之后，旧知识不再足够，新的地图、敌人、身份和版本又打开下一轮期待。

# Protagonist Desire & Agency

## 欲望

韩萧的欲望分阶段升级：

- 先活下来，拒绝被实验、洗脑和组织控制。[第001—002章，L19-L282]
- 在玩家降临前积累装备、资源、情报和任务额度。[第089章，L6688-L6766]
- 利用未来知识主动破坏萌芽组织，改变海蓝星主线，而不是等待剧情自行发生。[第124章，L9090-L9156]
- 在玩家消失期间维持并扩张黑星军团，把过去版本的收益转成长期实力。[第441—442章，L28914-L29081；第653章，L45514-L45602]
- 在超能阶级与三大文明的冲突中取得破局力量，并把个人力量转成更大的战略筹码。[第1270章，L107349-L107463；第1453—1463章，L125187-L126067]

这不是单纯的“登顶欲”。更稳定的核心是：保持自主、扩大可行动范围、让自己不再被世界事件推着走。

## Agency 机制

反复出现的因果链是：

`未来知识 / 面板信息 → 提前选择节点 → 制造具体行动优势 → 改写局面 → 产生新的未知`

面板本身不会替韩萧行动。他仍然需要材料、金钱、时间、战斗判断、谈判和组织能力；玩家消失后，经验和人力来源明显下降，直接暴露了金手指的边界。[第442章，L29010-L29081；第653章，L45514-L45602]

# Advantage / Power Experience

本书的优势体验由四种力量叠加：

1. **玩家知识**：知道地图、版本、任务、人物成长轨迹和隐藏事件。
2. **面板可见性**：等级、经验、属性、职业、技能、任务、声望、传说度和装备都能即时反馈。
3. **机械转化能力**：把经验和材料转成武器、机甲、机械兽、机器人、基地和舰队。
4. **玩家生态**：玩家提供不死战力、消费、传播、任务执行和社会影响。

机械职业最重要的幻想不是“会造东西”，而是：

> 任何知识都可能被转成新的行动工具；任何行动工具又能扩大下一次行动的范围。

例如，机械师通过知识融合造出弹药、机械兽和探测飞虫，机械能力直接改变侦察、战斗、生产和移动方式。[第089章，L6688-L6766；第443章所在窗口，约L29200之后；第320—324章，L21407-L21724]

# Reader-Facing World Coordinates

本书不是靠单一等级让读者比较世界，而是使用多维、可观察的尺：

- **等级 / 阶位 / 能级**：F、E、D、C、B、A、超A级。
- **战斗阈值**：C级可硬扛小型军队，B级接近灭城或单人荡平飞船，A级达到天灾级。[第324章，L21655-L21724]
- **装备与职业质量**：武器品质、机械数量、技能等级、知识树和装备组合。
- **信息可见度**：玩家侦测时可能得到完整信息，也可能只看到问号和危险等级。[第055章所在窗口，约L4173-L4236]
- **阵营关系**：敌对、中立、友善、军队身份、阵营贡献和声望等级。[第057—059章，L4289-L4509]
- **组织规模**：基地、舰队、干部数量、A级战力、领地和资源网络。[第653章，L45514-L45602；第993章所在窗口，约L78900之后]
- **传说度 / 公众身份**：一个人是否被视为神秘叛徒、星球英雄、军团长或时代核心。[第124章，L9090-L9156；第1270章，L107349-L107463]

因此读者得到的不是一条数值线，而是一张“战力—信息—装备—组织—身份”的坐标图。

# Core Advantage ↔ World Compatibility

适用，且核心优势有清晰边界。

## 真正获得的东西

- 提前知道部分世界事实和事件节点。
- 能读取面板化的能力、任务、关系和资源信息。
- 能把机械知识快速转成装备、基地和部队。
- 能把玩家纳入自己的行动体系。

## 没有替代的东西

- 韩萧不是玩家，不能自然复活，死亡只有一次。[第001章，L19-L117]
- 机械制造仍需要材料、金钱、经验和时间。
- 高阶敌人仍有明确阶位差距，不能靠“知道剧情”直接抹平。
- 未来会因他的干预而变化，旧情报会失效。
- 玩家消失后，任务、经验和军团成长速度都会下降。[第441—442章，L28914-L29081]
- 高层世界仍需要外交、联盟、组织和风险判断；终局的暗面宇宙计划也经过多年筹备，不是一次面板升级完成。[第1458—1463章，L125572-L126067]

本书的金手指服从世界规则，因为它扩大的是“可做什么”，不是“自动得到结果”。

# World Fantasy Ladder

这条梯子不是道德等级，而是读者可感知的空间、力量和问题规模升级。

1. **实验室与城市生存**：逃离萌芽、制造第一件武器。
2. **星球阵营与主线**：六国、萌芽、玩家、星球战争。
3. **公测世界**：玩家大规模降临，NPC社会被迫回应。
4. **星际佣兵与星系地图**：飞船、拾荒者、星际雇佣、星系级文明。
5. **星团战争**：长期秘密战争、代理势力、阵营资源和战略任务。
6. **闪耀世界与跨星域竞争**：新区域开放，旧势力带着既有资产进入新淘金时代。[第992—994章，约L78845-L79132]
7. **超A级与文明秩序**：个人伟力、协会、三大文明、圣所复苏。
8. **世界树与信息态**：战争从领土和舰队上升到文明存在方式与宇宙信息结构。[第1453—1463章，L125187-L126067]

每次升级都保留上一层的角色、资产和关系，因此新地图不是旧地图的替换，而是旧积累的新用法。

# Major Character & Relationship Engines

## 黑星—玩家

起初是NPC与玩家的交易关系：任务、装备、技能、经验。

后来变成长期阵营关系：玩家在黑星军团中获得装备、任务、身份、产品和归属感；老玩家甚至因为多年共同经历而不愿换阵营。[第057—059章，L4289-L4509；第1271章，L107464-L107571]

## 黑星—部下与潜力股

关系通过“识别潜力—针对性培养—成果兑现”加深。黑星不是只给口头承诺，而是安排老师、训练、资源和任务，促成角色真正升级，例如海拉进入超A级、卡罗特获得针对性训练。[第994章，L78990-L79132；第1272章所在窗口]

## 黑星—阵营与旧敌

萌芽组织的敌对关系被固定为不可改善，早期个人行动因此留下长期政治后果。[第124章，L9090-L9156]

后期三大文明、超能协会、超星团和世界树之间的关系不断重排。人物关系不是装饰，而是新的行动权限、敌人反应和世界入口。

## 玩家自身的自主性

玩家并不只是被主角操控。他们会因为奖励、开荒机会、职业偏好、论坛传播、阵营归属和个人荣誉自行选择。[第055—059章，约L4173-L4509；第125—126章，L9157-L9287]

# Payoff Grammar

本书的兑现语法主要有五种：

1. **信息先给局部优势，后变成世界改写**  
   韩萧先知道萌芽基地位置，后来把情报批发给六国，直接改变战争格局。[第089章，L6688-L6766；第124章，L9090-L9156]

2. **早期小道具，后期成为新线索入口**  
   任务道具、隐藏任务和旧事件不一定立即解释，而是在更高地图重新获得价值。[第280章，L19036-L19090；第443章所在窗口]

3. **玩家周期造成延迟回归**  
   玩家消失时，NPC世界继续发展；玩家回归时，旧关系被重新解释，人物和阵营已经变化。[第441—442章，L28914-L29081；第509—510章，L33500-L33696]

4. **身份与传说逐步升级**  
   零号、黑幽灵、黑星不是简单换名，而是同一人物在不同世界尺度上的重新定位。[第124章，L9090-L9156；第1270章，L107349-L107463]

5. **关系兑现为能力与组织成果**  
   对部下的长期投入最终表现为新的A级、超A级、舰队和阵营战力。[第653章，L45514-L45602；第994章，L78990-L79132]

# Repeatable Story Engines

只保留三个：

1. **已知剧情 → 主动介入 → 蝴蝶效应 → 新危机与新机会**
2. **玩家降临 / 消失 / 回归 → NPC世界后台演化 → 旧关系以新规模重返**
3. **职业与阵营投资 → 个人或组织跃迁 → 新地图、新对手、新版本主线**

这三个引擎覆盖了从萌芽组织到世界树、从个人生存到文明级冲突的长篇复利。

# World Expansion Grammar

本书的“不 reset”不是所有东西都永远保留，而是：

> 保留足够多的旧锚点，同时允许部分阵营、基地和任务真正毁灭。

例如，内测玩家投入的暗鸦谷基地在公测前已被摧毁，阵营关系和任务难度随之改变。[第125—126章，L9157-L9287]

但主角保留下来的信息、玩家关系、军团资产和人物成长，会成为下一版本的初始条件：

- 1.0结束：玩家消失，韩萧利用一年空窗期积累军团资产。[第441—442章，L28914-L29081]
- 2.0开启：玩家回到预先布置的避难所，直接接入异化之灾主线。[第509章，L33500-L33583]
- 3.0开启：韩萧提前十年进入秘密战争，并把2.0资产转成舰队、训练营和组织规模。[第653—654章，L45514-L45699]
- 4.0开启：黑星军团已经在闪耀世界拥有领地、关系网和高层战力。[第992—994章，约L78845-L79132]
- 5.0开启：玩家五十年后回归，发现黑星已经成为版本主题和宇宙时代中心。[第1270—1271章，L107349-L107571]
- 终局：旧版本的关系、战争和存在痕迹成为信息锚点，最终参与宇宙层面的转换。[第1458—1463章，L125572-L126067]

# 系统语言的故事承载边界

## 系统语言承载故事时

它会改变：

- 人物下一步能做什么；
- 阵营关系与社会位置；
- 读者对未来事件的期待；
- 版本之间的时间感和世界状态；
- 某个奖励是否改变行动空间。

例如“公测开启”“玩家回归”“版本更新”“主线任务开启”都同时是界面提示和世界事件。[第124—126章，L9090-L9287；第509章，L33500-L33583]

## 系统语言退化为数值时

当任务只提供可替换的经验、金钱或跑环行为，且不改变人物关系、地图状态或后续选择时，就容易退化成运营表格。第059章中韩萧发布荒诞任务、利用经验和好感度牟利，本身就是原作对这种机制的喜剧化展示。[第059章，L4430-L4509]

可迁移原则：

> 系统提示应该是读者看得见的世界变化，而不是把场景改写成任务列表。

# TGN Transfer

## Fantasy Seed

最值得迁移的不是“玩家面板”，而是：

> 主角拥有一种能反复把知识转成行动空间的独特乐趣。

Fantasy Seed 应先明确主角能享受什么具体动作：提前抵达、制造工具、识别隐藏入口、让别人主动来找自己、把一次选择变成长期优势。

不要把核心幻想写成“建立运营系统”或“管理资源网络”。

## World Vision

给读者一把多轴尺：

- 个人强弱；
- 信息掌握程度；
- 能做的动作；
- 装备与职业质量；
- 阵营身份；
- 组织与关系支持；
- 当前世界层级。

新地图必须提供新的可观察阈值，而不是只换一个地名。

## Story Program

采用“版本复利”而非“任务重置”：

`当前欲望 → 当前地图阻力 → 主角介入 → 状态变化 → 旧资产的新用途 → 新地图 / 新对手`

每个大阶段都应回答：上一阶段留下了什么？它如何改变这一阶段的选择？什么旧关系会以新形式回来？

## Outline

大纲最值得借鉴四项：

1. 每个阶段同时写即时目标和长期余波。
2. 明确哪些旧资产、人物、敌意和未知会跨阶段保留。
3. 让一次奖励改变后续行动空间，而不只是增加数值。
4. 在版本或地图切换前安排“主角先行准备、世界后台运行、读者延迟回收”的结构。

# Bias Check

原作实际存在的成本与约束：

- 韩萧不是不死玩家，现实死亡不可逆。[第001章，L19-L117]
- 玩家消失会造成真实的人力和经验损失。[第441—442章，L28914-L29081]
- 制造机械需要经验、材料、金钱、时间和基地。
- 高阶对象仍有明显阶位差距，信息优势不能自动抹平战力差。[第324章，L21655-L21724]
- 阵营、战争和版本更新会造成基地毁灭、任务改变、资源损失和关系重排。[第126章，L9225-L9287]
- 后期确实存在组织管理、训练、物流、避难所容量、文明联盟和战争决策。[第509—510章，L33500-L33696；第653—654章，L45514-L45699]

但这些不是原作默认的“更成熟价值观”。原作同样反复肯定主动搞事、资源收割、阵营竞争、信息压制和个人力量增长。治理在这里主要是维持行动空间的工具；责任和制度并没有被自动提升为故事的最终答案。
