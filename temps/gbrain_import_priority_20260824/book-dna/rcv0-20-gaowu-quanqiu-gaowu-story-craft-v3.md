# Core Reader Fantasy

核心读者幻想不是单纯“主角变成最强者”，而是：

> 一个原本贫穷、普通、缺乏资格的小人物，突然获得一把极易读懂的力量尺；他可以用这把尺确认自己正在变强，并不断取得进入更高世界的资格，最终让家人、朋友、学校、人类世界都因他的强大而获得新的生存空间。

这套幻想有四层叠加：

1. 贫穷和低地位可以被逆转。开篇的报名费、药品和家庭条件直接决定谁有资格尝试武科；方平从普通学生变成达到武大标准的人，变化立即可见。〔第1章，L36-L52；第4章，L325-L356；第14章，L1491-L1505〕

2. 进步不是模糊的“悟道”，而是数字、身体和他人反应同时变化。气血从普通人的尺度上升到武科线、淬骨线、品级线，读者能立即判断方平是否跨过门槛。〔第6章，L593-L676；第6章，L701-L729；第14章，L1494-L1579〕

3. 变强会带来现实资格：入学、导师、资源、任务权限、特殊待遇、组织话语权。方平不是只获得战力，而是不断获得“能进入哪里、能决定什么”的资格。〔第86章，L11556-L11607；第121章，L17397-L17447〕

4. 每次到达高位，都会打开更大的世界，而不是结束故事。校园高武扩展为武大，再扩展为地窟、王城、禁区、三界和种子，但读者仍能沿用气血、精神、品级、榜单、战绩和资源来比较。〔第125章，L18086-L18161；第127章，L18406-L18513；第701章，L138724-L138801〕

# Protagonist Desire & Agency

方平的欲望具有明显的层层升级：

- 早期：不要被贫穷卡死，想尝试武科，想让家人过得更好。〔第7章，L766-L775；第15章，L1659-L1677〕
- 前中期：进入武大、获得知识和资源、提升战力、建立自己的财富来源。〔第74章，L9878-L9892；第90章，L12127-L12157〕
- 中期：不被学校、公司、地窟势力和强者格局限制，主动选择进入更危险的区域。〔第121章，L17457-L17529；第361章，L60845-L60892〕
- 后期：让人类不再被动挨打，报仇、保护熟人和争夺人族的行动空间。〔第989章，L214801-L214862；第1370章，L319881-L319947〕
- 终局：在“保留武道但可能重演灭世”与“灭掉三界、制造无武世界”之间，选择保住当下的亲人、朋友和武道世界。〔第1432章，L338349-L338390；L338440-L338578〕

他的能动性来自三个动作模式：

- 先测算利益：钱、学分、丹药、战力、风险和身份。
- 再主动制造局面：借钱、卖资源、接任务、伪装身份、选择战场、公开夸功。
- 最后把结果转化成新的行动资格：从学生变成武者，从武者变成组织核心，从组织核心变成人族行动者。

他不是等待世界承认，而是经常主动制造“让世界不得不承认”的事实。〔第14章，L1491-L1579；第391章，L66423-L66457；第520章，L93271-L93336〕

# Advantage / Power Experience

方平的核心优势把“财富”转换为“气血”和“精神”，但爽点不止是加数值。

它同时提供四种体验：

1. 立即可感知：气血提升后，身体健康、轻盈、耐力和舒适感直接变化。〔第6章，L701-L718〕

2. 可计算：财富、气血、精神、淬骨、储物空间、能量屏障等都进入同一面板。〔第86章，L11568-L11582；第407章，L69442-L69460〕

3. 可验证：方平的数值会被同学、导师、榜单、对手和公共战果反复验证，而不是只有他自己知道。〔第14章，L1494-L1579；第127章，L18406-L18513〕

4. 可转化为社会结果：强大带来学校照顾、任务权限、导师关注、资源分配、荣誉、组织职位和公共影响力。〔第86章，L11588-L11607；第121章，L17397-L17447；第535章，L96699-L96716〕

重要的是，力量经验始终是：

> 数值增长 → 身体/战斗结果 → 他人重新评价 → 新资格或新敌人 → 下一条更高门槛。

所以读者继续读，不只是为了看“方平又升了几级”，而是为了看这次升级会让谁改变态度、哪扇门打开、哪个敌人被迫重新下注。

# Reader-Facing World Coordinates

本书提供的不是单一等级，而是一组可叠加的可观察坐标：

| 坐标 | 读者如何快速判断 | 会改变什么 |
|---|---|---|
| 财富 | 钱、丹药价格、学分、资源消耗 | 能否报名、修炼、恢复、投资、买情报 |
| 气血/精神 | 卡、赫，以及对应身体表现 | 是否达到武科线、突破线、战斗线 |
| 淬骨与品级 | 淬骨数量、一品至九品 | 身体完整度、可接任务、可进入区域 |
| 战绩 | 击败谁、越级杀敌、是否能活着回来 | 名声、榜单、组织地位 |
| 榜单 | 宗师榜、下三品榜、青年榜、三界风云榜 | 社会共识和竞争位置 |
| 身份/权限 | 学生、武者、导师、社长、部长、人王 | 能接触的任务、资源和决策层 |
| 世界位置 | 学校、地窟、王城、禁区、源地、三界 | 敌人规模、资源密度和生存风险 |

其中最关键的是“数字＋公开结果”的组合。单纯的气血数值会很快失去刺激，但当数值变成录取资格、榜单名次、战斗结果、城市待遇或全世界的欢呼时，数字就重新获得叙事压力。〔第9章，L993-L1024；第14章，L1491-L1579；第127章，L18406-L18513；第701章，L138724-L138801〕

本书也明确承认榜单并不等于绝对真相：有些强者长期在地窟、没有公开战绩，因此排名可能低估真实实力。这样既保留了“榜单爽点”，又避免世界完全变成机械排行榜。〔第127章，L18488-L18521〕

# Core Advantage ↔ World Compatibility

适用，不是 N/A。

## 核心优势真正获得什么

- 将财富和可交易资源转换成身体成长。
- 快速恢复气血、精神和伤势。
- 把资源、物品、战法和身体参数统一到可计算面板。
- 在后期获得气息模拟、能量屏障、本源分析、战法推演和力量转换等功能。〔第6章，L593-L676；第407章，L69452-L69460；第1195章，L270112-L270160〕

## 它没有替代什么

- 没有替代武道知识和训练方法。方平仍需要王金洋、导师、武大、战法课和实战训练。〔第7章，L766-L775；第74章，L9878-L9892；第127章，L18589-L18644〕
- 没有替代战斗经验。社会武者即使数值不高，也可能凭狠劲、经验和临场选择反杀。〔第130章，L18964-L18979〕
- 没有替代世界入口。方平仍要获得武大资格、导师权限、地窟准入和队伍认可。〔第121章，L17397-L17447；第234章，L38073-L38118〕
- 没有替代高层规则。种子、源地、门户和三界生命循环并不会因为方平拥有面板就自动服从他。〔第1396章，L327705-L327748；第1432章，L338297-L338390〕

## 面对高层对象时怎样仍服从世界规则

系统优势会被三个东西限制：

1. 成长有成本和瓶颈。199—200卡、三次淬骨、五品经脉等都需要时间、资源和身体承受力。〔第90章，L12092-L12141；第407章，L69465-L69477〕

2. 高层对象拥有不可被简单扫描或替换的规则地位。阳神和种子可以阻挡方平的探查，方平只能通过谈判、试探和行动逼出信息。〔第1396章，L327705-L327748〕

3. 最终优势变成了新的责任性选择，而不是万能解法。方平吞并三界后，发现没有种子供给，三界生命会逐渐枯萎；他必须继续寻找种子并承担后果。〔第1432章，L338161-L338263〕

# World Fantasy Ladder

| 阶段 | 世界入口 | 读者尺 | 核心幻想 |
|---|---|---|---|
| 普通高中 | 武科报名 | 报名费、气血卡、家庭资源 | 穷人也能尝试跃迁 |
| 武科竞争 | 五大关、录取线 | 政审、体检、气血、文化课、实测 | “我能不能进入这个世界” |
| 武大 | 导师、淬骨、学分、榜单 | 品级、淬骨数、战法、资源 | 入场后还能继续争夺位置 |
| 地窟 | 入口、任务、军部、王城 | 生存、军功、战绩、能源矿 | 武道不是校园游戏，而是人类生存资格 |
| 外域与禁区 | 城池、王境、禁地、复生武者 | 七品、九品、王境、区域势力 | 个人强大开始改变战争地图 |
| 三界 | 天外天、界域之地、源地 | 本源、门户、皇者、道果 | 旧世界的历史和身份重新解释 |
| 终局 | 种子、生命循环、阴阳两界 | 世界是否存在、武道是否延续 | 主角从“改变世界”进入“决定世界形态” |

扩张的关键不是不断增加名词，而是让同一把尺在更大的舞台上重新标定：

- 高中阶段，115卡决定是否有资格考武大。
- 武大阶段，淬骨数量决定导师和资源待遇。
- 地窟阶段，品级和战绩决定能否进入战场、是否能越级杀敌。
- 三界阶段，战绩和身份开始影响整个种族、势力和世界结构。〔第9章，L993-L1024；第86章，L11556-L11607；第234章，L38026-L38118；第407章，L69442-L69476〕

# Major Character & Relationship Engines

## 家庭关系：玩闹、承诺与保护

方平和方圆的关系不是静态“亲情标签”，而是通过捏脸、坑钱、送药、打电话、互相提醒危险持续回流。家庭让财富和力量获得私人意义。〔第7章，L732-L762；第74章，L9775-L9856；第361章，L60833-L60844〕

## 王金洋、李寒松、姚成军：竞争者变成共同战线

几人既比较强弱，又在地窟和终局中互相补位。共同战斗让“谁更强”不断转化成“谁能为团队打开下一条路”。〔第361章，L60845-L60892；第364章，L61350-L61399；第1432章，L338174-L338180〕

## 秦凤青：交易型竞争与喜剧缓冲

秦凤青的资源、债务、矿脉和嘴硬，持续把严肃的力量竞争转成可见的利益谈判。他不是单纯搞笑配角，而是把“资源不够怎么办”变成关系戏。〔第355章，L59803-L59831；第407章，L69480-L69539〕

## 导师与学校：资格门槛制造者

吕凤柔、武大和特训班一方面提供资源，另一方面不断判断学生是否有资格承担更危险的战场。导师不是万能保护者，而是把“想变强”转化为训练、任务和真实风险。〔第121章，L17414-L17450；第129—130章，L18742-L18815；L18915-L18979〕

## 公共群体：名声的放大器

同学、军人、武者、媒体和普通人共同构成反馈系统。方平的战果被夸功、拍成电影、公布于世，个人成长因此转化为社会信心和新的力量。〔第391章，L66423-L66457；第520章，L93296-L93336；第700—701章，L138485-L138801〕

# Payoff Grammar

本书反复使用以下兑现语法：

1. 先给出一个读者能理解的差距：报名线、气血线、淬骨数、榜单名次、品级差。
2. 主角发现差距不能只靠训练解决，于是寻找钱、丹药、导师、任务、战场或关系。
3. 主角做出带风险的选择，通常不是被动接受任务，而是主动选择更有收益的路径。
4. 在公开场合验证结果：考试、擂台、榜单、战役、新闻发布会、全校欢呼。
5. 社会反馈重新定义主角身份：普通学生变天才，学生变社长，武者变人王。
6. 兑现后的新身份立即带来更大敌人和更高门槛。

典型例子：

- 113卡不是孤立数值，而是直接改变同学对方平的判断，并接近武大录取标准。〔第14章，L1491-L1505〕
- 三次淬骨不是“升级提示”，而是身体外观、属性上限、导师选择和未来突破速度一起变化。〔第90章，L12104-L12141〕
- 地窟胜利不仅是杀敌，还要在出口处把战果转成欢呼、军心和人类信心。〔第391章，L66423-L66457〕
- 公开地窟把长期隐藏的战争转成全民可理解的历史证明，主角从特权受益者转成公开说明者。〔第701章，L138724-L138801〕

# Repeatable Story Engines

## 1. 可读门槛 → 资源筹措 → 跨线证明 → 新门槛

这是最核心的长篇发动机。门槛可以是气血、淬骨、品级、榜单、准入权或世界位置，但读者始终知道主角距离它还有多远。〔第9章，L993-L1024；第90章，L12092-L12141；第407章，L69442-L69476〕

## 2. 进入更大场域 → 利用规则差和身份差 → 取得资源/战果 → 重新定义局势

从武大任务到地窟王城、禁区和源地，主角不断进入陌生场域，利用信息、伪装、面板优势和临场胆量取得非对称收益。〔第121章，L17457-L17524；第235章，L38227-L38278；第364章，L61350-L61399〕

## 3. 关系簇回流 → 共同冒险/互相拆台 → 公开兑现 → 关系和组织共同升级

家人、同学、竞争者、导师和学校不会在一个事件后消失，而是带着旧账、新债和新身份回流。个人升级因此持续转化成群体变化。〔第355章，L59803-L59831；第626章，L119602-L119648；第1432章，L338440-L338578〕

# World Expansion Grammar

本书扩世界主要遵循五条语法：

1. 保留旧尺，只增加新坐标。气血、精神、品级、战绩、榜单和资源不会被完全废弃，而是在更高世界重新解释。

2. 通过实际入口扩张，而不是先做百科讲解。地窟先作为武大课程和任务背景出现，随后才变成真实入口、军营和战争现场。〔第125章，L18086-L18161；第234章，L38073-L38118；第235章，L38227-L38278〕

3. 每次扩张都提高“个人选择的后果”，但不抛弃个人欲望。校园里输一场是名次下降，地窟里输一场可能是死亡，三界里输一场可能是世界崩溃。

4. 公开胜利承担世界连接功能。战绩被学校、军部、媒体和全民看到后，个人爽点会转成组织信心和更大的行动空间。〔第520章，L93296-L93336；第700—701章，L138485-L138801〕

5. 终局不是简单数值封顶，而是把早期“财富—力量—资格”的逻辑提升为“生命力—世界—规则”的选择题。方平最终仍以当下的亲人和朋友为选择依据，而不是自动接受所谓更高层的理性答案。〔第1432章，L338297-L338390；L338440-L338578〕

# TGN Transfer

以下是可迁移的结构原则，不是《全球高武》的剧情或 Canon。

## Fantasy Seed

- 先确定一个具体、可感知的核心欲望，再决定能力形式。
- 给读者一把简单尺：它必须能迅速显示“我现在在哪、距离下一扇门还有多远”。
- 能力第一次兑现应同时改变身体/行动和他人反应。
- 不要先把幻想翻译成治理、责任或制度建设；那些只能在原作确实需要时进入。

## World Vision

- 世界入口应当同时提供更大力量、更大机会和更大风险。
- 扩世界时保留旧尺，让读者能比较新旧人物，而不是每次换一套完全陌生的规则。
- 超凡世界应通过物件、战果、门槛、待遇和公共反应被看见，而不是只靠名词说明。
- 核心幻想应从个人跃迁逐步连接到群体和世界，但不要让群体价值自动覆盖个人欲望。

## Story Program

- 每次成长必须改变主角的行动空间、对手策略、关系位置或世界事实。
- 奖励不能只增加数值；要让主角能进入新区域、获得新身份、改变资源流向或逼迫敌人回应。
- 将“门槛—资源—证明—重估—新门槛”作为主循环，但改变阻力类型：贫穷、竞争、权限、战场、身份、历史和世界规则轮换出现。
- 不要把任务系统本身当成长篇发动机；任务只有在改变关系、战局或主角选择时才值得保留。

## Outline

- 每个大阶段至少固定一个旧坐标和一个新坐标。
- 安排“公开证明”作为阶段性兑现点，让读者看到世界如何重新评价主角。
- 让旧关系跨阶段回流，承担情绪兑现、竞争升级和信息重释。
- 高层世界不要一次性解释完；每次只开放足够支撑当前选择的新规则。
- 终局应把早期核心欲望重新放到世界级选择中检验，而不是用抽象的成熟答案替换它。

# Bias Check

原作确实存在以下成本、责任与治理结构，但它们不是本次蒸馏中被自动判定为“更成熟答案”的主轴：

- **资源成本**：报名费、药品、丹药、能源、学分和公司资金直接决定成长速度。〔第4章，L325-L356；第9章，L1017-L1024；第119章，L17081-L17133〕
- **阶层差异**：城市、家庭财富和武道资源分配造成明显的起点差异。〔第八章，L875-L880；第九章，L1017-L1024〕
- **身体与死亡成本**：淬骨、内腑、颅骨、战场伤势和死亡都是真实后果，不是抽象扣血。〔第90章，L12104-L12141；第234章，L38043-L38065；第391章，L66381-L66457〕
- **责任叙事**：老校长、军部和武大确实把武者定义为承担地窟战争的人。〔第234章，L38026-L38035〕
- **治理结构**：政府、军部、武大、侦缉局、任务系统、榜单和公开发布会共同分配资源、权限和信息。〔第121章，L17397-L17447；第127章，L18416-L18458；第701章，L138724-L138801〕
- **社会反馈与公共引导**：政府会延迟公开战争信息，通过电影、榜单、勋章和发布会塑造全民认知。〔第391章，L66423-L66457；第520章，L93296-L93336；第700—701章，L138485-L138801〕

但本次样本不能推出“治理、克制、责任、制度建设就是更高级答案”。原作的主要阅读驱动力仍是：力量变得可读、主角跨过门槛、公开证明成功、获得更大行动空间，并继续进入更高世界。终局甚至明确保留了方平对当下亲友和私人复仇的选择，而不是让他自动服从抽象的长期最优解。〔第1432章，L338367-L338390〕
