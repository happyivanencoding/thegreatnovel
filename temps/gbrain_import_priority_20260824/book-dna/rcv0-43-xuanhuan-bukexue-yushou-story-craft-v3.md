# Core Reader Fantasy

本书的核心幻想是：

> 一个原本缺钱、体弱、只想过轻松生活的人，凭借一个能把“看见过的能力”转化为宠兽成长的优势，把低估、弱小、普通甚至非战斗型宠兽，逐步培养成有名字、有战术、有身份、有公共影响力的强者队伍。

世界本身允许每种生物进化，御兽空间能加速成长，御兽师又掌握技能、资源和契约，因此“宠兽成长”天然能够连接战斗、职业、财富、考古、比赛和世界扩张，而不是另造一套外部系统【第1章，L51–70】。

读者想继续读，主要因为：

1. 每次能力获得都能很快变成可见结果：硬化从局部防御变成全身武装，战斗力立刻改变【第13章，L1290–1317】。
2. 每只新宠兽都带来新的玩法，而不是单纯增加战力：十一偏正面战斗，虫虫偏空间、幻术和进化潜力，参宝宝偏恢复、补品与续航【第136–139章，L18371–18846】。
3. 旧成果会在更大舞台上重新定价：地方比赛成绩变成全国身份，普通青绵虫研究变成改变御兽生态的成果【第132章，L17767–17879；第211章，L31393–31535】。
4. 资源与身份兑现较早，读者很快看见“变强有什么用”，不会长期停留在抽象积累。
5. 高强度成长被训练、吐槽、比赛名场面和宠兽反应包住，整体保持轻快。

# Protagonist Desire & Agency

时宇的欲望不是固定不变的。

- 开始阶段，他想成为御兽师，也想避免前世考古经历带来的危险，倾向于“赚点钱、养宠兽、过安全生活”【第1章，L79–92；第30章，L2866–2873】。
- 获得技能图鉴后，实力和自由成为优先目标；当金钱与力量冲突时，他多次选择先提升战力【第29章，L2703–2708】。
- 他不是被动接受机缘，而是主动选择宠兽、技能、进化路线和比赛舞台：例如在多只稀有植物宠兽中，按自身“加点消耗、御兽空间承载、恢复能力”选择参宝宝【第133章，L17999–18033】。
- 他会主动把能力转成社会机会：参加职业考核、全国大赛、研究成果展示，并利用奖励继续培养队伍【第132章，L17873–17879；第266章，L41689–41717】。
- 终局欲望从个人变强扩大为让更多人获得御兽羁绊，但这是在长期个人成长与伙伴关系完成后才出现的实际愿望，不是开篇预设的价值观【第709章，L130625–130640】。

# Advantage / Power Experience

技能图鉴真正提供的是“技能知识与快速教学”，不是无条件战力。

它可以：

- 复制超凡生物的能力；
- 将已收录能力教学给非人类超凡生物；
- 通过重复教学提升技能熟练度【第2章，L140–167】。

读者看到的力量体验主要来自四层：

1. 熟练度跃迁：一次教学让宠兽获得原本需要长期训练的技能阶段【第13章，L1290–1317】。
2. 技能组合：硬化、倍化、超视力、雷掌、绝对睡眠、威慑等互相组合，形成超出单项技能的战术【第132章，L17789–17795】。
3. 宠兽个体化：同样是加点，不同宠兽会长出不同路线；参宝宝甚至从“没有攻击技能的补品型宠兽”变成可辅助战斗的队伍成员【第136–137章，L18395–18402；L18591–18687】。
4. 集体反馈：终局时，时宇可以同时强化多只宠兽，但代价是体力快速消耗【第700章，L129701–129723】。

实际限制包括：

- 复制需亲眼看到、身体接触，并在一小时内完成；
- 教学消耗体力，且要求目标有契合度；
- 有冷却时间；
- 技能页面有限；
- 高阶技能不能随意教学；
- 不能凭空创造宇宙级生命或宇宙级种族，后期突破仍依赖血脉、资源、外部传承和伙伴协助【第2章，L143–150；第134章，L18040–18063；第681章，L126529–126535】。

所以它与世界规则兼容：世界本来就以技能、培育、进化、契约和资源作为强弱基础，技能图鉴只是把“知识积累”极端加速，并没有替代宠兽、御兽空间、进化材料、比赛资格或世界层级。

# Reader-Facing World Coordinates

本书给读者的“尺”不是单一等级，而是多个可观察阈值叠加。

| 坐标 | 读者观察什么 | 直接后果 |
|---|---|---|
| 成长等级 | 觉醒、超凡、统领、君王、霸主、神话 | 基础能量与可进入的战斗层级 |
| 种族等级 | 宠兽的潜力上限 | 决定同成长等级下的上限 |
| 技能熟练度 | 入门、熟练、精通、完美、出神入化、技进乎道 | 决定技能是否出现质变 |
| 能量值 | 宠兽的可量化战力 | 可直接比较同级宠兽；例如统领级剑灵18万对比龙宫城三太子16万【第266章，L41660–41667】 |
| 御兽师职业 | 见习、职业、大师、传奇 | 决定资格、资源、组织地位和世界入口【第60章，L2773–2777】 |
| 实战证明 | 越级挑战、1对多、比赛排名、遗迹通关 | 可以在等级不足时证明真实战力【第25章，L2351–2379；第60章，L6031–6065】 |
| 公共身份 | 考核状元、研究负责人、冠军、世界传奇 | 把个人能力转化成资源、声望和更大舞台 |
| 关系与组织 | 十一局、大学、协会、研究团队、世界树联盟 | 决定能接触什么遗迹、资源和对手 |

因此读者比较强弱时，通常会问：

> 你是什么成长等级？种族潜力如何？技能练到哪一步？能不能越级？打过谁？拿到什么资格？下一层资源从哪里来？

# Core Advantage ↔ World Compatibility

技能图鉴真正获得：

- 技能复制权；
- 技能教学权；
- 熟练度加速；
- 对宠兽成长路线的规划优势；
- 通过能力组合制造新战术的机会。

它没有替代：

- 宠兽本身的种族潜力；
- 宠兽契约与队伍容量；
- 进化资源；
- 御兽空间；
- 体力、冷却和身体承受力；
- 遗迹进入资格；
- 比赛和组织身份；
- 高层世界中的血脉、规则、神话资源。

高层对象仍服从世界规则：即使技能图鉴和时宇已经极强，也无法凭空制造宇宙级生命；虫虫进入宇宙级，仍依赖异虫女王血脉、青龙血脉和新的技能推演【第681章，L126066–126085；第681章，L126529–126535】。

# World Fantasy Ladder

1. **普通生活与宠兽饲养**：实习饲养员、贷款、补品、初始宠兽。
2. **职业跃迁**：职业考核、越级挑战、职业证书、城市协会资源。
3. **大学与专业世界**：对战社、考古系、饲育研究、校队与全国大赛。
4. **城市与国家层级**：兽潮、守护神、国家组织、禁忌武器、城市经济。
5. **历史与图腾层级**：神话时代、图腾时代、御兽时代的断层；遗迹成为进入更高世界的入口【第27章，L2530–2553】。
6. **世界树与世界赛**：世界树祝福、七国与图腾国竞争、世界传奇称号【第295章，L46770–46790】。
7. **神话传承层级**：神话生物苏醒，以属性限定试炼和神话级资源筛选继承者【第432章，L78212–78272】。
8. **宇宙层级**：平行宇宙、宇宙级、宇宙霸主、宇宙维系者；宠兽的社会影响也从个人战斗扩展到梦境网络、军团、星球和文明【第704章，L129930–130013；第708–709章，L130557–130640】。

升级不是单纯“地图变大”，而是每一层都提供新的比较方式、资源和关系入口。

# Major Character & Relationship Engines

- **十一：自律与自我证明。** 它不接受“免费获得成长”，即使技能被加点，也会主动训练补回努力成本【第13章，L1334–1342】。它从被挑剩的食铁兽成长为队伍核心和种族象征。
- **虫虫：弱小种族的远大梦想。** 青绵虫初始战力极弱，但通过结茧、进化和技能组合获得一次次身份翻转；它的进化不是换皮，而是改变读者对“弱小宠兽”的判断【第164章，L22912–23094】。
- **参宝宝：辅助位争夺主体性。** 它没有攻击技能，却通过恢复、补品、时间果实和生命能力成为全队不可替代的资源核心，并不断要求证明自己不是“只会供给的补品”【第136–139章，L18371–18402；L18651–18687】。
- **赤瞳：关系与代价的情绪锚点。** 它在契约宇宙时替时宇承受时空震荡并消散，之后又被时宇复活；这让终局力量获得不只是战力展示，也有关系兑现【第708章，L130460–130488；第709章，L130500–130515】。
- **队伍关系：差异化角色＋队内竞争。** 每只宠兽有独立定位、成长欲望和队内位置，但都通过时宇的能力转化为下一次战斗或探索选择，而不是各自发展成无关支线。
- **终局回收：个体成长变成世界功能。** 十万年后，十一成为宇宙霸主与战斗民族象征，虫虫构筑梦境宇宙网络，参宝宝改变补品种族命运，凛成为科技与舰队供应者【第709章，L130557–130589】。

# Payoff Grammar

本书反复使用以下兑现顺序：

1. 先给一个具体异常：技能、宠兽、遗迹、进化材料或比赛资格。
2. 立即做可见测试：训练、对战、通关、展示或公开比赛。
3. 产生短线结果：技能质变、排名、奖金、资源、声望或身份。
4. 用结果解决下一个瓶颈：补品、御兽空间、进化材料、研究条件或新宠兽。
5. 把旧成果放进更大舞台重新估值。
6. 继续扩大世界坐标。

例如：

- 硬化加点 → 战斗力跃迁【第13章，L1290–1317】；
- 遗迹通关 → 空灵石 → 御兽空间升级【第60章，L6031–6111】；
- 职业考核 → 身份、奖励与全国大赛资格【第132章，L17767–17879】；
- 青虫茧研究 → 低门槛高价值进化路线 → 改变全民御兽预期【第211章，L31438–31535】；
- 世界赛神话试炼 → 神话级资源与更高世界入口【第432章，L78267–78272】。

# Repeatable Story Engines

1. **技能教学 → 实战验证 → 公开证明 → 资源再投资**

   重点不是“获得技能”，而是技能马上改变战斗和资格，再把奖励转成下一次成长。

2. **遗迹探索 → 历史揭示 → 试炼通关 → 稀有资源/身份**

   遗迹不是静态背景，而是同时提供谜团、危险、战斗、资源和世界入口。

3. **新宠兽入队 → 队内位置危机 → 专属成长路线 → 协同战术**

   新成员先产生关系和定位冲突，再通过独有能力找到不可替代的位置。

# World Expansion Grammar

- **从可触摸对象进入世界**：石像、宠兽、技能、比赛奖励、遗迹传送门先出现，世界历史和高层规则随后从行动结果中展开【第28章，L2683–2699；第30章，L2848–2865】。
- **横向扩展靠新角色功能**：植物、死灵、机械、龙族、空间系等，不只是新增名词，而是新增战术、资源或职业入口。
- **纵向扩展靠重新定价**：地方冠军后来成为全国、世界乃至宇宙级坐标；普通青绵虫研究后来可以成为国家级生态成果。
- **旧能力反复换场景**：技能图鉴早期用于硬化和治愈，后期用于血脉、规则和宇宙级宠兽，但每次都受新层级的材料、体力和契约约束。
- **世界奇观服务于主角关系与成长**：遗迹、雪山、世界树、宇宙不是百科展示，而是为宠兽进化、伙伴关系、比赛和下一次选择提供压力。

# TGN Transfer：Fantasy Seed

最有价值的迁移原则：

> 先确定一个能被读者立即感知的核心幻想兑现，例如“弱小对象被培养成不可替代的强者”，再让资源、身份、关系和世界扩展服务于它。

不要从治理、责任或完整系统开始。应先回答：

- 读者最想看到谁变强？
- 变强后具体改变了什么行动空间？
- 早期怎样在一个短场景或短事件中兑现一次？

# TGN Transfer：World Vision

最有价值的迁移原则：

> 世界必须给读者一把可用的尺：等级、能力熟练度、比赛资格、资源稀缺度、身份门槛和实战证明至少要有几项可观察坐标。

世界入口应通过具体对象进入：

- 一个被发现的遗迹；
- 一个可争夺的比赛；
- 一种改变宠兽上限的资源；
- 一个能带来更高资格的组织；
- 一项被公众验证的成果。

# TGN Transfer：Story Program

最有价值的迁移原则：

> 多对象成长不失焦的关键，不是减少对象，而是让每个对象拥有不同的欲望、能力和兑现方式，同时把它们汇入主角下一次可执行选择。

可迁移结构：

- 战斗型对象负责正面证明；
- 辅助型对象负责续航与资源；
- 探索型对象负责世界入口；
- 关系型对象负责情绪与长期承诺；
- 所有对象最终都改变主角的行动空间。

# TGN Transfer：Outline

最有价值的迁移原则：

> 每个阶段都应安排“能力/资源/身份/关系 → 可见结果”的转化；短线早兑现，中线做成长和进化，长线再做历史、世界或宇宙级重释。

大纲中应重点安排：

- 一个早期可验证的成长跃迁；
- 一个把成长转成公共身份的比赛或展示；
- 一个把探索转成稀有资源和新世界入口的遗迹；
- 一个让旧能力在更高层重新变强的回收点；
- 一个让多对象各自获得长期位置的终局兑现。

# Bias Check

原作实际存在的成本、责任和治理因素：

- 御兽师掌握社会核心岗位，普通人与高级御兽师之间存在明显阶层差异；派系、国家和组织竞争真实存在【第25章，L2331–2347】。
- 时宇会隐藏技能图鉴、参宝宝等能力，因为过度暴露可能引来组织和异族敌视【第260章，L40618–40624】。
- 遗迹探索有真实危险，时宇需要大师级保镖、准备路线和控制进入条件【第132章，L17832–17848；第138章，L18797–18804】。
- 比赛、协会、世界树试炼都有资格、属性和规则限制，不是所有力量都能无条件使用【第25章，L2371–2379；第432章，L78267–78272】。
- 终局成为宇宙维系者后，时宇实际承担修复宇宙、处理宇宙规则的责任【第709章，L130507–130513】。

但这些并没有被原作自动提升为“力量越大越应治理”“克制才是成熟答案”的主轴。主驱动仍然是成长、伙伴、奇观、竞争、资源兑现与更高世界入口。
