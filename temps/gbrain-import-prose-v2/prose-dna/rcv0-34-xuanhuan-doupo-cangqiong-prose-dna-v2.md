## Evidence Basis

本卡只重组既有 v1 证据，不新增原作事实，不重读原著。

- 书籍：`rcv0-34-xuanhuan-doupo-cangqiong`
- `source_id`：`book-01-3a7bba21`
- `distill_id`：`distill_9d04e2edf8949c652e0cd257`
- 直接使用：14 个 bounded scene windows，覆盖早期 W01–W05、中期 W06–W10、后期 W11–W14。
- 场景族：ENTRY、DIALOGUE、PAYOFF、ACTION、DISCOVERY、EXPOSITION、ORDINARY、EMOTION。
- v1 总报告中的 85 个 canonical scene windows 是整个 Prose Craft corpus 的总量；本书现有证据卡实际提供并逐窗描述的是上述 14 个窗口。
- 未进行全文句长、词频、段落长度或感官密度统计。

## Cross-Scene Invariants

1. 文本优先选择会改变当前判断、资格、关系或行动权的内容；细节必须让这种变化可见，而不是单纯增加质感。  
   证据：W01、W02、W05、W06、W08、W09、W12。

2. 抽象的身份、实力、名誉和世界尺度，通常需要由身体、物件、距离、制度结果或旁观者反应承接。  
   证据：W03、W04、W07、W09、W10、W13。

3. 信息只解释到当前选择能够成立的程度；来源、完整原理、完整计划或最终关系判断可以暂时留白，但空间关系和即时结果不能模糊。  
   证据：W05、W08、W09、W12。

4. 重大公共或世界级结果之后，文本会把尺度压回身体、家庭、朋友或生活动作，使胜利转化为人物实际获得的生活权利。  
   证据：W11、W13、W14。

## Attention DNA

### Core Selection Strategy

注意力集中在“状态尚未确定、且即将改变”的位置：

- 公开质疑、资格门槛、身份轻视或失败结论；
- 使判断不可逆的物件、伤势、动作或制度结果；
- 能改变敌我位置、关系站位或下一步行动的反应；
- 高潮中的尺度变化与代价。

细节优先级通常是：

`改变判断的事实 → 身体承受或动作结果 → 外部确认 → 少量空间锚点`

不是每场都需要完整经过这四层。

### Scene-Conditioned Behavior

- `ENTRY / OPENING`：先给公开结果、站位、目标或正在发生的关系压力，再补当前判断所需的历史。W01、W02。
- `DIALOGUE / STATUS`：把字数给正在重定价的期限、名誉、资格、行动权和关系位置；无状态变化的复述被压缩。W02、W08。
- `ACTION / DUEL`：把注意力给方向、距离、接触、失衡和结果，而不是招式名或视觉特效。W04、W10。
- `PAYOFF / PUBLIC_PROOF`：先让旧判断和可证伪标准成立，再用最短的可见结果击穿它，最后给外部反应和新身份／资源后果。W03、W06、W09、W10。
- `DISCOVERY / REVEAL`：保留尚未兑现的入口，同时选择秘密、合作风险、尾随或具体异常物，推动下一步行动。W05。
- `CLIMAX`：注意力随能力升级转移到敌方状态、身体代价、环境尺度和封印／结果状态。W07、W13。
- `AFTERMATH / ENDING`：宏观后果只需压缩到足够说明局势；随后把注意力交给一个私人动作或生活摩擦。W11、W14。

### Compression / Omission Boundary

可以压缩：

- 已经被读者和场面共同确认的背景；
- 群众的重复反应；
- 完整招式库、完整考试过程、全部行政安排；
- 所有配角的后续归宿；
- 不改变当前判断的环境陈设。

不能压缩：

- 当前目标和阻碍；
- 关键动作的空间因果；
- 使承诺不可撤回的物件或行为；
- 公开证明的可验证结果；
- 代价如何影响人物或下一步；
- 结论改变后谁获得了什么行动权。

W06 将考核过程留在门后，但保留资格、制度边界和资源后果；W04 则不能省略推、吸、反推造成的空间变化。

### Evidence / Anti-Evidence

正证据：

- W03：一次清楚的身体结果足以完成公开验证，不继续追加同类证明。
- W07：只保留关键伤势、撤离反应和远处环境破坏。
- W14：不逐一解释所有人物关系，只保留能改变余味的几个动作。

反证与限制：

- W12 的终局规则需要比普通场景更多说明，因为角色必须据此作出选择。
- `ORDINARY` 低压场景的细节证据只有 W11、W14，不能推断全书始终保持同等私人密度。
- INSUFFICIENT：无法据现有窗口判断全书章节中注意力分配的稳定比例。

## Knowledge DNA

### Core Selection Strategy

知识进入文本的顺序通常是：

`可见现场 → 局部反应或错误判断 → 当前选择所需规则 → 新行动出口`

叙述者不负责一次性展示完整世界知识，而是让人物在必须判断时获得足够信息。

### Scene-Conditioned Behavior

- `ENTRY`：先让读者知道“正在发生什么”，再解释它为什么具有社会压力。W01、W02。
- `ACTION`：必须先保证谁在哪里、力量朝哪里、身体发生什么是可理解的；技能等级和名称可以晚于动作。W04、W10、W13。
- `IDENTITY REVEAL`：先亮出可验证的能力或物件，再让旁观者推断身份价值。W08。
- `RULE EXPOSITION`：解释由当前死局、资格或风险逼出；答案出现后必须改变下一选择。W06、W12。
- `AFTERMATH`：世界局势可以用概括句压缩，进入人物关系后不再继续补设定。W11、W14。

### Compression / Omission Boundary

暂时不提供：

- 完整力量来源；
- 陌生势力的全部计划；
- 未揭身份的全部历史；
- 规则的完整世界史；
- 关系的最终情绪裁定；
- 所有旁观者的具体心理。

必须提供：

- 当前行动目标；
- 空间和物件关系；
- 直接结果；
- 角色作出下一选择所需的局部规则。

“留白”只能延迟意义，不能遮蔽动作本身。

### Evidence / Anti-Evidence

正证据：

- W05 不揭开全部探宝内容和潜在威胁，只给出秘密、营地、黑影和夜间行动。
- W08 不当场揭开完整身份与旧怨，而让能力证据先改变礼节和治疗权。
- W12 只解释能够使终局选择成立的规则。

反证与限制：

- W12 表明文本并非一律少解释；当规则直接决定生死选择时，解释可以展开。
- W06 表明制度规则需要说到资源路径成立的程度。
- INSUFFICIENT：现有证据不足以判断叙述者是否存在稳定、全书统一的知识边界或 POV 分配。

## Causal DNA

### Core Selection Strategy

因果解释通常停在“读者能够复原状态变化”的粒度：

`目标／门槛 → 位置或限制 → 动作／判断 → 接触或物证 → 身体／环境结果 → 外部反应 → 新选择`

解释不是为了完整介绍机制，而是为了证明为什么当前状态已经改变。

### Scene-Conditioned Behavior

- `ACTION`：优先交代目标、站位、距离、方向、接触点和失衡结果。W04、W10、W13。
- `POWER CREATION`：能力形成要同时呈现意图、过程中的风险和可见代价。W07。
- `PUBLIC PROOF`：先建立具体质疑，再提供可证伪标准，最后由物证或制度结果完成验证。W03、W06、W09。
- `DIALOGUE / NEGOTIATION`：对白的因果不是“说了更多”，而是每轮改变期限、资格、名誉成本或行动权。W02、W08。
- `EXPOSITION`：只解释当前规则如何打开、关闭或改变下一步路径。W06、W12。
- `AFTERMATH`：把宏大结果因果化为人物能回家、相认、调养、饮酒或继续生活的具体状态。W11、W14。

### Compression / Omission Boundary

可省略：

- 完整训练史；
- 全部技能原理；
- 观众对每个细节的解释；
- 已经由动作结果证明的能力判断。

不可省略：

- 谁对谁施加了什么；
- 力量或物件如何到达目标；
- 结果改变了谁的位置；
- 代价是否真实发生；
- 结果如何导向下一选择。

因此，“少解释”只适用于不影响当前因果的部分；若缺少局部解释会使行动无法复原，则不能省略。

### Evidence / Anti-Evidence

正证据：

- W04 的推、吸、反推使动作路线可以被复原。
- W09 的物件轨迹先完成反转，再补充其来源。
- W12 的规则说明结束后立即转化为终局选择。

反证与限制：

- W03 的公开证明不需要完整解释能力原理，因为身体结果已足够。
- W13 的宏大能力仍保留离体、归位、碰撞、反噬和封印等关键因果。
- INSUFFICIENT：未做全文因果链统计，不能推断所有战斗或所有规则说明都采用同样粒度。

## Reaction DNA

### Core Selection Strategy

人物状态通常不直接宣布，而通过具有立场差异的反应链泄露：

`状态改变 → 对手或承受者先反应 → 权威／旁观者重新估值 → 关系人物显示私人后果`

反应必须说明“谁受到什么影响”，而不是统一制造情绪声量。

### Scene-Conditioned Behavior

- `ENTRY`：用站位、追步、停顿、咽唾沫和目光变化表现社会孤立或关系支持。W01。
- `NEGOTIATION`：让物件处置和身体失控承接无法撤回的决定。W02、W08。
- `PAYOFF`：对手先出现不安、强撑、后退或失态，随后权威和群众改口。W03、W06、W09。
- `ACTION`：反应插入决定性结果之间，作为威力标尺，但不替代动作。W04、W07、W10、W13。
- `AFTERMATH`：通过抱怨、握拳、笑泪、饮酒、转身、咬唇等生活动作完成关系余波。W11、W14。

### Compression / Omission Boundary

应保留：

- 至少一个直接承受结果的人；
- 至少一个代表社会或制度判断的人；
- 关系场景中的一个私人反应；
- 与当前结果不同步的反应，例如先强撑、后改口或先松气再失态。

可以压缩：

- 同质化群众反应；
- 每个旁观者的独立心理；
- 已经被前一反应充分确认的重复惊讶。

### Evidence / Anti-Evidence

正证据：

- W03 以挑战者、长老、父亲和旧相识的不同反应完成多层确认。
- W08 以轻视、后退、礼节转变和治疗选择显示身份变化。
- W11、W14 以家庭或朋友间的小摩擦替代总结式情绪宣告。

反证与限制：

- 并非每个动作都需要反应链；短促攻击可以只保留结果。
- `ORDINARY` 的低压反应样本有限。
- INSUFFICIENT：无法判断全书是否存在固定的反应顺序或固定数量。

## Rhythm DNA

### Core Selection Strategy

节奏由 scene beat 和 state change 决定，而不是由固定的长短句比例决定。

- 条件、观察、多人位置、拖延和计算尚未结束时，允许展开句与较长段落。
- 命令、拒绝、命中、物证出现、身份改判或身体结果落地时，压缩到短促句段。
- 一轮动作或一轮对白完成后，给出反应和压力转移。
- 结果之后重新放长，让伤势、沉默、规模或关系重估被承受。

### Scene-Conditioned Behavior

- `DIALOGUE`：以“条件—反驳—权威／物件介入—新条件”推进，不采用平均轮流发言。W02、W08。
- `ACTION`：一段通常承载一轮可追踪攻防；关键命中或失衡单独留拍。W04、W10。
- `POWER CREATION / CLIMAX`：每次靠近临界、受伤、成形、投出或封印都改变节拍。W07、W13。
- `PAYOFF`：先延长失败结论或公众悬念，再用一个截断点进入反转，随后逐镜确认物证。W09。
- `AFTERMATH`：宏观总结可以压缩，家庭、朋友和关系场景重新放慢。W11、W14。

### Compression / Omission Boundary

不能把所有句子切成短句，也不能让所有结果都埋在长段中。

- 短句承担“状态已经改变”，不是单纯制造紧张。
- 长句承担“条件仍在计算”，不是单纯制造宏大。
- 低压生活段不应被强制切成战斗式节拍。
- 已经清楚的微动作不需要为了节奏人为拆分。

### Evidence / Anti-Evidence

正证据：

- W02 在平稳解释、累积陈词和血印落定之间改变句段速度。
- W09 以单独的打断切断失败结论，再逐步展开物证轨迹。
- W13 在召唤、碰撞、封印和拥抱之间反复升高与降速。

反证与限制：

- 没有可靠句长统计；结论只关于句子功能。
- W11、W14 说明低压余波允许更松的句段。
- INSUFFICIENT：不能推出全书平均节拍或固定段落长度。

## Lexical DNA

### Core Selection Strategy

词汇选择随叙事功能变化，而不是形成固定词表：

- 制度、等级、资格、资源词：说明社会价值；
- 身体、位置、材质、方向词：让价值落地；
- 动作动词：显示受力、移动、接触与结果；
- 规则、限制、例外、资格词：围绕当前选择组织解释；
- 日常物件与身体动作：把高潮结果转译为关系和生活后果。

判断方式也随场景变化：公共判断常由旁观者、制度持有人或对手说出；主角往往用保守回答、沉默或行动让别人替其放大价值。

### Scene-Conditioned Behavior

- `STATUS / PUBLIC PROOF`：抽象社会判断词与具体身体结果并置。W01、W03、W06。
- `ACTION`：方向性动词、身体部位、距离和材质承担主要信息。W04、W07、W10、W13。
- `DISCOVERY`：具体地形、营地、守卫、物件与行动风险共同出现。W05。
- `EXPOSITION`：规则词围绕限制、例外、存活、资格和当前物件展开。W12。
- `EMOTION / AFTERMATH`：词汇尺度从世界、制度和力量转向家庭、朋友、酒、身体、目光和停顿。W11、W14。

### Compression / Omission Boundary

应压缩：

- 只提供氛围、不改变尺度或风险的形容词；
- 连续技能名；
- 重复的社会评价；
- 没有具体对象承载的抽象情绪判断。

不能压缩：

- 能标记制度门槛或关系位置的词；
- 能说明方向、距离、接触和材质的词；
- 能让规则限制成立的关键名词；
- 能把世界结果转为身体或生活结果的词。

不得将专属体系、人物称呼、能力名称、固定比喻或原句迁移为通用词汇规则，也不建立禁词表。

### Evidence / Anti-Evidence

正证据：

- W03 以“一步、肩、倒地”承接公开实力判断。
- W06 以资格、特权、门和手部反应承接制度价值。
- W13 在最大规模的场面中仍回到破体、咳血、火茧等结果性词汇。
- W14 将世界级结算切换到朋友、酒、转身和咬唇。

反证与限制：

- 词汇尺度会随 scene family 改变，不能把“制度词＋身体词”理解成每句固定配对。
- 没有词频统计，不能判断任何词的全书频率。
- INSUFFICIENT：无法据现有证据建立稳定的词类比例或词汇密度模型。

## Detail Selection Across Dimensions

| 细节类型 | 进入文本的条件 | 承担的 story function | 删除后会失去什么 | 证据 |
|---|---|---|---|---|
| Story-bearing 事实 | 它改变目标、资格、期限、身份、资源或失败判断 | 让读者知道局势为何已经不同 | 因果、payoff 或行动门槛 | W02、W03、W06、W09 |
| 空间／动作细节 | 读者需要复原谁在哪里、力量如何到达目标 | 让战斗、逃离、接近或回收可视化 | 因果与身体尺度 | W04、W07、W10、W13 |
| Embodied 细节 | 抽象状态已经临界，或关系需要落到身体 | 显示疼痛、压力、羞辱、亲密、疲惫或代价 | 身体感、关系真实性与代价 | W01、W02、W08、W11、W14 |
| 外部反应细节 | 个人结果必须成为社会事实 | 让身份、实力或名誉获得外部确认 | 公共 payoff 与社会尺度 | W03、W06、W09、W13 |
| 物件处置 | 承诺、证据或选择需要变得不可撤回 | 将抽象决定转化为血印、资格、药物、封印或资源入口 | 不可逆性与下一行动 | W02、W06、W09、W13 |
| Atmospheric 细节 | 需要标记压力、尺度、转场或临界节点 | 固定广场、夜行、爆发、雾散或余波的空间感 | 尺度、节拍或压力边界 | W01、W05、W07、W09 |
| Ordinary friction | 高潮需要回到生活，或关系需要显露私人尺度 | 把胜利、伤口和权力转译为可继续生活的状态 | 人物身份、关系余波和生活后果 | W11、W14 |

选择顺序不是“每类都放一点”，而是：

1. 先确定读者必须重新判断什么；
2. 选择一个能证明判断变化的事实、物件或空间关系；
3. 必要时用一个身体反应固定代价或关系；
4. 只有在尺度、压力或转场确实变化时才加入环境细节；
5. payoff 或终局之后，用一个私人动作完成生活尺度转换。

## Production Implications

1. Curator 应先依据 `scene family + pressure + current state change` 选择细节优先级，而不是调用统一的“丰富描写”模式；仅在当前场景缺少必要读数时选择细节，否则可以不添加。

2. 对 `ACTION` 场景，Curator 应在当前场景缺少相应读数时，编译“目标—站位／距离—接触或方向—身体／环境结果”中的必要承重链，再决定是否加入能力名称或感官锚点。

3. 对 `PUBLIC_PROOF` 与身份翻转，Curator 应先保留具体旧判断或可证伪门槛；仅当当前场景缺少结果成立或影响落地的读数时，才配置必要的物证、对手变化、权威判断或资源后果。

4. 对 `DISCOVERY` 与 `EXPOSITION_RULE`，Curator 应优先编译可观察异常和当前风险，只解释会改变下一选择的规则；未知仅在当前场景缺少会影响风险判断的必要边界时保留。

5. 对 `AFTERMATH` 与 `EMOTION`，Curator 应把宏观结果压缩为必要背景；仅当当前场景缺少关系距离、生活权利或私人尺度变化的读数时，才选择必要的身体动作、物件或小摩擦。

## Limits / Insufficient Evidence

- 本书直接证据卡提供的是 14 个 bounded windows，不是对全文所有场景的统计。
- 早中晚均覆盖，但后期窗口集中于终局与余波；普通生活、长期对白和低压探索证据较少。
- `PAYOFF` 与 `ACTION` 窗口占比较高，因此公开证明、空间动作和高潮代价的结论强于日常节奏结论。
- 未进行全文句长、词频、段落长度、感官密度或 POV 比例统计。
- 不足以判断全书是否存在固定句长比例、固定段落长度、固定反应顺序或固定叙述视角。
- 不足以证明每个章节都以异常、未完成结果或低压动作结尾。
- 本卡不迁移任何专属世界规则、人物关系、能力名称、固定称呼、签名比喻或原句。
- 所有结论仅是参考写作中的选择机制，不是新作品 Canon、剧情规划、作者批准或 Writer 的逐句检查清单。
