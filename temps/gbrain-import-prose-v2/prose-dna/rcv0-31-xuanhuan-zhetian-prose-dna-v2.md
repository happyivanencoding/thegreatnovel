## Cross-Scene Invariants

1. **文本优先选择会改变判断、行动选项、关系状态或尺度认知的细节。**  
   距离失效、尸骨、锁链、门、伤势、身体变化、敌方退让和一句避答，都比抽象的“宏大”“神秘”“悲伤”更值得进入文本。

2. **抽象概念通常先被转化为可定位的物体、动作、身体反应或社会反馈。**  
   世界奇观由距离、材质、入口、位置和旁观者反应成立；力量由破坏结果、身体变化和敌方策略改变成立。

3. **信息与因果只解释到足以支持当前行动的粒度；远端来源、完整原理和隐藏动机可以延后。**  
   这不是少解释，而是把解释放在证据之后，并让解释改变下一步选择。

4. **段落、句群和细节密度跟随状态变化，而不是服从固定风格模板。**  
   探索按“移动—发现—判断”展开，战斗按“作用—应对—新变量”推进，关系戏则以停顿、物件和避答截断预期。

## Attention DNA

### Core Selection Strategy

注意力集中在“当前状态被改变”的位置：

- 新证据推翻旧认知；
- 新物体改变可走路径、可守范围或危险等级；
- 一次动作改变攻击权、距离、姿势或地形；
- 一项收获改变身体能力、保密压力或敌方判断；
- 一个小动作改变关系距离或社会地位；
- 一个远景锚点把场景尺度推到新的层级。

被压缩的是不产生上述变化的内容：完整背景回顾、重复的环境形容、无后果的技能罗列、已经被读者理解的情绪解释，以及不改变当前行动的历史细节。

### Scene-Conditioned Behavior

- **入口与探索：**  
  先选择能建立位置、距离、材质或边界的细节，再选择让旧认知失效的异常物。W01 先建立航天、距离和监控尺度，之后才让尸体、锁链和棺椁摧毁原有框架。W02、W03 则通过缝隙、脚下材质、骨灰、剑气和光线推进空间判断。

- **发现与奇观：**  
  关注“下一层证据如何修正上一层判断”，而不是一次性铺满景物。W10 从两轮月亮推进到头骨、废墟和古庙；W11 从锁链、山裂、神药推进到碑和门户。

- **战斗：**  
  注意力不平均分配给每个招式，而集中于位置、目标、屏障、攻击权和后果。W05–W07 中，新的威胁必须改变数量、空间承受力、通路或逃生策略。

- **回报与突破：**  
  选择能把“获得”变成身体、环境、旁观者和敌方策略变化的细节。W08 选择眼痛、经页消失、体内异变与藏匿压力；W09 选择器物亮起、敌军受创、旁观者退却和战略恐惧。

- **说明与关系：**  
  低压场景也只保留有功能的生活细节。W12 的食物、食盒、木墩和手掌使规则进入行动；W13 的茶水、草地和共同沉默承载离别；W14 的门、祭台、眼神和旗阵把重逢立即转成危险确认。

### Compression / Omission Boundary

细节可以压缩，当它只提供：

- 已经建立过的空间氛围；
- 不改变判断的重复感官；
- 不改变关系状态的闲谈；
- 不改变行动结果的招式名称；
- 不改变下一步选择的完整历史或理论。

细节不可压缩，当删掉后会失去：

- 谁在何处、对什么施加作用；
- 为什么角色改变路线、布阵、逃离或停下；
- 身体如何承受代价；
- 旁观者为何改变态度；
- 回报为何同时生成新风险；
- 未知为何仍然具有可观察边界。

### Evidence / Anti-Evidence

证据：

- W01、W02、W03：尺度、地貌、缝隙、尸骨和锁链承担探索骨架。
- W05、W06、W07：战斗注意力落在位置、保护范围、通路和空间后果。
- W08、W09：能力回报通过身体及外部反馈确认。
- W12、W13、W14：生活物件和微反应承担规则、情绪与关系功能。

反限制：

- W04 在大规模声望扩张之后重新缩回一桌酒菜，说明注意力不必持续停留在宏大尺度。
- W13 的情绪场景没有大量心理解释，但并不意味着情绪细节一律压缩。
- W07 的宇宙级战斗仍需要展开封印、入口和多人关系，说明高压不等于全面省略。

## Knowledge DNA

### Core Selection Strategy

知识选择遵循“当前观察者能够知道什么，以及这份知识是否会改变当前行动”。

保留：

- 角色已经看到、听到、触碰或验证的事实；
- 当前问题所需的局部规则；
- 能解释当前危险、路线、战术或身体变化的判断；
- 在现场物证之后出现的暂时性推测。

暂时留白：

- 未知物的完整来源与最终目的；
- 远古历史的全貌；
- 功法、法则或力量的完整原理；
- 关系对象的真实动机与自我状态；
- 尚未被行动验证的设定性判断。

### Scene-Conditioned Behavior

- **探索：**  
  知识贴着可见范围推进。W03 先出现地质、骨骼、锁链和剑气，再调用相关知识，并立即影响绕行、试探和是否前进。

- **发现：**  
  先让旧知识发挥否定作用，再让新物证扩大未知。W10 先用现代火星知识确认“不可能回家”，之后由头骨、废墟和古庙继续推翻已有判断。W11 保留传说与错误猜测，不替读者判定禁地目的。

- **规则说明：**  
  W12 并非一律少解释，而是先有饮食、身体和提问，再解释“从身体开始”的第一步；规则只推进到当前学习需要的位置。

- **回报：**  
  W08 不展示经文全文，而通过读不清、眼睛受伤、经页入体和无法取出，提供足够的价值与风险知识。W09 在现象造成敌军受创后，才由旁观者命名力量性质。

- **战斗：**  
  W05 的传说说明跟在成群凶物和远方巨眼之后，作用是改变逃离优先级；W06 的种族肉身判断在首次对抗未分胜负后才进入。

- **关系谈判：**  
  W14 只提供“身体像旧友、行为却不再是旧友”的现场知识，不提前解释被占据者还剩多少自我。

### Compression / Omission Boundary

知识可以停在：

- 当前角色能据以选择路线、目标、战术或是否接近的程度；
- 读者能理解即时危险和结果的程度；
- 角色能形成暂时判断，但仍可能被后续证据修正的程度。

知识不应被压缩到无法判断行动，也不应提前扩展为完整百科。

明确判断可以出现于：

- 当前角色必须据此行动时；
- 现象已经提供足够证据时；
- 旁观者需要给结果命名时；
- 规则说明必须产生第一个可执行步骤时。

### Evidence / Anti-Evidence

证据：

- W03：局部知识紧跟地貌与危险。
- W08、W09：力量知识分别通过读取代价和战场结果获得。
- W10、W11：新证据先于历史解释，错误猜测被保留。
- W12：说明被生活场景和具体问题切开。
- W14：关系真相保持在行为矛盾中。

反限制：

- W12 存在明确规则讲解，说明原则不是“永远不解释”。
- W09 存在清楚的力量性质判断，说明解释可以明确，只是应在现象和结果之后。
- W03 的自语判断也会压缩推理过程，说明不需要把每一步思考完整展开。

## Causal DNA

### Core Selection Strategy

因果解释到读者能够追踪以下链条时停止：

`可观察证据 → 角色判断或行动 → 即时结果 → 状态/选项改变`

超过这一链条的远端本体、完整历史和终极原理，除非当前行动确实需要，否则保持延后。

### Scene-Conditioned Behavior

- **探索：**  
  W02 通过棺盖偏移、光线、跌倒和无讯号，让读者理解“脱险”如何转成陌生世界；W03 通过骨骼、剑气和地形使绕行与试探具有原因。

- **战斗：**  
  W05 保留尸体内威胁、光罩破口、远处血眸和群体位置，形成从局部伤害到整体逃生压力的链条。W06 每次攻防都改变山体、距离、姿势或攻击节奏。W07 即使扩大到星河尺度，也保持“谁先进入、谁阻路、谁支援谁”的因果关系。

- **回报与突破：**  
  W08 把经页的价值解释到“能读取、会受伤、无法公开、会改变速度”的程度。W09 把突破解释到“攻击为何失效、敌方为何受创、战略恐惧如何生成”的程度，而没有完整解释全部法则。

- **说明：**  
  W12 先有饮食冲突与身体提问，再把规则落到第一步实践；解释的结果是可学对象，而非一次获得能力。

- **关系：**  
  W13 中茶水、沉默和共同决定把失落转成继续修行；W14 中称呼、避答、布阵和先手攻击把重逢转成控制权争夺。

### Compression / Omission Boundary

因果不应压缩掉：

- 作用者和受作用者；
- 方向、距离和阻隔；
- 具体后果；
- 后果如何改变下一步。

因果可以省略：

- 不影响当前行动的最终解释；
- 已由多个物证充分支持的中间重复步骤；
- 角色不可能知道的远端动机；
- 对完整技能机制的逐式拆解。

因此，停点不是“一律少解释”，而是“行动所需的因果已经闭合”。在 W12 和 W09 中，明确判断正是因为当前选择或结果命名需要它。

### Evidence / Anti-Evidence

证据：

- W05、W06、W07：动作均回到位置、目标与结果。
- W08、W09：回报均包含身体过程和外部后果。
- W12：规则说明由具体问题触发并改变下一步。
- W13、W14：关系状态通过动作和对白后果变化。

反限制：

- W01 对航天与距离的说明相对展开，因为它必须先建立发现的可信尺度。
- W06 的环境破坏使用连续展开句，因为空间后果本身是力量判断的依据。
- W10、W11 没有立即补齐远古来源，但并未省略当前可见证据和危险边界。

## Reaction DNA

### Core Selection Strategy

反应细节的功能是把不可直接观察的状态转化为：

- 身体失衡、停顿、疼痛或姿势变化；
- 视线与注意方向；
- 物件处置与失败动作；
- 对白中的回避、命名和转题；
- 旁观者的距离、退让或重新定位。

反应不是情绪标签的替代词，而是让读者看到认知、力量或关系如何泄露出来。

### Scene-Conditioned Behavior

- **奇观与发现：**  
  选择失神、变色、瞳孔、屏息、尖叫、凝固和视线移动，显示尺度或旧认知翻转。W01、W02、W10、W11 均让身体反应紧跟物证出现。

- **生存与战斗：**  
  选择捂嘴、护住同伴、后退、哭而不敢出声、倒退和重新聚拢，使反应同时承担人物差异与战术信息。W05 中群体反应不是统一的“害怕”。

- **能力回报：**  
  W08 通过眼痛、流泪、停步和内视表现价值与代价；W09 通过敌方脸色、倒退、受创和命令变化表现力量地位翻转。

- **低压关系：**  
  W13 选择茶水失手、躺下、共同仰望和长久沉默；关系由同步姿势和共同决定显现，而不是轮流说明心情。

- **谈判与身份危机：**  
  W14 选择眼神、静坐、未动却有压迫感、避答和布阵，把关系判断变成控制权竞争。

- **公共声望：**  
  W04 让陌生人的传言、杯盘乱响、站起和退到门外承担身份曝光的社会反馈。

### Compression / Omission Boundary

反应可以压缩，当它只是重复同一种已完成的状态确认。

反应不可压缩，当它：

- 区分不同人物的判断；
- 改变关系距离或社会位置；
- 影响战术选择；
- 证明力量确实产生外部效果；
- 暴露人物没有说出口的矛盾。

情绪词可以出现，但不能独自承担全部证明责任。`心沉`、`心凛`、`惊叫`等判断或命名可以作为落点，前后仍应有动作、物证或关系变化支撑。

### Evidence / Anti-Evidence

证据：

- W01、W02、W05：身体反应跟随即时危险。
- W08、W09：反应证明能力代价和地位变化。
- W13：生活物件与沉默承担失落。
- W14：眼神、避答和布阵承担身份不确定性。

反限制：

- W09 存在旁观者直接喊出结果，说明反应不必全部隐晦。
- W12 的师者“淡笑”、少年的目瞪口呆等简短命名可以保留，关键是要有关系位置与现场触发物。
- 证据不足以支持“全书禁止内心叙述”或“所有情绪都必须动作化”。

## Rhythm DNA

### Core Selection Strategy

节奏根据 scene beat 和 state change 选择，而不是根据固定句长比例选择。

- 条件、距离、连续后果和空间路线需要展开；
- 命名、命令、攻击命中、认知翻面和结果落地需要收束；
- 一次新的空间、目标、攻击权、关系或知识状态成立后，段落获得切分理由；
- 重大结果通常需要单独留出一拍，让结果先被接收，解释随后进入。

### Scene-Conditioned Behavior

- **探索与发现：**  
  采用阶梯式展开：移动、局部证据、判断、下一层边界。W03、W10、W11 都不是均匀推进，而是每层发现后留出认知反应。

- **战斗：**  
  用“攻击—应对—新变量”压缩连续攻防；当攻击权、地形或战略判断改变时，暂时放慢。W06 以段落对应一次攻防关系变化，W07 以每个新增战场变量扩展场面。

- **回报与突破：**  
  以获得、试用、代价、确认、外部反馈和新风险交替推进。W08 的短促断裂落在眼痛、消失和异变；W09 则在大规模攻防与关键身体结果之间切换。

- **规则与日常：**  
  W12 先展开洞天生活，再用短对白切入规则；W13 允许月夜、沉默和清晨过渡展开，之后以短句把情绪压回行动。

- **谈判与关系危机：**  
  W14 让接近、识别、否定、布阵、谈判和先手攻击不断截断团聚预期，节奏变化来自关系状态快速改写。

### Compression / Omission Boundary

节奏压缩的单位是 scene beat，不是句子长度。

可以压缩：

- 连续但没有新变量的动作；
- 已经完成空间建立后的重复移动；
- 不改变关系和压力的对白轮次；
- 结果已经明确后的重复反应。

需要展开：

- 新空间的建立；
- 连续后果如何改变可见边界；
- 一次攻防如何改变攻击权；
- 重大回报如何转化为新风险；
- 低压生活如何为规则或关系提供现实支点。

### Evidence / Anti-Evidence

证据：

- W01、W02：长段建立条件，短段落在异物、震动和认知翻面。
- W06、W07：段落对应攻防关系或战场变量。
- W11：连续奇观按物证层级展开。
- W13：沉默与时间过渡获得节奏空间。

反限制：

- “高压=全程短句”不成立：W06、W07 仍有长句承担环境后果与大尺度布置。
- “低压=全程舒缓”不成立：W12 的说明与 W14 的谈判会在关键判断处快速收束。
- 不能从句长或段长推出固定比例；v1 证据未做全文统计。

## Lexical DNA

### Core Selection Strategy

词汇选择由当前 scene function、观察位置和行动任务决定。

优先选择：

- 能定位距离、材质、边界和方向的具体名词；
- 能显示作用关系、移动和状态改变的动词；
- 能表达人物判断、权力位置和关系回避的对白；
- 能把抽象力量落到身体、器物、环境和社会反馈的词；
- 与当前尺度匹配、但不脱离可观察证据的判断语。

不建立禁词表、词频表或固定句式模板。

### Scene-Conditioned Behavior

- **入口与发现：**  
  词汇从距离、地貌、骨骼、锁链、碑、门户和光线等可追踪实体中选择，使奇观具有层级和边界。W01、W03、W10、W11 支持这一点。

- **战斗：**  
  词汇偏向攻击者、目标、方向、屏障、地形后果和身体受创。W05、W06、W07 的功能不是堆叠招式名，而是持续维护战场关系。

- **回报与突破：**  
  选择眼睛、纸页、体内器物、火、鼎、钟、兵器、敌军等可见承载物，让“变强”变成可验证过程。W08、W09 支持这一点。

- **说明：**  
  W12 将瀑布、药田、食盒、肉食、木墩和手掌与修行语汇并置，使高阶知识被日常经验托住。

- **关系与社会反馈：**  
  W04、W13、W14 使用酒菜、杯盏、茶、水、眼神、称呼、避答和旗阵，让声望、失落与身份危机通过具体互动显现。

- **感官：**  
  选择能标记位置、危险、时间或尺度的少数声光温度材质，不追求五感平均覆盖。

### Compression / Omission Boundary

可以压缩：

- 同义的抽象赞叹；
- 不改变空间或动作的形容词堆积；
- 与当前 POV 无关的术语链；
- 没有后果的技能名称连续出现；
- 只增加氛围、不增加识别度的感官重复。

不可压缩：

- 能区分空间位置和作用方向的名词；
- 能显示关系权力的称呼、回避和判断；
- 能证明身体代价或环境后果的词；
- 能让读者识别世界尺度或危险边界的实体词。

### Evidence / Anti-Evidence

证据：

- W01、W03：科学尺度或地下探索最终落到距离、骨骼、锁链、冷气和洞口。
- W05、W06、W07：战斗词汇持续指向物体、方向、地形与结果。
- W08、W09：力量通过近身物件和外部反馈命名。
- W12、W13、W14：日常物、姿势和对白维持人声与关系差异。

反限制：

- 抽象判断并非禁止；当证据已经成立时，旁观者可以命名“肉身成帝”、危险或身份变化。
- 科学、修行、机构和生活词汇可以并置，关键是它们是否服务当前观察和行动。
- 不能把“具体名词多”降格为词频目标；v1 没有全文词频与句法统计。

## Detail Selection Across Dimensions

细节进入文本的优先级不是“越多越好”，而是看它承担哪种不可替代的 story function。

| 细节功能 | 进入条件 | 删除后失去什么 |
|---|---|---|
| Story-bearing | 改变判断、路线、目标、风险或攻击权 | 因果链、空间地图或下一步选择 |
| Embodied | 让身体承受、证明或泄露某种状态 | 代价、真实感、情绪证据或力量证明 |
| Relational / Social | 改变称呼、距离、权力、声望或联盟 | 关系状态与社会反馈 |
| Scale-bearing | 建立距离、大小、入口、阻隔或全域—局部关系 | 奇观的可测尺度和空间清晰度 |
| Payoff-bearing | 让收获转化为能力、代价、敌方反应或新入口 | 回报的兑现、余波和后续动力 |
| Atmospheric | 在入口、转场或尺度切换时固定少数感官锚点 | 温度、时间、边界或场景身份 |

选择顺序通常是：

`当前判断所需的物证 → 身体/行动反馈 → 关系或社会反馈 → 少量尺度/氛围锚点`

但不是每个场景都需要完整铺齐六类细节：

- 探索场景优先 Story-bearing 与 Scale-bearing；
- 战斗场景优先 Story-bearing、Embodied 与空间后果；
- 回报场景优先 Embodied、Payoff-bearing 与敌方反馈；
- 关系场景优先 Relational / Social 与 Embodied；
- 规则场景优先 Story-bearing 与 Embodied，说明只到当前实践；
- Atmospheric 只在它完成边界、尺度或时间功能时保留。

因此，Detail Selection 的目标不是增加 sensory density，而是保证每个保留细节都能回答：它改变了什么判断、什么关系、什么身体状态、什么尺度或什么 payoff？

## Production Implications

以下原则供 Curator 编译为候选选择偏好：

- 当候选文本包含可定位物证，并且该物证改变当前判断、行动选项或风险等级时，提高其保留优先级。
- 对探索、战斗和发现候选，优先保留能够连续追踪“证据—行动—结果”的片段；缺少位置、作用对象或后果的华丽描述降低优先级。
- 对规则、历史和能力解释，优先选择刚好支持当前行动或结果判断的解释；来源、完整原理和远端动机只有在当前 payoff 或选择确实需要时才进入。
- 对关系与情绪候选，优先保留能通过动作、视线、停顿、物件处置、对白回避或社会反馈显示状态变化的细节；仅当当前场景缺少这种读数时，Curator 才选择必要细节，否则可以不添加。
- 对重大回报和突破，仅在当前场景缺少结果确认或后续影响读数时，选择能确认结果并生成新风险、保密压力、敌方反应或行动入口的必要片段。
- 对句群与段落，优先选择在 scene beat、攻击权、认知翻面或关系状态改变处完成节奏切换的版本，不以固定长短句比例作筛选标准。

## Limits / Insufficient Evidence

- 当前指定的 Terra evidence 与 v1 Prose DNA 都把《遮天》的证据范围记录为 14 个 windows、949 行；未在这两份文件中看到可直接核对的 85-window 分层证据，因此不把未呈现的窗口当作新增事实。
- 没有全文句长、词频、段长或章节节奏统计，不能推出全书层面的比例规律。
- 未覆盖完整结局后的日常收束、纯谈判长场面和低压长篇生活段。
- “章末模式”只能描述局部场景收束，不能外推为全书章节规律。
- 所有结论均为 scene-conditioned reference observation，不是作者永久文风、原创作品 Canon 或 Writer checklist。
- 未知内容应保留为 `INSUFFICIENT`，尤其是全书范围内的稳定词汇偏好、完整叙述视角分布及不同阶段的系统性节奏变化。
