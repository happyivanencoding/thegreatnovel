## Cross-Scene Invariants

1. 细节优先进入资格、方向、身份、关系、身体代价、空间尺度或兑现余波会发生变化的位置；无后续作用的景观和解释被压低。  
   证据：W02、W03、W06、W07、W11、W14、W15。

2. 信息按行动阈值释放：先给可见异常、失败、身体反应或局部位置，再补充足以改变下一步的规则；完整机制和动机不在尚未使用时提前封闭。  
   证据：W02、W08、W11、W14、W15。

3. 状态变化通常由动作、物件、身体反应、称呼、礼数和接待方式外化；重大兑现之后仍保留具体的人身余波。  
   证据：W03、W07、W09、W10、W12、W13。

4. 句段节奏随 scene beat 改变：条件、空间和多人因果展开；判定、拒绝和结果压缩；兑现后重新放慢，让人物承受结果。  
   证据：W03、W07、W08、W12、W13、W14。

## Attention DNA

### Core Selection Strategy

注意力集中在“状态即将改变或已经改变”的细节上：

- 资格与失败：队列、判词、距离、时限。
- 选择与离开：包裹、书信、回望、叩首、携带物。
- 力量兑现：碎裂、受伤、后退、抱拳、引路、宴请。
- 关系确认：呼名、目光、触碰、故物、拥抱。
- 空间危险：站位、可见范围、浮石、黑暗、声音。

这些细节值得进入，是因为删掉它们会损失资格变化、因果压力、关系重新定位、身体承受或 payoff 的可见证据。

### Scene-Conditioned Behavior

- `EMOTION_RELATIONSHIP`：优先照料物、身体停顿和不完整对白；当人物必须在留下与离开之间选择时，细节密度上升。若情绪已由回望、叩首或不松手成立，不再补充解释性心理。
- `ACTION_COMBAT`：优先方向、距离、资源、伤势和动作结果；每轮只保留会改变位置、消耗或生存概率的细节。无关景观不与战局争夺注意力。
- `ENTRY_EXPLORATION`：先建立群体配置，再放大个人隔绝和局部异物；不以宏大形容词代替站位与可见范围。
- `ORDINARY / AFTERMATH`：降低事件规模，放大问路、久站、旧物缺失、酒水和手部动作；这些细节必须改变记忆判断或关系状态。
- `PAYOFF_POWER_PROOF`：先选择能证明结果的物理细节，再选择社会反馈；不能只写“对方服了”。

### Compression / Omission Boundary

压缩：

- 已被动作充分证明的情绪。
- 不改变当前选择的背景历史。
- 没有被使用的规则全貌。
- 纯粹营造氛围、但不改变风险、关系或尺度的景物。

不压缩：

- 资格失败与下一项行动出口。
- 离开时实际获得的行动权和失去的关系。
- payoff 后的伤口、礼数变化、接待方式或未解代价。
- 让读者辨认空间方向、身体状态和关系对象的关键细节。

### Evidence / Anti-Evidence

证据：W02、W03、W04、W06、W07、W11、W12、W14、W15。  
反证边界：样本支持“功能性注意力分配”，不支持全文固定的细节密度、固定感官比例或统一的景物稀疏规则；W14 也不足以推出完整章节开篇模板。

## Knowledge DNA

### Core Selection Strategy

叙述只提供当前 POV 能观察、推断或承受的知识层级。信息进入文本的条件不是“它已经存在”，而是：

1. 它使当前动作可读；
2. 它改变人物下一步选择；
3. 它重排身份、风险或关系压力。

细节的价值在于标记“人物现在知道到哪里”，而不是让读者获得全景百科。

### Scene-Conditioned Behavior

- `PUBLIC_EVALUATION`：先给公开判定、队列和失败结果；规则在失败后出现，作为新的行动资格，而非事前讲义。
- `ACTION_COMBAT`：先给受伤、资源不足、敌我位置和可见结果，再让人物局部推断术法代价或机制。
- `RECOGNITION / MYSTERY`：先让故人通过名字、目光或短暂回应被确认，再由身体异常和物件位置反推阵法。
- `ENTRY_EXPLORATION`：先给空间尺度、隔绝位置和环境反驳，再逐步揭示危险；来历、能力和逃法暂时留白。
- `DIALOGUE_NEGOTIATION / REVELATION`：当关系容器尚未建立时，只给称呼、请求和拒绝；当两人退出公共场景、建立安全感后，才允许更深真相进入。

### Compression / Omission Boundary

压缩：

- 当前 POV 无法观察的完整动机。
- 尚未被行动验证的机制全貌。
- 书信、告别信和长期历史的全文内容。
- 读者可以从现有动作直接推断的心理结论。

不压缩：

- 使空间和动作基本可追踪的方位、距离与身体结果。
- 使规则能够改变行动的最小解释。
- 使关系变化可被辨认的称呼、礼数和回应差异。
- 当人物必须明确选择或公共制度必须落锤时，允许直接判断。

### Evidence / Anti-Evidence

证据：W02、W05、W06、W11、W13、W14、W15。  
反证边界：不能据此推出“一律少解释”或“永远不揭示机制”；W02、W11、W15 都表明，解释会在行动阈值或关系安全感成立后增加。

## Causal DNA

### Core Selection Strategy

因果解释停在“足以让下一步成立”的粒度：

- 先呈现结果、阻力或异常；
- 再给当前行动所需的局部原因；
- 保留尚未影响选择的远因和全貌。

细节值得进入，是因为它能把欲望、阻碍、选择和后果连接起来。若删掉它，读者会失去对行动代价、身份变化或关系不对称的理解。

### Scene-Conditioned Behavior

- `TEST / FAILURE`：先让失败发生，再说明下一轮规则；解释必须产生继续、退出或承担代价的出口。
- `COMBAT / SURVIVAL`：先展示施法、退身、牺牲或资源消耗的后果，再补充代价；每个能力至少留下位置、资源、身体或新威胁的变化。
- `RECOGNITION`：先确认关系仍可抵达，再说明为什么无法立即救援；因果链不能用机制讲义覆盖关系冲击。
- `FAMILY_LETTER / PUBLIC_RULE`：先积累长期质疑和无效声音，直到家书或实际损害把公共规则转为个人行动。
- `DEPARTURE / RELATIONSHIP`：明确离开同时带来行动权与损失；不把损失解释成双方已经互相成全。

### Compression / Omission Boundary

解释到以下程度即可停止：

- 当前人物为何必须继续、拒绝、离开或应战；
- 当前规则如何改变资格、路线或压力；
- 当前行动换来了什么，同时付出了什么。

继续解释只有在它会改变下一步行动、重新定位责任或揭示新风险时才有必要。不要补齐所有幕后动机，不要把未解决的期限和风险提前结算。

### Evidence / Anti-Evidence

证据：W02、W03、W08、W09、W11、W14、W15。  
反证边界：样本支持“因果局部化”，不支持因果永远隐晦；制度判定、明确选择和行动结果可以直接说明。

## Reaction DNA

### Core Selection Strategy

人物状态优先通过可观察的泄露方式进入文本：

- 动作：握拳、回望、久站、叩首、坐下。
- 身体：发白、吐血、视线凝聚、咬唇、触碰失败。
- 物件处置：递出、收起、反复阅读、碎裂、落下。
- 社会行为：称呼、后退、抱拳、引路、设宴。
- 对白形态：答话长度、答非所问、沉默、礼貌程度。

细节值得进入，是因为它把抽象情绪转成身份、关系、身体感或社会反馈。删除后若只剩“悲伤、震惊、愤怒”等结论，反应链就不成立。

### Scene-Conditioned Behavior

- `RELATIONSHIP`：用照料、回望、触碰和不完整对白显示亲疏与损失；当选择已清楚时，少加情绪总结。
- `COMBAT`：让身体反应早于机制说明；皱眉、闭眼、退身和吐血先说明压力，再让术法解释进入。
- `POWER_PROOF`：让不同角色以不同礼数反应；恐惧、试探、赔礼和拉拢不能合并成同一种“震惊”。
- `LOW / AFTERMATH`：用喝酒、沉默、问路、慢走、酒壶脱手承接强者疲惫；私人反应必须改变信息承接或关系。
- `DIALOGUE_NEGOTIATION`：让称呼和是否正面回答改变谈判压力；对白不必句句直答，但回避必须泄露防备、疲惫或拒绝。

### Compression / Omission Boundary

压缩：

- 已由动作和物件充分显示的情绪标签。
- 没有改变关系、选择或信息承接的插科打诨。
- 所有旁观者统一化的反应。

不压缩：

- 选择临界点的明确拒绝、离开或继续。
- 能区分不同社会位置的礼数和称呼。
- payoff 后能证明关系仍在、损失仍在或新风险已出现的反应。

### Evidence / Anti-Evidence

证据：W01、W03、W05、W06、W07、W09、W10、W11、W12、W13、W15。  
反证边界：不是禁止情绪词，也不是要求每个情绪都身体化；当制度判定或行动选择必须明确时，直接命名可以承担裁决功能。

## Rhythm DNA

### Core Selection Strategy

节奏由 scene beat 和 state change 驱动，而不是由固定句长模板驱动：

- 条件、等待、空间、时间差和多人位置展开；
- 碰撞、判定、拒绝、失败和动作结果压缩；
- 兑现后的伤口、关系、余波和新期限重新放慢。

细节值得进入，是因为它决定读者何时停留、何时加速、何时感到状态已落地。

### Scene-Conditioned Behavior

- `PUBLIC_EVALUATION`：判定、他人通过、主角失败和下一测试分段，制造逐级收窄的压力。
- `ENDURANCE / COMBAT`：每一段承载一轮动作、身体或环境后果；终止句单独落点。
- `DEPARTURE`：对白与家庭停顿放慢，跋涉压缩，危险出现时加速；获得行动权后保留损失段。
- `POWER_PROOF`：先用短促动作确认胜负，再用较长段落承接赔礼、邀请、利益和谜团。
- `PAYOFF / AFTERMATH`：兑现后不立即切换到更大规模；让人物通过拥抱、酒、伤口、接待或沉默承受结果。
- `ENTRY_EXPLORATION`：先铺开群体空间，再以短句逐步放大异物和危险。

### Compression / Omission Boundary

不应：

- 机械交替长句与短句；
- 把所有段落切成相同长度；
- 在空间仍不清楚时过早压缩动作；
- 在状态刚改变后立即跳到下一项能力或设定。

可以延展：

- 多人位置、距离、资源和时间差；
- 关系中的等待、寻找和不完整回答；
- payoff 后的人身余波。

可以压缩：

- 已经由动作完成的裁决；
- 不改变状态的过场移动；
- 重复的技能名称和无后果的反应。

### Evidence / Anti-Evidence

证据：W02、W03、W04、W06、W07、W08、W09、W11、W12、W13、W14、W15。

## Lexical DNA

### Core Selection Strategy

词汇选择按叙事功能路由，而不是按高频词或禁词路由：

- 资格与制度：判词、队列、物件、位置、可测量距离。
- 身体与代价：血、喉咙、双腿、视线、呼吸、触碰、退身。
- 关系与身份：称呼、亲属关系、恩情、礼数、请求、拒绝。
- 空间与尺度：黑暗、浮石、裂缝、声音、远近、方向。
- 余波与记忆：旧屋、坟头、酒、故物、纸张、沉默。

抽象目标出现后，通常由具体名词、结果动词或社会动作承接。细节值得进入，是因为词汇本身能让抽象情绪变成可携带物、身体变化、身份反馈或尺度判断。

### Scene-Conditioned Behavior

- `ACTION_COMBAT`：术法名词只能作为机制标记；结果动词必须持续显示冲出、退身、撕开、崩溃、牺牲和资源变化。
- `RELATIONSHIP`：优先使用照料物、身体动作、称呼和关系动作；不靠连续情绪形容词承担全部情感。
- `POWER / STATUS`：使用不同称呼、礼貌程度和动作动词显示强弱重排；“前辈”与“道友”这类身份变化属于关系功能，而非词汇装饰。
- `ENTRY / WONDER`：用物体、位置和感官锚点制造尺度；不让“宏大、神秘、恐怖”等概括词独自承担奇观。
- `LOW / REVELATION`：用酒、坐下、沉默、笑声和酒壶等日常词汇降低公共身份，使真相能在关系中落地。

### Compression / Omission Boundary

避免：

- 禁词表、词频表和固定句式；
- 将来源中的书信、酒、旧屋、残魂等具体物件固定成通用象征；
- 平均分配术法名词、感官词或形容词；
- 用抽象情绪词替代已经可以观察到的动作链。

保留：

- 能标记位置、距离、身体后果和资格变化的具体名词；
- 能显示选择和结果的动词；
- 能改变社会位置的称呼、礼数和关系词；
- 与新故事自身关系生成的独特物件。

### Evidence / Anti-Evidence

证据：W01、W03、W05、W06、W07、W08、W10、W11、W12、W13、W14、W15。  
反证边界：样本不支持对全文词汇频率、平均句长、形容词比例或固定词类禁用作结论。

## Detail Selection Across Dimensions

| Story function | 细节进入条件 | 删除后损失 | 主要证据 |
|---|---|---|---|
| 资格 / 因果门槛 | 规则正在判断身份、资格或下一步路线时 | 读者无法理解为何继续、失败或转向 | W02、W14、W15 |
| 身体承压 | 选择或战斗需要具体代价时 | 压力变成抽象情绪，行动失去重量 | W03、W08、W09、W11 |
| 关系 / 身份反馈 | 称呼、礼数、物件或触碰改变关系时 | 关系变化只能靠作者宣告 | W01、W07、W10、W12 |
| 空间 / 尺度定位 | 未知空间或多人行动需要可追踪时 | 奇观变成形容词，动作失去方向 | W03、W08、W14 |
| 记忆 / 延迟兑现 | 过去必须通过现物重新确认时 | 时间差和失去被一句总结抹平 | W06、W12、W13 |
| Payoff / aftermath | 兑现刚刚发生，需要显示回报与新代价时 | 成功变成无后果的升级提示 | W07、W08、W09、W12、W13 |

## Production Implications

1. Curator 编译状态变化目标，并选择能证明资格、因果、关系、身体、尺度或 payoff 的必要细节；仅当当前场景缺少相应读数时才加入，否则可以不添加。

2. Curator 将 `scene family + POV knowledge + current risk` 作为注意力与信息预算的联合输入，避免把局部场景特征扩展成全局规则。

3. Curator 对规则和机制只选择能改变当前行动的解释层；尚未被使用的远因、全貌和动机保持局部未知，除非当前场景缺少必要的判断依据。

4. Curator 选择“动作或结果 + 可观察反应 + 下一选择”中当前场景所缺少的必要环节，并在状态落地处允许节奏断点。

5. Curator 为关系和兑现段优先检索可操作物件、身体反应和社会反馈；仅当当前场景缺少可读的状态变化时，才决定是否加入直接情绪判断。

6. Curator 按功能路由词汇语义场：位置与结果动词服务动作，称呼与礼数服务关系，具体物件与感官锚点服务身份、记忆和尺度；不生成来源专名、固定象征或禁词表。

## Limits / Insufficient Evidence

- 证据是 bounded-window 观察，不是全文句长、词频、段落长度或章节结构统计。
- W14 是唯一直接的未知空间进入窗口，不能建立完整的章节开篇规则。
- 当前样本没有稳定章节边界覆盖，不能确定普通章末模板。
- “强者仍有人味”只能迁移为：公共身份暂时退场，并由普通动作改变关系、判断或信息承接；不能迁移具体人物、物件或关系结构。
- 未提供的 scene windows 不作补充推断；证据不足处保持 `INSUFFICIENT`。
- 未修改任何文件。
