## Cross-Scene Invariants

1. 文本优先选择会改变当前行动、关系、身体状态、公共地位或下一目标的细节；背景、机制和气氛只有在承担这些功能时才进入正文。  
   证据：W01、W02、W04、W07、W08、W09、W13、W14。

2. 抽象判断通常晚于可见证据：先出现物件、动作、受力、身体反应或他人行为，再允许“强大”“危险”“亲近”“成功”等判断落地。  
   证据：W02、W03、W04、W06、W10、W11、W12。

3. 信息量、因果解释、句段长度与词汇层级随 scene beat 和 state change 改变；不存在覆盖所有场景的固定“短句”“少解释”或“宏大词”规则。  
   证据：W03、W07、W08、W12、W13、W14。

4. 大尺度结果需要重新落回身体、关系、群体或具体物件；普通场景也必须保留社会后果与潜在冲突，不能成为无功能的休息段。  
   证据：W06、W09、W10、W11、W13、W14。

## Attention DNA

### Core Selection Strategy

注意力优先给正在改变场景状态的节点：

- 当前人物正在争取、拒绝、承受或决定的东西；
- 能改变下一步的物件、资源、位置或限制；
- 能证明力量、危险、关系或公共地位已经变化的结果；
- 能把抽象尺度转换成身体读数、环境边界或群体行为的细节。

细节进入文本，不是因为它“漂亮”或“有感官密度”，而是因为删掉它会损失：

- 当前选择的可理解性；
- 因果链中的接触、阻力或后果；
- 人物身份与欲望的具体形状；
- 关系边界或公共权力的变化；
- payoff 的可见确认。

### Scene-Conditioned Behavior

**这样：**

- 在入口与普通场景中，先选择正在进行的动作、手边物件和即时限制，再逐步打开更大的世界。见 W01、W02、W09。
- 在战斗中，把注意力集中到接触、方向、落点、受伤边界和对手反应，而不是平均描写所有动作。见 W04、W06、W12。
- 在突破或胜利中，选择能够确认状态变化的身体、环境与群体读数。见 W07、W10。
- 在关系场景中，优先选择改变靠近、回避、允许、拒绝或承诺含义的动作。见 W05、W11。
- 在发现与世界入口中，只选择少量能证明尺度变化、抵达或新危险出现的锚点。见 W13、W14。

**不这样：**

- 不把背景历史、完整制度、完整战术或完整世界结构与当前选择等量铺开。
- 不用“全场震惊”“气势磅礴”“无比宏大”替代实际的身体、环境和群体反应。
- 不因场景处于低压状态，就把食物、孩子、市场或饭桌写成无后果装饰。
- 不因场景处于高潮，就让所有细节获得同等篇幅。

### Compression / Omission Boundary

可以压缩：

- 不改变当前行动的背景；
- 已经被前文证明、且不再产生新后果的重复动作；
- 不会改变人物判断或关系状态的泛化心理；
- 不能改变尺度、温度或压力的附加感官描写。

不能压缩：

- 第一次出现的决定性物件；
- 让力量成立或失败的接触、阻力和落点；
- 让关系边界改变的微反应；
- 让 payoff 从主观宣称变成公共事实的外部读数；
- 让未知入口真正“抵达”的身体或环境变化。

### Evidence / Anti-Evidence

证据主要来自 W01、W02、W04、W06、W07、W09、W10、W12、W13、W14。

反向边界来自 W08 与 W12：说明场景仍会保留必要的知识细节，巨物战也会保留阻力与策略转向。注意力不是永远只给动作，而是给当前状态真正发生变化的部分。

## Knowledge DNA

### Core Selection Strategy

知识按照当前 narrator / POV 为了理解眼前选择所需要的程度进入文本，而不是按照作者已知信息的完整度进入文本。

常见时序是：

1. 先看见物件、危险、关系压力或异常；
2. 人物先作出局部反应；
3. 只补足当前判断所需的信息；
4. 说明结束后立即改变合作、追踪、战斗、归来或下一目标。

### Scene-Conditioned Behavior

**这样：**

- 入口场景只说明足以让人物决定留下、离开、赴宴或继续探索的压力；完整来历和地图暂时留白。见 W01、W14。
- 规则说明先让药、颜料、画册、卷轴、阵法或信件出现，再解释当前用途或来源。见 W08、W12。
- 战斗中先给威胁、位置和结果；只有当攻击受阻或策略改变时，才补充必要机制。见 W06、W12。
- 普通场景通过饭桌、税赋、丰收、孩子和家庭事实让社会结构显形，不先展开完整政策说明。见 W09。
- 世界发现先呈现新地貌、危险或机会，再让人物讨论命名、归属和去向。见 W13。
- 关系场景先让身体边界与现实压力发生，再补充动机、立场或未来成本。见 W05、W11。

**不这样：**

- 不预先解释完整世界层级、敌人全部战略、功法全部边界或人物完整心理史。
- 不把“作者知道”误当成“当前 POV 应该知道”。
- 不为了制造合理性而补齐不会改变当前选择的机制。
- 不把留白误解成含混；当前选择、风险和结果仍必须清楚。

### Compression / Omission Boundary

信息可以留白，只要读者仍能判断：

- 人物现在要什么；
- 什么正在阻止他；
- 他做了什么选择；
- 选择造成了什么可见结果；
- 下一步为何会发生。

当缺少信息会使当前选择、危险等级或结果因果无法理解时，允许明确说明。说明应停在当前 scene beat 所需的边界，不自动扩展成完整设定。

### Evidence / Anti-Evidence

证据主要来自 W01、W07、W08、W09、W12、W13、W14。

反向边界是：W07 的外部会议会集中展示主角突破的社会含义，W12 会在强攻失败后解释阵法意义。因此本 DNA 不是“一律少解释”，而是让解释服从当前选择与状态变化。

## Causal DNA

### Core Selection Strategy

因果解释以“读者能够理解当前动作为何成立、为何失败、失败后为何必须改变”为停止标准。

优先保留：

- 欲望或压力；
- 可见选择；
- 接触、方向、阻力与结果；
- 身体、环境、关系或群体的状态变化；
- 结果如何推动下一步。

明确判断可以出现，但通常在可见行动之后，或在人物必须划定行动边界时出现。

### Scene-Conditioned Behavior

**这样：**

- 普通场景中，让饥饿、肉、刀、分家和退步共同解释力量如何转成尊严与资源。见 W02。
- 首次暴力选择中，让目标行为、主角判断、刺杀行动和杀后身体反应形成完整但不过量的链条。见 W03。
- 战斗中至少交代足以追踪结果的接触物、方向、受力或落点；不把动作压成“瞬间击飞”。见 W04、W06、W12。
- 突破与胜利中，把身体变化、环境变化、旁观者读数和新的政治问题按层次连接起来。见 W07、W10。
- 说明场景中，解释应回答“这个物件或能力现在为何改变关系与行动”。见 W08。
- 关系场景中，让靠近、玩笑、制止、安抚和延期共同解释关系为何推进但没有彻底结清。见 W05、W11。

**不这样：**

- 不把功法、武器、阵法或制度讲成独立教程。
- 不用“因为他很强”“众人震惊”“关系更深了”替代可观察的因果链。
- 不在结果之前提前宣布全部意义。
- 不用长篇道德解释抹平恐惧、快意、犹豫或责任之间的并置。

### Compression / Omission Boundary

解释可以停在：

- 当前动作成功所需的物理差异；
- 当前攻击失败所需的阻力来源；
- 当前关系变化所需的边界反应；
- 当前公共结果成立所需的外部行为。

可以省略完整机制、完整战略、完整历史与最终道德结论，除非它们会直接改变下一项选择。

### Evidence / Anti-Evidence

证据主要来自 W02、W03、W04、W06、W07、W08、W10、W12、W13。

W12 是重要反向证据：主角强大仍会遇到明确反制，因果 DNA 必须保留失败、阻力和策略调整，而非把所有场景统一为顺利兑现。

## Reaction DNA

### Core Selection Strategy

人物状态通过动作、对白、停顿、物件处置、身体延迟反应和旁观者行为泄露。

反应细节值得进入，是因为它会：

- 修正对白的表面含义；
- 改变人物间的距离或边界；
- 证明力量或危险已被他人接受；
- 让抽象情绪产生身体代价；
- 推动下一项行动。

### Scene-Conditioned Behavior

**这样：**

- 在生存与暴力场景中，保留事件之后才出现的洗血、颤抖、吞咽、屏息或手软。见 W01、W02、W03。
- 在力量 payoff 中，让敌人失能、旁观者失声、群体散开、欢呼或投诚承担公共确认功能。见 W04、W07、W10。
- 在关系场景中，用靠近、避开、抱紧、停手、断开联系、落泪或重新安抚持续校正对白。见 W05、W11。
- 在知识交换中，用递物、看物、咳嗽、眼神骤亮或改变座位让信息交流保留人物温度。见 W08。
- 在普通场景中，保留孩子的狼狈、妇人的脸色变化、老人继续吃饭或外来者哽住等不整齐反应。见 W09。
- 在世界尺度场景中，让环境变化和身体反应共同承担“抵达”或“力量作用”的读数。见 W12、W13、W14。

**不这样：**

- 不先写“震惊、感动、复杂、害怕”，再用身体动作重复同一结论。
- 不用“全场震惊”替代具体的停手、后退、失声、散开或改换座次。
- 不把微动作堆成无状态的身体清单；每个反应都应改变关系、判断或下一步。
- 不要求所有场景都深入内心；当 POV 无法获得内情，外部行为即可承担反应功能。

### Compression / Omission Boundary

可以压缩：

- 不改变状态的重复表情；
- 已经被动作充分表达的情绪命名；
- 旁观者无差异的集体反应。

不能压缩：

- 第一次暴力或力量结果后的身体延迟；
- 关系边界被接受、拒绝或重新协商的动作；
- 旁观者行为改变所带来的公共地位变化；
- 反应与对白相反、从而产生人物复杂性的瞬间。

### Evidence / Anti-Evidence

证据主要来自 W03、W04、W05、W06、W07、W08、W09、W10、W11、W14。

反向边界来自 W01 与 W10：有时一个简短动作或命令已经足够，不必为每个反应补充心理解释；反应必须服务于状态变化，而不是增加动作数量。

## Rhythm DNA

### Core Selection Strategy

节奏跟随 scene beat 与 state change，而不是套用固定的长短句比例。

- 接近、观察、背景压力与不确定性可以展开；
- 决定、接触、撞击、命令和关键发现可以压缩；
- 结果确认需要独立停顿；
- 余波与新问题可以重新放宽。

句段长度的改变必须对应叙事任务的改变。

### Scene-Conditioned Behavior

**这样：**

- 入口场景从较宽的困顿或旁观判断，逐步压缩到异常、决定和身体反应，再随尺度展开。见 W01、W14。
- 高压战斗按位置变化、受力结果或决策分段；快速不等于跳过动作链。见 W03、W06、W12。
- payoff 在突破或命令处压短，在环境和社会回声处重新展开，并让关键结果获得独立节拍。见 W07、W10。
- 关系场景可以让斗嘴快速来回，在身体试探、沉默和未来成本处放慢。见 W05、W11。
- 说明场景以短问答、递物和较长解释交替，避免知识段落形成连续讲义。见 W08。
- 发现与造界场景可以先拉远到世界结构，再迅速收回命名、表情、争执和下一目标。见 W13。

**不这样：**

- 不把所有高压场景都写成连续短句。
- 不把所有宏大场景都写成舒展长句。
- 不用缩短段落掩盖没有实际状态变化的动作堆叠。
- 不把多个战斗 beat、多个关系反应或多个发现结果塞进一个总述段。
- 不把结果埋在过程描述中，使读者无法停在 payoff 上。

### Compression / Omission Boundary

节奏可以加速的条件是：读者已经知道位置、目标和当前阻力，且被压缩部分不会改变结果理解。

节奏必须放慢的条件是：

- 位置或受力第一次改变；
- 人物作出不可逆选择；
- 结果第一次被环境或他人确认；
- 关系边界从允许变成拒绝，或从拒绝变成重新靠近；
- 新世界从名词变成可感入口。

### Evidence / Anti-Evidence

证据主要来自 W03、W04、W05、W07、W08、W10、W12、W13、W14。

暂无足够证据推导全书固定的平均句长、段落长度或节奏比例；这些统计结论为 `INSUFFICIENT`。

## Lexical DNA

### Core Selection Strategy

词汇选择服从当前功能、尺度和人物行动，而不是形成禁词表或词频规则。

常见迁移方向是：

- 用具体名词承托抽象判断；
- 用硬动作词显示力量与边界；
- 用功能切换标记场景从生活、冲突、政治到奇观的变化；
- 让人物声线体现在回答方式、判断速度、玩笑、拒绝和命令中，而不是性格形容词中。

### Scene-Conditioned Behavior

**这样：**

- 生存与普通场景优先选择锅、柴、肉、刀、饭桌、墙头、钱物等低位实物，让欲望和社会状态落地。见 W01、W02、W09。
- 冲突与力量场景选择能显示接触、损伤和边界的硬名词与动词，再让判断出现。见 W03、W04、W06、W10、W12。
- 规则与政治场景选择信件、座次、画册、门、会议等关系性物件，让制度压力附着于现场。见 W07、W08。
- 关系场景保留口语、玩笑、冷硬环境词与不完整判断的并置，使亲密不自动变成端正情话。见 W05、W11。
- 发现与入口场景在身体或环境已经建立尺度后，才扩大到地貌、天空、光点、黑暗等宏观名词。见 W13、W14。
- 人物的“不驯化”通过直接拒绝、先行动后解释、短命令、现实欲望和身体占位呈现，而不是通过“桀骜”“霸气”等标签呈现。

**不这样：**

- 不把宏大形容词当作尺度本身。
- 不用低位实物词制造伪装饰；它必须连接欲望、选择、伤口、关系或社会状态。
- 不将本书特定的肉、酒、世界名词、兵器或笑料复制为通用词库。
- 不通过禁词、频率表或固定句子模板模拟声线。

### Compression / Omission Boundary

抽象词可以进入正文，尤其是在总结权力格局、关系判断或世界尺度时；但它应当：

- 建立在已出现的具体物理或社会事实之上；
- 能改变当前判断或下一步；
- 不取代必要的动作、身体和环境证据。

### Evidence / Anti-Evidence

证据主要来自 W01、W02、W03、W04、W05、W06、W07、W08、W09、W10、W11、W12、W13、W14。

暂无可靠的全书词频、句法分布或词域比例统计；精确词频和普遍性结论为 `INSUFFICIENT`。

## Detail Selection Across Dimensions

| 细节层级 | 值得进入的原因 | 删除后损失 | 主要维度 |
|---|---|---|---|
| Story-bearing Detail | 改变目标、资源、选择或后果 | 因果断裂，人物行动变得无由 | Attention、Knowledge、Causal |
| Embodied Detail | 把抽象状态落到手、脚、呼吸、疼痛、距离或动作 | 身份、身体代价和关系边界消失 | Reaction、Causal、Rhythm |
| Social-Readout Detail | 显示对手、旁观者、家庭或群体如何重新行动 | payoff 仍停留在主角自我宣称 | Reaction、Attention |
| Scale Anchor | 用风、光、声音、受损边界、落点或地貌改变读者对尺度的判断 | 世界变成空泛的“宏大” | Attention、Rhythm、Lexical |
| Atmospheric Detail | 改变当前场景的温度、压力或入口感，并与状态变化回收 | 场景温度或抵达感减弱 | Attention、Rhythm |

总体选择顺序通常是：

1. 先让读者知道事情和选择是什么；
2. 再让读者感到身体如何承受；
3. 再用少量环境或群体反应扩大结果；
4. 最后让结果推动关系、权力或下一目标。

删除测试不是“是否好看”，而是：删掉后是否损失身份、因果、关系、身体感、尺度或 payoff。若六者均不受影响，细节通常可以压缩或省略。

## Production Implications

供 Curator 编译的正向选择原则：

1. 仅当当前场景缺少正在发生的动作、可触物件或即时限制中的必要读数时，Curator 才选择相应细节，否则可以不添加。
2. 将 prose budget 集中到改变目标、位置、身体、关系、权力或下一目标的 scene beat；当前场景已有清晰读数时不重复补充。
3. 对力量与 payoff，仅当当前场景缺少结果或其影响的必要读数时，选择身体或环境结果、对手、群体或秩序反应中的必要细节。
4. 对规则、历史和世界信息，只编译当前选择所需的部分，并将解释绑定到物件、风险或下一项行动；不为满足信息完整而补充。
5. 根据 scene beat 编译节奏：接近与展开允许舒展，决定与撞击压缩，关键结果独立停顿，余波重新打开；仅在当前场景缺少相应节奏读数时调整。
6. 将宏大尺度和抽象判断绑定到少量物理锚点、人物反应与关系后果；仅当当前场景缺少尺度或后果读数时选择必要锚点，不编译来源作品的专名、笑料或固定声线。

## Limits / Insufficient Evidence

- 本版只基于 14 个 bounded windows，不代表全书全部章节或作者整体风格。
- 未进行全书句长、段落长度、词频、词域比例或叙述视角比例统计。
- `EXPOSITION_RULE / DIALOGUE_NEGOTIATION` 与 `DISCOVERY_REVEAL` 的直接窗口数量较少，结论仅适用于 W07、W08、W13 所支持的场景条件。
- 普通场景的饭桌、孩子、市场质感主要由 W02、W04、W09 支撑，不能外推为所有低压段落的固定结构。
- 成人关系窗口只支持“动作承担边界、微反应与未来成本”的功能判断，不支持迁移具体关系配置。
- 妖魔功法、世界层级、特定兵器、天界结构、具体奇观、人物专名、固定笑料与原句均保持 source-specific。
- 本版是 Selection DNA，不是 Writer checklist、人物设定、Canon、Planner 或永久文风。
