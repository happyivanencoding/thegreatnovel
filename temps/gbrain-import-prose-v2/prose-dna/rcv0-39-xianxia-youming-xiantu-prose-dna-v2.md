## Cross-Scene Invariants

1. 抽象压力通常先经过一个可验证的身体、器物、空间或称谓，才进入文本。关系压力落在领口、手腕、后颈、锁钉、座位和称呼上；力量落在屏障碎裂、剑气失手、空间收摄上，而不是先由判断句宣布。

2. 信息只推进到当前人物能够听见、触到、观察或暂时推断的边界；未知只有在继续影响风险判断时才保留。

3. 场景的有效单位是状态变化：谁改变了位置、筹码、接触关系、行动资格、身份读数或下一步选择。

4. 句段、细节和词汇随状态变化重新分配带宽：计算与观察时展开，认知截断、突袭或结果落地时压缩，余波需要重新展开时再放慢。  
   证据：W01、W02、W05、W10、W13、W14。

## Attention DNA

### Core Selection Strategy

文本优先把字数投向“会改变下一步”的局部：一个异常声音、一件改变筹码的物件、一次关系位置移动、一种可验证的身体失态，或一次使旧判断失效的结果。

低压场景先用少量生活动作、称呼和群体反应建立正常读数；异常出现后，注意力才收紧到能证明变化的感官或身体细节。高压场景不平均描写所有招式、人物和环境，而集中描写当前转折所需的接触、距离、价格、反应或失败。

力量兑现时，字数花在外部结果和旧关系位置变化上，不花在能力目录或境界宣告上。W14 只用雾影、剑气失手、空间收摄和称呼改变完成权能证明。

### Scene-Conditioned Behavior

- `ENTRY_EXPLORATION`：先写正在执行的赶路、追查或观察，再选择一个局部偏差改变其意义。W01 由闲谈转入音杀；W13 由石粉、窗影和旧画转入认知受控。
- `DISCOVERY_REVEAL`：把注意力放在证据载体、认知门槛和发现后的身体中断。W02 的画、笔势和真息比完整剑诀更重要；W04 的声音来源和无法出声的听者状态比身份答案更重要。
- `DIALOGUE_NEGOTIATION`：重点不是每个人说了多少，而是称呼、停顿、物件、座位、接触和报价是否改变筹码。
- `ACTION_COMBAT`：集中描写会改变位置、目标、保护对象或资源状态的动作；非关键招式压缩为结果。
- `ORDINARY / EXPOSITION_RULE`：保留火堆、盯火、递眼色、插科打诨等低压关系细节，让说明发生在人物生活中。
- `PAYOFF_POWER_PROOF`：选择一个外部对象无法完成的动作或一个旧关系无法维持的称呼，作为现实证明。

### Compression / Omission Boundary

可以压缩：

- 完整人物履历；
- 未影响当前选择的世界背景；
- 未进入行动结果的法术原理；
- 重复的情绪判断；
- 无法改变空间、因果或关系的环境陈设；
- 已经由动作证明过的能力。

必须保留：

- 异常的具体触发物；
- 当前交易的即时价格；
- 至少一个能证明身体或关系变化的细节；
- 关键动作造成的距离、对象或资源变化；
- 仍会影响下一步判断的未知。

这不是“细节越少越好”。当规则、解释或背景会直接改变当前判断时，应展开。W02 在发现之后解释“看见笔势却未看见身法”；W11 通过问题引入规则；W01 的传闻在音杀出现后立即获得现场验证。

### Evidence / Anti-Evidence

证据：W01、W02、W04、W05、W06、W09、W10、W11、W13、W14。

限制性证据：

- W11 是唯一明确的低压普通说明窗口，不能据此断言全书所有日常场景都采用同一密度。
- W14 是极短的力量兑现窗口，不能据此推导所有 payoff 都只需要一次外部失败。
- 没有全文句长、词频、段长统计，不能把局部注意力分配写成数量规律。
- `INSUFFICIENT`：无法判断全书在不同卷章中的注意力预算是否发生系统性变化。

## Knowledge DNA

### Core Selection Strategy

知识呈现服从当前 narrator/POV 的可验证范围，而不是服从读者需要的完整百科。文本可以解释，但解释通常发生在某个观察、失败、问题或交易之后，并且只解释足以改变当前判断的部分。

留白不是隐藏所有信息，而是把人物暂时无法确认的内容保留为异常、猜测、半句判断或不可靠的“明悟”。只要未知仍然改变风险判断，便应保留；一旦当前行动需要某条规则，就应让它以局部、可用的形式进入。

### Scene-Conditioned Behavior

- W01：传闻先作为闲谈出现，音杀随后把传闻转成现场危险；知识通过验证进入，而非先完成世界说明。
- W02：李珣先看到画中笔势，之后才理解自身“知剑而不会使剑”的缺口；解释紧跟失败，不提前讲完理论。
- W04：偷听者只能知道听见的声音和自己的推断；身份术语出现，但不被强行整合成答案。
- W06：信息按口诀、秘密和身体代价逐句交易；说明本身就是筹码。
- W08、W12：合作请求和邀请被保留在可利用但不可放心的状态，动机不被 narrator 代为确认。
- W13：物证、记忆和推理逐步累积，但“明悟”本身被重新怀疑，知识获得过程也成为危险来源。
- W11：规则通过晚辈提问、长辈接话和旁人反应进入，说明不脱离关系现场。

### Compression / Omission Boundary

应暂时留白：

- 角色尚未确认的身份；
- 对手未公开的动机；
- 关系历史的完整版本；
- 尚未影响下一步的法术全貌；
- 只能由作者全知视角确认的真相。

不应留白到无法理解当前选择：

- 谁在施压；
- 当前人物试图保住或争取什么；
- 某个动作为什么迫使下一步发生；
- 某条信息如何改变价格、资格、位置或风险。

### Evidence / Anti-Evidence

证据：W01、W02、W04、W06、W08、W11、W12、W13、W14。

反证与边界：

- W02 和 W11 说明知识不是一律少解释；关键是解释要由当前发现或问题触发。
- W01 说明背景传闻可以进入正文，但只有在立即改变现场读数时才值得展开。
- W14 说明能力机制可以保持极简，只需让结果足以证明空间权能。
- `INSUFFICIENT`：没有证据判断全书 narrator 是否始终保持同一种叙述距离，也没有证据支持全书统一的“信息延迟比例”。

## Causal DNA

### Core Selection Strategy

因果解释停在“读者能复原当前状态为什么改变”的粒度。需要保留触发物、即时选择、接触或交换、结果和下一步压力；不需要把每个机制、历史动机和心理根源一次解释到底。

明确判断可以出现，但优先作为人物在当前证据上的暂时判断，或作为刚发生结果的局部归纳，而不是作者替人物封闭所有因果。

### Scene-Conditioned Behavior

- `ACTION_COMBAT`：先给位置、目标和接触，再给结果。W05 的停战由共同威胁、松手、拉开距离和再次面对追兵组成；W10 的每次攻击都迫使某人避血、救人、转向或暴露资源。
- `DIALOGUE_NEGOTIATION`：因果表现为筹码链。W06 中信息换口诀；W08 中“合作”改变的是风险配置而非信任；W12 中追杀消息和第三人使上车成为更难拒绝的选择。
- `EMOTION_RELATIONSHIP`：不急于解释“真实情感”，而让习惯、称呼、触碰和回避造成因果压力。W03、W07、W09 的关系推进均通过动作失控或关系位置改变完成。
- `DISCOVERY_REVEAL`：因果链停在可验证事实与风险推断之间。W04、W13 的发现没有自动转为谜底。
- `PAYOFF_POWER_PROOF`：让外部对象的失败完成因果证明。W14 不解释洞天全部原理，只展示剑气为何失效、对方为何被送走。

### Compression / Omission Boundary

可以省略：

- 完整旧案；
- 每个法术的机制推导；
- 人物行为的最终心理解释；
- 不影响当前选择的远因。

不能省略：

- 当前行动的直接触发；
- 关键接触或交换；
- 结果如何迫使某人改变下一步；
- 必要的损耗、代价或关系后果。

“停止解释”的位置通常是当前下一步已经清楚、但更深一层仍会改变风险判断的地方。若未知不再产生判断压力，留白就会变成空洞。

### Evidence / Anti-Evidence

证据：W01、W02、W05、W06、W08、W09、W10、W13、W14。

限制性证据：

- W02、W11 表明明确解释可以有效，但必须服务刚发生的失误或当前问题。
- W10 的战斗因果是空间和对象关系，不支持逐招机制化解释。
- `INSUFFICIENT`：没有足够证据判断全书是否存在稳定的长因果链或章回级因果节奏。

## Reaction DNA

### Core Selection Strategy

反应是状态变化的可见接口，不是情绪标签的替代装饰。选择一个有触发物的动作、对白变化、停顿、呼吸、视线、物件处置或距离变化，让读者看到人物的身体、关系或判断已经偏移。

情绪判断并非禁止；但若人物尚未承认、关系仍在博弈中，优先让反应先出现，判断后置或保持不完整。

### Scene-Conditioned Behavior

- `EMOTION_RELATIONSHIP`：W03、W07、W09 以称呼、揪领、松手、扣腕、习惯、嗓音和失控动作承载关系压力。
- `DIALOGUE_NEGOTIATION`：W06、W08、W12 以吞咽、站起、停步、回头、沉默、接触和座位变化显示谈判位置。
- `DISCOVERY_REVEAL`：W04、W13 以憋气、寒颤、额热掌冷、肌肉紧松和反复转圈显示知识已经超出稳定判断。
- `ACTION_COMBAT`：W05、W10 的反应主要是松手、拉开距离、避血、救援、转向和撤退，属于战术反应。
- `ORDINARY`：W11 的递眼色、苦笑、盯火和移开目光让低压场保留未说出口的关怀或戒备。
- `PAYOFF`：W14 通过停住旧称呼、对方皱眉、剑出鞘又失效来确认关系位置翻面。

### Compression / Omission Boundary

应压缩：

- 没有触发物的“震惊、复杂、痛苦、愤怒、嫉妒”等概括；
- 同一心理状态的重复身体反应；
- 为了制造人味而添加的无后果动作。

应保留：

- 一个能回溯到具体触发物的反应；
- 一个改变关系、空间或判断的非语言变化；
- 反应后的新选择、沉默或代价。

高压对白不必每轮都添加动作，但连续几轮之后应有可见的压力变量变化。反应必须改变读者对当前状态的理解，而不是只增加身体名词。

### Evidence / Anti-Evidence

证据：W03、W04、W05、W06、W07、W08、W09、W10、W11、W12、W13、W14。

反证与边界：

- v1 的“每 2–4 轮出现非语言变化”只适用于高压交涉和关系对峙，不能变成所有场景的机械频率。
- W11 的低压动作不负责升级冲突，而是保持群体关系。
- `INSUFFICIENT`：没有证据支持固定的微反应数量、固定身体部位或固定心理显影顺序。

## Rhythm DNA

### Core Selection Strategy

节奏由 scene beat 和 state change 决定，而不是由“短句多”或“长短句结合”决定。

当文本需要承载空间、条件、观察、多个筹码或复杂判断时，句子和段落获得更大带宽；当认知被截断、行动结果落地、谈判空间突然收窄或权力翻面时，表达压缩并留下停拍。结果之后，如果新状态需要被重新理解，节奏再展开。

### Scene-Conditioned Behavior

- W01：赶路和闲谈允许展开；音杀出现后，异常独占短段，形成认知被切断的效果。
- W02：看画时认知逐步累积；发现门槛由单句截断；随后真息运转展开，肩上一拍再次切断。
- W03、W06、W08、W12：长句承载框架、诱导和多方计算；短句承担拒绝、反问、报价、停顿和无法继续的答复。
- W04：说话者变化与听者反应轮换成段，使信息差保持现场性。
- W05：互殴阶段压缩为动作链；停战后短暂恢复判断，再进入追逃。
- W10：潜伏观察、诱局加速和高阶对撞使用不同句群尺度；段落按人物选择接力，而非按招式目录排列。
- W11：环境铺陈后进入短问短答和问题接力，不因说明场而固定成慢节奏。
- W13：步骤化探查逐步变成长假设，认知失控处重新收束。
- W14：等待、见面、质问、拔剑、落空、送走六个小状态足以完成兑现，不扩大战斗规模。

### Compression / Omission Boundary

应在以下位置压缩：

- 认知突然失效；
- 一个动作已经改变结果；
- 权力位置完成翻面；
- 关键停顿本身成为信息；
- 结果需要留下余波而非继续堆叠动作。

应在以下位置展开：

- 读者尚未建立空间地图；
- 多方筹码仍需比较；
- 新状态的代价需要被理解；
- 低压场景需要让关系背景进入；
- 结果之后人物必须重新计算。

不能把每句都断成短段，也不能为视觉整齐保持均匀段长。

### Evidence / Anti-Evidence

证据：W01、W02、W04、W05、W06、W09、W10、W12、W13、W14。

限制性证据：

- W11 只有一个低压普通窗口，不能推出全书普通场景的固定节奏。
- 当前证据支持 scene-level rhythm，不支持章节级或全书级节奏统计。
- `INSUFFICIENT`：没有平均句长、段长、标点比例或加速间隔的可靠统计。

## Lexical DNA

### Core Selection Strategy

词汇选择服从当前功能：优先使用能定位身体、器物、空间、接触和后果的具体名词与动词；抽象词只有在成为当前谈判对象、规则对象或身份判断时才进入，并需要被动作、价格、距离、称呼或现实结果压住。

因此，Lexical DNA 不是禁词表，也不是词频表，而是“什么功能由哪一类词承担”。

### Scene-Conditioned Behavior

- `ENTRY_EXPLORATION`：使用当前可触空间和物证，如风雪、屏障、石粉、抽屉、窗影；认知词汇随着异常出现，不先用抽象危险概括。
- `DISCOVERY_REVEAL`：词汇贴近证据载体和感知通道。W02 以笔势、空白、浓淡和体内运转承载发现；W04 以玉碗、声息、喘息和陌生命名承载认知失重。
- `DIALOGUE_NEGOTIATION`：让正式抽象词与具体压力并置。合作、立场、信任、代价必须被杀意、吞咽、座位、价格、触碰或拒答重新解释。
- `EMOTION_RELATIONSHIP`：使用称呼、生活习惯、身体部位、衣物和手势，让关系而非情绪标签成为句子的中心。
- `ACTION_COMBAT`：优先使用能复原运动路线和结果的动词、接触对象与损伤名词，如松手、拉开、避开、夺取、失去凭依、转向。
- `ORDINARY / EXPOSITION_RULE`：使用火堆、眼珠、兽吼、递眼色、侧脸、垂眸等小尺度词汇，使规则说明留在人际现场。
- `PAYOFF_POWER_PROOF`：选择最少但可验证的空间和力量词，让他人的失败动作承担能力证明。

### Compression / Omission Boundary

可以删除：

- 不能改变空间、身份、因果或关系的泛化评价；
- 连续重复的气氛词；
- 仅为显得宏大而增加的抽象名词；
- 没有动作后果的术法名录。

应保留：

- 能指向具体接触或伤害结果的动词；
- 能固定空间尺度和对象关系的名词；
- 能改变关系位置的称呼；
- 与当前判断直接相关的抽象词及其现实摩擦。

抽象词不是禁用对象。W08、W12 的“合作”等词正因为与杀意、利用和受控状态不一致，才产生张力。

### Evidence / Anti-Evidence

证据：W01、W02、W03、W04、W05、W06、W07、W08、W09、W10、W11、W12、W13、W14。

限制性证据：

- 没有词频或词性统计，不能声称某类词在全书中占比更高。
- 不能把具体人物的称呼、羞辱语汇或暴力语汇迁移成模板。
- 不能把“具体名词多”简化成“形容词少”或“语言冷峻”。
- `INSUFFICIENT`：无法判断全书词汇是否存在稳定的时代、地域或人物群体分层。

## Detail Selection Across Dimensions

细节进入文本的理由，不是增加感官密度，而是承担可验证的叙事功能。

| 维度 | 优先选择的细节 | Story function | 删除后会失去什么 |
|---|---|---|---|
| Attention | 建立常态后出现的异常声音、动作或物件 | 指示注意力应从当前生活转向危险或发现 | 失去身份边界、紧张阈值和场景转折 |
| Knowledge | POV 能直接听见、触到或观察到的证据 | 固定 narrator 的知识边界，并让未知保持可判断 | 失去信息差、可靠性边界和读者参与判断 |
| Causal | 触发物、接触、交换、价格、结果 | 让读者复原状态为何改变 | 失去因果链、选择压力和下一步的必然性 |
| Reaction | 与称呼、问题、习惯或失败动作绑定的微反应 | 泄露隐藏状态，或改变关系、筹码、身体控制 | 失去关系身份、身体代价和未说出口的意图 |
| Rhythm | 认知中断、结果落地、权力翻面处的停顿或段落边界 | 标记 scene beat，告诉读者状态已切换 | 失去冲击、尺度和结果的可感边界 |
| Lexical | 具体身体、器物、空间和后果动词 | 把抽象压力转译为身份、因果、关系或尺度 | 失去可定位性、动作路线和功能性语气 |

细节层级应服从功能：

- Story-bearing 细节指定方向、筹码、规则、身份或 payoff。
- Embodied 细节显示身体代价、关系距离和控制权。
- Atmospheric 细节只建立温度、声音、光线、材质或尺度，随后退到背景。

W01 的风雪和无声建立危险尺度；W06 的冰壁、后颈和触温让谈判成为受制状态；W09 的洗手习惯和锁钉把关系历史变成当前行动；W14 的雾影和剑气失手证明洞天权能。它们都不是“写得更丰富”，而是替抽象信息承担可验证功能。

## Production Implications

1. Curator 应优先选择能改变当前选择、关系位置、知识边界或空间结果的具体细节，并按 scene family 决定其密度与优先级；仅在当前场景缺少必要读数时选择，否则可以不添加。

2. Curator 应保留 POV 可验证的证据面；未知仅在仍会影响下一步判断时保留，且只有当解释会改变筹码、价格、资格或行动时，才提高 Knowledge 预算。

3. Curator 应优先选择能形成“动作或话语 → 状态变化 → 下一步压力”的必要材料；ACTION_COMBAT 关注空间与接触，DIALOGUE_NEGOTIATION 关注筹码与关系位置。

4. Curator 仅在当前场景缺少由触发物引起的可读反应时，选择身体、称呼、停顿、物件或距离变化等必要细节，不把泛化情绪判断当作主要证据。

5. Curator 应把节奏预算放在 state change 上：状态仍需计算时允许展开，认知截断或结果落地时压缩，结果后的代价和新选择需要理解时重新展开；当前场景已有相应读数时不重复添加。

6. Curator 应按功能选择具体名词、后果动词和受现实摩擦约束的抽象词，不生成禁词表、词频目标或作者模仿模板。

## Limits / Insufficient Evidence

- 本轮依据的是《幽冥仙途》的 14 个 bounded windows；85 个窗口是六本书合计，不是本书单独的 85 个窗口。
- 这是场景功能证据，不是全文风格统计；不支持平均句长、词频、形容词比例、段长分布或固定节奏公式。
- W11 是唯一明确的低压普通说明窗口；普通场景的全书规律为 `INSUFFICIENT`。
- W14 是明确的 payoff proof 窗口，W02 兼有局部兑现；其他类型 payoff 的稳定规律为 `INSUFFICIENT`。
- 未提供足够证据判断整部作品的章节开头、章节结尾、长期余波或卷章级信息节奏。
- 未将人物、专名、世界规则、具体关系配置、签名比喻或原句转化为可迁移规则。
- 本轮为只读蒸馏，未修改任何文件。
