# 《死人经》Selection Prose DNA v2

## Evidence Basis

本卡仅基于：

- Terra evidence：`sirenjing-terra-evidence.md`
- v1 Prose DNA：`sirenjing-prose-dna.md`
- `source_book_id=rcv0-40-wuxia-sirenjing`

两份输入实际提供并逐窗定位的是 14 个 bounded windows，覆盖早、中、晚期：

- `W01` 规则兑现
- `W02` 日常入口
- `W03/W07/W08/W12` 谈判与关系重定价
- `W04/W09` 动作与混战
- `W05/W06/W11` 发现、背叛与身份判断
- `W10/W13` 能力或权力回报
- `W14` 照护与关系余波

本轮不重新读取原著，也不把未在两份输入中列出的其他窗口当作证据。

## Cross-Scene Invariants

1. **注意力跟随可改变选择的证据。** 细节、对白和动作获得篇幅，是因为它们改变当前的判断、站位、身份、关系或后果，而不是因为本身具有感官或修辞强度。证据见 `W01/W04/W06/W07/W09/W10/W13/W14`。

2. **知识按当前判断者的可见范围进入。** 叙述通常先给有限感知、误判或异常动作，再在选择已经发生后补足足以改变下一步的信息。证据见 `W02/W05/W06/W07/W11/W12`。

3. **节奏在状态改变处变细，在稳定或过渡处变粗。** 长句和较完整段落承载条件、复盘和谈判层次；短句、动作句和独立段落承载命令、转折、身体后果和权力确认。证据见 `W01/W04/W06/W07/W09/W10/W13`。

4. **关系和权力由外部证据结算。** 称谓、距离、物件、旁观者反应、制度动作和伤势，比直接宣布“信任”“臣服”“感动”更能确认状态变化。证据见 `W03/W07/W08/W10/W12/W13/W14`。

## Attention DNA

### Core Selection Strategy

文本优先把篇幅给当前正在改变以下事项的内容：

- 谁能做什么；
- 谁正在失去选择；
- 谁的身份或立场被重新解释；
- 哪个物件、距离或身体后果会改变下一步；
- 一个胜负如何传导到旁观者、制度或关系。

注意力不是平均分配给人物、背景和动作，而是围绕当前的决策节点移动。

### Scene-Conditioned Behavior

- **规则说明场景：**先给足以理解规则的概念，再迅速转向具体身体和惩罚，使规则立即获得现实重量。见 `W01 / segment-0002:42-84`。
- **低压入口场景：**先花篇幅建立日常安全感，再让一个小异常改变读者对日常动作的解释；异常出现后，叙述逐渐收窄。见 `W02 / segment-0003:91-134`。
- **谈判场景：**每次新条件、新距离、新称谓或旁观反应改变局面时，才重新分配注意力。见 `W03/W07/W08/W12`。
- **动作场景：**跟踪主角当前目标、保护对象、资源边界和一个转折，不平均覆盖所有参与者。见 `W04/W09`。
- **发现场景：**把注意力放在有限线索和旧动作的新意义上，而不是完整阴谋报告。见 `W05/W06/W11`。
- **回报场景：**注意力从私人胜负扩展到公共反应，再落回疲惫、求情、伤口或新压力。见 `W10/W13`。
- **关系场景：**只保留能改变照护、拒绝、计划或关系判断的身体和生活动作。见 `W14`。

### Compression / Omission Boundary

可以压缩：

- 不改变当前选择的稳定背景；
- 未被当前行动调用的完整制度史、计划全貌和技术谱系；
- 群战中不影响保护圈或战场转折的参与者；
- 已经被动作充分证明的重复判断。

不应压缩：

- 决策成立所需的规则、条件或漏洞；
- 改变身份、关系、站位或期限的物件；
- 动作的关键接触点及其结果；
- 回报之后确认胜负的公共或制度反应。

### Evidence / Anti-Evidence

`W02` 表明注意力并非始终高压、狭窄；日常基线需要足够篇幅才能让异常产生反差。  
`W10` 和 `W13` 表明回报也不能只聚焦胜负本身，公共确认和余波同样需要篇幅。

`INSUFFICIENT：没有全文统计证据支持固定篇幅比例、平均细节数量或所有章节都采用相同注意力曲线。`

## Knowledge DNA

### Core Selection Strategy

知识选择服从当前 narrator/POV 的可见范围和即时判断，而不是服从作者已经知道的完整事实。

叙述优先提供：

1. 当前角色能观察到的动作、声音、距离和物件；
2. 当前角色作出下一步判断所需的最小信息；
3. 足以改变旧事件意义、但不足以关闭全部疑问的 reveal。

### Scene-Conditioned Behavior

- **有限认知的入口：**保留少年对安全和危险的误判，不提前揭示完整计划。见 `W02`。
- **黑暗或不可见空间：**用呼吸、距离、火石、临时武器等有限感知组织判断，不替角色补全视野外真相。见 `W06 / segment-0289:19691-19761`。
- **背叛发现：**先展示失败、未归、照常行礼或共犯沉默，再回看其意义。见 `W05`。
- **身份审讯：**先让对方因维护同伴、面子或身份而缩小答案，再补足必要线索；不立即给出完整铁证。见 `W11`。
- **高压谈判：**可以在对白中逐层暴露对手的隐藏条件，但信息必须立即改变筹码、行动或距离。见 `W07/W08/W12`。
- **公共回报：**当某个私人动作已经改变全场关系时，叙述才短暂拉远到人群、军队或制度反应。见 `W10/W13`。

### Compression / Omission Boundary

保留：

- 当前角色必须知道才能行动的规则和条件；
- 一个判断成立所需的可见证据；
- 能重估既有动作的最小 reveal；
- 使不确定性继续影响下一步的缺口。

暂时留白：

- 他人未被当前行动调用的完整动机；
- 关系是否仍包含某种情感；
- 胜招或组织的完整机制；
- 反转之后尚未改变当前行动的额外背景。

### Evidence / Anti-Evidence

`W01` 表明知识并非一律延迟：规则在惩罚前必须明确到足以让惩罚可理解。  
`W06` 表明身份信息可以在安全检查之后进入，因为此时它会立即改变盟友判断。  
`W07` 表明隐藏计划也可以被直接说穿，只要说穿本身正在剥夺对方的谈判空间。

`INSUFFICIENT：未覆盖章节的全知叙述、内心独白比例和一般性背景说明边界无法判断。`

## Causal DNA

### Core Selection Strategy

因果解释停在“读者和当前角色能够理解下一步选择”的粒度。

因果链通常保留：

> 条件或误判 → 选择 → 可见后果 → 新约束或新选择

不追求把所有动机、历史和机制一次解释完；但关键行动不能只靠气氛、威压或神秘感连接。

### Scene-Conditioned Behavior

- **规则—惩罚：**规则先出现，惩罚在同一窗口兑现，证明规则确实支配行动。见 `W01`。
- **谈判—伏杀：**条款只解释到足以理解时间漏洞，随后漏洞立即转化为伏杀。见 `W04 / segment-0177:12159-12225`。
- **背叛 reveal：**解释在失败之后回收，使旧动作产生新意义，而不是提前展示完整计划。见 `W05`。
- **逃离—身份怀疑：**先完成脱险和安全检查，再补足组织身份；新知识立即扩大风险。见 `W06`。
- **高压交易：**条件、继承、援助、婚姻或人质等信息逐项进入，每一项都改变可牺牲对象或行动出口。见 `W07/W08/W12`。
- **动作与混战：**因果集中在站位、方向、命令和伤势，不展开每名参与者的完整招式逻辑。见 `W09`。
- **权力回报：**私人决断必须通过军令、跪下、放箭、离场或求情传导到公共结果。见 `W10/W13`。

### Compression / Omission Boundary

可以省略：

- 不影响当前选择的历史动机；
- 未被使用的完整计划；
- 不改变胜负的招式谱系；
- 反转之后尚未产生行动后果的解释。

必须保留：

- 使选择成立的条件；
- 使反转可回溯的前置动作；
- 使动作结果可追踪的接触和后果；
- 使回报能够外部确认的传导链。

### Evidence / Anti-Evidence

`W01`、`W04`、`W07` 和 `W13`共同表明，因果可以明确，但明确的是当前行动所需的因果，不是完整世界百科。  
`W05`、`W06` 和 `W11`表明，延后解释不是目的本身；它必须让旧动作重新获得意义或让下一步判断变得更危险。

`INSUFFICIENT：没有证据支持“一律少解释”或“一律延迟因果”的全书规则。`

## Reaction DNA

### Core Selection Strategy

人物状态优先通过可观察的行为泄露：

- 动作；
- 对白偏移；
- 停顿；
- 称谓变化；
- 物件处置；
- 距离和站位；
- 旁观者的沉默、退开或执行。

反应只有在改变读者对人物目标、关系、威胁或权力的判断时才值得进入。

### Scene-Conditioned Behavior

- **高压谈判：**握住、后退、堵耳、看门、拔刀、保持距离等动作替代情绪总结。见 `W07`。
- **联盟与试探：**递出、翻看、收回或保留风险物件，使信任保持可撤销。见 `W03/W08`。
- **动作场景：**看房梁、闭眼、下短命令、抓住伤处或改变保护位置，显示即时判断。见 `W04/W09`。
- **权力回报：**跪下、沉默、离场、低头、不敢转身或不等报告便传令，确认权力已经作用于他人。见 `W10/W13`。
- **亲密与照护：**递药、扶持、盖被、观察伤势，同时保留嘴硬、拒绝和否认。见 `W14`。
- **直接判断场景：**当命令、判决、交易或威胁本身就是行动时，可以直接说出，不必强行改写成微反应。见 `W01/W10/W12`。

### Compression / Omission Boundary

省略泛化的“害怕”“愤怒”“感动”“复杂”等封口式判断，前提是动作或对白已经足够让读者完成判断。

保留：

- 会改变关系或威胁评估的反应；
- 能让情感动作产生现实后果的照护；
- 直接启动制度或行动的命令、判决和交易；
- 旁观者对权力变化的外部反馈。

### Evidence / Anti-Evidence

`W12` 表明人物可以完全冷静、直接地说出威胁和筹码；Reaction DNA 不是禁止明确对白。  
`W10` 表明一个躬身、沉默或长出一口气只有在连接公共判决与私人负担时才有价值。

`INSUFFICIENT：没有证据支持每个情绪都必须通过动作表达，也没有证据支持固定的微反应清单。`

## Rhythm DNA

### Core Selection Strategy

句群和段落随 scene beat、压力变化和状态改变调整。

- 长句或较完整段落：条件、复盘、层层谈判、有限因果；
- 短句或动作句：命令、拒绝、确认、突发威胁、身体结果；
- 独立段落：关键一击、站位变化、沉默、文件或公共反应；
- 较舒展的余波：伤亡、疲惫、求情、关系重估和新压力。

### Scene-Conditioned Behavior

- **入口：**低压日常允许展开；异常出现后句段收窄。见 `W02`。
- **规则兑现：**规则段可以完整，决定落下后切为动作和结果句。见 `W01`。
- **谈判转战斗：**程序性谈判较平直，真正交手后拆成距离、接触和后果的短节拍。见 `W04`。
- **黑暗发现：**等待和不可见感知可拉长；火光或身份确认后转为逐项短确认。见 `W06`。
- **谈判重定价：**每个新筹码、移动、停顿或旁观反应获得一个节拍；成交或威胁落地时压缩。见 `W07/W08/W12`。
- **群战：**先交代资源边界，再用命令和战场转折形成短促拍点。见 `W09`。
- **回报：**公共确认可以分段展开，之后用较长余波承接现实成本。见 `W10/W13`。
- **照护：**身体处理多用短动作句；无法直说的情感和否认可以用绕话延长。见 `W14`。

### Compression / Omission Boundary

压缩：

- 稳定移动、重复操作和不改变状态的过渡；
- 群战中的无关人群和重复攻击；
- 已经完成判断后的同义反应。

展开：

- 状态转折前的条件；
- 决定性动作的方向和后果；
- 关系或权力重新定价的停顿；
- 胜利之后尚未结算的成本。

### Evidence / Anti-Evidence

`W12` 的高压父子谈判并非连续碎句，而是以相对静止的短回合制造压力。  
`W10` 的公开判决使用平静完整句，说明紧张不等于句子必短。  
`INSUFFICIENT：未进行全文句长、段落长度或节奏频率统计，不生成数值模板。`

## Lexical DNA

### Core Selection Strategy

词汇选择服从场景功能，而不是固定的“冷峻词库”。

抽象词可以出现，但通常被压到可操作的对象、身体、距离、文件、武器、灯光、门口或制度动作附近。判断方式随当前功能变化：

- 规则和判决使用明确的制度判断；
- 谈判使用条件、资格、筹码和可牺牲对象；
- 发现使用线索、关联、证据和有限推断；
- 动作使用方向、接触、位置和结果；
- 关系场景使用生活动作、身体状态、拒绝和绕话。

### Scene-Conditioned Behavior

- **规则/权力：**制度词必须能落到惩罚、职位、期限或身体结果。见 `W01/W10/W13`。
- **日常入口：**生活物件和家庭动作先于宏大世界词，用来建立安全感及其破裂。见 `W02`。
- **谈判：**身份词、交易词、盟约词和亲密称呼随着权力变化重组。见 `W03/W07/W08/W12`。
- **发现：**词汇围绕有限感知和可验证线索组织，不直接变成全知结论。见 `W05/W06/W11`。
- **动作：**名词和动词承担空间战术功能；不把动作退化成招式名或效果名堆叠。见 `W04/W09/W13`。
- **关系与照护：**生活词、死亡词和身体词可以并置，使关系保留实际尴尬和风险。见 `W14`。

### Compression / Omission Boundary

当具体动作、物件或旁观反应已经承载判断时，可以压缩：

- 泛化情绪形容；
- 空泛的力量形容；
- 不改变行动的修辞性环境词；
- 只重复角色已经表现出的态度。

但不能删除：

- 能区分制度处置层级的抽象词；
- 能改变契约、身份或行动资格的判断；
- 能让读者理解空间、对象和结果的具体名词与动词。

### Evidence / Anti-Evidence

`W01/W07/W08/W12` 支持“抽象权力词靠近具体可执行对象”的选择机制。  
`W02` 同时说明词汇并不总是硬、冷或制度化；低压生活场景会使用家庭、生活和物件词。  
`INSUFFICIENT：未进行词频统计，不输出高频词、禁词表或固定句式模板。`

## Detail Selection Across Dimensions

| 细节功能 | 什么时候进入 | 它承担的 story function | 删除后会失去什么 | 证据 |
|---|---|---|---|---|
| Story-bearing detail | 决策、身份确认、交易或回报之前 | 改变选择、期限、阵营、身份或关系 | 因果和 payoff 无法落地 | `W01/W05/W07/W08/W11/W13` |
| Embodied detail | 压力升高、关系重定价或伤势出现时 | 把判断和情绪压到手、脸、呼吸、姿势或动作上 | 身体感与潜台词 | `W03/W07/W09/W14` |
| Spatial/control detail | 站位、距离、出口、保护圈或公共秩序改变时 | 说明谁能接近、谁能拒绝、谁控制场面 | 权力尺度和行动可追踪性 | `W04/W06/W07/W09/W12` |
| Sensory anchor | POV 受限、空间不可见或需要确认尺度时 | 让读者共享当前角色的感知限制 | 现场判断和空间方向 | `W02/W04/W06/W09/W13` |
| Payoff carrier | 胜负已经发生但尚未被公共世界确认时 | 通过跪下、离场、放箭、军令、沉默或求情确认结果 | 回报的外部真实性 | `W10/W13` |
| Care/relationship detail | 照护、拒绝、嘴硬或秘密计划同时存在时 | 让关系通过仍然执行的行动显形 | 关系重量和余波 | `W14` |

细节不是越多越好。优先保留能同时承担两项以上功能的具体对象；纯粹装饰性的服饰、气味、布景和感官扩写，在不改变判断、尺度、关系或后果时退出文本。

## Production Implications

供 Curator 编译的正向选择原则：

- 将每个 scene 的注意力中心编译为一个当前决策、一个主要保护对象或一个正在改变的关系/权力状态。
- 将知识输出编译为当前 POV 可获得、且足以推动下一步的最小信息单元；把尚未影响行动的完整动机和背景保留为未决。
- 将因果编译为“条件或误判 → 选择 → 可见后果 → 新约束”的连续链，并在规则、契约、反转和回报处保留关键连接。
- 将反应编译为会改变判断的动作、对白偏移、停顿、物件处理、距离或旁观者反馈；直接命令和判决保留其行动功能。
- 将句段和词汇编译为随 scene beat 变化的颗粒度：条件与复盘展开，状态落点压缩，抽象 stakes 邻接可执行的对象、身体或制度动作。

## Limits / Insufficient Evidence

- 直接可核验材料只包含 14 个窗口；`INSUFFICIENT：未提供其余 71 个窗口的正文观察或 locator`。
- 未做全文词频、平均句长、平均段落长度、对白比例或感官密度统计。
- 不能据此断言所有章节、所有 POV、所有低压场景都遵循相同选择机制。
- 规则兑现、公共回报和终局动作具有较强功能性，不能单独代表普通叙述。
