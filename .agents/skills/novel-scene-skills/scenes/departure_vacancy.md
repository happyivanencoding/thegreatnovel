# departure_vacancy

**Primary Reading Question:** 一个长期重要的人离开、失联、沉眠或暂时不可用后，谁从此必须自己行动，哪些旧选择不再可用，谁会因此改变策略？

离开场景的核心不是移动过程，也不是把告别写得足够伤感，而是让“这个人不在了”成为可见的新局面。离开前如果人物本来就会做安排、留下期限、拒绝某件事、交出某个信息或明确自己的目标，让这个动作先成立；随后用留下者真正遇到的第一个问题证明旧状态已经结束。有人失去过去的保护，有人第一次不得不自己决定，有人可以利用空位，有人反而获得过去没有的自由。具体变化由人物欲望和当前冲突决定，不预设牺牲、责任或组织接管。

不要为了提醒未来回归而不断说“他还会回来”。只有 Canon 已经存在期限、承诺、物件、缺席位置或其它召回器时才保留它，然后允许这条线真正沉睡。当前场景只需要让离开产生不可回滚的关系或行动变化。若主要问题只是路程压缩，不使用本 Skill；若人物已经归来、重点变成重新辨认与重新入场，则转 `reunion_reentry`。

**Stop when:** 缺席已经通过一个新的决定、失败、机会、敌人反应或关系变化被读者真实感受到；继续告别或解释离开原因不再增加新的故事状态时结束。
