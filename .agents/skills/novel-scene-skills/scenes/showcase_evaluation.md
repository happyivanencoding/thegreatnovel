# showcase_evaluation

**Primary Reading Question:** 谁必须按新的尺度重新估价这项能力、成果或人物，估价后现实改变了什么？

**Projection Guidance:** 仅当新尺度或现实后果不清时，盯住基准、代表性用途与重新估价后的待遇或行动；已清楚则 NONE

**Revision Watch:** NONE

## Use When

展示结果会迫使某个拥有分配、部署、资格、谈判或策略权的人改变原有待遇或行动。

## Generation Lens

先保留旧尺或旧报价，再让成果在一个有意义的实际条件下工作。优先选择一项不可逆的身体、空间、资源、保护或机会结果，而不是连续参数。

观察者按自身利害反应：识别者校准上限，受威胁者改防或改逃，分配者改价、资格或部署，普通人获得直接保护或行动信心。

只保留一个主结果和一个现实后果。公开承诺以执行者承担成本验真；若结果已经成立并改变待遇，立即转入新局面。若仍缺条件、授权或动员，只补最短的执行闭环。

## Revision Lens

Preservation First：

- 只有围观和夸赞而没有现实变化时，接上一个已有行动权人物改变待遇、资源、策略或资格的动作。
- 只有参数没有用途时，把已有结果落到一个可见的身体、空间或机会成本。
- 反转没有旧误判行动时，不硬造反转。
- 多个观察者重复震惊时，合并为不同利害中的一个代表性反应。
- 已经重新估价却继续测试时，停止追加同层级证明。
- 不要求每次展示都产生排名、订单或公众欢呼。

## Failure Patterns

好看的动作被误写成展示；排名成立但无人改变行为；无行动权角色轮流宣布很强；公开宣言没有执行成本；用回放战斗代替现实定价；展示完成后继续炫技。

**Stop when:** 尺度、用途和至少一项现实判断或行动后果已经清楚。
