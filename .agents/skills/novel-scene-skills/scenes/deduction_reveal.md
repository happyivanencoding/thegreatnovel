# deduction_reveal

**Primary Reading Question:** 已知事实重新组合后，哪种解释突然能同时成立，并改变人物下一步做什么？

**Projection Guidance:** 仅当事实连接或行动后果不清时，盯住解释约束与一次改判或行动；结论成立即停，已清楚则 NONE

**Revision Watch:** NONE

## Use When

关键证据已经在场，主要问题不再是寻找更多事实，而是解释它们之间的时间、位置、动机、因果、身份或规则关系。

## Generation Lens

只召回支撑当前矛盾的少数事实，让不同解释互相约束。暂定模型可以成立，也可以被已有事实迫使修正；每次修正都应减少一种解释、暴露一个前提或改变验证方式。

旧证据重释必须接入新的时间、位置、对象或规则约束，并改变调查对象或验证动作。Reveal 的价值在于人物因此改防谁、去哪、信谁、利用什么机会或放弃哪条路线。

必要时只做最低限度的验证。只解释当前行动需要的层级，不凭揭示补造更大的世界机制。若还需要持续获取外部证据，返回 `investigation`。

## Revision Lens

Preservation First：

- 重新念线索却没有解释变化时，删除重复事实，保留真正承重的连接。
- 结论跳跃时，补一个已有的时间、位置、动机或规则约束，不新增事实。
- 揭示没有行动后果时，接上一个已有角色能作出的判断或选择。
- 暂定推断被写成确定真相时，恢复不确定性。
- 真相成立后继续搜集确认时，删除多余确认或切换到新问题。

## Failure Patterns

把旧线索按顺序复述；用灵光一闪跳过连接；让人物知道超出证据边界的答案；Reveal 只服务读者不改变行动；多个角色轮流确认同一真相；推理场景变成新的线索搜集。

**Stop when:** 一个解释已经能约束关键事实，并明确改变人物的判断或行动。
