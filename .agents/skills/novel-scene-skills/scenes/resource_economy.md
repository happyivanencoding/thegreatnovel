# resource_economy

**Primary Reading Question:** 人物手里的有限资源在当前价值体系中究竟能换来什么？该保留、出售、交换、分配还是投入哪一项，选择会关闭什么机会，又会让谁改变行动？

**Projection Guidance:** 仅当当前缺口、价格参照或配置后果不清时，盯住资源去向与关闭的机会；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物已经控制现金、学分、材料、装备、药物、能源、战利品、信息、时间、配额、资格或人情，并要决定如何留、卖、换、投入、共享、抵押或承诺，使下一行动变得可行或不可行。

若尚未找到或控制具体目标，转 `hunt_acquisition`；若材料正在经历关键转化，转 `crafting_creation`；若成果需要被新的尺度重新定价，转 `showcase_evaluation`。若配置本身是债务、保护、信用或亲密关系的主问题，转 `relationship`；若投入只回答还能否继续交战或撤离，局部转 `combat`。

## Generation Lens

先给欲望，再给资源。让读者知道人物要保住什么、进入什么、解决什么缺口或承担什么风险。价值尺来自一个熟悉的反事实：不用它会失去哪项行动，换掉它会关闭哪项未来选择，或它能把人物推到哪层权限。

先诊断稀缺类型：现金、流动性、配额、渠道、时间、安全边界、适配能力、机构权限或可出售资产不足。高收入仍可能买不到受限材料，资产很多仍可能不能安全出售。

价格只在改变接受、压价、保留、出售、路线或风险时进入正文。给一个熟悉参照物即可，不用完整预算、汇率表或库存清单替代选择。

机会成本必须是关闭的门。让人物在至少两个真实用途之间决定：保留未来权限或换取当前现金，购买武器或失去训练额度，接受高危任务换取材料，分配给同伴换取继续合作。被放弃的选项应有可感后果，但不机械附加损失。

配置必须成为交换。卖方、机构、同伴、家人或对手应回应价格、分配和承诺，交易完成后至少改变一项行动权、时间、身份、关系或路线。

奖励到账后优先兑现刚暴露的缺口，其余物资压缩。战利品分配只在它解决共同风险时展开，并让接受者以行动、态度、保密或下一次承诺回应。

高压场景中，资源选择只回答投入这一项能打开哪一拍窗口。投入后主问题转为交战、追逃或撤离时立即交接。

## Revision Lens

Preservation First：

- 只有价格没有欲望时，把金额落到人物正在失去或争取的一项行动。
- 只有“缺钱”没有机制时，指出是现金、配额、渠道、权限、时间或安全哪一种缺口，并删掉无关数字。
- 有取舍却没有机会成本时，明确被保留或放弃的一项真实选项及其后果。
- 资源到账后继续列清单时，让一项资源立即解决刚暴露的缺口，其余压缩。
- 分配没有关系后果时，只有在已有持续协作时接上贡献、共同成本或信用。
- 高压场景停下来做完整财务说明时，把选择缩成一次投入与一拍行动窗口。
- 经营流程吞掉成长主线时，保留许可、拒绝、转交或有限承诺，删除日常运营。

## Failure Patterns

数字很多却没有改变计划、态度或关系；高价自动等于值得；奖励只是获得某物；资产可无限出售或兑换；机会成本变成机械惩罚；分赃变成物品清单；战斗中插入账本；经营流程取代训练、冒险、关系和主线。

**Stop when:** 资源去向已确定，至少一项真实机会成本已关闭或被承担，配置已改变人物、同伴、机构或下一行动可做之事。
