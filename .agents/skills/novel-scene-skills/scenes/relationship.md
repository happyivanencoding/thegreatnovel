# relationship

**Primary Reading Question:** 既有关系在这一刻具体改变了人物愿意承担什么、允许什么或选择哪条路？

**Projection Guidance:** 仅当关系如何改写选择不清时，盯住具体欲望、对方回应与新边界或路线落点；已清楚则 NONE

**Revision Watch:** 仅修关系被命名却无行为后果，或单方付出被写成双向确认；保留既有边界与责任，做最小删补。

## Use When

共同历史、亏欠、信任、保护、失望、依赖或告别正在改变人物的行为，而不只是改变情绪名称。

## Generation Lens

让关系通过选择和回应显形：一方先做出符合自身历史的动作，对方再按自己的理解回应，随后改变距离、称呼、边界、行动权、风险、路线或共同计划。

关系对象应改变一个具体的安全路线、风险阈值、底牌、时间、劳动或身体承受。日常负荷只有在迁移、缺席、替换、争执或新责任迫使它重新分配时才展开。

公共身份、责任和程序仍可成立；私人靠近、沉默或保护只改变具体的人际边界，不自动改写制度结果。单方照料、保护、离开或牺牲只证明一方的选择，不替对方补出同意或永久关系。

若双方必须据此共同决定去留、风险、照料或边界，应使用具体直说，并由接受、拒绝、改线或共同动作承接。没有可执行共同结论时，才保留微反应或沉默；沉默必须有真实外部反事实。

区分单方选择、对方接受或拒绝、双向确认和竞争义务排序。关系兑现后允许停留，让新位置通过小动作、共同动作或尴尬适应被体验。

## Revision Lens

Preservation First。只修最高价值缺陷：

- 关系只被命名，没有行为后果时，补一个最小的边界、路线、风险或照料变化。
- 单方行动被写成双向确认时，删除未经支持的互爱、和解或承诺结论。
- 私人关系抹掉公共责任时，恢复仍在生效的身份、程序或第三方代价。
- 沉默被解释成深情但没有外部结果时，若已有可接动作则补动作，否则压缩沉默。
- 关系兑现后立即被新危机覆盖时，保留一小段适应或余波。
- 不把关系默认解释为浪漫关系，不设置情绪配额，不以关系强度覆盖师门、群体或生存义务。

## Failure Patterns

用“关系更深了”代替行为变化；亲近自动战胜责任和制度；一方付出被误写成双方共识；每个停顿和物件都被强行翻译；兑现后立即总结或制造新危机。

**Stop when:** 新的关系边界已经由行为、选择或明确表达成立，并且继续互动不再增加关系信息或体验。
