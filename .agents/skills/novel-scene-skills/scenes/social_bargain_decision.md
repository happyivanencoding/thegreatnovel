# social_bargain_decision

**Primary Reading Question:** 谁想让谁做什么；这一轮交流具体改变了谁的条件、信息边界、发言资格或下一行动？

**Projection Guidance:** 仅当诉求或本轮结算不清时，盯住条件、信息边界、发言资格与下一行动；已清楚则 NONE

**Revision Watch:** 仅修连续对白无结算或角色可互换：保留原决定与筹码，合并重复回合或恢复一个已批准的差异化反应。

## Use When

人物正在谈判、试探、招募、审问、拒答、交换条件、公开表态或争夺决定权；对话本身必须改变可行动空间，而不是只搬运信息。

## Generation Lens

先抓住各自最想保住的东西、愿付的代价和真正受话者。重要一句话必须留下可见结算：条件升降、有限信息暴露、信任改变、关系边界变化、发言资格变化、路线关闭或行动启动。

拒答不是气氛。若人物不完整回答，应留下一个可观察替代物：有限事实、新问题、担保、任务、时间点或行动。部分披露只在保留内容仍影响下一轮选择时成立。

动作、距离、旁观者和物件只有在改变谁能发言、谁必须表态、谁可旁听或谁承担风险时才进入对白结构。多人对白只保留会改变决定结构的角色。

专业信息应落在一个未决但可执行的问题上，并推动命令、配置、选人、路线或风险判断。人物声音来自压力下先保护什么、先注意什么、愿意承担什么，而不是口癖。

笑点只能短暂释放关系、面子或压力。真实责任、伤势、权限或行动一旦不可逆出现，立即回到主问题。

多人共同承压时，只保留能落到资源、位置、路线或责任的优先级差异。若新信息推翻了会改变部署的误判，下一拍应重排站位、通路、目标或授权；价值无法兼得时，以稀缺资源的实际投向结算，不强造共识，并让最小空间结构显示谁承担风险、谁有执行权。

## Revision Lens

Preservation First。只修明确失败：

- 连续对白没有改变条件、信息、关系或行动，删并同义回合，保留第一次真正结算。
- 人物可互换，不重写整段，只在一个关键回应处恢复各自已有的首保对象、注意对象或代价边界。
- 拒答只剩冷笑、沉默或反问且没有留下东西时，仅在上下文已有授权结果的情况下恢复一个最小有限事实或行动。
- 专业信息不可执行时，压到足以改变一次选择的最低信息。
- 多人轮流发言却没有职责差异时，保留真正推动状态的少数角色。
- 笑点越过危险、责任、处罚或决定成立后的停止点时，删到现实后果第一次接管场景。
- 不新增交易条件、秘密、筹码、承诺、制度权限或人物动机。

## Failure Patterns

信息搬运；会议纪要；连续试探不付成本；保留项没有筹码价值；身份只剩敬称；所有聪明人同一种声音；笑点吞掉后果。

**Stop when:** 决定、条件、承诺、合作边界、信息边界、发言资格或下一行动已经发生可执行变化。
