# chase_escape

**Primary Reading Question:** 当前功能距离、追踪置信度与出口状态，下一次怎样改变？

**Projection Guidance:** 只展开会改变可达性、可见性、追踪置信度、资源续航或出口权限的动作；已清楚则 NONE

**Revision Watch:** NONE

## Use When

双方仍在通过移动、追踪、改线、遮蔽、载具或出口争夺改变相对态势时使用。

## Generation Lens

距离必须写成功能距离：近距、攻击距、观察距、失联但可追踪距分别允许不同动作。只写更近或更远而不改变行动能力，不构成有效 Beat。

追踪是会变化的信息链。直视、最后位置、真实痕迹、假痕、残余信号和搜索置信度分开处理；每次失去或恢复信息，都要改变搜索范围、延迟或拦截可能性。

安全窗必须有来源、标尺和失效机制。遮蔽、入口、第三方牵制、剩余位移或资源地都不能自动等于安全。资源、伤势和载具只有在改变追击、改线、掩护、携带或撤离时才前景化。

终点不是跑了很久，而是移动已不能解决当前问题，转入战斗、潜入、生存或调查。

## Revision Lens

Preservation First。保留已经成立的距离、路线和资源事实。动作没有造成状态变化时压缩；资源只是报数时恢复一个已有行动后果；已转为战斗、潜入或生存时不补回重复奔跑。

## Failure Patterns

直线距离替代功能距离；失去视野就自动脱逃；发现痕迹就自动追上；安全窗无来源或失效点；弹药、伤势和载具不改变动作；第三方区域自动成为安全区；交接后状态被重置。

**Stop when:** 逃脱、截获、封路、出口隔绝、追踪链稳定断裂，或移动已不能改变结果而战斗、潜入、生存或调查接管。
