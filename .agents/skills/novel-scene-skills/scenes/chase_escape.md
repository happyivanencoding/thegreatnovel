# chase_escape

**Primary Reading Question:** 追逃双方的距离、路线和优势下一刻怎样变化？

追逐的核心状态是“双方之间还能利用多少空间与时间”。先让读者知道谁追谁、逃向哪里或要拦到什么、当前相对位置和最关键的出口/障碍。人物每次行动后，都应让距离、路线、视野、速度、体力、交通工具、可用出口或谁掌握主动方向中的至少一项发生变化；追方会根据逃方刚暴露的路线和习惯调整，逃方也会根据追兵位置重新选路。下一拍来自这种位置关系变化，而不是连续写“跑得更快”。

地形只有在能被利用时才值得展开：窄巷能封路，高处提供视野，门、车、人群、水面、断桥或复杂建筑改变路线选择。误导、弃物、分路、捷径、反向移动、短暂藏身和主动制造阻碍都可以成为策略，但不要求每次追逐都包含险些被抓或一次反转。普通奔跑、重复跨越相似障碍和没有改变相对态势的动作应压缩。

追逃中的身体负担、恐惧和急迫应通过选择体现：人物是否舍弃资源换时间、是否冒险走未知路线、是否停下救人、是否回头确认追兵，而不是不断写喘气和“越来越近”。当追方真正封住路线、逃方脱离视野或双方距离稳定到可以采取另一类行动时，及时转换 Skill。

**Stop when:** 一方真正脱离、被截住、主动停下转战、进入隐蔽状态，或追逃问题已经稳定转成 `combat`、`stealth_infiltration`、`social_bargain_decision` 等其它主场景；继续跑动不再改变相对态势时应结束。
