# recovery_restoration

**Primary Reading Question:** 已经受损、失去或中断的状态，怎样真正恢复，而且恢复到什么程度？

恢复场景的核心状态是“人物失去的功能、关系或生活能力怎样一点点变得可用”。先把缺损写具体：哪里疼、哪种能力失灵、什么记忆断掉、哪段关系不能再按原方式运作；同时明确人物现在最想恢复的并不一定是“满血”，而可能只是重新走路、握剑、说出某句话、认出某个人或重新获得参与生活的资格。治疗、修复、复原或复活过程应对这些具体缺损产生可观察变化。

每一次有效处理都应改变恢复判断：症状减轻、功能回来一部分、某个方法无效、旧限制被确认、人物第一次能承担更复杂的动作。只展开会改变恢复程度、方法或人物选择的步骤；重复吃药、运功、休养和没有新反馈的时间经过应压缩。反复、疼痛、代价或失败可以存在，但不作为所有恢复场景的固定必经税；如果当前恢复本来顺利，就让细微功能回归和人物重新使用它本身承载 payoff。

恢复结果要被体验，而不是只写“恢复如初”。人物第一次重新完成曾经做不到的动作、重新听见/记起某物、重新进入某个关系或工作位置，往往比状态栏更有价值。若恢复直接造成新的能力等级，应转 `breakthrough_advancement`；若主要问题变成测试恢复后的实力，则转 `showcase_evaluation`。关系修复只有在核心变化主要属于双方信任和边界时才应交给 `relationship`。

**Stop when:** 当前恢复程度已经通过功能、感受、关系行为或实际行动被确认，人物知道自己现在能做什么、还不能做什么；继续治疗不再产生新的恢复信息时应压缩或转场。
