# recovery_restoration

**Primary Reading Question:** 人物当前失去的是哪一层功能？什么阻断使普通恢复无效？本场只需恢复到什么行动阈值？部分恢复会怎样改变下一步？

**Projection Guidance:** 仅当恢复层级、阻断条件、行动阈值或残余限制不清时，盯住目标层与首次再用；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物的核心问题是从受损、失去或中断状态重新获得可用功能。

不因出现伤势、药物或休养自动调用。若主要问题已经变成战斗、资源争夺、模型误判、境界跨越或他人定价，应转交对应 Primary。

## Generation Lens

先把“不能做什么”写成可观察事实，再选择本场真正要恢复的一层。不要默认身体、能量、意识、能力和社会位置同步恢复。

当普通疗法无法解释进展时，先处理已经建立的核心阻断，不用不断换药、加痛感或延长时间替代诊断。每个处理动作都应改变恢复判断：确认有效、暴露失败、解除阻断、恢复一项功能，或改变可承担的行动。

长疗程只保留诊断、关键失败、首次有效反馈和首次再用。稳定重复的服药、运功、等待与移动压缩。

部分恢复必须明确现在能完成什么、还不能完成什么，以及为什么当前程度已经足以启动下一项行动。首次再用优先选择已有局势中的必要动作：复工、履约、保护、逃生、谈判或出手。

恢复若带来新境界，先结算恢复，再转入 `breakthrough_advancement`。身体、意识、行动权和社会位置可以分层恢复，不自动同步。

## Revision Lens

Preservation First：

- “恢复了”过于抽象时，补出恢复前做不到、恢复后重新做到的动作。
- 部分恢复被写成全盛时，降回实际阈值，保留会影响下一步的限制。
- 普通治疗反复推进时，找出已建立的真正阻断；没有依据则删除新增阻断。
- 时间跨度很长但状态没有节点时，压缩过程，只保留方法、反馈、阈值或行动变化。
- 残余限制只作装饰时，让它约束下一次选择；做不到时删除该限制。
- 身体已愈但意识或行动权未回归时，分开处理不同恢复层。
- 恢复资源已被看见并争夺时，停止静态疗伤，转入资源或战斗场景。
- 不为制造代价临时添加永久伤残或新规则。

## Failure Patterns

默认恢复如初；用疼痛代替恢复判断；醒来、止血、能量回升和回到峰值被写成同一状态；数日后痊愈却没有行动证明；一次能动被写成稳定作战能力；恢复后继续重复证明同一功能；社会位置由旁白宣布恢复。

**Stop when:** 本场目标层已通过实际行动确认，人物知道当前能做什么、不能做什么，且残余限制已兑现或不再影响下一步。
