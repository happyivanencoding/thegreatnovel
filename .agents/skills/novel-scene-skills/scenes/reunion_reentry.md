# reunion_reentry

**Primary Reading Question:** 一个离开很久、身份或能力已经改变的人回来后，双方如何完成认出、接纳与重新入位，而不是自动恢复原状？

**Projection Guidance:** 仅当认出、接纳、重新入位或当前错位不清时，盯住一项证据、一个限制与新的共同动作或合法分流；已清楚则 NONE

**Revision Watch:** NONE

## Use When

长期分离、误认、异化、失联、阶段性归来或旧关系重新进入公共或私人空间。

## Generation Lens

把认出、愿意重新靠近、允许其重新行动分开。旧物、旧动作、称呼或共同记忆只负责完成辨认；辨认之后必须出现一个当前仍存在的错位，以及一次新的共同动作、共同目的、边界选择，或明确说明为何暂时不能同行。

让回归者当前的新身份、新能力、新责任、伤痕、立场或生活位置有机会改写原定方案。“回家”必须落到哪个家、以什么风险回去。

低风险时可以用习惯、称呼或共同记忆；存在伪装风险时，才递进到旧物、私密记忆、难伪造的能力或行动；公共归来则让旧身份先撞上门槛、程序、团队分工或社会评价。

旧日常只保留一笔，并立即改变当前选择、风险、路线或分工。若双方目标不再兼容，重逢可以停在告别、偿还或有限承认，不强行恢复共同生活。

不完整回归要保留层级：可感知存在、意识回应、身体稳定、独立选择、重新取得团队或社会职能不是同一状态。

## Revision Lens

Preservation First：

- 认出被写成旧关系全部恢复时，保留当前身份、责任、能力或第三方限制。
- 已完成认出却没有行动位置变化时，仅从已有目标补一个最小共同动作或边界。
- 旧日常连续复演并遮蔽当前错位时，压缩为一个能推动选择的回声。
- 没有共同目的时，停止补写“重新开始”，改为已有事实支持的分流或有限关系。
- 不强行补全分离期间未被 Canon 建立的心理、历史或承诺。

## Failure Patterns

一声自报姓名解决全部怀疑；认出、接纳、社会认可和行动资格挤成一拍；旧日常完整复演；拥抱被当作恢复原状；所有重逢都强制遇袭、公开测试或再次分离；没有共同目的却硬写回到从前。

**Stop when:** 双方已经通过共同动作、边界、承诺或合法分流证明这个人重新进入关系，但不是简单回到过去。
