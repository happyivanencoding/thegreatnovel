# stealth_infiltration

**Primary Reading Question:** 人物能否在不暴露真实身份、位置或目的的情况下完成目标？

潜入的核心状态是“任务进度与暴露风险怎样同时变化”。先让谁可能发现、发现什么算失败、人物当前掌握哪些掩护/身份/路线/时间窗口足够清楚。每次靠近目标都应让人物获得新的位置、信息或权限，同时也让某种痕迹、视线、身份核验、声音、时间压力或他人注意力发生变化；守卫和环境会按照自己的规则行动，不是静止障碍。下一拍来自人物对刚发生的暴露变化做出修补或利用，而不是一路‘悄无声息’走过去。

观察巡逻、选择路线、伪装身份、制造合理理由、控制声音和痕迹、借用人流、临场应答都可以推进，但只展开真正改变“被发现概率/发现内容/距离目标多远”的动作。无新差异的开锁、等待、绕路和重复躲藏应压缩。险些被发现可以很有效，但不是强制 beat；如果人物准备充分，也可以通过连续正确判断体现专业性，只要世界仍然会对他的行为给出真实反馈。

暴露也不是只有“完全没事/立刻开战”两档：对方可能只记住脸、产生怀疑、发现物品少了、注意到路线异常或提高戒备，这些都会改变后续选择。若真实身份已经暴露且主问题变成脱离追捕，转 `chase_escape`；若人物主动停下用身份、谎言或利益解决盘查，可能转 `social_bargain_decision`。

**Stop when:** 目标已经在未越过当前暴露边界的情况下取得，人物明确暴露并转入其它行动，或潜入阶段已结束、剩余动作不再围绕隐藏身份/位置/目的；继续隐藏只是在重复同一紧张感时应退出。
