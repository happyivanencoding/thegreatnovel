# stealth_infiltration

**Primary Reading Question:** 当前观察者能通过什么界面验证身份、位置或目的；人物的退出权何时消失？

**Projection Guidance:** 先选一个可达的验证界面，再让观察或修补改变暴露边界；凭证只解决被核验的一层，已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物需要隐藏身份、位置、目的、关系或行动痕迹，并且现场存在真实观察者、制度核验或环境感知时使用。

## Generation Lens

先明确目标、观察者知道什么，以及什么算失败。每场只选实际可达的一两个验证界面：外形、习惯、关系、能力签名、时间、路线、声音或凭证。

每次接近同时改变任务进度与暴露边界。守卫、熟人和调查者按各自知识行动，不共享全知。一张凭证只解决它被验证的那一层，不能同时证明人数、路线、目的、时段和常识。

异常顺利本身也是信息，应改变人物对对方意图和下一步风险的判断。取得目标后立即检查退出权：谁已知情、谁能封路、谁会再次核验、哪条路线仍可用。局部怀疑不等于立即失败，但核心目的或位置失守时必须交接。

## Revision Lens

Preservation First：

- 伪装细节不能被现场观察验证时删除。
- 若伪装过于万能，补一个已有事实支持的不同验证维度。
- 被发现后仍重复潜行时，改为写知情者、出口和下一场景。
- 只写氛围时，保留一个能改变判断的声音、视线或人流变化。
- 不把怀疑直接升级为确认，不把取得目标写成风险清零。

## Failure Patterns

伪装完美却没有验证依据；一张凭证解决所有盘查；守卫静止不动；怀疑直接等于确认；取得目标后风险清零；异常顺利只当奖励；被发现后机械全员开战；静态替身被当作完整掩护。

**Stop when:** 目标已取得且验证链不再追及，或核心身份、位置、目的已失守；主问题转为追逃、战斗、谈判、讯问或调查时停止。
