# exploration

**Primary Reading Question:** 未知空间正在把人物的行动地图改写成什么？

**Projection Guidance:** 仅当行动地图缺口出现时，盯住入口、路线、风险边界与发现后的选择；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物需要确认一个空间能否进入、怎样通行、哪里有价值、哪里危险或下一步应往哪里去。

## Generation Lens

让环境回应人物当前目的，而不是独立展示景色。只保留会改变路线、权限、资源、风险、目标或解释模型的边界、痕迹、居民、设施和地形。

有效发现遵循：

`观察差异 → 暂定判断 → 环境或他人回应 → 新选择`

仅增加奇观、地点名或背景资料而不改变路线、风险、目标、资源或解释模型时压缩。风险推进必须表现为策略变化：能否继续、是否绕行、谁承担失败、是否还能撤离。

高价值地点不等于当前拥有进入权；能力、情报和失败代价不足时，延迟进入本身就是行动。切换 Skill 时交出人物位置、可用路线、已知规则、证据可信度和风险阶段，不重演导览。

首次面对会影响进入或选路的未知空间时，选一个可复核的尺度 ruler（距离、深度、视野、地标或身体承受），并让它直接改变靠近、绕行、分层或撤退中的一次选择；选择成立后压缩同质移动。

## Revision Lens

Preservation First：

- 环境变成景物目录时，删除不改变行动地图的细节。
- 人物位置或入口边界不清时，补一条当前可操作的边界。
- 发现没有产生选择时，补最小的靠近、绕行、标记或撤退决定。
- “很危险”没有策略含义时，改成谁不能继续、哪里不能走或撤离权如何变化。
- 已进入调查、猎取、生存或冲突时，删除继续探索式介绍。
- 不补完整地图、历史或地点百科。

## Failure Patterns

走到哪里介绍到哪里；奇观增加但路线和目标不变；把能看见写成能进入；为保持神秘隐藏眼下能否行动；每个地点同等展开；交接后重复旧空间。

**Stop when:** 未知空间已转成明确的路线、目标、权限、生存、调查或敌人问题；继续走动只增加景物时停止。
