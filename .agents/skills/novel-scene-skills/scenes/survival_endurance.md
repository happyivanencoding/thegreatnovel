# survival_endurance

**Primary Reading Question:** 当原计划被环境击穿且暂时无法结束问题时，谁以什么职责维持生命与行动能力，直到窗口出现？

**Projection Guidance:** 先让一个具体前提失效，再把资源、伤势、时间或出口改写成职责与动作；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物暂时不能直接获胜、撤离、求援或结束危险，必须通过补给、休息、协作、守备、改线或等待维持行动时使用。

## Generation Lens

先写清原计划依赖什么，再让一个可观察事实击穿它。关键变量必须分给具体责任人，并带有触发阈值与下一步动作。

食物、药物、能源和战利品只有在换回体力、守位、移动、士气、撤离距离或敌方迟滞时才前景化。多人场景区分谁守、谁护、谁撤、谁运输、谁维持出口。伤势回答“此人现在还能承担什么”，时间窗由实际承担者校准。

希望必须来自已经积累的信息、资源或环境变化。生存窗口成立后，交接给撤离、反击、求援、战斗、追逃或恢复。

## Revision Lens

Preservation First：

- 环境只是景观时，恢复一个已经成立的计划失效。
- 资源只被报数时，补一项已有功能后果。
- 伤势不改变职责时，改写为守位、携带、撤离或被保护对象。
- 重复疼痛、饥饿和库存报数时压缩。
- 战斗或撤离窗口已成立时，删除继续硬撑的重复段落。
- 不新增灾难、稀缺资源或计划外敌人。

## Failure Patterns

只堆风雪、饥饿和疼痛；原计划从未真正失效；资源发下去后人人自动感恩；所有人承担同一职责；伤员一律留下或撤离；倒计时不改变排序；撤退写成无目标奔跑；窗口成立后仍反复描写痛苦。

**Stop when:** 新路线、撤离、反击、求援、恢复或稳定生存已成为明确窗口，或敌人接触后主问题转为战斗、追逃或调查。
