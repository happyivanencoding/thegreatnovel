# identity_reveal

**Primary Reading Question:** 隐藏身份或真实归属揭开后，谁必须重新判断谁，谁获得或失去什么行动权，公开范围应停在哪里？

**Projection Guidance:** 仅当知识席位、证明物或行动权变化不清时，盯住最小知情集与一项权限、站队或保护变化；已清楚则 NONE

**Revision Watch:** NONE

## Use When

身份、归属、匿名关系、真实权力位置或伪身份的揭露会改变权限、站队、敌意、保护、保密或程序。

## Generation Lens

揭露前先确定知识席位：谁掌握秘密、谁能验证证据、谁只是受影响者、谁仍会按旧身份行动，以及谁知道后能立即改变部署、保护、站队或程序。

公开范围取当前任务所需的最小知情集，不随秘密的重要性自动扩大。证明形式服从接收者的知识与权力关系：本人确认、信物、文书、能力结果或现场后果都可以成立。

真正的揭露必须带来行动权差分：获得进入、调度、庇护或代表他人承诺的权利；失去旧准入、信任或公开位置；迫使敌方改攻、盟友撤手、亲属退出或组织重排；或让某人承担保护、保密或追责义务。

高危身份揭露必须服从已有的保护窗口、撤离路径或能承担敌意的人。关系承认、身份获准进入、恢复信任和解决旧债分开处理。

延迟揭露也必须产生结果，例如验证条件、保密责任、错误建模、部署升级或关系保护。事实、支持性推断和未知原因不能混写。

## Revision Lens

只修行动权链，不扩写世界百科：

- 保留不同人物的知识差异，不把全场改成统一震惊。
- 揭露后无人改变行动时，仅在已有条件内补一个权限、站位、保护或敌对动作；没有依据则降为线索重解释。
- 不必要地全场公开时，缩小到能实际改变行为的知情者。
- 高危真相已公开但没有保护路径时，只有在正文已有援手、窗口或撤离条件时补接。
- 不把身份揭露倒灌成未建立的长期历史、旧关系或隐藏动机。
- 不把高概率推断直接写成必须揭露。

## Failure Patterns

身份揭露只是给读者发答案；全场知道、全场相信、全场同一反应；只改变线索解释而不改变行动；高危真相公开后没有敌意、保护或时间窗口；亲近替代验证与授权；揭露后自动恢复全部旧身份。

**Stop when:** 必要知情者已经据此改变权限、站位、保护、敌我判断或程序。
