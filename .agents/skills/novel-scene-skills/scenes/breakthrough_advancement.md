# breakthrough_advancement

**Primary Reading Question:** 旧能力、身份或生命结构究竟跨过了哪道门槛？当前属于尝试、局部成功、半步、稳定突破还是社会证明？每项资源解决什么，结构瓶颈是什么？跨过后最先能做什么？

**Projection Guidance:** 仅当阶段状态、资源瓶颈、同一判尺或首次新行动不清时，盯住最小差异与停点；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物的旧上限、权限、身体结构、生命层级或能力边界真正失效，并形成新的可用状态。

不因资源增加、感悟出现、称号变化、临时强化、练熟或看见更高方向自动调用。没有结构变化或新状态成立证据时，不称为完整突破。

## Generation Lens

先标出阶段，不把尝试、半步、局部成功、稳定突破和社会证明合并成一句“突破了”。

用同一判尺比较前后状态。若突破前问的是核心能否承载高压，突破后仍应让读者看到核心是否稳定，而不是突然换成气势、等级或围观反应。

拆开资源瓶颈和结构瓶颈：

- 资源可以提供燃料、承载条件、维持时间或关键材料；
- 理解、身体或结构变化才可能解决真正的跨层门槛；
- 每项条件只承担一个明确职责。

失败必须诊断出旧路径为何不够，并改变下一步资源选择、结构方案或行动目标。资源开始消耗、局部成形、看见方向，都不等于稳定突破。

突破后的第一行动优先解决当前已存在的问题：破困、救人、转移、反制、开启新通路或承担此前无法承担的责任。没有合适现场时，不强行安排展示，可延后社会证明。

连续跨越必须分别结算每一道门槛。高阶突破若依赖多种力量，应写出它们如何稳定共存，而不是只写同时暴涨。适应期、消耗或限制只有在已有依据时保留，不把受伤设为固定成长税。

## Revision Lens

Preservation First：

- 只有数值和气势变化时，用同一判尺补出具体状态差异。
- 感悟、资源吸收或半步被写成完成时，降回实际阶段，保留未解门槛。
- 资源被当成结构解法时，明确资源只解决承载、燃料或维持中的哪一项。
- 结构变化没有缺口时，补出已有前置条件中真正缺失、替换或重排的部分；无依据则降低突破结论。
- 突破后没有首次新行动时，在已有局势中补最小可行兑现；没有合适局势则保留延迟证明。
- 私密突破被硬塞围观和排名时，把社会证明延后。
- 同一变化被连续测试时，保留首次有效动作，切出到下一主场景。
- 不为制造重量追加未经支持的永久代价。

## Failure Patterns

能量暴涨替代真实门槛；资源数量直接等于突破完成；想明白直接等于结构改变；局部成功、半步和稳定状态混为一谈；突破前后更换判尺；新状态只存在于旁白和数字；突破后只打木桩；每次突破都受伤或立刻获得社会地位。

**Stop when:** 阶段状态、同一判尺下的前后差异、资源与结构职责、首次新行动或合理的延迟证明已经清楚；若只完成理解、局部成功或资格，则转交对应 Skill 或保留下一门槛。
