# trial_challenge

**Primary Reading Question:** 这道外部门槛究竟授予或剥夺什么？人物拥有哪一个可见的决策权？哪个铰链会改变判定？多阶段试炼本场只结算哪一级权利？

**Projection Guidance:** 仅当资格、决策权、判定铰链或阶段权利不清时，盯住通过后的第一项行动权；已清楚则 NONE

**Revision Watch:** NONE

## Use When

人物必须在明确外部规则、判定线和失败后果下争取进入、资格、资源、位置或权限。

如果外部判定只提供合法身份，过程没有选择、代价或反馈，应压缩为结果。若主要问题是反复练习，转入 `training_learning`；若主要问题是证明能力价值，转入 `showcase_evaluation`。

## Generation Lens

先让读者知道判定物、阈值、失败后的损失和通过后的第一项行动空间。不要只说这场考试很重要。

把资格和真实故事分开。通过一层只授予该层已经承诺的权利，不自动完成救援、复仇、身份承认、资源占有或终局目标。

让人物拥有一个真正可见的决策权：改变顺序、押注强项、选择伙伴、分配资源、承担风险、利用规则或决定退出。若人物没有任何能改变结果的选择，试炼过程应压缩。

重点展开判定铰链，而不是完整考试流程。隐藏规则必须先由现场异常或失败支付验证成本，再让人物修正理解，不在结果揭晓时临时改写规则。

多阶段试炼每次切场都结算权利：保留什么、失去什么、下一层目标是什么、退出会付出什么。团队试炼重点写规则如何迫使队伍指挥、分工、重组或撤退，不平均展示成员。

## Revision Lens

Preservation First：

- 只说很重要时，写明通过后获得或失去的具体行动空间。
- 人物没有决策时，从已建立的选项中补一个改变结果的选择；没有既有选项则压缩场景。
- 资格通过被写成主线目标完成时，分开当前结算层和未结算目标。
- 隐藏规则像作者补丁时，补现场已有的异常、失败和一次验证成本；无依据则删除。
- 多阶段只换地点不换权利时，补每层的资格、退出代价和下一层目标。
- 重复操作没有新反馈时，合并同类尝试，保留真正改变判定的铰链。
- 通过后只有欢呼时，接上有行动权者改变资格、资源、待遇或策略的动作。
- 团队成员轮流炫技时，收回到一个改变整体结果的协作决策。

## Failure Patterns

把考试流程写成流水账；只写赢了一场而没有权利变化；主角没有选择；末尾突然揭露真规则；每过一层只换地图；资格通行证直接等于终极目标完成；团队试炼变成排队展示；确认通过后继续重复证明。

**Stop when:** 外部判定已经确认，本场应结算的资格或权利已经落地，且下一目标、退出代价或未结算层级清楚。
