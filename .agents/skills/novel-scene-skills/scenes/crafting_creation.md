# crafting_creation

**Primary Reading Question:** 人物怎样把材料、工具和方法转化成一个新的实物成果？

制作戏的核心状态是“设计目标与实际成品之间的差距怎样缩小”。先让成品用途、关键性能和当前限制具体：它要承受什么、解决什么问题、哪些材料/工具最关键。人物做出处理后，材料、结构或工具必须给出可观察反馈——强度不足、形变、温度不对、连接方式冲突、精度不够、某种性质意外地合适；人物根据反馈调整方案，使下一步来自真实物性和设计选择，而不是按清单继续下一道工序。

只展开会影响成败、性能、成本或人物判断的步骤。已经熟练、无风险且不会改变结果的重复加工可以压缩；专业细节用于解释“为什么这一步必须这样、这次调整换来了什么”，不要把正文写成教程。失败、返工和材料浪费可以发生，但不应作为所有制作场景的固定税；如果当前方案本来就成熟，可以通过细微选择、效率、质量控制或新的用途体现人物水平。

完成不是一句“炼成/做好了”。让人物检查或实际使用关键性能，使读者看见成品和原目标之间的关系：它能承受多少、哪里仍有限制、外观或操作方式有什么实际差异。若重点已经从“怎么做出来”转成“这个成果到底有多强/值多少钱”，应转 `showcase_evaluation` 或 `resource_economy`；如果核心成果只是理解一套原理而没有实物状态变化，则更接近 `comprehension_insight`。

**Stop when:** 成品已经形成并通过足够证明其当前用途的第一次检验，或制作明确暴露出必须另寻材料、工具或理解才能继续的瓶颈；后续重复工序不再增加新的制作信息时应压缩。
