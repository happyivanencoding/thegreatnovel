# comprehension_insight

**Primary Reading Question:** 人物怎样把目前看不懂的规则、法则、技艺或原理真正想明白，并转化成可用理解？

不要用“若有所悟/灵光一闪”代替悟的过程。先明确人物原有理解，再出现无法解释的新结构；让他观察、比较、模拟、试验或回忆，形成暂定模型，再由失败或矛盾迫使其换角度。真正的 insight 应重组旧知识，并让人物能做以前做不到、解释不了或控制不了的事情。允许长一点的思考，但每段思考都要改变模型。

**Stop when:** 新理解已经可以验证或应用；之后转 training、breakthrough、crafting 或行动。
