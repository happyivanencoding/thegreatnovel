# comprehension_insight

**Primary Reading Question:** 人物怎样把目前看不懂的规则、法则、技艺或原理真正想明白，并转化成可用理解？

这类场景的核心状态是人物脑中的“工作模型”怎样变化，而不是思考持续了多久。先让人物原有理解足够具体：他原本以为什么会发生、凭什么这么判断。随后出现一个旧模型解释不了的现象、失败、反例或结构差异，迫使人物重新观察。每段思考都应做一件事：增加可区分的信息、排除一种解释、发现新的关系，或改变下一次试验；不要用“若有所悟、似乎抓到了什么、灵光一闪”替代变化过程。

人物可以通过比较、回忆、模拟、拆分动作、观察别人、实际试验或把两个旧知识放在一起，形成一个暂定解释。世界必须回应这个解释：试验结果支持一部分、暴露矛盾或迫使他换角度。Insight 真正成立时，旧知识被重新组织，人物因而能够预测、解释、控制或选择以前做不到的事情。可以直接写清关键理解，不必故意用玄虚隐喻维持神秘；但只解释当前行动需要的层级，不顺势讲完整宇宙法则。

与 `investigation` 的区别是这里主要重组已有观察与知识，而不是继续收集外部证据；与 `training_learning` 的区别是这里首先解决“为什么/怎样理解”，而不是把动作练到稳定；与 `breakthrough_advancement` 的区别是理解本身不自动等于境界或能力状态已经跨级。

**Stop when:** 新模型已经足以改变一次判断、试验或行动，并得到最低限度的现实反馈；之后应转入应用、训练、制作、突破或其它具体行动，不继续用同义解释重复“悟到了什么”。
