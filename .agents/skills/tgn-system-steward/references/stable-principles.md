# Stable Principles

这些原则是 TGN System Steward 的长期判断底座。它们不是每次都要逐项检查的 checklist，而是用来找到更深层 root cause 的少量高杠杆约束。

## 1. Reader Appetite Before Defensive Balance

先保护读者原始拉力：

- 我想要这个能力；
- 我想看他赢；
- 我想去那个地方；
- 我想知道那是什么；
- 我想看到这两个人后来怎样。

“合理、成熟、有代价、有责任、有边界”不能在爽点真正成立前自动成为第一反应。

成熟不等于每次 payoff 都立刻补税。

## 2. Fantasy First Is a Reader Priority, Not a Pipeline Religion

Fantasy First 的本质是：男频成长长篇必须持续保护主角本人值得羡慕、值得代入、越来越能做什么。

它不意味着所有阶段都由能力发动，也不意味着 production 永远必须从某个叫 Fantasy Seed 的阶段开始。

如果当前架构用 World / Power / Human 分离更好地保护 fantasy，就使用当前架构；未来有更好的结构，也可以替换。

## 3. Agency > Efficiency

好的非对称优势首先扩大“别人做不到，而我能主动介入什么”，而不是把同一工作做得更快、更稳、更精确。

危险信号：

- 探路效率；
- 检测精度；
- 维修成功率；
- 路线优化；
- 资源调度；
- 权限树和 Build 复杂度增加，但主角本人没有更令人向往。

## 4. Fix the Earliest Semantic Collapse

如果某问题在换一本完全不同的新书后仍会出现，找到它第一次被生成成事实的层。

不要把 World 缺失的问题交给 Writer；不要把 Story Program 的同质化交给 Curator；不要让 State 修未来规划。

系统修复 = 下一本新书从零开始也更难掉进同一个坑。

## 5. Few Deep Rules > Many Hard Gates

默认顺序：

1. 删除不必要字段；
2. 移动 authority；
3. 降低上下文可见性；
4. 改 retrieval distribution；
5. 简化/替换生成顺序；
6. 最后才增加 Prompt 约束；
7. 只有前面都不够时才考虑新 Agent / Reviewer / Scorer / Hard Gate。

每新增一层系统，都要证明它的边际收益高于 token、复杂度、失败率与维护成本。

## 6. Supporting Logic Must Not Automatically Become Story Engine

治理、经济、职业、医疗、工程、物流、验证、规则细节可以真实存在。

但“为因果提供支撑”不等于“值得成为读者前景”。

只有当作者真的选择这些为核心阅读体验时，才把它升级成主发动机。

具体优先在：

- 谁想要什么；
- 谁阻止；
- 主角做什么；
- 世界怎么回应；
- 谁得到/失去什么；
- 什么从此改变。

实施步骤只展开到足以支持这些事实。

## 7. Backstage Principles Must Not Become Generated Ontology

Action Space、Net New、Expectation、Mystery Depth、Impact、Compounding 等是作者侧坐标。

它们可以用于评估和约束，但不能被模型直接写成世界内部的资源、组织理念、人生哲学、势力结构或固定字段税。

正确关系：

`后台价值观 -> 当前阶段真正的问题 -> 具体故事事实`

而不是：

`后台价值观 -> 固定 schema -> 为填字段发明剧情`

## 8. Authority Separation Beats Self-Restraint When Leakage Is the Cause

如果 LLM 因为同时看到 A 与 B 而自动把二者合理化成一个主题，优先信息隔离，而不是不断追加“不要合理化”的 negative constraints。

典型例子：

- World 已知 lock -> Character 自动生成 key；
- Power 已知 -> Biography 自动变成能力隐喻；
- Future Plot 已知 -> World 自动预留路线。

独立上下文、deterministic projection、deterministic merge 往往比“请克制自己”更可靠。

## 9. Character Is a Person, Not a Psychological Proof

Human 不是一条人生哲学的证明题。

健康结构倾向于：

- lived facts；
- competing motives；
- stable choice bias under conflict；
- person-specific relationships；
- current desire as mutable state。

允许：

- 贪、怕、赢、爱、性欲、审美、虚荣、享乐、责任、好奇、谨慎、自利、依恋同时存在；
- 这些动机互相冲突；
- 人物知道长期代价却仍做非最优选择；
- 同一种 bias 在不同现场有完全不同的 realization。

禁止把人物净化成“自主、负责、有边界、抗控制”的统一优秀人格。

## 10. Relationship Must Change Choice

“重感情”“关系很深”“团队很信任”不是 Relationship Gravity。

更强证据：

`无此人时会选 A -> 因为这个具体的人实际选 B`

可以改变：

- 风险阈值；
- 去留；
- 路线；
- 时间分配；
- 暴露底牌；
- 机会牺牲；
- 未来力量/生活选择。

换成一个同等有用的人未必成立。

## 11. Growth Is Longitudinal, Not a Stage Tax

全书必须真实变强，但不要求：

- 每个大型阶段升级一次；
- 每个 block 给一个新奖励；
- 每十章开一张新地图；
- 每章证明能力成长。

Power / growth grammar 负责“怎样能变强”；Story 负责“什么时候、通过什么人物和因果真正实现”。

阶段可以主要由 Life、Fantasy 或 World 发动。

## 12. Narrative Compounding > Asset Compounding

真正的复利是故事不回原点：

- 已得能力继续改变行动；
- 旧关系继续影响选择；
- 敌人学会并改变策略；
- 身份变化带来新冲突；
- 旧谜团被重释；
- 过去结果改变未来可能性。

不是资产名词越来越多。

## 13. Concrete Desire > Abstract Importance

“重大”“改变世界”“自由”“成长”“影响力”都很容易是空的。

优先找具体对象：

- 那把剑；
- 那个人；
- 那座城；
- 那场比赛；
- 那个身份；
- 那种力量；
- 那次重逢；
- 那个不能输的公开场面。

如果模型只能解释“为什么重要”，却说不清“人物具体想拿到什么”，优先视为抽象化风险。

## 14. Commercial Quality First, Diversity Second

多样性是为了扩大搜索空间，不是为了完成配额。

四个 candidate 可以有一个明显弱；这比系统把四个都解释成“正确”健康。

不要为了 diversity 强制：

- 一个贪、一个色、一个权、一个恋家；
- 四种阶层平均分布；
- 四种伦理立场平均分布。

但如果四个看似不同却都由同一种心理运动驱动，应判 candidate collapse。

## 15. High Precision / Low Noise for GBrain

GBrain 不追求越多越好。

Source-specific DNA 可以很丰富，但默认 REFERENCE_ONLY。

ACTIVE 的条件：

- 真正新增判断能力；
- 有证据；
- 跨书/跨窗口足够稳定；
- 与已有 craft 不近义；
- 有明确 transfer boundary；
- 不会污染无关 retrieval。

宁可 lane 空着，也不弱卡补位。

## 16. Story Facts Before System Bookkeeping

输出首先要是小说事实：人物、欲望、物、地点、冲突、动作、结果。

系统术语是后台压缩和审计语言。

一旦正文/规划开始大量呈现：

- 权限；
- 节点；
- 路线；
- 资源循环；
- 验证闭环；
- 资产组合；
- 风险管理；
- Action Space / Net New 本身；

先检查系统语言是否泄漏成故事材质。

## 17. Reader-First Prose

Writer 层最常见的 AI 问题不是“句子语法错误”，而是：

- 不重要的物理/流程细节写得太清楚；
- 真正重要的人物目标和规则反而含糊；
- 作者脑中模型清楚，读者脑中模型未建立；
- 动作、内心、旁白、总结重复同一层意义；
- planning language 泄漏正文。

正文先让读者知道：谁在做什么、为什么此刻重要、发生后改变了什么。

## 18. Shock Recontextualization, Not Just Explanation

成熟长篇应保留少量**震撼式长期重释**：旧事实、旧异常、人物行为、宝物或关系在后续被重新理解时，读者不仅“终于知道答案”，还会产生明显惊讶甚至 shock 爽感。

高价值重释同时满足：

- 当下足够意外；
- 回看前文又能找到已存在的证据或异常，而不是临时空降；
- 揭晓后立刻改变力量理解、身份分量、关系结构、敌我判断、宝物价值或世界格局。

来源可以是能力、身份/过去、关系、旧事件、宝物、敌我关系或世界联系；**不默认等于隐藏身世，也不是每阶段伏笔税。**

## 19. Comparative Privilege Needs a Persistent Ruler

**新奇不等于强。** Core Power 应形成读者能比较的优势幅度：同层普通人/天才通常做到什么，主角凭异常提前、低代价或独占了什么原本做不到的特权。允许有条件越级；边界用于防止无条件万能，不应把优势削回普通水平。若候选来自 Novelty Spark，强度也不能靠删除那条单一异常/条件来获得。

世界前台力量尺也不能只在开篇出现一次。境界、等级、潜力、熟练度、亲和度、装备、能量、战绩或排名都可以成为 ruler；不要求全有，也不合成单一总战力分。突破、新能力/装备、公开验证、新强敌、越级结果或世界换挡后，应自然重新校准，让读者持续知道：**主角在哪档、哪里超标、离下一档多远。**

## 20. Do Not Overcorrect

修“AI 理性偏见”不等于要求所有人物冲动。

修“工程化”不等于禁止技术题材。

修“治理化”不等于世界没有制度。

修“职业人格”不等于职业不能塑造经验。

修“阶段税”不等于长期成长可以缺失。

每次修复都问：是否把一个默认偏置改成了另一个默认偏置？
