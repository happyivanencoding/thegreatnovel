# Atomic Chapter Obligations Audit Protocol

> Stable audit method distilled from the 2026-08-29 v0.3 experiment. This is not a production snapshot and does not authorize an Atomic fast route.

## 1. Purpose

When a local Paragraph-Delta or bounded reviser claims that a chapter is safe, do not ask another LLM to classify the whole draft as safe/unsafe. Compile explicit obligations from Frozen Authority and validate the **complete final draft**.

Atomic closure can prove bounded factual safety. It cannot prove top-tier prose or commercial appetite by itself.

## 2. Source and identity precedence

For current actor identity:

`Current Frozen Mission explicit actor > explicit current Primary fallback > remote Human / Book fallback`.

A stale prototype name may not override the actor named in the current Mission. Pronouns cannot repair an explicit wrong actor.

For facts:

`Occurred Canon > Frozen Mission / Reader Release / Power / Human > Curator > Primary > optional inspiration`.

True incompatible sources fail closed. Missing context, keep-unknown instructions and repetition diagnostics are not automatically conflicts.

## 3. Typed obligation families

At minimum distinguish:

- actor → action → object;
- Direct Result;
- State Change;
- Ending;
- original / copy / custody / possession / use right / title;
- received / entitlement / pending / lost / disputed;
- time window versus completed event;
- stable power position / battle-scale output / temporary effect / cooldown;
- Public Proof;
- scheduled Reader Release;
- unresolved fact;
- named relationship transition;
- triggered Human cue;
- protected commercial value already present in Primary;
- whole-draft no-invention boundaries such as fabricated prior dialogue/history.

## 4. Modes

- `terminal`: true by chapter end.
- `pending`: must remain future/open; repeated wording is not required.
- `conditional`: required only after a named trigger is proven.
- `must_remain_unknown`: unauthorized answer is forbidden; silence is allowed.
- `preserve_if_present`: protect Primary value only if the relevant paragraph/category is touched.
- `diagnostic`: true source conflict or unsupported grammar; fail closed when material.

## 5. High-risk boundaries

### Money and resources

A first/partial payment cannot satisfy full settlement unless Frozen Authority explicitly authorizes partial fulfillment. An amount or unit not present in Authority is not a harmless detail.

### Power

Higher-scale resistance, a one-scene composite effect or knowledgeable praise does not create a stable tier. A cooldown is not the same as terminal dissipation.

### Public Proof

Require one causal chain for the same protagonist/topic:

`visible performance → qualified ruler → behavioral repricing`.

Do not assemble three unrelated paragraphs. Public Proof never authorizes an unapproved breakthrough.

### Relationship

Bind the transition to the same named counterpart. A cooperation scene with person B cannot satisfy a Mission transition involving person A.

### Human cue

Require approved Human authority, the same named person and a concrete contact/treatment/private trigger. “Make it human” is not atomic.

### Commercial value

Desire, relationship tension, reward possession, surprise and social repricing are `preserve_if_present`, not quotas. Ordinary semantic similarity cannot replace a surprise turn.

## 6. Gate behavior

- Validate the complete final draft, not only changed paragraphs.
- Local patch correctness is insufficient if a later paragraph asserts the opposite state.
- Any hard/triggered `FAIL`, `UNKNOWN` or `CONFLICT` blocks adoption.
- Unsupported grammar and true source conflict preflight fail closed.
- Full fallback must pass the same gate. If it still fails, report `FULL_REVISER_RESIDUAL_FAILURE`; do not silently save.

## 7. Evidence standard

Keep separate:

1. controlled safe/unsafe boundary tests;
2. known-bad mutation recall;
3. historical Full shadow, which is not gold;
4. real final-draft Reader and Authority blind;
5. independent repeatability;
6. cross-book coverage;
7. fallback-adjusted **complete** route wall, including discarded Delta, Full fallback and residual repair.

A low coverage gate can look safe by refusing almost everything. Report preflight coverage and unsupported families explicitly.

## 8. Production rule

Freeze the boundary method before freezing the compiler. A current compiler must not become production default until it has explainable cross-book typed coverage, no residual hard failures, acceptable repeatability, Reader + Authority non-regression and real fallback-adjusted end-to-end speed.
