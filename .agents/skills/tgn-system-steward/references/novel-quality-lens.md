# Novel Quality Lens

这些维度用于审计成熟中文男频成长长篇。不要每次全部打分；只选择当前问题真正相关的维度。

## 1. Primitive Reader Pull

最基础的问题：读者有没有产生直接欲望？

- 我想要这个能力；
- 我想看他赢；
- 我想知道那个秘密；
- 我想去那个地方；
- 我想看这段关系继续；
- 我想知道他下一步会怎么选。

如果文本只能解释“为什么设计得合理”，却没有这些拉力，优先判读者 appetite 不足。

## 2. Core Fantasy

健康 Core Fantasy 通常：

- 一句话能懂；
- 相对世界正常值明显特殊，并能说清同层普通人/天才与主角之间的 `Privilege Delta`；
- 读者愿意拥有；
- 能产生多个直观使用场景，必要时允许有条件越级而不是只增加便利；
- 正常成长与异常成长都真实增加主角能力，并能与后续功法、装备、环境或传承产生新组合；
- 高阶有质变，不只数字变大；
- 有边界，但边界不把 fantasy 变成工作流程。

警惕 Ability = Job / Diagnostics / Routing / Maintenance。

## 3. Protagonist Agency

主角是否因为自己想要、偏爱、愤怒、好奇、关系、野心或判断主动制造局面？

还是：

- 被任务推；
- 被组织安排；
- 只是最擅长解决问题的人；
- 按风险最优路线工作。

高 agency 不等于永远反控制，也不等于每次都拒绝合作。

## 4. Growth / Upward Motion

男频成长长篇允许短暂低谷，但长期必须能复述：

- 以前打不过谁，现在能；
- 以前进不了哪里，现在能；
- 以前只能接受什么，现在可以改变；
- Core Fantasy 的玩法怎样升级；
- 身体、寿命、战斗、移动、认知或规则掌握怎样真实变强；
- 读者能否用世界内反复出现的 ruler 判断主角当前到底几级 / 几星 / 几重 / 哪个数字序列、哪里超标、离下一精确位置或下一大档多远；World Root 是否有稳定精确 Grammar，Human T0 / State Current Power Position / macro Expansion 是否保持同一坐标连续性；若本章已经真实突破，结果处是否直接命名新的精确位置，而不是只给本地术语/现象让读者自行换算；越级胜利是否被错误当成升级；
- 高价值非对称优势显露时，按现场条件检查三条**并列、没有高低之分**的爽点：有真实观众时群体是否真的被撼动（全场安静、喧哗骤停、所有人明显震惊等）；最懂行者是否短促说明“精确位置/正常值 → 超标点 → 稀有/异常意义”；关键观察者是否真的换了动作/价格/待遇。主力量已有精确尺时，三条线是否共享同一坐标，例如43级对58级，而不是后台有数字、正文仍只写“很强”。大型 Public Proof 可以三者一起吃满，不以“克制”自动删群众震动；首次显露、新层级/复合、新圈层或旧估值过时时，是否再次校准，而不是开篇说过一次就永久消失。

财富、职位、团队规模不能长期替代主角本人变强。力量尺也不能只在开篇或设定文档里存在。

## 5. Concrete Desire Economy

世界与人物是否有真正值得争的东西：

- 功法；
- 神兵；
- 名额；
- 身份；
- 洞府；
- 船；
- 城；
- 某个人；
- 一场比赛；
- 一个秘密；
- 一种生活。

价值必须可感知：得到它以后，生活/战斗/身份/关系具体改变什么？

## 6. Character IP / Human Specificity

拿掉能力后，这个人还值得看吗？

看：

- competing motives；
- 非最优但可信选择；
- stable choice bias；
- variable realization；
- 欲望是否有身体性、物质性、关系性、审美性、胜负性；
- 是否会反复暴露自己的偏心，而不是统一做“成熟正确选择”。

不要把“奇怪”当必需。安静、谨慎的人也可以不可替代。

## 7. Relationship Gravity

重要关系是否真的改写行为？

强证据：

- 原本会走，因为某人留下；
- 原本会藏，因为某人暴露；
- 原本选安全，因为某人冒险；
- 原本追更优机会，因为某人放弃；
- 原本不回头，因为某人回头。

“关系很深”“很信任”不是事件证据。

## 8. World Appetite

世界是否让人想：

- 去那里；
- 见那个人；
- 拿那个东西；
- 看那个奇观；
- 参与那场争夺；
- 知道那段未知。

世界独立不靠治理复杂度证明，而靠没有主角仍有具体故事在走。

## 9. Story Engine Variation

长期故事是否只是：

`接任务 -> 危险地点 -> 竞争 -> 拿资源 -> 升级 -> 更大地图`

健康长篇可以交替由：

- Life；
- Fantasy；
- World；
- Relationship；
- Mystery；
- War / Competition / Exploration 等

发动。

不要求平均配额，只要因果自然。

## 10. Narrative Compounding

过去结果是否继续活着：

- 旧能力继续用；
- 旧敌人学会；
- 旧关系改变新选择；
- 旧身份带来新限制/机会；
- 旧谜团重释；
- 旧奖励首次真正进入实际行动。

如果每个 arc 结束后像重新开局，复利失败。

## 11. Outline Executability

Outline 应该让 Director 知道“这几十章具体发生什么”，但不提前写成 scene workflow。

好的 story anchor 包括：

- 谁想什么；
- 谁阻止；
- 主角关键选择；
- Core Fantasy 怎样参与；
- 发生什么不可逆结果；
- 这个结果为什么引出下一个 anchor。

坏信号：

- 观察 -> 分析 -> 验证 -> 调整 -> 实施；
- 每个 block 固定升级/奖励/新地图；
- 抽象说“扩大影响力”“获得更多选择权”。

## 12. Scene Realization

正文是否真的把事件写成正在发生的场景？

检查：

- 谁在场；
- 谁想什么；
- 动作有没有收到真实响应；
- 对话有没有改变现场；
- 环境是否参与因果；
- payoff 是否真正发生；
- 结果是否可见。

不要把小纲换成更长的概述。

## 13. Reader-First Information Order

第一章尤其重要：

- 读者先知道该关心什么；
- 核心规则在需要时足够清楚；
- 明显陌生/架空世界里，普通人从小知道的公共常识不应让读者猜：主流力量、粗略强弱尺、当前/下一档现实含义、会改变生活的危险、上升入口/价值物中与前几章真正相关的部分，应能被读者直接复述；
- 具名试场/选拔/招募/契约第一次成为主角当前欲望时，如果 Story Program / Outline 已批准其公开价值，读者也应直接知道“成功参与通常能打开什么”；这走 Plan/Director 链，不要求 World Vision 预知主角未来结果；
- 火盆、制服、器物、建筑、站位、术语和氛围可以承载 Texture，但不能单独充当规则说明；
- 非重要物理/技术过程不要比核心 fantasy 写得更清楚；
- 新名词、尺度、组织不要在读者没有模型时高速叠加。

“每句都懂，但连起来不知道看什么”通常是 reader model 建立失败。

相反，“画面都看懂，但仍要自己推理这个世界为什么这样运行”通常是 **Texture Present / Rule Missing**。不要把未知原因提前揭晓；只要求已经属于公共知识的答案足够直接。

## 14. Prose Humanization

AI 味常来自结构习惯，而不仅是词汇：

- 每段都总结；
- 抽象解释覆盖具体动作；
- 情绪动作/内心/旁白三重解释；
- 均匀句长；
- 模板化否定排比；
- **漂亮二段论 / aphoristic closure monoculture**：事实或动作已经成立后，另起短句做裁断、对照、否定翻转或意义升华，并在一章里反复复现成 `事实 → 金句总结 → 意义解释`；单独一次可能很好，稳定重复才是 AI 结构习惯。审计看语义同构，不看是否复用了“不是 / 怕的是 / 已经够了”等具体词；
- payoff 预告一次、发生一次、总结一次；
- planning language 直接进入正文。

Humanization 优先修信息与节奏功能，不做禁词表。

## 15. Shock Recontextualization

长期回收是否不只是解释谜团，而能让读者**重新理解已经看过的东西**并产生明显惊讶？

强信号：

- 揭晓当下足够意外；
- 回看前文能找到真实证据、异常或被误读的旧事实；
- 新解释立刻改变力量、身份、关系、敌我、宝物或世界格局；
- 读者会产生“原来如此，而且事情比我以为的大得多”的二次爽感。

它可以来自能力、身份/过去、关系、旧事件、宝物或世界联系，不要求隐藏血脉/身世，也不做固定数量伏笔。

## 16. Narrative Surplus / Organic Surprise

顶级作品经常有“不是为了完成当前系统目标，但就是让人记住”的东西：

- 一个人的小怪癖；
- 一场无收益的比赛；
- 一段关系动作；
- 一个漂亮场面；
- 一次冒险；
- 一种无用但迷人的器物或文化；
- 一个主角明知不划算仍想做的选择。

系统过度优化时最容易先删掉这些 surplus。

它们不是强制配额，但完全没有时，作品容易像精密项目计划。

## 17. Canon / Unknown Boundary

场景是否尊重已知与未知的权威边界？

检查：

- 已批准公共事实是否在需要时足够清楚；
- Future Plan 仍安排为 reveal 的答案是否被提前投放；
- 未解释的旧历史、旧对话、隐藏动机或世界机制是否被 Writer 为完整感补造；
- 本章新增确定事实是否由 Director Contract 授权，并真正发生在正文；
- State 是否只记录已经确定的事实，而不是人物猜测。

不要把“解释不足”和“保持未知”混为一谈：该知道的公共事实不说是 delivery 失败；尚未批准的历史答案被补出来是 authority 越界。
