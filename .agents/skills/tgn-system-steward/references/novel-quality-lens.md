# Novel Quality Lens

这些维度用于审计成熟中文男频成长长篇。不要每次全部打分；只选择当前问题真正相关的维度。

## 1. Primitive Reader Pull

最基础的问题：读者有没有产生直接欲望？

- 我想要这个能力；
- 我想看他赢；
- 我想知道那个秘密；
- 我想去那个地方；
- 我想看这段关系继续；
- 我想知道他下一步会怎么选。

如果文本只能解释“为什么设计得合理”，却没有这些拉力，优先判读者 appetite 不足。

## 2. Core Fantasy

健康 Core Fantasy 通常：

- 一句话能懂；
- 相对世界正常值明显特殊，并能说清同层普通人/天才与主角之间的 `Privilege Delta`；
- 读者愿意拥有；
- 能产生多个直观使用场景，必要时允许有条件越级而不是只增加便利；
- 正常成长与异常成长都真实增加主角能力，并能与后续功法、装备、环境或传承产生新组合；
- 高阶有质变，不只数字变大；
- 有边界，但边界不把 fantasy 变成工作流程。

警惕 Ability = Job / Diagnostics / Routing / Maintenance。

## 3. Protagonist Agency

主角是否因为自己想要、偏爱、愤怒、好奇、关系、野心或判断主动制造局面？

还是：

- 被任务推；
- 被组织安排；
- 只是最擅长解决问题的人；
- 按风险最优路线工作。

高 agency 不等于永远反控制，也不等于每次都拒绝合作。

## 4. Growth / Upward Motion

男频成长长篇允许短暂低谷，但长期必须能复述：

- 以前打不过谁，现在能；
- 以前进不了哪里，现在能；
- 以前只能接受什么，现在可以改变；
- Core Fantasy 的玩法怎样升级；
- 身体、寿命、战斗、移动、认知或规则掌握怎样真实变强；
- 读者能否用世界内反复出现的 ruler 判断主角当前在哪档、哪里超标、离下一档多远；突破、新强敌或世界换挡后是否重新校准。

财富、职位、团队规模不能长期替代主角本人变强。力量尺也不能只在开篇或设定文档里存在。

## 5. Concrete Desire Economy

世界与人物是否有真正值得争的东西：

- 功法；
- 神兵；
- 名额；
- 身份；
- 洞府；
- 船；
- 城；
- 某个人；
- 一场比赛；
- 一个秘密；
- 一种生活。

价值必须可感知：得到它以后，生活/战斗/身份/关系具体改变什么？

## 6. Character IP / Human Specificity

拿掉能力后，这个人还值得看吗？

看：

- competing motives；
- 非最优但可信选择；
- stable choice bias；
- variable realization；
- 欲望是否有身体性、物质性、关系性、审美性、胜负性；
- 是否会反复暴露自己的偏心，而不是统一做“成熟正确选择”。

不要把“奇怪”当必需。安静、谨慎的人也可以不可替代。

## 7. Relationship Gravity

重要关系是否真的改写行为？

强证据：

- 原本会走，因为某人留下；
- 原本会藏，因为某人暴露；
- 原本选安全，因为某人冒险；
- 原本追更优机会，因为某人放弃；
- 原本不回头，因为某人回头。

“关系很深”“很信任”不是事件证据。

## 8. World Appetite

世界是否让人想：

- 去那里；
- 见那个人；
- 拿那个东西；
- 看那个奇观；
- 参与那场争夺；
- 知道那段未知。

世界独立不靠治理复杂度证明，而靠没有主角仍有具体故事在走。

## 9. Story Engine Variation

长期故事是否只是：

`接任务 -> 危险地点 -> 竞争 -> 拿资源 -> 升级 -> 更大地图`

健康长篇可以交替由：

- Life；
- Fantasy；
- World；
- Relationship；
- Mystery；
- War / Competition / Exploration 等

发动。

不要求平均配额，只要因果自然。

## 10. Narrative Compounding

过去结果是否继续活着：

- 旧能力继续用；
- 旧敌人学会；
- 旧关系改变新选择；
- 旧身份带来新限制/机会；
- 旧谜团重释；
- 旧奖励首次真正进入实际行动。

如果每个 arc 结束后像重新开局，复利失败。

## 11. Outline Executability

Outline 应该让 Director 知道“这几十章具体发生什么”，但不提前写成 scene workflow。

好的 story anchor 包括：

- 谁想什么；
- 谁阻止；
- 主角关键选择；
- Core Fantasy 怎样参与；
- 发生什么不可逆结果；
- 这个结果为什么引出下一个 anchor。

坏信号：

- 观察 -> 分析 -> 验证 -> 调整 -> 实施；
- 每个 block 固定升级/奖励/新地图；
- 抽象说“扩大影响力”“获得更多选择权”。

## 12. Scene Realization

正文是否真的把事件写成正在发生的场景？

检查：

- 谁在场；
- 谁想什么；
- 动作有没有收到真实响应；
- 对话有没有改变现场；
- 环境是否参与因果；
- payoff 是否真正发生；
- 结果是否可见。

不要把小纲换成更长的概述。

## 13. Reader-First Information Order

第一章尤其重要：

- 读者先知道该关心什么；
- 核心规则在需要时足够清楚；
- 非重要物理/技术过程不要比核心 fantasy 写得更清楚；
- 新名词、尺度、组织不要在读者没有模型时高速叠加。

“每句都懂，但连起来不知道看什么”通常是 reader model 建立失败。

## 14. Prose Humanization

AI 味常来自结构习惯，而不仅是词汇：

- 每段都总结；
- 抽象解释覆盖具体动作；
- 情绪动作/内心/旁白三重解释；
- 均匀句长；
- 模板化否定排比；
- payoff 预告一次、发生一次、总结一次；
- planning language 直接进入正文。

Humanization 优先修信息与节奏功能，不做禁词表。

## 15. Shock Recontextualization

长期回收是否不只是解释谜团，而能让读者**重新理解已经看过的东西**并产生明显惊讶？

强信号：

- 揭晓当下足够意外；
- 回看前文能找到真实证据、异常或被误读的旧事实；
- 新解释立刻改变力量、身份、关系、敌我、宝物或世界格局；
- 读者会产生“原来如此，而且事情比我以为的大得多”的二次爽感。

它可以来自能力、身份/过去、关系、旧事件、宝物或世界联系，不要求隐藏血脉/身世，也不做固定数量伏笔。

## 16. Narrative Surplus / Organic Surprise

顶级作品经常有“不是为了完成当前系统目标，但就是让人记住”的东西：

- 一个人的小怪癖；
- 一场无收益的比赛；
- 一段关系动作；
- 一个漂亮场面；
- 一次冒险；
- 一种无用但迷人的器物或文化；
- 一个主角明知不划算仍想做的选择。

系统过度优化时最容易先删掉这些 surplus。

它们不是强制配额，但完全没有时，作品容易像精密项目计划。
