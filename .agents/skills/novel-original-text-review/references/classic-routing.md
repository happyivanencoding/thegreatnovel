# Classic Routing Hints

这不是固定书单，也不是质量排名。它只帮助在 400+ 本动态原著库里更快找到与当前问题**同位**的第一批候选。实际任务中，只要其它本地完整原著更合适，就直接使用其它书。

## 成长 / 力量尺 / Public Proof

常见起点：

- 《斗破苍穹》/本地文件《斗破》：力量阶段、公开测试、资源欲望、身份重新定价。
- 《遮天》：尺度扩张、世界入口、强者展示、长期力量身份。
- 《全球高武》：数字力量尺、成长过程、社会价格、群体比较。
- 《斗罗大陆》：等级母语、公开证明、团队人物力量位置。
- 《沧元图》：成长阶段与能力行动空间。
- 《不科学御兽》：现代读者友好的力量说明、契约/宠兽比较与升级期待。

## 世界进入 / 探索 / Mystery

常见起点：

- 《诡秘之主》：陌生世界公共常识、Mystery release、社会生活坐标。
- 《遮天》：奇观、探索、尺度升级与未知边界。
- 《一世之尊》：多世界/副本式进入、身份与主线复合。
- 《惊悚乐园》：副本规则、信息释放、场景目标清晰度。
- 《完美世界》：宏大世界与局部人物行动结合。

## 人物 / 对白 / 关系

常见起点：

- 《将夜》：人物关系、生活感、长短句混合对白、人物自己的人生。
- 《庆余年》：多人对白、信息与关系同时推进、政治/人物压力的场景化。
- 《大奉打更人》：商业网文对白、信息效率与人物语气结合。
- 《修真聊天群》：群体人物声音、轻松对白、多人同时在场仍可辨认。
- 《第一序列》：人物情感、群体关系与行动压力。
- 《诛仙》：关系变化、离别、情绪余波。

## 战斗 / 空间 / Action Scene

常见起点：

- 《遮天》：大尺度战斗与力量表现。
- 《仙逆》：战斗因果、危险判断、能力信息控制。
- 《斗破苍穹》：战斗技法与等级差的 reader-facing 校准。
- 《一世之尊》：多手段战斗、局势变化。
- 《全球高武》：战斗中的等级、资源与伤势状态。

## 长篇人物 / Book Engine / 历史复利

常见起点：

- 《斗罗大陆》：长期人物关系网、人物—人物历史、阶段回归。
- 《将夜》：人物自身人生与主线长期交织。
- 《庆余年》：上一代历史、身份、人物网络持续改变现在。
- 《诡秘之主》：长期 Mystery、身份与组织关系的分层兑现。
- 《凡人修仙传》：长期成长、世界扩张、旧资源/关系在新环境中的再定价。

## 文风 / 叙述节拍 / 克制表达

常见起点：

- 《间客》：人物、社会、行动和叙述节奏的结合。
- 《大道朝天》：极克制表达与信息密度。
- 《雪中悍刀行》：人物关系、长短节拍、情绪与场面。
- 《将夜》：生活质感与商业长篇叙述。
- 《死人经》（若本地完整原著可定位）：人物动机、压抑冲突、行动与心理。

## 使用原则

- 用户点名一本书时，优先读用户点名书，不用路由表替换。
- 未点名时，一般 1—3 本就够；选择互补证据，不做“经典越多越科学”的书目堆积。
- 同一判断如果只来自一部作品，只能说“这个窗口给出一个有效对照”，不能自动升成跨书普遍规律。
- 要升级为 Scene Skill / Stable Principle，仍走现有 Fidelity + cross-book promotion。
